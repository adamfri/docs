    Retrieves a tax group.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/tax-groups/{taxGroupId}
    ```

    ## Path Params

    <ParamField path="taxGroupId" type="string" required>

      ID of the tax group to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="taxGroup" type="TaxGroup">

      Retrieved tax group.

      See the [Tax Group Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-groups/tax-group-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
