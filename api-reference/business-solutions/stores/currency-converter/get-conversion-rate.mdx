    <div className="wix-ref">

    Returns the conversion rate between 2 currencies.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CURRENCY-CONVERTER.MANAGE-CURRENCIES">Manage Currencies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/currency_converter/v1/currencies/rate/{from}/convert/{to}
    ```

    ## Path Params

    <ParamField path="from" type="string" required>

      Original currency.

    </ParamField>

    <ParamField path="to" type="string" required>

      Target currency.

    </ParamField>

    ## Response Object

    <ResponseField name="rate" type="DecimalValue">

      Conversion rate between 2 currencies.

      <Expandable title="rate properties">

        <ResponseField name="value" type="string">

          Value without decimals (e.g., for 10.95 value will be 1095).

        </ResponseField>

        <ResponseField name="decimalPlaces" type="integer">

          Decimal places to apply (e.g., for 10.95 decimal_places will be 2).

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="rateTimestamp" type="datetime">

      Date and time the conversion rate was last updated.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
