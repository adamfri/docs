    <div className="wix-ref">

    Deletes a booking policy.

    You can't delete the default policy without first [setting a different policy as default](https://dev.wix.com/docs/api-reference/business-solutions/bookings/policies/booking-policies/set-default-booking-policy).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/bookings/v1/booking-policies/{bookingPolicyId}
    ```

    ## Path Params

    <ParamField path="bookingPolicyId" type="string" required>

      ID of the booking policy to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteBookingPolicyResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `DEFAULT_POLICY_CANNOT_BE_DELETED` | The default booking policy can't be deleted. Set a different policy as the default before deleting this one. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Booking Policy Deleted | `wix.bookings.v1.booking_policy_deleted` | Triggered when a booking policy is deleted. |

    </div>
