    Validates whether a booking can be rescheduled to a new time slot.

    Wix calls this method when a customer initiates a reschedule, before
    executing the reschedule. Use this to enforce custom business rules,
    for example, membership plan restrictions, pricing plan limits, or external
    calendar availability.

    The request may contain multiple items. Return a result for each `bookingId`.

    If your service returns an error or times out, Wix continues with the
    reschedule (fail-open behavior).

    ## Endpoint

    ```http
    POST /v1/validate-before-reschedule
    ```
