This article covers field support for filtering in
*Count Resource Types*
([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/resource-types/count-resource-types) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resource-types-v2/count-resource-types)).

## Filtering

Specify the `filter` object in the following format:

```json
{
  "filter": {
    "fieldName": {
      "$eq": "value"
    }
  }
}
```

The following table shows field support for filters and sorting for the
`resourceType` object:

| Field   | Supported Filters                                                 | Sortable |
|---------|-------------------------------------------------------------------|----------|
| `id`    | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`             | Sortable |
| `name`  | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`, `$isEmpty` | Sortable |
