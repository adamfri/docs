    Asynchronously updates tags on multiple invoices that match the provided filter criteria.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    To update tags on specific invoices by ID, call [Bulk Update Invoice Tags](https://dev.wix.com/docs/api-reference/business-management/get-paid/invoices/invoices/bulk-update-invoice-tags).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/bulk/invoices/update-tags-by-filter
    ```

    ## Examples

    Updates tags on multiple invoices using filter criteria.

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/invoices/v4/bulk/invoices/update-tags-by-filter' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        -d '{
          "filter": {
            "status": {"$eq": "DRAFT"},
            "customerInfo.contactId": {"$in": [
              "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
              "b2c3d4e5-f6a7-8901-bcde-f23456789012"
            ]},
            "issueDate": {"$gte": "2024-01-01T00:00:00.000Z"}
          },
          "assignTags": {
            "publicTags": {
              "tagIds": [
                "proce",
                "revie",
                "batch"
              ]
            }
          },
          "unassignTags": {
            "publicTags": {
              "tagIds": [
                "pendi",
                "draft"
              ]
            }
          }
        }'
      ```

