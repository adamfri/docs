    Creates a back in stock notification request.

    If a notification request already exists for the same `catalogReference` and `email`,
    then a new one isn't created and the existing request is returned.

    Back in stock notifications only work for [Wix Stores](https://support.wix.com/en/article/wix-stores-about-wix-stores).
    The `appId` for Wix Stores is `"215238eb-22a5-4c36-9e7b-e7c08025e04e"`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES-MEGA.MANAGE-STORES">Manage Stores - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/back-in-stock-service/v1/back-in-stock-notification-requests
    ```

    ## Body Params

    <ParamField body="request" type="BackInStockNotificationRequest" required>

      Notification request information.

      Includes details for the out of stock item and the email address
      requesting to be notified when it's back in stock.

      See the [Back In Stock Notification Request Object](/api-reference/business-solutions/e-commerce/other-services/back-in-stock/back-in-stock-notifications/back-in-stock-notification-request-object) for this object's fields.

    </ParamField>

    <ParamField body="itemDetails" type="BackInStockItemDetails" required>

      Item details to include in the notification when the item is back in stock.

      <Expandable title="itemDetails properties">

        <ParamField body="name" type="string" required>

          Item name.

        </ParamField>

        <ParamField body="price" type="string" required>

          Item price.

          Constraints: `>= 0`.

        </ParamField>

        <ParamField body="image" type="Image">

          Item image.

          <Expandable title="image properties">

            <ParamField body="id" type="string">

              WixMedia image ID.

            </ParamField>

            <ParamField body="url" type="string">

              Image URL.

            </ParamField>

            <ParamField body="height" type="integer">

              Original image height.

              **Read-only.**

            </ParamField>

            <ParamField body="width" type="integer">

              Original image width.

              **Read-only.**

            </ParamField>

            <ParamField body="altText" type="string">

              Image alt text.

            </ParamField>

            <ParamField body="filename" type="string">

              Image filename.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="request" type="BackInStockNotificationRequest">

      Created back in stock notification request.

      See the [Back In Stock Notification Request Object](/api-reference/business-solutions/e-commerce/other-services/back-in-stock/back-in-stock-notifications/back-in-stock-notification-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `BACK_IN_STOCK_NOTIFICATION_REQUEST_ALREADY_EXISTS` | There is already a back in stock notification request for this `catalogReference` and `email`. |
    | `428` | `FAILED_PRECONDITION` | `REQUEST_COLLECTION_DISABLED` | Request collection is disabled for this app. Enable it using the Start Collecting Requests method. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CATALOG_REFERENCE_OPTIONS` | The `catalogReference.options` field contains invalid option IDs or choice IDs. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_ITEM_IMAGE_URL` | The `itemDetails.image.url` field contains an invalid URL. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
