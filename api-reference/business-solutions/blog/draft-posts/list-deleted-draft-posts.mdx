    Retrieves a list of up to 100 deleted draft posts.

    List Draft Posts runs with these defaults, which you can override:
    - `editedDate` is sorted in descending order. In this case,`editedDate` implies the date the post was deleted.
    - `paging.limit` is `50`.
    - `paging.offset` is `0`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/blog/v3/draft-posts/trash-bin
    ```

    ## Query Params

    <ParamField query="language" type="string">

      Language filter.

      2-or-4-letter language code in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.
      If omitted, deleted draft posts in all languages are returned.

    </ParamField>

    <ParamField query="sort" type="string">

      Sorting options.

      Default: `EDITING_DATE_DESCENDING`

      **Supported values:**

      - `EDITING_DATE_DESC` — Sort by `editedDate` in descending order.
      - `EDITING_DATE_ASC` — Sort by `editedDate` in ascending order.

    </ParamField>

    <ParamField query="paging" type="BlogPaging">

      Pagination options.

      <Expandable title="paging properties">

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

          Default: `0`

          Constraints: `min 0`.

        </ParamField>

        <ParamField query="limit" type="integer">

          Number of items to return.

          Default:`50`

          Constraints: `min 1`, `max 100`.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      List of additional draft post fields to include in the response. For example, use the `URL` fieldset to retrieve the url field in
      the response in addition to the draft post's base fields. Base fields don’t include any of the supported fieldset values. By default
      only the draft post's base fields are returned.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes draft post preview URL.
      - `CONTENT` — Includes content field.
      - `RICH_CONTENT` — Includes rich content field.
      - `GENERATED_EXCERPT` — If the user has not set excerpt, returns the one autogenerated from content.

    </ParamField>

    <ParamField query="draftPostIds" type="string[]">

      Draft post ids.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>
