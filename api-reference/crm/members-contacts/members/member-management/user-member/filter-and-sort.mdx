| `metaSiteId`             | `$eq`, `$ne`, `$in`, `$nin`, `$exists`, `$hasSome`, `$startsWith`                               | Sortable |
| `createdDate`            | `$eq`, `$ne`, `$in`, `$nin`, `$lt`, `$lte`, `$gt`, `$gte`, `$exists`, `$hasSome`, `$startsWith` | Sortable |
| `siteMembersInstanceId`  | `$eq`, `$ne`, `$in`, `$nin`, `$exists`, `$hasSome`, `$startsWith`                               | Sortable |
