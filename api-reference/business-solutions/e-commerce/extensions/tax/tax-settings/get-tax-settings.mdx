    Retrieves the site's tax settings.

    If the site's tax settings have never been set, default values are returned.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="billing:tax:v1:tax_settings:get_tax_settings">billing:tax:v1:tax_settings:get_tax_settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/tax-settings
    ```

    ## Response Object

    <ResponseField name="taxSettings" type="TaxSettings">

      Retrieved tax settings.

      See the [Tax Settings Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-settings/tax-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
