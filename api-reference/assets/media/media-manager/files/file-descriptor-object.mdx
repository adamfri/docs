Docs for Folder in Media

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      File ID. Generated when a file is uploaded to the Media Manager.

      **Read-only.** Constraints: `maxLength 1000`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      File name as it appears in the Media Manager.

      Constraints: `maxLength 255`.

    </ResponseField>

    <ResponseField name="url" type="string">

      Static URL of the file.

      **Read-only.** Constraints: `format WEB_URL`.

    </ResponseField>

    <ResponseField name="parentFolderId" type="string">

      ID of the file's parent folder.

    </ResponseField>

    <ResponseField name="hash" type="string">

      File hash.

      **Read-only.** Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="sizeInBytes" type="string">

      Size of the uploaded file in bytes.

      **Read-only.**

    </ResponseField>

    <ResponseField name="private" type="boolean">

      Whether the file is public or private. Learn more about [private files](https://dev.wix.com/docs/rest/assets/media/media-manager/files/private-files).

      **Read-only.**

    </ResponseField>

    <ResponseField name="mediaType" type="string">

      Media file type.

      **Read-only.**

      **Supported values:**

      - `IMAGE`
      - `VIDEO`
      - `AUDIO`
      - `DOCUMENT`
      - `VECTOR`
      - `ARCHIVE`
      - `MODEL3D`
      - `OTHER`

    </ResponseField>

    <ResponseField name="operationStatus" type="string">

      Status of the file that was uploaded.

      **Read-only.**

      **Supported values:**

      - `FAILED` — The file failed to upload, for example, during media post processing.
      - `READY` — The file uploaded, finished all processing, and is ready for use.
      - `PENDING` — The file is processing and the URLs are not yet available. This response is returned when importing a file.

    </ResponseField>

    <ResponseField name="sourceUrl" type="string">

      URL where the file was uploaded from.

      **Read-only.**

    </ResponseField>

    <ResponseField name="thumbnailUrl" type="string">

      URL of the file's thumbnail.

      **Read-only.**

    </ResponseField>

    <ResponseField name="labels" type="string[]">

      Labels assigned to media files that describe and categorize them. Provided by the Wix user, or generated by [Google Vision API](https://cloud.google.com/vision/docs/drag-and-drop) for images.

      Constraints: `maxLength 200`, `maxItems 100`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the file was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the file was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="siteId" type="string">

      The Wix site ID where the media file is stored.

      **Read-only.** Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="state" type="string">

      State of the file.

      **Read-only.**

      **Supported values:**

      - `OK` — File is ready for consumption
      - `DELETED` — Deleted file

    </ResponseField>
