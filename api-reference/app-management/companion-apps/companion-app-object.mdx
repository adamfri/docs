A companion app is a site-tenanted app, coupled to one Wix site only, that lets the site use
app-provided features to customize itself.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Companion app ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the companion app. `READY` means the companion app can be used,
      `CLONING` means site duplication is still in progress, and
      `CLONE_FAILED` means the duplication process didn't complete successfully.

      **Supported values:**

      - `CLONING` — The companion app is being prepared during site duplication and may not be ready to use.
      - `READY` — The companion app is ready to use on the current site.
      - `CLONE_FAILED` — The companion app couldn't be prepared during site duplication. Retry duplication later or show the failure to the user.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the companion app was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the companion app was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "companionApp": {
          "id": "b59368ab-f194-452b-9fde-12123d4177ba",
          "status": "READY",
          "createdDate": "2026-08-06T11:36:07.490Z",
          "updatedDate": "2026-08-06T11:36:07.490Z"
        }
      }
      ```

    </CodeGroup>
