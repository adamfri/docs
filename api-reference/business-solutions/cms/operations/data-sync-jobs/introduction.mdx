> **Note for app developers:** Wix Data APIs require the site's [code editor](##code-editor*fallback::https://dev.wix.com/docs/develop-websites/articles/getting-started/development-environments#code-editor) to be enabled. If you are building a Wix app, add a [data collections extension](fallback::https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/data-collections/about-data-collections-extensions) to automatically enable the code editor and create data collections when your app is installed on a site.

The Data Sync Jobs API enables you to create and manage recurring data synchronization jobs that automatically run data movement operations on a schedule. This API works in conjunction with the [Data Movement Jobs API](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-movement-jobs/introduction) to provide a complete solution for scheduled, automated data transfers between sources and destinations.

With the Data Sync Jobs API, you can:

+ [Create](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-sync-jobs/create-data-sync-job) or [delete](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-sync-jobs/delete-data-sync-job) recurring data synchronization jobs with cron-based scheduling.
+ [Get](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-sync-jobs/get-data-sync-job) or [list](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-sync-jobs/list-data-sync-jobs) data sync jobs.
+ [Enable or disable jobs](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-sync-jobs/update-data-sync-job) without losing their configuration.

## Before you begin

It's important to note the following before starting to code:

+ Cross-site data synchronization requires sites to be in the same Wix account.
+ [Cron expressions](fallback::https://en.wikipedia.org/wiki/Cron#Cron_expression) use standard 5-field format in [UTC](fallback::https://en.wikipedia.org/wiki/Coordinated_Universal_Time) with minute-level precision only.

## Use case
+ [Automate recurring data transfers and monitor execution results](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-sync-jobs/sample-flows).

## Terminology

+ **Data sync job**: A recurring scheduled job that automatically runs data movement operations according to a cron expression.
+ **Data movement job**: An individual execution instance created each time a data sync job runs, through the [Data Movement Jobs API](fallback::https://dev.wix.com/docs/api-reference/business-solutions/cms/operations/data-movement-jobs/introduction).
+ **Reschedule**: Trigger an immediate execution of a sync job outside its normal cron schedule.
