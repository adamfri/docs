    Retrieves a list of rewards.

    The list includes rewards that are currently nonredeemable due to insufficient points held by any customers.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-rewards/v1/rewards
    ```

    ## Query Params

    <ParamField query="cursorPaging" type="CursorPaging">

      Pagination options.

      <Expandable title="cursorPaging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">
