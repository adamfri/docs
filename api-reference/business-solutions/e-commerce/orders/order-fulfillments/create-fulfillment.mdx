    Creates an order fulfillment.

    A line item's quantity can be split across multiple fulfillments. When `lineItems[i].quantity` isn't passed, it defaults to the line item's remaining unfulfilled quantity.

    <Note>

    + Fulfillments can only be created for orders with `status: "APPROVED"`.
    + When passing `trackingInfo`, both `trackingNumber` and `shippingProvider` are required.
    + Don't pass `fulfillment.id`. It's assigned automatically and passing it results in an error.
    + A shipping notification email may be sent to the buyer when the fulfillment is created, depending on the site's email settings.
    + The order's `fulfillmentStatus` is recalculated asynchronously after the call.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/fulfillments/orders/{orderId}/create-fulfillment
    ```

    <ParamField path="orderId" type="string" required>

      Order ID.

    </ParamField>

    ## Body Params

    <ParamField body="fulfillment" type="Fulfillment" required>

      Fulfillment info.

      <Expandable title="fulfillment properties">

        <ParamField body="id" type="string">

          Fulfillment ID.

          **Read-only.**

        </ParamField>

        <ParamField body="createdDate" type="datetime">

          Fulfillment creation date and time in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations) format.

          **Read-only.**

        </ParamField>

        <ParamField body="lineItems" type="FulfillmentLineItem[]" required>

          Line items being fulfilled.

          Constraints: `minItems 0`, `maxItems 300`.

          <Expandable title="lineItems properties">

            <ParamField body="id" type="string" required>

              Line item ID (mirrors the ID of the order line item).

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="quantity" type="integer">

              Line item quantity.

              * If this property isn't passed on creation, it defaults to the number of items not already linked to a fulfillment.
              * If the order does not have the requested quantity of line items available to add to this fulfillment, the fulfillment will not be created and an error is returned.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="status" type="string">

          The current status of the fulfillment process.

          Supported values (case-sensitive, any other value is rejected):
          + `"Pending"` - Initial state when fulfillment is created but processing hasn't started.
          + `"Accepted"` - Order has been received and validated for fulfillment.
          + `"Ready"` - Items have been picked and packed, ready for shipping.
          + `"In_Delivery"` - Items have been handed over to the shipping carrier.
          + `"Fulfilled"` - Delivery has been completed successfully.

          The status typically progresses from `Pending` to `Accepted`, `Ready`, `In_Delivery`, and finally `Fulfilled`.
          Update the status manually or automatically depending on your fulfillment workflow.

          This field is informational. The order's `fulfillmentStatus` is primarily derived from the fulfilled line item quantities, not from this field.

        </ParamField>

        <ParamField body="completed" type="boolean">

          Fulfillment handling complete.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="FulfillmentInfo" type="FulfillmentInfo">

          FulfillmentInfo

          <Expandable title="FulfillmentInfo properties">

            <ParamField body="trackingInfo" type="FulfillmentTrackingInfo">

              Tracking info.

              _Nested structure omitted for brevity — see the `FulfillmentTrackingInfo` object._

            </ParamField>

            <ParamField body="customInfo" type="CustomFulfillmentInfo">

              Custom fulfillment info.

              _Nested structure omitted for brevity — see the `CustomFulfillmentInfo` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
