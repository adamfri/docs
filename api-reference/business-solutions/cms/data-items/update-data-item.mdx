    Updates an item in a collection.

    Call this method when you want to replace an existing item's payload and expect the item to already exist. For different behavior, you can call:

    - [Patch Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/patch-data-item) to make partial field changes that keep the rest of the payload unchanged.
    - [Save Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/save-data-item) for upsert behavior, meaning to create the item if it doesn't exist and update it if it does.

    This method replaces the data item's existing data with the payload provided in `dataItem.data` in the request.

    To update an item, you need to specify an item ID and a collection ID.
    If an item is found in the specified collection with the specified ID, that item is updated.
    If the collection doesn't contain an item with that ID, the request fails.

    When an item is updated, its `data._updatedDate` field is changed to the current date and time.

    <Note>

    After an item is updated, it only contains the fields included in the `dataItem.data` payload in the request. If the existing item has fields with values and those fields aren't included in the updated item, their values are lost.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/data/v2/items/{dataItem.id}
    ```

    ## Path Params

    <ParamField path="dataItem.id" type="string" required>

      Data item ID.

      When an item is inserted into a collection, the item's ID is automatically assigned a random value. You can optionally provide a custom ID in `dataItem.id` when inserting the item. If you specify an ID that already exists in the collection, the insertion will fail.

    </ParamField>

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection containing the existing item.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="dataItem" type="DataItem" required>

      Updated data item content. The existing data item's content is replaced entirely.

      See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

    </ParamField>

    <ParamField body="appOptions" type="object">

      Additional parameters specific to the [Wix app collection](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-wix-app-collections) you are querying.

      When querying the Wix Stores [Products collection](https://dev.wix.com/docs/develop-websites/articles/wix-apps/wix-e-commerce-stores/wix-stores-products-collection-fields), pass the following optional parameters:
      - `includeHiddenProducts`: Whether to include hidden products in the response. Default: `false`.
      - `includeVariants`: Whether to include product variants in the query. Default: `false`.

    </ParamField>

    <ParamField body="publishPluginOptions" type="PublishPluginOptions">

      Options for the Publish plugin.
      This plugin allows items in a [data collection](https://dev.wix.com/docs/rest/business-solutions/cms/data-collections/data-collection-object) to be marked as draft or published. Published items are visible to site visitors, while draft items are not.

      <Expandable title="publishPluginOptions properties">

        <ParamField body="includeDraftItems" type="boolean">

          Whether to include draft items.

          When `true`, both published and draft items are affected. Default: `false`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="condition" type="Condition">

      Condition for updating the item.

      When a condition is provided, the item is only updated if the condition is met.

      <Expandable title="condition properties">

        <ParamField body="filter" type="object">

          Filter, changes to item(s) will only apply if they satisfy this filter.
          Learn more about filters in [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language#filters).

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="dataItem" type="DataItem">

      Updated data item.

      See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

    </ResponseField>
