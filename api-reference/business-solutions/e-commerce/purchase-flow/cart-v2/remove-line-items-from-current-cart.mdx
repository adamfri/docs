    Removes line items from the customer's current cart.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2">Write Carts V2</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/current/remove-line-items
    ```

    ## Body Params

    <ParamField body="lineItemIds" type="string[]" required>

      Line item IDs to remove from the current cart.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CART_ALREADY_ORDERED` | Cart was already placed as an order. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEM_NOT_FOUND_IN_CART` | Couldn't find the line item in the cart. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Cart Updated | `wix.ecom.v2.cart_updated` | Triggered when a cart is updated. |

    </div>
