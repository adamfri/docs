    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/fulfillment-methods/v1/fulfillment-methods/{fulfillmentMethodId}
    ```

    ## Path Params

    <ParamField path="fulfillmentMethodId" type="string" required>

      The ID of the fulfillment method to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="fulfillmentMethod" type="FulfillmentMethod">

      The retrieved fulfillment method.

      See the [Fulfillment Method Object](/api-reference/business-solutions/restaurants/online-orders/fulfillment-methods/fulfillment-method-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
