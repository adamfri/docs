    ## Examples

    Updates Payment Links Settings

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
        'https://www.wixapis.com/payment-links/v1/payment-links-settings' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        --data-binary '{
          "paymentLinksSettings": {
            "policyAgreementCheckboxDisabled": true,
            "continueShoppingButtonDisabled": true
          },
          "fieldMask": {
            "paths": [
              "policyAgreementCheckboxDisabled",
              "continueShoppingButtonDisabled"
            ]
          }
       }'
      ```

      ```json Response
      {
        "paymentLinksSettings": {
          "revision": 2,
          "policyAgreementCheckboxDisabled": true,
          "continueShoppingButtonDisabled": true
        }
      ```
