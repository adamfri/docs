    <div className="wix-ref">

    Searches intake form submissions using full-text search across submission content.

    Submissions belonging to deleted intake forms aren't returned by Search Intake Form Submissions.

    Use this method to search for submissions by text content within the form fields.
    For filtering by specific criteria such as contact ID, form ID, or status, call [Query Intake Form Submissions](https://dev.wix.com/docs/api-reference/crm/forms/other-services/intake-forms/intake-form-submissions/query-intake-form-submissions) instead.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.READ">Read Intake Form</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/intake-forms/v1/submissions/search
    ```
