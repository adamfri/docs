    Retrieves a manual tax mapping by ID.

    Use this method to get details about a specific manual tax mapping, including its tax rate,
    jurisdiction information, and associated tax group and region.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/manual-tax-mappings/{manualTaxMappingId}
    ```

    ## Path Params

    <ParamField path="manualTaxMappingId" type="string" required>

      Manual tax mapping ID.

    </ParamField>

    ## Response Object

    <ResponseField name="manualTaxMapping" type="ManualTaxMapping">

      Retrieved manual tax mapping.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
