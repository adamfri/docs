Triggered when a task reaches its due date.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.tasks.v2.task_task_overdue` |
| Package | `@wix/crm` |
| Permissions | `Read Tasks`, `Manage Tasks` |
