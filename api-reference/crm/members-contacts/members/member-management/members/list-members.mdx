    <div className="wix-ref">

    Lists site members, given the provided paging and fieldsets.

    A member's default privacy status is `"PRIVATE"`. Private members aren't returned in the response if a [site visitor](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities#site-visitor) or [site member](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities#site-member) identity calls this method. Learn more about [managing your member privacy settings](https://support.wix.com/en/article/site-members-managing-your-member-privacy-settings).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/members
    ```

    ## Query Params

    <ParamField query="paging" type="Paging">

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      Predefined sets of fields to return.

      Default: `"PUBLIC"`.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `PUBLIC` — Includes `id`, `contactId`, `createdDate`, `updatedDate` and the `profile` object.
      `status`, `privacyStatus`, and `activityStatus` are returned as `UNKNOWN`.
      - `EXTENDED` — Includes `id`, `loginEmail`, `status`, `contactId`, `createdDate`, `updatedDate`, `privacyStatus`, `activityStatus` and the `profile` object.
      - `FULL` — Includes all fields.

    </ParamField>

    <ParamField query="sorting" type="Sorting[]">

      <Expandable title="sorting properties">

        <ParamField query="fieldName" type="string">

          Name of the field to sort by.

          Constraints: `maxLength 512`.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.

          **Supported values:**

          - `ASC`
          - `DESC`

        </ParamField>

        <ParamField query="origin" type="AddressLocation">

          Origin point for geo-distance sorting on a GEO field
          results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

          <Expandable title="origin properties">

            <ParamField query="latitude" type="number">

              Address latitude.

            </ParamField>

            <ParamField query="longitude" type="number">

              Address longitude.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="members" type="Member[]">

      List of members.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Metadata for the paginated results.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

      </Expandable>

    </ResponseField>
