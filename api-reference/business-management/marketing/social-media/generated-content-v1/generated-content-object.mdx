Generated content is AI-created post material, such as captions, titles, and images, produced from a text prompt or a site's assets. Use generated content to build a post and then publish it as an item.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Generated content ID.

      **Read-only.**

    </ResponseField>

      ```json Object
        }
      }
      ```
