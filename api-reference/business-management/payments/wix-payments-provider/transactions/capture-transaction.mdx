Manually captures an authorized transaction by ID.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-TRANSACTIONS">Manage Transactions</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/payments/v3/transactions/{transactionId}/capture
```

## Path Params

<ParamField path="transactionId" type="string" required>

  Transaction ID.

</ParamField>

## Body Params

<ParamField body="accountId" type="string" required>

  Wix Payments account ID.

  Constraints: `format GUID`.

</ParamField>

<ParamField body="amount" type="integer">

  Amount to capture in minor units (for example, cents). When not passed, the whole transaction amount will be captured.

</ParamField>

<ParamField body="capturableAmount" type="integer">

  Amount that can be captured or voided in minor units to place a hold on a card to reserve funds.
  Specify the amount to prevent double partial captures.

</ParamField>

<ParamField body="idempotencyKey" type="string">

  Key to ensure idempotency.

</ParamField>

<ParamField body="externalCaptureId" type="string">

  Corresponding capture ID within the external entity that initiated the transaction capture.

</ParamField>

<ParamField body="metadata" type="object">

  Metadata to store within the created capture.

  Constraints: `format map`, `maxItems 16`.

  <Expandable title="metadata properties">

    <ParamField body="key" type="string" />

    <ParamField body="value" type="string" />

  </Expandable>

</ParamField>

## Response Object

<ResponseField name="transaction" type="Transaction">

  Captured transaction information.

  See the [Transaction Object](/api-reference/business-management/payments/wix-payments-provider/transactions/transaction-object) for this object's fields.

</ResponseField>

<ResponseField name="captureId" type="string">

  Capture ID.

  Constraints: `format GUID`.

</ResponseField>

## Errors

| Status | Code | Application code | Description |
| --- | --- | --- | --- |
| `409` | `ALREADY_EXISTS` | `TRANSACTION_ALREADY_CAPTURED` | Transaction was already captured. |

<Note>

  This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
