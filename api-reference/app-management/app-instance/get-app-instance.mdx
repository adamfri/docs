    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves data about the instance of your app that's installed on a Wix
    site and data about the site itself. For example, to check whether the Wix user has installed a free or paid version of your app,
    or to check which apps made by Wix are installed on the site.

    You must authenticate this method [as a Wix app](https://dev.wix.com/docs/build-apps/develop-your-app/access/authentication/authenticate-using-oauth#step-2--make-an-authenticated-api-request).

    To retrieve `site.ownerInfo` in the response, you must
    have the __READ SITE OWNER EMAIL__ permission scope in addition to
    __MANAGE YOUR APP__.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/instance
    ```

    ## Response Object

    <ResponseField name="instance" type="AppInstance">

      Retrieved app instance.

      See the [App Instance Object](/api-reference/app-management/app-instance/app-instance-object) for this object's fields.

    </ResponseField>

    <ResponseField name="site" type="SiteInfo">

      Information about the site.

      <Expandable title="site properties">

        <ResponseField name="siteDisplayName" type="string">

          Display name of the site.

        </ResponseField>

        <ResponseField name="locale" type="string">

          2-letter language code of the site's locale in
          [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) format.

        </ResponseField>

        <ResponseField name="paymentCurrency" type="string">

          3-letter currency code for the site's billing in
          [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) format.

        </ResponseField>

        <ResponseField name="multilingual" type="Multilingual">

          Information about the site's supported languages.

          <Expandable title="multilingual properties">

            <ResponseField name="isMultiLingual" type="boolean">

              Whether the site supports more than a single language.

            </ResponseField>

            <ResponseField name="supportedLanguages" type="SupportedLanguage[]">

              List of supported languages. Returned only when `{"isMultiLingual": true}`.

              _Nested structure omitted for brevity — see the `SupportedLanguage[]` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="url" type="string">

          URL of the site. Available only when the site has been published.

        </ResponseField>

        <ResponseField name="description" type="string">

          Description of the site.

        </ResponseField>

        <ResponseField name="installedWixApps" type="string[]">

          Apps made by Wix that are installed on the site.

        </ResponseField>

        <ResponseField name="ownerEmail" type="string">

          > **Deprecation Notice:** This parameter will be removed on June 30, 2022. Use `ownerInfo` instead.

        </ResponseField>

        <ResponseField name="ownerInfo" type="OwnerInfo">

          Information about the site's Wix user. Available only when calling
          _Get App Instance_ with the __Read Site Owner Email__ permission scope.

          <Expandable title="ownerInfo properties">

            <ResponseField name="email" type="string">

              Wix user's email address. Identical to the their login email.

              Constraints: `format EMAIL`.

            </ResponseField>

            <ResponseField name="emailStatus" type="string">

              Supported values: `VERIFIED_OPT_IN`, `VERIFIED_OPT_OUT`,
              `NOT_VERIFIED_OPT_IN`, `NOT_VERIFIED_OPT_OUT`.

              Whether the Wix user has verified their email and whether they have chosen
              to receive email notifications from Wix.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="siteId" type="string">

          Site ID.

        </ResponseField>

        <ResponseField name="siteUserType" type="string">

          Type of Wix user who owns the site.
          Available only when calling _Get App Instance_ with the __Read Site User Type__ permission scope.
          Supported values: `"Channel DIY"`, `"Channel DIFM"`, `"Enterprise"`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
