    Retrieves an inventory item.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INVENTORY_ITEM_READ">Read inventory in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/inventory-items/{inventoryItemId}
    ```

    ## Path Params

    <ParamField path="inventoryItemId" type="string" required>

      Inventory item ID.

    </ParamField>

    ## Response Object

    <ResponseField name="inventoryItem" type="InventoryItem">

      Inventory item.

      See the [Inventory Item Object](/api-reference/business-solutions/stores/catalog-v3/inventory-items-v3/inventory-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
