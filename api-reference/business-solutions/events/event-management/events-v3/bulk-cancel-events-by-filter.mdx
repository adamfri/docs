    <div className="wix-api-columns">

    <div className="wix-ref">

    Cancels multiple events that meet the specified criteria. <br /> <br />
    After cancellation, registration for an event is closed. To reuse the event, call Clone Event and Publish Event to publish it again. <br /> <br />
    If event cancellation notifications are enabled, canceling an event automatically triggers the sending of cancellation emails and/or push notifications to registered guests.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/bulk/events/cancel-by-filter
    ```

    ## Body Params
