<Tabs>

  <Tab title="REST">

    Checks a restaurant's availability to accommodate a reservation for a specified party size in a specified time slot.

    This endpoint returns availability information for the restaurant's table combinations, and flags any party pacing or seat pacing conflicts that the proposed reservation would cause.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-MEDIUM">Manage Reservations (Medium)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/reservations/v1/check-time-slot
    ```

    ## Body Params

    <ParamField body="reservationLocationId" type="string" required>

      ID of the reservation location for which to check the time slot.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="date" type="datetime" required>

      Date and time of the time slot to check.

    </ParamField>

    <ParamField body="duration" type="integer" required>

      Duration of the time slot in minutes .

      Min: `5`

    </ParamField>

    <ParamField body="partySize" type="integer" required>

      Party size to check the restaurant's availability for.

    </ParamField>

    <ParamField body="excludeReservationId" type="string">

      ID of a reservation to ignore during the check.

      Use this when rescheduling a reservation to exclude it in its current state from the availability calculations.

    </ParamField>

    ## Response Object

    <ResponseField name="tableCombinationAvailabilities" type="TableCombinationAvailability[]" deprecated>

      Table combinations and their availability information.

      **Deprecated.** Use `time_slot_availability` instead. Removal: 2025-12-05.

      <Expandable title="tableCombinationAvailabilities properties">

        <ResponseField name="tableIds" type="string[]">

          IDs of the tables in the table combination.

          Constraints: `format GUID`, `maxItems 2000`.

        </ResponseField>

        <ResponseField name="tableCombinationConflicts" type="string[]">

          Conflicts that would be generated by attempting to accommodate the proposed reservation using the table combination.

          Constraints: `maxItems 2`.

          **Supported values:**

          - `RESERVED` — One or more of the chosen tables are already reserved.
          - `TOO_BIG` — The party is too big for the selected table.
          - `TOO_SMALL` — The party is too small for the selected table.
          - `OFFLINE_ONLY` — The restaurant does not allow online reservations.
          - `RESERVED_FOR_EXPERIENCE` — The table is reserved for an active experience.
          - `TABLE_NOT_IN_AREA` — The table is not in the requested area.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="reservationLocationConflicts" type="string[]" deprecated>

      Reservation location conflicts that would occur by making a reservation for the specified party size in the specified time slot.

      **Deprecated.** Use `time_slot_availability` instead. Removal: 2025-12-05.

      **Supported values:**

      - `PARTY_PACING` — The restaurant cannot accommodate a party of the given size according to party pacing settings.
      - `SEAT_PACING` — The required number of seats are unavailable according to seat pacing settings.

    </ResponseField>

    <ResponseField name="timeSlotAvailability" type="TimeSlotAvailability">

      Time slot availability

      <Expandable title="timeSlotAvailability properties">

        <ResponseField name="timeSlotAvailabilityType" type="string">

          Type of availability.

          **Supported values:**

          - `STANDARD`
          - `EXPERIENCE`

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="options" type="options">

          options

          <Expandable title="options properties">

            <ResponseField name="standardOptions" type="StandardOptions">

              Response for standard reservation.

              _Nested structure omitted for brevity — see the `StandardOptions` object._

            </ResponseField>

            <ResponseField name="experienceOptions" type="ExperienceOptions">

              Response for a reservation that contains experience.

              _Nested structure omitted for brevity — see the `ExperienceOptions` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
