    Retrieves the optimization suggestions generated for a page.

    Poll this method after a trigger call. The response's `status` reports
    where the job stands: while generation is still in progress the
    suggestions are empty and `status` is `IN_PROGRESS`; when it completes,
    the response carries the full suggestion set with `status` `COMPLETED`.
    A job that failed reports `FAILED`. Trigger again to retry. Suggestions
    are stored per page, so a later trigger for the same page replaces them,
    and a replaced job's lookup reports `NOT_FOUND`.

    Look up by `predictionId` (from the trigger call), or by `pageId`. A
    `predictionId` can be looked up for 2 hours after the trigger call; after
    that, look up by `pageId`, which returns the page's latest generation.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/seo/suggestions/v1/page-optimization/results
    ```

    ## Query Params

    <ParamField query="predictionId" type="string">

      ID of the generation job, from the trigger call. Can be looked up for 2
      hours after the trigger call.

    </ParamField>

    <ParamField query="pageId" type="string">

      ID of the page to retrieve suggestions for. An alternative to
      `predictionId` that returns the page's latest generation.

    </ParamField>

    ## Response Object

    <ResponseField name="pageOptimization" type="PageOptimization">

      The generated suggestions. Returned only when `status` is `COMPLETED`.

      See the [Page Optimization Object](/api-reference/business-management/seo/page-optimization-v1/page-optimization-object) for this object's fields.

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the generation job the lookup matched.

      **Read-only.**

      **Supported values:**

      - `UNKNOWN_OPTIMIZATION_STATUS` — Unknown status.
      - `NOT_FOUND` — No generation job matches the lookup. It never existed, or a later
      trigger for the same page replaced it.
      - `IN_PROGRESS` — Generation is still running. Poll again.
      - `COMPLETED` — Generation finished; the response carries the suggestions.
      - `FAILED` — Generation failed. Trigger again to retry.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `GENERATION_FAILED` | Reading the stored result failed. Retry the call. |
    | `429` | `RESOURCE_EXHAUSTED` | `QUOTA_LIMIT_REACHED` | The caller's generation quota is exhausted. Reserved for future metering and not currently returned. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
