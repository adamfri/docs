Removes one or more references.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/data/v2/bulk/items/remove-references
```

## Body Params

<ParamField body="dataCollectionId" type="string" required>

  ID of the collection containing the referring items.

  Constraints: `maxLength 256`.

</ParamField>

<ParamField body="dataItemReferences" type="DataItemReference[]" required>

  References to remove.

  Constraints: `maxItems 1000`.

  <Expandable title="dataItemReferences properties">

    <ParamField body="referringItemFieldName" type="string" required>

      Referring item field containing the references to the referenced items.

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField body="referringItemId" type="string" required>

      ID of the referring item.

      Constraints: `maxLength 128`.

    </ParamField>

    <ParamField body="referencedItemId" type="string" required>

      ID of the referenced item.

      Constraints: `maxLength 128`.

    </ParamField>

  </Expandable>

</ParamField>

    </ResponseField>

      Metadata related to the reference for which the action was attempted.
