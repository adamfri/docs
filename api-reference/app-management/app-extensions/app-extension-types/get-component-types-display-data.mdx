    Retrieves display metadata for the available component types.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DEV_CENTER.READ_COMPONENTS_CATALOG">DEV_CENTER.READ_COMPONENTS_CATALOG</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/components/v1/components-catalog
    ```

    ## Response Object

    <ResponseField name="componentTypesDisplayData" type="ComponentTypeDisplayData[]">

      Display metadata for the available component types.

      <Expandable title="componentTypesDisplayData properties">

        <ResponseField name="type" type="string">

          Component type.

          Constraints: `maxLength 128`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Component type display name.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="labels" type="string[]">

          Labels shown for components of this type.

          Constraints: `maxLength 64`, `maxItems 32`.

        </ResponseField>

        <ResponseField name="attributes" type="Attributes">

          Rules enforced for components of this type, such as singular, non-updatable, and non-deletable behavior.

          <Expandable title="attributes properties">

            <ResponseField name="singular" type="boolean">

              Whether only one component of this type can exist per app.

            </ResponseField>

            <ResponseField name="nonDeletable" type="boolean">

              Whether components of this type can't be deleted.

            </ResponseField>

            <ResponseField name="nonUpdatable" type="boolean">

              Whether components of this type can't be updated.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="description" type="string">

          Component type description shown in the App Dashboard.

        </ResponseField>

        <ResponseField name="exposure" type="string">

          Exposure level of the component type.

          **Supported values:**

          - `PRIVATE` — Unexposed. to be used by dev team only
          - `INTERNAL` — Exposed internally
          - `PUBLIC` — Exposed to the world

        </ResponseField>

        <ResponseField name="learnMoreLink" type="string">

          Link to learn more about the component type.

        </ResponseField>

        <ResponseField name="requiresApproval" type="boolean">

          Whether components of this type require approval before release.

        </ResponseField>

        <ResponseField name="exampleComponentData" type="ComponentData">

          Example component data for this component type.

          <Expandable title="One of the following">

            <ResponseField name="data" type="data">

              data

              _Nested structure omitted for brevity — see the `data` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
