    Creates a new resource.

    ### Connected schedules

    A new event [schedule](https://dev.wix.com/docs/api-reference/business-management/calendar/wix-bookings-integration)
    is automatically created for the resource.

    ### Locations

    If you don't specify `locationOptions`, Wix Bookings automatically sets
    `locationOptions.availableInAllLocations` to `true`.

    If you specify 1 business location ID in `locationOptions.specificLocationOptions.businessLocations`,
    you must specify `locationOptions.specificLocationOptions.availableInBusinessLocations`
    as `true`. Currently, you can specify only a single business location.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/resources
    ```

    ## Body Params

    <ParamField body="resource" type="Resource" required>

      Resource to create.

      See the [Resource Object](/api-reference/business-solutions/bookings/resources/resources-v2/resource-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="resource" type="Resource">

      Created resource.

      See the [Resource Object](/api-reference/business-solutions/bookings/resources/resources-v2/resource-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_LOCATION_ID_IS_REQUIRED` | Business location ID is required. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_SPECIFIC_LOCATION_OPTIONS_NOT_ALLOWED` | `specificLocationOptions` can't be set when `availableInAllLocations` is set to `true`. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_SPECIFIC_LOCATION_OPTIONS_MUST_BE_SET` | `specificLocationOptions` must be set when `availableInAllLocations` is set to `false` or empty. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_AVAILABLE_IN_BUSINESS_LOCATION_MUST_BE_TRUE` | `availableInBusinessLocations` must be set to `true`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Resource Created | `wix.bookings.resources.v2.resource_created` | Triggered when a resource is created. |
