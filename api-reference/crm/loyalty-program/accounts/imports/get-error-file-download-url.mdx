  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the download URL for the error file of a failed loyalty import.

    If an import fails, the `importResult.errorFileExists` field in the `LoyaltyImport` object is set to `true`.

    Use this method to get the URL of the error file, which contains details about which items couldn't be imported and why.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_api/loyalty-imports/v1/loyalty-imports/error-file-download-url
    ```

    ## Query Params

    <ParamField query="loyaltyImportId" type="string" required>

      Loyalty import ID.

    </ParamField>

    ## Response Object

    <ResponseField name="url" type="string">

      URL for downloading the error file.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request

      }
      ```

    </CodeGroup>

    </div>
