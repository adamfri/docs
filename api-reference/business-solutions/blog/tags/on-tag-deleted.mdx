Triggered when a tag is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.blog.v3.tag_deleted` |
| Package | `@wix/blog` |
| Permissions | `Read Blog`, `Manage Blog`, `Read Draft Blog Posts` |
