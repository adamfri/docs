      **Deprecated.** This method is deprecated.

    </Warning>

    Archives a single plan.
    When a plan is archived, it's no longer visible as a public plan that can be chosen by site members or visitors.
    This is because the plan's `public` property is automatically set to `false`.
    Archived plans can't be purchased or reactivated.
    Plan archiving doesn't impact existing orders made for the plan. All orders for the plan are still active and keep their perks, payment options, and terms.
    Wix users can see archived plans in a site's dashboard under **Pricing Plans -> Archived Plans**.
    <Note>

    An attempt to archive an already-archived plan throws an error.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.MANAGE-PLANS">Manage Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/pricing-plans/v2/plans/{id}/archive
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the active plan to archive.

    </ParamField>

    ## Response Object

    <ResponseField name="plan" type="Plan">

      Archived plan.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-deprecated/plan-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PRICING_PLANS_NOT_INSTALLED` | The user does not have the Wix Pricing Plans app installed on the site. |
    | `404` | `NOT_FOUND` | `plan_not_found` | Pricing plan was not found. |
    | `400` | `INVALID_ARGUMENT` | `already_archived` | Cannot archive plan because it is already archived. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Plan Archived | `wix.pricing_plans.plan_plan_archived` | Triggered when a pricing plan is archived. |
