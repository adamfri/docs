    <div className="wix-ref">

    Voids a gift card transaction.
    Transaction IDs are returned in Redeem Gift Card.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.CHANGE-GIFT-CARDS-BALANCE">Change Gift Card Balances</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/gift-cards/void
    ```

    ## Body Params

    <ParamField body="transactionId" type="string" required>

      Gift card transaction ID, as returned from Redeem Gift Card.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="appId" type="string" required>

      App ID of the gift card provider.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="context" type="Context">

      Contextual information for the request, including the physical location ID if applicable.

      <Expandable title="context properties">

        <ParamField body="locationId" type="string">

          Physical location ID. Can be based on the Locations API or an external provider.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `VoidTransactionResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `TRANSACTION_NOT_FOUND` | Transaction not found. |
    | `409` | `ALREADY_EXISTS` | `ALREADY_VOIDED` | Transaction already voided. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_DISABLED` | Gift card is disabled. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_EXPIRED` | Gift card has expired. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
