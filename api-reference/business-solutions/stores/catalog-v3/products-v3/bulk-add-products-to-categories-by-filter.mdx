    Adds multiple products to up to 5 categories, given the provided filter and search expression.

    Learn more about the [Categories API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/categories/introduction).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_ITEM_WRITE">Category item write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/products/add-to-categories-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

    </ParamField>

    <ParamField body="categoryIds" type="string[]" required>

      IDs of the categories to which products will be added.

      Constraints: `format GUID`, `minItems 1`, `maxItems 5`.

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Defines how separate search terms in `expression` are combined

          **Supported values:**

          - `OR` — Any of the search terms must be present
          - `AND` — All search terms must be present

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

      Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/introduction) to retrieve job details and metadata..

      Constraints: `format GUID`.

    </ResponseField>
