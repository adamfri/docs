<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a data collection.

    Before deleting a collection:
    - Make sure the collection isn't connected to any site pages or elements.
    - You can create a manual backup of a collections with the Backups API, in case you need to restore them later.
    - You can also export a collection to a CSV file with the Data Movement Jobs API, if you want to save the data outside of Wix.

    <Note>

    Once a collection is deleted, it can only be restored for a limited amount of time.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/data/v2/collections/{dataCollectionId=**}
    ```

    ## Query Params

    <ParamField query="dataCollectionId" type="string" required>

      ID of the collection to delete.

      Constraints: `maxLength 256`.

    </ParamField>

    ## Response Object

    Returns `DeleteDataCollectionResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
