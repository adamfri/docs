    Updates an availability exception.

    Each time the availability exception is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the availability exception.
    This ensures you're working with the latest availability exception and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/restaurants-availability-exceptions/v1/availability-exceptions/{availabilityException.id}
    ```

    ## Path Params

    <ParamField path="availabilityException.id" type="string" required>

      Availability exception ID.

    </ParamField>

    ## Body Params

    <ParamField body="availabilityException" type="AvailabilityException" required>

      Availability exception to update.

      See the [Availability Exception Object](/api-reference/business-solutions/restaurants/online-orders/availability-exceptions/availability-exception-object) for this object's fields.

    </ParamField>

    ## Response Object

      Updated availability exception.

      See the [Availability Exception Object](/api-reference/business-solutions/restaurants/online-orders/availability-exceptions/availability-exception-object) for this object's fields.

    </ResponseField>

    <ParamField body="_id" type="string" required>

    <ParamField body="availabilityException" type="UpdateAvailabilityException" required>

      Availability exception to update.

      <Expandable title="availabilityException properties">

        <ParamField body="_id" type="string">

          Availability exception ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the availability exception is updated.
          To prevent conflicting changes, the current revision must be specified when updating the availability exception.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the availability exception was created in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the availability exception was last updated in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

          **Read-only.**

        </ParamField>

        <ParamField body="startTime" type="datetime">

          The start time of the availability exception in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

        </ParamField>

        <ParamField body="endTime" type="datetime">

          The end time of the availability exception in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

        </ParamField>

        <ParamField body="available" type="boolean">

          Whether the exception makes the [`start_time`, `end_time`] range available.
          If `true`, the exception makes the restaurant available for online ordering during the time range. If `false`, the exception makes the restaurant unavailable for ordering during the time range.
          Currently, only `false` is supported.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Exception name.

        </ParamField>

        <ParamField body="affectedFulfillmentMethods" type="AffectedFulfillmentMethods">

          Fulfillment methods for which this exception applies.

          <Expandable title="affectedFulfillmentMethods properties">

            <ParamField body="affectedMethods" type="string">

              The type of the fulfillment methods this exception applies to.

              **Supported values:**

              - `ALL_FULFILLMENT_METHODS` — All fulfillment methods of this operation applied for this exception.
              - `SPECIFIC_FULFILLMENT_METHODS` — Specific fulfillment methods applied for this exception.
              - `ALL_PICKUP_FULFILLMENT_METHODS` — All pickup fulfillment methods applied for this exception.
              - `ALL_DELIVERY_FULFILLMENT_METHODS` — All delivery fulfillment methods applied for this exception.

            </ParamField>
