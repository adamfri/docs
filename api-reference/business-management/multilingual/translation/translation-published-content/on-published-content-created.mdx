Triggered when published content is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.localization_public.v3.published_content_created` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation API`, `Wix Multilingual - Translation Content + Published Content Read` |
