    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PORTFOLIO.MANAGE-PORTFOLIO">Manage Portfolio</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/portfolio/v1/projects/{project.id}
    ```

    ## Path Params

    <ParamField path="project.id" type="string" required>

      Project ID.

    </ParamField>

    ## Body Params

    <ParamField body="project" type="Project" required>

      Project to update.

      See the [Project Object](/api-reference/business-solutions/portfolio/projects/project-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="project" type="Project">

      Updated project.

      See the [Project Object](/api-reference/business-solutions/portfolio/projects/project-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
