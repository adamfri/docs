    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates multiple translation content items by ID.

    To remove a field, pass the field key with an empty object as the value. For example:

    ```json
    {
    "fields": {
    "title": {}
    }
    }
    ```

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_CONTENT">Wix Multilingual - Write Translation Content</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/translation-content/v1/bulk/contents/update
    ```

    ## Body Params

    <ParamField body="contents" type="MaskedContent[]" required>

      Translation content items to update.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="contents properties">

        <ParamField body="content" type="Content" required>

          Translation content to update.

          See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

        </ParamField>

        <ParamField body="fieldMask" type="FieldMask">

          Explicit list of fields to update.

          <Expandable title="fieldMask properties">

            <ParamField body="paths" type="string[]" />

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to include the updated translation content items in the response. Set to `true` to receive the translation content items in the response.

    </ParamField>

    <ParamField body="forceFieldsTimestampUpdate" type="boolean">

      If true each field updated in fields map will also update the timestamp fields

      even if the field value is not changed, otherwise the timestamp fields will be updated only if the field value has changed

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkContentResult[]">

      Items created by bulk action.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Item metadata.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Content">

          Translation content. This field is only returned if the operation was successful and `returnEntity` was set to true in the request.

          See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Bulk action metadata.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Content Updated | `wix.multilingual.translation.v1.content_updated` | Triggered when translation content is updated. |
