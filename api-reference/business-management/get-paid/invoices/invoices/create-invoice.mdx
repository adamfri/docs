    Creates an invoice.

    To create multiple invoices in a single API call, call [Bulk Create Invoices](https://dev.wix.com/docs/api-reference/business-management/get-paid/invoices/invoices/bulk-create-invoices).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/invoices
    ```

    ## Body Params

    <ParamField body="invoice" type="Invoice" required>

      Invoice to create.

      See the [Invoice Object](/api-reference/business-management/get-paid/invoices/invoices/invoice-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="invoice" type="Invoice">

      Created invoice.

      See the [Invoice Object](/api-reference/business-management/get-paid/invoices/invoices/invoice-object) for this object's fields.

    </ResponseField>

    | `400` | `INVALID_ARGUMENT` | `DUE_DATE_BEFORE_ISSUE_DATE` | Invoice `dueDate` is before `issueDate`. |
    | `400` | `INVALID_ARGUMENT` | `INVOICE_DATE_OUT_OF_RANGE` | Invoice `issueDate` is more than 100 years before the current time, or `dueDate` is more than 100 years after the current time. |

    | `400` | `INVALID_ARGUMENT` | `LINE_ITEMS_MUST_EXIST` | Invoice must have at least one line item. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEMS_IDS_MUST_BE_UNIQUE` | Line item IDs must be unique. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEM_QUANTITY_MUST_BE_INTEGER` | Line item quantity must be whole number. |
    | `400` | `INVALID_ARGUMENT` | `RICH_CONTENT_TOO_LARGE` | Rich content object exceeds the maximum allowed size. |
    | `400` | `INVALID_ARGUMENT` | `RICH_CONTENT_INVALID` | Rich content object couldn't be parsed. |
    | `400` | `INVALID_ARGUMENT` | `SUBSCRIPTION_MULTIPLE_LINE_ITEMS_NOT_SUPPORTED` | A subscription invoice must contain exactly one line item. |
    | `400` | `INVALID_ARGUMENT` | `SUBSCRIPTION_LINE_ITEM_START_DATE_ILLEGAL_FOR_NON_INITIAL_INVOICE` | A subscription line item's `startDate` may only be set on the initial invoice (when `currentCycle` is 1). |
