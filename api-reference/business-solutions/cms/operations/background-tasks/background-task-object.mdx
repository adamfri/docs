Background task job that processes data items in bulk.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Task ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="type" type="string">

      Task type.

      Constraints: `immutable`.

      **Supported values:**

      - `DELETE_BY_QUERY` — Deletes all items that match the specified filter.
      - `COPY_FIELD_DATA` — Copies data from one field to another for all items in the collection.
      - `EDIT_FIELD_DATA` — Updates field data for items that match the specified filter.
      - `UPDATE_PUBLISH_STATUS` — In collections that have the Publish plugin, updates the publish status of items that match the specified filter.

    </ResponseField>

    <ResponseField name="status" type="string">

      Task status.

      **Read-only.**

      **Supported values:**

      - `NEW` — Task was created but has not started.
      - `RUNNING` — Task is currently running.
      - `COMPLETED` — Task has completed. Partial errors are listed in `failures`.
      - `FAILED` — Task has failed. Tasks can fail due to errors or because they were cancelled.

      Failures are listed in `failures`. Cancelled tasks have a failure `code` value of `CANCELLED`, and no associated failure `data`.

    </ResponseField>

    <ResponseField name="startedAt" type="datetime">

      Task start time. Empty if the task status is `NEW`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="finishedAt" type="datetime">

      Task finish time. Empty until the task status updates to `COMPLETED` or `FAILED`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="itemsFailed" type="integer">

      Number of items whose processing failed.

      **Read-only.**

    </ResponseField>

    <ResponseField name="failures" type="ApplicationError[]">

      List of errors generated during the task.

      Learn more about [Wix Data error codes](https://dev.wix.com/docs/sdk/backend-modules/data/wix-data-error-codes).

      **Read-only.** Constraints: `maxItems 100`.

      <Expandable title="failures properties">

        <ResponseField name="code" type="string">

          Error code.

        </ResponseField>

        <ResponseField name="description" type="string">

          Description of the error.

        </ResponseField>

        <ResponseField name="data" type="object">

          Data related to the error.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="estimatedItemCount" type="integer">

      Estimated number of items affected by the task.

      **Read-only.**

    </ResponseField>

    <ResponseField name="itemsSucceeded" type="integer">

      Number of items successfully processed so far.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "097a5564-0fec-4425-8d1e-3e753b48a422",
        "type": "DELETE_BY_QUERY",
        "status": "COMPLETED",
        "startedAt": "2024-09-05T10:34:59.507Z",
        "finishedAt": "2024-09-05T10:35:03.654Z",
        "itemCount": 3,
        "itemsSucceeded": 3,
        "itemsFailed": 0,
        "failures": [],
        "deleteByQueryOptions": {
          "dataCollectionId": "Items",
          "environment": "LIVE",
          "filter": {
            "altText": {
              "$contains": "Placeholder"
            }
          }
        }
      }
      ```

    </CodeGroup>
