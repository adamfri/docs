---
title: "Marketing Activity Object"
description: "A single planned marketing action within a site's marketing plan."
icon: "cube"
---

A single planned marketing action within a site's marketing plan.
Activities are generated by the AI when a marketing plan is created and represent
concrete tasks such as a social media campaign, a blog post, or an email. Each
activity has a title, description, target date, and type. Generating social posts
for an activity is handled by the separate Marketing Plan API, not this API.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Unique activity ID. Assigned on creation and read-only afterwards.

      **Read-only.**

    </ResponseField>

    <ResponseField name="marketingActivityType" type="string">

      Category of marketing action this activity represents.

      **Supported values:**

      - `SOCIAL_MARKETING` — Activity targets social media channels (e.g. Facebook, Instagram).
      - `EMAIL_MARKETING` — Activity targets an email campaign.
      - `BLOG` — Activity targets a blog post.

    </ResponseField>

    <ResponseField name="title" type="string">

      Short label for the activity, suitable for display in a marketing plan UI.

    </ResponseField>

    <ResponseField name="description" type="string">

      Human-readable explanation of what the activity involves and why it was suggested.

    </ResponseField>

    <ResponseField name="targetDate" type="datetime">

      Scheduled date by which the activity should be completed or published.

    </ResponseField>

    <ResponseField name="source" type="ActivitySource">

      Origin context that the AI used when generating this activity (for example, an upcoming event or a set of keywords).

      <Expandable title="source properties">

        <ResponseField name="type" type="string">

          Indicates what kind of input drove the AI to generate this activity.

          **Supported values:**

          - `EVENT` — Activity was generated based on a site event.
          - `KEYWORDS` — Activity was generated based on SEO or topic keywords.
          - `CONTENT_PILLARS` — Activity was generated based on the site's content pillars.

        </ResponseField>

        <ResponseField name="value" type="string">

          The specific value of the source input (for example, an event name or a keyword string).

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="asset" type="AssetReference">

      Site asset this activity is grounded in.

      <Expandable title="asset properties">

        <ResponseField name="type" type="string">

          Type of the site asset (for example, product or blog post). See `SiteAsset.Type` for the closed set of values.

          **Supported values:**

          - `BLOG_POST` — A Wix Blog post.
          - `EVENT` — A Wix Events event.
          - `STORES_PRODUCT` — A Wix Stores product.
          - `BOOKINGS_SERVICE` — A Wix Bookings service.
          - `STORES_COUPON` — A Wix Stores coupon.
          - `STORES_CATEGORY` — A Wix Stores category.

        </ResponseField>

        <ResponseField name="id" type="string">

          ID of the asset within its provider's data store.

        </ResponseField>

        <ResponseField name="name" type="string">

          Display name of the asset (for example, the product title or blog post title), cached at activity-generation time.

          Constraints: `maxLength 3000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "marketingActivity": {
          "id": "f4c8a1d2-9b3e-4a7c-8f6d-2e1b5c9a0d3f",
          "title": "Summer Sale Instagram Campaign",
          "description": "Promote the summer collection with a series of Instagram posts highlighting new arrivals and seasonal discounts.",
          "targetDate": "2026-07-15T09:00:00.000Z",
          "marketingActivityType": "SOCIAL_MARKETING"
        }
      }
      ```

    </CodeGroup>
