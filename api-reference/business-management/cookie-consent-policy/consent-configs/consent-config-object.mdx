---
title: "Consent Config Object"
description: "A consent config defines user consent settings for an app's embeds on a site."
icon: "cube"
---

A consent config defines user consent settings for an app's embeds on a site.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Consent config ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the consent config is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the consent config.

      Ignored when creating a consent config.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the consent config was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the consent config was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="configType" type="string">

      Type of consent config. Currently only the `TAG_OVERRIDE` type is supported.

      **Supported values:**

      - `UNKNOWN_CONFIG` — Unknown config type.
      - `TAG_OVERRIDE` — Overrides the app embed's category.

    </ResponseField>

    <ResponseField name="consentCategory" type="string">

      The consent config's categories for compliance with privacy regulations.

      **Supported values:**

      - `UNKNOWN_CATEGORY`
      - `essential` — Includes core functionality such as security, verification of identity and network management. These cookies can’t be disabled.
      - `functional` — Includes collecting data to remember choices users make to improve and give a more personalised experience.
      - `analytics` — Includes tracking visitor interactions with a site, to discover errors and provide better overall analytics.
      - `advertising` — Includes tracking advertising effectiveness to provide a more relevant service and deliver better ads to suit visitors' interests.
      - `data_to_third_party` — Includes collecting data to pass on to a third party.

    </ResponseField>

    <ResponseField name="createdBy" type="CreatedBy">

      Consent config creator.

      <Expandable title="createdBy properties">

        <ResponseField name="userId" type="string">

          User ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="appId" type="string">

          App ID.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the consent config. Extended fields must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Consent config tags, meaning labels for administrative purposes.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
