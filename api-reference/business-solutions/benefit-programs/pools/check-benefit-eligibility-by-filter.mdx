    <div className="wix-ref">

    Checks benefit eligibility across the beneficiary's pools that contain a benefit for the given item.

    Pools are matched by `itemReference` within `namespace` and must belong to `beneficiary`, which defaults to the calling identity. `poolSelector` narrows the matched pools further.

    To be redeemed, a benefit's pool must be active and the associated balance must be greater than the cost of the benefit.

    Each benefit is checked independently. For example, if there is a benefit with a price of 3 credits and a benefit with a price of 4 credits, and there are 5 available credits, both benefits would be returned as eligible, but they can't both be redeemed.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/pools/check-benefit-eligibility-by-filter
    ```

    ## Body Params

    <ParamField body="namespace" type="string" required>

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      Constraints: `minLength 1`, `maxLength 20`.

    </ParamField>

    <ParamField body="itemReference" type="ItemReference" required>

      Information about the item to check.

      <Expandable title="itemReference properties">

        <ParamField body="externalId" type="string" required>

          External ID of the item.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="category" type="string">

          Item category.

          Constraints: `maxLength 20`.

        </ParamField>

        <ParamField body="providerAppId" type="string" required>

          ID of the app providing the item.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="count" type="integer" required>

      Number of items to check.

      Ensures the balance is high enough to redeem this many items.

      Constraints: `min 1`.

    </ParamField>

    <ParamField body="targetDate" type="datetime">

      Date that the item will be provided to the beneficiary.

      This parameter should be used to manage the potential logistics of providing the item.

    </ParamField>

    <ParamField body="beneficiary" type="IdentificationData">

      Pool beneficiary. Defaults to the calling identity. Only the beneficiary's pools that also match `pool_selector` are checked.

      <Expandable title="One of the following">

        <ParamField body="id" type="id">

          id

          <Expandable title="id properties">

            <ParamField body="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="additionalData" type="object">

      Additional information.

    </ParamField>

    <ParamField body="poolSelector" type="PoolSelector">

      Predefined attributes used to select the pools to check eligibility in.

      When omitted, pools in all statuses are checked. Combined with `beneficiary`, `namespace`, and `item_reference`, the selector further narrows which pools are checked.

      <Expandable title="poolSelector properties">

        <ParamField body="poolStatuses" type="string[]">

          Only pools in these statuses are checked. When empty, pools in all statuses are checked.

          Constraints: `maxItems 10`.

          **Supported values:**

          - `ACTIVE` — Pool is active.
          - `PAUSED` — Pool is paused. It can be resumed.
          - `ENDED` — Pool is ended. It can't be resumed.
          - `PROVISIONING` — Pool provisioning is in progress. This status exists for a short time during processing.
          - `RENEWING` — Pool renewing is in progress. This status exists for a short time during processing.
          - `PENDING` — Pool is pending

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="EligibilityCheckResult[]">

      Results of the eligibility check for the benefits in the pools that match the request. A pool that contains multiple benefits for the requested item produces one result per benefit.

      Empty when no pools match.

      <Expandable title="results properties">

        <ResponseField name="benefitResults" type="BenefitResult[]">

          Eligibility status.

          Constraints: `maxItems 10`.

          <Expandable title="benefitResults properties">

            <ResponseField name="type" type="string">

              Eligibility status.

              **Supported values:**

              - `ELIGIBLE_BENEFIT` — Item is eligible to be redeemed.
              - `NOT_ENOUGH_BALANCE` — Balance is lower than the cost of redeeming the items.
              - `POOL_NOT_ACTIVE` — Pool isn't active.
              - `BENEFIT_NOT_FOUND` — Invalid benefit details provided.
              - `POOL_NOT_FOUND` — Invalid pool details provided.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
