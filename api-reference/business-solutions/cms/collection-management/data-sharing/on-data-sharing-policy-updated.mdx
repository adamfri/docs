Triggered when a data sharing policy is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.data.v1.data_sharing_policy_updated` |
| Package | `@wix/data` |
| Permissions | `Manage Data Collection Sharing` |
