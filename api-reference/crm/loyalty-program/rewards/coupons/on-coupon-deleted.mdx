Triggered when a loyalty coupon is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.v1.coupon_deleted` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty`, `Manage Restaurants - all permissions` |
