    Updates a question entry.

    Each time the question entry is updated, `revision` increments by 1.
    The current `revision` must be specified when updating the question entry.
    This ensures you're working with the latest version of a question entry and prevents unintended overwrites.

    To update multiple question entries, call the Bulk Update Question Entry method.

    To update only the question entry's `extendedFields` field, call the Update Extended Fields method.

    To update only the question entry's labels, call the Set Question Entry Labels method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/faq/v2/question-entries/{questionEntry.id}
    ```
