  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates a function with the specified configuration. After creation, you'll need to attach automation logic using the Function Methods API and configure any required service plugin settings before the function can be activated.

    This isn't the recommended way to create a function. Learn more about [function creation](https://dev.wix.com/docs/api-reference/business-management/functions/about-function-creation-and-activation#quick-creation-and-configuration).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/functions/v1/functions
    ```

    ## Body Params

    <ParamField body="function" type="Function" required>

      Function to create.

      See the [Function Object](/api-reference/business-management/functions/functions/function-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="function" type="Function">

      The created function.

      See the [Function Object](/api-reference/business-management/functions/functions/function-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Function Created | `wix.functions.v1.function_created` | Triggered when a function is created. |

    </div>
