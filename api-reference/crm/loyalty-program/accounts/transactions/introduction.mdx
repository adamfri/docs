<Note>This article applies to the REST API only.</Note>

The Loyalty Transactions API allows you to retrieve transactions related to account activity.

Transactions are created when a loyalty account takes certain actions. For example, when a loyalty account:

- Earns points by making purchases.
- Redeems points by getting rewards.
- Receives a points adjustment.
- Has points refunded for a previously redeemed reward.
- Has points expire.

<Note>

You can't create transactions, only retrieve them. Transactions are read-only.

</Note>
