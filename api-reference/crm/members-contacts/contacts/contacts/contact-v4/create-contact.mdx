    Creates a new contact.

    The `info` object must include at least one of the following:
    - Name
    - Phone number
    - Email address

    By default, if the call contains an email already in use by another contact,
    the new contact won't be created. To override this behavior, set `allowDuplicates` to `true`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/contacts
    ```

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |

    | `400` | `INVALID_ARGUMENT` | `INSUFFICIENT_CONTACT_DATA` | Contact must have a name, phone number, or email address. |
    | `409` | `ALREADY_EXISTS` | `CONTACT_ID_ALREADY_EXISTS` | A contact with the same ID already exists. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_HAVE_MULTIPLE_PRIMARY_INFO` | Contact can't have more than one primary email or phone number. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_EXTENDED_FIELD_VALUE` | Contact can't have extended fields values that are invalid or do not match the field type. |

    import { Permissions, webMethod } from '@wix/web-methods';
    import { contacts, labels } from '@wix/crm';
    import { auth } from '@wix/essentials';

    export const createContactWithLabels = webMethod(Permissions.Anyone, async (contactInfo) => {

    try {  
      const elevatedQueryLabels = auth.elevate(labels.queryLabels);
      const myLabels = await elevatedQueryLabels()
       .eq('labelType', "USER_DEFINED")
       .find();

      const items = myLabels.items;
      const labelKeys = items.map(label => {
        return label.key
      });

      contactInfo.labelKeys.items = labelKeys;

      const elevatedCreateContact = auth.elevate(contacts.createContact);
      const newContact = await elevatedCreateContact(contactInfo);

      return newContact;

      } catch (error) {
        console.log(error);
        // Handle the error
      }
    });
