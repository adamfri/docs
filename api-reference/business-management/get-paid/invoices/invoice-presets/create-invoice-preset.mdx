    Creates an invoice preset.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/invoice-presets
    ```

    ## Body Params

    <ParamField body="invoicePreset" type="InvoicePreset" required>

      Invoice preset to create.

      See the [Invoice Preset Object](/api-reference/business-management/get-paid/invoices/invoice-presets/invoice-preset-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="invoicePreset" type="InvoicePreset">

      Created invoice preset.

      See the [Invoice Preset Object](/api-reference/business-management/get-paid/invoices/invoice-presets/invoice-preset-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_RICH_CONTENT` | The `customFields.footerCustomField` value isn't valid rich content. Supported content includes text formatting and images. |
    | `428` | `FAILED_PRECONDITION` | `INVOICE_PRESETS_LIMIT_REACHED` | The site has reached the maximum allowed number of invoice presets (10). |
    | `500` | `INTERNAL` | `APP_INSTALLATION_FAILED` | App installation failed while creating the invoice preset. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | --- | --- | --- |
    | Invoice Preset Created | `wix.invoices.presets.v4.invoice_preset_created` | Triggered when an invoice preset is created. |
