    <div className="wix-ref">

    Clones a `serviceOptionsAndVariants` object and connects it to a [service](https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/introduction).

    The call fails if the service already has a connected
    `serviceOptionsAndVariants` object.

    The cloned `serviceOptionsAndVariants` object gets a new, unique option ID.
    The option ID of the existing `serviceOptionsAndVariants` object isn't reused.

    For example, you may call this method after [cloning a service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/clone-service).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/serviceOptionsAndVariants/{cloneFromId}/clone
    ```

    ## Path Params

    <ParamField path="cloneFromId" type="string" required>

      ID of the `serviceOptionsAndVariants` object to clone.

    </ParamField>

    ## Body Params

    <ParamField body="targetServiceId" type="string" required>

      ID of the service to which the cloned `serviceOptionsAndVariants` are
      connected.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="serviceOptionsAndVariants" type="ServiceOptionsAndVariants">

      Cloned `serviceOptionsAndVariants` object.

      See the [Service Options And Variants Object](/api-reference/business-solutions/bookings/services/service-options-and-variants/service-options-and-variants-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
