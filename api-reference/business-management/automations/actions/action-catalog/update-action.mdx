    Updates the specified action for the specified app.

    After the action is updated, it only contains the values specified in the request. Earlier values are replaced.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/automations/actioncatalog/v1/action/{action.id}
    ```

    ## Path Params

    <ParamField path="action.id" type="string" required>

      Action ID. (per component version)

    </ParamField>

    ## Body Params

    <ParamField body="action" type="Action">

      Action to update.

      See the [Action Object](/api-reference/business-management/automations/actions/action-catalog/action-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="updatedAction" type="Action">

      Updated action.

      See the [Action Object](/api-reference/business-management/automations/actions/action-catalog/action-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTION_NOT_FOUND` | No action exists for the requested app and action key. |
    | `403` | `PERMISSION_DENIED` | `UNAUTHORIZED_APP` | The caller is not authorized to manage actions for the requested app. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
