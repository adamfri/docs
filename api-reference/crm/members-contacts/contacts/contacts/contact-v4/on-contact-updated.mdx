Triggered when a contact is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.contacts.v4.contact_updated` |
| Package | `@wix/crm` |
| Permissions | `Manage Stores`, `Manage Events`, `Manage Challenges`, `Read Contacts`, `Read Members and Contacts - all read permissions`, `Manage Restaurants - all permissions`, `Manage Contacts`, `Set Up Automations`, `Manage Members and Contacts - all permissions` |
