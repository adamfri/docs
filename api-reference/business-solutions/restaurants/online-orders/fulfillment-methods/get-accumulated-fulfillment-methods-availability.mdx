    Retrieves the accumulated availability of all fulfillment methods.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/fulfillment-methods/v1/fulfillment-methods/accumulated-availability
    ```

    ## Query Params

    <ParamField query="fulfillmentMethodIds" type="string[]">

      fulfillment method ids to check availability for.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    ## Response Object

    <ResponseField name="availability" type="Availability">

      The accumulated availability of all fulfillment methods.

      <Expandable title="availability properties">

        <ResponseField name="availableTimes" type="DayOfWeekAvailability[]">

          A list of availability times for the days of the week.

          <Expandable title="availableTimes properties">

            <ResponseField name="dayOfWeek" type="string">

              The day of week this availability relates to.

              **Supported values:**

              - `MON` — Monday.
              - `TUE` — Tuesday.
              - `WED` — Wednesday.
              - `THU` — Thursday.
              - `FRI` — Friday.
              - `SAT` — Saturday.
              - `SUN` — Sunday.

            </ResponseField>

            <ResponseField name="timeRanges" type="TimeOfDayRange[]">

              A list of time ranges during which the fulfillment should be available.

              _Nested structure omitted for brevity — see the `TimeOfDayRange[]` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="timeZone" type="string">

          The timezone in which the availability times are given.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="types" type="string[]">

      Fulfillment methods types that accumulate availability.

      **Supported values:**

      - `UNKNOWN_FULFILLMENT_TYPE` — Unknown fulfillment type.
      - `PICKUP` — The customer must pick up the order from the restaurant.
      - `DELIVERY` — The restaurant, or someone on behalf of the restaurant, must deliver the order to the customer.

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
