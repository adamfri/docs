## SDK package

```bash
npm install @wix/data
```

Import the `backups` namespace from `@wix/data`.

## Methods

<CardGroup cols={2}>

  <Card title="List Backups" href="/api-reference/business-solutions/cms/operations/backups/list-backups">
    GET Retrieves a list of all backups for a site.
  </Card>
  <Card title="Create Backup" href="/api-reference/business-solutions/cms/operations/backups/create-backup">
    POST Creates an on-demand backup of live content in a site's collections.
  </Card>
  <Card title="Restore Backup" href="/api-reference/business-solutions/cms/operations/backups/restore-backup">
    POST Restores all data from a backup.
  </Card>
  <Card title="Restore Partial Backup" href="/api-reference/business-solutions/cms/operations/backups/restore-partial-backup">
    POST Restores specific collections from a backup.
  </Card>
  <Card title="List Restorations" href="/api-reference/business-solutions/cms/operations/backups/list-restorations">
    GET Retrieves a list of all data restorations from backups.
  </Card>
  <Card title="Delete Backup" href="/api-reference/business-solutions/cms/operations/backups/delete-backup">
    DELETE Deletes a backup.
  </Card>

</CardGroup>
