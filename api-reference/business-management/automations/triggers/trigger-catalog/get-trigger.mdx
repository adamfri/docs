    Retrieves a trigger by ID (changes per component version).
    To get trigger by appId + triggerKey in context of a specific site, see [GetTriggerByAppIdAndKey](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/trigger-catalog/get-trigger-by-app-id-and-key).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/automations/triggercatalog/v1/trigger/{triggerId}
    ```

    ## Path Params

    <ParamField path="triggerId" type="string" required>

      ID of the trigger to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="trigger" type="Trigger">

      Retrieved trigger.

      See the [Trigger Object](/api-reference/business-management/automations/triggers/trigger-catalog/trigger-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
