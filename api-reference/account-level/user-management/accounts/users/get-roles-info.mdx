    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves all available roles in the requesting account, including predefined and custom roles.
    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header. API keys are currently available to selected beta users only.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="ACCOUNT_ROLES.GET_ROLES">ACCOUNT_ROLES.GET_ROLES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/roles-management/roles
    ```

    ## Query Params

    <ParamField query="locale" type="string">

      Language of predefined roles names and descriptions to return, in ISO 639 format. Default: `en`.

    </ParamField>

    <ParamField query="filter" type="RolesInfoFilter">

      Roles to return.

      <Expandable title="filter properties">

        <ParamField query="roleLevel" type="string">

          Role level to return. Default: ALL.

          **Supported values:**

          - `ALL`
          - `SITE_LEVEL`
          - `ACCOUNT_LEVEL`

        </ParamField>

        <ParamField query="editorTypes" type="string[]">

          Filter for editor-specific roles. Default: ALL.

          **Supported values:**

          - `UNINITIALIZED`
          - `EDITORX`
          - `BLOCKS`
          - `STUDIO`

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="predefinedRoles" type="RoleInfo[]">

      Predefined roles.

      <Expandable title="predefinedRoles properties">

        <ResponseField name="id" type="string">

          Role ID.

        </ResponseField>

        <ResponseField name="title" type="string">

          Role title, translated according to the request locale. If translation fails, the original title is returned.

        </ResponseField>

        <ResponseField name="description" type="string">

          Role description, translated according to the request locale. If translation fails, the original description is returned.

        </ResponseField>

        <ResponseField name="restrictFromLevel" type="string">

          Whether this role is restricted from accessing a specific resource type. Default: `NoRestriction`.

          **Supported values:**

          - `NoRestriction`
          - `Site`
          - `Account`

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="customRoles" type="RoleInfo[]">

      Custom roles.

      <Expandable title="customRoles properties">

        <ResponseField name="id" type="string">

          Role ID.

        </ResponseField>

        <ResponseField name="title" type="string">

          Role title, translated according to the request locale. If translation fails, the original title is returned.

        </ResponseField>

        <ResponseField name="description" type="string">

          Role description, translated according to the request locale. If translation fails, the original description is returned.

        </ResponseField>

        <ResponseField name="restrictFromLevel" type="string">

          Whether this role is restricted from accessing a specific resource type. Default: `NoRestriction`.

          **Supported values:**

          - `NoRestriction`
          - `Site`
          - `Account`

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
