    Updates a function builderless production.

    If you have updated a function, or anything other elements of a builderless production, using other APIs, updating the builderless production has no effect.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/functions/v1/function-builderless-productions/{functionBuilderlessProduction.id}
    ```

    ## Path Params

    <ParamField path="functionBuilderlessProduction.id" type="string" required>

      Function builderless production ID. This is the same as the associated function's ID.

    </ParamField>

    ## Body Params

    <ParamField body="functionBuilderlessProduction" type="FunctionBuilderlessProduction" required>

      Function builderless production to update.

      See the [Builderless Production Object](/api-reference/business-management/functions/builderless-productions/builderless-production-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="functionBuilderlessProduction" type="FunctionBuilderlessProduction">

      Updated function builderless production.

      See the [Builderless Production Object](/api-reference/business-management/functions/builderless-productions/builderless-production-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
