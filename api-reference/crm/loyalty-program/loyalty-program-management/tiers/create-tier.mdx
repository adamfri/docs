    <div className="wix-ref">

    Creates a tier.

    The name for a tier and the amount of required points to qualify for a tier can only exist for a single tier.

    Attempts to create a tier with a `tierDefinition.name` or `requiredPoints` that already exist return an error.

    To create up to 20 tiers at once, call Bulk Create Tiers.

    <Note>

    A site must have a [Plus plan](https://support.wix.com/en/article/wix-studio-upgrading-sites) (Wix Studio)
    or a [Business plan](https://support.wix.com/en/article/choosing-a-premium-plan?tabs=Business) (Wix Editor) to add tiers.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-tiers/v1/tiers
    ```

    ## Body Params

    <ParamField body="tier" type="Tier" required>

      Tier to create.

      See the [Tier Object](/api-reference/crm/loyalty-program/loyalty-program-management/tiers/tier-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="tier" type="Tier">

      Created loyalty tier.

      See the [Tier Object](/api-reference/crm/loyalty-program/loyalty-program-management/tiers/tier-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Tier Created | `wix.loyalty.v1.tier_created` | Triggered when a tier is created. |
