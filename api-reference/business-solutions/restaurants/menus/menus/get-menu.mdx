    Retrieves a menu by ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/menus/v1/menus/{menuId}
    ```

    ## Path Params

    <ParamField path="menuId" type="string" required>

      Menu ID.

    </ParamField>

    ## Response Object

    <ResponseField name="menu" type="Menu">

      Menu.

      See the [Menu Object](/api-reference/business-solutions/restaurants/menus/menus/menu-object) for this object's fields.

    </ResponseField>

    <Note>
