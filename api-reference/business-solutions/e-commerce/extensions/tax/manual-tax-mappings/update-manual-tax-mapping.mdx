    Updates an existing manual tax mapping.

    Use this method to modify the tax rate or other details of an existing manual tax mapping.
    Each time the manual tax mapping is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the manual tax mapping.
    This ensures you're working with the latest manual tax mapping and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/billing/v1/manual-tax-mappings/{manualTaxMapping.id}
    ```

    ## Path Params

    <ParamField path="manualTaxMapping.id" type="string" required>

      Manual tax mapping ID.

    </ParamField>

    ## Body Params

    <ParamField body="manualTaxMapping" type="ManualTaxMapping" required>

      Manual tax mapping to update.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="manualTaxMapping" type="ManualTaxMapping">

      Updated manual tax mapping.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `MANUAL_TAX_MAPPING_ALREADY_EXISTS` | The update would result in a manual tax mapping that already exists for the given tax group and tax region combination. |
    | `404` | `NOT_FOUND` | `TAX_REGION_ID_NOT_FOUND` | The updated tax region ID doesn't exist. |
    | `404` | `NOT_FOUND` | `TAX_GROUP_ID_NOT_FOUND` | The updated tax group ID doesn't exist. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    <ParamField body="_id" type="string" required>

    <ParamField body="manualTaxMapping" type="UpdateManualTaxMapping" required>

      Manual tax mapping to update.

      <Expandable title="manualTaxMapping properties">

        <ParamField body="_id" type="string">

          Manual tax mapping ID.

          **Read-only.**

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the manual tax mapping is updated.

          **Read-only.**

        </ParamField>

          Date and time the manual tax mapping was created.

          **Read-only.**

        <ParamField body="_updatedDate" type="datetime">

          Date and time the manual tax mapping was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="taxGroupId" type="string">

          Tax group ID. Tax groups define collections of items or services that share the same tax treatment.

        </ParamField>

        <ParamField body="taxRegionId" type="string">

          Tax region ID. Tax regions represent geographical areas where specific tax rules apply.

        </ParamField>

        <ParamField body="taxRate" type="string">

          Tax rate to apply for this tax group and region combination.

          Specified as a decimal string representing a fraction, not a percentage. For example, `"0.05"` is 5%, `"0.1"` is 10%, and `"0.08"` is 8%. Don't pass a number (`0.05`), an integer (`5`), or a percentage string (`"5%"`). Up to 6 decimal places are supported.

          Constraints: `>= 0`.

        </ParamField>

        <ParamField body="description" type="string">

          Description of the manual tax mapping. Use this field to add context or notes about the tax rate.

        </ParamField>

        <ParamField body="taxType" type="string">

          Type of tax being applied, such as `VAT`, `GST`, or `Sales Tax`. This depends on the jurisdiction's tax laws.

          Constraints: `maxLength 200`.

        </ParamField>

        <ParamField body="taxName" type="string">

          Customer-facing name of the tax, shown at checkout. For example, `STATE TAX`, `GST`, or `VAT`.

          Cosmetic only. It doesn't affect the calculated amount. Can be left empty, in which case checkout shows a default label such as `Sales Tax`.

          Constraints: `maxLength 200`.

        </ParamField>

        <ParamField body="jurisdiction" type="string">

          Name of the jurisdiction where this tax rate applies. For example, `California` or `United Kingdom`.

          Constraints: `maxLength 200`.

        </ParamField>

        <ParamField body="jurisdictionType" type="string">

          Type of jurisdiction where this tax rate applies, such as country, state, county, city, or special district.

          **Supported values:**

          - `UNDEFINED`
          - `COUNTRY`
          - `STATE`
          - `COUNTY`
          - `CITY`
