Extended field that was found or created.

<Tabs>

  <Tab title="REST">

    <ResponseField name="namespace" type="string">

      Extended field namespace.

      Extended fields created through by calling the Find Or Create Extended Field method
      are automatically assigned to the `custom` namespace.

      **Read-only.**

    </ResponseField>

    <ResponseField name="key" type="string">

      Extended field key.

      When accessing contact data,
      extended field data is available at `extendedFields[key]`.
      For example, if the key is "custom.notes",
      the value can be accessed at `extendedFields["custom.notes"]`.

      `key` is generated when the extended field is created
      and can't be modified, even if `displayName` changes.

      **Read-only.** Constraints: `minLength 1`, `maxLength 80`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Display name shown in the contact list.

      Constraints: `minLength 1`, `maxLength 150`.

    </ResponseField>

    <ResponseField name="dataType" type="string">

      Type of data the field holds.

      **Read-only.**

      **Supported values:**

      - `TEXT` — Accepts strings.
      - `NUMBER` — Accepts floats.
      - `DATE` — Accepts dates formatted as `YYYY-MM-DD`.
      - `URL` — Accepts strings. Prepends `https://` if no protocol is included.

    </ResponseField>

    <ResponseField name="fieldType" type="string">

      Indicates whether the extended field is a system field or custom field.

      **Read-only.**

      **Supported values:**

      - `SYSTEM` — Field is a system field managed by Wix. System fields can't be modified by calling the Update Extended Field method.
      - `USER_DEFINED` — Field is a custom field and can be modified by calling the Update Extended Field method.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the field was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the field was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="description" type="string">

      Field description, if the field is a system field.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "namespace" : "custom",
        "key": "custom.my-field",
        "displayName": "My Field",
        "dataType": "TEXT",
        "fieldType" : "USER_DEFINED",
        "createdDate": "2019-10-10T12:30:56Z",
        "updatedDate": "2020-05-10T07:14:59Z"
      }
      ```

    </CodeGroup>
