    Retrieves a list of up to 500 item modifiers.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/item-modifiers/v1/modifiers
    ```

    ## Query Params

    <ParamField query="modifierIds" type="string[]">

      IDs of the item modifiers to retrieve.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Metadata of the paginated results.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="modifiers" type="Modifier[]">

      Retrieved item modifiers.

      See the [Item Modifier Object](/api-reference/business-solutions/restaurants/menus/items/item-modifiers/item-modifier-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="CursorPagingMetadata">

      Metadata of the paginated results.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor pointing to the next page and the previous page in the list of results.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

          Whether there are more results after the current page.

    </ResponseField>
