    Creates up to 100 join applications.

    Specify `memberId`, `programId`, and `status` for each application. Set `returnEntity` to `true` to return the created applications in the response.

    To create a single join application, call [Create Join Application](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/create-join-application).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/bulk/join-applications/create
    ```

    ## Body Params

    <ParamField body="joinApplications" type="JoinApplication[]" required>

      Join applications to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created join applications in the response.

      Default: `false`

    </ParamField>
