A program has a specific beneficiary who can redeem benefits in the program's pools.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Program ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the program is updated.
      To prevent conflicting changes, the current revision must be specified when updating the program.

      Ignored when creating a program.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the program was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the program was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="programDefinitionId" type="string">

      ID of the associated program definition.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Program status.

      **Read-only.**

      **Supported values:**

      - `ACTIVE` — Program is active.
      - `PAUSED` — Program is paused. It can be resumed.
      - `ENDED` — Program has ended. It can't be resumed.
      - `PROVISIONING` — Program is being activated for the first time. This status exists for a short time during processing.
      - `PAUSING` — Program is being paused. This status exists for a short time during processing.
      - `RESUMING` — Program is being re-activated after being paused. This status exists for a short time during processing.
      - `ENDING` — Program is being ended. This status exists for a short time during processing.

    </ResponseField>

    <ResponseField name="beneficiary" type="IdentificationData">

      Program beneficiary.

      **Read-only.** Constraints: `immutable`.

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Program name.

      You may want to use the same name that's used in the associated program definition, if it exists.

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the program object.

      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="externalId" type="string">

      ID for the program defined by you. You can use `externalId` to filter queries.

      **Read-only.**

    </ResponseField>

    <ResponseField name="programDefinition" type="ProgramDefinitionInfo">

      Associated program definition information.

      **Read-only.**

      <Expandable title="programDefinition properties">

        <ResponseField name="id" type="string">

          Program definition ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="externalId" type="string">

          Program definition external ID.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>
