    <div className="wix-ref">

    Updates multiple products, given the provided filter.

    To update `infoSections`, `brand` or `ribbon` fields, you must also pass their existing `id`.

    <Note>

    The following fields can't be updated with this endpoint:
    + `slug`
    + `options`
    + `modifiers`
    + `variantsInfo`

    To update these fields, use [Bulk Update Products](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/bulk-update-products).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_WRITE">Product write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/products/update-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

    </ParamField>

    <ParamField body="product" type="Product" required>

      Product to update.

      See the [Product Object](/api-reference/business-solutions/stores/catalog-v3/products-v3/product-object) for this object's fields.

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Defines how separate search terms in `expression` are combined

          **Supported values:**

          - `OR` — Any of the search terms must be present
          - `AND` — All search terms must be present

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

      Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/introduction) to retrieve job details and metadata..

      Constraints: `format GUID`.

    </ResponseField>

    | `428` | `FAILED_PRECONDITION` | `INVALID_SUBSCRIPTION_DISCOUNT_AMOUNT` | Subscription discount `amountOff` exceeds the minimum variant price. |
    | `409` | `ALREADY_EXISTS` | `SUBSCRIPTION_ID_ALREADY_EXISTS` | Multiple subscriptions have identical IDs. |
    | `500` | `INTERNAL` | `BRAND_CREATION_FAILED` | Brand creation failed. |
    | `404` | `NOT_FOUND` | `RIBBON_NOT_FOUND` | Couldn't find the ribbon. |
    | `400` | `INVALID_ARGUMENT` | `INFO_SECTION_ERROR_OCCURRED` | Info section update failed. |
    | `404` | `NOT_FOUND` | `CUSTOMIZATION_NOT_EXIST` | Couldn't find the customization. |
    | `500` | `INTERNAL` | `ADD_CUSTOMIZATION_CHOICES_FAILED` | Failed to add customization choices. |
    | `404` | `NOT_FOUND` | `CHOICE_NOT_EXIST` | Couldn't find the choice. |
    | `400` | `INVALID_ARGUMENT` | `FIELD_MASK_WITH_FIELD_NOT_PASSED_ERROR` | Field mask includes fields not provided in the request. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_RIBBON_IN_ADDITIONAL` | Same ribbon appears more than once in `additionalRibbons`. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_RIBBON_IN_PRIMARY_AND_ADDITIONAL` | Same ribbon used as both primary ribbon and additional ribbon. |
    | `400` | `INVALID_ARGUMENT` | `PRICE_PER_UNIT_NOT_ALIGNED` | If product physicalProperties.pricePerUnit is defined then it must be defined for all variant and vice versa. physicalProperties.pricePerUnit.measurementUnit must be aligned between product and all variants: you cannot have KG (weight) in products and ML (volume) in variants. measurementUnit of product and every variant must be aligned with site locale (metric or imperial). |
    | `400` | `INVALID_ARGUMENT` | `MISSING_OPTIONS_ON_UPDATE_VARIANTS` | Update request includes `variants` but is missing `options`. Both must be provided together. |
    | `400` | `INVALID_ARGUMENT` | `SUBSCRIPTION_INVALID_AUTO_RENEWAL` | The `autoRenewal` field is set to false. Set the number of billing cycles in `billingCycles` to prevent automatic renewal instead. |
    | `400` | `INVALID_ARGUMENT` | `DESCRIPTION_SIZE_TOO_BIG` | Product `description` field exceeds the maximum size of 32000 bytes. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_VARIANT_OPTION_CHOICE` | Variant choice doesn't exist in the product's option choices. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_VARIANT_OPTION` | Variant option doesn't exist in the product's options. |
