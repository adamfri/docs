    Counts the number of bookings matching the specified filters.

    See [Query Extended Bookings](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-reader-v2/query-extended-bookings) for a list of supported filters.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-CALENDAR-WITH-PARTICIPANTS">Read bookings calendar - including participants</span>
    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>
    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-SENSITIVE">Read Bookings - Including Participants</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/bookings-reader/v2/extended-bookings/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object in the following format:
      `"filter" : {`
      "fieldName1": "value1",
      "fieldName2":&#123;"$operator":"value2"&#125;
      &#125;``
      Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      The number of bookings matching the specified filter.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
