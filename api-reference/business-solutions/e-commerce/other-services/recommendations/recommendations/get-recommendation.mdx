    Returns a list of items to recommend to site visitors based on the specified algorithms.

    You can specify multiple algorithms in the request. The method processes them in order and returns the recommendations from the first algorithm that meets the `minimumRecommendedItems` threshold. If the first algorithm doesn't provide enough items, the method moves to the next algorithm in the list and repeats the process. If no algorithm meets the threshold, the method returns an empty array.

    <Note>

    - Both the app providing the algorithm and an app providing a supported catalog must be installed on the site.
    - This method doesn't run the algorithms directly. It calls the installed apps that provide them.

    </Note>

    To see which algorithms are available on a site, call [List Available Algorithms](https://dev.wix.com/docs/rest/api-reference/wix-e-commerce/recommendations/list-available-algorithms).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.READ-ECOM">Read eCommerce - all read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/recommendations/get
    ```

    ## Body Params

    <ParamField body="items" type="CatalogReference[]">

      Catalog items to base recommendations on. Required if the algorithm's `algorithmType` is `RELATED_ITEMS`.

      Constraints: `maxItems 300`.

      <Expandable title="items properties">

        <ParamField body="catalogItemId" type="string" required>

          ID of the item within the catalog it belongs to.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="appId" type="string" required>

          ID of the app providing the catalog.

          You can get your app's ID from its page in the [app dashboard](https://dev.wix.com/dc3/my-apps/).

          For items from Wix catalogs, the following values always apply:
          + Wix Stores: `"215238eb-22a5-4c36-9e7b-e7c08025e04e"`
          + Wix Bookings: `"13d21c63-b5ec-5912-8397-c3a5ddb27a97"`
          + Wix Restaurants: `"9a5d83fd-8570-482e-81ab-cfa88942ee60"`

          Constraints: `minLength 1`.

        </ParamField>

        <ParamField body="options" type="object">

          Additional item details in `key:value` pairs.

          Use this optional field for more specificity with item selection. The values of the `options` field differ depending on which catalog is providing the items.

          For Wix Stores products, learn more about integrating with [Catalog V3](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/e-commerce-integration)
          or [Catalog V1](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v1/catalog/e-commerce-integration), depending on [the version the site uses](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-versioning/introduction).

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="algorithms" type="Algorithm[]" required>

      Algorithms to specify for generating recommendations, ordered by preference. The method processes algorithms in order and provides recommendations from the first algorithm that meets the `minimumRecommendedItems` threshold.

      Constraints: `minItems 1`, `maxItems 10`.

      <Expandable title="algorithms properties">

        <ParamField body="id" type="string" required>

          ID of the algorithm, as defined by the app that provides it.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="appId" type="string" required>

          ID of the app providing the algorithm. This can be an app built by Wix or a 3rd-party app.

          See app IDs for [apps built by Wix](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/platform/about-apps-created-by-wix).

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="minimumRecommendedItems" type="integer">

      Minimum number of items an algorithm must provide for its recommendations to be returned in the response. If no algorithm provides enough items, an empty array is returned.

      Constraints: `min 0`, `max 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="recommendation" type="Recommendation">

      The recommended items and the algorithm that provided them. Empty if no algorithm met the `minimumRecommendedItems` threshold.

      See the [Recommendation Object](/api-reference/business-solutions/e-commerce/other-services/recommendations/recommendations/recommendation-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `ITEM_APP_ID_NOT_SUPPORTED` | The `items` array contains app IDs that aren't supported by the specified algorithm. |
    | `400` | `INVALID_ARGUMENT` | `ALGORITHM_NOT_SUPPORTED` | One or more algorithms in the `algorithms` array aren't supported by the provider. |
    | `404` | `NOT_FOUND` | `RECOMMENDATIONS_PROVIDER_NOT_FOUND` | Couldn't find the recommendation provider. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
