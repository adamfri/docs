    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/revshare/v1/premium-payouts/{premiumPayoutId}
    ```

    ## Path Params

    <ParamField path="premiumPayoutId" type="string" required>

      ID of the premium payout to retrieve.

    </ParamField>
