A `connectedDomain` object holds information about an external domain and its connection to a Wix site.

## SDK package

```bash
npm install @wix/domains
```

Import the `connectedDomains` namespace from `@wix/domains`.

## Methods

<CardGroup cols={2}>

  <Card title="List Connected Domains" href="/api-reference/account-level/domains/connected-domains/connected-domain-v1/list-connected-domains">

  </Card>
  <Card title="Create Connected Domain" href="/api-reference/account-level/domains/connected-domains/connected-domain-v1/create-connected-domain">

  </Card>
  <Card title="Get Connected Domain" href="/api-reference/account-level/domains/connected-domains/connected-domain-v1/get-connected-domain">

  <Card title="Delete Connected Domain" href="/api-reference/account-level/domains/connected-domains/connected-domain-v1/delete-connected-domain">
