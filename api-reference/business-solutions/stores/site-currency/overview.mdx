A currency that can be displayed on a site.
Site currencies control which currencies visitors can view prices in.
When a currency is enabled for a site, prices are automatically converted from their original currency using up-to-date exchange rates.

## SDK package

```bash
npm install @wix/currency-converter
```

Import the `siteSettings` namespace from `@wix/currency-converter`.
