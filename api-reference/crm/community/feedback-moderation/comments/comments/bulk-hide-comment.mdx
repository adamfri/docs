    Hides multiple comments. The comment status becomes `HIDDEN`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.MANAGE.COMMENTS">Manage Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/comments/v1/bulk/comments/hide-by-filter
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the app where to hide the comments.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="filter" type="object" required>

      Filter to identify the comments that need to be hidden. Each key corresponds to an option name, and its values correspond to the choices for this option. For example, &#123;`"resourceId"`: `"64ad407e0bf87891bba7de3a"`, `"parentComment.id"`: `"726cb137-a9c3-408b-9cc2-2b64c6be8a95"`&#125;.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

      Pass this ID to Get Async Job, in the Async Jobs API, to retrieve job details and metadata.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Comment Updated | `wix.comments.v2.comment_updated` | Triggered when a comment is updated. |
    | Comment Hidden | `wix.comments.v2.comment_comment_hidden` | Triggered when a comment is hidden. |
    | Resource Comment Count Changed | `wix.comments.v2.comment_resource_comment_count_changed` | Triggered when the total number of comments has changed in a resource. |
