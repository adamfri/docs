This article presents possible use cases and corresponding sample flows that you can support. This can be a helpful jumping off point as you plan your implementation.

## Delete residential building projects older than 2 years
You can integrate with the Projects API to display residential building projects available for investment. To keep listings current, once a year you might want to delete projects that are over 2 years old.

1. Call [Create Projects](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/create-project) to create a project for each residential building available for investment. 

2. Once a year, call [Query Projects](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/query-projects) using the created date property to retrieve all projects in the site's portfolio older than 2 years. Record the returned project IDs. 

2. For each project ID returned, call [Delete Project](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/delete-project) to remove the project from the portfolio. 

## Fetch project information for your art gallery

You can create a curated art gallery that lists various artists' projects. To display the most up-to-date projects from your artists, set the gallery to automatically fetch and display projects whenever Wix users add, update, or delete them. 

1. Wix users can create and manage projects in a Wix Portfolio. 

2. Listen for the [Project Created](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/project-created), [Project Updated](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/project-updated), and [Project Deleted](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/project-deleted) events to detect when projects have been added, updated, or deleted. Retrieve the latest project data from the event object.

3. Reflect the changes in your gallery.
