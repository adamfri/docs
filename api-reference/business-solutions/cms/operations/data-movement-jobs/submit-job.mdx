    Submit a data movement job.

    <Note>

    By default, the job is submitted for the current site.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE_MOVEMENT_JOBS">Data Mover Manage Jobs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data-mover/v1/jobs
    ```

    ## Examples

    This job moves data from a Wix data collection to a CSV file.

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/data-mover/v1/jobs' \
          -H 'Content-Type: application/json;charset=UTF-8' \
          -H 'Authorization: <AUTH>' \
          -d '{
              "name": "Wix Data Collection Export",
              "source": {
                  "wixDataCollection": {
                    "collectionId": "TodoList"
                  }
              },
              "destination": {
                  "file": {
                    "format": "CSV",
                    "fileName": "TodoList.csv"
                  }
              }
          }'
      ```

      ```json Response
      {
        "job": {
          "id": "8646fc6e-58f3-4d78-b3ab-6a63a5a46400",
      ```
