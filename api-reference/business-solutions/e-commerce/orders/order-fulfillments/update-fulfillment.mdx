    Updates a fulfillment's properties.

    To update a field's value, include the new value in the `fulfillment` field in the body params.

    <Note>

    + `trackingInfo.trackingNumber` and `trackingInfo.shippingProvider` can be updated but not removed.
    + When updating `lineItems`, each line item must include an explicit `quantity`.
    + Line items can't be updated for a fulfillment with `completed: true`.
    + A shipping notification email may be sent to the buyer when the tracking info changes, depending on the site's email settings.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v1/fulfillments/{fulfillment.id}/orders/{orderId}
    ```

    ## Path Params

    <ParamField path="orderId" type="string" required>

      Order ID.

    </ParamField>

    <ParamField path="fulfillment.id" type="string" required>

      Fulfillment ID.

    </ParamField>

    ## Body Params

    <ParamField body="fulfillment" type="Fulfillment">

      Fulfillment info to update.

      <Expandable title="fulfillment properties">

        <ParamField body="id" type="string" required>

          Fulfillment ID.

          **Read-only.**

        </ParamField>

        <ParamField body="createdDate" type="datetime">

          Fulfillment creation date and time in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations) format.

          **Read-only.**

        </ParamField>

        <ParamField body="lineItems" type="FulfillmentLineItem[]">

          Line items being fulfilled.

          Constraints: `minItems 0`, `maxItems 300`.

          <Expandable title="lineItems properties">

            <ParamField body="id" type="string">

              Line item ID (mirrors the ID of the order line item).

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="quantity" type="integer">

              Line item quantity.

              * If this property isn't passed on creation, it defaults to the number of items not already linked to a fulfillment.
              * If the order does not have the requested quantity of line items available to add to this fulfillment, the fulfillment will not be created and an error is returned.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="status" type="string">

          The current status of the fulfillment process.

          Supported values (case-sensitive, any other value is rejected):
          + `"Pending"` - Initial state when fulfillment is created but processing hasn't started.
          + `"Accepted"` - Order has been received and validated for fulfillment.
          + `"Ready"` - Items have been picked and packed, ready for shipping.
          + `"In_Delivery"` - Items have been handed over to the shipping carrier.
          + `"Fulfilled"` - Delivery has been completed successfully.

          The status typically progresses from `Pending` to `Accepted`, `Ready`, `In_Delivery`, and finally `Fulfilled`.
          Update the status manually or automatically depending on your fulfillment workflow.

          This field is informational. The order's `fulfillmentStatus` is primarily derived from the fulfilled line item quantities, not from this field.

        </ParamField>

        <ParamField body="completed" type="boolean">

          Fulfillment handling complete.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="FulfillmentInfo" type="FulfillmentInfo">

          FulfillmentInfo

          <Expandable title="FulfillmentInfo properties">

            <ParamField body="trackingInfo" type="FulfillmentTrackingInfo">

              Tracking info.

              _Nested structure omitted for brevity — see the `FulfillmentTrackingInfo` object._

            </ParamField>

            <ParamField body="customInfo" type="CustomFulfillmentInfo">

              Custom fulfillment info.

              _Nested structure omitted for brevity — see the `CustomFulfillmentInfo` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="orderWithFulfillments" type="OrderWithFulfillments">

      Order ID and the orders' associated fulfillments after update.

      See the [Fulfillments Object](/api-reference/business-solutions/e-commerce/orders/order-fulfillments/fulfillments-object) for this object's fields.

    </ResponseField>

    ## Examples

    Updating a fulfillment's tracking number and tracking link.

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
        'https://www.wixapis.com/ecom/v1/fulfillments/1d93cd8e-0de5-469b-b802-88bcd76cb222/orders/eb4b91d3-51f3-494d-94df-479ff2c6eb08' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>' \
        -d '{
          "fulfillment": {
            "trackingInfo": {
                "trackingNumber": "45782",
                "trackingLink": "https://www.fedex.com/apps/fedextrack/?action=track&trackingnumber=45782"
              }
          }
        }'
      ```
