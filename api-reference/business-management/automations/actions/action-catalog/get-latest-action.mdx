    Retrieves the latest version of an action, regardless of the site on which it's installed.

    When an app developer updates an action, the new version doesn't immediately become active on every site. This method retrieves the latest version of the action as defined in the [app dashboard](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard/about-the-app-dashboard).

    - To retrieve the version of the action that's active on the current site, call [Get Runtime Action](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-runtime-action).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/actions/latest/apps/{appId}/keys/{actionKey=**}
    ```

    ## Path Params

    <ParamField path="appId" type="string" required>

      ID of the app that defines the action.

    </ParamField>

    ## Query Params

    <ParamField query="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `minLength 5`, `maxLength 50`.

    </ParamField>

    <ParamField query="translate" type="boolean">

      Whether to apply translations to the action.

      Default: `false`.

    </ParamField>

    ## Response Object

    <ResponseField name="action" type="Action">

      The requested action.

      See the [Action Object](/api-reference/business-management/automations/actions/action-catalog/action-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTION_SPI_NOT_FOUND` | The requested action does not have a matching service plugin implementer. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
