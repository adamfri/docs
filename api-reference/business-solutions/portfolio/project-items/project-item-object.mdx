---
title: "Project Item Object"
description: "The Project Item object in the Wix Project Item API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="projectId" type="string">

      Project ID.

    </ResponseField>

    <ResponseField name="id" type="string">

      Project item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="sortOrder" type="number">

      Index that determines which position a project is displayed in the project.  &lt;br />

      Default: [Epoch](https://www.epoch101.com/) timestamp. &lt;br />

    </ResponseField>

    <ResponseField name="title" type="string">

      Project item title.

    </ResponseField>

    <ResponseField name="description" type="string">

      Project item description.

    </ResponseField>

    <ResponseField name="type" type="string">

      Project item data type.

      **Read-only.**

      **Supported values:**

      - `UNDEFINED` — Undefined item type.
      - `IMAGE` — Image item type.
      - `VIDEO` — Video item type.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the project item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the project item was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="link" type="Link">

      Project item link.

      <Expandable title="link properties">

        <ResponseField name="text" type="string">

          Display text of the link.

        </ResponseField>

        <ResponseField name="url" type="string">

          Target URL of the link.

        </ResponseField>

        <ResponseField name="target" type="string">

          Whether the link opens in a new tab or window. One of:
          * `'_blank'`: The link opens in a new tab or window.
          * `'_self'`: The link opens in the same tab or window.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "projectId": "123e4567-e89b-12d3-a456-426614174000",
        "id": "987e6543-e21a-10d2-b987-426614176789",
        "sortOrder": 1694090400.0,
        "title": "Sample Project Item Title",
        "description": "This is a description for the sample project item.",
        "type": "IMAGE",
        "image": {
          "imageInfo": {
            "id": "987e6543-e21a-10d2-b987-426614176789",
            "url": "https://example.com/image.jpg",
            "width": 1920,
            "height": 1080
          }
        },
        "createdDate": "2024-07-31T12:00:00Z",
        "updatedDate": "2024-07-31T12:00:00Z",
        "link": {
          "text": "View Project",
          "url": "https://example.com/project",
          "target": "_blank"
        }
      }
      ```

    </CodeGroup>
