    Terminates the member's session and clears authentication cookies.

    Returns the following:
    - `body`: HTML content for the logout response
    - `statusCode`: HTTP status code (200 for success, 302 for redirect)
    - `headers`: Array of key-value pairs including:
    - `Set-Cookie` headers to remove all session cookies
    - `Location` header (when `postLogoutRedirectUri` is provided, with 302 status)

    ## Endpoint

    ```http
    GET https://www.wixapis.com/iam/authentication/v1/logout
    ```

    ## Query Params

    <ParamField query="postLogoutRedirectUri" type="string">

      URL to redirect to after logout.

      Optional redirect destination after the logout process completes.

    </ParamField>

    <ParamField query="clientId" type="string">

      Client identifier for the logout request.

      Identifies the application or client initiating the logout.

    </ParamField>

    ## Response Object

    <ResponseField name="body" type="bytes" />
