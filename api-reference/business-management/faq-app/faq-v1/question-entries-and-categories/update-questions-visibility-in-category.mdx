```http
POST https://www.wixapis.com/faq/v1/question-entries/update-visibility
```

## Body Params

<ParamField body="visibility" type="QuestionVisibility[]">

  List of visibility updates for questions entries, each containing the ID of the question to update, and optional new values for status, order and categoryId.

  <Expandable title="visibility properties">

    <ParamField body="questionId" type="string">

      ID of the question entry to update.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="categoryId" type="string">

      ID of new category.

      Constraints: `minLength 1`, `maxLength 50`.

    </ParamField>

    <ParamField body="sortOrder" type="number">

      New order of question entry in category.

    </ParamField>

    <ParamField body="status" type="string">

      New status of question entry.

      **Supported values:**

      - `VISIBLE`
      - `HIDDEN`

    </ParamField>

  </Expandable>

</ParamField>

## Response Object

<ResponseField name="failures" type="string[]">

  List of failed question entry IDs that should be retried.

  Constraints: `format GUID`.

</ResponseField>
