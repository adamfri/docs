    Retrieves the first available time slot of each fulfillment type for each specified operation.

    The response includes time slots with delivery fulfillment types only if you specify a delivery address.
    Only fulfillment methods capable of delivering to the specified address are considered when calculating time slot availability.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/operations/v1/operations/first-available-time-slots-per-operations
    ```
