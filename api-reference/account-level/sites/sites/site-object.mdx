title: "Site Object"

icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Site ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="htmlAppId" type="string">

      HTML app ID for the site.

    </ResponseField>

    <ResponseField name="name" type="string">

      Site name. Used in the site's URL.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Site display name. Used for display purposes, such as in the browser's tab name.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Site creation date.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Site updated date.

    </ResponseField>

    <ResponseField name="trashedDate" type="datetime">

      Site trashed date.

    </ResponseField>

    <ResponseField name="published" type="boolean">

      Whether the site is published.

    </ResponseField>

    <ResponseField name="premium" type="boolean">

      Whether the site has a Wix Premium (paid) plan.

    </ResponseField>

    <ResponseField name="viewUrl" type="string">

      Live site URL.

    </ResponseField>

    <ResponseField name="editUrl" type="string">

      Editor site URL.

    </ResponseField>

    <ResponseField name="thumbnail" type="string">

      Site thumbnail.

    </ResponseField>

    <ResponseField name="ownerAccountId" type="string">

      Site owner's account ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="contributorAccountIds" type="string[]">

      Site contributors' account IDs.

      Constraints: `format GUID`, `minItems 1`, `maxItems 1000`.

    </ResponseField>

    <ResponseField name="editorType" type="string">

      Site's Wix editor type.

      **Supported values:**

      - `EDITOR`
      - `ADI`
      - `EDITORX`
      - `STUDIO`
      - `ODEDITOR`
      - `PICASSO`
      - `WIXEL`
      - `STUDIO_TWO`
      - `EDITORLESS`

    </ResponseField>

    <ResponseField name="blocked" type="boolean">

      Whether Wix has blocked this site due to legal issues.

    </ResponseField>

    <ResponseField name="folderId" type="string">

      Folder ID that contains this site. Empty if site is at root level.

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Namespace of the site, for internal use.

      **Supported values:**

      - `UNKNOWN_NAMESPACE`
      - `WIX` — Default namespace for UGC sites. MetaSites with this namespace will be shown in a user's site list by default.
      - `SHOUT_OUT` — ShoutOut stand alone product. These are siteless (no actual Wix site, no HtmlWeb). MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `ALBUMS` — MetaSites created by the Albums product, they appear as part of the Albums app. MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `WIX_STORES_TEST_DRIVE` — Part of the WixStores migration flow, a user tries to migrate and gets this site to view and if the user likes it then stores removes this namespace and deletes the old site with the old stores. MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `HOTELS` — Hotels standalone (siteless). MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `CLUBS` — Clubs siteless MetaSites, a club without a wix website. MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `ONBOARDING_DRAFT` — A partially created ADI website. MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `DEV_SITE` — AppBuilder for AppStudio / shmite (c). MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `LOGOS` — LogoMaker websites offered to the user after logo purchase. MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `VIDEO_MAKER` — VideoMaker websites offered to the user after video purchase. MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `PARTNER_DASHBOARD` — MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `DEV_CENTER_COMPANY` — MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `HTML_DRAFT` — A draft created by HTML editor on open. Upon "first save" it will be moved to be of WIX domain.

      Meta site with this namespace will *not* be shown in a user's site list by default.
      - `SITELESS_BUSINESS` — the user-journey for Fitness users who want to start from managing their business instead of designing their website.
      Will be accessible from Site List and will not have a website app.
      Once the user attaches a site, the site will become a regular wixsite.
      - `CREATOR_ECONOMY` — Belongs to "strategic products" company. Supports new product in the creator's economy space.
      - `DASHBOARD_FIRST` — It is to be used in the Business First efforts.
      - `ANYWHERE` — Bookings business flow with no site.
      - `HEADLESS` — Namespace for Headless Backoffice with no editor
      - `ACCOUNT_MASTER_CMS` — Namespace for master site that will exist in parent account that will be referenced by subaccounts
      The site will be used for account level CSM feature for enterprise
      - `RISE` — Rise.ai Siteless account management for Gift Cards and Store Credit.
      - `BRANDED_FIRST` — As part of the branded app new funnel, users now can create a meta site that will be branded app first.
      There's a blank site behind the scene but it's blank).
      The Mobile company will be the owner of this namespace.
      - `NOWNIA` — Nownia.com Siteless account management for Ai Scheduling Assistant.
      - `UGC_TEMPLATE` — UGC Templates are templates that are created by users for personal use and to sale to other users.
      The Partners company owns this namespace.
      - `CODUX` — Codux Headless Sites
      - `MEDIA_DESIGN_CREATOR` — Bobb - AI Design Creator.
      - `SHARED_BLOG_ENTERPRISE` — Shared Blog Site is a unique single site across Enterprise account,
      This site will hold all Blog posts related to the Marketing product.
      - `STANDALONE_FORMS` — Standalone forms (siteless). MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `STANDALONE_EVENTS` — Standalone events (siteless). MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `MIMIR` — MIMIR - Siteless account for MIMIR Ai Job runner.
      - `TWINS` — Wix Twins platform.
      - `NANO` — Wix Nano.
      - `BASE44` — Base44 headless sites.
      - `CHANNELS` — Wix Channels Sites
      - `NAUTILUS` — Nautilus platform.
      - `SYMPHONY` — Symphony — a siteless site representing a project within Symphony (the evolution of Orion).
      Holds project data, conversations, assets, and manages collaborators / shared team members for the project.
      - `NAUTILUS_APPS` — Nautilus platform app.
      - `VIBU` — Vibu — a siteless site representing a project built with Vibu (the AI app builder).
      Holds the project's generated code, conversations, assets, and manages collaborators for the project.
      - `ENTERPRISE_BRAND_KIT` — Ghost site for the BrandKit multi-site platform. Each ghost backs a single BrandKit
      (an Enterprise account may have several), holding that BrandKit's brand definition
      (theme, typography, assets) which is rolled out to the BrandKit's connected sites.
      MetaSites with this namespace will *not* be shown in a user's site list by default.
      - `DEV_CENTER_DEV_SITE` — Development sites managed by dev-center's DevelopmentSitesManager (com.wixpress.devcenter.dsm) —
      real, fully premium Wix sites created from a template and lent to a developer to test their
      in-development app. Distinct from DEV_SITE (Wix Blocks app-backing sites keyed by app_def_id).
      Owner: ot-dev-center-platform.
      MetaSites with this namespace will *not* be shown in a user's site list by default.

    </ResponseField>

    <ResponseField name="domainConnected" type="boolean">

      Whether the site has a connected domain.

    </ResponseField>

    <ResponseField name="parentChildRole" type="string">

      Role of the site in a parent-child data-sharing relationship.

      **Supported values:**

      - `NONE` — This site is not part of a parent-child relationship (regular site).
      - `CHILD` — This site is a child site, attached to a parent for data sharing.
      - `PARENT` — This site is a parent site, has children attached to it.

    </ResponseField>

    <ResponseField name="parentId" type="string">

      For child sites, the parent meta site ID.

    </ResponseField>

  </Tab>
