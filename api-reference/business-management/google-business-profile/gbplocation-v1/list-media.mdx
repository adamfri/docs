    Retrieves a location's media items from Google.

    Each item includes the media key you need to delete it. Media isn't stored for
    the site, so this always reflects what's on the Business Profile now.

    That means it lags behind anything still queued through Bulk Create Media
    Uploads. If a submission is still being applied, combine this with List Media
    Uploads to show what the site owner asked for. Count only changes still on
    their way, since a failed addition never reached Google:

    ```
    gallery = this list
    + additions still PENDING or UPLOADING
    - removals still PENDING or UPLOADING
    ```

    Errors:
    - `NOT_FOUND`: the location isn't recorded for this site. Google isn't called.
    - `GOOGLE_API_CALL_FAILED`: the call to Google failed. Google's status and
    response are in the error payload.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/locations/{locationId}/media
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID. This is Google's location identifier.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Cursor-based paging. `limit` maps to Google's page size (unset uses a server
      default of 100, max 100); `cursor` is the `next` token returned by a previous
      response (an opaque Google page token).

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="mediaItems" type="MediaItem[]">

      Media items for this page of the location's media.

      <Expandable title="mediaItems properties">

        <ResponseField name="mediaKey" type="string">

          Google's opaque media key (used to reference/delete media).

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="format" type="string">

          Whether this item is a photo or a video.

          **Supported values:**

          - `PHOTO`
          - `VIDEO`

        </ResponseField>

        <ResponseField name="googleUrl" type="string">

          Google-hosted URL the media is served at.

          Not stable: it can change over time, so use `mediaKey` as the durable
          identifier rather than this. For a video, this is a preview image rather
          than the stream.

          Constraints: `format WEB_URL`, `maxLength 2048`.

        </ResponseField>

        <ResponseField name="category" type="string">

          Category of the media (e.g. EXTERIOR, INTERIOR, LOGO).

          **Supported values:**

          - `COVER` — The banner image at the top of the profile. One per location.
          - `PROFILE` — The profile image shown alongside the business name.
          - `LOGO` — The business's logo. One per location.
          - `EXTERIOR` — The outside of the premises, including the storefront.
          - `INTERIOR` — The inside of the premises.
          - `PRODUCT` — A product the business sells.
          - `AT_WORK` — The team at work, such as staff serving customers.
          - `FOOD_AND_DRINK` — Food or drink the business serves.
          - `MENU` — The menu, for a business that serves food or drink.
          - `COMMON_AREA` — A shared space, such as a lobby or a waiting area.
          - `ROOMS` — Guest rooms, for accommodation businesses.
          - `TEAMS` — The people who work at the business.
          - `ADDITIONAL` — Anything that doesn't fit the other categories. This is the default for a
          gallery photo.

        </ResponseField>

        <ResponseField name="thumbnailUrl" type="string">

          Google-hosted thumbnail URL. Like `googleUrl`, this can change over time.

          Constraints: `format WEB_URL`, `maxLength 2048`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Caption or description of the media item.

          Constraints: `maxLength 5000`.

        </ResponseField>

        <ResponseField name="sourceUrl" type="string">

          The URL the image was originally fetched from, echoing the `sourceUrl` it
          was created with. Present on media the site owner posted, and absent on
          media contributed by customers.

          Constraints: `format WEB_URL`, `maxLength 2048`.

        </ResponseField>

        <ResponseField name="attribution" type="MediaItemAttribution">

          Attribution of the contributor, for customer-contributed media. Empty for
          merchant-posted media (e.g. items added via CreateMedia).

          <Expandable title="attribution properties">

            <ResponseField name="profileName" type="string">

              Display name of the contributor.

              Constraints: `maxLength 255`.

            </ResponseField>

            <ResponseField name="profilePhotoUrl" type="string">

              URL of the contributor's profile photo.

              Constraints: `format WEB_URL`, `maxLength 2048`.

            </ResponseField>

            <ResponseField name="takedownUrl" type="string">

              URL to report the media or request its takedown.

              Constraints: `format WEB_URL`, `maxLength 2048`.

            </ResponseField>

            <ResponseField name="profileUrl" type="string">

              URL of the contributor's profile.

              Constraints: `format WEB_URL`, `maxLength 2048`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata. `cursors.next` is the token to specify for the next page, and
      `hasNext` says whether there is one.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>
