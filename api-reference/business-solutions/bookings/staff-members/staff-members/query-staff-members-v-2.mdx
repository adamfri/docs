    Retrieves a list of staff members, given the provided filtering, sorting, and paging.

    Returns all staff members, including both service providers and staff members who don't
    provide services. To retrieve only service providers, filter by `serviceProvider`.

    ### Defaults

    Query Staff Members V2 has the following default settings, which you can override:
    + Sorted by `id` in ascending order.
    + `cursorPaging.limit` set to `100`.

    ### See also

    For the fields you can filter and sort by, see [Filtering and Sorting](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/filtering-and-sorting).

    To learn about working with Query methods, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language) and [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RENTALS.MANAGE">Manage_Wix_Rentals_App_Forms_submissions</span>

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/staff-members/query
    ```
