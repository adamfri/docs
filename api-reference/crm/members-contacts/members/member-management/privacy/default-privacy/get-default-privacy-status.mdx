    Retrieves the default privacy status of a site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/default-privacy-status
    ```

    ## Response Object

    <ResponseField name="defaultPrivacy" type="DefaultPrivacy">

      Retrieved default privacy settings.

      See the [Default Privacy Object](/api-reference/crm/members-contacts/members/member-management/privacy/default-privacy/default-privacy-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

    </Note>
