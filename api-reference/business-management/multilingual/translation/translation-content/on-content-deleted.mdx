Triggered when translation content is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.translation.v1.content_deleted` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation API`, `Wix Multilingual - Translation Content + Published Content Read` |
