    Updates a schedule.

    Each time the schedule is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the schedule.
    This ensures you're working with the latest schedule
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.MANAGE">Manage Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/calendar/v3/schedules/{schedule.id}
    ```

    ## Path Params

    <ParamField path="schedule.id" type="string" required>

      Schedule ID.

    </ParamField>

    ## Body Params

    <ParamField body="schedule" type="Schedule" required>

      Schedule to update.

      See the [Schedule Object](/api-reference/business-management/calendar/schedules-v3/schedule-object) for this object's fields.

    </ParamField>

    <ParamField body="participantNotification" type="ParticipantNotification">

      Information about whether participants of the schedule's updated events are
      notified and the message they receive.

      <Expandable title="participantNotification properties">

        <ParamField body="notifyParticipants" type="boolean">

          Whether to notify the participants about changes made to the schedule or event.

          Default: `false`

        </ParamField>

        <ParamField body="message" type="string">

          Message to send.

          Min: 1 character
          Max: 5000 characters

        </ParamField>

        <ParamField body="metadata" type="object">

          Information about the delivery channels used to send the notification.
          For example, `{"channels": "SMS" }`, `{"channels": "EMAIL" }`, or `{"channels": "EMAIL, SMS" }`.

          Max: 10 keys
          Max key length: 64 characters
          Max value length: 1000 characters

          Constraints: `format map`.

          <Expandable title="metadata properties">

            <ParamField body="key" type="string" />

            <ParamField body="value" type="string" />

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
