    <div className="wix-ref">

    Retrieves a list of up to 100 schedule items, with basic filter support.

    Default filters to schedule items with a `state` of `PUBLISHED` and `VISIBLE`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/schedule
    ```

    ## Query Params

    <ParamField query="eventId" type="string[]">

      Event ID to which the schedule items belong.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="state" type="string[]">

      Schedule item state filter.

      Defaults to `["PUBLISHED", "VISIBLE"]` when no filters are specified. &lt;br/>
      If neither `"PUBLISHED"` nor `"DRAFT"` are specified, assumes `"PUBLISHED"`, for example: [`"HIDDEN"`] becomes [`"HIDDEN"`, `"PUBLISHED"`].
      If neither `"VISIBLE"` nor `"HIDDEN"` are specified, assumes `"VISIBLE"`, for example: [`"DRAFT"`] becomes [`"DRAFT"`, `"VISIBLE"`].

      Constraints: `maxItems 20`.

      **Supported values:**

      - `PUBLISHED` — Schedule item is published.
      - `DRAFT` — Schedule item is in draft.
      - `VISIBLE` — Schedule item is visible to the event's guests.
      - `HIDDEN` — Schedule item is hidden to the event's guests.

    </ParamField>

    <ParamField query="startingFrom" type="datetime">

      Filters schedule items starting on or after specified point in time. Inclusive.

    </ParamField>

    <ParamField query="startingBefore" type="datetime">

      Filters schedule items starting before specified point in time. Non-inclusive.

    </ParamField>

    <ParamField query="offset" type="integer" deprecated>

      *Deprecated:** Use `paging` instead.

      **Deprecated.** Constraints: `min 0`, `max 1000`.

    </ParamField>

    <ParamField query="limit" type="integer" deprecated>

      *Deprecated:** Use `paging` instead.

      **Deprecated.** Constraints: `min 0`, `max 100`.

    </ParamField>

    <ParamField query="facet" type="string[]">

      Filter facets.

      Constraints: `minLength 1`, `maxLength 100`, `maxItems 20`.

    </ParamField>

    <ParamField query="itemId" type="string[]">

      Item IDs filter.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="tag" type="string[]">

      Tags filter.

      Constraints: `minLength 1`, `maxLength 30`, `maxItems 50`.

    </ParamField>

    <ParamField query="stageName" type="string[]">

      Stage names filter.

      Constraints: `maxLength 30`, `maxItems 50`.

    </ParamField>

    <ParamField query="paging" type="Paging">

      Pointer to page of results using offset.
      See [Paging](https://dev.wix.com/docs/rest/articles/getting-started/sorting-and-paging#paging).

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load per page.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>
