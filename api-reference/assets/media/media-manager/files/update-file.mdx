Updates a file.

Specify the `parentFolderId` parameter to move a file from its current folder to a different folder.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-MEDIA.MANAGE-MEDIAMANAGER">Manage Media Manager</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
PATCH https://www.wixapis.com/site-media/v1/files/update-file
```

## Body Params

<ParamField body="fileId" type="string" required>

  ID of the file to update.

  You can also specify the file's Wix media URL. For example, `wix:image://v1/0abec0_b291a9349a0b4da59067f76287e386fb~mv2.jpg/leon.jpg#originWidth=3024&originHeight=4032`.
  Learn more [about the file ID parameter](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/file-id).

  Constraints: `maxLength 1000`.

</ParamField>

<ParamField body="displayName" type="string">

  File name that appears in the Media Manager.

</ParamField>

<ParamField body="parentFolderId" type="string">

  ID of the file's parent folder. &lt;br />
  Default: `media-root`.

</ParamField>

<ParamField body="labels" type="string[]">

  Labels assigned to media files that describe and categorize them. Provided by the Wix user, or generated by [Google Vision API](https://cloud.google.com/vision/docs/drag-and-drop) for images.

  Constraints: `maxLength 200`, `maxItems 500`.

</ParamField>

## Response Object

<ResponseField name="file" type="FileDescriptor">

  Information about the updated file.

  See the [File Descriptor Object](/api-reference/assets/media/media-manager/files/file-descriptor-object) for this object's fields.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
