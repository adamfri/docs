    Generates a preview of a reservation invoice, including the specified coupon or pricing plan.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-BASIC-ORDERS">Read Basic Events Order Info</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/checkout/invoices/{reservationId}
    ```

    ## Path Params

    <ParamField path="reservationId" type="string" required>

      Reservation ID.

    </ParamField>
