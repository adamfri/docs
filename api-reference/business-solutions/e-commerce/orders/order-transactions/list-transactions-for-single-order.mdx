    <div className="wix-ref">

    Retrieves information about payments and refunds associated with a specified order.

    An order with no recorded payments or refunds returns an empty transactions record rather than an error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/payments/orders/{orderId}
    ```

    ## Path Params

    <ParamField path="orderId" type="string" required>

      Order ID.

    </ParamField>

    ## Response Object

    <ResponseField name="orderTransactions" type="OrderTransactions">

      Order ID and its associated transactions.

      See the [Order Transactions Object](/api-reference/business-solutions/e-commerce/orders/order-transactions/order-transactions-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
