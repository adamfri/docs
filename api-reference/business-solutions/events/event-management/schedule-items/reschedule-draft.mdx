  <Tab title="REST">

    Adjusts the time of all draft schedule items for an event at once.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS-MEGA.MANAGE-EVENTS">Manage Events - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/schedule/draft/reschedule
    ```

    ## Body Params

    <ParamField body="eventId" type="string" required>

      Event ID to which the draft schedule item belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="timeZoneId" type="string" required>

      Time zone ID in TZ database format, e.g., `"EST"`, `"America/Los_Angeles"`.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField body="timeSlotOffset" type="duration">

      Offset added or subtracted from schedule item start & end times.

    </ParamField>

    ## Response Object

    Returns `RescheduleDraftResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
