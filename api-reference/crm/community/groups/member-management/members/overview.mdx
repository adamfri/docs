A group member represents an existing site member that has joined a group.
You can add, remove, and query group members.
Learn more about [group members](https://support.wix.com/en/article/wix-groups-adding-new-members-to-your-group).

## SDK package

```bash
npm install @wix/groups
```

Import the `members` namespace from `@wix/groups`.
