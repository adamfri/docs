    Retrieve all a program definition's pool definitions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.READ_LIMITED">SCOPE.BENEFIT_PROGRAMS.READ (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/pool-definitions/find-pool-definitions-by-program-definition
    ```

    ## Body Params

    <ParamField body="programDefinitionId" type="string" required>

      ID of the program definition to retrieve its pool definitions.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="namespace" type="string" required>

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      Constraints: `minLength 1`, `maxLength 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="poolDefinitions" type="PoolDefinition[]">

      Retrieved pool definitions.

      See the [Pool Definition Object](/api-reference/business-solutions/benefit-programs/pool-definitions/pool-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
