    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.COOKIE-CONSENT-BANNER.READ">Read Cookie Consent Banner</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wixpress/cookie-banner-settings/v1/cookie-banner-settings
    ```

    ## Query Params

    <ParamField query="languageCode" type="string">

      Language code in [ISO 639-1](https://en.wikipedia.org/wiki/ISO_639-1) format, to return translated texts. All [languages supported by Wix Multilingual](https://support.wix.com/en/article/wix-multilingual-languages-available) can be passed.

    </ParamField>

    ## Response Object

    <ResponseField name="settings" type="CookieBannerSettings">

      Cookie banner settings.

      See the [Cookie Banner Settings Object](/api-reference/business-management/cookie-consent-policy/cookie-banner-settings/cookie-banner-settings-object) for this object's fields.

    </ResponseField>

    <ResponseField name="translations" type="object">

      Translated texts, if requested.

      Constraints: `format map`.

      <Expandable title="translations properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="string" />

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
