    <div className="wix-ref">

    Generates an upload URL for uploading a file as an attachment to a specified contact.

    To learn how to use the generated upload URL in the response to upload an attachment file,
    see the [Upload API](https://dev.wix.com/docs/rest/assets/media/media-manager/files/upload-api).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACT-ATTACHMENTS">Manage Contact Attachments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/attachments/{contactId}/upload-url
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact for whom the attachment is being uploaded.

    </ParamField>

    ## Body Params

    <ParamField body="fileName" type="string" required>

      File name of the attachment including the extension, for example, `contact-cv.pdf`.

      Constraints: `minLength 1`, `maxLength 260`.

    </ParamField>

    <ParamField body="mimeType" type="string" required>

      Mime type of the attachment file, for example, `application/pdf`.
      See [supported mime types](https://dev.wix.com/docs/rest/crm/members-contacts/contacts/attachments/attachment-v4/supported-mime-types).

      Constraints: `minLength 1`, `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="uploadUrl" type="string">

      The URL for uploading a file as an attachment to the contact.

      Constraints: `format WEB_URL`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Attachment Created | `wix.contacts.v4.attachment_created` |  |
