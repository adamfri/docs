<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a Wix user's storage quota information.

    This method returns the total quota limit and current usage in bytes.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-INBOX.MANAGE-MSGS">Manage Inbox Messages</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/communication-channels-media/v1/storage-quota
    ```

    ## Response Object

    <ResponseField name="totalQuota" type="integer">

      Total storage quota limit in bytes.

    </ResponseField>

    <ResponseField name="totalUsage" type="integer">

      Current storage usage in bytes.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X GET \
      'https://www.wixapis.com/communication-channels-media/v1/storage-quota' \
      -H 'Authorization: <AUTH>'
      ```

      ```json Response
      {
        "totalQuota": "10000000000",
        "totalUsage": "5425313"
      }
      ```

    </CodeGroup>
