    Retrieves a list of global and user-defined data extension schemas for a given FQDN.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATAEXTENSIONS.READ-SCHEMAS">Read Data Extensions Schemas</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/schema-service/v1/schemas
    ```

    ## Query Params

    <ParamField query="fqdn" type="string" required>

      [Fully qualified domain name](https://dev.wix.com/docs/rest/articles/getting-started/fqdns).

      Constraints: `maxLength 255`.

    </ParamField>

    <ParamField query="namespaces" type="string[]">

      Namespaces within the given entity.

      Constraints: `maxLength 164`, `maxItems 100`.

    </ParamField>

    <ParamField query="fields" type="string[]">

      Additional fields that are hidden by default. For example, fields with `"x-wix-archived": true`.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `UNKNOWN_REQUESTED_FIELD` — Undefined requested field.
      - `ARCHIVED` — Returns `x-wix-archived` fields in `DataExtensionSchema.json_schema`.

    </ParamField>

    <ParamField query="extensionPoints" type="string[]">

      Extension points within the given entity.

      Constraints: `maxLength 10`, `maxItems 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="dataExtensionSchemas" type="DataExtensionSchema[]">

      Requested schemas.

      See the [Data Extension Schema Object](/api-reference/business-management/data-extension-schema/data-extension-schema-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
