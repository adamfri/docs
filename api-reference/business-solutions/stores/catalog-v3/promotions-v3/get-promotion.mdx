    Retrieves a promotion.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_READ">Read v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/promotions/{promotionId}
    ```

    ## Path Params

    <ParamField path="promotionId" type="string" required>

      ID of the promotion to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="promotion" type="Promotion">

      Retrieved promotion.

      See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
