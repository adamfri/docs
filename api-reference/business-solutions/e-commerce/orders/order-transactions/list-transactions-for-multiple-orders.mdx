    Retrieves information about payments and refunds associated with all specified orders.

    Order IDs the caller isn't permitted to access are omitted from the response rather than returning an error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/payments/list-by-ids
    ```

    ## Body Params

    <ParamField body="orderIds" type="string[]" required>

      Order IDs for which to retrieve transactions.

      Constraints: `minLength 1`, `maxLength 100`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="orderTransactions" type="OrderTransactions[]">

      List of order IDs and their associated transactions.

      See the [Order Transactions Object](/api-reference/business-solutions/e-commerce/orders/order-transactions/order-transactions-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
