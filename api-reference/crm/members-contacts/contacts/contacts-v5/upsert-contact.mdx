    <div className="wix-ref">

    Creates a contact, or updates an existing one when a match is found based on the contact's identifiers.

    Matching uses `externalId`, `email.email`, and `phone.phone` to find an existing contact. See [contact matching](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/matching-contacts) for the detailed matching rules.

    Upsert modes: Set `upsertMode` to control how an existing contact is updated:
    - `OVERWRITE` (default): Replaces existing field values.
    - `APPEND`: Sets a non-array field only if it doesn't already have a value, and appends to array fields.
    - `OVERWRITE_APPEND_ARRAYS`: Overwrites non-array fields and appends to array fields.

    Member contacts: Set `updateMember` to `true` when upserting a contact that is a site member.

    The response's `action` field indicates whether the contact was `CREATED` or `UPDATED`.

    Image upload: When you provide an image URL, the image is uploaded asynchronously and an `imageUploadId` is returned for tracking upload progress. Call [Get Contact Image Upload Status](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/get-contact-image-upload-status) to monitor the upload.

    To create or update multiple contacts in a single request, call [Bulk Upsert Contacts](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/bulk-upsert-contacts).

    ## Permissions

    This method requires one of the following permission scopes:

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/upsert
    ```

    ## Body Params

    <ParamField body="contact" type="Contact" required>

      Contact to upsert.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ParamField>

    <ParamField body="upsertMode" type="string">

      Mode that determines how an existing contact is updated when a match is found. See the endpoint description for the supported modes.

      **Supported values:**

      - `OVERWRITE` — Replaces existing field values. Default value.
      - `APPEND` — Sets a non-array field only if it doesn't already have a value, and appends to array fields.
      - `OVERWRITE_APPEND_ARRAYS` — Overwrites non-array fields and appends to array fields.

    </ParamField>

    <ParamField body="updateMember" type="boolean">

      Whether to update the contact even if it's a site member.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Upserted contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>

    <ResponseField name="action" type="string">

      The action performed on the contact.

      **Supported values:**

      - `UPDATED`
      - `CREATED`

    </ResponseField>

    <ResponseField name="imageUploadId" type="string">

      The upload ID of the image upload process.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INSUFFICIENT_CONTACT_DATA` | A contact must have a name, phone number or email address. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_EMAIL` | The contact has duplicate emails. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_PHONE` | A contact has duplicate phones. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS` | A contact has duplicate addresses. |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_DEFAULT_ADDRESSES` | The contact has more than one address marked as default. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS_ID` | A contact has multiple addresses with the same ID. |
    | `400` | `INVALID_ARGUMENT` | `EMAIL_REQUIRED` | A contact has additional emails but no email. |
    | `400` | `INVALID_ARGUMENT` | `PHONE_REQUIRED` | A contact has additional phones but no phone. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TIME_ZONE` | The contact time zone is not in valid IANA format. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_IMAGE_URL` | The contact image URL is invalid. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_CHANGE_EXTERNAL_ID` | The contact's external ID can't be changed. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_MEMBER_EMAIL` | A contact that is a site member can't have its email updated. Update the site member's login email through the Members API instead. |
    | `403` | `PERMISSION_DENIED` | `UNAUTHORIZED_UPDATE_MEMBER` | Updating a site member's contact isn't allowed. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_MEMBER` | A contact that is a site member can't be updated unless `updateMember` is set to `true` in the request. |
