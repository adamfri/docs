    Retrieves a function type.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/functions/v1/types/{appDefId}/{functionTypeId}
    ```

    ## Path Params

    <ParamField path="functionTypeId" type="string" required>

      Function type ID.

    </ParamField>

    <ParamField path="appDefId" type="string" required>

      ID of the Wix app that defines the function type.

    </ParamField>

    ## Response Object

    <ResponseField name="functionType" type="FunctionType">

      Retrieved function type.

      See the [Function Type Object](/api-reference/business-management/functions/function-types/function-type-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
