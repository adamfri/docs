Triggered when one or more of an order's fulfillments are created, updated, or deleted.

The response contains the order's ID and details about all of its fulfillments following the change.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.ecom.v1.fulfillments_updated` |
| Package | `@wix/ecom` |
| Permissions | `Manage Stores - all permissions`, `Manage Stores`, `Read eCommerce - all read permissions`, `Read Orders`, `Read Stores - all read permissions`, `Manage Restaurants - all permissions`, `Manage eCommerce - all permissions`, `Manage Orders` |
