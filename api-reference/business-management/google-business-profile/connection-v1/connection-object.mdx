A site's Google Business Profile connection.

Carries no Google identity. Wix stores the site owner's Google credentials
server-side and never returns them, and the connection record itself holds no
personal data.

<Tabs>

  <Tab title="REST">

    <ResponseField name="createdDate" type="datetime">

      Date and time the Google account was connected.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the connection was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "connection": {
          "createdDate": "2026-05-12T09:14:27.511Z",
          "updatedDate": "2026-05-12T09:14:27.511Z"
        }
      }
      ```

    </CodeGroup>
