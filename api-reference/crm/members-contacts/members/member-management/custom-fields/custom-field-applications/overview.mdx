A custom field application defines which members or entities a custom field applies to.
By default, custom fields apply to all members. However, custom field applications allow you to target
specific members, roles, badges, or pricing plans, or exclude certain entities.

## SDK package

```bash
npm install @wix/members
```

Import the `customFieldApplications` namespace from `@wix/members`.
