@package_metadata:@wix/automations

To use the CustomTrigger API, install the `@wix/automations` package.

#### Install the package

Follow the installation instructions for your development environment.

| Development environment | Installation method |
|--|--|
| Wix sites (editor or IDE) | Use the [package manager](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-in-the-editor). |
| Wix sites (local IDE) | Run `wix install @wix/automations` using the [Wix CLI](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-with-the-wix-cli).|
| Blocks apps | Use the same installation method as Wix sites. |
| CLI and self-hosted apps | Run `npm install @wix/automations` or `yarn add @wix/automations`. |
| Headless sites and apps | Run `npm install @wix/automations` or `yarn add @wix/automations`. |

#### Import the package

To import the package in your code:

```js
import { customTrigger } from '@wix/automations'
```
