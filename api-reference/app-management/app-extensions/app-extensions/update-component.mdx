    Updates a component.

    Each time the component is updated, `revision` increments by 1. The current `revision` must be specified when updating the component. This ensures you're working with the latest component and prevents unintended overwrites.

    Send only the fields you want to update. Updating a component creates a new version. You can't change the type of the component's `data`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/apps/v1/components/v1/components/{component.id}
    ```

    ## Path Params

    <ParamField path="component.id" type="string" required>

      Component ID.

    </ParamField>

    ## Body Params

    <ParamField body="component" type="Component" required>

      Component to update. May be partial.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="component" type="Component">

      Updated component.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
