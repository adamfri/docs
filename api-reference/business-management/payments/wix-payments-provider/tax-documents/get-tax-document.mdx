    Retrieves a tax document by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYMENTS.MANAGE-TAX-DOCUMENTS">Managing tax tax documents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/payments/platform/v1/tax-documents/{taxDocumentId}
    ```

    ## Path Params

    <ParamField path="taxDocumentId" type="string" required>

      ID of the tax document to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="taxDocument" type="TaxDocument">

      Retrieved tax document.

      See the [Tax Document Object](/api-reference/business-management/payments/wix-payments-provider/tax-documents/tax-document-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
