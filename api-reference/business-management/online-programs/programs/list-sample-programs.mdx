    Lists sample programs used as templates for creating new programs.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/online-programs/v3/programs/samples
    ```

    ## Response Object

    <ResponseField name="programs" type="LabeledProgram[]">

      Sample programs available as templates.

      Constraints: `maxItems 100`.

      <Expandable title="programs properties">

        <ResponseField name="program" type="Program">

          Sample program.

          See the [Program Object](/api-reference/business-management/online-programs/programs/program-object) for this object's fields.

        </ResponseField>

        <ResponseField name="label" type="string">

          Display label for the sample program.

          Constraints: `maxLength 1000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
