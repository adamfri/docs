    Retrieves a list of orders, given the provided paging, filtering, and sorting.

    Search Orders runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order.
    - `cursorPaging.limit` is `100`.

    <Note>

    + By default, Search Orders doesn't return orders with `status: "PENDING"` or `status: "REJECTED"`. To retrieve them, filter for the relevant status explicitly. For example, `{"filter": {"status": "PENDING"}}`.
    + Search Orders never returns orders with `status: "INITIALIZED"`, regardless of the filter applied. To retrieve an order with `status: "INITIALIZED"`, use [Get Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/get-order).

    </Note>

    To learn how to query or search orders, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language).
