    Retrieves pricing breakdown for a product from the marketplace provider.

    Wix calls this method when a site owner views pricing details in the Suppliers Hub Marketplace. Wix calls it only when your implementation enables it by setting `toggleGetPricingBreakdownEnabled` to `true` in `MarketplaceProviderConfig`.

    Wix uses the response to display a pricing breakdown including base cost, suggested retail price, potential profit, and markup rate.

    ## Endpoint

    ```http
    POST /v2/get-pricing-breakdown
    ```

    ## Body Params

    <ParamField body="providerProductId" type="string">

      Product ID on the provider's platform.

      Constraints: `minLength 1`, `maxLength 36`.

    </ParamField>

    <ParamField body="currency" type="string">

      Currency for the pricing breakdown.

      Constraints: `format CURRENCY`.

    </ParamField>

    ## Response Object

    <ResponseField name="pricingBreakdown" type="PricingBreakdown">

      Pricing breakdown for the product.

      <Expandable title="pricingBreakdown properties">

        <ResponseField name="baseCostRange" type="PriceRange">

          Range of the base cost across all variants. This is the base cost charged by the provider.

          <Expandable title="baseCostRange properties">

            <ResponseField name="from" type="string">

              Lower bound of the price range.

              Constraints: `>= 0`, `<= 999999999`.

            </ResponseField>

            <ResponseField name="to" type="string">

              Upper bound of the price range. Absent when all variants have the same price.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="suggestedRetailPriceRange" type="PriceRange">

          Range of the suggested retail price across all variants. Calculated as cost multiplied by the markup rate.

          <Expandable title="suggestedRetailPriceRange properties">

            <ResponseField name="from" type="string">

              Lower bound of the price range.

              Constraints: `>= 0`, `<= 999999999`.

            </ResponseField>

            <ResponseField name="to" type="string">

              Upper bound of the price range. Absent when all variants have the same price.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="potentialProfitRange" type="PriceRange">

          Range of the potential profit across all variants. Calculated as the suggested retail price minus the base cost.

          <Expandable title="potentialProfitRange properties">

            <ResponseField name="from" type="string">

              Lower bound of the price range.

              Constraints: `>= 0`, `<= 999999999`.

            </ResponseField>

            <ResponseField name="to" type="string">

              Upper bound of the price range. Absent when all variants have the same price.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="markupRate" type="string">

          Markup rate applied to the base cost to calculate the suggested retail price. For example, `0.60` for a 60% markup, or `2.5` for a 250% markup.

        </ResponseField>

        <ResponseField name="currency" type="string">

          Currency of the monetary values.

          Constraints: `format CURRENCY`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
