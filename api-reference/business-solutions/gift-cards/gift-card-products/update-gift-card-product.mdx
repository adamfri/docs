    Updates a gift card product.

    Each time the gift card product is updated, `revision` increments by 1. The current `revision` must be passed when updating the gift card product. This ensures you're working with the latest gift card product and prevents unintended overwrites.

    When updating `presetVariants`, the entire list is replaced. To add, remove, or modify a single variant, include the full updated list.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/gift-cards/v1/gift-card-products/{giftCardProduct.id}
    ```

    ## Path Params

    <ParamField path="giftCardProduct.id" type="string" required>

      Gift card product ID.

    </ParamField>

    ## Body Params

    <ParamField body="giftCardProduct" type="GiftCardProduct" required>

      Gift card product to update.

      See the [Gift Card Product Object](/api-reference/business-solutions/gift-cards/gift-card-products/gift-card-product-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="giftCardProduct" type="GiftCardProduct">

      Updated gift card product.

      See the [Gift Card Product Object](/api-reference/business-solutions/gift-cards/gift-card-products/gift-card-product-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_GIFT_CARD_PRODUCT_TO_HAVE_NO_VARIANTS` | The gift card product must have at least one preset variant or a custom variant. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_GIFT_CARD_PRODUCT_TO_HAVE_PAST_EXPIRATION_DATE` | The `fixedExpirationDate` can't be in the past. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_GIFT_CARD_PRODUCT_WITH_INVALID_CUSTOM_AMOUNTS_RANGE` | The custom variant's `minValue` must be less than `maxValue`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
