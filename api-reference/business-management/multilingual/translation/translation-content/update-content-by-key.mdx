    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a translation content item using a unique key, which is a combination of `content.schemaId`, `content.entityId`, and `content.locale`.

    To remove a field, pass the field key with an empty object as the value. For example:

    ```json
    {
    "fields": {
    "title": {}
    }
    }
    ```

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_CONTENT">Wix Multilingual - Write Translation Content</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/translation-content/v1/contents/by-key
    ```

    ## Body Params

    <ParamField body="content" type="Content" required>

      Content to update.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ParamField>

    <ParamField body="forceFieldsTimestampUpdate" type="boolean">

      If true each field updated in fields map will also update the timestamp fields

      even if the field value is not changed, otherwise the timestamp fields will be updated only if the field value has changed

    </ParamField>

    ## Response Object

    <ResponseField name="content" type="Content">

      Updated Content.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Content Updated | `wix.multilingual.translation.v1.content_updated` | Triggered when translation content is updated. |

    </div>
