    Retrieves a group's rules.

    <Note>

    This endpoint requires [visitor or member authentication](https://dev.wix.com/docs/rest/articles/getting-started/access-types-and-permissions).

    </Note>

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-groups/v2/rules/{groupId}
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Response Object

    <ResponseField name="rules" type="GroupRule[]">

      Retrieved rules.

      Constraints: `maxItems 100`.

      <Expandable title="rules properties">

        <ResponseField name="title" type="string">

          Rule title.

        </ResponseField>

        <ResponseField name="description" type="string">

          Rule description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
