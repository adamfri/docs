<Tabs>

  <Tab title="REST">

    Retrieves the number of reviews that match a specified filter.

    If a filter isn't passed in the request, the method returns the count of all reviews.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.READ-REVIEWS">Read reviews</span>
    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v1/reviews/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object in the following format:
      `"filter" : {`
      "fieldName1": "value1",
      "fieldName2":&#123;"$operator":"value2"&#125;
      &#125;``

      See [Query Reviews](https://dev.wix.com/docs/rest/crm/community/reviews/reviews/query-reviews) for a list of supported filters.

    </ParamField>

    <ParamField body="includePrivateReviews" type="boolean">

      Whether to include unpublished reviews in the count.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of reviews.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_TO_COUNT` | Attempt to count the reviews timed out. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

  </Tab>
