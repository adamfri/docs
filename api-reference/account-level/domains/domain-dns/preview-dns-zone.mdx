<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Generates a preview for a DNS zone based on
    [Google's Cloud DNS](https://cloud.google.com/dns).

    This includes calculating the `A`, `CNAME`, `NS` and `SOA` records.
    You can use this information to configure a domain from an external
    provider, before connecting it to a Wix site.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.READ_DNS_ZONES">DOMAINS.READ_DNS_ZONES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/domains/v1/dns-zones/{domainName}/preview
    ```

    ## Path Params

    <ParamField path="domainName" type="string" required>

      Domain name to generate a DNS zone preview for.

    </ParamField>

    ## Response Object

    <ResponseField name="dnsZone" type="DnsZone">

      DNS zone preview.

      Includes calculated `A`, `CNAME`, `NS` and `SOA` records.

      See the [Dns Zone Object](/api-reference/account-level/domains/domain-dns/dns-zone-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X GET 
      'https://www.wixapis.com/domains/v1/dns-zones/mysite.com/preview' \
      -H 'wix-account-id: <ACCOUNT_ID>' \
      -H 'Authorization: <AUTH>' \
      ```

      ```json Response
      {
        "dnsZone": {
          "records": [
            {
              "values": [

              ],
              "ttl": 3600,
              "hostName": "mysite.com",
              "type": "MX"
            }
          ],
          "domainName": "mysite.com"
        }
      }
      ```

    </CodeGroup>
