    Updates a modifier group.

    Each time a modifier group is updated, its revision increments by 1. The existing revision must be included when updating the modifier group. This ensures you're working with the latest modifier group information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/restaurants/menus/v1/modifier-groups/{modifierGroup.id}
    ```

    ## Path Params

    <ParamField path="modifierGroup.id" type="string" required>

      Modifier group ID.

    </ParamField>

    ## Body Params

    <ParamField body="modifierGroup" type="ModifierGroup" required>

      Modifier group to update.

      See the [Item Modifier Group Object](/api-reference/business-solutions/restaurants/menus/items/item-modifier-groups/item-modifier-group-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="modifierGroup" type="ModifierGroup">

      Updated modifier group.

      See the [Item Modifier Group Object](/api-reference/business-solutions/restaurants/menus/items/item-modifier-groups/item-modifier-group-object) for this object's fields.
