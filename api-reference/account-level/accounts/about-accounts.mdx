<Note>This article applies to the REST API only.</Note>

The Wix Accounts API enables you to create Wix accounts.

An account is a collection of Wix assets, such as: sites, domains, and premium plans., etc, Note that Wix assets belong to accounts and not to users. 
Accounts are managed by one or more Wix registered users, referred to as team members.

Accounts allow companies to:
- Manage teams.  
- Assign relevant roles and permissions of each team member within the account.  
- Create and manage Wix assets for second-party customers.  

When an account owner creates a new account using the Accounts API, the new account is considered a **child account** of the creating account, referred to as the **parent account**. For example, a website reseller might create a child account when funnelling customers directly into Wix’s site creation flow, to build a site for themselves, while retaining a relationship to the reseller's account.

## Before you begin
- The Accounts API is only open to companies with a signed contract with Wix.

## Terminology
- **Account**: A collection of Wix assets, such as sites, domains, and premium plans, managed by one or more Wix users.
  - **Parent account**: An account that has created child accounts. Depending on the company's specific needs, they may retain management access to the child accounts' assets.
  - **Child account**: An account that was created by another account.  
- **Role**: A defined type of access that a user has on a specific site or account. Wix provides several predefined roles, such as co-owner, website manager, and website designer. Account owners and co-owners can also define custom roles.  
- **Team member**: A Wix user that has been added to an account, with access to one or more sites and other assets. A single Wix user can be a team member in multiple accounts.
- **User**: A logged in user on *.wix.com.
