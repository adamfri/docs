    Retrieves an account's certifications for public display, given the account ID.

    This is a public, visitor-safe projection that returns only each certification's type and
    creation date. To retrieve the full account certification records, including the underlying
    `userCertificationIds`, call [Query Account Certifications](https://dev.wix.com/docs/api-reference/account-level/studio-workspace/certifications/account-certification-v1/query-account-certifications) instead.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/academy/certifications/v1/account-certifications/by-account/{accountId}
    ```

    ## Path Params

    <ParamField path="accountId" type="string" required>

      ID of the account to get certifications for.

    </ParamField>

    ## Response Object

    <ResponseField name="certifications" type="Certification[]">

      The account's certifications, as a public, visitor-safe projection.

      <Expandable title="certifications properties">

        <ResponseField name="certificationType" type="string">

          Type of certification the account holds.

          **Supported values:**

          - `VELO` — Velo certification: proficiency in building with Velo, Wix's full-stack development platform.
          - `WEB_DESIGNER` — Web Designer certification: proficiency in designing and building Wix websites.
          - `ACCESSIBILITY` — Accessibility certification: proficiency in building accessible Wix websites.
          - `STUDIO_DEVELOPER` — Wix Studio Developer certification: proficiency in developing with Wix Studio.
          - `STUDIO_DESIGN_LEAGUE` — Wix Studio Design League certification, awarded through the Wix Studio Design League program.
          - `STUDIO_DEV_WEBSITES_LEAGUE` — Wix Studio Developer Websites League certification, awarded through the Wix Studio Developer Websites League program.

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the account certification was created.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
