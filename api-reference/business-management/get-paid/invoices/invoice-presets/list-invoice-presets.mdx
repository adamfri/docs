    Lists invoice presets.

    Returns all presets for the site, sorted by last updated date (most recent first), with the default preset always listed first. The number of presets per site is limited, so paging isn't required.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/invoices/v4/invoice-presets
    ```

    ## Response Object

    <ResponseField name="invoicePresets" type="InvoicePreset[]">

      List of invoice presets.

      See the [Invoice Preset Object](/api-reference/business-management/get-paid/invoices/invoice-presets/invoice-preset-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
