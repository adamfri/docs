    <div className="wix-ref">

    Sends a payment link to up to 50 specified recipients.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYLINKS.MANAGE">Manage Paylinks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/paymentlinks/v1/payment-links/{paymentLinkId}/send
    ```

    ## Path Params

    <ParamField path="paymentLinkId" type="string" required>

      Payment link ID.

    </ParamField>

    ## Body Params

    <ParamField body="recipients" type="Recipient[]">

      Recipients who will receive the payment link.

      Constraints: `maxItems 50`.

      <Expandable title="recipients properties">

        <ParamField body="contactId" type="string">

          Recipient contact ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="lastSendDate" type="datetime">

          Date of last attempt to send payment link to the recipient.

          **Read-only.**

        </ParamField>

        <ParamField body="sendSuccessful" type="boolean">

          Status of the last attempt to send payment link to the recipient.

          **Read-only.**

        </ParamField>

        <ParamField body="sendMethods" type="string[]">

          Methods that should be used to send the payment link to the recipient.

          Constraints: `maxItems 1`.

          **Supported values:**

          - `EMAIL_METHOD` — Email method.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="statuses" type="RecipientSendStatus[]">

      Statuses of payment links sent.

      <Expandable title="statuses properties">

        <ResponseField name="contactId" type="string">

          Recipient contact ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="successSendMethods" type="string[]">

          Methods through which the payment link was sent successfully.

          **Supported values:**

          - `EMAIL_METHOD` — Email method.

        </ResponseField>

        <ResponseField name="failedSendMethods" type="string[]">

          Methods in which errors occurred.

          **Supported values:**

          - `EMAIL_METHOD` — Email method.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="sendMetadata" type="SendMetadata">

      Send metadata.

      <Expandable title="sendMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of recipients where send was successful.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of recipients in which sending failed.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NO_EMAIL_FOR_RECIPIENT` | Recipient's contact has no associated email. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_ACCEPT_PAYMENTS` | Site isn't set up to accept payments. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_RECIPIENT_SEND_METHOD` | Missing recipient's send method. |
    | `400` | `INVALID_ARGUMENT` | `RECIPIENT_NOT_FOUND` | Recipient's contact not found. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_RECIPIENT_SEND_METHOD` | Invalid send method specified. |
    | `400` | `INVALID_ARGUMENT` | `TOO_MANY_RECIPIENTS` | Too many recipients specified. Limit: 50. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Payment Link Updated | `wix.paymentlinks.v1.payment_link_updated` | Triggered when a payment link is updated. |
    | Payment Link Sent | `wix.paymentlinks.v1.payment_link_payment_link_sent` | Triggered when a payment link is sent. |
