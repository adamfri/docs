    Updates a coupon.

    Only the properties passed in the `specification` object will be updated. All other properties will remain the same.

    To remove a value from the coupon, pass its corresponding property with a value of `null`.

    When updating a coupon, you cannot change the coupon's `type`. For example, if the coupon's `type` is `moneyOffAmount`,
    you cannot change it to `fixedPriceAmount`. You can update the coupon type's value. For example, you can change the
    value of `moneyOffAmount` from `5` to `10`.

    The coupon `scope` defines the items a coupon applies to. A coupon can apply to all items in a specific Wix application,
    a group within the application, or a single item within a group.
    See [valid scope values](https://dev.wix.com/api/rest/coupons/coupons/valid-scope-values).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-COUPONS.MANAGE-COUPONS">Manage Coupons</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v2/coupons/{id}
    ```

      ID of the coupon to update.

    </ParamField>

        <ParamField body="paths" type="string[]" />

      </Expandable>

    <ParamField body="specification" type="Specification">

      Coupon information to update.

      <Expandable title="specification properties">

        <ParamField body="name" type="string">

          Name of coupon.

        </ParamField>

        <ParamField body="code" type="string">

          Coupon code. Must be unique for all coupons on your site.

          Max: 20 characters

        </ParamField>

        <ParamField body="startTime" type="integer">

          Coupon valid from this date and time, in milliseconds.
          For example, `"1554066000000"`.

        </ParamField>

        <ParamField body="expirationTime" type="integer">

          Coupon expires at this date and time, in milliseconds.
          For example, `"1554325199999"`.

        </ParamField>

        <ParamField body="usageLimit" type="integer">

          Maximum number of times the coupon can be used.

          >**Note:** Multiple purchases by the same customer or purchases by different customers are both counted toward `usageLimit`.

        </ParamField>

        <ParamField body="limitPerCustomer" type="integer">

          Maximum number of times the coupon can be used per customer.

        </ParamField>

        <ParamField body="limitedToOneItem" type="boolean">

          Whether the coupon is limited to one item.

          If `true` and a customer pays for multiple items, the discount applies to only the lowest priced item.
          Coupons with a `bookings` `scope.namespace` are always limited to one item.

        </ParamField>

        <ParamField body="appliesToSubscriptions" type="boolean">

          Whether the coupon applies to subscription products.

        </ParamField>

        <ParamField body="discountedCycleCount" type="integer">

          Specifies the amount of discounted cycles for a subscription item.

          + Can only be set when `scope.namespace = pricingPlans`.
          + If `discountedCycleCount` is empty, the coupon applies to all available cycles.
          + `discountedCycleCount` is ignored if `appliesToSubscriptions = true`.

          Max: `999`

        </ParamField>

        <ParamField body="active" type="boolean">

          Whether the coupon is currently [active](https://support.wix.com/en/article/wix-stores-activating-and-deactivating-coupons).

          Default: `true`

        </ParamField>

        <ParamField body="type" type="string">

          Coupon type. Read-only.

        </ParamField>

        <ParamField body="tags" type="string[]">

          Tags for categorizing the coupon.

          Constraints: `maxLength 255`, `maxItems 100`.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="ScopeOrMinSubtotal" type="ScopeOrMinSubtotal">

          ScopeOrMinSubtotal

          <Expandable title="ScopeOrMinSubtotal properties">

            <ParamField body="scope" type="Scope">

              Specifies the type of line items this coupon will apply to. See [valid scope values](https://dev.wix.com/api/rest/coupons/coupons/valid-scope-values).

              _Nested structure omitted for brevity — see the `Scope` object._

            </ParamField>

            <ParamField body="minimumSubtotal" type="number">

              Limit the coupon to carts with a subtotal above this number.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="Behavior" type="Behavior">

          Behavior

          <Expandable title="Behavior properties">

            <ParamField body="moneyOffAmount" type="number">

              Discount as a fixed amount.

            </ParamField>

            <ParamField body="percentOffRate" type="number">

              Discount as a percentage.

            </ParamField>

            <ParamField body="freeShipping" type="boolean">

              Free shipping.

              If `true`, the coupon applies to all items in all `namespaces`.

            </ParamField>

            <ParamField body="fixedPriceAmount" type="number">

              Fixed sale price.

            </ParamField>

            <ParamField body="buyXGetY" type="BuyXGetY">

              Receive free products when making a purchase.

              For example, purchase `x` number of products and receive `y` number of products for free.

              _Nested structure omitted for brevity — see the `BuyXGetY` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
