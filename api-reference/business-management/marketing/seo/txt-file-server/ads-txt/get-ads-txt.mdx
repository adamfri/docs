    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.MANAGE-ADS-TXT">Manage Ads.txt</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote-seo-robots-server/v2/ads
    ```

    ## Query Params

    <ParamField query="subdomain" type="string">

      Subdomain of Ads.txt, for example `www`, `es`, `fr`. Default is `www`.

    </ParamField>

    ## Response Object

    <ResponseField name="adsTxt" type="AdsTxt">

      Ads txt object

      See the [Ads Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/ads-txt/ads-txt-object) for this object's fields.

    </ResponseField>
