Triggered when a folder is created.

This event is also triggered when a folder is restored from the Media Manager's trash bin.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.media.site_media.v1.folder_created` |
| Package | `@wix/media` |
| Permissions | `Manage Bookings Services and Settings`, `Manage Events`, `Manage Challenges`, `Read Media Manager`, `Manage Media Manager`, `Manage Portfolio`, `Access Verticals by Automations`, `Manage Restaurants - all permissions`, `Set Up Automations`, `Picasso private app mega scope` |

## Examples

<CodeGroup>

  ```javascript onFolderCreated
  import { folders } from '@wix/media';

  folders.onFolderCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onFolderCreated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { folders } from '@wix/media';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        folders,
      },
  });

  wixClient.folders.onFolderCreated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
