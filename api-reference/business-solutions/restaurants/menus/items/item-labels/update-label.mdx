    Updates an item Label.

    Each time an item label is updated, its revision increments by 1. The existing revision must be included when updating the item labels. This ensures you're working with the latest item labels information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/restaurants/menus/v1/labels/{label.id}
    ```

    ## Path Params

    <ParamField path="label.id" type="string" required>

      Item label ID.

    </ParamField>

    ## Body Params

    <ParamField body="label" type="Label" required>

      Item label to update.

      See the [Item Label Object](/api-reference/business-solutions/restaurants/menus/items/item-labels/item-label-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="label" type="Label">

      Updated item label.

      See the [Item Label Object](/api-reference/business-solutions/restaurants/menus/items/item-labels/item-label-object) for this object's fields.
