    Updates the quantity of 1 or more line items in the current site visitor's cart.

    This method is only for updating the quantity of line items.
    To entirely remove a line item from the current cart, use the Remove Line Items From Current Cart method.
    To add a new line item to the current cart, use the Add To Current Cart method.

    This method checks the amount of stock remaining for this line item.
    If the specified `quantity` is greater than the remaining stock,
    then the `quantity` returned in the response is the total amount of remaining stock.

    <Note>

    + This method requires [visitor or member authentication](https://dev.wix.com/docs/rest/articles/getting-started/access-types-and-permissions).
    + After a cart is updated, call [Refresh Cart](https://dev.wix.com/docs/sdk/frontend-modules/ecom/refresh-cart) to update the cart's UI elements and trigger the Cart Updated event.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/carts/current/update-line-items-quantity
    ```

    ## Body Params

    <ParamField body="lineItems" type="LineItemQuantityUpdate[]" required>

      Line item IDs and their new quantity.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="lineItems properties">

        <ParamField body="id" type="string">

          *Required.** Line item ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="quantity" type="integer">

          *Required.** New quantity. Number must be 1 or higher.

          Constraints: `min 1`, `max 100000`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
