<Note>This article applies to the REST API only.</Note>

The Coupons API allows you to create loyalty coupons when a customer [redeems their loyalty points](https://dev.wix.com/docs/rest/crm/loyalty-program/coupons/redeem-points-for-coupon) for loyalty rewards.

With the Coupons API, you can:

+ Redeem points for coupons.
+ Redeem points for coupons for the current member.
+ Retrieve information about existing loyalty coupons.
+ Bulk retrieve loyalty coupons.
+ Get coupons for the current member.
+ Query loyalty coupons.
+ Delete loyalty coupons.

## Before you begin

It's important to note the following points before starting to code:
+ The site must have the [Wix Loyalty Program](fallback::https://www.wix.com/app-market/loyalty) installed.

## Use cases

- [Redeem loyalty points for coupons](fallback::https://dev.wix.com/docs/api-reference/crm/loyalty-program/rewards/coupons/sample-use-cases-and-flows)

## Terminology

- **Loyalty coupon:** A specific loyalty object that holds the specifications used to create a reference [coupon](https://dev.wix.com/docs/rest/business-management/marketing/coupons/about-wix-coupons).
- **Reference coupon:** The actual [coupon](https://dev.wix.com/docs/rest/business-management/marketing/coupons/about-wix-coupons) that is created when loyalty points are redeemed for a loyalty reward. The customer receives the reference coupon, which they can apply to their order.
