    Records a custom activity for a contact with a free-text message.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/contacts-activity-log/v1/activities/custom
    ```

    ## Body Params

    <ParamField body="activityDate" type="datetime" required>

      Date and time the activity occurred.

    </ParamField>

    <ParamField body="contactId" type="string" required>

      ID of the contact to record the activity for.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="message" type="string" required>

      Free-text description of the activity.

      Constraints: `maxLength 2000`.

    </ParamField>

    ## Response Object

    <ResponseField name="activity" type="Activity">

      Created activity.

      See the [Activity Object](/api-reference/crm/members-contacts/contacts/activity-log/activity-v1/activity-object) for this object's fields.

    </ResponseField>

    ## Examples

    Record a free-text activity for a contact. The `message` field in the response is empty; the text is stored in `params.MessageContent` and populated into `message` when the activity is retrieved via List Activities.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/crm/contacts-activity-log/v1/activities/custom' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "activityDate": "2024-06-15T14:00:00.000Z",
        "contactId": "7867990e-45f0-47ee-bb7b-f01960bdda2f",
        "message": "Spoke with John about his upcoming renewal. He confirmed he wants to stay on the premium plan."
      }'
      ```

      ```json Response
      {
        "activity": {
          "id": "1718460000000/1e98a239-6d3c-4934-890f-36f2dcfd36a4",
          "activityDate": "2024-06-15T14:00:00Z",
          "contactId": "7867990e-45f0-47ee-bb7b-f01960bdda2f",
          "message": "",
          "templateId": "e1c5a6ad-c926-450b-99e0-49057d7e46f4",
          "params": {
            "MessageContent": "Spoke with John about his upcoming renewal. He confirmed he wants to stay on the premium plan."
          }
        }
      }
      ```

    </CodeGroup>
