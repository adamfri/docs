    Retrieves the default marketing settings applied when a site hasn't configured its own preferences.
    Use `field_mask` on the request to limit which defaults are returned. Accepted values are:
    `socialChannels`, `calendar`, `marketingPlanGoal`, and `frequency`. Any other value returns an error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-settings/defaults
    ```

    ## Query Params

    <ParamField query="fieldMask" type="string[]">

      Dot-notation field paths to limit which defaults are returned. Omit to return all defaults.
      Accepted values: `socialChannels`, `calendar`, `marketingPlanGoal`, `frequency`.
      Any other value returns an error.

      Constraints: `maxLength 100`, `maxItems 50`.

    </ParamField>

    ## Response Object

      The default settings applied when a site hasn't configured its own preferences.

      <Expandable title="defaults properties">

        <ResponseField name="socialChannels" type="string[]">

          Constraints: `minItems 0`, `maxItems 10`.

          **Supported values:**

          - `FACEBOOK` — Facebook.

          - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
          - `PINTEREST` — Pinterest.
          - `GBP` — Google Business Profile.
          - `TIKTOK` — TikTok.

        </ResponseField>

        <ResponseField name="calendar" type="Calendar">

          Default calendars whose events are considered when planning activities.

              IDs of the selected calendar options.

              Constraints: `format GUID`, `minItems 0`, `maxItems 20`.

            </ResponseField>

          </Expandable>

        </ResponseField>

    ## Examples

    Retrieve recommended default values for marketing settings. The optional fieldMask accepts only these values - socialChannels, calendar, marketingPlanGoal, frequency. Here it requests socialChannels and frequency.

    <CodeGroup>

      ```bash Request
      curl -X GET \
      'https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-settings/defaults?fieldMask=socialChannels&fieldMask=frequency' \
      -H 'Authorization: <AUTH>'
      ```

      ```json Response
      {
        "defaults": {
          "socialChannels": [
            "INSTAGRAM",
            "FACEBOOK"
          ],
          "frequency": {
            "socialMarketing": {
              "interval": "WEEK",
              "count": 3
            },
            "blog": {
              "interval": "WEEK",
              "count": 1
            },
            "emailMarketing": {
              "interval": "MONTH",
              "count": 2
            }
          }
        }
      }
      ```
