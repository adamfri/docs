    Creates a tax group.

    Call Stores Update Product to add the `taxGroupId` to specific products to categorize as a group based on distinct tax treatment.
    Wix uses tax groups to calculate tax.

    In addition to tax groups you create, default tax groups are already included in all Wix catalogs.
    Call List Default Tax Groups to retrieve them. You can also use the Tax Groups Integration service plugin (REST only)
    to create new default tax groups that can be applied directly to an entire catalog of products.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/tax-groups
    ```

    ## Body Params

    <ParamField body="taxGroup" type="TaxGroup" required>

      Tax group to create.

      See the [Tax Group Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-groups/tax-group-object) for this object's fields.

    </ParamField>

    <ResponseField name="taxGroup" type="TaxGroup">

    </ResponseField>
