    <div className="wix-ref">

    Retrieves the settings for the tiers program. Tiers program settings apply globally to all tiers in the program.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-tiers/v1/tiers/program-settings
    ```

    ## Response Object

    <ResponseField name="programSettings" type="TiersProgramSettings">

      Tiers program settings.

      <Expandable title="programSettings properties">

        <ResponseField name="status" type="string">

          Tiers program status.

          **Supported values:**

          - `DISABLED` — Tiers are disabled.
          - `DRAFT` — Tiers are enabled but not yet active.
          - `ACTIVE` — Tiers are active.
          - `PAUSED` — Tiers are paused.

        </ResponseField>

        <ResponseField name="revision" type="integer">

          Revision number, which increments by 1 each time the loyalty tiers settings are updated.

          To prevent conflicting changes, the current `revision` must be passed when updating the loyalty tiers settings.

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the loyalty tiers program was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the loyalty tiers program was last updated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="baseTierDefinition" type="TierDefinition">

          Information about the base loyalty tier.

          The base tier is the default tier for any account that's unassigned for not meeting
          the required points threshold of any other tier.

          <Expandable title="baseTierDefinition properties">

            <ResponseField name="icon" type="Image">

              Details about the tier icon.

              _Nested structure omitted for brevity — see the `Image` object._

            </ResponseField>

            <ResponseField name="name" type="string">

              Tier name.

            </ResponseField>

            <ResponseField name="description" type="string">

              Tier description.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="period" type="period">

          period

          <Expandable title="period properties">

            <ResponseField name="rollingWindow" type="RollingWindow">

              **Required.**
              Period of time used to calculate loyalty points for tier assignment.

              The loyalty points accumulated during this period determine if the account meets a tier's required point threshold.

              _Nested structure omitted for brevity — see the `RollingWindow` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
