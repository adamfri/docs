    Retrieves a reservation.

    You can only retrieve the `FULL` fieldset if the [identity](https://dev.wix.com/docs/build-apps/develop-your-app/access/about-identities) you're authenticated as has the `MANAGE RESERVATIONS (MEDIUM)` or `MANAGE RESERVATIONS (FULL)` permission scopes.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-BASIC">Manage Reservations (Basic)</span>
    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-MEDIUM">Manage Reservations (Medium)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/table-reservations/reservations/v1/reservations/{reservationId}
    ```

    ## Path Params

    <ParamField path="reservationId" type="string" required>

      Reservation ID.

    </ParamField>

    ## Query Params

    <ParamField query="fieldSet" type="string" deprecated>

      **Deprecated.** Predefined sets of fields to return.
