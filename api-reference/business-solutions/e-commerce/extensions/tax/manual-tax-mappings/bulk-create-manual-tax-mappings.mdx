    <div className="wix-ref">

    Creates up to 100 manual tax mappings in a single request.

    Use this method when you need to set up tax mappings for multiple tax group and region combinations at once,
    such as when initially configuring tax rates for a new business or importing mappings from an external system.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/bulk/manual-tax-mappings/create
    ```

    ## Body Params

    <ParamField body="manualTaxMappings" type="ManualTaxMapping[]" required>

      Manual tax mappings to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created manual tax mapping entities in the response.

      Default: `false`

    </ParamField>
