A group object represents a community space where site members can connect and share content.
You can create groups and manage their visibility, settings, and metadata.
Learn more about [groups](https://support.wix.com/en/article/wix-groups-about-groups).

## SDK package

```bash
npm install @wix/groups
```

Import the `groups` namespace from `@wix/groups`.
