    Updates multiple info sections.

    Each time an info section is updated, `revision` increments by 1.
    The current `revision` must be passed when updating an info section.
    This ensures you're working with the latest info section and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INFO_SECTION_WRITE">Info section write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/info-sections/update
    ```

    ## Body Params

    <ParamField body="infoSections" type="MaskedInfoSection[]" required>

      List of info sections to update.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="infoSections properties">

        <ParamField body="infoSection" type="InfoSection">

          Info section to update.

          See the [Info Section Object](/api-reference/business-solutions/stores/catalog-v3/info-sections-v3/info-section-object) for this object's fields.

        </ParamField>

        <ParamField body="fieldMask" type="FieldMask">

          Explicit list of fields to update.

          <Expandable title="fieldMask properties">

            <ParamField body="paths" type="string[]" />

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full updated info sections entities in the response.

      Default: `false`

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT`

    </ParamField>
