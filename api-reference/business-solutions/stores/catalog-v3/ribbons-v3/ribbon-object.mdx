A Ribbon is a visual element that you can assign to products to highlight them on your site.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Ribbon ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the ribbon is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the ribbon.

      Ignored when creating a ribbon.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the ribbon was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the ribbon was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Ribbon name.

      Constraints: `minLength 1`, `maxLength 30`.

    </ResponseField>

    <ResponseField name="assignedProductCount" type="integer">

      Number of products this ribbon is assigned to. Includes both primary and additional ribbons.

      > **Note:** Returned only when you pass `"ASSIGNED_PRODUCT_COUNT"` to the `fields` array in Ribbon API requests.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "ribbon": {
          "id": "2254c3b3-6bbd-457d-b868-9122657c5d1c",
          "revision": "1",
          "createdDate": "2024-06-26T08:34:04.787Z",
          "updatedDate": "2024-06-26T08:34:04.787Z",
          "name": "New Arrival!",
          "assignedProductCount": 3
        }
      }
      ```

    </CodeGroup>
