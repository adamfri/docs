    Updates an address on a contact.

    Each time the contact is updated, `revision` increments by 1. The current `revision` must be passed. This ensures you're working with the latest contact and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/contacts/v5/contacts/{contactId}/addresses/{address.id}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to update the address on.

    </ParamField>

    <ParamField path="address.id" type="string" required>

      Address ID.

    </ParamField>

    ## Body Params

    <ParamField body="address" type="ContactAddress" required>

      Address to update. Must include `address.id`.

      <Expandable title="address properties">

        <ParamField body="tag" type="string">

          Address type classification. Helps categorize the address purpose.

          Default: `OTHER`

          **Supported values:**

          - `OTHER`
          - `HOME`
          - `WORK`
          - `BILLING`
          - `SHIPPING`

        </ParamField>

        <ParamField body="address" type="Address">

          Physical address information including street, city, country, and postal code.
          Contains structured address data following common address formatting standards.

          <Expandable title="address properties">

            <ParamField body="country" type="string">

              2-letter country code in an
              [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format.

            </ParamField>

            <ParamField body="subdivision" type="string">

              Subdivision shorthand. Usually, a short code (2 or 3 letters) that represents a state, region, prefecture, or province. For example, `NY`.

            </ParamField>

            <ParamField body="city" type="string">

              City name.

            </ParamField>

            <ParamField body="postalCode" type="string">

              Postal or zip code.

            </ParamField>

            <ParamField body="addressLine2" type="string">

              Free text providing more detailed address information,
              such as apartment, suite, or floor.

            </ParamField>

            <ParamField body="formattedAddress" type="string">

              Human-readable address string.
              If not provided, the value is generated from the available address data.

            </ParamField>

            <ParamField body="hint" type="string">

              Instructions to help someone find the address, such as landmarks or where the entrance is.

            </ParamField>

            <ParamField body="geocode" type="AddressLocation">

              Coordinates of the physical address.

              _Nested structure omitted for brevity — see the `AddressLocation` object._

            </ParamField>

            <ParamField body="countryFullname" type="string">

              Full country name.

            </ParamField>

            <ParamField body="subdivisions" type="Subdivision[]">

              Hierarchical list of subdivisions, where the first array item is the highest level of hierarchy, and so on.

              Constraints: `maxItems 6`.

              _Nested structure omitted for brevity — see the `Subdivision[]` object._

            </ParamField>

            <ParamField body="subdivisionFullname" type="string">

              Subdivision full name.

            </ParamField>

          </Expandable>

          <Expandable title="One of the following">

            <ParamField body="street" type="street">

              street

              _Nested structure omitted for brevity — see the `street` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="defaultAddress" type="boolean">

          Whether this address is the contact's default address.
          Only one address can be designated as default per contact.
          If no address is explicitly set as default, the first address automatically becomes the default.

        </ParamField>

        <ParamField body="id" type="string" required>

          Address ID.

        </ParamField>

        <ParamField body="recipient" type="Recipient">

          Address recipient information for delivery purposes.

          <Expandable title="recipient properties">

            <ParamField body="firstName" type="string">

              Recipient's first name.

            </ParamField>

            <ParamField body="lastName" type="string">

              Recipient's last name.

            </ParamField>

            <ParamField body="company" type="string">

              Recipient's company name.

            </ParamField>

            <ParamField body="phone" type="string">

              Recipient's phone number.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="revision" type="integer" required>

      Contact revision number.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>
