Triggered when a custom embed is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.embeds.v1.custom_embed_updated` |
| Package | `@wix/embeds` |
| Permissions | `SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS`, `Manage Marketing Tags` |

## Examples

<CodeGroup>

  ```javascript onCustomEmbedUpdated
  import { customEmbeds } from '@wix/embeds';

  customEmbeds.onCustomEmbedUpdated((event) => {
      // handle your event here
  });
  ```
