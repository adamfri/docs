    <Note>

    The Form Submission API only works with the Wix Forms app. Call [GetAppInstance](https://dev.wix.com/docs/rest/api-reference/app-management/apps/app-instance/get-app-instance) to confirm that the app named `wix_forms` is installed on the site.

    <br />
    Creates a new submission. <br />
    For which keys `submissions` accepts and the value each field type submits, see [About Submission Values](https://dev.wix.com/docs/api-reference/crm/forms/form-submissions/about-submission-values).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORMS.MANAGE-SUBMISSIONS">Manage Submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/v4/submissions
    ```

    ## Body Params

    <ParamField body="submission" type="FormSubmission" required>

      Submission to create.

      See the [Submission Object](/api-reference/crm/forms/form-submissions/submission-object) for this object's fields.

    </ParamField>

    <ParamField body="captchaToken" type="string">

      Captcha token.

    </ParamField>

    <ParamField body="additionalMetadata" type="object">

      Optional metadata passed to SPI implementer, allowing clients to include additional business-specific data.

    </ParamField>

    ## Response Object

    <ResponseField name="submission" type="FormSubmission">

      The created submission.

      See the [Submission Object](/api-reference/crm/forms/form-submissions/submission-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVALID_CAPTCHA` | Captcha verification failed. |
    | `428` | `FAILED_PRECONDITION` | `SITE_IS_A_TEMPLATE` | Site is a template and can't accept form submissions. |
    | `404` | `NOT_FOUND` | `FORM_NOT_FOUND` | Couldn't find the form. |
    | `503` | `UNAVAILABLE` | `FORM_RETRIEVAL_ERROR` | Form retrieval failed due to a temporary service issue. |
    | `400` | `INVALID_ARGUMENT` | `SUBMISSION_VALIDATION` | Form submission contains validation errors. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Submission Created | `wix.forms.v4.submission_created` | > **Note:** The Form Submission API only works with the Wix Forms app. Call [GetAppInstance](https://dev.wix.com/docs/rest/api-reference/app-management/apps/app-instance/get-app-instance) to confirm that the app named `wix_forms` is installed on the site. &lt;br> Triggered when a submission is created. |

    ```javascript Create a submission with a media file (with $w)
    /********************************************
     * Backend code - my-backend-file.web.js/ts *
     *******************************************/

    import { Permissions, webMethod } from '@wix/web-methods';
    import { submissions } from '@wix/forms';
    import { auth } from '@wix/essentials';

    // Get a URL for uploading a media file

    export const myGetMediaUploadUrlFunction = webMethod(Permissions.Anyone, async (formId, filename, mimeType) => {
      try {
        const elevatedGetMediaUploadUrl = auth.elevate(submissions.getMediaUploadUrl);
        const uploadUrl = await elevatedGetMediaUploadUrl(formId, filename, mimeType);
        return uploadUrl;
      } catch (error) {
        console.error(error);
        // Handle the error
      }
    });

    // Create a submission

    export const myCreateSubmissionFunction = webMethod(Permissions.Anyone, async (submission, options) => {
      try {
        const elevatedCreateSubmission = auth.elevate(submissions.createSubmission);
        const createdSubmission = await elevatedCreateSubmission(submission, options);
        return createdSubmission;
      } catch (error) {
        console.error(error);
        // Handle the error
      }
    });

    /*************
     * Page code *
     ************/

    import { myCreateSubmissionFunction, myGetMediaUploadUrlFunction } from 'backend/my-backend-file.web';

    const submission = {
      "formId": "21bcb6c7-02b3-4ed1-b6db-7856094fac03",
      "seen": false,
      "revision": "6",
      "submissions": {
        "first_name": "Jane",
        "last_name": "McBride",
        "file_upload_7a7f": ""
      }
    }

    const formId = "21bcb6c7-02b3-4ed1-b6db-7856094fac03"

    const filename = "photo.jpg"

    const mimeType = "image/jpg"

    $w.onReady(() => {

      myGetMediaUploadUrlFunction(formId, filename, mimeType).then((result) => {
        submission.submissions.file_upload_7a7f = result.uploadUrl // push the URL into the submissions object
      });

      /* 
         Upload a media file to the generated URL by following the  
         information written in the Upload API (https://www.wix.com/velo/reference/wix-media-v2/upload-api) article. 
      */

      myCreateSubmissionFunction(submission).then((result) => {

      });

    });
    ```
