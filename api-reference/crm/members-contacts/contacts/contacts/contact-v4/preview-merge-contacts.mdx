    <div className="wix-ref">

    Previews merging source contacts into a target contact.

    This method performs a dry run without deleting or updating any contacts.
    A preview of the updated target contact is returned,
    but no data is changed in the contact list.

    To perform the actual merge, use Merge Contacts.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/contacts/{targetContactId}/preview-merge
    ```

    ## Path Params

    <ParamField path="targetContactId" type="string" required>

      Target contact ID.

    </ParamField>

    ## Body Params

    <ParamField body="sourceContactIds" type="string[]">

      IDs of up to 5 contacts to merge into the target contact.
      When you merge more than one source contact,
      the first source is given precedence, then the second, and so on.

      Constraints: `minItems 1`, `maxItems 5`.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Preview of the updated target contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts/contact-v4/contact-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CONTACT_NOT_FOUND` | Contact not found. |
    | `428` | `FAILED_PRECONDITION` | `FAILED_PRECONDITION` | Can't merge contact with membership status. |
    | `400` | `INVALID_ARGUMENT` | `ILLEGAL_MERGE` | Can't merge contact with itself. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
