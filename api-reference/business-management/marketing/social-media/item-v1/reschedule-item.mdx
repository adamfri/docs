    Changes the scheduled publish date of a scheduled item.

    Only an item with a `status` of `SCHEDULED` can be rescheduled.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-publisher/v1/items/{id}/reschedule
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the scheduled item to reschedule.

    </ParamField>

    ## Body Params

    <ParamField body="scheduledDate" type="datetime">

      Date and time to publish the item. If omitted, the item is published immediately.

    </ParamField>

    ## Response Object

    <ResponseField name="item" type="Item">

      Rescheduled item.

      See the [Item Object](/api-reference/business-management/marketing/social-media/item-v1/item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ITEM_NOT_EXISTS` | Couldn't find the item. |
    | `428` | `FAILED_PRECONDITION` | `ITEM_IS_PUBLISHED` | The item was already published. Only a scheduled item can be rescheduled. |
    | `428` | `FAILED_PRECONDITION` | `ITEM_IS_DELETED` | The item was deleted. Only a scheduled item can be rescheduled. |
    | `428` | `FAILED_PRECONDITION` | `INELIGIBLE_FOR_FEATURE` | The site's social media marketing plan doesn't permit scheduling, or its quota for the current period is exhausted. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
