    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves RSVP summaries for the specified events.

    You can retrieve summaries for up to 100 events per request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-GUEST-LIST">Read Event Tickets and Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v2/rsvps/summaries
    ```

    ## Query Params

    <ParamField query="eventId" type="string[]" required>

      Event IDs to retrieve RSVP summaries for.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="summaries" type="RsvpSummary[]">

      Retrieved RSVP summary.

      <Expandable title="summaries properties">

        <ResponseField name="eventId" type="string">

          Event ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="yesGuestCount" type="integer">

          Number of RSVPs that answered `yes`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="noGuestCount" type="integer">

          Number of RSVPs that answered `no`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="waitlistGuestCount" type="integer">

          Number of RSVPs that are in the waitlist.

          **Read-only.**

        </ResponseField>

        <ResponseField name="totalRsvpCount" type="integer">

          Total number of RSVPs.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
