    <div className="wix-ref">

    Removes a tip from an
    eCommerce order ([SDK](https://dev.wix.com/docs/sdk/backend-modules/ecom/orders/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/orders/order-object)).

    If no tip exists on the order, the call succeeds and the response contains an
    empty `OrderInfo` object.

    The call fails if the customer has already been charged for at least one of
    the associated tip distributions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/tips/v1/tips/remove
    ```

    ## Response Object

    <ResponseField name="orderInfo" type="OrderInfo">

      Information about the order from which the tip was removed.

      <Expandable title="orderInfo properties">

        <ResponseField name="additionalFeeId" type="string">

          ID of the order's additional fee that's associated with the tip.

        </ResponseField>

        <ResponseField name="additionalFeePrice" type="Price">

          Price of the order's additional fee that's associated with the tip.

          <Expandable title="additionalFeePrice properties">

            <ResponseField name="amount" type="string">

              Amount of the additional fee that's associated with the tip.

              Constraints: `>= 0`, `<= 1000000000000000`.

            </ResponseField>

            <ResponseField name="formattedAmount" type="string">

              Amount formatted with currency symbol.

              Max: 100 characters

              **Read-only.** Constraints: `maxLength 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="identifier" type="identifier">

          identifier

          <Expandable title="identifier properties">

            <ResponseField name="orderId" type="string">

              Order ID.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_REMOVE_PAID_TIP_DISTRIBUTION` | Can't remove the tip because the customer was already charged for at least one of the tip distributions. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
