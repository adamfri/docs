<Note>This article applies to the REST API only.</Note>

The Custom Fields API allows you to create and manage [custom fields](fallback::https://support.wix.com/en/article/site-members-customizing-your-member-profile-fields) to allow members to share any info relevant to a site. For example, you can add fields for a member to share their favorite animal or astrological sign.

By default, a member gets the following system fields in their profile after signing up:

- First name
- Last name
- Phone

The Members Area provides additional system fields that a Wix user can only add in the dashboard:

- Address
- Birth date
- Company
- Position

With the Custom Fields API, you can:

- [Create](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-fields/create-custom-field) a custom field.
- [Retrieve](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-fields/list-custom-fields) information about all fields (custom and already provided by the Members Area).
- [Delete](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-fields/delete-custom-field) and [hide](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-fields/hide-custom-field) a custom field.
- [Update](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-fields/update-custom-field) a custom field.

## Before you begin

It’s important to note the following before starting to code:

- A site must have the [Wix Members Area](fallback::https://www.wix.com/app-market/web-solution/members-area) installed from the App Market.
- By default, a custom field is assigned to all members on a site. If you wish to assign the custom field only to specific members or entities, use the [Custom Field Applications API](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-field-applications/introduction) after creating the custom field.

## Terminology

- **Custom Field**: A user-defined field that extends the default member profile information.
- **System Field**: A Wix-defined field from the default member profile information.
