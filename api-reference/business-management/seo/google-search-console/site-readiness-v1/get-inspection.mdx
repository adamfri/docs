    </Info>

    Retrieves the stored results of the site's latest URL inspection.

    Returns the results accumulated by Inspect URLs, including partial results
    while an inspection is still `ONGOING`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gsc/v1/inspection
    ```

    ## Response Object

    <ResponseField name="results" type="InspectedPage[]">

      Results of the pages inspected so far.

      <Expandable title="results properties">

        <ResponseField name="page" type="SitePage">

          The inspected page.

          **Read-only.**

          <Expandable title="page properties">

            <ResponseField name="pageId" type="string">

              ID of the page.

              **Read-only.** Constraints: `maxLength 200`.

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name of the page.

              **Read-only.** Constraints: `maxLength 1000`.

            </ResponseField>

            <ResponseField name="path" type="string">

              URL path of the page.

              **Read-only.** Constraints: `maxLength 2000`.

            </ResponseField>

            <ResponseField name="itemType" type="string">

              Item type of the page. For example, `static-page` or a vertical item
              type.

              **Read-only.** Constraints: `maxLength 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="status" type="string">

          Whether the page's inspection succeeded. `OK` or `ERROR`.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

        <ResponseField name="data" type="object">

          Google's raw URL-inspection result for the page, as returned by the
          Google Search Console
          [URL Inspection API](https://developers.google.com/webmaster-tools/v1/urlInspection.index/inspect).

          Any human-readable text in this payload (issue descriptions and the like)
          is in English. Verdicts and states are stable identifiers, so localize
          from those rather than from the text.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time this result was produced.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the inspection. `ONGOING` means Wix is still inspecting the
      remaining pages in the background.

      **Supported values:**

      - `UNKNOWN_INSPECTION_STATUS` — Unknown inspection status.
      - `ONGOING` — The inspection is still running in the background.
      - `COMPLETE` — The inspection finished, and nothing is running in the background anymore.
      Pages can still be left uninspected if the connected account's Google
      quota ran out, so check the remaining page count.
      - `ERROR` — The inspection stopped with an error.

    </ResponseField>

    <ResponseField name="remainingPageCount" type="integer">

      Number of pages not inspected yet.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the stored results were last updated.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
