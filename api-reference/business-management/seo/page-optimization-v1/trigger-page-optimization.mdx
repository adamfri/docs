    Starts generating optimization suggestions for a site page.

    The suggestions target the page's focus keyword, so set it first: run
    keyword research, set the chosen keyword as the page's focus keyword,
    then trigger. Returns a `predictionId` to poll Get Page Optimization
    Results with.

    Triggering is idempotent per page: while a generation for the page is in
    progress, calling again returns the same `predictionId` instead of
    starting a new job, unless the page's focus keyword changed since the
    job started, which returns a `SUGGESTIONS_ALREADY_IN_PROGRESS` error.

    Must be called with a [Wix user identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities). Calls made with an API key fail.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/seo/suggestions/v1/page-optimization/trigger
    ```

    ## Body Params

    <ParamField body="pageId" type="string" required>

      ID of the site page to optimize. The page's focus keyword must be set.

      Constraints: `minLength 1`, `maxLength 1000`.

    </ParamField>

    <ParamField body="pagePath" type="string" required>

      URL path of the page, relative to the site's domain. For example,
      `/about`.

      Constraints: `minLength 1`, `maxLength 1000`.

    </ParamField>

    ## Response Object

    <ResponseField name="predictionId" type="string">

      ID of the generation job. Pass to Get Page Optimization Results.

      **Read-only.** Constraints: `maxLength 200`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_SUPPORTED` | The site can't be optimized, for example, a headless project with no Wix-rendered site. |
    | `428` | `FAILED_PRECONDITION` | `FOCUS_KEYWORD_NOT_SET` | The page has no focus keyword set. Run keyword research, set the page's focus keyword, then trigger. |
    | `428` | `FAILED_PRECONDITION` | `CONTENT_TOO_SHORT` | The page doesn't have enough text content to optimize. |
    | `428` | `FAILED_PRECONDITION` | `SUGGESTIONS_ALREADY_IN_PROGRESS` | A generation job for this page is already in progress with a different focus keyword. Wait for it to finish, or poll its results. |
    | `500` | `INTERNAL` | `GENERATION_FAILED` | The AI generation pipeline failed. Retry the call. |
    | `429` | `RESOURCE_EXHAUSTED` | `QUOTA_LIMIT_REACHED` | The caller's generation quota is exhausted. Reserved for future metering and not currently returned. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
