<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Inserts custom script tags into a site, with the specified values for any dynamic parameters. Call this method when your app is installed on a site.

    Your app must have an existing
    [embedded script component](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/site-extensions/embedded-scripts/about-embedded-scripts),
    with exactly matching parameter names.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-APPS.MANAGE-EMBEDDED-SCRIPTS">Manage Embedded Scripts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/scripts
    ```

    ## Body Params

    <ParamField body="properties" type="ScriptProperties" required>

      Details of the script to embed.

      See the [Script Properties Object](/api-reference/app-management/embedded-scripts/script-properties-object) for this object's fields.

    </ParamField>

    <ParamField body="componentId" type="string">

      Extension ID of the embedded script.

      You can find the extension ID in the **Extensions** page in the [app dashboard](https://manage.wix.com/account/custom-apps). If you added the embedded script extension [using the Wix CLI](https://dev.wix.com/docs/wix-cli/guides/extensions/site-extensions/embedded-scripts/add-an-embedded-script-extension), you can also find it in the extension's [`embedded.extension.ts` file](https://dev.wix.com/docs/wix-cli/guides/extensions/site-extensions/embedded-scripts/embedded-script-extension-files-and-code#embeddedextensionts).

    </ParamField>

    ## Response Object

    <ResponseField name="properties" type="ScriptProperties">

      Details of the embedded script.

      See the [Script Properties Object](/api-reference/app-management/embedded-scripts/script-properties-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
