    Creates a dispute evidence document for a specific dispute.

    Use the upload URL in the response to upload your evidence file. Once uploaded, you can submit it by calling [Defend Dispute](https://dev.wix.com/docs/api-reference/business-management/payments/disputes/disputes/defend-dispute). Learn how to [upload an evidence document](https://dev.wix.com/docs/api-reference/business-management/payments/disputes/dispute-evidence-documents/upload-an-evidence-document).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/dispute-evidence-documents/v1/dispute-evidence-documents
    ```

    ## Body Params

    <ParamField body="disputeEvidenceDocument" type="DisputeEvidenceDocument" required>

      Dispute evidence document to create.

      See the [Dispute Evidence Document Object](/api-reference/business-management/payments/disputes/dispute-evidence-documents/dispute-evidence-document-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="disputeEvidenceDocument" type="DisputeEvidenceDocument">

      Created dispute evidence document.

      See the [Dispute Evidence Document Object](/api-reference/business-management/payments/disputes/dispute-evidence-documents/dispute-evidence-document-object) for this object's fields.

    </ResponseField>

    <ResponseField name="uploadUrl" type="string">

      URL for uploading the evidence file.

      Use this URL to upload the file that will serve as evidence for the dispute.
      Learn how to [upload an evidence document](https://dev.wix.com/docs/api-reference/business-management/payments/disputes/dispute-evidence-documents/upload-an-evidence-document).

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
