    Retrieves the site's default tax exempt groups.

    Default tax exempt groups are predefined groups contributed by installed apps, such as a global full-exemption group. They're available on the site without being created through Create Tax Exempt Group, and you can associate contacts with them like any other tax exempt group.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/tax-exempt-groups/default-tax-exempt-groups
    ```

    ## Response Object

    <ResponseField name="taxExemptGroups" type="TaxExemptDefaultGroup[]">

      List of the site's default tax exempt groups.

      <Expandable title="taxExemptGroups properties">

        <ResponseField name="id" type="string">

          Default tax exempt group ID.

        </ResponseField>

        <ResponseField name="name" type="string">

          Default tax exempt group name.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of the app that contributes the default tax exempt group.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
