The Groups Create Requests API provides functionality for managing requests to create a group.
 
With the Groups Create Requests API, you can:
+ [Approve](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/approve-group-requests) or [reject](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/reject-group-requests) requests to create a group. 
+ [List](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/list-group-requests) or [query](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/query-group-requests) requests to create a group.

## Before you begin
It is important to note that this module is only relevant if admin approval is required for creating a group. 

## Who can create a group
Wix users determine who can create a group. 
This setting can be found in [a site's Dashboard](fallback::https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fwix-groups/settings?) under **Groups > General Settings > Group Creation**.

+ If set to **members with approval**, site members can create a group with [Create Group](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/create-group), and the group becomes a [`createRequest`](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/group-request-object) with a status of `PENDING`. A group admin either [approves](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/approve-group-requests) or [rejects](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/reject-group-requests) the request to create a group.

+ If set to **all site members**, site members can create a group with [Create Group](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/create-group) and no approval is required.

+ If set to **only admins**, only group admins can create a group with [Create Group](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/create-group).
The default is set to **members with approval**.

## Terminology
- **Group request**: A request made by a site member to create a group.
- **Wix user**: A site owner or a site collaborator with **Manage Groups** permissions. Wix users determine who can create groups in [a site's Dashboard](fallback::https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fwix-groups/settings?) under **Groups > General Settings > Group Creation**.
