Triggered when the conversation
is merged, for example when contacts are merged
or when a visitor becomes a contact.

If messages exist in both conversations when they merge,
the messages are preserved in chronological order.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.inbox.v2.conversation_conversations_merged` |
| Package | `@wix/inbox` |
| Permissions | `Manage Inbox Messages`, `Read Inbox Messages` |
