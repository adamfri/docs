  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves 3 separate lists of business, custom, and customer [locations](https://dev.wix.com/docs/api-reference/business-management/locations/introduction),
    given the provided filtering, and whether each location is connected to at
    least one of the site's services.

    ### Defaults

    Query Locations has the following default setting, which you can't override:
    Sorted by `id` in ascending order.

    ### Filters

    For a complete list of supported filters, refer to the `location` object
    ([REST](https://dev.wix.com/docs/rest/business-management/locations/location-object)).

    When using date filters, you must use
    [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time).

    ### See also

    To learn about working with Query methods, see
    [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language)
    and [Sorting and Paging](https://dev.wix.com/docs/rest/articles/getting-started/sorting-and-paging).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/locations/query
    ```

    ## Body Params

    <ParamField body="filter" type="QueryLocationsFilter">

      Filter.

      <Expandable title="filter properties">

        <ParamField body="services" type="object">

          Service filter. See [Query Services](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/query-services) for a list of supported filters.

        </ParamField>

        <ParamField body="businessLocationIds" type="string[]">

          List of business IDs to filter by.

          Constraints: `format GUID`, `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="businessLocations" type="BusinessLocations">

      Retrieved business locations and whether each location is connected to at
      least one service.

      <Expandable title="businessLocations properties">

        <ResponseField name="exists" type="boolean">

          Whether at least one service matching the filter is connected to any of the
          retrieved business locations.

        </ResponseField>

        <ResponseField name="locations" type="Location[]">

          Retrieved business locations.

          Constraints: `maxItems 100`.

          <Expandable title="locations properties">

            <ResponseField name="id" type="string">

              Location ID.

              **Read-only.** Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="type" type="string">

              Location type.

              Default: `CUSTOM`

              **Supported values:**

              - `CUSTOM` — Location set by the business that is not a standard business [location](https://dev.wix.com/docs/api-reference/business-management/locations/introduction).
              - `BUSINESS` — Business [location](https://dev.wix.com/docs/api-reference/business-management/locations/introduction).
              - `CUSTOMER` — The customer specifies any address when booking. Available only for
              appointment-based services.

            </ResponseField>

            <ResponseField name="calculatedAddress" type="Address">

              Location address. Empty for `{"type": "CUSTOMER"}`.

              **Read-only.**

              _Nested structure omitted for brevity — see the `Address` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="customLocations" type="CustomLocations">

      Retrieved custom locations and whether each location is connected to at
      least one service.

      <Expandable title="customLocations properties">

        <ResponseField name="exists" type="boolean">

          Whether at least one service matching the filter is connected to any of the
          retrieved custom locations.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="customerLocations" type="CustomerLocations">

      Retrieved customer locations and whether each location is connected to at
      least one service.

      <Expandable title="customerLocations properties">

        <ResponseField name="exists" type="boolean">

          Whether at least one service matching the filter is connected to any of the
          retrieved customer locations.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/bookings/v2/services/locations/query' \
      -H 'Authorization: <AUTH>' \
      -d '{
        "filter": {
          "businessLocationIds": ["11f78622-ae7e-44d8-94e1-b2b4a77d0ffe"]
        }
      }'
      ```

      ```json Response
      {
        "businessLocations": {
          "exists": true,
          "locations": [
            {

              "type": "BUSINESS",
              "calculatedAddress": {
                "country": "IE"
              },
              "business": {
                "id": "11f78622-ae7e-44d8-94e1-b2b4a77d0ffe",
                "name": "New Studio",
                "default": true,
                "address": {
                  "country": "IE"
                }
              }
            }
          ]
        },
        "customLocations": {
          "exists": false
        },
        "customerLocations": {
          "exists": false
        }
      }
      ```

    </CodeGroup>
