    Deletes a calendar event.

    Events from a connected calendar are read-only: deleting one returns a `FAILED_PRECONDITION`
    error. Deleting an event ID that doesn't exist also returns a `FAILED_PRECONDITION` error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/promote/marketing-plan-service/v1/events/{eventId}
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      ID of the event to delete.

    </ParamField>

    ## Response Object

    <ResponseField name="event" type="CalendarEvent">

      The deleted event.

      See the [Calendar Event Object](/api-reference/business-management/marketing/marketing-plan/calendar-event-v1/calendar-event-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
