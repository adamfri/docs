    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves an action's dynamic [input schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/the-action-input-schema) and [UI schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#the-ui-schema), based on the [action's input mapping](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#understanding-input-mapping).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions/dynamic-input-schema
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the [app that created the action](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `minLength 5`, `maxLength 50`.

    </ParamField>

    <ParamField body="inputMapping" type="object" required>

      Action input mapping as defined in the [action's input schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/the-action-input-schema).

      The input mapping must include all parameters specified in the action's input schema's `required` array, and can include any other parameters from the schema.

    </ParamField>

    ## Response Object

    <ResponseField name="inputSchema" type="object">

      A [JSON schema](https://json-schema.org/) containing the action's added dynamic fields and its static fields.

    </ResponseField>

    <ResponseField name="uiSchema" type="object">

      A [UI schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#the-ui-schema) that describes the UI of the static and dynamic fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTION_SPI_NOT_FOUND` | The requested action does not have a matching service plugin implementer. |
    | `428` | `FAILED_PRECONDITION` | `GET_DYNAMIC_INPUT_SCHEMA_NOT_IMPLEMENTED` | The action provider does not implement dynamic input schema retrieval. |
    | `404` | `NOT_FOUND` | `ACTION_SPI_INPUT_SCHEMA_NOT_DEFINED` | The action provider did not define an input schema for the requested action. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/v1/actions/dynamic-input-schema' \
          -H 'Authorization: <AUTH>' \
          -H 'Content-Type: application/json' \
          -d '{
            "appId": "e4c3e640-0b63-4bd9-8574-53f8c14e0236",

            }
          }'

      {
        "inputSchema": {
          "$schema": "http://json-schema.org/draft-07/schema",
          "type": "object",
          "required": ["contactId", "amount"],
          "properties": {
            "contactId": {
              "type": "string",
              "format": "uuid",
              "title": "Contact ID",
              "identityType": "contact"
            },
            "amount": {
              "type": "number",
              "title": "Gift card amount"
            },
            "message": {
              "type": "string",
              "title": "Personal message"
            }
          }
        },
        "uiSchema": {
          "ui:order": ["contactId", "amount", "message"]
        }
      }
      ```
