  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retries generating a receipt document that has a `FAILED` or stuck in `PROCESSING` status.

    Note that you can access a receipt document with an `AVAILABLE` status with the URL provided in `document.downloadUrl` without regenerating.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/receipts/v1/receipts/{receiptId}/regenerate-receipt-document
    ```

    ## Path Params

    <ParamField path="receiptId" type="string" required>

      Receipt ID.

    </ParamField>

    ## Response Object

    Returns `RegenerateReceiptDocumentResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NOT_APPLICABLE_TO_REGENERATE` | Receipt document can only be regenerated if `document.status`:`FAILED` or stuck in `PROCESSING`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
