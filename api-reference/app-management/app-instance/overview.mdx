An app instance is a specific occurrence of an app on a Wix site.
When a Wix user installs an app, a unique instance is generated for that
specific site. Use the `instanceId` to keep track of the individual data
associated with each app instance.

## SDK package

```bash
npm install @wix/app-management
```

Import the `appInstances` namespace from `@wix/app-management`.
