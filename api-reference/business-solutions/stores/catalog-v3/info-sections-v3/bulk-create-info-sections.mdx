    Creates multiple info sections.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INFO_SECTION_WRITE">Info section write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/info-sections/create
    ```

    ## Body Params

    <ParamField body="infoSections" type="InfoSection[]" required>

      Info sections to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Info Section Object](/api-reference/business-solutions/stores/catalog-v3/info-sections-v3/info-section-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full created info section entities in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkInfoSectionItemResult[]">

      Info sections created by bulk action.

      Constraints: `minItems 1`, `maxItems 100`.

        <ResponseField name="itemMetadata" type="ItemMetadata">

        </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INFO_SECTIONS_LIMIT_EXCEEDED` | Number of info sections exceeded the limit of 200. |
    | `400` | `INVALID_ARGUMENT` | `ONLY_SPACES_STRING_ERROR` | `uniqueName` contains only spaces. Provide a valid `uniqueName`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
