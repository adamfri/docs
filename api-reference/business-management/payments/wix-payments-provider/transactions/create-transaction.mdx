<Warning>

  **Deprecated.** This method is deprecated.

</Warning>

Creates initial request for a transaction to authorize and optionally capture funds. Capture can be executed separately with an additional API call. Use this endpoint to execute one-time and [recurring payments]().

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-TRANSACTIONS">Manage Transactions</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/payments/v3/transactions
```
