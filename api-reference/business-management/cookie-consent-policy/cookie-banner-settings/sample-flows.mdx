<Note>This article applies to the REST API only.</Note>

This article shares some possible use cases your app could support, as well as an example flow that could support each use case. 
You're certainly not limited to these use cases, but they can be a helpful jumping off point as you plan your app's implementation.

## Manage a site's cookie banner display settings
You might choose to manage the site's cookie banner display settings with this API, as defined in the [introduction](fallback::https://dev.wix.com/docs/rest/business-management/cookie-consent-policy/cookie-banner-settings/introduction). For example, if your app manages the cookie banner display settings across multiple sites. 

To change the settings:   
Call the [Update Cookie Banner Settings](fallback::https://dev.wix.com/docs/rest/business-management/cookie-consent-policy/cookie-banner-settings/update-cookie-banner-settings) endpoint with the fields to update.  
For example:  
```json
"settings": {
      "enabled": true,
      "theme": "dark",
      "declineAllConfig": {
             "enabled": false
      }
}
```

## Manage a cookie banner's texts
You might choose to manage the texts displayed in the site's cookie banner with this API. For a complete list of default texts, see [Banner text default values](fallback::https://dev.wix.com/docs/rest/business-management/cookie-consent-policy/cookie-banner-settings/introduction#banner-text-default-values). For example, if your app manages the cookie banner display settings across multiple sites.  

To update cookie banner texts:  
Call the [Update Cookie Banner Settings](fallback::https://dev.wix.com/docs/rest/business-management/cookie-consent-policy/cookie-banner-settings/update-cookie-banner-settings) endpoint and pass the `texts` field as an object with all relevant key:value pairs.  
For example:  
```json
"texts": {
      "accept.cookies.button": "Accept",
      "advanced.category.analytics.headline": "Enable all analytics cookies",
      "advanced.category.analytics.paragraph": "These cookies track how visitors interact with our website, help us discover errors and provide a better overall experience.",
      "decline.all.button": "Decline everything",
      "policy.banner.text": "We use cookies on this website. By accepting, you agree to our use of cookies."
    }
```
