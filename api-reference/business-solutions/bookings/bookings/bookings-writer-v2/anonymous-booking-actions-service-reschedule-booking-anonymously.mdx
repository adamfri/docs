    Reschedules a booking to a new slot using an anonymous token.

    This method doesn't require standard authentication. Pass a token generated by [Get Anonymous Action Token](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/get-anonymous-action-token) instead.

    Before calling this method, check that `allowedAnonymousActions.reschedule` is `true` in the [Get Booking Anonymously](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/anonymous-booking-actions-service-get-booking-anonymously) response.

    A notification is always sent to participants.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/anonymous-bookings/{token}/reschedule
    ```

    ## Path Params

    <ParamField path="token" type="string" required>

      Anonymous token for the booking.

    </ParamField>

    ## Body Params

    <ParamField body="slot" type="Slot" required>

      New slot to reschedule the booking to.

      <Expandable title="slot properties">

        <ParamField body="sessionId" type="string">

          Identifier for the underlying session when the session is a single session or generated from a recurring session.

        </ParamField>

        <ParamField body="serviceId" type="string">

          Service identifier. Required.

        </ParamField>

        <ParamField body="scheduleId" type="string">

          Schedule identifier. Required.

        </ParamField>

        <ParamField body="startDate" type="string">

          The start time of this slot in `YYYY-MM-DDThh:mm:ss`, `YYYY-MM-DDThh:mm:ss:SSS`, or `YYYY-MM-DDThh:mm:ss:SSSZZ` [ISO-8601 format](https://en.wikipedia.org/wiki/ISO_8601). For example, `2026-01-30T13:30:00`, `2026-01-30T13:30:00:000`, or `2026-01-30T13:30:00:000-05:00`.

        </ParamField>

        <ParamField body="endDate" type="string">

          The end time of this slot in `YYYY-MM-DDThh:mm:ss`, `YYYY-MM-DDThh:mm:ss:SSS`, or `YYYY-MM-DDThh:mm:ss:SSSZZ` [ISO-8601 format](https://en.wikipedia.org/wiki/ISO_8601). For example, `2026-01-30T13:30:00`, `2026-01-30T13:30:00:000`, or `2026-01-30T13:30:00:000-05:00`.

        </ParamField>

        <ParamField body="timezone" type="string">

          The timezone according to which the slot is calculated and presented.

        </ParamField>

        <ParamField body="resource" type="SlotResource">

          The resource required for this slot.
          When populated, the specified resource will be assigned to the slot upon confirmation according to its availability.
          When empty, if `skip_availability_validation` is `false`, a random available resource will be assigned to the slot upon confirmation.
          Otherwise, one of the service resources will be assigned to the slot randomly upon confirmation.

          <Expandable title="resource properties">

            <ParamField body="id" type="string">

              Resource ID.

              **Read-only.**

            </ParamField>

            <ParamField body="name" type="string">

              Resource name.

            </ParamField>

            <ParamField body="transparency" type="string">

              The desired transparency for this resource in the calendar event.

              Supported values:
              + `OPAQUE`: The schedule is blocked during the booking, preventing other bookings involving the same resource from being scheduled at the same time.
              + `TRANSPARENT`: The schedule remains open during the booking, allowing other bookings to be scheduled concurrently.

              Default: `UNKNOWN_TRANSPARENCY`.

              **Supported values:**

              - `OPAQUE`
              - `TRANSPARENT`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="location" type="Location">

          Geographic location of the slot.

          <Expandable title="location properties">

            <ParamField body="id" type="string">

              Business Location ID. Present if the location is a business location.

            </ParamField>

            <ParamField body="name" type="string">

              Location name.

            </ParamField>

            <ParamField body="formattedAddress" type="string">

              A string containing the full address of this location.

            </ParamField>

            <ParamField body="locationType" type="string">

              Location type.

              **Supported values:**

              - `UNDEFINED` — Undefined location type.
              - `OWNER_BUSINESS` — The business address as set in the site’s general settings.
              - `OWNER_CUSTOM` — The address set when creating the service.
              - `CUSTOM` — The address set for the individual session.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="eventId" type="string">

          Calendar event ID - not supported.
          If not empty, on all write flows (create/update), it takes priority over `sessionId`.
          So if both `sessionId` and `eventId` are provided, the `sessionId` will be based on the `eventId`.
          Otherwise, if `eventId` is empty on write flow,

        </ParamField>

        <ParamField body="resourceSelections" type="ResourceSelection[]">

          Information about how the customer has selected resources for the booking.
          Each resource type may have a different selection method.
          Check `resource` for resource details.

          Constraints: `maxItems 3`.

          <Expandable title="resourceSelections properties">

            <ParamField body="resourceTypeId" type="string">

              ID of the [resource type](https://dev.wix.com/docs/api-reference/business-solutions/bookings/resources/resource-types-v2/introduction).

            </ParamField>

            <ParamField body="selectionMethod" type="string">

              Information about how the customer has selected the resource for this resource type.

              **Supported values:**

              - `SPECIFIC_RESOURCE` — The customer explicitly chose a particular resource.
              - `ANY_RESOURCE` — The customer explicitly chose "any available resource" for this resource type.
              - `NO_SELECTION` — The customer wasn't offered a resource selection or agreement option for this resource type.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="allDay" type="boolean">

          Whether the slot spans one or more full days.
          For class bookings, this value is derived from the linked calendar event.
          For appointment bookings, this value is derived from the availability slot. Any caller-provided value is ignored.

          When `true`, `startDate` is set to `00:00:00` of the first day and `endDate` is set to `00:00:00` of the day after the last day (exclusive). Midnight boundaries are interpreted in the slot's `timezone`.

          Default: `false`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="revision" type="integer" required>

      Revision number, which increments by 1 each time the booking is updated.
      To prevent conflicting changes, the current revision must be passed when rescheduling the booking.

    </ParamField>

    ## Response Object

    <ResponseField name="booking" type="Booking">

      Rescheduled booking.

      See the [Booking Object](/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/booking-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `INVALID_TOKEN` | Token is invalid, expired, or cannot be decrypted. |
    | `404` | `NOT_FOUND` | `BOOKING_NOT_FOUND` | Couldn't find the booking encoded in the token. |
    | `428` | `FAILED_PRECONDITION` | `RESCHEDULING_NOT_ALLOWED` | Rescheduling is not allowed for this booking. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
