Settings that determine who can see site members' profiles and who is allowed to make member profiles public.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Member privacy settings ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="publicMemberVisibility" type="string">

      Who can see the public member profiles.

      **Supported values:**

      - `VISIBLE_TO_MEMBERS_ONLY` — The members' profiles are only visible to logged-in site members.
      - `VISIBLE_TO_ALL` — All site visitors can see the members' profiles.

    </ResponseField>

    <ResponseField name="publicMemberCandidates" type="string">

      Who can make the member profile public.

      **Supported values:**

      - `NO_ONE` — All members have private profiles with no option to make them public.
      - `ANYONE` — All members can make the profile public.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the member privacy settings are updated. To prevent conflicting changes, the existing revision must be used when updating member privacy settings.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time when the member privacy settings were updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "e411fe13-9794-42b6-ad62-72c9917f1bac",
        "publicMemberVisibility": "VISIBLE_TO_ALL",
        "publicMemberCandidates": "ANYONE",
        "revision": "1",
        "updatedDate": "2021-08-30T08:44:20.629071Z"
      }
      ```

    </CodeGroup>
