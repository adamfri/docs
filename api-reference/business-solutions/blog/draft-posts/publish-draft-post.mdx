<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Publishes a draft post by ID. This creates a new [post](https://dev.wix.com/docs/rest/business-solutions/blog/posts-stats/post-object)
    with the data from the draft post.

    If the draft post was already published, the published post will be updated with the latest values
    from the draft post.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/blog/v3/draft-posts/{draftPostId}/publish
    ```

    ## Path Params

    <ParamField path="draftPostId" type="string" required>

      Draft post ID.

    </ParamField>

    ## Response Object

    <ResponseField name="postId" type="string">

      Published post ID.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Draft Post Created | `wix.blog.v3.draft_created` | Triggered when a draft post is created. |
    | Draft Post Updated | `wix.blog.v3.draft_updated` | Triggered when a draft post is updated. |

    </div>
