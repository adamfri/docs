An account is a social channel connection that a site owner has set up, such as an Instagram business account or a Facebook page. Items are published to an account. Accounts are connected through the site's dashboard.

## SDK package

```bash
npm install @wix/promote-growth-tools-publisher
```

Import the `accounts` namespace from `@wix/promote-growth-tools-publisher`.
