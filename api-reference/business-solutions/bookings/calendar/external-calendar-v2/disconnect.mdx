    <div className="wix-ref">

    Disconnects a Wix schedule from an external calendar and deletes all Wix
    calendar [events](https://dev.wix.com/docs/api-reference/business-management/calendar/events-v3/introduction)
    from the external calendar.

    When an external calendar is disconnected, the connection's `status`
    changes to `DISCONNECTED`.

    After disconnecting, [List Events](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/list-events)
    no longer returns events from the disconnected external calendar.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-EXTERNAL-CALENDARS">Manage External Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/external-calendars/connections/{connectionId}/disconnect
    ```

    ## Path Params

    <ParamField path="connectionId" type="string" required>

      ID of the external calendar connection to disconnect.

    </ParamField>

    ## Response Object

    <ResponseField name="connection" type="Connection">

      Updated connection details.

      <Expandable title="connection properties">

        <ResponseField name="id" type="string">

          ID of the connection between the external calendar and the Wix site.

        </ResponseField>

        <ResponseField name="providerId" type="string">

          ID of the external calendar provider.

        </ResponseField>

        <ResponseField name="calendarType" type="string">

          External calendar type.

          **Supported values:**

          - `UNDEFINED` — There is no information about the external calendar type.
          - `GOOGLE` — [Google Calendar](https://developers.google.com/calendar/api/guides/overview).
          - `I_CAL` — Apple iCalendar.
          - `OUTLOOK` — __Deprecated__. Use `MICROSOFT` instead.
          - `OFFICE_365` — __Deprecated__. Use `MICROSOFT` instead.
          - `MICROSOFT` — Microsoft Calendar. For example, Office 365 calendar or Outlook calendar.
          - `OTHER` — A different type of external calendar, not listed here.

        </ResponseField>

        <ResponseField name="scheduleId" type="string">

          ID of the [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction)
          that's connected to the external calendar.

        </ResponseField>

        <ResponseField name="userId" type="string">

          ID of the [Wix user](https://dev.wix.com/docs/rest/articles/getting-started/about-identities#wix-user)
          to whom the external calendar connection belongs.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of the app which created the external calendar connection.

        </ResponseField>

        <ResponseField name="externalAccountEmail" type="string">

          Email address associated with the external calendar account. Available only
          after completed successfully.

        </ResponseField>

        <ResponseField name="status" type="string">

          Connection status.

          **Supported values:**

          - `UNDEFINED` — There is no information about the connection status.
          - `CONNECTED` — The external calendar is connected to the Wix [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction),
          but the sync process hasn't started yet.
          - `SYNC_IN_PROGRESS` — Sync process is ongoing.
          - `SYNCED` — The Wix calendar and the external calendar are in sync.
          - `DISCONNECTED` — The external calender has been disconnected from the Wix [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction).
          - `ERROR` — The calendars sync is in error state.

        </ResponseField>

        <ResponseField name="errorReason" type="string">

          Reason for the error. Available only if `status` is `ERROR`.

          **Supported values:**

          - `UNDEFINED` — There is no information about the connection error.
          - `TOKEN_REVOKED` — The external calendar's access token has been revoked.
          - `EXTERNAL_CALENDAR_CREATION_FAILED` — The external calendar couldn't be created.
          - `EXTERNAL_CALENDAR_DELETED` — The external calendar was deleted.

        </ResponseField>

        <ResponseField name="syncConfig" type="ConnectionSyncConfig">

          Settings about which sync operations are supported.

          <Expandable title="syncConfig properties">

            <ResponseField name="listEventFromCalendars" type="ListEventFromCalendars">

              Configuration for importing events from the external calendar to the Wix
              site.

              _Nested structure omitted for brevity — see the `ListEventFromCalendars` object._

            </ResponseField>

            <ResponseField name="syncToCalendar" type="SyncToCalendar">

              Configuration for exporting events from the Wix site to the external
              calendar.

              _Nested structure omitted for brevity — see the `SyncToCalendar` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CONNECTION_ALREADY_DISCONNECTED` | The connection is already disconnected. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
