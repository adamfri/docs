    Retrieves a contact's tax details by contact ID.

    To include the contact's name, email, and VAT ID in the response, pass `CONTACT_DETAILS` in the `fields` array.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.READ-ECOM">Read eCommerce - all read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/contact-tax-details/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the contact whose tax details to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Additional fields to return in the response.

      Supported values: `CONTACT_DETAILS`

      Constraints: `maxItems 10`.

      **Supported values:**

      - `CONTACT_DETAILS` — Returns the contact's details, including first name, last name, company, email, and VAT ID.

    </ParamField>

    ## Response Object

    <ResponseField name="contactTaxDetails" type="ContactTaxDetails">

      Retrieved contact tax details.

      See the [Contact Tax Details Object](/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/contact-tax-details-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
