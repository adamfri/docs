    Runs an aggregation query on the specified data collection and returns the resulting list of items.

    ## Endpoint

    ```http
    POST /v3/items/aggregate
    ```

    ## Body Params

    <ParamField body="collectionId" type="string" required>

      ID of the collection on which to run the aggregation.

    </ParamField>

    <ParamField body="initialFilter" type="object">

      Filter to apply to the collection's data before aggregation. See [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#the-filter-section) for more information about handling data queries.

    </ParamField>

    <ParamField body="aggregation" type="Aggregation">

      Aggregation to apply to the data.

      <Expandable title="aggregation properties">

        <ParamField body="groupingFields" type="string[]">

          Fields by which to group items for the aggregation, in the order they appear in the array. If empty, the aggregation must be applied to the entire collection.

        </ParamField>

        <ParamField body="operations" type="Operation[]">

          Operations to carry out on the data in each grouping.

          <Expandable title="operations properties">

            <ParamField body="resultFieldName" type="string">

              Name of the field that contains the results of the operation.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="finalFilter" type="object">

      Filter to apply to the processed data after aggregation. See [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#the-filter-section) for more information about handling data queries.

    </ParamField>

    <ParamField body="sort" type="Sorting[]">

      Sorting configuration.

      <Expandable title="sort properties">

        <ParamField body="fieldName" type="string">

          Name of the field to sort by.

        </ParamField>

        <ParamField body="order" type="string">

          Sort order.

          **Supported values:**

          - `ASC`
          - `DESC`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="consistentRead" type="boolean" required>

      Whether to retrieve data from the primary database instance. This decreases performance but ensures data retrieved is up-to-date even immediately after an update. Applicable if the external database is eventually consistent.

    </ParamField>

    <ParamField body="returnTotalCount" type="boolean" required>

      When `true`, the query response must include the total number of items that match the query.

    </ParamField>

    ## Response Object

    <ResponseField name="items" type="object[]">

      Aggregation results. Each result must contain a field for each `groupingFields` value, and a field for each `operations.resultFieldName` value.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="PagingMetadataV2">

      Paging information.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
