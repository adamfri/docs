      **Deprecated.** This method is deprecated.

    </Warning>

    Retrieves badges assigned to specified members.

    Members are typically associated with a contact, each having a distinct `memberId` and `contactId`. When passing the ID as a parameter, avoid presuming the IDs are identical since they represent separate entities.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-BADGES">Read Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v3/badges/members
    ```

    ## Body Params

    <ParamField body="memberIds" type="string[]" required>

      Member IDs to retrieve badges for.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="memberBadgeIds" type="MemberBadgeIds[]">

      List of members and the badges they're assigned to.

      <Expandable title="memberBadgeIds properties">

        <ResponseField name="memberId" type="string">

          Member ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="badgeIds" type="string[]">

          List of badges the member is assigned to.

          Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
