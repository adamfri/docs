    <div className="wix-ref">

    Assigns a product instance to a site.

    You must pass the ID of the Wix account that the product instance belongs
    to in the header of the call.

    The customer immediately gains access to features included in the
    assigned service. It's up to the reseller to decide whether assigning
    a product instance affects the customer’s payment.

    It's possible to assign a product instance that's already assigned to a site,
    to a different site without [unassigning](https://dev.wix.com/api/rest/account-level-apis/resellers/product-instances/unassign-product-instance-from-site)
    it first. But if the call fails in such a situation, the product instance
    may either remain assigned to the original site or become unassigned. You can
    confirm the instance's status by
    [retrieving the relevant package](https://dev.wix.com/api/rest/account-level-apis/resellers/packages/get-package).

    <Note>

    This call requires an account level API key and cannot be
    authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="premium.reseller-package.manage">premium.reseller-package.manage</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/resellers/v1/packages/product-instances/{instanceId}/{siteId}
    ```

    ## Path Params

    <ParamField path="instanceId" type="string" required>

    </ParamField>

    <ParamField path="siteId" type="string" required>

      ID of the site to which the product instance is assigned.

    </ParamField>

    ## Body Params

    <ParamField body="idempotencyKey" type="string">

      Idempotency key.

    </ParamField>

    ## Response Object

    <ResponseField name="idempotencyKey" type="string">

      Idempotency key.

    </ResponseField>

    <ResponseField name="package" type="Package">

      Updated package that includes the assigned product instance.

      See the [Packages Object](/api-reference/account-level/resellers/packages-and-product-instances/packages-object) for this object's fields.

    </ResponseField>

    ## Errors
