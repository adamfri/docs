    Retrieves a plan by ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.READ-ORDERS">Read Orders</span>
    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.READ-PLANS">Read Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/pricing-plans/v3/plans/{planId}
    ```

    ## Path Params

    <ParamField path="planId" type="string" required>

      ID of the plan to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="plan" type="Plan">

      Requested plan.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-v3/plan-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
