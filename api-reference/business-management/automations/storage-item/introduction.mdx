The Storage Item API allows you to manage data storage containers across [automations](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/introduction). Storage items store data in key-value pairs and support different types, including strings, booleans, numbers, and counters that you can [update atomically](fallback::#atomic-updates). Use storage items to synchronize, store, and share data across automations.

Using the Storage Item API, you can:

- [Create storage items](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/create-storage-item) with different value types.
- [Update storage item values](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/update-storage-item-value).
- Atomically [update counters](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/update-storage-item-counter-by) to maintain data integrity.
- [Update storage item tags](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/bulk-update-storage-item-tags) for multiple storage items.
- [Get](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/get-storage-item) and [Query Storage Items](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/query-storage-items).

<Note>

You can create up to 100 storage items.

</Note>

## Atomic updates

Atomic updates either complete fully or fail entirely. They can't succeed partially. Atomic updates help maintain data integrity when multiple automations update the same storage item at the same time.

The Storage Item API supports atomic updates for items of type `COUNTER`, which you can update by calling [Update Storage Item Counter By](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/update-storage-item-counter-by).

## Before you begin

To manage storage items, the site must have [at least 1 automation](fallback::https://support.wix.com/en/article/wix-automations-creating-an-automation-with-the-new-builder).

## Terminology

- Storage item: A container that stores data across automations in a key-value pair.
- Tag: Label assigned to a storage item, enabling flexible categorization, filtering, and data management. Learn more about [tags](fallback::https://dev.wix.com/docs/api-reference/business-management/tags/introduction).
- Counter: Storage type that stores a numeric value that can be incremented or decremented using atomic operations.
- Atomic update: Operation that completes in full or not at all, thereby preserving data integrity during concurrent updates.
