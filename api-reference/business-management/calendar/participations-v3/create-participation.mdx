    Creates a `participation` object for a schedule or event.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.MANAGE">Manage Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/calendar/v3/participations
    ```

    ## Body Params

    <ParamField body="participation" type="Participation" required>

      `participation` object to create.

      See the [Participation Object](/api-reference/business-management/calendar/participations-v3/participation-object) for this object's fields.

    </ParamField>

    <ParamField body="idempotencyKey" type="string">

      Idempotency key guaranteeing that you don't create the same `participation`
      object more than once.

    </ParamField>

    ## Response Object

    <ResponseField name="participation" type="Participation">

      Created `participation` object.

      See the [Participation Object](/api-reference/business-management/calendar/participations-v3/participation-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
