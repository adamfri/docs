    Retrieves an array of all rules.

    You can filter by location or app that the rules are associated with.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/service-fees/v1/rules
    ```

    ## Query Params

    <ParamField query="locationId" type="string">

      Retrieve only rule that apply at the [location](https://dev.wix.com/docs/rest/api-reference/business-tools/locations/location-object) with this ID. If this field is `null`, the rules will not be filtered by location.

    </ParamField>

    <ParamField query="label" type="string">

      DEPRECATED. Defines the app that the rule is connected to.

    </ParamField>

    <ParamField query="appId" type="string">

      Defines the app that the rule is connected to.

    </ParamField>

    ## Response Object

    <ResponseField name="rules" type="Rule[]">

      Array containing the retrieved rules.

      See the [Rule Object](/api-reference/business-solutions/restaurants/online-orders/service-fees/rules/rule-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
