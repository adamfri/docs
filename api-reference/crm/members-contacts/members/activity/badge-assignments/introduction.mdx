The Badge Assignments API creates and manages [badge](fallback::https://support.wix.com/en/article/site-members-creating-and-managing-member-badges) assignments to site members. When you assign a badge to a member, they receive any permissions or recognition associated with that badge.

With the Badge Assignments API you can:

- Assign [single](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/create-badge-assignment) or [multiple](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/bulk-create-badge-assignments) badges to members.
- Remove [single](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/delete-badge-assignment) or [multiple](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/bulk-delete-badge-assignments) badges from members.
- [Retrieve](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/query-badge-assignments) badge assignments to see which badges a member holds.

To create a badge, use the [Badges V4](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badges-v4/introduction) API.

## Before you begin

It’s important to note the following points before starting to code:

- The site must have [Wix Members Area](fallback::https://www.wix.com/app-market/web-solution/members-area) installed.
