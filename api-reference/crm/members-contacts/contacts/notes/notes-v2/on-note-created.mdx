Triggered when a note is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.notes.v2.note_created` |
| Package | `@wix/crm` |
| Permissions | `Manage_Wix_Rentals_App_Forms_submissions`, `Read Members and Contacts - all read permissions`, `Manage Notes`, `Manage Members and Contacts - all permissions`, `Read Notes` |
