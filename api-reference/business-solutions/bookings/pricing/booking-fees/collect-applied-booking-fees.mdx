    Collects booking fees by charging the customer using the payment method that's
    saved on the corresponding [eCommerce order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/introduction)

    <Warning>

    Currently, there is no validation that prevents idempotent requests.
    This means that your code must make sure to not charge customers multiple
    times for the same booking fee. You could use
    [List Transactions For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/list-transactions-for-single-order)
    to check which charges were made previously for an eCommerce order.

    </Warning>

    An HTTP status of `200` means that all booking fees were successfully collected.
    Any other HTPP status means that collection failed.

    Collects the order's `additionalFees.price.amount` that's related to the
    booking fees. If there are multiple additional fees on the eCommerce order,
    the amount that's collected differs from `priceSummary.totalAdditionalFees.amount`.

    Possible failure reasons include:
    + The order's `status` isn't `APPROVED`.
    + There is no payment method saved on the order.
    + The order's `balanceSummary.balance.amount` is lower than the
    `additionalFees.price.amount` to collect.
    + The order's `additionalFeeId` doesn't belong to a Wix Bookings cancellation fee.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/booking-fees/v1/booking-fees/collect
    ```

    ## Body Params

    <ParamField body="orderId" type="string" required>

      ID of the eCommerce order that includes the booking fees as a single
      `additionalFee`.

    </ParamField>

    <ParamField body="additionalFeeId" type="string" required>

      ID of the additional fee that's related to all given booking fees.

    </ParamField>

    <ParamField body="businessNotification" type="BusinessNotification">

      Information about whether to notify the business about failing to collect the
      booking fees from the customer and the message to send.

      <Expandable title="businessNotification properties">

        <ParamField body="notifyBusiness" type="boolean">

          Whether to notify the business about changes made to the booking fees.
          Default is false.

        </ParamField>

        <ParamField body="message" type="string">

          Optional custom message to send.

        </ParamField>

      </Expandable>

    </ParamField>

    <ResponseField name="collectedPrice" type="Price">

        <ResponseField name="amount" type="string">

        </ResponseField>

        <ResponseField name="formattedAmount" type="string">

        </ResponseField>

      </Expandable>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_NOT_FOUND` | Couldn't find the order. |
    | `404` | `NOT_FOUND` | `ADDITIONAL_FEE_NOT_FOUND` | Couldn't find the additional fee. |
    | `400` | `INVALID_ARGUMENT` | `FEE_IS_NOT_BOOKING_FEE` | The specified additional fee isn't a booking fee. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_BALANCE_NON_POSITIVE` | The order balance is `0` or negative. There is no outstanding amount to collect. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
