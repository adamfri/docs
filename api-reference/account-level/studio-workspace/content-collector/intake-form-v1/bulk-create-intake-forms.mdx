    Creates multiple intake forms in a single request.

    The owner (`userId`) and `accountId` of each intake form are set
    automatically from the caller's identity.

    Set `returnEntity` to `true` to include the created intake forms in the
    response.

    To create a single intake form, call [Create Intake Form](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/create-intake-form).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.CONTENT-COLLECTOR">SCOPE.PARTNERS.CONTENT-COLLECTOR</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/content-collector/v1/bulk/intake-forms/create
    ```

    ## Body Params

    <ParamField body="intakeForms" type="IntakeForm[]" required>

      List of IntakeForms to be created

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Intake Form Object](/api-reference/account-level/studio-workspace/content-collector/intake-form-v1/intake-form-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      set to `true` if you wish to receive back the created IntakeForms in the response

    </ParamField>

      Fields to include in the response.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `CONTEXT`
      - `SOURCE_MATERIALS`
      - `INTRO_DATA`

    </ParamField>
