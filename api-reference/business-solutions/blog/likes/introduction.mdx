The Likes API allows you to manage likes on blog content. This API provides a liking system that can handle likes for blog posts, comments, and other blog-related content.

With the Likes API, you can:
- [Create](fallback::https://dev.wix.com/docs/api-reference/business-solutions/blog/likes/create-like) likes for any blog content.
- [Retrieve](fallback::https://dev.wix.com/docs/api-reference/business-solutions/blog/likes/get-like) individual likes or [query](fallback::https://dev.wix.com/docs/api-reference/business-solutions/blog/likes/query-likes) likes created by the authenticated visitor or member.
- [Delete](fallback::https://dev.wix.com/docs/api-reference/business-solutions/blog/likes/delete-like) likes using either the like ID or content reference (FQDN + entity ID).

The API uses [FQDN-based content identification](fallback::https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/platform/about-fqdns), allowing it to work across different content types. For example, for the related Blog content (posts or comments) you'll pass the `wix.blog.v3.post` FQDN. Visitor or member authentication is required for creating and deleting likes.

## Before you begin

It's important to note the following points before starting to code:

- A Wix user must install the [Wix Blog](fallback::https://www.wix.com/app-market/web-solution/blog) app on their site.
- The [Query Likes](fallback::https://dev.wix.com/docs/api-reference/business-solutions/blog/likes/query-likes) and [Get Like](fallback::https://dev.wix.com/docs/api-reference/business-solutions/blog/likes/get-like) methods only returns likes created by the currently authenticated site visitor or member through the API. It doesn't return:
    - Likes created through the blog's UI.
    - Likes created by other site visitors.
    - A complete list of all likes for a piece of content.

## Terminology

- **FQDN (Fully Qualified Domain Name)**: A unique identifier for the type of blog content being liked (for example, `wix.blog.v3.post` for blog posts).
- **Like**: A record representing a user's appreciation for specific blog content.
