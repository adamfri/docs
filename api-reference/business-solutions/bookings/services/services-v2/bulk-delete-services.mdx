    <div className="wix-ref">

    Deletes multiple services.

    See [Delete Service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/delete-service)
    for more details about deleting a service.

    The call succeeds even if one or more individual services can't be deleted.
    Information about failures is returned in `bulkActionMetadata`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bulk/services/delete
    ```

    ## Body Params

    <ParamField body="ids" type="string[]" required>

      IDs of the services to delete.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField body="preserveFutureSessionsWithParticipants" type="boolean">

      Whether to preserve future sessions with participants.

      Default: `false`.

    </ParamField>

    <ParamField body="participantNotification" type="ParticipantNotification">

      Whether to notify participants about the change and an optional
      custom message.

      <Expandable title="participantNotification properties">

        <ParamField body="notifyParticipants" type="boolean">

          Whether to send a message about the changes to the customer.

          Default: `false`

        </ParamField>

        <ParamField body="message" type="string">

          Custom message to send to the participants about the changes to the booking.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkServiceResult[]">

      The result of each service removal.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Update metadata.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Service">

          Updated service.

          See the [Service Object](/api-reference/business-solutions/bookings/services/services-v2/service-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Delete statistics.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
