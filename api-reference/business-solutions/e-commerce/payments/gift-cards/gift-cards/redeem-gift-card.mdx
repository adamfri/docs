    <div className="wix-ref">

    Redeems a gift card.
    Creates a transaction and lowers the card balance by the transaction amount.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.CHANGE-GIFT-CARDS-BALANCE">Change Gift Card Balances</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/gift-cards/redeem
    ```

    ## Body Params

    <ParamField body="code" type="string" required>

      Gift card code.

      Constraints: `minLength 8`, `maxLength 20`.

    </ParamField>

    <ParamField body="amount" type="Money" required>

      Amount to redeem from the gift card.

      <Expandable title="amount properties">

        <ParamField body="value" type="string" required>

          Monetary amount. Decimal string with a period as a decimal separator (e.g., 3.99). Optionally, a single (-), to indicate that the amount is negative.

          Constraints: `format DECIMAL_VALUE`, `>= 0`, `<= 999999999.99`.

        </ParamField>

        <ParamField body="currency" type="string">

          Currency code. Must be valid ISO 4217 currency code (e.g., USD).

          Constraints: `format CURRENCY`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="orderId" type="string">

      Order ID to apply the gift card transaction, when applying a gift card after order creation. Order ID can be collected from the eCommerce Order Created webhook or by calling eCommerce Search Orders.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="appId" type="string" required>

      App ID of the gift card provider.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="context" type="Context">

      Contextual information for the request, including the physical location ID if applicable.

      <Expandable title="context properties">

        <ParamField body="locationId" type="string">

          Physical location ID. Can be based on the Locations API or an external provider.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="pin" type="string">

      Gift card PIN.
      Required for some providers, like 'Moneris'.

    </ParamField>

    <ParamField body="extendedFields" type="ExtendedFields">

      [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

      **Developer Preview.**

      <Expandable title="extendedFields properties">

        <ParamField body="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ParamField body="key" type="string" />

            <ParamField body="value" type="object" />

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="transactionId" type="string">

      Gift card transaction ID.

      Constraints: `minLength 1`, `maxLength 100`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `GIFT_CARD_NOT_FOUND` | Gift card not found. |
    | `409` | `ALREADY_EXISTS` | `ALREADY_REDEEMED` | Gift card already redeemed. |
    | `400` | `INVALID_ARGUMENT` | `CURRENCY_NOT_SUPPORTED` | Gift card doesn't support the requested currency. |
    | `428` | `FAILED_PRECONDITION` | `INSUFFICIENT_FUNDS` | Gift card doesn't have sufficient funds to perform the transaction. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_DISABLED` | Gift card is disabled. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_EXPIRED` | Gift card has expired. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
