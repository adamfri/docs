    Deletes a site visitors' or members' like by blog content FQDN and entity ID.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/go-headless/coding/rest-api/visitors-and-members/make-api-calls-with-oauth).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/blog/v1/likes/fqdn/{fqdn}/entity-id/{entityId}
    ```

    ## Path Params

    <ParamField path="fqdn" type="string" required>

      Fully qualified domain name that identifies the type of blog content being liked. For example, `wix.blog.v3.post` for blog posts.

    </ParamField>

    <ParamField path="entityId" type="string" required>

      ID of the specific blog content being liked.

    </ParamField>

    ## Response Object

    Returns `DeleteLikeByFqdnAndEntityIdResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
