    <div className="wix-ref">

    Initiates payment for a payment link by creating a Wix eCommerce checkout.
    Intended for use by Wix users to create a Wix eCommerce checkout directly without opening a payment link.
    Initiating a payment will fail if successful payment will take the payment link over it's payment limit.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYLINKS.MANAGE">Manage Paylinks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/paymentlinks/v1/payment-links/{paymentLinkId}/initiate-payment
    ```

    ## Path Params

    <ParamField path="paymentLinkId" type="string" required>

      ID of the payment link to initiate payment for.

    </ParamField>

    ## Response Object

    Returns `InitiatePaymentResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_ACCEPT_PAYMENTS` | Site isn't set up to accept payments. |
    | `428` | `FAILED_PRECONDITION` | `APP_NOT_ENABLED` | Payment links app installed but not enabled. |
    | `428` | `FAILED_PRECONDITION` | `APP_NOT_INSTALLED` | Payment links app not installed. |
    | `428` | `FAILED_PRECONDITION` | `EXPIRED` | Payment link expired. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_ACTION_NOT_ACTIVE` | Payment link not active. |
    | `428` | `FAILED_PRECONDITION` | `LIMIT_EXCEEDED` | The number of received payments plus this initiated payments takes the payment link over it's `paymentsLimit`. |
    | `428` | `FAILED_PRECONDITION` | `INACTIVE_CHECKOUT_TEMPLATE` | Checkout template disabled. |
    | `428` | `FAILED_PRECONDITION` | `ALREADY_PAID` | The specified Wix eCommerce order has already been paid. |
    | `428` | `FAILED_PRECONDITION` | `ITEM_NOT_FOUND_IN_CATALOG` | An item in the payment link is no longer available in the catalog. |
    | `428` | `FAILED_PRECONDITION` | `INSUFFICIENT_INVENTORY` | Insufficient inventory for an item in the payment link. |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Site not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Payment Link Updated | `wix.paymentlinks.v1.payment_link_updated` |  |
    | Payment Link Payment Initiated | `wix.paymentlinks.v1.payment_link_payment_link_payment_initiated` | Triggered when a payment link payment is initiated. |

    </div>
