    Retrieves up to 100 add-ons, given the specified filtering, sorting, and paging.

    By default, results are sorted by `id` in ascending order.

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `name` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `price.value` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `price.currency` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `price.formattedValue` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `durationInMinutes` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `taxGroup` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `maxQuantity` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/addons/v1/add-ons/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery">

      Filtering, sorting, and paging details.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object in the following format:
          `"filter" : {`
          "fieldName1": "value1",
          "fieldName2":&#123;"$operator":"value2"&#125;
          &#125;``
          Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`

          Refer to [supported filters](https://dev.wix.com/docs/rest/business-solutions/bookings/services/add-ons/supported-filters) for a complete list of supported fields.

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"sortField1","order":"ASC"},{"fieldName":"sortField2","order":"DESC"}]`

          Constraints: `maxItems 5`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

          <Expandable title="pagingMethod properties">

            <ParamField body="cursorPaging" type="CursorPaging">

              Cursor token pointing to a page of results. Not used in the first request. Following requests use the cursor token and not `filter` or `sort`.

              _Nested structure omitted for brevity — see the `CursorPaging` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
