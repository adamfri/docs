    Retrieves checkout details.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.EVENTS-CHECKOUT">Events Checkout</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/checkout/options
    ```

    ## Response Object

    <ResponseField name="paymentMethodConfigured" type="boolean">

      Whether any payment method is configured and available for payment.

    </ResponseField>

    <ResponseField name="acceptCoupons" type="boolean">

      Whether coupons are accepted at checkout.

    </ResponseField>

    <ResponseField name="premiumServices" type="boolean">

      Whether premium services are enabled. Enabled for free if site doesn't sell any paid tickets. Selling tickets for a fee requires a premium feature `"events_sell_tickets"`.

    </ResponseField>

    <ResponseField name="paidTickets" type="boolean">

      Whether there are any paid tickets available for sale.

    </ResponseField>

    <ResponseField name="acceptGiftCards" type="boolean">

      Whether gift cards are accepted at checkout.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
