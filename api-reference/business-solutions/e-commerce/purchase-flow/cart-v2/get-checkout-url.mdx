  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the checkout URL for the cart.

    By default, this is the standard Wix checkout page.
    If `customCheckoutUrl` is set, it overrides the default and is returned as the checkout URL.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.READ-CARTS-V2_LIMITED">Read Carts V2 (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/{cartId}/get-checkout-url
    ```

    ## Path Params

    <ParamField path="cartId" type="string" required>

      ID of the Cart to calculate.

    </ParamField>

    ## Body Params

    <ParamField body="currencyCode" type="string">

      Checkout currency parameter to append as a query param

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutUrl" type="string">

      The checkout URL.

      Constraints: `format WEB_URL`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CHECKOUT_PAGE_NOT_FOUND` | Couldn't find the checkout page. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_PUBLISHED` | The site isn't published. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Retrieves the checkout page URL for a cart.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/ecom/v2/carts/ca727402-f531-4bcf-ab09-db70ea0bd008/get-checkout-url' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{}'
      ```

      ```json Response
      {
        "checkoutUrl": "https://www.mystore.com/checkout?checkoutId=ca727402-f531-4bcf-ab09-db70ea0bd008"
      }
      ```

    </CodeGroup>

    </div>

    </div>
