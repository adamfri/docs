  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a list of social media channels followed by the account. The list is ordered by creation date.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-social-media/v1/followed-channels
    ```

    ## Response Object

    <ResponseField name="followedChannels" type="FollowedChannel[]">

      List of followed social media channels.

      Constraints: `minItems 0`, `maxItems 5`.

      See the [Followed Channel Object](/api-reference/crm/loyalty-program/accounts/social-media/followed-channel-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
