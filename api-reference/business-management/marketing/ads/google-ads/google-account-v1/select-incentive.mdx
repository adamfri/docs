    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Records the user's Google Ads acquisition incentive choice in the database before checkout.
    Does not call the Google Ads API. The recorded incentive is applied automatically after the
    account's budget is assigned. Use ApplyIncentive to apply it immediately on an existing account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-GOOGLE-ADS">Manage google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/accounts/current-site/incentives/select
    ```

    ## Body Params

    <ParamField body="incentiveId" type="string" required>

      Incentive ID returned by `SuggestionsService.GetIncentives`.

      Constraints: `maxLength 1000`.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="Account">

      The account with the updated `selectedIncentiveId` persisted.

      See the [Google Account Object](/api-reference/business-management/marketing/ads/google-ads/google-account-v1/google-account-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INCENTIVE_ALREADY_APPLIED` | An incentive has already been applied to this account. |
    | `428` | `FAILED_PRECONDITION` | `INCENTIVE_FAILED_TO_APPLY` | The incentive could not be applied after all retry attempts were exhausted. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
