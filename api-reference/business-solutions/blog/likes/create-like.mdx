    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/blog/v1/likes
    ```

    ## Body Params

    <ParamField body="like" type="Like">

      Like to create.

      See the [Like Object](/api-reference/business-solutions/blog/likes/like-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="like" type="Like">

      Created like.

      See the [Like Object](/api-reference/business-solutions/blog/likes/like-object) for this object's fields.
