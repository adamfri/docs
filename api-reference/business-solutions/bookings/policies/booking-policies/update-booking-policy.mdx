    Updates a booking policy.

    Each time the booking policy is updated, `revision` increments by 1.
    The current `revision` must be specified when updating the booking policy.
    This ensures you're working with the latest booking policy and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bookings/v1/booking-policies/{bookingPolicy.id}
    ```

    ## Path Params

    <ParamField path="bookingPolicy.id" type="string" required>

      ID of the booking policy.

    </ParamField>

    <ParamField body="bookingPolicy" type="BookingPolicy" required>

      Booking policy to update.

      See the [Booking Policy Object](/api-reference/business-solutions/bookings/policies/booking-policies/booking-policy-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="bookingPolicy" type="BookingPolicy">

      Updated booking policy.

      See the [Booking Policy Object](/api-reference/business-solutions/bookings/policies/booking-policies/booking-policy-object) for this object's fields.

    </ResponseField>

    | `400` | `INVALID_ARGUMENT` | `INVALID_BOOKING_WINDOW` | `limitEarlyBookingPolicy.earliestBookingInMinutes` must be greater than `limitLateBookingPolicy.latestBookingInMinutes` when both policies are enabled. |
    | `400` | `INVALID_ARGUMENT` | `CANCELLATION_FEE_WITHOUT_CREDIT_CARD` | `saveCreditCardPolicy.enabled` must be set to `true` when `cancellationFeePolicy.enabled` is `true`. |
    | `400` | `INVALID_ARGUMENT` | `CANCELLATION_FEE_WITHOUT_DESCRIPTION` | `customPolicyDescription` is required when `cancellationFeePolicy.enabled` is set to `true`. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CANCELLATION_WINDOWS_ORDER` | `cancellationFeePolicy.cancellationWindows` must be provided in descending order. |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_CANCELLATION_WINDOWS_LIST` | `cancellationFeePolicy.cancellationWindows` is required when `cancellationFeePolicy.enabled` is set to `true`. |
    | `400` | `INVALID_ARGUMENT` | `INTAKE_FORM_ID_REQUIRED` | `intakeFormPolicy.formId` is required when `intakeFormPolicy.enabled` is `true`. |
    | `400` | `INVALID_ARGUMENT` | `INTAKE_FORM_NOT_FOUND` | The referenced intake form must exist. |
    | `400` | `INVALID_ARGUMENT` | `INTAKE_FORM_ARCHIVED` | The referenced intake form must not be archived. |

    | `400` | `INVALID_ARGUMENT` | `INVALID_COMPLETION_REQUIREMENT_FOR_TIMING` | `REQUIRED_BEFORE_BOOKING` can only be used with `"timing": "BEFORE_BOOKING"`. |
