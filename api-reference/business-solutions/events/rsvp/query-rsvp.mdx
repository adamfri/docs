    <Warning>

      **Deprecated.** This method is deprecated.

    </Warning>

    Retrieves a list of up to 100 RSVPs, supporting structurized queries.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-GUEST-LIST">Read Event Tickets and Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/rsvp/query
    ```

    ## Body Params

    <ParamField body="offset" type="integer">

      Offset. See [Pagination](https://dev.wix.com/api/rest/getting-started/pagination).

      Constraints: `min 0`.

    </ParamField>

    <ParamField body="limit" type="integer">

      Limit. See [Pagination](https://dev.wix.com/api/rest/getting-started/pagination).

      Constraints: `min 0`, `max 100`.

    </ParamField>

    <ParamField body="fieldset" type="string[]">

      Control which data is returned. See [Fieldset](https://dev.wix.com/api/rest/wix-events/wix-events/fieldset#wix-events_wix-events_fieldset_rsvp-fieldset).

      Constraints: `maxItems 20`.

      **Supported values:**

      - `DETAILS` — Include RSVP details including: `created`, `modified`, `firstName`, `lastName`, `status`, `totalGuests`, `guests`, and `annonymized`.
      - `FORM` — Include RSVP form.
      - `CONTACT_DETAILS` — Include RSVP email.

    </ParamField>

    <ParamField body="filter" type="object">

      Filter.

    </ParamField>

    <ParamField body="memberId" type="string[]">

      Site member ID.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    <ParamField body="facet" type="string[]">

      Filter facets to include in the response.

      Constraints: `maxLength 100`, `maxItems 20`.

    </ParamField>

    <ParamField body="searchPhrase" type="string">

      Textual search filter - search is performed on "guests.full_name".

      Constraints: `maxLength 200`.

    </ParamField>

    <ParamField body="eventCreatorId" type="string[]">

      Event creator ID.

      Constraints: `format GUID`, `maxItems 50`.

    </ParamField>

    <ParamField body="sort" type="string">

      Sort order, defaults to `"created:asc"`.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField body="contactId" type="string[]">

      Contact ID.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField body="tag" type="string[]">

      RSVP tag

      **Supported values:**

      - `FULLY_CHECKED_IN` — Return only RSVPs of all guests that are fully checked-in.
      - `NOT_FULLY_CHECKED_IN` — Return only RSVPs of all guests that aren't fully checked-in.
      - `MEMBER` — Return only RSVPs of guests that are members.

    </ParamField>
