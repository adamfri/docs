<Note>This article applies to the REST API only.</Note>

The Pools API allows you to manage your app or site's [pools](##pool*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#pool). Use this API together with other [Wix Benefit Programs APIs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/introduction).

With the Pools API, you can:
- Retrieve, create, update, and delete pools.
- Check which benefits a [beneficiary](##beneficiary*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#beneficiary) can redeem.
- [Redeem benefits](##redeem-a-benefit*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#redeem-a-benefit).

## Pools in benefit programs
A pool is a list of benefits that its beneficiary can redeem. It also contains settings that determine how [renewing](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle#renewing-programs) a pool affects its associated [balance](##balance*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#balance).

You create pools when you [provision programs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle#provisioning-programs). Pools are created from [pool definitions](##pool-definition*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#pool-definition).

Visitors can redeem benefits from pools in programs they are enrolled in.

Learn more about benefit programs [components](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-program-components) and [lifecycle](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle).

## Before you begin
It's important to note the following points before starting to code:
- Sites using this API must install the Pricing Plans app.
