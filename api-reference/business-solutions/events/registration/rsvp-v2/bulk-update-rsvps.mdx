    Updates multiple RSVPs.

    You can update up to 100 RSVPs per request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v2/bulk/rsvps/update
    ```

    ## Body Params

    <ParamField body="rsvps" type="MaskedRsvp[]" required>

      RSVPs to update.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="rsvps properties">

        <ParamField body="rsvp" type="Rsvp">

          RSVP to update.

          See the [Rsvp Object](/api-reference/business-solutions/events/registration/rsvp-v2/rsvp-object) for this object's fields.

        </ParamField>

        <ParamField body="fieldMask" type="FieldMask">

          Explicit list of fields to update.

          <Expandable title="fieldMask properties">

            <ParamField body="paths" type="string[]" />

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the whole `rsvp` object in the response. If `false`, only metadata is returned.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `DETAILS` — Returns `createdDate`, `updatedDate`, `firstName`, `lastName`, `totalGuests`, `guests`.
      - `FORM` — Returns `form`.
      - `CONTACT_DETAILS` — Returns `email`.

    </ParamField>

    <ParamField body="options" type="ModificationOptions">

      RSVP options. &lt;br> The **WIX_EVENTS.MANAGE_RSVP** permission is required to pass these fields.

      <Expandable title="options properties">

        <ParamField body="ignoreLimits" type="boolean">

          Whether to create or update an RSVP regardless of the event's guest limit.

        </ParamField>

        <ParamField body="ignoreFormValidation" type="boolean">

          Whether to ignore the form validation.

        </ParamField>

        <ParamField body="ignoreResponseStatus" type="boolean">

          Whether to accept the RSVP `status` even when the event's registration doesn't allow it, for example when registration is closed or hasn't started, the waitlist is unavailable, or the event only accepts `YES` responses.

        </ParamField>

        <ParamField body="ignoreAdditionalGuestNames" type="boolean">

          Whether to ignore the additional guest names validation.

        </ParamField>

      </Expandable>

    </ParamField>
