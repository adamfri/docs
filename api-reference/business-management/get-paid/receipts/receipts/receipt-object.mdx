A receipt is a document that confirms a Wix user has received money or property as payment following a sale, transfer of goods, or provision of a service.
Read more about [receipts](https://support.wix.com/en/article/wix-receipts-adding-and-setting-up-your-receipts).

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the receipt is updated.

      **Read-only.**

    <ResponseField name="updatedDate" type="datetime">
