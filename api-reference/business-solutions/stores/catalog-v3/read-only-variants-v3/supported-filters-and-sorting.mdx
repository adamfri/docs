## Query Variants Endpoint

The following table shows field support for filters and sorting for the [Query Variants](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/read-only-variants-v3/query-variants) method:

| Field                   | Supported Filters           | Sortable |
|-------------------------|-----------------------------|----------|
| `id`                    | `$eq`, `$in`, `$ne`, `$nin` | Sortable |
| `productData.productId` | `$eq`, `$in`, `$ne`, `$nin` | Sortable |
