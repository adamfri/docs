    <div className="wix-ref">

    Updates the assignments of roles and conditions for an existing team member.  Changing assignments changes the team member’s access to account assets.
    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header. API keys are currently available to selected beta users only.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.IDENTITY.MANAGE-TEAM-MEMBERS">Manage Team Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/roles-management/v2/team/assignments
    ```

    ## Body Params

    <ParamField body="userId" type="string" required>

      ID of team member being affected.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="newAssignments" type="AssignmentV3[]" required>

      New assignments to apply to the team member in this account.

      Constraints: `maxItems 50`.

      <Expandable title="newAssignments properties">

        <ParamField body="policyId" type="string">

          Role assigned to the user. To retrieve all available roles, call Get Roles Info.

        </ParamField>

        <ParamField body="assignmentId" type="string">

          Unique ID for this specific assignment.

          **Read-only.**

        </ParamField>

        <ParamField body="restrictions" type="Restriction">

          The asset where a user is assigned access in an assignment. When empty, the role covers all assets, with no restrictions to specific sites or folders.

          <Expandable title="One of the following">

            <ParamField body="restrictions" type="restrictions">

              restrictions

              _Nested structure omitted for brevity — see the `restrictions` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="subject" type="AssignedSubject">

          Identity assigned to the asset in an assignment, referred to as subject. Supported subjects include user IDs, account IDs, and app IDs.

          <Expandable title="subject properties">

            <ParamField body="id" type="string">

              Identity ID.

              **Read-only.** Constraints: `format GUID`.

            </ParamField>

            <ParamField body="subjectType" type="string">

              Identity type.

              **Supported values:**

              - `ACCOUNT`
              - `USER`
              - `USER_GROUP`
              - `MEMBER_GROUP`
              - `VISITOR_GROUP`
              - `EXTERNAL_APP`
              - `ACCOUNT_GROUP`
              - `WIX_APP`

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="assignmentIdsToRemove" type="string[]">

      Existing assignment IDs to remove. To retrieve all existing assignment IDs for a team member, call Search Team.

      Constraints: `format GUID`, `minItems 0`, `maxItems 50`.

    </ParamField>
