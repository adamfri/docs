> **Note for app developers:** Wix Data APIs require the site's [code editor](##code-editor*fallback::https://dev.wix.com/docs/develop-websites/articles/getting-started/development-environments#code-editor) to be enabled. If you are building a Wix app, add a [data collections extension](fallback::https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/data-collections/about-data-collections-extensions) to automatically enable the code editor and create data collections when your app is installed on a site.

The Folders API enables you to manage folders of collections for a [Wix CMS](fallback::https://support.wix.com/en/article/cms-formerly-content-manager-working-with-collection-folders).

With the Folders API, you can:
+ [Create](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/create-folder), [delete](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/delete-folder), [update](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/update-folder-details), or [retrieve](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/get-folder) a folder.
+ [Create](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/create-collection-reference), [delete](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/delete-collection-reference), and [retrieve](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/get-collection-references) collection references that connect a collection to a folder.
+ Listen for events that trigger when a folder is [created](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/folder-created) or [updated](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/folder-updated).

## Use cases
+ [Create folders to organize a site's content.](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/sample-flows)
+ [Retrieve a list of all folders in a site.](https://dev.wix.com/docs/api-reference/business-solutions/cms/folders/sample-flows)

## Terminology

+ **Folder:** Organizes collections into groups.
+ **Root folder:** The default folder created with every [Wix CMS](fallback::https://support.wix.com/en/article/cms-formerly-content-manager-working-with-collection-folders). All collections are automatically grouped into the root folder. The root folder's ID is `null` and is the only folder in a site that may contain other folders.
+ **Collection:** A group of data items stored together. See the [Data Collections API](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-collections/introduction).
+ **Collection reference:** Connects a collection to a folder.
