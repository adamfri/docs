    <div className="wix-ref">

    Retrieves a list of schedule time frames by schedule IDs.

    Sorted by schedule ID in ascending order.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PUBLIC">Read Calendar</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/calendar/v3/schedules/timeframe
    ```

    ## Query Params

    <ParamField query="ids" type="string[]" required>

      IDs of the schedules for which to retrieve schedule time frames.

      Min: 1 schedule ID
      Max: 100 schedule IDs

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField query="timeZone" type="string">

      Time zone for adjusting the times of the returned schedule time frames.

      Default: `timeZone` of the [site properties](https://dev.wix.com/docs/rest/business-management/site-properties/properties/properties-object)

    </ParamField>

    ## Response Object

    <ResponseField name="scheduleTimeFrames" type="ScheduleTimeFrame[]">

      Retrieved schedule time frames.

      See the [Schedule Time Frame Object](/api-reference/business-management/calendar/schedule-time-frames-v3/schedule-time-frame-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
