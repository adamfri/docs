    Creates a site from a template.

    The new site is a duplicate of the template's site and is added to the template's `sites` list. Use this to create sites from your own templates within your account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES">SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wixstudio/templates/v1/templates/{templateId}/create-site
    ```

    ## Path Params

    <ParamField path="templateId" type="string" required>

      ID of the template to create the site from.

    </ParamField>

    ## Response Object

    <ResponseField name="createdSiteMetaSiteId" type="string">

      ID of the created site.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
