      Legacy coupon information assigned to the account. Use `appliedIncentive` for the full incentive lifecycle.

      <Expandable title="couponInfo properties">

        <ResponseField name="customerId" type="string">

        </ResponseField>

        <ResponseField name="accountName" type="string">

          Google Ads account name.

        </ResponseField>

        <ResponseField name="couponCode" type="string">

          Unique coupon code returned by Google Ads when the incentive was applied.

        </ResponseField>

        <ResponseField name="status" type="string">

          Current status of the coupon.

          **Supported values:**

          - `REDEEMED` — Coupon has been redeemed. This is the initial status; the account is eligible but has not yet met the spend requirements.
          - `FULFILLED` — Spend requirements have been met and the reward is being processed.
          - `EXPIRED` — Coupon expired before the spend requirements were met.
          - `REWARD_GRANTED` — Reward has been granted and is available for use.
          - `INVALIDATED` — Coupon was marked as invalid after redemption.

        </ResponseField>

        <ResponseField name="redemptionDate" type="datetime">

          Date when the account became eligible for the coupon (coupon redemption date).

        </ResponseField>

        <ResponseField name="expirationDate" type="datetime">

          Date until which spend is counted toward the coupon match requirements.

        </ResponseField>

        <ResponseField name="rewardGrantDate" type="datetime">

          Date when the coupon reward was granted to the account.

        </ResponseField>

        <ResponseField name="redemptionTimeMs" type="datetime">

          Same date as `redemptionDate`, represented as a Unix timestamp in milliseconds.

        </ResponseField>

        <ResponseField name="expirationTimeMs" type="datetime">

          Same date as `expirationDate`, represented as a Unix timestamp in milliseconds.

        </ResponseField>

        <ResponseField name="rewardGrantTimeMs" type="datetime">

          Same date as `rewardGrantDate`, represented as a Unix timestamp in milliseconds.

        </ResponseField>

        <ResponseField name="maxDaysToReward" type="integer">

          Total number of days over which the spend match is calculated. Equivalent to the number of days between `redemptionDate` and `expirationDate`.

        </ResponseField>

        <ResponseField name="daysToReward" type="integer">

          Days remaining to fulfill the spend match requirements. Returns `0` when `expirationDate` has passed.

      Current status of the account.

      **Read-only.**

      **Supported values:**

    <ResponseField name="blockReason" type="BlockReasonEnum">

      Reason the account is blocked by Wix, if applicable. Set by fraud, unpaid balance, or chargeback handlers. Cleared when the block is lifted.

      **Read-only.**

      <Expandable title="blockReason properties">

        <ResponseField name="reason" type="string">

          The block reason.

          **Supported values:**

          - `UNSPECIFIED` — Account is not blocked by Wix. The account may still be suspended or canceled by Google independently.
          - `FRAUD` — Account was blocked because a fraud flag was raised.
          - `UNPAID_BALANCE` — Account was blocked due to an unpaid balance from a failed recurring custom charge.
          - `CHARGEBACK` — Account was blocked due to a chargeback dispute filed with the bank.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="blockedDate" type="datetime">

      Date and time the account was blocked. Set together with `blockReason` and cleared when the block is lifted.

      **Read-only.**

        <ResponseField name="incentiveState" type="string">

          Current lifecycle state of the applied incentive.

          **Supported values:**

          - `UNSPECIFIED` — Unknown incentive state.

          - `FULFILLED` — The spend requirements have been met but the reward has not yet been granted.
          - `REWARD_GRANTED` — The reward has been granted to the account.
          - `EXPIRED` — The incentive expired before the spend requirements were met.
          - `REWARD_EXPIRED` — The granted reward has expired without being fully used.
          - `INVALIDATED` — The incentive was marked as invalid after redemption.
          - `REWARD_EXHAUSTED` — The granted reward has been fully used.

        </ResponseField>
