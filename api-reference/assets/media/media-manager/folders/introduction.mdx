The Folders API allows you to manage the folders in a site's Media Manager. 

With the Folders API, you can:
- [Get](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/get-folder), [list](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/list-folders), [search](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/search-folders), and [query](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/query-folders) folders.
- [Create](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/create-folder), [update](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/update-folder), and [delete](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/bulk-delete-folders) folders. 
- [Restore](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/bulk-restore-folders-from-trash-bin) folders from the trash bin.
- [Generate URLs](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/folders/generate-folder-download-url) for downloading folders from the Media Manager.
