---
title: "Order Payment Request Object"
description: "The Order Payment Request object in the Wix Order Payment Request API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Order payment request ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="source" type="Source">

      Details about the source that created the order payment request.

      Constraints: `immutable`.

      <Expandable title="source properties">

        <ResponseField name="appId" type="string">

          ID of the app that created the order payment request.

        </ResponseField>

        <ResponseField name="externalId" type="string">

          Reference to a record in the source system. For example, if the payment request was created from a paylink or invoice, use this field to store the paylink ID or invoice ID.

          Constraints: `minLength 1`, `maxLength 100`, `immutable`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Payment request status. Set by the system. A new order payment request starts as `UNPAID`, unless `expirationDate` is already in the past at creation time, in which case it is created as `EXPIRED`. The system sets the status to `PAID` once payment is collected, `EXPIRED` when the expiration date passes, or `VOIDED` when the request is voided.

      **Read-only.**

      **Supported values:**

      - `UNPAID` — Payment is owed but hasn't been collected yet.
      - `PAID` — Payment has been collected.
      - `EXPIRED` — The order payment request has passed its `expirationDate` without being paid.

    </ResponseField>

    <ResponseField name="orderId" type="string">

      Order ID.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="orderNumber" type="string">

      Order number.

      **Read-only.**

    </ResponseField>

    <ResponseField name="amount" type="Price">

      Amount to collect. Set when the order payment request is created and can't be changed afterward.

      Constraints: `immutable`.

      <Expandable title="amount properties">

        <ResponseField name="amount" type="string">

          Amount.

          Constraints: `>= 0`, `<= 1000000000000000`.

        </ResponseField>

        <ResponseField name="formattedAmount" type="string">

          Amount formatted with currency symbol.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="currency" type="string">

      Three-letter currency code in [ISO-4217 alphabetic format](http://en.wikipedia.org/wiki/ISO_4217). Always matches the order's currency.

      **Read-only.** Constraints: `format CURRENCY`.

    </ResponseField>

    <ResponseField name="paymentGatewayOrderId" type="string">

      Payment gateway order ID associated with this payment request.

      **Read-only.**

    </ResponseField>

    <ResponseField name="title" type="string">

      Title displayed to the customer on the payment page.

      Constraints: `minLength 1`, `maxLength 200`.

    </ResponseField>

    <ResponseField name="description" type="string">

      Description displayed to the customer on the payment page.

    </ResponseField>

    <ResponseField name="expirationDate" type="datetime">

      Date and time the order payment request expires. If not provided, the order payment request doesn't expire.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for this order payment request.

      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the order payment request was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the order payment request was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="image" type="Image">

      Image to display to the customer on the payment page.

      <Expandable title="image properties">

        <ResponseField name="id" type="string">

          WixMedia image ID.

          Constraints: `maxLength 200`.

        </ResponseField>

        <ResponseField name="height" type="integer">

          Original image height.

          **Read-only.**

        </ResponseField>

        <ResponseField name="width" type="integer">

          Original image width.

          **Read-only.**

        </ResponseField>

        <ResponseField name="altText" type="string">

          Image alt text.

        </ResponseField>

        <ResponseField name="filename" type="string">

          Image filename.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="blockedPaymentMethods" type="string[]">

      List of payment methods that can't be used for this order payment request.

      **Developer Preview.** Constraints: `maxItems 1`.

      **Supported values:**

      - `MANUAL` — Manual payment.

    </ResponseField>

  </Tab>
