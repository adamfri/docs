---
title: "Manual Tax Mapping Object"
description: "The Manual Tax Mapping object in the Wix Manual Tax Mapping API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Manual tax mapping ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the manual tax mapping is updated.
      To prevent conflicting changes, the current revision must be passed when updating the manual tax mapping.

      Ignored when creating a manual tax mapping.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the manual tax mapping was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the manual tax mapping was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="taxGroupId" type="string">

      Tax group ID. Tax groups define collections of items or services that share the same tax treatment.

    </ResponseField>

    <ResponseField name="taxRegionId" type="string">

      Tax region ID. Tax regions represent geographical areas where specific tax rules apply.

    </ResponseField>

    <ResponseField name="taxRate" type="string">

      Tax rate to apply for this tax group and region combination.

      Specified as a decimal string representing a fraction, not a percentage. For example, `"0.05"` is 5%, `"0.1"` is 10%, and `"0.08"` is 8%. Don't pass a number (`0.05`), an integer (`5`), or a percentage string (`"5%"`). Up to 6 decimal places are supported.

      Constraints: `>= 0`.

    </ResponseField>

    <ResponseField name="description" type="string">

      Description of the manual tax mapping. Use this field to add context or notes about the tax rate.

    </ResponseField>

    <ResponseField name="taxType" type="string">

      Type of tax being applied, such as `VAT`, `GST`, or `Sales Tax`. This depends on the jurisdiction's tax laws.

      Constraints: `maxLength 200`.

    </ResponseField>

    <ResponseField name="taxName" type="string">

      Customer-facing name of the tax, shown at checkout. For example, `STATE TAX`, `GST`, or `VAT`.

      Cosmetic only. It doesn't affect the calculated amount. Can be left empty, in which case checkout shows a default label such as `Sales Tax`.

      Constraints: `maxLength 200`.

    </ResponseField>

    <ResponseField name="jurisdiction" type="string">

      Name of the jurisdiction where this tax rate applies. For example, `California` or `United Kingdom`.

      Constraints: `maxLength 200`.

    </ResponseField>

    <ResponseField name="jurisdictionType" type="string">

      Type of jurisdiction where this tax rate applies, such as country, state, county, city, or special district.

      **Supported values:**

      - `UNDEFINED`
      - `COUNTRY`
      - `STATE`
      - `COUNTY`
      - `CITY`
      - `SPECIAL`

    </ResponseField>

    <ResponseField name="exemptRates" type="ExemptDetails[]">

      Tax exemption details for user-defined exempt groups.

      Constraints: `maxItems 50`.

      <Expandable title="exemptRates properties">

        <ResponseField name="taxExemptGroupId" type="string">

          Tax exempt group ID.

          **Developer Preview.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="taxRate" type="string">

          Tax override rate for given tax mapping.

          Constraints: `>= 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields for storing additional custom data.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
