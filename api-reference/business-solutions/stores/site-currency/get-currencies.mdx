    <div className="wix-ref">

    Retrieves the list of currencies that can be displayed on the site.

    Returns all currencies that are currently enabled for the site.
    Visitors can view prices in any of these currencies.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.MANAGE-STORES">Manage Stores</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/settings/v1/currencies/site
    ```

    ## Response Object

    <ResponseField name="currencies" type="SiteCurrency[]">

      List of currencies currently enabled for the site.

      See the [Site Currency Object](/api-reference/business-solutions/stores/site-currency/site-currency-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Retrieves the list of currencies that can be displayed on the site.

    <CodeGroup>

      ```bash Request
      curl -X GET \
        'https://www.wixapis.com/settings/v1/currencies/site' \
        -H 'Content-type: application/json' \
        -H 'Authorization:  <AUTH>' \
      ```

      ```json Response
      {
        "currencies": [
          {"code": "AED"},
          {"code": "AFN"},
          {"code": "AMD"}
        ]
      }
      ```

    </CodeGroup>
