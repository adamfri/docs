    <div className="wix-ref">

    Retrieves a custom field with a specified name, or creates one if it doesn't exist.
    The number of custom fields is limited to 100.

    Successful calls to this method always return a field,
    which can be specified in subsequent calls.

    To find an existing custom field without potentially creating a new one, call Get Extended Field or
    Query Extended Fields.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-EX-FIELDS">Manage Contact Extended Fields</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/extended-fields
    ```

    ## Body Params

    <ParamField body="displayName" type="string" required>

      Display name to retrieve or create.

      If an existing custom field is an exact match
      for the specified display name,
      the existing field is returned.
      If not, a new field is created and returned.

      Constraints: `minLength 1`, `maxLength 150`.

    </ParamField>

    <ParamField body="dataType" type="string">

      Type of data the field holds.
      Ignored if an existing field is an exact match
      for the specified display name.

      **Supported values:**

      - `TEXT` — Accepts strings.
      - `NUMBER` — Accepts floats.
      - `DATE` — Accepts dates formatted as `YYYY-MM-DD`.
      - `URL` — Accepts strings. Prepends `https://` if no protocol is included.

    </ParamField>

    ## Response Object

    <ResponseField name="field" type="ExtendedField">

      Extended field that was found or created.

      See the [Extended Field Object](/api-reference/crm/members-contacts/contacts/extended-fields/extended-field-object) for this object's fields.

    </ResponseField>

    <ResponseField name="newField" type="boolean">

      Indicates whether the extended field was just created or already existed.

      Returns `true` if the field was just created.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `429` | `RESOURCE_EXHAUSTED` | `FIELDS_QUOTA_EXCEEDED` | The site reached the limit of 100 custom fields. Some fields must be deleted before any more can be created. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Extended Field Created | `wix.contacts.v4.extended-field_created` | Triggered when an extended field is created. |

    </div>
