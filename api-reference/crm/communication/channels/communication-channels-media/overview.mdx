## SDK package

```bash
npm install @wix/comm-channels-media
```

Import the `communicationChannelsMedia` namespace from `@wix/comm-channels-media`.

  </Card>
  <Card title="Generate File Upload Url" href="/api-reference/crm/communication/channels/communication-channels-media/generate-file-upload-url">
    POST Generates a secure upload URL for storing a file in the Media Manager.
  </Card>
  <Card title="Import File" href="/api-reference/crm/communication/channels/communication-channels-media/import-file">
    POST Imports a file from an external URL directly into the Media Manager.
  </Card>
  <Card title="Get Storage Quota" href="/api-reference/crm/communication/channels/communication-channels-media/get-storage-quota">
