    <div className="wix-ref">

    Retrieves an item from a collection.

    Set `consistentRead` to `true` when you need to read an item back immediately after a write and want to reduce the chance of stale data.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.READ">Read Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v2/items/{dataItemId}
    ```

    ## Path Params

    <ParamField path="dataItemId" type="string" required>

      ID of the data item to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="dataCollectionId" type="string" required>

      ID of the collection from which to retrieve the data item.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField query="consistentRead" type="boolean">

      Whether to retrieve data from the primary database instance.
      This decreases performance but ensures data retrieved is up to date even immediately after an update.
      Learn more about [Wix Data and eventual consistency](https://dev.wix.com/api/rest/wix-data/wix-data/eventual-consistency).

      Default: `false`

    </ParamField>

    <ParamField query="language" type="string">

      Language to translate result text into, in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.
      If provided, the result text is returned in the specified language.
      **Note:** Translation for the specified language must be enabled for the collection in [Wix Multilingual](https://www.wix.com/app-market/wix-multilingual).

      If not provided, result text is not translated.

    </ParamField>

    <ParamField query="fields" type="string[]">

      Fields to return for the item. Only fields specified in the array are included in the response. If the array is empty, all fields are returned.
      **Note:** The `_id` system field is always returned.

      Constraints: `maxLength 1000`, `maxItems 1000`.

    </ParamField>

    <ParamField query="appOptions" type="object">

      Additional parameters specific to the [Wix app collection](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-wix-app-collections) you are querying.

      When querying the Wix Stores [Products collection](https://dev.wix.com/docs/develop-websites/articles/wix-apps/wix-e-commerce-stores/wix-stores-products-collection-fields), pass the following optional parameters:
      - `includeHiddenProducts`: Whether to include hidden products in the response. Default: `false`.
      - `includeVariants`: Whether to include product variants in the query. Default: `false`.

    </ParamField>

    <ParamField query="publishPluginOptions" type="PublishPluginOptions">

      Options for the Publish plugin.
      This plugin allows items in a [data collection](https://dev.wix.com/docs/rest/business-solutions/cms/data-collections/data-collection-object) to be marked as draft or published. Published items are visible to site visitors, while draft items are not.

      <Expandable title="publishPluginOptions properties">

        <ParamField query="includeDraftItems" type="boolean">

          Whether to include draft items.

          When `true`, both published and draft items are affected. Default: `false`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="referencedItemOptions" type="ReferencedItemOptions[]" deprecated>

      Options for retrieving referenced items.

      **Deprecated.** Use `include_references` instead. Removal: 2026-08-01. Constraints: `maxItems 100`.

      <Expandable title="referencedItemOptions properties">

        <ParamField query="fieldName" type="string">

          Field containing references in the queried item.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField query="limit" type="integer">

          Maximum number of referenced items to include for each queried item.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="includeFieldGroups" type="string[]">

      Requests conditional fields. Currently used in App Collections.
      Please refer to app collection documentation for a list of valid values.

      Constraints: `maxLength 100`, `maxItems 100`.

    </ParamField>

    <ParamField query="includeReferences" type="IncludeReference[]">

      Fields for which to include referenced items. For each reference field specified, the response includes the full data items being referenced. Use this to retrieve related data in a single call without additional queries.

      Constraints: `maxItems 100`.

      <Expandable title="includeReferences properties">

        <ParamField query="field" type="string">

          Field containing references in the item. This field must be configured as a reference or multi-reference field in the collection schema.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField query="limit" type="integer">

          Maximum number of referenced items to include for each item. When a reference field contains more items than this limit, only the first items up to the limit are included in the response. If not specified, up to 50 items are included.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="dataItem" type="DataItem">

      Retrieved item.

      See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
