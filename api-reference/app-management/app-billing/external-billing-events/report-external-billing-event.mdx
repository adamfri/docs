    <div className="wix-ref">

    Sends an external billing event to Wix.
    Use this to report charges or refunds for your [Partner Billed App](https://dev.wix.com/docs/build-apps/launch-your-app/pricing-and-billing/partner-billed-apps-reporting).
    The reported event enables Wix to track revenue, deductions, and Wix's share related to Partner Billed App charges.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/billing-event
    ```

    ## Body Params

    <ParamField body="event" type="ExternalBillingEvent">

      The billing event with details of the external transaction, including the gross revenue,
      net revenue, and billing type (charge or refund).

      See the [External Billing Event Object](/api-reference/app-management/app-billing/external-billing-events/external-billing-event-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="event" type="ExternalBillingEvent">

      The billing event that was processed.

      See the [External Billing Event Object](/api-reference/app-management/app-billing/external-billing-events/external-billing-event-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `FAILED_PRECONDITION` | The app isn't configured for external billing or the required conditions aren't met to report external billing events. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
