    <div className="wix-ref">

    Retrieves the current permissions for the specified data collection.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wix-data/v1/permissions
    ```

    ## Query Params

    <ParamField query="dataCollectionId" type="string" required>

      ID of the collection to retrieve permissions of.

      Constraints: `maxLength 256`.

    </ParamField>

    ## Response Object

    <ResponseField name="dataPermissions" type="DataPermissions">

      Permissions of the specified collection.

      See the [Data Permissions Object](/api-reference/business-solutions/cms/collection-management/data-permissions/data-permissions-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0025` | Returned when the specified data collection isn't found. Learn more about [Wix Data error codes](https://dev.wix.com/docs/rest/business-solutions/cms/wix-data-error-codes). |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
