    This method retrieves quota information for an action.

    Wix calls this method when a Wix user opens the **Manage your automations quotas** modal
    in the **Automations** dashboard. The response from this method is displayed in the modal.
    The data is displayed based on the response body format.

    Implementing this method is optional. To implement it, select the method under **Service plugin endpoints** when editing your
    action in the app dashboard.

    <Note>

    Wix doesn't enforce action quota limits. It only displays them to Wix users.
    Enforcing quota limits is the action provider's responsibility.

    </Note>

    ## Endpoint

    ```http
    POST /v1/quota-info
    ```

    ## Body Params

    <ParamField body="actionKey" type="string" required>

      Action key as defined in your app's action configuration in the app dashboard.
      For example, `send-email` or `generate-invoice`.

      Constraints: `minLength 1`.

    </ParamField>

    ## Response Object

    <ResponseField name="actionQuotaInfo" type="ActionQuotaInfo">

      Details about the quotas for your action.

      <Expandable title="actionQuotaInfo properties">

        <ResponseField name="enforced" type="boolean">

          Whether the quotas for your action are enforced. If you mark this as `true` in the response body,
          Wix displays the information in the quota object on the site dashboard. If you mark this as `false` for
          a user, Wix does not display any quota info on the site dashboard for your service.

        </ResponseField>

        <ResponseField name="quotaInfo" type="QuotaInfo[]">

          The plans your service provides, together with the quotas enforced by each plan. A site may be enrolled
          in multiple plans. Plans and quotas can be related as follows:

          + A single plan has a single quota.
          + A single plan has multiple quotas.
          + Multiple plans are associated with multiple quotas.

          Plans and quotas that are related should be grouped together in a single `quotaInfo`
          object.

          <Expandable title="quotaInfo properties">

            <ResponseField name="plans" type="Plan[]">

              List of plans associated with the site making the request.

              _Nested structure omitted for brevity — see the `Plan[]` object._

            </ResponseField>

            <ResponseField name="quotas" type="Quota[]">

              List of quotas associated with the plans the site is enrolled in.

              Constraints: `minItems 1`.

              _Nested structure omitted for brevity — see the `Quota[]` object._

            </ResponseField>

            <ResponseField name="upgradeCta" type="UpgradeCTA">

              Details for an upgrade call-to-action button.
              Displayed in the Wix user’s site dashboard together with the quota details.

              _Nested structure omitted for brevity — see the `UpgradeCTA` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
