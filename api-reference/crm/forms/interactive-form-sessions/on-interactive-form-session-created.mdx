## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.forms.ai.v1.interactive_form_session_created` |
| Package | `@wix/forms` |
| Permissions | `View Forms`, `Manage form submissions.`, `Manage forms`, `Manage Online Programs` |
