      **Deprecated.** This method is deprecated.

    </Warning>

    Removes the `overrideCheckoutUrl` from a specified checkout.

    When `overrideCheckoutUrl` is removed, the `checkoutUrl` will be set to the default, standard
    Wix checkout page URL.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkouts/{id}/remove-override-checkout-url
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the checkout to remove the override checkout url from.

    </ParamField>

    ## Response Object

    <ResponseField name="checkout" type="Checkout">

      Updated checkout after removal of override checkout url.

      See the [Checkout Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout/checkout-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Updated | `wix.ecom.v1.checkout_updated` | Triggered when a checkout is updated. |

    </div>
