    Invites a Google account to manage a location's Business Profile.

    Specify the `email` of the Google account to invite and the `role` to grant.
    The invitation has to be accepted by that account before it takes effect.
    Until then it appears in Get Location Admins with `pendingInvitation` set to
    `true`.

    An account that already manages the location isn't invited again, so calling
    this twice is safe.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/locations/{locationId}/invite-admin
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID (Google's opaque location id) to invite the account to manage.

    </ParamField>

    ## Body Params

    <ParamField body="email" type="string" required>

      The email of the Google account to invite as a manager. PII.

    </ParamField>

    <ParamField body="role" type="string" required>

      The role to assign to the invited account.

      **Supported values:**

      - `MANAGER` — Can manage the profile but not transfer or delete it.
      - `OWNER` — Owner-level access to the profile.
      - `PRIMARY_OWNER` — The primary owner. A location has exactly one.
      - `SITE_MANAGER` — Legacy Google+ pages manager. Google no longer grants this.

    </ParamField>

    ## Response Object

    <ResponseField name="inviteId" type="string">

      Google's invite ID, returned for the consumer to track invitation state.

      **Read-only.**

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
