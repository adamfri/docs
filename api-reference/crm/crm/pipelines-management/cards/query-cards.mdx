    Retrieves a list of up to 100 cards, given the provided paging, filtering, and sorting.

    By default, 50 cards are returned and sorted by `updatedDate` in descending order.

    For a detailed list of supported operations, see [Cards: Supported Filters and Sorting](https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/supported-filters-sorting-and-search).

    To learn more about working with _Query_ methods, see [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language) and [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$nin` | None |
    | `pipelineId` | `$eq`, `$ne`, `$in`, `$nin` | None |
    | `stageId` | `$eq`, `$ne`, `$in`, `$nin` | None |
    | `createdDate` | `$eq`, `$ne`, `$gte`, `$gt`, `$lte`, `$lt` | Sort: `ASC` |
    | `updatedDate` | `$eq`, `$ne`, `$gte`, `$gt`, `$lte`, `$lt` | Sort: `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
