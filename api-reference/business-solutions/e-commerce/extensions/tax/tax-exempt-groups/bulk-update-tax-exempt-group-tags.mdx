    Adds or removes tags on multiple tax exempt groups.

    Specify which tags to assign and which tags to unassign. A tag that appears in both the list to assign and the list to unassign will be assigned. Tags that don't exist are ignored.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="BILLING.TAX_EXEMPT_GROUP_UPDATE_TAGS">BILLING.TAX_EXEMPT_GROUP_UPDATE_TAGS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/bulk/tax-exempt-groups/update-tags
    ```
