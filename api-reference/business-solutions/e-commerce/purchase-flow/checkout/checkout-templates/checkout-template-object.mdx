A reusable template for creating checkouts with predefined line items, coupons, and customization settings.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Checkout template ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the checkout template.

      When `status` is `INACTIVE` checkouts will not be created with this template `id`. Instead, the endpoint will redirect to the domain site.

      Default: `ACTIVE`

      **Supported values:**

      - `ACTIVE`
      - `INACTIVE`

    </ResponseField>

    <ResponseField name="customization" type="CheckoutCustomization">

      Custom settings to apply to the checkout page created from this template.

      **Developer Preview.**

      <Expandable title="customization properties">

        <ResponseField name="webClient" type="WebClientCustomization">

          Web client customizations. These customizations only apply to the standard Wix checkout page.

          <Expandable title="webClient properties">

            <ResponseField name="disabledContinueShoppingButton" type="boolean">

              Whether to disable the "Continue shopping" button.

              Default: `false`

            </ResponseField>

            <ResponseField name="disabledPolicyAgreementCheckbox" type="boolean">

              Whether to disable policy agreement checkout in the checkout page

              Default: `false`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="lockedGiftCard" type="boolean">

          Whether to lock the ability to add or remove a gift card.

          Default: `false`

        </ResponseField>

        <ResponseField name="lockedCoupon" type="boolean">

          Whether to lock the ability to apply or remove a coupon code.

          Default: `false`

        </ResponseField>

        <ResponseField name="disabledManualPayment" type="boolean">

          Whether to disable manual payment option for this checkout.

          Default: `false`

        </ResponseField>

      </Expandable>

                <ResponseField name="value" type="string">

                  Type of selected payment option for current item.

                  Default: `FULL_PAYMENT_ONLINE`

                  **Supported values:**

                  - `FULL_PAYMENT_ONLINE` — The entire payment for this item happens as part of the checkout.
                  - `FULL_PAYMENT_OFFLINE` — The entire payment for this item happens after checkout. For example, when using cash, check, or other offline payment methods.
                  - `MEMBERSHIP` — Payment for this item is done by charging a membership. Any remaining amount not covered by the membership, such as item modifiers, is paid online.
                  - `DEPOSIT_ONLINE` — Partial payment to be paid upfront during checkout. The initial amount to be paid for each line item is specified in `depositAmount`.
                  - `MEMBERSHIP_OFFLINE` — Payment for this item can only be done by charging a membership and must be manually redeemed in the dashboard by the site admin. When selected, `price` is `0`.
                  - `MEMBERSHIP_ONLINE_WITH_OFFLINE_REMAINDER` — Item price is charged to online membership. Any remaining amount not covered by the membership, such as item modifiers, is paid offline.

          Type of selected payment option for current item. Defaults to `FULL_PAYMENT_ONLINE`.

          + `FULL_PAYMENT_ONLINE` - Entire payment for this item happens as part of the checkout.
          + `FULL_PAYMENT_OFFLINE` - Entire payment for this item happens after the checkout. For example, when using cash, check, or other offline payment methods.
          + `MEMBERSHIP` - Payment for this item is done by charging a membership. When this option is used, `lineItem.price.amount` is 0.
          + `DEPOSIT_ONLINE` -  Partial payment for the given item to be paid upfront during the checkout. Amount to be paid is defined by deposit_amount field.

          **Supported values:**

          - `FULL_PAYMENT_ONLINE` — The entire payment for this item happens as part of the checkout.
          - `FULL_PAYMENT_OFFLINE` — The entire payment for this item happens after checkout. For example, when using cash, check, or other offline payment methods.
          - `MEMBERSHIP` — Payment for this item is done by charging a membership. Any remaining amount not covered by the membership, such as item modifiers, is paid online.
          - `DEPOSIT_ONLINE` — Partial payment to be paid upfront during checkout. The initial amount to be paid for each line item is specified in `depositAmount`.
          - `MEMBERSHIP_OFFLINE` — Payment for this item can only be done by charging a membership and must be manually redeemed in the dashboard by the site admin. When selected, `price` is `0`.
          - `MEMBERSHIP_ONLINE_WITH_OFFLINE_REMAINDER` — Item price is charged to online membership. Any remaining amount not covered by the membership, such as item modifiers, is paid offline.
