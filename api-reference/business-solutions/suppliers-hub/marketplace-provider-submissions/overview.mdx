Marker facade for the marketplace provider submissions host.

Submissions are stateless provider-to-Wix notifications. This message exists
to satisfy the `service_entity` requirement for fqdn-based namespacing.

## SDK package

```bash
npm install @wix/suppliers-hub
```

Import the `marketplaceProviderSubmissions` namespace from `@wix/suppliers-hub`.
