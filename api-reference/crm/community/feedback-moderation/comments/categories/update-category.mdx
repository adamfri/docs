    Updates a category.

    When you update `permissionsSettings`, existing comments remain visible even if they don't meet the updated permissions.

    Each time the category is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the category.
    This ensures you're working with the latest category and prevents unintended overwrites.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="WIX_COMMENTS.CATEGORY_EDIT">WIX_COMMENTS.CATEGORY_EDIT</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/comments/v1/categories/{category.id}
    ```

    ## Path Params

    <ParamField path="category.id" type="string" required>

      Category ID.

    </ParamField>

    ## Body Params

    <ParamField body="category" type="Category" required>

      Category to update, may be partial and include only category ID and the field to change.

      See the [Category Object](/api-reference/crm/community/feedback-moderation/comments/categories/category-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="category" type="Category">

      Updated category.

      See the [Category Object](/api-reference/crm/community/feedback-moderation/comments/categories/category-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
