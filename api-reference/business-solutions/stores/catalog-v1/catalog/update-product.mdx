    Updates specified fields in a product.

    To update a single field across multiple products, use [Bulk Update Product Property](https://dev.wix.com/docs/rest/business-solutions/stores/catalog/bulk-update-product-property).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v1/products/{product.id}
    ```

    ## Path Params

    <ParamField path="product.id" type="string" required>

      Product ID (generated automatically by the catalog).

    </ParamField>

    ## Body Params

    <ParamField body="product" type="Product" required>

      See the [Product Object](/api-reference/business-solutions/stores/catalog-v1/catalog/product-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="product" type="Product">

      See the [Product Object](/api-reference/business-solutions/stores/catalog-v1/catalog/product-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
