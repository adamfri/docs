    Updates tags on multiple suppliers matching filter criteria in a single asynchronous request.

    Use this endpoint for large-scale tag operations across many suppliers based on conditions such as location, verification status, or rating. An empty filter updates all suppliers. The operation returns a job ID for tracking completion status.

    If a tag appears in both `assignTags` and `unassignTags` lists, it will be assigned. Assignment takes precedence. This endpoint has no supplier limit, unlike the synchronous tag update endpoint which is limited to 100 suppliers.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
