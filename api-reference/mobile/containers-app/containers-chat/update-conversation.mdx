    Updates a conversation.

    Each time the conversation is updated, `revision` increments by 1. The current `revision`
    must be passed when updating the conversation. This ensures you're working with the latest
    conversation and prevents unintended overwrites.

    A field mask is required. Only fields included in the mask are updated.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="containers:chat:v1:conversation:update_conversation">containers:chat:v1:conversation:update_conversation</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/containers/chat/v1/conversations/{conversation.id}
    ```

    ## Path Params

    <ParamField path="conversation.id" type="string" required>

      Conversation ID.

    </ParamField>

    ## Body Params

    <ParamField body="conversation" type="Conversation" required>

      Conversation to update. `id` and `revision` are required.

      See the [Conversation Object](/api-reference/mobile/containers-app/containers-chat/conversation-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="conversation" type="Conversation">

      Updated conversation.

      See the [Conversation Object](/api-reference/mobile/containers-app/containers-chat/conversation-object) for this object's fields.

    </ResponseField>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

    <ParamField body="conversation" type="UpdateConversation" required>

      Conversation to update. `id` and `revision` are required.

        <ParamField body="_id" type="string">

          Conversation ID.

          **Read-only.**

        </ParamField>

        <ParamField body="projectId" type="string">

          ID of the project this conversation belongs to.

        </ParamField>

        <ParamField body="sessionId" type="string">

          Agent session ID. Set when a build job begins; used to resume the coding agent session.

        </ParamField>

        <ParamField body="status" type="string">

          Conversation status.

          **Supported values:**

          - `ACTIVE` — The conversation is open and active.
          - `ARCHIVED` — The conversation is archived. Currently not in use.

        </ParamField>

        <ParamField body="title" type="string">

          Conversation title. Currently defaults to `new chat`.

          Constraints: `maxLength 200`.

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the conversation was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the conversation was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the conversation is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the conversation.

          **Read-only.**

        </ParamField>
