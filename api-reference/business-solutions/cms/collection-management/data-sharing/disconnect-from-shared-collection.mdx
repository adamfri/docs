<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Disconnects the current site from a shared data collection.

    This method removes the local view of the shared collection from the current site. Once removed, the collection is no longer accessible through the CMS or Data Items APIs.

    <Note>

    This method doesn't affect the collection on the source site or other target sites that share the collection.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v1/data-collection-sharing/disconnect-from-shared-collection
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" deprecated>

      Shared data collection ID.

      **Deprecated.** Use `target_data_collection_id` instead. Removal: 2026-12-31. Constraints: `maxLength 255`.

    </ParamField>

    <ParamField body="targetDataCollectionId" type="string">

      ID of the shared collection on the target site.

      Constraints: `maxLength 255`.

    </ParamField>

    ## Response Object

    Returns `DisconnectFromSharedCollectionResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0156` | Shared collection not found. Verify the collection ID is correct and that the collection is shared with the current site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Sharing Policy Shared Collection Disconnected | `wix.data.v1.data_sharing_policy_shared_collection_disconnected` | Triggered when a connection is disconnected, which means a collection is removed from the site it was previously shared with. |

    </div>

    <div className="wix-examples">
