Triggered when a post is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.blog.v3.post_created` |
| Package | `@wix/blog` |
| Permissions | `Read Blog`, `Manage Blog`, `Read Draft Blog Posts` |

## Examples

<CodeGroup>

  ```javascript onPostCreated
  import { posts } from '@wix/blog';

  posts.onPostCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onPostCreated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { posts } from '@wix/blog';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        posts,
      },
  });

  wixClient.posts.onPostCreated((event) => {
      // handle your event here
  });
  ```
