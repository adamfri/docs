---
title: "Guest Object"
description: "Gives the information about all guests who bought tickets to an event or who RSVP'ed."
icon: "cube"
---

Gives the information about all guests who bought tickets to an event or who RSVP'ed. Read more about Event Guests in this [overview](https://dev.wix.com/docs/rest/business-solutions/events/event-guests/introduction).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Guest ID.

    </ResponseField>

    <ResponseField name="eventId" type="string">

      Event ID.

    </ResponseField>

    <ResponseField name="rsvpId" type="string">

      RSVP ID. &lt;br/> &lt;br/> **Note:** Only applicable when `guestType` is `"RSVP"`.

    </ResponseField>

    <ResponseField name="orderNumber" type="string">

      Order number. &lt;br/> &lt;br/> **Note:** Only applicable when `guestType` is `"BUYER"` or `"TICKET_HOLDER"`.

    </ResponseField>

    <ResponseField name="ticketNumber" type="string">

      Ticket number. &lt;br/> &lt;br/> **Note:** Only applicable when `guestType` is `"TICKET_HOLDER"`.

    </ResponseField>

    <ResponseField name="tickets" type="TicketDetails[]">

      List of names, numbers, and definition IDs for each ticket.

      Constraints: `maxItems 50`.

      <Expandable title="tickets properties">

        <ResponseField name="number" type="string">

          Ticket number.

          Constraints: `maxLength 36`.

        </ResponseField>

        <ResponseField name="definitionId" type="string">

          Ticket definition ID.

        </ResponseField>

        <ResponseField name="name" type="string">

          Ticket name.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Guest's contact ID. See the Contacts API for more details.

    </ResponseField>

    <ResponseField name="guestDetails" type="GuestDetails">

      Guest details. &lt;br/> &lt;br/> Returned only when the `guestDetails` fieldset is sent in the request.

      <Expandable title="guestDetails properties">

        <ResponseField name="email" type="string">

          Email.

        </ResponseField>

        <ResponseField name="firstName" type="string">

          First name.

        </ResponseField>

        <ResponseField name="lastName" type="string">

          Last name.

        </ResponseField>

        <ResponseField name="formResponse" type="FormResponse">

          Form response.

          <Expandable title="formResponse properties">

            <ResponseField name="inputValues" type="InputValue[]">

              Form field inputs.

              Constraints: `maxItems 200`.

              <Expandable title="inputValues properties">

                <ResponseField name="inputName" type="string">

                  Form field input name.

                  Constraints: `maxLength 100`.

                </ResponseField>

                <ResponseField name="value" type="string">

                  Form field value.

                  Constraints: `maxLength 5000`.

                </ResponseField>

                <ResponseField name="values" type="string[]">

                  Form field values.

                  Constraints: `maxLength 5000`, `maxItems 100`.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="checkedIn" type="boolean">

          Whether the guest has checked into the event.

        </ResponseField>

        <ResponseField name="onlineConferencingLogin" type="OnlineConferencingLogin">

          The login details for the guest to access the online conference event.

          <Expandable title="onlineConferencingLogin properties">

            <ResponseField name="link" type="string">

              Link URL to the online conference.

              **Read-only.** Constraints: `format WEB_URL`.

            </ResponseField>

            <ResponseField name="password" type="string">

              Password for the online conference.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="phone" type="string">

          Phone extracted from form response. If multiples phone inputs are present, first one is returned.

        </ResponseField>

        <ResponseField name="address" type="string">

          Address extracted from form response. If multiples address inputs are present, first one is returned.

        </ResponseField>

        <ResponseField name="checkInDetails" type="GuestCheckInDetails[]">

          Per-guest check-in details. Only present for guests that have check-in history.

          Constraints: `maxItems 50`.

          <Expandable title="checkInDetails properties">

            <ResponseField name="checkedIn" type="boolean">

              Whether this guest is checked in.

            </ResponseField>

            <ResponseField name="checkInDate" type="datetime">

              Date and time the guest checked in.

            </ResponseField>

            <ResponseField name="checkInCanceledDate" type="datetime">

              Date and time the guest canceled check-in.

            </ResponseField>

            <ResponseField name="checkedInBy" type="string">

              ID of the user who last performed check-in.

            </ResponseField>

            <ResponseField name="checkInCanceledBy" type="string">

              ID of the user who last canceled check-in.

            </ResponseField>

            <ResponseField name="checkedInByStaffMember" type="string">

              ID of the staff member who last performed check-in.

            </ResponseField>

            <ResponseField name="checkInCanceledByStaffMember" type="string">

              ID of the staff member who last canceled check-in.

            </ResponseField>

            <ResponseField name="fullName" type="string">

              Full name of the guest. Only set for RSVP guests.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="attendanceStatus" type="string">

      Attendance status. The attendance status updates based on status values in an RSVP object (for RSVP events) or in an Order object (for ticketed events).
      For more information, see [Guest Attendance Status Mapping](https://dev.wix.com/docs/api-reference/business-solutions/events/registration/event-guests/guest-attendance-status-mapping). &lt;br/> &lt;br/> **Note:** For `guestType` of `"BUYER"` or `"TICKET_HOLDER"` the `"IN_WAITLIST"` value is not applicable.

      **Supported values:**

      - `NOT_ATTENDING` — Not attending.
      - `ATTENDING` — Attending.
      - `IN_WAITLIST` — In a waiting list.

    </ResponseField>

    <ResponseField name="secondaryLanguageCode" type="string">

      Secondary language code in [ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) format. Used when the event ticket should be translated into another language.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the guest was created in `yyyy-mm-ddThh:mm:sssZ` format.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the guest was updated in `yyyy-mm-ddThh:mm:sssZ` format.

    </ResponseField>

    <ResponseField name="attendanceStatusUpdatedDate" type="datetime">

      Date and time of guest's latest attendance status update.

    </ResponseField>

    <ResponseField name="memberId" type="string">

      Site member ID.

    </ResponseField>

    <ResponseField name="guestType" type="string">

      Guest type.

      **Supported values:**

      - `RSVP` — An invited guest, no ticket necessary.
      - `BUYER` — The guest who bought the ticket.
      - `TICKET_HOLDER` — The guest for whom the ticket was bought.

    </ResponseField>

    <ResponseField name="locale" type="string">

      Locale in [IETF BCP 47](https://en.wikipedia.org/wiki/IETF_language_tag) format. Used when the event date and time on a ticket should be formatted into another locale.

    </ResponseField>

    <ResponseField name="totalGuests" type="integer">

      Number of total guests in an event (registered guests + additional ones).

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the guest is updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="additionalDetails" type="AdditionalDetails">

      Additional Details

      **Read-only.**

      <Expandable title="additionalDetails properties">

        <ResponseField name="createdDate" type="datetime">

          Date and time the source entity (RSVP or Order) was created.

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the source entity (RSVP or Order) was updated.

        </ResponseField>

        <ResponseField name="rsvpStatus" type="string">

          Rsvp Status

          **Supported values:**

          - `YES` — Guest is attending the event.
          - `NO` — Guest isn't attending the event.
          - `WAITLIST` — Guest is on a waitlist.

        </ResponseField>

        <ResponseField name="orderStatus" type="string">

          Order Status

          **Supported values:**

          - `UNKNOW_ORDER_STATUS` — Order status is not available for this request fieldset.
          - `FREE` — Order is confirmed, no payment is required.
          - `PENDING` — Order was paid, but the payment gateway suspended the payment.
          - `PAID` — Order is paid.
          - `OFFLINE_PENDING` — Order is confirmed but has be paid via offline payment. Status needs to be manually updated to `"PAID"`.
          - `INITIATED` — Order is awaiting for payment at the cashier.
          - `CANCELED` — Order is canceled.
          - `DECLINED` — Order payment is declined.
          - `AUTHORIZED` — Order payment is authorized.
          - `VOIDED` — Order payment is voided.
          - `PARTIALLY_PAID` — Order is partially paid with less than the total amount.

        </ResponseField>

      </Expandable>

    </ResponseField>

      ```json Object
            "tickets":[],
            "guestDetails":
              {
                "email": "patsy.mcbride@mail.com",
                "firstName": "Patsy",
                "lastName": "McBride",
                "formResponse":
                  {
                    "inputValues":
                      [
                        {
                          "inputName": "firstName",
                          "value": "Patsy",
                          "values": []
                          },
                        {
                          "inputName": "lastName",
                          "value": "McBride",
                          "values": []
                        },
                        {
                          "inputName": "email",
                          "value": "patsy.mcbride@mail.com",
                          "values": []
                        }
                      ]
                  },
                "checkedIn": false
            },
            "contactId": "023b6403-17e6-42dc-b475-a5ae6c2b8df4",
            "attendanceStatus": "IN_WAITLIST",
            "createdDate": "2023-01-10T13:22:23.302Z",
            "updatedDate": "2023-01-10T13:22:23.302Z",
            "attendanceStatusUpdatedDate": "2023-01-10T13:22:23Z",
            "guestType": "RSVP",
            "totalGuests": 1,
            "revision": 1
          }
        ]
      }
      ```
