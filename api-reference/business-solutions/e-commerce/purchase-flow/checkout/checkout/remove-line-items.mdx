    Removes line items from the specified checkout.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkouts/{id}/remove-line-items
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the checkout to remove line items from.

    </ParamField>

    ## Body Params

    <ParamField body="lineItemIds" type="string[]" required>

      IDs of the line items to remove from the checkout.

      To find the IDs of the checkout line items you'd like to remove,
      pass the checkout ID to Get Checkout and look for the IDs under
      `lineItems`.

      Constraints: `format GUID`, `minItems 1`, `maxItems 300`.

    </ParamField>

    ## Response Object

    <ResponseField name="checkout" type="Checkout">

      Updated checkout after removal of line items.

      See the [Checkout Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout/checkout-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Updated | `wix.ecom.v1.checkout_updated` | Triggered when a checkout is updated. |

    </div>
