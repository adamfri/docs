    Applies a coupon to a join application's payment order to reduce the payment amount.

    `paymentStatus` must be `PAYMENT_IN_PROGRESS`, `PAYMENT_FAILED`, or `PAYMENT_CANCELED`. The last two let a member apply or change a coupon when retrying after a failed or canceled payment.

    Returns the order totals with the discount applied. An order supports a single coupon, so remove the current coupon before applying a different one.

    To remove the coupon, call [Remove Coupon](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/remove-coupon). If the coupon covers the full amount, call [Complete Free Coupon Payment](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/complete-free-coupon-payment) to finish without a paid checkout.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}/apply-coupon
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to apply the coupon to.

    </ParamField>

    ## Body Params

    <ParamField body="couponCode" type="string" required>

      Coupon code to apply.

      Constraints: `maxLength 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="couponId" type="string">

      ID of the applied coupon.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="subTotal" type="string">

      Order subtotal before the discount, formatted using the precision of the site currency configured in Site Properties. The value doesn't include the currency.

      Constraints: `maxLength 50`.

    </ResponseField>

    <ResponseField name="discount" type="string">

      Discount applied to the order, formatted using the precision of the site currency configured in Site Properties. The value doesn't include the currency.

      Constraints: `maxLength 50`.

    </ResponseField>

    <ResponseField name="total" type="string">

      Order total after the discount, formatted using the precision of the site currency configured in Site Properties. The value doesn't include the currency.

      Constraints: `maxLength 50`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_PAYMENT_ORDER` | No payment order exists for the join application. Call Prepare Payment first. |
    | `428` | `FAILED_PRECONDITION` | `COUPON_IS_ALREADY_APPLIED` | A coupon is already applied to the payment order. |
    | `428` | `FAILED_PRECONDITION` | `COUPON_DOES_NOT_EXIST` | No coupon matches the specified coupon code. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_PAYMENT_STATUS` | The join application's `paymentStatus` doesn't permit applying a coupon. Allowed from `PAYMENT_IN_PROGRESS`, `PAYMENT_FAILED`, and `PAYMENT_CANCELED`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
