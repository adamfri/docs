---
title: "Bulk Download Object"
description: "A bulk download contains the download information to retrieve items in the Get Paid APIs."
icon: "cube"
---

A bulk download contains the download information to retrieve items in the Get Paid APIs.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Bulk download ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the bulk download is updated.
      To prevent conflicting changes, the current `revision` must be passed when updating the bulk download.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the bulk download was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the bulk download was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="expirationDate" type="datetime">

      Date and time the bulk download expires.

      The .zip file is available for download with the `downloadUrl` until this time.

      Default expiration date is 24 hours after creation.

      **Read-only.**

    </ResponseField>

    <ResponseField name="downloadGenerationStatus" type="string">

      Status of the bulk download generation.

      **Read-only.**

      **Supported values:**

      - `UNKNOWN_DOWNLOAD_STATUS` — Unknown download status.
      - `PROCESSING` — Generation is in progress.
      - `PARTIAL_SUCCESS` — Generation was successful for some, but not all, entities. Check `skippedEntityIds` for entities not included. The `downloadUrl` is available to download the .zip file containing the successfully generated entities.
      - `SUCCESS` — Generation was successful. The .zip file is ready for download using the `downloadUrl`.
      - `FAILED` — Generation has failed.

    </ResponseField>

    <ResponseField name="downloadUrl" type="string">

      URL to download the generated .zip file. Open this URL in a browser to download the file.

      Only available when the `downloadGenerationStatus` is `"PARTIAL_SUCCESS"` or `"SUCCESS"`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="namespace" type="string">

      App namespace. Currently only supports `"RECEIPTS"`.

      Constraints: `immutable`.

      **Supported values:**

      - `UNKNOWN_NAMESPACE` — Unknown namespace.
      - `RECEIPTS` — Receipts ([SDK](https://dev.wix.com/docs/sdk/backend-modules/get-paid/receipts/about-the-receipts-apis) | [REST](https://dev.wix.com/docs/rest/business-management/get-paid/receipts/about-the-receipts-apis)).

    </ResponseField>

    <ResponseField name="entityIds" type="string[]">

      List of IDs of the entities to include in the bulk download.

      Constraints: `format GUID`, `minItems 2`, `maxItems 100`, `immutable`.

    </ResponseField>

    <ResponseField name="skippedEntityIds" type="string[]">

      IDs of the entities that aren't included in the .zip file.

      If `downloadGenerationStatus` is `"PARTIAL_SUCCESS"` then these entities may still be included once the initiated download is complete.
      If the value of `downloadGenerationDetails.processed` matches `downloadGenerationDetails.total` then all of the entities have been processed and
      the skipped entities aren't included in the bulk download.

      **Read-only.** Constraints: `format GUID`, `maxItems 100`.

    </ResponseField>

    <ResponseField name="downloadGenerationDetails" type="DownloadGenerationDetails">

      Details about the number of files processed.

      **Read-only.**

      <Expandable title="downloadGenerationDetails properties">

        <ResponseField name="processed" type="integer">

          Number of files that have been processed.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of files to process.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
