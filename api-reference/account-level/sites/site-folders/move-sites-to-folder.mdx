    <div className="wix-ref">

    Moves sites into a specific folder/root.
    Limited to 500 sites per request.
    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="site-actions.move-site-to-folder">site-actions.move-site-to-folder</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-folders/v2/folders/bulk/sites/move
    ```

    ## Body Params

    <ParamField body="targetFolderId" type="string">

      Folder ID.
      Empty when moving sites to root level.

      Constraints: `maxLength 36`.

    </ParamField>

    <ParamField body="sites" type="object" required>

      Sites to move.
      Currently supports only site IDs and is limited to 500 sites.
      For example: `{ "id": { "$in": ["<siteId1>", "<siteId2>", ...] } }`.

    </ParamField>

    ## Response Object

    Returns `object`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `folder_not_found` | Couldn't find the specified folder. |
    | `400` | `INVALID_ARGUMENT` | `metasite_ids_count_exceeded` | The number of site IDs exceeds the server's limit of 500 sites. |
    | `400` | `INVALID_ARGUMENT` | `invalid_move_spec` | The move specification is invalid. Ensure you're providing valid site IDs and a valid target folder ID. |
    | `400` | `INVALID_ARGUMENT` | `malformed_filter` | The filter is malformed. Check the filter syntax and try again. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
