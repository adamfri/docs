    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a service plugin configuration.

    Each time the service plugin configuration is updated, its `revision` increases by 1.
    The current `revision` must be passed when updating the service plugin configuration.
    This ensures you're working with the latest service plugin configuration
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/functions/v1/function-spi-configurations/{functionSpiConfiguration.id}
    ```

    ## Path Params

    <ParamField path="functionSpiConfiguration.id" type="string" required>

      Service plugin configuration ID.

    </ParamField>

    ## Body Params

    <ParamField body="functionSpiConfiguration" type="FunctionSpiConfiguration" required>

      Service plugin configuration to update.

      See the [Spi Configuration Object](/api-reference/business-management/functions/function-spi-configurations/spi-configuration-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="functionSpiConfiguration" type="FunctionSpiConfiguration">

      Updated service plugin configuration.

      See the [Spi Configuration Object](/api-reference/business-management/functions/function-spi-configurations/spi-configuration-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
