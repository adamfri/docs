    Updates or creates an email subscription for the requested email.

    An email subscription is returned in the response
    whether it was updated or created.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MANAGE.EMAIL-SUBSCRIPTIONS">Manage Email Subscriptions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/email-subscriptions
    ```

    ## Body Params

    <ParamField body="subscription" type="EmailSubscription">

      Email subscription to update or create.

      See the [Emailsubscription Object](/api-reference/crm/communication/email-subscriptions/emailsubscription-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="subscription" type="EmailSubscription">

      Updated or created email subscription.

      See the [Emailsubscription Object](/api-reference/crm/communication/email-subscriptions/emailsubscription-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
