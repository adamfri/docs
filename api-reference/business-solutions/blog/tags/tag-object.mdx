---

The `Tags` object represents the information for blog tags.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Tag ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="label" type="string">

      Tag label.

      A blog can't have two tags with the same label.

      Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="slug" type="string">

      Part of a tag's URL that refers to a specific tag.

      For example, `'https:/example.com/tags/{my-tag-slug}'`

      Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date the tag was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date the tag was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="postCount" type="integer" deprecated>

      Number of posts with this tag. Includes unpublished draft posts.

      **Read-only.** **Deprecated.** Number of posts with this tag. Includes unpublished draft posts. Use `published_post_count` instead. Removal: 2026-10-29. Constraints: `min 0`.

    </ResponseField>

    <ResponseField name="url" type="PageUrl">

      Tag URL.

      The `url` directs you to a page that lists every post with the specified tag.

      **Read-only.**

      <Expandable title="url properties">

        <ResponseField name="base" type="string">

          The base URL. For premium sites, this is the domain. For free sites, this is the site URL. For example, `mysite.wixsite.com/mysite`.

        </ResponseField>

        <ResponseField name="path" type="string">

          The relative path for the page within the site. For example, `/product-page/a-product`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="publishedPostCount" type="integer">

      Number of published posts with this tag.

      **Read-only.** Constraints: `min 0`.

    </ResponseField>

    <ResponseField name="translationId" type="string">

      ID of the tag's translations when [Wix Multilingual](https://support.wix.com/en/article/wix-multilingual-translating-your-blog) is installed on a site.

      All translations of a single tag share the same `translationId`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="language" type="string">

      Tag language.

      2-or-4-letter language code in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "tag": {
          "id": "33b7a30f-ca8a-4678-84c4-0bab5e3ebf63",
          "label": "vacation",
          "slug": "vacation",
          "createdDate": "2021-06-21T08:27:09.764Z",
          "updatedDate": "2021-06-21T08:27:09.764Z",
          "publicationCount": 3,
          "postCount": 10,
          "language": "fr"
        }
      }
      ```

    </CodeGroup>
