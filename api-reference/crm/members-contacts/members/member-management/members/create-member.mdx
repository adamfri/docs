    <div className="wix-ref">

    Creates a site member.

    After creation, you can call
    [Send Set Password Email](https://dev.wix.com/docs/rest/crm/members-contacts/members/member-authentication/send-set-password-email)
    to email the member with a link to set their password.
    The member can log in to the site
    when they set their password for the first time.

    <Note>

    When creating multiple members,
    set your requests at least 1 second apart to keep below rate limits.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/members
    ```

    ## Body Params

    <ParamField body="member" type="Member">

      Member to create.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      New member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Member Created | `wix.members.v1.member_created` | Triggered when a member is created. The site owner can configure the site to automatically approve members or require manual approval. A member who has been approved either automatically or manually has a `status` of `"APPROVED"`. A created member waiting for approval has a `status` of `"PENDING"`. A `"PENDING"` member can't log in to the site. |

    </div>

    import { members } from '@wix/members';
    import { webMethod, Permissions } from '@wix/web-methods';
    import { auth } from '@wix/essentials';
    import { items } from '@wix/data';

    const elevatedCreateMember = auth.elevate(members.createMember);

    export const myCreateMemberFunction = webMethod(
        Permissions.Anyone,
        async (member) => {
          try {
            const newMember = await elevatedCreateMember(member);
            console.log('Created new member:', newMember);
            return newMember;
          } catch (error) {
            console.error();
            // Handle the error
          }
        }
      );

    export const importMembersFromCollection = webMethod(
      Permissions.Anyone, 
      async function (collectionId) {
        try {
          let membersToImport = [];
          let currentPage = await items.query(collectionId).limit(1).find();
