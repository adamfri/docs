    Creates an intake form.

    The owner (`userId`) and `accountId` are set automatically from the caller's
    identity. Any values you provide for these fields are ignored.

    To create multiple intake forms in a single request, call [Bulk Create Intake Forms](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/bulk-create-intake-forms).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.CONTENT-COLLECTOR">SCOPE.PARTNERS.CONTENT-COLLECTOR</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/content-collector/v1/intake-forms
    ```

    ## Body Params

    <ParamField body="intakeForm" type="IntakeForm" required>

      IntakeForm to be created.

      See the [Intake Form Object](/api-reference/account-level/studio-workspace/content-collector/intake-form-v1/intake-form-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `CONTEXT`
      - `SOURCE_MATERIALS`
      - `INTRO_DATA`

    </ParamField>

    ## Response Object

    <ResponseField name="intakeForm" type="IntakeForm">

      The created IntakeForm.

      See the [Intake Form Object](/api-reference/account-level/studio-workspace/content-collector/intake-form-v1/intake-form-object) for this object's fields.

    </ResponseField>
