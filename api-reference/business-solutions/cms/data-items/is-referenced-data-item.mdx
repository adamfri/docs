    <div className="wix-ref">

    Checks whether a field in a referring item contains a reference to a specified item.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.READ">Read Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/items/is-referenced
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection containing the referring data item.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="referringItemFieldName" type="string" required>

      Field to check for a reference to the item that may be referenced.

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField body="referringItemId" type="string" required>

      ID of the referring item.

      Constraints: `maxLength 128`.

    </ParamField>

    <ParamField body="referencedItemId" type="string" required>

      ID of the item that may be referenced.

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField body="consistentRead" type="boolean">

      Whether to retrieve data from the primary database instance.
      This decreases performance but ensures data retrieved is up to date even immediately after an update.
      Learn more about [Wix Data and eventual consistency](https://dev.wix.com/api/rest/wix-data/wix-data/eventual-consistency).

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="isReferenced" type="boolean">

      Whether the specified reference exists.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
