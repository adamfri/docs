---
title: "Partner Profile Object"
description: "Represents a Wix Partner's editable profile in the partner directory."
icon: "cube"
---

Represents a Wix Partner's editable profile in the partner directory. Partners use this entity to manage their own professional information, services offered, portfolio items, and contact details. Once a partner's updates pass verification, a new [PublicPartnerProfile] is published for unauthenticated public viewing. Read/write access to this entity is restricted to the authenticated partner who owns the profile.

    </ResponseField>

      Revision number, which increments by 1 each time the partner profile is updated. To prevent conflicting changes, the current revision must be passed when updating the partner profile.

      **Read-only.**

    </ResponseField>

      Date and time the partner profile was last updated.

      **Read-only.**

            </ResponseField>

        <ResponseField name="city" type="string">

        </ResponseField>

        <ResponseField name="postalCode" type="string">

        <ResponseField name="addressLine2" type="string">

          Free text providing more detailed address info. Usually contains Apt, Suite, and Floor.

        </ResponseField>

      </Expandable>

              <Expandable title="streetAddress properties">

                  Street number.

                  Street name.

                </ResponseField>

            </ResponseField>

            <ResponseField name="addressLine" type="string">

            </ResponseField>

          </Expandable>

    <ResponseField name="professionalInformation" type="ProfessionalInformation">

      Professional details about the partner, including business name, website, social media links, and contact email.

          Partner's business or agency name.

        </ResponseField>

        <ResponseField name="businessWebsite" type="string">

          URL of the partner's business website.

        </ResponseField>

        <ResponseField name="tagline" type="string">

          Short headline displayed on the partner's profile page.

        </ResponseField>

        <ResponseField name="about" type="string">

          Free-text description of the partner's business, background, and areas of expertise.

        </ResponseField>

        <ResponseField name="profileImage" type="string">

          URL of the partner's profile image.

        </ResponseField>

        <ResponseField name="email" type="string">

          Partner's public contact email address, displayed on the profile page. This isn't the partner's Wix login email.

        </ResponseField>

        <ResponseField name="socials" type="Socials">

          Partner's social media profile links.

          <Expandable title="socials properties">

            <ResponseField name="facebook" type="string">

              URL of the partner's Facebook page.

            </ResponseField>

            <ResponseField name="linkedIn" type="string">

              URL of the partner's LinkedIn page.

            </ResponseField>

            <ResponseField name="instagram" type="string">

              URL of the partner's Instagram page.

            </ResponseField>

            <ResponseField name="pinterest" type="string">

              URL of the partner's Pinterest page.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="schedulingLink" type="string" />

      </Expandable>

    </ResponseField>

    <ResponseField name="portfolio" type="Portfolio">

      Partner's portfolio of completed client work. Each item references a Wix site the partner built.

      <Expandable title="portfolio properties">

        <ResponseField name="items" type="PortfolioItem[]">

          <Expandable title="items properties">

            <ResponseField name="metaSiteId" type="string">

              ID of the Wix site featured in this portfolio item.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="customImage" type="string">

              URL of a custom thumbnail image for this portfolio item. When set, overrides the site's auto-generated screenshot.

            </ResponseField>

            <ResponseField name="hidden" type="boolean">

              Whether this portfolio item is hidden from the partner's profile page. Hidden items are still returned in API responses.

            </ResponseField>

            <ResponseField name="siteName" type="string">

              Display name of the Wix site. Can be customized to differ from the actual site title.

            </ResponseField>

            <ResponseField name="description" type="string">

              Description of this portfolio item.

            </ResponseField>

            <ResponseField name="sitePlatform" type="string">

              Platform used to build this site.

              **Supported values:**

              - `WIX` — Site built using the classic Wix Editor.
              - `STUDIO` — Site built using Wix Studio.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="slug" type="string">

      URL-friendly identifier used in the partner's public profile page URL. For example, `acme-studio`. Auto-generated from `professionalInformation.businessName` when the profile is created. Can be changed via the API.

    </ResponseField>

    <ResponseField name="platforms" type="Platforms">

      Wix platform products the partner works with.

      <Expandable title="platforms properties">

        <ResponseField name="wix" type="boolean">

          Partner builds sites using the classic Wix Editor.

        </ResponseField>

        <ResponseField name="studio" type="boolean">

          Partner builds sites using Wix Studio.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="euValid" type="boolean">

      Whether this partner is verified as compliant with EU regulations. When `true`, you can display an EU compliance indicator on the partner's profile. Set automatically based on the partner's country and EU trader traceability status. When absent, EU compliance isn't applicable for this partner.

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayConfiguration" type="DisplayConfiguration">

      Partner-controlled display settings for the profile page.

      <Expandable title="displayConfiguration properties">

        <ResponseField name="hideTemplatesSection" type="boolean">

          Whether to hide the templates section from the partner's public profile page.

        </ResponseField>

        <ResponseField name="hideAppsSection" type="boolean">

          Whether to hide the apps section from the partner's public profile page.

        </ResponseField>

        <ResponseField name="servicesDisplayOrder" type="string[]">

          Ordered list of service IDs controlling the display order of the partner's services on their profile page.

          Constraints: `format GUID`, `maxItems 100`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="validation" type="Validation">

      Content verification status of this profile. Updated automatically after each change. Only changes that pass verification are reflected in the corresponding public partner profile.

      **Read-only.**

      <Expandable title="validation properties">

        <ResponseField name="validationStatus" type="string">

          Current status of content verification.

          **Supported values:**

          - `PENDING_VALIDATION` — Profile content is awaiting verification.
          - `VALID` — Profile content has passed verification and is published to the public directory.
          - `NOT_VALID` — Profile content failed verification. See `failedValidationReasons` for details. To resolve, update the profile with corrected content.

        </ResponseField>

        <ResponseField name="failedValidationReasons" type="FailedValidationReason[]">

          List of specific reasons if validation failed, each identifying the affected field and failure category.

          Constraints: `maxItems 100`.

          <Expandable title="failedValidationReasons properties">

            <ResponseField name="failureReason" type="string">

              The category of validation failure.

              **Supported values:**

              - `OFFENSIVE_CONTENT` — Profile content contains offensive or inappropriate language.
              - `MALICIOUS_CODE` — Profile content contains malicious code.
              - `ERROR` — A system error occurred during verification.
              - `COMPETITION` — Profile content references a Wix competitor product or service.
              - `HTTP_ERROR` — The partner's website URL couldn't be reached during verification.

            </ResponseField>

            <ResponseField name="description" type="string">

              Human-readable explanation of why this validation failed.

            </ResponseField>

            <ResponseField name="field" type="string">

              The partner profile field that triggered this validation failure. For example, `professionalInformation.about`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="hideFromDirectory" type="boolean">

      Whether the partner has opted out of appearing in the Partner Directory listing. The public partner profile remains accessible via the API regardless of this setting.

    </ResponseField>

    <ResponseField name="languages" type="string[]">

      Languages the partner works in. Each value is a language code in BCP 47 format. For example, `en` for English or `fr-CA` for Canadian French.

      Constraints: `format LANGUAGE`, `maxItems 100`.

    </ResponseField>

    <ResponseField name="scheduling" type="SchedulingLink">

      Link allowing site visitors to schedule a meeting with the partner.

      <Expandable title="scheduling properties">

        <ResponseField name="name" type="string">

          Display label for the scheduling link as it appears on the partner's profile page. For example, `Book a free consultation`.

        </ResponseField>

        <ResponseField name="link" type="string">

          URL for booking a meeting with the partner.

        </ResponseField>

      </Expandable>

    </ResponseField>
