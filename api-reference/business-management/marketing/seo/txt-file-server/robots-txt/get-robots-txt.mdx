    <div className="wix-ref">

    Retrieves the `robots.txt` file entity.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote-seo-robots-server/v2/robots
    ```

    ## Query Params

    <ParamField query="subdomain" type="string">

      Subdomain of the requested `robots.txt file`. For example, `www`, `es`, `fr`. Default: `www`.

    </ParamField>

    ## Response Object

    <ResponseField name="robotsTxt" type="RobotsTxt">

      Retrieved `robots.txt` file entity.

      See the [Robots Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/robots-txt/robots-txt-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | — | Site ID is missing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
