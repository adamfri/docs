    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a program definition.

    Each time the program definition is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the program definition.
    This ensures you're working with the latest program definition
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/benefit-programs/v1/program-definitions/{programDefinition.id}
    ```

    ## Path Params

    <ParamField path="programDefinition.id" type="string" required>

      Program definition ID.

    </ParamField>

      Updated program definition.

      See the [Program Definition Object](/api-reference/business-solutions/benefit-programs/program-definitions/program-definition-object) for this object's fields.

    </ResponseField>
