A record of all payments and refunds associated with an order.

Use order transactions to track payment status, add payment records, process refunds, and monitor chargebacks.

## SDK package

```bash
npm install @wix/ecom
```

Import the `orderTransactions` namespace from `@wix/ecom`.

  <Card title="List Transactions For Single Order" href="/api-reference/business-solutions/e-commerce/orders/order-transactions/list-transactions-for-single-order">

  <Card title="List Transactions For Multiple Orders" href="/api-reference/business-solutions/e-commerce/orders/order-transactions/list-transactions-for-multiple-orders">
