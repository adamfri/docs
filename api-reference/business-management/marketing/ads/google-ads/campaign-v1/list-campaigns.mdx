    Retrieves all campaigns associated with the current site.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/campaigns
    ```

    ## Response Object

    <ResponseField name="campaigns" type="Campaign[]">

      All campaigns associated with the site. Maximum 1,000 items.

      Constraints: `maxItems 1000`.

      See the [Campaign Object](/api-reference/business-management/marketing/ads/google-ads/campaign-v1/campaign-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACCOUNT_NOT_FOUND` | Couldn't find the Google Ads account. |
    | `428` | `FAILED_PRECONDITION` | `ACCOUNT_CANCELED` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
