<span className="wix-method wix-method-put">PUT</span>

<Tabs>

  <Tab title="REST">

    Creates rules if no rules have been set up. Otherwise, replaces all existing rules.

    <Note>

    + Only group admins can create or replace rules.
    + This endpoint requires [visitor or member authentication](https://dev.wix.com/docs/rest/articles/getting-started/access-types-and-permissions).

    </Note>

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/social-groups/v2/rules/{groupId}
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Body Params

    <ParamField body="rules" type="GroupRule[]">

      New rules.

      Constraints: `maxItems 100`.

      <Expandable title="rules properties">

        <ParamField body="title" type="string">

          Rule title.

        </ParamField>

        <ParamField body="description" type="string">

          Rule description.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="groupId" type="string">

      Group ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="rules" type="GroupRule[]">

      Rules.

      Constraints: `maxItems 100`.

      <Expandable title="rules properties">

        <ResponseField name="title" type="string">

          Rule title.

        </ResponseField>

        <ResponseField name="description" type="string">

          Rule description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | --- | --- | --- |
    | Group Rules Updated | `wix.social_groups.v2.group_rules_updated` | Triggered when rules are updated. |
