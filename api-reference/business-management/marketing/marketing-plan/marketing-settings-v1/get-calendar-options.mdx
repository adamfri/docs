    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-settings/calendar-options
    ```

    ## Response Object

    <ResponseField name="options" type="CalendarOption[]">

      Selectable calendar options, ordered for display.

      Constraints: `minItems 0`, `maxItems 50`.

      <Expandable title="options properties">

        <ResponseField name="id" type="string">

          Unique ID of this calendar option.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Display name of the calendar in the account's language.

        </ResponseField>

        <ResponseField name="categories" type="string[]">

          Classification tags for the calendar (country-specific, religion-specific, or recommended).

          Constraints: `minItems 0`, `maxItems 10`.

          **Supported values:**

          - `COUNTRY` — Holidays and events specific to a country.
          - `RELIGION` — Observances tied to a religious tradition.
          - `RECOMMENDED` — Calendars recommended as a good starting point.

        </ResponseField>

        <ResponseField name="description" type="string">

          Short description of what events this calendar covers.

        </ResponseField>

      </Expandable>

    </ResponseField>
