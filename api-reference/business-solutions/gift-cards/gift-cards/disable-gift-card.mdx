    <div className="wix-ref">

    Disables a gift card, preventing it from being used for purchases.

    Use this method for customer service actions, fraud prevention, or when
    gift cards need to be deactivated due to policy violations. Disabled
    gift cards cannot be re-enabled and their balance becomes inaccessible.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gift-cards/v1/gift-cards/{giftCardId}/disable
    ```

    ## Path Params

    <ParamField path="giftCardId" type="string" required>

      Gift card ID.

    </ParamField>

    ## Response Object

    <ResponseField name="giftCard" type="GiftCard">

      Disabled gift card with updated disable date.

      See the [Gift Card Object](/api-reference/business-solutions/gift-cards/gift-cards/gift-card-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `GIFT_CARD_NOT_FOUND` |  |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_DISABLED` |  |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_EXPIRED` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
