    Accepts liability for a dispute, indicating the merchant agrees with the customer's claim.

    When a dispute is accepted, the refund is processed automatically.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/disputes/v1/disputes/{disputeId}/accept
    ```

    ## Path Params

    <ParamField path="disputeId" type="string" required>

      ID of the dispute to accept.

    </ParamField>

    ## Response Object

    <ResponseField name="dispute" type="Dispute">

      Updated dispute after acceptance.

      See the [Dispute Object](/api-reference/business-management/payments/disputes/disputes/dispute-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
