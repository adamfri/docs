<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a folder and moves its content to the parent folder (or to root level if no parent folder exists).
    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="folders.delete, FOLDERS.MOVE">folders.delete, FOLDERS.MOVE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/site-folders/v2/folders/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Folder ID.

    </ParamField>

    ## Response Object

    Returns `object`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `folder_not_found` | Couldn't find the specified folder. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Folder Deleted | `wix.site_folders.v2.folder_deleted` | Triggered when a folder is deleted. |

    </div>
