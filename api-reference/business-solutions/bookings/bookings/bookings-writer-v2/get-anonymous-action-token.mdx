    Generates an anonymous action token for a booking.

    The generated token is an encrypted, URL-safe string that authorizes booking actions without authentication. Specify the token when calling other methods in this API to retrieve, cancel, or reschedule the booking without authentication.

    This is the only method in this API that requires authentication.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/anonymous-bookings/{bookingId}/token
    ```

    ## Path Params

    <ParamField path="bookingId" type="string" required>

      Booking ID.

    </ParamField>

    ## Response Object

    <ResponseField name="token" type="string">

      Encrypted, URL-safe token for anonymous access to the booking.
      Pass this token to the other methods in this API to retrieve, cancel, or reschedule the booking without authentication.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `BOOKING_NOT_FOUND` | Couldn't find the booking with the specified ID. |
    | `428` | `FAILED_PRECONDITION` | `FAILED_GENERATING_TOKEN` | Failed to generate the token for the specified booking. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
