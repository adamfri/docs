Wix provides templates for different site types and styles. You can specify a template ID when calling [Create Project](fallback::https://dev.wix.com/docs/rest/account-level/projects/project-v1/create-project) to create a Wix site with that template's layout.  

The tables below list some examples of site template IDs organized by type and style.
