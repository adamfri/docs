    Retrieves the site's search performance data from Google Search Console.

    Returns clicks, impressions, click-through rate, and average position,
    grouped by the requested dimensions. For example, group by `date` for a
    daily chart, or by `query` for top search terms.

    The data is Google Search Console's search performance report for the
    site, so its freshness and history range follow Google Search Console.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gsc/v1/search-analytics
    ```

    ## Query Params

    <ParamField query="startDate" type="string" required>

      First day of the requested period, in `YYYY-MM-DD` format.

      Constraints: `maxLength 10`.

    </ParamField>

    <ParamField query="endDate" type="string" required>

      Last day of the requested period, in `YYYY-MM-DD` format. Inclusive.

      Constraints: `maxLength 10`.

    </ParamField>

    <ParamField query="dimensions" type="string[]">

      Dimensions to group the results by, in the order they should appear in
      each result's `keys`. Supported values are Google Search Console's search
      analytics dimensions: `date`, `query`, `page`, `country`, `device`,
      `searchAppearance`.

      Default: no grouping, a single aggregate row for the whole period.

      Constraints: `maxLength 50`, `maxItems 10`.

    </ParamField>

    <ParamField query="type" type="string">

      Search type to report on. Supported values: `web`, `image`, `video`,
      `news`.

      Default: `web`.

      Constraints: `maxLength 20`.

    </ParamField>

    <ParamField query="rowLimit" type="integer">

      Maximum number of rows to return.

    </ParamField>

    <ParamField query="startRow" type="integer">

      Zero-based index of the first row to return. Use with `rowLimit` to page
      through large result sets.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="SearchAnalyticsResult[]">

      Search performance rows, one per combination of the requested dimensions.

      Constraints: `maxItems 10000`.

      <Expandable title="results properties">

        <ResponseField name="keys" type="string[]">

          Values of the requested dimensions, in the order the dimensions were
          requested. For example, for `dimensions: ["date"]`, the row's date.

          **Read-only.** Constraints: `maxLength 5000`, `maxItems 10`.

        </ResponseField>

        <ResponseField name="clicks" type="number">

          Number of clicks from Google Search results.

          **Read-only.**

        </ResponseField>

        <ResponseField name="impressions" type="number">

          Number of times the site appeared in Google Search results.

          **Read-only.**

        </ResponseField>

        <ResponseField name="ctr" type="number">

          Click-through rate: `clicks / impressions`, between 0 and 1.

          **Read-only.**

        </ResponseField>

        <ResponseField name="position" type="number">

          Average position of the site's topmost result, where 1 is the first
          position.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_TOKEN` | No Google account is connected for this site. Connect first with the GSC Connection API. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_URL` | The site's public URL couldn't be resolved. For example, the site isn't published yet. |
    | `429` | `RESOURCE_EXHAUSTED` | `GOOGLE_QUOTA_EXCEEDED` | Google's API quota for the property is used up. Retry after the quota window resets. |
    | `503` | `UNAVAILABLE` | `GOOGLE_UNAVAILABLE` | Google answered with a temporary server error. Retry with backoff. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
