---
title: "Sending Domain Object"
description: "A sending domain is a custom domain that's authenticated for sending emails from a Wix site."
icon: "cube"
---

A sending domain is a custom domain that's authenticated for sending emails from a Wix site. While it's possible to send emails without authentication, unauthenticated emails will either show the Wix domain to recipients or use the Wix domain as the **From** address with the Wix user's email as the **Reply-To** address. Authenticating a sending domain allows emails to use a custom domain in the **From** field, improving email deliverability and helping establish domain reputation for email campaigns and transactional emails.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Sending domain ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the sending domain was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="domain" type="string">

      Domain name to authenticate for sending emails. For example, `example.com`.

      Constraints: `format HOSTNAME`, `minLength 4`, `maxLength 64`, `immutable`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Authentication status. Indicates whether the domain is ready for sending emails.

      **Read-only.**

      **Supported values:**

      - `INITIALIZING` — Domain is being set up. DNS records are being generated. Wait for this to change to NOT_AUTHENTICATED before proceeding.
      - `NOT_AUTHENTICATED` — Domain is ready to be authenticated. DNS records are available in dnsRecords. Add these records at the DNS provider, then call [Authenticate Sending Domain](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/sending-domains/authenticate-sending-domain) to verify them.
      - `AUTHENTICATED` — Domain is authenticated and ready for sending emails. This domain can now be used in the **From** field for email campaigns and transactional emails.

    </ResponseField>

    <ResponseField name="dnsRecords" type="DnsRecord[]">

      DNS records required to authenticate the domain. These records must be added to the domain's DNS configuration at the DNS provider (such as GoDaddy, Cloudflare, or Namecheap) to verify domain ownership and enable email sending.

      To authenticate the domain, add these records at the DNS provider and use DNS lookup tools (such as `dig` or online DNS checkers) to verify the records are visible globally. Then call [Authenticate Sending Domain](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/sending-domains/authenticate-sending-domain).

      **Read-only.** Constraints: `maxItems 5`.

      <Expandable title="dnsRecords properties">

        <ResponseField name="hostName" type="string">

          Hostname for the DNS record. Add this as the subdomain or record name at the DNS provider.

          Constraints: `format HOSTNAME`.

        </ResponseField>

        <ResponseField name="value" type="string">

          Value for the DNS record. Add this as the target value at the DNS provider.

          Constraints: `format HOSTNAME`.

        </ResponseField>

        <ResponseField name="type" type="string">

          DNS record type.

          **Supported values:**

          - `CNAME` — CNAME record for domain authentication.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
