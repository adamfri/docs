    <div className="wix-ref">

    <Note>

    The Item API only works with the Wix Restaurants Menus app. Make sure you have installed this app from the [Wix App Market](https://www.wix.com/app-market/wix-restaurants-menus-new).

    </Note>

    Retrieves a list of up to 500 items.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/menus/v1/items
    ```

    ## Query Params

    <ParamField query="itemIds" type="string[]">

      Item IDs.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      The metadata of the paginated results.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="onlyVisible" type="boolean">

      Whether to return only items that are visible to site visitors.

    </ParamField>

    ## Response Object

    <ResponseField name="items" type="Item[]">

      Items.

      See the [Item Object](/api-reference/business-solutions/restaurants/menus/items/items/item-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      The metadata of the paginated results.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Offset that was requested.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
