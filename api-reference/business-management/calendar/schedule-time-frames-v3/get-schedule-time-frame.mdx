    <div className="wix-ref">

    Retrieves a schedule time frame by schedule ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PUBLIC">Read Calendar</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/calendar/v3/schedules/timeframe/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      [Schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/schedule-object)
      ID for which to retrieve the schedule time frame.

    </ParamField>

    ## Query Params

    <ParamField query="timeZone" type="string">

      Time zone for adjusting the times of the returned schedule time frame.

      Default: `timeZone` of the [site properties](https://dev.wix.com/docs/rest/business-management/site-properties/properties/properties-object)

    </ParamField>

    ## Response Object

    <ResponseField name="scheduleTimeFrame" type="ScheduleTimeFrame">

      Retrieved schedule time frame.

      See the [Schedule Time Frame Object](/api-reference/business-management/calendar/schedule-time-frames-v3/schedule-time-frame-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
