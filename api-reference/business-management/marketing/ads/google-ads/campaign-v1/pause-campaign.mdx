    Pauses a running campaign, stopping ad delivery immediately.
    An optional scheduledResumeDate can be provided to automatically reactivate the campaign at a future time.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-GOOGLE-ADS">Manage google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/campaigns/{campaignId}/pause
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      ID of the campaign to pause.

    </ParamField>

    ## Body Params

    <ParamField body="turnAutoRenewOff" type="boolean">

      Whether to disable subscription auto-renewal when pausing.

    </ParamField>

    <ParamField body="resumeReminderDate" type="datetime">

      Date on which to send a dashboard notification reminding the user to resume the campaign.

    </ParamField>

    <ParamField body="scheduledResumeDate" type="datetime">

      Date on which the campaign will automatically resume. When set, a CampaignAutoResumedEvent is emitted at this time.

    </ParamField>

    ## Response Object

    <ResponseField name="campaign" type="Campaign">

      The paused campaign.

      See the [Campaign Object](/api-reference/business-management/marketing/ads/google-ads/campaign-v1/campaign-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CAMPAIGN_NOT_FOUND` | Couldn't find the campaign. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
