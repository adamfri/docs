    <div className="wix-ref">

    Lists logs for the specified job.

    Logs are generated by the destination for each item that failed to move. Some destinations also generate logs for items that moved successfully.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE_MOVEMENT_JOBS">Data Mover Manage Jobs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data-mover/v1/jobs/{jobId}/logs
    ```

    ## Path Params

    <ParamField path="jobId" type="string" required>

      ID of the job for which to list logs.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Paging metadata.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="logs" type="MovementLog[]">

      Job logs.

      <Expandable title="logs properties">

        <ResponseField name="sourceItemId" type="string">

          ID of the item in the source, such as a Wix Data Item or a row number in a CSV file.

          Constraints: `maxLength 512`.

        </ResponseField>

        <ResponseField name="failure" type="ApplicationError">

          Details about the failure if moving the item fails.

          <Expandable title="failure properties">

            <ResponseField name="code" type="string">

              Error code.

            </ResponseField>

            <ResponseField name="description" type="string">

              Description of the error.

            </ResponseField>

            <ResponseField name="data" type="object">

              Data related to the error.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="details" type="object">

          Additional details provided when moving the item succeeds with details.

          > **Note**: Each destination type determines the structure of its `details` object.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>
