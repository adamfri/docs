The Groups Members API provides functionality for managing group members.

The Groups Members API allows you to:

 + [Add](fallback::https://dev.wix.com/docs/rest/crm/community/groups/members/add-group-members) members to or [remove](fallback::https://dev.wix.com/docs/rest/crm/community/groups/members/remove-group-members) members from a group. 
 + [List](fallback::https://dev.wix.com/docs/rest/crm/community/groups/members/list-group-members) or [query](fallback::https://dev.wix.com/docs/rest/crm/community/groups/members/query-group-members) members of a group. 
 + [List](fallback::https://dev.wix.com/docs/rest/crm/community/groups/members/list-memberships) or [query](fallback::https://dev.wix.com/docs/rest/crm/community/groups/members/query-memberships) a site member's group memberships.

## Who can see a group and add group members to a group
The visibility of a group and how a site member can join it is defined with its `privacyStatus`.
  - **Public**: Anyone can see the group and its content. Anyone can join the group.
  - **Private**: Anyone can see the group, but only group members can view its content. In order to join the group, site members must submit a [join group request](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/introduction).
  - **Secret**: Only group members and admins can see the group. It is not possible for site members to submit a [join group request](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/introduction). Instead, group members and admins can add new members.

## Terminology
+ **Group settings:** Group specific `settings`. Includes whether members can see the full group member list or invite new members. Wix users can also manage settings [in the dashboard](fallback::https://support.wix.com/en/article/wix-groups-managing-your-group).
+ **Join group request:** Request submitted by a site member to join a private group. The request can be approved or rejected by a group admin.
+ **Roles:** Role a site visitor has in a group.
  - **Anonymous:** Site visitor that isn't logged in.
  - **Site member:** Site visitor that is logged in but not a group member.
  - **Group member:** Site member that has joined a group.
  - **Group admin:** Group member with additional permissions. The creator of a group is automatically a group admin.
  - **Wix Groups Manager:** Member, Wix user or Wix app with full management permissions. Wix users are always Wix Groups Managers.
