    Removes a marketing consent. The consent is cancelled, and the `state` is updated to `REVOKED`.
    The marketing consent entity still exists, but the recipient is no longer eligible to receive communication.
    To delete a marketing consent entirely, use Delete Marketing Consent.

    Required fields:
    - `details.type`.
    - `details.email` OR `details.phone`.
    - `info.lastRevokeActivity`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MARKETING.CONSENT-MANAGE">Manage Marketing Consents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/marketing-consent/v1/marketing-consent/remove
    ```

    ## Body Params

    <ParamField body="details" type="MarketingConsentDetails" required>

      Marketing consent communication details.

      <Expandable title="details properties">

        <ParamField body="type" type="string" required>

          The communication channel of the marketing consent.

          **Supported values:**

          - `UNKNOWN_TYPE`
          - `EMAIL`
          - `PHONE`

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="identifier" type="identifier">

          identifier

          <Expandable title="identifier properties">

            <ParamField body="email" type="string">

              Email address used for the marketing consent.

              Constraints: `format EMAIL`.

            </ParamField>

            <ParamField body="phone" type="string">

              Phone number in [E.164](https://en.wikipedia.org/wiki/E.164) format used for the SMS marketing consent.

              Constraints: `format PHONE`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="lastRevokeActivity" type="LastRevokeActivity">

      Information about the last revoke.

      <Expandable title="lastRevokeActivity properties">

        <ParamField body="source" type="string">

          Source of the given revoke (how the visitor signed up).

          **Supported values:**

          - `IN_PERSON`
          - `FORM`
          - `REVOKE_LINK`
          - `WIX_USERS`
          - `OTHER`

        </ParamField>

        <ParamField body="description" type="string">

          Details about the revoke, if relevant.

        </ParamField>

        <ParamField body="updatedDate" type="datetime">

          Date and time the consent was updated.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="marketingConsent" type="MarketingConsent">

      The canceled marketing consent.

      See the [Marketing Consent Object](/api-reference/business-management/marketing/marketing-consent/marketing-consent-object) for this object's fields.

    </ResponseField>
