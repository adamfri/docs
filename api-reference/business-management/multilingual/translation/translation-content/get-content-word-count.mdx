    Gets word counts and field counts for translatable content across a site.

    This method provides detailed translation analytics showing translatable source content statistics and target language translation progress, including current translations and outdated translations. Statistics are provided at the site level and broken down by translation schema for granular progress tracking.

    Call this method when you need to track translation progress or build dashboards showing translation completion rates across different translation schemas.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/translation-content/v1/contents/word-count/{sourceLanguage}
    ```

    ## Path Params

    <ParamField path="sourceLanguage" type="string" required>

      Source language for the translatable content (typically a site's primary language), in IETF BCP 47 language tag format. For example, `en-US` for English as used in the U.S.

    </ParamField>

    ## Query Params

    <ParamField query="targetLanguage" type="string">

      Target language for translation content to include in the response. When omitted, returns only source language statistics without translation progress metrics, in IETF BCP 47 language tag format. For example, `fr-FR` for French as used in France.

    </ParamField>

    ## Response Object

    <ResponseField name="sourceWordCount" type="integer">

      Number of words in the source language across all translation content.

    </ResponseField>

    <ResponseField name="translatedWordCount" type="integer">

      Number of words translated into the target language. Returned only when `targetLanguage` is specified.

    </ResponseField>

    <ResponseField name="outdatedTranslatedWordCount" type="integer">

      Number of translated words that are outdated due to source content modifications after translation. Returned only when `targetLanguage` is specified.

    </ResponseField>

    <ResponseField name="totalFieldCount" type="integer">

      Number of fields in the source language across all translation schemas.

    </ResponseField>

    <ResponseField name="translatedFieldCount" type="integer">

      Number of fields translated into the target language. Returned only when `targetLanguage` is specified.

    </ResponseField>

    <ResponseField name="outdatedTranslatedFieldCount" type="integer">

      Number of translated fields that are outdated due to source content modifications after translation. Returned only when `targetLanguage` is specified.

    </ResponseField>

    <ResponseField name="schemaWordCount" type="SchemaWordCount[]">

      Word counts and field counts broken down by schema. Includes all schemas with translation content, whether translated or not.

      Constraints: `maxItems 500`.

      <Expandable title="schemaWordCount properties">

        <ResponseField name="schemaId" type="string">

          Translation schema ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="sourceWordCount" type="integer">

          Number of words in the source language for this schema.

        </ResponseField>

        <ResponseField name="translatedWordCount" type="integer">

          Number of words translated into the target language for this schema. Returned only when `targetLanguage` is specified.

        </ResponseField>

        <ResponseField name="outdatedTranslatedWordCount" type="integer">

          Number of translated words that are outdated due to source content modifications after translation for this schema. Returned only when `targetLanguage` is specified.

        </ResponseField>

        <ResponseField name="totalFieldCount" type="integer">

          Number of fields in the source language for this schema.

        </ResponseField>

        <ResponseField name="translatedFieldCount" type="integer">

          Number of fields translated into the target language for this schema. Returned only when `targetLanguage` is specified.

        </ResponseField>

        <ResponseField name="outdatedTranslatedFieldCount" type="integer">

          Number of translated fields that are outdated due to source content modifications after translation for this schema. Returned only when `targetLanguage` is specified.

        </ResponseField>

      </Expandable>

    </ResponseField>
