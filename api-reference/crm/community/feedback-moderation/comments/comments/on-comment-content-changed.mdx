Triggered when comment content is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.comments.v2.comment_comment_content_changed` |
| Package | `@wix/comments` |
| Permissions | `Read Comments`, `Manage Comments` |

  ```javascript onCommentContentChanged
  import { comments } from '@wix/comments';

      // handle your event here
  });
  ```
