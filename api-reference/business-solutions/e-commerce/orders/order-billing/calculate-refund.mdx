    Calculates the total refund amount and breakdown for specified line items, shipping, and additional fees.

    Returns detailed calculations including:
    - Total refund amount with tax, discount, and subtotal breakdowns
    - Individual item calculations with pricing details
    - Validation of whether the requested refund items are available

    Use this method to preview refund amounts before calling Refund Payments.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-billing/calculate-refund
    ```
