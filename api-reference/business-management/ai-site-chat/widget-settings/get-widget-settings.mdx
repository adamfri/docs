    Retrieves the widget settings for the site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INNOVATION_LAB.USER">Innovation Lab User</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/innovation/widget/v1/settings
    ```

    ## Response Object

    <ResponseField name="widgetSettings" type="WidgetSettings">

      Retrieved widget settings.

      See the [Widget Settings Object](/api-reference/business-management/ai-site-chat/widget-settings/widget-settings-object) for this object's fields.

    </ResponseField>

    <ResponseField name="assistantOnline" type="boolean">

      Whether the assistant is currently online.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
