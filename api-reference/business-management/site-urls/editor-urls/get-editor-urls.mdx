    <div className="wix-ref">

    Retrieves a site's Editor URLs.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-SITES.READ-URLS">Read Site URLs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/editor-urls
    ```

    ## Query Params

    <ParamField query="branchId" type="string">

      Optional branch ID to include in generated URLs

    </ParamField>

    ## Response Object

    <ResponseField name="urls" type="EditorUrls">

      Editor URL.

      See the [Editor Urls Object](/api-reference/business-management/site-urls/editor-urls/editor-urls-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNABLE_TO_EXTRACT_MS_ID` | Can't extract the site ID from the request. |
    | `404` | `NOT_FOUND` | `SITE_NOT_FOUND` | Couldn't find the site. |
    | `428` | `FAILED_PRECONDITION` | `EDITOR_NOT_FOUND` | Can't retrieve editor URLs. The site doesn't have an editor app. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
