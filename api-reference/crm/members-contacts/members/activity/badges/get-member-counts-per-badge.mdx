    Retrieves a member count per badge.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-BADGES">Read Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v3/badges/members/count
    ```

    ## Response Object

    <ResponseField name="badgeMemberCounts" type="BadgeMemberCount[]">

      Badges and the amount of members who have each badge.

      <Expandable title="badgeMemberCounts properties">

        <ResponseField name="badgeId" type="string">

          Badge ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="memberCount" type="integer">

          Badge member count.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
