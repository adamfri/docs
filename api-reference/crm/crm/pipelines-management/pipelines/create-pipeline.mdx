    Creates a pipeline with defined stages and a final stage.

    Pipelines must have at least one stage in addition to the `doneStage`.
    You must specify allowed outcomes that cards can have when moved to the final stage.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/pipelines/v1/pipelines
    ```

    ## Body Params

    <ParamField body="pipeline" type="Pipeline" required>

      Pipeline to create.

      See the [Pipeline Object](/api-reference/crm/crm/pipelines-management/pipelines/pipeline-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="pipeline" type="Pipeline">

      Created pipeline.

      See the [Pipeline Object](/api-reference/crm/crm/pipelines-management/pipelines/pipeline-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MAX_PIPELINES_REACHED` | The site has reached the maximum number of pipelines allowed. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
