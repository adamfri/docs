    Subtracts a set number of items from inventory.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v2/inventoryItems/decrement
    ```

    ## Body Params

    <ParamField body="decrementData" type="DecrementData[]">

      Constraints: `minItems 1`, `maxItems 300`.

      <Expandable title="decrementData properties">

        <ParamField body="variantId" type="string">

          Variant ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="decrementBy" type="integer">

          Number to decrement inventory by.

          Constraints: `min 1`.

        </ParamField>

        <ParamField body="preorderRequest" type="boolean">

          Whether the request to decrement the item's inventory was made as part of a purchase that includes preorder items.
          If true and the item is available for preorder, we allow negative inventory.
          If false and the item is not available for preorder, we allow regular buy flow (no negative inventory).

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `DecrementInventoryResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
