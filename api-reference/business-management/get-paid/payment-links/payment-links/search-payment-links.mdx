    ## Examples

    Retrieves relevant payment links, given the provided paging, filtering, sorting and aggregations.

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/payment-links/v1/payment-links/search' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        --data-binary '{
          "search": {
            "sort": [
              {
                "fieldName": "createdDate",
                "order": "DESC"
              }
            ],
            "aggregations": [
              {
                "name": "statuses",
                "type": "VALUE",
                "fieldPath": "status",
                "value": {
                  "sortType": "COUNT"
                }
              }
            ],
            "search": {
              "fuzzy": true,
              "expression": "Test",
              "fields": [
                "title"
              ]
            }
          }
        }'
      ```

      ```json Response
      {
        "paymentLinks": [],
        "pagingMetadata": {
          "count": 0,
          "total": 18,
          "cursors": {
            "next": ""

          "hasNext": true

        "aggregationData": {
          "results": [
            {
              "name": "statuses",
              "type": "VALUE",
              "values": {
                "results": [
                  {
                    "value": "active",
                    "count": 15
                  },
                  {
                    "value": "expired",

                    "value": "inactive",

                  },
      ```
