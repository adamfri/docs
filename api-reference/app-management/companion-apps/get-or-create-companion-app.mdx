    Retrieves the companion app for the current site, creating and installing it if it doesn't exist.

    The request must be made in the context of a Wix site.

    If installation fails, the method returns an error but keeps the newly created companion app.
    Call the method again to retry installation.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DEV_CENTER.WRITE_COMPANION_APPS">DEV_CENTER.WRITE_COMPANION_APPS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/companion-apps/get-or-create
    ```

    ## Response Object

    <ResponseField name="companionApp" type="CompanionApp">

      Companion app that was retrieved, or created and installed successfully.

      See the [Companion App Object](/api-reference/app-management/companion-apps/companion-app-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
