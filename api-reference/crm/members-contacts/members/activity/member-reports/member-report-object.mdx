title: "Member Report Object"
description: "A report submitted by a member about another member."
icon: "cube"
---

A report submitted by a member about another member.
Reports help maintain community safety by allowing members to flag inappropriate behavior such as spam, harassment, or impersonation.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Report ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="reportedMemberId" type="string">

      ID of the reported member.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="reportingMemberId" type="string">

      ID of the member who created the report.

      **Read-only.**

    </ResponseField>

    <ResponseField name="reason" type="Reason">

      Reason for reporting a member.

      <Expandable title="reason properties">

        <ResponseField name="category" type="string">

          Report reason type.

          **Supported values:**

          - `SPAM` — The member is reported for spam.
          - `IMPERSONATION` — The member is reported for impersonation.
          - `HARASSMENT` — The member is reported for harassment.
          - `OTHER` — The member is reported for other reasons.

        </ResponseField>

        <ResponseField name="description" type="string">

          Explanation of why the member is being reported.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the report was created.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "memberReport": {
          "id": "dd7cfd02-1837-4fb8-bc6f-86316f0984a9",
          "reportedMemberId": "e411fe13-9794-42b6-ad62-72c9917f1bac",
          "reportingMemberId": "50353fbc-b265-4f03-888f-a53aa272758d",
          "reason": {
            "category": "OTHER",
            "description": "I think this user's profile info is inappropriate."
          },
          "createdDate": "2021-10-26T17:22:10.299Z"
        }
      }
      ```

    </CodeGroup>
