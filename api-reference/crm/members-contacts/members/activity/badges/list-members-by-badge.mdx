    Retrieves up to 1,000 site members
    who have a specified badge.

    Default `paging.limit` is `100` and `paging.offset` is `0`.
    For more information, see
    [API Query Language: Paging](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#paging).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-BADGES">Read Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v3/badges/{id}/members
    ```
