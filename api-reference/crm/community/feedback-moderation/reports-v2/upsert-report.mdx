    Creates or updates a report.
    If the report for the requested entity already exists, updates the report with the provided `reason` value. Otherwise, creates the report.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_REPORTS.MANAGE-REPORTS">Manage Reports</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reports/v2/reports/upsert/entity-name/{report.entityName}/entity-id/{report.entityId}
    ```

    ## Path Params

    <ParamField path="report.entityName" type="string" required>

      Reported entity name, such as `comment`.

    </ParamField>

    <ParamField path="report.entityId" type="string" required>

      Reported entity ID.

    </ParamField>

    ## Body Params

    <ParamField body="report" type="Report">

      Report to create or update.

      See the [Report Object](/api-reference/crm/community/feedback-moderation/reports-v2/report-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="report" type="Report">

      Updated or created report.

      See the [Report Object](/api-reference/crm/community/feedback-moderation/reports-v2/report-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Report Created | `wix.reports.v2.report_created` | Triggered when a report is created. |
    | Report Updated | `wix.reports.v2.report_updated` | Triggered when a report is updated. |

    </div>
