    <Warning>

      **Deprecated.** This method is deprecated.

    </Warning>

    Creates a pricing plan. The specified `plan` object must contain a pricing model. A pricing model can be 1 of the following:
    - **A subscription**: A subscription with recurring payments and how often the plan occurs. Subscriptions can have free trial days.
    - **A plan that doesn't renew**: A single payment for a specific duration that doesn't renew.
    - **An unlimited plan**: A single payment for an unlimited amount of time (until canceled).
    Pricing plans are available to the Wix user in the Pricing Plans section in a site's dashboard.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.MANAGE-PLANS">Manage Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/pricing-plans/v2/plans
    ```

    ## Body Params

    <ParamField body="plan" type="Plan" required>

      Plan details.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-deprecated/plan-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="plan" type="Plan">

      Created plan.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-deprecated/plan-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PRICING_PLANS_NOT_INSTALLED` | The user does not have the Wix Pricing Plans app installed on the site. |
    | `400` | `INVALID_ARGUMENT` | `PLAN_NAME_BLANK` | The plan name must not be empty. |
    | `400` | `INVALID_ARGUMENT` | `PLAN_FEE_NAME_BLANK` | The plan fee name must not be empty. |
    | `400` | `INVALID_ARGUMENT` | `PERIOD_AMOUNT_OUT_OF_RANGE` | The total plan length in specified units is out of range. |
    | `400` | `INVALID_ARGUMENT` | `RECURRING_PLAN_PAYMENT_PRICE_MISSING` | The price must be defined when setting pricing options for recurring payments. |
    | `400` | `INVALID_ARGUMENT` | `RECURRING_PLAN_CYCLE_DURATION_TOO_SHORT` | The cycle length must be at least 7 days. |
    | `400` | `INVALID_ARGUMENT` | `RECURRING_PLAN_CYCLE_COUNT_INVALID` | The number of cycles cannot be a negative number or 1. |
    | `400` | `INVALID_ARGUMENT` | `SINGLE_PAYMENT_DURATION_TOO_SHORT` | The duration must be at least 7 days. |
    | `400` | `INVALID_ARGUMENT` | `SINGLE_PAYMENT_CYCLE_COUNT_INVALID` | The number of cycles must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `SINGLE_PAYMENT_FREE_TRIAL_UNSUPPORTED` | Free trials are not supported for single-payment plans. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SINGLE_PAYMENT_WITHOUT_DURATION` | For single-payment pricing, the plan must be either unlimited or have a set duration. |
    | `400` | `INVALID_ARGUMENT` | `invalid_duration_unit` | Duration unit is invalid for this type of plan. |
    | `400` | `INVALID_ARGUMENT` | `client_data_is_invalid` | Client data format is invalid. |

        const selectedPlan = await elevatedGetPlan(planId);

        return selectedPlan;
      } catch (error) {
        console.error(error);
        // Handle the error
      }
    });

      try {
        const newPlan = await elevatedCreatePlan(plan);
