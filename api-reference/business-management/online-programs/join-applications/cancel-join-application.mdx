    Cancels a member's own request to join a program.

    Changes `status` from `APPROVAL_PENDING` to `CANCELLED`. Returns an error if the join application has any other status. Any payment already initiated is canceled.

    `CANCELLED` is a terminal status, and the join application is removed asynchronously.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}/cancel
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to cancel.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Canceled join application.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVALID_JOIN_APPLICATION_STATUS` | The join application isn't in `APPROVAL_PENDING` status, which canceling requires. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |

    | Join Application Status Changed | `wix.online_programs.participants.v3.join_application_status_changed` | Triggered when a join application's `status` changes. |
