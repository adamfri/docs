    Deletes a dispute evidence document.

    <Note>

    After you've submitted an evidence document by calling [Defend Dispute](https://dev.wix.com/docs/api-reference/business-management/payments/disputes/disputes/defend-dispute), you can't delete it.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/payments/dispute-evidence-documents/v1/dispute-evidence-documents/{disputeEvidenceDocumentId}
    ```

    ## Path Params

    <ParamField path="disputeEvidenceDocumentId" type="string" required>

      ID of the dispute evidence document to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteDisputeEvidenceDocumentResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `DISPUTE_EVIDENCE_DOCUMENT_ALREADY_SUBMITTED` | Cannot delete a dispute evidence document that has already been submitted for dispute resolution. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | --- | --- | --- |
    | Dispute Evidence Document Deleted | `wix.payments.dispute_evidence_documents.v1.dispute_evidence_document_deleted` | Triggered when a dispute evidence document is deleted. |

    </div>
