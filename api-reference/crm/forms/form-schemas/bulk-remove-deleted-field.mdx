    Permanently removes deleted fields from a form schema.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/forms/fields/delete
    ```

    ## Body Params

    <ParamField body="formId" type="string" required>

      ID of the form schema to delete fields from.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="fieldsIds" type="string[]">

      IDs of the deleted fields to remove.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="form" type="Form">

      Form schema with the fields removed.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DELETED_FIELD_NOT_FOUND` | Couldn't find the deleted field. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
