A brand is a visible property of a product.
Adding brands to your products can help improve site and product visibility on search engines.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Brand ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the brand is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the brand.

      Ignored when creating a brand.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the brand was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the brand was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Brand name.
      >**Note:** `name` must be unique.

      Constraints: `minLength 1`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="assignedProductsCount" type="integer">

      Number of products this brand is assigned to.
      > **Note:** Returned only when you pass `"ASSIGNED_PRODUCTS_COUNT"` to the `fields` array in Brand API requests.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "brand": {
          "id": "35cfd6ff-2c0d-4e68-b881-2fc78942a3c4",
          "revision": "1",
          "createdDate": "2024-06-27T11:46:29.372Z",
          "updatedDate": "2024-06-27T11:46:29.372Z",
          "name": "Adidas",
          "assignedProductsCount": 0
        }
      }
      ```

    </CodeGroup>
