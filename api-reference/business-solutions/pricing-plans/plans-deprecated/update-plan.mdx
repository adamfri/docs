      **Deprecated.** This method is deprecated.

    </Warning>

    Updates a pricing plan.
    Updating a plan doesn't impact existing orders made for the plan. All orders keep the details of the original plan that was active at the time of purchase.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.MANAGE-PLANS">Manage Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/pricing-plans/v2/plans/{plan.id}
    ```

    ## Path Params

    <ParamField path="plan.id" type="string" required>

      Plan ID.

    </ParamField>

    ## Body Params

    <ParamField body="plan" type="Plan" required>

      ID of the plan to update.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-deprecated/plan-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="plan" type="Plan">

      Updated plan.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-deprecated/plan-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `plan_not_found` | Pricing plan was not found. |
    | `428` | `FAILED_PRECONDITION` | `PRICING_PLANS_NOT_INSTALLED` | The user does not have the Wix Pricing Plans app installed on the site. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_PLAN_ID` | To update a plan, the plan ID must be provided. |
    | `400` | `INVALID_ARGUMENT` | `PLAN_NAME_BLANK` | The plan name must not be empty. |
    | `400` | `INVALID_ARGUMENT` | `PLAN_FEE_NAME_BLANK` | The plan fee name must not be empty. |
    | `400` | `INVALID_ARGUMENT` | `PERIOD_AMOUNT_OUT_OF_RANGE` | The total plan length in units is out of range. |
    | `400` | `INVALID_ARGUMENT` | `RECURRING_PLAN_PAYMENT_PRICE_MISSING` | The price must be defined when setting pricing options for recurring payments. |
    | `400` | `INVALID_ARGUMENT` | `RECURRING_PLAN_CYCLE_DURATION_TOO_SHORT` | The cycle length must be at least 7 days. |
    | `400` | `INVALID_ARGUMENT` | `RECURRING_PLAN_CYCLE_COUNT_INVALID` | The number of cycles cannot be a negative number or 1. |
    | `400` | `INVALID_ARGUMENT` | `SINGLE_PAYMENT_CYCLE_COUNT_INVALID` | The number of cycles must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `SINGLE_PAYMENT_FREE_TRIAL_UNSUPPORTED` | Free trials are not supported for single-payment plans. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SINGLE_PAYMENT_WITHOUT_DURATION` | For single-payment pricing, the plan must be either unlimited or have a set duration. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_DURATION_UNIT` | Period unit is invalid. |
    | `400` | `INVALID_ARGUMENT` | `update_not_supported` | Cannot update plan because it is archived. |
    | `400` | `INVALID_ARGUMENT` | `invalid_period_amount` | Period amount is out of range. |
    | `400` | `INVALID_ARGUMENT` | `price_missing` | Recurring payment option must have a price. |
    | `400` | `INVALID_ARGUMENT` | `duration_missing` | Both duration unit and amount must be given. |
    | `400` | `INVALID_ARGUMENT` | `free_trial_not_supported` | Free trial not supported for single payment plans. |
    | `400` | `INVALID_ARGUMENT` | `client_data_is_invalid` | Client data format is invalid. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
