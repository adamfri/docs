    Updates tags for storage items that match the specified filter criteria. Specifying an empty filter updates tags for all storage items.

    Learn more about [tags](https://dev.wix.com/docs/api-reference/business-management/tags/introduction).

    <Note>

    A tag that appears in both `assignTags` and `unassignTags` is assigned.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/storage-service/v1/bulk/storage-items/update-tags-by-filter
    ```

              Constraints: `maxLength 5`, `maxItems 100`.
