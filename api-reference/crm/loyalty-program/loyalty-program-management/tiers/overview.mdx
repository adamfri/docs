A tier is a loyalty level that customers are assigned to based on the amount of points they earn.
Read more [about loyalty tiers](https://support.wix.com/en/article/about-tiers).

## SDK package

```bash
npm install @wix/loyalty
```

Import the `tiers` namespace from `@wix/loyalty`.
