    Runs the automation associated with the trigger ID that you pass to it.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.ACCESS-VERTICALS-BY-AUTOMATIONS">Access Verticals by Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/crm-automations-utils/v1/trigger-custom
    ```

    ## Body Params

    <ParamField body="triggerId" type="string">

      Trigger ID. You can find this in the custom trigger configuration in the automations builder.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField body="payload" type="object">

      Optional payload object to pass to run trigger. Define the payload schema from sample data in the custom trigger configuration in the
      automations builder.

    </ParamField>

    ## Response Object

    Returns `RunTriggerResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Trigger an automation with a button click

    /***** Backend *****/
    import { customTrigger } from "@wix/automations";
    import { auth } from '@wix/essentials';
    import { Permissions, webMethod } from "wix-web-module";

    export const runTriggerWithPayload = webMethod(
      Permissions.Anyone,
      async (payload) => {
        const triggerMethod = auth.elevate(customTrigger.runTrigger);

        // Your code here
        await triggerMethod({
          triggerId: 'a0f95461-4fea-4971-b2d8-86128ae3e6e9',
          payload,
        });
      }
    );

    /***** Frontend *****/
    import { runTriggerWithPayload } from 'backend/trigger.web';

    $w('#button1').onClick(() => {
      const payload = {
    		firstName: "Amy",
    		age: 50,
    		favoriteFood: "pizza",
    		favoriteColor: "green"
    	};
    	runTriggerWithPayload(payload);
    })
    ```
