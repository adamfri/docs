    <div className="wix-ref">

    Adds multiple items to a collection.

    To add a single item, call Insert Data Item instead.

    When each item is inserted into a collection, its ID is automatically assigned a random value.
    You can optionally provide your own ID when inserting the item. If you specify an ID that already exists in the collection, the insertion will fail.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/bulk/items/insert
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection in which to insert the items.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="dataItems" type="DataItem[]" required>

      Data items to insert.

      Constraints: `maxItems 1000`.

      See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the inserted data items.
      When `true`, the `results` objects contain a `dataItem` field.

      Default: `false`

    </ParamField>

    <ParamField body="appOptions" type="object">

      Additional parameters specific to the [Wix app collection](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-wix-app-collections) you are querying.

      When querying the Wix Stores [Products collection](https://dev.wix.com/docs/develop-websites/articles/wix-apps/wix-e-commerce-stores/wix-stores-products-collection-fields), pass the following optional parameters:
      - `includeHiddenProducts`: Whether to include hidden products in the response. Default: `false`.
      - `includeVariants`: Whether to include product variants in the query. Default: `false`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkDataItemResult[]">

      Information about the inserted items.

      <Expandable title="results properties">

        <ResponseField name="action" type="string">

          Action attempted for the data item.

          **Supported values:**

          - `UNKNOWN_ACTION_TYPE`
          - `INSERT`
          - `UPDATE`
          - `DELETE`
          - `PATCH`

        </ResponseField>

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Item metadata.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Does not appear if the item ID is missing. For example, when item creation fails.

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Original index of the item in the array specified in the request. Use this to match items in the request with those in the response.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              In case of failure, the error details.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="dataItem" type="DataItem">

          Updated data item.

          Returned if `returnEntity` is set to `true` and the action is successful.

          See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Bulk action metadata.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
