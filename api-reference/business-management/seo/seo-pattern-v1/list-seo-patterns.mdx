    Retrieves the patterns stored for a site, one per page type.

    Only returns page types that have had a pattern of the site's own stored, so a page
    type that has never had one is absent. A page type that was reset to its default remains in the
    list, with an empty `pattern` and `source` of `PATTERN_SOURCE_DEFAULT`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/seo/v1/seo-patterns
    ```

    ## Response Object

    <ResponseField name="seoPatterns" type="SeoPattern[]">

      The patterns stored for the site, one per page type.

      A page type that has never had a pattern stored isn't included. A page type that was
      reset to its Wix default is included, with an empty `pattern`.

      Constraints: `maxItems 200`.

      See the [Seo Pattern Object](/api-reference/business-management/seo/seo-pattern-v1/seo-pattern-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
