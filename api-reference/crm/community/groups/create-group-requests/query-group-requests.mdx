    Retrieves a list of groups requests across a site.

    Supported fields for filtering:
    - `status`

    Supported fields for sorting:
    - `createdDate`

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/social-groups-proxy/group-requests/v2/group-requests/query
    ```

    ## Body Params

    <ParamField body="query" type="Query">

      query

      <Expandable title="query properties">

        <ParamField body="filter" type="any">

          Filter object in the following format:
          `"filter" : {`
          "fieldName1": "value1",
          "fieldName2":&#123;"$operator":"value2"&#125;
          &#125;``
          Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"sortField1","order":"ASC"},{"fieldName":"sortField2","order":"DESC"}]`

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

            <ParamField body="origin" type="AddressLocation">

              Origin point for geo-distance sorting on a GEO field
              results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

              _Nested structure omitted for brevity — see the `AddressLocation` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="paging" type="Paging">

          Paging options to limit and skip the number of items.

          <Expandable title="paging properties">

            <ParamField body="limit" type="integer">

              Number of items to load.

            </ParamField>

            <ParamField body="offset" type="integer">

              Number of items to skip in the current sort order.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="fields" type="string[]">

          Array of projected fields. A list of specific field names to return. If `fieldsets` are also specified, the union of `fieldsets` and `fields` is returned.

        </ParamField>

        <ParamField body="fieldsets" type="string[]">

          Array of named, predefined sets of projected fields. A array of predefined named sets of fields to be returned. Specifying multiple `fieldsets` will return the union of fields from all sets. If `fields` are also specified, the union of `fieldsets` and `fields` is returned.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="groupRequests" type="GroupRequest[]">

      Retrieved group requests.

    <ResponseField name="metadata" type="PagingMetadata">

        </ResponseField>

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>
