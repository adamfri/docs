<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a list of past purchases for your app on this site.

    You don't have to explicitly pass an identifier for the Wix site as part of
    the request, since this information is taken automatically from the context.

    The response doesn't include any details about cancellations.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/checkout/history
    ```

    ## Response Object

    <ResponseField name="purchases" type="PurchasedItem[]">

      Retrieved purchases the Wix user has completed for you app.

      <Expandable title="purchases properties">

        <ResponseField name="productId" type="string">

          ID of your app's paid plan.

        </ResponseField>

        <ResponseField name="price" type="string">

          Price of your app's paid plan. For example, `9.95`.

        </ResponseField>

        <ResponseField name="currency" type="string">

          3-letter currency code in
          [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) format.

        </ResponseField>

        <ResponseField name="billingCycle" type="string">

          Information about the billing cycle for your app's paid plan.

          **Supported values:**

          - `NO_CYCLE`
          - `MONTHLY`
          - `YEARLY`
          - `ONE_TIME`
          - `TWO_YEARS`
          - `THREE_YEARS`
          - `FOUR_YEARS`
          - `FIVE_YEARS`

        </ResponseField>

        <ResponseField name="dateCreated" type="datetime">

          Date and time the site purchased your app's paid plan in
          `YYYY-MM-DDThh:mm:ss.sssZ` format.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
