    <div className="wix-ref">

    Updates specified properties of a data collection.

    Only updates the properties specified in the request, all other properties remain unchanged.
    The following properties can be updated with this method: `displayName`, `displayField`, and `permissions`.
    Attempting to update unsupported properties causes this operation to fail.

    To update properties in a collection's `fields` array, use [Patch Data Collection Field](https://dev.wix.com/docs/api-reference/business-solutions/cms/collection-management/data-collections/patch-data-collection-field).
    To add or remove `plugins`, use [Add Data Collection Plugin](https://dev.wix.com/docs/api-reference/business-solutions/cms/collection-management/data-collections/add-data-collection-plugin) or [Delete Data Collection Plugin](https://dev.wix.com/docs/api-reference/business-solutions/cms/collection-management/data-collections/delete-data-collection-plugin).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/data/v2/collections/{dataCollection.id}
    ```

    ## Path Params

    <ParamField path="dataCollection.id" type="string" required>

      For [app collections](https://dev.wix.com/docs/api-reference/business-solutions/cms/collection-management/wix-app-collections/introduction), use `AppName/CollectionName`.

    </ParamField>

    ## Body Params

    <ParamField body="dataCollection" type="DataCollection" required>

      Data collection to update.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="dataCollection" type="DataCollection">

      Updated data collection.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ResponseField>
