    <div className="wix-ref">

    Updates the email and SMS marketing subscription statuses of multiple contacts that match the provided filter. Works asynchronously.

    If a requested subscription status matches a contact's current status, that contact is left unchanged. Provide at least one of `emailSubscriptionStatus` or `phoneSubscriptionStatus`.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/bulk/contacts/subscriptions/update
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      A filter for the contacts that the subscription statuses will be applied to.

      Example:
      `{ "filter": { "name.last": "Smith" } }`

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields for the contacts that the subscription statuses will be applied to.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          How separate search terms in `expression` are combined.

          **Supported values:**

          - `OR` — Any of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If empty, searches all searchable fields. Use dot notation to specify the JSON path.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to use fuzzy search, which allows typos using a managed proximity algorithm.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="emailSubscriptionStatus" type="string">

      The subscription status to apply to the contact's email address.

      **Supported values:**

      - `NOT_SET` — No subscription status has been reported yet.
      - `SUBSCRIBED` — Opted in to receive marketing messages.
      - `UNSUBSCRIBED` — Opted out of receiving marketing messages.

    </ParamField>

    <ParamField body="phoneSubscriptionStatus" type="string">

      The subscription status to apply to the contact's phone.

      **Supported values:**

      - `NOT_SET` — No subscription status has been reported yet.
      - `SUBSCRIBED` — Opted in to receive marketing messages.
      - `UNSUBSCRIBED` — Opted out of receiving marketing messages.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID. Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job) to retrieve the status of the asynchronous operation.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MISSING_SUBSCRIPTION_STATUS` | At least one of the subscription statuses must be requested. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Examples

    Asynchronously updates email and phone subscription statuses for all contacts matching a filter. Returns a job ID to poll for status.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/contacts/v5/bulk/contacts/subscriptions/update' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "filter": {
          "company.name": "ExampleCo"
        },
        "emailSubscriptionStatus": "SUBSCRIBED"
      }'
      ```

      ```json Response
      {
        "jobId": "9411a01a-10e7-4180-b899-03adace4d4f2"
      }
      ```
