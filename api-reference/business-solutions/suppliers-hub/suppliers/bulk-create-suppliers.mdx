    Creates multiple suppliers in a single synchronous request.

    Supports up to 100 suppliers per request. Set `returnEntity` to `true` to receive the created suppliers with their assigned IDs and revision numbers. Use this endpoint when importing suppliers from external sources or onboarding multiple suppliers simultaneously.

    Each supplier in the request is processed independently. The response includes metadata indicating success or failure for each supplier.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/bulk/suppliers/create
    ```

    ## Body Params

    <ParamField body="suppliers" type="Supplier[]" required>

      List of suppliers to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Supplier Object](/api-reference/business-solutions/suppliers-hub/suppliers/supplier-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return created supplier entities in the response. Set to `true` to receive the created suppliers with their assigned IDs and revision numbers.

    </ParamField>

    ## Response Object

        </ResponseField>
