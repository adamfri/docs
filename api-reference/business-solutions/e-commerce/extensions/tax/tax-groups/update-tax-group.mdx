    <div className="wix-ref">

    Updates a tax group.

    Each time the tax group is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the tax group.
    This ensures you're working with the latest tax group and prevents
    unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/billing/v1/tax-groups/{taxGroup.id}
    ```

    ## Path Params

    <ParamField path="taxGroup.id" type="string" required>

      Tax group ID.

    </ParamField>

    ## Body Params

    <ParamField body="taxGroup" type="TaxGroup" required>

      Tax group info to update.

      See the [Tax Group Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-groups/tax-group-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="taxGroup" type="TaxGroup">

      Updated tax group.

      See the [Tax Group Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-groups/tax-group-object) for this object's fields.

    </ResponseField>

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `ILLEGAL_UPDATE_ON_SYSTEM_DEFINED_TAX_GROUP` | Cannot modify system defined tax groups. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
