This article presents possible use cases and corresponding sample flows that you can support. These flows provide a helpful jumping-off point as you plan your implementation.

## Add custom note-taking functionality

You can create custom note-taking capabilities to help Wix users document interactions with their contacts.

To add custom note-taking functionality:

1. When a Wix user creates or selects a contact, get the contact's ID to create notes associated with that contact.

2. Provide a form where Wix users can enter note text and select a note type from a dropdown for organizational purposes.

3. Call [Create Note](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/create-note) with the contact ID, note text, and selected type to save the note.

4. Call [Query Notes](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/query-notes) with the contact ID, to display existing notes sorted by created date.

5. Allow Wix users to edit notes by calling [Get Note](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/get-note) to retrieve current content, then calling [Update Note](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/update-note) with the revised information and current revision number.

## Sync notes between your app and Wix

Your app already has its own notes system and you want to synchronize notes bidirectionally with Wix contacts.

To sync notes between your app and Wix:

1. Map your existing contacts to Wix contact IDs and store this mapping in your database.

2. When a Wix user creates a note in your app, call [Create Note](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/create-note) to add the note to the corresponding Wix contact.

3. Periodically call [Query Notes](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/query-notes) for each mapped contact to retrieve new notes created in Wix since your last sync.

4. Import new notes from Wix into your app's database, avoiding duplicates by checking note IDs.

5. Handle updates by comparing revision numbers and calling [Update Note](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/notes/notes-v2/update-note) when notes have been modified.
