---
title: "Payment Details Object"
description: "Retrieve a monthly breakdown of ad spend and payment history for a Wix site's Google Ads account."
icon: "cube"
---

Retrieve a monthly breakdown of ad spend and payment history for a Wix site's Google Ads account.

<Tabs>

  <Tab title="REST">

    <ResponseField name="currency" type="string">

      The account's billing currency in ISO-4217 format. All monetary amounts in this entity are expressed in this currency.

      **Read-only.** Constraints: `format CURRENCY`.

    </ResponseField>

    <ResponseField name="monthlyPayments" type="MonthlyPayment[]" deprecated>

      Deprecated: Use upcomingPayments instead.

      **Read-only.** **Deprecated.** Deprecated: Use upcomingPayments instead. Use `upcoming_payments` instead. Removal: 2025-03-24. Constraints: `maxItems 2`.

      <Expandable title="monthlyPayments properties">

        <ResponseField name="usageAmount" type="string">

          Ad spend for the billing period, excluding the Wix service fee.

          **Read-only.**

        </ResponseField>

        <ResponseField name="wixServiceFee" type="string">

          Wix platform fee for the billing period.

          **Read-only.**

        </ResponseField>

        <ResponseField name="totalAmount" type="string">

          Total charge for the billing period: usageAmount plus wixServiceFee, minus any couponAdjustmentAmount.

          **Read-only.**

        </ResponseField>

        <ResponseField name="billingPeriod" type="BillingPeriod">

          The date range covered by this payment record.

          **Read-only.**

          <Expandable title="billingPeriod properties">

            <ResponseField name="from" type="string">

              Start date of the billing period in YYYY-MM-DD format.

              Constraints: `maxLength 10`.

            </ResponseField>

            <ResponseField name="to" type="string">

              End date of the billing period in YYYY-MM-DD format.

              Constraints: `maxLength 10`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="couponAdjustmentAmount" type="string">

          Discount applied from a promotional coupon for this billing period.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="upcomingPayments" type="Payment[]">

      Breakdown of payments for the current billing period.

      **Read-only.** Constraints: `maxItems 2`.

      <Expandable title="upcomingPayments properties">

        <ResponseField name="usageAmount" type="string">

          Ad spend for the billing period, excluding the Wix service fee.

          **Read-only.**

        </ResponseField>

        <ResponseField name="wixServiceFee" type="string">

          Wix platform fee for the billing period.

          **Read-only.**

        </ResponseField>

        <ResponseField name="totalAmount" type="string">

          Total charge for the billing period: usageAmount plus wixServiceFee, minus any couponAdjustmentAmount.

          **Read-only.**

        </ResponseField>

        <ResponseField name="billingPeriod" type="BillingPeriod">

          The date range covered by this payment record.

          **Read-only.**

          <Expandable title="billingPeriod properties">

            <ResponseField name="from" type="string">

              Start date of the billing period in YYYY-MM-DD format.

              Constraints: `maxLength 10`.

            </ResponseField>

            <ResponseField name="to" type="string">

              End date of the billing period in YYYY-MM-DD format.

              Constraints: `maxLength 10`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="couponAdjustmentAmount" type="string">

          Discount applied from a promotional coupon for this billing period.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="creditBalance" type="string">

      The site's current credit balance in the account's billing currency. A positive value indicates available credits; a negative value indicates outstanding debt that has not yet been charged. The final amount may differ once the charge is processed.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "paymentDetails": {
          "currency": "USD",
          "upcomingPayments": [
            {
              "usageAmount": "123.45",
              "wixServiceFee": "12.35",
              "totalAmount": "135.80",
              "billingPeriod": {
                "from": "2026-03-01",
                "to": "2026-03-31"
              },
              "couponAdjustmentAmount": "0.00"
            }
          ],
          "creditBalance": "0.00"
        }
      }
      ```

    </CodeGroup>
