    Retrieves the job status and a list of session IDs, if ready.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ANALYTICS-AND-REPORTS.MANAGE-SESSIONS">Manage Session Recording Analytics - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/analytics/v1/sessions/list/result
    ```

    ## Query Params

    <ParamField query="jobId" type="string" required>

      List sessions job ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="limit" type="integer" required>

      Number of items to load.

      Constraints: `min 1`, `max 1000`.

    </ParamField>

    <ParamField query="offset" type="integer" required>

      Number of items to skip in the current sort order.

      Constraints: `min 0`.

    </ParamField>

    ## Response Object

    <ResponseField name="result" type="JobResult">

      List sessions job result data.

      <Expandable title="result properties">

        <ResponseField name="jobStatus" type="string">

          Job status.

          **Supported values:**

          - `UNKNOWN_JOB_STATUS` — Unknown.
          - `IN_PROGRESS` — In progress.
          - `FINISHED` — Finished.
          - `ERROR` — Error.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of sessions.

        </ResponseField>

        <ResponseField name="sessionIds" type="string[]">

          Session IDs.

          Constraints: `format GUID`, `maxItems 1000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
