    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/menu-ordering-settings/v1/menu-ordering-settings/{id}/update-extended-fields
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the entity to update.

    </ParamField>

    ## Body Params

    <ParamField body="namespace" type="string" required>

      Identifier for the app whose extended fields are being updated.

    </ParamField>

    <ParamField body="namespaceData" type="object" required>

      Data to update. Structured according to the [schema](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields#json-schema-for-extended-fields) defined when the extended fields were configured.

    </ParamField>

    <ResponseField name="menuOrderingSettings" type="MenuOrderingSettings">
