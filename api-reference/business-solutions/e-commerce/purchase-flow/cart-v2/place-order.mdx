    <div className="wix-ref">

    Completes checkout and creates an order.
    This endpoint may charge the customer.

    Read more about the [eCommerce Orders API](https://dev.wix.com/api/rest/wix-ecommerce/orders-api/introduction).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2_LIMITED">Write Carts V2 (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/{cartId}/place-order
    ```

    ## Path Params

    <ParamField path="cartId" type="string" required>

      Cart ID.

    </ParamField>

    ## Body Params

    <ParamField body="priceVerificationToken" type="string">

      Price verification token from `CalculateCart` response.
      Used to verify that prices shown to the customer haven't changed before checkout completes.

    </ParamField>

    <ParamField body="savePaymentMethod" type="boolean">

      Whether to save the payment method on the order.

    </ParamField>

    <ParamField body="delayCapture" type="boolean">

      Whether to authorize the payment and delay capture.

    </ParamField>

    ## Response Object

    <ResponseField name="orderId" type="string">

      Order ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="paymentGatewayOrderId" type="string">

      Cashier payment gateway order ID when money was charged.
      Omitted when no charge occurs (for example, a zero-total cart, a fully discounted order, or when another payment method such as a gift card covers the total).

    </ResponseField>

    <ResponseField name="completed" type="boolean">

      Whether an order was created from this cart and the payment completed successfully.

    </ResponseField>
