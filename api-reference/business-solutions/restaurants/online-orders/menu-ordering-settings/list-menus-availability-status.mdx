    Retrieves a list of a menu's availability statuses for a given time slot and restaurant operation. (See the Restaurants Operations API for more information.)
    Returns the availability status for the given time slot per menu.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/menu-ordering-settings/v1/menu-ordering-settings/menus-availability-status
    ```

    ## Query Params

    <ParamField query="timeSlot" type="TimeSlot" required>

      The time slot for which to check the availability of menus.

      <Expandable title="timeSlot properties">

        <ParamField query="startTime" type="datetime">

          The start time of the time slot in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

        </ParamField>

        <ParamField query="endTime" type="datetime">

          The end time of the time slot in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="operationId" type="string">

      The ID of the restaurant operation whose menus will be checked. (See the Restaurants Operations API for more information.)

    </ParamField>

    <ParamField query="cursorPaging" type="CursorPaging">

      Cursor paging

      <Expandable title="cursorPaging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="menusAvailabilityStatus" type="MenuAvailabilityStatus[]">

      The retrieved menus' availability statuses.

      Constraints: `maxItems 100`.

      <Expandable title="menusAvailabilityStatus properties">

        <ResponseField name="menuId" type="string">

          Menu ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="availabilityStatus" type="string">

          The menu's availability status.

          **Supported values:**

          - `UNKNOWN_AVAILABILITY_STATUS` — Unknown availability status.
          - `AVAILABLE` — Available.
          - `UNAVAILABLE` — Unavailable.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      The metadata of the paginated results.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
