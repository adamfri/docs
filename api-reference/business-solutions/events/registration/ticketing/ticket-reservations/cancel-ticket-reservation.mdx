    Cancels an existing ticket reservation.

    Changes the reservation status to `CANCELED_MANUALLY` and releases the reserved
    tickets back to available inventory. Once cancelled, a reservation cannot be
    restored. Only `PENDING` and `CONFIRMED` reservations can be cancelled.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.EVENTS-CHECKOUT">Events Checkout</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/ticket-reservations/{ticketReservationId}/cancel
    ```

    ## Path Params

    <ParamField path="ticketReservationId" type="string" required>

      ID of the ticket reservation to cancel.

    </ParamField>

    ## Response Object

    <ResponseField name="ticketReservation" type="TicketReservation">

      The canceled ticket reservation.

      See the [Ticket Reservation Object](/api-reference/business-solutions/events/registration/ticketing/ticket-reservations/ticket-reservation-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `TICKET_RESERVATION_NOT_FOUND` |  |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
