    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-BADGES">Read Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/badges/v4/badges/{badgeId}
    ```

    ## Path Params

    <ParamField path="badgeId" type="string" required>

      Badge ID.

    </ParamField>

    ## Response Object

    <ResponseField name="badge" type="Badge">

      Retrieved badge.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges-v4/badge-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
