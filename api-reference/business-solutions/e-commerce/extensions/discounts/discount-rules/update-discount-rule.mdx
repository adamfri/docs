    Updates a discount rule.

    Each time the discount rule is updated, `revision` increments by 1. The existing `revision` must be included when updating the discount rule.
    This ensures you're working with the latest discount rule information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v1/discount-rules/{discountRule.id}
    ```

    ## Path Params

    <ParamField path="discountRule.id" type="string" required>

      Discount rule ID.

    </ParamField>

    </ParamField>

      See the [Discount Rule Object](/api-reference/business-solutions/e-commerce/extensions/discounts/discount-rules/discount-rule-object) for this object's fields.

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Discount rule ID.

      **Read-only.**

    </ParamField>

    <ParamField body="discountRule" type="UpdateDiscountRule" required>

      Discount rule info.

      <Expandable title="discountRule properties">

        <ParamField body="_id" type="string">

          Discount rule ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the discount rule is updated.
          To prevent conflicting changes, the current `revision` must be passed when updating the discount rule.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the discount rule was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the discount rule was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="active" type="boolean">

          Whether the discount rule is active.

          Default: `true`

        </ParamField>

        <ParamField body="name" type="string">

          Discount rule name.

        </ParamField>

        <ParamField body="trigger" type="DiscountTrigger">

          Discount rule trigger.
          A set of conditions that must be met for the `discounts` to be applied.
          Not passing a trigger will cause the discount to always apply.

          <Expandable title="trigger properties">

            <ParamField body="triggerType" type="string">

              Trigger type.

              **Supported values:**

              - `AND` — Operator used for chaining multiple triggers. Currently 1 `AND` chain operator is supported.
              - `SUBTOTAL_RANGE` — Subtotal must be within the specified `subtotalRange` values.
              - `ITEM_QUANTITY_RANGE` — Quantity of items in scope must be within specified `itemQuantityRange` values.
              - `CUSTOM` — Custom trigger type defined in `customTrigger` object.
              - `OR` — Chain multiple triggers with OR operator
              - `CUSTOMER_ELIGIBILITY` — Customer eligibility type must be within specified `customerEligibility` values.

            </ParamField>

          </Expandable>

          <Expandable title="One of the following">

            <ParamField body="trigger" type="trigger">

              trigger

              _Nested structure omitted for brevity — see the `trigger` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="activeTimeInfo" type="ActiveTimeInfo">

          Time frame in which the discount rule is active.

          <Expandable title="activeTimeInfo properties">

            <ParamField body="start" type="datetime">

              Date and time the discount rule is active **from**, in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations) format.

            </ParamField>

            <ParamField body="end" type="datetime">

              Date and time the discount rule is active **till**, in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations) format.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="discounts" type="Discounts">

          List of discounts that are applied when one or more triggers are met.

          > **Notes:**
          >
          > + Currently, only 1 discount can be defined per discount rule.
          > + A discount rule can be applied on multiple items per cart.
          > + A discount rule can only be applied once per item.

          <Expandable title="discounts properties">

            <ParamField body="values" type="Discount[]">

              Discounts.

              Constraints: `minItems 1`, `maxItems 1`.

              _Nested structure omitted for brevity — see the `Discount[]` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="status" type="string">

          Discount rule status.
          Default: `UNDEFINED`

          **Read-only.**

          **Supported values:**

          - `LIVE` — Rule status is live.
          - `EXPIRED` — Rule status is expired, it might have been live in the past.
          - `PENDING` — Rule status is pending, it might be live in the future.

        </ParamField>

        <ParamField body="usageCount" type="integer">

          Number of times the discount rule was used.

          **Read-only.**

        </ParamField>

        <ParamField body="tags" type="Tags">

          Tags for this discount rule.

          <Expandable title="tags properties">

            <ParamField body="privateTags" type="TagList">

              Tags that require an additional permission in order to access them, normally not given to site members or visitors.

              _Nested structure omitted for brevity — see the `TagList` object._

            </ParamField>

            <ParamField body="publicTags" type="TagList">

              Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

              _Nested structure omitted for brevity — see the `TagList` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
