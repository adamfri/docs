    <div className="wix-ref">

    Checks whether the specified email address will be used as the "from" address when sending campaigns, or whether it will be replaced by a different address.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/identify-sender-address
    ```

    ## Body Params

    <ParamField body="emailAddress" type="string" required>

      Email address to verify.

      Constraints: `format EMAIL`, `minLength 6`, `maxLength 254`.

    </ParamField>

    ## Response Object

    <ResponseField name="senderAddress" type="string">

      Actual "from" address that will be used for sending emails.

      Constraints: `format EMAIL`, `minLength 6`, `maxLength 254`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Check what "from" address will be used when sending a campaign for a given email address.

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/email-marketing/v1/identify-sender-address' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>' \
      -d '{
            "emailAddress": "john.doe@gmail.com"
          }'
      ```

      ```json Response
      {
        "senderAddress": "john.doe@pb01.wixemails.com"
      }
      ```

    </CodeGroup>
