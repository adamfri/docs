    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates and assigns a new primary locale for a site.

    This method changes the site's primary locale. The process may take time, depending on the amount of content present on the site. When called, this method returns a token, which you can use with the Get New Primary Locale Status method to check the status of the primary locale change.

    <Note>

    - The desired new primary locale can't already exist as a secondary locale on the site. If the locale is already a secondary locale on the site, you must first remove it from the site by calling Delete Locale before changing the primary locale.
    - This method automatically deletes the original primary locale and transfers its data to the new primary locale.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/locales/v2/locale/change-primary
    ```

    ## Body Params

    <ParamField body="primaryLocale" type="Locale" required>

      New primary locale.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="token" type="string">

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NEW_MAIN_LOCALE_EXIST_ON_SITE` | The specified locale already exists as a secondary locale on the site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Multilingual Primary Locale Changed | `wix.multilingual.locales.v2.locale_multilingual_primary_locale_changed` | Triggered when a new primary locale is created. |

    </div>
