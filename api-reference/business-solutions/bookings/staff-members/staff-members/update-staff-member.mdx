    Updates a staff member.

    Each time the staff member is updated, `revision` increments by 1.
    You must include current revision of the staff member when updating it.
    This ensures you're working with the latest service information and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bookings/v1/staff-members/{staffMember.id}
    ```

    ## Path Params

    <ParamField path="staffMember.id" type="string" required>

      Staff member ID.

    </ParamField>

    ## Body Params

    <ParamField body="staffMember" type="StaffMember" required>

      Staff member to update.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `RESOURCE_DETAILS` — Includes `resource` in the response.
      - `ASSOCIATED_IDENTITY_STATUS` — Includes `associatedIdentityStatus` in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="staffMember" type="StaffMember">

      Updated staff member.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ResponseField>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ## Examples

    Update a staff member, `id` and `revision` are required. partial updates are supported.

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
      'https://www.wixapis.com/bookings/v1/staff-members/0954bbb2-88cd-445c-9827-44253eb8b039' \
      -H 'Authorization: <AUTH>' \
      -d '{
        "staffMember": {
          "name": "Some other name",
          "id": "0954bbb2-88cd-445c-9827-44253eb8b039",
          "revision": "2"
        }
      }'
      ```

      ```json Response
      {
        "staffMember": {
          "id": "0954bbb2-88cd-445c-9827-44253eb8b039",
          "name": "Some other name",
          "resourceId": "136d9d9a-97ab-49fa-a0cf-ec24f500bd98",
          "revision": "3",
          "createdDate": "2024-08-28T13:22:32.784Z",
          "updatedDate": "2024-08-28T14:16:11.948Z"
        }
      }
      ```
