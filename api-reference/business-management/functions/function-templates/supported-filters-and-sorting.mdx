The following table shows field support for filters and sorting
for the function template object:

| Field                    | Supported Filters                             | Sortable |
| ------------------------ | --------------------------------------------- | -------- |
| `id`                     | `$ne`                                                                       | Sortable |
| `appDefId`               | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$lt`, `$gte`, `$lte`, `$startsWith` | Sortable |
| `functionExtensionId`    | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$lt`, `$gte`, `$lte`, `$startsWith` | Sortable |
| `formTemplateExtensionId`| `$exists`                                                                   | Sortable |

<Note>

`appDefId` and `functionExtensionId` are required filters.

</Note>
