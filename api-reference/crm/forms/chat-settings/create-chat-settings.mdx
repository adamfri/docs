<Tabs>

  <Tab title="REST">

    Creates a chat settings entity.

    The settings specified in a chat settings entity apply to the form with the same ID as the chat settings entity. Each form can have exactly one set of chat settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/ai/v1/chat-settings
    ```

    ## Body Params

    <ParamField body="chatSettings" type="ChatSettings" required>

      Chat settings to be created.

      See the [Chat Settings Object](/api-reference/crm/forms/chat-settings/chat-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="chatSettings" type="ChatSettings">

      Created chat settings.

      See the [Chat Settings Object](/api-reference/crm/forms/chat-settings/chat-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Chat Settings Created | `wix.forms.ai.v1.chat_settings_created` |  |
