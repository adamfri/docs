title: "Fulfillments Object"
description: "An order and its associated fulfillments."

---

An order and its associated fulfillments. A fulfillment represents the shipment or delivery of order items.

<Tabs>

  <Tab title="REST">

    <ResponseField name="orderId" type="string">

      Order ID.

      Constraints: `minLength 1`, `maxLength 100`.

    </ResponseField>

    <ResponseField name="fulfillments" type="Fulfillment[]">

      Fulfillments associated with the order.

      <Expandable title="fulfillments properties">

        <ResponseField name="id" type="string">

          Fulfillment ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Fulfillment creation date and time in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations) format.

          **Read-only.**

        </ResponseField>

        <ResponseField name="lineItems" type="FulfillmentLineItem[]">

          Line items being fulfilled.

          Constraints: `minItems 0`, `maxItems 300`.

          <Expandable title="lineItems properties">

            <ResponseField name="id" type="string">

              Line item ID (mirrors the ID of the order line item).

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="quantity" type="integer">

              Line item quantity.

              * If this property isn't passed on creation, it defaults to the number of items not already linked to a fulfillment.
              * If the order does not have the requested quantity of line items available to add to this fulfillment, the fulfillment will not be created and an error is returned.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="status" type="string">

          The current status of the fulfillment process.

          Supported values (case-sensitive, any other value is rejected):
          + `"Pending"` - Initial state when fulfillment is created but processing hasn't started.
          + `"Accepted"` - Order has been received and validated for fulfillment.
          + `"Ready"` - Items have been picked and packed, ready for shipping.
          + `"In_Delivery"` - Items have been handed over to the shipping carrier.
          + `"Fulfilled"` - Delivery has been completed successfully.

          The status typically progresses from `Pending` to `Accepted`, `Ready`, `In_Delivery`, and finally `Fulfilled`.
          Update the status manually or automatically depending on your fulfillment workflow.

          This field is informational. The order's `fulfillmentStatus` is primarily derived from the fulfilled line item quantities, not from this field.

        </ResponseField>

        <ResponseField name="completed" type="boolean">

          Fulfillment handling complete.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "orderWithFulfillments": {
          "orderId": "58c9a790-27b7-463f-a865-c7cb494f7c29",
          "fulfillments": [
            {
              "id": "0d824fc7-2621-4e97-a5c8-489ec1b43377",
              "createdDate": "2023-02-22T15:55:47.021Z",
              "lineItems": [
                {
                  "id": "00000000-0000-0000-0000-000000000001",
                  "quantity": 1
                }
              ],
              "trackingInfo": {
                "trackingNumber": "12345",
                "shippingProvider": "fedex",
                "trackingLink": "https://www.fedex.com/apps/fedextrack/?action=track&trackingnumber=12345"
              }
            }
          ]
        }
      }
      ```

    </CodeGroup>
