---
title: "Resource Type Object"
description: "A resource type is a classification of resources."
icon: "cube"
---

A resource type is a classification of resources. For example room, equipment, or vehicle.
Customers can only book [services](https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/introduction) if at least 1 [resource](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/introduction) for every resource type connected to the service is available during the requested time.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Resource type ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the resource type is updated.
      To prevent conflicting changes, the current revision must be passed when updating the resource type.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource type was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource type was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Name of the resource type. For example, `meeting room`.
      The name must be unique per site.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extensions enabling users to save custom data related to the resource type.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "resourceType": {
          "id": "28221941-9d0d-4c91-806b-e2a08073d37a",
          "revision": "1",
          "createdDate": "2024-11-14T13:32:36.462Z",
          "updatedDate": "2024-11-14T13:32:36.462Z",
          "name": "Meeting room"
        }
      }
      ```

    </CodeGroup>
