## Customize receipts with specific business and tax details to comply with local requirements
You can enable Wix users to customize the details of generated receipts with the Receipt Presets API.

1. Call [Get Default Receipt Preset](https://dev.wix.com/docs/rest/business-management/get-paid/get-paid/receipts/receipt-preset-v1/get-default-receipt-preset) to retrieve the default receipt preset.
1. Collect the Wix user's desired changes to the receipt preset. 
1. Call [Update Receipt Preset](https://dev.wix.com/docs/rest/business-management/get-paid/get-paid/receipts/receipt-preset-v1/update-receipt-preset) with the desired changes.
All receipts created using this preset will include the desired changes.
