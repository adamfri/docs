    Updates a task.

    Each time the task is updated, `revision` increments by 1.
    The existing `revision` must be included when updating the task.
    This ensures you're working with the latest task
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-TASKS">Manage Tasks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/crm/tasks/v2/tasks/{task.id}
    ```

    ## Path Params

    <ParamField path="task.id" type="string" required>

      Task ID.

    </ParamField>

    ## Body Params

    <ParamField body="task" type="Task" required>

      Task to update.

      See the [Task Object](/api-reference/crm/crm/tasks/task-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="task" type="Task">

      The updated task.

      See the [Task Object](/api-reference/crm/crm/tasks/task-object) for this object's fields.

    </ResponseField>

    | --- | --- | --- | --- |
