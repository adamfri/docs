    Retrieves a list of up to 100 GBP locations, given the provided paging,
    filtering, and sorting.

    Returns the site's stored locations. It doesn't call Google, so the response
    contains identifiers and stored metadata rather than live profile data. To
    retrieve the same locations with their current Google data, call Query Google
    Locations.

    Supported properties for filtering and sorting: `id`, `googleLocationId`,
    `accountId`.

    To learn about working with Query methods, see
    [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language),
    [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging),
    and [Field Projection](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `googleLocationId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `accountId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
