    Retrieves an intake form by ID.

    Returns only intake forms in the caller's account. A valid ID belonging to
    another account reads as not found.

    By default, `context` and `sourceMaterials` aren't returned. To retrieve them,
    include `CONTEXT` or `SOURCE_MATERIALS` in `fields`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.CONTENT-COLLECTOR">SCOPE.PARTNERS.CONTENT-COLLECTOR</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/content-collector/v1/intake-forms/{intakeFormId}
    ```

    ## Path Params

    <ParamField path="intakeFormId" type="string" required>

      ID of the IntakeForm to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Fields to include in the response.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `CONTEXT`
      - `SOURCE_MATERIALS`
      - `INTRO_DATA`

    </ParamField>

    ## Response Object

    <ResponseField name="intakeForm" type="IntakeForm">

      The requested IntakeForm.

      See the [Intake Form Object](/api-reference/account-level/studio-workspace/content-collector/intake-form-v1/intake-form-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
