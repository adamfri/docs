DNS zones hold information about the records that map a domain's URL to an IP address.

## SDK package

```bash
npm install @wix/domains
```

Import the `domainDns` namespace from `@wix/domains`.

## Methods

<CardGroup cols={2}>

  <Card title="Create Dns Zone" href="/api-reference/account-level/domains/domain-dns/create-dns-zone">

  </Card>
  <Card title="Get Dns Zone" href="/api-reference/account-level/domains/domain-dns/get-dns-zone">
    GET Retrieves the DNS zone belonging to the domain from Google's Cloud DNS.
  </Card>
  <Card title="Delete Dns Zone" href="/api-reference/account-level/domains/domain-dns/delete-dns-zone">

  </Card>
  <Card title="Update Dns Zone" href="/api-reference/account-level/domains/domain-dns/update-dns-zone">

  <Card title="Preview Dns Zone" href="/api-reference/account-level/domains/domain-dns/preview-dns-zone">
