    Creates multiple draft posts.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/blog/v3/bulk/draft-posts/create
    ```

    ## Body Params

    <ParamField body="draftPosts" type="DraftPost[]" required>

      Draft posts to create.

      Constraints: `minItems 1`, `maxItems 20`.

      See the [Draft Object](/api-reference/business-solutions/blog/draft-posts/draft-object) for this object's fields.

    </ParamField>

    <ParamField body="publish" type="boolean">

      Whether the draft post should be published after creation.

    </ParamField>

    <ParamField body="returnFullEntity" type="boolean">

      Whether to return the full created draft post entities in the response.

    </ParamField>

    <ParamField body="fieldsets" type="string[]">

      List of draft post fields to be included in the response if the entities are present.
      Base default fieldset returns all core draft post properties (all properties that are not a supported fieldset value).
      For example,  when `URL` fieldset is selected, returned draft post will include the set of base properties and the draft post's preview url.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes draft post preview URL.
      - `CONTENT` — Includes content field.
      - `RICH_CONTENT` — Includes rich content field.
      - `GENERATED_EXCERPT` — If the user has not set excerpt, returns the one autogenerated from content.

    </ParamField>
