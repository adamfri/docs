This endpoint is used to connect a merchant's Payment Service Provider (PSP) account to a Wix site.

Wix calls this endpoint when a merchant chooses to connect a PSP in the Wix dashboard.
The PSP must verify the merchant's credentials and ensure that the merchant has an operational PSP account.
Learn more about [implementing this endpoint](https://dev.wix.com/docs/rest/api-reference/payment-provider-spi/connecting-accounts).

## Endpoint

```http
POST /connect
```

## Body Params

<ParamField body="credentials" type="object" required>

  Merchant credentials for a PSP account.
  The PSP specifies the keys for this object in the [app dashboard](https://dev.wix.com/apps).
  The merchant is prompted to enter these credentials when they connect their PSP account to their Wix site.

  Constraints: `format map`.

  <Expandable title="credentials properties">

    <ParamField body="key" type="string" />

    <ParamField body="value" type="string" />

  </Expandable>

</ParamField>

<ParamField body="country" type="string">

  Country where the merchant provides their services, in [ISO 3166-1 alpha-2](http://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format.

</ParamField>

<ParamField body="currency" type="string">

  Code for the merchant's preferred [currency](https://en.wikipedia.org/wiki/ISO_4217).

</ParamField>

<ParamField body="mode" type="string">

  Connection mode. Identifies whether a request is live or for testing purposes.

  **Supported values:**

  - `undefined` — Undefined mode.
  - `live` — Request is live.
  - `sandbox` — Request is for testing purposes.

</ParamField>

<ParamField body="wixMerchantId" type="string" required>

  Wix merchant ID.

</ParamField>

<ParamField body="siteId" type="string">

  Wix site ID.

</ParamField>

## Response Object

<ResponseField name="credentials" type="object">

  Merchant credentials that Wix will use when sending the merchant's payment and refund requests.

  Constraints: `format map`.

  <Expandable title="credentials properties">

    <ResponseField name="key" type="string" />

    <ResponseField name="value" type="string" />

  </Expandable>

</ResponseField>

<ResponseField name="accountId" type="string">

  Merchant account ID. The PSP must not change this value over the lifetime of the merchant's account.

</ResponseField>

<ResponseField name="accountName" type="string">

  Merchant account name.

</ResponseField>

<ResponseField name="reasonCode" type="integer">

  Wix [reason code](https://dev.wix.com/docs/rest/api-reference/payment-provider-spi/reason-codes#account-connection-failure) indicating a type of failed request.

</ResponseField>

<ResponseField name="errorCode" type="string">

  PSP-specific error code.

</ResponseField>

<ResponseField name="errorMessage" type="string">

  PSP-specific error message.

</ResponseField>

<ResponseField name="mode" type="string" deprecated>

  This field is deprecated.

  **Deprecated.** This field is deprecated.

  **Supported values:**

  - `undefined` — Undefined mode.
  - `live` — Request is live.
  - `sandbox` — Request is for testing purposes.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
