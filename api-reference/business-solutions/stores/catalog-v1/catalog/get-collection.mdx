<div className="wix-ref">

Retrieves a collection with the provided ID.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-STORES.READ-PRODUCTS">Read Products</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`, `MEMBER`, `VISITOR`.

## Endpoint

```http
GET https://www.wixapis.com/stores/v1/collections/{id}
```

## Path Params

<ParamField path="id" type="string" required>

  Requested collection ID.

</ParamField>

## Query Params

<ParamField query="includeNumberOfProducts" type="boolean">

  Whether to return the `collection.numberOfProducts` field in the response.
  Defaults to `false`, in which case the value of `collection.numberOfProducts` will be `0`.

</ParamField>

## Response Object

<ResponseField name="collection" type="Collection">

  The requested collection.

  <Expandable title="collection properties">

    <ResponseField name="id" type="string">

      Collection ID (generated automatically by the catalog).

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Collection name.

    </ResponseField>

    <ResponseField name="media" type="Media">

      Media items (images, videos etc) associated with this collection. Read only.

      **Read-only.**

      <Expandable title="media properties">

        <ResponseField name="mainMedia" type="MediaItem">

          Primary media (image, video etc) associated with this product.

          _Nested structure omitted for brevity — see the `MediaItem` object._

        </ResponseField>

        <ResponseField name="items" type="MediaItem[]">

          Media (images, videos etc) associated with this product.

          _Nested structure omitted for brevity — see the `MediaItem[]` object._

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="numberOfProducts" type="integer">

      Number of products in the collection. Read only.

      **Read-only.**

    </ResponseField>

    <ResponseField name="description" type="string">

      Collection description.

    </ResponseField>

    <ResponseField name="slug" type="string">

      Collection slug.

    </ResponseField>

    <ResponseField name="visible" type="boolean">

      Collection visibility. Only impacts dynamic pages, no impact on static pages. Default: `true`.

    </ResponseField>

  </Expandable>

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
