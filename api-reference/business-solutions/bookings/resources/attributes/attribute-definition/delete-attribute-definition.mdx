    Deletes an attribute definition.

    All attribute values for this attribute definition are deleted across every entity.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="bookings:attributes:v1:attribute_definition:delete_attribute_definition">bookings:attributes:v1:attribute_definition:delete_attribute_definition</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/_api/attributes/v1/attribute-definitions/{attributeDefinitionId}
    ```

    ## Path Params

    <ParamField path="attributeDefinitionId" type="string" required>

      ID of the attribute definition to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteAttributeDefinitionResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
