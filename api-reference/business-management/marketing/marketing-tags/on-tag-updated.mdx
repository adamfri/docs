Triggered when a marketing tag is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.marketing.v1.tag_updated` |
| Package | `@wix/marketing-tags` |
| Permissions | `Manage Marketing Tags`, `Read Marketing Tags` |
