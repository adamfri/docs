    Voids the given order payment request.

    Only `UNPAID` order payment requests can be voided. Voiding an order payment request that is already `VOIDED` succeeds without making any changes. Voiding a `PAID` or `EXPIRED` order payment request fails.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-payment-requests/void
    ```

    ## Body Params

    <ParamField body="orderPaymentRequestId" type="string" required>

      ID of the order payment request to void.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    Returns `VoidOrderPaymentRequestResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_PAYMENT_REQUEST_NOT_FOUND` | Couldn't find the order payment request. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_VOID_PAID_ORDER_PAYMENT_REQUEST` | Order payment requests with a `status` of `PAID` can't be voided. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_VOID_EXPIRED_ORDER_PAYMENT_REQUEST` | Order payment requests with a `status` of `EXPIRED` can't be voided. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Payment Request Voided | `wix.ecom.v1.order_payment_request_voided` | Triggered when an order payment request's `status` changes to `VOIDED`. |

    </div>
