    Updates an invoice preset.

    Each time the invoice preset is updated, `revision` increments by 1. The current `revision` must be passed when updating the invoice preset. This ensures you're working with the latest invoice preset and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/invoices/v4/invoice-presets/{invoicePreset.id}
    ```

    ## Path Params

    <ParamField path="invoicePreset.id" type="string" required>

      Invoice preset ID.

    </ParamField>

    ## Body Params

    <ParamField body="invoicePreset" type="InvoicePreset" required>

      Invoice preset to update.

      See the [Invoice Preset Object](/api-reference/business-management/get-paid/invoices/invoice-presets/invoice-preset-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="invoicePreset" type="InvoicePreset">

      Updated invoice preset.

      See the [Invoice Preset Object](/api-reference/business-management/get-paid/invoices/invoice-presets/invoice-preset-object) for this object's fields.

    </ResponseField>

    ## Errors

    | `400` | `INVALID_ARGUMENT` | `INVALID_RICH_CONTENT` | The `customFields.footerCustomField` value isn't valid rich content. Supported content includes text formatting and images. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
