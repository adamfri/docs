Triggered when a secondary locale is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.locales.v2.locale_created` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation API` |

  import { locales } from '@wix/multilingual';

      // handle your event here
  });
