The JSON object below defines the configuration for this service plugin extension. How you supply values depends on the framework you’re using:

+ **Self-hosted apps:** After adding a service plugin extension to your app in the app dashboard, provide configuration details in your extension's page. Learn more about how to add and configure a self-hosted service plugin extension with [REST](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/self-hosting/supported-extensions/backend-extensions/add-self-hosted-service-plugin-extensions-with-rest) or the [SDK](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/self-hosting/supported-extensions/backend-extensions/add-self-hosted-service-plugin-extensions-with-the-sdk).
+ **CLI apps:** Customize the configuration in your extension's [`<extension-name>.extension.ts`](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-cli/supported-extensions/backend/service-plugins/service-plugin-extension-files-and-code#service-plugin-builder) file.

      Action service plugin configuration

      <Expandable title="actionConfig properties">

        <ResponseField name="actionKey" type="string">

          Identifier for this action - human-readable action key - unique per app def ID

          Constraints: `minLength 5`, `maxLength 50`.

        </ResponseField>

        <ResponseField name="inputSchema" type="object">

          The action expects the following input
          The schema is described according to the JSON Schema standard: https://json-schema.org/

          Example - Add Label to Contact Action input schema:
          &#123;
          "$schema": "https://json-schema.org/draft/2020-12/schema",
          "type": "object",
          "title": "Add label to contact input schema",
          "description": "The schema of the JSON that is sent when invoking this add label to contact action",
          "default": &#123;&#125;,
          "examples": [
          &#123;
          "contactId": "a647eb32-c5f4-11ec-9d64-0242ac120002",
          "labelId": "1e8b5e5e-dba2-11ec-9d64-0242ac120002"
          &#125;
          ],
          "required": [
          "contactId",
          "labelId"
          ],
          "properties": &#123;
          "contactId": &#123;
          "$id": "#/properties/contactId",
          "type": "string",
          "format": "uuid",
          "title": "Contact Id",
          "description": "The ID of the contact to apply the label to",
          "default": "",
          "identityType": "contact" // can be contact/visitor/user, limited to 1 type per identity.
          &#125;,
          "labelId": &#123;

          "format": "uuid",
