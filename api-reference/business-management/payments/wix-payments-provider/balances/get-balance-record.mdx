    Retrieves a single balance record by ID for the specified account.

    Returns an error if the record doesn't exist or doesn't belong to the specified account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYMENTS.PAYOUTS-VIEW-FOR-SITE">View settlement reports and payouts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wixpay-balances/v5/balance-records/{balanceRecordId}
    ```

    ## Path Params

    <ParamField path="balanceRecordId" type="string" required>

      Balance record ID.

    </ParamField>

    ## Query Params

    <ParamField query="accountId" type="string" required>

      ID of the Wix Payments account that owns the balance record. The record must belong to this account. Retrieve account IDs from the Accounts API.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="record" type="BalanceRecord">

      Retrieved balance record.

      See the [Balance Record Object](/api-reference/business-management/payments/wix-payments-provider/balances/balance-record-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
