    Updates a staff member.

    Each time the staff member is updated, `revision` increments by 1. The current `revision` must be specified when updating the staff member. This ensures you're working with the latest version of the staff member and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS-MEGA.MANAGE-EVENTS">Manage Events - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/staff-members/{staffMember.id}
    ```

    <ParamField body="_id" type="string" required>

      Staff member ID.

      **Read-only.**

    </ParamField>

    <ParamField body="staffMember" type="UpdateStaffMember" required>

      Staff member to update.

      <Expandable title="staffMember properties">

        <ParamField body="_id" type="string">

          Staff member ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the staff member is updated. To prevent conflicting changes, the existing `revision` must be used when updating a staff member.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the staff member was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the staff member was updated.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Staff member name.

        </ParamField>

        <ParamField body="status" type="string">

          Staff member status. To change the status, call Update Staff Member.

          **Supported values:**

          - `PENDING` — The staff member hasn't logged in yet.
          - `HAS_ACCESS` — The staff member is logged in and has access to an event.
          - `ACCESS_PAUSED` — The access to an event is paused for the staff member.

        </ParamField>

        <ParamField body="extendedFields" type="ExtendedFields">

          Data extensions.

          <Expandable title="extendedFields properties">

            <ParamField body="namespaces" type="object">

              Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
              The value of each key is structured according to the schema defined when the extended fields were configured.

              You can only access fields for which you have the appropriate permissions.

              Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

              Constraints: `format map`.

              _Nested structure omitted for brevity — see the `object` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="permissions" type="string[]">

          Staff member permissions.

          Constraints: `maxItems 4`.

          **Supported values:**

          - `CHECK_IN_GUESTS` — The staff member can view the guest list, check in guests, and scan tickets.
          - `SELL_TICKETS` — The staff member can sell tickets.
          - `ADD_GUESTS` — The staff member can add guests to the event manually and mark their payment status.
          - `READ_ANALYTICS` — The staff member can track tickets sales, site visits, and trends.
          - `READ_GUEST_FORM` — The staff member can see the guest's form answers.

        </ParamField>

        <ParamField body="loginLink" type="string">

          Login link generated for the staff member. This link opens up the [Check-in](https://support.wix.com/en/article/check-in-by-wix-an-overview) app.

          **Read-only.**

        </ParamField>
