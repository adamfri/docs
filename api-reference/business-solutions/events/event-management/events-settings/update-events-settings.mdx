    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/settings/{eventsSettings.id}
    ```

    ## Path Params

    <ParamField path="eventsSettings.id" type="string" required>

      Events Settings ID.

    </ParamField>

    ## Body Params

    <ParamField body="eventsSettings" type="EventsSettings" required>

      Events Settings object containing the fields to update. Must include the current `revision` number to prevent conflicting changes.

      See the [Events Settings Object](/api-reference/business-solutions/events/event-management/events-settings/events-settings-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Settings categories to return in the response. Use this to optimize the response size by requesting only needed information.

      Constraints: `maxItems 6`.

      **Supported values:**

      - `SITE_INFO` — Returns site information including locale, language, and available premium features that determine Events capabilities.
      - `EVENTS_INFO` — Returns Events-related information like first event creation status and current ticket sales flags.
      - `SERVICE_FEE_SETTINGS` — Returns Wix service fee configuration, activation status, and agreement dates.
      - `PAYMENT_SETTINGS` — Returns available payment methods, delayed capture settings, and payment acceptance configuration.

    </ParamField>

    ## Response Object

    <ResponseField name="eventsSettings" type="EventsSettings">

      The updated Events Settings object reflecting the applied changes.

      See the [Events Settings Object](/api-reference/business-solutions/events/event-management/events-settings/events-settings-object) for this object's fields.

    </ResponseField>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Events Settings ID.

      **Read-only.**

    </ParamField>

    <ParamField body="eventsSettings" type="UpdateEventsSettings" required>

      Events Settings object containing the fields to update. Must include the current `revision` number to prevent conflicting changes.

      <Expandable title="eventsSettings properties">

        <ParamField body="_id" type="string">

          Events Settings ID.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the Events Settings were created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the Events Settings were last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the Events Settings are updated. To prevent conflicting changes, the current revision must be passed when updating the Events Settings.

          **Read-only.**

        </ParamField>

        <ParamField body="siteInfo" type="SiteInfo">

          Site information including locale, language, and available premium features.

          **Read-only.**

          <Expandable title="siteInfo properties">

            <ParamField body="locale" type="string">

              Site locale in IETF BCP 47 language tag format. For example, `en-US` for U.S. English.

              **Read-only.**

            </ParamField>

            <ParamField body="language" type="string">

              Site language in ISO 639-1 alpha-2 format. For example, `en`.

              **Read-only.**

            </ParamField>

            <ParamField body="premiumFeatures" type="string[]">

              Premium features available to the site. These features control access to advanced events capabilities. Use this array to determine which functionality to enable in your integration. For example, check for `SELL_TICKETS` before showing payment options.

              **Read-only.** Constraints: `maxItems 20`.

              **Supported values:**

              - `SELL_TICKETS` — Enables paid ticket sales for events. When present, the site can create paid ticket definitions and process payments through configured payment providers.
              - `INCLUDE_URL_IN_EMAIL` — Allows including custom URLs in event notification emails sent to attendees. Useful for adding registration links, additional information, or branded content in emails.
              - `HIDE_FOOTER_IN_EMAIL` — Removes Wix branding from event notification emails. Provides a fully customized email without Wix attribution in the footer.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="eventsInfo" type="EventsInfo">

          Global information about the site's events, including whether any events have been created and current ticket sales status.

          **Read-only.**

          <Expandable title="eventsInfo properties">

            <ParamField body="firstEventCreated" type="boolean">

              Whether the site has created its first event.

              **Read-only.**

            </ParamField>

            <ParamField body="sellingTickets" type="boolean">

              Whether any events on the site sell tickets, including both free and paid tickets.

              **Read-only.**

            </ParamField>

            <ParamField body="sellingPaidTickets" type="boolean">

              Whether any events on the site sell paid tickets specifically. Requires both ticket definitions with non-zero prices and the `SELL_TICKETS` premium feature.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="serviceFeeSettings" type="ServiceFeeSettings">

          Settings for Wix service fees applied to paid ticket sales.

          **Read-only.**

          <Expandable title="serviceFeeSettings properties">

            <ParamField body="serviceFeeEnabled" type="boolean">

              Whether Wix service fees are applied to paid ticket sales.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="paymentSettings" type="PaymentSettings">

          Payment configuration including available payment methods, coupon acceptance, and delayed capture settings.

          <Expandable title="paymentSettings properties">

            <ParamField body="ticketSalesEnabled" type="boolean">

              Whether ticket sales are enabled for the site. Free ticket sales are always available; paid ticket sales require the `SELL_TICKETS` premium feature and configured payment providers.

              **Read-only.**

            </ParamField>

            <ParamField body="activePaymentMethods" type="PaymentMethod[]">

              Payment methods currently available for ticket checkout. Automatically populated based on the site's payment provider configuration. Common methods include credit cards, PayPal, and digital wallets.

              **Read-only.** Constraints: `maxItems 100`.

              _Nested structure omitted for brevity — see the `PaymentMethod[]` object._

            </ParamField>

            <ParamField body="couponsAccepted" type="boolean">

              Whether discount coupons can be used during ticket checkout. Automatically enabled when at least one coupon exists on the site.

              **Read-only.**

            </ParamField>

            <ParamField body="giftCardsAccepted" type="boolean">

              Whether gift cards can be used during ticket checkout. Requires gift card functionality to be enabled at the site level.

              **Read-only.**

            </ParamField>

            <ParamField body="delayedPaymentCaptureSettings" type="DelayedPaymentCaptureSettings">

              Configuration for delayed payment capture, allowing payments to be authorized at purchase but captured later. This setting applies to all events on the site and can be updated through the API.

              _Nested structure omitted for brevity — see the `DelayedPaymentCaptureSettings` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>
