    <div className="wix-ref">

    Retrieves the answers to the membership questions, given the provided filters.

    <Note>

    This endpoint requires [visitor or member authentication](https://dev.wix.com/docs/rest/articles/getting-started/access-types-and-permissions).

    </Note>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-groups-proxy/questions/v2/membership-questions/{groupId}/answers
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Body Params

    <ParamField body="memberIds" type="string[]">

      Member IDs. If no member ID is provided, answers for all members will be returned. See the Members API for more details.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    <ParamField body="paging" type="Paging">

      paging

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField body="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="memberAnswers" type="MemberMembershipQuestionAnswers[]">

      Answers to the membership questions, grouped by member.

      <Expandable title="memberAnswers properties">

        <ResponseField name="memberId" type="string">

          Member ID. See the Members API for more details.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="answers" type="MembershipQuestionAnswer[]">

          Answers to the membership question.

          <Expandable title="answers properties">

            <ResponseField name="id" type="string">

              Question ID.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="text" type="string">

              Answer text.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="questions" type="object">

      Membership questions by question ID. Includes only questions that have been answered by the specified members.

      Constraints: `format map`.

      <Expandable title="questions properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="MembershipQuestion">

          See the [Membership Question Object](/api-reference/crm/community/groups/member-management/membership-questions/membership-question-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      metadata

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
