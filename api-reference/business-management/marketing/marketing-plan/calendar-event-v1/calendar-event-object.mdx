---
title: "Calendar Event Object"
description: "A custom event that a site owner adds to their marketing content calendar, such as a sale, holiday, product launch, or business milestone."
icon: "cube"
---

A custom event that a site owner adds to their marketing content calendar, such as a sale,
holiday, product launch, or business milestone. These events give the AI additional context
when generating a marketing plan: plan activities can be scheduled around them. The events
themselves do not directly create marketing activities.

An event can be one-time (set `date`) or recurring (set `recurringRule`). If both are sent,
`recurringRule` takes precedence.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Unique event ID. Assigned on creation.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Display name of the event (for example, "Summer Sale" or "Independence Day").

    </ResponseField>

    <ResponseField name="date" type="datetime">

      Date and time of the event. Set this field for a one-time event. For a recurring event, set
      `recurringRule` instead. If both are sent, `recurringRule` takes precedence and `date` is
      ignored. If neither is sent, the request fails with `INVALID_ARGUMENT`.

    </ResponseField>

    <ResponseField name="calendarId" type="string">

      ID of the marketing calendar this event belongs to.

      **Read-only.**

    </ResponseField>

    <ResponseField name="recurringRule" type="RecurringRule">

      Recurrence rule for the event. Set this field for a recurring event (weekly, monthly, or
      yearly). If both `recurringRule` and `date` are sent, `recurringRule` takes precedence and
      `date` is ignored. `frequency` is required and must not be `UNKNOWN`; omitting it returns a
      `FAILED_PRECONDITION` error.

      <Expandable title="recurringRule properties">

        <ResponseField name="frequency" type="string">

          How often the event repeats.

          **Supported values:**

          - `WEEKLY` — The event repeats every week.
          - `MONTHLY` — The event repeats every month.
          - `YEARLY` — The event repeats every year.

        </ResponseField>

        <ResponseField name="weekDay" type="integer">

          Day of the week the event falls on, where `0` is Monday and `6` is Sunday. Used with `WEEKLY` frequency.

        </ResponseField>

        <ResponseField name="monthDay" type="integer">

          Day of the month the event falls on. Used with `MONTHLY` frequency.

        </ResponseField>

        <ResponseField name="month" type="integer">

          Month of the year the event falls in, where `1` is January and `12` is December. Used with `YEARLY` frequency.

        </ResponseField>

        <ResponseField name="occurrencePosition" type="integer">

          Ordinal position of the occurrence within the period (for example, `2` means "the 2nd Monday of the month"). Used with `MONTHLY` frequency alongside `weekDay`.

        </ResponseField>

        <ResponseField name="startDate" type="datetime">

          Date from which the recurrence starts.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="recurringOccurrences" type="RecurringEventOccurrence[]">

      Computed individual occurrences of a recurring event. Read-only; populated only in
      `QueryEvents` responses, and only for occurrences within the requested date range.

      **Read-only.** Constraints: `minItems 0`, `maxItems 100`.

      <Expandable title="recurringOccurrences properties">

        <ResponseField name="date" type="datetime">

          Date and time of this occurrence.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="description" type="string">

      Optional description providing additional context about the event.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "calendarEvent": {
          "id": "d7a341c4-196b-46e7-813c-2b0fc1847ec6",
          "name": "Summer Sale Launch",
          "description": "Summer promotion running across all social channels.",
          "date": "2026-07-05T09:00:00.000Z"
        }
      }
      ```

    </CodeGroup>
