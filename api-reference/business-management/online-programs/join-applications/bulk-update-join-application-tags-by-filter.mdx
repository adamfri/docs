    Asynchronously adds or removes tags on all join applications that match the provided filter.

    Specify which tags to assign and which tags to unassign. A tag that appears in both the list to assign and the list to unassign is assigned. Specify at least one of `assignTags` or `unassignTags`.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    To update tags on a specific list of join applications, call [Bulk Update Join Application Tags](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/bulk-update-join-application-tags).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
