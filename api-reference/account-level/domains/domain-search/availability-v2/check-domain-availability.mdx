<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Checks whether the given domain is available for purchase.

    You can purchase the specified domain in case the returned
    `availability.available` boolean is `true`. The domain is already taken
    when `false` is returned.

    The `domain` field must include the TLD. For example, `my-new-domain.com`.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.PUBLIC_API_PERMISSION">DOMAINS.PUBLIC_API_PERMISSION</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/premium/domains/v2/check-domain-availability
    ```

    ## Query Params

    <ParamField query="domain" type="string" required>

      Domain name. Must include the TLD. For example, `my-new-domain.com`. Only
      alphanumeric characters, hyphens, and dots are supported.

      Min: 3 characters
      Max: 63 characters

      Constraints: `format HOSTNAME`.

    </ParamField>

    ## Response Object

    <ResponseField name="availability" type="DomainAvailability">

      Information about the domain's availability.

      <Expandable title="availability properties">

        <ResponseField name="domain" type="string">

          Domain name including TLD. For example, `my-new-domain.com`.

          Constraints: `format HOSTNAME`.

        </ResponseField>

        <ResponseField name="available" type="boolean">

          Whether the domain is available for purchase. You can purchase the
          domain in case the boolean is `true`. The domain is already taken
          when `false` is returned.

        </ResponseField>

        <ResponseField name="premium" type="boolean">

          Whether the domain has a higher price due to its perceived value or demand.

        </ResponseField>

        <ResponseField name="premiumType" type="string">

          In case the domain is premium the premium_type will represent the type of the premium domain.
          FIRST_YEAR_ONLY - only initial purchase price is  premium while the renewal will cost the regular price of the TLD.
          FIRST_YEAR_AND_RENEWAL - both initial purchase and renewal prices are premium.

          **Supported values:**

          - `FIRST_YEAR_ONLY`
          - `FIRST_YEAR_AND_RENEWAL`

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
