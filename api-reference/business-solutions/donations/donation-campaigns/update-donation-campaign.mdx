    Updates a donation campaign. Supports partial updates.

    Each update increments the campaign's `revision` by 1. To prevent conflicts, you must provide the current `revision` in the request.

    You can update campaign settings like payment options, goals, and frequencies while maintaining the existing donation history.

    To update multiple donation campaigns in a single call, use [Bulk Update Donation Campaigns](https://dev.wix.com/docs/rest/business-solutions/donations/donation-campaigns/bulk-update-donation-campaigns).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DONATIONS.MANAGE-CAMPAIGNS">Manage Donation Campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/donation-campaigns/v2/donation-campaigns/{donationCampaign.id}
    ```

    ## Path Params

    <ParamField path="donationCampaign.id" type="string" required>

      Donation campaign ID.

    </ParamField>

    ## Body Params

    <ParamField body="donationCampaign" type="DonationCampaign" required>

      Donation campaign to update. May be partial.

      See the [Donation Campaign Object](/api-reference/business-solutions/donations/donation-campaigns/donation-campaign-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="donationCampaign" type="DonationCampaign">

      Updated donation campaign.

      See the [Donation Campaign Object](/api-reference/business-solutions/donations/donation-campaigns/donation-campaign-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `SITE_CURRENCY_UNAVAILABLE` | Site currency settings are temporarily unavailable. Try again later. |
    | `400` | `INVALID_ARGUMENT` | `NO_PAYMENT_DEFINITION` | Either `customAmountEnabled` must be set to `true` or at least one amount must be provided in `predefinedDonationAmounts`. |
    | `400` | `INVALID_ARGUMENT` | `NON_POSITIVE_CAMPAIGN_GOAL_AMOUNT` | The `campaignGoal.targetAmount` must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CUSTOM_AMOUNT_RANGE` | The `customAmountOptions.maximum` must be greater than `customAmountOptions.minimum`. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_PREDEFINED_AMOUNTS` | The `predefinedDonationAmounts` array contains duplicate amounts. |
    | `400` | `INVALID_ARGUMENT` | `NON_POSITIVE_PREDEFINED_AMOUNT` | All amounts in `predefinedDonationAmounts` must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_CAMPAIGN_NAME` | Campaign `name` can't be empty. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

        <ParamField body="archived" type="boolean">

          Whether the donation campaign is archived and hidden from site visitors.
          Archived campaigns can't accept donations.

          Default: `false`

        <ParamField body="status" type="string">

          Current status of the donation campaign.

          The status is automatically calculated based on campaign settings and current progress:
          - `COLLECTING`: Campaign is active and accepting donations
          - `EXPIRED`: Campaign has passed its end date and `acceptDonationsAfterEndDate` is `false`
          - `GOAL_REACHED`: Campaign has reached its target amount and `acceptDonationsAfterGoal` is `false`

          **Read-only.**

          **Supported values:**

          - `COLLECTING` — Campaign is actively accepting donations.
          - `EXPIRED` — Campaign has passed its `endDate` and `acceptDonationsAfterEndDate` is `false`.
          - `GOAL_REACHED` — Campaign has reached its `targetAmount` and `acceptDonationsAfterGoal` is `false`.

        </ParamField>

            </ParamField>

            <ParamField body="acceptDonationsAfterEndDate" type="boolean">

              Whether donations are accepted after `endDate`. This field is ignored if `endDate` is not set.

              Default: `false`

            </ParamField>

            <ParamField body="acceptDonationsAfterGoal" type="boolean">

              Whether donations are accepted after reaching `targetAmount`.

              Default: `true`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="commentsEnabled" type="boolean">

          Whether donors can add comments to their donations.

          Default: `false`

        </ParamField>

        <ParamField body="donationFrequencies" type="string[]">

          Donation frequencies available for this campaign.

          At least one frequency must be specified.

          Constraints: `minItems 1`, `maxItems 4`.

          **Supported values:**

          - `ONE_TIME` — One-time donation.
          - `WEEK` — Weekly recurring donation.
          - `MONTH` — Monthly recurring donation.
          - `YEAR` — Yearly recurring donation.

        </ParamField>

        <ParamField body="askDonorCoverFee" type="boolean">

          Whether to ask donors during checkout if they want to add 2.9% to their donation to cover fees.

          When `false`, fees are deducted from the donation amount,
          meaning the campaign receives less than the donor's original contribution.

          When `true`, donors are presented with an option in the checkout UI to
          add a 2.9% fee on top of their donation. This fee helps offset
          processing costs, ensuring more of the original donation reaches the campaign.
          The donor always has the choice — they are never automatically charged the fee.

          For recurring donations, if the donor opts to cover fees, the 2.9% fee
          is applied to each recurring payment (not just the first one).

          > **Notes:**
          > + The 2.9% rate is fixed and cannot be customized by campaign owners.
          > + This feature works with all payment methods and currencies.

          Default: `false`

          **Developer Preview.**
