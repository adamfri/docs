---

A function method is a link between a function and an automation, which defines the logic that runs when a function is triggered.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Function method ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Function method revision.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the function method was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the function method was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="automationId" type="string">

      ID of the automation to link to the function.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="functionId" type="string">

      ID of the function that this method links to an automation.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="methodName" type="string">

      Display name for the function method.

      Constraints: `maxLength 160`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "automationId": "e5bc4bc7-a9cc-4948-ad5d-b693f039f60f",
        "methodName": "MethodName",
        "functionId": "cf0dd172-ce83-4c55-bbd3-944922ac74ad"
      }
      ```

    </CodeGroup>
