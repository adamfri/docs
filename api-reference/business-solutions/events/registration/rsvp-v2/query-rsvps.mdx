    Retrieves a list of RSVPs, with the specified paging, filtering, and sorting.

    Query RSVPs runs with these defaults, which you can override:
    - `createdDate` is sorted in `ASC` order.
    - `paging.limit` is `100`.
    - `paging.offset` is `0`.

    To learn about working with Query methods, see [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language), [Sorting and Paging](https://dev.wix.com/docs/rest/articles/get-started/sorting-and-paging), and [Field Projection](https://dev.wix.com/docs/rest/articles/get-started/field-projection).

    <Note>

    This method is quite slow. Use the following filter pairs for the most optimal speed:
    - `eventId` and `status`
    - `eventId` and `fullyCheckedIn`
    - `eventId` and `memberId`
    - `eventId` and `contactId`
    - `eventId` and `createdDate`

    </Note>

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$nin`, `$exists` | None |
    | `eventId` | `$eq`, `$ne`, `$in`, `$nin`, `$exists` | None |
    | `memberId` | `$eq`, `$ne`, `$in`, `$nin`, `$exists` | None |
    | `contactId` | `$eq`, `$ne`, `$in`, `$nin`, `$exists` | None |
    | `status` | `$eq`, `$ne`, `$in`, `$nin` | Sort: `ASC`, `DESC` |
    | `fullyCheckedIn` | `$eq`, `$ne`, `$in`, `$nin` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$in`, `$nin`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$nin`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
