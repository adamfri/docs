    Retrieves a list of deleted form schemas given the provided paging, filtering, and sorting.

    This method lists form schemas that have were deleted and are in the trash bin but haven't yet been permanently removed.

    You must specify a namespace equality filter. For example, `"namespace:{"$eq":"<your_namespace>"}`.

    Refer to the [supported filters and sorting article](https://dev.wix.com/docs/api-reference/crm/forms/form-schemas/supported-filters-and-sorting) for a complete list of supported filters and sorting options.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/forms/trash-bin/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery">

          Constraints: `maxItems 3`.
