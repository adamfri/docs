title: "Review Request Object"

---

A review request is a request sent to a customer to solicit a review for a specific order or specific items.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Review request ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the review request is updated.
      To prevent conflicting changes, the current revision must be passed when updating the review request.

      Ignored when creating a review request.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the review request was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the review request was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="sendDate" type="datetime">

      Date and time the review request was, or will be, sent. This field is only informational and does not trigger a send action.

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Name of the Wix app whose catalog the items being reviewed belong to.

      Supported values:
      + Wix Stores: `stores`

      Currently, only Wix Stores is fully integrated with the Wix Reviews app.

      Constraints: `minLength 1`, `maxLength 100`, `immutable`.

    </ResponseField>

    <ResponseField name="order" type="Order">

      Order that a review is requested for.

      Constraints: `immutable`.

      <Expandable title="order properties">

        <ResponseField name="id" type="string">

          Order ID.

          Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="items" type="Item[]">

      Items that a review is requested for.

      Constraints: `maxItems 5`, `immutable`.

      <Expandable title="items properties">

        <ResponseField name="catalogItemId" type="string">

          ID of the item within the catalog it belongs to.

          For example, `product.id` for items from the Stores Catalog API.

          Constraints: `minLength 1`, `maxLength 36`, `immutable`.

        </ResponseField>

        <ResponseField name="reviewId" type="string">

          ID of the review created for this item by the review request recipient.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="recipient" type="Recipient">

      Customer to send a review request to.

      Constraints: `immutable`.

      <Expandable title="recipient properties">

        <ResponseField name="contactId" type="string">

          Recipient contact ID. See the Contacts API for more information.

          Constraints: `format GUID`, `immutable`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="communicationChannel" type="string">

      Communication channel for sending the review request.

      Constraints: `immutable`.

      **Supported values:**

      - `EMAIL`

    </ResponseField>

    <ResponseField name="status" type="string">

      Review request status.

      **Read-only.**

      **Supported values:**

      - `UNKNOWN_REVIEW_REQUEST_STATUS` — Unknown review request status.
      - `SCHEDULED` — Review request scheduled.
      - `CANCELED` — Review request canceled.
      - `FAILED` — Review request failed to send.
      - `SENT` — Review request sent.

    </ResponseField>

    <ResponseField name="automationActivationId" type="string">

      ID of the automation action that triggered the review request to be created.

      This field is only used if a review request was created by the [automation included with Wix Reviews](https://support.wix.com/en/article/wix-stores-adding-and-setting-up-wix-reviews#step-3-optional-customize-review-requests).
      Also see the Automations API for more information.

    </ResponseField>

    <ResponseField name="requestedBy" type="IdentificationData">

      ID of the user or app that generated the review request.

      **Read-only.**

      <Expandable title="requestedBy properties">

        <ResponseField name="identityType" type="string">

          Identity type.

          **Read-only.**

          **Supported values:**

          - `WIX_USER`
          - `APP`

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="wixUserId" type="string">

              Wix user ID.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="appId" type="string">

              Wix app ID.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
