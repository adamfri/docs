    Returns a list of converted amounts, from the original (from) currency to the target (to) currency.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CURRENCY-CONVERTER.MANAGE-CURRENCIES">Manage Currencies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/currency_converter/v1/currencies/amounts/{from}/convert/{to}
    ```

    ## Path Params

    <ParamField path="from" type="string" required>

      Original currency.

    </ParamField>

    <ParamField path="to" type="string" required>

      Target currency.

    </ParamField>

    ## Body Params

    <ParamField body="amounts" type="DecimalValue[]">

      Amounts to convert.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="amounts properties">

        <ParamField body="value" type="string">

          Value without decimals (e.g., for 10.95 value will be 1095).

        </ParamField>

        <ParamField body="decimalPlaces" type="integer">

          Decimal places to apply (e.g., for 10.95 decimal_places will be 2).

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="amounts" type="DecimalValue[]">

      Converted amounts.

      <Expandable title="amounts properties">

        <ResponseField name="value" type="string">

          Value without decimals (e.g., for 10.95 value will be 1095).

        </ResponseField>

        <ResponseField name="decimalPlaces" type="integer">

          Decimal places to apply (e.g., for 10.95 decimal_places will be 2).

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="rateTimestamp" type="datetime">

      Date and time the conversion rate was last updated.

    </ResponseField>

    <Note>

    ```javascript Convert an array of amounts from one currency to another
    import { currencies } from '@wix/ecom';

    const identifiers = {
      'from': 'USD',
      'to': 'GBP'
    };

    const amounts =	[ 
      {
        'decimalPlaces': 2,
        'value': '1000'
      },
      {
        'decimalPlaces': 2,
        'value': '20324'
      } 
    ];

    currencies.convertCurrency(identifiers, amounts)
      .then((convertedAmounts) => {
        const firstConvertedAmount = convertedAmounts.amounts[0];
        const timestamp = convertedAmounts.rateTimestamp;
    ```
