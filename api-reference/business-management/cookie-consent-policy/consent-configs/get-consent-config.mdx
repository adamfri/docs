    Retrieves a consent config.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CONSENT_CONFIG.MANAGE">Consent config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bu/legal/v1/consent-configs/{consentConfigId}
    ```

    ## Path Params

    <ParamField path="consentConfigId" type="string" required>

      Consent config ID to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="consentConfig" type="ConsentConfig">

      Requested consent config.

      See the [Consent Config Object](/api-reference/business-management/cookie-consent-policy/consent-configs/consent-config-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
