    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves the sitemaps submitted for the site, with Google's processing
    details for each: content counts, warnings, errors, and download dates.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gsc/v1/sitemaps
    ```

    ## Response Object

    <ResponseField name="sitemaps" type="Sitemap[]">

      The sitemaps submitted for the site, with Google's processing details.

      <Expandable title="sitemaps properties">

        <ResponseField name="url" type="string">

          URL of the sitemap.

          **Read-only.** Constraints: `format WEB_URL`.

        </ResponseField>

        <ResponseField name="type" type="string">

          Type of the sitemap. For example, `sitemap` or `rssFeed`.

          **Read-only.** Constraints: `maxLength 100`.

        </ResponseField>

        <ResponseField name="pending" type="boolean">

          Whether the sitemap hasn't been processed by Google yet.

          **Read-only.**

        </ResponseField>

        <ResponseField name="sitemapsIndex" type="boolean">

          Whether the sitemap is an index of other sitemaps.

          **Read-only.**

        </ResponseField>

        <ResponseField name="lastDownloadedDate" type="datetime">

          Date and time Google last downloaded the sitemap.

          **Read-only.**

        </ResponseField>

        <ResponseField name="lastSubmittedDate" type="datetime">

          Date and time the sitemap was last submitted.

          **Read-only.**

        </ResponseField>

        <ResponseField name="errorCount" type="string">

          Number of issues with the sitemap itself. Errors must be fixed before
          Google can process the sitemap correctly.

          **Read-only.**

        </ResponseField>

        <ResponseField name="warningCount" type="string">

          Number of non-critical issues with URLs in the sitemap.

          **Read-only.**

        </ResponseField>

        <ResponseField name="contents" type="SitemapContent[]">

          Breakdown of the sitemap's contents by content type.

          **Read-only.** Constraints: `maxItems 100`.

          <Expandable title="contents properties">

            <ResponseField name="type" type="string">

              Content type. For example, `web` or `image`.

              **Read-only.** Constraints: `maxLength 100`.

            </ResponseField>

            <ResponseField name="submittedCount" type="string">

              Number of URLs of this content type in the sitemap.

              **Read-only.**

            </ResponseField>

            <ResponseField name="indexedCount" type="string">

              Number of URLs of this content type that Google has indexed.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_TOKEN` | No Google account is connected for this site. Connect first with the GSC Connection API. |
    | `429` | `RESOURCE_EXHAUSTED` | `GOOGLE_QUOTA_EXCEEDED` | Google's API quota for the property is used up. Retry after the quota window resets. |
    | `503` | `UNAVAILABLE` | `GOOGLE_UNAVAILABLE` | Google answered with a temporary server error. Retry with backoff. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
