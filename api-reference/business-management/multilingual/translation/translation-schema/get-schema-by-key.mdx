    Retrieves a translation schema by key.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.READ_TRANSLATION_SCHEMA">Wix Multilingual - Translation Schema Read</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/translation-schema/v1/schemas/app-id/{key.appId}/entity-type/{key.entityType}/scope/{key.scope}
    ```

    ## Path Params

    <ParamField path="key.appId" type="string" required>

      ID of the app that created the schema.

    </ParamField>

    <ParamField path="key.entityType" type="string" required>

      A unique name defined by the app developer to differentiate translation schemas for various entities within their app. For example, if an app developer is creating a translation schema for blog posts, the `entityType` can be `'blog-posts'`.

    </ParamField>

    <ParamField path="key.scope" type="string" required>

      Scope of the translation schema.

    </ParamField>

    ## Query Params

    <ParamField query="key" type="SchemaKey" required>

      ID of the translation schema to retrieve.

      <Expandable title="key properties">

        <ParamField query="appId" type="string">

          ID of the app that created the schema.

          **Read-only.** Constraints: `format GUID`.

        </ParamField>

        <ParamField query="entityType" type="string">

          A unique name defined by the app developer to differentiate translation schemas for various entities within their app. For example, if an app developer is creating a translation schema for blog posts, the `entityType` can be `'blog-posts'`.

          Constraints: `minLength 1`, `maxLength 100`, `immutable`.

        </ParamField>

        <ParamField query="scope" type="string">

          Scope of the translation schema.

          Constraints: `immutable`.

          **Supported values:**

          - `GLOBAL` — Global schema for all sites.
          - `SITE` — Custom schema for a specific site.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="schema" type="Schema">

      The requested translation schema.

      See the [Schema Object](/api-reference/business-management/multilingual/translation/translation-schema/schema-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
