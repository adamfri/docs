    <div className="wix-ref">

    Retrieves a list of up to 100 join group requests, given the provided paging.

    Default sorts to created date in descending order.

    Only group admins can see requests to join their group. Site members can access their own join requests in a site.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-groups-proxy/join/v2/groups/{groupId}/join-requests
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Query Params

    <ParamField query="limit" type="integer">

      Maximum number of join group requests to retrieve. Defaults to 100.

    </ParamField>

    <ParamField query="offset" type="integer">

      Number of join group requests to skip in the list.

    </ParamField>

    ## Response Object

    <ResponseField name="joinGroupRequests" type="JoinGroupRequest[]">

      Retrieved join group requests.

      See the [Join Group Request Object](/api-reference/crm/community/groups/member-management/join-requests/join-group-request-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      metadata

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>
