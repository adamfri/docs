    Asynchronously updates tags on multiple attribute definitions that match the provided filter criteria.

    An empty filter updates all attribute definitions. A tag that appears in both the list to assign and the list to unassign will be assigned. Tags that don't exist are ignored.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="bookings:attributes:v1:attribute_definition:bulk_update_attribute_definition_tags_by_filter">bookings:attributes:v1:attribute_definition:bulk_update_attribute_definition_tags_by_filter</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/attributes/v1/bulk/attribute-definitions/update-tags-by-filter
    ```
