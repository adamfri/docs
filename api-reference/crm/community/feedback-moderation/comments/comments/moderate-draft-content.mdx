    Moderates the draft content of a comment.

    - `APPROVE`: Moves `draftContent` to `content` and updates the comment `status` to `PUBLISHED`.

    - `REJECT`: Handles the draft content based on the current comment status:
    - If the comment `status` is `PUBLISHED`, clears `draftContent`.
    - If the comment `status` is `PENDING`, keeps `draftContent` unchanged and changes `status` to `HIDDEN`.

    To moderate multiple comments, call Bulk Moderate Draft Content.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.MANAGE.COMMENTS">Manage Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/comments/v1/comments/{commentId}/moderate
    ```

    ## Path Params

    <ParamField path="commentId" type="string" required>

      ID of the comment to moderate.

    </ParamField>

    ## Body Params

    <ParamField body="revision" type="integer" required>

      Revision number, which increments by `1` each time the comment is updated.

      To prevent conflicting changes, the current `revision` must be passed when updating the comment.

    </ParamField>

    <ParamField body="draftContentAction" type="string">

      Draft content action.

      **Supported values:**

      - `APPROVE` — Approve draft content.
      - `REJECT` — Reject draft content.

    </ParamField>

    ## Response Object

    <ResponseField name="comment" type="Comment">

      Moderated comment.

      See the [Comment Object](/api-reference/crm/community/feedback-moderation/comments/comments/comment-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Comment Updated | `wix.comments.v2.comment_updated` | Triggered when a comment is updated. |
    | Comment Published | `wix.comments.v2.comment_comment_published` | Triggered when a comment is published. |
    | Comment Hidden | `wix.comments.v2.comment_comment_hidden` | Triggered when a comment is hidden. |
    | Comment Content Changed | `wix.comments.v2.comment_comment_content_changed` | Triggered when comment content is updated. |
    | Resource Comment Count Changed | `wix.comments.v2.comment_resource_comment_count_changed` | Triggered when the total number of comments has changed in a resource. |
