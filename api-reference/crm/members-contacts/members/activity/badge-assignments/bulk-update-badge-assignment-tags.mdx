    Updates tags on multiple badge assignments.

    Allows adding or removing tags from multiple badge assignments in a single operation. Specify badge IDs and the tags to assign or unassign. If a tag appears in both assign and unassign lists, it will be assigned.

    Use this for immediate tag updates on a known set of badge assignments.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/badges/v4/bulk/assignments/bulk-update-tags
    ```
