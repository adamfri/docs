    Installs an app on a site using a share URL.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEV_CENTER.INSTALL-APPS">The app will be able to manage application installations on this site.</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps-installer-service/v1/app-share-url/install
    ```

    ## Body Params

    <ParamField body="tenant" type="Tenant" required>

      Tenant details.

      <Expandable title="tenant properties">

        <ParamField body="id" type="string" required>

          Tenant ID. For a site, this is the [site ID](https://dev.wix.com/docs/rest/account-level/sites/sites/introduction). For an account this is the [account ID](https://dev.wix.com/docs/rest/account-level/user-management/accounts/accounts/about-accounts).

        </ParamField>

        <ParamField body="tenantType" type="string">

          Tenant type. This can be a Wix site or account.

          **Supported values:**

          - `SITE`
          - `ACCOUNT`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="shareUrlId" type="string" required>

      ID of the share URL to install the app from.

      To get the share URL of an app:

      1. [Generate an install link](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard-setup/share-your-app-with-an-install-link).

      2. Click the link, which will redirect you to a page where you can install the app. The URL of this page is the share URL, and the string after `install/` in the URL is the share URL ID. For example, in the share URL `https://www.wix.com/app-market/install/8d5179a2-6d46-45b0-bcfa-64f479c6a2al`, the share URL ID is `8d5179a2-6d46-45b0-bcfa-64f479c6a2al`.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="devVersion" type="DevVersionInstallation">

      Information about the development version of the app to install. Only relevant if the share URL refers to a development version of an app created in the Wix CLI.

      <Expandable title="devVersion properties">

        <ParamField body="overrideId" type="string">

          ID of the override to assign to the development version.

          Constraints: `maxLength 50`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="appInstance" type="AppInstance">

      App instance created when the app was installed.

      See the [App Instance Object](/api-reference/business-management/app-installation/app-installation/app-instance-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_TENANT_TYPE` | Tenant type isn't supported for this operation. |
    | `400` | `INVALID_ARGUMENT` | `SHARE_URL_IS_REVOKED` | Share URL has been revoked and can't be used for installation. |
    | `404` | `NOT_FOUND` | `SHARE_URL_NOT_FOUND` | Couldn't find the share URL. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
