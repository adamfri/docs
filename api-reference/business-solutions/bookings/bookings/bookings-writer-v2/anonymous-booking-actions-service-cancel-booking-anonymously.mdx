    Cancels a booking using an anonymous token.

    This method doesn't require standard authentication. Pass a token generated by [Get Anonymous Action Token](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/get-anonymous-action-token) instead.

    Before calling this method, check that `allowedAnonymousActions.cancel` is `true` in the [Get Booking Anonymously](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/anonymous-booking-actions-service-get-booking-anonymously) response.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/anonymous-bookings/{token}/cancel
    ```

    ## Path Params

    <ParamField path="token" type="string" required>

      Anonymous token for the booking.

    </ParamField>

    ## Body Params

    <ParamField body="revision" type="integer" required>

      Revision number, which increments by 1 each time the booking is updated.
      To prevent conflicting changes, the current revision must be passed when canceling the booking.

    </ParamField>

    ## Response Object

    <ResponseField name="booking" type="Booking">

      Canceled booking.

      See the [Booking Object](/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/booking-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `INVALID_TOKEN` | Token is invalid, expired, or cannot be decrypted. |
    | `404` | `NOT_FOUND` | `BOOKING_NOT_FOUND` | Couldn't find the booking encoded in the token. |
    | `428` | `FAILED_PRECONDITION` | `BOOKING_CANNOT_BE_CANCELLED` | Cancellation is not allowed for this booking. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
