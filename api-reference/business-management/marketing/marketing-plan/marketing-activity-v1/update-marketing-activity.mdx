    Updates a marketing activity.

    Supports partial updates via `field_mask`. Only `title`, `description`, and `targetDate` can be updated.
    Listing any other field in the `fieldMask` returns an error. Omitted fields are left unchanged.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/promote/marketing-plan-service/v1/items/{marketingActivity.id}
    ```

    ## Path Params

    <ParamField path="marketingActivity.id" type="string" required>

      Unique activity ID. Assigned on creation and read-only afterwards.

    </ParamField>

    ## Body Params

    <ParamField body="marketingActivity" type="MarketingActivity" required>

      Marketing activity with updated field values. The `id` field must be set.

      See the [Marketing Activity Object](/api-reference/business-management/marketing/marketing-plan/marketing-activity-v1/marketing-activity-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="marketingActivity" type="MarketingActivity">

      The marketing activity after applying the update.

      See the [Marketing Activity Object](/api-reference/business-management/marketing/marketing-plan/marketing-activity-v1/marketing-activity-object) for this object's fields.

    </ResponseField>

          Category of marketing action this activity represents.

          **Supported values:**

          - `SOCIAL_MARKETING` — Activity targets social media channels (e.g. Facebook, Instagram).

              - `EVENT` — Activity was generated based on a site event.

              - `CONTENT_PILLARS` — Activity was generated based on the site's content pillars.

            </ParamField>

            <ParamField body="value" type="string">

              The specific value of the source input (for example, an event name or a keyword string).

            </ParamField>

          </Expandable>

              - `STORES_PRODUCT` — A Wix Stores product.
              - `BOOKINGS_SERVICE` — A Wix Bookings service.

              ID of the asset within its provider's data store.
