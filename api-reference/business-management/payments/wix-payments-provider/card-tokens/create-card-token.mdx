Create a card token to securely perform a credit card transaction.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="PAYMENTS.CARD_TOKENS_CREATE">PAYMENTS.CARD_TOKENS_CREATE</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

## Endpoint

```http
POST /v1/card-tokens
```

## Body Params

<ParamField body="cardNumber" type="string">

  Credit/debit card number. If absent CVV token is returned instead

</ParamField>

<ParamField body="securityCode" type="string">

  Credit/debit card security code (CVV).

</ParamField>

## Response Object

<ResponseField name="cardToken" type="CardToken">

  Generated credit/debit card token.

  See the [Card Token Object](/api-reference/business-management/payments/wix-payments-provider/card-tokens/card-token-object) for this object's fields.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
