    Approves a member's request to join a program.

    Changes `status` from `APPROVAL_PENDING` to `APPROVED`. Returns an error if the join application has any other status.

    For a free program, a participant is created immediately. If the program requires payment, `paymentStatus` is updated and the member must complete payment before a participant is created.

    To reject the request instead, call [Decline Join Application](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/decline-join-application).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}/approve
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to approve.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Approved join application.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVALID_JOIN_APPLICATION_STATUS` | The join application isn't in `APPROVAL_PENDING` status, which approval requires. |
    | `428` | `FAILED_PRECONDITION` | `PREMIUM_PLAN_REQUIRED` | The site needs a Premium plan to add more participants. |
    | `428` | `FAILED_PRECONDITION` | `PARTICIPANTS_LIMIT_EXCEEDED` | The program's participant limit has been reached. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | Join Application Status Changed | `wix.online_programs.participants.v3.join_application_status_changed` | Triggered when a join application's `status` changes. |
