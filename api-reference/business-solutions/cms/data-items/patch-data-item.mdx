    Patches an item in a collection.

    Call this method when you need a partial update and want fields that aren't mentioned in the request to stay unchanged. Patch requests are also the right place to use `fieldModifications` actions such as `SET_FIELD` for a direct replacement and `INCREMENT_FIELD` for arithmetic changes. For different behavior, you can call:

    - [Update Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/update-data-item) to replace the full payload rather than patch part of it.
    - [Save Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/save-data-item) for upsert behavior, meaning to create if the item doesn't exist and update if it does.

    This method modifies the specified item's existing data. Unlike [`Update Data Item`](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/update-data-item), only the fields specified in the request are modified. Data that isn't explicitly modified remains unchanged.

    To patch an item, specify its ID, the ID of the collection that contains it, and the modifications you want to apply. If an item is found in the specified collection with the specified ID, that item is patched. If the collection doesn't contain an item with that ID, the request fails.

    <Note>

    - When an item is patched, its `data._updatedDate` property is updated to the current date and time.
    - You can only patch items in [collections created by Wix users](https://support.wix.com/en/article/cms-formerly-content-manager-creating-a-collection). Items in [Wix app collections](https://dev.wix.com/docs/develop-websites/articles/databases/wix-data/collections/working-with-wix-app-collections-and-code) cannot be patched.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/data/v2/items/{patch.dataItemId}
    ```

    ## Path Params

    <ParamField path="patch.dataItemId" type="string" required>

      ID of the item to patch.

    </ParamField>

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection that contains the item to patch.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="patch" type="Patch" required>

      Patch to apply to the item.

      <Expandable title="patch properties">

        <ParamField body="dataItemId" type="string" required>

          ID of the item to patch.

          Constraints: `maxLength 256`.

        </ParamField>

        <ParamField body="fieldModifications" type="FieldModification[]" required>

          Modifications to apply.

          Constraints: `minItems 1`, `maxItems 100`.

          <Expandable title="fieldModifications properties">

            <ParamField body="fieldPath" type="string" required>

              Path of the field to be modified. For example: `title`.

              Nested fields can be specified using dot notation. For example: `address.street`.

              Constraints: `maxLength 1000`.

            </ParamField>

            <ParamField body="action" type="string" required>

              Patch action to apply to the specified field.

              **Supported values:**

              - `SET_FIELD` — Sets the specified field to the specified value.
              - `REMOVE_FIELD` — Clears the specified field.
              - `INCREMENT_FIELD` — Increments the specified field by the specified value. To decrement, specify a negative value.
              - `APPEND_TO_ARRAY` — Appends the specified value to the array.

              Learn more about [data types in Wix Data](https://dev.wix.com/docs/rest/business-solutions/cms/data-types-in-wix-data).
              - `REMOVE_FROM_ARRAY` — Removes the first instance of the specified value from the array.

              Learn more about [data types in Wix Data](https://dev.wix.com/docs/rest/business-solutions/cms/data-types-in-wix-data).

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="publishPluginOptions" type="PublishPluginOptions">

      Options for the [Publish plugin](https://support.wix.com/en/article/cms-controlling-live-site-item-visibility-from-your-collection).

      This plugin allows items in a [data collection](https://dev.wix.com/docs/rest/business-solutions/cms/data-collections/data-collection-object) to be marked as draft or published. Published items are visible to site visitors, while draft items are not.

      <Expandable title="publishPluginOptions properties">

        <ParamField body="includeDraftItems" type="boolean">

          Whether to include draft items.

          When `true`, both published and draft items are affected. Default: `false`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="condition" type="Condition">

      Condition for patching the item.

      When a condition is provided, the item is only patched if the condition is met.

      <Expandable title="condition properties">

        <ParamField body="filter" type="object">

          Filter, changes to item(s) will only apply if they satisfy this filter.
          Learn more about filters in [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language#filters).

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="dataItem" type="DataItem">

      Patched data item.

      See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

    </ResponseField>
