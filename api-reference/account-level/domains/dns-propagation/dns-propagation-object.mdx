The DNS (Domain Name System) propagation object contains information for a domain.
Tracks whether the DNS records are correctly configured and propagated globally.
Learn more [about DNS propagation](https://support.wix.com/en/article/about-domain-propagation).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      ID of the DNS propagation. Identical to the domain name, including the [TLD](https://dev.wix.com/docs/api-reference/account-level/domains/dns-propagation/introduction#terminology) (top-level domain).

      **Read-only.** Constraints: `format HOSTNAME`.

    </ResponseField>

    <ResponseField name="domain" type="string">

      Domain name, including the [TLD](https://dev.wix.com/docs/api-reference/account-level/domains/dns-propagation/introduction#terminology). Both root domains and subdomains are supported.

      Constraints: `format HOSTNAME`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the DNS propagation
      is updated. Ignored when creating a DNS propagation.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the DNS propagation was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the DNS propagation was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the DNS propagation. Can take up to 3 days to complete.

      **Read-only.**

      **Supported values:**

      - `SUCCEEDED` — DNS propagation completed successfully. All required DNS records are properly configured and propagated.
      - `FAILED` — DNS propagation failed. One or more DNS records are incorrectly configured or haven't propagated.
      - `IN_PROGRESS` — DNS propagation is in progress. Check again later for updated status.

    </ResponseField>

    <ResponseField name="dnsResolverIncludesWixNs" type="boolean">

      Whether Wix name servers were detected among the domain's name servers.
      For subdomains, this value matches the root domain's setting.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
          "id": "example.com",
          "domain": "example.com",
          "revision": "2",
          "createdDate": "2024-01-15T10:30:00.000Z",
          "updatedDate": "2024-01-15T14:22:00.000Z",
          "status": "FAILED",
          "failureInfo": {
            "invalidRecords": ["INVALID_A_RECORD", "INVALID_CNAME_RECORD"],
            "invalidARecordInfo": {
              "expectedDnsRecords": [
                {
                  "hostName": "example.com",
                  "values": ["185.230.63.107", "185.230.63.108"]
                }
              ],
              "actualDnsRecords": [
                {
                  "hostName": "example.com", 
                  "values": ["192.168.1.1"]
                }
              ]
            },
            "invalidCnameRecordInfo": {
              "expectedDnsRecords": [
                {
                  "hostName": "www.example.com",
                  "values": ["example.com.wixdns.net"]
                }
              ],
              "actualDnsRecords": [
                {
                  "hostName": "www.example.com",
                  "values": ["old-server.example.com"]
                }
              ]
            }
          },
          "dnsResolverIncludesWixNs": true
        }
      ```

    </CodeGroup>
