  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates the `llms.txt` file entity.

    The content can be set to an empty string to create a blank file.

    To restore Wix's default content, set the `default` field to `true` and omit the `content` field.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/promote-seo-robots-server/v2/llms
    ```

    ## Body Params

    <ParamField body="llmsTxt" type="LlmsTxt">

      `llms.txt` file to update.

      See the [Llms Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/llms-txt/llms-txt-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="llmsTxt" type="LlmsTxt">

      Updated Llms txt object

      See the [Llms Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/llms-txt/llms-txt-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | — | Site ID is missing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
