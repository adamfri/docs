    Retrieves the form limits and premium features in force for the site, and the number of forms it currently has.

    Call Get Restrictions before creating or updating a form to check the change against the site's plan. A form that
    exceeds a limit, or that uses a feature absent from `restrictions.features`, is rejected. Compare
    `totalFormCount` with `restrictions.formsLimit` to check whether the site can add another form, and use each
    limit's `warnThreshold` to warn a site owner who is approaching it.

    The limits come from the site's premium plan and change when the plan changes. When a plan change leaves a form
    over a limit, the form is disabled rather than deleted: it stops accepting submissions, but it and its
    submissions remain readable.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/form-app-service/v4/restrictions
    ```

    ## Response Object

    <ResponseField name="restrictions" type="PremiumRestrictions">

      Form limits and premium features in force for the site.

      See the [Restrictions Object](/api-reference/crm/forms/form-restrictions/restrictions-object) for this object's fields.

    </ResponseField>

    <ResponseField name="totalFormCount" type="integer">

      Number of forms on the site that count toward `restrictions.formsLimit`.

      Forms in the trash bin aren't counted. When the count can't be retrieved, the call still succeeds and this field
      is `0`, so treat `0` as unknown rather than as an empty site before using it to decide whether a form can be
      added.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
