    <div className="wix-ref">

    Updates the special permissions for the specified user or role.

    <Note>

    Special permissions that aren't explicitly included in the request are set to `UNSPECIFIED` and replaced by [collection-level permissions](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-permissions/introduction#collection-level-permissions).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v1/permissions/special/{specialPermissions.id}
    ```

    ## Path Params

    <ParamField path="specialPermissions.id" type="string" required>

      ID of the special permissions set.

    </ParamField>
