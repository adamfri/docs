    Retrieves a list of up to 50 components, given the provided paging, filtering, and sorting.

    Query Component runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order
    - `cursorPaging.limit` is `50`

    The query must filter by `appId`. Supported fields for filtering and sorting are `id`, `appId`, `version`, `externalId`, and `type`.

    To learn about working with Query methods, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language), [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging), and [Field Projection](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith`, `$gt`, `$lt`, `$lte`, `$gte` | Sort: `ASC`, `DESC` |
    | `appId` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith`, `$gt`, `$lt`, `$lte`, `$gte` | Sort: `ASC`, `DESC` |
    | `version` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$lt`, `$lte`, `$gt`, `$gte` | Sort: `ASC`, `DESC` |
    | `externalId` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith`, `$gt`, `$lt`, `$lte`, `$gte` | Sort: `ASC`, `DESC` |
    | `type` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome` | Sort: `ASC`, `DESC` |
