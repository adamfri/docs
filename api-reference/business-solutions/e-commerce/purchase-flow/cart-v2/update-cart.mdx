    Updates a cart.

    Use this endpoint to set and replace fields such as `note` and the delivery method.
    To add or remove list elements (line items, coupons, gift cards), use the dedicated endpoints.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2_LIMITED">Write Carts V2 (PII)</span>
    <span className="wix-scope" title="SCOPE.ECOM.MANAGE-ADMIN">Manage eCommerce - Admin Permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v2/carts/{cart.id}
    ```

    ## Path Params

    <ParamField path="cart.id" type="string" required>

      Cart ID.

    </ParamField>

    ## Body Params

    <ParamField body="cart" type="Cart" required>

      Cart to update. May be partial.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CART_ALREADY_ORDERED` | Cart was already placed as an order. |
    | `400` | `INVALID_ARGUMENT` | `BUSINESS_LOCATION_NOT_FOUND` | Couldn't find the business location. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_ADDRESS_FORMAT` | The address format is invalid. |
    | `428` | `FAILED_PRECONDITION` | `DATA_EXTENSION_UPDATE_FAILED` | Extended fields couldn't be updated. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Cart Updated | `wix.ecom.v2.cart_updated` | Triggered when a cart is updated. |

    </div>
