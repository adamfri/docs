    <div className="wix-ref">

    Deletes multiple services by filter.

    See [Delete Service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/delete-service)
    for more details about deleting a service.

    The call succeeds even if one or more individual services can't be deleted.
    Information about failures is returned in `bulkActionMetadata`.

    Refer to the [supported filters article](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/introduction#services-filtering-and-sorting)
    for more details.

    To learn about working with filters in general, see
    [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#filters).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bulk/services/delete-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter to identify the services that need to be deleted.

    </ParamField>

    <ParamField body="preserveFutureSessionsWithParticipants" type="boolean">

      Whether to preserve future sessions with participants.

      Default: `false`.

    </ParamField>

    <ParamField body="participantNotification" type="ParticipantNotification">

      Whether to notify participants about the change and an optional custom message.

      <Expandable title="participantNotification properties">

        <ParamField body="notifyParticipants" type="boolean">

          Whether to send a message about the changes to the customer.

          Default: `false`

        </ParamField>

        <ParamField body="message" type="string">

          Custom message to send to the participants about the changes to the booking.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      ID of the service deletion job.

      Pass this ID to [Get Async Job](https://dev.wix.com/docs/rest/business-management/async-job/introduction) to retrieve job details and metadata.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Service Deleted | `wix.bookings.services.v2.service_deleted` | Triggered when a service is deleted. |

    </div>
