    Resumes the specified program.

    Call this method for paused programs.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/programs/resume
    ```

    ## Body Params

    <ParamField body="programId" type="string" required>

      ID of program to resume.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="idempotencyKey" type="string" required>

      Idempotency key to ensure that the request is processed only once.

      Constraints: `maxLength 64`.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID of the resuming of the program. Retrieve job details using the [Async Job API](https://dev.wix.com/docs/rest/business-management/async-job/introduction).

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PROGRAM_STATUS_TRANSITION_NOT_ALLOWED` | Program isn't paused and can't be resumed. |
    | `409` | `ALREADY_EXISTS` | `ALREADY_EXECUTED` | Program was already resumed. |
    | `409` | `ALREADY_EXISTS` | `IN_PROGRESS` | Program resuming is in progress. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
