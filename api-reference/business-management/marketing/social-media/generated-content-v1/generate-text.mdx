    Generates post captions from a text prompt.

    Returns suggested captions that you can add to an item's content.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-publisher/v1/generate-text
    ```

    ## Body Params

    <ParamField body="userInput" type="string" required>

      Text prompt describing the post to generate captions for.

    </ParamField>

    <ParamField body="channelName" type="string">

      Social channel to tailor the captions for.

      **Supported values:**

      - `INSTAGRAM`
      - `FACEBOOK`
      - `YOUTUBE`
      - `LINKEDIN`
      - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
      - `PINTEREST`
      - `GBP` — Google Business Profile.
      - `TIKTOK`

    </ParamField>

    <ParamField body="tone" type="string">

      Tone of voice for the captions. For example, `professional` or `playful`.

    </ParamField>

    <ParamField body="languageCode" type="string">

      2-letter language code for the generated captions in ISO 639-1 alpha-2 format.

    </ParamField>

    <ParamField body="additionalContent" type="AdditionalContent">

      Additional content to incorporate into the captions.

      <Expandable title="additionalContent properties">

        <ParamField body="url" type="string">

          URL to reference in the captions, such as a link to promote.

        </ParamField>

        <ParamField body="withHashtags" type="boolean">

          Whether to include hashtags in the captions.

        </ParamField>

        <ParamField body="addLinkInBio" type="boolean">

          Whether to add a "link in bio" reference to the captions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="GenerateTextResult[]">

      Generated caption suggestions.

      <Expandable title="results properties">

        <ResponseField name="caption" type="string">

          Generated caption.

        </ResponseField>

        <ResponseField name="title" type="string">

          Generated title.

        </ResponseField>

      </Expandable>

    </ResponseField>
