    Create multiple Tax Regions by Bulk

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/bulk/tax-regions/create
    ```

    ## Body Params

    <ParamField body="taxRegions" type="TaxRegion[]" required>

      Tax regions to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Tax Region Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-regions/tax-region-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full tax region objects in the response.

      Default: `true`

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `ALREADY_EXISTS` | A tax region with this `country` and `subdivision` already exists. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SUBDIVISION_FORMAT` | The `subdivision` format is invalid. It must be in ISO 3166-2 format. |
    | `400` | `INVALID_ARGUMENT` | `SUBDIVISIONS_NOT_SUPPORTED_FOR_COUNTRY` | Subdivisions aren't supported for the specified `country`. |
