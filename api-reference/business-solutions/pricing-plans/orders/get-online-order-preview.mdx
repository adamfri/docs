    <div className="wix-ref">

    Returns an `order` object that represents a potential online order for a site member.

    You can use this method to show a site member a preview of an online order before [creating](https://dev.wix.com/docs/rest/business-solutions/pricing-plans/pricing-plans/orders/create-online-order) it.

    This method must be called using the [site member identity](https://dev.wix.com/docs/rest/articles/getting-started/about-identities#site-member). Therefore, [Wix apps](https://dev.wix.com/docs/build-apps) can't currently call this method using REST.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PRICING-PLANS.OWN-EXTERNAL">Perform member actions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/pricing-plans/v2/checkout/orders/preview-online
    ```

    ## Body Params

    <ParamField body="planId" type="string" required>

      Plan ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="startDate" type="datetime">

      Start date and time for the plan of the order preview in a `YYYY-MM-DDThh:mm[:ss][.sss]Z` format.

      Default: Current date and time.

    </ParamField>

    <ParamField body="couponCode" type="string">

      Coupon code to apply.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Order preview. This field is undefined if the member has already reached the purchase limit for the order's plan.

      See the [Order Object](/api-reference/business-solutions/pricing-plans/orders/order-object) for this object's fields.

    </ResponseField>

    <ResponseField name="purchaseLimitExceeded" type="boolean">

      Whether the member has already reached purchase limit for the order's plan.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PRICING_PLANS_NOT_INSTALLED` | Pricing Plans app isn't installed on the site. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_IS_DISABLED` | Coupon is disabled and can't be applied. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_USAGE_EXCEEDED` | Coupon usage limit exceeded. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_LIMIT_PER_CUSTOMER_EXCEEDED` | Coupon limit per customer exceeded. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_IS_NOT_ACTIVE_YET` | Coupon isn't active yet. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_HAS_EXPIRED` | Coupon has expired. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_DOES_NOT_EXIST` | Coupon doesn't exist. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_NOT_APPLICABLE_FOR_PLAN` | Coupon can't be applied to this plan. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_INVALID_SUBTOTAL` | Subtotal is invalid for the applied coupon. |
    | `400` | `INVALID_ARGUMENT` | `undefined_not_allowed` | Undefined values aren't allowed. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_BUSINESS_ADDRESS_COUNTRY` | Business address country is missing. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_BUSINESS_ADDRESS_STATE` | Business address state is missing. |
    | `400` | `INVALID_ARGUMENT` | `invalid_sort_field` | Invalid sort field specified. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
