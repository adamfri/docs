Triggered when a postback button is clicked.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.inbox.v2.message_button_interacted` |
| Package | `@wix/inbox` |
| Permissions | `Manage Stores`, `Manage Inbox Messages`, `Read Inbox Messages` |
