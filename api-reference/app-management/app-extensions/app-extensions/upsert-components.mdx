    Creates or updates multiple components for a single app.

    For each component, if a component with the same `id` already exists, it's updated. Otherwise, it's created. All components must belong to the same app. Each result indicates whether the operation succeeded for that component.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/apps/v1/components/v1/components
    ```

    ## Body Params

    <ParamField body="components" type="Component[]" required>

      Components to create or update.

      Constraints: `minItems 0`, `maxItems 100`.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="UpsertComponentStatus[]">

      Upsert results.

      <Expandable title="results properties">

        <ResponseField name="component" type="Component">

          Component that was created or updated.

          See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

        </ResponseField>

        <ResponseField name="success" type="boolean">

          Whether the operation succeeded for this component.

        </ResponseField>

        <ResponseField name="error" type="string">

          Error message, when the operation fails.

        </ResponseField>

        <ResponseField name="errorCode" type="string">

          Error code, when the operation fails.

        </ResponseField>

        <ResponseField name="errorData" type="object">

          Structured error payload, when provided.

        </ResponseField>

      </Expandable>

    </ResponseField>
