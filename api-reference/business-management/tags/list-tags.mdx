<Tabs>

  <Tab title="REST">

    Retrieves a list of tags.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.READ-TAGS">Read Tags</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/tags/v1/tags
    ```

    ## Query Params

    <ParamField query="fqdn" type="string" required>

      The Fully Qualified Domain Name (FQDN) to which the tags are associated. Currently supports only eCommerce Orders: `wix.ecom.v1.order`.

      Constraints: `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="tags" type="Tag[]">

      A list of tags.

      See the [Tag Object](/api-reference/business-management/tags/tag-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
