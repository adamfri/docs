    <div className="wix-ref">

    Retrieves a list of all Wix-supported locales that can be added to a site.

    Call this method to display supported language details when creating or updating a locale.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/locales/v2/locales/supported
    ```

    ## Query Params

    <ParamField query="languageCode" type="string">

      Language to filter by. For example, `"en"` for all English locales.

    </ParamField>

    <ParamField query="includeAllLocales" type="boolean">

      Whether to include all possible regional variants for each language code in the response. When `false`, only the default locale, such as `"en-US"`, is returned and regional variants like `"en-GB"` and `"en-AU"` are excluded.

    </ParamField>

    <ParamField query="includeRegionOptions" type="boolean">

      Whether to include region-specific options such as flags and regional codes for each locale in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="supportedLocales" type="SupportedLocale[]">

      A list of all the locales that can be added to a site.

      <Expandable title="supportedLocales properties">

        <ResponseField name="id" type="string" />

        <ResponseField name="languageCode" type="string">

          Language code.

        </ResponseField>

        <ResponseField name="regionCode" type="string">

          Region code.

        </ResponseField>

        <ResponseField name="defaultFlag" type="string">

          Default flag code for the locale.

        </ResponseField>

        <ResponseField name="defaultRegionalFormat" type="string">

          Default format for how to display data types such as dates, times, numbers, and currencies.

        </ResponseField>

        <ResponseField name="machineTranslationCode" type="string">

          Language code used when content is sent for machine translation.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Display name of the locale.

        </ResponseField>

        <ResponseField name="regionOptions" type="RegionOptions[]">

          All flags and their regional formats per locale.

          Constraints: `maxItems 100`.

          <Expandable title="regionOptions properties">

            <ResponseField name="flag" type="string">

              Flag code of the region.

            </ResponseField>

            <ResponseField name="regionalFormat" type="string">

              Format for how to display data types such as dates, times, numbers, and currencies.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
