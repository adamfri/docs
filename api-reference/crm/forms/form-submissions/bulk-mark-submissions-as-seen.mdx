    <Note>

    The Form Submission API only works with the Wix Forms app. Call [GetAppInstance](https://dev.wix.com/docs/rest/api-reference/app-management/apps/app-instance/get-app-instance) to confirm that the app named `wix_forms` is installed on the site.

    </Note>
    <br />
    Marks form submissions with `ids` as "seen". If `ids` are empty, all unseen form submissions are marked as "seen". <br />
    This endpoint marks the submissions as if they were seen by the site owner. Only site collaborators with the [Manage Submission](https://support.wix.com/en/article/roles-permissions-accessing-roles-permissions) permissions can mark submissions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORMS.READ-SUBMISSIONS">Read Submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-payment-service/v4/bulk/submissions/mark-as-seen
    ```

    ## Body Params

    <ParamField body="ids" type="string[]">

      Submission IDs to mark as seen.

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    <ParamField body="formId" type="string" required>

      ID of the form which the submissions belongs to.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job id for the bulk update operation

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
