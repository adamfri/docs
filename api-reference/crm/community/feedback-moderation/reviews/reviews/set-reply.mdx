    Sets a reply on a review.

    Only 1 reply can be left on a review. Calling Set Reply when a reply
    already exists overwrites the existing reply.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/reviews/v1/reviews/{reviewId}/reply
    ```

    ## Path Params

    <ParamField path="reviewId" type="string" required>

      Review ID.

    </ParamField>

    ## Body Params

    <ParamField body="message" type="string" required>

      Response to review author.

      Constraints: `maxLength 10000`.

    </ParamField>

    ## Response Object

    <ResponseField name="review" type="Review">

      Updated review.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Review Updated | `wix.reviews.v1.review_updated` | Triggered when a review is updated. |

    </div>
