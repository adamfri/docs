    Publishes and sends a specified campaign.

    Pass `emailDistributionOptions` to send the campaign to contacts. Omit it to publish as a landing page only. This decision is permanent — once published as a landing page only, the campaign can't be sent by email. Use [Reuse Campaign](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/email-marketing/campaign/reuse-campaign) to create a new draft if email distribution is needed later.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/publish
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      Campaign ID

    </ParamField>

    ## Body Params

    <ParamField body="emailDistributionOptions" type="EmailDistributionOptions">

      Email distribution options. If omitted, the campaign is published as a landing page only — this decision is permanent and the campaign can't be sent by email later.

      <Expandable title="emailDistributionOptions properties">

        <ParamField body="emailSubject" type="string">

          The subject line for the email campaign, which appears in recipients’ inboxes.

        </ParamField>

        <ParamField body="labelIds" type="string[]">

          IDs of contact labels to send the campaign to.

        </ParamField>

        <ParamField body="contactIds" type="string[]">

          IDs of contacts to whom to send out the campaign.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="sendAt" type="datetime">

          Future date and time to send the campaign. Must be at least 30 minutes in the future. Requires a plan that supports scheduling.

        </ParamField>

        <ParamField body="segmentIds" type="string[]">

          Segment IDs used to define the campaign audience.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="activeContactsOnly" type="boolean">

          Whether to send the campaign only to active contacts.

          Default: `false`

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="publishingData" type="PublishingData">

      Publishing info.

      <Expandable title="publishingData properties">

        <ResponseField name="landingPageUrl" type="string">

          Landing page URL.

          Constraints: `format WEB_URL`.

        </ResponseField>

        <ResponseField name="statistics" type="CampaignStatistics">

          Campaign engagement statistics.

          <Expandable title="statistics properties">

            <ResponseField name="landingPage" type="LandingPageStatistics">

              Landing page statistics.

              _Nested structure omitted for brevity — see the `LandingPageStatistics` object._

            </ResponseField>

            <ResponseField name="emailCampaign" type="DistributionStatistics">

              Email distribution statistics.

              _Nested structure omitted for brevity — see the `DistributionStatistics` object._

            </ResponseField>

            <ResponseField name="total" type="TotalStatistics">

              Combined statistics of landing page and email distribution.

              _Nested structure omitted for brevity — see the `TotalStatistics` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="datePublished" type="datetime">

          Date and time the campaign was published.

        </ResponseField>

        <ResponseField name="wasResentToNonOpeners" type="boolean">

          Whether the campaign was resent to recipients who didn't open the original email.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ALREADY_PUBLISHED` | Campaign was already published. |
    | `428` | `FAILED_PRECONDITION` | `SCHEDULING_FEATURE_UNAVAILABLE` | Scheduling isn't available on the current plan. Upgrade your plan to schedule campaigns. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SEND_AT` | The `sendAt` time is invalid. The campaign must be scheduled at least 30 minutes in the future. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Campaign Rejected Event | `wix.email_marketing.v1.campaign_campaign_rejected_event` | Triggered when a campaign is identified as abusive and rejected without sending emails to recipients. |
    | Campaign Published Event | `wix.email_marketing.v1.campaign_campaign_published_event` | Triggered when a draft campaign is published. |
    | Campaign Terminated Event | `wix.email_marketing.v1.campaign_campaign_terminated_event` | Triggered when a campaign is terminated after failing the sampling test due to poor mailing list quality. |
    | Campaign Distributed Event | `wix.email_marketing.v1.campaign_campaign_distributed_event` | Triggered when a campaign is successfully distributed to all recipients. |
    | Email Activity Updated | `wix.email_marketing.v1.campaign_email_activity_updated` | Triggered when an email campaign recipient performs an activity such as opening, clicking, or bouncing. |
    | Campaign Scheduled Event | `wix.email_marketing.v1.campaign_campaign_scheduled_event` | Triggered when a campaign is scheduled for delivery at a future time. |
