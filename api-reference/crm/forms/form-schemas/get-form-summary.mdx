    <div className="wix-ref">

    Retrieves a summary of a form schema containing information about its fields.

    Use this method to get an overview of a form schema without all the detailed configuration information.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/form-schema-service/v4/forms/{formId}/summary
    ```

    ## Path Params

    <ParamField path="formId" type="string" required>

      ID of the form schema to retrieve the summary for.

    </ParamField>

    ## Response Object

    <ResponseField name="formSummary" type="FormSummary">

      The retrieved form schema summary.

      <Expandable title="formSummary properties">

        <ResponseField name="id" type="string">

          Form schema ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="fields" type="Field[]">

          Simplified representation of form fields for quick overview and processing.
          Contains essential field information without complex validation or layout details.

          Constraints: `maxItems 500`.

          <Expandable title="fields properties">

            <ResponseField name="target" type="string">

              Human readable identifier used to reference a field.

            </ResponseField>

            <ResponseField name="label" type="string">

              Display label shown to users for this field.

            </ResponseField>

            <ResponseField name="type" type="string">

              Data type that this field accepts and validates.

              **Supported values:**

              - `UNKNOWN_INPUT_TYPE` — Unknown input type.
              - `STRING` — String input.
              - `NUMBER` — Numeric input.
              - `RATING` — Rating input.
              - `BOOLEAN` — Boolean input.
              - `ARRAY` — Array input.
              - `OBJECT` — Object input.
              - `WIX_FILE` — File upload input.
              - `SIGNATURE` — Digital signature input.
              - `PAYMENT` — Payment input.
              - `MULTILINE_ADDRESS` — Multi-line address input.
              - `DATE` — Date input.
              - `TIME` — Time input.
              - `DATE_TIME` — Combined date and time input.
              - `EMAIL` — Email input.
              - `URL` — URL input.
              - `UUID` — UUID input.
              - `PHONE` — Phone number input.
              - `URI` — URI input.
              - `HOSTNAME` — Hostname input.
              - `COLOR_HEX` — Color input.
              - `CURRENCY` — Currency input.
              - `LANGUAGE` — Language input.
              - `DATE_OPTIONAL_TIME` — Date input with optional time component.
              - `OBJECT_ARRAY` — Array of object inputs, e.g. a repeater field with nested sub-fields.

            </ResponseField>

            <ResponseField name="options" type="Option[]">

              Available options for fields that allow selection from predefined choices.

              Constraints: `maxItems 400`.

              _Nested structure omitted for brevity — see the `Option[]` object._

            </ResponseField>

            <ResponseField name="deleted" type="boolean">

              Whether this field has been soft deleted from the form schema and placed in the trash bin.

            </ResponseField>

            <ResponseField name="id" type="string">

              Field ID.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="fields" type="Field[]">

              Nested fields for object-array (repeater) inputs. Empty for all other input types.

              Constraints: `maxItems 50`.

              _Recursive reference to `Field[]`._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
