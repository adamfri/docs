Triggered when an add-on is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.addons.v1.add_on_created` |
| Package | `@wix/bookings` |
| Permissions | `Manage Bookings`, `Manage Bookings - all permissions` |
