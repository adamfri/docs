    <div className="wix-ref">

    Retrieves an order by ID.

    To retrieve an order's payment and refund details, including amounts, payment methods, and payment statuses, pass the order ID to [List Transactions For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/list-transactions-for-single-order).

    <Note>

    When Get Order is called with a site member's or site visitor's identity, the order is returned only if that member or visitor placed it. Orders retrieved by members or visitors don't include the `archived`, `activities`, `seenByAHuman`, `attributionSource`, and `tags.privateTags` fields.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>
    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/orders/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the order to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      The requested order.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_NOT_FOUND` | Order not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
