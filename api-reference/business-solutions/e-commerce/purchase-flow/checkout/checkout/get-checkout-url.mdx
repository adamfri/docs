    <div className="wix-ref">

    <Warning>

      **Deprecated.** This method is deprecated.

    </Warning>

    Retrieves the checkout page URL of a specified checkout.

    By default, a `checkoutUrl` generates for a checkout and directs to a standard Wix checkout page.
    However, if `overrideCheckoutUrl` has a value, it will replace and set the value of `checkoutUrl`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/checkouts/{id}/checkout-url
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Checkout ID.

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutUrl" type="string">

      Checkout URL.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
