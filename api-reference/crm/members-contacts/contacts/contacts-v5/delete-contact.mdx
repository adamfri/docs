    <div className="wix-ref">

    Deletes a contact.

    Deleted contacts are moved to the trash bin and can be restored within 90 days by calling [Restore Contact From Trash Bin](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/restore-contact-from-trash-bin) or [Bulk Restore Contacts From Trash Bin](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/bulk-restore-contacts-from-trash-bin). After 90 days, they're permanently deleted.

    Member contacts: To delete a contact that is also a site member, set `deleteMember` to `true`. This deletes both the contact and the member.

    Restrictions:
    - A contact with an active billing subscription can't be deleted.
    - A site owner or contributor can't be deleted.

    To delete multiple contacts in a single request, call [Bulk Delete Contacts](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/bulk-delete-contacts).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>
    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/contacts/v5/contacts/{contactId}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to delete.

    </ParamField>

    ## Query Params

    <ParamField query="deleteMember" type="boolean">

      Whether to delete the contact even if it's a site member. If `true`, the site member is also deleted.

      Default: `false`

    </ParamField>

    ## Response Object

    Returns `DeleteContactResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `UNAUTHORIZED_DELETE_MEMBER` | Deleting a site member's contact isn't allowed. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_MEMBER` | Contact is a site member and can't be deleted. The site member must be deleted first. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_CONTACT_WITH_BILLING_SUBSCRIPTION` | Contact has an active billing subscription and can't be deleted. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_WIX_USERS_MEMBER` | Site member can't be deleted because it's the owner or a contributor. |
    | `500` | `INTERNAL` | `FAILED_DELETE_CONTACT_AFTER_MEMBER_DELETION` | Site member was deleted, but the contact wasn't. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
