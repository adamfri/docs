This article presents possible use cases and corresponding sample flows that you can support. It provides a useful starting point as you plan your implementation.

## Publish an email campaign from a new sender

This use case demonstrates how to send an email campaign from a new sender. For example, if a business now accepts bookings and wants to start a new email campaign, they may want to send it from a different sender, such as `Yoga Bookings: [bookings@yogawithpuppies.com]`.    

<Note>

- Currently, there's a limitation when publishing an email campaign with the [Campaign API](fallback::https://dev.wix.com/docs/rest/business-management/marketing/email-marketing/campaign/publish-campaign). The API automatically publishes campaigns only from the default sender. For this use case to work, the new sender needs to be set as the default.
- This flow assumes that the site already has an [email campaign](fallback::https://support.wix.com/en/article/email-marketing-creating-and-sending-a-campaign-from-start-to-finish) to send.

</Note>

To publish a campaign from a new sender:

1. Create and verify the new email address using the [Sender Emails API](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/introduction).
1. Call [Create Sender Details](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-details/create-sender-details) passing the verified email address into the `fromEmailAddress` field. Also, enter the sender's name into the `fromName` field. Save the value of `id` field for later use.
1. Call [Mark Sender Details as Default](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-details/mark-sender-details-as-default) and pass the saved ID.
1. Call [Publish Campaign](fallback::https://dev.wix.com/docs/rest/business-management/marketing/email-marketing/campaign/publish-campaign) to send out the campaign. The campaign will automatically use the new sender details.
