    Updates a step.

    Each time the step is updated, `revision` increments by 1. The current `revision` must be passed when updating the step. This ensures you're working with the latest step and prevents unintended overwrites.

    Use this method to update step content and quiz settings.
    To move a step within a section or to another section, call [MoveStep](https://dev.wix.com/docs/api-reference/business-management/online-programs/steps/move-step) instead of updating `step.sectionId`.
    To attach a quiz to the step, create or clone the quiz separately, then specify its ID in `step.quizOptions.id`.

    To update multiple steps in a single API call, call [BulkUpdateSteps](https://dev.wix.com/docs/api-reference/business-management/online-programs/steps/bulk-update-steps).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
