    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.MANAGE-TAGS">Manage Tags</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/tags/v1/tags/{tag.id}
    ```

    ## Path Params

    <ParamField path="tag.id" type="string" required>

      Tag ID.

    </ParamField>

    ## Body Params

    <ParamField body="tag" type="Tag" required>

      See the [Tag Object](/api-reference/business-management/tags/tag-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="tag" type="Tag">

      The updated tag.

      See the [Tag Object](/api-reference/business-management/tags/tag-object) for this object's fields.

    </ResponseField>

    <Note>
