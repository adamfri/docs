---
title: "Pool Definition Item Object"
description: "Manage which catalog items are assigned to benefits in pool definitions."
icon: "cube"
---

Manage which catalog items are assigned to benefits in pool definitions.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Benefit item ID. Deterministically generated from pool_definition_id and item_id — if you know both, you can compute the ID without querying.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the benefit item is updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the item was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="externalId" type="string">

      External item ID assigned by the provider of the items.

      For example, if the benefit items are products, this ID corresponds to the specific product ID in the provider's system.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="category" type="string">

      Item category. Groups benefit items together for organization and management purposes. For example, classes, posts, groups.

      **Read-only.** Constraints: `maxLength 20`, `immutable`.

    </ResponseField>

    <ResponseField name="providerAppId" type="string">

      ID of the application providing the benefit items. Each item's external_id is unique within its provider application.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you
      created and entities that other apps created.

      **Read-only.** Constraints: `minLength 1`, `maxLength 20`, `immutable`.

    </ResponseField>

    <ResponseField name="poolDefinitionId" type="string">

      ID of the pool definition - the configuration that defines a set of benefits and which items are accessible within each benefit.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="itemSetId" type="string">

      Internal grouping identifier for this benefit's item set. Use pool_definition_id together with benefit_key
      to identify a benefit — item_set_id is an implementation detail.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="poolDefinition" type="PoolDefinitionInfo">

      Pool definition details including display name, description, and credit settings. Only populated when
      POOL_DEFINITION is included in the fields request parameter.

      **Read-only.**

      <Expandable title="poolDefinition properties">

        <ResponseField name="displayName" type="string">

          Pool definition name.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Pool definition description.

        </ResponseField>

        <ResponseField name="creditConfiguration" type="CreditConfiguration">

          Credit configuration for this pool definition. When absent, benefits in this pool do not support credit-based pricing.

          <Expandable title="creditConfiguration properties">

            <ResponseField name="amount" type="string">

              Number of credits initially granted to a subscriber when this pool definition's benefits are activated.

              Constraints: `>= 0`.

            </ResponseField>

            <ResponseField name="unitDisplayName" type="string">

              Credit unit display name.

            </ResponseField>

            <ResponseField name="unitType" type="string">

              Credit unit type.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="programDefinitions" type="ProgramDefinitionInfo[]">

      Program definitions that include this item as an accessible benefit. Only id and external_id are
      returned by default; request PROGRAM_DEFINITION to include display_name and description.

      **Read-only.** Constraints: `maxItems 20`.

      <Expandable title="programDefinitions properties">

        <ResponseField name="id" type="string">

          Program definition id

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="externalId" type="string">

          Program definition external id

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Program definition name

        </ResponseField>

        <ResponseField name="description" type="string">

          Program definition description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="itemId" type="string">

      Item ID.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="benefitInfo" type="BenefitInfo">

      Pricing and display information for the associated benefit, including credit price, name, and description.
      Only populated when BENEFIT is included in the fields request parameter.

      **Read-only.**

      <Expandable title="benefitInfo properties">

        <ResponseField name="price" type="string">

          Price of the benefit in credits. The price is the same for all of this benefit's items.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Benefit name.

        </ResponseField>

        <ResponseField name="description" type="string">

          Benefit description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="itemInfo" type="ItemInfo">

      Display name for the catalog item. Only populated when ITEM is included in the fields request parameter.

      **Read-only.**

      <Expandable title="itemInfo properties">

        <ResponseField name="displayName" type="string">

          Item display name.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="benefitKey" type="string">

      Unique identifier for the benefit associated with this item.

      **Read-only.** Constraints: `maxLength 64`, `immutable`.

    </ResponseField>

    <ResponseField name="itemSearchKey" type="string">

      Pre-computed search key for the item reference, built by concatenating provider_app_id, category, and external_id
      separated by /. Use this field for efficient single-field filtering instead of composing three separate conditions.

      **Read-only.** Constraints: `maxLength 94`, `immutable`.

    </ResponseField>

    <ResponseField name="removed" type="boolean">

      Whether this item has been removed from the pool definition.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "pool_definition_item": {
          "id": "124bc876-66d2-4603-8c20-395a09eb0e44",
          "revision": "1",
          "created_date": "2024-11-07T12:47:11.370Z",
          "updated_date": "2024-11-07T12:47:11.370Z",
          "external_id": "00000000-0000-0000-0000-000000000001",
          "category": "class",
          "pool_definition_id": "201db180-5043-45cf-a501-bd9c06df5ae5",
          "item_set_id": "f1a2b3c4-d5e6-7890-abcd-ef1234567890",
          "provider_app_id": "00000000-0000-0000-0000-000000000000",
          "namespace": "fitness-app",
          "benefit_key": "unlimited-classes",
          "item_id": "9a8b7c6d-5e4f-3210-fedc-ba9876543210"
        }
      }
      ```
