    <div className="wix-ref">

    Retrieves a list of files in the Media Manager, given the provided [cursor paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language#cursor-paging), filtering, and sorting.

    Up to 200 files can be returned per request.

    When filtering by `mediaType`, supported values are: `IMAGE`, `VIDEO`, `AUDIO`, `DOCUMENT`, `VECTOR`, `ARCHIVE`, and `MODEL3D`.

    To learn about working with *Query* methods, see
    [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language) and
    [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `displayName` |  | Sort: `ASC`, `DESC` |
    | `sizeInBytes` |  | Sort: `ASC`, `DESC` |
    | `private` | `$eq` | None |
    | `mediaType` | `$eq`, `$in` | None |
    | `updatedDate` |  | Sort: `ASC`, `DESC` |
    | `state` | `$eq` | None |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEDIA.READ-MEDIAMANAGER">Read Media Manager</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-media/v1/files/query
    ```

    import { files } from '@wix/media';

    async function myQueryAllFilesFunction() {
      const allFiles = [];
      let cursor = undefined;
      let hasNext = true;

      try {
        while (hasNext) {
          const result = await files.queryFileDescriptors({
            query: {
              filter: {
                state: 'OK',
              },
              cursorPaging: {
                limit: 50,
                cursor,
              },

          });

          allFiles.push(...result.files);
          cursor = result.pagingMetadata?.cursors?.next;
          hasNext = result.pagingMetadata?.hasNext ?? false;
