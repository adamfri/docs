A review request is a request sent to a customer to solicit a review for a specific order or specific items.

## SDK package

```bash
npm install @wix/reviews
```

Import the `reviewRequests` namespace from `@wix/reviews`.

## Methods

<CardGroup cols={2}>

  <Card title="Create Review Request" href="/api-reference/crm/community/feedback-moderation/reviews/review-requests/create-review-request">
    POST Creates a new review request.
  </Card>
  <Card title="Get Review Request" href="/api-reference/crm/community/feedback-moderation/reviews/review-requests/get-review-request">
    GET Retrieves a review request.
  </Card>
  <Card title="Delete Review Request" href="/api-reference/crm/community/feedback-moderation/reviews/review-requests/delete-review-request">
    DELETE Deletes a review request.
  </Card>
  <Card title="Query Review Requests" href="/api-reference/crm/community/feedback-moderation/reviews/review-requests/query-review-requests">
    POST Retrieves a list of review requests, give the provided paging, filtering, and sorting.
  </Card>
  <Card title="Count Review Requests" href="/api-reference/crm/community/feedback-moderation/reviews/review-requests/count-review-requests">
    POST Retrieves the number of review requests that match a specified filter.
  </Card>
  <Card title="Bulk Cancel Review Requests By Filter" href="/api-reference/crm/community/feedback-moderation/reviews/review-requests/bulk-cancel-review-requests-by-filter">
    PUT Cancels review requests given specified filters.
  </Card>

</CardGroup>
