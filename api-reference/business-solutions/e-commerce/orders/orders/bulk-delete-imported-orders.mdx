    Deletes multiple imported orders.

    Only orders that were created with [Import Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/import-order) can be deleted. This is useful for clearing out a faulty migration before re-importing. Deletion is permanent: each order is removed from the site, including from search results.

    This endpoint runs asynchronously and returns a `jobId`. To track progress and see any orders that couldn't be deleted, pass the `jobId` to [Get Async Job](https://dev.wix.com/docs/rest/business-management/async-job/get-async-job) or [List Async Job Items](https://dev.wix.com/docs/rest/business-management/async-job/list-async-job-items).

    An `ImportedOrderDeleted` webhook is emitted for each order that's successfully deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.IMPORT-ORDERS">SCOPE.ECOM.IMPORT-ORDERS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/orders/import/bulk-delete-imported-orders
    ```

    ## Body Params

    <ParamField body="orderIds" type="string[]" required>

      IDs of the orders to delete. Only orders created with Import Order can be deleted. An ID that doesn't belong to an imported order is reported as a failed item in the async job.

      Constraints: `format GUID`, `minItems 1`, `maxItems 1000`.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID for async operation tracking. Pass to [Get Async Job](https://dev.wix.com/docs/rest/business-management/async-job/get-async-job) or [List Async Job Items](https://dev.wix.com/docs/rest/business-management/async-job/list-async-job-items) to retrieve details and metadata

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Imported Order Deleted | `wix.ecom.v1.order_imported_order_deleted` | Triggered when an imported order is deleted. |

    </div>
