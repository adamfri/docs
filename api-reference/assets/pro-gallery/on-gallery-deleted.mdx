Triggered when a gallery is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pro_gallery.gallery_v2_deleted` |
| Package | `@wix/pro-gallery` |
| Permissions | `Manage Galleries`, `Read Galleries` |
