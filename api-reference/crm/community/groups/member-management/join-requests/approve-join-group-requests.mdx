    Approves pending join group requests.
    Group managers always have access to this functionality. In some cases, site owners will allow group members to use this functionality as well.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-groups-proxy/join/v2/groups/{groupId}/join-requests/approve
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      ID of the group requested to join.

    </ParamField>

    ## Body Params

    <ParamField body="memberIds" type="string[]">

      IDs of the site members to approve.

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="joinGroupRequests" type="JoinGroupRequest[]">

      Approved join group requests.

      See the [Join Group Request Object](/api-reference/crm/community/groups/member-management/join-requests/join-group-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Join Group Request Approved | `wix.social_groups.v2.join_group_request_approved` | Triggered when a join group request is approved. |

    </div>
