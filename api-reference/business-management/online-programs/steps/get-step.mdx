    Retrieves a step.

    Use `descriptionFieldSet` to control how much description content to return.
    Some returned fields depend on the caller's permissions.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/online-programs/v3/steps/{stepId}
    ```

    ## Path Params

    <ParamField path="stepId" type="string" required>

      Step ID.

    </ParamField>

    ## Query Params

    <ParamField query="descriptionFieldSet" type="string">

      Predefined set of description fields to return.

      **Supported values:**

      - `STANDARD` — Returns the standard step description fields.
      - `EXTENDED` — Returns additional step description fields when they're available to the caller.

    </ParamField>

    ## Response Object

    <ResponseField name="step" type="Step">

      Retrieved step.

      See the [Step Object](/api-reference/business-management/online-programs/steps/step-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
