    <div className="wix-ref">

    Retrieves a list of external calendar providers supported on the Wix site.

    The list of external calendar providers includes:

    + External calendar providers that are supported by default, such as Google, Apple, and Microsoft.
    + External calenders for which the site owner has enabled integration by installing an app.

    For each provider, check `features.connectMethods` to find out whether to use
    [Connect By Credentials](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/connect-by-credentials)
    or [Connect By OAuth](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/connect-by-o-auth)
    to establish a connection.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-EXTERNAL-CALENDARS">Manage External Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v2/external-calendars/providers
    ```

    ## Response Object

    <ResponseField name="providers" type="Provider[]">

      List of external calendar providers supported on the site.

      <Expandable title="providers properties">

        <ResponseField name="id" type="string">

          ID of the external calendar provider.

        </ResponseField>

        <ResponseField name="name" type="string">

          Name of the external calendar provider.

        </ResponseField>

        <ResponseField name="calendarType" type="string">

          External calendar provider type.

          **Supported values:**

          - `UNDEFINED` — There is no information about the external calendar type.
          - `GOOGLE` — [Google Calendar](https://developers.google.com/calendar/api/guides/overview).
          - `I_CAL` — Apple iCalendar.
          - `OUTLOOK` — __Deprecated__. Use `MICROSOFT` instead.
          - `OFFICE_365` — __Deprecated__. Use `MICROSOFT` instead.
          - `MICROSOFT` — Microsoft Calendar. For example, Office 365 calendar or Outlook calendar.
          - `OTHER` — A different type of external calendar, not listed here.

        </ResponseField>

        <ResponseField name="features" type="ProviderFeatures">

          Information about how you can connect the external calendar to the Wix site,
          and which functionality it supports.

          <Expandable title="features properties">

            <ResponseField name="connectMethods" type="string[]">

              List of supported connection methods.

              **Supported values:**

              - `UNDEFINED` — There is no information about how you can connect the external calendar
              to the Wix site.
              - `OAUTH` — You can connect the external calendar to the Wix site by calling [Connect By O Auth](https://dev.wix.com/docs/rest/business-solutions/bookings/calendar/external-calendar-v2/connect-by-o-auth).
              - `CREDENTIALS` — You can connect the external calendar to the Wix site by calling [Connect By Credentials](https://dev.wix.com/docs/rest/business-solutions/bookings/calendar/external-calendar-v2/connect-by-credentials).

            </ResponseField>

            <ResponseField name="updateSyncConfig" type="boolean">

              Whether you can update `syncConfic` for all external calendar connections
              by calling [Update Sync Config](https://dev.wix.com/docs/rest/business-solutions/bookings/calendar/external-calendar-v2/update-sync-config).

            </ResponseField>

            <ResponseField name="listEventFromCalendars" type="string">

              Information about which events you can import from the external calendar to
              the Wix site.

              **Supported values:**

              - `UNDEFINED` — There is no information about which external calendar events you
              can import to the Wix site.
              - `NOT_SUPPORTED` — You can't import any events from the external calendar to the Wix site.
              - `PRIMARY_CALENDAR_ONLY` — You can import events only for the external calendar that's
              designated as primary.
              - `SPECIFIC_CALENDARS` — You can import events only for a specific external calendar account.
              You can call [List Calendars](https://dev.wix.com/docs/rest/business-solutions/bookings/calendar/external-calendar-v2/list-calendars)
              to retrieve a complete list of external calendar accounts.

            </ResponseField>

            <ResponseField name="syncToCalendar" type="string">

              Whether you can export Wix calendar [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
              to the external calendar.

              **Supported values:**

              - `UNDEFINED` — There is no information about which Wix calendar [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
              you can export to the external calendar.
              - `NOT_SUPPORTED` — You can't export any Wix calendar [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
              to the external calendar.
              - `PRIMARY_CALENDAR_ONLY` — You can export Wix calendar [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
              only to the external calendar that's designated as primary.
              - `SPECIFIC_CALENDAR` — Events can be exported to specific external calendars. Use [List Calendars](#list-calendars) to get a list of calendars for a connected external calendar account.
              - `DEDICATED_CALENDAR` — You can export Wix calendar [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
              only to a dedicated external calendar account. You can
              call [List Calendars](https://dev.wix.com/docs/rest/business-solutions/bookings/calendar/external-calendar-v2/list-calendars)
              to retrieve a complete list of external calendar accounts.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
