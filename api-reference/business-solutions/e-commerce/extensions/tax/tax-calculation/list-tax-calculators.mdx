    <div className="wix-ref">

    Retrieves a list of installed tax calculators.

    Wix uses these calculators to calculate tax.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.MANAGE-STORES">Manage Stores</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/list-tax-calculators
    ```

    ## Response Object

    <ResponseField name="taxCalculatorDetails" type="TaxCalculatorDetails[]">

      Retrieved tax calculators.

      Constraints: `maxItems 10`.

      <Expandable title="taxCalculatorDetails properties">

        <ResponseField name="appId" type="string">

          ID of the tax calculator.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Display name of the tax calculator.

          Constraints: `minLength 1`, `maxLength 200`.

        </ResponseField>

        <ResponseField name="unsupportedCountries" type="string[]">

          List of countries, in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements) format, that the calculator does not support.

          Constraints: `format COUNTRY`, `maxItems 195`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
