## Methods

<CardGroup cols={2}>

  <Card title="List Manual Tax Mappings" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/list-manual-tax-mappings">

  </Card>
  <Card title="Create Manual Tax Mapping" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/create-manual-tax-mapping">
    POST Creates a manual tax mapping for a specific tax group and region combination.
  </Card>
  <Card title="Bulk Create Manual Tax Mappings" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/bulk-create-manual-tax-mappings">
    POST Creates up to 100 manual tax mappings in a single request.
  </Card>
  <Card title="Get Manual Tax Mapping" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/get-manual-tax-mapping">
    GET Retrieves a manual tax mapping by ID.
  </Card>
  <Card title="Delete Manual Tax Mapping" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/delete-manual-tax-mapping">
    DELETE Deletes a manual tax mapping.
  </Card>
  <Card title="Update Manual Tax Mapping" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/update-manual-tax-mapping">
    PATCH Updates an existing manual tax mapping.
  </Card>
  <Card title="Query Manual Tax Mappings" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/query-manual-tax-mappings">
    POST Retrieves a list of manual tax mappings based on the provided query criteria.
  </Card>
  <Card title="Update Extended Fields" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/update-extended-fields">
    POST Updates extended fields of a manual tax mapping.
  </Card>
  <Card title="Bulk Assign Exempt Overrides" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/bulk-assign-exempt-overrides">
    POST Assigns tax exempt overrides to multiple manual tax mappings in a single request.
  </Card>
  <Card title="Bulk Unassign Exempt Overrides" href="/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/bulk-unassign-exempt-overrides">
    POST Unassigns tax exempt overrides to multiple manual tax mappings in a single request.
  </Card>
