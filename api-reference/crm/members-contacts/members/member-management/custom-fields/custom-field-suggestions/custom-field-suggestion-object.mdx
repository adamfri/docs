A custom field that can be suggested for Wix users to add to member profiles.

<Tabs>

  <Tab title="REST">

    <ResponseField name="name" type="string">

      Custom field name.

    </ResponseField>

    <ResponseField name="defaultPrivacy" type="string">

      Privacy level of the custom field.

      **Supported values:**

      - `PUBLIC` — The information appears on the members' public profile pages.
      - `PRIVATE` — Only the member can see this information.

    </ResponseField>

    <ResponseField name="fieldType" type="string">

      Type of information to provide for members.

      **Supported values:**

      - `TEXT` — A text box to write text.
      - `NUMBER` — Only a number can be entered into the field.
      - `DATE` — Only a date can be entered into the field.
      - `URL` — Only a URL can be entered into the field.
      - `SOCIAL` — Only a link from the selected social media platform can be entered into the field.

    </ResponseField>

    <ResponseField name="socialType" type="string">

      Social network type.

      **Supported values:**

      - `FACEBOOK` — Facebook social media platform.
      - `INSTAGRAM` — Instagram social media platform.
      - `LINKEDIN` — LinkedIn social media platform.
      - `TWITTER` — X (formerly Twitter) social media platform.
      - `YOUTUBE` — Youtube social media platform.
      - `PINTEREST` — Pinterest social media platform.
      - `TIKTOK` — TikTok social media platform.
      - `DEVIANTART` — DeviantArt social media platform.
      - `SOUNDCLOUD` — SoundCloud social media platform.
      - `TUMBLR` — Tumblr social media platform.
      - `VIMEO` — Vimeo social media platform.
      - `VKONTAKTE` — VKontakte social media platform.
      - `ODNOKLASSNIKI` — Odnoklassniki social media platform.
      - `OTHER` — Other social media platform.

    </ResponseField>

    <ResponseField name="fieldOrigin" type="string">

      Field origin.

      **Supported values:**

      - `CUSTOM` — Custom field created by a Wix user.
      - `CONTACT` — Contact type of field. These are default fields that are already provided by Members Area, such as: "birth date", "position", "company".
      - `SYSTEM` — System fields, such as: "first name", "last name", "email", "phone", "address", and  "title". Some system fields are only available from the dashboard.

    </ResponseField>

    <ResponseField name="customFieldId" type="string">

      Custom field ID.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "name": "Favorite Animal",
        "defaultPrivacy": "PRIVATE",
        "fieldType": "TEXT",
        "socialType": "UNKNOWN",
        "fieldOrigin": "CUSTOM",
        "customFieldId": "e75aee4c-21c1-469a-ad3e-8f64ab8073cc"
      }
      ```

    </CodeGroup>
