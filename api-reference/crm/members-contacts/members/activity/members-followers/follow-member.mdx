    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v3/followers/{memberId}
    ```

    ## Path Params

    <ParamField path="memberId" type="string" required>

      ID of the member to follow.

    </ParamField>
