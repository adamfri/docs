    Retrieves a list of up to 500 tags, given the provided paging, filtering, and sorting.

    Query Posts runs with these defaults, which you can override:
    - `postCount` is sorted in `DESC` order.
    - `paging.limit` is `50`.
    - `paging.offset` is `0`.

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging), and
    [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$nin` | Sort: `ASC`, `DESC` |
    | `label` | `$eq`, `$ne`, `$startsWith`, `$lt`, `$lte`, `$gt`, `$gte`, `$exists`, `$in` | Sort: `ASC`, `DESC` |
    | `slug` | `$eq`, `$ne`, `$startsWith`, `$lt`, `$lte`, `$gt`, `$gte`, `$exists`, `$in` | Sort: `ASC`, `DESC` |
    | `publishedPostCount` | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sort: `ASC`, `DESC` |
    | `postCount` | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sort: `ASC`, `DESC` |
    | `language` | `$eq`, `$ne`, `$exists`, `$in` | Sort: `ASC`, `DESC` |
    | `translationId` | `$eq`, `$ne`, `$exists`, `$in` | None |
