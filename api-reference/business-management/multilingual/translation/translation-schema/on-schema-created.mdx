Triggered when translation schema is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.translation.v1.schema_created` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation Schema Read` |
