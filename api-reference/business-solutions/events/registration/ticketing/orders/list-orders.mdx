    <div className="wix-ref">

    Retrieves a list of orders, including ticket data, with basic filter support.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-BASIC-ORDERS">Read Basic Events Order Info</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/orders
    ```

    ## Query Params

    <ParamField query="offset" type="integer">

      Offset.

      Constraints: `min 0`.

    </ParamField>

    <ParamField query="limit" type="integer">

      Limit.

      Constraints: `min 0`, `max 400`.

    </ParamField>

    <ParamField query="fieldset" type="string[]">

      Which fields to return.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `TICKETS` — Returns `tickets`.
      - `DETAILS` — Returns `archived`, `confirmed`, `created`, `firstName`, `fullName`,
      `lastName`, `method`, `reservationId`, `snapshotId`,
      `status`, `ticketsPdf`, `ticketsQuantity`, `totalPrice`.
      - `FORM` — Returns `checkoutForm`.
      - `INVOICE` — Returns `invoice`.

    </ParamField>

    <ParamField query="status" type="string[]">

      Status.

      **Supported values:**

      - `NA_ORDER_STATUS` — Order status isn't available for this request fieldset.
      - `FREE` — Order is confirmed, no payment is required.
      - `PENDING` — Order was paid, but the payment gateway suspended the payment.
      - `PAID` — Order is paid.
      - `OFFLINE_PENDING` — Order is confirmed but must be paid via offline payment. Status needs to be manually updated to `"PAID"`.
      - `INITIATED` — Order is waiting for payment at the cashier.
      - `CANCELED` — Order is canceled.
      - `DECLINED` — Order payment is declined.
      - `AUTHORIZED` — Order payment is authorized.
      - `VOIDED` — Order payment is voided.
      - `PARTIALLY_PAID` — Order is partially paid with less than the total amount.

    </ParamField>

    <ParamField query="eventId" type="string[]">

      Event ID.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="orderNumber" type="string[]">

      Order number.

      Constraints: `maxLength 36`, `maxItems 500`.

    </ParamField>

    <ParamField query="memberId" type="string[]">

      Site member ID.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    <ParamField query="facet" type="string[]">

      Field facets.

      Constraints: `maxLength 100`, `maxItems 20`.

    </ParamField>

    <ParamField query="searchPhrase" type="string">

      Textual search filter - search is performed on "full_name", "email" and "order_number".

      Constraints: `maxLength 200`.

    </ParamField>

    <ParamField query="eventCreatorId" type="string[]">

      Event creator ID.

      Constraints: `format GUID`, `maxItems 50`.

    </ParamField>

    <ParamField query="sort" type="string">

      Sort order. Defaults to "created:asc".

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField query="tag" type="string[]">

      Order tag.

      **Supported values:**

      - `CONFIRMED` — Return only confirmed orders.
      - `UNCONFIRMED` — Return only unconfirmed orders.
      - `MEMBER` — Return only member orders.
      - `ARCHIVED` — Return only archived orders.
      - `NON_ARCHIVED` — Return only non archived orders.
      - `FULLY_CHECKED_IN` — Return only orders with all guests checked-in.
      - `NOT_FULLY_CHECKED_IN` — Return only orders with no guests checked-in.

    </ParamField>

    <ParamField query="contactId" type="string[]">

      Guest contact IDs.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>
