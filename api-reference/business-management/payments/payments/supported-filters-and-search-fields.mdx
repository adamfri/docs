[Search Payments](fallback::https://dev.wix.com/docs/api-reference/business-management/payments/payments/search-payments) accepts
structured filters, full-text search expressions, and correlated nested
matches against refunds and disputes. The tables below list the fields supported in each.

For an overview of the query and search syntax,
see [API Query and Search Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

## Top-level filters and sorting

| Field         | Supported Filters                                                    | Sortable |
|---------------|----------------------------------------------------------------------|----------|
| `id`          | `$eq`, `$ne`, `$in`, `$nin`, `$exists`                               | Yes      |
| `appId`       | `$eq`, `$ne`, `$in`, `$nin`, `$exists`                               | No       |
| `refundable`  | `$eq`, `$ne`, `$exists`                                              | Yes      |
| `createdDate` | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists` | Yes      |

## Full-text search

The `search.expression` field matches against the following fields. A match in any of them returns the payment.

- `charge.billingInfo.contactDetails.firstName`
- `charge.billingInfo.contactDetails.lastName`
- `charge.billingInfo.contactDetails.email`
- `charge.shippingInfo.contactDetails.email`
- `charge.orderLineItems.name`

## Correlated nested matching

Use `$matchItems` on `refunds` or `disputes` to require all conditions to match the same item, rather than different
items on the same payment.

For example, use the following `search.filter` section to find payments with a `SUCCEEDED` refund whose amount is
greater than `100`:

```json
{
  "filter": {
    "refunds": {
      "$matchItems": [
        {
          "status": {
            "$eq": "SUCCEEDED"
          }
        },
        {
          "amount": {
            "$gt": "100"
          }
        }
      ]
    }
  }
}
```

Without `$matchItems`, the same query would also return payments where one refund is `SUCCEEDED` and a different
refund's amount is greater than `100`.
