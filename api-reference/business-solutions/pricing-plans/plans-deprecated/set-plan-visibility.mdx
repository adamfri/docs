    <Warning>

      **Deprecated.** This method is deprecated.

    </Warning>

    Sets visibility for pricing plans. Visible plans are considered public plans.
    By default, pricing plans are public, meaning they are visible. Plans can be hidden so that site members and visitors can't choose them.
    As opposed to archiving, setting visibility can be reversed. This means that a public plan can be hidden, and a hidden plan can be made public (visible). (An archived plan always remains archived and can't be made active again.)
    Changing a plan’s visibility doesn't impact existing orders for the plan. All orders for hidden plans are still active and keep their perks.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.MANAGE-PLANS">Manage Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/pricing-plans/v2/plans/{id}/visibility
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      The ID of the plan to either display or hide on a site page.

    </ParamField>

    ## Body Params

    <ParamField body="visible" type="boolean" required>

      Whether a plan is visible to members and site visitors. Updates the `public` field.

    </ParamField>

    ## Response Object

    <ResponseField name="plan" type="Plan">

      Pricing plan.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-deprecated/plan-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PRICING_PLANS_NOT_INSTALLED` | The user does not have the Wix Pricing Plans app installed on the site. |
    | `404` | `NOT_FOUND` | `plan_not_found` | Pricing plan was not found. |
    | `400` | `INVALID_ARGUMENT` | `set_visibility_not_supported` | Cannot change plan's visibility because it is archived. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
