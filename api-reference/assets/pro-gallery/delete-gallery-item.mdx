<span className="wix-method wix-method-delete">DELETE</span>

<div className="wix-api-columns">

<div className="wix-ref">

Deletes a media item from a gallery.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PROGALLERY.MANAGE-GALLERIES">Manage Galleries</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
DELETE https://www.wixapis.com/pro-gallery/v2/galleries/{galleryId}/items/{itemId}
```

## Path Params

<ParamField path="galleryId" type="string" required>

  Gallery ID.

</ParamField>

<ParamField path="itemId" type="string" required>

  ID of the media item to delete.

</ParamField>

## Response Object

<ResponseField name="itemId" type="string">

  ID of the deleted media item.

  **Read-only.** Constraints: `format GUID`.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>

</div>
