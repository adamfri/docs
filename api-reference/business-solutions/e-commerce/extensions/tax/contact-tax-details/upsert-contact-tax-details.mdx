    Creates or updates a contact's tax details.

    If tax details already exist for the contact specified in `id`, they're updated. Otherwise, new tax details are created. The request must include `id`, the contact ID, and `taxExemptGroupId`.

    To create or update tax details for multiple contacts in a single API call, call [Bulk Upsert Contact Tax Details](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/bulk-upsert-contact-tax-details).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/contact-tax-details
    ```

    ## Body Params

    <ParamField body="contactTaxDetails" type="ContactTaxDetails" required>

      Contact tax details to create or update.

      See the [Contact Tax Details Object](/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/contact-tax-details-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Additional fields to return in the response.

      Supported values: `CONTACT_DETAILS`

      Constraints: `maxItems 10`.

      **Supported values:**

      - `CONTACT_DETAILS` — Returns the contact's details, including first name, last name, company, email, and VAT ID.

    </ParamField>

    ## Response Object

    <ResponseField name="contactTaxDetails" type="ContactTaxDetails">

      Created or updated contact tax details.

      See the [Contact Tax Details Object](/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/contact-tax-details-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

          "contactTaxDetails": {
            "id": "f1c3e2a0-1b2c-4d5e-8f90-1a2b3c4d5e6f",
