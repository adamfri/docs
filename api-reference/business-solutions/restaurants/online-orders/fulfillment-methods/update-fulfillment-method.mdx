    Updates a fulfillment method.

    Each time the fulfillment method is updated, its revision increments by 1. The existing revision must be included when updating the fulfillment method. This ensures you're working with the latest fulfillment method information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/fulfillment-methods/v1/fulfillment-methods/{fulfillmentMethod.id}
    ```

    ## Path Params

    <ParamField path="fulfillmentMethod.id" type="string" required>

      Fulfillment method ID.

    </ParamField>

    ## Body Params

    <ParamField body="fulfillmentMethod" type="FulfillmentMethod" required>

      Fulfillment method to update.
      The fulfillment method update may be partial with the use of `field_mask`.

      See the [Fulfillment Method Object](/api-reference/business-solutions/restaurants/online-orders/fulfillment-methods/fulfillment-method-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="fulfillmentMethod" type="FulfillmentMethod">

      The updated fulfillment method.

      See the [Fulfillment Method Object](/api-reference/business-solutions/restaurants/online-orders/fulfillment-methods/fulfillment-method-object) for this object's fields.

    </ResponseField>
