    Generates temporary information for downloading a tax document's file.

    The returned `downloadInfo.url` is a temporary link to a PDF. It expires 10 seconds after it's generated, so follow it immediately, and don't store it as a static link. Call this method again to get a fresh URL.

    The tax document must have a file available, meaning its `downloadable` field is `true`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYMENTS.MANAGE-TAX-DOCUMENTS">Managing tax tax documents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/payments/platform/v1/tax-documents/{taxDocumentId}/generate-file-download-info
    ```

    ## Path Params

    <ParamField path="taxDocumentId" type="string" required>

      ID of the tax document to download a file for.

    </ParamField>

    ## Response Object

    <ResponseField name="downloadInfo" type="Document">

      Information for downloading the tax document's file.

      <Expandable title="downloadInfo properties">

        <ResponseField name="id" type="string">

          Not used. Always empty for tax documents.

          Constraints: `maxLength 0`.

        </ResponseField>

        <ResponseField name="url" type="string">

          Temporary URL for downloading the tax document's PDF file. Expires 10 seconds after it's generated.

          Constraints: `format WEB_URL`.

        </ResponseField>

        <ResponseField name="urlExpirationDate" type="datetime">

          Date and time the download URL expires, 10 seconds after it's generated.

        </ResponseField>

        <ResponseField name="sizeInBytes" type="string">

          File size in bytes.

        </ResponseField>

        <ResponseField name="filename" type="string">

          File name.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
