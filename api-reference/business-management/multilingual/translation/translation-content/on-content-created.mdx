Triggered when translation content is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.translation.v1.content_created` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation API`, `Wix Multilingual - Translation Content + Published Content Read` |

## Examples

<CodeGroup>

  ```javascript onContentCreated
  import { translationContents } from '@wix/multilingual';

  translationContents.onContentCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onContentCreated (self-hosted)

  import { translationContents } from '@wix/multilingual';

    auth: AppStrategy({

      publicKey: 'YOUR_APP_PUBLIC_KEY',

     modules: {

      },
  });

  wixClient.translationContents.onContentCreated((event) => {
      // handle your event here
  });
  ```
