title: "Refund Object"
description: "The refund object."
icon: "cube"
---

The refund object. A refund object is the record of an attempt to return charged funds.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Refund ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the refund is updated.

      Ignored when creating a refund.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the refund was created in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#coordinated_Universal_Time_(UTC)) format. For example, "2024-01-30T13:30:00".

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the refund was last updated in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#coordinated_Universal_Time_(UTC)) format. For example, "2024-01-30T13:30:00".

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the refund object.

      [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="chargeId" type="string">

      ID of the charge to refund.

    </ResponseField>

    <ResponseField name="currencyCode" type="string">

      Refund currency. Should be the same as the charge currency.

    </ResponseField>

    <ResponseField name="amount" type="string">

      Amount being returned to the buyer in the refund currency's main units (such as dollars or euros).
      For example, `"12.95"`.

    </ResponseField>

    <ResponseField name="returnedApplicationFee" type="string">

      Application fee returned to the merchant from Wix in the refund currency's main units (such as dollars or euros). For example, `"12.95"`.

      Only included if an application fee was returned.

      **Read-only.**

    </ResponseField>

    <ResponseField name="returnedProcessingFee" type="string">

      Processing fee returned to the merchant from the payment service provider in the refund currency's main units (such as dollars or euros). For example, `"12.95"`.

      This field is empty when the processing fee is unknown.

      **Read-only.**

    </ResponseField>

    <ResponseField name="full" type="boolean">

      Whether the refund is for the entire amount of the charge.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the refund.

      Learn more about the [refund lifecycle](https://dev.wix.com/docs/rest/business-management/payments/refunds/introduction#lifecycle-of-a-refund>).

      **Read-only.**

      **Supported values:**

      - `PENDING` — Refund is in progress.
      - `SUCCEEDED` — Refund succeeded.
      - `FAILED` — Refund failed.
      - `REVERSED` — Refund had succeeded, but has since been reversed.

    </ResponseField>

    <ResponseField name="providerRefundId" type="string">

      Payment service provider's ID for the refund.

      **Read-only.**

    </ResponseField>

    <ResponseField name="reason" type="string">

      Reason this refund was issued.

    </ResponseField>

    <ResponseField name="statusInfo" type="StatusInfo">

      Details about the refund status.
      Used to provide additional information about why a refund was given its status.

      **Read-only.**

      <Expandable title="statusInfo properties">

        <ResponseField name="code" type="string">

          Reason code with detailed information about the refund status.
          See the full list of [reason codes](https://dev.wix.com/docs/rest/business-management/payments/service-plugins/payment-service-provider-service-plugin/reason-codes#refund-declined).

          Constraints: `minLength 1`, `maxLength 10`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Description of the status.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="acquirerReferenceNumber" type="string">

      Unique number assigned to a refund. This number is shared across all parties involved in processing the refund. It allows the merchant to track the refund with their bank.

      **Read-only.**

    </ResponseField>

    <ResponseField name="note" type="string">

      Note providing additional information about this refund.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
        "revision": 2,
        "createdDate": "2019-10-30T17:22:10.458Z",
        "updatedDate": "2019-10-30T17:22:11.299Z",
        "chargeId": "602b516f-e8a2-4e1a-9a17-0708099a74db",
        "currencyCode": "USD",
        "amount": "100",
        "full": true,
        "status": "SUCCEEDED",
        "providerRefundId": "re_1Nispe2eZvKYlo2Cd31jOCsZ"
      }
      ```

    </CodeGroup>
