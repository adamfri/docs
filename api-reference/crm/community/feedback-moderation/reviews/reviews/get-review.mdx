    Retrieves a review.

    By default, unpublished reviews aren't returned.
    To retrieve an unpublished review, pass `returnPrivateReviews` as `true`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.READ-REVIEWS">Read reviews</span>
    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/reviews/v1/reviews/{reviewId}
    ```

    ## Path Params

    <ParamField path="reviewId" type="string" required>

      Review ID.

    </ParamField>

    ## Query Params

    <ParamField query="returnPrivateReviews" type="boolean">

      Whether to return unpublished reviews.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="review" type="Review">

      Review.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
