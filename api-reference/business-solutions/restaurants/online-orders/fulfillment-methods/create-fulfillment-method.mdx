    Creates a new fulfillment method.

    <Note>

    `fulfillmentMethod.availability.time_zone` uses the time zone specified in the [`language and regions`](https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fsettings/language-and-region) settings in the dashboard, regardless of the value provided.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/fulfillment-methods/v1/fulfillment-methods
    ```

    ## Body Params

    <ParamField body="fulfillmentMethod" type="FulfillmentMethod" required>

      Fulfillment method to create.

      See the [Fulfillment Method Object](/api-reference/business-solutions/restaurants/online-orders/fulfillment-methods/fulfillment-method-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="fulfillmentMethod" type="FulfillmentMethod">

      The created fulfillment method.

      See the [Fulfillment Method Object](/api-reference/business-solutions/restaurants/online-orders/fulfillment-methods/fulfillment-method-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Fulfillment Method Created | `wix.restaurants.v1.fulfillment_method_created` | Triggered when a fulfillment method is created. |
