    Retrieves a list of balances.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.READ_LIMITED">SCOPE.BENEFIT_PROGRAMS.READ (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/benefit-programs/v1/balances
    ```

    ## Query Params

    <ParamField query="poolIds" type="string[]">

      List of IDs of the pools associated with the balances to retrieve. These are also the IDs of the balances.

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    <ParamField query="cursorPaging" type="CursorPaging">

      Cursor paging.

      <Expandable title="cursorPaging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="balances" type="Balance[]">

      Retrieved balances.

      Constraints: `maxItems 100`.

      See the [Balance Object](/api-reference/business-solutions/benefit-programs/balances/balance-object) for this object's fields.
