    <div className="wix-ref">

    Duplicates a program as a new draft.

    The duplicated program gets a new ID and owner, starts in `DRAFT` status,
    keeps category assignments and translation content, resets the SEO slug to
    the duplicated program ID, clears the connected social group, and doesn't
    copy section or step references.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/v3/programs/{programId}/duplicate
    ```

    ## Path Params

    <ParamField path="programId" type="string" required>

      ID of the program to duplicate.

    </ParamField>

    ## Response Object

    <ResponseField name="program" type="Program">

      New draft program created from the source program.

      See the [Program Object](/api-reference/business-management/online-programs/programs/program-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
