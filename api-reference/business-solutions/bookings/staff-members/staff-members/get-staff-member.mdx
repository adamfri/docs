    This method requires one of the following permission scopes:

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v1/staff-members/{staffMemberId}
    ```

    ## Path Params

    <ParamField path="staffMemberId" type="string" required>

      ID of the staff member to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `RESOURCE_DETAILS` — Includes `resource` in the response.
      - `ASSOCIATED_IDENTITY_STATUS` — Includes `associatedIdentityStatus` in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="staffMember" type="StaffMember">

      Retrieved staff member.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ResponseField>
