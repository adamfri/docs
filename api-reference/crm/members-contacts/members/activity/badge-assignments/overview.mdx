A badge assignment represents the relationship between a badge and a member.
When a badge assignment is created, the specified member receives the badge
and any associated permissions or privileges.

## SDK package

```bash
npm install @wix/members
```

Import the `badgeAssignments` namespace from `@wix/members`.
