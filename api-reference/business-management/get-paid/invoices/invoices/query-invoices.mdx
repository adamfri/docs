    Retrieves a list of up to 1,000 invoices, given the provided paging, filtering, and sorting.

    Query Invoices runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order
    - `paging.limit` is `50`
    - `paging.offset` is `0`
