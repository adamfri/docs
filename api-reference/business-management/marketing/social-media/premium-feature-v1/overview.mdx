A premium feature is a capability, such as publishing or scheduling a post, whose availability and usage quota depend on the site's plan. Check a feature before calling the method that uses it to confirm the site can perform the action and has remaining quota.

## SDK package

```bash
npm install @wix/promote-growth-tools-publisher
```

Import the `premiumFeatures` namespace from `@wix/promote-growth-tools-publisher`.
