    Retrieves a join application by ID.

    Members can retrieve their own join applications. Wix users can retrieve any join application.

    To retrieve the calling member's own application for a program without knowing its ID, call [Get Current Join Application](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/get-current-join-application).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Retrieved join application.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
