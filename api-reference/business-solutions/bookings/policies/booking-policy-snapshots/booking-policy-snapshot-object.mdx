---
title: "Booking Policy Snapshot Object"
description: "The bookingPolicySnapshot object is the version of a service's booking policy at the time a booking is created."
icon: "cube"
---

The `bookingPolicySnapshot` object is the version of a service's booking policy
at the time a booking is created. This allows you for example to charge
customers the correct cancellation fee even after a service's cancellation
policy has been updated.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Booking policy snapshot ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="bookingId" type="string">

      ID of the booking that's associated with this policy snapshot.

    </ResponseField>

    <ResponseField name="policy" type="BookingPolicy">

      Snapshot of the [booking policy](https://dev.wix.com/docs/rest/business-solutions/bookings/policies/booking-policies/introduction).
      at the time the corresponding booking was created.

      <Expandable title="policy properties">

        <ResponseField name="id" type="string">

          Booking policy ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="revision" type="integer">

          Revision number, which increments by 1 each time the booking policy is updated. To prevent conflicting changes, the current `revision` must be passed when updating the booking policy.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the booking policy was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the booking policy was updated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="name" type="string">

          Name of the booking policy.

        </ResponseField>

        <ResponseField name="customPolicyDescription" type="PolicyDescription">

          Custom description for the booking policy and whether the booking policy is displayed to the participant.

          <Expandable title="customPolicyDescription properties">

            <ResponseField name="enabled" type="boolean">

              Whether the description is displayed to the participant. `true` means the
              description is displayed.

              Default: `false`

            </ResponseField>

            <ResponseField name="description" type="string">

              Description of the booking policy.

              Default: Empty
              Max length: 2500 characters

              Constraints: `maxLength 2500`.

            </ResponseField>

            <ResponseField name="descriptionTranslated" type="string">

              Description of the translated booking policy.

              Default: Empty
              Max length: 2500 characters

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="default" type="boolean">

          Whether the booking policy is the default.

          **Read-only.**

        </ResponseField>

        <ResponseField name="cancellationPolicy" type="CancellationPolicy">

          Rule for canceling a booking.

          <Expandable title="cancellationPolicy properties">

            <ResponseField name="enabled" type="boolean">

              Whether customers can cancel the booking. `true` means customers can cancel
              the booking.

              Default: `false`

            </ResponseField>

            <ResponseField name="limitLatestCancellation" type="boolean">

              Whether there's a limit on the latest cancellation time. `false` means
              customers can cancel the booking until the last minute before the course or
              session starts.

              Default: `false`

            </ResponseField>

            <ResponseField name="latestCancellationInMinutes" type="integer">

              Minimum number of minutes before the start of the session customers can cancel.
              For courses, this refers to the start of the first course session.

              Default: `1440` minutes (1 day)
              Min: `1` minute

              Constraints: `min 1`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="reschedulePolicy" type="ReschedulePolicy">

          Rule for rescheduling a booking.

          <Expandable title="reschedulePolicy properties">

            <ResponseField name="enabled" type="boolean">

              Whether customers can reschedule a booking for an appointment-based service.
              `true` means customers can reschedule.

              Default: `false`

            </ResponseField>

            <ResponseField name="limitLatestReschedule" type="boolean">

              Whether there's a limit on the latest supported rescheduling time. `false`
              means customers can reschedule until the last minute before the session start.

              Default: `false`

            </ResponseField>

            <ResponseField name="latestRescheduleInMinutes" type="integer">

              Minimum number of minutes before the session start session customers can
              reschedule their booking.

              Default: `1440` minutes (1 day)
              Min: `1` minute

              Constraints: `min 1`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="cancellationFeePolicy" type="CancellationFeePolicy">

          Rules for cancellation fees.

          <Expandable title="cancellationFeePolicy properties">

            <ResponseField name="enabled" type="boolean">

              Whether customers must pay a cancellation fee when canceling a booking.

              Default: `false`

            </ResponseField>

            <ResponseField name="cancellationWindows" type="CancellationWindow[]">

              Time windows relative to the session start during which customers can cancel
              their booking. Each window includes details about the fee for canceling
              within it.

              Constraints: `maxItems 2`.

              <Expandable title="cancellationWindows properties">

                <ResponseField name="startInMinutes" type="integer">

                  Start of the cancellation window in minutes before the session start. For
                  courses, this refers to the start of the first course session.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="autoCollectFeeEnabled" type="boolean">

              Whether Wix automatically charges the cancellation fee from the customer once
              they cancel their booking.

              Default: `true`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="saveCreditCardPolicy" type="SaveCreditCardPolicy">

          Rule for saving credit card details.

          <Expandable title="saveCreditCardPolicy properties">

            <ResponseField name="enabled" type="boolean">

              Whether Wix stores credit card details of the customer. Storing the details
              allows Wix to prefill the checkout and thus increases the likelihood that the
              customer completes the booking process.

              Default: `false`

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the booking policy snapshot was created in `YYYY-MM-DDThh:mm:ssZ` format.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "booking_policy_snapshots": [
          {
            "id": "c82a3f42-7605-4e24-91f5-7517ae189b7d",
            "booking_id": "353aa3b7-00ef-42bd-86ff-720d7ef60443",
            "policy": {
              "id": "7f31c2b3-9e6e-4b5f-b589-d524f1b3c872",
              "revision": 5,
              "created_date": "2024-01-10T10:30:00Z",
              "updated_date": "2024-05-20T15:45:00Z",
              "name": "Standard Booking Policy",
              "custom_policy_description": {
                "enabled": true,
                "description": "This is the standard booking policy description."
              },
              "default": true,
              "cancellation_policy": {
                "enabled": true,
                "limit_latest_cancellation": false,
                "latest_cancellation_in_minutes": 1440
              },
              "reschedule_policy": {
                "enabled": true,
                "limit_latest_reschedule": false,
                "latest_reschedule_in_minutes": 1440
              },
              "cancellation_fee_policy": {
                "enabled": true,
                "cancellation_windows": [
                  {
                    "amount": {
                      "value": "10",
                      "currency": "USD",
                      "formatted_value": null
                    },
                    "start_in_minutes": 1440
                  }
                ]
              },
              "save_credit_card_policy": {
                "enabled": true
              }
            },
            "created_date": "2024-06-15T10:45:00Z"
          }
        ]
      }
      ```

    </CodeGroup>

  </Tab>
