    Decrements quantities of multiple inventory items by variant and location.

    <Note>

    + `trackQuantity` must be `true` to allow for decrementing the quantity.
    + If you pass `restrictInventory: true` and the `decrementData.decrementBy` amount is greater than the current quantity in stock, the request will fail with an `INSUFFICIENT_INVENTORY` error.
    + Pass `restrictInventory: false` to allow for negative quantities.
    + If you pass `preorderRequest: true` and the item is available for preorder, the item's `preorderCounter` will increase and the item's quantity will stay the same.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

          + If `false` and the item is not available for preorder, negative inventory is not allowed.

        </ParamField>

    <ParamField body="restrictInventory" type="boolean">

      Whether to allow negative inventory following this decrement action.

      Default: `false` (negative inventory is not allowed)

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full inventory item entities in the response.

      Default: `false`

    </ParamField>

    <ParamField body="reason" type="string">

      Reason for decrement inventory action.

      **Supported values:**

      - `ORDER`
      - `MANUAL`
      - `REVERT_INVENTORY_CHANGE`

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVENTORY_QUANTITY_NOT_TRACKED` | Decrement attempted for untracked inventory. Enable inventory tracking first. |
    | `428` | `FAILED_PRECONDITION` | `INSUFFICIENT_INVENTORY` | Decrement would result in negative `quantity` or exceed preorder limit. Set `restrict_inventory` to `false` to allow negative quantities. |
    | `428` | `FAILED_PRECONDITION` | `MIN_QUANTITY_LIMIT_REACHED` | Decrement would reduce inventory below minimum quantity limit or `preorderInfo.counter` would exceed its maximum value. |
    | `428` | `FAILED_PRECONDITION` | `NOT_FOUND` | Inventory item with the specified `variant_id` and `location_id` not found. |
