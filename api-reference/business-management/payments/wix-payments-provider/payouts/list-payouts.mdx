    Retrieves a paginated list of payouts for the specified Wix Payments account.

    Supports optional filters by account profile and by creation date range.
    A newly created payout can take a short time to appear in the results.

    Calls are limited to 100 requests per 10 seconds per caller. Requests
    over the limit fail with a `RESOURCE_EXHAUSTED` error and the message
    `The request was throttled`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYMENTS.PAYOUTS-VIEW-FOR-SITE">View settlement reports and payouts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wixpay-payouts/v4/payouts
    ```

    ## Query Params

    <ParamField query="accountId" type="string" required>

      ID of the Wix Payments account whose payouts to list. Retrieve account
      IDs from the Accounts API.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="accountProfileId" type="string">

      ID of the Wix Payments account profile to filter by.

      When omitted, payouts across all profiles of the account are returned.
      Retrieve profile IDs from the Accounts API.

    </ParamField>

    <ParamField query="createdBefore" type="datetime">

      Returns only payouts created before this date and time. The date and time
      itself is excluded.

    </ParamField>

    <ParamField query="createdAfter" type="datetime">

      Returns only payouts created on or after this date and time. The date and
      time itself is included.

    </ParamField>

    <ParamField query="sort" type="Sorting">

      Sort order for the result list.

      Supported `fieldName` values: `created_date` (snake_case, not auto-converted). At most 1 sort field is allowed.

      <Expandable title="sort properties">

        <ParamField query="fieldName" type="string">

          Name of the field to sort by.

          Constraints: `maxLength 512`.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.

          **Supported values:**

          - `ASC`
          - `DESC`

        </ParamField>

        <ParamField query="origin" type="AddressLocation">

          Origin point for geo-distance sorting on a GEO field
          results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

          <Expandable title="origin properties">

            <ParamField query="latitude" type="number">

              Address latitude.

            </ParamField>

            <ParamField query="longitude" type="number">

              Address longitude.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="paging" type="Paging">

      Offset-based paging. `limit` supports values from `1` to `20`.

      Default: `limit` is `20`, `offset` is `0`.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>
