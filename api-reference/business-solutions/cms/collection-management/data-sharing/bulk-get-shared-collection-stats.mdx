    Retrieves sharing statistics for data collections shared out from the current site.

    For each source data collection, returns the number of distinct target sites the collection is
    currently shared with. Use this when you need a per-collection sharing summary
    (for example, a "Shared with N sites" indicator) without retrieving the full list of sharing connections.

    You can look up stats for up to 100 collections per call by specifying `sourceDataCollectionIds`.
    Leave `sourceDataCollectionIds` empty to return stats for every source data collection on the current site
    that has at least one active sharing connection.

    When you specify `sourceDataCollectionIds`, the response contains one result per distinct provided ID.
    A result has `itemMetadata.success = true` and `stats` populated when the collection has at least
    one active sharing connection. Otherwise, `itemMetadata.success = false` with
    `itemMetadata.error.code = "NOT_FOUND"`.

    To retrieve the full list of sharing connections (including target site and collection IDs), call
    [List Shared Data Collections](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-sharing-policy-v1/list-shared-data-collections)
    with `sharedWithCurrentSite` set to `false`.

    <Note>

    `connectedSitesCount` counts distinct target sites. If the same target site connects
    through multiple policies, it is counted once.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v1/data-collection-sharing/bulk-get-stats
    ```

    ## Body Params

    <ParamField body="sourceDataCollectionIds" type="string[]">

      Optional. Source data collection IDs to look up.

      Maximum: 100 IDs per request.

      If empty, returns one successful result per source data collection on the current site that has
      at least one active sharing connection.
      If non-empty, returns one result per distinct provided ID. Duplicate IDs are deduplicated; each
      ID's `itemMetadata.originalIndex` reflects its first position in the request array.
      A result has `itemMetadata.success = true` with `stats` populated when the collection has at least
      one active sharing connection; otherwise `itemMetadata.success = false` with
      `itemMetadata.error.code = "NOT_FOUND"`.

      Constraints: `maxLength 255`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkSharedCollectionStatsResult[]">

      Per-collection sharing stats results.

      When `sourceDataCollectionIds` is empty, contains one successful result per source data collection
      on the current site that has at least one active sharing connection.
      When `sourceDataCollectionIds` is non-empty, contains one result per distinct provided ID.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Per-item metadata: success flag, original request index, and error details when the lookup failed.

          `itemMetadata.id` is set to the source data collection ID.
          When `itemMetadata.success` is `false`, `itemMetadata.error.code` is `"NOT_FOUND"`.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Does not appear if the item ID is missing. For example, when item creation fails.

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Original index of the item in the array specified in the request. Use this to match items in the request with those in the response.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              In case of failure, the error details.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="stats" type="SharedCollectionStats">

          Sharing stats for the collection. Populated only when `itemMetadata.success` is `true`.

          <Expandable title="stats properties">

            <ResponseField name="sourceDataCollectionId" type="string">

              Source data collection ID on the current site.

              Constraints: `maxLength 255`.

            </ResponseField>

            <ResponseField name="connectedSitesCount" type="integer">

              Number of distinct target sites the collection is currently shared with.

              If the same target site connects through multiple sharing policies, it is counted once.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Aggregate success and failure counts across `results`.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

      </Expandable>

    </ResponseField>
