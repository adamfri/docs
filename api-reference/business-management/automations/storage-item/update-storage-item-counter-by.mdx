    Atomically increments or decrements a storage item of type `COUNTER` by the specified value.

    Learn more about [atomic updates](https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/introduction#atomic-updates).

    <Note>

    To update other types of items, call [Update Storage Item Value](https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/update-storage-item-value).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/storage-service/v1/storage-items/{key}/update-counter-by
    ```

    ## Path Params

    <ParamField path="key" type="string" required>

      Key of the storage item to update.

    </ParamField>

    ## Body Params

    <ParamField body="value" type="string" required>

      Value to add to the existing counter, represented as a string. To decrement the counter, use a negative value.

      Constraints: `>= -9999999999999999.99`, `<= 9999999999999999.99`.

    </ParamField>

    ## Response Object

    <ResponseField name="storageItem" type="StorageItem">

      Updated storage item.

      See the [Storage Item Object](/api-reference/business-management/automations/storage-item/storage-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_STORAGE_ITEM_TYPE_EXCEPTION` | Invalid storage item type. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_NUMBER_VALUE` | Invalid value. The value is not a valid number. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
