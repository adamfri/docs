    Updates an earning rule.

    Supports partial updates.

    Revision number, which increments by 1 each time the earning rule is updated. To prevent conflicting changes,
    the current `revision` must be passed when updating the earning rule.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/_api/loyalty-earning-rules/v1/earning-rules/{earningRule.id}
    ```

    ## Path Params

    <ParamField path="earningRule.id" type="string" required>

      Loyalty earning rule ID.

    </ParamField>

    ## Body Params

    <ParamField body="earningRule" type="LoyaltyEarningRule" required>

      Earning rule to update.

      See the [Loyalty Earning Rule Object](/api-reference/crm/loyalty-program/loyalty-program-management/earning-rules/loyalty-earning-rule-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="earningRule" type="LoyaltyEarningRule">

      The updated earning rule.

      See the [Loyalty Earning Rule Object](/api-reference/crm/loyalty-program/loyalty-program-management/earning-rules/loyalty-earning-rule-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
