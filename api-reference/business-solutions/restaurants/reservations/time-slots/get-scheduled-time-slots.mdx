    Returns a list of scheduled time slots at a specified reservation location for a specified time range, and their availability for a specified `partySize`.

    Scheduled time slots are sequential time periods whose start times fall within a restaurant's opening hours. Opening hours are defined in the reservation location's `businessSchedule`.

    [Experiences](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/wix-restaurants-new/reservations/experiences/introduction) have their own business schedules that override that of the reservation location. To get scheduled time slots for an experience, pass the ID of that experience to this method.

    If a restaurant is open during distinct time periods throughout the week, the `startDate` of the first scheduled time slot returned for each period is the same as starting time of that time period.
    If a restaurant is always open, the `startDate` of the first returned scheduled time slot for each week is Sunday at `00:00`.

    The duration of scheduled time slots and the interval between their `startDate`s is determined by the reservation location's `timeSlotInterval`.

    For example:

    A restaurant is open every night from `22:30` to `03:55` with a `timeSlotInterval` of 1 hour.
    If you called this method with the time range `23:00` to `02:50`, it would return time slots starting at `23:30`, `00:30`, `01:30`, and `02:30`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-BASIC">Manage Reservations (Basic)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/reservations/v1/scheduled-time-slots
    ```

    ## Body Params

    <ParamField body="reservationLocationId" type="string" required>

      ID of the reservation location for which to retrieve time slots.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="timeRange" type="TimeRange" required>

      Time range from which to retrieve time slots.

      <Expandable title="timeRange properties">

        <ParamField body="startDate" type="datetime" required>

          Date and time from which to retrieve time slots in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601#coordinated_Universal_Time_(UTC)) format.

        </ParamField>

        <ParamField body="endDate" type="datetime" required>

          Date and time to which to retrieve time slots in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601#coordinated_Universal_Time_(UTC)) format.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="partySize" type="integer" required>

      Size of the party that needs to be seated during this time slot.

      Min: `1`

    </ParamField>

    ## Response Object

    <ResponseField name="timeSlots" type="TimeSlot[]">

      A list of time slots and their availability according to the specified party size.

      Constraints: `minItems 0`, `maxItems 100`.

      See the [Time Slot Object](/api-reference/business-solutions/restaurants/reservations/time-slots/time-slot-object) for this object's fields.

    </ResponseField>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
