    Creates a refund.

    The refunding process starts immediately after a refund entity is created.

    If you specify an `amount`, you must also specify a `currency_code`. This currency should be the same as the currency of the charge.
    If `amount` and `currency_code` are not specified, the refund is created for the full charge amount. If the charge was already partially refunded, this refund will fail.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-REFUNDS">Manage Refunds</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/refunds/v1/refunds
    ```

    ## Body Params

    <ParamField body="refund" type="Refund" required>

      Refund to be created.

      See the [Refund Object](/api-reference/business-management/payments/refunds/refund-object) for this object's fields.

    </ParamField>

    <ParamField body="previouslyRefundedAmount" type="string">

      Amount of the charge that was previously refunded.

      Specify this to compare your records of previously refunded amounts against those on the server. If they don't match, this method will return an error with the code `PREVIOUSLY_REFUNDED_AMOUNT_MISMATCH`.

      Learn more about [preventing unintended refunds](https://dev.wix.com/docs/rest/business-management/payments/refunds/introduction#preventing-unintended-refunds).

    </ParamField>

    ## Response Object

    <ResponseField name="refund" type="Refund">

      The created refund.

      See the [Refund Object](/api-reference/business-management/payments/refunds/refund-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CHARGE_REFUNDED` | Charge was already fully refunded. |
    | `428` | `FAILED_PRECONDITION` | `CHARGE_REFUND_IN_PROGRESS` | Another refund is in progress for this charge. |
    | `428` | `FAILED_PRECONDITION` | `CHARGE_DISPUTED` | Charge is disputed and can't be refunded. |
    | `428` | `FAILED_PRECONDITION` | `CHARGE_REFUND_PERIOD_ENDED` | Charge is too old to refund. |
    | `428` | `FAILED_PRECONDITION` | `CHARGE_UNPAID` | Charge is unpaid and can't be refunded. |
    | `428` | `FAILED_PRECONDITION` | `PROVIDER_DOWN` | Payment service provider is temporarily unavailable. Try again later. |
    | `428` | `FAILED_PRECONDITION` | `PROVIDER_NOT_SUPPORTED` | Payment service provider doesn't support refunds for this charge. |
    | `428` | `FAILED_PRECONDITION` | `PAYMENT_METHOD_NOT_SUPPORTED` | Payment method doesn't support refunds. |
    | `428` | `FAILED_PRECONDITION` | `MERCHANT_BALANCE_INSUFFICIENT` | Merchant account balance is insufficient to process the refund. |
    | `428` | `FAILED_PRECONDITION` | `ONLINE_REFUND_NOT_SUPPORTED` | Charge was made at a POS terminal and must be refunded on that terminal. |
    | `428` | `FAILED_PRECONDITION` | `PARTIAL_REFUND_NOT_SUPPORTED` | Payment service provider doesn't support partial refunds. Refund the full amount. |
    | `428` | `FAILED_PRECONDITION` | `REFUND_AMOUNT_OUT_OF_BOUNDS` | Refund amount is outside the allowed range. |
    | `400` | `INVALID_ARGUMENT` | `REFUND_CURRENCY_MISSING` | The `currency_code` field is required when specifying an `amount`. |
    | `400` | `INVALID_ARGUMENT` | `REFUND_CURRENCY_MISMATCH` | Refund currency doesn't match the charge currency. |
    | `428` | `FAILED_PRECONDITION` | `PREVIOUSLY_REFUNDED_AMOUNT_MISMATCH` | The `previously_refunded_amount` doesn't match the server's calculated amount. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
