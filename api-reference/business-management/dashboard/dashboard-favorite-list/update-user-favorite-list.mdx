    <div className="wix-ref">

    Updates the current Wix user's list of favorite dashboard pages.

    Make sure to include the current revision number when calling this method.

    <Note>

    Updating the list replaces the favorite pages it contains with those specified in the method call.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.MANAGE_DASHBOARD">Manage Dashboard</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/dashboard/v1/user-favorite-list/{favoriteList.id}
    ```

    ## Path Params

    <ParamField path="favoriteList.id" type="string" required>

      Dashboard favorite list ID. Automatically generated by Wix.

    </ParamField>

    ## Body Params

    <ParamField body="favoriteList" type="DashboardFavoriteList" required>

      Dashboard favorite list to update. The `favorites` array in the request replaces the existing `favorites` array.

      To prevent conflicting changes, include the current revision number.

      See the [Favorite List Object](/api-reference/business-management/dashboard/dashboard-favorite-list/favorite-list-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="favoriteList" type="DashboardFavoriteList">

      Updated dashboard favorite list.

      See the [Favorite List Object](/api-reference/business-management/dashboard/dashboard-favorite-list/favorite-list-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | --- | --- | --- |
    | Favorite List Updated | `wix.dashboard.v1.favorite_list_updated` | Triggered when pages are added, removed, or the dashboard favorite list is updated. |

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Dashboard favorite list ID. Automatically generated by Wix.

      **Read-only.**

    </ParamField>

    <ParamField body="favoriteList" type="UpdateUserFavoriteList" required>

      Dashboard favorite list to update. The `favorites` array in the request replaces the existing `favorites` array.

      To prevent conflicting changes, include the current revision number.

      <Expandable title="favoriteList properties">

        <ParamField body="_id" type="string">

          Dashboard favorite list ID. Automatically generated by Wix.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number. Increments automatically by 1 whenever the list is successfully updated. To prevent conflicting changes, pass the current revision number when updating the list.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the dashboard favorite list was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the dashboard favorite list was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="favorites" type="Favorite[]">

          List of favorite dashboard pages.

          Constraints: `maxItems 100`.

          <Expandable title="favorites properties">

            <ParamField body="_id" type="string">

              Favorite ID. Automatically generated by Wix.

            </ParamField>

            <ParamField body="pageId" type="string">

              ID of the page added to the list.

              Constraints: `minLength 1`, `maxLength 200`.

            </ParamField>

            <ParamField body="relativeUrl" type="string">

              Relative URL appended to the page's URL for customizing the navigation. It can include path segments, a query string, or a fragment identifier.

            </ParamField>

            <ParamField body="title" type="string">

              Custom title displayed in the list of favorite pages.

            </ParamField>

          </Expandable>

        </ParamField>
