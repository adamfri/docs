    Deletes a delivery profile.

    Permanently deletes the delivery profile and its delivery regions and carrier configurations. Delivery regions are unique to each profile and aren't shared across profiles. This action can't be undone.

    The default delivery profile can't be deleted because every site requires one for core delivery functionality.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/ecom/v1/delivery-profiles/{deliveryProfileId}
    ```

    ## Path Params

    <ParamField path="deliveryProfileId" type="string" required>

      Delivery profile ID.

    </ParamField>

    ## Response Object

    Returns `DeleteDeliveryProfileResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Delivery Profile Deleted | `wix.ecom.v1.delivery_profile_deleted` | Triggered when a delivery profile is deleted. |
    | Delivery Profile Region Removed | `wix.ecom.v1.delivery_profile_region_removed` | Triggered when a delivery region is removed from a delivery profile. |

    </div>
