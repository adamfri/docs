---
title: "Delivery Profile Object"
description: "A delivery profile is a collection of delivery regions that define shipping options for products."
icon: "cube"
---

A delivery profile is a collection of delivery regions that define shipping options for products.
Each profile contains delivery regions, which specify where products can be shipped and which carriers can deliver to those destinations.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Delivery profile ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Delivery profile name.

    </ResponseField>

    <ResponseField name="default" type="boolean">

      Whether this is the default delivery profile.

      > **Notes:**
      >
      > - The first delivery profile is automatically created and marked as default when the Wix Stores, Wix Bookings, Wix Events, or Wix Restaurants business solutions are installed on a site.
      > - Default status can't be changed or transferred to another profile.
      > - The default profile can't be deleted because every site requires one for core delivery functionality.

      **Read-only.**

    </ResponseField>

    <ResponseField name="deliveryRegions" type="DeliveryRegion[]">

      Delivery regions in this profile.

      Constraints: `minItems 0`, `maxItems 100`.

      <Expandable title="deliveryRegions properties">

        <ResponseField name="id" type="string">

          Delivery region ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="name" type="string">

          Delivery region name. For example, `"Domestic"` or `"International"`.

        </ResponseField>

        <ResponseField name="active" type="boolean">

          Whether this delivery region is active and available during checkout.

          Default: `true`

        </ResponseField>

        <ResponseField name="deliveryCarriers" type="DeliveryCarrier[]">

          Delivery carriers assigned to this region. Carriers are managed using the [Add Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/add-delivery-carrier), [Update Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/update-delivery-carrier), and [Remove Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/remove-delivery-carrier) methods.

          **Read-only.** Constraints: `minItems 0`, `maxItems 25`.

          <Expandable title="deliveryCarriers properties">

            <ResponseField name="appId" type="string">

              Carrier app ID.

              Get app IDs from the [app dashboard](https://dev.wix.com/dc3/my-apps/), or by calling [List Installed Delivery Carriers](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/list-installed-delivery-carriers).

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="backupRate" type="BackupRate">

              Backup rate to use when the carrier doesn't return a rate for a specific shipping option.

              When `active` is `false` and the carrier doesn't return a rate, the carrier's shipping options aren't shown to customers.

              <Expandable title="backupRate properties">

                <ResponseField name="title" type="string">

                  Title displayed for the backup rate. For example, `"Standard Shipping"`.

                </ResponseField>

                <ResponseField name="amount" type="string">

                  Backup rate amount.

                </ResponseField>

                <ResponseField name="active" type="boolean">

                  Whether the backup rate is active.

                  The backup rate is used in the following situations:
                  + When `active` is `true`.
                  + When the carrier does not return a cost for any reason.

                  If active, and no cost is returned by the carrier, the backup rate will be displayed to customers as the shipping option.

                  Default: `false`

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="additionalCharges" type="AdditionalCharge[]">

              Additional charges to add to the delivery rate. These charges are combined with the carrier's rate into a single shipping cost and itemized in order details.

              Constraints: `maxItems 10`.

              <Expandable title="additionalCharges properties">

                <ResponseField name="description" type="string">

                  Description of the additional charge. For example, `"Handling fee of $5 applied for gift wrapping"`.

                </ResponseField>

                <ResponseField name="amount" type="string">

                  Additional fixed charge amount to add to the delivery rate. For example, `"12.50"`.

                  Constraints: `maxLength 16`.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="destinations" type="Destination[]">

          Geographic destinations covered by this region. If empty, the region applies globally (Rest of World). A site can have up to 250 destinations across all delivery profiles.

          Constraints: `minItems 0`, `maxItems 250`.

          <Expandable title="destinations properties">

            <ResponseField name="countryCode" type="string">

              2-letter country code in [ISO-3166 alpha-2](https://www.iso.org/obp/ui/#search/code/) format.

              Constraints: `format COUNTRY`.

            </ResponseField>

            <ResponseField name="subdivisions" type="string[]">

              Subdivision codes in [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) format. For example, `"US-CA"` for California. If empty, the delivery region applies to the entire country.

              The following countries don't support subdivision-level delivery and require an empty `subdivisions` list. Sending subdivisions for these countries fails with `SUBDIVISIONS_UNSUPPORTED_FOR_COUNTRY`:
              `AT`, `BE`, `BS`, `CH`, `CI`, `CZ`, `DO`, `GR`, `NO`, `PL`, `RS`, `SD`, `SI`, `SK`, `SN`.

              Constraints: `minLength 1`, `maxLength 256`, `minItems 0`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the delivery region was created.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdBy" type="CreatedBy">

      Information about who created the delivery profile.

      Currently only for use with Wix Restaurants.

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="appId" type="string">

              App ID, when the delivery profile was created by an external application or Wix service.

            </ResponseField>

            <ResponseField name="userId" type="string">

              Wix user ID, when the delivery profile was created by a Wix user using the dashboard or an API call.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the delivery profile is updated. To prevent conflicting changes, the current revision must be passed when updating the delivery profile. Ignored when creating a delivery profile.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the delivery profile was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the delivery profile was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the delivery profile object. [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
