    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-rewards/v1/rewards/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the reward to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="reward" type="Reward">

      Retrieved reward.

      See the [Reward Object](/api-reference/crm/loyalty-program/rewards/rewards/reward-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
