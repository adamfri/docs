    <div className="wix-ref">

    Sets the member privacy settings for a site.

    Each time the member privacy settings are updated, `revision` increments by 1. The existing `revision` must be included when updating the member privacy settings. This ensures you're working with the latest member privacy settings and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/privacy-settings
    ```

    ## Body Params

    <ParamField body="memberPrivacySettings" type="MemberPrivacySettings" required>

      Member privacy settings details.

      See the [Member Privacy Settings Object](/api-reference/crm/members-contacts/members/member-management/privacy/member-privacy-settings/member-privacy-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="memberPrivacySettings" type="MemberPrivacySettings">

      Member privacy settings.

      See the [Member Privacy Settings Object](/api-reference/crm/members-contacts/members/member-management/privacy/member-privacy-settings/member-privacy-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_REVISION` | The `revision` value doesn't match the current revision of the member privacy settings. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SETTINGS` | The provided `publicMemberVisibility` or `publicMemberCandidates` values are not supported. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Set Member Privacy Settings
    // @description: Updates the member privacy settings for a site. Call getMemberPrivacySettings first to retrieve the current revision.
    import { memberPrivacySettings } from "@wix/members";

    const memberPrivacySettingsData = {
      publicMemberVisibility: memberPrivacySettings.Visibility.VISIBLE_TO_ALL,
      publicMemberCandidates: memberPrivacySettings.Candidates.ANYONE,
      revision: "1",
    };

    async function setMemberPrivacySettings() {
      const response = await memberPrivacySettings.setMemberPrivacySettings(
        memberPrivacySettingsData
      );
      return response;
    }

    /* Promise resolves to:
     * {
     *   memberPrivacySettings?: {
     *     _id?: string | null;
     *     publicMemberVisibility?: "UNKNOWN" | "VISIBLE_TO_MEMBERS_ONLY" | "VISIBLE_TO_ALL";
     *     publicMemberCandidates?: "UNKNOWN" | "NO_ONE" | "ANYONE";
     *     revision?: string | null;
     *     _updatedDate?: Date | null;
     *   };
     * }
     */
    ```
