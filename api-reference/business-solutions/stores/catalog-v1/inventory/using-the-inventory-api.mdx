<Note>This article applies to the REST API only.</Note>

## Step 1 - Call [Get Inventory Variants](https://dev.wix.com/api/rest/wix-stores/inventory/get-inventory-variants) to retrieve product variants

<Tabs>

<Tab title="REST">

```bash
curl -X POST https://www.wixapis.com/stores/v2/inventoryItems/be547028-fb08-b962-75e8-3f3e56da9ee3/getVariants \
   -H 'Content-Type: application/json' \
   -H 'Authorization: <AUTH>' \
```

</Tab>

<Tab title="SDK">

```js
import { inventory } from "@wix/stores";

const inventoryId = "be547028-fb08-b962-75e8-3f3e56da9ee3"

async function getInventoryVariants(inventoryId) {
  const response = await inventory.getInventoryVariants(inventoryId);
}
```

</Tab>

</Tabs>

## Step 2 - Call [Update Inventory Status](https://dev.wix.com/api/rest/wix-stores/inventory/update-inventory-variants) to update specific variant of a product 

Update whether the product inventory is tracked:
<Tabs>

<Tab title="REST">

```bash
curl -X PATCH https://www.wixapis.com/stores/v2/inventoryItems/078acefc-f4c5-4db5-b6ce-af21d7f53ce5 \
   -H 'Content-Type: application/json' \
   -H 'Authorization: <AUTH>' \
   -d '
       {
       	"inventoryItem": {
           "trackQuantity": false,
       	}
       }'

```

</Tab>

<Tab title="SDK">

```js
import { inventory } from "@wix/stores";

const productId = "078acefc-f4c5-4db5-b6ce-af21d7f53ce5";

const inventoryItem = {
    trackQuantity: false
  }

async function updateInventoryVariants(productId, inventoryItem) {
  const response = await inventory.updateInventoryVariants(
    productId,
    inventoryItem
  );
}

```

</Tab>

</Tabs>

For a non-tracked product, you should update the `inStock` value:
<Tabs>

<Tab title="REST">

```bash
curl -X PATCH https://www.wixapis.com/stores/v2/inventoryItems/078acefc-f4c5-4db5-b6ce-af21d7f53ce5 \
   -H 'Content-Type: application/json' \
   -H 'Authorization: <AUTH>' \
   -d '
       {
       	"inventoryItem": {
       		"trackQuantity": false,
       		"variants": [
            {
                "variantId": "00000000-0000-0001-0005-9a596c8e6f10",
                "inStock": false
            }
          ]
       	}
       }'

```

</Tab>

<Tab title="SDK">

```js
import { inventory } from "@wix/stores";

const productId = "078acefc-f4c5-4db5-b6ce-af21d7f53ce5";

const inventoryItem = {
    trackQuantity: false,
    variants: [
      {
          variantId: "00000000-0000-0001-0005-9a596c8e6f10",
          inStock: false
      }
    ]
  }

async function updateInventoryVariants(productId, inventoryItem) {
  const response = await inventory.updateInventoryVariants(
    productId,
    inventoryItem
  );
}

```

</Tab>

</Tabs>
