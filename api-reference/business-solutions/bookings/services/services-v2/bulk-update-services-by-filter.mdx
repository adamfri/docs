    <div className="wix-ref">

    Updates multiple services by filter.

    See [Query Services](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/query-services) for a list of supported filters.

    See [Update Service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/update-service) for more details about updating a service.

    The call succeeds even if one or more individual services can't be updated.
    Information about failures is returned in `bulkActionMetadata`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bulk/services/update-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter to identify the services to update.

    </ParamField>

    <ParamField body="service" type="Service" required>

      Service to update.

      See the [Service Object](/api-reference/business-solutions/bookings/services/services-v2/service-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      ID of the service update job.

      Pass this ID to [Get Async Job](https://dev.wix.com/docs/rest/business-management/async-job/introduction) to retrieve job details and metadata.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Service Updated | `wix.bookings.services.v2.service_updated` | Triggered when a service is updated. |

    </div>
