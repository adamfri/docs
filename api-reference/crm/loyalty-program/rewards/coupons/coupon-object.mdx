---
title: "Coupon Object"
description: "A loyalty coupon is created when a customer redeems their loyalty points for a reward."
icon: "cube"
---

A loyalty coupon is created when a customer redeems their loyalty points for a reward. Creating a loyalty coupon
also creates a corresponding "reference" coupon with the Coupons API.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Loyalty coupon ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="accountId" type="string">

      Loyalty [account ID](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/account-object) of the customer that redeemed points for a coupon.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="memberIdDeprecated" type="string" deprecated>

      Member ID of the customer that redeemed points for a coupon. See the Members API for more information.

      **Read-only.** **Deprecated.** Member ID of the customer that redeemed points for a coupon. See the Members API for more information. Use `member_id` instead. Removal: 2024-06-01. Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="memberId" type="string">

      Member ID of the customer that redeemed points for a coupon. See the Members API for more information.

      **Read-only.**

    </ResponseField>

    <ResponseField name="transactionId" type="string">

      [Transaction ID](https://dev.wix.com/docs/rest/crm/loyalty-program/transactions/loyalty-transaction-object) for the transaction that created a coupon.

      **Read-only.**

    </ResponseField>

    <ResponseField name="couponReference" type="CouponReference">

      Reference coupon information for the corresponding [coupon](https://dev.wix.com/docs/rest/business-management/marketing/coupons/coupons/coupon-object)
      that is created along with the loyalty coupon.

      **Read-only.**

      <Expandable title="couponReference properties">

        <ResponseField name="couponId" type="string">

          Coupon ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="code" type="string">

          Coupon code.

          Unique code entered by a customer to apply the coupon.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

        <ResponseField name="name" type="string">

          Name of coupon.

          **Read-only.**

        </ResponseField>

        <ResponseField name="specification" type="Specification">

          The information to use when creating the coupon.

          **Read-only.**

          <Expandable title="specification properties">

            <ResponseField name="name" type="string">

              Name of coupon.

            </ResponseField>

            <ResponseField name="type" type="string">

              **Supported values:**

              - `MONEY_OFF_AMOUNT`
              - `PERCENT_OFF_RATE`
              - `FREE_SHIPPING`
              - `FIXED_PRICE_AMOUNT`
              - `BUY_X_GET_Y`

            </ResponseField>

            <ResponseField name="limitedToOneItem" type="boolean">

              Whether the coupon is limited to 1 discount per order. If true and a customer pays for multiple items
              that the coupon applies to, only the lowest priced item is discounted.
              Coupons with a `bookings` `namespace` are always limited to 1 item.

            </ResponseField>

            <ResponseField name="appliesToSubscriptions" type="boolean">

              Whether the coupon also applies to subscriptions.

            </ResponseField>

            <ResponseField name="discountedCycleCount" type="integer">

              Specifies the amount of cycles to apply the discount to for a subscription item.

              Can only be set when `appliesToSubscriptions` is `TRUE` and `specification.scope.namespace` is `pricingPlans`.
              If `discountedCycleCount` is empty, the coupon applies to all available cycles.

              Min: `1`

              Max: `999`

            </ResponseField>

          </Expandable>

          <Expandable title="One of the following">

            <ResponseField name="typeDetails" type="typeDetails">

              typeDetails

              <Expandable title="typeDetails properties">

                <ResponseField name="moneyOffAmount" type="number">

                  Fixed price discount.

                  Constraints: `min 0.01`.

                </ResponseField>

                <ResponseField name="percentOffRate" type="number">

                  Discount as a percentage.

                </ResponseField>

                <ResponseField name="freeShipping" type="boolean">

                  Free shipping. If true, the coupon applies to all items in all `namespaces` on a site.

                </ResponseField>

                <ResponseField name="fixedPriceAmount" type="number">

                  Specific sale price. Currently only supported for coupons with a `stores` `namespace`.

                </ResponseField>

                <ResponseField name="buyXGetY" type="BuyXGetY">

                  Free products when making a purchase. `buyXGetY` is an object that specifies `x` and `y` in the
                  following scenario: if a visitor purchases x number of products, they receive y number of products for free. C
                  urrently only supported for coupons with a `stores` `namespace`.

                  _Nested structure omitted for brevity — see the `BuyXGetY` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="ScopeOrMinSubtotal" type="ScopeOrMinSubtotal">

              ScopeOrMinSubtotal

              <Expandable title="ScopeOrMinSubtotal properties">

                <ResponseField name="scope" type="Scope">

                  Scope of the coupon. When no scope is defined, the coupon applies to all
                  items in all `namespaces` in the site.

                  _Nested structure omitted for brevity — see the `Scope` object._

                </ResponseField>

                <ResponseField name="minimumSubtotal" type="number">

                  The coupon is only applicable when the order subtotal is over this amount.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="deleted" type="boolean">

          Whether the referenced coupon was deleted.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Loyalty coupon status.

      This status relates to the corresponding coupon that is created
      at the same time as the loyalty coupon and is included in `couponReference`.

      **Read-only.**

      **Supported values:**

      - `PENDING` — The reference coupon was created but the loyalty points have not been redeemed yet.
      - `ACTIVE` — The reference coupon is active and available to the customer.
      - `APPLIED` — The reference coupon was applied and is no longer available for use.
      - `FAILED` — The reference coupon was created but something went wrong when redeeming points from the loyalty account.
      - `ARCHIVED` — The reference coupon was deleted.

    </ResponseField>

    <ResponseField name="rewardName" type="string">

      Name of reward that was redeemed to create this coupon.

      **Read-only.** Constraints: `minLength 1`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the loyalty coupon is updated.

      To prevent conflicting changes, the current `revision` must be passed when updating the loyalty coupon.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the loyalty coupon was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the loyalty coupon was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="refundable" type="boolean">

      Whether the loyalty coupon was created in a "refundable workflow" i.e. checkout-exchange, and therefore can be deleted in the background. Refundable coupons should not be visible to customers in the UI.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "coupon": {
          "id": "c90918b2-e9a5-4147-b4a4-953e235b9ddd",
          "accountId": "bf14421a-0ccb-4656-a91f-84119e8fc994",
          "memberId": "e64eee9f-ec4e-4c8a-b015-eb3be0b2761b",
          "couponReference": {
            "couponId": "e48b4b92-3481-40bf-943d-c9324ae3cd6d",
            "code": "6Q1LC0K4KHSL",
            "name": "Free shipping",
            "specification": {
              "type": "FREE_SHIPPING",
              "freeShipping": true
            }
          },
          "status": "PENDING",
          "rewardName": "Free shipping",
          "revision": "1",
          "createdDate": "2024-04-18T15:07:53.639Z",
          "updatedDate": "2024-04-18T15:07:53.639Z"
        }
      }
      ```

    </CodeGroup>
