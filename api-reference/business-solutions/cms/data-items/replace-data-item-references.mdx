    <div className="wix-ref">

    Replaces references in a specified field of a specified data item.

    This method replaces the existing reference or references contained in the field specified in `referringItemFieldName` within the data item specified in `referringItemId`.
    The method removes existing references and in their place it adds references to the items specified in `newReferencedItemIds`.

    <Note>

    If you pass an empty array in `newReferencedItemIds`, all existing references are removed.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/items/replace-references
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection containing the referring item.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="referringItemFieldName" type="string" required>

      Field containing references in the referring item.

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField body="referringItemId" type="string" required>

      ID of the referring item.

      Constraints: `maxLength 128`.

    </ParamField>

    <ParamField body="newReferencedItemIds" type="string[]">

      List of new referenced item IDs to replace the existing ones.

      Constraints: `maxLength 128`, `maxItems 1000`.

    </ParamField>

    ## Response Object

    <ResponseField name="dataItemReferences" type="DataItemReference[]">

      Updated references.

      <Expandable title="dataItemReferences properties">

        <ResponseField name="referringItemFieldName" type="string">

          Referring item field containing the references to the referenced items.

          Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="referringItemId" type="string">

          ID of the referring item.

          Constraints: `maxLength 128`.

        </ResponseField>

        <ResponseField name="referencedItemId" type="string">

          ID of the referenced item.

          Constraints: `maxLength 128`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
