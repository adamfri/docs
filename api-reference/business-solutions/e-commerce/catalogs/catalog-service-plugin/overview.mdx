Describes the catalog integration to be called by Wix and received by the relevant catalog provider. This integration is used to interface between the Wix eCommerce platform and externally managed repositories of sellable items.

## SDK package

```bash
npm install @wix/ecom
```

Import the `catalog` namespace from `@wix/ecom`.
