    <div className="wix-ref">

    Retrieves a list of shared data collections.

    Returns either the collections that are either being shared by the current site or shared with the current site. Specify `sharedWithCurrentSite` to filter the direction.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v1/data-collection-sharing/shared
    ```

    ## Query Params

    <ParamField query="dataCollectionIds" type="string[]">

      List of collection IDs to filter by.

      When provided, only returns shared connections for the specified collections.

      Constraints: `maxLength 255`, `maxItems 100`.

    </ParamField>

    <ParamField query="sharedWithCurrent" type="boolean" deprecated>

      Whether to list collections shared with the current site or shared from the current site.

      **Deprecated.** Use `shared_with_current_site` instead. Removal: 2026-12-31.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Paging information.
      By default, shared collections are sorted by `id` in ascending order.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="sharedWithCurrentSite" type="boolean">

      Whether to list collections shared with the current site or shared from the current site.
      When `true`, lists collections shared with the current site. When `false`, lists collections shared from the current site's policies.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="connections" type="SharingConnection[]">

      List of shared collections.

      <Expandable title="connections properties">

        <ResponseField name="sourceDataCollectionId" type="string">

          ID of the data collection owned and shared by the source site.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="sourceSiteId" type="string">

          ID of the source site that owns the collection and created the policy.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="targetDataCollectionId" type="string">

          ID of the shared collection on the target site.
          The ID includes the namespace. For example, `"namespace/collectionName"`.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="targetSiteId" type="string">

          ID of the target site that the collection is shared with.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="targetDisplayNamespace" type="string">

          Optional display name for the namespace that appears on the target site.

        </ResponseField>

        <ResponseField name="dataSharingPolicyId" type="string">

          ID of the data sharing policy that controls this connection.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the connection was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the connection was last updated.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Offset that was requested.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
