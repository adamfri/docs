---
title: "Secret Object"
description: "The Secret object in the Wix Secret API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Unique secret ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      A unique, human-friendly name for the secret. Use it to retrieve the secret value with Get Secret Value.

      **Note:** You can use alphanumeric characters and the following special characters: `_+=-@#$`. Spaces are not supported.

    </ResponseField>

    <ResponseField name="description" type="string">

      Optional text describing the secret's purpose or any other notes about it.

    </ResponseField>

    <ResponseField name="value" type="string">

      The encrypted confidential value.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when the secret was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time when the secret was updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "secret": {
          "id": "a560ff70-3e9b-41b6-b66d-cf3434085f7d",
          "name": "secret_key",
          "description": "AWS secret access key",
          "value": "Fm8OfflH6bJOwWjenqAtLurLbkiMNvmhQHZV+118"
        }
      }
      ```

    </CodeGroup>
