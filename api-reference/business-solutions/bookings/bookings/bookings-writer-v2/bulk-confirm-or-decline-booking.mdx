    Confirms or declines up to 300 bookings.

    See [Confirm Or Decline Booking](https://dev.wix.com/docs/rest/business-solutions/bookings/bookings/bookings-writer-v2/confirm-or-decline-booking)
    for details about when a booking is confirmed or declined.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bulk/bookings/confirmOrDecline
    ```

    ## Body Params

    <ParamField body="details" type="BookingDetails[]" required>

      Bookings to confirm or decline.

      Constraints: `minItems 1`, `maxItems 300`.

      <Expandable title="details properties">

        <ParamField body="bookingId" type="string" required>

          ID of the booking to confirm or decline.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="paymentStatus" type="string">

          Current payment status of the booking when using a custom checkout page and
          not the [eCommerce checkout](https://dev.wix.com/docs/rest/business-solutions/e-commerce/checkout/introduction).

          The booking is declined if there is a double booking conflict and you provide
          one of these payment statuses: `UNDEFINED`, `NOT_PAID`, `REFUNDED`, or `EXEMPT`.

          **Supported values:**

          - `UNDEFINED` — Undefined payment status.
          - `NOT_PAID` — The booking isn't paid.
          - `PAID` — The booking is fully paid.
          - `PARTIALLY_PAID` — The booking is partially paid.
          - `REFUNDED` — The booking is refunded.
          - `EXEMPT` — The booking is free of charge.
          - `FAILED` — The most recent subscription payment for this booking failed. If the payment is later recovered, the status changes back to `PAID`. Returned only for course bookings with subscription pricing.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the confirmed or declined booking objects.

    </ParamField>
