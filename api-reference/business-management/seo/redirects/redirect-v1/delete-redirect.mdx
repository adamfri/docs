<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Deletes a redirect by ID.

    The response is empty. Deleting a redirect can't be undone, so retrieve it first if you might
    need to recreate it.

    A redirect scoped to a language stops taking effect but can still appear in [List Redirects](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/list-redirects).

    To delete multiple redirects in a single API call, call [Bulk Delete Redirects](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/bulk-delete-redirects).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/seo-redirects-service/v1/redirects/{redirectId}
    ```

    ## Path Params

    <ParamField path="redirectId" type="string" required>

      ID of the redirect to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteRedirectResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | — | The `redirectId` is missing or empty. Details are in `fieldViolations`. |
    | `404` | `NOT_FOUND` | `REDIRECT_NOT_FOUND` | Couldn't find the redirect. Nothing is deleted. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
