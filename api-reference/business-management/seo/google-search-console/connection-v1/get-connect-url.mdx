    Retrieves the Google authorization URL for the Wix user to open.

    Surface the returned URL to the person connecting. After they authorize in
    their browser, Wix completes the OAuth exchange server-side. There is no
    code-exchange call to make. Poll Get Connection until the status is
    `VALID`.

    Any Google account can be used and needs no prior Search Console setup.
    Site verification and property access are established afterwards through
    the GSC Site Readiness API.

    Each call starts a new authorization attempt: the returned URL is
    single-use and expires after 2 hours, so request a fresh one for every
    attempt rather than caching or reusing one.

    Any user with SEO permissions can start a connection, not only the site
    owner. The resulting connection is owned by the calling user; Get
    Connection reports whether the current caller is that owner.

    An already-connected site may call this too. Authorizing again with the
    same Google account refreshes the stored credentials, and authorizing with
    a different one replaces the connection.

    Requires the site to be published, have a connected domain, and allow
    search-engine indexing; otherwise fails with `FAILED_PRECONDITION`. These
    are a subset of what the SEO dashboard checks before it offers the flow.
    The dashboard also blocks on unpublished changes, on a site the caller
    lacks permission to publish or to connect a domain for, and on a
    non-indexable homepage.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gsc/v1/connect-url
    ```

    ## Response Object

    <ResponseField name="connectUrl" type="string">

      URL the connecting person opens to authorize Wix to access their Google
      Search Console data. Single-use and short-lived; request a new one for
      each attempt.

      Constraints: `format SECURE_WEB_URL`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `GSC_CALLBACK_URL_NOT_CONFIGURED` | The server-side connect flow is not enabled on this environment. |
    | `403` | `PERMISSION_DENIED` | `GSC_CONSENT_URL_MISSING_IDENTITY` | The caller has no resolvable user identity to own the connection. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_RESOLVED` | The site could not be resolved from the request context. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_PUBLISHED` | The site is not published. |
    | `428` | `FAILED_PRECONDITION` | `DOMAIN_NOT_CONNECTED` | The site has no connected domain. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_INDEXABLE` | The site does not allow search-engine indexing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
