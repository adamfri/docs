    <div className="wix-ref">

    Updates a site's locale settings.

    <Note>

    You can't call this method to update a site's multilingual mode. To enable or disable multilingual mode, call Set Multilingual Mode.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/locale-settings/v2/settings
    ```

    ## Body Params

    <ParamField body="localeSettings" type="LocaleSettings" required>

      Locale settings to update.

      See the [Locale Settings Object](/api-reference/business-management/multilingual/locale-management/locale-settings/locale-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="localeSettings" type="LocaleSettings">

      Updated locale settings.

      See the [Locale Settings Object](/api-reference/business-management/multilingual/locale-management/locale-settings/locale-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Locale Settings Updated | `wix.multilingual.settings.v2.locale_settings_updated` | Triggered when locale settings are updated. |

    </div>
