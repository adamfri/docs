  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Validates any provided link. Call this method when you want to check whether the link complies with the abuse rules and can be used in a campaign.

    If you provide a link as a placeholder, it's returned in a response as valid.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaign-validation/validate-link
    ```

    ## Body Params

    <ParamField body="url" type="string" required>

      URL to validate.

      Constraints: `minLength 1`.

    </ParamField>

    ## Response Object

    <ResponseField name="valid" type="boolean">

      Whether the link is valid.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Check whether a URL is on the email marketing blocklist.

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/email-marketing/v1/campaign-validation/validate-link' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>' \
      -d '{
            "url": "https://www.wix.com"
          }'
      ```

      ```json Response
      {
        "valid": true
      }
      ```

    </CodeGroup>

    </div>
