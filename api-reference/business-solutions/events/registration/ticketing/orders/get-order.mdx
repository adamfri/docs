    Retrieves an order, including ticket data.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-BASIC-ORDERS">Read Basic Events Order Info</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/events/{eventId}/orders/{orderNumber}
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID to which the order belongs.

    </ParamField>

    <ParamField path="orderNumber" type="string" required>

      Unique order number.

    </ParamField>

    ## Query Params

    <ParamField query="fieldset" type="string[]">

      Which fields to return.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `TICKETS` — Returns `tickets`.
      - `DETAILS` — Returns `archived`, `confirmed`, `created`, `firstName`, `fullName`,
      `lastName`, `method`, `reservationId`, `snapshotId`,
      `status`, `ticketsPdf`, `ticketsQuantity`, `totalPrice`.
      - `FORM` — Returns `checkoutForm`.
      - `INVOICE` — Returns `invoice`.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Requested order.

      See the [Order Object](/api-reference/business-solutions/events/registration/ticketing/orders/order-object) for this object's fields.

    </ResponseField>

    <ResponseField name="calendarLinks" type="CalendarLinks">

      "Add to calendar" links.

      <Expandable title="calendarLinks properties">

        <ResponseField name="google" type="string">

          "Add to Google calendar" URL.

        </ResponseField>

        <ResponseField name="ics" type="string">

          "Download ICS calendar file" URL.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
