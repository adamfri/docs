    <div className="wix-ref">

    Retrieves the manually arranged items in a category.

    Returns only items that have been explicitly arranged using [Set Arranged Items](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/categories/set-arranged-items). Items added to the category but not manually arranged aren't included.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_READ">Read categories</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/categories/v1/categories/{categoryId}/arranged-items
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      Category ID.

    </ParamField>

    ## Query Params

    <ParamField query="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField query="appNamespace" type="string">

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField query="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="items" type="ItemReference[]">

      List of arranged items.

      Constraints: `maxItems 100`.

      <Expandable title="items properties">

        <ResponseField name="catalogItemId" type="string">

          ID of the item within the catalog.

          For Wix Stores, this is the product ID from the [Catalog V3 Products API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/introduction).

          Constraints: `minLength 1`, `maxLength 36`.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of the Wix app providing the catalog.

          Currently, only Wix Stores is supported. Use `"215238eb-22a5-4c36-9e7b-e7c08025e04e"` for all Wix Stores products.

          Constraints: `minLength 1`, `maxLength 36`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
