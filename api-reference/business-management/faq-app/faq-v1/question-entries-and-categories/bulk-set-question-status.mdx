## Endpoint

```http
POST https://www.wixapis.com/faq/v1/question-entries/update-status
```

## Body Params

<ParamField body="questionIds" type="string[]">

  List of question entry IDs to change status for.

  Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

</ParamField>

<ParamField body="status" type="string">

  Updated status of question entries.

  **Supported values:**

  - `VISIBLE`
  - `HIDDEN`

</ParamField>

## Response Object

<ResponseField name="failures" type="string[]">

  List of failed question entry IDs that should be retried.

</ResponseField>
