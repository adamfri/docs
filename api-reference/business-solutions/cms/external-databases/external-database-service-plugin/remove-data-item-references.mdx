    Removes one or more item references from a referring field of the specified item.

    ## Endpoint

    ```http
    POST /v3/items/remove-references
    ```

    ## Body Params

    <ParamField body="collectionId" type="string" required>

      ID of the referring collection.

    </ParamField>

    <ParamField body="referringFieldKey" type="string" required>

      Field ID of the field in the referring collection to remove references from.

    </ParamField>

    <ParamField body="references" type="ReferenceId[]" required>

      References to remove.

      Constraints: `minItems 1`.

      <Expandable title="references properties">

        <ParamField body="referringItemId" type="string">

          ID of the item in the referring collection.

        </ParamField>

        <ParamField body="referencedItemId" type="string">

          ID of the item in the referenced collection.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="ReferenceModificationResult[]">

      Response must include either the removed reference or an error.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
