    <div className="wix-ref">

    Moves a task specified by ID to be placed after another task in the task display.

    You can reposition a task to be first in the display by omitting `beforeTaskId`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-TASKS">Manage Tasks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/tasks/v2/tasks/{taskId}/move-after
    ```

    ## Path Params

    <ParamField path="taskId" type="string" required>

      ID of the task to move.

    </ParamField>

    ## Body Params

    <ParamField body="beforeTaskId" type="string">

      The ID of the task after which the moved task is positioned in the task display.
      If `beforeTaskId` is not specified, the moved task is positioned first in the task display.

    </ParamField>

    ## Response Object

    Returns `MoveTaskAfterResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `TASK_NOT_FOUND` | Couldn't find the task. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
