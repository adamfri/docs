    <div className="wix-ref">

    Returns a list of recommendation algorithms that can be used on a Wix site or project. These algorithms can be used with [Get Recommendation](https://dev.wix.com/docs/rest/api-reference/wix-e-commerce/recommendations/get-recommendation) to provide item recommendations to site visitors.

    Apps built by Wix may provide algorithms to support their own catalogs or catalogs from other apps installed on the same site.

    For an algorithm to be considered available and returned in this method's response, the following conditions must be met:
    1. The app that provides the algorithm must be installed on the site. This is the app whose ID matches the algorithm's `appId`.
    2. At least one app whose catalog is supported by the algorithm must be installed on the site. These are the apps whose IDs are in the algorithm's `catalogAppIds` array.

    App IDs for apps built by Wix are [listed here](https://dev.wix.com/docs/api-reference/articles/get-started/apps-created-by-wix).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.READ-ECOM">Read eCommerce - all read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/recommendations/algorithms
    ```

    ## Response Object

    <ResponseField name="availableAlgorithms" type="AlgorithmInfo[]">

      List of algorithms available for use on a site.

      Constraints: `maxItems 500`.

      <Expandable title="availableAlgorithms properties">

        <ResponseField name="config" type="AlgorithmConfig">

          Algorithm configuration.

          <Expandable title="config properties">

            <ResponseField name="name" type="string">

              Algorithm name. This value is not translatable.

              Constraints: `minLength 1`, `maxLength 50`.

            </ResponseField>

            <ResponseField name="description" type="string">

              Algorithm description. This describes how the algorithm works and if it has any limitations regarding site content, number of items in the catalog, site traffic, and so on. This value is not translatable.

              Constraints: `minLength 1`, `maxLength 500`.

            </ResponseField>

            <ResponseField name="additionalInfo" type="string">

              A supplemental `description`. It can be used to help break up and organize information. You can, for example, display this information as a tooltip or as an additional section that is collapsed by default.

            </ResponseField>

            <ResponseField name="algorithmType" type="string">

              Algorithms may have the following types:
              * `RELATED_ITEMS` - This type of algorithm provides recommendations based on 1 or more other provided items. For example, when an item is added to a cart, the algorithm can suggest other items frequently bought together with that item.
              * `GLOBAL` - This type of algorithm provides general recommendations based on site or project statistics. For example, bestsellers or new arrivals.

              **Supported values:**

              - `UNSPECIFIED`
              - `RELATED_ITEMS`
              - `GLOBAL`

            </ResponseField>

            <ResponseField name="algorithmId" type="string">

              Algorithm ID. This must be unique for a specific app but does not have to be unique across all apps on the site or in the project.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of the app that provides the algorithm. This can be an app built by Wix or a 3rd-party app.

          See app IDs for [apps built by Wix](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/platform/about-apps-created-by-wix).

          Constraints: `minLength 1`, `maxLength 36`.

        </ResponseField>

        <ResponseField name="catalogAppIds" type="string[]">

          IDs of apps with catalogs that this algorithm supports. This can be an app built by Wix or a 3rd-party app.

          See app IDs for [apps built by Wix](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/platform/about-apps-created-by-wix).

          Constraints: `minLength 1`, `maxLength 36`, `minItems 1`, `maxItems 100`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
