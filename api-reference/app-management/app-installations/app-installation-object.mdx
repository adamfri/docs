---
title: "App Installation Object"
description: "An app installation represents a single installation of one of your apps on a Wix site."
icon: "cube"
---

An app installation represents a single installation of one of your apps on a Wix site. It includes details about the site, the app instance, the installed app version, the purchased plan, the installation status, and any review the site owner left for the app.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      App installation ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="instanceId" type="string">

      Unique identifier of the app instance on the site. Stable across uninstalls and reinstalls of the same app on the same site.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the app installation was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the app installation was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the app installation is updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="firstInstallationDate" type="datetime">

      Date and time the app was first installed on the site. Preserved across uninstalls and reinstalls.

    </ResponseField>

    <ResponseField name="siteInfo" type="SiteInfo">

      Information about the site the app is installed on.

      <Expandable title="siteInfo properties">

        <ResponseField name="siteId" type="string">

          Site ID.

        </ResponseField>

        <ResponseField name="businessName" type="string">

          Business name displayed on the site.

        </ResponseField>

        <ResponseField name="siteUrl" type="string">

          Public URL of the site.

        </ResponseField>

        <ResponseField name="businessEmail" type="string">

          Business email address configured on the site.

        </ResponseField>

        <ResponseField name="countryCode" type="string">

          2-letter country code in [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format.

        </ResponseField>

        <ResponseField name="businessCategory" type="Categories">

          Business category the site belongs to.

          <Expandable title="businessCategory properties">

            <ResponseField name="primary" type="string">

              Primary site category.

              Constraints: `maxLength 100`.

            </ResponseField>

            <ResponseField name="secondary" type="string[]">

              Secondary site category.

              Constraints: `maxLength 100`, `maxItems 50`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="premium" type="boolean">

          Whether the site has an active Premium subscription.

        </ResponseField>

        <ResponseField name="editorType" type="string">

          Editor the site was created with.

          **Supported values:**

          - `EDITOR` — Wix Editor.
          - `ADI` — Wix ADI.
          - `EDITORX` — Editor X.
          - `STUDIO` — Wix Studio.
          - `HARMONY` — Wix Harmony.
          - `VIBE` — Wix Vibe.
          - `WIXEL` — Wixel.

        </ResponseField>

        <ResponseField name="ownerEmail" type="string">

          Email address of the site owner. Returned only when `OWNER_EMAIL` is requested in the `fields` parameter and the app has the **Get Site Owner** permission.

        </ResponseField>

        <ResponseField name="accountId" type="string">

          ID of the site owner's account.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="planInfo" type="PlanInfo">

      Information about the plan the site owner purchased for the app.

      <Expandable title="planInfo properties">

        <ResponseField name="planName" type="string">

          Name of the plan the site owner purchased for the app.

        </ResponseField>

        <ResponseField name="billingCycle" type="Cycle">

          Billing cycle of the purchased plan.

          <Expandable title="billingCycle properties">

            <ResponseField name="cycleType" type="string">

              Type of the billing cycle.

              + `"UNKNOWN_UNIT"`:  There is no information about the billing cycle.
              + `"ONE_TIME"`:  The customer pays for unlimited usage of the app with a single payment.
              + `"RECURRING"`: The customer pays for a subscription to the app on a recurring schedule.

              **Supported values:**

              - `ONE_TIME`
              - `RECURRING`

            </ResponseField>

            <ResponseField name="cycleDuration" type="Duration">

              Duration of the billing cycle. Available only for `{"cycleType": "RECURRING"}`.

              <Expandable title="cycleDuration properties">

                <ResponseField name="unit" type="string">

                  Unit of the billing cycle.

                  **Supported values:**

                  - `MONTH` — Month.
                  - `YEAR` — Year.

                </ResponseField>

                <ResponseField name="count" type="integer">

                  Count of units that make up the billing cycle.

                  Constraints: `min 0`.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="planStatus" type="string">

          Current status of the purchased plan.

          **Supported values:**

          - `UPGRADED` — The site owner upgraded the app to a paid plan.
          - `CANCELED` — The site owner upgraded the app to a paid plan and has since canceled it.
          - `AUTO_RENEW_OFF` — The plan is still active, but auto-renewal is turned off.

        </ResponseField>

        <ResponseField name="freeTrialInfo" type="FreeTrialInfo">

          Free trial details for the purchased plan, if a free trial is or was active.

          <Expandable title="freeTrialInfo properties">

            <ResponseField name="status" type="string">

              Current free trial status.

              **Supported values:**

              - `IN_PROGRESS` — The free trial is currently in progress.
              - `ENDED` — The free trial has ended.

            </ResponseField>

            <ResponseField name="endDate" type="datetime">

              Date and time the free trial ended.

              Returned only after the free trial has ended.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="endDate" type="datetime">

          Date and time the plan expires.

          Returned only when auto-renewal is turned off.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="appId" type="string">

      ID of the installed app.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="appVersion" type="string">

      Major version of the installed app.

      Constraints: `maxLength 6`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current installation status of the app on the site.

      **Supported values:**

      - `INSTALLED` — The app is currently installed on the site.
      - `UNINSTALLED` — The app was installed on the site and has since been removed.

    </ResponseField>

    <ResponseField name="review" type="ReviewInfo">

      Information about the review the site owner left for the app, if any.

      <Expandable title="review properties">

        <ResponseField name="id" type="string">

          Review ID.

        </ResponseField>

        <ResponseField name="date" type="datetime">

          Date and time the review was published.

        </ResponseField>

        <ResponseField name="rating" type="integer">

          Rating the site owner left for the app, from 1 to 5.

        </ResponseField>

        <ResponseField name="title" type="string">

          Review title.

        </ResponseField>

        <ResponseField name="description" type="string">

          Review body text.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
