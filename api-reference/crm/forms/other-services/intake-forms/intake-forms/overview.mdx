A wrapper around a Wix form that adds expiration tracking and submission management.
Intake forms collect information from contacts with time-based validity requirements.

## SDK package

```bash
npm install @wix/intake-forms
```

Import the `intakeForms` namespace from `@wix/intake-forms`.
