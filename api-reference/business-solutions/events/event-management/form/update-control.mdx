    <div className="wix-ref">

    Updates an existing input control in the form. The applied changes trigger form publishing.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/events/v1/events/{eventId}/form/controls/{id}
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID to which the form belongs.

    </ParamField>

    <ParamField path="id" type="string" required>

      Unique input control ID.

    </ParamField>

    ## Body Params

    <ParamField body="orderIndex" type="integer">

      Index used to sort input controls in ascending order.

    </ParamField>

    ## Response Object

    <ResponseField name="form" type="Form">

      Modified event form.

      See the [Form Object](/api-reference/business-solutions/events/event-management/form/form-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_EVENT_CONFIGURATION` | The control configuration is invalid for this event. |
    | `404` | `NOT_FOUND` | `CONTROL_NOT_FOUND` | Couldn't find the control. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
