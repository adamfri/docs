An account is a social channel connection that a site owner has set up, such as an Instagram business account or a Facebook page. Items are published to an account. Accounts are connected through the site's dashboard.

<Tabs>

  <Tab title="REST">

    <ResponseField name="channelName" type="string">

      Social channel the account belongs to.

      **Supported values:**

      - `INSTAGRAM`
      - `FACEBOOK`
      - `YOUTUBE`
      - `LINKEDIN`
      - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
      - `PINTEREST`
      - `GBP` — Google Business Profile.
      - `TIKTOK`

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "account": {
          "channelName": "YOUTUBE",
          "youtube": {
            "id": "UCa8fkLm3QxR7vTq2NpZ9wEd",
            "displayName": "Jane's Pottery Studio",
            "pictureUrl": "https://yt3.ggpht.com/ytc/AIdro_kQz8xTm5vNpR3wYf2LbGd9sHj4uXeC7oMnAs1vTqWxYz=s88-c-k-c0x00ffffff-no-rj"
          }
        }
      }
      ```

    </CodeGroup>
