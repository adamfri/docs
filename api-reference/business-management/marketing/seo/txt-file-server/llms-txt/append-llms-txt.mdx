<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Appends additional content to the existing `llms.txt` file.

    The provided content will be added to the end of the current file content.

    To reset to Wix's default content instead, set `default` to `true` and omit the `content` field.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/promote-seo-robots-server/v2/llms
    ```

    ## Body Params

    <ParamField body="llmsTxt" type="LlmsTxt">

      `llms.txt` file to append.

      See the [Llms Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/llms-txt/llms-txt-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="llmsTxt" type="LlmsTxt">

      Appended `llms.txt` file.

      See the [Llms Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/llms-txt/llms-txt-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | — | Site ID is missing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X PATCH https://www.wixapis.com/promote-seo-txt-file-server/v2/llms \
          -H 'Content-Type: application/json;charset=UTF-8' \
          -H 'Authorization: <AUTH>' \
          -d '{
              "llmsTxt": {
                  "content": "\n## Citation\nPlease attribute content to the site owner when quoting portfolio work.",
                  "subdomain": "www"
              }
          }'
      ```

      ```json Response
      {
          "llmsTxt": {
              "content": "# My Portfolio\n\n> A designer showcasing client work.\n\n## Citation\nPlease attribute content to the site owner when quoting portfolio work.",
              "default": false,
              "subdomain": "www"
          }
      }
      ```
