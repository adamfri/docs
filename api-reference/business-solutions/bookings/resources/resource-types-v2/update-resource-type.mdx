  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a resource type.

    Each time the resource type is updated, `revision` increments by 1.
    You must include current revision of the resource type when updating it.
    This ensures you're working with the latest service information and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bookings/v2/resources/resource-types/{resourceType.id}
    ```

    ## Path Params

    <ParamField path="resourceType.id" type="string" required>

      Resource type ID.

    </ParamField>

    ## Body Params

    <ParamField body="resourceType" type="ResourceType" required>

      Resource type to update.

      See the [Resource Type Object](/api-reference/business-solutions/bookings/resources/resource-types-v2/resource-type-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="resourceType" type="ResourceType">

      Updated resource type.

      See the [Resource Type Object](/api-reference/business-solutions/bookings/resources/resource-types-v2/resource-type-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `RESOURCE_TYPE_ALREADY_EXISTS_FOR_NAME` | There is already a resource type with this name. Choose a different name. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Examples

    To update a resource type the fields `id` and `revision` are required. Partial updates are supported.

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
      'https://www.wixapis.com/bookings/v2/resources/resource-types/28221941-9d0d-4c91-806b-e2a08073d37a' \
      -H 'Authorization: <AUTH>' \
      -d '{
        "resourceType": {
          "id": "28221941-9d0d-4c91-806b-e2a08073d37a",
          "revision": "1",
          "name": "Meeting room with conference system"
        }
      }'
      ```

      ```json Response
      {
        "resourceType": {
          "id": "28221941-9d0d-4c91-806b-e2a08073d37a",
          "revision": "2",
          "createdDate": "2024-11-14T13:32:36.462Z",
          "updatedDate": "2024-11-14T13:39:20.409Z",
          "name": "Meeting room with conference system"
        }
      }
      ```

    </CodeGroup>

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource type was created.

          **Read-only.**

          **Read-only.**
