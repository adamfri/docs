Retrieves the same aggregated context as `GetDynamicContext`, rendered as a
markdown report. The markdown is byte-identical to the output of the
`@wix/dynamic-context-enricher` package used by the Wix MCP.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="code:context:v1:get_dynamic_context_markdown">code:context:v1:get_dynamic_context_markdown</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

## Endpoint

```http
POST https://www.wixapis.com/_api/dynamic-context/v1/dynamic-context/markdown
```

  ```bash Request
  curl -X POST \
    'https://www.wixapis.com/_api/dynamic-context/v1/dynamic-context/markdown' \
    -H 'Authorization: <AUTH>' \
    -H 'Content-Type: application/json' \
    -d '{"includeAccountContext": true}'
  ```
