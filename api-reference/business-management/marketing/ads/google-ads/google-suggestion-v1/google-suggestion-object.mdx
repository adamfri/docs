A polymorphic container returned by suggestion endpoints. Exactly one field is populated depending on the request type.

<Tabs>

  <Tab title="REST">

    _No public fields._

    ## Example

    <CodeGroup>

      ```json Object
      {
        "googleSuggestion": {
          "keywordThemes": {
            "keywordThemes": [
              { "id": "theme-001", "displayName": "bakery" },
              { "id": "theme-002", "displayName": "fresh bread" },
              { "id": "theme-003", "displayName": "pastries near me" }
            ]
          }
        }
      }
      ```

    </CodeGroup>

  </Tab>

  <Tab title="SDK">

    _No public fields._
