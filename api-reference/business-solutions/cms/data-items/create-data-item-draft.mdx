    Creates a draft copy of a published data item in the corresponding `{dataCollectionId}__drafts` shadow collection.

    The published item remains live and unchanged. To retract a published item and convert it to a draft in one step, use [Unpublish Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/unpublish-data-item) instead.

    Returns `ALREADY_EXISTS` if a draft already exists for this item. To check first, query the `{dataCollectionId}__drafts` collection before calling this method.

    After creating the draft, edit it via [Update Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/update-data-item) or [Patch Data Item](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/patch-data-item) against the `{dataCollectionId}__drafts` collection. To put the edits live, call [Publish Data Item Draft](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/publish-data-item-draft).

    <Note>

    - The response carries the newly-created draft, not the published item.
    - Returns `NOT_FOUND` if no published item exists with the supplied `dataItemId`.
    - Calling this method triggers a [Data Item Created](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/data-item-created) event on the drafts shadow collection.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/items/create-draft
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the published data collection.

      Pass the main collection ID (for example, `tutorials`), not the drafts shadow collection ID (`tutorials__drafts`).

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="dataItemId" type="string" required>

      ID of the published data item to copy into the drafts shadow collection.

      Returns `NOT_FOUND` if no published item exists with this ID.

      Constraints: `maxLength 128`.

    </ParamField>

    ## Response Object

    <ResponseField name="dataItem" type="DataItem">

      The newly-created draft data item, seeded with the current published data.

      The returned item's `dataCollectionId` is the drafts shadow collection ID (for example, `tutorials__drafts`).

      See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

    </ResponseField>

    ## Errors

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
