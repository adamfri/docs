Triggered when a gallery is updated.

<Note>

The event data doesn't include gallery items or their IDs.
To receive information about the updated items you need to listen to the [Gallery Item Updated webhook](https://dev.wix.com/api/rest/site-content/pro-gallery/gallery-item-updated-webhook).

</Note>

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pro_gallery.gallery_v2_updated` |
| Package | `@wix/pro-gallery` |
| Permissions | `Manage Galleries`, `Read Galleries` |

## Examples

<CodeGroup>

  ```javascript onGalleryUpdated
  import { proGallery } from '@wix/pro-gallery';

  proGallery.onGalleryUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onGalleryUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { proGallery } from '@wix/pro-gallery';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        proGallery,
      },
  });

  wixClient.proGallery.onGalleryUpdated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
