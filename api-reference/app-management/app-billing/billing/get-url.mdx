    <div className="wix-ref">

    Retrieves the URL for a Wix checkout page for the specified paid plan of your app.

    Call this method when initiating the purchase flow from your pricing page.
    The returned checkout URL redirects to Wix to complete payment.

    This call succeeds only if you have previously
    [set up an external pricing page in your app's dashboard](https://dev.wix.com/docs/build-apps/build-your-app/pricing-plans/set-up-an-external-pricing-page).

    The returned checkout URL is valid for 48 hours.

    This API allows your app to manage your pricing page outside of Wix while
    still using the standard Wix checkout flow.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/checkout
    ```

    ## Body Params

    <ParamField body="productId" type="string" required>

      ID of your app's paid plan to retrieve the Wix checkout URL for. Check your app's dashboard
      for a list of your app's supported product IDs.

    </ParamField>

    <ParamField body="successUrl" type="string">

      URL for the Wix checkout page. Redirect Wix users to this URL after
      they've successfully purchased a paid plan for your app.

    </ParamField>

    <ParamField body="testCheckout" type="boolean">

      Whether the checkout is for testing purposes only. Testing is mainly
      relevant for in-app purchase flows. When `true`, Wix charges the site
      owners an amount of `0.00`.

      Not supported for usage-based plans.

    </ParamField>

    <ParamField body="billingCycle" type="string">

      Information about the paid plan's billing cycle.

      Set to `MONTHLY` for usage-based plans.

      **Supported values:**

      - `NO_CYCLE`
      - `MONTHLY`
      - `YEARLY`
      - `ONE_TIME`
      - `TWO_YEARS`
      - `THREE_YEARS`
      - `FOUR_YEARS`
      - `FIVE_YEARS`

    </ParamField>

    <ParamField body="countryCode" type="string">

      2-letter country code in
      [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements)
      format.

      Default: `"US"`

    </ParamField>

    <ParamField body="languageCode" type="string">

      2-letter language code in
      [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) format.

      Default: `"EN"`

    </ParamField>

    <ParamField body="couponCode" type="string">

      Coupon code for the paid plan. Available only in case there is a discount.

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutUrl" type="string">

      URL for the Wix checkout page.

      Constraints: `format WEB_URL`.

    </ResponseField>

    <ResponseField name="token" type="string">

      Token for the Wix checkout page. The token holds all data about the order
      you're creating a checkout for. It's [signed](https://dev.wix.com/docs/api-reference/articles),
      so you can verify that it comes from Wix.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
