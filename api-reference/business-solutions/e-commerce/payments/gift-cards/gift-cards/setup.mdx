<Note>This article applies to the JavaScript SDK only.</Note>

To use the GiftVouchers API, install the `@wix/ecom` package using npm or Yarn:
  ```bash
npm install @wix/ecom
```

or

```bash
yarn add @wix/ecom
```

Then import `{ giftVouchers }` from `@wix/ecom`:

```js
import { giftVouchers } from '@wix/ecom'
```
