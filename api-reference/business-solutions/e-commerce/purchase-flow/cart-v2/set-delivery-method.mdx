    Sets the delivery method for the cart.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2">Write Carts V2</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/{cartId}/set-delivery-method
    ```

    ## Path Params

    <ParamField path="cartId" type="string" required>

      Cart ID.

    </ParamField>

    ## Body Params

    <ParamField body="deliveryMethod" type="DeliveryMethodInput" required>

      Delivery method.

      <Expandable title="deliveryMethod properties">

        <ParamField body="code" type="string" required>

          Delivery method code.

          Constraints: `maxLength 100`.

        </ParamField>

        <ParamField body="appId" type="string">

          Carrier app id.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CART_ALREADY_ORDERED` | Cart was already placed as an order. |
    | `400` | `INVALID_ARGUMENT` | `DELIVERY_METHOD_NOT_FOUND` | Couldn't find the delivery method. |
    | `428` | `FAILED_PRECONDITION` | `DELIVERY_METHOD_MISSING_ADDRESS` | The delivery method requires a delivery address that isn't set. |
    | `428` | `FAILED_PRECONDITION` | `DELIVERY_METHOD_MISSING_LINE_ITEMS` | The delivery method doesn't apply to the selected line items. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Cart Updated | `wix.ecom.v2.cart_updated` | Triggered when a cart is updated. |

    </div>
