---
title: "Billable Item Object"
description: "A billable item represents a billable product or service that can be added to invoices."
icon: "cube"
---

A billable item represents a billable product or service that can be added to invoices.
You can create, manage, and organize these items to streamline your billing process.
Billable items include details like name, description, price, and tax information.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Billable item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the billable item is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the billable item.

      Ignored when creating a billable item.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the billable item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the billable item was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Billable item name, for display on invoices.

      Constraints: `minLength 1`, `maxLength 200`.

    </ResponseField>

    <ResponseField name="description" type="string">

      Detailed description of the billable item. Provides additional information about the product or service.

    </ResponseField>

    <ResponseField name="price" type="string">

      Price of the billable item in decimal format with up to 4 decimal places.
      Represents the base cost before taxes are applied. This is a required field when creating a new billable item.

      Constraints: `format DECIMAL_VALUE`, `>= -1000000000000000`, `<= 1000000000000000`.

    </ResponseField>

    <ResponseField name="taxGroupId" type="string">

      Reference to a tax group that defines the tax rules applicable to this billable item.
      Use the Tax Groups API ([SDK](https://dev.wix.com/docs/sdk/backend-modules/billing/tax-groups/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/tax/tax-groups/introduction)) to retrieve available tax groups for the business.
      The tax group determines how taxes are calculated when this item is added to an invoice.
      If not specified, the default tax rules for the business will apply.

    </ResponseField>

    <ResponseField name="image" type="Image">

      Billable item image, stored in the Wix Media Manager.
      Upload an image with the Media Manager API ([SDK](https://dev.wix.com/docs/sdk/backend-modules/media/introduction) | [REST](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction)) or the site dashboard before associating it to a billable item.

      <Expandable title="image properties">

        <ResponseField name="id" type="string">

          WixMedia image ID.

        </ResponseField>

        <ResponseField name="url" type="string">

          Image URL.

        </ResponseField>

        <ResponseField name="height" type="integer">

          Original image height.

          **Read-only.**

        </ResponseField>

        <ResponseField name="width" type="integer">

          Original image width.

          **Read-only.**

        </ResponseField>

        <ResponseField name="altText" type="string">

          Image alt text.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the billable item.
      Extended fields must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
