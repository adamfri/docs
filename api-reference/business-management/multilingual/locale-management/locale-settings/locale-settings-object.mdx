---
title: "Locale Settings Object"
description: "The Locale Settings object represents the multilingual configuration settings for a site."
icon: "cube"
---

The Locale Settings object represents the multilingual configuration settings for a site.

<Tabs>

  <Tab title="REST">

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the locale settings are updated. To prevent conflicting changes, the existing revision must be passed when updating the locale settings.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the locale settings were created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the locale settings were last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="multilingualModeEnabled" type="boolean">

      Whether multilingual mode is enabled for the site. When enabled, you can create secondary locales.

      Default: `false`

      **Read-only.**

    </ResponseField>

    <ResponseField name="autoSwitch" type="boolean">

      Whether the live site automatically opens in a secondary locale if the
      site visitor's browser is set to that locale.

      Default: `false`

      &lt;blockquote class="caution">

      __Caution:__
      Auto-switch can harm SEO by causing duplicate content issues and restricting search engine indexing of different language versions, which limits visibility in search results.

      &lt;/blockquote>

    </ResponseField>

    <ResponseField name="urlStructure" type="string">

      Defines the default method for how secondary languages appear in the live site's URL.
      The URL structure can be overridden per locale, using the Locale API.

      Default: `"SUBDIRECTORY"`

      **Supported values:**

      - `SUBDIRECTORY` — URL structure as a subdirectory. For example, `"www.mysite.com/fr"`.
      - `SUBDOMAIN` — URL structure as a subdomain. For example, `"fr.mysite.com"`.
      - `QUERY_PARAM` — URL structure as a query parameter. For example, `"www.mysite.com?lang=fr"`.

    </ResponseField>

    <ResponseField name="primaryLocale" type="Locale">

      The site's primary locale.

      **Read-only.**

      <Expandable title="primaryLocale properties">

        <ResponseField name="id" type="string">

          Locale ID.

          The locale ID is made up of the language and region codes supported by Wix. For example, `"en-US"` for U.S. English.

          **Read-only.**

        </ResponseField>

        <ResponseField name="revision" type="integer">

          Revision number, which increments by 1 each time the locale is updated. To prevent conflicting changes, the existing revision must be passed when updating the locale object.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the locale was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the locale was last updated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="languageCode" type="string">

          Language code. For example, `"en"` for English.

        </ResponseField>

        <ResponseField name="regionCode" type="string">

          Region code. For example, `"UK"` for United Kingdom.

        </ResponseField>

        <ResponseField name="visibility" type="string">

          Locale visibility status.

          **Supported values:**

          - `HIDDEN` — Locale is hidden from site visitors. A site's locale should be hidden when a translation is not ready to be exposed to visitors.
          - `VISIBLE` — Locale is visible to site visitors. A site can only have up to 100 visible locales.

        </ResponseField>

        <ResponseField name="primaryLocale" type="boolean">

          Whether the locale is the site's primary locale.

          **Read-only.**

        </ResponseField>

        <ResponseField name="visitorPrimaryLocale" type="boolean">

          Whether the locale is the site's visitor primary locale.

          **Read-only.**

        </ResponseField>

        <ResponseField name="flag" type="string">

          Flag icon as a 3-letter language code based on Wix's supported locales. For example, `"USA"` for the United States flag icon.

        </ResponseField>

        <ResponseField name="regionalFormat" type="string">

          Regional format for determining how to display data types such as dates, times, numbers, and currencies. For example, `"en-US"` to format dates like this: `MM-DD-YYYY`.

        </ResponseField>

        <ResponseField name="effectiveUrlStructure" type="string">

          Default URL structure for the locale's live site URL,
          based on the locale's settings, unless overridden.

          **Read-only.**

          **Supported values:**

          - `SUBDIRECTORY` — URL structure as a subdirectory. For example, `"www.mysite.com/fr"`.
          - `SUBDOMAIN` — URL structure as a subdomain. For example, `"fr.mysite.com"`.
          - `QUERY_PARAM` — URL structure as a query parameter. For example, `"www.mysite.com?lang=fr"`.

        </ResponseField>

        <ResponseField name="urlStructureOverride" type="UrlStructureOverride">

          Optional override for the locale's default URL structure.

          <Expandable title="urlStructureOverride properties">

            <ResponseField name="urlStructure" type="string">

              URL structure to use instead of the default.

              **Supported values:**

              - `SUBDIRECTORY` — URL structure as a subdirectory. For example, `"www.mysite.com/fr"`.
              - `SUBDOMAIN` — URL structure as a subdomain. For example, `"fr.mysite.com"`.
              - `QUERY_PARAM` — URL structure as a query parameter. For example, `"www.mysite.com?lang=fr"`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="machineTranslationCode" type="string">

          Language code based on Wix's supported locales, used to specify the target language when
          translatable content is sent for machine translation. For example, `"ES"` for Spanish
          or `"ZH_TW"` for Traditional Chinese.

          Default: The locale's `languageCode` value.

        </ResponseField>

        <ResponseField name="effectiveDisplayName" type="string">

          The locale's `displayName`, unless overridden.

          **Read-only.**

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Default display name for the locale, inferred from the locale ID and region code.

          **Read-only.**

        </ResponseField>

        <ResponseField name="overrideDisplayName" type="string">

          Optional override for the locale's display name.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "revision": "1",
        "createdDate": "2025-01-11T19:05:03.413Z",
        "updatedDate": "2025-01-11T19:05:03.413Z",
        "multilingualModeEnabled": false,
        "autoSwitch": false,
        "urlStructure": "SUBDIRECTORY",
        "primaryLocale": {
          "id": "en",
          "revision": "1",
          "createdDate": "2025-01-11T19:05:03.343Z",
          "updatedDate": "2025-01-11T19:05:03.343Z",
          "languageCode": "en",
          "regionCode": null,
          "visibility": "VISIBLE",
          "primaryLocale": true,
          "visitorPrimaryLocale": true,
          "flag": "USA",
          "regionalFormat": "en-US",
          "effectiveUrlStructure": "SUBDIRECTORY",
          "urlStructureOverride": null,
          "machineTranslationCode": "EN",
          "effectiveDisplayName": "English",
          "displayName": "English",
          "overrideDisplayName": null
        }
      }
      ```

    </CodeGroup>
