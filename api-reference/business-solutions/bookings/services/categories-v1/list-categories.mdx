    Retrieves all categories.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v1/categories
    ```

    ## Query Params

    <ParamField query="categoryIds" type="string[]">

      IDs of the categories to retrieve.

      Default: All categories are retrieved.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="includeDeleted" type="boolean">

      Whether to include deleted categories in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="categories" type="Category[]">

      Retrieved categories.

      See the [Category Object](/api-reference/business-solutions/bookings/services/categories-v1/category-object) for this object's fields.

    </ResponseField>
