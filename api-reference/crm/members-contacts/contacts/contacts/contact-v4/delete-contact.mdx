  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a contact.

    Deleting a contact permanently removes it from the contact list.
    If a contact is also a site member or Wix user, or has a valid billing subscription,
    the contact can't be deleted. The related site member or Wix user must first be deleted
    and any valid billing subscriptions must be canceled, before the contact can be deleted.

    Members are typically linked to contacts, and while they share a relationship, the member ID and contact ID are distinct identifiers.
    Make sure to specify the contact ID when calling Delete Contact.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>
    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/contacts/v4/contacts/{contactId}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteContactResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_MEMBER` | Contact is a site member and can't be deleted. Delete site member first. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_CONTACT_WITH_BILLING_SUBSCRIPTION` | Contact has a valid billing subscription and can't be deleted. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_MEMBER_OWNER_OR_CONTRIBUTOR` | Member is a Wix user and can't be deleted. |
    | `500` | `INTERNAL` | `FAILED_DELETE_CONTACT_AFTER_MEMBER_DELETION` | Member was deleted, but contact was not. This can happen only if the request indicated to delete the member. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Contact Deleted | `wix.contacts.v4.contact_deleted` | Triggered when a contact is deleted. If a contact is deleted as part of a merge, the `originatedFrom` property is sent as `merge`. Otherwise, `originatedFrom` isn't returned. |

    </div>
