Triggered when a payment link is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.paymentlinks.v1.payment_link_updated` |
| Package | `@wix/get-paid` |
| Permissions | `Manage Stores`, `Manage Paylinks` |
