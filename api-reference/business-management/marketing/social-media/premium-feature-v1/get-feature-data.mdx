    </Info>

    Retrieves the availability and usage quota for a premium feature on the site.

    Use this to check whether the site's plan allows an action, such as publishing or scheduling a post, and how much quota remains before calling the relevant method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-publisher/v1/features/{featureType}
    ```

    ## Path Params

    <ParamField path="featureType" type="string" required>

      Premium feature to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="featureData" type="FeatureData">

      Availability and quota for the requested feature.

      <Expandable title="featureData properties">

        <ResponseField name="type" type="string">

          Premium feature.

          **Supported values:**

          - `CONNECT_CHANNEL` — Connecting a social channel.
          - `PUBLISH_POST` — Publishing a post.
          - `SCHEDULE_POST` — Scheduling a post.
          - `WATCH_POST_INSIGHTS` — Viewing post insights.
          - `AI_TOOLS` — Using AI content tools.
          - `PUBLISH_STORY` — Publishing a story.
          - `EXTENDED_SOCIAL_PLAN_PERIOD` — Creating a social plan that spans an extended period.
          - `ADVANCED_ANALYTICS` — Viewing advanced analytics.
          - `ANALYTICS_AI_INSIGHTS` — Viewing AI-generated analytics insights.
          - `PREMIUM_IMAGE_GENERATION` — Generating premium, higher-quality AI images.
          - `GENERATE_CAROUSELS` — Generating multi-image carousels.

        </ResponseField>

        <ResponseField name="enabled" type="boolean">

          Whether the feature is available on the site's plan.

        </ResponseField>

        <ResponseField name="quotaInfo" type="QuotaInfo">

          Usage quota for the feature.

          <Expandable title="quotaInfo properties">

            <ResponseField name="limit" type="integer">

              Maximum number of uses allowed in the period.

            </ResponseField>

            <ResponseField name="currentUsage" type="integer">

              Number of uses consumed in the current period.

            </ResponseField>

            <ResponseField name="remainingUsage" type="integer">

              Number of uses remaining in the current period.

            </ResponseField>

            <ResponseField name="period" type="string">

              Period the quota resets over.

              **Supported values:**

              - `NO_PERIOD` — The quota doesn't reset over a period.
              - `MILLISECOND`
              - `SECOND`
              - `MINUTE`
              - `HOUR`
              - `DAY`
              - `WEEK`
              - `MONTH`
              - `YEAR`

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="monetizationEnabled" type="boolean">

      Whether premium-feature quotas are enforced for the site through its plan. When `true`, each feature's `quotaInfo` reflects the plan's metered limits. When `false`, quotas aren't enforced, and a feature's `enabled` value reflects baseline availability rather than plan limits.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
