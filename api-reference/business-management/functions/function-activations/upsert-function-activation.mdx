    Activates a function or publishes changes to an already active function (reactivates).

    This method also creates or updates a function activation object.

    This method's behavior depends on the function specified:
    - **Functions that aren't already activated**: Calling this method activates the specified function and creates a function activation object.
    - **Functions that are already activated**: Calling this method reactivates the specified function, meaning it publishes any changes made to function, and updates the function activation associated with the function.
    <Note>

    If the function hasn't changed since its last activation, nothing happens to the function. However, the function activation

    </Note>
    object is still updated, meaning its `revision` increases by 1.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/functions/v1/activations/upsert
    ```

    ## Body Params

    <ParamField body="functionActivation" type="FunctionActivation" required>

      Details of the function to activate or reactivate.

      See the [Function Activation Object](/api-reference/business-management/functions/function-activations/function-activation-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="functionActivation" type="FunctionActivation">

      The created or updated function activation.

      See the [Function Activation Object](/api-reference/business-management/functions/function-activations/function-activation-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTIVATION_APP_NOT_FOUND_RETRY` | Couldn't find the activation app. |
    | `428` | `FAILED_PRECONDITION` | `SPI_CONFIG_INVALID` | The SPI configuration is invalid. |
    | `428` | `FAILED_PRECONDITION` | `SPI_CONFIG_MISSING_REQUIRED_FIELD` | The SPI configuration is missing a required field. |
    | `428` | `FAILED_PRECONDITION` | `SPI_CONFIG_TYPE_MISMATCH` | The SPI configuration has a type mismatch. |
    | `428` | `FAILED_PRECONDITION` | `SPI_CONFIG_SCHEMA_MISMATCH` | The SPI configuration doesn't match the expected schema. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_AUTOMATION` | The automation is invalid. |
    | `429` | `RESOURCE_EXHAUSTED` | `FUNCTION_ACTIVATIONS_LIMIT_EXCEEDED` | FunctionActivations limit exceeded. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
