    Updates a referred friend. Supports partial updates.

    You must pass the latest `revision` for a successful update.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/referral_friends/v1/referred-friends/{referredFriend.id}
    ```

    ## Path Params

    <ParamField path="referredFriend.id" type="string" required>

      ID of the referred friend.

    </ParamField>

    <ParamField body="referredFriend" type="ReferredFriend" required>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      ID of the referred friend.

      **Read-only.** Constraints: `format GUID`.

    </ParamField>

    <ParamField body="referredFriend" type="UpdateReferredFriend" required>

      Referred friend to be updated. May be partial.

      <Expandable title="referredFriend properties">

        <ParamField body="_id" type="string">

          ID of the referred friend.

          **Read-only.** Constraints: `format GUID`.

        </ParamField>

        <ParamField body="contactId" type="string" required>

          Contact ID of the referred friend.

          **Read-only.** Constraints: `format GUID`.

        </ParamField>

        <ParamField body="referringCustomerId" type="string" required>

          ID of the customer who referred this friend.

          **Read-only.** Constraints: `format GUID`.

        </ParamField>

        <ParamField body="status" type="string">

          Status of the referred friend.

          **Supported values:**

          - `SIGN_UP_COMPLETED` — Initial status when the referred friend joins the site as a member.
          - `ACTIONS_COMPLETED` — Status after the referred friend completes a specific action, such as making a purchase.

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the referred friend is updated.
          To prevent conflicting changes, the current revision must be passed when updating the referred friend.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the referred friend was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the referred friend was last updated.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>
