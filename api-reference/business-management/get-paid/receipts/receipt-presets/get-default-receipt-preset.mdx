    Retrieves the default receipt preset.

    The default preset is used during receipt creation when a preset isn't specified or doesn't exist.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/receipts/v1/receipt-presets/default
    ```

    ## Response Object

    <ResponseField name="receiptPreset" type="ReceiptPreset">

      Default receipt preset.

      See the [Receipt Preset Object](/api-reference/business-management/get-paid/receipts/receipt-presets/receipt-preset-object) for this object's fields.

    </ResponseField>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
