    Retrieves the list of plan goal options a site can choose from when configuring marketing settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-settings/plan-goal-options
    ```

    ## Response Object

    <ResponseField name="options" type="PlanGoalOption[]">

      Selectable plan goal options, ordered for display.

      Constraints: `minItems 0`, `maxItems 10`.

      <Expandable title="options properties">

        <ResponseField name="planGoalKey" type="string">

          The enum value identifying this goal.

          **Supported values:**

          - `DRIVE_TRAFFIC` — Increase visits to the site.
          - `BRAND_AWARENESS` — Grow recognition and reach of the brand.
          - `BOOST_SALES` — Promote products or services to increase purchases.
          - `COLLECT_LEADS` — Capture contact information from potential customers.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Localized display name for this goal.

        </ResponseField>

      </Expandable>

    </ResponseField>
