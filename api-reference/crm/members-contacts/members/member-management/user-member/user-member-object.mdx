A site member who is also a Wix user.

<Tabs>

  <Tab title="REST">

    <ResponseField name="memberId" type="string">

      Profile ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="userId" type="string">

      User ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Contact ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="siteMembersInstanceId" type="string">

      Instance ID of the installed [Wix Members Area app](https://www.wix.com/app-market/web-solution/members-area) on the Wix site.

      **Read-only.**

    </ResponseField>

    <ResponseField name="metaSiteId" type="string">

      Metasite ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="photo" type="Image">

      User member profile picture.

      <Expandable title="photo properties">

        <ResponseField name="id" type="string">

          Wix Media image ID,
          set when the member selects an image from Wix Media.

        </ResponseField>

        <ResponseField name="url" type="string">

          Image URL.

        </ResponseField>

        <ResponseField name="height" type="integer">

          Original image width.

        </ResponseField>

        <ResponseField name="width" type="integer">

          Original image height.

        </ResponseField>

        <ResponseField name="offsetX" type="integer">

          X-axis offset.

          Default: `0`.

        </ResponseField>

        <ResponseField name="offsetY" type="integer">

          Y-axis offset.

          Default: `0`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="nickname" type="string">

      User member nickname.

      **Read-only.**

    </ResponseField>

    <ResponseField name="privacyStatus" type="string">

      User member profile privacy status.

      **Read-only.**

      **Supported values:**

      - `PRIVATE` — User member is hidden from everyone who visits the site. The member is returned only to Wix users and apps with the appropriate permissions.
      - `PUBLIC` — User member is visible to everyone.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the user member was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the user member was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      User member site access status.

      **Read-only.**

      **Supported values:**

      - `PENDING` — User member is created and is waiting for the approval.
      - `APPROVED` — User member is approved and can log in to the site.
      - `BLOCKED` — User member is approved and can't log in to the site.
      - `OFFLINE` — User member is a [guest author](https://support.wix.com/en/article/wix-blog-adding-managed-writers-to-your-blog) for the site blog and can't log in to the site.

    </ResponseField>

    <ResponseField name="activityStatus" type="string">

      User member activity status.

      **Read-only.**

      **Supported values:**

      - `ACTIVE` — User member can participate in site activities, such as writing blog posts and forum comments.
      - `MUTED` — User member can't participate in site activities, such as writing blog posts and forum comments.

    </ResponseField>
