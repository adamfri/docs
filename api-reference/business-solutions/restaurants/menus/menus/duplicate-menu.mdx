    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/menus/{id}/duplicate
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Menu id to be duplicated.

    </ParamField>

    ## Body Params

    <ParamField body="businessLocationIds" type="string[]">

      Business location ids to duplicate the menu to.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField body="duplicateSubEntities" type="boolean">

      Indicates whether sub-entities (such as items) should be duplicated as well.

    </ParamField>

    <ParamField body="menuName" type="string">

      The new name of the duplicated menu.

    </ParamField>

    ## Response Object
