    <div className="wix-ref">

    Retrieves a list of statistics for up to 100 selected campaigns.

    For each campaign, returns the total activity count for the campaign's landing page and email. For example, the total
    number of times the landing page was opened, or the total number of email recipients that clicked a link in an email.

    Call [List Campaigns](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/email-marketing/campaign/list-campaigns) to retrieve additional information for a site's campaigns.
    Call [List Recipients](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/email-marketing/campaign/list-recipients) to retrieve a list of recipients and their activities for a specific campaign.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.READ-EMAIL-MARKETING">Read Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/email-marketing/v1/campaigns/statistics
    ```

    ## Query Params

    <ParamField query="campaignIds" type="string[]" required>

      IDs of the campaigns to retrieve (max 100 campaigns).

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="statistics" type="CampaignStatisticsContainer[]">

      List of statistics.

      <Expandable title="statistics properties">

        <ResponseField name="campaignId" type="string">

          Campaign ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="landingPage" type="LandingPageStatistics">

          Landing page statistics.

          <Expandable title="landingPage properties">

            <ResponseField name="opened" type="integer">

              Number of times the landing page was loaded or viewed.

            </ResponseField>

            <ResponseField name="clicked" type="integer">

              Number of times a link was clicked in a landing page.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="email" type="DistributionStatistics">

          Email campaign statistics.

          <Expandable title="email properties">

            <ResponseField name="delivered" type="integer">

              Number of delivered emails.

            </ResponseField>

            <ResponseField name="opened" type="integer">

              Number of recipients who opened an email.

              If the same recipient opened the same email twice, it is counted as a one unique open.

            </ResponseField>

            <ResponseField name="clicked" type="integer">

              Number of recipients who clicked a link in the email.

              If the same recipient clicked the same link twice, it is counted as a one unique click.

              If the same recipient clicked different links, it is counted as a one unique click.

            </ResponseField>

            <ResponseField name="bounced" type="integer">

              Number of emails that didn't reach the recipient.

            </ResponseField>

            <ResponseField name="complained" type="integer">

              Number of recipients who reported the email as spam.

            </ResponseField>

            <ResponseField name="notSent" type="integer">

              Number of audience members who didn't receive the email because the campaign was terminated during sampling before reaching the full audience.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
