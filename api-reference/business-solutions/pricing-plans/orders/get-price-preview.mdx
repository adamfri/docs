    Retrieves a plan's pricing.

    The price preview uses the same logic as purchasing a plan, but the preview is not saved. Tax is only applied if
    the site [has it configured](https://support.wix.com/en/article/pricing-plans-setting-up-tax-collection). The price is returned
    in the pricing model format used for orders. Learn more about [pricing models](https://dev.wix.com/api/rest/wix-pricing-plans/pricing-plans/introduction#wix-pricing-plans_pricing-plans_introduction_pricing-models).

    Buyers do not have to be logged in to preview the price, and as such, the details returned are not buyer-specific. To
    generate a preview of a purchase for a specific buyer, call Get Offline Order Preview.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/pricing-plans/v2/checkout/orders/price-preview
    ```

    ## Body Params

    <ParamField body="planId" type="string" required>

      ID of plan to preview.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="couponCode" type="string">

      Coupon code to apply, from the Coupons API.

    </ParamField>

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_IS_DISABLED` | Coupon is disabled and can't be applied. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_USAGE_EXCEEDED` | Coupon usage limit exceeded. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_LIMIT_PER_CUSTOMER_EXCEEDED` | Coupon limit per customer exceeded. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_IS_NOT_ACTIVE_YET` | Coupon isn't active yet. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_HAS_EXPIRED` | Coupon has expired. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_DOES_NOT_EXIST` | Coupon doesn't exist. |
    | `428` | `FAILED_PRECONDITION` | `ERROR_COUPON_NOT_APPLICABLE_FOR_PLAN` | Coupon can't be applied to this plan. |
