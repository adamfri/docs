<Note>This article applies to the REST API only.</Note>

This article covers field support for filtering in
*Query Resource Types*
([SDK](fallback::https://dev.wix.com/docs/sdk/backend-modules/bookings/resource-types/query-resource-types) | [REST](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resource-types-v2/query-resource-types))
and *Count Resource Types*
([SDK](fallback::https://dev.wix.com/docs/sdk/backend-modules/bookings/resource-types/count-resource-types) | [REST](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resource-types-v2/count-resource-types)).

## Filtering

Specify the `filter` object in the following format:

```json
{
  "filter": {
    "fieldName": {
      "$eq": "value"
    }
  }
}
```

The following table shows field support for filters and sorting for the
`resourceType` object:

| Field   | Supported Filters                                                 | Sortable |
|---------|-------------------------------------------------------------------|----------|
| `id`    | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`             | Sortable |
| `name`  | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`, `$isEmpty` | Sortable |

## Sorting

Results in *Query Resource Types*
([SDK](fallback::https://dev.wix.com/docs/sdk/backend-modules/bookings/resource-types/query-resource-types) | [REST](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resource-types-v2/query-resource-types))
are sorted by `id` in ascending order by default.

To sort by a different field, use the `sort` object in the following format:

```json
{
  "sort": [
    {
      "fieldName": "name",
      "order": "DESC"
    }
  ]
}
```
