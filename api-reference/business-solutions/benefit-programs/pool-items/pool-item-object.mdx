---
title: "Pool Item Object"
description: "A pool item represents a specific catalog item that a beneficiary can access as part of a benefit in their pool."
icon: "cube"
---

A pool item represents a specific catalog item that a beneficiary can access as part of a benefit in their pool. Pool items are created automatically when items become available to a beneficiary, and they're removed when the items are revoked.

Each pool item links a beneficiary's pool to a single catalog item, surfacing pricing, display details, and references to the underlying pool, program, pool definition, and program definition.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Pool item ID. Generated deterministically from `poolId` and `itemId`.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the pool item is updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the pool item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the pool item was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="externalId" type="string">

      External item ID assigned by the provider of the items.

      For example, if the items are products, this ID corresponds to the specific product ID in the provider's system.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="category" type="string">

      Item category. Groups benefit items together for organization and management. For example, `classes`, `posts`, or `groups`.

      **Read-only.** Constraints: `maxLength 20`, `immutable`.

    </ResponseField>

    <ResponseField name="providerAppId" type="string">

      ID of the application that provides the benefit items. Each item's `externalId` is unique within its provider application.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Namespace for your app or site's benefit programs. Namespaces let you distinguish between entities that you created and entities that other apps created.

      **Read-only.** Constraints: `minLength 1`, `maxLength 20`, `immutable`.

    </ResponseField>

    <ResponseField name="poolId" type="string">

      ID of the pool that contains this item. A pool is the runtime container of benefits and items provisioned for a beneficiary.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="programId" type="string">

      ID of the program that contains this pool item. The program is the runtime instance of a program definition for a specific beneficiary.

      **Read-only.**

    </ResponseField>

    <ResponseField name="externalProgramId" type="string">

      External program ID assigned by the provider.

      **Read-only.**

    </ResponseField>

    <ResponseField name="programDefinitionId" type="string">

      ID of the program definition that's the template for this pool item's program.

      **Read-only.**

    </ResponseField>

    <ResponseField name="externalProgramDefinitionId" type="string">

      External program definition ID assigned by the provider.

      **Read-only.**

    </ResponseField>

    <ResponseField name="poolDefinitionId" type="string">

      ID of the pool definition that's the template for this pool item's pool.

      **Read-only.**

    </ResponseField>

    <ResponseField name="itemSetId" type="string">

      Internal grouping identifier for this benefit's item set. Use `poolId` together with `benefitKey` to identify a benefit - `itemSetId` is an implementation detail.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="beneficiary" type="IdentificationData">

      Beneficiary of the pool - the member, contact, or visitor who holds this pool item.

      **Read-only.** Constraints: `immutable`.

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pool" type="PoolInfo">

      Pool details, including display name and description.

      Returned only when `POOL` is included in the `fields` request parameter.

      **Read-only.**

      <Expandable title="pool properties">

        <ResponseField name="displayName" type="string">

          Pool's display name. Often matches the name on the associated pool definition.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Pool description.

        </ResponseField>

        <ResponseField name="status" type="string">

          Status of the pool that contains this item.

          **Read-only.**

          **Supported values:**

          - `ACTIVE` — Pool is active.
          - `PAUSED` — Pool is paused. It can be resumed.
          - `ENDED` — Pool is ended. It can't be resumed.
          - `PROVISIONING` — Pool provisioning is in progress. This status exists for a short time during processing.
          - `RENEWING` — Pool renewing is in progress. This status exists for a short time during processing.
          - `PENDING` — Pool is pending

        </ResponseField>

        <ResponseField name="creditConfiguration" type="CreditConfiguration">

          Credit configuration of the pool, when credit-based pricing is enabled.

          **Read-only.**

          <Expandable title="creditConfiguration properties">

            <ResponseField name="amount" type="string">

              Number of credits configured for the pool.

              Constraints: `>= 0`.

            </ResponseField>

            <ResponseField name="unitDisplayName" type="string">

              Credit unit display name.

            </ResponseField>

            <ResponseField name="unitType" type="string">

              Credit unit type.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="program" type="ProgramInfo">

      Program details - `id`, `externalId`, and `displayName`.

      Returned only when `PROGRAM` is included in the `fields` request parameter.

      **Read-only.**

      <Expandable title="program properties">

        <ResponseField name="id" type="string">

          Program ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="externalId" type="string">

          External program ID assigned by the provider.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Program's display name.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="programDefinition" type="ProgramDefinitionInfo">

      Program definition that includes this item as an accessible benefit.

      Returned only when `PROGRAM_DEFINITION` is included in the `fields` request parameter.

      **Read-only.**

      <Expandable title="programDefinition properties">

        <ResponseField name="id" type="string">

          Program definition ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="externalId" type="string">

          External program definition ID assigned by the provider.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Program definition's display name.

        </ResponseField>

        <ResponseField name="description" type="string">

          Program definition description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="itemId" type="string">

      Item ID.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="itemInfo" type="ItemInfo">

      Display name for the catalog item.

      Returned only when `ITEM` is included in the `fields` request parameter.

      **Read-only.**

      <Expandable title="itemInfo properties">

        <ResponseField name="displayName" type="string">

          Item's display name.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="benefitInfo" type="BenefitInfo">

      Pricing and display information for the associated benefit, including credit price, name, and description.

      Returned only when `BENEFIT` is included in the `fields` request parameter.

      **Read-only.**

      <Expandable title="benefitInfo properties">

        <ResponseField name="price" type="string">

          Cost of the benefit in credits. The cost is the same for all items in this benefit.

          Credits are a configurable unit defined on the parent pool definition. The unit type is set in the pool definition's credit configuration. Absent when no credit-based pricing is configured for this benefit.

        </ResponseField>

        <ResponseField name="benefitKey" type="string">

          Unique identifier for this benefit. Same value as `poolItem.benefitKey`.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Benefit's display name.

        </ResponseField>

        <ResponseField name="description" type="string">

          Benefit description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="balance" type="BalanceInfo">

      Credit balance of the pool that contains this item.

      Returned only when `BALANCE` is included in the `fields` request parameter.

      **Read-only.**

      <Expandable title="balance properties">

        <ResponseField name="available" type="string">

          Number of available credits in the pool.

          Credits are a configurable unit defined on the parent pool definition. Absent when no credit-based pricing is configured for the pool.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="benefitKey" type="string">

      Unique identifier for the benefit that grants access to this item.

      **Read-only.** Constraints: `maxLength 64`, `immutable`.

    </ResponseField>

    <ResponseField name="itemSearchKey" type="string">

      Pre-computed search key for the item reference, built by concatenating `providerAppId`, `category`, and `externalId` separated by `/`. Use this field for efficient single-field filtering instead of composing three separate conditions.

      **Read-only.** Constraints: `maxLength 94`, `immutable`.

    </ResponseField>

    <ResponseField name="removed" type="boolean">

      Indicates whether this pool item has been removed

      **Read-only.**

    </ResponseField>
