    Creates an attribute definition.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="bookings:attributes:v1:attribute_definition:create_attribute_definition">bookings:attributes:v1:attribute_definition:create_attribute_definition</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/attributes/v1/attribute-definitions
    ```

    ## Body Params

    <ParamField body="attributeDefinition" type="AttributeDefinition" required>

      Attribute definition to be created.

      See the [Attribute Definition Object](/api-reference/business-solutions/bookings/resources/attributes/attribute-definition/attribute-definition-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="attributeDefinition" type="AttributeDefinition">

      The created attribute definition.

      See the [Attribute Definition Object](/api-reference/business-solutions/bookings/resources/attributes/attribute-definition/attribute-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NUMBER_CONFIG_MAX_LESS_THAN_MIN` | The number configuration is invalid: `max` is less than `min`. |
    | `400` | `INVALID_ARGUMENT` | `DEFAULT_VALUE_TYPE_MISMATCH` | The default value's variant does not match the attribute's `valueType`. |
    | `400` | `INVALID_ARGUMENT` | `DEFAULT_VALUE_NOT_IN_ALLOWED_VALUES` | The default value is not one of the configured `allowedValues`. |
    | `400` | `INVALID_ARGUMENT` | `DEFAULT_VALUE_OUT_OF_RANGE` | The default value is outside the configured number range. |
    | `409` | `ALREADY_EXISTS` | `DUPLICATE_ATTRIBUTE_NAME` | Another attribute definition on the site already uses this name. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
