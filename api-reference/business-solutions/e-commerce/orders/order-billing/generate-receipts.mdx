    <div className="wix-api-columns">

    <div className="wix-ref">

    Generates digital receipts for an order's completed payments.

    Creates formal receipt documents for successful payments that can be provided to customers
    for record-keeping and tax purposes.

    <Note>

    Only `PAID` status payments with valid payment types can have receipts generated.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-billing/generate-receipts
    ```

    ## Body Params

    <ParamField body="orderId" type="string" required>

      ID of the order containing the payments to generate receipts for.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="paymentIds" type="string[]" required>

      IDs of the payments to generate receipts for.

      Only successful payments with valid payment types can have receipts generated.

      Constraints: `format GUID`, `minItems 1`, `maxItems 1`.

    </ParamField>

    ## Response Object

    <ResponseField name="receipts" type="ReceiptInfo[]">

      Information about the generated receipts including receipt IDs for each payment.

      <Expandable title="receipts properties">

        <ResponseField name="paymentId" type="string">

          ID of the payment that the receipt was generated for.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="receiptId" type="string">

          Generated receipt ID that can be used to retrieve the receipt details.

          Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_NOT_FOUND` | Couldn't find the order. |
    | `409` | `ALREADY_EXISTS` | `RECEIPT_ALREADY_EXIST` | Receipt already exists. |
    | `409` | `ALREADY_EXISTS` | `RECEIPT_GENERATION_IN_PROGRESS` | Receipt generation is already in progress. |
    | `404` | `NOT_FOUND` | `PAYMENT_NOT_FOUND` | Couldn't find the payment. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_PAYMENT_TYPE` | Payment has an invalid type for receipt generation. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_PAYMENT_STATUS` | Payment has an invalid status for receipt generation. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
