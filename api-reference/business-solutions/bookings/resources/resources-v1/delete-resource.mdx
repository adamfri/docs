<Warning>

  **Deprecated.** This method is deprecated.

</Warning>

<Info>

  **Developer Preview.** This method is in Developer Preview and may change without notice.

</Info>

Deletes a resource.

Deleting a resource updates its `status` to `"DELETED"`.

You cannot delete a resource if it has booked sessions.

<Note>

+ The Bookings app creates a resource with `"business"` in name and tag values. This resource is used for the business's schedule and working hours and cannot be deleted.
+ You can have up to 135 active resources and an additional 135 deleted resources.

</Note>

> **Permissions:**
> This endpoint requires the Manage Bookings [permission scope](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>
