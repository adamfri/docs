    Retrieves a list of email campaigns.

    Sorted by `dateUpdated` in `DESC` order by default.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.READ-EMAIL-MARKETING">Read Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/email-marketing/v1/campaigns
    ```

    ## Query Params

    <ParamField query="paging" type="Paging">

      Paging parameters.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="optionIncludeStatistics" type="boolean">

      Whether to include `publishingData.statistics` in the returned campaign object.

      Default: `false`.

    </ParamField>

    <ParamField query="statuses" type="string[]">

      Campaign statuses to filter by. When not specified, returns campaigns with `ACTIVE` and `ARCHIVED` statuses.

      **Supported values:**

      - `ACTIVE` — Campaign is active.
      - `ARCHIVED` — Campaign is archived.
      - `DELETED` — Campaign is deleted.

    </ParamField>

    <ParamField query="visibilityStatuses" type="string[]">

      Visibility statuses to filter by.

      **Supported values:**

      - `DRAFT` — Campaign isn't published yet.
      - `PUBLISHED` — Campaign is published.
      - `TEMPLATE` — Campaign is a template.

    </ParamField>
