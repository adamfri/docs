The Action Catalog API allows you to manage [actions](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions) for your app. It also allows you to retrieve the catalog of actions available to Wix users on a site. With this API you can:

- [Create](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/create-action), [update](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/update-action), and [delete](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/delete-action) actions from your app.
- [Query actions](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/query-actions) to retrieve available actions.
- [Resolve actions](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/resolve-actions) installed on the current site.
- [Retrieve a specific action](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-runtime-action) by its app ID and action key.
- [Retrieve an action's dynamic input schema](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-action-dynamic-input-schema) and [dynamic output schema](fallback::https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-action-dynamic-output-schema).

## Before you begin

It's important to note the following points before starting to code:

- You can only create, update, and delete actions for [apps you own or collaborate on](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard-setup/manage-collaborators).
- A site's action catalog only contains actions from apps installed on the site.
