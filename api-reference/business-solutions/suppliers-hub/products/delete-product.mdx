    Deletes a product permanently from the Marketplace.

    This action cannot be undone. The product will no longer be available for store owners to add to their stores.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/suppliers-hub/v1/products/{productId}
    ```

    ## Path Params

    <ParamField path="productId" type="string" required>

      Product ID.

    </ParamField>

    ## Response Object

    Returns `DeleteProductResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Product Deleted | `wix.suppliershub.marketplace_product.v1.product_deleted` | Triggered when a product is deleted. |

    </div>
