    Updates the specified automation.

    When an automation is updated, its `revision` property is incremented by 1. When updating an automation, you must specify the current revision number.

    <Note>

    Create and Update don't validate the automation configuration. Call [Validate Automation](https://dev.wix.com/docs/api-reference/business-management/automations/automations/automations-v2/validate-automation) before activating the automation to find configuration errors.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/automations-service/v2/automations/{automation.id}
    ```
