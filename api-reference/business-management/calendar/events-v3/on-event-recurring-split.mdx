Triggered when a `MASTER` event is split.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.calendar.v3.event_recurring_split` |
| Package | `@wix/calendar` |
| Permissions | `Read Calendar - Including PI`, `Manage Calendars`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions`, `Read bookings calendar - including participants` |

## Examples

<CodeGroup>

  ```javascript onEventRecurringSplit
  import { events } from '@wix/calendar';

  events.onEventRecurringSplit((event) => {
      // handle your event here
  });
  ```

  ```javascript onEventRecurringSplit (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { events } from '@wix/calendar';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        events,
      },
  });

  wixClient.events.onEventRecurringSplit((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
