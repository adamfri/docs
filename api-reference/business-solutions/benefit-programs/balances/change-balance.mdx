    Changes the number of available credits in a balance.

    You can adjust or set the number of available credits.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/balances/{poolId}/change
    ```

    ## Path Params

    <ParamField path="poolId" type="string" required>

      ID of the pool associated with the balance to change. This is also the ID of the balance.

    </ParamField>

    <ResponseField name="balance" type="Balance">

      Updated balance.

    </ResponseField>

    <ResponseField name="transactionId" type="string">

      ID of the transaction associated with this change in balance.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `ALREADY_EXECUTED` | Balance was already changed with the specified idempotency key. This is likely a duplicate call. |
    | `409` | `ALREADY_EXISTS` | `BALANCE_ALREADY_INITIALIZED` | Balance was already initialized. This is likely a duplicate call or a call with wrong operation type. |
    | `428` | `FAILED_PRECONDITION` | `BALANCE_EXCEEDED_LIMITS` | Insufficient credits to complete balance change. |
