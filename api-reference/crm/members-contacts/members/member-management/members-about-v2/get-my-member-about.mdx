  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the "About" section content of the current member.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v2/abouts/my
    ```

    ## Response Object

    <ResponseField name="memberAbout" type="MemberAbout">

      The "About" section content of the current member.

      See the [Member About Object](/api-reference/crm/members-contacts/members/member-management/members-about-v2/member-about-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
