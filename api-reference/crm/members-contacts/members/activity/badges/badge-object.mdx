---
title: "Badge Object"
description: "A badge is an object that can be assigned to site members."
icon: "cube"
---

A badge is an object that can be assigned to site members. Badges encourage member participation, helping members stand out. Badges can also grant access to restricted pages reserved for specific members.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Badge ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="title" type="string">

      Text displayed on the badge.

    </ResponseField>

    <ResponseField name="description" type="string">

      Badge description.

    </ResponseField>

    <ResponseField name="backgroundColor" type="string">

      Badge background color in hexadecimal RGB format. &lt;br/>&lt;br/>
      Uppercase letters only.&lt;br/>
      Example: `#FFFFFF`.

    </ResponseField>

    <ResponseField name="textColor" type="string">

      Badge text color in hexadecimal RGB format. &lt;br/>&lt;br/>
      Uppercase letters only.&lt;br/>
      Example: `#C81B53`.

    </ResponseField>

    <ResponseField name="icon" type="string">

      URL of the badge icon image. &lt;br/>&lt;br/>

      It is recommended to use an `SVG` image format as it's resolution independent and looks good at any scale.

    </ResponseField>

    <ResponseField name="permissionsEnabled" type="boolean">

      Whether the badge has special permissions
      to access specific members-only pages. &lt;br/>&lt;br/>
      When `true`, members with the badge receive special permissions,
      and Wix users can
      [manage badge permissions in the dashboard](https://support.wix.com/en/article/site-members-creating-and-managing-member-badges?tabs=Dashboard-2#managing-member-badges).
      When `false`, members with the badge receive no special permissions.

    </ResponseField>

    <ResponseField name="slug" type="string">

      Slugified name. Used to represent the badge in a URL.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date the badge was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date the badge was updated.

      **Read-only.**

    </ResponseField>

  </Tab>
