## Create a category and connect a service

By default, all services are connected to the site's default category.

To add an additional category and connect an existing service to it:

1. Call [Create Category](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/categories-v2/create-category), specifying the `name`.
   Save the returned category ID.
1. Call [Update Service](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/update-service), specifying the new category ID as `service.category.id`.
1. Optional: If you want to change the display order for categories, call [Move Category](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/categories-v2/move-category).
   You can move the category to the beginning, end, or immediately after another category.
