    Updates an external database connection.

    <Note>

    After an external database connection is updated, it only contains the values provided in the request. All previous values are lost.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.EXTERNAL-DATABASE-CONNECTIONS-MANAGE">Manage External Database Connections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/data/v1/external-database-connections/{externalDatabaseConnection.name=**}
    ```

    ## Body Params

    <ParamField body="externalDatabaseConnection" type="ExternalDatabaseConnection" required>

      Updated external database connection. The existing connection is replaced with this version.

      See the [External Database Connection Object](/api-reference/business-solutions/cms/external-databases/external-database-connection/external-database-connection-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="externalDatabaseConnection" type="ExternalDatabaseConnection">

      Details of the updated external database connection.

      See the [External Database Connection Object](/api-reference/business-solutions/cms/external-databases/external-database-connection/external-database-connection-object) for this object's fields.

    ## Method Parameters

    <ParamField body="name" type="string" required>

      Name of the external database connection.

      An external database connection can connect to one or more external data collections or tables. These appear as `connectionName/dataCollectionId`.

      Constraints: `minLength 1`, `maxLength 255`, `immutable`.

    </ParamField>

    <ParamField body="externalDatabaseConnection" type="ExternalDatabaseConnection" required>

      Updated external database connection details. The existing connection is replaced with this version.

      See the [External Database Connection Object](/api-reference/business-solutions/cms/external-databases/external-database-connection/external-database-connection-object) for this object's fields.
