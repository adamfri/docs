    <div className="wix-ref">

    Updates a site's payment currency or time zone.

    Specify the fields to update in `fields`. Unspecified fields remain unchanged.
    To clear a field, include it in `fields` and omit it from `businessRegion`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-SITEPROP.MANAGE-BUSINESS-REGION">SCOPE.DC-SITEPROP.MANAGE-BUSINESS-REGION</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-properties/v4/properties/business-region
    ```

    ## Body Params

    <ParamField body="businessRegion" type="BusinessRegionData">

      Business region settings to update.

      <Expandable title="businessRegion properties">

        <ParamField body="paymentCurrency" type="string">

          Three-letter currency code in [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) format.

        </ParamField>

        <ParamField body="timeZone" type="string">

          Time zone in IANA time zone database format. For example, `America/New_York`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fields" type="FieldMask">

      Business region fields to update. Properties not included in `fields` are ignored.
      Properties included in `fields` but omitted from `businessRegion` are cleared.

      Supported properties: `paymentCurrency`, `timeZone`.

      <Expandable title="fields properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `UpdateBusinessRegionResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `PERMISSION_DENIED` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method doesn't have the required permissions. |
    | `401` | `UNAUTHENTICATED` | `META_SITE_NOT_FOUND` | Couldn't find the site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
