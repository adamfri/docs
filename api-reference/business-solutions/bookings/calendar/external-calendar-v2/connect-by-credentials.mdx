    Connects a [Wix schedule](https://dev.wix.com/docs/api-reference/business-management/calendar/schedules-v3/introduction)
    to an external calendar account using credentials.

    ### Next steps

    After connecting an external calendar account to a Wix schedule, you can do
    the following.

    #### Check the 2-way-sync settings

    Call [List Connections](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/list-connections)
    and filter by the relevant schedule ID.

    If needed, call [Update Sync Config](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/update-sync-config)
    to adjust the syncing configuration.

    #### Retrieve external calendar events

    Once a connection is successfully created, you can call [List Events](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/list-events)
    to obtain an up-to-date list of events in the connected external calendars.

    ### When to call Connect By OAuth instead

    You could call [Connect By OAuth](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/connect-by-o-auth)
    if:

    + The external calendar provider doesn't support authorization by credentials.
    + You don't have access to the external calendar account credentials.
    + You want the account owner to approve the connection.

    Call [List Providers](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/list-providers)
    for a complete list of external calendar providers supported on the Wix site,
    including which authorization methods they support.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-EXTERNAL-CALENDARS">Manage External Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/external-calendars/connections:connectByCredentials
    ```

    ## Body Params

    <ParamField body="scheduleId" type="string" required>

      ID of the schedule to connect with the external calendar account.

    </ParamField>

    <ParamField body="providerId" type="string" required>

      ID of the external calendar provider. Find this with the [List Providers](#list-providers) endpoint.

    </ParamField>

    <ParamField body="email" type="string" required>

      Email address for the external calendar account.

    </ParamField>

    <ParamField body="password" type="string" required>

      Password for the external calendar account.

    </ParamField>

    ## Response Object

    <ResponseField name="connection" type="Connection">

      Established connection details.

      <Expandable title="connection properties">

        <ResponseField name="id" type="string">

          ID of the connection between the external calendar and the Wix site.

        </ResponseField>

        <ResponseField name="providerId" type="string">

          ID of the external calendar provider.

        </ResponseField>

        <ResponseField name="calendarType" type="string">

          External calendar type.

          **Supported values:**

          - `UNDEFINED` — There is no information about the external calendar type.
          - `GOOGLE` — [Google Calendar](https://developers.google.com/calendar/api/guides/overview).
          - `I_CAL` — Apple iCalendar.
          - `OUTLOOK` — __Deprecated__. Use `MICROSOFT` instead.
          - `OFFICE_365` — __Deprecated__. Use `MICROSOFT` instead.
          - `MICROSOFT` — Microsoft Calendar. For example, Office 365 calendar or Outlook calendar.
          - `OTHER` — A different type of external calendar, not listed here.

        </ResponseField>

        <ResponseField name="scheduleId" type="string">

          ID of the [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction)
          that's connected to the external calendar.

        </ResponseField>

        <ResponseField name="userId" type="string">

          ID of the [Wix user](https://dev.wix.com/docs/rest/articles/getting-started/about-identities#wix-user)
          to whom the external calendar connection belongs.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of the app which created the external calendar connection.

        </ResponseField>

        <ResponseField name="externalAccountEmail" type="string">

          Email address associated with the external calendar account. Available only
          after completed successfully.

        </ResponseField>

        <ResponseField name="status" type="string">

          Connection status.

          **Supported values:**

          - `UNDEFINED` — There is no information about the connection status.
          - `CONNECTED` — The external calendar is connected to the Wix [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction),
          but the sync process hasn't started yet.
          - `SYNC_IN_PROGRESS` — Sync process is ongoing.
          - `SYNCED` — The Wix calendar and the external calendar are in sync.
          - `DISCONNECTED` — The external calender has been disconnected from the Wix [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction).
          - `ERROR` — The calendars sync is in error state.

        </ResponseField>

        <ResponseField name="errorReason" type="string">

          Reason for the error. Available only if `status` is `ERROR`.

          **Supported values:**

          - `UNDEFINED` — There is no information about the connection error.
          - `TOKEN_REVOKED` — The external calendar's access token has been revoked.
          - `EXTERNAL_CALENDAR_CREATION_FAILED` — The external calendar couldn't be created.
          - `EXTERNAL_CALENDAR_DELETED` — The external calendar was deleted.

        </ResponseField>

        <ResponseField name="syncConfig" type="ConnectionSyncConfig">

          Settings about which sync operations are supported.

          <Expandable title="syncConfig properties">

            <ResponseField name="listEventFromCalendars" type="ListEventFromCalendars">

              Configuration for importing events from the external calendar to the Wix
              site.

              _Nested structure omitted for brevity — see the `ListEventFromCalendars` object._

            </ResponseField>

            <ResponseField name="syncToCalendar" type="SyncToCalendar">

              Configuration for exporting events from the Wix site to the external
              calendar.

              _Nested structure omitted for brevity — see the `SyncToCalendar` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `BAD_CREDENTIALS` | The provided credentials are incorrect. Verify the email and password and try again. |
    | `428` | `FAILED_PRECONDITION` | `NOT_SUPPORTED_BY_PROVIDER` | The external calendar provider doesn't support this operation. Use a different connection method or provider. |
    | `403` | `PERMISSION_DENIED` | `PREMIUM_FEATURE_NOT_ENABLED` | This feature requires a premium plan. Upgrade to access external calendar integration. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
