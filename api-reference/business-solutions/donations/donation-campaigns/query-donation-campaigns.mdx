    Retrieves a list of donation campaigns, given the provided paging, filtering, and sorting.

    Query Donation Campaigns runs with these defaults, which you can override:
    - `createdDate` is sorted in `ASC` order
    - `cursorPaging.limit` is `100`

    To learn how to query donation campaigns, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `name` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `tags` | `$exists` | Sort: `ASC`, `DESC` |
    | `archived` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |

    ## Permissions
