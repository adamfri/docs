    <div className="wix-ref">

    Exempts a customer from having to submit an intake form.
    Creates a submission with `EXEMPT` status for the specified [contact](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts/introduction) and intake form.

    Use this when you want to waive the form requirement for a contact so they count as compliant without filling out the form. For example, when approving all forms for a customer group such as VIPs or special circumstances.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.MANAGE_LIMITED">Manage Intake Form (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/intake-forms/v1/submissions/{intakeFormId}/exempt
    ```

    ## Path Params

    <ParamField path="intakeFormId" type="string" required>

      Intake form ID.

    </ParamField>

    ## Body Params

    <ParamField body="contactId" type="string">

      Contact ID.

    </ParamField>

    ## Response Object

    <ResponseField name="intakeFormSubmission" type="IntakeFormSubmission">

      Exempted intake form submission.

      See the [Intake Form Submission Object](/api-reference/crm/forms/other-services/intake-forms/intake-form-submissions/intake-form-submission-object) for this object's fields.

    </ResponseField>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
