      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves complete AI-generated campaign configurations. For Smart campaigns, generated from a previously
    created campaign brief. For PMAX Leads campaigns, generated from the site's marketing settings and pages.
    Uses the Wix AI Gateway (LLM). Responses may take up to 120 seconds.
    Returns complete campaign configurations including assets, keywords, and geo targets.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/campaign-suggestions
    ```

    ## Body Params

    <ParamField body="campaignBriefId" type="string">

      ID of a previously created campaign brief used to generate campaign configurations.

    </ParamField>

    <ParamField body="amount" type="integer">

      Number of campaign suggestions to generate. Maximum is 3.

    </ParamField>

    <ParamField body="campaignType" type="string">

      Type of campaign to generate suggestions for. Defaults to SMART when not set.

      **Supported values:**

      - `SMART` — Simplified auto-managed campaign. Google handles bidding and ad delivery based on keyword themes and geo targets.
      Creating new campaigns of this type is deprecated. Support for it will be removed in a future release, so use
      PERFORMANCE_MAX or PERFORMANCE_MAX_LEADS instead. Existing campaigns of this type aren't affected.
      - `PERFORMANCE_MAX` — Goal-based campaign that runs across all Google channels (Search, Display, YouTube, etc.) using asset groups.
      - `PERFORMANCE_MAX_LEADS` — Performance Max variant optimized for lead generation, such as phone calls and form fills.

    </ParamField>

              Wix internal account ID associated with this campaign.

            </ResponseField>

            <ResponseField name="campaignType" type="string">

              Type of the campaign, either Smart or Performance Max.

              **Supported values:**

              - `SMART` — Simplified auto-managed campaign. Google handles bidding and ad delivery based on keyword themes and geo targets.
              Creating new campaigns of this type is deprecated. Support for it will be removed in a future release, so use
              PERFORMANCE_MAX or PERFORMANCE_MAX_LEADS instead. Existing campaigns of this type aren't affected.
              - `PERFORMANCE_MAX` — Goal-based campaign that runs across all Google channels (Search, Display, YouTube, etc.) using asset groups.
              - `PERFORMANCE_MAX_LEADS` — Performance Max variant optimized for lead generation, such as phone calls and form fills.

            </ResponseField>

            <ResponseField name="status" type="string">

              Current campaign status, synced from Google Ads on each read.

              **Read-only.**

              **Supported values:**

              - `LIVE` — Campaign is currently serving ads, depending on budget information.
              - `PAUSED` — Campaign has been paused by the user.
              - `ENDED` — Campaign has been ended.
              - `IN_REVIEW` — The campaign was created but its budget hasn't been charged yet.
              - `ERROR` — Error state.
              - `DISAPPROVED` — Campaign is not approved.
              - `NOT_SERVING` — Campaign is currently not serving due to budget limitations.
              - `DRAFT` — Campaign is a draft.
              - `LEARNING` — Campaign is in the learning phase. Currently supported only for Google Ads Performance Max leads campaigns.

            </ResponseField>

            <ResponseField name="resourceName" type="string">

              Google Ads resource name for this campaign, e.g. customers/&#123;customerId&#125;/campaigns/&#123;campaignId&#125;.

              **Read-only.**

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name of the campaign.

            <ResponseField name="createdDate" type="datetime">

              Date and time the campaign was created.

            </ResponseField>

            <ResponseField name="updatedDate" type="datetime">

              Date and time the campaign was last updated.

              **Read-only.**

            </ResponseField>

            <ResponseField name="actionDate" type="datetime">

              Date and time of the most recent lifecycle action (pause, resume, launch, etc.).

              **Read-only.**

            </ResponseField>

            <ResponseField name="budget" type="CampaignBudget">

              Daily budget for the campaign.

              _Nested structure omitted for brevity — see the `CampaignBudget` object._

            </ResponseField>

            <ResponseField name="locations" type="LocationCriterion[]">

              Geographic locations targeted by this campaign.

              Constraints: `maxItems 1000`.

              _Nested structure omitted for brevity — see the `LocationCriterion[]` object._

            </ResponseField>

            <ResponseField name="adSchedule" type="WeeklyAdSchedule">

              Weekly ad schedule defining the days and hours when ads can run.

              _Nested structure omitted for brevity — see the `WeeklyAdSchedule` object._

            <ResponseField name="reportingKey" type="string">

              Value used as the utm_campaign parameter for conversion tracking.

              **Read-only.**

            </ResponseField>

            <ResponseField name="campaignBrief" type="CampaignBrief">

              The brief used to generate this campaign.
              Only present on campaigns created via the GetCampaignSuggestions endpoint of SuggestionsService.

              _Nested structure omitted for brevity — see the `CampaignBrief` object._

            </ResponseField>

          </Expandable>

          <Expandable title="One of the following">

            <ResponseField name="campaign" type="campaign">

            </ResponseField>

          </Expandable>
