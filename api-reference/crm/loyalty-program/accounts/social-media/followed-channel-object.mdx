title: "Followed Channel Object"
description: "The Followed Channel object in the Wix Followed Channel API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Followed social media channel ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="accountId" type="string">

      ID of the account that has followed a social media channel.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="channel" type="string">

      Followed social media channel.

      **Supported values:**

      - `FACEBOOK` — Facebook social media channel.
      - `INSTAGRAM` — Instagram social media channel.
      - `LINKEDIN` — LinkedIn social media channel.
      - `X` — X social media channel.
      - `TIKTOK` — TikTok social media channel.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when an entity for following a social media channel was created.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "3efb39b6-5bae-493d-a8ed-749f3794a8ba",
        "accountId": "18de02d0-a88c-49f7-987f-8558ca02162d",
        "channel": "TIKTOK",
        "createdDate": "2024-08-01T11:51:41.431Z" 
      }
      ```

    </CodeGroup>
