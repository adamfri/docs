    Retrieves a list of up to 100 tip distributions, given the provided paging, filtering, and sorting.

    Query Tip Distributions runs with these defaults, which you can override:
    - `cursorPaging.limit` is `50`

    When setting a date filter remember to use
    [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time).

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

          Max: 10 `lineItemInfo` objects

          Constraints: `minItems 0`, `maxItems 12`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the distribution was created in
          `YYYY-MM-DDThh:mm:ss.sssZ` format.

          **Read-only.**

          - `UNKNOWN_SOURCE` — There is no information about who created the tip distributions.

          - `WEB` — The customer added the tip distributions during an online eCommerce checkout ([SDK](https://dev.wix.com/docs/sdk/backend-modules/ecom/checkout/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/checkout/introduction)).
