    <div className="wix-api-columns">

    <div className="wix-ref">

    Moves a badge to a specific position in the display order.

    You can position a badge first, last, or immediately after another badge.

    This affects how badges appear to site members and in the site dashboard.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/badges/v4/badges/{badgeId}/move
    ```

    ## Path Params

    <ParamField path="badgeId" type="string" required>

      ID of the badge to move.

    </ParamField>

    ## Body Params

    <ParamField body="position" type="string">

      Target position for the badge.

      **Supported values:**

      - `LAST` — Position the badge at the end of the display sequence.
      - `FIRST` — Position the badge at the beginning of the display sequence.
      - `AFTER` — Position the badge after another specific badge.
      In this case you need to specify `moveAfterBadgeId`.

    </ParamField>

    <ParamField body="moveAfterBadgeId" type="string">

      ID of the badge after which to position your badge.

    </ParamField>

    ## Response Object

    Returns `MoveBadgeResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
