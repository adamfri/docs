    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates a data sharing policy for the specified collection.

    You can optionally filter which items in the collection can be shared. If no filters are specified, all items in the collection are shared. You can create multiple policies for the same collection with different filters.

    You can find which fields can be filtered for each collection by calling [Get Data Collection](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-collections/get-data-collection). The supported filters are returned in the response under `collections.fields.capabilities.queryOperators`.

    <Note>

    Only collections created in the CMS or with the [Data Collections API](https://dev.wix.com/docs/api-reference/business-solutions/cms/introduction) can be shared. External collections and Wix App collections can't be shared.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v1/data-collection-sharing/policies
    ```

    ## Body Params

    <ParamField body="dataSharingPolicy" type="DataSharingPolicy">

      Data sharing policy to create.

      See the [Data Sharing Policy Object](/api-reference/business-solutions/cms/collection-management/data-sharing/data-sharing-policy-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="dataSharingPolicy" type="DataSharingPolicy">

      Created data sharing policy.

      See the [Data Sharing Policy Object](/api-reference/business-solutions/cms/collection-management/data-sharing/data-sharing-policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `WDE0107` | Collection type can't be shared. Verify the collection isn't an external collection or a Wix App collection. |
    | `404` | `NOT_FOUND` | `WDE0025` | Collection not found. Verify the collection ID is correct and that the collection exists. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Sharing Policy Created | `wix.data.v1.data_sharing_policy_created` | Triggered when a new data sharing policy is created. |

    </div>
