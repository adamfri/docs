    Updates a GBP location's stored fields.

    This doesn't change anything on the Google Business Profile. Only fields the
    GBP location itself stores can be updated: `serviceAreaPostalAddress`, and
    `feedEntityId` if it doesn't have a value yet. Naming a Google-owned field in
    `fieldMask` has no effect. To change the profile in Google, call Update Google
    Location.

    List the fields to change in `fieldMask`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    Callable by: `APP`.

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Google's opaque location identifier on the public API.

      Constraints: `minLength 1`, `maxLength 255`, `immutable`.

    </ParamField>

    <ParamField body="location" type="UpdateLocation" required>

      The location to update. Can be partial.

      <Expandable title="location properties">

        <ParamField body="_id" type="string">

          Google's opaque location identifier on the public API.

          Constraints: `minLength 1`, `maxLength 255`, `immutable`.

        </ParamField>

        <ParamField body="accountId" type="string">

          ID of the Google Business Profile account that holds this location, what
          Google calls a location group.

          One site can have locations in more than one account, because a single
          Google login can own several.

          Constraints: `maxLength 255`, `immutable`.

        </ParamField>

        <ParamField body="serviceAreaPostalAddress" type="PostalAddress">

          Saved postal address for service-area businesses. Used as the `context`
          parameter in Google's FetchVerificationOptions call for service-area
          verification flows. Null for storefront businesses.

          <Expandable title="serviceAreaPostalAddress properties">

            <ParamField body="countryCode" type="string">

              ISO 3166-1 alpha-2 country code (e.g. "US", "GB").

              Constraints: `format COUNTRY`.

            </ParamField>

            <ParamField body="postalCode" type="string">

              Postal/ZIP code.

              Constraints: `maxLength 20`.

            </ParamField>

            <ParamField body="administrativeArea" type="string">

              Administrative area (state, province, region).

              Constraints: `maxLength 100`.

            </ParamField>

            <ParamField body="locality" type="string">

              City or locality.

              Constraints: `maxLength 100`.

            </ParamField>

            <ParamField body="addressLines" type="string[]">

              Street address lines. Up to 5 lines.

              Constraints: `maxLength 255`, `maxItems 5`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the location was imported into Wix.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the location was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="string">

          Revision number, incremented on every update. Used for optimistic locking.

          **Read-only.**

        </ParamField>

        <ParamField body="googleLocationId" type="string">

          Google's location identifier for this location, the same value as `id`.
          Filter and sort on this field in Query GBP Locations.

          **Read-only.** Constraints: `maxLength 255`, `immutable`.

        </ParamField>

        <ParamField body="feedEntityId" type="string">

          Identity this location is published under in Google partner feeds, used as
          the entity ID, merchant ID or parent entity ID across Reserve with Google,
          Order with Google and Dine with Google.

          Can be set once. A location that already has a value keeps it, and a request
          that tries to change it is rejected: Google has already ingested the value as
          the merchant's identity, so changing it withdraws the business from those
          feeds and can remove its booking and ordering buttons. Setting it on a
          location that doesn't have one yet is allowed.

          Locations created through this API are given a value automatically, so you
          usually don't need to set it. Specify it only when migrating a location whose
          identity Google already knows.

        </ParamField>

      </Expandable>

    </ParamField>
