---
title: "Task Object"
description: "The task object represents all information available for tasks."
icon: "cube"
---

The `task` object represents all information available for tasks. A task is a specific action or assignment to be completed.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Task ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the task is updated. To prevent conflicting changes, the existing `revision` must be used when updating a task.

      **Read-only.**

    </ResponseField>

    <ResponseField name="title" type="string">

      Title of the task.

    </ResponseField>

    <ResponseField name="description" type="string">

      Description of the task.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the task was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the task was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="dueDate" type="datetime">

      Due date for the task.

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the task.

      Default: `ACTION_NEEDED`

      **Supported values:**

      - `ACTION_NEEDED` — Action needed.
      - `COMPLETED` — Task completed.

    </ResponseField>

    <ResponseField name="source" type="TaskSource">

      Details about the task source.

      <Expandable title="source properties">

        <ResponseField name="sourceType" type="string">

          How the task was created.

          **Read-only.**

          **Supported values:**

          - `APP` — Task was created by an app.
          - `USER` — Task was created by a Wix user.

        </ResponseField>

        <ResponseField name="appId" type="string">

          App ID, if the task was created by an app.

          **Read-only.**

        </ResponseField>

        <ResponseField name="userId" type="string">

          User ID, if the task was created by a Wix user.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="contact" type="ContactInfo">

      Information about the contact associated with the task.

      <Expandable title="contact properties">

        <ResponseField name="id" type="string">

          ID of the contact associated with the task.

        </ResponseField>

        <ResponseField name="firstName" type="string">

          Contact's first name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="lastName" type="string">

          Contact's last name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="imageUrl" type="string">

          Contact's image URL.

          **Read-only.**

        </ResponseField>

        <ResponseField name="email" type="string">

          Contact's primary email.

          **Read-only.**

        </ResponseField>

        <ResponseField name="phone" type="string">

          Contact's primary phone.

          **Read-only.**

        </ResponseField>

        <ResponseField name="imageUrlExpirationDate" type="datetime">

          Image URL expiration date.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>
