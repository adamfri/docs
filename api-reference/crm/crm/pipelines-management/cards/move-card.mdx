    Moves a card to a different stage within the same pipeline.

    Cards can only be moved between stages within the same pipeline.

    Each time a card is moved, its `revision` increments by 1.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/crm/pipelines/v1/cards/move/{cardId}
    ```

    ## Path Params

    <ParamField path="cardId" type="string" required>

      Card ID to move.

    </ParamField>

    ## Body Params

    <ParamField body="stageId" type="string" required>

      ID of the stage to move the card to.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="revision" type="integer" required>

      Revision of the card to move. Moving the card changes the `stageId` on the card and increases `revision` by 1.

    </ParamField>

    <ParamField body="outcome" type="string">

      New card outcome.

      **Supported values:**

      - `NONE` — No specific outcome. The card reached the final stage but hasn't been specified as successful or unsuccessful.
      - `WON` — Successful outcome. The card achieved its intended goal.
      - `LOST` — Unsuccessful outcome. The card didn't achieve its intended goal.

    </ParamField>

    ## Response Object

    <ResponseField name="card" type="Card">

      Updated card.

      See the [Card Object](/api-reference/crm/crm/pipelines-management/cards/card-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `STAGE_NOT_FOUND` | The specified stage doesn't exist in the pipeline. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_OUTCOME` | The card is being moved to the done stage but doesn't have a valid outcome. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Card Updated | `wix.crm.pipelines.v1.card_updated` | Triggered when a card is updated. |
    | Card Moved | `wix.crm.pipelines.v1.card_moved` | Triggered when a card is moved from one stage to another. |

    </div>
