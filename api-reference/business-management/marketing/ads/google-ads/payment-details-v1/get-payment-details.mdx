    </Info>

    Retrieves billing and payment details for the current site's Google Ads account.

    Billing data is calculated from cached subscription information, not fetched live from Google Ads.
    This method has a response-time SLA of 30 seconds due to charge calculation complexity.

    Errors:
    - ACCOUNT_NOT_FOUND: Couldn't find the account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/payment-details
    ```

    ## Response Object

    <ResponseField name="paymentDetails" type="PaymentDetails">

      Payment details for the current site's Google Ads account.

      See the [Payment Details Object](/api-reference/business-management/marketing/ads/google-ads/payment-details-v1/payment-details-object) for this object's fields.

    </ResponseField>
