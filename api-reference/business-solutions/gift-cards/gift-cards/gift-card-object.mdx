---
title: "Gift Card Object"
description: "A gift card represents a prepaid payment method that customers can use to make purchases."
icon: "cube"
---

A gift card represents a prepaid payment method that customers can use to make purchases.
Gift cards store monetary value that can be redeemed during checkout and support email
delivery to recipients with personalized messaging. All balance changes are automatically
tracked for audit and reporting purposes.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Gift card ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="code" type="string">

      Gift card code used for redemption.

      > **Notes:**
      > + The gift card code can be custom-provided or automatically generated by omitting the field.
      > + The `code` field contains the **obfuscated** gift card code, for example, `****-****-****-4444`.
      > + Only the returned code is obfuscated. You can still find a gift card by filtering `code` with the full code.

    </ResponseField>

    <ResponseField name="initialValue" type="Amount">

      Initial monetary value assigned to the gift card when created.

      Constraints: `immutable`.

      <Expandable title="initialValue properties">

        <ResponseField name="amount" type="string">

          Monetary amount in the specified currency as a decimal string.
          For example, `"10.50"` for $10.50, or `"100"` for $100.00.

          Constraints: `format DECIMAL_VALUE`, `>= 0`.

        </ResponseField>

        <ResponseField name="formattedAmount" type="string">

          Amount formatted with currency symbol for display purposes.
          For example: `"$10.50"` or `"€25.00"`.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="balance" type="Amount">

      Current available balance that can be spent.

      Decreases when the gift card is used for purchases and increases with refunds.

      **Read-only.**

      <Expandable title="balance properties">

        <ResponseField name="amount" type="string">

          Monetary amount in the specified currency as a decimal string.
          For example, `"10.50"` for $10.50, or `"100"` for $100.00.

          Constraints: `format DECIMAL_VALUE`, `>= 0`.

        </ResponseField>

        <ResponseField name="formattedAmount" type="string">

          Amount formatted with currency symbol for display purposes.
          For example: `"$10.50"` or `"€25.00"`.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="currency" type="string">

      Three-letter currency code in [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) format. For example, `"USD"`, `"EUR"`.

    </ResponseField>

    <ResponseField name="expirationDate" type="datetime">

      Date and time when the gift card expires and becomes unusable.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the gift card was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the gift card was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="disabledDate" type="datetime">

      Date and time the gift card was disabled, if applicable.

      **Read-only.**

    </ResponseField>

    <ResponseField name="notificationInfo" type="NotificationInfo">

      Email notification settings including recipient, sender, and delivery options.

      Constraints: `immutable`.

      <Expandable title="notificationInfo properties">

        <ResponseField name="recipient" type="Recipient">

          Recipient information for email delivery.

          Constraints: `immutable`.

          <Expandable title="recipient properties">

            <ResponseField name="email" type="string">

              Email address where the gift card will be sent.

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name shown in the gift card email.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="notificationDate" type="datetime">

          Scheduled date and time to send the gift card email notification.
          Leave empty to send the email immediately.

        </ResponseField>

        <ResponseField name="personalizedMessage" type="string">

          Custom message to include in the gift card email.
          Personalizes the gift card for the recipient.

        </ResponseField>

        <ResponseField name="sender" type="Sender">

          Sender information for email display.

          Constraints: `immutable`.

          <Expandable title="sender properties">

            <ResponseField name="email" type="string">

              Email address displayed in the gift card notification.

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name shown in the gift card email.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="source" type="string">

      How the gift card was created.

      Constraints: `immutable`.

      **Supported values:**

      - `ORDER` — Gift card was purchased through an order.
      - `MANUAL` — Gift card was created manually via API.

    </ResponseField>

    <ResponseField name="codeSuffix" type="string">

      Last 4 characters of the gift card code for search and identification purposes.

      **Read-only.**

    </ResponseField>

  </Tab>
