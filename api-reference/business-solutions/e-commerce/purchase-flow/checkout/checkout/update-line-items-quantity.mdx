    Updates the quantity of one or more line items in a checkout.

    This method is only for updating the quantity of line items. To entirely remove a line item from
    the checkout, use the Remove Line Items method.
    To add a new line item to the checkout, use the Add to Checkout method.

    This method checks the amount of stock remaining for this line item. If the specified `quantity`
    is greater than the remaining stock, then the `quantity` returned in the response is the total amount
    of remaining stock.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkouts/{id}/update-line-items-quantity
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Checkout ID.

    </ParamField>

    ## Body Params

    <ParamField body="lineItems" type="LineItemQuantityUpdate[]" required>

      Line item info to update.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="lineItems properties">

        <ParamField body="id" type="string" required>

          ID of the line item to update.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="quantity" type="integer" required>

          New total amount of the line item,
          not the amount to add to the current `quantity`.

          Min: `1`

          Max: `100000`

          Constraints: `min 1`, `max 100000`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="checkout" type="Checkout">

      Updated checkout.

      See the [Checkout Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout/checkout-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
