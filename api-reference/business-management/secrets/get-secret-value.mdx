    Retrieves a secret value by name.

    <Warning>

    Only use a secret's value in the backend code. Returning the secret value in the frontend is a security risk.

    </Warning>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.VELO.MANAGE_SECRETS">Manage Secrets</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/secrets-service/api/v1/secrets/name/{name}
    ```

    ## Path Params

    <ParamField path="name" type="string" required>

      Secret name.

    </ParamField>

    ## Response Object

    <ResponseField name="value" type="string">

      The confidential value to protect, such as an API key.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
