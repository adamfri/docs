    Creates and sends an email transmission to one or more recipients.

    The email is sent asynchronously. The returned transmission has `ACCEPTED` status.
    Call [Get Email Transmission](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/email-transmission-v1/get-email-transmission) or listen for the `EmailTransmissionCreated` webhook to track delivery status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/emails/transmissions/v1/email-transmissions/send
    ```

    ## Body Params

    <ParamField body="emailTransmission" type="EmailTransmission" required>

      Email transmission to send.

      See the [Email Transmission Object](/api-reference/business-management/marketing/emails/email-transmission-v1/email-transmission-object) for this object's fields.

    </ParamField>

    <ParamField body="idempotencyKey" type="string">

      Unique key used to prevent duplicate transmissions. If a request with the same idempotency key is received,
      the original response is returned without creating a new transmission.

    </ParamField>

    ## Response Object

    <ResponseField name="emailTransmission" type="EmailTransmission">

      Sent email transmission.

      See the [Email Transmission Object](/api-reference/business-management/marketing/emails/email-transmission-v1/email-transmission-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `ACCOUNT_SUSPENDED` | This site's account is suspended due to a terms of service violation. |
    | `428` | `FAILED_PRECONDITION` | `UNVERIFIED_SENDER_EMAIL` | The provided `senderEmailAddress` hasn't been verified. Verify the sender email using the Sender Emails API before sending. |
    | `428` | `FAILED_PRECONDITION` | `OUT_OF_QUOTA` | The site has reached its email sending quota. Upgrade the site's Email Marketing plan to send more emails. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_METADATA` | One or more metadata keys or values contain invalid characters. Keys and values must consist of 1-50 alphanumeric characters. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
