    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves all existing collection references for a data collection.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v1/folders/collection-references/get
    ```

    ## Body Params

    <ParamField body="collectionName" type="string" required>

      Name of the collection to retrieve references for.

      Constraints: `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="collectionReferences" type="CollectionReference[]">

      Collection references.

      <Expandable title="collectionReferences properties">

        <ResponseField name="collectionName" type="string">

          Collection's name as displayed in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-creating-a-collection).

          Constraints: `maxLength 255`, `immutable`.

        </ResponseField>

        <ResponseField name="folderId" type="string">

          ID of the folder that contains the collection reference.

          Omitted if the collection reference is in the root folder.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST https://wixapis.com/autocms/v1/folders/collection-references/get  \
          -H 'Authorization: <AUTH>' \
          -d '{
              "collectionName": "RestaurantMenu"
          }'
      ```

      ```json Response
      {
          "collectionReferences": [
              {
                  "folderId": "593c732f-d781-4457-b4a9-7ad73ddf4b1a",
                  "collectionName": "RestaurantMenu"
              }
          ]
      }
      ```

    </CodeGroup>
