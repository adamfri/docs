    <div className="wix-ref">

    Clones an event, including the registration form, notifications, multilingual translations and ticket configuration from the original event. <br /> <br />
    The new event's date is automatically set to 14 days from the original event date. <br /> <br />
    If an event with the same `title` already exists, the new event's `title` gets a sequence number. For example, if you clone an event named `"Leather Crafting 101"`, the new event's title is `"Leather Crafting 101 (1)"`. <br /> <br />
    You can change the required entity field values while cloning an event.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/events/{eventId}/clone
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID.

    </ParamField>

    ## Body Params

    <ParamField body="event" type="Event">

      Event info to change in the cloned event.

      See the [Event Object](/api-reference/business-solutions/events/event-management/events-v3/event-object) for this object's fields.

    </ParamField>

    <ParamField body="draft" type="boolean">

      Whether to clone the event as a draft.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `DETAILS` — Returns `shortDescription`, `mainImage` and `calendarUrls`.
      - `TEXTS` — Returns `description`.
      - `REGISTRATION` — Returns `registration`.
      - `URLS` — Returns `eventPageUrl`.
      - `FORM` — Returns `form`.
      - `DASHBOARD` — Returns `summaries`.
      - `FEED` — Returns `feed`.
      - `ONLINE_CONFERENCING_SESSION` — Returns `onlineConferencing.session`.
      - `SEO_SETTINGS` — Returns `seoSettings`.
      - `AGENDA` — Returns `agendaSettings`.
      - `CATEGORIES` — Returns `categories`.

    </ParamField>

    ## Response Object

    <ResponseField name="event" type="Event">

      Cloned event.

      See the [Event Object](/api-reference/business-solutions/events/event-management/events-v3/event-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:

    | Event Published | `wix.events.v3.event_published` | Triggered when an event is published. |
