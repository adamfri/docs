    <Note>

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/events/v1/tickets/check-in
    ```

    ## Query Params

    <ParamField query="eventId" type="string" required>

      Event ID to which the ticket belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="ticketNumber" type="string[]">

      Ticket numbers to delete check-ins for.

      Constraints: `minLength 1`, `maxLength 36`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="tickets" type="Ticket[]">

      Updated tickets.

      See the [Ticket Object](/api-reference/business-solutions/events/registration/ticketing/tickets/ticket-object) for this object's fields.
