    <div className="wix-ref">

    Updates multiple projects.

    To update a single project, call Update Project.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PORTFOLIO.MANAGE-PORTFOLIO">Manage Portfolio</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/portfolio/projects/projects/api/v1/bulk/portfolio/projects/update
    ```

    ## Body Params

    <ParamField body="projects" type="MaskedProject[]">

      Projects to update.

      Constraints: `maxItems 100`.

      <Expandable title="projects properties">

        <ParamField body="project" type="Project" required>

          Project to update.

          See the [Project Object](/api-reference/business-solutions/portfolio/projects/project-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnFullEntity" type="boolean">

      Whether to return the updated projects.

      Set to `true` to return the projects in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkUpdateProjectsResult[]">

      List of individual Bulk Update Projects results.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Information about the updated project.
          Including its ID, index in the bulk request and whether it was successfully updated.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="project" type="Project">

          Updated project. Only returned if `returnEntity` is set to `true` in the request.

          See the [Project Object](/api-reference/business-solutions/portfolio/projects/project-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Total number of successes and failures for Bulk Update Projects.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Project Updated | `wix.portfolio.projects.v1.project_updated` | Triggered when a project is updated. |
