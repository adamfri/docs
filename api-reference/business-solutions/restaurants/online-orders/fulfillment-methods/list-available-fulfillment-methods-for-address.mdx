    Retrieves a list of up to 100 fulfillment methods available for a given address.

    The response will only include:
    - Non-delivery fulfillment methods.
    - Delivery fulfillment methods that are available to the given address according to their delivery areas.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/fulfillment-methods/v1/fulfillment-methods/available-for-address
    ```
