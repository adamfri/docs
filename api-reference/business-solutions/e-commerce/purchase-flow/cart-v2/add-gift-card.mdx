    <div className="wix-ref">

    Adds a gift card to the cart.

    Once added, the gift card balance is used as a payment method during checkout, either partially or fully covering the cart total.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2">Write Carts V2</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/{cartId}/add-gift-card
    ```

    ## Path Params

    <ParamField path="cartId" type="string" required>

      Cart ID.

    </ParamField>

    ## Body Params

    <ParamField body="giftCard" type="GiftCardInput" required>

      Gift card to add.

      Currently only one is supported.

      <Expandable title="giftCard properties">

        <ParamField body="code" type="string" required>

          Gift card code.

          Constraints: `minLength 8`, `maxLength 20`.

        </ParamField>

        <ParamField body="redeemAmount" type="ConvertedMoney">

          The amount requested to redeem from this gift card.

          <Expandable title="redeemAmount properties">

            <ParamField body="amount" type="string">

              Monetary amount in the original currency, as specified in `businessInfo.currencyCode`.

              Constraints: `format DECIMAL_VALUE`, `>= 0`, `<= 999999999`.

            </ParamField>

            <ParamField body="convertedAmount" type="string">

              Monetary amount in the converted currency, as specified in `customerInfo.currencyCode`.

              Default: `amount`.

              **Read-only.** Constraints: `format DECIMAL_VALUE`, `>= 0`, `<= 999999999`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CART_ALREADY_ORDERED` | Cart was already placed as an order. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_GIFT_CARD_CODE` | The gift card code is invalid. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_GIFT_CARD_STATUS` | The gift card isn't currently active. |
    | `428` | `FAILED_PRECONDITION` | `MAX_GIFT_CARDS_PER_CART_EXCEEDED` | Number of gift cards exceeds the cart's limit. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_ALREADY_EXISTS` | A gift card is already applied to this cart. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_LOCKED` | The gift card is locked and can't be changed. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Cart Updated | `wix.ecom.v2.cart_updated` | Triggered when a cart is updated. |

    </div>
