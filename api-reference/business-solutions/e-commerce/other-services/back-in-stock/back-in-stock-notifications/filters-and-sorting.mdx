<Note>This article applies to the REST API only.</Note>

The following table shows field support for filters and sorting
for the Back In Stock Notification Request object:

| Field           | Supported Filters                             | Sortable |
| --------------- | --------------------------------------------- | -------- |
| `id`            | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith` | Sortable |
| `contactId`   | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith` | Sortable |
| `status`   | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome` | Sortable |
| `autoNotified`        | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome` | Sortable |
| `createdDate` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$lt`, `$le`, `$gt`, `$ge` | Sortable |
| `itemUrl` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith` | Sortable |
