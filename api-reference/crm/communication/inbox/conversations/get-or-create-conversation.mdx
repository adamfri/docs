    Retrieves a conversation by the specified visitor, contact, or member ID. If the conversation doesn't exist for the specified visitor, contact, or member, the method creates a new conversation.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-INBOX.MANAGE-MSGS">Manage Inbox Messages</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/inbox/v2/conversations
    ```

    ## Body Params

    <ParamField body="participantId" type="ParticipantId">

      ID of the visitor, contact, or member chatting with the business.

      Required for 3rd-party apps.

      <Expandable title="One of the following">

        <ParamField body="id" type="id">

          id

          <Expandable title="id properties">

            <ParamField body="contactId" type="string">

              Contact ID. See the Contacts API for more information.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="anonymousVisitorId" type="string">

              ID of an anonymous site visitor.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="memberId" type="string">

              Member ID. See the Members API for more information.

              Constraints: `format GUID`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="conversation" type="Conversation">

      Created or retrieved conversation.

      See the [Conversation Object](/api-reference/crm/communication/inbox/conversations/conversation-object) for this object's fields.

    </ResponseField>

    <ResponseField name="newConversation" type="boolean">

      Indicates whether the conversation previously exists or was just created.

      If `true`, the conversation was just created.
      If `false`, the conversation already existed.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
