@package_metadata:@wix/user-management

To use the Accounts API, install the `@wix/user-management` package.

#### Install the package

Follow the installation instructions for your development environment.

| Development environment | Installation method |
|--|--|
| Wix sites (editor or IDE) | Use the [package manager](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-in-the-editor). |
| Wix sites (local IDE) | Run `wix install @wix/user-management` using the [Wix CLI](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-with-the-wix-cli).|
| Blocks apps | Use the same installation method as Wix sites. |
| CLI and self-hosted apps | Run `npm install @wix/user-management` or `yarn add @wix/user-management`. |
| Headless sites and apps | Run `npm install @wix/user-management` or `yarn add @wix/user-management`. |

#### Import the package

To import the package in your code:

```js
import { accounts } from '@wix/user-management'
```
