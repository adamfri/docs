    Retrieves a list of extended fields.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-EX-FIELDS">Manage Contact Extended Fields</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/extended-fields
    ```

    ## Query Params

    <ParamField query="fieldType" type="string">

      Filter for fields of the specified type.

      **Supported values:**

      - `SYSTEM` — Field is a system field managed by Wix. System fields can't be modified by calling the Update Extended Field method.
      - `USER_DEFINED` — Field is a custom field and can be modified by calling the Update Extended Field method.

    </ParamField>

    <ParamField query="namespace" type="string">

      Filter for fields in the specified namespace.
      Fields created by calling the Find Or Create Extended Field method
      are automatically assigned to the `custom` namespace.

    </ParamField>

    <ParamField query="startsWith" type="string">

      Filter for fields where `displayName` starts with the specified case-sensitive string.

    </ParamField>

    <ParamField query="sort" type="Sorting">

      Sorting options.

      <Expandable title="sort properties">

        <ParamField query="fieldName" type="string">

          Name of the field to sort by.

          Constraints: `maxLength 100`.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.

          Default: `ASC`.

          **Supported values:**

          - `ASC` — Sort by ascending order.
          - `DESC` — Sort by descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="paging" type="Paging">

      Paging options.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to return.

          Defaults to `100`.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

          Defaults to `0`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="fields" type="ExtendedField[]">

      List of extended fields.

      See the [Extended Field Object](/api-reference/crm/members-contacts/contacts/extended-fields/extended-field-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Metadata for the page of results.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Requested offset.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Number of items that matched the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Indicates if `total` calculation timed out before the response was sent.
          Typically this happens if there is a large set of results.

        </ResponseField>

      </Expandable>

    </ResponseField>
