A project represents a site, mobile app, or backend-only setup in a Wix account.
It's the container for your Wix business features, data, and settings, and may or may not include a Wix-managed frontend.
You can use the `metaSiteId` to access the project dashboard at `https://manage.wix.com/dashboard/{metaSiteId}`.

<Tabs>

  <Tab title="REST">

    <ResponseField name="metaSiteId" type="string">

      Project ID. Use this ID to access the project dashboard.

      **Read-only.**

    </ResponseField>

    <ResponseField name="siteId" type="string">

      Site ID. The ID of the project's visual site component.

      **Read-only.**

    </ResponseField>

    <ResponseField name="templateId" type="string">

      ID of the template used to create this project.
      Defaults to a blank template if no template was specified.

      **Read-only.**

    </ResponseField>

    <ResponseField name="apps" type="App[]">

      Apps installed on this project.

      **Read-only.** Constraints: `maxItems 100`.

      <Expandable title="apps properties">

        <ResponseField name="appDefId" type="string">

          ID of the app to install. See [About Apps Created by Wix](https://dev.wix.com/docs/api-reference/articles/get-started/apps-created-by-wix) for a list of available App Definition IDs.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
