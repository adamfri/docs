    <div className="wix-ref">

    Updates a campaign's editor data, including the content and subject line.

    The `composerDataJson` format must match the campaign's existing `campaignEditorType`. Passing a mismatched format causes a silent failure when sending or previewing the campaign.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/composer
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      Campaign ID.

    </ParamField>

    ## Body Params

    <ParamField body="composer" type="Composer">

      Updated campaign editor data.

      <Expandable title="composer properties">

        <ParamField body="composerDataJson" type="string" required>

          Editor content for the campaign. The format depends on `campaignEditorType`:

          - `WEB`: Wix proprietary JSON format used by the drag-and-drop email editor.
          - `MOBILE`: A subset of the `WEB` format, used by the mobile email editor.
          - `MJML`: MJML markup wrapped in a JSON object under key "mjml".

          Passing the wrong format for the given `campaignEditorType` causes a silent failure when sending or previewing the campaign.

          Constraints: `maxLength 10000000`.

        </ParamField>

        <ParamField body="defaultValues" type="DefaultValues">

          Fallback values for dynamic placeholders in the campaign content.

          <Expandable title="defaultValues properties">

            <ParamField body="map" type="object">

              Map of placeholder keys to their default values.

              Constraints: `format map`, `maxItems 500`.

              _Nested structure omitted for brevity — see the `object` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="emailSubject" type="string">

      Subject line displayed in recipients' inboxes (optional).

    </ParamField>

    <ParamField body="emailPreheader" type="string">

      Short preview text shown after the subject line in some email clients (optional).

    </ParamField>

    ## Response Object

    Returns `UpdateComposerResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
