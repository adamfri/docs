A record representing a contact's completion of an intake form.
Each submission has one of these statuses: `VALID`, `EXPIRED`, `CANCELED`, `EXTENDED`, or `EXEMPT`, with expiration and lifecycle management.

## SDK package

```bash
npm install @wix/intake-forms
```

Import the `intakeFormSubmissions` namespace from `@wix/intake-forms`.
