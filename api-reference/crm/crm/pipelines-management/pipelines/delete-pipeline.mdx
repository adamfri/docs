    Deletes a pipeline.

    <Note>

    - You can't delete a pipeline that contains cards. Make sure to remove all cards in the pipeline before calling this method.
    - Deleting a pipeline permanently removes it from a site.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/crm/pipelines/v1/pipelines/{pipelineId}
    ```

    ## Path Params

    <ParamField path="pipelineId" type="string" required>

      Pipeline ID.

    </ParamField>

    ## Response Object

    Returns `DeletePipelineResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_NON_EMPTY_PIPELINE` | A pipeline that contains cards can't be deleted. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
