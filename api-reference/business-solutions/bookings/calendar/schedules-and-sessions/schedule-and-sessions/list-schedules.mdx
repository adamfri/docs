Lists schedules by schedule IDs or schedule owner IDs.

> **Permissions**
> This endpoint requires the Read Bookings Calendar or the Manage Bookings permission scope.
> With the Read Bookings Calendar permission scope, the schedule participants are not returned.

## Endpoint

```http
GET https://www.wixapis.com/bookings/v1/calendar/schedules
```

## Query Params

<ParamField query="scheduleIds" type="string[]">

  List by schedule IDs.

</ParamField>

<ParamField query="scheduleOwnerIds" type="string[]">

  List by schedule owner IDs.

</ParamField>

<ParamField query="dontIncludeScheduleParticipants" type="boolean">

  Whether to return a list of the schedule's participants.

</ParamField>

<ParamField query="userIds" type="string[]">

  List schedules assigned to the given Wix user ids.
  Requires the Manage Personal Calendar or the Manage Business Calendar scope.

  Constraints: `format GUID`.

</ParamField>

## Response Object

<ResponseField name="schedules" type="Schedule[]">

  Schedule.

  See the [Schedule Object](/api-reference/business-solutions/bookings/calendar/schedules-and-sessions/schedule-and-sessions/schedule-object) for this object's fields.

</ResponseField>
