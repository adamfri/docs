    <div className="wix-ref">

    Returns all currencies currently supported by Wix.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CURRENCY-CONVERTER.MANAGE-CURRENCIES">Manage Currencies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/currency_converter/v1/currencies
    ```

    ## Response Object

    <ResponseField name="currencies" type="Currency[]">

      Supported currencies

      <Expandable title="currencies properties">

        <ResponseField name="code" type="string">

          Currency code.

          Constraints: `format CURRENCY`.

        </ResponseField>

        <ResponseField name="symbol" type="string">

          Currency symbol.

          Constraints: `maxLength 10`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
