    Creates a modifier group.

    To create multiple modifier groups at once, use [Bulk Create Modifiers](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-modifier-groups/bulk-create-modifier-groups).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/modifier-groups
    ```

    ## Body Params

    <ParamField body="modifierGroup" type="ModifierGroup" required>

      See the [Item Modifier Group Object](/api-reference/business-solutions/restaurants/menus/items/item-modifier-groups/item-modifier-group-object) for this object's fields.

    <ResponseField name="modifierGroup" type="ModifierGroup">
