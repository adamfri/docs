<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates an upload URL for a data source file.

    Before submitting a job to import data from a file to a collection, call this method to generate an upload URL. Use the `uploadUrl` in the response to upload your source file. For example:

    `curl --request PUT --upload-file "${path_to_file}" "${uploadUrl}"`

    <Note>

    The URL is valid for 15 minutes.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE_MOVEMENT_JOBS">Data Mover Manage Jobs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data-mover/v1/temporary-files/upload-url
    ```

    ## Body Params

    <ParamField body="fileName" type="string">

      Name of uploaded file.

    </ParamField>

    ## Response Object

    <ResponseField name="fileId" type="string">

      File ID.

      Constraints: `maxLength 512`.

    </ResponseField>

    <ResponseField name="uploadUrl" type="string">

      URL to which you can upload the file.

      Constraints: `maxLength 8192`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/data-mover/v1/temporary-files/upload-url' \
          -H 'Authorization: <AUTH>'
      ```

      ```json Response
      {
          "fileId": "temporary-files/1234567.dat",
          "uploadUrl": "http://example.com/temporary-files/1234567.dat"
      }
      ```

    </CodeGroup>

    </div>
