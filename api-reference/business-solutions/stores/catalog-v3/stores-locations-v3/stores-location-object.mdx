---

A location is a physical or virtual site where products are sold.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Stores location ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the Stores location is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the Stores location.

      Ignored when creating a Stores location.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the Stores location was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the Stores location was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="wixLocationId" type="string">

      Wix location ID.
      Learn more about the [Locations API](https://dev.wix.com/docs/api-reference/business-management/locations/introduction).

    </ResponseField>

    <ResponseField name="locationType" type="string">

      Location type.

      **Read-only.**

      **Supported values:**

      - `VIRTUAL` — Online store.
      - `PHYSICAL` — Physical location, for example, POS.

    </ResponseField>

    <ResponseField name="name" type="string">

      Stores location name.

      **Read-only.** Constraints: `minLength 1`, `maxLength 150`.

    </ResponseField>

    <ResponseField name="defaultLocation" type="boolean">

      Whether the location is the site's default location.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "5b0059cf-db7d-4685-a3d3-4e9ae6b2094d",
        "revision": "1",
        "createdDate": "2024-07-08T13:22:05.403Z",
        "updatedDate": "2024-07-08T13:22:05.403Z",
        "wixLocationId": "bbb24f31-c838-4636-84a6-e4f014282867",
        "locationType": "PHYSICAL",
        "name": "Main Street",
        "defaultLocation": false
      }
      ```

    </CodeGroup>
