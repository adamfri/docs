    Cancels an order. The `order.status` field changes to `CANCELED`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/orders/{id}/cancel
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Order ID.

    </ParamField>

    ## Body Params

    <ParamField body="sendOrderCanceledEmail" type="boolean">

      Whether to send an order canceled email to the buyer.

    </ParamField>

    <ParamField body="customMessage" type="string">

      Custom note to be added to the email (optional).

    </ParamField>

    <ParamField body="restockAllItems" type="boolean">

      Whether to restock all items in the order. This will only apply to products in the Wix Stores inventory.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Canceled order.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ORDER_HAS_AUTHORIZED_TRANSACTION` | Order can't be canceled because it has authorized transactions. Void or refund the authorized transactions before canceling the order. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_IS_PENDING` | Order can't be canceled because its status is `PENDING`. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_IS_REJECTED` | Order can't be canceled because its status is `REJECTED`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Updated | `wix.ecom.v1.order_updated` | Triggered when an order is updated. |
    | Order Canceled | `wix.ecom.v1.order_canceled` | Triggered when an order is canceled. |

    </div>
