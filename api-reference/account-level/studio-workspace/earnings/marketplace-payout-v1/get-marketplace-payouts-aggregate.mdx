    Retrieves the total amount, in USD, and count of marketplace payouts matching the provided filter.

    The totals cover exactly the payouts the filter matches, including `REJECTED` ones and reversals. To reproduce the earnings total shown in the Wix Studio dashboard, add `status` not equal to `REJECTED` to the filter. Note that `status` isn't part of the WQL pattern declared for `QueryMarketplacePayouts`, so the same condition can't be used to filter that method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/marketplace/v1/marketplace-payouts/aggregate
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter that selects which marketplace payouts to aggregate. Supports the same fields as `QueryMarketplacePayouts`, plus `status` (for example, `status` not equal to `REJECTED`), which `QueryMarketplacePayouts` doesn't support.

    </ParamField>

    ## Response Object

    <ResponseField name="payoutsTotalAmount" type="number">

      Sum of the `amount` of all matching marketplace payouts, in USD. Reversals (`negative` set to `true`) subtract from the total.

    </ResponseField>

    <ResponseField name="payoutsCount" type="number">

      Number of marketplace payouts matching the filter.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Returns the total amount and count of a partner's marketplace payouts matching a filter, in USD

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/partners/marketplace/v1/marketplace-payouts/aggregate' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        -d '{
          "filter": {
            "transactionDate": {
              "$gte": "2026-05-01T00:00:00.000Z",
              "$lt": "2026-06-01T00:00:00.000Z"
            }
          }
        }'
      ```

      ```json Response
      {
        "payoutsTotalAmount": 199,
        "payoutsCount": 2
      }
      ```

    </CodeGroup>
