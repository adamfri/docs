Triggered when a ticket sale ends. Sales details are not included in the payload.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.events.v3.ticket_definition_sale_ended` |
| Package | `@wix/events` |
| Permissions | `Manage Events - all permissions`, `Manage Orders`, `Manage Ticket Definitions` |
