    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/marketplace/v1/projects/{projectId}
    ```

    ## Path Params

    <ParamField path="projectId" type="string" required>

      ID of the project to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="project" type="Project">

      Retrieved project.

      See the [Project Object](/api-reference/account-level/studio-workspace/marketplace/project-v1/project-object) for this object's fields.

    </ResponseField>
