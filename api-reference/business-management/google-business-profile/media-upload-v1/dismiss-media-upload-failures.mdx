    <div className="wix-ref">

    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Clears a location's failed photo changes, leaving queued ones alone.

    Failures are otherwise kept until the next submission for that location
    replaces them, so this is how a site owner dismisses a photo that's never
    going to succeed.

    `dismissedCount` reports how many were cleared.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/locations/{locationId}/media-uploads/dismiss-failures
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      ID of the location. This is Google's location identifier.

    </ParamField>

    ## Response Object

    <ResponseField name="dismissedCount" type="integer">

      How many failed changes were cleared.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Clears only FAILED items. Anything still PENDING or UPLOADING keeps draining.

    <CodeGroup>

      ```bash Request

      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json'
      ```

      ```json Response
      {
        "dismissedCount": 1
      }
      ```

    </CodeGroup>
