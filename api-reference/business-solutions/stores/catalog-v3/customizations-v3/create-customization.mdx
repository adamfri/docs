    Creates a customization.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CUSTOMIZATION_WRITE">Customization write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/customizations
    ```

    ## Body Params

    <ParamField body="customization" type="Customization" required>

      Customization to create.

      See the [Customization Object](/api-reference/business-solutions/stores/catalog-v3/customizations-v3/customization-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="customization" type="Customization">

      Created customization.

      See the [Customization Object](/api-reference/business-solutions/stores/catalog-v3/customizations-v3/customization-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `OPTIONS_LIMIT_EXCEEDED` | Number of product options exceeded the limit. |
    | `428` | `FAILED_PRECONDITION` | `MODIFIERS_LIMIT_EXCEEDED` | Number of modifiers exceeded the limit. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CUSTOMIZATION_RENDER_TYPE` | Customization type and render type don't match. For example, product options can't have a free text render type. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_FREE_TEXT_SETTINGS` | `maxCharCount` is less than `minCharCount` or exceeds 500. |
    | `400` | `INVALID_ARGUMENT` | `ONLY_SPACES_STRING_ERROR` | Text field contains only spaces. Provide valid text content. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_CHOICE_NAME` | Duplicate choice name found. Each choice name must be unique within the customization. |
    | `400` | `INVALID_ARGUMENT` | `CUSTOMIZATION_WITH_ONLY_ID_OR_CHOICE_IDS` | Customization ID provided without choice IDs or vice versa. Provide both customization ID and choice IDs together. |
    | `400` | `INVALID_ARGUMENT` | `MIXED_CHOICE_IDS_CONSISTENCY` | Some choices have IDs while others don't. All choices must have IDs or none of them can have IDs. |
    | `400` | `INVALID_ARGUMENT` | `ID_NOT_ALLOWED_IN_REQUEST` | Caller doesn't have the required permissions to pass IDs in the request. |
    | `400` | `INVALID_ARGUMENT` | `PRIMARY_CHOICE_SELF_REFERENCE` | Choice references itself in `primaryChoiceIds`. |
    | `400` | `INVALID_ARGUMENT` | `PRIMARY_CHOICE_NOT_FOUND` | `primaryChoiceIds` contains an ID that doesn't match any existing choice in the customization. |
    | `400` | `INVALID_ARGUMENT` | `PRIMARY_CHOICE_HIERARCHY_VIOLATION` | A choice that is a primary of other choices can't also be a linked choice. Only a single level of grouping is supported. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
