    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v2/categories/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      ID of the category to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="category" type="Category">

      Retrieved category.

      See the [Category Object](/api-reference/business-solutions/bookings/services/categories-v2/category-object) for this object's fields.

    </ResponseField>
