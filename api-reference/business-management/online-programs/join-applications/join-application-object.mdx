---
title: "Join Application Object"
description: "A join application tracks a member's request or invitation to join an online program, from application through approval, payment, and enrollment."
icon: "cube"
---

A join application tracks a member's request or invitation to join an online program, from application through approval, payment, and enrollment.

Wix users can invite members, review applications, and manage payment-related activity. Members can apply to join a program, accept invitations, and complete payment when required.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Join application ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time a lifecycle, payment, or tag action changes the join application.

      This API doesn't provide a generic update method, so `revision` is read-only. Don't specify it when creating or changing a join application.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the join application was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the join application was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="memberId" type="string">

      ID of the site member applying or invited to participate in the program.

      Required when a Wix user creates an application on a member's behalf. Automatically set to the caller's member ID when a member creates their own application.

      **Read-only.**

    </ResponseField>

    <ResponseField name="programId" type="string">

      ID of the program the join application is for.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the join application.

      Read-only for member-initiated applications. A Wix user can set the initial status when creating an application on a member's behalf.

      **Read-only.**

      **Supported values:**

      - `INVITED` — Member has been invited to join the program and has not yet accepted.
      - `APPROVAL_PENDING` — Member's application is awaiting the Wix user's decision.
      - `APPROVED` — Application is approved. Payment may still be required before the member is enrolled.
      - `CANCELLED` — Member canceled the application. The join application is removed asynchronously.
      - `DECLINED` — Wix user declined the application. The join application is removed asynchronously.
      - `SUSPENDED` — Connected participant is suspended after the related Pricing Plans subscription expires. A successful new payment resumes the participation flow.

    </ResponseField>

    <ResponseField name="paymentStatus" type="string">

      Payment status of the join application.

      **Read-only.**

      **Supported values:**

      - `NO_PAYMENT_REQUIRED` — Payment isn't required because the program is free or the member has an eligible Pricing Plans entitlement.
      - `PAYMENT_PENDING` — Payment is required before the member can be enrolled.
      - `PAYMENT_IN_PROGRESS` — Payment checkout or a Pricing Plans purchase is in progress.
      - `PENDING_OWNER_APPROVAL` — Member submitted an offline payment that awaits the Wix user's decision.
      - `PAYMENT_SUCCESSFUL` — Payment completed successfully.
      - `PAYMENT_FAILED` — Payment was declined by the payment system or, for an offline payment, by the Wix user.
      - `PAYMENT_CANCELED` — Member canceled payment.

    </ResponseField>

    <ResponseField name="paymentInfo" type="PaymentInfo">

      Wix Payments or Pricing Plans data associated with the join application.

      **Read-only.**

      <Expandable title="paymentInfo properties">

        <ResponseField name="paymentOrderId" type="string">

          Wix Payments order ID. Populated when the member selects one-time payment at checkout.

          **Read-only.**

        </ResponseField>

        <ResponseField name="offlineTransactionId" type="string">

          Offline transaction ID. Populated when the member selects manual payment at checkout.

          **Read-only.**

        </ResponseField>

        <ResponseField name="paidPlanIds" type="string[]">

          IDs of the pricing plans connected to the program. Populated when the member selects Pricing Plans at checkout.

          **Read-only.** Constraints: `format GUID`, `maxItems 100`.

        </ResponseField>

        <ResponseField name="couponId" type="string">

          ID of the coupon applied to the payment order. Populated when a coupon is applied with [Apply Coupon](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/apply-coupon).

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="member" type="Member">

      Snapshot of the member identified by `memberId`, copied from the Members API. It isn't the authoritative member record.

      **Read-only.**

      <Expandable title="member properties">

        <ResponseField name="firstName" type="string">

          Member contact's first name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="lastName" type="string">

          Member contact's last name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="email" type="string">

          Member's login email.

          **Read-only.**

        </ResponseField>

        <ResponseField name="contactId" type="string">

          Member's contact ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="nickname" type="string">

          Member's nickname.

          **Read-only.**

        </ResponseField>

        <ResponseField name="profileImageUrl" type="string">

          URL of the member's profile image.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="participantId" type="string">

      ID of the participant created from the join application.

      Populated when `status` is `APPROVED` and `paymentStatus` is `NO_PAYMENT_REQUIRED` or `PAYMENT_SUCCESSFUL`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the join application object.

      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags for categorizing and organizing join applications.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, typically restricted from site members and visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="publicTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="publicTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
