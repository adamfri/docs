    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/schedule/{itemId}
    ```

    ## Path Params

    <ParamField path="itemId" type="string" required>

      Schedule item ID.

    </ParamField>

    ## Query Params

    <ParamField query="eventId" type="string">

      Event ID to which the schedule item belongs.

    </ParamField>

    <ParamField query="includeDraft" type="boolean">

      Whether to include draft schedule items in the response.

    </ParamField>

    <ResponseField name="item" type="ScheduleItem">

    </ResponseField>
