With the Reviews API you can manage reviews for a site's services, content, or products. The review entity contains the content of the review, a rating score, and information about the author. Learn more about [Wix Reviews](fallback::https://support.wix.com/en/article/wix-stores-adding-and-setting-up-wix-reviews).

The Wix Reviews API allows you to:

- Import reviews from other sites and export reviews to other sites.
- Retrieve and display positive review data.
- Retrieve data on negative reviews, allowing you to respond effectively.
- Use the [Media API](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) to retrieve related review media.

## Moderation

If moderation is turned on, reviews are checked for content that requires moderation. If moderation is required, reviews remain as pending until a Wix user rejects or approves them in the site's [dashboard](fallback::https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Freviews/pending). 
A Wix user can configure moderation settings in the site's [dashboard](fallback::https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Freviews/settings/moderation). Learn more about [managing reviews](fallback::https://support.wix.com/en/article/wix-stores-managing-wix-reviews).

## Before you begin
It's important to note the following points before starting to code:

- The Reviews API is currently only available with the `"stores"` namespace.
- Every review needs a contact. To check whether a contact exists, you can call the [Contacts API](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/contacts/contacts/contact-v4/query-contacts) with the author's email address.
- A review author is limited to 1 review per entity. Duplicate reviews receive an error response.

## Terminology

- **Entity**: The entity to review. For example, a Wix Stores product.  
- **Namespace**: The Wix service that the Reviews API is integrated with. Currently only Wix Stores is supported.
- **Rating**: The rating score for the review item. An author can give a rating score between 1 and 5. The rating displays with the site review.  
- **Helpfulness**: Helpfulness is the overall helpfulness score calculated by subtracting `foundUnhelpful` from `foundHelpful` in a review. Site visitors can indicate whether a review was helpful or not.  
- **Reply**: A direct reply to a review. The reply displays with the review.
