Docs for Folder in Media

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Folder ID. Generated when a folder is created in the Media Manager.

      Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Folder name as it appears in the Media Manager.

      Constraints: `maxLength 1000`.

    </ResponseField>

    <ResponseField name="parentFolderId" type="string">

      ID of the folder's parent folder. &lt;br /> Default: `media-root` folder.

      Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date the folder was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date the folder was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="state" type="string">

      State of the folder.

      **Read-only.**

      **Supported values:**

      - `OK`
      - `DELETED`

    </ResponseField>

    <ResponseField name="siteId" type="string">

      Site ID the folder belongs to.

      **Read-only.** Constraints: `maxLength 100`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "60baab4a44554097bf1f56370df245f2",
        "displayName": "empty folder",
        "parentFolderId": "media-root",
        "createdDate": "2022-08-30T17:21:03Z",
        "updatedDate": "2022-08-30T17:21:03Z",
        "state": "OK"
      }
      ```

    </CodeGroup>
