    <div className="wix-ref">

    Retrieves the status of the contact image upload process.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v5/contacts/{contactId}/image-upload/{imageUploadId}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact whose image upload status to retrieve.

    </ParamField>

    <ParamField path="imageUploadId" type="string" required>

      The upload ID of the image upload process. Returned when an image URL is provided while creating or updating a contact, or from [Generate Contact Image Upload Url](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/generate-contact-image-upload-url).

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      The status of the image upload process.

      **Supported values:**

      - `IN_PROGRESS` — Image upload is in progress.
      - `SUCCESS` — Image is uploaded.
      - `FAILURE` — Image upload failed.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `UPLOAD_ID_NOT_FOUND` | Couldn't find an image upload with this `imageUploadId`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

      ```bash Request
      -H 'Authorization: <AUTH>'
      ```

      ```json Response
      {
        "status": "IN_PROGRESS"
      }
      ```
