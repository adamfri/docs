<div className="wix-ref">

Retrieves a list of galleries.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PROGALLERY.READ-GALLERIES">Read Galleries</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`, `MEMBER`, `VISITOR`.

## Endpoint

```http
GET https://www.wixapis.com/pro-gallery/v2/galleries
```

## Query Params

<ParamField query="itemLimit" type="integer">

  Maximum number of media items to return. &lt;br />

  Min: `1` &lt;br />
  Max: `100` &lt;br />
  Default: `10`

</ParamField>

<ParamField query="offset" type="integer">

  Number of galleries to skip in the response. &lt;br />

  Default: `0`

</ParamField>

<ParamField query="limit" type="integer">

  Maximum number of galleries to return. &lt;br />

  Min: `1` &lt;br />
  Max: `10` &lt;br />
  Default: `10`

</ParamField>

## Response Object

<ResponseField name="totalGalleries" type="integer">

  Total number of galleries in the site.

</ResponseField>

<ResponseField name="galleries" type="Gallery[]">

  List of galleries. Sorted by `createdDate`.

  See the [Gallery Object](/api-reference/assets/pro-gallery/gallery-object) for this object's fields.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>

</div>
