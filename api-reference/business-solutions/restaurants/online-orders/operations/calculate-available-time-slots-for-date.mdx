    Retrieves all available time slots of each fulfillment type for the specified date.

    The response includes time slots with delivery fulfillment types only if you specify a delivery address.
    Only fulfillment methods capable of delivering to the specified address are considered when calculating time slot availability.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/operations/v1/operations/{operationId}/available-time-slots-per-date
    ```

    ## Response Object

    <ResponseField name="timeslotsPerFulfillmentType" type="TimeSlotForFulfillment[]">

        </ResponseField>

        <ResponseField name="fulfillmentInfo" type="FulfillmentInfo[]">

            </ResponseField>

            <ResponseField name="freeFulfillmentPriceThreshold" type="string">

            </ResponseField>

            <ResponseField name="address" type="Address">

              Details on the address of the fulfillment.
              For pickup fulfillment types, this is the address to take the order from.

        </ResponseField>

        <ResponseField name="fulfilmentType" type="string">

          Fulfillment type.

          - `PICKUP` — Pickup fulfillment. The customer picks up the order from the restaurant.
          - `DELIVERY` — Delivery fulfillment. The restaurant, or a representative, delivers the order to the customer.

        </ResponseField>

      </Expandable>
