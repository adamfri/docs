    <div className="wix-ref">

    Creates an inventory item.

    The combination of `variantId` and `locationId` must be unique.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INVENTORY_ITEM_WRITE">Inventory write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/inventory-items
    ```

    ## Body Params

    <ParamField body="inventoryItem" type="InventoryItem" required>

      Inventory item to create.

      See the [Inventory Item Object](/api-reference/business-solutions/stores/catalog-v3/inventory-items-v3/inventory-item-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="inventoryItem" type="InventoryItem">

      Created inventory item.

      See the [Inventory Item Object](/api-reference/business-solutions/stores/catalog-v3/inventory-items-v3/inventory-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `ITEM_ALREADY_EXISTS` | There is already an inventory item with this `variant_id` and `location_id`. |
    | `428` | `FAILED_PRECONDITION` | `PRE_ORDER_VALIDATION` | Preorder enabled for a digital product or subscription product. Preorder isn't supported for these product types. |
    | `400` | `INVALID_ARGUMENT` | `REQUESTED_QUANTITY_MUST_BE_NON_NEGATIVE` | Tracked inventory creation attempted with negative `quantity`. Quantity must be non-negative. |
    | `400` | `INVALID_ARGUMENT` | `PREORDER_LIMIT_NOT_SUPPORTED_FOR_UNTRACKED_INVENTORY` | Preorder limit set for untracked inventory. Preorder limits are only supported for tracked inventory. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_BULK_UPSERT_KEY` | The request contains duplicate upsert keys. Each `productId`, `variantId`, and `locationId` combination must be unique after default location resolution. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Inventory Item Created | `wix.stores.catalog.v3.inventory_item_created` | Triggered when an inventory item is created. |
