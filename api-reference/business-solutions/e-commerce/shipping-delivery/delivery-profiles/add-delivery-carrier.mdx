    Adds a delivery carrier to a delivery region.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/delivery-profiles/add-delivery-carrier
    ```

    ## Body Params

    <ParamField body="deliveryRegionId" type="string" required>

      Delivery region ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="deliveryCarrier" type="DeliveryCarrier" required>

      Delivery carrier to add.

      <Expandable title="deliveryCarrier properties">

        <ParamField body="appId" type="string">

          Carrier app ID.

          Get app IDs from the [app dashboard](https://dev.wix.com/dc3/my-apps/), or by calling [List Installed Delivery Carriers](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/list-installed-delivery-carriers).

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="backupRate" type="BackupRate">

          Backup rate to use when the carrier doesn't return a rate for a specific shipping option.

          When `active` is `false` and the carrier doesn't return a rate, the carrier's shipping options aren't shown to customers.

          <Expandable title="backupRate properties">

            <ParamField body="title" type="string">

              Title displayed for the backup rate. For example, `"Standard Shipping"`.

            </ParamField>

            <ParamField body="amount" type="string" required>

              Backup rate amount.

            </ParamField>

            <ParamField body="active" type="boolean">

              Whether the backup rate is active.

              The backup rate is used in the following situations:
              + When `active` is `true`.
              + When the carrier does not return a cost for any reason.

              If active, and no cost is returned by the carrier, the backup rate will be displayed to customers as the shipping option.

              Default: `false`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="additionalCharges" type="AdditionalCharge[]">

          Additional charges to add to the delivery rate. These charges are combined with the carrier's rate into a single shipping cost and itemized in order details.

          Constraints: `maxItems 10`.

          <Expandable title="additionalCharges properties">

            <ParamField body="description" type="string">

              Description of the additional charge. For example, `"Handling fee of $5 applied for gift wrapping"`.

            </ParamField>

            <ParamField body="amount" type="string">

              Additional fixed charge amount to add to the delivery rate. For example, `"12.50"`.

              Constraints: `maxLength 16`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="deliveryProfile" type="DeliveryProfile">

      Updated delivery profile.

      See the [Delivery Profile Object](/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/delivery-profile-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DELIVERY_REGION_NOT_FOUND` | Couldn't find the delivery region. |
    | `409` | `ALREADY_EXISTS` | `CARRIER_ALREADY_EXISTS_IN_REGION` | This delivery carrier is already assigned to the region. |
    | `428` | `FAILED_PRECONDITION` | `DELIVERY_CARRIER_MISSING_BACKUP_RATE` | The delivery carrier requires a `backupRate` to be set. |
    | `428` | `FAILED_PRECONDITION` | `UNKNOWN_DELIVERY_CARRIER` | The specified `appId` doesn't exist. |
    | `400` | `INVALID_ARGUMENT` | `DELIVERY_CARRIER_MISSING_BACKUP_RATE` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | Delivery Profile Updated | `wix.ecom.v1.delivery_profile_updated` | Triggered when a delivery profile is updated. |
