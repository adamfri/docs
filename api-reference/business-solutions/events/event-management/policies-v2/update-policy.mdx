    Updates a policy.

    Each time the policy is updated, `revision` increments by 1. The existing `revision` must be included when updating the policy.
    This ensures you're working with the latest policy and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-POLICIES">Manage Policies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v2/policies/{policy.id}
    ```

    ## Path Params

    <ParamField path="policy.id" type="string" required>

      Policy ID.

    </ParamField>

    ## Body Params

    <ParamField body="policy" type="Policy" required>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Policy ID.

      **Read-only.**

    </ParamField>

    <ParamField body="policy" type="UpdatePolicy" required>

      Policy to update.

      <Expandable title="policy properties">

        <ParamField body="_id" type="string">

          Policy ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the policy is updated.

          To prevent conflicting changes, the current revision must be used when updating a policy.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the policy was created in `yyyy-mm-ddThh:mm:sssZ` format.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the policy was updated in `yyyy-mm-ddThh:mm:sssZ` format.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string" required>

          Policy name that is visible in the dashboard and checkout form.

          Min: 1 character  &lt;br/>
          Max: 40 characters

          Constraints: `minLength 1`, `maxLength 40`.

        </ParamField>

        <ParamField body="body" type="string" required>

          Policy body. Usually contains various terms and conditions.

          Min: 1 character
          Max: 50,000 characters

          &lt;b>Note:&lt;/b> You can format text using various HTML tags such as `<p>`, `<b>`, `<ul>`, etc.

          Constraints: `minLength 1`, `maxLength 50000`.

        </ParamField>

        <ParamField body="eventId" type="string" required>

          ID of the event to which the policy belongs.

          Constraints: `format GUID`, `immutable`.

        </ParamField>

      </Expandable>

    </ParamField>
