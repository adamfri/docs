    Imports multiple existing Google Business Profile locations.

    Specify `id` and `accountId` on every location. This doesn't create listings in
    Google, the same as Create Location.

    Locations are processed independently: one that fails doesn't stop the others,
    and its reason is in that item's `itemMetadata.error`. Check the results
    per item rather than relying on the response status.

    A Google account must be connected first. See the
    [Connection API](https://dev.wix.com/docs/api-reference/business-management/google-business-profile/connection-v1).

    To import a single location, call Create Location.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/bulk/locations/create
    ```

    ## Body Params

    <ParamField body="locations" type="GBPLocation[]" required>

      The locations to record for this site. Set `id` and `accountId` on each.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Gbplocation Object](/api-reference/business-management/google-business-profile/gbplocation-v1/gbplocation-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return each created location in `results.item`. Defaults to
      `false`, which keeps the response small for a large batch.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkCreateLocationResult[]">

      Results in the order the locations were sent. Each carries its own
      `itemMetadata.originalIndex`.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Whether this location was created, and why not if it wasn't.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Provided only whenever possible. For example, `itemId` can't be provided when item creation has failed.

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

              Constraints: `min 0`.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action for this item was successful. When `false`, the `error` field is returned.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="GBPLocation">

          The created location. Returned only when `returnEntity` is `true`.

          See the [Gbplocation Object](/api-reference/business-management/google-business-profile/gbplocation-v1/gbplocation-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      How many locations succeeded and failed.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

          Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

          Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

          Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>
