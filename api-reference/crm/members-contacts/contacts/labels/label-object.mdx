Label that was found or created.

<Tabs>

  <Tab title="REST">

    <ResponseField name="namespace" type="string">

      Label namespace.

      Labels created by calling the Find Or Create Label method
      are automatically assigned to the `custom` namespace.

      **Read-only.**

    </ResponseField>

    <ResponseField name="namespaceDisplayName" type="string">

      Display name for the namespace,
      used to organize the list of labels in the site dashboard.

      **Read-only.**

    </ResponseField>

    <ResponseField name="key" type="string">

      Label key.

      `key` is generated when the label is created.
      It can't be modified, even if `displayName` is updated.

      **Read-only.** Constraints: `minLength 1`, `maxLength 80`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Label display name shown in the dashboard.

      Constraints: `minLength 1`, `maxLength 180`.

    </ResponseField>

    <ResponseField name="labelType" type="string">

      Label type indicating how the label was created.

      **Read-only.**

      **Supported values:**

      - `SYSTEM` — Default system label for the contact list.
      - `USER_DEFINED` — Label created by calling the Find Or Create Label method.
      - `WIX_APP_DEFINED` — Label created by an app built by Wix.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the label was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the label was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "namespace" : "custom",
        "key": "custom.my-label",
        "displayName": "My Label",
        "labelType": "USER_DEFINED",
        "createdDate": "2020-04-20T14:02:20Z",
        "updatedDate": "2020-04-20T14:02:20Z"
      }
      ```

    </CodeGroup>
