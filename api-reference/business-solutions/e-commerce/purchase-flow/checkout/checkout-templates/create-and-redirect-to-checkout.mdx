    Creates a new checkout based on the checkout template and redirects to the new checkout page.

    Before using this method, you must have a checkout template available. Create a checkout template with Create Checkout Template.

    To build a URL that uses this method, follow this format:
    `https://www.wixapis.com/ecom/v1/checkout-templates/{checkoutTemplateId}/create-and-redirect-to-checkout?siteId={siteId}`

    To create a checkout but not automatically redirect to the checkout page, use Create Checkout From Template.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/checkout-templates/{checkoutTemplateId}/create-and-redirect-to-checkout
    ```

    ## Path Params

    <ParamField path="checkoutTemplateId" type="string" required>

      ID of the checkout template to use to create a checkout.

    </ParamField>

    ## Query Params

    <ParamField query="siteId" type="string" required>

      ID of the site associated with the checkout template.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="body" type="bytes" />

    <ResponseField name="statusCode" type="integer" />

    <ResponseField name="headers" type="HeadersEntry[]">

      <Expandable title="headers properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="string" />

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_CREATE_CHECKOUT_FROM_INACTIVE_TEMPLATE` | Checkout template is inactive. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Template Used | `wix.ecom.v1.checkout_template_used` | Triggered when a checkout is created from a checkout template. |
