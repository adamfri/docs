    Retrieves a draft order.

    The retrieved draft order contains the latest calculations:
    + Line items, shipping details, and buyer information.
    + Tax details and price totals.

    <Note>

    When retrieving a committed draft order, it **is not recalculated**.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}
    ```

    ## Path Params

    <ParamField path="draftOrderId" type="string" required>

      Draft order ID.

    </ParamField>
