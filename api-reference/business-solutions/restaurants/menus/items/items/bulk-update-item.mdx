    <Note>

    The Item API only works with the Wix Restaurants Menus app. Make sure you have installed this app from the [Wix App Market](https://www.wix.com/app-market/wix-restaurants-menus-new).

    </Note>

    Updates up to 100 multiple items at once.

    Each time an item is updated, its revision increments by 1. The existing revision must be included when updating item. This ensures you're working with the latest item information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/bulk/items/update
    ```

    import { items } from "@wix/restaurants";

    const itemsToUpdate = [
      {
        item: {

          revision: "3",
          name: "Soft drink",
          priceInfo: {
            price: "2.5"
          }

          priceInfo: {
            price: "7.50"
          }
        }
      }
    ];

    const options = {
      returnEntity: false
    };

    async function bulkUpdateItems() {
      const response = await items.bulkUpdateItems(itemsToUpdate, options);
