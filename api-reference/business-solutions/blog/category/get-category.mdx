    Gets a category with the specified ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v3/categories/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      Category ID.

    </ParamField>

    ## Query Params

    <ParamField query="fieldsets" type="string[]">

      List of additional category fields to include in the response. By default
      only the category’s base fields are returned. Base fields are all category fields that don't appear in the fieldset enum.

      To retrieve a field, pass the relevant fieldset in the enum in the `fieldsets` array. For example, add the `URL` fieldset to `fieldsets` to
      retrieve the url field in the response in addition to the category’s base fields.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes category URL.
      - `SEO` — Includes SEO data.

    </ParamField>

    ## Response Object

    <ResponseField name="category" type="Category">

      Category info.

      See the [Category Object](/api-reference/business-solutions/blog/category/category-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
