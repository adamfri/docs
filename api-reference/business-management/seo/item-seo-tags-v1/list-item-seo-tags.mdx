    Retrieves a list of the items of one type, with their SEO tags.

    Each item reports `hasOverride`, so a single pass shows which items have tags of their
    own and which inherit. Use this to discover the item IDs available on a site.

    Item types are the same on every site. A site without the business solution that
    provides an item type has no items of that type, so this method returns an empty list
    for it.

    Limitation: same as [Get Item SEO
    Tags](https://dev.wix.com/docs/api-reference/business-management/seo/item-seo-tags-v1/get-item-seo-tags) —
    for `STATIC_PAGE`, every item's `tags`, `focusKeywords`, and `resolvedTags` reflect the
    saved revision, never the published one.

    Cursors are opaque, so pass back the one you received rather than constructing or
    storing one.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    This method requires one of the following permission scopes:

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/seo/v1/item-seo-tags/{itemType}
    ```

    ## Path Params

    <ParamField path="itemType" type="string" required>

      Type of item to list tags for. For example, `STATIC_PAGE` or `STORES_PRODUCT`.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Number of items to return per page, and the cursor to continue from.

      Omit the cursor to retrieve the first page.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="itemSeoTags" type="ItemSeoTags[]">

      Retrieved item SEO tags.

      Constraints: `maxItems 200`.

      See the [Item Seo Tags Object](/api-reference/business-management/seo/item-seo-tags-v1/item-seo-tags-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging information, including the cursor to pass to retrieve the next page.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>
