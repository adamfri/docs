    <div className="wix-ref">

    Creates a new tag with the provided label if a tag with the same label doesn't already exist.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v3/tags
    ```

    ## Body Params

    <ParamField body="label" type="string" required>

      Tag label. The label for each tag in a blog must be unique.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    <ParamField body="language" type="string">

      Tag language.

      2-or-4-letter language code in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.

    </ParamField>

    <ParamField body="slug" type="string">

      Preferred tag slug. For example, `'tag-slug'`.

    </ParamField>

    <ParamField body="fieldsets" type="string[]">

      List of additional tag fields to include in the response. For example, use the `URL` fieldset to retrieve the url field in
      the response in addition to the tag's base fields. Base fields don’t include any of the supported fieldset values. By default
      only the tag's base fields are returned.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes Tag URL when present.

    </ParamField>

    ## Response Object

    <ResponseField name="tag" type="Tag">

      Created tag.

      See the [Tag Object](/api-reference/business-solutions/blog/tags/tag-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |

    | Tag Created | `wix.blog.v3.tag_created` | Triggered when a tag is created. |
