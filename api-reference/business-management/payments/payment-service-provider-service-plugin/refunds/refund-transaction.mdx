This endpoint is used to send a merchant's refund requests to a Payment Service Provider (PSP).

Wix calls this endpoint when a merchant initiates a refund from the Wix dashboard. Learn more about [implementing this endpoint](https://dev.wix.com/docs/rest/api-reference/payment-provider-spi/processing-refunds).

## Endpoint

```http
POST /refund
```

## Body Params

<ParamField body="wixTransactionId" type="string" required>

  Wix transaction ID.

  Constraints: `format GUID`.

</ParamField>

<ParamField body="wixRefundId" type="string" required>

  Refund ID.

  Constraints: `format GUID`.

</ParamField>

<ParamField body="pluginTransactionId" type="string" required>

  PSP transaction ID.

</ParamField>

<ParamField body="merchantCredentials" type="object" required>

  Credentials that the PSP provided when the merchant connected their account.

  Constraints: `format map`.

  <Expandable title="merchantCredentials properties">

    <ParamField body="key" type="string" />

    <ParamField body="value" type="string" />

  </Expandable>

</ParamField>

<ParamField body="refundAmount" type="string">

  Total amount to refund in a currency’s minor units.
  Learn more about [currencies](https://dev.wix.com/docs/rest/business-management/payments/service-plugins/payment-service-provider-service-plugin/currencies).

</ParamField>

<ParamField body="mode" type="string">

  Connection mode. Identifies whether a request is live or for testing purposes.

  **Supported values:**

  - `undefined` — Undefined mode.
  - `live` — Request is live.
  - `sandbox` — Request is for testing purposes.

</ParamField>

<ParamField body="reason" type="string">

  Reason for refund. Defined by the merchant.

  **Supported values:**

  - `DUPLICATE`
  - `FRAUDULENT`
  - `REQUESTED_BY_CUSTOMER`

</ParamField>

<ParamField body="siteId" type="string">

  Wix site ID.

</ParamField>

## Response Object

<ResponseField name="pluginRefundId" type="string">

  PSP refund ID.

</ResponseField>

<ResponseField name="reasonCode" type="integer">

  Wix [reason code](https://dev.wix.com/docs/rest/api-reference/payment-provider-spi/reason-codes#all-apis_provider-platform_reason-codes_refund-declined) indicating a failed request.

</ResponseField>

<ResponseField name="errorCode" type="string">

  PSP-specific error code.

</ResponseField>

<ResponseField name="errorMessage" type="string">

  PSP-specific error message.

</ResponseField>

<ResponseField name="status" type="string" deprecated>

  This field is deprecated.

  **Deprecated.** This field is deprecated.

  **Supported values:**

  - `APPROVED`
  - `PENDING`
  - `CANCELED`
  - `DECLINED`

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
