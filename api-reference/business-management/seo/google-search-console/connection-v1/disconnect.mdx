    Removes the site's Google Search Console connection.

    Wix deletes the stored Google credentials for the site. This does not
    remove the site's `google-site-verification` tag (see the GSC Site Readiness API's Clear
    Verification), does not change anything in the connected Google account,
    and does not revoke the grant on Google's side. The account owner can
    revoke it from their Google account settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gsc/v1/disconnect
    ```

    ## Response Object

    Returns `DisconnectResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CONNECTION_NOT_FOUND` | No stored Google credentials exist for this site. It was never connected, or is already disconnected. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_RESOLVED` | The site could not be resolved from the request context. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
