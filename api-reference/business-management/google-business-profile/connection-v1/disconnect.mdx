    Removes the site's Google Business Profile connection.

    Wix deletes the stored Google credentials. This does not change anything in
    the customer's Google Business Profile account, and it does not revoke the
    grant on Google's side — the site owner can do that from their Google
    account settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/connection/v1/connection:disconnect
    ```

    ## Response Object

    Returns `DisconnectResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CONNECTION_NOT_FOUND` |  |
    | `428` | `FAILED_PRECONDITION` | `MULTIPLE_CONNECTIONS_NOT_REPRESENTABLE` | The singleton premise ("a site has at most one Google connection") can stop holding if multi-connection mode is enabled for a site. These RPCs report it rather than acting on an arbitrary connection. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
