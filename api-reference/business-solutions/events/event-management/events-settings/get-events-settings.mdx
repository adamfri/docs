    <div className="wix-ref">

    Retrieves the current events settings for a site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/settings
    ```

    ## Query Params

    <ParamField query="fields" type="string[]">

      Settings categories to include in the response. If omitted, returns only basic settings for performance optimization. Use this to request specific information like premium features or payment settings.

      Constraints: `maxItems 11`.

      **Supported values:**

      - `SITE_INFO` — Returns site information including locale, language, and available premium features that determine Events capabilities.
      - `EVENTS_INFO` — Returns Events-related information like first event creation status and current ticket sales flags.
      - `SERVICE_FEE_SETTINGS` — Returns Wix service fee configuration, activation status, and agreement dates.
      - `PAYMENT_SETTINGS` — Returns available payment methods, delayed capture settings, and payment acceptance configuration.

    </ParamField>

    ## Response Object

    <ResponseField name="eventsSettings" type="EventsSettings">

      The Events Settings object containing the requested configuration and status information.

      See the [Events Settings Object](/api-reference/business-solutions/events/event-management/events-settings/events-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
