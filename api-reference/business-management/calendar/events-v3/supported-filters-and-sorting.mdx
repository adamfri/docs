## Filtering

The following table shows field support for filters for the
[event object](fallback::https://dev.wix.com/docs/rest/business-management/calendar/events-v3/event-object)
in [Query Events](fallback::https://dev.wix.com/docs/rest/business-management/calendar/events-v3/query-events).

| Field                    | Supported Filters                              |
|--------------------------|------------------------------------------------|
| `appId`                  | `eq`, `in`                                     |
| `scheduleId`             | `eq`, `in`                                     |
| `externalScheduleId`     | `eq`, `in`                                     |
| `type`                   | `eq`, `in`                                     |
| `recurringEventId`       | `eq`, `in`                                     |
| `transparency`           | `eq`                                           |
| `location`               | `exists`                                       |
| `location.type`          | `eq`, `in`                                     |
| `location.id`            | `eq`, `in`                                     |
| `resources.id`           | `hasSome`, `hasAll`                            |
| `resources.type`         | `hasSome`, `hasAll`                            |
| `resources.scheduleId`   | `hasSome`, `hasAll`                            | 
| `resources.transparency` | `hasSome`, `hasAll`                            |
| `totalCapacity`          | `eq`, `ne`, `gt`, `lt`, `gte`, `lte`, `exists` |
| `remainingCapacity`      | `eq`, `ne`, `gt`, `lt`, `gte`, `lte`           |
| `participants.total`     | `eq`, `ne`, `gt`, `lt`, `gte`, `lte`           |
| `conferencingDetails`    | `exists`                                       |

To learn about working with _Query_ endpoints in general, see
[API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language).

## Sorting

By default, the response in [Query Events](fallback::https://dev.wix.com/docs/rest/business-management/calendar/events-v3/query-events)
is sorted by `event.start` object in ascending order. You can also sort by
end date in descending order.

| Field   | Order  |
|---------|--------|
| `start` | `ASC`  |
| `end`   | `DESC` |
