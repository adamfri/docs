    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the highest receipt number currently in use (the sequential identifier displayed between the prefix and suffix in receipt display numbers).
    Can be filtered by prefix.

    Receipt numbering is managed in the Receipts Settings API.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/receipts/v1/receipts/get-latest-number
    ```

    ## Query Params

    <ParamField query="prefix" type="string">

      Receipt prefix to filter by.

    </ParamField>

    ## Response Object

    <ResponseField name="number" type="integer">

      Receipt number.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Returns latest number for a given prefix

    <CodeGroup>

      ```bash Request
      curl -X GET \
        'https://www.wixapis.com/receipts/v1/receipts/get-latest-number' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        -d '{
          "prefix": "NY-"
        }'
      ```

      ```json Response
      {
        "number": 10
      }
      ```

    </CodeGroup>
