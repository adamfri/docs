The JSON object below defines the configuration for this service plugin extension. How you supply values depends on the framework you’re using:

+ **Self-hosted apps:** After adding a service plugin extension to your app in the app dashboard, provide configuration details in your extension's page. Learn more about how to add and configure a self-hosted service plugin extension with [REST](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/self-hosting/supported-extensions/backend-extensions/add-self-hosted-service-plugin-extensions-with-rest) or the [SDK](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/self-hosting/supported-extensions/backend-extensions/add-self-hosted-service-plugin-extensions-with-the-sdk).
+ **CLI apps:** Customize the configuration in your extension's [`<extension-name>.extension.ts`](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-cli/supported-extensions/backend/service-plugins/service-plugin-extension-files-and-code#service-plugin-builder) file.

<Tabs>

  <Tab title="REST">

    <ResponseField name="deploymentUri" type="string">

      Base URI which Wix eCommerce will call to access Catalog service plugin endpoints. For example, to call the Get Catalog Items endpoint at `https://my-external-catalog.com/get-catalog-items`, the base URI you provide here is `https://my-external-catalog.com`.

    </ResponseField>

    <ResponseField name="allItemsDiscount" type="AllItemsDiscountConfig">

      Configuration details for discounts applied to all items in the catalog.

      <Expandable title="allItemsDiscount properties">

        <ResponseField name="enabled" type="boolean">

          Whether the discount is enabled.

          Default: `false`.

        </ResponseField>

        <ResponseField name="name" type="string">

          Translatable name for "all items discount" in the catalog.
          For example, for restaurant menus, this could be "All dishes".

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="specificItemsDiscount" type="SpecificItemsDiscountConfig">

      Configuration details for discounts applied to specific items in the catalog.

      <Expandable title="specificItemsDiscount properties">

        <ResponseField name="enabled" type="boolean">

          Whether the discount is enabled.

          Default: `false`.

        </ResponseField>

        <ResponseField name="name" type="string">

          Translatable name for "all items discount" in the catalog.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="supportedPurchaseTypes" type="string[]">

      The purchase types this catalog's items support (one-time and/or subscription).
      Used by the discount-rule editor to offer only the purchase-type options relevant to this catalog.
      An empty list means no restriction is declared and all purchase types are offered.

      **Developer Preview.**

      **Supported values:**

      - `ONE_TIME` — The item can be bought as a one-time purchase.
      - `SUBSCRIPTION` — The item can be purchased as a subscription.

    </ResponseField>

  </Tab>
