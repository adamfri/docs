The Functions API allows you to create, access, and manage functions. Use this API together with other [Wix Functions APIs](fallback::https://dev.wix.com/docs/api-reference/business-management/functions/about-wix-functions-apis).

With the Functions API, you can:

- Create, update, and delete the fundamental function objects that serve as containers for custom business logic.
- Search, filter, and retrieve functions to understand your site's custom functionality landscape.
- Manage function names, descriptions, and other properties that help organize and identify custom logic.

## Functions in the Wix Functions ecosystem
A function is the main entity in the Wix Functions ecosystem. All other entities and APIs are used to create functions or to define their behavior. However, without the other entities in the ecosystem, a function is just an empty object.

## Function creation

You can call [Create Function](fallback::https://dev.wix.com/docs/api-reference/business-management/functions/functions/create-function) to create a function, but you'll need to handle its logic and configuration separately using different APIs. To create a function with all its dependencies in a single call, call [Create Function Production](fallback::https://dev.wix.com/docs/api-reference/business-management/functions/function-productions/create-function-production) or [Create Function Builderless Production](fallback::https://dev.wix.com/docs/api-reference/business-management/functions/builderless-productions/create-function-builderless-production). Learn more about [function creation](fallback::https://dev.wix.com/docs/api-reference/business-management/functions/about-function-creation-and-activation#quick-creation-and-configuration).
