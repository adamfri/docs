    Lists all bulk downloads available for the user that initiated them.
    By default, response is sorted by `updatedDate` in descending order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/get-paid/v1/bulk-downloads
    ```

    ## Query Params

    <ParamField query="namespace" type="string" required>

      Namespace of the app to download from.

      **Supported values:**

      - `UNKNOWN_NAMESPACE` — Unknown namespace.
      - `RECEIPTS` — Receipts ([SDK](https://dev.wix.com/docs/sdk/backend-modules/get-paid/receipts/about-the-receipts-apis) | [REST](https://dev.wix.com/docs/rest/business-management/get-paid/receipts/about-the-receipts-apis)).

    </ParamField>

    ## Response Object

    <ResponseField name="bulkDownloads" type="BulkDownload[]">

      Retrieved bulk downloads.

      See the [Bulk Download Object](/api-reference/business-management/get-paid/bulk-downloads/bulk-download-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `PERMISSION_DENIED` | Caller doesn't have permissions. |
    | `404` | `NOT_FOUND` | `USER_ID_NOT_FOUND` | User identification ID is missing. |
    | `400` | `INVALID_ARGUMENT` | `NAMESPACE_NOT_SUPPORTED` | Calling this method with this namespace isn't supported. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
