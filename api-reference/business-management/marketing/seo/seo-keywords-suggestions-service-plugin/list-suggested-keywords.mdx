    This method requests keyword suggestions for a specified phrase.
    You provide statistical data about the requested keyword and a list of similar keywords
    so the user can compare the SEO strength of the suggested keywords.

    Wix calls this method when a Wix user requests data about a keyword via the SEO page of the Dashboard.

    ## Endpoint

    ```http
    POST /v1/list-suggested-keywords
    ```

    ## Body Params

    <ParamField body="keyword" type="string">

      Keyword to analyze for SEO strength.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="countryCode" type="string">

      Specific country for analysis.

      2-letter country code in
      [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements)
      format.

      Constraints: `format COUNTRY`.

    </ParamField>

    ## Response Object

    <ResponseField name="data" type="SuggestedKeywords[]">

      Analysis of the keyword.

      <Expandable title="data properties">

        <ResponseField name="keyword" type="string">

          *Required**. Keyword suggestions offered by the SEO tool.

          Constraints: `maxLength 256`.

        </ResponseField>

        <ResponseField name="volume" type="integer">

          *Required**. Average number of searches per month for the keyword.

        </ResponseField>

        <ResponseField name="difficulty" type="integer">

          *Required**. Indicates how competitive the keyword is and how difficult to rank in an organic search. A higher difficulty means the keyword has a lower search ranking. &lt;br>
          Min: `1` &lt;br>
          Max: `100`

          Constraints: `min 1`, `max 100`.

        </ResponseField>

        <ResponseField name="latestTrends" type="number[]">

          *Required**. Trends in searches for the keyword per month over the last 12 months.

          Must include exactly 12 values.

          Typically, the trend values represent the number of searches relative to the peak search volume.

          A value of `1.0` represents the highest search volume for the term. A value of `0.50` means that there were half as many searches. &lt;br>
          Min: `0.0` &lt;br>
          Max: `1.0`

          Constraints: `min 0`, `max 1`, `minItems 12`, `maxItems 12`.

        </ResponseField>

        <ResponseField name="searcherIntent" type="string[]">

          User's reason for searching for the keyword.

          Constraints: `maxItems 4`.

          **Supported values:**

          - `COMMERCIAL` — Users searched for specific brands or services, usually with an intent to purchase.
          - `INFORMATIONAL` — Users searched for information about a topic.
          - `NAVIGATIONAL` — Users searched for a specific page, site, or physical location.
          - `TRANSACTIONAL` — Users searched to perform a transaction, for example a purchase.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="quota" type="Quota">

      Updated quota after request processed.

      <Expandable title="quota properties">

        <ResponseField name="remaining" type="integer">

          *Required**. Number of searches left until the end of the current quota cycle.

        </ResponseField>

        <ResponseField name="limit" type="integer">

          *Required**. Total number of searches available in the current quota cycle.

        </ResponseField>

        <ResponseField name="startDate" type="datetime">

          *Required**. Start date and time of the current quota cycle as UTC datetime in `YYYY-MM-DDThh:mm[:ss][.sss]Z` format.

        </ResponseField>

        <ResponseField name="endDate" type="datetime">

          *Required**. End date and time of the current quota cycle as UTC datetime in `YYYY-MM-DDThh:mm[:ss][.sss]Z` format.
          After this time, the quota is reset

        </ResponseField>

        <ResponseField name="paidPlan" type="boolean">

          *Required**. Whether the user currently has a paid plan.
          If `false`, the user is offered an upgrade using the `upgradeUrl` from the configuration.

        </ResponseField>

      </Expandable>

    </ResponseField>
