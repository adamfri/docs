    Sets a new active slug for the service.

    The call fails if at least one of these conditions is met:
    - The slug doesn't adheres to the supported format.
    - Another service is currently using the slug.
    - Another service has used the slug in the past.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/{serviceId}/slugs/custom
    ```

    ## Path Params

    <ParamField path="serviceId" type="string" required>

      ID of the service for which to update the active slug.

    </ParamField>

    ## Body Params

    <ParamField body="slug" type="string">

      Slug to set as the active service slug.

      Constraints: `maxLength 500`.

    </ParamField>

    ## Response Object

    <ResponseField name="slug" type="Slug">

      Updated active service slug.

      <Expandable title="slug properties">

        <ResponseField name="name" type="string">

          The unique part of service's URL that identifies the service's information page. For example, `service-1` in `https:/example.com/services/service-1`.

          Constraints: `maxLength 500`.

        </ResponseField>

        <ResponseField name="custom" type="boolean">

          Whether the slug was generated or customized. If `true`, the slug was customized manually by the business owner. Otherwise, the slug was automatically generated from the service name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the slug was created. This is a system field.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="service" type="Service">

      Updated service.

      See the [Service Object](/api-reference/business-solutions/bookings/services/services-v2/service-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `SLUG_ALREADY_EXISTS` | Another service is already using this slug. |
    | `400` | `INVALID_ARGUMENT` | `SLUG_CONTAINS_ILLEGAL_CHARACTERS` | Slug contains invalid characters. Use only lowercase letters, numbers, and hyphens. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Service Updated | `wix.bookings.services.v2.service_updated` | Triggered when a service is updated. |
