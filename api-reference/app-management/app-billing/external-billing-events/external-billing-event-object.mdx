---
title: "External Billing Event Object"
description: "The External Billing Event object in the Wix External Billing Event API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="appId" type="string">

      The app ID linked to this transaction. This field is only relevant if using an API key for authorization,
      in which case you're required to pass the app ID.

    </ResponseField>

    <ResponseField name="instanceId" type="string">

      The app instance ID linked to this transaction. This field is only relevant if using an API key for authorization,
      in which case you can optionally pass the instance ID.

      This connects the transaction to a specific instance of your app installed on a Wix site.
      Learn more [about app instances](https://dev.wix.com/docs/build-apps/develop-your-app/access/app-instances/about-app-instances).

    </ResponseField>

    <ResponseField name="grossRevenue" type="string">

      The total amount of the transaction in USD, not including tax.
      This value can be negative for refunds or adjustments.

      Example: "120.50" for a $120.50 charge, or "-120.50" for a $120.50 refund.

      Constraints: `format DECIMAL_VALUE`.

    </ResponseField>

    <ResponseField name="netRevenue" type="string">

      The amount charged in USD minus agreed-upon expenses, such as shipping fees or
      payment processing fees. Wix subtracts its share from this amount.
      The value can be negative for refunds.

      Example calculation:
      - Gross revenue: $120.50
      - Minus expenses: $20.00 (shipping)
      - Net revenue: $100.50

    </ResponseField>

    <ResponseField name="wixShare" type="string">

      Wix's share of the transaction in USD, taken from the net revenue.
      This value can be negative, such as for adjustments or refunds.

      Calculate based on your Partner Agreement terms. For example, if Wix's share is 20%:
      - Net revenue: $100.50
      - Wix share (20%): $20.10

      Important: Update this value if your revenue share percentage changes.

      Constraints: `format DECIMAL_VALUE`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      The date and time of the transaction.

    </ResponseField>

    <ResponseField name="billingType" type="string">

      The type of billing event, either charge or refund.

      **Supported values:**

      - `CHARGE`
      - `REFUND`

    </ResponseField>

  </Tab>
