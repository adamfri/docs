## SDK package

```bash
npm install @wix/identity
```

Import the `authentication` namespace from `@wix/identity`.

## Methods

<CardGroup cols={2}>

  <Card title="Register V 2" href="/api-reference/business-management/headless/authentication/register-v-2">
    POST Registers a new member.
  </Card>
  <Card title="Login V 2" href="/api-reference/business-management/headless/authentication/login-v-2">
    POST Logs in an existing member.
  </Card>
  <Card title="Change Password" href="/api-reference/business-management/headless/authentication/change-password">
    POST Changes the password of a logged-in member.
  </Card>
  <Card title="Sign On" href="/api-reference/business-management/headless/authentication/sign-on">
    POST Authenticates a member without credentials and returns a session token.
  </Card>
  <Card title="Logout" href="/api-reference/business-management/headless/authentication/logout">
    GET Terminates the member's session and clears authentication cookies.
  </Card>
