    Updates multiple order payments with a specified status.

    This method only updates the payment records. It doesn't interact with the payment provider or move any funds.

    <Note>

    + Payments that fail validation are reported in `results[i].itemMetadata.error`, while the remaining payments are updated.
    + Gift card and membership payments only support the `APPROVED` and `VOIDED` statuses.

    </Note>

    To update the status of a single payment, call [Update Payment Status](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/update-payment-status).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/bulk/payments/update-payment-transaction-status
    ```
