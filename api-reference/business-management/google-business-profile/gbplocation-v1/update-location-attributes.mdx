    Sets or deletes attributes on a location's Business Profile.

    Only the attributes you specify are affected. Attributes you don't mention are
    left as they are, so you don't need to resend the whole set.

    Whether an attribute is set or deleted depends on `valueJson`:

    - Specify `valueJson` to set the attribute to that value. It takes Google's
    attribute value JSON, for example `{"valueType":"BOOL","values":[true]}` or
    `{"valueType":"URL","uriValues":[{"uri":"https://example.com"}]}`. Use the
    bare attribute key in `attributeId`, such as `has_wifi`.
    - Leave `valueJson` empty to delete the attribute.

    There's no flag for clearing everything: to delete several attributes, send one
    entry per attribute with `valueJson` empty. To delete all of them, first
    retrieve the location's attributes with Get Location Attributes, then send one
    empty entry per attribute you get back. At least one entry is always required,
    and a request carries at most 50, so a location with more than 50 attributes
    needs more than one call.

    Call List Attribute Metadata to find which attributes a location supports and
    what value type each one takes.

    Errors:
    - `INVALID_VALUE_JSON`: a `valueJson` isn't valid Google attribute JSON. The
    response says which entries were wrong, by index and attribute ID. This is
    checked before anything else, so nothing is changed.
    - `NOT_FOUND`: the location isn't recorded for this site. Google isn't called.
    - `GOOGLE_API_CALL_FAILED`: the call to Google failed. Google's status and
    response are in the error payload.

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    ## Body Params

    <ParamField body="attributes" type="LocationAttribute[]" required>

      The attributes to set or delete, keyed by `attributeId`.

      Only the attributes you name are touched. Every other attribute on the
      listing is left alone. An entry with a `valueJson` sets that attribute, and
      an entry with an empty `valueJson` deletes it.

      Constraints: `minItems 1`, `maxItems 50`.

      <Expandable title="attributes properties">

        <ParamField body="attributeId" type="string">

          Attribute key without the "attributes/" prefix (e.g. "has_wifi",
          "accepts_credit_cards"). The prefix Google requires on the wire is applied
          for you.

          Constraints: `maxLength 255`.

        </ParamField>

        <ParamField body="valueJson" type="string">

          The attribute's value, as the JSON object Google expects, for example
          `{"valueType":"BOOL","values":[true]}` or
          `{"valueType":"URL","uriValues":[{"uri":"https://..."}]}`.

          Passed through as-is, so its shape has to match what the attribute accepts.
          Call List Attribute Metadata to find out what that is.

          On Update Location Attributes, leaving this empty deletes the attribute from
          the location. On a response, and on Get Location Attributes, it's always
          set.

          Constraints: `maxLength 4096`.

        </ParamField>

      </Expandable>

    </ParamField>
