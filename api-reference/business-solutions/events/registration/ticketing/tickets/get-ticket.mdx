    <div className="wix-ref">

    Retrieves a ticket by unique ticket number.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-GUEST-LIST">Read Event Tickets and Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/tickets/{ticketNumber}
    ```

    ## Path Params

    <ParamField path="ticketNumber" type="string" required>

      Unique ticket number.

    </ParamField>

    ## Query Params

    <ParamField query="eventId" type="string">

      Event ID to which the ticket belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="fieldset" type="string[]">

      Set of fields to return in the response. See [Fieldsets](https://dev.wix.com/api/rest/wix-events/wix-events/fieldset#wix-events_wix-events_fieldset_ticket-fieldset).

      Constraints: `maxItems 20`.

      **Supported values:**

      - `GUEST_DETAILS` — Include guest details in the ticket response.
      - `TICKET_DETAILS` — Include ticket details in the ticket response.
      - `GUEST_FORM` — Include individual guest form in the ticket response.

    </ParamField>

    ## Response Object

    <ResponseField name="ticket" type="Ticket">

      Ticket.

      See the [Ticket Object](/api-reference/business-solutions/events/registration/ticketing/tickets/ticket-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
