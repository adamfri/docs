    Creates an unsubscribe link to be shared with the relevant recipient.

    If someone clicks the **Unsubscribe** button on the confirmation page,
    the recipient's `subscriptionStatus` is changed to `UNSUBSCRIBED`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MANAGE.EMAIL-SUBSCRIPTIONS">Manage Email Subscriptions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/email-subscriptions/unsubscribe-link
    ```

    ## Body Params

    <ParamField body="emailAddress" type="string" required>

      Email address the unsubscribe link is for.

      Constraints: `format EMAIL`.

    </ParamField>

    <ParamField body="metadata" type="object">

      Arbitrary parameters for closing-the-loop.

      Constraints: `format map`.

      <Expandable title="metadata properties">

        <ParamField body="key" type="string" />

        <ParamField body="value" type="string" />

      </Expandable>

    </ParamField>

    <ParamField body="language" type="string">

      Language for displaying unsubscribe confirmation page.

      2-letter language code in [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) format.

      Default: `EN`

    </ParamField>

    ## Response Object

    <ResponseField name="link" type="string">

      The unsubscribe link.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
