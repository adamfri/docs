  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a function.

    Each time the function is updated,
    `revision` increments by 1.
    The existing `revision` must be passed when updating the function.
    This ensures you're working with the latest version of the function
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/functions/v1/functions/{function.id}
    ```

    ## Path Params

    <ParamField path="function.id" type="string" required>

      Function ID.

    </ParamField>

    ## Body Params

    <ParamField body="function" type="Function" required>

      Function to update.

      See the [Function Object](/api-reference/business-management/functions/functions/function-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="function" type="Function">

      Updated function.

      See the [Function Object](/api-reference/business-management/functions/functions/function-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    | Function Updated | `wix.functions.v1.function_updated` | Triggered when a function is updated. |

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Function ID.

      **Read-only.**

    </ParamField>

    <ParamField body="function" type="UpdateFunction" required>

      Function to update.

      <Expandable title="function properties">

        <ParamField body="_id" type="string">

          Function ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the function is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the function.

          Ignored when creating a function.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the function was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the function was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="functionExtensionId" type="string">

          ID of the function type that defines when and how the function runs. This is the function type that the function is based on.

        </ParamField>

        <ParamField body="functionName" type="string">

          Display name for the function in the dashboard's function builder.

        </ParamField>

        <ParamField body="activationStatus" type="string">

          Activation status.

          **Read-only.**

          **Supported values:**

          - `ACTIVE` — Function is active and runs when triggered.
          - `INACTIVE` — Function is inactive and doesn't run when triggered.
          - `DRAFT` — Function is saved but has never been activated.

        </ParamField>

        <ParamField body="appId" type="string">

          ID of the Wix app that defines the function type that the function is based on.

        </ParamField>

        <ParamField body="functionExtensionName" type="string">

          Display name of the function type.

        </ParamField>

        <ParamField body="functionTemplateExtensionId" type="string">

          ID of the function template used to create this function.

        </ParamField>

        <ParamField body="formTemplateExtensionId" type="string">

          ID of the form template used to create this function. Included if the function was created using the [Builderless Productions](https://dev.wix.com/docs/api-reference/business-management/functions/builderless-productions/introduction) API.

        </ParamField>

        <ParamField body="hasUnpublishedChanges" type="boolean">

          Whether the function has changes that were made since it was last activated.

        </ParamField>

        <ParamField body="tags" type="Tags">

          Tags assigned to the function for organization and filtering.

          <Expandable title="tags properties">

            <ParamField body="privateTags" type="TagList">

              Tags that require an additional permission in order to access them, typically restricted from site members and visitors.

              _Nested structure omitted for brevity — see the `TagList` object._

            </ParamField>

            <ParamField body="publicTags" type="TagList">

              Tags that are exposed to anyone with access to the entity, including site members and visitors.

              _Nested structure omitted for brevity — see the `TagList` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
