Aggregated AI Site-Chat statistics for a site.

Statistics include daily KPI rows for recent activity and period KPI rows for comparison windows, such as the last 30 days and the previous 30 days.

## SDK package

```bash
npm install @wix/assistant-stats
```

Import the `statistics` namespace from `@wix/assistant-stats`.
