    Retrieves a list of menus given the provided paging, filtering, and sorting. Up to 500 menus can be returned per request.

    To learn how to query menus, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$in`, `$nin`, `$eq`, `$ne` | None |
    | `sectionIds` | `$hasSome` | None |
    | `name` | `$startsWith`, `$in`, `$nin`, `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `description` | `$startsWith`, `$in`, `$nin`, `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `urlQueryParam` | `$startsWith`, `$in`, `$nin`, `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$gt`, `$gte`, `$lt`, `$lte`, `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$gt`, `$gte`, `$lt`, `$lte`, `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `visible` | `$eq`, `$ne` | None |

    ## Permissions

    This method requires one of the following permission scopes:
