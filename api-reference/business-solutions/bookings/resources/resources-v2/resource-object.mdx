---
title: "Resource Object"
description: "A resource represents an entity, such as a room or a staff member, that can be scheduled for use in a booking."
icon: "cube"
---

A resource represents an entity, such as a room or a staff member, that can be
scheduled for use in a [booking](https://dev.wix.com/docs/rest/business-solutions/bookings/bookings/about-the-bookings-apis).
The availability of a resource is tracked to ensure that it
can be allocated at a requested time slot and to prevent double bookings.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Resource ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the resource is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the resource.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Name of the resource.

    </ResponseField>

    <ResponseField name="typeId" type="string">

      ID of the [resource type](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resource-types-v2/introduction).

      Once a type has been set it can't be modified. You can create a resource
      without specifying a type. However, customers can't book such resources.

    </ResponseField>

    <ResponseField name="workingHoursSchedules" type="WorkingHoursSchedules">

      Information about the [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction)
      specifying the working hours and locations of the resource.

      Resources without a working hour schedule are available 24/7 at the locations
      specified in the field `locationOptions`.
      When both `workingHoursSchedules` and `locationOptions` are set,
      `workingHoursSchedules` takes precedence.

      <Expandable title="workingHoursSchedules properties">

        <ResponseField name="values" type="WorkingHoursSchedule[]">

          Schedules specifying the working hours of the resource. Currently, only a single schedule is supported.

          Constraints: `maxItems 1`.

          <Expandable title="values properties">

            <ResponseField name="scheduleId" type="string">

              ID of the working hour [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction).

            </ResponseField>

            <ResponseField name="shared" type="boolean">

              Whether the schedule is shared by multiple resources or unique for this resource.

              Default: `false`

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="locationOptions" type="LocationOptions">

      Information about the location where the resource is available.

      <Expandable title="locationOptions properties">

        <ResponseField name="availableInAllLocations" type="boolean">

          Whether the resource is available in all [business locations](https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/about-service-locations#location-types).

          - `true`: The resource is available in all business locations.
          - `false`: The resource is available only in specific locations.

          Default: `false`

        </ResponseField>

        <ResponseField name="specificLocationOptions" type="SpecificLocation">

          Details of resource availability in specific locations.

          <Expandable title="specificLocationOptions properties">

            <ResponseField name="availableInBusinessLocations" type="boolean">

              Whether the resource is available in [business locations](https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/about-service-locations#location-types).

              - `true`: The resource is available in business locations.
              - `false`: The resource isn't available in business locations.

              Default: `false`

            </ResponseField>

            <ResponseField name="businessLocations" type="BusinessLocation[]">

              Information about the business locations where the resource is available.
              Not returned, if the resource is available in either all business locations
              or in no business location.
              You can specify up to 100 business locations.

              Constraints: `maxItems 100`.

              <Expandable title="businessLocations properties">

                <ResponseField name="locationId" type="string">

                  ID of the business [location](https://dev.wix.com/docs/rest/business-management/locations/introduction).

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="eventsSchedule" type="EventsSchedule">

      Schedule containing the [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
      for which the resource has been booked.

      **Read-only.**

      <Expandable title="eventsSchedule properties">

        <ResponseField name="scheduleId" type="string">

          ID of the event [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction).

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extensions enabling users to save custom data related to the resource.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "resource": {
          "id": "ffedf9dc-932d-439f-b1f4-e42b2a5a8bb5",
          "revision": "1",
          "createdDate": "2024-11-22T13:36:47.104Z",
          "updatedDate": "2024-11-22T13:36:47.104Z",
          "name": "Meeting room with conference system",
          "typeId": "dd7790c7-f3ac-4821-accb-52ed385fd932",
          "locationOptions": {
            "availableInAllLocations": false,
            "specificLocationOptions": {
              "availableInBusinessLocations": true,
              "businessLocations": [
                {
                  "locationId": "1295e5ff-ecb3-41bc-8b6f-7345792e5ec0"
                }
              ]
            }
          },
          "eventsSchedule": {
            "scheduleId": "e263b1ca-a1e9-45bf-a39c-044e97c63500"
          }
        }
      }
      ```

    </CodeGroup>
