    Sets up [Wix Meetings](https://dev.wix.com/docs/api-reference/business-solutions/meetings/introduction) infrastructure on a site.

    Use this method to provision the required components for Wix Meetings when building an app
    that relies on Meetings functionality for customers who may not have the Meetings app installed.

    Provisioning creates:
    - A [headless OAuth client](https://dev.wix.com/docs/go-headless/self-managed-headless/authentication/oauth/create-a-client-for-authentication-with-oauth) named `WixMeetings` with `applicationType: SYSTEM` and `technology: REACT`.
    - A [booking form](https://dev.wix.com/docs/api-reference/business-solutions/bookings/wix-forms-integration#booking-forms) using the `wix.meetings.form` namespace.
    - A default [booking policy](https://dev.wix.com/docs/api-reference/business-solutions/bookings/policies/booking-policies/introduction) with cancellation enabled and a 24-hour cancellation window.
    - A default [schedule](https://dev.wix.com/docs/api-reference/business-management/calendar/schedules-v3/introduction) with 30-minute meeting duration.
    - A default [service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/introduction) (scheduling link) of type `APPOINTMENT` with the Wix Meetings `appId`.

    This method is idempotent. Calling it multiple times on the same site
    has no additional effect if the infrastructure already exists.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MEETINGS.MANAGE_OWN">Manage Personal Scheduling, Forns & submissions, (can create his own staff)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/meetings/v1/provision-meetings-app
    ```

    ## Response Object

    <ResponseField name="meetingsProvisioning" type="MeetingsProvisioning">

      The Wix Meetings infrastructure provisioned on the site.

      See the [Provisioning Object](/api-reference/business-solutions/meetings/provisioning-v1/provisioning-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `FAILED_TO_CREATE_DEFAULT_FORM` | Default booking form for Wix Meetings couldn't be created. |
    | `500` | `INTERNAL` | `FAILED_TO_CREATE_OAUTH_APP` | Headless OAuth client for Wix Meetings couldn't be created. |
    | `500` | `INTERNAL` | `FAILED_TO_CREATE_POLICY` | Default booking policy for Wix Meetings couldn't be created. |
    | `500` | `INTERNAL` | `FAILED_TO_CREATE_DEFAULT_SERVICE` | Default service (scheduling link) for Wix Meetings couldn't be created. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
