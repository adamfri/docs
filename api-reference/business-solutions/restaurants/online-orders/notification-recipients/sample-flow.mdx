## Manage restaurant notification recipients

A restaurant chain needs to set up and maintain notification systems across multiple locations. This involves creating initial recipients when locations are established and updating the recipient list as staff changes occur.

To manage restaurant notification recipients:

1. Create the primary recipient by calling [Create Recipient](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/wix-restaurants-new/online-orders/notification-recipients/create-recipient) with the restaurant manager's details:

   ```json
   {
     "recipient": {
       "phone": "+1-555-987-6543",
       "businessLocationIds": ["abd8c787-62b1-49f1-93c6-bfbab87ed966"],
       "channels": ["PHONE"],
       "tags": {
         "publicTags": {
           "tagIds": ["manager", "evening-shift"]
         }
       },
       "note": "Restaurant Manager - Primary Contact"
     }
   }
   ```

2. Query existing recipients when staff changes occur by calling [Query Recipients](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/wix-restaurants-new/online-orders/notification-recipients/query-recipients) to find recipients by location:

   ```json
   {
     "query": {
       "filter": {
         "businessLocationIds": {
           "$in": ["abd8c787-62b1-49f1-93c6-bfbab87ed966"]
         }
       }
     }
   }
   ```

3. Update recipient information by calling [Update Recipient](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/wix-restaurants-new/online-orders/notification-recipients/update-recipient) when staff roles or contact details change:

   ```json
   {
     "recipient": {
       "id": "12345678-1234-1234-1234-123456789012",
       "phone": "+1-555-987-6543",
       "channels": ["PHONE", "SMS"]
     }
   }
   ```

4. Remove recipients by calling [Delete Recipient](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/wix-restaurants-new/online-orders/notification-recipients/delete-recipient) when staff members leave the restaurant.
