---
title: "Llms Txt Object"
description: "The Llms Txt object in the Wix Llms Txt API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="content" type="string">

      CFull text content of the `llms.txt` file.

      Constraints: `maxLength 720000`.

    </ResponseField>

    <ResponseField name="default" type="boolean">

      Whether this `llms.txt` file uses Wix's default content.

    </ResponseField>

    <ResponseField name="subdomain" type="string">

      Target subdomain for the `llms.txt` file (for example, 'www', 'es', 'fr'). Default: 'www'

      Constraints: `maxLength 63`.

    </ResponseField>

    <ResponseField name="hidden" type="boolean">

      Whether the llms.txt file should be hidden from public access.

      **Read-only.**

    </ResponseField>

    <ResponseField name="manuallyEdited" type="boolean">

      Whether the content was manually edited by the user. If `true` in DB, update/append requests must also set `manually_edited=true` or they'll be rejected with `FAILED_PRECONDITION`.

    </ResponseField>

    <ResponseField name="detectedLanguage" type="string">

      ISO 639-1 language code detected for the site (e.g. en, fr). Used to localize the MCP documentation section when serving llms.txt.

      Constraints: `maxLength 2`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "llmsTxt": {
              "content": "# My Portfolio\n\n> A designer showcasing client work.\n\n## AI Agent Access\n\nThis site is powered by Wix and supports the Model Context Protocol (MCP) for agentic AI access.",
              "default": false,
              "subdomain": "www",
              "detectedLanguage": "en"
          }
      }
      ```

    </CodeGroup>
