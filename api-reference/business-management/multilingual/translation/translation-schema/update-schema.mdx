    <div className="wix-ref">

    Updates a translation schema.

    To remove a field, pass the field key with an empty object as the value. For example:

    ```json
    {
    "fields": {
    "title": {}
    }
    }
    ```

    <Warning>

    Removing a schema field makes the corresponding content field unavailable.

    </Warning>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_SCHEMA">Wix Multilingual - Translation Schema Write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/translation-schema/v1/schemas/{schema.id}
    ```

    ## Path Params

    <ParamField path="schema.id" type="string" required>

      Translation schema ID.

    </ParamField>

    ## Body Params

    <ParamField body="schema" type="Schema" required>

      Translation schema to update.

      See the [Schema Object](/api-reference/business-management/multilingual/translation/translation-schema/schema-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="schema" type="Schema">

      Updated Schema.

      See the [Schema Object](/api-reference/business-management/multilingual/translation/translation-schema/schema-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    <Warning>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_SCHEMA">Wix Multilingual - Translation Schema Write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Method Declaration

    ```typescript
    import { translationSchemas } from '@wix/multilingual';

    translationSchemas.updateSchema(_id, schema): Promise<Schema>
    ```

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Translation schema ID.

      **Read-only.**

    </ParamField>

    <ParamField body="schema" type="UpdateSchema" required>

      Translation schema to update.

      <Expandable title="schema properties">

        <ParamField body="_id" type="string">

          Translation schema ID.

          **Read-only.**

        </ParamField>

        <ParamField body="key" type="SchemaKey">

          Translation schema unique key identifier.

          <Expandable title="key properties">

            <ParamField body="appId" type="string">

              ID of the app that created the schema.

              **Read-only.** Constraints: `format GUID`.

            </ParamField>

            <ParamField body="entityType" type="string">

              A unique name defined by the app developer to differentiate translation schemas for various entities within their app. For example, if an app developer is creating a translation schema for blog posts, the `entityType` can be `'blog-posts'`.

              Constraints: `minLength 1`, `maxLength 100`, `immutable`.

            </ParamField>

            <ParamField body="scope" type="string">

              Scope of the translation schema.

              Constraints: `immutable`.

              **Supported values:**

              - `GLOBAL` — Global schema for all sites.
              - `SITE` — Custom schema for a specific site.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="fields" type="object">

          List of fields for the translation schema. This property uses a string to map to a `SchemaField` (`Map<string, SchemaField>`). The string serves as a key, which you'll need to access each field in the schema and when adding translation content.

          Constraints: `format map`, `minItems 1`, `maxItems 1000`.

          <Expandable title="fields properties">

            <ParamField body="key" type="string" />

            <ParamField body="value" type="SchemaField">

              _Nested structure omitted for brevity — see the `SchemaField` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="previewFields" type="PreviewFields">

          Fields displayed in content previews. For example, a product name for a product translation schema.

          <Expandable title="previewFields properties">

            <ParamField body="titleFieldId" type="string">

              ID of the field representing the schema's title.

            </ParamField>

            <ParamField body="imageFieldId" type="string">

              ID of the field representing the schema's image.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="hidden" type="boolean">

          Whether the translation schema is hidden from the site.

          Default: `false`

        </ParamField>

        <ParamField body="displayName" type="string">

          Translation schema name displayed in the [Translation Manager](https://support.wix.com/en/article/wix-multilingual-using-the-translation-manager).

        </ParamField>

        <ParamField body="parentId" type="string">

          A reference to the parent schema. For example, if the schema is for a menu item,
          this property would contain the schema ID of the menu it belongs to.

          Required when `require_parent_entity` is set to `true`.

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the schema is updated. To prevent conflicting changes, the existing `revision` must be used when updating a schema.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the translation schema was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the translation schema was updated.

          **Read-only.**

        </ParamField>

        <ParamField body="duplicateContent" type="boolean">

          Whether to duplicate the translated content when a site containing the translation schema and content is duplicated.

          Default: `false`

        </ParamField>

        <ParamField body="schemaGroupId" type="string">

          Indicate if this schema should be grouped under a custom group in the Translation Manager
          For more info about this field check dev-center extension `Multilingual Schema Group`

        </ParamField>

        <ParamField body="requireParentEntity" type="boolean">

          Whether content created or updated with this schema must include a `parent_entity_id`.
          When set to `true`, any Create Content or Update Content call targeting this schema
          will fail if `parent_entity_id` is missing or empty.

          The schema itself must also have a `parent_id` defined, otherwise the schema
          Create or Update call will fail with `SchemaRequireParentEntityWithoutParentIdException`.

          Default: `false`

          Example: A "menu-item" schema that always belongs to a "menu" parent schema would set
          `require_parent_entity = true` and `parent_id` to the "menu" schema ID. Every translation
          content item created for "menu-item" must then specify which menu it belongs to via
          `parent_entity_id`.

        </ParamField>

      </Expandable>

    </ParamField>
