The following table shows field support for filters and sorting for the form schema object:

| Field                                               | Supported Filters                                                              | Sortable |
|-----------------------------------------------------|--------------------------------------------------------------------------------| -------- |
| `id`                                                | `$eq`, `$ne`, `$in`, `$nin`                                                    | Sortable |
| `namespace`                                         | `$eq`, `$ne`, `$in`, `$nin`                                                    | Sortable |
| `createdDate`                                       | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$gt`, `$lt`, `$le`, `$ge`, `$nin` | Sortable |
| `updatedDate`                                       | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$gt`, `$lt`, `$le`, `$ge`, `$nin` | Sortable |
| `name`                                              | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`                                     | Sortable |
| `enabled`                                           | `$eq`, `$ne`                                                                   | Sortable |
