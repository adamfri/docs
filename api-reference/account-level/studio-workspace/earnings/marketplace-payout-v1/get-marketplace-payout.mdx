    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/marketplace/v1/marketplace-payouts/{marketplacePayoutId}
    ```

    ## Path Params

    <ParamField path="marketplacePayoutId" type="string" required>

      ID of the marketplace payout to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="marketplacePayout" type="MarketplacePayout">

      Retrieved marketplace payout.

      See the [Marketplace Payout Object](/api-reference/account-level/studio-workspace/earnings/marketplace-payout-v1/marketplace-payout-object) for this object's fields.

    </ResponseField>
