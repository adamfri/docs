A benefit item is a reference to a product, service, or reward hosted by another app which beneficiaries can redeem as part of a benefit.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Benefit item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the benefit item is updated.
      To prevent conflicting changes, the current revision must be passed when updating the benefit item.

      Ignored when creating a benefit item.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the item was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="externalId" type="string">

      ID of the item in the app providing it.

      For example, if the item is a product provided by Wix Stores, the `externalId` would be the Wix Stores `product Id`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="category" type="string">

      Benefit item category.

      **Read-only.**

    </ResponseField>

    <ResponseField name="itemSetId" type="string">

      Item set ID of the benefit that this benefit item is a part of.

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Benefit item display name.

    </ResponseField>

    <ResponseField name="providerAppId" type="string">

      ID of the [app](https://dev.wix.com/docs/rest/articles/getting-started/apps-created-by-wix) that defines and provides the item. For example, if the item is a Wix Stores product, this field's value is `215238eb-22a5-4c36-9e7b-e7c08025e04e`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the benefit item object.
      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      **Read-only.**

    </ResponseField>

      ```json Object
          "extended_fields": null,
          "namespace": "example_namespace"
        }
      }
      ```
