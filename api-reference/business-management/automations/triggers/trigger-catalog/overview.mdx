## SDK package

```bash
npm install @wix/automations
```

Import the `triggerCatalog` namespace from `@wix/automations`.

## Methods

<CardGroup cols={2}>

  <Card title="Create Trigger" href="/api-reference/business-management/automations/triggers/trigger-catalog/create-trigger">
    POST Creates a trigger for the specified app.
  </Card>
  <Card title="Get Trigger" href="/api-reference/business-management/automations/triggers/trigger-catalog/get-trigger">
    GET Retrieves a trigger by ID (changes per component version).
  </Card>
  <Card title="Update Trigger" href="/api-reference/business-management/automations/triggers/trigger-catalog/update-trigger">
    PATCH Updates the specified trigger for the specified app.
  </Card>
  <Card title="Delete Trigger By App Id And Key" href="/api-reference/business-management/automations/triggers/trigger-catalog/delete-trigger-by-app-id-and-key">
    DELETE Deletes a trigger from the specified app.
  </Card>
  <Card title="Get Trigger By App Id And Key" href="/api-reference/business-management/automations/triggers/trigger-catalog/get-trigger-by-app-id-and-key">
    GET Retrieves a trigger by app ID and trigger key.
  </Card>
  <Card title="Query Triggers" href="/api-reference/business-management/automations/triggers/trigger-catalog/query-triggers">
    POST Retrieves a list of triggers, given the provided paging, filtering, and sorting.
  </Card>
  <Card title="Resolve Triggers" href="/api-reference/business-management/automations/triggers/trigger-catalog/resolve-triggers">
    POST Retrieves the triggers available on the current site.
  </Card>
  <Card title="Get Trigger Dynamic Schema" href="/api-reference/business-management/automations/triggers/trigger-catalog/get-trigger-dynamic-schema">
    POST Retrieves a trigger's payload schema with the user's filter field selections applied.
  </Card>
  <Card title="Get Identities Schema" href="/api-reference/business-management/automations/triggers/trigger-catalog/get-identities-schema">
    POST Retrieves the schema of the identity types that triggers can reference.
  </Card>

</CardGroup>
