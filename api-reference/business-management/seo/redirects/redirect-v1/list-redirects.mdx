    Retrieves every redirect on the site.

    The response isn't paged and the method takes no filter or sort, so filter the returned list on
    your side. A site with no redirects returns an empty list.

    A redirect that Wix created on the site owner's behalf, such as when a page's URL slug is
    renamed in the editor, is returned alongside the ones created through this API.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/seo-redirects-service/v1/redirects
    ```

    ## Response Object

    <ResponseField name="redirects" type="Redirect[]">

      Retrieved redirects.

      Includes redirects that Wix created on the site owner's behalf, such as when a page's URL slug
      is renamed in the editor. Empty when the site has no redirects.

      See the [Redirect Object](/api-reference/business-management/seo/redirects/redirect-v1/redirect-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
