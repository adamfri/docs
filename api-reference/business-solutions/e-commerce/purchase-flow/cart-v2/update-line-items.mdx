    Updates line items in the cart.

    Use this endpoint to update line item properties such as `quantity` and `selectedMembership`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2">Write Carts V2</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/{cartId}/update-line-items
    ```

    ## Path Params

    <ParamField path="cartId" type="string" required>

      Cart ID.

    </ParamField>

    ## Body Params

    <ParamField body="lineItems" type="LineItemUpdate[]">

      Line item updates to apply to the cart.

      Constraints: `minItems 1`, `maxItems 300`.

      <Expandable title="lineItems properties">

        <ParamField body="lineItemId" type="string" required>

          Line item ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="quantity" type="QuantityUpdate">

          Quantity update. If omitted, quantity isn't updated.

          <Expandable title="quantity properties">

            <ParamField body="newQuantity" type="integer" required>

              New quantity for the line item.

              Constraints: `min 1`, `max 100000`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="selectedMembership" type="SelectedMembershipUpdate" deprecated>

          Selected membership update. If omitted, membership isn't updated.

          DEPRECATED — migrate to `membership_payment`.

          **Deprecated.** Use `membership_payment` instead. Removal: 2026-06-22.

          <Expandable title="selectedMembership properties">

            <ParamField body="newMembership" type="SelectedMembership">

              New `selectedMembership` for the line item.

              Pass an empty value to remove the current membership without selecting a new one.

              _Nested structure omitted for brevity — see the `SelectedMembership` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="membershipPayment" type="MembershipInput">

          Membership payment update. If omitted, the membership payment isn't updated.

          Specify an empty value to remove the current membership without selecting a new one.

          **Developer Preview.**

          <Expandable title="One of the following">

            <ParamField body="membership" type="membership">

              membership

              _Nested structure omitted for brevity — see the `membership` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_LINE_ITEM_UPDATES` | No line item updates were provided. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_LINE_ITEM_UPDATES` | The same line item appears more than once in the update request. |
    | `428` | `FAILED_PRECONDITION` | `CART_ALREADY_ORDERED` | Cart was already placed as an order. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEM_NOT_FOUND_IN_CART` | Couldn't find the line item in the cart. |
    | `400` | `INVALID_ARGUMENT` | `ITEM_NOT_FOUND_IN_CATALOG` | One or more items weren't found in the catalog. |
    | `428` | `FAILED_PRECONDITION` | `INSUFFICIENT_INVENTORY` | Insufficient inventory for one or more items. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_MEMBERSHIP_PAYMENT_OPTION` | The membership payment option is invalid. |
    | `400` | `INVALID_ARGUMENT` | `PLAN_LINE_ITEM_NOT_FOUND` | A future membership references a plan line item that wasn't found in the cart. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Cart Updated | `wix.ecom.v2.cart_updated` | Triggered when a cart is updated. |

    </div>
