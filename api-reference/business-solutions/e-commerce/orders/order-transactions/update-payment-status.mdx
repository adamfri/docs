    Updates the status of an order's payment.

    This method only updates the payment record. It doesn't interact with the payment provider or move any funds.

    <Note>

    + To issue a refund and update the payment status to refunded, use [Refund Payments](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-billing/refund-payments) in the Order Billing API instead.
    + Gift card and membership payments only support the `APPROVED` and `VOIDED` statuses.
    + The order's `paymentStatus` is recalculated asynchronously after the call.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/payments/{paymentId}/orders/{orderId}/update-payment-transaction-status
    ```

    ## Path Params

    <ParamField path="orderId" type="string" required>

      Order ID.

    </ParamField>

    <ParamField path="paymentId" type="string" required>

      Payment ID.

    </ParamField>

    ## Body Params

    <ParamField body="status" type="string">

      Payment status.

      **Supported values:**

      - `UNDEFINED`
      - `APPROVED`
      - `PENDING`
      - `PENDING_MERCHANT`
      - `CANCELED`
      - `DECLINED`
      - `REFUNDED`
      - `PARTIALLY_REFUNDED`
      - `AUTHORIZED`
      - `VOIDED`

    </ParamField>

    ## Response Object

    <ResponseField name="orderTransactions" type="OrderTransactions">

      Order ID and its associated transactions after update.

      See the [Order Transactions Object](/api-reference/business-solutions/e-commerce/orders/order-transactions/order-transactions-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:

Contains the ID of the updated order and details of its associated transactions, as well as IDs of the updated payments and refunds. |
    | Order Transactions Details Updated | `wix.ecom.v1.order_transactions_details_updated` | Triggered when a payment or refund is added to an order, or when an existing payment is updated. Contains the ID of the updated order and details of its associated transactions, as well as IDs of the updated payments and refunds. |
