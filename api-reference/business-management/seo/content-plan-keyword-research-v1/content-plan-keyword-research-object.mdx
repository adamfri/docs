A keyword research item is one target keyword in a site's content plan,
together with the search data behind it and the page it belongs to.

The content plan pipeline generates a set of these for a site. A site owner
can then refine them, and the blog post briefs are built from the result.

Items are grouped into clusters. Each site page has one main keyword, marked
by `primary`, and the other keywords in that cluster support it.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Keyword research item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="keyword" type="string">

      The keyword itself.

      An update is rejected if the new keyword is longer than 80 characters, or
      if it duplicates another keyword in the same research.

    </ResponseField>

    <ResponseField name="pageId" type="string">

      ID of the site page the keyword is assigned to.

    </ResponseField>

    <ResponseField name="itemType" type="string">

      Type of the site page the keyword is assigned to, such as a static
      page or a blog post.

    </ResponseField>

    <ResponseField name="pageUrl" type="string">

      URL of the site page the keyword is assigned to.

    </ResponseField>

    <ResponseField name="competition" type="integer">

      How hard it is to rank for the keyword, on a scale where a higher
      number means more competition.

      Recalculated when `keyword` changes, even if you don't name this field
      in the field mask.

    </ResponseField>

    <ResponseField name="searchVolume" type="integer">

      Estimated number of searches for the keyword per month.

      Recalculated when `keyword` changes, even if you don't name this field
      in the field mask.

    </ResponseField>

    <ResponseField name="pageDeleted" type="boolean">

      Whether the site page this keyword is assigned to has been deleted.

      A keyword assigned to a deleted page stays in the research.

    </ResponseField>

    <ResponseField name="primary" type="boolean">

      Whether this keyword is the main keyword for its page.

      A page has a single main keyword, and the other keywords in its cluster
      support it.

    </ResponseField>

    <ResponseField name="clusterName" type="string">

      Name of the cluster that groups this keyword with the others covering
      the same topic.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "keywordResearch": {
          "id": "8c14e7d0-2a63-4b9f-91d5-7ae0c3f28b64",
          "keyword": "best coffee beans home brewing",
          "pageId": "c1f83b57",
          "itemType": "STATIC_PAGE",
          "pageUrl": "https://www.example.com/shop/coffee-beans",
          "competition": 42,
          "searchVolume": 2900,
          "pageDeleted": false,
          "primary": true,
          "clusterName": "coffee beans"
        }
      }
      ```

    </CodeGroup>
