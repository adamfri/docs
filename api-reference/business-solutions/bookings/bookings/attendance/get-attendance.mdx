    Retrieves attendance information.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-SENSITIVE">Read Bookings - Including Participants</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/attendance/{attendanceId}
    ```

    ## Path Params

    <ParamField path="attendanceId" type="string" required>

      ID of the attendance object to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="attendance" type="Attendance">

      Retrieved attendance.

      See the [Attendance Object](/api-reference/business-solutions/bookings/bookings/attendance/attendance-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ATTENDANCE_NOT_FOUND` | Couldn't find the attendance record. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
