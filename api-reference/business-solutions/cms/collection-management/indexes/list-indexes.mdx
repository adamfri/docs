    <div className="wix-ref">

    Lists all indexes defined for a data collection.

    When an index's status is `ACTIVE`, it is ready to use.
    While it is still being created, its status is `BUILDING`.

    When an index's status is `DROPPED`, it has been dropped successfully.
    While it is still in the process of being removed, its status is `DROPPING`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.INDEXES-MANAGE">Manage Data Indexes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v2/indexes
    ```

    ## Query Params

    <ParamField query="dataCollectionId" type="string" required>

      ID of the data collection for which to list indexes.

      Constraints: `maxLength 1024`.

    </ParamField>

    <ParamField query="paging" type="Paging">

      Paging options to limit and skip the number of items.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="indexes" type="Index[]">

      List of all indexes for the requested data collection.

      See the [Index Object](/api-reference/business-solutions/cms/collection-management/indexes/index-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="PagingMetadata">

      Paging metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
