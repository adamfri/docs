    Regenerates the story drafts for a marketing activity, leaving its post drafts unchanged.

    Generation is asynchronous. The response returns a transient snapshot; regeneration continues
    in the background. Poll [Get Marketing Activity Posts](https://dev.wix.com/docs/api-reference/business-management/marketing/marketing-plan/marketing-plan-v1/get-marketing-activity-posts) to check
    when the new stories are ready.

    If the activity has no story draft, nothing is regenerated and the returned snapshot is final.
    This method never creates a story that was not already planned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan/regenerate-marketing-activity-stories
    ```

            <ResponseField name="type" type="string">

              Item format. The `type` and the content set in `data` must match a combination supported by the item's `channel.name`:

              - Instagram: `POST` with `instagramPost`, or `STORY` with `instagramStory`.
              - Facebook: `POST` with `facebookPost`, `REEL` with `facebookReel`, or `STORY` with `facebookStory`.
              - YouTube: `VIDEO` with `youtubeVideo`, or `SHORT` with `youtubeShort`.
              - LinkedIn: `POST` with `linkedinPost`.
              - X (Twitter): `POST` with `twitterPost`. Deprecated: No longer functional as of July 31, 2026.
              - Pinterest: `POST` with `pinterestPost`.
              - Google Business Profile: `POST` with `gbpPost`.
              - TikTok: `POST` with `tiktokPhoto`, or `VIDEO` with `tiktokVideo`.

              **Supported values:**

              - `POST` — A standard post.
              - `REEL` — A short-form vertical video reel.
              - `VIDEO` — A video.
              - `SHORT` — A short-form vertical video.
              - `STORY` — A story that's available for a limited time.

            </ResponseField>

            <ResponseField name="status" type="string">

              Current status of the item in its lifecycle.

              **Read-only.**

              - `SCHEDULED` — Scheduled to be published at a future date.
              - `CANCELED` — Scheduling was canceled before the item was published.
              - `FAILED` — Publishing failed.
              - `DELETED` — Deleted.
              - `PROCESSING` — Publishing is in progress.
              - `DRAFT` — Saved as a draft, not yet published.
              - `IN_QUEUE` — Queued for publishing as part of a bulk operation.

              Date and time the item was published. Returned only after the item is published.

              **Read-only.**

            </ResponseField>

            <ResponseField name="consumerInfo" type="ConsumerInfo">

              Identifies what created the item.

              Specify `consumerInfo.name` when you create or publish an item, using one stable name for whatever is
              making the call, whether that's an app, an AI agent, or a service of your own. An item created without
              it is stored with an empty name, and the name can't be added later, because Update Item doesn't change
              it. See
              [Identifying what created an item](https://dev.wix.com/docs/api-reference/business-management/marketing/social-media/item-v1/introduction#identifying-what-created-an-item).

            <ResponseField name="referenceId" type="string">

              Caller-defined reference that uniquely identifies the item. Can be used to prevent duplicate publishing: an attempt to publish a second item with the same `referenceId` fails. Can also be used as a UTM campaign ID.

              Aggregated analytics for the site, attributed to traffic from this post.

              _Nested structure omitted for brevity — see the `SiteAnalytics` object._

              Creation and update dates, returned for draft items.

            <ResponseField name="suggested" type="boolean">

              Whether the item was generated as an AI suggestion.

              Whether the item is a post created natively on the social channel rather than published through Wix.

              **Read-only.**

              _Nested structure omitted for brevity — see the `PublicationErrorDetails` object._

              Set per channel.

              ID of the item this item was derived from, when publishing produced several items
              from one. Currently set only by `PublishMultiStoryDraft`, which splits a multi-media

              originating draft's ID here. Lets a consumer re-correlate the new items with whatever
              it had recorded against the original draft, which no longer exists after the split.
              Set by the publisher, never by the caller.

              **Read-only.**

            </ResponseField>

              Current generation status of the video candidate.

              **Supported values:**

              - `IN_PROGRESS` — Video is currently being generated.
              - `FAILED` — Generation failed. Add a new candidate to retry.
              - `READY` — Video is ready. `video_url` is populated.

            </ResponseField>

            <ResponseField name="videoUrl" type="string">

              URL of the generated video. Returned only when `status` is `READY`.

            </ResponseField>

            <ResponseField name="prompt" type="string">

              Prompt used to generate the video.

            </ResponseField>

            <ResponseField name="sourceMediaUrl" type="string">

              URL of the source media used as input for video generation.

            </ResponseField>

            <ResponseField name="itemType" type="string">

              Type of activity content this video was generated for. Either `POST` or `STORY`. Defaults to `POST`.

              - `REEL` — A short-form vertical video reel.

              - `BOOKINGS_SERVICE` — A Wix Bookings service.
              - `STORES_COUPON` — A Wix Stores coupon.
              - `STORES_CATEGORY` — A Wix Stores category.

            </ResponseField>
