    Creates a policy.

    An event may have up to 3 policies.
    Attempts to create more than 3 returns a `"POLICIES_LIMIT_REACHED"` error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-POLICIES">Manage Policies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v2/policies
    ```

    ## Body Params

    <ParamField body="policy" type="Policy" required>

      Policy info.

      See the [Policy Object](/api-reference/business-solutions/events/event-management/policies-v2/policy-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="policy" type="Policy">

      Created policy.

      See the [Policy Object](/api-reference/business-solutions/events/event-management/policies-v2/policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `POLICIES_LIMIT_REACHED` | Number of policies exceeds the server's limit of 3. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
