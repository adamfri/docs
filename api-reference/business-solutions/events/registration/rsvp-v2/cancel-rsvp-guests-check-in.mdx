    Cancels the check-in of RSVP guests.

    If the request body is empty, cancels all check-ins from the RSVP. After the cancellation, the `guests.checkInDate` value becomes empty.

    You can cancel the check-in of up to 11 guests per request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v2/rsvps/{rsvpId}/cancel-check-in
    ```

    ## Path Params

    <ParamField path="rsvpId" type="string" required>

      ID of the RSVP to cancel check-in for.

    </ParamField>

    ## Body Params

    <ParamField body="guestIds" type="integer[]">

      IDs of guests to cancel check-in for.

      Constraints: `min 1`, `minItems 1`, `maxItems 11`.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `DETAILS` — Returns `createdDate`, `updatedDate`, `firstName`, `lastName`, `totalGuests`, `guests`.
      - `FORM` — Returns `form`.
      - `CONTACT_DETAILS` — Returns `email`.

    </ParamField>

    <ParamField body="checkInCanceledDate" type="datetime">

      Optional check-in cancel date. If omitted, runtime timestamp is used.

    </ParamField>

    ## Response Object

    <ResponseField name="rsvp" type="Rsvp">

      Updated RSVP.

      See the [Rsvp Object](/api-reference/business-solutions/events/registration/rsvp-v2/rsvp-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `GUEST_NOT_FOUND` | Couldn't find the guest. |
    | `428` | `FAILED_PRECONDITION` | `GUEST_NOT_CHECKED_IN` | Guest isn't checked in. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Rsvp Updated | `wix.events.v2.rsvp_updated` | Triggered when an RSVP is updated. |
