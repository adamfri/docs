    <div className="wix-ref">

    Retrieves a ribbon by name, or creates a ribbon if one with the passed `ribbonName` doesn't exist.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.RIBBON_WRITE">Ribbon write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/ribbons/get-or-create
    ```

    ## Body Params

    <ParamField body="ribbonName" type="string" required>

      Ribbon name to retrieve or create.

      Constraints: `minLength 1`, `maxLength 30`.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCT_COUNT`

    </ParamField>

    ## Response Object

    <ResponseField name="ribbon" type="Ribbon">

      Ribbon.

      See the [Ribbon Object](/api-reference/business-solutions/stores/catalog-v3/ribbons-v3/ribbon-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
