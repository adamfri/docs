    <div className="wix-ref">

    Deletes a loyalty coupon.

    The deletion of a loyalty coupon does not impact the functionality of the corresponding coupon itself.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/loyalty-coupons/v1/coupons/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the loyalty coupon to delete.

    </ParamField>

    ## Query Params

    <ParamField query="revision" type="number">

      Revision number, which increments by 1 each time the loyalty coupon is updated.

      To prevent conflicting changes, the current `revision` must be passed when updating the loyalty coupon.

    </ParamField>

    ## Response Object

    Returns `DeleteLoyaltyCouponResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Coupon Deleted | `wix.loyalty.v1.coupon_deleted` | Triggered when a loyalty coupon is deleted. |

    </div>
