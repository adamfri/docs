    Imports a file to the Media Manager using an external url.

    Returns information about the imported file.
    Specify the `parentFolderId` and `filePath` parameters to specify which folder you want the file to be imported to.
    If no folder is specified, the file is imported to the `media-root` folder.

    <Note>

    - The `media` property isn't returned in the `files` response object.
    - When you import a file, it's not immediately available, meaning you can't manage or use the file straight away. Learn more about [knowing when a file is ready](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/importing-files#knowing-when-a-file-is-ready).

    </Note>

    To import a file, you need to do one of the following:
    - Specify its [MIME type](https://developer.mozilla.org/en-US/docs/Web/HTTP/Basics_of_HTTP/MIME_types) in the `mimeType` field of the request. For example, `mimeType: 'image/jpeg'`.
    - Specify its extension in either the `displayName` or `url` field of the request. For example, `displayName: 'Example Image.jpeg` or `url: https://www.example.com/image.jpeg`.
    - Ensure the server hosting the file supports HEAD requests. In these cases the Wix servers can retrieve the MIME type from the hosting server.
    <Note>

    If you want to validate the media type, specify the file's expected media type in the optional `mediaType` field of the request.  For example, `mediaType: 'IMAGE'`.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEDIA.MANAGE-MEDIAMANAGER">Manage Media Manager</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-media/v1/files/import
    ```

    ## Body Params

    <ParamField body="url" type="string" required>

      Publicly accessible external file URL.

      Constraints: `format WEB_URL`, `minLength 2`.

    </ParamField>

    <ParamField body="mediaType" type="string">

      Media type of the file to import.
      excluding: OTHER media type

      **Supported values:**

      - `IMAGE`
      - `VIDEO`
      - `AUDIO`
      - `DOCUMENT`
      - `VECTOR`
      - `ARCHIVE`
      - `MODEL3D`
      - `OTHER`

    </ParamField>

    <ParamField body="displayName" type="string">

      File name that appears in the Media Manager.
      The file name is truncated to 255 characters if longer.

    </ParamField>

    <ParamField body="parentFolderId" type="string">

      ID of the file's parent folder. &lt;br />
      This folder is the path root for the `filePath`. &lt;br />
      Default: `media-root`.

    </ParamField>

    <ParamField body="private" type="boolean">

      Whether the file will be public or private. Learn more [about private files](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/private-files).

    </ParamField>

    <ParamField body="labels" type="string[]">

      Labels assigned to media files that describe and categorize them. Provided by the Wix user, or generated by [Google Vision API](https://cloud.google.com/vision/docs/drag-and-drop) for images.

      Constraints: `maxLength 200`, `maxItems 500`.

    </ParamField>

    <ParamField body="mimeType" type="string">

      File mime type.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField body="externalInfo" type="ExternalInfo">

      Information sent to the File Ready and File Failed events. See [Importing Files](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/importing-files) to learn more.

      <Expandable title="externalInfo properties">

        <ParamField body="origin" type="string">

          External information to specify in the File Ready or File Failed events.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="externalIds" type="string[]">

          External IDs to specify in the File Ready or File Failed events.

          Constraints: `maxLength 4000`, `maxItems 30`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="urlParams" type="object">

      Optional parameters that should be sent with the external URL.

    </ParamField>

    <ParamField body="urlHeaders" type="object">

      Optional headers that should be sent with the external URL.

    </ParamField>

    <ParamField body="filePath" type="string">

      Path to the folder where the file will be stored.
      For example, `/videos/2024/december`. &lt;br/>
      If `parentFolderId` is defined, the parent folder is used as the path root. Otherwise, the root is `media-root`.
      The folders in the path will be created if they don't already exist.  &lt;br />

    </ParamField>

    ## Response Object

    <ResponseField name="file" type="FileDescriptor">

      Information about the imported file.

      See the [File Descriptor Object](/api-reference/assets/media/media-manager/files/file-descriptor-object) for this object's fields.

    </ResponseField>
