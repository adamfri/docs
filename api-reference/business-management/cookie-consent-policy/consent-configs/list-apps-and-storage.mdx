    <div className="wix-ref">

    Retrieves a list of installed embedded script apps that are in use on a site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CONSENT_CONFIG.MANAGE">Consent config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bu/legal/v1/site-apps-and-storage
    ```

    ## Response Object

    <ResponseField name="installedEmbedApps" type="AppData[]">

      Apps with embedded scripts installed on the site.

      <Expandable title="installedEmbedApps properties">

        <ResponseField name="consentConfigId" type="string">

          Consent config ID.

        </ResponseField>

        <ResponseField name="name" type="string">

          App name.

        </ResponseField>

        <ResponseField name="appId" type="string">

          App ID.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="version" type="string">

          App version.

        </ResponseField>

        <ResponseField name="componentId" type="string">

          Component ID.

        </ResponseField>

        <ResponseField name="consentCategory" type="string">

          Consent category for compliance with privacy regulations.

          **Supported values:**

          - `UNKNOWN_CATEGORY`
          - `essential` — Includes core functionality such as security, verification of identity and network management. These cookies can’t be disabled.
          - `functional` — Includes collecting data to remember choices users make to improve and give a more personalised experience.
          - `analytics` — Includes tracking visitor interactions with a site, to discover errors and provide better overall analytics.
          - `advertising` — Includes tracking advertising effectiveness to provide a more relevant service and deliver better ads to suit visitors' interests.
          - `data_to_third_party` — Includes collecting data to pass on to a third party.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="storageData" type="StorageDetails[]">

      Cookies configured on the site.

      **Read-only.**

      <Expandable title="storageData properties">

        <ResponseField name="consentConfigId" type="string">

          Consent config ID.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of app that owns the cookie.

        </ResponseField>

        <ResponseField name="name" type="string">

          Storage item name

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="type" type="string">

          **Supported values:**

          - `UNKNOWN_STORAGE_TYPE` — Unknown storage type.
          - `COOKIE` — A [cookie](https://developer.mozilla.org/en-US/docs/Web/API/Document/cookie) Wix stores in the browser.
          - `LOCALSTORAGE` — A [local storage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) item that persists across tabs in the domain.
          - `SESSIONSTORAGE` — A [session storage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage) item for a specific tab in the domain.
          - `INDEXDB` — An item in [IndexDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API).

        </ResponseField>

        <ResponseField name="consentCategory" type="string">

          Consent category for compliance with privacy regulations.

          **Supported values:**

          - `UNKNOWN_CATEGORY`
          - `essential` — Includes core functionality such as security, verification of identity and network management. These cookies can’t be disabled.
          - `functional` — Includes collecting data to remember choices users make to improve and give a more personalised experience.
          - `analytics` — Includes tracking visitor interactions with a site, to discover errors and provide better overall analytics.
          - `advertising` — Includes tracking advertising effectiveness to provide a more relevant service and deliver better ads to suit visitors' interests.
          - `data_to_third_party` — Includes collecting data to pass on to a third party.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
