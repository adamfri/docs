    Starts the actual import process for a loyalty import.

    Call this method after the loyalty import object reaches the `"PARSED"` status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/loyalty-imports/v1/loyalty-imports/execute
    ```

    ## Body Params

    <ParamField body="loyaltyImportId" type="string" required>

      Loyalty import ID.

    </ParamField>

    <ParamField body="headerMappingInfo" type="HeaderMappingInfo">

      Header mapping information for the import file.

      <Expandable title="headerMappingInfo properties">

        <ParamField body="headerMappings" type="HeaderMapping[]">

          Mappings between required loyalty data fields and file columns.
          Must contain exactly 2 mappings: one for `"EMAIL"` and one for `"POINTS"`.

          Constraints: `minItems 2`, `maxItems 2`.

          <Expandable title="headerMappings properties">

            <ParamField body="columnName" type="string">

              The required loyalty data field that this mapping corresponds to. Must be either `"EMAIL"` or `"POINTS"`.

              **Supported values:**

              - `EMAIL` — Column containing the customer's email address.
              - `POINTS` — Column containing the customer's loyalty point balance to be imported or updated.

            </ParamField>

            <ParamField body="columnIndex" type="integer">

              The zero-based index of the column in the uploaded file that contains the data for this loyalty field.
              For example, if the email addresses are in the second column of the CSV file, this value would be `1`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="loyaltyImport" type="LoyaltyImport">

      Executed loyalty import.

      See the [Loyalty Import Object](/api-reference/crm/loyalty-program/accounts/imports/loyalty-import-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
