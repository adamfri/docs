Triggered when the points of a loyalty account are adjusted, earned, or redeemed.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.v1.account_points_updated` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty` |
