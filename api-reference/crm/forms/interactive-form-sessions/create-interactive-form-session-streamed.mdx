    Creates an interactive form session for AI-powered conversational form completion, with real-time streaming.

    For implementations that prefer to wait for the complete response, call [Create Interactive Form Session](https://dev.wix.com/docs/api-reference/crm/forms/interactive-form-sessions/create-interactive-form-session) instead.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/ai/v1/interactive-form-sessions/create-streamed
    ```

    ## Body Params

    <ParamField body="formId" type="string" required>

      Form ID to create an interactive session for.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="currentValues" type="object">

      Pre-filled values to apply to the form, to initialize the session with existing data.
      Field keys must match the form schema field names.
      For example: `{"firstName": "John", "email": "john@example.com", "age": 25}`.
      These values are merged with any data extracted during the conversation.

    </ParamField>

    <ParamField body="dryRun" type="boolean">

      Whether the session should run in dry run mode when no actual form submission occurs.
      In dry run mode, the full conversational flow works normally and form data is extracted,
      but no actual form submission occurs.

      Default: `false`

      Constraints: `immutable`.

    </ParamField>

    <ParamField body="clientTime" type="ClientTime">

      Caller's local date and time.

      <Expandable title="clientTime properties">

        <ParamField body="currentTime" type="string">

          Current date and time in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) UTC format.
          For example, `2023-10-01T12:00:00Z`.

        </ParamField>

        <ParamField body="timeZone" type="string">

          Browser's timezone identifier for localizing date and time values in IANA timezone format (for example, `Europe/Vilnius`, `America/New_York`).

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="responseChunk" type="InteractiveFormSessionResponseChunk">

      AI assistant response chunk, streamed in real-time.
      Process each chunk as it arrives to provide progressive user feedback.

      <Expandable title="responseChunk properties">

        <ResponseField name="chunkType" type="string">

          Response chunk type, that determines how the content should be processed and displayed.

          **Supported values:**

          - `TEXT` — Text message for display to the user.
          - `TEXT_DATA` — Structured data extracted from user input and mapped to form fields.
          - `MULTI_SELECT_INPUT` — Selector for selecting multiple options from a list.
          - `NUMBER_INPUT` — Selector for numeric input with optional validation.
          - `SEPARATOR` — Visual separator element such as paragraph breaks.
          - `SINGLE_SELECT_INPUT` — Selector for selecting one option from a list.
          - `ERROR` — Error message when processing fails or validation errors occur.
          - `SUBMISSION` — Form submission confirmation including a submission ID.
          - `IMPORTANT_TEXT` — Highlighted information that may influence form data extraction.
          - `DEBUG` — Diagnostic information for troubleshooting and development.
          - `END_OF_RESPONSE` — Signals the completion of a response stream.
          - `FILE_UPLOAD` — Input for file upload. Not supported.
          - `SIGNATURE` — Input for digital signature capture. Not supported.

        </ResponseField>

        <ResponseField name="meaningfulInput" type="MeaningfulInput">

          Indicates which portion of the original user input was meaningful for data extraction.
          Can be used to highlight relevant parts of the user's message in the UI.

          <Expandable title="meaningfulInput properties">

            <ResponseField name="startOffset" type="integer">

              Character position (0-indexed) where the meaningful portion of user input begins.

              Constraints: `min 0`, `max 10000`.

            <ResponseField name="length" type="integer">

              Length in characters of the meaningful portion of user input.

              Constraints: `min 0`, `max 10000`.
