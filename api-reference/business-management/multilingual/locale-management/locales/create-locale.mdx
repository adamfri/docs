    <div className="wix-ref">

    Creates a new secondary locale.

    This method adds a new secondary locale to the site. A site can have up to 200 locales and up to 100 visible locales.

    To retrieve a list of all locales supported by Wix that can be created on a site, call List Supported Locales.

    <Note>

    - This method can only be called on sites where multilingual mode is enabled. To enable multilingual mode, call [Set Multilingual Mode](https://dev.wix.com/docs/api-reference/business-management/multilingual/locale-management/locale-settings/set-multilingual-mode).
    - This method creates only secondary locales. To create and set a new primary locale, call Create New Primary Locale.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/locales/v2/locale
    ```

    ## Body Params

    <ParamField body="locale" type="Locale" required>

      Locale to create.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="locale" type="Locale">

      The created locale.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
