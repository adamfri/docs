    Updates an existing add-on.

    Each time an add-on is updated, its revision number increments by 1.
    The current revision must be passed when updating to ensure you're working with the latest version and prevent unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/addons/v1/add-ons/{addOn.id}
    ```

    ## Path Params

    <ParamField path="addOn.id" type="string" required>

      Add-on ID.

    </ParamField>

    ## Body Params

    <ParamField body="addOn" type="AddOn" required>

      Add-on to update.

      See the [Add On Object](/api-reference/business-solutions/bookings/services/add-ons/add-on-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="addOn" type="AddOn">

      Updated add-on.

      See the [Add On Object](/api-reference/business-solutions/bookings/services/add-ons/add-on-object) for this object's fields.

    </ResponseField>
