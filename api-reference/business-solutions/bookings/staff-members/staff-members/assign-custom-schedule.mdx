    Assigns a custom working hours schedule to the staff member

    The working hours schedule is a schedule that defines the working hours of a staff member, and dictate when the staff member is available for bookings.

    By default staff members use the shared business working hours schedule.
    By assigning a custom working hours schedule to a staff member, you can define specific working hours for that staff member.

    To create and manage schedules and working hours sessions, use the [Events API](https://dev.wix.com/docs/api-reference/business-management/calendar/events-v3/introduction).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/staff-members/{staffMemberId}/assign-custom-schedule
    ```

    ## Path Params

    <ParamField path="staffMemberId" type="string" required>

      ID of the staff member for which to assign a working hour schedule.

    </ParamField>

    ## Body Params

    <ParamField body="scheduleId" type="string" required>

      ID of the [schedule](https://dev.wix.com/docs/api-reference/business-management/calendar/schedules-v3/introduction)
      to assign to the staff member.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `RESOURCE_DETAILS` — Includes `resource` in the response.
      - `ASSOCIATED_IDENTITY_STATUS` — Includes `associatedIdentityStatus` in the response.

    </ParamField>

    <ResponseField name="staffMember" type="StaffMember">

      Updated staff member.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ResponseField>
