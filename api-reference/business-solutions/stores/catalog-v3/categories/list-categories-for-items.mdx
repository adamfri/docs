    <div className="wix-ref">

    Retrieves the categories that contain each of the specified items.

    Returns both directly assigned categories, as well as their parent and ancestor categories for each item.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_READ">Read categories</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/categories/v1/categories/list-categories-for-items
    ```

    ## Body Params

    <ParamField body="items" type="ItemReference[]" required>

      List of Item reference info.

      Constraints: `maxItems 100`.

      <Expandable title="items properties">

        <ParamField body="catalogItemId" type="string" required>

          ID of the item within the catalog.

          For Wix Stores, this is the product ID from the [Catalog V3 Products API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/introduction).

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="appId" type="string" required>

          ID of the Wix app providing the catalog.

          Currently, only Wix Stores is supported. Use `"215238eb-22a5-4c36-9e7b-e7c08025e04e"` for all Wix Stores products.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField body="appNamespace" type="string" required>

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField body="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="categoriesForItems" type="MapItemToCategories[]">

      Map of item references to lists of direct category IDs and all category IDs, including parent categories and direct ones.

      Constraints: `maxItems 100`.

      <Expandable title="categoriesForItems properties">

        <ResponseField name="item" type="ItemReference">

          Item reference.

          <Expandable title="item properties">

            <ResponseField name="catalogItemId" type="string">

              ID of the item within the catalog.

              For Wix Stores, this is the product ID from the [Catalog V3 Products API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/introduction).

              Constraints: `minLength 1`, `maxLength 36`.

            </ResponseField>

            <ResponseField name="appId" type="string">

              ID of the Wix app providing the catalog.

              Currently, only Wix Stores is supported. Use `"215238eb-22a5-4c36-9e7b-e7c08025e04e"` for all Wix Stores products.

              Constraints: `minLength 1`, `maxLength 36`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="directCategoryIds" type="string[]">

          IDs of categories that directly contain this item.

          Constraints: `format GUID`, `maxItems 1000`.

        </ResponseField>

        <ResponseField name="indirectCategoryIds" type="string[]">

          IDs of ancestor categories of the item's direct categories. These categories indirectly contain the item through their subcategories.

          Constraints: `format GUID`, `maxItems 1000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
