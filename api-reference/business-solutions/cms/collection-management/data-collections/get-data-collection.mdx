    <div className="wix-ref">

    Retrieves a data collection by ID.

    Starting on August 3rd, 2026, when called with a visitor (unauthenticated) identity, the response contains only
    the collection details needed to display the collection's data: `id`, `displayName`, `displayField`, `plugins`,
    and for each field in `fields` its `key`, `displayName`, `type`, and `typeMetadata`. All other collection
    details, such as `permissions` and `capabilities`, are omitted. Calls made with any other identity return the
    full collection.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v2/collections/{dataCollectionId=**}
    ```

    ## Query Params

    <ParamField query="dataCollectionId" type="string" required>

      ID of the collection to retrieve.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField query="consistentRead" type="boolean">

      Whether to retrieve data from the primary database instance.
      This decreases performance but ensures data retrieved is up to date even immediately after an update.
      Learn more about [Wix Data and eventual consistency](https://dev.wix.com/api/rest/wix-data/wix-data/eventual-consistency).

      Default: `false`

    </ParamField>

    <ParamField query="fields" type="string[]">

      List of specific field names to return, if empty all fields are returned.
      Affects all returned collections

      Constraints: `maxLength 1000`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="collection" type="DataCollection">

      Details of the collection requested.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    Retrieves a data collection by ID.

    Starting on August 3rd, 2026, when called with a visitor (unauthenticated) identity, the response contains only
    the collection details needed to display the collection's data: `id`, `displayName`, `displayField`, `plugins`,
    and for each field in `fields` its `key`, `displayName`, `type`, and `typeMetadata`. All other collection
    details, such as `permissions` and `capabilities`, are omitted. Calls made with any other identity return the
    full collection.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Method Declaration

    ```typescript
    import { collections } from '@wix/data';

    collections.getDataCollection(dataCollectionId, options): Promise<DataCollection>
    ```

    ## Method Parameters

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection to retrieve.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="options" type="GetDataCollectionOptions">

      Options for retrieving a data collection.

      <Expandable title="options properties">

        <ParamField body="consistentRead" type="boolean">

          Whether to retrieve data from the primary database instance.
          This decreases performance but ensures data retrieved is up to date even immediately after an update.
          Learn more about [Wix Data and eventual consistency](https://dev.wix.com/api/rest/wix-data/wix-data/eventual-consistency).

          Default: `false`

        </ParamField>

        <ParamField body="fields" type="string[]">

          List of specific field names to return, if empty all fields are returned.
          Affects all returned collections

          Constraints: `maxLength 1000`, `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Returns

    Returns `Promise<DataCollection>`.

    See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.
