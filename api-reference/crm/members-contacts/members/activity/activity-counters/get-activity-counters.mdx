<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves activity counters for the specified site member, including all public counters and any private counters owned by the authenticated caller.

    <Note>

    Make sure to pass a `memberId` and not a `contactId` to identify the member. Any relationship between a member's `memberId` and `contactId` is coincidental.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-ACTIVITY-COUNTERS">Read Activity Counters</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/activity-counters/{memberId}
    ```

    ## Path Params

    <ParamField path="memberId" type="string" required>

      Member ID whose counters will be returned.

    </ParamField>

    ## Response Object

    <ResponseField name="activityCounters" type="ActivityCounter[]">

      Activity counters.

      See the [Activity Counter Object](/api-reference/crm/members-contacts/members/activity/activity-counters/activity-counter-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
