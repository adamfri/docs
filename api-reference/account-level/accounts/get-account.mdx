    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves an account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.IDENTITY.MANAGE-TEAM-MEMBERS">Manage Team Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/accounts/v1/accounts/{accountId}
    ```

    ## Path Params

    <ParamField path="accountId" type="string" required>

      Account ID to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="Account">

      account

      <Expandable title="account properties">

        <ResponseField name="accountId" type="string">

          Account ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="slug" type="string">

          Slug used in the prefix of a free site's URL.

        </ResponseField>

        <ResponseField name="accountName" type="string">

          Account name for display.

        </ResponseField>

        <ResponseField name="accountImg" type="string">

          Deprecated. Use `accountProperties. accountImg` instead.

        </ResponseField>

        <ResponseField name="status" type="string">

          Account status.

          **Supported values:**

          - `ACTIVE`
          - `BLOCKED`
          - `DELETED`

        </ResponseField>

        <ResponseField name="accountOwner" type="string">

          Account owner's user ID.

        </ResponseField>

        <ResponseField name="accountProperties" type="AccountProperties">

          Additional account properties.

          <Expandable title="accountProperties properties">

            <ResponseField name="isTeam" type="boolean">

              Whether this account is a team account.

            </ResponseField>

            <ResponseField name="accountImg" type="string">

              Account image for display. Relevant primarily for accounts with [custom branding](https://support.wix.com/en/article/wix-studio-setting-up-custom-branding).

            </ResponseField>

            <ResponseField name="accountBanner" type="string">

              Account banner for display. Relevant primarily for accounts with [custom branding](https://support.wix.com/en/article/wix-studio-setting-up-custom-branding).

            </ResponseField>

            <ResponseField name="accountLogo" type="string">

              Account logo, displayed on customer sites that inherit the custom branding.

            </ResponseField>

            <ResponseField name="coBranding" type="string">

              Account [custom branding](https://support.wix.com/en/article/wix-studio-setting-up-custom-branding) status.

              **Supported values:**

              - `None` — The account does not have custom branding.
              - `CoBranded` — The account has custom branding.
              - `CoBranded_Customer_New` — The account is a contributor of an account with custom branding and was created because of the contributor invite.
              - `CoBranded_Customer_Existing` — The account is a contributor of an account with custom branding and existed before receiving the contributor invite.

            </ResponseField>

            <ResponseField name="websiteUrl" type="string">

              Account website URL. This URL is displayed on customer sites that inherit the custom branding.

            </ResponseField>

            <ResponseField name="parentAccountId" type="string">

              ID of parent account to this account, if relevant.

            </ResponseField>

            <ResponseField name="dataLocality" type="boolean">

              Whether the account's data should be stored locally.

            </ResponseField>

            <ResponseField name="accountType" type="string">

              The type of this account, as an open string drawn from the Wix user-type vocabulary
              (e.g. `Nautilus`, `Wixel`). Mirrors the user's user type; unset for regular Wix accounts.
              Once set, it can be updated but not cleared.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="dateCreated" type="datetime">

          Date and time the account was created.

        </ResponseField>

        <ResponseField name="dateUpdated" type="datetime">

          Date and time the account was last updated.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
