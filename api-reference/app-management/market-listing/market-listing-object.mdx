---
title: "Market Listing Object"
description: "A market listing is the localized marketing page for an app in the Wix App Market."
icon: "cube"
---

A market listing is the localized marketing page for an app in the Wix App Market.
A listing is uniquely identified by the combination of `appId`, `languageCode`, and `status`.
An app therefore has one listing record per language per lifecycle status.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Market listing ID.

    </ResponseField>

    <ResponseField name="appId" type="string">

      ID of the app the listing belongs to.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="languageCode" type="string">

      2-letter language code in ISO 639-1 alpha-2 format. For example, `en` for English.

      Constraints: `format LANGUAGE`.

    </ResponseField>

    <ResponseField name="basicInfo" type="BasicInfo">

      Basic marketing information about the app, including its name, description, and categories.

      <Expandable title="basicInfo properties">

        <ResponseField name="name" type="string">

          Display name of the app shown in the Wix App Market.

        </ResponseField>

        <ResponseField name="teaser" type="string">

          Short description of the app shown in listing previews.

        </ResponseField>

        <ResponseField name="longDescription" type="string">

          Full description of the app shown on the listing detail page.

        </ResponseField>

        <ResponseField name="benefits" type="Benefits[]">

          Key benefits of the app displayed on its listing page.

          <Expandable title="benefits properties">

            <ResponseField name="title" type="string">

              Benefit title.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="searchKeywords" type="string[]">

          Keywords used to improve the app's discoverability in search.

        </ResponseField>

        <ResponseField name="demoUrl" type="string">

          URL of a demo page or video for the app.

        </ResponseField>

        <ResponseField name="categories" type="string[]">

          App Market categories the app belongs to.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="assetsMap" type="object">

      Map of marketing assets keyed by asset type. JSON field name is `assetsMap`.
      Common keys include `appIcon`, `screenshots`, and `banners`. The platform may add other keys over time.

      Constraints: `format map`.

      <Expandable title="assetsMap properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="Assets">

          <Expandable title="value properties">

            <ResponseField name="assets" type="Asset[]">

              <Expandable title="assets properties">

                <ResponseField name="url" type="string">

                  Constraints: `format WEB_URL`.

                </ResponseField>

                <ResponseField name="mediaType" type="string">

                  **Supported values:**

                  - `VIDEO`
                  - `IMAGE`
                  - `YOUTUBE`

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="contactInfo" type="ContactInfo">

      Developer contact and legal information for the app.

      <Expandable title="contactInfo properties">

        <ResponseField name="website" type="string">

          URL of the developer's website.

        </ResponseField>

        <ResponseField name="developerMetaSiteId" type="string">

          ID of the developer's Wix development site associated with the app.

        </ResponseField>

        <ResponseField name="supportEmail" type="string">

          Support email address for the app.

        </ResponseField>

        <ResponseField name="privacyPolicyUrl" type="string">

          URL of the app's privacy policy.

        </ResponseField>

        <ResponseField name="termsOfUseUrl" type="string">

          URL of the app's terms of use.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="installationRequirement" type="InstallationRequirement">

      Conditions that control where and how the app can be installed.

      <Expandable title="installationRequirement properties">

        <ResponseField name="requiredApps" type="RequiredApp[]">

          Apps created by Wix that must already be installed for this app to function. For example, Wix Stores.

          <Expandable title="requiredApps properties">

            <ResponseField name="id" type="string">

              Required app ID.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="slug" type="string">

              URL-friendly identifier for the required app, as it appears in the Wix App Market URL.
              For example, in `https://www.wix.com/app-market/wix-stores`, the slug is `wix-stores`.
              Optional — use `id` alone if you have the app's GUID.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="includeCountries" type="string[]">

          2-letter country codes in ISO-3166 alpha-2 format for countries where this app is available for installation. Empty means available in all countries not listed in `excludeCountries`.

          Constraints: `format COUNTRY`.

        </ResponseField>

        <ResponseField name="excludeCountries" type="string[]">

          2-letter country codes in ISO-3166 alpha-2 format for countries where this app is not available for installation.

          Constraints: `format COUNTRY`.

        </ResponseField>

        <ResponseField name="includeLanguages" type="string[]">

          2-letter language codes in ISO 639-1 alpha-2 format for languages supported by this app. Empty means all languages are supported, except those in `excludeLanguages`.

          Constraints: `format LANGUAGE`.

        </ResponseField>

        <ResponseField name="excludeLanguages" type="string[]">

          2-letter language codes in ISO 639-1 alpha-2 format for languages not supported by this app.

          Constraints: `format LANGUAGE`.

        </ResponseField>

        <ResponseField name="allowLanguageCustomization" type="boolean">

          Whether the user can choose their preferred language when installing the app.

        </ResponseField>

        <ResponseField name="requiredWixPremium" type="boolean">

          Whether a Wix Premium plan is required to install this app.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the market listing is updated.
      To prevent conflicting changes, the current revision must be passed when updating the market listing.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the market listing was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the market listing was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Lifecycle status of the listing.

      **Supported values:**

      - `DRAFT` — Editable working copy of the listing in the app dashboard.
      - `PUBLISHED` — Live listing visible to users in the Wix App Market.
      - `APPROVED` — Post-review, pre-publication state. The listing has passed review but hasn't been promoted to `PUBLISHED` yet. Status transitions are handled manually and can't be set directly.

    </ResponseField>

    <ResponseField name="classification" type="string">

      How the app integrates with Wix and who can install it. Each app has exactly one classification.

      **Supported values:**

      - `SITE_APP` — A publicly listed app that users install on their Wix sites.
      - `API_KEY` — An app that authenticates using an API key to access Wix services, without installing on a site.
      - `VELO_APP` — An app built for the Velo development environment.
      - `PRIVATE_APP` — An app restricted to the owner account and its sub-accounts. Not available in the public App Market.
      - `HEADLESS` — A headless app that accesses Wix public services without installing on a site.
      - `FUNCTION_ACTIVATION_APP` — An app scoped to a specific site that tracks activated functions on that site.

    </ResponseField>

    <ResponseField name="pricingData" type="PricingData">

      Pricing and free trial information for the app.

      <Expandable title="pricingData properties">

        <ResponseField name="externalPricingPageUrl" type="string">

          URL of the app's external pricing page, when hosted outside Wix.

        </ResponseField>

        <ResponseField name="externalCheckout" type="boolean">

          Whether checkout for this app happens on an external site instead of in Wix.

        </ResponseField>

        <ResponseField name="freeTrialDays" type="integer">

          Number of free trial days offered by the app developer.

        </ResponseField>

        <ResponseField name="internalFreeTrialDays" type="integer">

          Number of free trial days provided and managed by Wix.

        </ResponseField>

        <ResponseField name="openPremiumPage" type="boolean">

          Whether the app's upgrade button opens the Wix premium page directly.
          Not translatable. The value is shared by all of the app's listings in the same `status`, and is taken from the English listing.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="llmContext" type="LLMContext">

      Custom description used by LLM-based tools for AI-generated content and recommendations.
      Available only with the `APP_MARKET.LLM_CONTEXT` permission.

      <Expandable title="llmContext properties">

        <ResponseField name="instructions" type="string">

          Custom description of the app used by LLM-based tools for AI-generated content and recommendations.

          Constraints: `maxLength 10000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="llmMetadata" type="LlmMetadata">

      Structured metadata for AI-powered app discovery and recommendations.
      Available only with the `APP_MARKET.LLM_CONTEXT` permission.

      <Expandable title="llmMetadata properties">

        <ResponseField name="primaryUseCases" type="string[]">

          Primary use cases for the app, used by AI tools for app discovery and recommendations.

          Constraints: `maxLength 100`, `maxItems 20`.

        </ResponseField>

        <ResponseField name="capabilities" type="Capabilities">

          Functional capabilities of the app.

          <Expandable title="capabilities properties">

            <ResponseField name="coreFeatures" type="string[]">

              Core features of the app.

              Constraints: `maxLength 100`, `maxItems 20`.

            </ResponseField>

            <ResponseField name="advancedFeatures" type="string[]">

              Advanced features of the app.

              Constraints: `maxLength 100`, `maxItems 20`.

            </ResponseField>

            <ResponseField name="apiCapabilities" type="string[]">

              API capabilities exposed by the app.

              Constraints: `maxLength 100`, `maxItems 20`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="platformFeatures" type="PlatformFeatures">

          Platform and technical constraints of the app.

          <Expandable title="platformFeatures properties">

            <ResponseField name="headlessCapable" type="boolean">

              Whether the app supports headless deployments.

            </ResponseField>

            <ResponseField name="requiresWixPremium" type="boolean">

              Whether the app requires Wix Premium to function.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
