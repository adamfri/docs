    <div className="wix-api-columns">

    <div className="wix-ref">

    Removes a badge assignment, removing the badge from the specified member.

    When a badge assignment is deleted, the member loses any permissions or privileges associated with that badge.
    This action can't be undone.

    To delete multiple assignments, call [Bulk Delete Badge Assignments](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/bulk-delete-badge-assignments).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/badges/v4/assignments/{badgeAssignmentId}
    ```

    ## Path Params

    <ParamField path="badgeAssignmentId" type="string" required>

      ID of the badge assignment to delete.

    </ParamField>
