    Adjusts the prices and costs of multiple variants by a specified amount or percentage, given the provided filter and search expression.

    Use this method to apply bulk pricing changes, such as increasing all prices by 10%, without setting explicit values. Use [Bulk Update Product Variants By Filter](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/bulk-update-product-variants-by-filter) to set explicit values instead.

    The following variant fields can be increased or decreased:
    + `compareAtPrice` - Original price before discounts
    + `actualPrice` - Current selling price
    + `cost` - Merchant's cost to acquire/produce the item
    + `compareAtPriceDiscount` - Discount percentage applied to compare-at price

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_WRITE">Product write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/products/adjust-variants-by-filter
    ```

      Rounding strategy of new calculated prices.

      + `NO_ROUNDING`: Calculated prices will be saved without rounding to keep max possible precision.
      + `CURRENCY_PRECISION`: Calculated prices will be rounded according to the currency's precision requirements. For example. `$3.5555` will be saved as `$3.56`; `¥3.5555` will be saved as `¥4`.
      + `NEAREST_WHOLE_NUMBER`: Calculated prices will be rounded to the nearest whole number.

      **Supported values:**

      - `NO_ROUNDING` — Calculated prices will be saved without rounding to keep max possible precision. It's still good idea to round numbers before displaying them.
      Example: input $3.5555 -> saved value $3.5555
      - `CURRENCY_PRECISION` — Calculated prices will be rounded according to currency precision.
      Example: input $3.5555 -> saved value $3.56, input ¥3.5555 -> saved value ¥4
      - `NEAREST_WHOLE_NUMBER` — Calculated prices will be rounded to nearest whole number.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `ADJUSTED_ACTUAL_PRICE_OUT_OF_RANGE` | Adjusted `actualPrice` is outside the valid range. |
    | `400` | `INVALID_ARGUMENT` | `ADJUSTED_COMPARE_AT_PRICE_OUT_OF_RANGE` | Adjusted `compareAtPrice` is outside the valid range. |
    | `400` | `INVALID_ARGUMENT` | `ADJUSTED_COST_OUT_OF_RANGE` | Adjusted `cost` is outside the valid range. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_ADJUST_PRICE_RESTRICTED_VARIANT` | Price adjustment attempted for a restricted variant. Price can't be adjusted for variants with restrictions. |
    | `400` | `INVALID_ARGUMENT` | `NO_VARIANT_ADJUSTMENTS_PASSED` | No adjustment values provided. At least 1 adjustment value is required. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_PRICES_ADJUSTMENTS` | Both price fields and `compareAtPriceDiscount` provided. The `actualPrice` and `compareAtPrice` can't be combined with `compareAtPriceDiscount`. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_VARIANT_OPTION_CHOICE` | Variant choice doesn't exist in the product's option choices. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_VARIANT_OPTION` | Variant option doesn't exist in the product's options. |

    ## Examples

    Decreases the actual price, compare at price, and cost of all product variants that were created after July 22nd, 2024.

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/stores/v3/bulk/products/adjust-variants-by-filter' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>' \
      -d '{
            "filter": {
              "createdDate": {
                "$gt": "2024-07-22T13:22:45"
              }
            },
            "actualPrice": {
              "amount": "-1"
            },
            "compareAtPrice": {
              "amount": "-1"
            },
            "cost": {
              "amount": "-1"
            }
          }'
      ```

      ```json Response
      {
          "jobId": "e95725e2-9159-4d45-b1c5-d3a0fed56d7b"
      }
      ```
