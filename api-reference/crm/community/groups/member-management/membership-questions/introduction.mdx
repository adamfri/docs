The Groups Membership Questions API provides functionality for managing questions members are asked when requesting to join a group.
 
The Groups Membership Questions API allows you to:

 + [Create or replace](fallback::https://dev.wix.com/docs/rest/crm/community/groups/membership-questions/create-or-replace-all-membership-questions) all the membership questions for a group. 
 + [List](fallback::https://dev.wix.com/docs/rest/crm/community/groups/membership-questions/list-membership-questions) a group's membership questions. 
 + [List](fallback::https://dev.wix.com/docs/rest/crm/community/groups/membership-questions/list-answers) answers to a group's membership questions.
