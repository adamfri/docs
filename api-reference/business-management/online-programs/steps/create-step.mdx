    Creates a step.

    Specify the parent section in `step.sectionId`.
    The service derives the parent program automatically.
    To create a quiz step, create or clone the quiz separately, then specify its ID in `step.quizOptions.id`.

    To create multiple steps in a single API call, call [BulkCreateSteps](https://dev.wix.com/docs/api-reference/business-management/online-programs/steps/bulk-create-steps).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/v3/steps
    ```
