Triggered when a draft post is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.blog.v3.draft_updated` |
| Package | `@wix/blog` |
| Permissions | `Manage Blog`, `Read Draft Blog Posts`, `Read Blog` |

## Examples

  import { draftPosts } from '@wix/blog';

      // handle your event here
  });
