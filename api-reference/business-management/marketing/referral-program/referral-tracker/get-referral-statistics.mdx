    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_api/referral-tracker/v1/referral-statistics
    ```

    ## Response Object

    <ResponseField name="totalSignUpsCompleted" type="integer">

      Total number of sign-ups completed by referred friends.

    </ResponseField>

    <ResponseField name="totalActionsCompleted" type="integer">

      Total number of actions completed by referred friends.

    </ResponseField>

    <ResponseField name="totalAmountGenerated" type="string">

      Total amount of purchases made by referred friends.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
