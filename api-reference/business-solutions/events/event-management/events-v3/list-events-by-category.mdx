    Retrieves a list of up to 100 events that belong to the same event category.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-EVENTS">Read Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v3/events/category/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      Category ID.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="Paging">

      Paging options to limit and skip the number of items.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to return. See [Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging#getting-started_sorting-and-paging_paging) for more information.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="fields" type="string[]">

      Predefined sets of fields to return. If both `fields` and `fieldsets` are sent in the request, the union of both lists is returned.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `DETAILS` — Returns `shortDescription`, `mainImage` and `calendarUrls`.
      - `TEXTS` — Returns `description`.
      - `REGISTRATION` — Returns `registration`.
      - `URLS` — Returns `eventPageUrl`.
      - `FORM` — Returns `form`.
      - `DASHBOARD` — Returns `summaries`.
      - `FEED` — Returns `feed`.
      - `ONLINE_CONFERENCING_SESSION` — Returns `onlineConferencing.session`.
      - `SEO_SETTINGS` — Returns `seoSettings`.
      - `AGENDA` — Returns `agendaSettings`.
      - `CATEGORIES` — Returns `categories`.

    </ParamField>

    ## Response Object

    <ResponseField name="pagingMetadata" type="PagingMetadataV2">

      Metadata for the paginated results.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items to return. See [Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging#getting-started_sorting-and-paging_paging) for more information.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Requested offset.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="events" type="Event[]">

      List of events.

      See the [Event Object](/api-reference/business-solutions/events/event-management/events-v3/event-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
