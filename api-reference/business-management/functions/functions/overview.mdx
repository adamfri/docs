A function is the main entity in the Wix Functions ecosystem. All other entities are used to create functions or to define their behavior. Learn more about [Functions](https://support.wix.com/en/wix-functions).

## SDK package

```bash
npm install @wix/functions
```

Import the `functions` namespace from `@wix/functions`.
