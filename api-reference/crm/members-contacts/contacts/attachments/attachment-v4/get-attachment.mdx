    Retrieves the specified attachment for the specified contact.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACT-ATTACHMENTS">Manage Contact Attachments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/attachments/{contactId}/{attachmentId}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      Contact ID for the attachment to retrieve.

    </ParamField>

    <ParamField path="attachmentId" type="string" required>

      Attachment ID to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="attachment" type="ContactAttachment">

      The requested attachment.

      See the [Attachment Object](/api-reference/crm/members-contacts/contacts/attachments/attachment-v4/attachment-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
