    <div className="wix-ref">

    Counts the number of categories that match the provided filtering.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_READ">Read categories</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/categories/v1/categories/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

      Learn more about the [filter object structure](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language#filters).

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Search options.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Search mode. Defines the search logic for combining multiple terms in the `expression`.

          **Supported values:**

          - `OR` — At least 1 of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `parentCategory.index`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search method to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField body="appNamespace" type="string" required>

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField body="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnNonVisibleCategories" type="boolean">

      Whether to return categories with `visible: false` (hidden categories).

      Default: `false` - only visible categories are returned in the response

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total count of categories which satisfy the given filter and/or search.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Counts categories with `name` that starts with `"Drinkware"`

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/categories/v1/categories/count' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>' \
        -d '{
          "search": {
            "expression": "name $startsWith Drinkware",
            "fuzzy": true
          },
          "returnNonVisibleCategories": true,
          "treeReference": {
            "appNamespace": "@wix/stores",
            "treeKey": null
          }
        }'
      ```

      ```json Response
      {
        "count": 2
      }
      ```

    </CodeGroup>

    </div>

    </div>
