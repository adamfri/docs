A Google Ads campaign managed through the Wix Promote interface.
A campaign can be either a Smart Campaign or a Performance Max campaign, determined by the campaignType field.
Creating new Smart Campaigns is deprecated. Support for it will be removed in a future release, so use
PERFORMANCE_MAX or PERFORMANCE_MAX_LEADS instead. Existing Smart Campaigns aren't affected.

## SDK package

```bash
npm install @wix/promote-google-ads
```

Import the `campaigns` namespace from `@wix/promote-google-ads`.
