    Checks if the business can still accommodate an existing multi-service booking and returns overall bookability status, capacity details, and policy violations.

    Wix Bookings considers:
    - The relevant services' [booking policies](https://dev.wix.com/docs/rest/business-solutions/bookings/policies/booking-policies/introduction).
    - The availability of all required [resources](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/introduction).

    Call this method to check if an existing multi-service booking is still valid after business configuration changes.
    For example, staff changes, policy updates, or capacity modifications.

    For checking availability before creating new multi-service bookings, call [List Multi Service Availability Time Slots](https://dev.wix.com/docs/rest/business-solutions/bookings/time-slots/time-slots-v2/list-multi-service-availability-time-slots) instead.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-CALENDAR">Read Bookings Calendar Availability</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/bookings-service/v2/multi_service_bookings/{multiServiceBookingId}/get_availability
    ```

    ## Path Params

    <ParamField path="multiServiceBookingId" type="string" required>

      ID of the multi-service booking to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="bookable" type="boolean">

      Whether all contained single-service bookings are bookable.

    </ResponseField>

    <ResponseField name="totalCapacity" type="integer">

      Total number of spots.

    </ResponseField>

    <ResponseField name="remainingCapacity" type="integer">

      Number of open spots.

    </ResponseField>

    <ResponseField name="policyViolations" type="BookingPolicyViolations">

      Indicators for policy violations of the multi-service booking.

      <Expandable title="policyViolations properties">

        <ResponseField name="tooEarlyToBook" type="boolean">

          Booking policy violation: Too early to book this slot.

        </ResponseField>

        <ResponseField name="tooLateToBook" type="boolean">

          Booking policy violation: Too late to book this slot.

        </ResponseField>

        <ResponseField name="bookOnlineDisabled" type="boolean">

          Booking policy violation: Online booking is disabled for this slot.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="policySettings" type="BookingPolicySettings">

      Multi-service booking policy settings.

      <Expandable title="policySettings properties">

        <ResponseField name="maxParticipantsPerBooking" type="integer">

          Booking policy settings for a given slot or schedule.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="multiServiceBookingInfo" type="BookingInfo[]">

      Details of the multi-service booking.

      <Expandable title="multiServiceBookingInfo properties">

        <ResponseField name="bookingId" type="string">

          Booking ID.

        </ResponseField>

      </Expandable>

    </ResponseField>
