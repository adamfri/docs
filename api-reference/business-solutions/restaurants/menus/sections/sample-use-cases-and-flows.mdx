## Sync pizza menus across all sites

If you have several pizzeria sites, you might need to sync menus across those sites. For example, if you have a new section in the menu, called "Salads" this change also needs to be reflected on other sites.    

To sync the pizza menu across all sites:

1. Call [Get Section](fallback::https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/menus/sections/get-section) on the site where you created a new section.
1. Extract the whole `section` object.
1. Call [Create Section](fallback::https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/menus/sections/create-section) for your other sites and pass the new section to each.
1. Call [Update Menu](fallback::https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/menus/menus/update-menu) and add the new section ID to the `sectionIds` array.
