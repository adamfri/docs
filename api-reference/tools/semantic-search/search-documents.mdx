    Searches Wix documentation entries by a search term and document type.

    Returns a ranked list of matching documentation entries ordered by relevance
    score descending. Method results include kb_name to identify the source
    knowledge base. Each result is truncated to lines_in_each_result lines
    (defaults to 20) with contextual "read more" hints; pass a larger value
    for more content per result.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="igor:v1:document_entry:search_documents">igor:v1:document_entry:search_documents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/mcp-docs-search/v1/v1/docs/search
    ```

    ## Body Params

    <ParamField body="searchTerm" type="string" required>

      The search term to look up in the documentation.

      Constraints: `minLength 1`, `maxLength 500`.

    </ParamField>

    <ParamField body="maximumResults" type="integer">

      The maximum number of results to return. Defaults to 15. Valid range: [1, 20].

    </ParamField>

    <ParamField body="documentType" type="string">

      The type of documentation to search. Defaults to REST if not provided.

      **Supported values:**

      - `VELO` — Velo JavaScript APIs for Wix sites.
      - `SDK` — Wix JavaScript SDK for headless and external applications.
      - `REST` — Wix REST APIs.
      - `WDS` — Wix Design System documentation.
      - `BUILD_APPS` — Documentation for building Wix apps.
      - `WIX_HEADLESS` — Wix Headless documentation for external and headless applications.
      - `CLI` — Wix CLI documentation.
      - `BUSINESS_SOLUTIONS` — Wix business solutions and workflow documentation.

    </ParamField>

    <ParamField body="linesInEachResult" type="integer">

      Maximum number of lines to include per result content. Defaults to 20.
      Method results use section-aware truncation; article results are truncated
      at this line count. A "Read more here: &lt;url>" hint is appended when content
      is truncated.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="DocumentEntry[]">

      The ranked list of matching documentation entries, ordered by relevance score descending.

      Constraints: `maxItems 100`.

      See the [Document Entry Object](/api-reference/tools/semantic-search/document-entry-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
