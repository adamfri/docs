    Creates a tax region.

    A tax region requires a tax calculator `appId`. Call [List Tax Calculators](https://dev.wix.com/docs/rest/business-solutions/e-commerce/tax/tax-calculation/list-tax-calculators) to retrieve the available calculators for a site, and never hardcode the `appId`. Calculator app IDs are installation-scoped and can differ between sites.

    Set `subdivision` to a state, province, or prefecture using its [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) code without the country prefix (for example, `NY`), or leave it empty (or `*`) to create a country-level region. Subdivisions are supported only for these countries: `AU`, `BR`, `CA`, `FR`, `DE`, `IN`, `IT`, `MX`, `NL`, `PT`, `ES`, `AE`, `GB`, and `US`. For any other country, create the region at the country level; a subdivision-level region for an unsupported country may be rejected with `SUBDIVISIONS_NOT_SUPPORTED_FOR_COUNTRY`.

    Tax regions can't be created for embargoed countries (Cuba, Iran, North Korea, and Syria).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `ALREADY_EXISTS` | A tax region with this `country` and `subdivision` already exists. |
    | `404` | `NOT_FOUND` | `CALCULATOR_ID_NOT_FOUND` | Couldn't find the calculator. |
    | `428` | `FAILED_PRECONDITION` | `CALCULATOR_IS_NOT_SUPPORTED_FOR_THIS_TAX_REGION` | The calculator doesn't support this tax region. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SUBDIVISION_FORMAT` | The `subdivision` format is invalid. It must be in ISO 3166-2 format. |
    | `400` | `INVALID_ARGUMENT` | `SUBDIVISIONS_NOT_SUPPORTED_FOR_COUNTRY` | Subdivisions aren't supported for the specified `country`. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
