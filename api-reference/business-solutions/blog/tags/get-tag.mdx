    Retrieves a tag with the provided ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v3/tags/{tagId}
    ```

    ## Path Params

    <ParamField path="tagId" type="string" required>

      ID of tag to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fieldsets" type="string[]">

      List of additional tag fields to include in the response. For example, use the `URL` fieldset to retrieve the url field in
      the response in addition to the tag's base fields. Base fields don’t include any of the supported fieldset values. By default
      only the tag's base fields are returned.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes Tag URL when present.

    </ParamField>

    ## Response Object

    <ResponseField name="tag" type="Tag">

      Retrieved tag.

      See the [Tag Object](/api-reference/business-solutions/blog/tags/tag-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
