    Retrieves the result of an asynchronous image-generation request.

    Poll this with the `executionId` returned by Generate Image until the status is `READY`, when the generated image's `imageUrl` and `fileId` are populated, or `FAILED`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-publisher/v1/generated-image/{executionId}
    ```

    ## Path Params

    <ParamField path="executionId" type="string" required>

      The image-generation process ID returned by Generate Image.

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      Status of the image generation.

      **Supported values:**

      - `IN_PROGRESS` — Generation is still in progress.
      - `READY` — Generation completed and the image is available.
      - `FAILED` — Generation failed.

    </ResponseField>

    <ResponseField name="imageUrl" type="string">

      URL of the generated image. Returned only when the status is `READY`.

    </ResponseField>

    <ResponseField name="fileId" type="string">

      Media Manager file ID of the generated image. Returned only when the status is `READY`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `GENERATED_IMAGE_NOT_FOUND` | Couldn't find an image generation for the provided `executionId`. It's invalid or has expired. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    Retrieve the result of an image-generation request by its executionId. Poll until the status is READY or FAILED.

    <CodeGroup>

      ```bash Request

      'https://www.wixapis.com/social-publisher/v1/generated-image/b7c2f0a1-4e6d-4a8b-9c3f-2d5e1a7b0c94' \
      -H 'Authorization: <AUTH>'
      ```

      ```json Response

        "status": "READY",
        "imageUrl": "https://static.wixstatic.com/media/cf2434_generated-image.jpg",

      }
      ```
