    <div className="wix-ref">

    Updates tags on multiple cards by specified card IDs.

    If you specify a tag that in both `assignTags` and `unassignTags`, the tag is assigned to the cards.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/pipelines/v1/bulk/cards/update-tags
    ```

    ## Body Params

    <ParamField body="cardIds" type="string[]" required>

      List of card IDs whose tags will be updated.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="assignTags" type="PrivateTags">

      List of tags to assign.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="PrivateTags">

      List of tags to unassign.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the updated cards in the response.

      Default: `false`

    </ParamField>
