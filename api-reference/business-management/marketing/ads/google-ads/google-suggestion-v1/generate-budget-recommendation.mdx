    Retrieves a recommended budget for PERFORMANCE_MAX or PERFORMANCE_MAX_LEADS campaigns.
    Uses the Google Ads recommendation API based on campaign configuration, location, and historical signals.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/budget-recommendation
    ```

    ## Body Params

    <ParamField body="campaignType" type="string" required>

      Required. Campaign type for which to generate a budget recommendation. Must be PERFORMANCE_MAX or PERFORMANCE_MAX_LEADS.

      **Supported values:**

      - `SMART` — Simplified auto-managed campaign. Google handles bidding and ad delivery based on keyword themes and geo targets.
      Creating new campaigns of this type is deprecated. Support for it will be removed in a future release, so use
      PERFORMANCE_MAX or PERFORMANCE_MAX_LEADS instead. Existing campaigns of this type aren't affected.
      - `PERFORMANCE_MAX` — Goal-based campaign that runs across all Google channels (Search, Display, YouTube, etc.) using asset groups.
      - `PERFORMANCE_MAX_LEADS` — Performance Max variant optimized for lead generation, such as phone calls and form fills.

    </ParamField>

    <ParamField body="assetGroupInfo" type="BudgetRecommendationAssetGroupInfo[]" required>

      Required. Asset group information for the campaign. At least one entry with a `finalUrl` is required.

      Constraints: `maxItems 10`.

      <Expandable title="assetGroupInfo properties">

        <ParamField body="finalUrl" type="string">

          Required. Final landing page URL of the asset group.

          Constraints: `format WEB_URL`.

        </ParamField>

        <ParamField body="headlines" type="string[]">

          Optional. Short headline text assets associated with the asset group.

          Constraints: `maxLength 1000`, `maxItems 15`.

        </ParamField>

        <ParamField body="descriptions" type="string[]">

          Optional. Description text assets associated with the asset group.

          Constraints: `maxLength 1000`, `maxItems 5`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="adGroupInfo" type="BudgetRecommendationAdGroupInfo[]">

      Optional. Ad group information containing keywords used as additional context for the recommendation.

      Constraints: `maxItems 10`.

      <Expandable title="adGroupInfo properties">

        <ParamField body="keywords" type="string[]">

          Optional. Keywords associated with the ad group, used as additional context for the recommendation.

          Constraints: `maxLength 1000`, `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="isNewCustomer" type="boolean">

      Optional. Whether the account has no existing campaigns. When true, a dedicated new-customer recommendation model is used.

    </ParamField>

    <ParamField body="currentBudgetMicros" type="integer">

      Optional. Current campaign budget in micros (1,000,000 micros = 1 currency unit), used as additional context for the recommendation.

    </ParamField>

    <ParamField body="merchantCenterAccountId" type="integer">

      Optional. Google Merchant Center account ID for Performance Max retail campaigns.

    </ParamField>

    <ParamField body="campaignImageAssetCount" type="integer">

      Optional. Number of image assets currently in the campaign.

    </ParamField>

    <ParamField body="campaignCallAssetCount" type="integer">

      Optional. Number of call assets currently in the campaign.

    </ParamField>

    <ParamField body="countryCodes" type="string[]">

      Optional. ISO 3166-1 alpha-2 country codes for the campaign's target locations.

      Constraints: `maxLength 10`, `maxItems 50`.

    </ParamField>

    <ParamField body="languageCodes" type="string[]">

      Optional. ISO 639-1 language codes for the campaign's target languages.

      Constraints: `maxLength 10`, `maxItems 50`.

    </ParamField>

    <ParamField body="positiveLocationIds" type="string[]">

      Optional. Google Ads geo target location IDs to include in targeting.

      Constraints: `maxItems 1000`.

    </ParamField>

    <ParamField body="negativeLocationIds" type="string[]">

      Optional. Google Ads geo target location IDs to exclude from targeting.

      Constraints: `maxItems 1000`.

    </ParamField>

    <ParamField body="targetPartnerSearchNetwork" type="boolean">

      Optional. Whether the campaign serves ads on the Google Search Partner network.

    </ParamField>

    <ParamField body="targetContentNetwork" type="boolean">

      Optional. Whether the campaign serves ads on the Google Display Network.

    </ParamField>

    <ParamField body="currency" type="string" required>

      Required. ISO 4217 currency code for the recommendation (for example, "USD" or "EUR").

      Constraints: `maxLength 10`.

    </ParamField>

    ## Response Object

    <ResponseField name="budgetRecommendation" type="BudgetRecommendation">

      The generated budget recommendation. Absent when insufficient data is available to produce a recommendation.

      <Expandable title="budgetRecommendation properties">

        <ResponseField name="currentBudgetAmountMicros" type="integer">

          Current campaign budget in micros, echoed from the request when provided.

        </ResponseField>

        <ResponseField name="recommendedBudgetAmountMicros" type="string">

          Google Ads recommended budget amount in micros (1,000,000 micros = 1 currency unit).

        </ResponseField>

        <ResponseField name="budgetOptions" type="BudgetOption[]">

          Alternative budget options with estimated performance impact for each.

          Constraints: `maxItems 10`.

          <Expandable title="budgetOptions properties">

            <ResponseField name="budgetAmountMicros" type="string">

              Budget amount in micros (1,000,000 micros = 1 currency unit).

            </ResponseField>

            <ResponseField name="impact" type="BudgetRecommendationImpact">

              Estimated impact of choosing this budget amount compared to the current budget.

              _Nested structure omitted for brevity — see the `BudgetRecommendationImpact` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="impact" type="BudgetRecommendationImpact">

          Estimated performance impact of adopting the recommended budget.

          <Expandable title="impact properties">

            <ResponseField name="baseMetrics" type="BudgetRecommendationMetrics">

              Estimated performance metrics at the current budget level.

              _Nested structure omitted for brevity — see the `BudgetRecommendationMetrics` object._

            </ResponseField>

            <ResponseField name="potentialMetrics" type="BudgetRecommendationMetrics">

              Estimated performance metrics if the budget option is applied.

              _Nested structure omitted for brevity — see the `BudgetRecommendationMetrics` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
