    Retrieves a list of deleted form schemas.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/form-schema-service/v4/forms/trash-bin
    ```

    ## Query Params

    <ParamField query="namespace" type="string" required>

      Namespace of the deleted form schemas to list.

      Constraints: `minLength 10`, `maxLength 50`.

    </ParamField>

    <ParamField query="disabled" type="boolean">

      Whether to filter for disabled deleted form schemas.

      **Deprecated:** Use `enabled` instead.

    </ParamField>

    <ParamField query="formIds" type="string[]">

      IDs of specific deleted form schemas to retrieve.

      When specified, only deleted form schemas with these IDs are returned.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="order" type="string">

      Order to list deleted forms in the response.

      Ordering options.

      - `UPDATED_DATE_ASC`: Order by `updatedDate` in ascending order.
      - `UPDATED_DATE_DESC`: Order by `updatedDate` in descending order.
      - `NAME_ASC`: Order by `properties.name` in ascending order.
      - `NAME_DESC`: Order by `properties.name` in descending order.

      Default: `UPDATED_DATE_DESC`

      **Supported values:**

      - `UPDATED_DATE_DESC` — Sort by updated date in descending order. Default.
      - `UPDATED_DATE_ASC` — Sort by updated date in ascending order.
      - `NAME_DESC` — Sort by name in descending order.
      - `NAME_ASC` — Sort by name in ascending order.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Cursor token pointing to a page of results. Not used in the first request. Following requests use the cursor token and not filter or `order`.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="paymentForm" type="boolean">

      Whether to filter for deleted payment form schemas.

      When `true`, returns only deleted form schemas that contain payment fields.
      When `false`, returns all deleted form schemas regardless of payment fields.

    </ParamField>

    <ParamField query="enabled" type="boolean">

      Whether to filter for enabled deleted form schemas.

      When `true`, returns only deleted form schemas that were enabled before deletion.
      When `false`, returns all deleted form schemas regardless of enabled status.

      Default: `true`

    </ParamField>

    ## Response Object

    <ResponseField name="forms" type="Form[]">

      The retrieved form schemas.

      Constraints: `maxItems 100`.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Details on the paged set of results returned.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Offset that was requested.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>
