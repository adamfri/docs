---
title: "App Permission Object"
description: "The App Permission object in the Wix App Permission API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="appId" type="string">

      App ID.

      You can find the app ID in the app's dashboard's [Home page](https://manage.wix.com/app-selector?title=Select+an+App&primaryButtonText=Select+Site&actionUrl=https%3A%2F%2Fdev.wix.com%2Fapps%2F%7BappId%7D%home).

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="permission" type="Permission">

      Permission the app requests when installed on a site.

      Learn more [about permissions for Wix apps](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

      <Expandable title="permission properties">

        <ResponseField name="permissionId" type="string">

          Permission ID.

          To find the permission ID, navigate to the [Permissions page](https://dev.wix.com/app-selector?title=Select+an+App&primaryButtonText=Select+Site&actionUrl=https%3A%2F%2Fdev.wix.com%2Fapps%2F%7BappId%7D%2Fdev-center-permissions/add) in the app's dashboard and search for the [permission you want to configure](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/configure-permissions-for-your-app#step-1--identify-required-permissions).

          Constraints: `minLength 1`, `maxLength 164`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      When the permission was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      When the permission was last updated.

      **Read-only.**

    </ResponseField>

  </Tab>
