Triggered when a reward is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.v1.reward_deleted` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty` |
