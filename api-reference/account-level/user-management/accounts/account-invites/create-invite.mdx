    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates and sends invite emails to a list of potential team members, inviting them to become team members of the requesting account.
    The invites may be limited to a specific resource (site or other asset).
    Maximum 50 invitees can be specified per call.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header. API keys are currently available to selected beta users only.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.IDENTITY.MANAGE-TEAM-MEMBERS">Manage Team Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invites/account-invite/create
    ```

    ## Body Params

    <ParamField body="subjectsAssignments" type="SubjectInviteAssignments[]" required>

      Array of potential team members' email addresses and their corresponding assignments (how they will be assigned when they accept the invite).

      Constraints: `minItems 1`, `maxItems 50`.

      <Expandable title="subjectsAssignments properties">

        <ParamField body="subjectEmail" type="string">

          Invitee's email address.

          Constraints: `format EMAIL`.

        </ParamField>

        <ParamField body="assignments" type="InviteResourceAssignment[]">

          Mapping of roles (referred to here as policies) and assets (referred to here as resources) that will be assigned to the invitee when they accept the invite. When no resources are specified, the invitee will be given access to everything within the account.

          <Expandable title="assignments properties">

            <ParamField body="policyId" type="string">

              Role ID.

            </ParamField>

            <ParamField body="assignments" type="InviteAssignment[]">

              Resources the user will be able to access.

              _Nested structure omitted for brevity — see the `InviteAssignment[]` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="defaultEmailLanguage" type="string">

      Language of emails to send. Relevant only for recipients that don't currently have a Wix user ID. Default: Site owner's language.

    </ParamField>

    ## Response Object

    <ResponseField name="successfulInvites" type="AccountInvite[]">

      Invites that were sent successfully.

      See the [Account Invite Object](/api-reference/account-level/user-management/accounts/account-invites/account-invite-object) for this object's fields.

    </ResponseField>

    <ResponseField name="failedInvites" type="InviteFailure[]">

      Invites that failed.

      <Expandable title="failedInvites properties">

        <ResponseField name="subjectEmail" type="string">

          Email address of the failed invite.

          Constraints: `format EMAIL`.

        </ResponseField>

        <ResponseField name="errorMessage" type="string">

          Error description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
