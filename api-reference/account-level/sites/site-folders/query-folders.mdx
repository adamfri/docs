    <div className="wix-ref">

    Retrieves a list folders, given the provided paging, sorting and filtering.
    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="FOLDERS.VIEW">FOLDERS.VIEW</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-folders/v2/folders/query
    ```

    ## Body Params

    <ParamField body="query" type="QueryV2">

      Filtering, sorting and paging for retrieving the folders.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter folders by name/id/parentId in the following format:
          `"filter" : {`
          "name": "my-folder",
          "id":&#123;"$in":["value1", "value2"]&#125;,
          "parentId": "value",
          &#125;`.`
          Examples:
          - `{"filter": {"name": "my folder"}}`
          - `{"filter": {"name": {"$startsWith" :"my folder"}}}`
          - `{"filter": {"name": {"$contains" :"my folder"}}}`
          - `{"filter": {"id": "d20c988a-5f6f-4b55-aeb1-0dfb7646da38"}}`
          - `{"filter": {"id":{"$in":["6a26dd24-af0b-474a-813a-c442093483a9", "d5f5f00d-b600-4114-8ff0-e86005c050ce"]}}}`
          - `{"filter": {"parentId":{"283f4660-8f6f-462b-94a1-160a57338032"}}}`
          - `{"filter": {"parentId": { "$exists": false }}}` - query root's folders

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"name","order":"ASC"}]`.
          Examples:
          - `{"sort": [{"fieldName":"name","order":"ASC"}]}`

          Constraints: `minItems 0`, `maxItems 4`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

            <ParamField body="origin" type="AddressLocation">

              Origin point for geo-distance sorting on a GEO field
              results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

              _Nested structure omitted for brevity — see the `AddressLocation` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

          <Expandable title="pagingMethod properties">

            <ParamField body="paging" type="Paging">

              Paging options to limit and skip the number of items (default limit is 1000).

              _Nested structure omitted for brevity — see the `Paging` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="folders" type="Folder[]">

      List of retrieved folders.
      Maximal number of retrieved folders is 1000.

      See the [Folder Object](/api-reference/account-level/sites/site-folders/folder-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadataV2">

      Meta data about the returned folders

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
