    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/delivery-profiles/delivery-carriers/set-active-status
    ```

    ## Body Params

    <ParamField body="carrierAppId" type="string" required>

      Carrier app ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="rowId" type="string" required>

      Row identifier in the carrier's dashboard settings table that identifies the specific shipping configuration to update.

      Pass the `row.key` field from the response of [List Delivery Carriers](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/list-delivery-carriers).

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="active" type="boolean" required>

      Whether the configuration defined in the row is active.

    </ParamField>

    ## Response Object
