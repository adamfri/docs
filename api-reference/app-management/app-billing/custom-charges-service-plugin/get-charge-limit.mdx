    <div className="wix-api-columns">

    <div className="wix-ref">

    Wix calls this method to retrieve the initial charge limit for a paid instance
    of your app. This happens every time a customer is upgrading to a paid version of
    your app.

    You can't update the charge limit after you've set an initial
    value. Customers can increase the limit in their site's dashboard, currently they
    aren't allowed to decrease it.

    <Note>

    This feature isn't yet available to all users. Your app can have only 1 usage-based plan and no other plans. To add a usage-based plan to your app, [submit a request to add a usage-based plan](https://www.wix.com/support-chatbot?nodeId=25a57397-ccf7-4376-8b74-48d51edf7159&referral=devRels).

    </Note>

    ## Endpoint

    ```http
    POST /v1/charge-limit
    ```

    ## Body Params

    <ParamField body="subscriptionId" type="string">

      ID of the subscription for which Wix retrieves the charge limit. Equals
      `null` in case Wix hasn't created the subscription when retrieving an
      initial charge limit. To track usage and billing for apps, we recommend to
      use `instanceId` instead of the `subscriptionId`.

    </ParamField>

    <ParamField body="currency" type="string">

      Supported values: `AUD`, `BRL`, `CAD`, `EUR`, `GBP`, `ILS`, `INR`, `JPY`, `MXN`, `PLN`, `RUB`, `TRY`, `USD`.

      3-letter currency code in
      [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)
      format of the charge limit. Wix may add supported currencies in the future.

      Constraints: `format CURRENCY`.

    </ParamField>

    <ParamField body="cycle" type="Cycle">

      Billing cycle the charge limit applies to.

      <Expandable title="cycle properties">

        <ParamField body="cycleType" type="string">

          Payment type.
          + `UNKNOWN`: The payment type hasn't been set.
          + `ONE_TIME`: The reseller pays Wix in a single payment.
          + `RECURRING`: The reseller pays Wix on a recurring schedule.

          **Supported values:**

          - `ONE_TIME`
          - `RECURRING`

        </ParamField>

        <ParamField body="cycleDuration" type="Duration">

          Duration of the billing cycle. Available only for `RECURRING` payments.

          <Expandable title="cycleDuration properties">

            <ParamField body="unit" type="string">

              Unit of the billing cycle.

              **Supported values:**

              - `DAY` — day
              - `WEEK` — week
              - `MONTH` — month
              - `YEAR` — year

            </ParamField>

            <ParamField body="count" type="integer">

              Count of units that make up the billing cycle.

              Constraints: `min 0`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="chargeLimit" type="string">

      Retrieved charge limit for the app instance. You can't update the
      charge limit after you've set an initial value. Site owners can increase the
      limit in their site's dashboard, currently they aren't allowed to decrease it.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
