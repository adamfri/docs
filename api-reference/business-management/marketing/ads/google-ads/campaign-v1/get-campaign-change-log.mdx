    Retrieves the full change log for a campaign — all status-changing events in chronological order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/campaigns/{campaignId}/change-log
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      ID of the campaign whose change log to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="entries" type="CampaignChangeLogEntry[]">

      Change log entries in chronological order. Maximum 1,000 items.

      Constraints: `maxItems 1000`.

      <Expandable title="entries properties">

        <ResponseField name="action" type="string">

          The type of action that occurred. Possible values: CREATED, CREATED_AS_LIVE, LAUNCHED, PAUSED, RESUMED, UPDATED, ENDED.

          Constraints: `maxLength 20`.

        </ResponseField>

        <ResponseField name="timestamp" type="datetime">

          Date and time the action occurred.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
