    Updates a branch.

    Each time the branch is updated, `revision` increments by 1. The current `revision` must be passed when updating the branch. This ensures you're working with the latest branch and prevents unintended overwrites.

    Note that `ORIGINAL_BRANCH` types can't be updated.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DOCUMENT-MANAGEMENT.MANAGE-BRANCHES">Manage Site Branches</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/branches/v1/branches/{branch.id}
    ```

    ## Path Params

    <ParamField path="branch.id" type="string" required>

      Branch ID.

    </ParamField>

    ## Body Params

    <ParamField body="branch" type="Branch" required>

      Branch to update.

      See the [Branch Object](/api-reference/business-management/branches/branch-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="branch" type="Branch">

      Updated branch.

      See the [Branch Object](/api-reference/business-management/branches/branch-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |

    | `428` | `FAILED_PRECONDITION` | `FORBIDDEN_UPDATE_ORIGINAL_BRANCH_TYPE` | Can't update branches with `ORIGINAL_BRANCH` type. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the branch is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the branch.

          **Read-only.**

        </ParamField>

        <ParamField body="type" type="string">

          Branch type.

          **Supported values:**

          - `USER` — A branch created by a site owner that can be accessed for editing and publishing in the editor.
          - `TECHNICAL` — A branch created for technical purposes, unrelated to site owners. For internal use, can't be accessed in the editor.
          - `ORIGINAL_BRANCH` — The original branch of the site, created when the site is created. Can be accessed for editing and publishing in the editor.

        </ParamField>

        <ParamField body="name" type="string">

          Branch name.

        </ParamField>

        <ParamField body="sourceType" type="string">

          Source type for this branch's content. Must be aligned with the corresponding source properties below.

          **Supported values:**

          - `SOURCE_BRANCH` — This branch's source was another branch. Must be used with `sourceBranchProperties`.

        </ParamField>

        <ParamField body="lastPublishDate" type="integer">

          Date and time the branch was last published.

          **Read-only.**

        </ParamField>

        <ParamField body="editorType" type="EditorType">

          Wix editor type.
          Provide this field only when the new branch uses a different editor than the branch it was created from, and the branch is not created from a template. Only `STUDIO_TWO` may be provided explicitly; otherwise the editor type is calculated automatically.

          Constraints: `immutable`.

          <Expandable title="editorType properties">

            <ParamField body="editorTypeOptions" type="string">

              Wix editor types.

              **Supported values:**

              - `STUDIO` — Wix Studio Editor.
              - `CLASSIC` — Wix's Classic Editor.
              - `HARMONY` — Wix Type Harmony Editor.
              - `STUDIO_TWO` — Wix StudioTwo Editor.

            </ParamField>
