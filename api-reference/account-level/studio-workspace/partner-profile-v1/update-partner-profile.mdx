    Updates a partner profile.

    Each time the partner profile is updated, `revision` increments by 1. The current `revision` must be passed when updating the partner profile. This ensures you're working with the latest partner profile and prevents unintended overwrites.

    After a successful update, the updated content enters the verification queue. Once verified, the changes are reflected in the corresponding public partner profile.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/partners/profile/v1/partner-profiles
    ```

    ## Body Params

    <ParamField body="partnerProfile" type="PartnerProfile" required>

      Partner profile to update.

      See the [Partner Profile Object](/api-reference/account-level/studio-workspace/partner-profile-v1/partner-profile-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="partnerProfile" type="PartnerProfile">

      Updated partner profile.

      See the [Partner Profile Object](/api-reference/account-level/studio-workspace/partner-profile-v1/partner-profile-object) for this object's fields.
