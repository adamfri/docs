    <div className="wix-ref">

    Submits a user message to an existing interactive form session and processes the conversational input, with real-time streaming.

    For implementations that prefer to wait for the complete response, call [Send User Message](https://dev.wix.com/docs/api-reference/crm/forms/interactive-form-sessions/send-user-message) instead.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/ai/v1/interactive-form-sessions/{interactiveFormSessionId}/send-user-message-streamed
    ```

    ## Path Params

    <ParamField path="interactiveFormSessionId" type="string" required>

      Interactive form session ID to send the message to.

    </ParamField>

    ## Body Params

    <ParamField body="input" type="string">

      User's natural language input to process.
      The AI assistant analyzes this text to extract form field data and determine the next conversation step.

    </ParamField>

    <ParamField body="currentValues" type="object">

      Form field values to apply to the session.
      Use this to update form data from other sources while the conversation is ongoing.
      These values override any existing data for the same field keys.
      For example: `{"lastName": "Smith", "phoneNumber": "+1234567890"}`.

    </ParamField>

    ## Response Object

    <ResponseField name="responseChunk" type="InteractiveFormSessionResponseChunk">

      AI assistant response chunk streamed in real-time as the message is processed.

      <Expandable title="responseChunk properties">

        <ResponseField name="chunkType" type="string">

          Response chunk type, that determines how the content should be processed and displayed.

          **Supported values:**

          - `TEXT` — Text message for display to the user.
          - `TEXT_DATA` — Structured data extracted from user input and mapped to form fields.
          - `MULTI_SELECT_INPUT` — Selector for selecting multiple options from a list.
          - `NUMBER_INPUT` — Selector for numeric input with optional validation.
          - `SEPARATOR` — Visual separator element such as paragraph breaks.
          - `SINGLE_SELECT_INPUT` — Selector for selecting one option from a list.
          - `ERROR` — Error message when processing fails or validation errors occur.
          - `SUBMISSION` — Form submission confirmation including a submission ID.
          - `IMPORTANT_TEXT` — Highlighted information that may influence form data extraction.
          - `DEBUG` — Diagnostic information for troubleshooting and development.
          - `END_OF_RESPONSE` — Signals the completion of a response stream.
          - `FILE_UPLOAD` — Input for file upload. Not supported.
          - `SIGNATURE` — Input for digital signature capture. Not supported.

        </ResponseField>

        <ResponseField name="meaningfulInput" type="MeaningfulInput">

          Indicates which portion of the original user input was meaningful for data extraction.
