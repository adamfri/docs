    Updates a recipient's information.

    Each time the recipient is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the recipient.
    This ensures you're working with the latest recipient and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/restaurants/recipient/v1/recipients/{recipient.id}
    ```

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Recipient ID.

      **Read-only.**

    </ParamField>

    <ParamField body="recipient" type="UpdateRecipient" required>

      Recipient to update. May be partial.

      <Expandable title="recipient properties">

        <ParamField body="_id" type="string">

          Recipient ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the Recipient is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the Recipient.

          Ignored when creating a Recipient.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the Recipient was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the Recipient was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="phone" type="string">

          Recipient's phone number for receiving notifications.

          Constraints: `format PHONE`.

        </ParamField>

        <ParamField body="businessLocationIds" type="string[]">

          IDs of the business locations this recipient should receive order creation notifications for.

          If this list is empty the recipient receives notifications for orders created at all locations.

          Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

        </ParamField>

        <ParamField body="channels" type="string[]">

          Communication channels for sending notifications to the recipient.

          At least 1 channel is required. Recipients can receive notifications
          through multiple channels simultaneously.

          Constraints: `minItems 1`, `maxItems 2`.

          **Supported values:**

          - `SMS` — Send notifications via SMS text messages.
          - `PHONE` — Send notifications via phone calls.

        </ParamField>

        <ParamField body="note" type="string">

          Additional information about the recipient.

          Use this field to store notes about the recipient's role, availability,
          or other relevant details for notification management.

        </ParamField>
