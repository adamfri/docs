  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Counts comments, given the specified filtering. Comments with the `HIDDEN` status are not included in the response.

    See [Query Comments](https://dev.wix.com/docs/rest/crm/community/comments/comments/query-comments) for a list of supported filters.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.MANAGE.COMMENTS">Manage Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/comments/v1/comments/count
    ```

    ## Body Params

    <ParamField body="appId" type="string">

      App ID to count the comments of.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="filter" type="object">

      Filter to identify the comments that need to be counted.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of comments.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_TO_COUNT` | Number of comments exceeds the server's limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
