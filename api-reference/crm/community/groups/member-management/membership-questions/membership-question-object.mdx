Question asked to members when joining a group.
Only group admins can create or update membership questions
and can set whether it is required to answer membership questions.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Question ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="required" type="boolean">

      Whether a member must answer this question when joining the group.

    </ResponseField>

    <ResponseField name="text" type="string">

      Question text.

      Constraints: `minLength 1`, `maxLength 300`.

    </ResponseField>

  </Tab>

  <Tab title="SDK">

    <ResponseField name="_id" type="string">

      Question ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="required" type="boolean">

      Whether a member must answer this question when joining the group.

    </ResponseField>

    <ResponseField name="text" type="string">

      Question text.

      Constraints: `minLength 1`, `maxLength 300`.

    </ResponseField>

  </Tab>

</Tabs>
