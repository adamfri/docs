    Retrieves a list of all delivery carriers installed on a site.

    Use this method to discover available carriers before adding them to delivery regions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.READ-ECOM">Read eCommerce - all read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/delivery-profiles/installed-carriers
    ```

    ## Response Object

    <ResponseField name="installedDeliveryCarriers" type="InstalledDeliveryCarrier[]">

      List of installed delivery carriers on the site.

      Constraints: `maxItems 100`.

      <Expandable title="installedDeliveryCarriers properties">

        <ResponseField name="id" type="string">

          Carrier app ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Carrier display name.

          Constraints: `maxLength 256`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Carrier description.

        </ResponseField>

        <ResponseField name="learnMoreUrl" type="string">

          URL to learn more about the carrier.

        </ResponseField>

        <ResponseField name="dashboardUrl" type="string">

          URL to the carrier's dashboard.

        </ResponseField>

        <ResponseField name="fallbackDefinitionMandatory" type="boolean">

          Whether a backup rate is required for this carrier.

        </ResponseField>

        <ResponseField name="thumbnailUrl" type="string">

          URL for the carrier's thumbnail image.

        </ResponseField>

        <ResponseField name="toggleGetCarrierSettingsEnabled" type="boolean">

          Whether the carrier supports retrieving carrier settings.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
