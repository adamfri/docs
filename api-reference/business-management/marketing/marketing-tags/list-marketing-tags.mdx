    <div className="wix-ref">

    Retrieves marketing tags given the provided filter.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MARKETING.READ-TAGS">Read Marketing Tags</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/marketing/v1/tags
    ```

    ## Query Params

    <ParamField query="filter" type="Filter">

      optional filter

      <Expandable title="filter properties">

        <ParamField query="byType" type="string">

          Filter by tag type.

          **Supported values:**

          - `GOOGLE_ADS`
          - `GOOGLE_ANALYTICS`
          - `YANDEX_METRICA`
          - `FACEBOOK_PIXEL`
          - `GOOGLE_TAG_MANAGER`
          - `TIKTOK_PIXEL`
          - `GOOGLE_TAG_MANAGER_CONSENT_MODE`
          - `GOOGLE_ANALYTICS_CONSENT_MODE`

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="tags" type="MarketingTag[]">

      List of marketing tags.

      See the [Tag Object](/api-reference/business-management/marketing/marketing-tags/tag-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
