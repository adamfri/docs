    <div className="wix-ref">

    Sends a gift card notification email to the recipient.

    Use this method to deliver gift cards via email, either immediately after creation
    or at a scheduled time. The recipient email can be specified in the request to
    override the gift card's stored recipient information.

    <Note>

    Premium site is a requirement for this functionality.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gift-cards/v1/gift-cards/{giftCardId}/send-email
    ```

    ## Path Params

    <ParamField path="giftCardId" type="string" required>

      Gift card ID.

    </ParamField>

    ## Body Params

    <ParamField body="recipientEmail" type="string">

      Recipient email address to send the gift card notification.
      If not provided, uses the recipient email stored in the gift card's notification info.

    </ParamField>

    ## Response Object

    Returns `SendGiftCardEmailResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_NOT_FOUND` |  |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_RECIPIENT_NOT_FOUND` |  |
    | `428` | `FAILED_PRECONDITION` | `SITE_IS_NOT_PREMIUM` | Gift card functionalities requires the site to be premium. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
