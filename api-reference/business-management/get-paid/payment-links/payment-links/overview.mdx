Payment links are unique URLs that Wix users can send to customers, allowing them to make convenient online payments for goods and services.
Learn more about [payment links](https://support.wix.com/en/article/wix-pay-links-creating-and-managing-pay-links).

## SDK package

```bash
npm install @wix/get-paid
```

Import the `paymentLinks` namespace from `@wix/get-paid`.
