    <div className="wix-ref">

    Creates a category.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_WRITE">Category write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/categories/v1/categories
    ```

    ## Body Params

    <ParamField body="category" type="Category" required>

      Category to create.

      See the [Category Object](/api-reference/business-solutions/stores/catalog-v3/categories/category-object) for this object's fields.

    </ParamField>

    <ParamField body="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField body="appNamespace" type="string" required>

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField body="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Constraints: `maxItems 100`.

      **Supported values:**

      - `BREADCRUMBS_INFO`
      - `DESCRIPTION`
      - `RICH_CONTENT_DESCRIPTION`

    </ParamField>

    ## Response Object

    <ResponseField name="category" type="Category">

      Created category.

      See the [Category Object](/api-reference/business-solutions/stores/catalog-v3/categories/category-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NAMESPACE_NOT_FOUND_IN_DEV_CENTER` | Couldn't find the app with the specified `treeReference.appNamespace` in the [app dashboard](https://dev.wix.com/dc3/my-apps/). |
    | `409` | `ALREADY_EXISTS` | `DUPLICATE_SLUG` | There is already a category with this `slug`. |
    | `409` | `ALREADY_EXISTS` | `DUPLICATE_HANDLE` | There is already a category with this `handle`. |
    | `428` | `FAILED_PRECONDITION` | `CATEGORIES_LIMIT_PER_TREE_EXCEEDED` | Number of categories exceeds the tree's limit of 1000. |
    | `404` | `NOT_FOUND` | `PARENT_CATEGORY_NOT_IN_TREE` | Category's `parentCategoryId` must belong to the same tree as `treeReference`. |
    | `428` | `FAILED_PRECONDITION` | `TREES_LIMIT_EXCEEDED` | Number of trees exceeds the site's limit. |
    | `428` | `FAILED_PRECONDITION` | `CATEGORY_DEPTH_LIMIT_EXCEEDED` | Category depth exceeds the limit of 4 levels. |
    | `428` | `FAILED_PRECONDITION` | `PARENT_CATEGORY_HIDDEN` | Category can't be visible when its parent category isn't visible. |
    | `400` | `INVALID_ARGUMENT` | `ID_NOT_ALLOWED_IN_REQUEST` | Passing category id in request is only allowed with permission CATEGORIES.CATEGORIES_WRITE_ENTITY_ID |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SLUG_FORMAT` | The `slug` provided is not a valid URL slug. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Category Created | `wix.categories.v1.category_created` | Triggered when a category is created. |
