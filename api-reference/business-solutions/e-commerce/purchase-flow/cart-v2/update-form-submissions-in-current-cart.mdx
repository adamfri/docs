    Updates form submissions associated with the customer's current cart line items.

    Forms are defined by catalog apps and used for collecting additional information per line item (for example, personalization text or event details).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2">Write Carts V2</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/current/update-forms-submission
    ```

    ## Body Params

    <ParamField body="formSubmissions" type="FormSubmission[]">

      Form submission data to set on the current cart.

      Constraints: `minItems 1`, `maxItems 1000`.

      <Expandable title="formSubmissions properties">

        <ParamField body="id" type="string">

          Form instance ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="formSubmissionId" type="string">

          Form submission ID.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="cart" type="Cart">

      Updated cart.

      See the [Cart Object](/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/cart-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Cart Updated | `wix.ecom.v2.cart_updated` | Triggered when a cart is updated. |

    </div>
