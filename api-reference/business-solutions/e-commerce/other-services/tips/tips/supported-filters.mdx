<Note>This article applies to the REST API only.</Note>

Query endpoints allow you to filter and sort results based on service properties.
This article covers field support for filtering and sorting.

The following table shows field support for filters and sorting
for the `tipDistributions` object in
[Query Tip Distributions](fallback::https://dev.wix.com/docs/rest/business-solutions/e-commerce/tips/tips/query-tip-distributions):

| Field           | Supported Filters                             | Sortable |
| --------------- | --------------------------------------------- | -------- |
| `id` | `$eq`, `$ne`, `$in`, `$exists` | Sortable |
| `tipId` | `$eq`, `$ne`, `$in`, `$exists` | Sortable |
| `transaction.transactionDate` | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$exists` | Sortable |
| `transaction.transactionId` | `$eq`, `$ne`, `$in`, `$exists` | Sortable |
| `orderId` | `$eq`, `$ne`, `$in`, `$exists` | Sortable |
| `staff.id` | `$eq`, `$ne`, `$in`, `$exists` | Sortable |
| `createdDate` | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$exists` | Sortable |
