    Retrieves a list of disputes, given the provided paging, filtering, and sorting.

    Query Disputes runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order
    - `paging.limit` is `50`
    - `paging.offset` is `0`

    To learn how to query disputes, see
    [About the Wix API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `chargeId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `stage` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `status` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Examples

    Retrieves disputes using filters and sorting options

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/payments/disputes/v1/disputes/query' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "query": {
          "filter": {
            "status": "WAITING_MERCHANT",
            "createdDate": {
              "$gte": "2024-01-01T00:00:00.000Z"
            }
          },
          "sort": [
            {
              "fieldName": "createdDate",
              "order": "DESC"
            }
          ],
          "paging": {
            "limit": 50
          }
        }
      }'
      ```

      ```json Response
      curl -X GET \
      'https://www.wixapis.com/payments/disputes/v1/disputes/query?query.filter.status=WAITING_MERCHANT&query.paging.limit=20' \
      -H 'Authorization: <AUTH>'
      ```
