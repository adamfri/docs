    Publishes a previously created item by its `id`.

    The item can be a draft or a scheduled item. To schedule the item for a future date, set `scheduledDate`; otherwise it's published immediately.

    Published items appear on the site's Social Media Marketing page in the dashboard.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-publisher/v1/publish-by-id
    ```

    ## Body Params

    <ParamField body="id" type="string" required>

      ID of the item to publish.

    </ParamField>

    <ParamField body="scheduledDate" type="datetime">

      Date and time to publish the item. If omitted, the item is published immediately.

    </ParamField>

    ## Response Object

    <ResponseField name="item" type="Item">

      Published item.

      See the [Item Object](/api-reference/business-management/marketing/social-media/item-v1/item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `REFERENCE_ID_ALREADY_EXIST` | An item with this `referenceId` already exists. |
    | `428` | `FAILED_PRECONDITION` | `INELIGIBLE_FOR_FEATURE` | The site's social media marketing plan doesn't permit this action, or its quota for the current period is exhausted. |
    | `429` | `RESOURCE_EXHAUSTED` | `PUBLISH_LIMIT_EXCEEDED` | The site has reached its publishing rate limit. Try again later. |
    | `428` | `FAILED_PRECONDITION` | `MULTI_STORY_PUBLISH_NOT_SUPPORTED` | Story items with more than one media item must be published with Publish Multi Story Draft. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
