Triggered when a marketing tag is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.marketing.v1.tag_created` |
| Package | `@wix/marketing-tags` |
| Permissions | `Manage Marketing Tags`, `Read Marketing Tags` |
