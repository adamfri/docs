    Sets buyer info on a draft order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/ecom/v1/draft-orders/set-buyer-info
    ```

    ## Body Params

    <ParamField body="draftOrderId" type="string" required>

      Draft order ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="buyerInfo" type="BuyerInfo">

      > **Note:** Passing an empty object will remove the existing buyer info.

      <Expandable title="buyerInfo properties">

        <ParamField body="contactId" type="string">

        </ParamField>

        <ParamField body="email" type="string">

          Buyer's email address.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="id" type="id">

          id

          <Expandable title="id properties">

            <ParamField body="visitorId" type="string">

              Visitor ID. Returned when the buyer isn't a logged-in site member.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="memberId" type="string">

              Member ID. Returned when the buyer is a logged-in site member.
