    </Info>

    Retrieves the provider state for the current account.
    Each provider account has exactly one provider state, created during marketplace registration, so no ID is
    required - the state is resolved from the calling account's identity. `id` on the returned state equals the
    provider's account ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/marketplace/v1/provider-states
    ```

    ## Response Object

    <ResponseField name="providerState" type="ProviderState">

      Retrieved provider state.

      See the [Providerstate Object](/api-reference/account-level/studio-workspace/marketplace/provider-state-v1/providerstate-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
