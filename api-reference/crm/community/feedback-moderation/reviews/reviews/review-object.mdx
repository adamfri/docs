---
title: "Review Object"
description: "A Review object includes all of the details related to the review of an entity."
icon: "cube"
---

A Review object includes all of the details related to the review of an entity.
An entity is a specific resource to review, for example, a store product.
You can manage existing reviews, create new reviews, and retrieve reviews.
Read more about [Adding and Setting Up Wix Reviews](https://support.wix.com/en/article/wix-stores-adding-and-setting-up-wix-reviews).

<Tabs>

  <Tab title="REST">

    <ResponseField name="namespace" type="string">

      Review namespace.

      Supported values:
      + Wix Stores: `stores`

      Currently, only Wix Stores is fully integrated with the Wix Reviews app.

    </ResponseField>

    <ResponseField name="entityId" type="string">

      ID of the entity to review. For example, a Wix Stores product ID.

      Constraints: `maxLength 36`.

    </ResponseField>

    <ResponseField name="id" type="string">

      Review ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="content" type="ReviewContent">

      Review content.

      <Expandable title="content properties">

        <ResponseField name="title" type="string">

          Review title.

        </ResponseField>

        <ResponseField name="body" type="string">

          Review body.

          Max: 3,000 characters

        </ResponseField>

        <ResponseField name="media" type="Media[]">

          List of media items associated with the review.

          Max: 10 items

          Constraints: `maxItems 10`.

        </ResponseField>

        <ResponseField name="rating" type="integer">

          Rating of the review.

          Min: `1` &lt;br />
          Max: `5`

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the review was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the review was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="author" type="Author">

      Author of the review.

      <Expandable title="author properties">

        <ResponseField name="contactId" type="string">

          Contact ID of the author.

        </ResponseField>

        <ResponseField name="authorName" type="string">

          Display name of the author.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="reply" type="Reply">

      Reply to the review.

      **Read-only.**

      <Expandable title="reply properties">

        <ResponseField name="message" type="string">

          Reply content.

          Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the reply was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the reply was updated.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="foundHelpful" type="integer">

      Number of site visitors who found the review helpful.

      **Read-only.**

    </ResponseField>

    <ResponseField name="foundUnhelpful" type="integer">

      Number of site visitors who found the review unhelpful.

      **Read-only.**

    </ResponseField>

    <ResponseField name="helpfulness" type="integer">

      Helpfulness score.

      Calculated by subtracting `foundUnhelpful` from `foundHelpful`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="moderation" type="Moderation">

      Moderation status of the review.

      **Read-only.**

      <Expandable title="moderation properties">

        <ResponseField name="moderationStatus" type="string">

          Supported states of the review.

          **Supported values:**

          - `APPROVED` — The review is approved and published.
          - `IN_MODERATION` — The review is pending moderation. Moderation can be applied in the Wix user's [dashboard](https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Freviews/pending).
          - `REJECTED` — The review is rejected and not visible on the site.
          - `SUBMITTED` — Initial status of the review before the moderation process.
          - `SKIPPED` — Moderation was skipped and the review was published instantly because moderation is disabled.

        </ResponseField>

        <ResponseField name="manuallyChanged" type="boolean">

          Indicates whether a moderator manually changed the `moderationStatus` of the review.

          If the `moderationStatus` changed automatically because the review
          passed the moderation rules or if moderation is turned off, this field is set to `false`.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the review is updated.
      To prevent conflicting changes,
      the current `revision` must be passed when updating the review.
      Ignored when creating a review.

      **Read-only.**

    </ResponseField>

    <ResponseField name="verified" type="boolean">

      Whether the review has been verified.

      **Read-only.**

    </ResponseField>

    <ResponseField name="origin" type="Origin">

      Origin of a review.

      **Read-only.**

      <Expandable title="origin properties">

        <ResponseField name="type" type="string">

          Origin type.

          **Supported values:**

          - `ORGANIC` — Review was created directly by members or site visitors.
          - `APP` — Review was created through an app. Includes reviews created through an app even if the author is a member or site visitor.

        </ResponseField>

        <ResponseField name="appId" type="string">

          The app ID of the origin for the review.
          Only available when the `origin.type` is `"APP"`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="reviewDate" type="datetime">

      Date and time when the review was written.
      This should match `createdDate`, except for reviews imported from another system.

    </ResponseField>

    <ResponseField name="relevanceScore" type="number">

      Platform-calculated score of review's relevance to the item.
      Used to sort reviews by relevance.

      **Read-only.**

    </ResponseField>

    <ResponseField name="publishCount" type="integer">

      Number of times a review has been published.

      **Read-only.**

    </ResponseField>

      ```json Object
      {

        "entityId": "df19c1f7-07d8-a265-42f8-e8dfa824cc6e",
        "content": 
        {
          "title": "Excellent Laptop with Great Features",
          "body": "This laptop excels in speed, battery life, display quality, and is great for both work and gaming.",

                "width": 1572,
                "altText": "laptop.jpeg",
                "filename": "laptop.jpeg"
              }
            }
          ],
          "rating": 4
        },
        "createdDate": "2023-05-15T13:09:26.856Z",
        "updatedDate": "2023-05-15T13:09:27.270Z",
        "author": 
        {
          "contactId": "453faee9-8e67-45f1-87dc-f247bdf3510e",
          "authorName": "Joey"
        },
        "foundHelpful": 0,
        "foundUnhelpful": 0,
        "helpfulness": 0,
        "moderation": 
        {
          "moderationStatus": "APPROVED",
          "manuallyChanged": false
        },
        "verified": false,
        "origin": {
          "type": "ORGANIC"
        },
        "publishCount": 1
      }
      ```
