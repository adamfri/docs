    <div className="wix-ref">

    Removes site members from a specific group.

    Only group admins can remove members from their group.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/social-groups-proxy/members/v2/groups/{groupId}/members
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Query Params

    <ParamField query="memberIds" type="string[]">

      Member IDs. See the Members API for details.

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    ## Response Object

    Returns `RemoveGroupMembersResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Member Removed | `wix.social_groups.v2.group_member_removed` | Triggered when a member is removed from a group. |

    </div>
