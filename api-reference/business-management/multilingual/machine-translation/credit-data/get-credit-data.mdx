    <div className="wix-ref">

    Retrieves a site's word credit data.

    For sites with a limited quota, you can calculate the available word credits by subtracting the credits used from the quota.
    For example, if a site has a quota of 100 credits and all credits have been used (`"creditsUsed": 100`), the available word credits will be 0.
    If a Wix user purchases an additional 50 credits, the `quota` will increase to `150`, and the site will have 50 available word credits.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/translation-credits/v1/credit
    ```

    ## Response Object
