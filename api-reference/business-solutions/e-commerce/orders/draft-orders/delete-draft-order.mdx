<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a draft order along with all its pending changes.

    Draft orders with status 'COMMITTED' cannot be deleted.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}
    ```

    ## Path Params

    <ParamField path="draftOrderId" type="string" required>

      Draft order ID.

    </ParamField>

    ## Response Object

    Returns `DeleteDraftOrderResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DRAFT_ORDER_DOES_NOT_EXIST` | Couldn't find the draft order. |
    | `428` | `FAILED_PRECONDITION` | `DRAFT_ORDER_CANNOT_BE_DELETED` | Can't delete draft order due to ownership or status validation. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Draft Order Deleted | `wix.ecom.v1.draft_order_deleted` | Triggered when a draft order is deleted. |

    </div>
