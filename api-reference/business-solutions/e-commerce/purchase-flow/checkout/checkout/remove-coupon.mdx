    Removes the coupon from a specified checkout.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkouts/{id}/remove-coupon
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the checkout to remove the coupon from.

    </ParamField>

    ## Response Object

    <ResponseField name="checkout" type="Checkout">

      Updated checkout after removal of coupon.

      See the [Checkout Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout/checkout-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Updated | `wix.ecom.v1.checkout_updated` | Triggered when a checkout is updated. |
