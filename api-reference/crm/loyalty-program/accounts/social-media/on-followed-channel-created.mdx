## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.socialmedia.v1.followed_channel_created` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty`, `Manage Restaurants - all permissions` |
