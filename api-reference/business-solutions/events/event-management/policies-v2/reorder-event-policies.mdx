    <div className="wix-ref">

    Changes policy order in an event dashboard and agreement checkbox on the checkout form.
    By default, policies are arranged by the created date in descending order.

    <Note>

    It is possible to use both `beforePolicyId` and `afterPolicyId` at the same time but only the last one defined will be executed.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-POLICIES">Manage Policies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v2/policies/reorder
    ```

    ## Body Params

    <ParamField body="eventId" type="string" required>

      Event ID to which the policy belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="policyId" type="string" required>

      ID of the policy to reorder.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="policies" type="Policy[]">

      Policies in the new order.

      See the [Policy Object](/api-reference/business-solutions/events/event-management/policies-v2/policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_REORDER_INSTRUCTION` | Both `beforePolicyId` and `afterPolicyId` can't be specified at the same time. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Policy Updated | `wix.events.v2.policy_updated` | Triggered when a policy is updated. |

    </div>
