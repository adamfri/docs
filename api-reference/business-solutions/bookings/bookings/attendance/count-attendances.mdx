    Counts attendance records for the calling [member](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/introduction).
    The member is identified from the site member ID in the `Authorization` header's auth token.
    Calls with other [identity types](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) return a `PERMISSION_DENIED` error.
    Returns the total number of attendance records matching the provided filters.
    If no filters are provided, returns the count of all attendance records for the caller.

    Filter the results by providing a `filter` object with any of the following fields:

    + `status`: Filter by attendance status. Supported values: `ATTENDED`, `NOT_ATTENDED`.
    + `serviceId`: Filter by service ID. Accepts a single ID or an array of IDs.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-SENSITIVE">Read Bookings - Including Participants</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/attendance/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter criteria for counting attendance records. If not provided, counts all attendance records for the contact.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total number of attendance records matching the filters.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
