    Creates multiple fulfillments for one or more orders.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/fulfillments/orders/bulk/create-fulfillments
    ```

    ## Body Params

    <ParamField body="ordersWithFulfillments" type="BulkCreateOrderWithFulfillments[]" required>

      List of order IDs and their associated fulfillments.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="ordersWithFulfillments properties">

        <ParamField body="orderId" type="string" required>

          Order ID.

          Constraints: `minLength 1`, `maxLength 100`.

        </ParamField>

        <ParamField body="fulfillments" type="Fulfillment[]" required>

          Fulfillments associated with the order.

          Constraints: `minItems 1`.

          <Expandable title="fulfillments properties">

            <ParamField body="id" type="string">

              Fulfillment ID.

              **Read-only.**

            </ParamField>

            <ParamField body="createdDate" type="datetime">

              Fulfillment creation date and time in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#Combined_date_and_time_representations) format.

              **Read-only.**

            </ParamField>

            <ParamField body="lineItems" type="FulfillmentLineItem[]" required>

              Line items being fulfilled.

              Constraints: `minItems 0`, `maxItems 300`.

              _Nested structure omitted for brevity — see the `FulfillmentLineItem[]` object._

            </ParamField>

            <ParamField body="status" type="string">

              The current status of the fulfillment process.

              Supported values (case-sensitive, any other value is rejected):
              + `"Pending"` - Initial state when fulfillment is created but processing hasn't started.
              + `"Accepted"` - Order has been received and validated for fulfillment.
              + `"Ready"` - Items have been picked and packed, ready for shipping.
              + `"In_Delivery"` - Items have been handed over to the shipping carrier.
              + `"Fulfilled"` - Delivery has been completed successfully.

              The status typically progresses from `Pending` to `Accepted`, `Ready`, `In_Delivery`, and finally `Fulfilled`.
              Update the status manually or automatically depending on your fulfillment workflow.

              This field is informational. The order's `fulfillmentStatus` is primarily derived from the fulfilled line item quantities, not from this field.

            </ParamField>

            <ParamField body="completed" type="boolean">

              Fulfillment handling complete.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
