    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/bulk/pool-definitions/delete
    ```

    ## Body Params

    <ParamField body="poolDefinitionIds" type="string[]" required>

      List of IDs of the pool definitions to delete.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="cascade" type="string">

      *Required**. Determines when the changes to these pool definitions the program definitions containing it will be applied to associated programs and pools.

      **Supported values:**

      - `UNKNOWN_CASCADE` — Unknown cascade.
      - `NEXT_RENEWAL` — Changes are applied to existing programs and pools when they are next renewed.
      - `IMMEDIATELY` — Changes are applied to associated programs and pools immediately.
      - `FUTURE_PROVISIONS` — Changes are not applied to existing associated programs and pools. They are only applied to future programs and pools.

    </ParamField>
