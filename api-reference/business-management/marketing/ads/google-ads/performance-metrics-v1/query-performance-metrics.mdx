    Retrieves a list of daily performance metrics for a campaign, given the provided filtering and sorting.
    Queries clicks, impressions, CTR, cost, leads, and phone calls from Google Ads in parallel.
    Use the fields parameter to control which metrics are returned. When includePreviousPeriod is true,
    the response also includes a previousPeriodSummaryRow and trends showing decimal percentage changes.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/performance-metrics
    ```

    ## Body Params

    <ParamField body="campaignResourceName" type="string" required>

      Google Ads resource name of the campaign to query, in the format `customers/{customerId}/campaigns/{campaignId}`.

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField body="dateRange" type="DateRange">

      Date range to query. When omitted, defaults to the campaign lifetime.

      <Expandable title="One of the following">

        <ParamField body="Range" type="Range">

          Range

          <Expandable title="Range properties">

            <ParamField body="custom" type="CustomDateRange">

              Custom date range.

              _Nested structure omitted for brevity — see the `CustomDateRange` object._

            </ParamField>

            <ParamField body="predefined" type="string">

              Predefined date range.

              **Supported values:**

              - `UNSPECIFIED` — Not specified.
              - `TODAY` — Today only.
              - `YESTERDAY` — Yesterday only.
              - `LAST_7_DAYS` — The last 7 days not including today.
              - `LAST_BUSINESS_WEEK` — The 5 day business week, Monday through Friday, of the previous business week.
              - `THIS_MONTH` — All days in the current month.
              - `LAST_MONTH` — All days in the previous month.
              - `LAST_14_DAYS` — The last 14 days not including today.
              - `LAST_30_DAYS` — The last 30 days not including today.
              - `THIS_WEEK_SUN_TODAY` — The period between the previous Sunday and the current day.
              - `THIS_WEEK_MON_TODAY` — The period between the previous Monday and the current day.
              - `LAST_WEEK_SUN_SAT` — The 7-day period starting with the previous Sunday.
              - `LAST_WEEK_MON_SUN` — The 7-day period starting with the previous Monday.
              - `LIFETIME` — Since the beginning of the campaign.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="sort" type="PerformanceSorting">

      Sorting to apply. Defaults to descending by date when omitted.

      <Expandable title="sort properties">

        <ParamField body="field" type="string">

          Metric field to sort by.

          **Supported values:**

          - `UNSPECIFIED` — Unknown field. Do not use.
          - `IMPRESSIONS` — Number of times the ad was shown.
          - `CLICKS` — Number of clicks on the ad.
          - `CTR` — Click-through rate expressed as a decimal, for example 0.05 for 5%.
          - `DATE` — The date of the metric row, in YYYY-MM-DD format.
          - `PHONE_CALLS` — Number of phone calls initiated through the ad.
          - `LEADS` — Number of leads generated by the campaign.
          - `COST` — Total amount spent on the campaign in the account's currency.
          - `COST_PER_CLICK` — Average cost per click in the account's currency.
          - `CLICKS_BY_AD_NETWORK_TYPE` — Click count broken down by ad network type.
          - `IMPRESSIONS_BY_AD_NETWORK_TYPE` — Impression count broken down by ad network type.

        </ParamField>

        <ParamField body="order" type="string">

          Sort direction.

          **Supported values:**

          - `ASC` — Ascending order.
          - `DESC` — Descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fields" type="string[]">

      Metrics to include in each result row. When omitted, defaults to clicks, impressions, CTR, cost, phone calls, and date.

      Constraints: `maxItems 1000`.

      **Supported values:**

      - `UNSPECIFIED` — Unknown field. Do not use.
      - `IMPRESSIONS` — Number of times the ad was shown.
      - `CLICKS` — Number of clicks on the ad.
      - `CTR` — Click-through rate expressed as a decimal, for example 0.05 for 5%.
      - `DATE` — The date of the metric row, in YYYY-MM-DD format.
      - `PHONE_CALLS` — Number of phone calls initiated through the ad.
      - `LEADS` — Number of leads generated by the campaign.
      - `COST` — Total amount spent on the campaign in the account's currency.
      - `COST_PER_CLICK` — Average cost per click in the account's currency.
      - `CLICKS_BY_AD_NETWORK_TYPE` — Click count broken down by ad network type.
      - `IMPRESSIONS_BY_AD_NETWORK_TYPE` — Impression count broken down by ad network type.

    </ParamField>

    <ParamField body="includePreviousPeriod" type="boolean">

      When true, the response includes previousPeriodSummaryRow and trends showing percentage changes relative to the equivalent preceding period.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="PerformanceMetrics[]">

      Daily performance metric rows for the requested date range.

      Constraints: `maxItems 1000`.

      See the [Performance Metrics Object](/api-reference/business-management/marketing/ads/google-ads/performance-metrics-v1/performance-metrics-object) for this object's fields.

    </ResponseField>

    <ResponseField name="summaryRow" type="PerformanceMetrics">

      Aggregated totals across all result rows.

      See the [Performance Metrics Object](/api-reference/business-management/marketing/ads/google-ads/performance-metrics-v1/performance-metrics-object) for this object's fields.

    </ResponseField>

    <ResponseField name="previousPeriodSummaryRow" type="PerformanceMetrics">

      Aggregated totals for the equivalent preceding period. Only present when includePreviousPeriod was true.

      See the [Performance Metrics Object](/api-reference/business-management/marketing/ads/google-ads/performance-metrics-v1/performance-metrics-object) for this object's fields.

    </ResponseField>

    <ResponseField name="trends" type="PerformanceMetricsTrends">

      Decimal percentage changes between the current and previous period summary rows. Only present when includePreviousPeriod was true.

      <Expandable title="trends properties">

        <ResponseField name="impressions" type="number">

          Impressions change as a decimal percentage, for example 0.10 for a 10% increase or -0.05 for a 5% decrease.

          **Read-only.**

        </ResponseField>

        <ResponseField name="clicks" type="number">

          Clicks change as a decimal percentage, for example 0.10 for a 10% increase or -0.05 for a 5% decrease.

          **Read-only.**

        </ResponseField>

        <ResponseField name="ctr" type="number">

          CTR change as a decimal percentage, for example 0.10 for a 10% increase or -0.05 for a 5% decrease.

          **Read-only.**

        </ResponseField>

        <ResponseField name="phoneCalls" type="number">

          Phone calls change as a decimal percentage, for example 0.10 for a 10% increase or -0.05 for a 5% decrease.

          **Read-only.**

        </ResponseField>

        <ResponseField name="leads" type="number">

          Leads change as a decimal percentage, for example 0.10 for a 10% increase or -0.05 for a 5% decrease.

        </ResponseField>

        <ResponseField name="cost" type="number">

          Cost change as a decimal percentage, for example 0.10 for a 10% increase or -0.05 for a 5% decrease.

        </ResponseField>

    </ResponseField>
