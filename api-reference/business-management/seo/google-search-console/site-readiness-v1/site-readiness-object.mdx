The site's standing in Google Search Console setup.

A read projection assembled from the connected Google account. It carries
no Google identity and no credentials.

<Tabs>

  <Tab title="REST">

    <ResponseField name="status" type="string">

      Whether the site has completed Google Search Console setup.

      **Read-only.**

      **Supported values:**

      - `UNKNOWN_READINESS_STATUS` — Unknown readiness status.
      - `READY` — The site is fully set up in Google Search Console.
      - `NOT_READY` — Setup isn't complete. See `blockingReason` for the step that's missing.

    </ResponseField>

    <ResponseField name="blockingReason" type="string">

      The first setup step that's still blocking the site.
      Only returned when `status` is `NOT_READY`.

      **Read-only.**

      **Supported values:**

      - `UNKNOWN_BLOCKING_REASON` — Unknown blocking reason.
      - `TOKEN_INVALID` — The stored Google credentials are no longer usable. Reconnect the Google
      account with the GSC Connection API.
      - `SITE_OWNER_NOT_VERIFIED` — Site ownership hasn't been verified with Google. Call Verify Site.
      - `DOMAIN_MISSING` — The site doesn't have a premium domain, which Google Search Console
      setup requires.
      - `SITE_NOT_CREATED` — The site hasn't been created yet.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "status": "NOT_READY",
        "blockingReason": "SITE_OWNER_NOT_VERIFIED"
      }
      ```

    </CodeGroup>
