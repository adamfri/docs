    Updates a checkout template.

    If the info in a checkout template is updated, only new checkouts created from this template will include the updated items. Checkouts previously
    created from this template before the update will not be affected.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v1/checkout-templates/{checkoutTemplate.id}
    ```

    ## Path Params

    <ParamField path="checkoutTemplate.id" type="string" required>

      Checkout template ID.

    </ParamField>

    ## Body Params

    <ParamField body="checkoutTemplate" type="CheckoutTemplate" required>

      Checkout template info to update.

      See the [Checkout Template Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout-templates/checkout-template-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutTemplate" type="CheckoutTemplate">

      Updated checkout template.

      See the [Checkout Template Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout-templates/checkout-template-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_CHECKOUT_TEMPLATE_WITHOUT_SPECIFIED_FIELDS` | No fields specified to update. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_CHECKOUT_TEMPLATE_WITH_UNSUPPORTED_FIELD` | Unsupported field in the update request. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_CHECKOUT_UPDATE_TEMPLATE_WITH_UNKNOWN_STATUS` | Unknown status value. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_CHECKOUT_TEMPLATE_WITH_EMPTY_ITEMS` | Checkout template can't be updated with an empty items list. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Template Updated | `wix.ecom.v1.checkout_template_updated` | Triggered when a checkout template is updated. |

              Type of selected payment option for current item. Defaults to `FULL_PAYMENT_ONLINE`.

              + `FULL_PAYMENT_ONLINE` - Entire payment for this item happens as part of the checkout.
              + `FULL_PAYMENT_OFFLINE` - Entire payment for this item happens after the checkout. For example, when using cash, check, or other offline payment methods.
              + `MEMBERSHIP` - Payment for this item is done by charging a membership. When this option is used, `lineItem.price.amount` is 0.
              + `DEPOSIT_ONLINE` -  Partial payment for the given item to be paid upfront during the checkout. Amount to be paid is defined by deposit_amount field.

              **Supported values:**

              - `FULL_PAYMENT_ONLINE` — The entire payment for this item happens as part of the checkout.
              - `FULL_PAYMENT_OFFLINE` — The entire payment for this item happens after checkout. For example, when using cash, check, or other offline payment methods.
              - `MEMBERSHIP` — Payment for this item is done by charging a membership. Any remaining amount not covered by the membership, such as item modifiers, is paid online.
              - `DEPOSIT_ONLINE` — Partial payment to be paid upfront during checkout. The initial amount to be paid for each line item is specified in `depositAmount`.
              - `MEMBERSHIP_OFFLINE` — Payment for this item can only be done by charging a membership and must be manually redeemed in the dashboard by the site admin. When selected, `price` is `0`.
              - `MEMBERSHIP_ONLINE_WITH_OFFLINE_REMAINDER` — Item price is charged to online membership. Any remaining amount not covered by the membership, such as item modifiers, is paid offline.
