    Deletes multiple question entries.

    Deleting a question entry permanently removes it from the site's Wix FAQ dashboard page.

    To delete a single question entry, call the Delete Question Entry method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/faq/question-entry/v2/bulk/question-entries/delete
    ```

    ## Body Params

    <ParamField body="questionEntryIds" type="string[]" required>

      IDs of question entries to delete.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>
