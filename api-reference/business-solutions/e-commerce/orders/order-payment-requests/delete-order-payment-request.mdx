    Deletes an order payment request.

    You can delete an order payment request in any status except `PAID`. Attempting to delete a `PAID` order payment request fails with `CANNOT_DELETE_PAID_ORDER_PAYMENT_REQUEST`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/ecom/v1/order-payment-requests/{orderPaymentRequestId}
    ```

    ## Path Params

    <ParamField path="orderPaymentRequestId" type="string" required>

      ID of the order payment request to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteOrderPaymentRequestResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_PAID_ORDER_PAYMENT_REQUEST` | Order payment requests with a `status` of `PAID` can't be deleted. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Payment Request Deleted | `wix.ecom.v1.order_payment_request_deleted` | Triggered when an order payment request is deleted. |

    </div>
