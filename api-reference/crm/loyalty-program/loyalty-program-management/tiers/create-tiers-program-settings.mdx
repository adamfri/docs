    Create tiers program settings.

    Tiers program settings apply globally to all tiers in the program.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-tiers/v1/tiers/program-settings
    ```

    ## Body Params

    <ParamField body="programSettings" type="TiersProgramSettings" required>

      Tiers program settings.

      <Expandable title="programSettings properties">

        <ParamField body="status" type="string">

          Tiers program status.

          **Supported values:**

          - `DISABLED` — Tiers are disabled.
          - `DRAFT` — Tiers are enabled but not yet active.
          - `ACTIVE` — Tiers are active.
          - `PAUSED` — Tiers are paused.

        </ParamField>

        <ParamField body="revision" type="integer">

          Revision number, which increments by 1 each time the loyalty tiers settings are updated.

          To prevent conflicting changes, the current `revision` must be passed when updating the loyalty tiers settings.

        </ParamField>

        <ParamField body="createdDate" type="datetime">

          Date and time the loyalty tiers program was created.

          **Read-only.**

        </ParamField>

        <ParamField body="updatedDate" type="datetime">

          Date and time the loyalty tiers program was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="baseTierDefinition" type="TierDefinition">

          Information about the base loyalty tier.

          The base tier is the default tier for any account that's unassigned for not meeting
          the required points threshold of any other tier.

          <Expandable title="baseTierDefinition properties">

            <ParamField body="icon" type="Image">

              Details about the tier icon.

              _Nested structure omitted for brevity — see the `Image` object._

            </ParamField>

            <ParamField body="name" type="string">

              Tier name.

            </ParamField>

            <ParamField body="description" type="string">

              Tier description.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="period" type="period">

          period

          <Expandable title="period properties">

            <ParamField body="rollingWindow" type="RollingWindow">

              **Required.**
              Period of time used to calculate loyalty points for tier assignment.

              The loyalty points accumulated during this period determine if the account meets a tier's required point threshold.

              _Nested structure omitted for brevity — see the `RollingWindow` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>
