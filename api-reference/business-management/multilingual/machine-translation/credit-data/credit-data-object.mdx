---

<Tabs>

  <Tab title="REST">

    <ResponseField name="creditsUsed" type="integer">

      Total number of word credits consumed by a site. For sites with an unlimited word credit quota, this property still reflects the number of credits used, even though no usage limit applies.

    </ResponseField>

    <ResponseField name="quotaType" type="string">

      Quota type.

      **Supported values:**

      - `LIMITED` — Limited word credit quota.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "creditData": {
          "creditsUsed": 100,
          "quotaType": "LIMITED",
          "limitedQuota": {
            "quota": 3000
          }
        }
      }
      ```

    </CodeGroup>
