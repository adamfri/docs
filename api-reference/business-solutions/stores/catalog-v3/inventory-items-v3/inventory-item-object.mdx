Inventory Item.

Each inventory item represents a specific product variant at a specific location.
The combination of `variantId` and `locationId` is unique — you can't have two inventory items for the same variant at the same location.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Inventory item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the inventory item is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the inventory item.

      Ignored when creating an inventory item.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the inventory item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the inventory item was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="variantId" type="string">

      Variant ID.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="locationId" type="string">

      Stores location ID. If not specified when creating an inventory item, the store's default location is used.

    </ResponseField>

    <ResponseField name="productId" type="string">

      Product ID.

      Constraints: `minLength 1`, `maxLength 36`, `immutable`.

    </ResponseField>

    <ResponseField name="trackQuantity" type="boolean">

      Whether the quantity is being tracked.

      **Read-only.**

    </ResponseField>

    <ResponseField name="availabilityStatus" type="string">

      Inventory item availability status.

      **Read-only.**

      **Supported values:**

      - `OUT_OF_STOCK` — Item is out of stock. For tracked inventory, `quantity` is zero or negative and preorder isn't available.
      - `IN_STOCK` — Item is in stock and available for purchase. For tracked inventory, see the `quantity` field for the exact amount in stock.
      - `PREORDER` — Item is available for preorder only. Stock is zero or negative, but preorder is enabled with remaining capacity.

    </ResponseField>

    <ResponseField name="preorderInfo" type="PreorderInfo">

      Item preorder info.

      Preorder settings are configured per inventory item, so each variant-location combination can have its own preorder configuration.

      > **Note:** The product entity's `inventory.preorderStatus` and `inventory.preorderAvailability` fields reflect only the default location's preorder state.

      <Expandable title="preorderInfo properties">

        <ResponseField name="enabled" type="boolean">

          Whether preorder is enabled for this inventory item.

          > **Note:** Preorder can't be enabled for digital products or products with subscriptions.

          Default: `false`

        </ResponseField>

        <ResponseField name="message" type="string">

          Message displayed to customers when the item is out of stock and preorder is enabled.

        </ResponseField>

        <ResponseField name="limit" type="integer">

          Maximum number of items that can be preordered after stock reaches zero.

          Supported only for inventory items with `trackQuantity = true`.

          Default: `100000`

        </ResponseField>

        <ResponseField name="counter" type="integer">

          Number of times this item has been preordered.

          Supported only for inventory items with `trackQuantity = true`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="quantity" type="integer">

          Remaining quantity available for preorder.

          Supported only for items with `trackQuantity` set to `true`.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="product" type="Product">

      Associated product and variant details.

      **Read-only.**

      <Expandable title="product properties">

        <ResponseField name="name" type="string">

          Product name.

        </ResponseField>

        <ResponseField name="directCategoryIds" type="string[]">

          List of category IDs that this product is included in directly.

          Constraints: `format GUID`, `maxItems 2000`.

        </ResponseField>

        <ResponseField name="variantName" type="string">

          Variant name.

        </ResponseField>

        <ResponseField name="variantSku" type="string">

          Variant SKU (stock keeping unit).

        </ResponseField>

        <ResponseField name="variantVisible" type="boolean">

          Whether the variant is visible in the store.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the inventory item object.

      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "inventoryItem": {
          "id": "9c346207-6467-434f-aa9e-8999c32d119d",
          "revision": "3",
          "createdDate": "2024-06-27T09:23:55.186Z",
          "updatedDate": "2024-07-03T11:27:03.993Z",
          "variantId": "590cef15-c81d-4ed7-970c-1ff879946306",
          "locationId": "8fb0985f-9027-43d6-b4f9-c4c4f5324194",
          "productId": "babd2bcc-ea03-4b63-8053-0ec59c73fc36",
          "quantity": 0,
          "trackQuantity": true,
          "availabilityStatus": "PREORDER",
          "preorderInfo": {
            "enabled": true,
            "counter": 2,
            "limit": 10,
            "message": "Expected shipping by June",
            "quantity": 8
          },
          "product": {
            "name": "t shirt",
            "directCategoryIds": [
              "05f9cc2f-b5df-4287-aa32-3314179192b8"
            ]
          },
          "extendedFields": null
        }
      }
      ```

    </CodeGroup>
