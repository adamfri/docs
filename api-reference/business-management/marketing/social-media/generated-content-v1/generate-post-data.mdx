    Generates post content for one or more social channels.

    Returns per-channel post payloads matching an item's content, so you can use the result to create a draft or publish. Provide site assets, a text prompt, or both.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-publisher/v1/generate-post-data
    ```

    ## Body Params

    <ParamField body="siteAssets" type="SiteAsset[]">

      Site assets the generated post is based on.

      Constraints: `maxItems 10`.

      <Expandable title="siteAssets properties">

        <ParamField body="id" type="string">

          ID of the asset in the Wix app that owns it. For example, a product ID for a `STORES_PRODUCT` asset.

        </ParamField>

        <ParamField body="type" type="string">

          Type of asset.

          **Supported values:**

          - `BLOG_POST` — A Wix Blog post.
          - `EVENT` — A Wix Events event.
          - `STORES_PRODUCT` — A Wix Stores product.
          - `BOOKINGS_SERVICE` — A Wix Bookings service.
          - `STORES_COUPON` — A Wix Stores coupon.
          - `STORES_CATEGORY` — A Wix Stores category.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="userInput" type="string">

      Free-form guidance for the generated post content.

    </ParamField>

    <ParamField body="media" type="Media[]">

      Candidate media for the generated post. Accepts images only. Each item carries a `type` (must be image), a `url`, and an optional Wix Media Manager `fileId` for media already in Wix.

      Constraints: `maxItems 10`.

      <Expandable title="media properties">

        <ParamField body="type" type="string">

          Media type.

          **Supported values:**

          - `IMAGE`
          - `VIDEO`

        </ParamField>

        <ParamField body="url" type="string">

          Media URL.

        </ParamField>

        <ParamField body="fileId" type="string">

          Media Manager file ID backing the media. Available only when the media is stored in the Media Manager.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="context" type="object">

      Additional context to incorporate into the generated content.

    </ParamField>

    <ParamField body="channels" type="string[]">

      Channels to generate post content for. When empty, the response includes one entry for each supported channel: Instagram, Facebook, LinkedIn, Pinterest, Google Business Profile, and TikTok. A non-empty value narrows the response to the requested channels.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `INSTAGRAM`
      - `FACEBOOK`
      - `YOUTUBE`
      - `LINKEDIN`
      - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
      - `PINTEREST`
      - `GBP` — Google Business Profile.
      - `TIKTOK`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="ChannelPostData[]">

      Generated post content, one entry per requested channel.

      <Expandable title="results properties">

        <ResponseField name="channelName" type="string">

          Channel the content is generated for.

          **Supported values:**

          - `INSTAGRAM`
          - `FACEBOOK`
          - `YOUTUBE`
          - `LINKEDIN`
          - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
          - `PINTEREST`
          - `GBP` — Google Business Profile.
          - `TIKTOK`

        </ResponseField>

      </Expandable>

    </ResponseField>
