<Note>This article applies to the REST API only.</Note>

This article covers field support for filtering, sorting, and searching in the Reservations API.

## Query Reservations

The following table shows field support for filters and sorting
for the reservation object when using Query Reservations:

| Field                               | Supported Filters                              | Sortable |
| ----------------------------------- | ---------------------------------------------- | -------- |
| `id`                                | `$eq`, `$ne`, `$in`                            |          |
| `status`                            | `$eq`, `$ne`, `$in`                            |          |
| `details.startDate`                 | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sortable  |
| `archived`                          | `$eq`, `$ne`, `$in`                            |          |

__Related content:__
[API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
[Query Reservations](https://dev.wix.com/docs/rest/api-reference/wix-restaurants/reservations/reservations/query-reservations)

## Search Reservations

The following table shows field support for filters and sorting
for the reservation object when using Search Reservations:

| Field                           | Supported Filters                              | Sortable |
|---------------------------------| ---------------------------------------------- | -------- |
| `source`                        | `$eq`, `$ne`, `$in`                            |          |
| `status`                        | `$eq`, `$ne`, `$in`                            |          |
| `details.reservationLocationId` | `$eq`, `$ne`, `$in`                            |          |
| `reservee.contactId`            | `$eq`, `$ne`, `$in`                            |          |
| `details.tables.ids`            | `$eq`, `$has_all`, `$has_some`, `$empty`       |          |
| `details.startDate`             | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sortable |
| `details.partySize`             | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sortable |
| `createdDate`                   | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sortable |
| `updatedDate`                   | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in` | Sortable |
| `archived`                      | `$eq`, `$ne`, `$in`                            |           |

The following fields in the reservation object are searchable:
- `reservee.firstName`
- `reservee.lastName`
- `reservee.phone`
- `reservee.email`
