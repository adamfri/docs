  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the tip choice that's currently selected by the customer for a specific eCommerce checkout ([SDK](https://dev.wix.com/docs/sdk/backend-modules/ecom/checkout/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/checkout/introduction)).
    If the customer hasn't yet selected a tip choice, the response is empty.

    Please refer to the Sample Flows for more information.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/tips/v1/tips/choice/{purchaseFlowId}
    ```

    ## Path Params

    <ParamField path="purchaseFlowId" type="string" required>

      ID of the purchase flow that's associated with the
      eCommerce order ([SDK](https://dev.wix.com/docs/sdk/backend-modules/ecom/orders/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/orders/order-object)).

      The purchase flow ID is a persistent ID that correlates between the various eCommerce elements: cart, checkout, and order.

    </ParamField>

    ## Response Object

    <ResponseField name="tipChoice" type="TipChoice">

      Tip choice that's currently selected for the given purchase flow.

      <Expandable title="tipChoice properties">

        <ResponseField name="value" type="string">

          Value of the tip choice.

        </ResponseField>

        <ResponseField name="tipType" type="string">

          Type of the tip choice.

          **Supported values:**

          - `UNKNOWN_TIP_TYPE` — There is no information about the tip type.
          - `PERCENTAGE` — The tip is calculated as a percentage of the subtotal of associated line items.
          - `AMOUNT` — The tip is a fixed value, pre-configured from the relevant settings presets.
          - `CUSTOM` — The customer, or the business on behalf of the customer, manually set a tip amount, which may not match any preset values.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `PERSON_IDENTITY_NOT_FOUND` | Couldn't find the person identity. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
