A tier is a loyalty level that customers are assigned to based on the amount of points they earn.
Read more [about loyalty tiers](https://support.wix.com/en/article/about-tiers).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Tier ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="tierDefinition" type="TierDefinition">

      Information about the tier.

      <Expandable title="tierDefinition properties">

        <ResponseField name="icon" type="Image">

          Details about the tier icon.

          <Expandable title="icon properties">

            <ResponseField name="id" type="string">

              WixMedia image ID.

            </ResponseField>

            <ResponseField name="url" type="string">

              Image URL.

            </ResponseField>

            <ResponseField name="height" type="integer">

              Original image height.

              **Read-only.**

            </ResponseField>

            <ResponseField name="width" type="integer">

              Original image width.

              **Read-only.**

            </ResponseField>

            <ResponseField name="altText" type="string">

              Image alt text.

            </ResponseField>

            <ResponseField name="filename" type="string">

              Image filename.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="name" type="string">

          Tier name.

        </ResponseField>

        <ResponseField name="description" type="string">

          Tier description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="requiredPoints" type="integer">

      The amount of points required to be in this tier.

      Constraints: `min 0`, `max 9999999`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the loyalty tier is updated.

      To prevent conflicting changes, the current `revision` must be passed when updating the loyalty tier.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the tier was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the tier was last updated.

      **Read-only.**

    </ResponseField>

      ```json Object
      {

        },
        "requiredPoints": 200,
        "revision": "2",
        "createdDate": "2024-02-15T14:22:02.539Z",
        "updatedDate": "2024-04-17T11:34:25.274Z"
      }
      ```

    </CodeGroup>
