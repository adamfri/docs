    You can also use this method to perform data aggregations on a site's table reservation fields.

              Name of the field to sort by.

              - `ASC` — Sort by ascending order.
              - `DESC` — Sort by descending order.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="aggregations" type="Aggregation[]">

          A search method for grouping data into various categories (facets) and providing summaries for each category.
          For example, use aggregations to allow site visitors to narrow down their search results by selecting specific reservation statuses, party sizes, etc.

          Constraints: `maxItems 100`.

          <Expandable title="aggregations properties">

            <ParamField body="name" type="string" />

            <ParamField body="type" type="string">

              **Supported values:**

              - `UNKNOWN_AGGREGATION_TYPE` — Undefined aggregation type.
              - `VALUE` — An aggregation where result buckets are dynamically built - one per unique value.
              - `RANGE` — An aggregation where you can define a set of ranges - each representing a bucket.
              - `SCALAR` — A single-value metric aggregation - such as min, max, sum, or avg.
              - `DATE_HISTOGRAM` — An aggregation where result buckets are dynamically built - one per time interval such as hour, day, or week.
              - `NESTED` — Multi-level aggregation, where each next aggregation is nested within the previous one.

            </ParamField>

            <ParamField body="fieldPath" type="string">

              Constraints: `maxLength 1000`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="search" type="SearchDetails">

          Free text to match in searchable fields.

          <Expandable title="search properties">

            <ParamField body="mode" type="string">

              Boolean search mode. Defines how separate search terms in the `expression` are combined.

              **Supported values:**

              - `OR` — Returns instances where any terms in the expression occur.
              - `AND` — Returns instances where all the terms in the expression occur.

            </ParamField>

            <ParamField body="expression" type="string">

              Search term or expression.

            </ParamField>

            <ParamField body="fields" type="string[]">

              Fields to search in.

              Searchable fields are `reservee.firstName`, `reservee.lastName`, `reservee.phone`, and `reservee.email`.

              If the array is empty, all fields are searched.

              Constraints: `maxLength 1000`, `maxItems 100`.

            </ParamField>

            <ParamField body="fuzzy" type="boolean">

              Whether to allow the search function to automatically correct typos or minor mistakes in the search expression.
              The search function uses an algorithm to find results that are close to what the site visitor typed.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="timeZone" type="string">
