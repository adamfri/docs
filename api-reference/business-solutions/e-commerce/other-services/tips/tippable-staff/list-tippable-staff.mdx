    Retrieves a list of up to 100 staff who are eligible to receive tips, given
    the provided filtering.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/tips-staff/v1/eligible-staff
    ```

    ## Query Params

    <ParamField query="includeWixUsers" type="boolean">

      Whether to include staff who are only Wix users and not
      Bookings staff members ([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/staff-members/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/staff-members/staff-member-object))
      in the response. Setting `{"includeWixUsers": true}` returns all tippable
      staff, including Bookings staff, site collaborators, or those who are both.
      By default, or if you provide `{"includeWixUsers": false}`, only Bookings
      staff members or those who are both are returned.

      Default: `false`.

    </ParamField>

    <ParamField query="filterByName" type="string">

      Filters the returned staff by name. If you provide a name as filter, only
      staff whose names start with the given input are returned. The filter isn't
      case sensitive.

      Max: 500 characters

    </ParamField>

    <ParamField query="filterByIds" type="string[]">

      Filters the returned staff by ID. If you provide a list of IDs as filter,
      only staff members with exact matching IDs are returned.

      Max: 100 IDs

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="staff" type="Staff[]">

      Retrieved staff.

      Constraints: `maxItems 100`.

      See the [Staff Object](/api-reference/business-solutions/e-commerce/other-services/tips/tippable-staff/staff-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
