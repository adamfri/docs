    Retrieves a policy.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-POLICIES">Read Policies</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v2/policies/{policyId}
    ```

    ## Path Params

    <ParamField path="policyId" type="string" required>

      ID of the policy to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="policy" type="Policy">

      Retrieved policy.

      See the [Policy Object](/api-reference/business-solutions/events/event-management/policies-v2/policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
