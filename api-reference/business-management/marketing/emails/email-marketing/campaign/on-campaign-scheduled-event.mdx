| Property | Value |
| --- | --- |
| Event type | `wix.email_marketing.v1.campaign_campaign_scheduled_event` |

| Permissions | `Manage Stores`, `Access Verticals by Automations`, `Set Up Automations`, `Read Email Marketing`, `Manage Email Marketing` |
