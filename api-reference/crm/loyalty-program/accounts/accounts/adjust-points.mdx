    Adjusts the point balance of a loyalty account.

    You can adjust the balance in two ways:
    - `balance` allows you to set the total points balance to this new amount. The transaction `type` will return as `"ADJUST"`.
    - `amount` allows you to adjust the points balance by this amount. This amount can be a positive number to increase the points balance or a negative number to decrease the balance. The transaction `type` will return as `"GIVE"`.

    An account may not be adjusted to result in a negative balance. If you pass an integer in both the `balance` and the `amount` parameters then the `balance` adjustment takes effect and the
    `amount` adjustment is ignored.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-accounts/v1/accounts/{accountId}/adjust-points
    ```

    ## Path Params

    <ParamField path="accountId" type="string" required>

      Loyalty account ID.

    </ParamField>

    ## Body Params

    <ParamField body="description" type="string">

      Description to explain the reason for the points adjustment.

    </ParamField>

    <ParamField body="revision" type="number">

      Each time the loyalty account is updated, `revision` increments by 1.

      The current `revision` must be passed when adjusting points in the loyalty account. This
      ensures you're working with the latest version of the loyalty account and prevents unintended overwrites.

      Constraints: `min 1`.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="LoyaltyAccount">

      Loyalty account.

      See the [Account Object](/api-reference/crm/loyalty-program/accounts/accounts/account-object) for this object's fields.

    </ResponseField>

    <ResponseField name="transactionId" type="string">

      Transaction ID associated with the points adjustment.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
