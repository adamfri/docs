    Updates a member's properties.

    Members are typically associated with a contact, each having a distinct member ID and contact ID. When specifying the ID as a parameter, don't presume the IDs are identical since they represent separate entities.

    The `privacyStatus` and `loginEmail` field can't be updated. You can call [Leave Community](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/leave-community) or [Join Community](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/join-community) to update `privacyStatus`.

    To clear a field's value, set an empty value with an empty string `""`.

    Note that updating the `contact.addresses`, `contact.emails`, or `contact.phones` array overwrites
    the entire array, so any existing values you want to retain should be specified in the Update Member call
    along with the new values to add. However, passing an empty array will have no effect and the following
    methods must be called to clear all the data from these respective arrays:
    - To clear `contact.addresses`, call [Delete Member Addresses](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/delete-member-addresses).
    - To clear `contact.emails`, call [Delete Member Emails](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/delete-member-emails).
    - To clear `contact.phones`, call [Delete Member Phones](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/delete-member-phones).
