    Deletes multiple locales.

    This method removes only secondary locals from a site. The primary locale can't be deleted.

    <Warning>

    This method permanently deletes multiple secondary locales and their data from the site.

    </Warning>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/locales/v2/bulk/locale/delete
    ```

    ## Body Params

    <ParamField body="localeIds" type="string[]" required>

      IDs of locales to delete.

      Constraints: `format LANGUAGE_TAG`, `maxLength 20`, `minItems 1`, `maxItems 100`.

    </ParamField>
