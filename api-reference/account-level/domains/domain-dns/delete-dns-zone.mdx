<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a DNS zone in [Google's Cloud DNS](https://cloud.google.com/dns).

    The call is synchronous, that means it fails in case of an error on
    Google's side.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.MANAGE_DNS_ZONES">DOMAINS.MANAGE_DNS_ZONES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/domains/v1/dns-zones/{domainName}
    ```

    ## Path Params

    <ParamField path="domainName" type="string" required>

      Domain name to delete the DNS zone for.

    </ParamField>

    ## Response Object

    Returns `DeleteDnsZoneResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
