A transaction is a record of a change to a balance.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Transaction ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the transaction is updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the transaction was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the transaction was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="pool" type="PoolInfo">

      Pool associated with this transaction.

      **Read-only.**

      <Expandable title="pool properties">

        <ResponseField name="id" type="string">

          Pool ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="poolDefinitionId" type="string">

          ID of the pool definition the pool was created from.

          **Read-only.**

        </ResponseField>

        <ResponseField name="programDefinitionId" type="string">

          ID of the program definition containing the pool definition the pool was created from.

          **Read-only.**

        </ResponseField>

        <ResponseField name="externalProgramDefinitionId" type="string">

          External ID of the program definition the pool was created from.

          **Read-only.**

        </ResponseField>

        <ResponseField name="programId" type="string">

          ID of the program that contains the pool.

          **Read-only.**

        </ResponseField>

        <ResponseField name="externalProgramId" type="string">

          External ID of the program that contains the pool.

          **Read-only.**

        </ResponseField>

        <ResponseField name="creditAmount" type="string">

          Available credits.

          **Read-only.**

        </ResponseField>

        <ResponseField name="namespace" type="string">

          Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Pool name

          **Read-only.**

        </ResponseField>

        <ResponseField name="benefitDisplayName" type="string">

          Benefit name

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="amount" type="string">

      Amount the balance was adjusted in this transaction.

      Constraints: `>= 0`.

    </ResponseField>

    <ResponseField name="source" type="string">

      Where the credits came from.

      **Supported values:**

      - `AVAILABLE` — In a pool's balance.
      - `EXTERNAL` — Outside a pool's balance.

    </ResponseField>

    <ResponseField name="target" type="string">

      Where the credits went to.

      **Supported values:**

      - `AVAILABLE` — In a pool's balance.
      - `EXTERNAL` — Outside a pool's balance.

    </ResponseField>

    <ResponseField name="idempotencyKey" type="string">

      Unique identifier, generated by the client.
      Used to recognize repeated attempts to make the same request.

      **Read-only.** Constraints: `maxLength 200`.

    </ResponseField>

    <ResponseField name="relatedTransactionId" type="string">

      ID of the related transaction. For example, if this transaction is a refund for a benefit redemption, the related transaction is the benefit redemption transaction.

      **Read-only.**

    </ResponseField>

    <ResponseField name="beneficiary" type="IdentificationData">

      Beneficiary of the pool associated with this transaction.

      **Read-only.** Constraints: `immutable`.

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="instructingParty" type="IdentificationData">

      Identity that created the transaction.

      **Read-only.** Constraints: `immutable`.

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Transaction status.

      **Supported values:**

      - `PENDING` — Transaction is pending. This is the initial transaction status.
      - `COMPLETED` — Transaction completed successfully.
      - `FAILED` — Transaction failed.

    </ResponseField>

    <ResponseField name="details" type="TransactionDetails">

      Additional transaction details.

      **Read-only.**

      <Expandable title="details properties">

        <ResponseField name="item" type="Item">

          Item associated with the transaction.

          **Read-only.**

          <Expandable title="item properties">

            <ResponseField name="id" type="string">

              Item ID.

              **Read-only.**

            </ResponseField>

            <ResponseField name="externalId" type="string">

              Item external ID.

              **Read-only.**

            </ResponseField>

            <ResponseField name="category" type="string">

              Item category.

              **Read-only.**

            </ResponseField>

            <ResponseField name="itemSetId" type="string">

              Item set ID.

              **Read-only.**

            </ResponseField>

            <ResponseField name="displayName" type="string">

              Item name.

              **Read-only.**

            </ResponseField>

            <ResponseField name="providerAppId" type="string">

              Provider app id

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="itemCount" type="integer">

          Amount of items associated with the transaction.

        </ResponseField>

        <ResponseField name="effectiveDate" type="datetime">

          Date and time the transaction was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="reason" type="string">

          Reason for the transaction. For example, `Redemption`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="benefitKey" type="string">

          Benefit key associated with the transaction.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the transaction object.

      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="externalId" type="string">

      External transaction ID.

      **Read-only.**

    </ResponseField>
