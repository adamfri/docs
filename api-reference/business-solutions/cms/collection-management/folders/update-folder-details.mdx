  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a folder's details.

    <Note>

    Details of the root folder can't be updated.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/wix-data/v1/folders/{folderId}/details
    ```

    ## Path Params

    <ParamField path="folderId" type="string" required>

      Folder ID.

    </ParamField>

    ## Body Params

    <ParamField body="folderDetails" type="FolderDetails">

      Folder details to update.

      Details that aren't specified remain unchanged.

      <Expandable title="folderDetails properties">

        <ParamField body="name" type="string">

          Folder name as it appears in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-collection-folders).

        </ParamField>

        <ParamField body="description" type="string">

          Folder description.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="folder" type="Folder">

      Updated folder.

      See the [Folder Object](/api-reference/business-solutions/cms/collection-management/folders/folder-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `FOLDER_NOT_FOUND` | Couldn't find the folder. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X PATCH https://wixapis.com/autocms/v1/folders/593c732f-d781-4457-b4a9-7ad73ddf4b1a/details  \
          -H 'Authorization: <AUTH>' \
          -H 'Content-Type: application/json' \

              "folders": []
          }
      }
      ```
