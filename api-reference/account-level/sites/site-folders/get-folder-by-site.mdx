<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Returns data about the folder that contains the specified site.
    <Note>

    If the specified site is root level, the returned folder object will be empty.
    **Important**: You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="FOLDERS.VIEW">FOLDERS.VIEW</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/site-folders/v2/folders/sites/{siteId}
    ```

    ## Path Params

    <ParamField path="siteId" type="string" required>

      Site ID.

    </ParamField>

    ## Response Object

    <ResponseField name="folder" type="Folder">

      Folder containing the specified site. Empty if site is at root level.

      See the [Folder Object](/api-reference/account-level/sites/site-folders/folder-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">
