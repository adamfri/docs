    Approves group requests.

    Only Wix users can approve group requests.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/social-groups-proxy/group-requests/v2/group-requests/approve
    ```

    ## Body Params

    <ParamField body="groupRequestIds" type="string[]">

      Group request IDs to approve. Limited to `100`.

      Constraints: `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="groupRequest" type="GroupRequest[]">

      Approved group requests.

      See the [Group Request Object](/api-reference/crm/community/groups/create-group-requests/group-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Group Request Approved | `wix.social_groups.v2.group_request_approved` | Triggered when a group request is approved. |

    </div>
