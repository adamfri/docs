    Retrieves the count of found accounts, given the provided filters and search capabilities.

    Use with Search Accounts to retrieve the total amount of loyalty accounts on a site.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-accounts/v1/accounts/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Search mode. Defines the search logic for combining multiple terms in the `expression`.

          **Supported values:**

          - `OR` — At least one of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Constraints: `min 0`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
