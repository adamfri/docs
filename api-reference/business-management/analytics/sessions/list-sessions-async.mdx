    <div className="wix-api-columns">

    <div className="wix-ref">

    Start an async job to retrieve a list of session IDs, given the specified filters. The following filters **must** be passed:
    - Time period, either predefined or custom.
    - Session filter, either navigation flow (page interactions), conversion funnel steps, or device type.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ANALYTICS-AND-REPORTS.MANAGE-SESSIONS">Manage Session Recording Analytics - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/analytics/v1/sessions/list/async
    ```

    ## Body Params

    <ParamField body="timezone" type="string">

      User's timezone. Defaults to timezone as set in the [Site Properties API](https://dev.wix.com/docs/rest/business-management/site-properties/properties/properties-object).

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      List sessions job ID.
      Pass this ID to Get List Sessions Job Result to retrieve job details and metadata.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
