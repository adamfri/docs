    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates a translation content item by ID.

    To remove a field, pass the field key with an empty object as the value. For example:

    ```json
    {
    "fields": {
    "title": {}
    }
    }
    ```

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_CONTENT">Wix Multilingual - Write Translation Content</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/translation-content/v1/contents/{content.id}
    ```

    ## Path Params

    <ParamField path="content.id" type="string" required>

      Translation content ID.

    </ParamField>

    ## Body Params

    <ParamField body="content" type="Content" required>

      Translation content to update.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ParamField>

    <ParamField body="forceFieldsTimestampUpdate" type="boolean">

      If true each field updated in fields map will also update the timestamp fields

      even if the field value is not changed, otherwise the timestamp fields will be updated only if the field value has changed

    </ParamField>

    ## Response Object

    <ResponseField name="content" type="Content">

      Updated translation content.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Content Updated | `wix.multilingual.translation.v1.content_updated` | Triggered when translation content is updated. |

    </div>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Translation content ID.

      **Read-only.**

    </ParamField>

    <ParamField body="content" type="UpdateContent" required>

      Translation content to update.

      <Expandable title="content properties">

        <ParamField body="_id" type="string">

          Translation content ID.

          **Read-only.**

        </ParamField>

        <ParamField body="schemaId" type="string" required>

          Translation schema ID.

          Constraints: `format GUID`, `immutable`.

        </ParamField>

        <ParamField body="entityId" type="string">

          A unique identifier defined by the app developer to differentiate translation content for various entities within the site. For example, if an app developer is creating translation content for blog posts, the `entityId` can be `'blog-posts-1'`.

          Constraints: `minLength 1`, `maxLength 100`, `immutable`.

        </ParamField>

        <ParamField body="locale" type="string">

          Translation content locale.

          Constraints: `format LANGUAGE_TAG`, `immutable`.

        </ParamField>

        <ParamField body="fields" type="object">

          List of fields for the translation content. This property uses a string to map to a `ContentField` (`Map<string, ContentField>`). The string serves as a key, which you'll need to access each field in the content and when referencing a translation schema.

          Constraints: `format map`, `minItems 0`, `maxItems 2000`.

          <Expandable title="fields properties">

            <ParamField body="key" type="string" />

            <ParamField body="value" type="ContentField">

              _Nested structure omitted for brevity — see the `ContentField` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="parentEntityId" type="string">

          A reference to the parent content. For example, if the content is a menu item, this property would contain the `entityId` of the menu it belongs to.

        </ParamField>

        <ParamField body="publishStatus" type="string">

          The aggregated published status across all content fields.

          **Read-only.**

          **Supported values:**

          - `UNKNOWN_PUBLISH_STATUS` — Unknown publish status.
          - `UNPUBLISHED` — None of the fields have been sent for publication.
          - `PARTIALLY_PUBLISHED` — Some of the fields have been sent for publication.
          - `PUBLISHED` — All of the fields have been sent for publication.

        </ParamField>

        <ParamField body="previewField" type="string">

          Contains the value of the preview field if the schema defines one.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the translation content was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the translation content was updated.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="options" type="UpdateContentOptions">

      options

      <Expandable title="options properties">

        <ParamField body="forceFieldsTimestampUpdate" type="boolean">

          If true each field updated in fields map will also update the timestamp fields

          even if the field value is not changed, otherwise the timestamp fields will be updated only if the field value has changed

        </ParamField>

      </Expandable>
