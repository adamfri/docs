    Asks Google to crawl and index a single page.

    Like Request Site Indexing, this is a request into Google's crawl queue,
    subject to Google's quotas, not an immediate re-index.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gsc/v1/request-page-indexing
    ```

    ## Body Params

    <ParamField body="url" type="string" required>

      Full URL of the page to index. Must be a page of the site the call is
      made on.

      Constraints: `format WEB_URL`.

    </ParamField>

    ## Response Object

    Returns `RequestPageIndexingResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_TOKEN` | No Google account is connected for this site. Connect first with the GSC Connection API. |
    | `429` | `RESOURCE_EXHAUSTED` | `GOOGLE_QUOTA_EXCEEDED` | Google's API quota for the property is used up. Retry after the quota window resets. |
    | `503` | `UNAVAILABLE` | `GOOGLE_UNAVAILABLE` | Google answered with a temporary server error. Retry with backoff. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
