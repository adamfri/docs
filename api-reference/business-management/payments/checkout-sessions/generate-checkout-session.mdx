    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates a Wix-hosted checkout session for the supplied line items and returns its redirect URL
    and session ID.

    Each call creates a new, independent session. The method isn't idempotent, so a retry produces
    an additional session rather than recovering the prior one.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.CHECKOUT-SESSION-GENERATE">Generate checkout sessions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/platform/v1/checkout-sessions/generate
    ```

    ## Body Params

    <ParamField body="cart" type="Cart" required>

      Items, quantities, and prices the buyer is paying for, plus optional pre-fill customer details.

      <Expandable title="cart properties">

        <ParamField body="items" type="LineItem[]" required>

          Line items the buyer is paying for in this checkout session.

          At most 1 subscription line item (an item with `subscriptionInfo` set) is allowed per request.
          Wix rejects requests with 2 or more subscription items. Non-recurring items can be combined with a
          single subscription item. In that case the buyer is charged once at checkout for the non-recurring
          items and, if applicable, the first cycle of the subscription. Wix bills any subsequent cycles on
          the subscription's own schedule.

          Constraints: `maxItems 100`.

          <Expandable title="items properties">

            <ParamField body="name" type="string" required>

              Name of the item, shown on the checkout page.

            </ParamField>

            <ParamField body="quantity" type="integer" required>

              Quantity of this item to charge for.

            </ParamField>

            <ParamField body="price" type="string" required>

              Per-unit price as a decimal string in the merchant account currency. For example, `"19.99"`.

            </ParamField>

            <ParamField body="subscriptionInfo" type="SubscriptionInfo">

              Subscription configuration. When set, the line item follows a scheduled-billing model defined by
              `subscriptionSettings` instead of a single immediate charge. The recurring charge each billing
              cycle is `price × quantity`, and `quantity` is locked at session creation.

              At most 1 line item per request may set `subscriptionInfo`. Wix rejects requests with 2 or more
              subscription line items with `MULTIPLE_SUBSCRIPTION_ITEMS`.

              _Nested structure omitted for brevity — see the `SubscriptionInfo` object._

            </ParamField>

            <ParamField body="physicalProperties" type="PhysicalProperties">

              Optional. Physical properties of the item, used when the item requires shipping.

              _Nested structure omitted for brevity — see the `PhysicalProperties` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="customerInfo" type="CustomerInfo">

          Buyer details used to pre-fill the checkout form. The buyer can edit any of these fields on the
          Wix checkout page.

          <Expandable title="customerInfo properties">

            <ParamField body="firstName" type="string">

              Buyer's first name.

            </ParamField>

            <ParamField body="lastName" type="string">

              Buyer's last name.

            </ParamField>

            <ParamField body="phone" type="string">

              Buyer's phone number.

            </ParamField>

            <ParamField body="email" type="string">

              Buyer's email address.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="callbackUrls" type="CallbackUrls" required>

      URLs the buyer is redirected to after completing or leaving the checkout flow.

      <Expandable title="callbackUrls properties">

        <ParamField body="postFlowUrl" type="string">

          URL the buyer is redirected to from the Wix checkout page when they choose to leave without
          completing payment, either when they click **Continue browsing** or when they navigate back to
          a cart-style page.

          Deprecated. Use `continueBrowsingUrl` instead.

        </ParamField>

        <ParamField body="thankYouPageUrl" type="string" required>

          URL the buyer is redirected to after a successful payment.

        </ParamField>

        <ParamField body="continueBrowsingUrl" type="string">

          URL the buyer is redirected to from the Wix checkout page when they choose to leave without
          completing payment, either when they click **Continue browsing** or when they navigate back to
          a cart-style page.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutSession" type="CheckoutSession">

      The created checkout session.

      See the [Checkout Session Object](/api-reference/business-management/payments/checkout-sessions/checkout-session-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_SUBSCRIPTION_ITEMS` | Returned when `cart.items` contains more than 1 subscription line item. At most 1 subscription line item is allowed per request. |
    | `400` | `INVALID_ARGUMENT` | `AUTO_RENEWAL_AND_BILLING_CYCLES_CONFLICT` | Returned when a subscription line item sets both `subscriptionSettings.autoRenewal = true` and `subscriptionSettings.billingCycles`. The 2 values are mutually exclusive. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Examples

    Creates a Wix-hosted checkout session for a single one-time line item

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/payments/platform/v1/checkout-sessions/generate' \
        -H 'Authorization: <AUTH>' \
        -H 'wix-site-id: <SITE_ID>' \
        -H 'Content-Type: application/json' \
        --data-binary '{
          "cart": {
            "items": [
              {
                "name": "Donation",
                "quantity": 1,
                "price": "3.00"
              }
            ]
          },
          "callbackUrls": {
            "continueBrowsingUrl": "https://www.example.com/",
            "thankYouPageUrl": "https://www.example.com/thank-you"
          }
        }'
      ```

      ```json Response
      {
        "checkoutSession": {
          "id": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
          "redirectUrl": "https://www.wix.com/_serverless/payments-checkout-server/redirect/8046df3c-7575-4098-a5ab-c91ad8f33c47?hideLoginLogoutBar=true&successUrl=https%3A%2F%2Fwww.example.com%2Fthank-you"
        }
      }
      ```

    </CodeGroup>
