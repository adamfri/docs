Triggered when a loyalty coupon is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.v1.coupon_created` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty`, `Manage Restaurants - all permissions` |
