    Retrieves an order for the currently logged-in member by ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PRICING-PLANS.OWN-EXTERNAL">Perform member actions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/pricing-plans/v2/member/orders/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Order ID.

    </ParamField>

    ## Query Params

    <ParamField query="fieldSet" type="string">

      Predefined set of fields to return.

      Default: If `fieldSet` is omitted, no order form submission data is returned.

      **Supported values:**

      - `UNKNOWN_SET` — Same behavior as `BASIC`.``
      - `BASIC` — Doesn't return any order form submission data.
      - `FULL` — Returns all order form submission data.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Requested order.

      See the [Order Object](/api-reference/business-solutions/pricing-plans/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
