    Returns a list of posts by query.

    Paging
    - limit: default - 10, min - 0, max - 100
    - offset: default - 0, min - 0

    Filterable fields:
    - id
    - categoryId
    - ownerId
    - title
    - contentText
    - bestAnswerCommentId
    - pinned
    - commentingEnabled
    - commentCount
    - likeCount
    - viewCount
    - createdDate
    - editedDate
    - lastActivityDate
    - slug

    Sortable fields:
    - lastActivityDate
    - createdDate
    - commentCount
    - viewCount
    - likeCount
    - pinned

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORUM.READ-FORUM">Read Forums</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forum/v1/posts/query
    ```

    ## Body Params

    <ParamField body="paging" type="PostsPaging">

      Paging object (e.g., &#123; limit: 10, offset: 100 &#125; ).

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          The number of items to load.

          Constraints: `min 0`, `max 100`.

        </ParamField>

        <ParamField body="offset" type="integer">

          Number of items to skip in the current sort order.

          Constraints: `min 0`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="filter" type="object">

      Filter object (e.g., &#123; $and: [&#123; ownerId: &#123; eq: 'ownerId' &#125; &#125;, &#123; likeCount: &#123; $gt: 0 &#125;] &#125; ).

    </ParamField>

    <ParamField body="sort" type="PostsSort[]">

      Array of sort objects (e.g.,  [&#123; fieldName: createdDate, order: Order.ASC &#125;] ).

      <Expandable title="sort properties">

        <ParamField body="fieldName" type="string">

          Records can be sorted by:
          lastActivityDate
          createdDate
          commentCount
          viewCount
          likeCount
          isPinned

        </ParamField>

        <ParamField body="order" type="string">

          Records can be sorted in ascending (default) or descending order.

          **Supported values:**

          - `ASC` — Sort by ascending order.
          - `DESC` — Sort by descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="extraFields" type="string[]">

      Array of extra post fields to be added in the response.

      **Supported values:**

      - `IMAGES` — Include images from post content.
      - `VIDEOS` — Include videos from post content.
      - `URL` — Include post URL.
      - `REACTION_IDENTITIES` — Include reaction identities.
      - `RICH_CONTENT` — Includes the post content as a stringified [Rich Content document](https://dev.wix.com/docs/ricos/api-reference/ricos-document)

    </ParamField>

    ## Response Object

    <ResponseField name="posts" type="Post[]">

      List of posts.

      See the [Post Object](/api-reference/business-solutions/forum/post/post-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metaData" type="QueryPostsResponseMetaData">

      Pagination.

      <Expandable title="metaData properties">

        <ResponseField name="count" type="integer">

          Total number of records returned.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset of records.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of records that match the filters.

        </ResponseField>

      </Expandable>

    </ResponseField>
