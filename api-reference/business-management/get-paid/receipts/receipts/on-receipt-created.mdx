Triggered when a receipt is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.receipts.v1.receipt_created` |
| Package | `@wix/get-paid` |
| Permissions | `Manage Receipts`, `Manage Stores` |

## Examples

      // handle your event here
  });
