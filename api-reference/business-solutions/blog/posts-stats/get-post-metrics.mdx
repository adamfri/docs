    <div className="wix-ref">

    Retrieves a post's metrics.

    A post's metrics include the comments, likes, and views the post receives.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v3/posts/{postId}/metrics
    ```

    ## Path Params

    <ParamField path="postId" type="string" required>

      Post ID to retrieve metrics for.

    </ParamField>

    ## Response Object

    <ResponseField name="metrics" type="Metrics">

      Retrieved post metrics.

      <Expandable title="metrics properties">

        <ResponseField name="comments" type="integer">

          Total number of post comments.

          **Read-only.**

        </ResponseField>

        <ResponseField name="likes" type="integer">

          Total number of post likes.

          **Read-only.**

        </ResponseField>

        <ResponseField name="views" type="integer">

          Total number of post views.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
