    <div className="wix-ref">

    Sends the receipt to the specified recipient in an email.

    Specifying a contact ID is required only when no contact ID was specified upon receipt creation.

    Note that if the specified contact ID doesn't have an associated email address, the call will fail.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/receipts/v1/receipts/{receiptId}/send-email
    ```

    ## Path Params

    <ParamField path="receiptId" type="string" required>

      Receipt ID to send.

    </ParamField>

    ## Body Params

    <ParamField body="contactId" type="string">

      Recipient contact ID.

    </ParamField>

    ## Response Object

    Returns `SendReceiptEmailResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_CONTACT` | This receipt has no associated contact ID. Contact ID must be specified in order to fetch their email address. |
    | `428` | `FAILED_PRECONDITION` | `SEND_LIMIT_REACHED` | This receipt has already been sent to 5 different contacts. |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Site not found. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_DOCUMENT` | Receipt document hasn't been generated. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_NUMBERING` | Receipt numbering hasn't been allocated. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Receipt Sent | `wix.receipts.v1.receipt_sent` | Triggered when a receipt is sent. |

    </div>
