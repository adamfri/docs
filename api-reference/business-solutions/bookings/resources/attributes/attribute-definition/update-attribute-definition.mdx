    Updates an attribute definition.

    Each time the attribute definition is updated, `revision` increments by 1. The current `revision` must be passed when updating the attribute definition. This ensures you're working with the latest attribute definition and prevents unintended overwrites.

    `valueType` is immutable. The request is rejected if a different `valueType` is passed.

    Changing the attribute's `config` (a string attribute's `allowedValues`, or a number attribute's `min`/`max`) re-validates every stored attribute value for this definition across all entities: any value that no longer conforms to the new configuration is reset to the attribute's `defaultValue`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="bookings:attributes:v1:attribute_definition:update_attribute_definition">bookings:attributes:v1:attribute_definition:update_attribute_definition</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/_api/attributes/v1/attribute-definitions/{attributeDefinition.id}
    ```

    ## Path Params

    <ParamField path="attributeDefinition.id" type="string" required>

      Attribute definition ID.

    </ParamField>

    ## Body Params

    <ParamField body="attributeDefinition" type="AttributeDefinition" required>

      Attribute definition to be updated, may be partial.

      See the [Attribute Definition Object](/api-reference/business-solutions/bookings/resources/attributes/attribute-definition/attribute-definition-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="attributeDefinition" type="AttributeDefinition">

      Updated attribute definition.

      See the [Attribute Definition Object](/api-reference/business-solutions/bookings/resources/attributes/attribute-definition/attribute-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `VALUE_TYPE_IMMUTABLE` |  |
    | `400` | `INVALID_ARGUMENT` | `NUMBER_CONFIG_MAX_LESS_THAN_MIN` | The number configuration is invalid: `max` is less than `min`. |
    | `409` | `ALREADY_EXISTS` | `DUPLICATE_ATTRIBUTE_NAME` | Another attribute definition on the site already uses this name. |
    | `400` | `INVALID_ARGUMENT` | `DEFAULT_VALUE_NO_LONGER_VALID` | After the config or default change, the default value no longer conforms to the configuration. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
