      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves a list of up to 100 reviews for a location, given the provided
    paging and sorting.

    Reviews belong to Google and can't be created or edited here. You can reply
    to one with Put Review Reply.

    Sort with `orderBy`: `NEWEST`, `HIGHEST_RATING` or `LOWEST_RATING`.

    `metrics` carries the location's average rating and total review count.
    Those cover every review on the profile, not just the current page.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/locations/{locationId}/reviews
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID. This is Google's location identifier.

    </ParamField>

    ## Query Params

    <ParamField query="orderBy" type="string">

      Sort order for reviews.

      **Supported values:**

      - `NEWEST`
      - `HIGHEST_RATING`
      - `LOWEST_RATING`

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Cursor-based paging. Unset `limit` uses a server default of 20; `cursor`
      is the `next` token returned by a previous response (opaque Google token).
      Google caps `limit` at 50.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="reviews" type="Review[]">

      Reviews for the location.

      <Expandable title="reviews properties">

        <ResponseField name="reviewId" type="string">

          Google's opaque review ID.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="starRating" type="integer">

          Star rating, from 1 to 5.

          Constraints: `min 1`, `max 5`.

        </ResponseField>

        <ResponseField name="comment" type="string">

          Review comment text.

          Constraints: `maxLength 4096`.

        </ResponseField>

        <ResponseField name="createTime" type="string">

          ISO 8601 timestamp of when the review was written.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="reviewerDisplayName" type="string">

          Reviewer's display name.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="anonymousReviewer" type="boolean">

          Whether the reviewer chose to remain anonymous.

        </ResponseField>

        <ResponseField name="reply" type="ReviewReply">

          The merchant's current reply to this review, if any.

          <Expandable title="reply properties">

            <ResponseField name="text" type="string">

              The reply text.

              Constraints: `maxLength 4096`.

            </ResponseField>

            <ResponseField name="updateTime" type="string">

              ISO 8601 timestamp of when the reply was last updated.

              Constraints: `maxLength 64`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata. `cursors.next` is the token to specify for the next page, and
      `hasNext` says whether there is one.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="metrics" type="ReviewMetrics">

      Aggregate review metrics for the location.

      <Expandable title="metrics properties">

        <ResponseField name="averageRating" type="number">

          Average star rating, from 1.0 to 5.0, across every review on the profile.

        </ResponseField>

        <ResponseField name="totalReviewCount" type="integer">

          Total number of reviews.

        </ResponseField>

      </Expandable>

    </ResponseField>
