    Retrieves business suggestions for partial text, for autocompleting a
    business name as someone types.

    Only existing businesses come back. Regions and street addresses never do,
    so use Suggest Regions for those. Use this to find and prefill the business
    a site owner wants to claim.

    Needs no connected Google account and no existing location. Text shorter
    than 3 characters returns an empty list rather than an error.

    `countryCode` is optional here, unlike Suggest Regions: business names are
    searched worldwide unless you narrow them.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/establishments/suggest
    ```

    ## Body Params

    <ParamField body="query" type="string" required>

      Partial free-text the end-user is typing (e.g. "acme hard"). Sent per
      debounced keystroke; Google returns business-name predictions matching
      this prefix. Queries shorter than 3 chars return an empty list
      (handled server-side), not an error.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    <ParamField body="countryCode" type="string">

      Optional ISO 3166-1 alpha-2 country to restrict results to (e.g. "US").
      Unlike SuggestRegions, business search is unrestricted when omitted.

    </ParamField>

    <ParamField body="languageCode" type="string">

      Optional BCP-47 language for the returned names (e.g. "fr"). Defaults to
      Google's behavior (typically the account/region language) when empty.

      Constraints: `maxLength 35`.

    </ParamField>

    ## Response Object

    <ResponseField name="suggestions" type="EstablishmentSuggestion[]">

      Business-name predictions ranked by Google, best match first.

      Constraints: `maxItems 20`.

      <Expandable title="suggestions properties">

        <ResponseField name="placeId" type="string">

          Google's opaque place identifier for the predicted business.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Full human-readable prediction text (e.g. "Acme Hardware, Main St, NYC").

          Constraints: `maxLength 512`.

        </ResponseField>

        <ResponseField name="mainText" type="string">

          Primary part of the prediction (e.g. "Acme Hardware"), for bold styling.

          Constraints: `maxLength 512`.

        </ResponseField>

        <ResponseField name="secondaryText" type="string">

          Secondary part of the prediction (e.g. "Main St, NYC"), for muted styling.

          Constraints: `maxLength 512`.

        </ResponseField>

      </Expandable>

    </ResponseField>
