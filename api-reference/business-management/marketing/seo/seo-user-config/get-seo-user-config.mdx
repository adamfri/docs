<Tabs>

  <Tab title="REST">

    Retrieves the SEO configuration for the current site.

    If no configuration exists, a configuration with default values is created and returned.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="seo_user_config:v1:seo_user_config:get_seo_user_config">seo_user_config:v1:seo_user_config:get_seo_user_config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/seo/user-config/v1/seo-user-config
    ```

    ## Response Object

    <ResponseField name="seoUserConfig" type="SeoUserConfig">

      Retrieved SEO configuration.

      If no configuration has been created yet, default values are returned.

      See the [Seo User Config Object](/api-reference/business-management/marketing/seo/seo-user-config/seo-user-config-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

  </Tab>
