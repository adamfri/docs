    <div className="wix-api-columns">

    <div className="wix-ref">

    Change the order of events that are assigned to the same category on the Events Widget.

    For more information on how events are displayed in the widget, read [this article](https://support.wix.com/en/article/creating-and-displaying-event-categories).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS-MEGA.MANAGE-EVENTS">Manage Events - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/categories/{categoryId}/reorder
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      Category ID.

    </ParamField>

    ## Body Params

    <ParamField body="eventId" type="string">

      Event ID.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    Returns `ReorderCategoryEventsResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_REORDER_INSTRUCTION` | The reorder instruction is invalid. Make sure the event is assigned to a category, and the reference event ID (`beforeEventId` or `afterEventId`) exists in the category. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
