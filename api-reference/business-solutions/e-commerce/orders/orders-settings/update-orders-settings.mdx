    ## Examples

    Updates the site's orders settings to automatically create an invoice for each new order.

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
        'https://www.wixapis.com/ecom/v1/orders-settings' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>' \
        -d '{
         "ordersSettings": {
           "createInvoice": true
         }
        }'
      ```

      ```json Response
      {
        "ordersSettings": {
          "inventoryUpdateTrigger": "ON_ORDER_PLACED",
      ```
