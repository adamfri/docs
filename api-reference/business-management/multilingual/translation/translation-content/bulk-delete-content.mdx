    Deletes multiple translation content items.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_CONTENT">Wix Multilingual - Write Translation Content</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/translation-content/v1/bulk/contents/delete
    ```

    ## Body Params

    <ParamField body="contentIds" type="string[]" required>

      IDs of the translation content items to delete.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>
