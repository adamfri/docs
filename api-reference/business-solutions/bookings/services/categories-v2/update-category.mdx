    Updates a category.

    Each time the category is updated, `revision` increments by 1.
    You must specify the current `revision` to prevent unintended overwrites.

    You can't adjust a categories `sortOrder` with this method, call [Move Category](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/categories-v2/move-category) instead.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bookings/v2/categories/{category.id}
    ```

    ## Path Params

    <ParamField path="category.id" type="string" required>

    </ParamField>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Category ID.

      **Read-only.**

    </ParamField>

    <ParamField body="category" type="UpdateCategory" required>

      Category to update.

      <Expandable title="category properties">

        <ParamField body="_id" type="string">

          Category ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the category is updated.
          To prevent conflicting changes, you must specify the current revision when updating the category.

          Ignored when creating a category.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the category was created in `YYYY-MM-DDThh:mm:ss.sssZ` format.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the Category was last updated in `YYYY-MM-DDThh:mm:ss.sssZ` format.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Category name.

        </ParamField>

        <ParamField body="sortOrder" type="integer">

          Defines the category's position in the categories list relative to other categories.
          Wix Bookings assigns `sortOrder` values with large gaps between adjacent categories, allowing efficient reordering without updating the entire list. When gaps become too small, the system automatically reassigns new `sortOrder` values to restore larger gaps.

          **Read-only.**

        </ParamField>

        <ParamField body="extendedFields" type="ExtendedFields">

          Custom field data for the category object.

          [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.
