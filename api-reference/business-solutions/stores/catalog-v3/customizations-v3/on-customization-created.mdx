Triggered when a customization is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.stores.catalog.v3.customization_created` |
| Package | `@wix/stores` |
| Permissions | `Manage Stores - all permissions`, `Read v3 catalog`, `Manage Products`, `Read Stores - all read permissions`, `Read Products`, `Manage Restaurants - all permissions`, `Product write in v3 catalog`, `Read customizations in v3 catalog`, `Manage v3 catalog`, `Manage Orders` |
