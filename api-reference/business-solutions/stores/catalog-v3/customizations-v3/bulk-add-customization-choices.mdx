    Adds choices to multiple customizations.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CUSTOMIZATION_WRITE">Customization write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/customizations/add-choices
    ```

    ## Body Params

    <ParamField body="customizationsChoices" type="CustomizationChoices[]" required>

      List of customization IDs and choices.

      Constraints: `minItems 1`, `maxItems 1000`.

      <Expandable title="customizationsChoices properties">

        <ParamField body="customizationId" type="string" required>

          Customization ID.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="choices" type="Choice[]" required>

          Choices to add.

          Constraints: `minItems 1`, `maxItems 100`.

          <Expandable title="choices properties">

            <ParamField body="id" type="string">

              Choice ID.

              **Read-only.** Constraints: `format GUID`.

            </ParamField>

            <ParamField body="choiceType" type="string">

              Choice type.

              > **Notes:**
              > + For `customizationRenderType: SWATCH_CHOICES`, the supported `choiceType` value is: `ONE_COLOR`.
              > + For a `customizationRenderType` of `TEXT_CHOICES`, the supported `choiceType` value is: `CHOICE_TEXT`.

              Constraints: `immutable`.

              **Supported values:**

              - `CHOICE_TEXT` — For a `customizationRenderType` of `TEXT_CHOICES`.
              - `ONE_COLOR` — For `customizationRenderType: SWATCH_CHOICES`.

            </ParamField>

            <ParamField body="key" type="string">

              A read-only identifier generated from the choice name.

              Use `key` in the `catalogReference.options` object when [integrating Catalog V3 with eCommerce APIs](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/e-commerce-integration).

              **Read-only.**

            </ParamField>

            <ParamField body="name" type="string">

              Choice name.

              Constraints: `minLength 1`, `maxLength 50`.

            </ParamField>

            <ParamField body="defaultAddedPrice" type="string">

              Default amount added to a product's price when this customization is assigned to a modifier.

            </ParamField>

            <ParamField body="displayImage" type="Image">

              Optional image displayed alongside a `ONE_COLOR` choice in the storefront.
              Only valid for `ONE_COLOR` choices; not populated for other choice types.

              _Nested structure omitted for brevity — see the `Image` object._

            </ParamField>

            <ParamField body="primaryChoiceIds" type="string[]">

              IDs of the primary choices this choice is grouped under.

              A choice that has `primaryChoiceIds` is a "linked" choice; a choice without `primaryChoiceIds` is a "primary" choice.
              A linked choice can reference up to 4 primary choices and appears nested under each of them on the storefront,
              rather than in the top-level choice list.

              Only one level of grouping is supported: a primary choice cannot itself be a linked choice.

              **Developer Preview.** Constraints: `format GUID`, `maxItems 4`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full customization entities in the response.

      Default: `false`

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT` — Assigned products count.
      - `CHOICE_DISPLAY_IMAGE` — Returns display images for choices.

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CHOICES_LIMIT_EXCEEDED` | Number of choices exceeded the limit of 100 per customization. |
    | `400` | `INVALID_ARGUMENT` | `DOESNT_SUPPORT_CHOICES` | `FREE_TEXT` render type doesn't support choices. Use `SWATCH_CHOICES` or `TEXT_CHOICES` render type instead. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CHOICE_TYPE` | Choice type doesn't match the customization type. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CHOICE_VALUE` | Choice value doesn't match the choice type. For `SWATCH_CHOICES`, use `ONE_COLOR` choice type. For `TEXT_CHOICES`, use `CHOICE_TEXT` choice type. |
    | `400` | `INVALID_ARGUMENT` | `PRIMARY_CHOICE_SELF_REFERENCE` | Choice references itself in `primaryChoiceIds`. |
    | `400` | `INVALID_ARGUMENT` | `PRIMARY_CHOICE_NOT_FOUND` | `primaryChoiceIds` contains an ID that doesn't match any existing choice in the customization. |
    | `400` | `INVALID_ARGUMENT` | `PRIMARY_CHOICE_HIERARCHY_VIOLATION` | A choice that is a primary of other choices can't also be a linked choice. Only a single level of grouping is supported. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
