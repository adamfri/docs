    Retrieves a booking and its allowed anonymous actions using an anonymous token.

    This method doesn't require standard authentication. Pass a token generated by [Get Anonymous Action Token](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/get-anonymous-action-token) instead.

    To include booking fee details, specify `BOOKING_FEES` in `fields`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/anonymous-bookings/{token}
    ```

    ## Path Params

    <ParamField path="token" type="string" required>

      Anonymous token for the booking.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Additional fields to return.

      Constraints: `maxItems 1`.

      **Supported values:**

      - `BOOKING_FEES` — Booking fee details.

    </ParamField>

    ## Response Object

    <ResponseField name="booking" type="Booking">

      Retrieved booking.

      See the [Booking Object](/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/booking-object) for this object's fields.

    </ResponseField>

    <ResponseField name="allowedAnonymousActions" type="AllowedAnonymousActions">

      Allowed anonymous actions for this booking.

      <Expandable title="allowedAnonymousActions properties">

        <ResponseField name="cancel" type="boolean">

          Whether the booking can be canceled anonymously.

        </ResponseField>

        <ResponseField name="reschedule" type="boolean">

          Whether the booking can be rescheduled anonymously.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bookingFee" type="BookingFee">

      Booking fee details.

      Returned only when `BOOKING_FEES` is passed in `fields`.

      <Expandable title="bookingFee properties">

        <ResponseField name="id" type="string">

          Booking fee ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="bookingId" type="string">

          ID of the booking associated with the fee.

        </ResponseField>

        <ResponseField name="cancellationFee" type="CancellationFee">

          Cancellation fee details.

          <Expandable title="cancellationFee properties">

            <ResponseField name="price" type="Money">

              Price the customer must pay.

              _Nested structure omitted for brevity — see the `Money` object._

            </ResponseField>

            <ResponseField name="status" type="string">

              Status of the booking fee.

              **Supported values:**

              - `UNKNOWN_STATUS` — There is no eCommerce order associated with the booking.
              - `PREVIEW` — The fee is informational only; the customer doesn't have to pay it. For example, it shows how much the customer would owe if they canceled the booking now.
              - `NOT_YET_APPLIED_TO_ORDER` — The booking fee hasn't been added to the eCommerce order yet.
              - `APPLIED_TO_ORDER` — The booking fee has been added to the eCommerce order. The customer may not have paid it yet.

            </ResponseField>

            <ResponseField name="trigger" type="string">

              Information about what triggered the creation of the booking fee.

              **Read-only.**

              **Supported values:**

              - `UNKNOWN_TRIGGER` — There is no information about what triggered the creation of the booking fee.
              - `NOT_ATTENDED` — The booking fee was created because the customer didn't show up to the booking or canceled after the expiration of the last cancellation window.
              - `BOOKING_CANCELED` — The booking fee was created because the customer canceled the booking before the expiration of the last cancellation window.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="policyDetails" type="PolicyDetails">

          Information about the [booking policy snapshot](https://dev.wix.com/docs/api-reference/business-solutions/bookings/policies/booking-policy-snapshots/introduction)
          according to which the fee was created.

          <Expandable title="policyDetails properties">

            <ResponseField name="id" type="string">

              ID of the booking policy.

              **Read-only.**

            </ResponseField>

            <ResponseField name="description" type="string">

              Description of the booking policy.

            </ResponseField>

            <ResponseField name="descriptionTranslated" type="string">

              Translated description of the booking policy according to the buyer language of the eCommerce order.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `INVALID_TOKEN` | Token is invalid, expired, or cannot be decrypted. |
    | `404` | `NOT_FOUND` | `BOOKING_NOT_FOUND` | Couldn't find the booking encoded in the token. |
    | `428` | `FAILED_PRECONDITION` | `FAILED_GETTING_BOOKING_FEES` | Couldn't get the fees for the booking encoded in the token. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
