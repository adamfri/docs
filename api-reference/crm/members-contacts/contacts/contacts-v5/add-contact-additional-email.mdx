    Adds an additional email to a contact.

    The contact must have a main email (`email.email`) before an additional email can be added.

    Each time the contact is updated, `revision` increments by 1. The current `revision` must be passed. This ensures you're working with the latest contact and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/{contactId}/additional-emails
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to add an email to.

    </ParamField>

    ## Body Params

    <ParamField body="email" type="AdditionalEmail" required>

      Email to add.

      <Expandable title="email properties">

        <ParamField body="email" type="string">

          Additional email address for the contact.
          Does not affect subscription status or contact matching logic.

          Constraints: `format EMAIL`, `maxLength 320`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="revision" type="integer" required>

      Contact revision number.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>

    ## Errors

    | `428` | `FAILED_PRECONDITION` | `ADDITIONAL_EMAILS_LIMIT_REACHED` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
