---
title: "Gift Card Object"
description: "The Gift Card object in the Wix Gift Card API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="obfuscatedCode" type="string">

      Gift card obfuscated code.

      For example: "****-****-****-1234".

      Constraints: `maxLength 30`.

    </ResponseField>

    <ResponseField name="balance" type="Money">

      Gift card balance.

      <Expandable title="balance properties">

        <ResponseField name="value" type="string">

          Monetary amount. Decimal string with a period as a decimal separator (e.g., 3.99). Optionally, a single (-), to indicate that the amount is negative.

          Constraints: `format DECIMAL_VALUE`, `>= 0`, `<= 999999999.99`.

        </ResponseField>

        <ResponseField name="currency" type="string">

          Currency code. Must be valid ISO 4217 currency code (e.g., USD).

          Constraints: `format CURRENCY`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Current gift card status.

      **Supported values:**

      - `VALID` — Gift card is active and can be used for purchases.
      - `EXPIRED` — Gift card expiration date has passed and can no longer be used.
      - `DISABLED` — Gift card has been disabled by the merchant and can no longer be used.

    </ResponseField>

    <ResponseField name="appId" type="string">

      App ID of the gift card provider, as returned in eCommerce Get Checkout or List Transactions for Single Order.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="externalId" type="string">

      External ID in the gift card provider's system.
      Used for integration and tracking across different platforms.

    </ResponseField>

  </Tab>
