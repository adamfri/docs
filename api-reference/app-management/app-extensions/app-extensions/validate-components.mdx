    Validates components for a single app.

    Use this method to check component configuration while building or editing an app, before creating, updating, or deleting components. Validation returns a result for each requested operation and doesn't persist changes.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/apps/v1/components/v1/components/validate
    ```

    ## Body Params

    <ParamField body="components" type="ValidateComponentsOperation[]">

      Component operations to validate.

      Constraints: `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="ComponentValidationResult[]">

      Validation results.

      <Expandable title="results properties">

        <ResponseField name="componentId" type="string">

          Component ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="valid" type="boolean">

          Whether the component operation is valid.

        </ResponseField>

        <ResponseField name="error" type="string">

          Validation error message, when validation fails.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Validates component operations for an app without persisting changes. This example validates a delete operation; each result reports whether the operation is valid.

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
      'https://www.wixapis.com/apps/v1/components/v1/components/validate' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "components": [
          {
            "deletedComponent": {
              "componentId": "a1c8e5d2-3b47-4f60-9e21-7d4a6c0f29b8",
              "appId": "7b3f9a21-0c64-4e8a-b1d2-5f6c8e90a4d3"
            }
          }
        ]
      }'
      ```

      ```json Response
      {
        "results": [
          {
            "componentId": "a1c8e5d2-3b47-4f60-9e21-7d4a6c0f29b8",
            "valid": true
          }
        ]
      }
      ```

    </CodeGroup>
