<Warning>

__Deprecation Notice:__

**The eCommerce Cart API** has been replaced with [Cart V2](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/introduction) and will be removed on February 1, 2027.

For migration guidance, see the [Cart V2 Migration Guide](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/migration-guide).

</Warning>

The cart is the first phase of a purchase, followed by checkout, then order.

A cart holds information about purchased items, prices, discounts, site details, buyer IDs (contact and member/visitor) and more. 
Additionally, some methods in the Cart API can directly manage the current cart of the site visitor or logged-in member.

With the eCommerce Cart API you can:
+ Get [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/get-cart) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/get-current-cart).
+ Add catalog items to [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/add-to-cart) or to [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/add-to-current-cart).
+ Create a checkout from [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/create-checkout-from-cart) or from [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/create-checkout-from-current-cart). 
+ Estimate the price totals for [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/estimate-totals) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/estimate-current-cart-totals).
+ Update the properties of [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/update-cart) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/update-current-cart).
+ Update the quantity of line items in [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/update-line-items-quantity) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/update-current-cart-line-item-quantity).
+ Remove a coupon from [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/remove-coupon) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/remove-coupon-from-current-cart).
+ Remove line items from [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/remove-line-items) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/remove-line-items-from-current-cart).
+ Delete [a cart](https://dev.wix.com/api/rest/wix-ecommerce/cart/delete-cart) or [the current cart](https://dev.wix.com/docs/rest/business-solutions/e-commerce/cart/delete-current-cart).

You can also listen for events when a cart is [created](https://dev.wix.com/api/rest/wix-ecommerce/cart/cart-created-webhook), [updated](https://dev.wix.com/api/rest/wix-ecommerce/cart/cart-updated-webhook), and [deleted](https://dev.wix.com/api/rest/wix-ecommerce/cart/cart-deleted-webhook).

<Note>

Some methods in this API require [visitor or member authentication](fallback::https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>
