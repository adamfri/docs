Triggered when a certain amount of time is left until the event. In total there are 6 reminders:
- 7 days
- 3 days
- 1 day
- 2 hours
- 1 hour
- 30 minutes

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.events.v3.event_reminder` |
| Package | `@wix/events` |
| Permissions | `Read Events - all read permissions`, `Manage Bookings Services and Settings`, `Manage Events - all permissions`, `Read Events`, `Manage Portfolio`, `Manage Restaurants - all permissions`, `Manage Guest List`, `Manage Events` |

## Examples

<CodeGroup>

  ```javascript onEventReminder: Wix-hosted
  import { wixEventsV2 } from '@wix/events';

  wixEventsV2.onEventReminder((event) => {
      // handle your event here
  });
  ```

  ```javascript onEventReminder: Self-hosted
  import { createClient, AppStrategy } from '@wix/sdk';
  import { wixEventsV2 } from '@wix/events';

    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        wixEventsV2,
      },
  });

  wixClient.wixEventsV2.onEventReminder((event) => {
      // handle your event here
  });
  ```
