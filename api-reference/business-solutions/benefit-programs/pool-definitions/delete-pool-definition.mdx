    Deletes a pool definition.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/benefit-programs/v1/pool-definitions/{poolDefinitionId}
    ```

    ## Path Params

    <ParamField path="poolDefinitionId" type="string" required>

      ID of the pool definition to delete.

    </ParamField>

    ## Query Params

    <ParamField query="cascade" type="string" required>

      *Required**. Determines when the changes to this pool definition the program definitions containing it will be applied to associated programs and pools.

      **Supported values:**

      - `UNKNOWN_CASCADE` — Unknown cascade.
      - `NEXT_RENEWAL` — Changes are applied to existing programs and pools when they are next renewed.
      - `IMMEDIATELY` — Changes are applied to associated programs and pools immediately.
      - `FUTURE_PROVISIONS` — Changes are not applied to existing associated programs and pools. They are only applied to future programs and pools.

    </ParamField>

    ## Response Object

    Returns `DeletePoolDefinitionResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
