    Bulk creates messages.

    This method must be called using the [site visitor or site member identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) to identify the site visitor that is creating the messages.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INNOVATION_LAB.USER">Innovation Lab User</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/innovation/widget/v1/bulk/messages/create
    ```

    ## Body Params

    <ParamField body="messages" type="Message[]">

      Messages to be created.

      Constraints: `minItems 1`, `maxItems 25`.

      See the [Message Object](/api-reference/business-management/ai-site-chat/messages/message-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="messages" type="Message[]">

      Created messages.

      See the [Message Object](/api-reference/business-management/ai-site-chat/messages/message-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `FORBIDDEN_MESSAGE_TYPE` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Examples

    Creates one or more messages from the site visitor in a single request.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/innovation/widget/v1/bulk/messages/create' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "messages": [
          {
            "messageType": "QUESTION",
            "body": {
              "mainText": "What are your business hours?"
      ```
