The Tasks API provides functionality for managing tasks on a site, allowing you to organize and prioritize tasks, enhancing customer relationship management. Tasks include activities such as follow-up calls or emails, scheduling meetings with clients, tracking steps for customer onboarding, and more. Learn more about [managing tasks](fallback::https://support.wix.com/en/article/wix-contacts-creating-and-managing-tasks-reminders).

With the Tasks API, you can:
- Create, update, and delete tasks. 
- Retrieve and view tasks. 
- Link a task to a contact.
- Enable task reminder notifications by setting a due date for tasks. 
- Prioritize tasks by adjusting the display order.
- Count the total number of tasks or the number of tasks based on specified filters.

## Terminology

- **Task:** A specific activity, action, or assignment created by calling the Create Task method for completion by a Wix user.
- **Reminder notification:** A notification that is sent if the task has a due date. Reminder notifications are sent the day before the task's due date and on the day of the task's due date. Reminder notifications can't be sent for overdue tasks.
