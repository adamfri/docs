    Updates a group.

    When a public or private group's name is updated, the slug is updated to reflect the new group name.
    Only group admins can update their group.

    <Note>

    + When `group.privacyStatus` is updated from `PRIVATE` to `PUBLIC`, all pending group join requests are automatically approved.
    + When `group.privacyStatus` is updated from `PRIVATE` to `SECRET`, all pending group join requests are automatically rejected.

    </Note>

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/social-groups-proxy/groups/v2/groups/{group.id}
    ```

    ## Path Params

    <ParamField path="group.id" type="string" required>

      Group ID.

    </ParamField>

    ## Body Params

    <ParamField body="group" type="Group" required>

      Group to update.

      See the [Group Object](/api-reference/crm/community/groups/groups/group-object) for this object's fields.

    </ParamField>

    <ParamField body="contentType" type="string">

      Content type.

      **Supported values:**

      - `PLAIN_TEXT`
      - `DRAFTJS`
      - `RICH_CONTENT`

    </ParamField>

    ## Response Object

    <ResponseField name="group" type="Group">

      Updated group.

      See the [Group Object](/api-reference/crm/community/groups/groups/group-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

          A unique part of a group's URL, for example `https:/example.com/groups/slug`.

        <ParamField body="privacyStatus" type="string">

          Group privacy status.

          **Supported values:**

          - `PUBLIC` — Anyone can see the group and its content. Anyone can join the group.
          - `PRIVATE` — Anyone can see the group, but only members can see its content. New members must submit a `Join Group Request`.
          - `SECRET` — Only admins and members can see the group. New members can only be added by other members.

        </ParamField>
