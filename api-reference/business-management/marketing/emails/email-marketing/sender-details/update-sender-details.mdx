    <div className="wix-ref">

    <Warning>

      **Deprecated.** This method is deprecated.

    </Warning>

    Updates sender details (only provided fields will be updated).

    If `from_email` is changed - a verification code will be sent to new email address.
    If verification is needed, a verification email will be sent to the user, and `verification_needed` will return true.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/email-marketing/v1/sender-details
    ```

    ## Body Params

    <ParamField body="senderDetails" type="SenderDetails" required>

      New sender details.

      See the [Sender Details Object](/api-reference/business-management/marketing/emails/email-marketing/sender-details/sender-details-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="verificationNeeded" type="boolean">

      Whether email address needs verification.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
