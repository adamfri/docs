    Retrieves a list of loyalty imports with the specified paging, filtering, and sorting.

    Query Loyalty Imports runs with these defaults, which you can override:

    - `"createdDate"` is sorted in `"DESC"` order.
    - `"paging.limit"` is `50`.

    To learn about working with _Query_ methods, see [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/docs/rest/articles/get-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/docs/rest/articles/get-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `status` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
