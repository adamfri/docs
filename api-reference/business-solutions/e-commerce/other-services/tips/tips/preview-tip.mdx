    <div className="wix-ref">

    Previews a tip for a list of line items.

    If you provide the Wix Bookings app ID ([SDK](https://dev.wix.com/docs/sdk/articles/work-with-the-sdk/apps-created-by-wix) | [REST](https://dev.wix.com/docs/rest/articles/getting-started/apps-created-by-wix))
    as `lineItemInfo.catalogReference.appId`, the response includes tip
    distributions for each associated
    Bookings staff member ([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/staff-members/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/staff-members/staff-member-object)).

    If you don't provide a `tipSettingsId`, the `staffDistributionMethod` is
    based on the site's default tip settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/tips/v1/tips/preview
    ```

    ## Body Params

    <ParamField body="lineItemInfo" type="LineItemInfo[]" required>

      Information about the line items to preview the tip for.

      Min: 1 line item
      Max: 50 line items

      Constraints: `minItems 1`, `maxItems 50`.

      <Expandable title="lineItemInfo properties">

        <ParamField body="lineItemId" type="string">

          IDs of the line items associated with the tip.

          Min: 1 character &lt;br/>
          Max: 100 characters

        </ParamField>

        <ParamField body="catalogReference" type="CatalogReference">

          Information about the line item and the corresponding catalog. Catalogs
          include Wix Bookings and Wix Stores.

          <Expandable title="catalogReference properties">

            <ParamField body="catalogItemId" type="string" required>

              ID of the line item within its catalog, corresponding to:
              + `product.name` for Stores ([SDK](https://dev.wix.com/docs/sdk/backend-modules/stores/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/stores/about-wix-stores)).
              + `service.name` for Bookings ([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/about-wix-bookings)).

            </ParamField>

            <ParamField body="appId" type="string" required>

              ID of the app ([SDK](https://dev.wix.com/docs/sdk/articles/work-with-the-sdk/apps-created-by-wix) | [REST](https://dev.wix.com/docs/rest/articles/getting-started/apps-created-by-wix))
              to which the catalog belongs.

              Supported app IDs:
              + [Wix Tips](https://www.wix.com/app-market/wix-tips): `"869a50c8-dd38-4324-b201-e33dc0747a5f"`
              + [Wix Stores](https://www.wix.com/app-market/wix-stores): `"215238eb-22a5-4c36-9e7b-e7c08025e04e"`
              + [Wix Bookings](https://www.wix.com/app-market/bookings): `"13d21c63-b5ec-5912-8397-c3a5ddb27a97"`
              + [Wix Restaurants Orders](https://www.wix.com/app-market/web-solution/wix-restaurants-orders-new): `"13e8d036-5516-6104-b456-c8466db39542"`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="price" type="string" required>

          Price of the line item.

          Min: `0.00`

        </ParamField>

        <ParamField body="name" type="string">

          Name of the line item, which is identical to:
          + `product.name` for Stores ([SDK](https://dev.wix.com/docs/sdk/backend-modules/stores/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/stores/about-wix-stores)).
          + `service.name` for Bookings ([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/about-wix-bookings)).

          Min: 1 character  &lt;br/>
          Max: 200 characters

        </ParamField>

        <ParamField body="quantity" type="integer">

          Quantity of the line item.

          Min: `1` &lt;br/>
          Max: `100000` (one hundred thousand)

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="tipChoice" type="TipChoice" required>

      Information about how to calculate the total tip amount and the distribution
      amounts.

      <Expandable title="tipChoice properties">

        <ParamField body="value" type="string" required>

          Value of the tip choice.

        </ParamField>

        <ParamField body="tipType" type="string" required>

          Type of the tip choice.

          **Supported values:**

          - `UNKNOWN_TIP_TYPE` — There is no information about the tip type.
          - `PERCENTAGE` — The tip is calculated as a percentage of the subtotal of associated line items.
          - `AMOUNT` — The tip is a fixed value, pre-configured from the relevant settings presets.
          - `CUSTOM` — The customer, or the business on behalf of the customer, manually set a tip amount, which may not match any preset values.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="tipSettingsId" type="string">

      ID of the tip settings used to preview the tip. If you don't provide a
      `tipSettingsId`, the `staffDistributionMethod` is based on the site's
      default tip settings.

    </ParamField>

    <ParamField body="draftOrderId" type="string">

      ID of draft order. If provided, we'll take overridden data from the draft.

    </ParamField>

    ## Response Object

    <ResponseField name="tip" type="Tip">

      Tip.

      See the [Tip Object](/api-reference/business-solutions/e-commerce/other-services/tips/tips/tip-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `TIP_SETTINGS_NOT_FOUND` | Couldn't find the tip settings. |
    | `404` | `NOT_FOUND` | `CATALOG_ITEMS_NOT_FOUND` | Couldn't find the catalog items. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
