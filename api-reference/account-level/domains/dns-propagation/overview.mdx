The DNS (Domain Name System) propagation object contains information for a domain.
Tracks whether the DNS records are correctly configured and propagated globally.
Learn more [about DNS propagation](https://support.wix.com/en/article/about-domain-propagation).

## SDK package

```bash
npm install @wix/domains
```

Import the `dnsPropagation` namespace from `@wix/domains`.
