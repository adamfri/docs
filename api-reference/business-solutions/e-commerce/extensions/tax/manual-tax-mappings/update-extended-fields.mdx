    Updates extended fields of a manual tax mapping.

    Use this method to modify extended field data associated with a manual tax mapping.
    Unlike the standard update operation, this does not increment the revision number.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/manual-tax-mappings/{id}/update-extended-fields
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the entity to update.

    </ParamField>

    ## Body Params

    <ParamField body="namespace" type="string" required>

      Identifier for the app whose extended fields are being updated.

    </ParamField>

    <ParamField body="namespaceData" type="object" required>

      Data to update. Structured according to the [schema](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields#json-schema-for-extended-fields) defined when the extended fields were configured.

    </ParamField>

    ## Response Object

    <ResponseField name="manualTaxMapping" type="ManualTaxMapping">

      Updated manual tax mapping.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
