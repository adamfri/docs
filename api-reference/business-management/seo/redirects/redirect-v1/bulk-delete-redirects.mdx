    Deletes up to 500 redirects by ID.

    Each ID succeeds or fails on its own. An ID that matches no redirect on the site fails with
    `REDIRECT_NOT_FOUND` while the rest of the request goes ahead. Read those failures from
    `results[].itemMetadata.error` in a successful response, matched to the request by
    `results[].itemMetadata.originalIndex`. A malformed request, such as an empty `redirectIds`
    list, is rejected as a whole and returns no results.

    A successful item means the redirect was found and its deletion was sent, not that the deletion
    is confirmed. Call [List Redirects](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/list-redirects) if you need to confirm the outcome.

    A redirect scoped to a language stops taking effect but can still appear in [List Redirects](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/list-redirects).
    [Delete Redirect](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/delete-redirect) behaves the same way.

    To delete a single redirect, call [Delete Redirect](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/delete-redirect).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    This method requires one of the following permission scopes:

    ## Endpoint

    ```http
    POST https://www.wixapis.com/seo-redirects-service/v1/bulk/redirects/delete
    ```

    ## Body Params

    <ParamField body="redirectIds" type="string[]" required>

      IDs of the redirects to delete.

      Constraints: `format GUID`, `minItems 1`, `maxItems 500`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkRedirectResult[]">

      Outcome of each ID, in request order. `originalIndex` is the ID's position in `redirectIds`.

      A successful item means the redirect was found and its deletion was sent, not that the deletion
      is confirmed. An ID that matches no redirect on the site fails with `REDIRECT_NOT_FOUND`, and
      every other ID in the request is still deleted.

      Constraints: `maxItems 500`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Whether this redirect succeeded, its position in the request as `originalIndex`, and the error
          if it failed.

          A redirect that already exists on the site is reported as a success with no `id`, and nothing is
          written for it.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Redirect">

          Created redirect.

          Returned only when `returnFullEntity` is `true` in the request. Never returned by Bulk Delete
          Redirects.

          See the [Redirect Object](/api-reference/business-management/seo/redirects/redirect-v1/redirect-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Number of redirects deleted and number that failed.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>
