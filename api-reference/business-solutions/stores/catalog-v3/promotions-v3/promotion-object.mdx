title: "Promotion Object"

icon: "cube"

A promotion is a visual banner displayed on store category pages, including their product gallery sections.
Use promotions to highlight sales, seasonal offers, or featured content and link customers to relevant pages.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Promotion ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the promotion is updated.
      To prevent conflicting changes, the current revision must be passed when updating the promotion.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the promotion was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the promotion was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Promotion name.

      Constraints: `minLength 1`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="media" type="PromotionMedia">

      Promotion media.

      <Expandable title="media properties">

        <ResponseField name="altText" type="string">

          Image alt text.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Media display name.

          Overrides the default media name. Can be passed only when the media is set by a URL in this item's `url` field.

        </ResponseField>

        <ResponseField name="mediaType" type="string">

          Media type.

          **Read-only.**

          **Supported values:**

          - `IMAGE` — Image media type.

        </ResponseField>

        <ResponseField name="uploadId" type="string">

          ID of the asynchronous media import that Wix Media Manager runs when media is set with a `url`.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="setBy" type="setBy">

          setBy

          <Expandable title="setBy properties">

            <ResponseField name="id" type="string">

              Set media by ID of an existing file in Wix Media Manager.

              Constraints: `minLength 1`, `maxLength 200`.

            </ResponseField>

            <ResponseField name="url" type="string">

              Set media using an external media URL.

              When provided, Wix Media Manager imports the media asynchronously. During import:
              - `image` is empty.
              - The promotion is saved as disabled regardless of the requested `enabled` value.

              Once the import completes successfully, the promotion's `image` is populated and
              `enabled` is set to the originally requested value. If the import fails, the
              promotion's entire `media` object is cleared and the promotion stays disabled.
              To retry, set new media.

              Constraints: `format WEB_URL`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="media" type="media">

          media

          <Expandable title="media properties">

            <ResponseField name="image" type="Image">

              Image details. Populated when media is resolved from Wix Media Manager.

              **Read-only.**

              <Expandable title="image properties">

                <ResponseField name="id" type="string">

                  WixMedia image ID.

                  Constraints: `maxLength 400`.

                </ResponseField>

                <ResponseField name="url" type="string">

                  Image URL.

                  Constraints: `format WEB_URL`.

                </ResponseField>

                <ResponseField name="height" type="integer">

                  Original image height.

                  **Read-only.**

                </ResponseField>

                <ResponseField name="width" type="integer">

                  Original image width.

                  **Read-only.**

                </ResponseField>

                <ResponseField name="altText" type="string">

                  Image alt text.

                </ResponseField>

                <ResponseField name="filename" type="string">

                  Image filename.

                  **Read-only.**

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="destinationUrl" type="string">

      URL the promotion redirects to when a customer clicks the banner.

    </ResponseField>

    <ResponseField name="categories" type="CategoryAssignment[]">

      Categories the promotion is directly assigned to.
      A promotion may also appear in subcategories when `appliedToSubcategories` is `true` for a directly assigned category.

      Constraints: `maxItems 1000`.

      <Expandable title="categories properties">

        <ResponseField name="id" type="string">

          Category ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="position" type="integer">

          Position of the promotion within the category, starting from 1.

          Must be provided for each category assignment — omitting it fails validation, because positions start from 1.

          Constraints: `min 1`.

        </ResponseField>

        <ResponseField name="appliedToSubcategories" type="boolean">

          Whether the promotion also appears in this category's subcategories. When inherited by a subcategory, the promotion keeps the same position.

          Default: `false`

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="enabled" type="boolean">

      Whether the promotion is enabled.

      When creating or updating with `media.url`, this value takes effect only after
      the media import completes successfully. See `media.url` for details.

      Default: `false`

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the promotion object.

      [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags for organizing and filtering promotions.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="publicTags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="publicTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

      ```json Object
          "updatedDate": "2026-07-08T19:33:03.538Z",

            "id": "a27d24_8a3c5e8a724f4b8a9065b0c6f4a2e7~mv2.png",

              "id": "a27d24_8a3c5e8a724f4b8a9065b0c6f4a2e7~mv2.png",

              "height": 184,
              "width": 544,
              "altText": "Summer sale banner with 50% off",
              "filename": "summer-sale-banner.png",
              "sizeInBytes": "7108"
            },
            "displayName": "summer-sale-banner.png",
            "mediaType": "IMAGE"
          },
          "destinationUrl": "https://www.example.com/summer-sale-final",
          "categories": [
            {
              "id": "f6c2e4a1-8b3d-4e5f-9a1b-2c3d4e5f6a7b",
              "position": 1,
              "appliedToSubcategories": true
            }
          ],
          "enabled": true,
          "tags": {
            "privateTags": {
              "tagIds": [
                "vN3xQ",
                "gY7dW"
              ]
            }
          }
        }
      }
      ```
