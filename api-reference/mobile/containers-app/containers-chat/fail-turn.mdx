    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="containers:chat:v1:conversation:fail_turn">containers:chat:v1:conversation:fail_turn</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/containers/chat/v1/conversations/{conversationId}/fail-turn
    ```

    ## Path Params

    <ParamField path="conversationId" type="string" required>

      Conversation ID.

    </ParamField>

    ## Body Params

    <ParamField body="correlationId" type="string" required>

      ID of the user message this turn answers.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="error" type="string">

      Human-readable failure reason.

      Constraints: `maxLength 5000`.

    </ParamField>
