    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves a trigger's payload schema with the user's [filter field](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/automations/triggers/filter-fields) selections applied.

    Learn more about [the trigger payload schema](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/the-trigger-payload-schema).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/triggers/dynamic_schema
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the [app that created the trigger](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/add-a-trigger-to-your-app).

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="triggerKey" type="string" required>

      Trigger key.

      Learn more about [adding a trigger to your app](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/add-a-trigger-to-your-app).

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="selectedFilterOptions" type="SelectedFilterOptions[]">

      When the trigger includes [filter fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/automations/triggers/filter-fields), the trigger schema only includes the schemas of the specified filter fields.

      When empty, the full trigger's payload schema is returned.

      Constraints: `maxItems 5`.

      <Expandable title="selectedFilterOptions properties">

        <ParamField body="fieldKey" type="string">

          Key representing a field from the trigger's [payload schema](https://dev.wix.com/docs/rest/business-management/automations/triggers/the-trigger-payload-schema) that has been configured as an [item selection filter](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/automations/triggers/filter-fields#item-selection). For example `formId`.

          Constraints: `minLength 1`, `maxLength 110`.

        </ParamField>

        <ParamField body="values" type="string[]">

          Values selected for the filter field.

          Constraints: `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="dynamicSchema" type="object">

      A [JSON schema](https://json-schema.org/) corresponding to the filter selection sent in the request.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Get a trigger's dynamic schema
    import { triggerCatalog } from "@wix/automations";

    const appId = "a1b2c3d4-e5f6-7890-abcd-ef1234567890";

    const options = {
      triggerKey: "my_app-form_submitted",
      selectedFilterOptions: [
        {
          fieldKey: "formId",
          values: ["contact-form", "newsletter-signup"],
        },
      ],
    };

    async function getTriggerDynamicSchema() {
      const response = await triggerCatalog.getTriggerDynamicSchema(appId, options);
      return response;
    }

    /* Promise resolves to:
    ```
