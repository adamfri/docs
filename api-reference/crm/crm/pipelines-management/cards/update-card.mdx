    <div className="wix-ref">

    Updates a card by ID.

    Each time the card is updated, `revision` increments by 1. The current `revision` must be specified when updating the card. This ensures you're working with the latest card and prevents unintended overwrites.

    The card's `pipelineId` and `currency` fields can't be updated.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/crm/pipelines/v1/cards/{card.id}
    ```

    ## Path Params

    <ParamField path="card.id" type="string" required>

      Card ID.

    </ParamField>

    ## Body Params

    <ParamField body="card" type="Card">

      Card to update, may be partial.

      See the [Card Object](/api-reference/crm/crm/pipelines-management/cards/card-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="card" type="Card">

      Updated card.

      See the [Card Object](/api-reference/crm/crm/pipelines-management/cards/card-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `REVISION_MISSING` | The revision number is required for updates. |
    | `400` | `INVALID_ARGUMENT` | `STAGE_NOT_FOUND` | The specified stage doesn't exist in the pipeline. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_OUTCOME` | The card is being moved to the done stage but doesn't have a valid outcome. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_REMOVE_NAME` | The card name can't be removed. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_ASSIGNEE_ID` | The specified assignee ID doesn't exist. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CONTACT_ID` | The specified contact ID doesn't exist. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_CHANGE_CURRENCY` | The card currency can't be changed after creation. |
    | `400` | `INVALID_ARGUMENT` | `INSUFFICIENT_CARD_DATA` | The card is missing required data. |
    | `400` | `INVALID_ARGUMENT` | `CONTACTS_NOT_FOUND` | One or more of the specified contact IDs don't exist. |
    | `400` | `INVALID_ARGUMENT` | `ADDITIONAL_CONTACTS_WITHOUT_MAIN_CONTACT` | Additional contacts were specified without a main contact. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Card Updated | `wix.crm.pipelines.v1.card_updated` | Triggered when a card is updated. |
    | Card Assigned | `wix.crm.pipelines.v1.card_assigned` | Triggered when a card is assigned. |
    | Card Moved | `wix.crm.pipelines.v1.card_moved` | Triggered when a card is moved from one stage to another. |

    </div>
