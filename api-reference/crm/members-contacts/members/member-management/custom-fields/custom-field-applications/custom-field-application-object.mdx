---
title: "Custom Field Application Object"
description: "A custom field application defines which members or entities a custom field applies to."
icon: "cube"
---

A custom field application defines which members or entities a custom field applies to.
By default, custom fields apply to all members. However, custom field applications allow you to target
specific members, roles, badges, or pricing plans, or exclude certain entities.

<Tabs>

  <Tab title="REST">

    <ResponseField name="customFieldId" type="string">

      Custom field ID.

    </ResponseField>

    <ResponseField name="customFieldKey" type="string">

      Custom field key.

      **Read-only.**

    </ResponseField>

    <ResponseField name="applications" type="ApplicationsWrapper">

      Entities to which the custom field applies.

      <Expandable title="applications properties">

        <ResponseField name="items" type="AppliesTo[]">

          List of up to 100 entities to which the the custom field applies.

          Constraints: `maxItems 100`.

          <Expandable title="items properties">

            <ResponseField name="applicationType" type="string">

              Type of the application.

              **Supported values:**

              - `ROLE` — The field is applied to members with a specific role.
              - `BADGE` — The field is applied to members with a specific badge.
              - `PRICING_PLAN` — The field is applied to members with a specific pricing plan.
              - `MEMBER` — The field is applied to the specified members.

            </ResponseField>

            <ResponseField name="entityId" type="string">

              Entity ID.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="exclusions" type="ExclusionsWrapper">

      Entities from which the custom field is excluded.

      <Expandable title="exclusions properties">

        <ResponseField name="items" type="Exclusion[]">

          List of up to 100 entities from which the custom field is excluded.

          Constraints: `maxItems 100`.

          <Expandable title="items properties">

            <ResponseField name="exclusionType" type="string">

              Type of the exclusion.

              **Supported values:**

              - `ROLE` — The field is excluded from members with a specific role.
              - `BADGE` — The field is excluded from members with a specific badge.
              - `PRICING_PLAN` — The field is excluded from members with a specific pricing plan.
              - `MEMBER` — The field is excluded from the specified members.

            </ResponseField>

            <ResponseField name="entityId" type="string">

              Entity ID.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the custom field is updated. To prevent conflicting changes, the existing revision must be used when updating a custom field.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "customFieldId": "4e4b1840-3833-4dbd-93d1-b2c9a33caa7d",
        "customFieldKey": "custom.favorite-animal",
        "applications": {
          "items": [
            {
              "applicationType": "MEMBER",
              "entityId": "ca1f9c6a-78f3-4b37-b977-951793410042"
            }
          ]
        },
        "revision": "1",
        "exclusions": {
          "items": [
            {
              "applicationType": "PRICING_PLAN",
              "entityId": "c638fb81-c3ab-44ca-bc11-883a04f980f3"
            }
          ]
        }
      }
      ```

    </CodeGroup>
