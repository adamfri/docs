    <div className="wix-ref">

    Updates selected fields of a program.

    Each time the program is updated, `revision` increments by 1. The current
    `revision` must be passed when updating the program. This ensures you're
    working with the latest program and prevents unintended overwrites.

    Ended and archived programs can't be updated. Timeline changes are blocked
    when the program has active participants.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/online-programs/v3/programs/{program.id}
    ```

    ## Path Params

    <ParamField path="program.id" type="string" required>

      Program ID.

    </ParamField>

    ## Body Params

    <ParamField body="program" type="Program" required>

      Program fields to update. Include `id` and the latest `revision`.

      See the [Program Object](/api-reference/business-management/online-programs/programs/program-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="program" type="Program">

      Updated program.

      See the [Program Object](/api-reference/business-management/online-programs/programs/program-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `WRONG_STATE` | The program is ended or archived and can't be updated. |
    | `400` | `INVALID_ARGUMENT` | `WRONG_START_DATE` | The program start date is in the past for the site's timezone. |
    | `400` | `INVALID_ARGUMENT` | `WRONG_PARTICIPANTS_NUMBER` | The participant limit is lower than the number of active participants. |
    | `428` | `FAILED_PRECONDITION` | `DUPLICATED_SLUG` | There is already a program with this SEO slug or a program ID that matches this SEO slug. |
    | `428` | `FAILED_PRECONDITION` | `TIMELINE_SWITCH_FORBIDDEN` | Timeline settings can't be changed while the program has active participants. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
