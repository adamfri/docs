## Update a site's portfolio settings
When integrating with Wix Portfolio, you can configure a site's portfolio settings.

1. Call [Get Portfolio Settings](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/portfolio-settings/get-portfolio-settings) to retrieve the current portfolio settings.

2. Call [Update Portfolio Settings](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/portfolio-settings/update-portfolio-settings) to update the portfolio settings as desired.
