The JSON object below defines the configuration for this service plugin extension. How you supply values depends on the framework you’re using:

+ **Self-hosted apps:** After adding a service plugin extension to your app in the app dashboard, provide configuration details in your extension's page. Learn more about how to add and configure a self-hosted service plugin extension with [REST](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/self-hosting/supported-extensions/backend-extensions/add-self-hosted-service-plugin-extensions-with-rest) or the [SDK](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/self-hosting/supported-extensions/backend-extensions/add-self-hosted-service-plugin-extensions-with-the-sdk).
+ **CLI apps:** Customize the configuration in your extension's [`<extension-name>.extension.ts`](https://dev.wix.com/docs/build-apps/develop-your-app/frameworks/wix-cli/supported-extensions/backend/service-plugins/service-plugin-extension-files-and-code#service-plugin-builder) file.

<Tabs>

  <Tab title="REST">

    <ResponseField name="baseUri" type="SpiBaseUri">

      Base part of your integration's deployment URI for the Custom Charges SPI.
      For example `"https://provider.example.com"`, if Wix should call your
      integration at `https://provider.example.com/v1/charge-limit` for the
      Get Charge Limit method.

      <Expandable title="baseUri properties">

        <ResponseField name="baseUri" type="string">

          Base URI for your service plugin. Wix appends each method's path to this URI.

          For example, to receive requests at `https://my-app.com/v1/my-method`, set this field to `https://my-app.com/`.

          Constraints: `minLength 6`, `maxLength 2048`.

        </ResponseField>

        <ResponseField name="alternativeUris" type="AlternativeUri[]">

          Alternative URIs for specific methods. Use these to override the default URI for individual methods.

          <Expandable title="alternativeUris properties">

            <ResponseField name="methodName" type="string">

              Name of the method to call at the absolute URI, in PascalCase. For example, to call [Get Shipping Rates](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/shipping-rates/shipping-rates-integration-service-plugin/get-shipping-rates) on an alternative URI, specify `GetShippingRates`.

              Constraints: `minLength 3`, `maxLength 128`.

            </ResponseField>

            <ResponseField name="absoluteUri" type="string">

              Absolute URI that Wix calls for this method. Wix doesn't append any path to this URI.

              The URI must begin with `https://`, such as `https://my-app.com/v1/my-custom-method`.

              Constraints: `minLength 6`, `maxLength 2048`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="listUsagesEnabled" type="boolean">

      Flag that indicates if charges by usages are enabled

    </ResponseField>

  </Tab>
