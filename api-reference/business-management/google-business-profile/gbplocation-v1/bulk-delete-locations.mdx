    Deletes multiple GBP locations, leaving their Google Business Profile
    listings in place.

    The bulk counterpart of Delete Location, and the same recovery path: use it
    to clean up stored locations whose listings are already gone from Google or
    unreachable. To remove the listings from Google too, call Delete Google
    Location once per location.

    Locations are processed independently, so one that fails doesn't stop the
    others. Check the results per location rather than relying on the response
    status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/bulk/locations/delete
    ```
