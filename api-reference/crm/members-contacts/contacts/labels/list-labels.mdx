    <div className="wix-ref">

    Lists all contact labels for a site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-LABELS">Manage Contact Labels</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/labels
    ```

    ## Query Params

    <ParamField query="labelType" type="string">

      Filter for labels of the specified type.

      **Supported values:**

      - `SYSTEM` — Default system label for the contact list.
      - `USER_DEFINED` — Label created by calling the Find Or Create Label method.
      - `WIX_APP_DEFINED` — Label created by an app built by Wix.

    </ParamField>

    <ParamField query="namespace" type="string">

      Filter for labels in the specified namespace.

    </ParamField>

    <ParamField query="startsWith" type="string">

      Filter for labels where `displayName` starts with the specified case-sensitive string.

    </ParamField>

    <ParamField query="sort" type="Sorting">

      Sorting options.

      <Expandable title="sort properties">

        <ParamField query="fieldName" type="string">

          Name of the field to sort by.

          Constraints: `maxLength 3000`.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.

          Default: `ASC`.

          **Supported values:**

          - `ASC` — Sort by ascending order.
          - `DESC` — Sort by descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="paging" type="Paging">

      Paging options.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to return.

          Defaults to `1000`. &lt;br>
          Maximum: `2000`.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="language" type="string" />

    ## Response Object

    <ResponseField name="labels" type="ContactLabel[]">

      List of labels.

      See the [Label Object](/api-reference/crm/members-contacts/contacts/labels/label-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Metadata for the page of results.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Requested offset.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Number of items that matched the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Indicates if `total` calculation timed out before the response was sent.
          Typically this happens if there is a large set of results.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
