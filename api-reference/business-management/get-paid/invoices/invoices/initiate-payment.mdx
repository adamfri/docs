    Initiates payment for an invoice.

    Creates a Wix eCommerce order if one doesn't exist, generates a payment request, and returns a checkout URL for the customer.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/invoices/{invoiceId}/initiate-payment
    ```

    ## Path Params

    <ParamField path="invoiceId" type="string" required>

      Invoice ID.

    </ParamField>

    ## Response Object

    <ResponseField name="url" type="string">

      Checkout URL for the customer to make a payment.

      Constraints: `format WEB_URL`.

    </ResponseField>

    <ResponseField name="paymentRequestId" type="string">

      Payment request ID.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ILLEGAL_ACTION` | Invoice isn't in a state that allows payment. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_INVOICE_BALANCE_FOR_ONLINE_PAYMENT` | Invoice balance must be greater than 0 for online payment. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_PUBLISHED` | The site isn't published. Publish the site and try again. |
    | `500` | `INTERNAL` | `ECOM_INSTALLATION_FAILED` | The Wix eCommerce app couldn't be installed. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_PAYMENT_REQUEST_PAGE_NOT_FOUND` | The site page required for creating an order payment request couldn't be found. |
    | `400` | `INVALID_ARGUMENT` | `ORDER_TOTAL_EXCEEDS_LIMIT` | Invoice total must be less than 10^13. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Invoice Updated | `wix.invoices.invoices.v4.invoice_updated` | Triggered when an invoice is updated. |
