    <div className="wix-ref">

    Retrieves a list of up to 1,000 data sharing policies on the current site.

    Specify `dataCollectionIds` to filter policies for specific collections.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v1/data-collection-sharing/policies
    ```

    ## Query Params

    <ParamField query="dataCollectionIds" type="string[]">

      List of collection IDs to filter policies by.

      When provided, only returns policies for the specified collections.

      Constraints: `maxLength 255`, `maxItems 100`.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Paging information.
      By default, policies are sorted by `id` in ascending order.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="dataSharingPolicies" type="DataSharingPolicy[]">

      List of data sharing policies.

      See the [Data Sharing Policy Object](/api-reference/business-solutions/cms/collection-management/data-sharing/data-sharing-policy-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Offset that was requested.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
