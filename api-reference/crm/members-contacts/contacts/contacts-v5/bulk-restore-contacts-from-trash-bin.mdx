    Restores multiple soft-deleted contacts from the trash bin.

    To restore a single contact, call [Restore Contact From Trash Bin](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/restore-contact-from-trash-bin).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/bulk/contacts/trash-bin/restore
    ```

    ## Body Params

    <ParamField body="contactIds" type="string[]">

      IDs of the contacts to restore from the trash bin.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to include the restored contacts in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkContactResult[]">

      Results of the restore operation for each contact.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Metadata regarding the restoration of this specific contact.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

            </ResponseField>

            <ResponseField name="success" type="boolean">

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Contact">

          Returned only when `returnEntity` is `true` in the request.

          See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>
