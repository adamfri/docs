## Enable the owner of a blog to display advertisements on their site through a content discovery platform

The owners of a fitness blog would like to increase revenue by displaying advertisements on their Wix site. Your app will modify the existing Ads.txt file to enable a content discovery platform as an authorized seller.

### Append an existing Ads.txt file

To add an authorized digital seller, your app will call [AppendAdsTxt](fallback::https://dev.wix.com/docs/rest/business-management/marketing/txt-file-server/ads-txt/append-ads-txt). You’ll need to pass the platform’s name, account id, payment type, and tag id inside the `content` field of the `adsTxt` object. You can read more about the structure of Ads.txt files on the [IAB’s website][IABwebsite].

<Tabs>

<Tab title="REST">

```bash
curl PATCH https://www.wixapis.com/promote-seo-txt-file-server/v2/ads \
    -H 'Content-Type: application/json;charset=UTF-8' \
    -H 'Authorization: <AUTH>' \
    -d '{
          "adsTxt": {
            "content": "google.com, pub-0000000000000001, DIRECT, f08c47fec0942fa0",
            "subdomain": "www"
           }
         }'
```

</Tab>

<Tab title="SDK">

```js
import { adsTxt } from "@wix/marketing";

const options = {
            adsTxt: {
                content: "google.com, pub-0000000000000001, DIRECT, f08c47fec0942fa0",
                subdomain: "www"
           }
         }

async function appendAdsTxt(options) {
  const response = await adsTxt.appendAdsTxt(options);
}
```

</Tab>

</Tabs>

Notice that the content field in the response has two lines, separated by the new line (\n) control character.

```json
{
   "adsTxt": {
       "content": "google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0\nsilveradexchange.com, pub-0000000000000001, RESELLER, b124y6716v287058",
       "default": false,
       "subdomain": "www"
   }
}
```
