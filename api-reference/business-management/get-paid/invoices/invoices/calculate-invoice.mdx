    Calculates totals, taxes, and available shipping options for a standalone invoice. Supports both custom and catalog line items.

    Use this method before creating or updating an invoice to preview calculated values. Pass the returned `correlationId` in subsequent calculations to optimize incremental recalculations.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/invoices/calculate-invoice
    ```

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Couldn't resolve the site. Make sure authentication includes a valid site ID. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEM_CATALOG_ITEM_NOT_FOUND` | A line item references a catalog item that does not exist or is unavailable in its source catalog. |
    | `400` | `INVALID_ARGUMENT` | `DEPOSIT_MUST_BE_LESS_THAN_TOTAL` | Deposit amount must be less than the invoice total. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_INVOICE_TYPE` | Calculate is only supported for invoices with reference type STANDALONE or AUTO_CHARGE. |
    | `500` | `INTERNAL` | `APP_INSTALLATION_FAILED` | The required apps couldn't be installed. |
    | `500` | `INTERNAL` | `SITE_PROPERTIES_FAILED` | Couldn't retrieve business details from the site properties service. |
    | `400` | `INVALID_ARGUMENT` | `ORDER_TOTAL_EXCEEDS_LIMIT` | Invoice total must be less than 10^13. |
