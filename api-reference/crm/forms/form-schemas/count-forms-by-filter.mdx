    <div className="wix-ref">

    Returns the total number of form schemas in the specified namespace that match the specified filter criteria.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/forms/count-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object for counting form schemas.

    </ParamField>

    <ParamField body="namespace" type="string" required>

      Namespace for filtering the form schemas.

      Constraints: `minLength 10`, `maxLength 50`, `immutable`.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total form schemas count. Includes active and disabled forms. Doesn't include deleted forms.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Counts the number of forms

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'http://www.wixapis.com/form-schema-service/v4/forms/count-by-filter' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>' \
        -d '{
          "filter": {
            "createdDate": {
              "$gt": "2025-01-31T07:16:52.779Z"
            }
          },
          "namespace": "wix.form_app.form"
        }'
      ```

      ```json Response
      {
          "count": 2
        }
      ```

    </CodeGroup>

    </div>
