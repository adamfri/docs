title: "Spi Configuration Object"
description: "A function SPI configuration is the service plugin configuration for a specific function."
icon: "cube"
---

A function SPI configuration is the service plugin configuration for a specific function.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Service plugin configuration ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Service plugin configuration revision.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the service plugin configuration was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the service plugin configuration was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="functionId" type="string">

      ID of the function this service plugin configuration belongs to.

    </ResponseField>

    <ResponseField name="configuration" type="object">

      Service plugin configuration data. This must adhere to the schema defined by the function type that the function is based on.

      Learn more about [service plugins and Wix Functions](https://dev.wix.com/docs/api-reference/business-management/functions/about-service-plugins-and-wix-functions).

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "00019845-6387-4006-9e9b-366caffed188",
        "revision": "2",
        "createdDate": "2024-11-28T11:55:15.984Z",
        "updatedDate": "2024-12-06T12:37:04.675Z",
        "functionId": "fb7d2934-4906-45b6-85cd-5d55d3cc9da0",
        "configuration": {
          "rewardDescription": "Loyalty Program Reward",
          "rewardName": "Frequent buyer perk"
        }
      }
      ```

    </CodeGroup>
