The Orders API allows apps or site owners to customize management of the order lifecycle, including viewing, updating, and canceling. In the dashboard, business staff can create new orders, view and edit existing orders, track fulfillment, and manage the payments cycle.

An order holds information about purchased items, price and tax summaries, shipping and billing information, any applied discounts, and the status of payment and fulfillment.

With the Orders API, you can:

* [Get](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/get-order) and [search](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/search-orders) for orders.
* [Update](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/update-order) and [cancel](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/cancel-order) an order.
* Archive and unarchive orders by setting the `archived` field with [Update Order](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/update-order). Archived orders are hidden from the main orders view in the dashboard.
* [Create](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/create-order) an order for your records.
* Listen to events when an order is [approved](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/order-approved), [updated](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/order-updated), or [canceled](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/order-canceled).

## Order creation and the Create Order method

Orders are typically created automatically when a buyer completes checkout on a Wix site. However, you can use the [Create Order](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/create-order) method to:
+ Record orders from external systems, such as POS terminals, marketplaces, or legacy platforms.
+ Create manual orders for phone or email sales.

When creating an order via the API, set the `channelInfo.type` to match the original source of the order. If no matching type exists, use `OTHER_PLATFORM`.

## Editing orders with draft orders

The [Update Order](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/update-order) method only supports updating specific fields such as contact info, addresses, and metadata. To modify pricing or line items on an existing order, use the [Draft Orders API](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/draft-orders/introduction).
