    Retrieves a list of `participations`, given the provided paging, filtering, and sorting.

    Query Participations runs with these defaults, which you can override:
    - `createdDate` is sorted in `DESC` order
    - `cursorPaging.limit` is `50`

    To learn how to query participations, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$in` | None |
    | `eventId` | `$eq`, `$in` | None |
    | `scheduleId` | `$eq`, `$in` | None |
    | `externalId` | `$eq`, `$in` | None |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.MANAGE">Manage Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/calendar/v3/participations/query
    ```
