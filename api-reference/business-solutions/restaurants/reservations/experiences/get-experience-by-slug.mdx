    Retrieves an experience by slug.

    The slug is a URL-friendly identifier for the experience page, derived from the experience display name in kebab-case format. For example, "wine-tasting-event".

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/table-reservations/experiences/v1/experiences/slug/{slug}
    ```

    ## Path Params

    <ParamField path="slug" type="string" required>

      Slug of the experience to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="experience" type="Experience">

      Retrieved experience.

      See the [Experience Object](/api-reference/business-solutions/restaurants/reservations/experiences/experience-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

  </Tab>
