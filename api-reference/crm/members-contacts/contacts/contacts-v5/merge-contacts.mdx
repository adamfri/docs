    Merges up to 5 source contacts into a target contact.

    The current target contact revision must be passed as `targetContactRevision`. This ensures you're working with the latest contact and prevents unintended overwrites.

    The merge behaves in one of two ways, depending on whether you provide `targetContact` in the request:

    - Without `targetContact`: The source contacts are merged into the existing target contact. Non-empty fields from the sources fill empty fields on the target, and array fields (emails, phones, and addresses) are combined and deduplicated. When you provide multiple sources, they're merged in order: the first source into the second, that result into the third, and so on, and finally into the target. Earlier sources take precedence over later ones.
    - With `targetContact`: The provided `targetContact` overwrites the target according to `fieldMask`, and the source contacts are deleted without their data being merged in.

    In both cases, the source contacts are permanently deleted after a successful merge.

    Set `preview` to `true` to return the merged result without applying it, so you can review the outcome before committing.

    Restrictions:
    - Source contacts can't be site members. The target contact can be a site member.
    - `externalId` can be set only once and can't be changed if it already has a value.
    - The target contact must remain valid after the merge, keeping at least one of `name`, `email`, or `phone`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/{targetContactId}/merge
    ```

    ## Path Params

    <ParamField path="targetContactId" type="string" required>

      Target contact ID.

    </ParamField>

    ## Body Params

    <ParamField body="targetContactRevision" type="integer" required>

      Revision number of the target contact, which increments by 1 each time the contact is updated.
      The current revision must be passed to prevent conflicting changes.

    </ParamField>

    <ParamField body="targetContact" type="Contact">

      Contact to overwrite the target with, instead of merging in the source contacts' data. See the endpoint description for details.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ParamField>

    <ParamField body="sourceContactIds" type="string[]">

      IDs of up to 5 contacts to merge into the target contact.
      If merging more than one source contact,
      the first source is given precedence, then the second, and so on.

      Constraints: `format GUID`, `minItems 1`, `maxItems 5`.

    </ParamField>

    <ParamField body="preview" type="boolean">

      Whether to return a preview of the merged contact instead of performing the actual merge.

      Default: `false`

    </ParamField>

    <ParamField body="allowDuplicates" type="boolean">

      Whether to update the target contact even if it becomes a duplicate of another contact. Relevant only when `targetContact` is provided.
      More about duplicate contacts can be found [here](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/matching-contacts).

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated target contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>

    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_MEMBER_EMAIL` | A contact that is a site member can't have its email updated. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CONTACT_MERGE` | Contact can't be merged into itself. |
    | `404` | `NOT_FOUND` | `SOURCE_NOT_FOUND` | Couldn't find one of the source contacts. |
    | `400` | `INVALID_ARGUMENT` | `INSUFFICIENT_CONTACT_DATA` | The target contact must have a name, phone number or email address. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_EMAIL` | The target contact has duplicate emails. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_PHONE` | The target contact has duplicate phones. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS` | The target contact has duplicate addresses. |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_DEFAULT_ADDRESSES` | The target contact has more than one address marked as default. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS_ID` | A contact has multiple addresses with the same ID. |
    | `400` | `INVALID_ARGUMENT` | `EMAIL_REQUIRED` | The target contact has additional emails but no email. |
    | `400` | `INVALID_ARGUMENT` | `PHONE_REQUIRED` | The target contact has additional phones but no phone. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_CHANGE_EXTERNAL_ID` | The contact's external ID can't be changed. |
    | `409` | `ALREADY_EXISTS` | `DUPLICATE_CONTACT_EXISTS` | A contact with the same identifier already exists. More about identifiers can be found [here](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/matching-contacts). |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TIME_ZONE` | The contact time zone is not in valid IANA format. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_IMAGE_URL` | The contact image URL is invalid. |
