    <div className="wix-ref">

    Retrieves a function template by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/api/functions/v1/templates/{appDefId}/{functionTemplateId}
    ```

    ## Path Params

    <ParamField path="functionTemplateId" type="string" required>

      ID of the function template to retrieve.

    </ParamField>

    <ParamField path="appDefId" type="string" required>

      ID of the app that owns the function template.

    </ParamField>

    ## Response Object

    <ResponseField name="functionTemplate" type="FunctionTemplate">

      The requested function template.

      See the [Function Template Object](/api-reference/business-management/functions/function-templates/function-template-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `FUNCTION_TEMPLATE_NOT_FOUND` | Couldn't find the function template associated with the specified app. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
