    Creates a ticket definition.

    You may create up to 100 definitions per event.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-TICKET-DEF">Manage Ticket Definitions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/ticket-definitions
    ```

    ## Body Params

    <ParamField body="ticketDefinition" type="TicketDefinition" required>

      Ticket definition info.

      See the [Ticket Definition Object](/api-reference/business-solutions/events/event-management/ticket-definitions-v3/ticket-definition-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `SALES_DETAILS` — Returns `salesDetails` in the response.
      - `EVENT_DETAILS` — Returns `eventDetails` in the response.
      - `SEATING_DETAILS` — Returns `seatingDetails` with available seats in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="ticketDefinition" type="TicketDefinition">

      Created ticket definition.

      See the [Ticket Definition Object](/api-reference/business-solutions/events/event-management/ticket-definitions-v3/ticket-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVALID_EVENT_TYPE` | Ticket definitions can't be created for this event type. |
    | `428` | `FAILED_PRECONDITION` | `TICKET_DEFINITIONS_LIMIT_REACHED` | Number of ticket definitions exceeds the server's limit of 100. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_SALE_PERIOD` | The `salePeriod.startDate` must be before the `salePeriod.endDate`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Ticket Definition Created | `wix.events.v3.ticket_definition_created` | Triggered when a ticket definition is created. |
    | Ticket Definition Sale Started | `wix.events.v3.ticket_definition_sale_started` | Triggered when a ticket sale starts. Sales details aren't included in the response. |
