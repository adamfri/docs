    Creates a ticket reservation.

    Reserves specified tickets for a limited time while a customer completes their purchase.
    The reservation will have `PENDING` status and will automatically expire after the
    event's configured reservation duration (typically 5-30 minutes) unless confirmed.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.EVENTS-CHECKOUT">Events Checkout</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/ticket-reservations
    ```

    ## Body Params

    <ParamField body="ticketReservation" type="TicketReservation" required>

      Ticket reservation details to create.

      Must include at least one ticket line item with valid ticket definition ID
      and quantity. Additional settings like seat assignments and pricing options
      can be specified in the ticket info.

      See the [Ticket Reservation Object](/api-reference/business-solutions/events/registration/ticketing/ticket-reservations/ticket-reservation-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="ticketReservation" type="TicketReservation">

      The created ticket reservation.

      See the [Ticket Reservation Object](/api-reference/business-solutions/events/registration/ticketing/ticket-reservations/ticket-reservation-object) for this object's fields.

    </ResponseField>

    <ResponseField name="promotionErrors" type="PromotionErrors">

      Promotion-related errors that occurred during reservation creation.

      <Expandable title="promotionErrors properties">

        <ResponseField name="error" type="Error[]">

          Errors.

          **Read-only.** Constraints: `maxItems 10`.

          <Expandable title="error properties">

            <ResponseField name="promotionType" type="string">

              Promotion type.

              **Supported values:**

              - `UNKNOWN_PROMOTION_TYPE` — Unknown promotion type. This value isn't used.
              - `OTHER` — Error after failing to apply a promotion that doesn't fit into specific categories.
              - `COUPON_CODE` — Error after failing to apply the coupon code.
              - `PAID_PLAN_BENEFIT` — Error after failing to apply the paid plan benefit.
              - `GIFT_CARD` — Error after failing to apply the gift card.

            </ResponseField>

            <ResponseField name="code" type="string">

              Error code from the service provider.

              **Read-only.**

            </ResponseField>

            <ResponseField name="message" type="string">

              Additional error message.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
