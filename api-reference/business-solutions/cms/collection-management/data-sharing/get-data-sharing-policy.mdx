  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a data sharing policy specified by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v1/data-collection-sharing/policies/{dataSharingPolicyId}
    ```

    ## Path Params

    <ParamField path="dataSharingPolicyId" type="string" required>

      Data sharing policy ID.

    </ParamField>

    ## Response Object

    <ResponseField name="dataSharingPolicy" type="DataSharingPolicy">

      Retrieved data sharing policy.

      See the [Data Sharing Policy Object](/api-reference/business-solutions/cms/collection-management/data-sharing/data-sharing-policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0154` | Data sharing policy not found. Verify the policy ID is correct and is owned by the current site. |
    | `403` | `PERMISSION_DENIED` | `WDE0144` | Permissions denied. Must have `MANAGE DATA COLLECTION SHARING` permission. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
