    Retrieves a list of up to 100 tickets, with the specified paging, filtering & sorting.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-GUEST-LIST">Read Event Tickets and Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/tickets
    ```

    ## Query Params

    <ParamField query="eventId" type="string[]">

      Event IDs to which the tickets belong.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="offset" type="integer">

      Paging offset.

      Constraints: `min 0`.

    </ParamField>

    <ParamField query="limit" type="integer">

      Number of items to load per page.

      Constraints: `min 0`, `max 100`.

    </ParamField>

    <ParamField query="orderNumber" type="string[]">

      Order numbers.

      Constraints: `minLength 1`, `maxLength 36`, `maxItems 20`.

    </ParamField>

    <ParamField query="ticketNumber" type="string[]">

      Ticket numbers.

      Constraints: `minLength 1`, `maxLength 36`, `maxItems 50`.

    </ParamField>

    <ParamField query="searchPhrase" type="string">

      Textual search filter - search is performed on `"orderFullName"`, `"guestFullName"`, and `"ticketNumber"`.

      Constraints: `maxLength 200`.

    </ParamField>

    <ParamField query="orderStatus" type="string[]">

      Order statuses.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `NA_ORDER_STATUS` — Order status isn't available for this request fieldset.
      - `FREE` — Order is confirmed, no payment is required.
      - `PENDING` — Order was paid, but the payment gateway suspended the payment.
      - `PAID` — Order is paid.
      - `OFFLINE_PENDING` — Order is confirmed but must be paid via offline payment. Status needs to be manually updated to `"PAID"`.
      - `INITIATED` — Order is waiting for payment at the cashier.
      - `CANCELED` — Order is canceled.
      - `DECLINED` — Order payment is declined.
      - `AUTHORIZED` — Order payment is authorized.
      - `VOIDED` — Order payment is voided.
      - `PARTIALLY_PAID` — Order is partially paid with less than the total amount.

    </ParamField>

    <ParamField query="fieldset" type="string[]">

      Set of fields to return in the response. See [Fieldsets](https://dev.wix.com/api/rest/wix-events/wix-events/fieldset#wix-events_wix-events_fieldset_ticket-fieldset).

      Constraints: `maxItems 20`.

      **Supported values:**

      - `GUEST_DETAILS` — Include guest details in the ticket response.
      - `TICKET_DETAILS` — Include ticket details in the ticket response.
      - `GUEST_FORM` — Include individual guest form in the ticket response.

    </ParamField>

    <ParamField query="state" type="string[]">

      Ticket states.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `ORDER_ARCHIVED` — Returns only archived orders' tickets.
      - `ORDER_ACTIVE` — Returns only non-archived orders' tickets.
      - `TICKET_ARCHIVED` — Returns only archived tickets.
      - `TICKET_ACTIVE` — Returns only non-archived tickets.
      - `CHECKED_IN` — Returns only checked-in tickets.
      - `NON_CHECKED_IN` — Returns only non-checked-in tickets.
      - `FREE` — Returns only free tickets.
      - `PAID` — Returns only paid tickets.
      - `MEMBER` — Returns only member tickets.

    </ParamField>

    <ParamField query="memberId" type="string[]">

      Site member IDs.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    <ParamField query="facet" type="string[]">

      Filter facets. For supported facets, see [Events Schema for Wix Search](https://dev.wix.com/docs/api-reference/business-solutions/events/events-schema-for-wix-search).

      Constraints: `maxLength 100`, `maxItems 20`.

    </ParamField>

    <ParamField query="sort" type="string">

      Sort order. Defaults to `ticketNumber` in ascending order.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField query="contactId" type="string[]">

      Guest contact IDs.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="ticketDefinitionId" type="string[]">

      Ticket definition IDs.

      Constraints: `format GUID`, `maxItems 10`.

    </ParamField>

    <ParamField query="seatId" type="string[]">

      Seat IDs.

      Constraints: `maxLength 36`, `maxItems 50`.

    </ParamField>

      </Expandable>

    </ResponseField>
