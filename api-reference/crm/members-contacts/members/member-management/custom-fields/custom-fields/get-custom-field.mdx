    Retrieves a custom field by ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/custom-fields/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Custom field ID.

    </ParamField>

    ## Response Object

    <ResponseField name="field" type="CustomField">

      The retrieved custom field.

      See the [Custom Field Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-fields/custom-field-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
