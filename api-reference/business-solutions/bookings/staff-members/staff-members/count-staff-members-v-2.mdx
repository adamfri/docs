    Retrieves the number of staff members that match the provided filter.

    Counts all staff members, including both service providers and staff members who don't
    provide services. To count only service providers, filter by `serviceProvider`.

    ### See also

    For the fields you can filter by, see [Filtering and Sorting](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/filtering-and-sorting).

    To learn about working with filters in general, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#filters).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RENTALS.MANAGE">Manage_Wix_Rentals_App_Forms_submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/staff-members/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter to base the count upon.
      See [Filtering and Sorting](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/filtering-and-sorting)
      for a complete list of supported filters.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total number of staff members matching the given filter.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
