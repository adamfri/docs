    <div className="wix-ref">

    Retrieves an extended field by the specified extended field key.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-EX-FIELDS">Manage Contact Extended Fields</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/extended-fields/{key}
    ```

    ## Path Params

    <ParamField path="key" type="string" required>

      Extended field key.

      When accessing contact data,
      extended field values are available at `info.extendedFields.items[key]`.
      For example, if the key is "custom.patronus",
      the value can be accessed at `info.extendedFields.items["custom.patronus"]`.

      `key` is generated when the extended field is created.
      It can't be modified, even if `displayName` is updated.

    </ParamField>

    ## Response Object

    <ResponseField name="field" type="ExtendedField">

      The specified field.

      See the [Extended Field Object](/api-reference/crm/members-contacts/contacts/extended-fields/extended-field-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
