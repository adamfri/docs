    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/v3/categories/{category.id}
    ```

    ## Path Params

    <ParamField path="category.id" type="string" required>

      Category ID.

    </ParamField>

    ## Body Params

    <ParamField body="category" type="Category" required>

      Category info.

      See the [Category Object](/api-reference/business-solutions/blog/category/category-object) for this object's fields.

    </ParamField>

    <ParamField body="fieldsets" type="string[]">

      List of additional category fields to include in the response. By default
      only the category’s base fields are returned. Base fields are all category fields that don't appear in the fieldset enum.

      To retrieve a field, pass the relevant fieldset in the enum in the `fieldsets` array. For example, add the `URL` fieldset to `fieldsets` to
      retrieve the url field in the response in addition to the category’s base fields.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes category URL.
      - `SEO` — Includes SEO data.

    </ParamField>

    ## Response Object

    <ResponseField name="category" type="Category">

      Category info.

      See the [Category Object](/api-reference/business-solutions/blog/category/category-object) for this object's fields.
