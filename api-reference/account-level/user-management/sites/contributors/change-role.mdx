    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates all of a contributor's roles for the specified site, overriding any existing roles.

    Replaces all existing role assignments for the contributor with the roles specified in `newRoles`. To retrieve available roles, call [Get Roles Info](https://dev.wix.com/docs/api-reference/account-level/user-management/accounts/users/get-roles-info).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-IDENTITY.MANAGE-CONTRIBUTORS">Manage Contributors</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/roles-management/contributor/change/role
    ```

    ## Body Params

    <ParamField body="accountId" type="string" required>

      Contributor's account ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="newRoles" type="SiteRoleAssignment[]" required>

      New roles to assign to the contributor on the site. Replaces all existing role assignments.

      <Expandable title="newRoles properties">

        <ParamField body="roleId" type="string">

          Role ID. Sometimes referred to as policy ID. See [Roles and Permissions](https://support.wix.com/en/article/roles-permissions-overview) for a list of available roles.

        </ParamField>

        <ParamField body="assignmentId" type="string">

          Assignment ID mapping the role to the contributor on the site.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="newAssignedRoles" type="SiteRoleAssignment[]">

      Roles assigned to the contributor on the site.

      <Expandable title="newAssignedRoles properties">

        <ResponseField name="roleId" type="string">

          Role ID. Sometimes referred to as policy ID. See [Roles and Permissions](https://support.wix.com/en/article/roles-permissions-overview) for a list of available roles.

        </ResponseField>

        <ResponseField name="assignmentId" type="string">

          Assignment ID mapping the role to the contributor on the site.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
