    Retrieves a list of categories, given the provided paging, filtering, and sorting.

    Query Categories runs with these defaults, which you can override:

    - `paging.limit` is `10`
    - `paging.offset` is `0`

    For field support for filters and sorting,
    see [Categories: Supported Filters and Sorting](https://dev.wix.com/docs/rest/api-reference/wix-forum/wix-forum/filter-and-sort#category-api-supported-filters-and-sorting).

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/docs/rest/articles/getting-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORUM.READ-FORUM">Read Forums</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forum/v1/categories/query
    ```

    ## Body Params

    <ParamField body="paging" type="CategoriesPaging">

      Paging object (e.g., &#123;limit: 10, offset: 100 &#125; )

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          The number of items to load.

          Constraints: `min 0`, `max 100`.

        </ParamField>

        <ParamField body="offset" type="integer">

          Number of items to skip in the current sort order.

          Constraints: `min 0`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="filter" type="object">

      Filter object (e.g., &#123; $and: [&#123; postViewCount: &#123; $gt: 0 &#125; &#125;, &#123; postCount: &#123; $gt: 0 &#125;] &#125; )

    </ParamField>

    <ParamField body="sort" type="CategoriesSort[]">

      Array of sort objects (e.g.,  [&#123; fieldName: rank, order: Order.ASC &#125;] )

      <Expandable title="sort properties">

        <ParamField body="fieldName" type="string">

          Records can be sorted by:
          rank
          postCount
          postViewCount

        </ParamField>

        <ParamField body="order" type="string">

          Records can be sorted in ascending (default) or descending order.

          **Supported values:**

          - `ASC` — Sort by ascending order.
          - `DESC` — Sort by descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="extraFields" type="string[]">

      Array of extra category fields to be added in the response. `UNKNOWN` must not be passed.

      **Supported values:**

      - `URL` — Include the category's URL.

    </ParamField>

    <ResponseField name="categories" type="Category[]">
