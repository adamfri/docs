---

An item modifier is a type of menu item that serves as an addition to a menu item.
Read more about [item modifiers](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-modifiers/introduction).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Item modifier ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the item modifier is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the item modifier. &lt;br />

      Ignored when creating an item modifier.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the item modifier was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the item modifier was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Item modifier display name.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="inStock" type="boolean">

      Whether the modifier is in stock.
      Default: `true`.

    </ResponseField>

    <ResponseField name="businessLocationIds" type="string[]">

      IDs of the business locations ([SDK](https://dev.wix.com/docs/sdk/backend-modules/restaurants/wix-restaurants-new/about-business-locations) | [REST](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/about-business-locations)) where these item modifiers are available.

      **Read-only.** Constraints: `format GUID`, `maxItems 100`.

    </ResponseField>

  </Tab>
