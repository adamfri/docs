    Assigns a badge to site members.

    Members inherit the badge's permissions when they receive the badge.
    Badge permissions are added to previous member permissions, they don't replace the existing permissions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v3/badges/{id}/members
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Badge ID.

    </ParamField>

    ## Body Params

    <ParamField body="memberIds" type="string[]" required>

      Member IDs to assign to the badge.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="memberIds" type="string[]">

      Member IDs assigned to the badge.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ```javascript Assign a badge to forum members with a top post
    /**********************************
     * Backend code - badges.web.js/ts *
     **********************************/

    import { Permissions, webMethod } from "@wix/web-methods";
    import { badges } from '@wix/members';

    export const assignMembersBackendFunction = webMethod(
      Permissions.Anyone,
      (_id, memberIds) => {
        return badges.assignBadge(_id, memberIds);
      },
    );

    /*************
     * Page code *
     ************/

    import { items } from '@wix/data';
    import { assignMembersBackendFunction } from "backend/badges.web";

    // ...

    // Get the "Top Poster" badge ID from the Members/Badges collection
    // Must be placed in an async function
    const badges = await items
      .query("Members/Badges")
      .contains("title", "Top Poster")
      .find();
    const topPosterBadgeId = items
      .query("Members/Badges")
      .contains("title", "Top Poster")
      .find()
      .then((results) => {
        return results.items[0]._id;
      })
      .catch((error) => {
        console.log(error);
      });

    items
      .query("Forum/Posts")
      .gt("likeCount", 50)
      .find()
      .then((results) => {
        if (results.items.length > 0) {
          const topPosts = results.items;

          // Assign post owner IDs to the topPostOwners array
          const topPostOwners = topPosts.map((post) => post._ownerId);
          assignMembersBackendFunction(topPosterBadgeId, topPostOwners);
        } else {
          console.log("No top posts");
        }
      })
      .catch((error) => {
        console.log(error);
      });
    ```
