    <div className="wix-ref">

    Add site members to a specific group. Public members are added right away, while private members receive an invitation to join the group.

    For `SECRET` groups, group admins and group members can add additional members to their group.
    For `PUBLIC` and `PRIVATE` groups, only group admins can add additional members to their group.
    They can also allow all group members to add a new member to the group with `group.settings`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-groups-proxy/members/v2/groups/{groupId}/members
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Body Params

    <ParamField body="memberIds" type="string[]">

      Member IDs. See the Members API for details.

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="members" type="GroupMember[]">

      New members.

      See the [Group Member Object](/api-reference/crm/community/groups/member-management/members/group-member-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Member Added | `wix.social_groups.v2.group_member_added` | Triggered when a new member is added to a group, either directly by an admin or when a Join Request is approved. |

    </div>
