planning. Your app could add identify customers who have recently canceled

## Reach out to customers who have recently canceled

Your app could add identify customers who have canceled a booking that was
scheduled to take place during a specific month and reach out to them.

To identify recently canceled bookings:

1. Call Query Extended Bookings
   ([SDK](fallback::https://dev.wix.com/docs/sdk/backend-modules/bookings/extended-bookings/query-extended-bookings) | [REST](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/bookings/bookings-reader-v2/query-extended-bookings)). Use this query filter:
   
   ```json
   {
     "query":{
       "filter":{
         "status":"CANCELED",
         "$and":[
           {
             "startDate":{
               "$gte":"2025-02-01T00:00:00Z"
             }
           }
         ],
         "$and":[
           {
             "startDate":{
               "$lte":"2025-02-28T23:59:59Z"
             }
           }
         ]
       }
     }
   }
   ```

   Make sure to include at least one filter performance-optimized filter
   ([SDK](fallback::https://dev.wix.com/docs/sdk/backend-modules/bookings/extended-bookings/supported-filters#filter-performanc) | [REST](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/bookings/bookings-reader-v2/supported-filters#filter-performance)).
1. For every retrieved booking, save `contactDetails.email`.
1. Reach out to the relevant customers.
