    Updates the order of custom fields in a section.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/custom-fields/order
    ```

    ## Body Params

    <ParamField body="fieldIds" type="string[]" required>

      IDs of the custom fields to be reordered.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="section" type="string">

      The section which the fields belong to.

      **Supported values:**

      - `GENERAL` — General section. All custom fields and the following default fields are assigned to this section: "first name", "last name", "email", "phone", "birth date", "position", "company".
      - `SOCIAL` — Social media section. The "social media" field is assigned to this section.
      - `DISPLAY_INFO` — Display info section. The default "title" field is assigned to this section.
      - `ADDRESS` — Address section. The default "address" field is assigned to this section.

    </ParamField>

    ## Response Object

    <ResponseField name="fields" type="CustomField[]">

      Reordered custom fields.

      See the [Custom Field Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-fields/custom-field-object) for this object's fields.

    </ResponseField>

    <ResponseField name="section" type="string">

      The section which the fields belong to.

      **Supported values:**

      - `GENERAL` — General section. All custom fields and the following default fields are assigned to this section: "first name", "last name", "email", "phone", "birth date", "position", "company".
      - `SOCIAL` — Social media section. The "social media" field is assigned to this section.
      - `DISPLAY_INFO` — Display info section. The default "title" field is assigned to this section.
      - `ADDRESS` — Address section. The default "address" field is assigned to this section.

    </ResponseField>
