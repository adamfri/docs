A dated record of something that happened with a contact — such as a message sent, a subscription change, or any other noteworthy event.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Activity ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="activityDate" type="datetime">

      Date and time the activity occurred.

    </ResponseField>

    <ResponseField name="contactId" type="string">

      ID of the contact the activity is associated with.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="message" type="string">

      Activity message. For activities created by Wix from a template, this is generated from the template's wording and the supplied `params`, and returned in the language specified by the `language` parameter in [List Activities](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/activity-log/activity-v1/list-activities). For custom activities you create with [Create Custom Activity](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/activity-log/activity-v1/create-custom-activity), this is the free-text `message` you provided.

      **Read-only.** Constraints: `maxLength 2000`.

    </ResponseField>

    <ResponseField name="templateId" type="string">

      ID of the template used to create this activity. For custom activities you create with [Create Custom Activity](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/activity-log/activity-v1/create-custom-activity), this is the ID of the Generic template.

    </ResponseField>

    <ResponseField name="params" type="object">

      Parameter values used to compose the activity message, as a key-value map. For activities created by Wix from a template, keys correspond to the template's `activityParams` keys.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "activity": {
          "id": "1718460000000/a3f2c8d1-5e7b-4920-8b4c-d6e9f3a2c1b5",
          "activityDate": "2024-06-15T14:00:00.000Z",
          "contactId": "7867990e-45f0-47ee-bb7b-f01960bdda2f",
          "message": "Submitted the form 'Contact Us'.",
          "templateId": "25c2a6cc-40c2-4883-ab09-6e7fcd7d0342",
          "params": {
            "FormName": "Contact Us",
            "FormURL": "https://example.com/contact"
          }
        }
      }
      ```

    </CodeGroup>
