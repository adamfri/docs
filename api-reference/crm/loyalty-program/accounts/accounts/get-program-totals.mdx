    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the total amount of points earned, redeemed, and adjusted for the entire loyalty program.

    The `balance` is the current total of points outstanding, while the `earned`, `adjusted`, and `redeemed` amounts
    are the all-time accumulated amounts. The totals include the amounts for all loyalty accounts.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-accounts/v1/accounts/program-totals
    ```

    ## Response Object

    <ResponseField name="points" type="Points">

      Point totals for the entire program.

      <Expandable title="points properties">

        <ResponseField name="balance" type="integer">

          Current points balance.

          Equal to the sum of `earned` and `adjusted` points, minus `redeemed` points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="earned" type="integer">

          Total earned points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="adjusted" type="integer">

          Total adjusted points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="redeemed" type="integer">

          Total redeemed points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="expired" type="integer">

          Total expired points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tierTotals" type="TierTotal[]">

      Tier total for the entire program.

      <Expandable title="tierTotals properties">

        <ResponseField name="id" type="string">

          Tier ID. If no Tier ID is provided, the ID is `null`.
          See the base tier in the Tiers API for more information.

          **Read-only.**

        </ResponseField>

        <ResponseField name="numberOfAccounts" type="integer">

          Total number of loyalty account that belong to a particular tier.

          Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>
