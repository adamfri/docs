| Property | Value |

| Event type | `wix.functions.v1.function_created` |
| Package | `@wix/functions` |
| Permissions | `Manage_Wix_Rentals_App_Forms_submissions`, `Manage Stores`, `View Forms`, `Manage form submissions.`, `Manage forms`, `Manage Events`, `Manage Functions`, `Manage Restaurants - all permissions`, `Set Up Automations` |
