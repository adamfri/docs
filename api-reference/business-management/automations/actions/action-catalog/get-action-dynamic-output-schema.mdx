    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves an [action's dynamic output schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#the-output-schema), based on the action's input mapping.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions/dynamic-output-schema
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the [app that created the action](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `minLength 5`, `maxLength 50`.

    </ParamField>

    <ParamField body="inputMapping" type="object" required>

      Action input mapping as defined in the [action's input schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/the-action-input-schema).

      The input mapping must include all parameters specified in the action's input schema's `required` array, and can include any other parameters from the schema.

    </ParamField>

    ## Response Object

    <ResponseField name="outputSchema" type="object">

      A [JSON schema](https://json-schema.org/) containing the action's output schema.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTION_SPI_NOT_FOUND` | The requested action does not have a matching service plugin implementer. |
    | `428` | `FAILED_PRECONDITION` | `GET_DYNAMIC_OUTPUT_SCHEMA_NOT_IMPLEMENTED` | The action provider does not implement dynamic output schema retrieval. |
    | `404` | `NOT_FOUND` | `ACTION_SPI_OUTPUT_SCHEMA_NOT_DEFINED` | The action provider did not define an output schema for the requested action. |
    | `400` | `INVALID_ARGUMENT` | `ACTION_SPI_OUTPUT_SCHEMA_NOT_VALID_JSON_SCHEMA` | The action provider returned an output schema that is not valid JSON schema. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
