    Updates the number of participants for a class or course booking and changes
    the `totalNumberOfParticipants` for the relevant sessions.

    ### Appointment limitation

    You can't update the number of participants for appointment bookings.

    ### Participant information

    You must specify either `participantsChoices` or `totalParticipants`.
    The call fails if the specified `participantsChoices` aren't among the
    supported [service options and variants](https://dev.wix.com/docs/rest/business-solutions/bookings/services/service-options-and-variants/introduction).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bookings/{bookingId}/update_number_of_participants
    ```

    ## Path Params

    <ParamField path="bookingId" type="string" required>

      ID of the booking to update the number of participants for.

    </ParamField>

    ## Body Params

    <ParamField body="revision" type="integer" required>

      Revision number, which increments by 1 each time the booking is updated.

      To prevent conflicting changes, the current revision must be specified
      when updating the booking.

    </ParamField>

    ## Response Object

    <ResponseField name="booking" type="Booking">

      Updated booking.

      See the [Booking Object](/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/booking-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `BOOKING_NOT_FOUND` | Couldn't find the booking. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
