---
title: "Storage Item Object"
description: "A storage item is a global data container that you can use across multiple automations to store different types of data in key-value pairs."
icon: "cube"
---

A storage item is a global data container that you can use across multiple automations to store different types of data in key-value pairs. This include data such as Wix user preferences, counters, and configuration settings.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Storage item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="key" type="string">

      Unique storage item key. The key can only contain letters, numbers, and underscores.

      Once you create the item, you can't update its key.

      Constraints: `minLength 1`, `maxLength 63`, `immutable`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Storage item display name. The display name appears when you [add or edit steps to your automation](https://support.wix.com/en/article/wix-automations-creating-an-automation-with-the-new-builder#step-3-add-steps-to-you-automation).

      Constraints: `minLength 1`, `maxLength 63`.

    </ResponseField>

    <ResponseField name="description" type="string">

      Storage item description.

    </ResponseField>

    <ResponseField name="type" type="string">

      Data type of the storage item's value. Once created, you can't change the value's type.

      Constraints: `immutable`.

      **Supported values:**

      - `STRING` — String.
      - `BOOLEAN` — Boolean.
      - `NUMBER` — Number.
      - `COUNTER` — Counter.

      > **Note**: Counters are numeric values used for running totals. They support [atomic increment and decrement operations](https://dev.wix.com/docs/api-reference/business-management/automations/storage-item/introduction#atomic-updates).

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      When the storage item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      When the storage item was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      [Tags](https://dev.wix.com/docs/api-reference/business-management/tags/introduction) assigned to the storage item.

      You can use public and private tags for categorization and filtering.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          List of private tags.

          Private tags require additional permissions to access. They are usually hidden from site members and visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="publicTags" type="TagList">

          List of public tags.

          Public tags are visible to anyone with access to the main storage item, including site members and visitors.

          <Expandable title="publicTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
        "key": "user_dashboard_config",
        "displayName": "User Dashboard Configuration",
        "description": "Complete configuration settings for the user's automation dashboard including theme, layout preferences, and notification settings",
        "type": "STRING",
        "stringValue": {
          "value": "{\"theme\":\"dark\",\"layout\":\"grid\",\"notifications\":{\"email\":true,\"push\":false},\"widgets\":[\"metrics\",\"recent_activity\",\"quick_actions\"]}",
          "format": "PLAIN_TEXT"
        },
        "createdDate": "2024-01-15T10:30:45.123Z",
        "updatedDate": "2024-01-15T14:22:17.456Z",
        "tags": {
          "publicTags": ["dashboard", "config"],
          "privateTags": ["internal"]
        }
      }
      ```

    </CodeGroup>
