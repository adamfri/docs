## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-LABS.READ-FAQ">Read FAQ</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`, `MEMBER`, `VISITOR`.

## Endpoint

```http
GET https://www.wixapis.com/faq/v1/categories
```

## Query Params

<ParamField query="paging" type="CursorPaging">

  Request more categories using cursor paging.

  <Expandable title="paging properties">

    <ParamField query="limit" type="integer">

      Maximum number of items to return in the results.

    </ParamField>

    <ParamField query="cursor" type="string">

      Pointer to the next or previous page in the list of results.

      Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
      Not relevant for the first request.

    </ParamField>

  </Expandable>

</ParamField>

## Response Object

<ResponseField name="categories" type="Category[]">

  List of categories.

  <Expandable title="categories properties">

    <ResponseField name="id" type="string">

      Category ID.

    </ResponseField>

    <ResponseField name="title" type="string">

      Category title.

      Constraints: `maxLength 500`.

    </ResponseField>

    <ResponseField name="sortOrder" type="number">

      Order of category within a site.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Category's creation timestamp.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Category's last update timestamp.

      **Read-only.**

    </ResponseField>

  </Expandable>

</ResponseField>

<ResponseField name="pagingMetadata" type="PagingMetadataV2">

  Metadata for the paginated results.

  <Expandable title="pagingMetadata properties">

    <ResponseField name="count" type="integer">

      Number of items returned in the response.

    </ResponseField>

    <ResponseField name="offset" type="integer">

      Offset that was requested.

    </ResponseField>

    <ResponseField name="total" type="integer">

      Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

    </ResponseField>

    <ResponseField name="tooManyToCount" type="boolean">

      Flag that indicates the server failed to calculate the `total` field.

    </ResponseField>

    <ResponseField name="cursors" type="Cursors">

      Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

      <Expandable title="cursors properties">

        <ResponseField name="next" type="string">

          Cursor string pointing to the next page in the list of results.

        </ResponseField>

        <ResponseField name="prev" type="string">

          Cursor pointing to the previous page in the list of results.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Expandable>

</ResponseField>
