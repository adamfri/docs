<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Sets a locale as the visitor primary locale for the site.

    Only one locale can be set as the visitor primary locale at a time. When you update the visitor primary locale, site visitors see the new default language on their next page load.

    <Note>

    The specified locale's `visibility` must be set to `"VISIBLE"`.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/locales/v2/locale/set-visitor-primary
    ```

    ## Body Params

    <ParamField body="localeId" type="string" required>

      ID of the locale to set as visitor primary.

      Constraints: `format LANGUAGE_TAG`.

    </ParamField>

    ## Response Object

    <ResponseField name="locale" type="Locale">

      Updated locale that is now set as the visitor primary locale.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `LOCALE_NOT_FOUND` | Couldn't find the locale. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Locale Updated | `wix.multilingual.locales.v2.locale_updated` | Triggered when a locale is updated. |

    </div>
