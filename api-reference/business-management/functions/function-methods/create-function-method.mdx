    Creates a function method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/functions/v1/methods
    ```

    ## Body Params

    <ParamField body="functionMethod" type="FunctionMethod" required>

      Function method to create.

      See the [Function Method Object](/api-reference/business-management/functions/function-methods/function-method-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="functionMethod" type="FunctionMethod">

      The created function method.

      See the [Function Method Object](/api-reference/business-management/functions/function-methods/function-method-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
