<Note>This article applies to the REST API only.</Note>

Query endpoints allow you to filter and sort results based on category properties. This article covers field support for
filtering and sorting in:

- [Query Categories](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/categories-v2/query-categories).
- [Count Categories](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/categories-v2/count-categories).

## Filtering

Specify the `filter` object in the following format:

```json
{
  "filter": {
    "fieldName": {
      "$eq": "value"
    }
  }
}
```

The following table shows field support for filters and sorting
for the [Category](https://dev.wix.com/docs/rest/business-solutions/bookings/services/category-v2/category-object) object:

| Field       | Supported Filters                                     | Sortable |
|-------------|-------------------------------------------------------|----------|
| `id`        | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith` | Sortable |
| `name`      | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith` | Sortable |
| `sortOrder` | `$eq`, `$ne`, `$exists`, `$in`, `$nin`,               | Sortable |

## Sorting

Specify the `sort` object in the following format:

```json
{
  "sort": [
    {
      "fieldName": "createdDate",
      "order": "DESC"
    }
  ]
}
```
