    <div className="wix-ref">

    Updates a folder.
    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="FOLDERS.UPDATE">FOLDERS.UPDATE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/site-folders/v2/folders/{folder.id}
    ```

    ## Path Params

    <ParamField path="folder.id" type="string" required>

      Folder ID.

    </ParamField>

    ## Body Params

    <ParamField body="folder" type="Folder">

      Folder data.

      See the [Folder Object](/api-reference/account-level/sites/site-folders/folder-object) for this object's fields.

    </ParamField>

    <ParamField body="fieldMask" type="FieldMask">

      Set of fields to update.
      Example: `"fieldMask": "name"`.

      <Expandable title="fieldMask properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="folder" type="Folder">

      Folder data.

      See the [Folder Object](/api-reference/account-level/sites/site-folders/folder-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `invalid_update_field` | The field you're trying to update can't be modified. |
    | `409` | `ALREADY_EXISTS` | `duplicate_folder_name` | There's already a folder with this name. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Folder Updated | `wix.site_folders.v2.folder_updated` | Triggered when a folder is updated. |

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X PATCH 'https://www.wixapis.com/site-folders/v2/folders/59c80b6f-9cae-49c5-ab0e-83b9a479c573' \
        -H 'Content-Type: application/json' \
        -H 'Accept: application/json, text/plain, */*' \
        -H 'Authorization: <AUTH>' \
        -H 'wix-account-id: <Account ID>' \
        -d '{"folder":{"id":"59c80b6f-9cae-49c5-ab0e-83b9a479c573","name":"My Folder 2"}, "fieldMask": "name"}'
      ```

      ```json Response
      {"folder":{"id":"59c80b6f-9cae-49c5-ab0e-83b9a479c573","name":"My Folder 2","siteCount":0,"parentId":""}}
      ```

    </CodeGroup>

    </div>
