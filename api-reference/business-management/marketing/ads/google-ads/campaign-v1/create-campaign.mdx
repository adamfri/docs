    Creates a campaign and immediately activates it in the requested status.
    The campaign becomes visible in the site's Promote/Ads dashboard alongside any manually created campaigns.

    Creating a Smart Campaign (campaignType `SMART`) is deprecated. Support for creating new Smart Campaigns
    will be removed in a future release, so use `PERFORMANCE_MAX` or `PERFORMANCE_MAX_LEADS` instead. Existing
    Smart Campaigns aren't affected and can still be retrieved, updated, paused, and resumed through this API.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-GOOGLE-ADS">Manage google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/campaigns
    ```

    ## Body Params

    <ParamField body="campaign" type="Campaign" required>

      The campaign to create.

      See the [Campaign Object](/api-reference/business-management/marketing/ads/google-ads/campaign-v1/campaign-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="campaign" type="Campaign">

      The newly created campaign.

      See the [Campaign Object](/api-reference/business-management/marketing/ads/google-ads/campaign-v1/campaign-object) for this object's fields.

    </ResponseField>
