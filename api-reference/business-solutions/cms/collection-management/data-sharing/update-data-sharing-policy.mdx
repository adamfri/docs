  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates an existing data sharing policy.

    You can only update the `dataItemsFilter` field to change which items from the collection are shared.
    You can't change which collection is shared. If you want to share a different collection, create a new data sharing policy

    Any updates to the policy automatically apply to all sites connected using this policy.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v1/data-collection-sharing/policies/{dataSharingPolicy.id}
    ```

    ## Path Params

    <ParamField path="dataSharingPolicy.id" type="string" required>

      Data sharing policy ID.

    </ParamField>

    ## Body Params

    <ParamField body="dataSharingPolicy" type="DataSharingPolicy" required>

      Data sharing policy to update.

      See the [Data Sharing Policy Object](/api-reference/business-solutions/cms/collection-management/data-sharing/data-sharing-policy-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="dataSharingPolicy" type="DataSharingPolicy">

      Updated data sharing policy.

      See the [Data Sharing Policy Object](/api-reference/business-solutions/cms/collection-management/data-sharing/data-sharing-policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0154` | Data sharing policy not found. Verify the policy ID is correct and is owned by the current site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Sharing Policy Updated | `wix.data.v1.data_sharing_policy_updated` | Triggered when a data sharing policy is updated. |

    </div>

          }
        }'

          "dataItemsFilter": {

        }
      }
