The Balances API allows you to manage your app or site's [balances](##balance*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#balance). Use this API together with other [Wix Benefit Programs APIs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/introduction).

With the Balances API, you can retrieve and update balances.

## Balances in benefit programs
A balance is the amount of credits in a pool that are available to be exchange for a benefit. 

You can update a balance manually by calling [Change Balance](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/balances/change-balance), and a balance is change automatically when a [benefit is redeemed](##redeeming-a-benefit*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#redeeming-a-benefit).

Learn more about benefit programs [components](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-program-components) and [lifecycle](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle).
