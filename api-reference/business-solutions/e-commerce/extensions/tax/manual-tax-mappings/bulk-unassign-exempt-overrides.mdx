    Unassigns tax exempt overrides to multiple manual tax mappings in a single request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/manual-tax-mappings/bulk-unassign-exempt-overrides
    ```

    ## Body Params

    <ParamField body="unassignOverrides" type="UnassignOverride[]" required>

      List of unassign overrides.

      Constraints: `maxItems 50`.

      <Expandable title="unassignOverrides properties">

        <ParamField body="manualTaxMappingId" type="string" required>

          ID of the manual tax mapping from which the exempt group override will be unassigned.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="exemptGroupIds" type="string[]">

          List of exempt group IDs to unassign from the manual tax mapping.

          Constraints: `format GUID`, `minItems 1`, `maxItems 50`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the updated manual tax mapping entities in the response.
      Default: `false`

    </ParamField>
