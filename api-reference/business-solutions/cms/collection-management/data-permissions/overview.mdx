Permissions that determine who can access or perform actions on items in a data collection.

Learn more about [collection permissions](https://support.wix.com/en/article/cms-collection-permissions-overview).

## SDK package

```bash
npm install @wix/data
```

Import the `permissions` namespace from `@wix/data`.

## Methods

<CardGroup cols={2}>

  <Card title="Get Permissions" href="/api-reference/business-solutions/cms/collection-management/data-permissions/get-permissions">
    GET Retrieves the current permissions for the specified data collection.
  </Card>
  <Card title="Update Permissions" href="/api-reference/business-solutions/cms/collection-management/data-permissions/update-permissions">
    POST Updates permissions for the specified data collection.
  </Card>
  <Card title="Add Special Permissions" href="/api-reference/business-solutions/cms/collection-management/data-permissions/add-special-permissions">
    POST Adds special permissions to a specific user or role for the specified data collection.
  </Card>
  <Card title="Update Special Permissions" href="/api-reference/business-solutions/cms/collection-management/data-permissions/update-special-permissions">
    POST Updates the special permissions for the specified user or role.
  </Card>
  <Card title="Remove Special Permissions" href="/api-reference/business-solutions/cms/collection-management/data-permissions/remove-special-permissions">
    DELETE Removes special permissions from a specific user or role.
  </Card>
  <Card title="Get My Permissions" href="/api-reference/business-solutions/cms/collection-management/data-permissions/get-my-permissions">
    GET Retrieves the current user's permissions for the specified data collection.
  </Card>

</CardGroup>
