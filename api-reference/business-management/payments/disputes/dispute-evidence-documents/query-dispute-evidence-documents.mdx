    Retrieves a list of dispute evidence documents, given the provided paging, filtering, and sorting.

    Query Dispute Evidence Documents runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order
    - `paging.limit` is `50`
    - `paging.offset` is `0`

    To learn how to query disputes, see
    [About the Wix API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `disputeId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
