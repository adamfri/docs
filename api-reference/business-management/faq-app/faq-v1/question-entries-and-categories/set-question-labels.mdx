Adds or updates a question entry's labels. Replaces existing labels.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
PUT https://www.wixapis.com/faq/v1/question-entries/{questionId}/labels
```

## Path Params

<ParamField path="questionId" type="string" required>

  ID of question entry to add labels to.

</ParamField>

## Body Params

<ParamField body="labels" type="Label[]">

  Labels to add to the question entry.

  <Expandable title="labels properties">

    <ParamField body="title" type="string">

      Label title.

      Constraints: `minLength 1`, `maxLength 36`.

    </ParamField>

    <ParamField body="sortOrder" type="number">

      Order of question entry within label.

    </ParamField>

  </Expandable>

</ParamField>

## Response Object

<ResponseField name="questionEntry" type="QuestionEntry">

  Question entry with updated labels.

  See the [Question Entry Object](/api-reference/business-management/faq-app/faq-v1/question-entries-and-categories/question-entry-object) for this object's fields.

</ResponseField>
