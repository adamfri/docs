    Validates an operation's address.

    The method checks if the operation's address stored in `businessLocationDetails.address` is valid.

    An address is considered valid if it has:

    1. A non-empty, formatted address.
    2. Valid geocode coordinates (not 0,0).
    3. A non-empty country field.

    If the address is invalid, the response includes specific violations.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/operations/v1/operations/{operationId}/validate-address
    ```

    ## Path Params

    <ParamField path="operationId" type="string" required>

      The ID of the operation whose address should be validated.

    </ParamField>

    ## Response Object

    <ResponseField name="valid" type="boolean">

      Whether the address is valid.

    </ResponseField>

    <ResponseField name="violations" type="AddressViolation[]">

      List of violations. Empty if the address is invalid.

      Constraints: `maxItems 5`.

      <Expandable title="violations properties">

        <ResponseField name="type" type="string">

          Type of violation in the address.

          **Supported values:**

          - `NO_ADDRESS` — The operation has no address configured.
          - `MISSING_FORMATTED_ADDRESS` — The address exists but is missing a formatted address string.
          - `INVALID_GEOCODE` — The address has invalid or missing geocoding information.
          - `MISSING_COUNTRY` — The address is missing country information.
          - `MISSING_SUBDIVISION` — The address is missing subdivision information.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
