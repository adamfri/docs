    Retrieves a custom field application.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/custom-fields-applications/{customFieldId}
    ```

    ## Path Params

    <ParamField path="customFieldId" type="string" required>

      ID of the custom field with an application to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="application" type="CustomFieldApplication">

      Retrieved custom field application.

      See the [Custom Field Application Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-field-applications/custom-field-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
