The Communication Channels Media API manages media files in the [Media Manager](fallback::https://support.wix.com/en/article/wix-media-about-the-media-manager) for use in communication channels. This API enables you to handle media files that you can use in messages sent through the [Inbox APIs](fallback::https://dev.wix.com/docs/api-reference/crm/communication/inbox/introduction). For example, you can include images or documents in chat messages, emails, or other communications.

With the Communication Channels Media API, you can:

- Generate upload URLs to store files in the Media Manager.
- Generate download URLs for accessing media manager files.
- Import files from external URLs directly into the Media Manager.
- Monitor storage quota and usage.

## Media Manager integration

This API is an integration with the Media Manager service and designed to work with the Inbox APIs. 
While planning your implementation, keep the following in mind: 

- Before calling [Generate File Upload Url](fallback::https://dev.wix.com/docs/api-reference/crm/communication/channels/communication-channels-media/generate-file-upload-url), learn to use the [Upload API](fallback::https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/upload-api).
- Before calling the [Import File](fallback::https://dev.wix.com/docs/api-reference/crm/communication/channels/communication-channels-media/import-file) method, learn about [importing files](fallback::https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/importing-files) with the Media Manager.
- Use the file metadata returned by the Communication Channels Media API calls in your inbox message requests.
- To delete files from the Media Manager, call the [Bulk Delete Files](fallback::https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/bulk-delete-files) method from the [Media Manager API](fallback::https://dev.wix.com/docs/api-reference/assets/media/media-manager/introduction).

## Before you begin

It's important to note the following points before starting to code:

- Check that your file's [size and MIME type are supported](fallback::https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes).
- If you exceed the storage quota, your file upload or import will fail.
- Download URLs that you generate are temporary and expire after 10 hours.
- When you upload or import a file, the file is stored in the media manager under the `/<Provider Name> Uploads` folder. For example, `/Facebook Uploads`.
