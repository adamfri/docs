    Generates social post drafts (AI image and per-channel captions) for the given marketing activities.

    Generation is asynchronous. The response returns immediately. Poll `GetMarketingActivityPosts`
    until posts appear on the activities. Posts are generated for all supported social channels;
    only posts for connected channels can be scheduled and published. Schedule the resulting
    drafts with `ScheduleDrafts`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan/generate-social-posts
    ```

    ## Body Params

    <ParamField body="marketingActivityIds" type="string[]" required>

      IDs of the marketing activities to generate posts for.

      **Read-only.** Constraints: `format GUID`, `minItems 1`, `maxItems 20`.

    </ParamField>

    ## Response Object

    Returns `GenerateSocialPostsResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
