    <div className="wix-ref">

    Creates a `connectedDomain` object and starts the domain connection process.
    It may take up to 48 hours for the DNS changes to take effect.

    You must pass the relevant Wix account ID in the header of the call.
    You may also pass a Wix site ID in the header.

    You can only connect external domains using this endpoint. Domains purchased
    and billed through Wix can't be connected via this endpoint to a Wix site.

    You can connect both root domains and subdomains to Wix sites.

    The domain can be assigned as a primary domain or a redirect.
    You can read more about [primary and redirected domains](https://support.wix.com/en/article/switching-your-primary-and-redirected-domains).
    If you connect a domain as `"PRIMARY"` to a Wix site, the existing primary
    domain automatically becomes unassigned.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.MANAGE_CONNECTED_DOMAINS">DOMAINS.MANAGE_CONNECTED_DOMAINS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/domains/v1/connected-domains
    ```

    ## Body Params

    <ParamField body="connectedDomain" type="ConnectedDomain" required>

      Domain to connect.

      See the [Connected Domain Object](/api-reference/account-level/domains/connected-domains/connected-domain-v1/connected-domain-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="connectedDomain" type="ConnectedDomain">

      Connected domain.

      See the [Connected Domain Object](/api-reference/account-level/domains/connected-domains/connected-domain-v1/connected-domain-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Connect a domain by pointing
    // @description: Creates a connected domain with POINTING connection type and PRIMARY assignment.

    import { createClient, ApiKeyStrategy } from "@wix/sdk";
    import { connectedDomains } from "@wix/domains";

    const connectedDomain = {
      domain: "mysite.com",
      connectionType: "POINTING" as const,
      siteInfo: {
        assignmentType: "PRIMARY" as const,
      },
    };

    async function createConnectedDomainExample() {
      const wixClient = createClient({
        modules: { connectedDomains },
        auth: ApiKeyStrategy({
          siteId: process.env.WIX_SITE_ID!,
          apiKey: process.env.WIX_API_KEY!,
        }),
      });

      const response = await wixClient.connectedDomains.createConnectedDomain(connectedDomain);
      return response;
    }

    /* Promise resolves to:
    ```
