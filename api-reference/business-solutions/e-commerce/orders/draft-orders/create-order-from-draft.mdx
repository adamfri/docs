    Creates a new order from a draft, while specifying which side-effects are executed.

    <Note>

    + The draft order's status is set to `COMMITTED`. This happens asynchronously, so the draft may briefly return status `DRAFT` after the order is created.
    + Committing a draft order cannot be undone or reverted.
    + A committed draft order does not allow for further modifications. However, it is kept for reference and can be retrieved.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}/create-order
    ```

          - `PENDING_MERCHANT` — Payment received, but not yet confirmed by the payment provider.

          In most cases, when a payment provider is holding payment it's because setup hasn't been successfully completed by the merchant/site owner.
          To solve this, the merchant/site owner should log in to the payment provider's dashboard and make sure their account is set up correctly, or contact their support for further assistance.

    | `428` | `FAILED_PRECONDITION` | `CREATE_ORDER_FAILED_VALIDATIONS` | Draft order isn't valid. Check `calculationErrors` for details. |
    | `409` | `ALREADY_EXISTS` | `DRAFT_ORDER_ALREADY_COMMITTED` | Draft order was already committed. |
    | `428` | `FAILED_PRECONDITION` | `DRAFT_ORDER_DEPOSIT_AMOUNT_EXCEEDS_ORDER_TOTAL` | Draft order deposit amount exceeds order total. |
    | `428` | `FAILED_PRECONDITION` | `SUBSCRIPTION_BUYER_INFO_REQUIRED` |  |
    | `428` | `FAILED_PRECONDITION` | `BILLING_ADDRESS_REQUIRED_FOR_TAX_CALCULATION` | Tax calculation requires a billing address but none is provided on the draft. |
    | `428` | `FAILED_PRECONDITION` | `BUSINESS_ADDRESS_MISSING_OR_INVALID_FOR_TAX_CALCULATION` | Tax calculation needs an address with a country, but neither the draft addresses nor the site business address (used as fallback) carry one.     Creates a new order from a draft, while specifying which side-effects are executed.

    <Note>

    + The draft order's status is set to `COMMITTED`. This happens asynchronously, so the draft may briefly return status `DRAFT` after the order is created.
    + Committing a draft order cannot be undone or reverted.
    + A committed draft order does not allow for further modifications. However, it is kept for reference and can be retrieved.

    </Note>
