    Retrieves a list of booking policy snapshots by [booking IDs](https://dev.wix.com/docs/rest/business-solutions/bookings/bookings/about-the-bookings-apis).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/booking-policy-snapshots/v1/policy-snapshots
    ```

    ## Query Params

    <ParamField query="bookingIds" type="string[]" required>

      List of booking IDs to retrieve policy snapshots for.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="bookingPolicySnapshots" type="BookingPolicySnapshot[]">

      Retrieved booking policy snapshots.

      See the [Booking Policy Snapshot Object](/api-reference/business-solutions/bookings/policies/booking-policy-snapshots/booking-policy-snapshot-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `BOOKING_POLICY_SNAPSHOT_NOT_FOUND` | Couldn't find the booking policy snapshot. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
