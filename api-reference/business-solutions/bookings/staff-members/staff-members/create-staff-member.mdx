    <div className="wix-ref">

    Creates a staff member.

    By default, the staff member works during the business working hours.
    You could follow this [sample flow](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/sample-flows#assign-a-staff-working-hour-schedule) to set custom working hours.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/staff-members
    ```

    ## Body Params

    <ParamField body="staffMember" type="StaffMember" required>

      Staff member to create.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `RESOURCE_DETAILS` — Includes `resource` in the response.
      - `ASSOCIATED_IDENTITY_STATUS` — Includes `associatedIdentityStatus` in the response.

    </ParamField>

    <ParamField body="serviceProvider" type="boolean">

      Whether the staff member provides services to customers. When `false`, the staff member is created without appearing in booking flows.

      Default: `true`.

    </ParamField>

    ## Response Object

    <ResponseField name="staffMember" type="StaffMember">

      Created staff member.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Staff Member Created | `wix.bookings.staff.v1.staff_member_created` | Triggered when a staff member is created. |
    | Staff Member Fully Created | `wix.bookings.staff.v1.staff_member_fully_created` | Triggered when a staff member is created and their working hours schedule is attached to them. Fires after the staff member created event, and the payload includes the `resource` field. |
