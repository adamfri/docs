    Retrieves the IDs of invoices associated with all specified orders.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/invoices/list-by-ids
    ```

    ## Body Params

    <ParamField body="orderIds" type="string[]" required>

      Order IDs for which to retrieve invoices.

      Constraints: `minLength 1`, `maxLength 100`, `minItems 0`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="invoicesForOrder" type="InvoicesForOrder[]">

      List of order IDs and their associated invoices.

      <Expandable title="invoicesForOrder properties">

        <ResponseField name="orderId" type="string">

          Order ID.

        </ResponseField>

        <ResponseField name="invoicesInfo" type="Invoice[]">

          Invoices info.

          Constraints: `maxItems 300`.

          See the [Invoice Object](/api-reference/business-solutions/e-commerce/orders/order-invoices/invoice-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
