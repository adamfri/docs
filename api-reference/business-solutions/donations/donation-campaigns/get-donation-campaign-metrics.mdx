    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves metrics for a donation campaign.

    Returns the total number of successful donations and amount collected for the campaign.
    The `campaignGoal` must be configured before using this method.

    Currently supports metrics in the site's default currency only.

    <Note>

    This method provides aggregated metrics only. To retrieve individual donation details, use [Search Orders](https://dev.wix.com/docs/rest/business-solutions/e-commerce/orders/orders/search-orders) and filter by `lineItems.catalogReference.catalogItemId` equal to the donation campaign ID.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DONATIONS.MANAGE-CAMPAIGNS">Manage Donation Campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/donation-campaigns/v2/donation-campaigns/{donationCampaignId}/metrics
    ```

    ## Path Params

    <ParamField path="donationCampaignId" type="string" required>

      ID of the donation campaign to retrieve metrics for.

    </ParamField>

    ## Response Object

    <ResponseField name="currencyMetricsList" type="CurrencyMetrics[]">

      List of metrics per currency.

      Currently returns only the site's default currency.

      Constraints: `maxItems 1`.

      <Expandable title="currencyMetricsList properties">

        <ResponseField name="currencyCode" type="string">

          Three-letter currency code in ISO-4217 alphabetic format.

          Constraints: `maxLength 8`.

        </ResponseField>

        <ResponseField name="donationCount" type="integer">

          Total number of successful donations.

        </ResponseField>

        <ResponseField name="totalAmount" type="MultiCurrencyPrice">

          Total amount collected from all donations.

          <Expandable title="totalAmount properties">

            <ResponseField name="amount" type="string">

              Amount.

              Constraints: `>= 0`, `<= 1000000000000000`.

            </ResponseField>

            <ResponseField name="convertedAmount" type="string">

              Converted amount.

              **Read-only.** Constraints: `>= 0`, `<= 1000000000000000`.

            </ResponseField>

            <ResponseField name="formattedAmount" type="string">

              Amount formatted with currency symbol.

              **Read-only.**

            </ResponseField>

            <ResponseField name="formattedConvertedAmount" type="string">

              Converted amount formatted with currency symbol.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CAMPAIGN_GOAL_NOT_SET` | Campaign goal must be configured before retrieving metrics. |
    | `500` | `INTERNAL` | `SITE_CURRENCY_UNAVAILABLE` | Site currency settings are temporarily unavailable. Try again later. |
    | `500` | `INTERNAL` | `METRICS_TEMPORARILY_UNAVAILABLE` | Metrics are temporarily unavailable. Try again later. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
