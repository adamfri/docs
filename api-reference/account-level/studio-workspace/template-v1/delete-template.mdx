      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    This method requires one of the following permission scopes:

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/wixstudio/templates/v1/templates/{templateId}
    ```

    ## Path Params

    <ParamField path="templateId" type="string" required>

      ID of the template to delete.

    </ParamField>
