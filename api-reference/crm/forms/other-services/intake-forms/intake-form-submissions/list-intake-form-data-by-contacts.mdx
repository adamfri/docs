    Retrieves intake form data for specified contacts.

    Returns both intake forms without submissions and the most recent submission per contact and form ID.
    If you include a deleted intake form ID in the request, that form is omitted from the response.

    Call this method to see which forms each contact has submitted and which they haven't. You can use it for a single contact or many at once.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.READ">Read Intake Form</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/intake-forms/v1/submissions
    ```

    ## Body Params

    <ParamField body="contactInfo" type="ContactInfo[]" required>

      Contacts to retrieve intake form data for.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="intakeFormIds" type="string[]">

      Optional filter. List of intake form IDs to limit results to.

      Constraints: `format GUID`, `maxItems 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="contactIntakeFormData" type="ContactIntakeFormData[]">

      Intake form data per contact.

      <Expandable title="contactIntakeFormData properties">

        <ResponseField name="contactInfo" type="ContactInfo">

          Contact information.

          <Expandable title="One of the following">

            <ResponseField name="contactIdentifier" type="contactIdentifier">

              contactIdentifier

              _Nested structure omitted for brevity — see the `contactIdentifier` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="intakeFormData" type="IntakeFormData[]">

          Intake form data for the contact.

          Constraints: `minItems 1`, `maxItems 20`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `UNAUTHORIZED_CONTACT_ACCESS` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method doesn't have the required permissions. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
