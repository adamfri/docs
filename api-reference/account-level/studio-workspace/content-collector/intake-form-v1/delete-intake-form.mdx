    Deletes an intake form.

    After deletion, the intake form no longer appears in [Query Intake Forms](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/query-intake-forms)
    or [Search Intake Forms](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/search-intake-forms) results.

    Deleting an intake form also permanently deletes the questionnaire behind it.
    This is irreversible: the questionnaire and its configuration are destroyed
    along with the intake form.

    To delete multiple intake forms in a single request, call [Bulk Delete Intake Forms](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/bulk-delete-intake-forms).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.CONTENT-COLLECTOR">SCOPE.PARTNERS.CONTENT-COLLECTOR</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.
