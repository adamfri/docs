---
title: "External Database Connection Object"
description: "An external database connection defines a connection between an external database and a Wix site."
icon: "cube"
---

An external database connection defines a connection between an external database and a Wix site.

<Tabs>

  <Tab title="REST">

    <ResponseField name="name" type="string">

      Name of the external database connection.

      An external database connection can connect to one or more external data collections or tables. These appear as `connectionName/dataCollectionId`.

      Constraints: `minLength 1`, `maxLength 255`, `immutable`.

    </ResponseField>

    <ResponseField name="endpoint" type="string">

      Base URL for accessing and managing data in the external database. For example: `https://example.com/my-external-database`.
      Required for STANDALONE connection type.

    </ResponseField>

    <ResponseField name="configuration" type="object">

      Settings specified to the external database connection as part of each request.

      These settings can relate to authentication, tenancy, or provide any other information necessary for processing a request. Their content and structure depend on the specific requirements of the external database's API.

    </ResponseField>

    <ResponseField name="connectionStatus" type="ConnectionStatus">

      Status of the external database connection. Includes whether the connection was established successfully, and if not, the reason for the failure.

      **Read-only.**

      <Expandable title="connectionStatus properties">

        <ResponseField name="successful" type="boolean">

          Whether the connection was established successfully.

        </ResponseField>

        <ResponseField name="causeOfFailure" type="string">

          Whether and why the connection attempt failed.

          **Supported values:**

          - `NONE` — No connection failure.
          - `COMMUNICATION_FAILURE` — General communication failure.
          - `DESTINATION_HOST_UNREACHABLE` — External database host is unreachable.
          - `UNAUTHORIZED` — Unauthorized to access the external database.
          - `DESTINATION_ENDPOINT_NOT_DEFINED` — `endpoint` is not set.

        </ResponseField>

        <ResponseField name="hasCollections" type="string">

          Whether the external database has collections.

          **Read-only.**

          **Supported values:**

          - `YES` — External database has collections.
          - `NO` — External database does not have any collections.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="publicKey" type="string">

      Public key used to validate requests to the external database.

      **Read-only.**

    </ResponseField>

    <ResponseField name="capabilities" type="Capabilities">

      Capabilities of the external database.

      **Read-only.**

      <Expandable title="capabilities properties">

        <ResponseField name="collectionModificationsSupported" type="boolean">

          Whether the external database supports creating new collections, updating the structure of existing collections, or deleting them.

        </ResponseField>

        <ResponseField name="fieldTypes" type="string[]">

          Field types the external database supports. Applies only when `collectionModificationsSupported` is set to `true`.

          Constraints: `maxItems 255`.

          **Supported values:**

          - `TEXT`
          - `NUMBER`
          - `DATE`
          - `DATETIME`
          - `IMAGE`
          - `BOOLEAN`
          - `DOCUMENT`
          - `URL`
          - `RICH_TEXT`
          - `VIDEO`
          - `ANY`
          - `ARRAY_STRING`
          - `ARRAY_DOCUMENT`
          - `AUDIO`
          - `TIME`
          - `LANGUAGE`
          - `RICH_CONTENT`
          - `MEDIA_GALLERY`
          - `ADDRESS`
          - `PAGE_LINK`
          - `REFERENCE`
          - `MULTI_REFERENCE`
          - `OBJECT`
          - `ARRAY`
          - `LEGACY_TIME` — Deprecated - can’t be added to collections. Can only appear in older collections.
          - `LEGACY_BOOK` — Deprecated - can’t be added to collections. Can only appear in older collections.
          - `LEGACY_EXTERNAL_URL` — Deprecated - can’t be added to collections. Can only appear in older collections.
          - `LEGACY_BROKEN_REFERENCE` — Deprecated - can’t be added to collections. Can only appear in older collections.
          - `LEGACY_IMAGE` — Deprecated - can’t be added to collections. Can only appear in older collections.
          - `LEGACY_COLOR` — Deprecated - can’t be added to collections. Can only appear in older collections.
          - `LEGACY_EXTERNAL_VIDEO` — Deprecated - can’t be added to collections. Can only appear in older collections.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
          "name":"MyExternalDatabase",
          "endpoint":"https://example.com/my-external-database",
          "configuration": {
              "secretKey": "2b723306-4d74-42a2-8438-2ff40da3e6b6"
          },
          "connectionStatus": {
              "successful": true,
              "causeOfFailure": "NONE",
              "hasCollections": "YES"
          },
          "capabilities": {
              "collectionModificationsSupported": false,
              "fieldTypes": []
          }
      }
      ```

    </CodeGroup>
