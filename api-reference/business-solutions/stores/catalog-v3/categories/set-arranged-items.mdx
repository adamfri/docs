    Sets the manual arrangement of items in a category.

    The order of items in the `items` array determines their display order when L[ist Items In Category](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/categories/list-items-in-category) is called with `useCategoryArrangement: true`. The category's existing arrangement is replaced with the provided list.

    Limited to 100 items. Items beyond this limit are displayed after the arranged items, sorted by the date they were added.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_ITEM_WRITE">Category item write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/categories/v1/categories/{categoryId}/set-arranged-items
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      Category ID.

    </ParamField>

    ## Body Params

    <ParamField body="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField body="appNamespace" type="string" required>

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField body="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="items" type="ItemReference[]">

      List of items in the desired order. The order in this array determines the display order when List Items In Category is called with `useCategoryArrangement: true`.

      Constraints: `maxItems 100`.

      <Expandable title="items properties">

        <ParamField body="catalogItemId" type="string">

          ID of the item within the catalog.

          For Wix Stores, this is the product ID from the [Catalog V3 Products API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/introduction).

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="appId" type="string">

          ID of the Wix app providing the catalog.

          Currently, only Wix Stores is supported. Use `"215238eb-22a5-4c36-9e7b-e7c08025e04e"` for all Wix Stores products.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="items" type="ItemReference[]">

      List of arranged items.

      Constraints: `maxItems 100`.

      <Expandable title="items properties">

        <ResponseField name="catalogItemId" type="string">

          ID of the item within the catalog.

          Constraints: `minLength 1`, `maxLength 36`.
