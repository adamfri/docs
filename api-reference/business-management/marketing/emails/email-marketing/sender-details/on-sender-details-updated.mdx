An event that triggers when sender details are updated without the need for explicit verification.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.email_marketing.v1.sender_details_updated` |
| Package | `@wix/email-marketing` |
| Permissions | `Access Verticals by Automations`, `Set Up Automations`, `Read Email Marketing`, `Manage Email Marketing` |
