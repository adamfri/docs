    Retrieves a list of tax documents that belong to a Wix Payments account.

    You must specify the `accountId` of the account whose tax documents you want to retrieve.

    Tax documents are sorted in descending order by `period`, then by `createdDate`.

    When `type` is omitted, tax documents of all types are returned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYMENTS.MANAGE-TAX-DOCUMENTS">Managing tax tax documents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/payments/platform/v1/tax-documents
    ```
