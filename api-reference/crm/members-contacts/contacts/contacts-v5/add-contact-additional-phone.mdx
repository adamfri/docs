    Adds an additional phone to a contact.

    The contact must have a main phone (`phone.phone`) before an additional phone can be added. If the contact already has the same phone number with the same tag, the request is ignored.

    Each time the contact is updated, `revision` increments by 1. The current `revision` must be passed. This ensures you're working with the latest contact and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/{contactId}/additional-phones
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to add a phone to.

    </ParamField>

    ## Body Params

    <ParamField body="phone" type="AdditionalPhone" required>

      Phone to add.

      <Expandable title="phone properties">

        <ParamField body="tag" type="string">

          Phone type classification for the additional phone number.

          Default: `OTHER`

          **Supported values:**

          - `OTHER`
          - `MAIN`
          - `HOME`
          - `MOBILE`
          - `WORK`
          - `FAX`

        </ParamField>

        <ParamField body="phone" type="string">

          Additional phone number for the contact.
          Does not affect subscription status or contact matching logic.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="e164" type="string">

          Additional phone number in [ITU E.164 international](https://www.itu.int/rec/T-REC-E.164/) format (e.g., +12345550123).
          This field is automatically generated from the phone field if it represents a valid E.164 number.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="revision" type="integer" required>

      Contact revision number.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |

    | `428` | `FAILED_PRECONDITION` | `ADDITIONAL_PHONES_LIMIT_REACHED` |  |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
