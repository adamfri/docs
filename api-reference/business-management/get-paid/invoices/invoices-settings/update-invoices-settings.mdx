    Updates a site's invoice settings.

    Each time the invoice settings are updated, `revision` increments by 1. The current `revision` must be passed when updating the invoice settings. This ensures you're working with the latest invoice settings and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/invoices/v4/invoices-settings
    ```

    ## Body Params

    <ParamField body="invoicesSettings" type="InvoicesSettings" required>

      Invoice settings to update.

      See the [Invoices Settings Object](/api-reference/business-management/get-paid/invoices/invoices-settings/invoices-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="invoicesSettings" type="InvoicesSettings">

      Updated invoice settings.

      See the [Invoices Settings Object](/api-reference/business-management/get-paid/invoices/invoices-settings/invoices-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Couldn't find the site. |
    | `400` | `INVALID_ARGUMENT` | `NEXT_NUMBER_MISSING` | The `nextNumber` field must be specified. |
    | `400` | `INVALID_ARGUMENT` | `PREFIX_CONTAINS_ILLEGAL_CHARACTERS` | The `prefix` contains illegal characters (&lt;, >, :, ", /, \, \|, ?, *). |
    | `400` | `INVALID_ARGUMENT` | `SUFFIX_CONTAINS_ILLEGAL_CHARACTERS` | The `suffix` contains illegal characters (&lt;, >, :, ", /, \, \|, ?, *). |
    | `400` | `INVALID_ARGUMENT` | `NEXT_NUMBER_DESCENDING` | The specified `nextNumber` is lower than the already used number for the current `prefix`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | Invoices Settings Updated | `wix.invoices.settings.v4.invoices_settings_updated` | Triggered when invoice settings are updated. |

      curl -X PATCH \

        -d '{
          "invoicesSettings": {
            "revision": "1",

              "numbering.nextNumber",
