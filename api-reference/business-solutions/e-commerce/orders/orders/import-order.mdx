    Imports a single order together with its historical data, such as the original creation date, order number, and statuses.

    Import Order is designed for migrating existing orders into a site from an external system, for example when a merchant moves from another eCommerce platform. Provide the complete order in the request. Wix stores the values you provide as-is and doesn't recalculate totals or statuses, so fields such as `priceSummary`, `balanceSummary`, and `fulfillmentStatus` reflect exactly what you send.

    Unlike creating an order through the regular flow, importing an order doesn't trigger side effects: no notifications are sent to the buyer, inventory isn't adjusted, and no contact, invoice, receipt, or subscription is created. Standard order webhooks aren't fired either. Instead, a single `OrderImported` webhook is emitted.

    To overwrite a previously imported order, pass its `id`. The existing order is fully replaced with the details in the request. Only orders that were originally created with Import Order can be overwritten this way. To import a new order, omit `id`, and Wix generates one.

    To define the number assigned to orders created after your migration, call [Set Order Number Counter](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/set-order-number-counter). To remove imported orders, call [Bulk Delete Imported Orders](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/bulk-delete-imported-orders).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.IMPORT-ORDERS">SCOPE.ECOM.IMPORT-ORDERS</span>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/orders/import
    ```

    ## Body Params

    <ParamField body="order" type="Order" required>

      Order to import, including its historical data. Provide the complete order. Wix stores the values as provided and doesn't recalculate totals or statuses.

      To overwrite a previously imported order, set `id` to that order's ID.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Imported order.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ResponseField>
