<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a tax region.

    After deletion, tax is no longer calculated for addresses in this region and zero tax is returned.

    Wix also removes the manual tax mappings for the deleted region, but this cleanup isn't guaranteed for every site yet. To be safe, delete a region's manual tax mappings yourself before deleting the region.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/billing/v1/tax-regions/{taxRegionId}
    ```

    ## Path Params

    <ParamField path="taxRegionId" type="string" required>

      ID of the tax region to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteTaxRegionResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Tax Region Deleted | `wix.billing.v1.tax_region_deleted` | Triggered when a tax region is deleted. |
