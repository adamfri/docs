    <div className="wix-ref">

    Joins the current member to the site community and sets their profile to public.

    When a member's profile is public, they have access to the site's
    [Members Area](https://support.wix.com/en/article/site-members-about-the-members-area)
    features, such as chat, forum, and followers.
    Their profile is visible to other members and site visitors.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    To remove the current member from the site community and set their profile to private, call [Leave Community](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/leave-community).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/members/join-community
    ```

    ## Response Object

    <ResponseField name="member" type="Member">

      The updated member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `COMMUNITY_JOIN_IMPOSSIBLE` | Member can't join the community because the site's privacy settings don't allow public members. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
