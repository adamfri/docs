    Updates a review.

    Each time the review is updated, `revision` increments by 1.
    The existing `revision` must be included when updating the review.
    This ensures you're working with the latest review information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/reviews/v1/reviews/{review.id}
    ```

    ## Path Params

    <ParamField path="review.id" type="string" required>

      Review ID.

    </ParamField>

    ## Body Params

    <ParamField body="review" type="Review">

      Review to update.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="review" type="Review">

      Updated review data.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Review Updated | `wix.reviews.v1.review_updated` | Triggered when a review is updated. |
    | Review Moderation Status Changed | `wix.reviews.v1.review_moderation_status_changed` | Triggered when a review's moderation status is changed or a review is created. |
    | Review Published | `wix.reviews.v1.review_review_published` | Triggered when a review's moderation status is set to `"APPROVED"`. |

    </div>

    Updates a review.

    Each time the review is updated, `revision` increments by 1.
    The existing `revision` must be included when updating the review.
    This ensures you're working with the latest review information, and it prevents unintended overwrites.

    <Note>

      **Authentication**

      This method may require higher-level permissions than the caller has, based on their [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) and [roles and permissions](https://support.wix.com/en/article/roles-permissions-overview). In these cases, you can ensure the method is called with the required level of authorization by using one of the following:

      - In Wix sites and Wix apps, use [elevated permissions](https://dev.wix.com/docs/api-reference/articles/authentication/about-elevated-permissions).
      - In Wix Headless projects, use [API key authentication](https://dev.wix.com/docs/go-headless/develop-your-project/admin-operations/about-admin-operations).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">


    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Review ID.

      **Read-only.** Constraints: `format GUID`.

    </ParamField>

    <ParamField body="review" type="UpdateReview" required>

      Review to update.

      <Expandable title="review properties">

        <ParamField body="namespace" type="string">

          Review namespace.

          Supported values:
          + Wix Stores: `stores`

          Currently, only Wix Stores is fully integrated with the Wix Reviews app.

        </ParamField>

        <ParamField body="entityId" type="string">

          ID of the entity to review. For example, a Wix Stores product ID.

          Constraints: `maxLength 36`.

        </ParamField>

        <ParamField body="_id" type="string">

          Review ID.

          **Read-only.** Constraints: `format GUID`.

        </ParamField>

        <ParamField body="content" type="ReviewContent">

          Review content.

          <Expandable title="content properties">

            <ParamField body="title" type="string">

              Review title.

            </ParamField>

            <ParamField body="body" type="string">

              Review body.

              Max: 3,000 characters

            </ParamField>

            <ParamField body="media" type="Media[]">

              List of media items associated with the review.

              Max: 10 items

              Constraints: `maxItems 10`.

              _Nested structure omitted for brevity — see the `Media[]` object._

            </ParamField>

            <ParamField body="rating" type="integer">

              Rating of the review.

              Min: `1` &lt;br />
              Max: `5`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the review was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the review was updated.

          **Read-only.**

        </ParamField>

        <ParamField body="author" type="Author">

          Author of the review.

          <Expandable title="author properties">

            <ParamField body="contactId" type="string">

              Contact ID of the author.

            </ParamField>

            <ParamField body="authorName" type="string">

              Display name of the author.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="reply" type="Reply">

          Reply to the review.

          **Read-only.**

          <Expandable title="reply properties">

            <ParamField body="message" type="string">

              Reply content.

              Constraints: `maxLength 1000`.

            </ParamField>

            <ParamField body="_createdDate" type="datetime">

              Date and time the reply was created.

              **Read-only.**

            </ParamField>

            <ParamField body="_updatedDate" type="datetime">

              Date and time the reply was updated.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="foundHelpful" type="integer">

          Number of site visitors who found the review helpful.

          **Read-only.**

        </ParamField>

        <ParamField body="foundUnhelpful" type="integer">

          Number of site visitors who found the review unhelpful.

          **Read-only.**

        </ParamField>

        <ParamField body="helpfulness" type="integer">

          Helpfulness score.

          Calculated by subtracting `foundUnhelpful` from `foundHelpful`.

          **Read-only.**

        </ParamField>

        <ParamField body="moderation" type="Moderation">

          Moderation status of the review.

          **Read-only.**

          <Expandable title="moderation properties">

            <ParamField body="moderationStatus" type="string">

              Supported states of the review.

              **Supported values:**

              - `APPROVED` — The review is approved and published.
              - `IN_MODERATION` — The review is pending moderation. Moderation can be applied in the Wix user's [dashboard](https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Freviews/pending).
              - `REJECTED` — The review is rejected and not visible on the site.
              - `SUBMITTED` — Initial status of the review before the moderation process.
              - `SKIPPED` — Moderation was skipped and the review was published instantly because moderation is disabled.

            </ParamField>

            <ParamField body="manuallyChanged" type="boolean">

              Indicates whether a moderator manually changed the `moderationStatus` of the review.

              If the `moderationStatus` changed automatically because the review
              passed the moderation rules or if moderation is turned off, this field is set to `false`.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the review is updated.
          To prevent conflicting changes,
          the current `revision` must be passed when updating the review.
          Ignored when creating a review.

          **Read-only.**

        </ParamField>

        <ParamField body="verified" type="boolean">

          Whether the review has been verified.

          **Read-only.**

        </ParamField>

        <ParamField body="origin" type="Origin">

          Origin of a review.

          **Read-only.**

          <Expandable title="origin properties">

            <ParamField body="type" type="string">

              Origin type.

              **Supported values:**

              - `ORGANIC` — Review was created directly by members or site visitors.
              - `APP` — Review was created through an app. Includes reviews created through an app even if the author is a member or site visitor.

            </ParamField>

            <ParamField body="appId" type="string">

              The app ID of the origin for the review.
              Only available when the `origin.type` is `"APP"`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="reviewDate" type="datetime">

          Date and time when the review was written.
          This should match `createdDate`, except for reviews imported from another system.

        </ParamField>

        <ParamField body="relevanceScore" type="number">

          Platform-calculated score of review's relevance to the item.
          Used to sort reviews by relevance.

          **Read-only.**

        </ParamField>

        <ParamField body="publishCount" type="integer">

          Number of times a review has been published.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>
