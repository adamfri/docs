    Sets a booking policy as the default.

    Also updates the site's current default policy by setting its `default`
    attribute to `false`. If the provided policy is already the site's
    default, the call succeeds without changing any `bookingPolicy` object.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/booking-policies/{bookingPolicyId}:setDefault
    ```

    ## Path Params

    <ParamField path="bookingPolicyId" type="string" required>

      ID of the booking policy that's set as default.

    </ParamField>

    ## Response Object

    <ResponseField name="currentDefaultBookingPolicy" type="BookingPolicy">

      New default booking policy.

      See the [Booking Policy Object](/api-reference/business-solutions/bookings/policies/booking-policies/booking-policy-object) for this object's fields.

    </ResponseField>

    <ResponseField name="previousDefaultBookingPolicy" type="BookingPolicy">

      Previous default booking policy. Not available if the provided booking policy
      was already the default.

      See the [Booking Policy Object](/api-reference/business-solutions/bookings/policies/booking-policies/booking-policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Default Booking Policy Set | `wix.bookings.v1.booking_policy_default_booking_policy_set` | Triggered when the site's default policy changes. Then, [Booking Policy Updated](https://dev.wix.com/docs/rest/business-solutions/bookings/policies/booking-policies/booking-policy-updated) is also triggered both for the new and the previous default policy. |
    | Booking Policy Updated | `wix.bookings.v1.booking_policy_updated` | Triggered when a booking policy is updated, including when a policy's `default` attribute changes. |

    </div>
