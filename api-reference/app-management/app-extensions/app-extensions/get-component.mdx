    Retrieves a component by ID.

    Specify the component ID and its `appId`. REST callers currently specify the component ID in the `id` path parameter; `componentId` is the replacement field for SDK and RPC callers. Specify `version` to retrieve a specific version. Version `0` retrieves the draft component.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/components/v1/components/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required />

    <ParamField query="appId" type="string" required>
