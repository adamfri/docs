    <div className="wix-ref">

    Creates and sends emails inviting potential site contributors to become contributors in the requesting site.
    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header. API keys are currently available to selected beta users only.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-IDENTITY.MANAGE-CONTRIBUTORS">Manage Contributors</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invites/site-invite/bulk
    ```

    ## Body Params

    <ParamField body="policyIds" type="string[]" required>

      Role IDs, referred to as policy IDs, to assign to the contributors.

    </ParamField>

    <ParamField body="emails" type="string[]" required>

      Email addresses to which the invites should be sent.

      Constraints: `minItems 1`, `maxItems 10`.

    </ParamField>

    <ParamField body="invitePurpose" type="string">

      Details explaining the purpose of the invite.

    </ParamField>

    <ParamField body="defaultEmailLanguage" type="string">

      Language of emails to send. Relevant only for recipients that don't currently have a Wix user ID. Default: Site owner's language.

    </ParamField>

    <ParamField body="locationRestriction" type="LocationRestriction">

      Location restriction for the invite.

      <Expandable title="locationRestriction properties">

        <ParamField body="locationIds" type="string[]">

          Constraints: `format GUID`, `maxItems 20`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="invites" type="SiteInvite[]">

      Invites that were sent successfully.

      See the [Site Invite Object](/api-reference/account-level/user-management/sites/site-invites/site-invite-object) for this object's fields.

    </ResponseField>

    <ResponseField name="failedEmails" type="string[]" deprecated>

      Deprecated: use `failed_invites`. Populated in parallel for existing clients.

      **Deprecated.** Deprecated: use `failed_invites`. Populated in parallel for existing clients. Use `failed_invites` instead. Removal: 2027-08-01.

    </ResponseField>

    <ResponseField name="failedInvites" type="FailedSiteInvite[]">

      Invites that failed, with the reason for each.

      <Expandable title="failedInvites properties">

        <ResponseField name="email" type="string">

          Email address the invite was addressed to.

          Constraints: `format EMAIL`.

        </ResponseField>

        <ResponseField name="reason" type="string">

          Why this invite failed.

          **Supported values:**

          - `UNKNOWN_FAILURE_REASON` — Failure reason could not be determined.
          - `USER_IS_SITE_OWNER` — This person owns the site.
          - `USER_ON_REQUESTER_TEAM` — This person has access to the site as a member of the requester's team.
          - `USER_ON_ANOTHER_TEAM` — This person has access to the site as a member of a team that is not the requester's.
          - `USER_VIA_COLLABORATOR_ACCOUNT` — This person's own account holds a collaborator assignment on the site.
          - `USER_ALREADY_HAS_ACCESS` — This person already has access, but the source could not be determined.
          - `INVITE_ALREADY_EXISTS` — An invite for this email address already exists on the site - pending, declined or expired.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
