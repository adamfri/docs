The Program Definitions API allows you to manage your app or site's [program definitions](##program-defintion*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#program-defintion). Use this API together with other [Wix Benefit Programs APIs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/introduction).

With the Program Definitions API, you can retrieve, create, update, and delete program definitions.

## Program definitions in benefit programs
Use program definitions to group [pool definitions](##pool-defintion*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#pool-defintion). A program definition serves as a template for future [programs](##program*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#program), which are each assigned a [beneficiary](##beneficiary*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#beneficiary).

Consider a program definition to be the theory of a program. A program definition is how a program looks before a visitor enrolls in it.

Learn more about benefit programs [components](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-program-components) and [lifecycle](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle).
