Triggered when a category is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.forum.category_created` |
| Package | `@wix/forum` |
| Permissions | `Read Forums`, `Manage Forums` |

## Examples

<CodeGroup>

  ```javascript onCategoryCreated
  import { categories } from '@wix/forum';

  categories.onCategoryCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onCategoryCreated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { categories } from '@wix/forum';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        categories,
      },
  });

  wixClient.categories.onCategoryCreated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
