    <div className="wix-ref">

    Resolves SEO tags for a Wix product using its slug and item type.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/seo/v1/resolve-item-seo-tags
    ```

    ## Query Params

    <ParamField query="pageUrl" type="string">

      Full canonical URL of the item page where the SEO tags are applied.

      Constraints: `format WEB_URL`, `minLength 1`, `maxLength 2048`.

    </ParamField>

    <ParamField query="itemType" type="string">

      Item type identifier specifying the product and content type for SEO tag generation.
      This determines which product-specific optimization rules and schema are applied.

      **Supported values:**

      - `UNKNOWN_ITEM_TYPE` — Unknown item type. This value isn't used.
      - `STORES_PRODUCT` — Item type for e-commerce products.
      - `BOOKINGS_SERVICE` — Item type for service-based businesses.
      - `STORES_CATEGORY` — Item type for e-commerce categories.
      - `BLOG_POST` — Item type for blog posts.
      - `BLOG_CATEGORY` — Item type for blog categories.
      - `CHALLENGES_PAGE` — Item type for online programs / challenges pages.
      - `EVENTS_PAGE` — Item type for events pages.
      - `PORTFOLIO_COLLECTIONS` — Item type for portfolio collections.
      - `PORTFOLIO_PROJECTS` — Item type for portfolio projects.
      - `RESTAURANTS_MENU_PAGE` — Item type for restaurants menu pages.
      - `STORES_SUB_CATEGORY` — Item type for stores sub-categories.
      - `TABLE_RESERVATIONS_EXPERIENCE` — Item type for table reservations experiences.
      - `WIX_DATA_PAGE_ITEM` — Item type for Wix Data dynamic pages.
      Generates SEO tags from default patterns and Wix Data page-specific pattern overrides.
      - `PRICING_PLANS` — Item type for Pricing Plans pages.
      Generates SEO tags from default patterns and Pricing Plans pattern overrides.

    </ParamField>

    <ParamField query="slug" type="string">

      URL-friendly version of the item's name or title. Required for slug-backed item types. For example, if the site URL is `https://www.nike.com/shoes/air-jordans`, then the slug is `air-jordans`.

      Constraints: `minLength 1`, `maxLength 255`.

    </ParamField>

    <ParamField query="pagination" type="Pagination">

      Pagination information for the item page

      <Expandable title="pagination properties">

        <ParamField query="prevUrl" type="string">

          URL for the previous page

          Constraints: `format WEB_URL`, `minLength 1`, `maxLength 2048`.

        </ParamField>

        <ParamField query="nextUrl" type="string">

          URL for the next page

          Constraints: `format WEB_URL`, `minLength 1`, `maxLength 2048`.

        </ParamField>

        <ParamField query="totalPages" type="integer">

          Total number of pages

        </ParamField>

        <ParamField query="currentPage" type="integer">

          Current page number

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="pageId" type="string">

      Dynamic page identifier used by item types whose pattern overrides are page-specific, such as Wix Data.

      Constraints: `maxLength 255`.

    </ParamField>

    <ParamField query="pageName" type="string">

      Display name of the page, used by default patterns when item data is not fetched from a slug-backed API.

      Constraints: `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="seoTags" type="SeoTags">

      The resolved SEO tags entity containing product-specific optimized metadata.

      See the [Seo Tags Object](/api-reference/site/viewer/seo-tags/seo-tags-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
