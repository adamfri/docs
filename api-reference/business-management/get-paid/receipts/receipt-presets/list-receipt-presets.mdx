    Lists all available receipt presets.

    By default the returned receipt presets are sorted by `default` and `updatedDate` in descending order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/receipts/v1/receipt-presets
    ```

    ## Response Object

    <ResponseField name="receiptPresets" type="ReceiptPreset[]">

      List of receipt presets.

      See the [Receipt Preset Object](/api-reference/business-management/get-paid/receipts/receipt-presets/receipt-preset-object) for this object's fields.

    </ResponseField>
