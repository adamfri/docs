    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Callable by: `APP`.

    ```http
    PATCH https://www.wixapis.com/members/v1/default-privacy-status
    ```

    <ParamField body="defaultPrivacy" type="DefaultPrivacy" required>

    <ResponseField name="defaultPrivacy" type="DefaultPrivacy">
