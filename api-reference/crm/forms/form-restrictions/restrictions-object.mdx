---
title: "Restrictions Object"
description: "The form limits and premium features in force for a site."
icon: "cube"
---

The form limits and premium features in force for a site.

These values come from the site's premium plan and change when the plan changes. Creating or updating a form that
exceeds a limit, or that uses a feature absent from `features`, is rejected.

Not to be confused with form provider restrictions, which a form schema provider declares once for every site in a
namespace it owns, independently of any site's plan. A form must satisfy both.

<Tabs>

  <Tab title="REST">

    <ResponseField name="formsLimit" type="Limit">

      Maximum number of forms allowed on the site.

      Compare this limit with `totalFormCount`, which counts the same set of forms. Forms in the trash bin aren't
      counted.

      <Expandable title="formsLimit properties">

        <ResponseField name="limit" type="integer">

          Maximum number allowed.

          `null` when the plan places no limit.

        </ResponseField>

        <ResponseField name="warnThreshold" type="integer">

          Count at which to warn that the limit is close to being reached.

          An absolute count in the same unit as `limit`, never greater than it. Reaching this count doesn't block the
          action; it's the point at which to surface a nearing-limit warning. For some limits it equals `limit`, meaning
          there's no early warning.

          `null` when `limit` is `null`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="features" type="string[]">

      Premium features the site's plan allows.

      Any feature absent from this list is unavailable on the site, and a form that uses it is rejected.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `UNKNOWN_FEATURE` — Unknown feature.
      - `FILE_UPLOAD_FIELD` — Forms can include a file upload field, letting respondents attach files to their submission.
      - `ACCEPT_PAYMENTS` — Forms can collect payments through payment, fixed payment, and donation fields.
      - `REMOVE_WIX_BRANDING` — Wix branding can be hidden on the published form.
      - `SIGNATURE_FIELD` — Forms can include a signature field.
      - `FILE_DOWNLOAD` — Files that respondents attached to their submissions can be downloaded from the site's submissions.

    </ResponseField>

    <ResponseField name="ascendPlan" type="string">

      Ascend by Wix plan the site holds.

      `NOT_ASCEND` when the site isn't on an Ascend plan. The limits and features that follow from the plan are already
      reflected in the other fields, so most callers don't need to read this field.

      **Supported values:**

      - `NOT_ASCEND` — Site isn't on an Ascend by Wix plan.
      - `FREE` — Ascend by Wix Free plan.
      - `BASIC` — Ascend by Wix Basic plan.
      - `PROFESSIONAL` — Ascend by Wix Professional plan.
      - `UNLIMITED` — Ascend by Wix Unlimited plan.

    </ResponseField>

    <ResponseField name="rulesLimit" type="Limit">

      Maximum number of rules allowed per form.

      A single rule's `condition` can combine several tests, and the rule still counts once against this limit.

      <Expandable title="rulesLimit properties">

          `null` when `limit` is `null`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "premiumRestrictions": {
          "formsLimit": {
            "limit": 10,
            "warnThreshold": 8
          },
          "fieldsLimit": {
            "limit": 100,
            "warnThreshold": 85
          },
          "stepsLimit": {
            "limit": 20,
            "warnThreshold": 19
          },
          "emailsLimit": {
            "limit": 5,
            "warnThreshold": 5
          },
          "features": [
            "FILE_UPLOAD_FIELD",
            "ACCEPT_PAYMENTS",
            "REMOVE_WIX_BRANDING",
            "SIGNATURE_FIELD",
            "FILE_DOWNLOAD"
          ],
          "ascendPlan": "PROFESSIONAL",
          "rulesLimit": {
            "limit": 20,
            "warnThreshold": 19
          }
        }
      }
      ```

    </CodeGroup>
