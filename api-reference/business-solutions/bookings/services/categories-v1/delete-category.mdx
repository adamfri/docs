    Deletes a category.

    You can specify `{"deleteServices": true}` to also delete all associated
    services. Learn more about [deleting a service](https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/delete-service).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/bookings/v1/categories/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the category to delete.

    </ParamField>

    ## Query Params

    <ParamField query="deleteServices" type="boolean">

      Whether to delete all the services associated with the category.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="id" type="string">

      ID of the deleted category.

    </ResponseField>
