---
title: "Conversation Object"
description: "A conversation represents a chat thread between a user and the Wix AI coding agent for a project."
icon: "cube"
---

A conversation represents a chat thread between a user and the Wix AI coding agent for a project.
A project can have multiple conversations. Each conversation holds thread metadata such as
status and title; the messages are returned via Query Messages.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Conversation ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="projectId" type="string">

      ID of the project this conversation belongs to.

    </ResponseField>

    <ResponseField name="sessionId" type="string">

      Agent session ID. Set when a build job begins; used to resume the coding agent session.

    </ResponseField>

    <ResponseField name="status" type="string">

      Conversation status.

      **Supported values:**

      - `ACTIVE` — The conversation is open and active.
      - `ARCHIVED` — The conversation is archived. Currently not in use.

    </ResponseField>

    <ResponseField name="title" type="string">

      Conversation title. Currently defaults to `new chat`.

      Constraints: `maxLength 200`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the conversation was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the conversation was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the conversation is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the conversation.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "1f5b2c8e-9a3d-4c21-8b77-2d2f6e0a9c10",
        "projectId": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
        "title": "new chat",
        "status": "ACTIVE",
        "revision": "1",
        "createdDate": "2026-07-29T09:00:00.000Z",
        "updatedDate": "2026-07-29T09:00:00.000Z"
      }
      ```

    </CodeGroup>
