Triggered when an order created from this checkout is
successfully paid for or when a checkout is marked as completed.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.ecom.v1.checkout_completed` |
| Package | `@wix/ecom` |
| Permissions | `Manage Stores - all permissions`, `Read eCommerce - all read permissions`, `Read Orders`, `Read Stores - all read permissions`, `Manage Restaurants - all permissions`, `Manage eCommerce - all permissions`, `Manage Orders` |

## Examples

<CodeGroup>

  ```javascript onCheckoutCompleted
  import { checkout } from '@wix/ecom';

  checkout.onCheckoutCompleted((event) => {
      // handle your event here
  });
  ```

  ```javascript onCheckoutCompleted (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';

      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        checkout,
      },
  });

  wixClient.checkout.onCheckoutCompleted((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
