    Updates a locale by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/locales/v2/locale/{locale.id}
    ```

    ## Path Params

    <ParamField path="locale.id" type="string" required>

      Locale ID.

      The locale ID is made up of the language and region codes supported by Wix. For example, `"en-US"` for U.S. English.

    </ParamField>

    ## Body Params

    <ParamField body="locale" type="Locale" required>

      Locale to update, may be partial.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="locale" type="Locale">

      The updated locale.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Locale Updated | `wix.multilingual.locales.v2.locale_updated` | Triggered when a locale is updated. |

    </div>

    ```typescript
    locales.updateLocale(_id, locale): Promise<V2Locale>
    ```

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Locale ID.

      The locale ID is made up of the language and region codes supported by Wix. For example, `"en-US"` for U.S. English.

      **Read-only.**

    </ParamField>

    <ParamField body="locale" type="UpdateLocale" required>

      Locale to update, may be partial.

      <Expandable title="locale properties">

        <ParamField body="_id" type="string">

          Locale ID.

          The locale ID is made up of the language and region codes supported by Wix. For example, `"en-US"` for U.S. English.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the locale is updated. To prevent conflicting changes, the existing revision must be passed when updating the locale object.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the locale was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the locale was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="languageCode" type="string">

          Language code. For example, `"en"` for English.

        </ParamField>

        <ParamField body="regionCode" type="string">

          Region code. For example, `"UK"` for United Kingdom.

        </ParamField>

        <ParamField body="visibility" type="string">

          Locale visibility status.

          **Supported values:**

          - `HIDDEN` — Locale is hidden from site visitors. A site's locale should be hidden when a translation is not ready to be exposed to visitors.
          - `VISIBLE` — Locale is visible to site visitors. A site can only have up to 100 visible locales.

        </ParamField>

        <ParamField body="primaryLocale" type="boolean">

          Whether the locale is the site's primary locale.

          **Read-only.**

        </ParamField>

        <ParamField body="visitorPrimaryLocale" type="boolean">

          Whether the locale is the site's visitor primary locale.

          **Read-only.**

        </ParamField>

        <ParamField body="flag" type="string">

          Flag icon as a 3-letter language code based on Wix's supported locales. For example, `"USA"` for the United States flag icon.

        </ParamField>

        <ParamField body="regionalFormat" type="string">

          Regional format for determining how to display data types such as dates, times, numbers, and currencies. For example, `"en-US"` to format dates like this: `MM-DD-YYYY`.

        </ParamField>

        <ParamField body="effectiveUrlStructure" type="string">

          Default URL structure for the locale's live site URL,
          based on the locale's settings, unless overridden.

          **Read-only.**

          **Supported values:**

          - `SUBDIRECTORY` — URL structure as a subdirectory. For example, `"www.mysite.com/fr"`.
          - `SUBDOMAIN` — URL structure as a subdomain. For example, `"fr.mysite.com"`.
          - `QUERY_PARAM` — URL structure as a query parameter. For example, `"www.mysite.com?lang=fr"`.

        </ParamField>

        <ParamField body="urlStructureOverride" type="UrlStructureOverride">

          Optional override for the locale's default URL structure.

          <Expandable title="urlStructureOverride properties">

            <ParamField body="urlStructure" type="string">

              URL structure to use instead of the default.

              **Supported values:**

              - `SUBDIRECTORY` — URL structure as a subdirectory. For example, `"www.mysite.com/fr"`.
              - `SUBDOMAIN` — URL structure as a subdomain. For example, `"fr.mysite.com"`.
              - `QUERY_PARAM` — URL structure as a query parameter. For example, `"www.mysite.com?lang=fr"`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="machineTranslationCode" type="string">

          Language code based on Wix's supported locales, used to specify the target language when
          translatable content is sent for machine translation. For example, `"ES"` for Spanish
          or `"ZH_TW"` for Traditional Chinese.

          Default: The locale's `languageCode` value.

        </ParamField>

        <ParamField body="effectiveDisplayName" type="string">

          The locale's `displayName`, unless overridden.

          **Read-only.**

        </ParamField>

        <ParamField body="displayName" type="string">

          Default display name for the locale, inferred from the locale ID and region code.

          **Read-only.**

        </ParamField>

        <ParamField body="overrideDisplayName" type="string">

          Optional override for the locale's display name.

        </ParamField>

      </Expandable>

    </ParamField>
