Manage Contact Attachments

## SDK package

```bash
npm install @wix/crm
```

Import the `attachments` namespace from `@wix/crm`.

## Methods

<CardGroup cols={2}>

  <Card title="Generate Attachment Upload Url" href="/api-reference/crm/members-contacts/contacts/attachments/attachment-v4/generate-attachment-upload-url">
    POST Generates an upload URL for uploading a file as an attachment to a specified contact.
  </Card>
  <Card title="List Attachments" href="/api-reference/crm/members-contacts/contacts/attachments/attachment-v4/list-attachments">
    GET Retrieves a list of attachments associated with a specified contact.
  </Card>
  <Card title="Get Attachment" href="/api-reference/crm/members-contacts/contacts/attachments/attachment-v4/get-attachment">
    GET Retrieves the specified attachment for the specified contact.
  </Card>
  <Card title="Delete Attachment" href="/api-reference/crm/members-contacts/contacts/attachments/attachment-v4/delete-attachment">
    DELETE Deletes the specified attachment from the specified contact.
  </Card>

</CardGroup>
