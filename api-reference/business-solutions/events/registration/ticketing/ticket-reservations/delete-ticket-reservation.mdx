    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a ticket reservation permanently.

    Completely removes the reservation and releases all reserved tickets back into the inventory to available inventory. This action can't be undone.

    Call [Cancel Ticket Reservation](https://dev.wix.com/docs/api-reference/business-solutions/events/ticket-reservations/cancel-ticket-reservation) if you want to change the reservation status while keeping the record.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/events/v1/ticket-reservations/{ticketReservationId}
    ```

    ## Path Params

    <ParamField path="ticketReservationId" type="string" required>

      ID of the ticket reservation to delete.

    </ParamField>

    ## Response Object

    <ResponseField name="ticketReservation" type="TicketReservation">

      Deleted ticket reservation.

      See the [Ticket Reservation Object](/api-reference/business-solutions/events/registration/ticketing/ticket-reservations/ticket-reservation-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
