A Wix documentation entry returned as a search result.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      The unique identifier for this documentation entry.

      Constraints: `maxLength 500`.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      The date the document was last updated.

    </ResponseField>

    <ResponseField name="title" type="string">

      The title of the documentation entry.

      Constraints: `maxLength 1000`.

    </ResponseField>

    <ResponseField name="content" type="string">

      The full text content of the documentation entry.

      Constraints: `maxLength 100000`.

    </ResponseField>

    <ResponseField name="url" type="string">

      The direct URL to the documentation page for this entry.

      Constraints: `maxLength 2000`.

    </ResponseField>

    <ResponseField name="relevanceScore" type="float">

      The relevance score in the range [0, 1]. Higher means more relevant.

    </ResponseField>

    <ResponseField name="kbName" type="string">

      The knowledge base this entry was retrieved from (e.g. "REST_METHODS_KB_ID").

      Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="examples" type="DocumentExample[]">

      Authored request examples found in this result's indexed content. Set only
      on method results whose documentation embeds titled examples. The list may
      be a subset of the method's examples when the result is a content chunk.
      Retrieve a complete example by reading the full article at `url` and
      locating the example with the exact title.

      Constraints: `maxItems 100`.

      <Expandable title="examples properties">

        <ResponseField name="title" type="string">

          The exact example title as authored in the method documentation. In the
          full article the example appears as a heading with this title.

          Constraints: `maxLength 1000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
