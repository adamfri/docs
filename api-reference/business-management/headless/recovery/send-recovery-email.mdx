  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Sends an email to a member with a unique link to a Wix-managed password reset page.
    The member can use this page to reset their site password.
    If the site owner uses this page, it resets their Wix account password instead.

    <Note>

    You must publish the Wix site connected to your Headless project.
    Wix uses the published site to display the password reset page. To do this, open your project dashboard,
    select **Design Site** from the left panel, and then select **Publish**.

    </Note>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/iam/recovery/v1/send-email
    ```

    ## Body Params

    <ParamField body="email" type="string" required>

      Email address associated with the account to recover.

      Constraints: `format EMAIL`.

    </ParamField>

    <ParamField body="language" type="string">

      2-letter language code in [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) format of the email to be sent.

      If no language is specified, the language specified in the member's profile is used.

    </ParamField>

    <ParamField body="redirect" type="Redirect">

      Where to redirect to after successfully resetting the password.

      <Expandable title="redirect properties">

        <ParamField body="url" type="string">

          URL to redirect to after successfully resetting the password.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="clientId" type="string">

          Client ID of the [OAuth app](https://dev.wix.com/docs/go-headless/getting-started/setup/authentication/create-an-oauth-app-for-visitors-and-members) your Headless project is using.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `SendRecoveryEmailResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
