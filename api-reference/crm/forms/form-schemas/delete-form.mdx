<span className="wix-method wix-method-delete">DELETE</span>

<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a form schema.

    The schema is moved to the trash bin where it's stored for 90 days before permanent deletion.
    When permanently deleted, all associated form submissions are also deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/form-schema-service/v4/forms/{formId}
    ```

    ## Path Params

    <ParamField path="formId" type="string" required>

      ID of the form schema to delete.

    </ParamField>

    ## Query Params

    <ParamField query="permanent" type="boolean">

      Whether to permanently delete the form schema, bypassing the trash bin.

      Default: `false`

    </ParamField>

    ## Response Object

    Returns `DeleteFormResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Form Deleted | `wix.forms.v4.form_deleted` | Triggers when a form schema is deleted. |

    </div>

    <div className="wix-examples">

    ## Examples

    Deletes form. If permanent is set to false, form is stored in trash-bin for 90 days

    <CodeGroup>

      ```bash Request
      curl -X DELETE \
        'https://www.wixapis.com/form-schema-service/v4/forms/76d01133-44df-490e-810f-c10e30f330a1' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>'
        -d '{
          "permanent": false
        }'
      ```

      ```json Response
      {}
      ```

    </CodeGroup>

    </div>

    </div>
