    <div className="wix-ref">

    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Changes the password of a logged-in member. The member must have a valid session to use this method.

    The member's session remains valid after password change.

    The new password must meet the site's configured password requirements for length
    and complexity. These requirements are enforced automatically when processing the request.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="IAM.CHANGE_PASSWORD">IAM.CHANGE_PASSWORD</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/iam/authentication/v2/change-password
    ```

    ## Body Params

    <ParamField body="newPassword" type="string" required>

      New password to set for the logged-in member.

      The password must meet the site's configured password requirements for length and complexity.

    </ParamField>

    ## Response Object

    Returns `ChangePasswordResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
