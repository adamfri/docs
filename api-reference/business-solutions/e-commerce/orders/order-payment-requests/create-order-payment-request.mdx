    Creates an order payment request.

    The response includes the payment page URL, which you can share with the customer. To retrieve the URL later, call [Get Order Payment Request URL](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-payment-requests/get-order-payment-request-url).

    Creation fails with `ORDER_PAYMENT_REQUEST_PAGE_NOT_FOUND` if the site doesn't have a Payment Request Page added and published.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-payment-requests
    ```

    ## Body Params

    <ParamField body="orderPaymentRequest" type="OrderPaymentRequest">

      Order payment request to create.

      See the [Order Payment Request Object](/api-reference/business-solutions/e-commerce/orders/order-payment-requests/order-payment-request-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="orderPaymentRequest" type="OrderPaymentRequest">

      Created order payment request.

      See the [Order Payment Request Object](/api-reference/business-solutions/e-commerce/orders/order-payment-requests/order-payment-request-object) for this object's fields.

    </ResponseField>

    <ResponseField name="orderPaymentRequestUrl" type="string">

      Payment page URL for the order payment request. Share this URL with the customer so they can complete the payment.

      Constraints: `minLength 1`, `maxLength 100`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_PUBLISHED` | The site isn't published. |
    | `428` | `FAILED_PRECONDITION` | `PARTIAL_PAYMENT_NOT_SUPPORTED_FOR_SUBSCRIPTION` | Partial payment isn't supported for orders with subscriptions. The `amount` must equal the order total. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_ORDER_STATUS_FOR_SUBSCRIPTION` | The order must have a status of `INITIALIZED` to create a payment request for a subscription order. |
    | `428` | `FAILED_PRECONDITION` | `SUBSCRIPTION_ALREADY_STARTED` | The order's subscription has already started billing. Payment requests are supported only for subscriptions that haven't been charged yet. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_PAYMENT_REQUEST_PAGE_NOT_FOUND` | The Payment Request Page isn't published on the site. Add and publish a Payment Request Page in the Wix Editor. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | --- | --- | --- |
    | Order Payment Request Created | `wix.ecom.v1.order_payment_request_created` | Triggered when an order payment request is created. |
