    <div className="wix-api-columns">

    <div className="wix-ref">

    <Note>

    The Item API only works with the Wix Restaurants Menus app. Make sure you have installed this app from the [Wix App Market](https://www.wix.com/app-market/wix-restaurants-menus-new).

    </Note>

    Retrieves the number of items that match a specified filter.

    If a filter isn't passed in the request, the endpoint returns the count of all items.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/items/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter for counting items.

    </ParamField>

    <ParamField body="searchDetails" type="SearchDetails">

      Search details.

      <Expandable title="searchDetails properties">

        <ParamField body="mode" type="string">

          Search mode. Defines the search logic for combining multiple terms in the `expression`.

          **Supported values:**

          - `OR` — At least one of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Counted items.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_TO_COUNT` | Number of items exceeds the server's limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST https://www.wixapis.com/restaurants/menus-item/v1/items/count \
        -H 'Authorization: <AUTH>' \
        --data-binary '{
                      "filter": {
                        "price": {
                          "$gte": "5"
                          }
                        }
                      }'
      ```

      ```json Response
      {
        "count": 9
      }
      ```

    </CodeGroup>

    </div>
