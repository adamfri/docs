  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a tax group.

    If a tax group is deleted but the `taxGroupId` is still assigned to a product (see Stores Products API) then the default tax group is used to calculate tax.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.MANAGE-STORES">Manage Stores</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/billing/v1/tax-groups/{taxGroupId}
    ```

    ## Path Params

    <ParamField path="taxGroupId" type="string" required>

      ID of the tax group to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteTaxGroupResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Tax Group Deleted | `wix.billing.v1.tax_group_deleted` | Triggered when a tax group is deleted. |

    </div>
