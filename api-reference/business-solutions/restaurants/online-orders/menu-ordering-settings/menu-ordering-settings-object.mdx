---
title: "Menu Ordering Settings Object"
description: "Create and manage menu ordering settings."
icon: "cube"
---

Create and manage menu ordering settings.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Menu ordering settings object ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number. Increments by 1 each time the menu ordering settings object is updated. To prevent conflicting changes, the existing revision must be specified when updating a menu ordering settings object.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the menu ordering settings object was created in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the menu ordering settings object was last updated in [ISO-8601](https://en.wikipedia.org/wiki/ISO_8601#combined_date_and_time_representations) format.

      **Read-only.**

    </ResponseField>

    <ResponseField name="operationId" type="string">

      ID of the restaurant operation the menu belongs to. (See the Restaurants Operations API for more information.)

    </ResponseField>

    <ResponseField name="menuId" type="string">

      ID of the menu these settings apply to.

      **Read-only.**

    </ResponseField>

    <ResponseField name="onlineOrderingEnabled" type="boolean">

      Whether online ordering is enabled for the menu.

    </ResponseField>

    <ResponseField name="availability" type="Availability">

      Menu availability settings.

      <Expandable title="availability properties">

        <ResponseField name="type" type="string">

          Availability type.

          **Supported values:**

          - `UNSPECIFIED_AVAILABILITY_OPTION` — Missing type due to an error.
          - `ALWAYS_AVAILABLE` — Available all the time.
          - `WEEKLY_SCHEDULE` — Available on specific days and times throughout the week.
          - `TIMESTAMP_RANGES` — Available during a specific time range.

        </ResponseField>

        <ResponseField name="timeZone" type="string">

          Time zone in [Time Zone Database](https://www.iana.org/time-zones) format.

          **Read-only.**

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="availabilityTypeOptions" type="availabilityTypeOptions">

          availabilityTypeOptions

          <Expandable title="availabilityTypeOptions properties">

            <ResponseField name="weeklyScheduleOptions" type="WeeklyScheduleOptions">

              Settings for availability on a weekly schedule.

              <Expandable title="weeklyScheduleOptions properties">

                <ResponseField name="availableTimes" type="DayOfWeekAvailability[]">

                  List of available time ranges for specific days of the week.

                  Constraints: `maxItems 7`.

                  _Nested structure omitted for brevity — see the `DayOfWeekAvailability[]` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="timestampRangesOptions" type="TimestampRangesOptions">

              Settings for availability within a time range.

              <Expandable title="timestampRangesOptions properties">

                <ResponseField name="ranges" type="AvailableRange[]">

                  List of available time ranges.

                  Constraints: `maxItems 50`.

                  _Nested structure omitted for brevity — see the `AvailableRange[]` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="businessLocationId" type="string">

      Business location ID ([SDK](https://dev.wix.com/docs/sdk/backend-modules/restaurants/wix-restaurants-new/about-business-locations) | [REST](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/about-business-locations)) of the menu.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags ([SDK](https://dev.wix.com/docs/sdk/backend-modules/tags/tags/introduction) | [REST](https://dev.wix.com/docs/rest/business-management/tags/introduction)) used to classify and sort different types of menu ordering settings.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "menuOrderingSettings": {
          "id": "f83c385c-1485-4daa-9bba-bc332e12c8ce",
          "revision": "3",
          "createdDate": "2024-07-08T13:44:00.443Z",
          "updatedDate": "2024-07-08T13:50:08.572Z",
          "operationId": "48605ac5-53fc-49b4-96b2-87f7636f5ce0",
          "menuId": "bbb65621-6338-4837-8fdd-aebc654523e0",
          "onlineOrderingEnabled": true,
          "availability": {
            "type": "ALWAYS_AVAILABLE",
            "timeZone": "Asia/Jerusalem"
          }
        }
      }
      ```

    </CodeGroup>
