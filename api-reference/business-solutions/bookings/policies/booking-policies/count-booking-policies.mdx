    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/booking-policies/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter to base the count on.
      See [Query Booking Policies](https://dev.wix.com/docs/api-reference/business-solutions/bookings/policies/booking-policies/query-booking-policies) for a list of supported filters.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of booking policies matching the provided filter.

    </ResponseField>
