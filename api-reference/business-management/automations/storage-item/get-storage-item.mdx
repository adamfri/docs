    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/storage-service/v1/storage-items/{key}
    ```

    ## Path Params

    <ParamField path="key" type="string" required>

      Key of the storage item to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="consistentRead" type="boolean">

      Whether to retrieve the item from the primary instance. This decreases performance but ensures the item retrieved is up to date even immediately after an update.

      Default: `false`.

    </ParamField>

    ## Response Object

    <ResponseField name="storageItem" type="StorageItem">

      Retrieved storage item.

      See the [Storage Item Object](/api-reference/business-management/automations/storage-item/storage-item-object) for this object's fields.

    </ResponseField>
