    Connects a Wix Payments account to the site.

    The call fails if:
    - A Wix Payments account is already connected to the site.
    - You don't specify `{"tosAccepted": true}`.
    - You specify an `account.country` that isn't currently supported. Supported
    countries: `US`, `CA`, `GB`, `ES`, `AT`, `BE`, `FI`, `DE`, `IT`, `NL`, `PT`,
    `CH`, `LT`. If you don't specify a country, it defaults to `US`.

    The connected Wix Payments account has the following limitations, which site
    owners can manage in their dashboard:

    - By default, customers can only pay via credit card, Apple Pay, or Google Pay.
    - To receive payments, site owners must complete onboarding to their Wix
    Payments account in the site's dashboard.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:
