    Schedules the given draft posts for publishing via the Publisher.

    Only items whose `status` is `DRAFT` are scheduled; non-draft IDs are silently ignored.
    Only drafts for channels the site has connected through the Publisher are scheduled; drafts
    for unconnected channels are silently skipped and remain drafts. Requires the site's plan to
    include the schedule-posts premium feature; otherwise the call returns a `FAILED_PRECONDITION`
    error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan/schedule-drafts
    ```

    ## Body Params

    <ParamField body="draftIds" type="string[]" required>

      IDs of the draft posts to schedule for publishing.

      **Read-only.** Constraints: `format GUID`, `minItems 1`, `maxItems 20`.

    </ParamField>
