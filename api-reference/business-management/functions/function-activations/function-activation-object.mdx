A function activation is an object that represents the activation of a function.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Function activation ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="functionId" type="string">

      ID of the function activated by this function activation.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="extensionId" type="string">

      ID of the service plugin extension created upon function activation. This happens automatically and the field is primarily used in the background.

      **Read-only.**

    </ResponseField>

    <ResponseField name="appId" type="string">

      App ID of the business solution that created the function type that the activated function is based on.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the function activation was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the function activation was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="functionExtensionId" type="string">

      ID of the function type that the activated function is based on.

      **Read-only.**

    </ResponseField>

    <ResponseField name="migrationState" type="string">

      State of the function activation during Function-to-Velo migration.

      **Read-only.**

      **Supported values:**

      - `ACTIVE_FUNCTION` — The function is live and serving traffic (the default for any activation not under migration).
      - `MIGRATED_TO_VELO` — The function has been migrated to Velo: its extension is removed and its Velo twin serves traffic.

    </ResponseField>

    <CodeGroup>

      ```json Object
      {
        "id": "4ac8f7f5-6053-4f92-9d19-4fd9ec22f2ba",
        "functionId": "0481a48d-0dff-40a9-abd1-6267a3355e70",
        "extensionId": "c21a023f-4acb-42fa-bef5-9160155abbf6",
        "appId": "7cb1447d-42f3-4313-97ee-44016823915b",
        "createdDate": "2024-12-03T09:01:10.562Z",
        "updatedDate": "2024-12-03T09:01:10.562Z"
      }
      ```

    </CodeGroup>
