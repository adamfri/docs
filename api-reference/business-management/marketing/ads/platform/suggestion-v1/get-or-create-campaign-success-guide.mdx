    Retrieves a campaign success guide or creates one by analyzing the campaign's
    landing page, campaign configuration, and relevant site connections.

    The first call can take up to 120 seconds. Later calls return the saved guide
    unless changes to the campaign require a new analysis.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/pa-platform/suggestions/v1/campaign-success-guides/get-or-create
    ```

    ## Body Params

    <ParamField body="campaignId" type="string" required>

      Campaign ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="platformType" type="string">

      Ad platform to generate suggestions for. Currently supports only `GOOGLE`.

      **Supported values:**

      - `GOOGLE`
      - `FACEBOOK`

    </ParamField>

    ## Response Object

    <ResponseField name="campaignSuccessGuide" type="CampaignSuccessGuide">

      Generated or retrieved campaign success guide.

      <Expandable title="campaignSuccessGuide properties">

        <ResponseField name="id" type="string">

          Campaign success guide ID. Same as the campaign ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="url" type="string">

          Campaign landing page URL.

          **Read-only.**

        </ResponseField>

        <ResponseField name="suggestions" type="CampaignSuccessGuideSuggestion[]">

          Optimization suggestions in priority order. Includes only suggestions that need attention.

          **Read-only.**

          <Expandable title="suggestions properties">

            <ResponseField name="id" type="string">

              Suggestion ID.

              **Read-only.**

            </ResponseField>

            <ResponseField name="type" type="string">

              Type of optimization suggestion.

              **Read-only.**

              **Supported values:**

              - `CLEAR_CTA_COPY` — Recommendation to clarify the primary call-to-action button's conversion intent.
              - `ABOVE_THE_FOLD_CTA` — Recommendation to place a call-to-action button where it's visible without scrolling.
              - `HEADER_MATCH` — Recommendation to align the landing page heading with the campaign's ad headlines.
              - `CONVERSION_POINT` — Recommendation to add a visible lead form or booking action to the landing page.
              - `GOOGLE_REVIEWS` — Recommendation to display Google reviews or ratings on the landing page.
              - `TESTIMONIAL` — Recommendation to display customer testimonials attributed to named individuals.
              - `CONTACT_AND_CREDIBILITY` — Recommendation to display a phone number and email address on the landing page.
              - `FAQ_SECTION` — Recommendation to add a visible FAQ section to the landing page.
              - `MINIMIZE_FORM_FIELDS` — Recommendation to limit the landing page's lead form to 4 visible input fields.
              - `SOCIAL_CHANNELS` — Recommendation to add a visible social media profile link to the landing page.
              - `GOOGLE_MERCHANT_CENTER_CONNECTION` — Recommendation to connect a Google Merchant Center account to the Wix Stores site.
              - `GOOGLE_BUSINESS_PROFILE_CONNECTION` — Recommendation to connect a Google Business Profile to the site.
              - `GOOGLE_ADS_SEARCH_THEMES` — Recommendation to configure Google Ads search themes for the campaign.
              - `MOBILE_OPTIMIZATION` — Mobile optimization improvements are recommended for the site.
              - `SITE_SPEED` — Site speed improvements are recommended.

            </ResponseField>

            <ResponseField name="status" type="string">

              Current suggestion status. New suggestions have an `OPEN` status.

              **Read-only.**

              **Supported values:**

              - `OPEN` — Suggestion is pending action by the user.
              - `COMPLETED` — User has marked this suggestion as completed.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `PLATFORM_NOT_SUPPORTED` | The specified platform type isn't supported. Set `platformType` to `GOOGLE`. |
    | `428` | `FAILED_PRECONDITION` | `CAMPAIGN_TYPE_NOT_SUPPORTED` | The specified campaign isn't a Google Ads Performance Max Leads campaign. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
