    <div className="wix-ref">

    Retrieves a member's "About" section content.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v2/abouts/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the "About" section content to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="memberAbout" type="MemberAbout">

      The retrieved "About" section content.

      See the [Member About Object](/api-reference/crm/members-contacts/members/member-management/members-about-v2/member-about-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
