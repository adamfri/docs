<Tabs>

  <Tab title="REST">

    Updates only the hidden state of the Llms.txt file.
    Content remains unchanged - only visibility is modified.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/promote-seo-robots-server/v2/llms/hidden
    ```

    ## Body Params

    <ParamField body="hidden" type="boolean">

      Hidden state to set for the Llms.txt file.
      If true, the llms.txt file will be hidden from public access (returns 404).
      If false, the llms.txt file will be publicly accessible.

    </ParamField>

    <ParamField body="subdomain" type="string">

      Subdomain of Llms.txt, for example `www`, `es`, `fr`. Default is `www`.

      Constraints: `maxLength 63`.

    </ParamField>

    ## Response Object

    <ResponseField name="llmsTxt" type="LlmsTxt">

      Updated Llms txt object with new hidden state

      See the [Llms Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/llms-txt/llms-txt-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | — | Site ID is missing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
