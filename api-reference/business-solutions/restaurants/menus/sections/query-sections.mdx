    Retrieves a list of sections given the provided paging, filtering, and sorting. Up to 500 sections can be returned per request.

    To learn how to query sections, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `image` | `$exists` | None |
    | `id` | `$in`, `$nin`, `$eq`, `$ne` | None |
    | `name` | `$in`, `$nin`, `$startsWith`, `$eq`, `$ne` | None |
    | `description` | `$in`, `$nin`, `$startsWith`, `$eq`, `$ne` | None |
    | `itemIds` | `$exists`, `$hasSome` | None |
    | `createdDate` | `$gt`, `$gte`, `$lt`, `$lte`, `$eq`, `$ne` | None |
    | `updatedDate` | `$gt`, `$gte`, `$lt`, `$lte`, `$eq`, `$ne` | None |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/sections/query
    ```

    ## Body Params

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Sort order.
