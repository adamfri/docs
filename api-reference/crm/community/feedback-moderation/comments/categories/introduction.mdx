The Categories API allows you to define settings for a specified group of comments. For example, you can specify which site visitors can comment, react, and reply to a site's blog posts or whether to require submitting a rating when leaving comments on product pages.

With the Categories API, you can:

+ [Create](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/create-category) and [update](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/update-category) categories.
+ [Retrieve](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/get-category) or [query](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/query-category) categories.
+ Handle events that trigger when a category is [created](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/category-created) or [updated](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/category-updated).

## Use cases
+ [Turn off guest commenting for a category to avoid spam.](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/sample-flows)
+ [Retrieve all recent comments from a specific category.](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/sample-flow#retrieve-all-recent-comments-from-a-specific-category)
+ [Restrict permissions for replies to comments on product pages.](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/sample-flows)
+ [Handle comments when deleting a category](fallback::https://dev.wix.com/api-reference/crm/community/comments/sample-flow#handle-comments-before-deleting-a-category).
