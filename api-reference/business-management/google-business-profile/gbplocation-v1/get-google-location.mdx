    Retrieves a GBP location with its current Google data.

    The single-location counterpart of Query Google Locations, with the same
    behavior: if the profile data can't be retrieved from Google, the location is
    still returned and the reason is in `googleError`.

    If the location isn't found, the call fails and Google isn't contacted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/locations/google/{locationId}
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      ID of the location to retrieve. This is Google's location identifier.

    </ParamField>

    ## Response Object

    <ResponseField name="location" type="LocationWithGoogle">

      The location, with its Google profile data or the reason that couldn't be
      retrieved.

          The location as it's stored for the site, including its `id` and
          `accountId`.

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="googleResult" type="googleResult">

          googleResult

          <Expandable title="googleResult properties">

            <ResponseField name="googleLocation" type="GoogleLocation">

              The location's current profile data from Google.

              _Nested structure omitted for brevity — see the `GoogleLocation` object._

            </ResponseField>

            <ResponseField name="googleError" type="ApplicationError">

              Why the profile data couldn't be retrieved for this location. See the
              description of this object for the error codes.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="voiceOfMerchantResult" type="voiceOfMerchantResult">

          voiceOfMerchantResult

          <Expandable title="voiceOfMerchantResult properties">

            <ResponseField name="voiceOfMerchant" type="VoiceOfMerchantState">

              Whether Google considers this location's profile trusted and live.

              _Nested structure omitted for brevity — see the `VoiceOfMerchantState` object._

            </ResponseField>

            <ResponseField name="voiceOfMerchantError" type="ApplicationError">

              Why the Voice of Merchant state couldn't be retrieved for this location.
              Same error codes as `googleError`.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
