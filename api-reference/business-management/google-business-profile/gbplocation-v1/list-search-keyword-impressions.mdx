    Retrieves a list of up to 100 search terms people used to find a location,
    by calendar month.

    Each term carries either `value`, the exact number of impressions, or
    `threshold`, meaning the real count is below that number and Google won't
    report it precisely. Check which one is set rather than assuming a count.

    Search terms are what real people typed, so treat `searchKeyword` as
    possibly containing personal information.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
