            <ResponseField name="seatPacing" type="SeatPacing">

              Seat pacing settings.

              The maximum number of seats that can be filled by new reservations within a 15-minute period.
              For example, setting a seat pacing of 15 would mean that between `10:00.000`-`10:14.999` there will be no more than 15 new seats available for reservation.

              <Expandable title="seatPacing properties">

                <ResponseField name="number" type="integer">

                  Maximum number of seats allowed per `timeSlotInterval`.

                  Constraints: `min 0`, `max 10000`.

                </ResponseField>

                <ResponseField name="enabled" type="boolean">

                  Whether this option is enabled.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="partyPacing" type="PartyPacing">

              Party pacing settings.

              The maximum number of party reservations that can start within a `timeSlotInterval` period.
              For example, if `timeSlotInterval` is 15 minutes, then a party pacing of 5 would mean that no more than 5 parties could make a reservation for the period between `10:00.000`-`10:14.999`.

              <Expandable title="partyPacing properties">

                <ResponseField name="number" type="integer">

                  Maximum number of new party reservations allowed per `timeSlotInterval`.

                  Constraints: `min 0`, `max 10000`.

                </ResponseField>

                <ResponseField name="enabled" type="boolean">

                  Whether this option is enabled.

                </ResponseField>

              </Expandable>

            <ResponseField name="mode" type="string">

              Table management mode. The mode determines how tables are assigned for reservations at this location.

              **Supported values:**

              - `ON` — Tables can be assigned manually for reservations at this location. When tables aren't manually assigned, Wix assigns them automatically.
              - `IN_HOUSE_ONLY` — Tables can be assigned manually for reservations at this location. Wix doesn't assign tables automatically.
              - `OFF` — Tables can't be assigned manually for reservations at this location. Wix doesn't assign tables automatically. If you try to assign a table manually, the request will fail.
