    Retrieves a list of up to 100 invoices, given the provided filtering, search expression, sorting, and cursor paging.

    Unlike [Query Invoices], Search Invoices supports free-text search across fields like `title`, `numbering.displayNumber`, and customer contact details. It also returns aggregation data.
