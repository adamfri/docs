    Updates an experience.

    Each time the experience is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the experience.
    This ensures you're working with the latest experience information and prevents unintended overwrites.

    To update multiple experiences in a single request, call [Bulk Update Experiences](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/reservations/experiences/bulk-update-experiences).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-LOCATIONS">Manage Reservation Locations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/table-reservations/experiences/v1/experiences/{experience.id}
    ```

    ## Path Params

    <ParamField path="experience.id" type="string" required>

      Experience ID.

    </ParamField>

    <ParamField body="experience" type="Experience" required>

      See the [Experience Object](/api-reference/business-solutions/restaurants/reservations/experiences/experience-object) for this object's fields.

    </ParamField>

    <ResponseField name="experience" type="Experience">
