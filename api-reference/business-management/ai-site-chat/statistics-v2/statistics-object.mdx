---
title: "Statistics Object"
description: "Aggregated AI Site-Chat statistics for a site."
icon: "cube"
---

Aggregated AI Site-Chat statistics for a site.

Statistics include daily KPI rows for recent activity and period KPI rows for comparison windows, such as the last 30 days and the previous 30 days.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Site ID the statistics are scoped to.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="dailies" type="Daily[]" deprecated>

      Typed daily statistics.

      Deprecated. Use `dailyKpis` instead.

      **Deprecated.** Typed daily statistics.

      Deprecated. Use `dailyKpis` instead. Use `daily_kpis` instead. Removal: 2026-02-03. Constraints: `maxItems 30`.

      <Expandable title="dailies properties">

        <ResponseField name="date" type="datetime">

          Date the daily statistics are for.

        </ResponseField>

        <ResponseField name="conversations" type="integer">

          Number of conversations on this date.

        </ResponseField>

        <ResponseField name="messages" type="integer">

          Number of messages on this date.

          Deprecated.

        </ResponseField>

        <ResponseField name="visitors" type="integer">

          Number of unique visitors on this date.

        </ResponseField>

        <ResponseField name="exposedItems" type="integer">

          Number of product items shown or recommended in AI Site-Chat on this date.

        </ResponseField>

        <ResponseField name="orders" type="integer">

          Number of orders associated with AI Site-Chat activity on this date.

        </ResponseField>

        <ResponseField name="chatHandler" type="string">

          Chat handler the daily statistics are grouped by.

          **Supported values:**

          - `UNKNOWN_HANDLER` — Unknown handler.
          - `AI` — AI assistant.
          - `WIX_USER` — Wix user, such as a site owner or contributor.

        </ResponseField>

        <ResponseField name="repliedConversationsCount" type="integer">

          Number of conversations that received a response on this date.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="timespans" type="Timespan[]" deprecated>

      Typed period statistics.

      Deprecated. Use `periodKpis` instead.

      **Deprecated.** Typed period statistics.

      Deprecated. Use `periodKpis` instead. Use `period_kpis` instead. Removal: 2026-02-03. Constraints: `maxItems 10`.

      <Expandable title="timespans properties">

        <ResponseField name="period" type="string">

          Comparison period the statistics are aggregated for.

          **Supported values:**

          - `UNKNOWN_PERIOD` — Unknown period.
          - `LAST_30_DAYS` — Rolling 30-day period from the current date.
          - `PREVIOUS_30_DAYS` — The 30-day period before `LAST_30_DAYS`.

        </ResponseField>

        <ResponseField name="conversations" type="integer">

          Number of conversations in this period.

        </ResponseField>

        <ResponseField name="messages" type="integer">

          Number of messages in this period.

          Deprecated.

        </ResponseField>

        <ResponseField name="visitors" type="integer">

          Number of unique visitors in this period.

        </ResponseField>

        <ResponseField name="exposedItems" type="integer">

          Number of product items shown or recommended in AI Site-Chat in this period.

        </ResponseField>

        <ResponseField name="orders" type="integer">

          Number of orders associated with AI Site-Chat activity in this period.

        </ResponseField>

        <ResponseField name="chatHandler" type="string">

          Chat handler the period statistics are grouped by.

          **Supported values:**

          - `UNKNOWN_HANDLER` — Unknown handler.
          - `AI` — AI assistant.
          - `WIX_USER` — Wix user, such as a site owner or contributor.

        </ResponseField>

        <ResponseField name="repliedConversationsCount" type="integer">

          Number of conversations that received a response in this period.

        </ResponseField>

        <ResponseField name="medianResponseTimeSecondsP50" type="integer">

          Median response time in seconds.

        </ResponseField>

        <ResponseField name="medianFirstResponseTimeSecondsP50" type="integer">

          Median first response time in seconds.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="dailyKpis" type="object[]">

      Daily KPI rows for the last 30 days.

      Each row contains the fields requested in `dailyFields`, or all default daily KPI fields if `dailyFields` isn't provided.

      Constraints: `maxItems 30`.

    </ResponseField>

    <ResponseField name="periodKpis" type="object[]">

      Period KPI rows for comparison windows.

      Each row contains the fields requested in `byPeriodFields`, or all default period KPI fields if `byPeriodFields` isn't provided.

      Constraints: `maxItems 10`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "statistics": {
          "id": "118f445d-6b84-4268-821d-7d2b9f40ac60",
          "dailyKpis": [
            {
              "kpi_date": "2026-07-09",
              "mode": "ai",
              "conversations_count": 3,
              "visitors_distinct_count": 3,
              "exposed_items_count": 5,
              "total_orders_count": 0,
              "replied_conversations_count": 3,
              "response_time_seconds_p50": 0,
              "first_response_time_seconds_p50": 0
            }
          ],
          "periodKpis": [
            {
              "period": "last_30_days",
              "mode": "ai",
              "conversations_count": 3,
              "visitors_distinct_count": 3,
              "exposed_items_count": 5,
              "total_orders_count": 0,
              "replied_conversations_count": 3,
              "response_time_seconds_p50": 0,
              "first_response_time_seconds_p50": 0
            }
          ]
        }
      }
      ```

    </CodeGroup>
