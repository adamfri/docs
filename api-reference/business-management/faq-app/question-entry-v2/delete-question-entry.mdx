  <Tab title="REST">

    <div className="wix-ref">

    Deletes a question entry.

    Deleting a question entry permanently removes it from the site's Wix FAQ dashboard page.

    To delete multiple question entries, call the Bulk Delete Question Entries method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/faq/v2/question-entries/{questionEntryId}
    ```

    ## Path Params

    <ParamField path="questionEntryId" type="string" required>

      ID of the question entry to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteQuestionEntryResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Question Entry Deleted | `wix.faq.question_entry.v2.question_entry_deleted` | Triggered when a question entry is deleted. |

    </div>
