    Retrieves a list of fields that are applied to specified members.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/custom-fields-applications/members
    ```

    ## Body Params

    <ParamField body="memberIds" type="string[]" required>

      IDs of members with custom field applications to retrieve.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="MemberCustomFieldApplication[]">

      Retrieved list of custom field applications.

      <Expandable title="results properties">

        <ResponseField name="memberId" type="string">

          Member ID.

        </ResponseField>

        <ResponseField name="applications" type="FieldApplication[]">

          Custom field applications for the member.

          <Expandable title="applications properties">

            <ResponseField name="customFieldKey" type="string">

              Custom field key.

              **Read-only.**

            </ResponseField>

            <ResponseField name="applies" type="boolean">

              Whether the custom field applies to the member.

            </ResponseField>

            <ResponseField name="customField" type="CustomField">

              Custom field details.

              _Nested structure omitted for brevity — see the `CustomField` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
