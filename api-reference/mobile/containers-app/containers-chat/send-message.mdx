    Sends a user message in a conversation.

    An assistant turn with `WORKING` status is immediately opened and can be tracked via
    [Query Messages](https://dev.wix.com/docs/api-reference/mobile/containers-app/containers-chat/conversation-v1/query-messages). When the assistant completes its response, the turn is
    finalized. An `idempotencyKey` is required to prevent duplicate submissions on retry.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="containers:chat:v1:conversation:send_message">containers:chat:v1:conversation:send_message</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/containers/chat/v1/conversations/{conversationId}/messages
    ```

    ## Path Params

    <ParamField path="conversationId" type="string" required>

      Conversation ID.

    </ParamField>

    ## Body Params

    <ParamField body="parts" type="MessagePart[]">

      Content of the user message.

      Constraints: `maxItems 200`.

      <Expandable title="parts properties">

        <ParamField body="type" type="string">

          Kind of content carried by this part.

          - `TEXT`

          - `TOOL_CALL`

        </ParamField>

        <ParamField body="text" type="string">

          Inline textual content (used by TEXT / CODE / TOOL_CALL parts).

        </ParamField>

        <ParamField body="uri" type="string">

          Reference to external content (used by IMAGE / FILE parts).

          Constraints: `maxLength 2000`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="idempotencyKey" type="string">

      Unique key to prevent duplicate submissions on retry. Downstream services use this key
      to ensure that retrying a failed request doesn't create duplicate jobs. Required.

      Constraints: `maxLength 200`.

    </ParamField>

    <ParamField body="type" type="string">

      Kind of message being sent. Defaults to TEXT when unset.

      **Supported values:**

      - `TEXT` — Plain conversational content, carried in `parts`. No payload.
      - `QUESTIONNAIRE` — Assistant is presenting clarifying questions; see QuestionnairePayload.
      - `QUESTIONNAIRE_RESPONSE` — User is answering a QUESTIONNAIRE message; see QuestionnaireResponsePayload.
      - `CHECKPOINT` — A new project version was saved; see CheckpointPayload. No payload on TEXT.

    </ParamField>
