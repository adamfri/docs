    Retrieves a content plan flow.

    While a flow is generating, poll this method with the
    `contentPlanFlowId` returned by Trigger Content Plan Generation Flow to
    follow the flow's progress.

    Omit `contentPlanFlowId` to retrieve the site's most recent successful
    flow. This is useful for picking up a content plan that was generated in
    the site dashboard. A flow that's still running is never returned this
    way, and a site with no successful flow returns a not found error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/seo/v1/content-plan-flows/{contentPlanFlowId}
    ```

    ## Path Params

    <ParamField path="contentPlanFlowId" type="string" required>

      ID of the content plan flow to retrieve.

      Omit to retrieve the site's most recent successful flow.

    </ParamField>

    ## Response Object

    <ResponseField name="contentPlanFlow" type="ContentPlanFlow">

      Retrieved content plan flow.

      See the [Content Plan Content Plan Flow Object](/api-reference/business-management/seo/content-plan-content-plan-flow-v1/content-plan-content-plan-flow-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
