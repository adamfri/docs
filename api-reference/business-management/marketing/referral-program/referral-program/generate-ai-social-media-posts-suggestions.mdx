    Creates new AI-generated social media post suggestions for promoting the referral program.

    This method generates new AI-powered social media post suggestions for promoting the referral program. Use it to refresh content or create alternatives to existing suggestions.

    <Note>

    This method generates new suggestions each time it's called. To retrieve existing suggestions without generating new ones, use Get AI Social Media Posts Suggestions.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/referral-programs/v1/program/ai-social-media-posts-suggestions
    ```

    ## Body Params

    <ParamField body="topic" type="string">

      Topic to generate social media post suggestions for. For example, fitness, education, or technology.

      Constraints: `maxLength 512`.

    </ParamField>

    ## Response Object

    <ResponseField name="suggestions" type="AISocialMediaPostSuggestion[]">

      Generated social media post suggestions.

      Constraints: `maxItems 3`.

      <Expandable title="suggestions properties">

        <ResponseField name="postContent" type="string">

          Suggested post content.

          Constraints: `maxLength 4096`.

        </ResponseField>

        <ResponseField name="hashtags" type="string[]">

          Suggested hashtags.

          Constraints: `maxLength 256`, `maxItems 256`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="referFriendsPageUrl" type="string">

      Referral URL to refer friends.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
