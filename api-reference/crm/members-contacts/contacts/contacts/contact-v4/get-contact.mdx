    Retrieves a contact.

    #### Getting Merged Contacts

    When a source contact is merged
    with a target contact, the source contact is deleted.
    When calling Get Contact for a merged contact,
    you can use the source or target contact ID.
    In both bases, the target contact is returned.

    This is supported only when calling Get Contact on merged contacts.
    Previously deleted source contact IDs can't be used for any other method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.READ-CONTACTS">Read Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/contacts/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the contact to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      List of projected fields to return.
      If both `fields` and `fieldsets` are sent in the request,
      the union of both lists is returned.
      `id` and `revision` are always returned.

      Supported properties:
      `source`, `createdDate`, `updatedDate`, `lastActivity`, `primaryInfo`,
      `info.name`, `info.emails`, `info.phones`, `info.addresses`, `info.company`,
      `info.jobTitle`, `info.picture`, `info.birthdate`, `info.locale`,
      `info.labelKeys`, `info.locations`, `info.extendedFields`

      Constraints: `maxLength 100`, `maxItems 100`.

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      Predefined sets of fields to return.
      If both `fields` and `fieldsets` are sent in the request,
      the union of both lists is returned.

      - `BASIC`: Returns `id`, `revision`, `primaryInfo`, `info.name`.
      - `COMMUNICATION_DETAILS`: Returns `id`, `revision`, `primaryInfo`, `info.name`, `info.emails`, `info.phones`, `info.addresses`.
      - `EXTENDED`: Returns `id`, `revision`, `primaryInfo`, `info.name`, `info.extendedFields`.
      - `FULL`: Returns all fields.

      Default: If `fields` is omitted from the request, `FULL`.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `BASIC` — name, primaryEmail, primaryPhone
      - `COMMUNICATION_DETAILS` — name, phones, emails, addresses
      - `EXTENDED` — name, primaryInfo(email, phone), extendedFields
      - `FULL` — Full contact object

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      The requested contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts/contact-v4/contact-object) for this object's fields.

    </ResponseField>

    <ResponseField name="responseType" type="string">

      Contact response type.

      **Supported values:**

      - `REGULAR` — The specified contact was returned.
      - `IMPLICIT` — Not used.
      - `MERGED` — The specified contact was previously merged with another contact and the new contact was returned.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CONTACT_NOT_FOUND` | Contact not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
