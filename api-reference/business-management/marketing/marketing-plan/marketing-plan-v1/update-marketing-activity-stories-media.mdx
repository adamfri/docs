    Updates the media on a marketing activity's story drafts with the provided media URL,
    leaving its post drafts unchanged.

    A story draft holds one media item per frame, up to 5 frames. Specify `mediaIndex` to replace a
    single frame, or omit it to replace the whole story with the one new media item. A story that has
    no frame at that index is left unchanged.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan/update-marketing-activity-stories-media
    ```

    ## Body Params

    <ParamField body="marketingActivityId" type="string" required>

      ID of the marketing activity whose story drafts will have their media replaced.

      **Read-only.**

    </ParamField>

    <ParamField body="mediaUrl" type="string" required>

      URL of the media to apply to the activity's stories.

    </ParamField>

    <ParamField body="mediaType" type="string" required>

      Type of the media at `mediaUrl`.

      **Supported values:**

      - `IMAGE`
      - `VIDEO`

    </ParamField>

    <ParamField body="fileId" type="string">

      Media Manager file ID backing the media, when the media originates from the Media Manager.

    </ParamField>

    <ParamField body="mediaIndex" type="integer">

      Optional 0-based index of the story frame to replace. When omitted, the story's entire media set
      is replaced with the single new media. Stories that have no frame at this index are left unchanged.

    </ParamField>
