---
title: "Category Object"
description: "Categories are used to group multiple services together."
icon: "cube"
---

Categories are used to group multiple services together. A service must be associated with a category in order to be exposed in the Wix Bookings UI.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Category ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Category name.

    </ResponseField>

    <ResponseField name="status" type="string">

      Category status.

      Default: `CREATED`

      **Read-only.**

      **Supported values:**

      - `CREATED` — The category was created.
      - `DELETED` — The category was deleted.

    </ResponseField>

    <ResponseField name="sortOrder" type="integer">

      Sort order of the category in the live site and dashboard.

    </ResponseField>

  </Tab>
