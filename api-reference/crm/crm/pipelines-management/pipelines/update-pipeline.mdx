    Updates a pipeline.

    Each time the pipeline is updated, `revision` increments by 1. The current `revision` must be specified when updating the pipeline.  This ensures you're working with the latest pipeline and prevents unintended overwrites.

    <Note>

    You can add and remove stages by calling this method. However, the done stage and any stages that contain cards can't be removed.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/crm/pipelines/v1/pipelines/{pipeline.id}
    ```

    ## Path Params

    <ParamField path="pipeline.id" type="string" required>

      Pipeline ID.

    </ParamField>

    ## Body Params

    <ParamField body="pipeline" type="Pipeline" required>

      Pipeline to update, may be partial.

      See the [Pipeline Object](/api-reference/crm/crm/pipelines-management/pipelines/pipeline-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="pipeline" type="Pipeline">

      Updated pipeline.

      See the [Pipeline Object](/api-reference/crm/crm/pipelines-management/pipelines/pipeline-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_CHANGE_DURATION_ON_STAGE_WITH_CARDS` | The stale duration can't be changed for a stage that contains cards. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_STAGE_WITH_CARDS` | A stage that contains cards can't be deleted. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_DELETE_PIPELINE_DONE_STAGE` | The done stage can't be deleted. |
    | `400` | `INVALID_ARGUMENT` | `INSUFFICIENT_PIPELINE_DATA` | The pipeline is missing required data. |
    | `400` | `INVALID_ARGUMENT` | `STAGE_IDS_MUST_BE_UNIQUE` | Stage IDs must be unique within the pipeline. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Pipeline name.

        </ParamField>

        <ParamField body="currency" type="string">

          Currency code for monetary values in this pipeline. Must be a valid ISO 4217 currency code. For example, `USD`.

          Default: Based on the site's currency settings.

        </ParamField>

        <ParamField body="stages" type="Stage[]">

          Pipeline stages in order.
          Cards move through these stages as they progress through the business process.

          Constraints: `minItems 1`, `maxItems 30`.

          <Expandable title="stages properties">

            <ParamField body="_id" type="string">

              Stage ID.

              **Read-only.**

            </ParamField>

            <ParamField body="name" type="string">

              Stage name.

            </ParamField>

            <ParamField body="staleDurationInHours" type="integer">

              The duration (in hours) a card can remain in this stage before becoming stale.
              When a card exceeds this duration, it's marked as stale to indicate potential workflow delays.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="doneStage" type="DoneStage">

          The final pipeline stage where cards receive a final outcome.

          <Expandable title="doneStage properties">

            <ParamField body="_id" type="string">

              Done stage ID.

              **Read-only.**

            </ParamField>

            <ParamField body="name" type="string">

              Done stage name.

            </ParamField>

              Outcomes that cards can have when moved to the done stage.

              Constraints: `minItems 1`, `maxItems 3`.

              **Supported values:**

              - `NONE` — No specific outcome. The process reached the final stage but has not been specified as successful or unsuccessful.
              - `WON` — Successful outcome. The process achieved its intended goal.
              - `LOST` — Unsuccessful outcome. The process didn't achieve its intended goal.
