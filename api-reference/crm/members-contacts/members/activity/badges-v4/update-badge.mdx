    Updates a badge.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/badges/v4/badges/{badge.id}
    ```

    ## Path Params

    <ParamField path="badge.id" type="string" required>

      Badge ID.

    </ParamField>

    ## Body Params

    <ParamField body="badge" type="Badge" required>

      Badge to update. Must include ID and revision to prevent conflicts.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges-v4/badge-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="badge" type="Badge">

      Updated badge with incremented revision and updated timestamp.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges-v4/badge-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `BADGE_NOT_PROVIDED` | Badge isn't provided. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Badge ID.

      **Read-only.**

    </ParamField>

    <ParamField body="badge" type="UpdateBadge" required>

      Badge to update. Must include ID and revision to prevent conflicts.

      <Expandable title="badge properties">

        <ParamField body="_id" type="string">

          Badge ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer">

          Revision number, which increments by 1 each time the badge is updated. To prevent conflicting changes, the current revision must be passed when updating the badge.

          **Read-only.**

        </ParamField>

        <ParamField body="title" type="string">

          Badge title displayed on the member's profile.

        </ParamField>

        <ParamField body="description" type="string">

          Badge description explaining its purpose or criteria for earning it.

        </ParamField>

        <ParamField body="backgroundColor" type="string">

          Badge background color in hexadecimal RGB format.

        </ParamField>

        <ParamField body="textColor" type="string">

          Badge text color in hexadecimal RGB format.

        </ParamField>

        <ParamField body="icon" type="string">

          Badge icon image.

          Any image format is accepted with automatic conversion and resizing handled by the system.
          SVG format is recommended as it is resolution independent and looks great at any scale.

        </ParamField>

        <ParamField body="permissionsEnabled" type="boolean">

          Whether the badge grants special permissions to access specific members-only pages.

          When `true`, members with this badge receive special permissions.
          Site owners can configure these permissions in the site dashboard. For more information, see [Creating and Managing Member Badges](https://support.wix.com/en/article/site-members-creating-and-managing-member-badges).

        </ParamField>

        <ParamField body="slug" type="string">

          URL-friendly slug for the badge, automatically generated from the title.

          Generated by converting the title to lowercase, replacing spaces with hyphens, and removing special characters.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the badge was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the badge was last updated.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>
