    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-EVENTS">Read Events</span>

    </div>

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/events/count-by-status
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object in the following format: &lt;br/> `"filter" : { "fieldName1": "value1" }`.

    </ParamField>

    <ParamField body="facet" type="string[]">

      Parameters to count events by.

      Constraints: `maxLength 100`, `maxItems 20`.

    </ParamField>

    <ParamField body="includeDrafts" type="boolean">

      Whether draft events should be returned in the response. &lt;br>
      **Note:** This parameter requires the `WIX_EVENTS.READ_DRAFT_EVENTS` permission.

    </ParamField>

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/events/v3/events/count-by-status' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH TOKEN>' \
      -d '{
        "filter": {
          "status": {
            "$eq": "CANCELED"
          }
        },
        "facet": ["status"],
        "includeDrafts": false
      }'
      ```

      ```json Response
      {
        "pagingMetadata": {
          "count": 10,
          "offset": 0,
          "total": 10,
          "tooManyToCount": null,
          "cursors": null
        },
        "facets": {
          "status": {
            "counts": {
              "CANCELED": 10
            }
          }
        }
      }
      ```
