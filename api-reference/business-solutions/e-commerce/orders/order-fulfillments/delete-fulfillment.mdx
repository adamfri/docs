    <div className="wix-ref">

    Deletes an existing order fulfillment.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/ecom/v1/fulfillments/{fulfillmentId}/orders/{orderId}
    ```

    ## Path Params

    <ParamField path="orderId" type="string" required>

      Order ID.

    </ParamField>

    <ParamField path="fulfillmentId" type="string" required>

      ID of the fulfillment to delete.

    </ParamField>

    ## Response Object

    <ResponseField name="orderWithFulfillments" type="OrderWithFulfillments">

      Order ID and the order's associated fulfillments after deletion.

      See the [Fulfillments Object](/api-reference/business-solutions/e-commerce/orders/order-fulfillments/fulfillments-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order With Fulfillments Updated | `wix.ecom.v1.fulfillments_updated` | Triggered when one or more of an order's fulfillments are created, updated, or deleted. The response contains the order's ID and details about all of its fulfillments following the change. |

    </div>
