---
title: "Member Object"
description: "A registered user of a Wix site who can log in, access member-only content, and participate in site activities."
icon: "cube"
---

A registered user of a Wix site who can log in, access member-only content, and participate in site activities.
Members have profiles, contact information, and can interact with site features such as forums, blogs, and community features.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Member ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="loginEmail" type="string">

      Email used by a member to log in to the site.

    </ResponseField>

    <ResponseField name="loginEmailVerified" type="boolean">

      Whether the email used by a member has been verified.

      **Read-only.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Member site access status.

      **Read-only.**

      **Supported values:**

      - `PENDING` — Member is created and is waiting for approval by a Wix user.
      - `APPROVED` — Member can log in to the site.
      - `BLOCKED` — Member is blocked and can't log in to the site.
      - `OFFLINE` — Member is a [guest author](https://support.wix.com/en/article/wix-blog-adding-managed-writers-to-your-blog) for the site blog and can't log in to the site.

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Contact ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="contact" type="Contact">

      Member's contact information. Contact information is stored in the
      [Contact List](https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fcontacts).

      The full set of contact data can be accessed and managed with the
      [Contacts API](https://dev.wix.com/docs/rest/crm/members-contacts/contacts/contacts/introduction).

      <Expandable title="contact properties">

        <ResponseField name="firstName" type="string">

          Contact's first name.

        </ResponseField>

        <ResponseField name="lastName" type="string">

          Contact's last name.

        </ResponseField>

        <ResponseField name="phones" type="string[]">

          List of phone numbers.

        </ResponseField>

        <ResponseField name="emails" type="string[]">

          List of email addresses.

          Constraints: `format EMAIL`, `immutable`.

        </ResponseField>

        <ResponseField name="addresses" type="Address[]">

          List of street addresses.

          <Expandable title="addresses properties">

            <ResponseField name="id" type="string">

              Street address ID.

              **Read-only.**

            </ResponseField>

            <ResponseField name="addressLine2" type="string">

              Free text providing more detailed address information,
              such as apartment, suite, or floor.

            </ResponseField>

            <ResponseField name="city" type="string">

              City name.

            </ResponseField>

            <ResponseField name="subdivision" type="string">

              Code for a subdivision (such as state, prefecture, or province) in an
              [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) format.

            </ResponseField>

            <ResponseField name="country" type="string">

              2-letter country code in an
              [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format.

            </ResponseField>

            <ResponseField name="postalCode" type="string">

              Postal code.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="birthdate" type="string">

          Contact's birthdate, formatted as `"YYYY-MM-DD"`.

          Example: `"2020-03-15"` for March 15, 2020.

        </ResponseField>

        <ResponseField name="company" type="string">

          Contact's company name.

        </ResponseField>

        <ResponseField name="jobTitle" type="string">

          Contact's job title.

        </ResponseField>

        <ResponseField name="customFields" type="object">

          Custom fields,
          where each key is the field key,
          and each value is the field's value for the member.

          Constraints: `format map`.

          <Expandable title="customFields properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="CustomField">

              <Expandable title="value properties">

                <ResponseField name="name" type="string">

                  Custom field name.

                </ResponseField>

                <ResponseField name="value" type="any">

                  Custom field value.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="profile" type="Profile">

      Profile display details.

      <Expandable title="profile properties">

        <ResponseField name="nickname" type="string">

          Name that identifies the member to other members.
          Displayed on the member's profile page
          and interactions in the forum or blog.

        </ResponseField>

        <ResponseField name="slug" type="string">

          Slug that determines the member's profile page URL.

          **Read-only.**

        </ResponseField>

        <ResponseField name="photo" type="Image">

          Member's profile photo.

          <Expandable title="photo properties">

            <ResponseField name="id" type="string">

              Wix Media image ID,
              set when the member selects an image from Wix Media.

            </ResponseField>

            <ResponseField name="url" type="string">

              Image URL.

            </ResponseField>

            <ResponseField name="height" type="integer">

              Original image width.

            </ResponseField>

            <ResponseField name="width" type="integer">

              Original image height.

            </ResponseField>

            <ResponseField name="offsetX" type="integer">

              X-axis offset.

              Default: `0`.

            </ResponseField>

            <ResponseField name="offsetY" type="integer">

              Y-axis offset.

              Default: `0`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="cover" type="Image">

          Member's cover photo,
          used as a background picture in a member's profile page.

          Cover positioning can be altered with `cover.offsetX` and `cover.offsetY`.
          When left empty, the values default to `0`.

          <Expandable title="cover properties">

            <ResponseField name="id" type="string">

              Wix Media image ID,
              set when the member selects an image from Wix Media.

            </ResponseField>

            <ResponseField name="url" type="string">

              Image URL.

            </ResponseField>

            <ResponseField name="height" type="integer">

              Original image width.

            </ResponseField>

            <ResponseField name="width" type="integer">

              Original image height.

            </ResponseField>

            <ResponseField name="offsetX" type="integer">

              X-axis offset.

              Default: `0`.

            </ResponseField>

            <ResponseField name="offsetY" type="integer">

              Y-axis offset.

              Default: `0`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="title" type="string">

          Member title.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="privacyStatus" type="string">

      Member privacy status.

      **Supported values:**

      - `PRIVATE` — Member is hidden from site visitors and other site members. Member is returned only to Wix users.
      - `PUBLIC` — Member is visible to everyone.

    </ResponseField>

    <ResponseField name="activityStatus" type="string">

      Member activity status.

      **Read-only.**

      **Supported values:**

      - `ACTIVE` — Member can write forum posts and blog comments.
      - `MUTED` — Member can't write forum posts or blog comments.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when the member was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time when the member was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="lastLoginDate" type="datetime">

      Date and time when the member last logged in to the site.

      **Read-only.**

    </ResponseField>
