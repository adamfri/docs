    Adds or removes tags on multiple attribute definitions.

    Specify which tags to assign and which tags to unassign. A tag that appears in both the list to assign and the list to unassign will be assigned. Tags that don't exist are ignored.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="bookings:attributes:v1:attribute_definition:bulk_update_attribute_definition_tags">bookings:attributes:v1:attribute_definition:bulk_update_attribute_definition_tags</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/attributes/v1/bulk/attribute-definitions/update-tags
    ```
