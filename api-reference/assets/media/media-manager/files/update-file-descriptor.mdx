    <div className="wix-ref">

    Updates a file. <br />

    Specify the `parentFolderId` parameter to move a file from its current folder to a different folder.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEDIA.MANAGE-MEDIAMANAGER">Manage Media Manager</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/site-media/v1/files/update-file-descriptor
    ```

    ## Body Params

    <ParamField body="file" type="FileDescriptor" required>

      The file to update.

      See the [File Descriptor Object](/api-reference/assets/media/media-manager/files/file-descriptor-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="file" type="FileDescriptor">

      Information about the updated file.

      See the [File Descriptor Object](/api-reference/assets/media/media-manager/files/file-descriptor-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `FIELD_MASK_IS_EMPTY_OR_MISSING` | `fieldMask` is empty or missing from the request. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

        const elevatedUpdateFileDescriptor = auth.elevate(files.updateFileDescriptor);
        const updatedDescriptor = await elevatedUpdateFileDescriptor({

        return updatedDescriptor;

    export const listImages = webMethod(Permissions.Anyone, async () => {
      const listOptions = {

        const elevatedListFiles = auth.elevate(files.listFiles)
        const images = await elevatedListFiles(listOptions);

        return images.files;
      } catch (error) {

      }
