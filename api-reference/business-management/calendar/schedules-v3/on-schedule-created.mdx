Triggered when a schedule is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.calendar.v3.schedule_created` |
| Package | `@wix/calendar` |
| Permissions | `Read Calendar - Including PI`, `Manage Calendars`, `Manage Bookings`, `Read Bookings - Including Participants`, `Manage Bookings - all permissions`, `Read bookings calendar - including participants` |

## Examples

<CodeGroup>

  ```javascript onScheduleCreated
  import { schedules } from '@wix/calendar';

  schedules.onScheduleCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onScheduleCreated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { schedules } from '@wix/calendar';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        schedules,
      },
  });

  wixClient.schedules.onScheduleCreated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
