    <div className="wix-ref">

    Creates a new data collection.

    The request body must include an ID, details for at least 1 field, and a permissions object. If any of these are missing, the collection isn't created.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/collections
    ```

    ## Body Params

    <ParamField body="collection" type="DataCollection" required>

      Collection details.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="collection" type="DataCollection">

      Details of collection created.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
