title: "Badge Object"
description: "A badge is a visible label displayed on a site member's profile."

---

A badge is a visible label displayed on a site member's profile.

Site owners can create badges to categorize members and optionally grant them special permissions to access specific pages.

Badges are managed separately from their assignment to members. To assign badges to members, use the [Badge Assignments](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/activity/badge-assignments/introduction) API.

For more information, see [Creating and Managing Member Badges](https://support.wix.com/en/article/site-members-creating-and-managing-member-badges).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Badge ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the badge is updated. To prevent conflicting changes, the current revision must be passed when updating the badge.

      **Read-only.**

    </ResponseField>

    <ResponseField name="title" type="string">

      Badge title displayed on the member's profile.

    </ResponseField>

    <ResponseField name="description" type="string">

      Badge description explaining its purpose or criteria for earning it.

    </ResponseField>

    <ResponseField name="backgroundColor" type="string">

      Badge background color in hexadecimal RGB format.

    </ResponseField>

    <ResponseField name="textColor" type="string">

      Badge text color in hexadecimal RGB format.

    </ResponseField>

    <ResponseField name="icon" type="Image">

      Badge icon image.

      Any image format is accepted with automatic conversion and resizing handled by the system.
      SVG format is recommended as it is resolution independent and looks great at any scale.

      <Expandable title="icon properties">

        <ResponseField name="id" type="string">

          [WixMedia](https://support.wix.com/en/article/wix-media-about-the-media-manager) image ID. If you pass the ID, you don't need to pass `url`.

        </ResponseField>

        <ResponseField name="url" type="string">

          Image URL. Could be any image from the internet.

        </ResponseField>

        <ResponseField name="height" type="integer">

          Original image height.

          **Read-only.**

        </ResponseField>

        <ResponseField name="width" type="integer">

          Original image width.

          **Read-only.**

        </ResponseField>

        <ResponseField name="altText" type="string">

          Image alt text.

        </ResponseField>

        <ResponseField name="filename" type="string">

          Image filename. Only applicable when passing `id`.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="permissionsEnabled" type="boolean">

      Whether the badge grants special permissions to access specific members-only pages.

      When `true`, members with this badge receive special permissions.
      Site owners can configure these permissions in the site dashboard. For more information, see [Creating and Managing Member Badges](https://support.wix.com/en/article/site-members-creating-and-managing-member-badges).

    </ResponseField>

    <ResponseField name="slug" type="string">

      URL-friendly slug for the badge, automatically generated from the title.

      Generated by converting the title to lowercase, replacing spaces with hyphens, and removing special characters.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the badge was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the badge was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "badge": {
          "id": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
          "revision": 1,
          "title": "Top Contributor",
          "description": "Awarded for being a top contributor in the community",
          "backgroundColor": "#2A5FA7",
          "textColor": "#FFFFFF",
          "slug": "top-contributor",
          "icon": {
            "url": "https://example.com/badge-icon.png",
            "height": 64,
            "width": 64,
            "altText": "Top Contributor"
          },
          "permissionsEnabled": true,
          "createdDate": "2023-10-30T17:22:10.299Z",
          "updatedDate": "2023-10-30T17:22:10.299Z"
         }
      }
      ```

    </CodeGroup>
