    Creates a promotion.

    To create multiple promotions in a single API call, call [Bulk Create Promotions](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/promotions-v3/bulk-create-promotions).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_WRITE">Manage v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/promotions
    ```

    ## Body Params

    <ParamField body="promotion" type="Promotion" required>

      Promotion to create.

      See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="promotion" type="Promotion">

      Created promotion.

      See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MEDIA_NOT_FOUND` | Couldn't find the media in Media Manager. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_CATEGORY_ASSIGNMENT` | A category is assigned to the same promotion more than once. |
    | `428` | `FAILED_PRECONDITION` | `PROMOTIONS_LIMIT_EXCEEDED` | The maximum number of promotions per site has been reached. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Promotion Created | `wix.stores.catalog.v3.promotion_created` | Triggered when a promotion is created. |

    </div>
