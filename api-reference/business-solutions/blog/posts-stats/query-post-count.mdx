    Retrieves the number of published posts per month within a specified time range.

    The time range is set using the `rangeStart` and `months` properties.
    The time range always starts on the 1st day of the month set in `rangeStart` and
    includes the number of `months` following `rangeStart`.
    For example, if `rangeStart` is set to `'2022-03-13'` and `months` is set to `4`,
    the time range will be from `'2022-03-01'` until `'2022-06-30'`. The time range always ends on the last day of the month.
    > Note: If there are no published posts in a month within the time range, that month is not included in the response. For example, let's say a blog has `0` posts dated in February 2022. If `rangeStart` is set to `'2022-01-01'` and `months` is set to `3`, the response includes `postCount` values for January and March, but not February.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v2/stats/post/count
    ```

    ## Query Params

    <ParamField query="rangeStart" type="datetime">

      Start of time range to return, in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) date and time format.

    </ParamField>

    <ParamField query="order" type="string">

      Order of returned results.

      - `OLDEST`: posts by date in ascending order.
      - `NEWEST`: posts by date in descending order.

      Default: `OLDEST`

      **Supported values:**

      - `OLDEST`
      - `NEWEST`

    </ParamField>

    <ParamField query="months" type="integer">

      Number of months to include in response.

      Constraints: `min 0`.

    </ParamField>

    <ParamField query="language" type="string">

      Language filter.

      2-or-4-letter language code in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.
      Pass a language to only receive the period post count for that specified language.

    </ParamField>

    <ParamField query="timeZone" type="string">

      Time zone to use when calculating the start of the month.

      [UTC timezone offset](https://en.wikipedia.org/wiki/List_of_UTC_offsets) format. For example, New York time zone is `-05`.

    </ParamField>

    ## Response Object

    <ResponseField name="stats" type="PeriodPostCount[]">

      List of published post counts by month.

      <Expandable title="stats properties">

        <ResponseField name="periodStart" type="datetime">

          Start of time range in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) date and time format.

        </ResponseField>

        <ResponseField name="postCount" type="integer">

          Number of posts published during this month.

          Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>
