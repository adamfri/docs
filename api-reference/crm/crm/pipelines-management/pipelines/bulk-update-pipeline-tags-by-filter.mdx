    Updates tags on multiple pipelines, using a filter to select which pipelines to update.

    If you don't specify a filter, all pipelines on the site are updated.
    If you specify a tag in both `assignTags` and `unassignTags`, the tag is assigned to the pipelines.

    <Note>

    This is an asynchronous method that returns a job ID for tracking progress.

    </Note>
    To get the status of the job, call [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/pipelines/v1/bulk/pipelines/update-tags-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter to select which pipelines to update.

    </ParamField>

    <ParamField body="assignTags" type="PrivateTags">

      List of tags to assign.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="PrivateTags">

      List of tags to unassign.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the updated pipelines in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID for tracking the asynchronous tag updates.

      Constraints: `format GUID`.

    </ResponseField>
