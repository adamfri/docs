    This method retrieves an array containing the lists of recommended items returned by each algorithm. Items must be selected from catalogs in Wix apps installed on the site.

    If a requested recommendation algorithm's type is `RELATED_ITEMS` then the `items` field is included in the request. The response should contain items related to those submitted.
    How the related items are selected depends on the recommendation algorithms used. For example, items can be in the same category, or can be frequently bought or watched together.

    ## Endpoint

    ```http
    POST /v1/get-recommendations
    ```

    ## Body Params

    <ParamField body="items" type="CatalogReference[]">

      The set of items used by algorithms with the `RELATED_ITEMS` `algorithmType` to determine related item recommendations.

      Constraints: `maxItems 300`.

      <Expandable title="items properties">

        <ParamField body="catalogItemId" type="string">

          ID of the item within the catalog it belongs to.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="appId" type="string">

          ID of the app providing the catalog.

          You can get your app's ID from its page in the [app dashboard](https://dev.wix.com/dc3/my-apps/).

          For items from Wix catalogs, the following values always apply:
          + Wix Stores: `"215238eb-22a5-4c36-9e7b-e7c08025e04e"`
          + Wix Bookings: `"13d21c63-b5ec-5912-8397-c3a5ddb27a97"`
          + Wix Restaurants: `"9a5d83fd-8570-482e-81ab-cfa88942ee60"`

          Constraints: `minLength 1`.

        </ParamField>

        <ParamField body="options" type="object">

          Additional item details in `key:value` pairs.

          Use this optional field for more specificity with item selection. The values of the `options` field differ depending on which catalog is providing the items.

          For Wix Stores products, learn more about integrating with [Catalog V3](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/e-commerce-integration)
          or [Catalog V1](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v1/catalog/e-commerce-integration), depending on [the version the site uses](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-versioning/introduction).

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="algorithmIds" type="string[]">

      List of algorithms used to find recommended items. Items will be returned in a separate object for each algorithm

      Constraints: `format GUID`, `minItems 1`, `maxItems 10`.

    </ParamField>

    ## Response Object

    <ResponseField name="recommendationPerAlgorithm" type="RecommendationForAlgorithm[]">

      Related items returned by each algorithm.

      Each object in the array contains an `algorithmId` and a list of the item recommendations provided by that algorithm.

      Constraints: `maxItems 10`.

      <Expandable title="recommendationPerAlgorithm properties">

        <ResponseField name="algorithmId" type="string">

          Id of the algorithm that provided the recommendation.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="recommendedItems" type="CatalogReference[]">

          Item recommendations provided by the algorithm. Depending on the algorithm, these recommendations may be influenced by the items provided in the request.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `ALGORITHM_NOT_SUPPORTED` | One or more of the requested `algorithm_ids` aren't supported by the provider. Check the provider's `supported_algorithms` configuration for valid algorithm IDs. |
    | `400` | `INVALID_ARGUMENT` | `ITEM_APP_ID_NOT_SUPPORTED` | One or more items are from catalogs that aren't supported by the provider. Only provide items from catalogs listed in the provider's `catalog_app_ids` configuration. |
