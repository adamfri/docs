title: "Content Plan Content Plan Flow Object"

A content plan flow tracks the generation of an SEO content plan for a site.

A content plan is a set of blog post briefs built from the site's pages, its
business category, and real search volume data. Generating one takes several
minutes, so the flow runs asynchronously and reports its progress in `status`.

A flow doesn't run to completion on its own. It stops at `KEYWORD_RESEARCH`
and waits for a call to Create Content Plan before it continues.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Content plan flow ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdAt" type="string">

      Date and time the content plan flow was created.

    </ResponseField>

    <ResponseField name="updatedAt" type="string">

      Date and time the content plan flow was updated.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the content plan flow.

      The status advances on its own as generation progresses, except at
      `KEYWORD_RESEARCH`, where the flow waits for a call to Create Content
      Plan.

      **Supported values:**

      - `CREATED` — The flow is created and the generation pipeline is starting.
      - `SITE_SUMMARY` — The site's existing content is being summarized.
      - `KEYWORD_RESEARCH` — Keyword research is complete and the flow is waiting. Call Create
      Content Plan to generate the blog post briefs and continue the flow.
      - `CONTENT_PLAN` — Blog post briefs are being generated from the keyword research.
      - `SUCCESS` — Generation is complete. Retrieve the results with List Blog Post
      Candidates and List Keyword Research Items.
      - `FAIL` — Generation failed. Trigger a flow to try again.
      - `PENDING_REQUIREMENTS` — The site is missing business information that keyword research
      requires. The flow resumes automatically once the information is
      added to the site.
      - `CANCELED` — The flow was canceled and can't be resumed.
      - `SITE_ANALYSIS` — The site's pages are being analyzed.

    </ResponseField>

    <ResponseField name="origin" type="string">

      What started the content plan flow. Flows started by an app are
      recorded as `AGENT`.

    </ResponseField>

    <ResponseField name="summaryId" type="string">

      ID of the site content summary the flow produced.

    </ResponseField>

    <ResponseField name="keywordResearchId" type="string">

      ID of the keyword research the flow produced.

      Available once `status` is `KEYWORD_RESEARCH` or later.

    </ResponseField>
