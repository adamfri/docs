    <div className="wix-ref">

    Retrieves a list of child account IDs for the requesting account.
    If no child accounts exist, an empty list will be returned.

    <Note>

    This call requires an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="ACCOUNT.CHILD_ACCOUNTS_LIST">ACCOUNT.CHILD_ACCOUNTS_LIST</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/accounts/v1/account/child-accounts
    ```

    ## Query Params

    <ParamField query="paging" type="Paging">

      Paging options to limit and offset the number of items.
