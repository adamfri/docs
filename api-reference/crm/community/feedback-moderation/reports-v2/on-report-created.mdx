Triggered when a report is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.reports.v2.report_created` |
| Package | `@wix/reports` |
| Permissions | `Manage Reports`, `Read Reports` |

## Examples

<CodeGroup>

  ```javascript onReportCreated
  import { reports } from '@wix/reports';

  reports.onReportCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onReportCreated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { reports } from '@wix/reports';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        reports,
      },
  });

  wixClient.reports.onReportCreated((event) => {
      // handle your event here
  });
  ```
