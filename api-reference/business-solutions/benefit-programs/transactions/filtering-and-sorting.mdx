<Note>This article applies to the REST API only.</Note>

The following table shows field support for filters and sorting for the transaction object:

| Field                       | Supported Filters                                                                                   | Sortable | 
| --------------------------  | --------------------------------------------------------------------------------------------------- | -------- |
| `id`                        | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`, `$lt`, `$gt`, `$lte`, `$gte`                            | Sortable |
| `relatedTransactionId`      | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`, `$lt`, `$gt`, `$lte`, `$gte`                            | Sortable |
| `pool.id`                   | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`, `$lt`, `$gt`, `$lte`, `$gte`                            | Sortable |
| `beneficiary.memberId`      | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`, `$lt`, `$gt`, `$lte`, `$gte`                            | Sortable |
| `beneficiary.wixUserId`     | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`, `$lt`, `$gt`, `$lte`, `$gte`                            | Sortable |
| `details.item.id`           | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith`, `$lt`, `$gt`, `$lte`, `$gte`                            | Sortable |
| `createdDate`               | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`                                                   | Sortable |
