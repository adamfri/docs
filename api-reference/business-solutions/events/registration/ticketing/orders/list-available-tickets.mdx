    Retrieves tickets available to reserve.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.EVENTS-CHECKOUT">Events Checkout</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/checkout/available-tickets
    ```

    ## Query Params

    <ParamField query="eventId" type="string">

      Event ID to list tickets for. If not specified, available tickets for all events on a site will be returned.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="offset" type="integer">

      Offset.

      Constraints: `min 0`.

    </ParamField>

    <ParamField query="limit" type="integer">

      Limit.

      **Default:** `0`. If you don't pass this field in the request, only `metadata` is returned.

      Constraints: `min 0`, `max 100`.

    </ParamField>

    <ParamField query="sort" type="string">

      Sort order.

      Default: `created:asc`.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField query="state" type="string[]">

      **Supported values:**

      - `INCLUDE_HIDDEN_NOT_ON_SALE`

    </ParamField>

          Configuration of the fixed-rate Wix service fee that is applied at checkout to each ticket sold.

          **Read-only.**

          <Expandable title="wixFeeConfig properties">

            <ResponseField name="type" type="string">

              Fee calculation method.

              **Supported values:**

              - `FEE_ADDED` — Fee is added to the ticket price at checkout.
              - `FEE_INCLUDED` — Seller absorbs the fee. It's deducted from the ticket price.
              - `FEE_ADDED_AT_CHECKOUT` — Fee is added to the ticket price at checkout.

            </ResponseField>

          </Expandable>

          Ticket sale status.
