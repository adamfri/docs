  <Tab title="REST">

    Sets `settings.collectionStates.collectingRequests` to `true` for given `appId`.

    When the collection state is set to `true`, collecting requests is enabled and customers may request
    notifications for out of stock products. While collecting is enabled, customers see a "Notify When Available"
    button on out-of-stock items. Customers can click the button to enter their email address, which creates the
    notification request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES-MEGA.MANAGE-STORES">Manage Stores - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/back-in-stock-service/v1/back-in-stock-notification-requests/settings/start-collecting
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the app to start accepting notification requests for.

      Back in stock notifications only work for [Wix Stores](https://support.wix.com/en/article/wix-stores-about-wix-stores).
      The `appId` for Wix Stores is `"215238eb-22a5-4c36-9e7b-e7c08025e04e"`.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="settings" type="BackInStockSettings">

      Back in stock settings info.

      See the [Back In Stock Settings Object](/api-reference/business-solutions/e-commerce/other-services/back-in-stock/back-in-stock-settings/back-in-stock-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NOT_SUPPORTED_APP_DEF_ID` | The specified `appId` isn't supported. Back in stock notifications only work for Wix Stores. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
