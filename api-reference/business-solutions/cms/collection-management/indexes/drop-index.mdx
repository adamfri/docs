<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Removes an index from a data collection.

    The process of dropping an index from a collection takes time.
    You can check whether an index has been dropped by calling List Indexes.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.INDEXES-MANAGE">Manage Data Indexes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/data/v2/indexes
    ```

    ## Query Params

    <ParamField query="indexName" type="string" required>

      Name of the index to drop.

      Constraints: `minLength 1`, `maxLength 128`.

    </ParamField>

    <ParamField query="dataCollectionId" type="string" required>

      ID of the data collection for which the index to be dropped is defined.

      Constraints: `maxLength 1024`.

    </ParamField>

    ## Response Object

    Returns `DropIndexResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Index Updated | `wix.data.v2.index_updated` | Triggered when an index's status field is updated. For example, during index creation, the index's status transitions from `BUILDING` to `ACTIVE` or `FAILED`. Either transition triggers this event. |

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X DELETE \
      'https://www.wixapis.com/wix-data/v2/indexes' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>'
      -d {
        "dataCollectionId": "my-collection",
        "indexName": "my-index"
      }
      ```

      ```json Response
      {}
      ```

    </CodeGroup>

    </div>
