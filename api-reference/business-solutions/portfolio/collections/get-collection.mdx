    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    </div>

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/portfolio/v1/collections/{collectionId}
    ```

    ## Path Params

    <ParamField path="collectionId" type="string" required>

      ID of the collection to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="includePageUrl" type="boolean">

      Whether to include the collection's page URL and relative path in the response. Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="collection" type="Collection">

      The requested collection.

      See the [Collection Object](/api-reference/business-solutions/portfolio/collections/collection-object) for this object's fields.

    </ResponseField>

    <Note>
