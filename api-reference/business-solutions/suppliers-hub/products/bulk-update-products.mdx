    Updates multiple products in a single request.

    Supports partial success and partial field updates. Each result includes an `itemMetadata` object indicating success or failure with error details.

    When handling failures, distinguish between validation errors which shouldn't be retried,
    and transient errors which can be retried. Only retry failed items, not the entire batch.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/suppliers-hub/v1/bulk/products/update
    ```

    ## Body Params

    <ParamField body="products" type="MaskedProduct[]" required>

      Products to update. Each can be partial based on its field mask.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="products properties">

        <ParamField body="product" type="Product">

          Product to update. May be partial - only fields to be updated need to be provided.

          See the [Product Object](/api-reference/business-solutions/suppliers-hub/products/product-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the updated products in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkProductResult[]">

      Results

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Metadata regarding the specific single update operation

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible. For example, when failing to create an item.

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Product">

          Only exists if `returnEntity` was set to true in the request

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata regarding the bulk update operation

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        <ResponseField name="totalFailures" type="integer">

        </ResponseField>

          Number of failures without details because detailed failure threshold was exceeded.

    </ResponseField>
