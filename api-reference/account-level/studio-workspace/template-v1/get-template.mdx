    Retrieves a template by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES">SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wixstudio/templates/v1/templates/{templateId}
    ```

    ## Path Params

    <ParamField path="templateId" type="string" required>

      ID of the template to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="template" type="Template">

      Retrieved template.

      See the [Template Object](/api-reference/account-level/studio-workspace/template-v1/template-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
