    Sends the verification code to the created sender email's inbox.

    <Note>

    If the code wasn't received, check the spam folder. If it's not there, try to send the verification email again.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.ACCESS-VERTICALS-BY-AUTOMATIONS">Access Verticals by Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/sender-emails/v1/sender-emails/{senderEmailId}/send-verification-code
    ```

    ## Path Params

    <ParamField path="senderEmailId" type="string" required>

      ID of the sender email to send the code for.

    </ParamField>

    ## Response Object

    Returns `SendVerificationCodeResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
