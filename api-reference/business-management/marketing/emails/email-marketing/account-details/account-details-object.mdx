Email marketing account details for a site, including the account's current status, premium plan information, and email quota for the current billing period.

<Tabs>

  <Tab title="REST">

    <ResponseField name="status" type="string">

      Account status. If the account isn't active, the site owner must visit the Email Marketing dashboard and follow the instructions.

      **Supported values:**

      - `ACTIVE` — Account is in good standing and can send email marketing campaigns.
      - `WARNED` — Account must accept the terms of use in the Wix Email Marketing dashboard before email marketing is available.
      - `SUSPENDED` — Account is suspended. Email marketing is unavailable until the site owner completes the required compliance questionnaire in the Wix Email Marketing dashboard.
      - `BANNED` — Account is suspended. Email marketing is unavailable until the site owner completes a more rigorous compliance questionnaire in the Wix Email Marketing dashboard.
      - `SUSPENDED_AUTOLIFT` — Account is suspended but may be automatically reinstated after the compliance questionnaire in the Wix Email Marketing dashboard is completed.

    </ResponseField>

    <ResponseField name="package" type="Package">

      Current premium plan information.

      <Expandable title="package properties">

        <ResponseField name="id" type="string">

          ID of the specific Wix premium plan.

        </ResponseField>

        <ResponseField name="group" type="string">

          Plan group identifier. Plans in the same group can be upgraded or downgraded between each other.

        </ResponseField>

        <ResponseField name="monthlyQuotaAllocation" type="Quota">

          Allocated quota per month.

          <Expandable title="monthlyQuotaAllocation properties">

            <ResponseField name="campaigns" type="integer">

              Number of campaigns in this period. In the `monthly_quota_allocation` context, represents the maximum allowed; `-1` means unlimited. In the `quota_usage` context, represents the number sent so far.

            </ResponseField>

            <ResponseField name="emails" type="integer">

              Number of emails in this period. In the `monthly_quota_allocation` context, represents the maximum allowed. In the `quota_usage` context, represents the number sent so far.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="quotaPeriod" type="QuotaPeriod">

      Current billing period with quota allocation and usage.

      <Expandable title="quotaPeriod properties">

        <ResponseField name="dateFrom" type="datetime">

          Current quota period start date.

        </ResponseField>

        <ResponseField name="dateTo" type="datetime">

          End date of the current quota period. Quota resets at the start of the next period.

        </ResponseField>

        <ResponseField name="quotaUsage" type="Quota">

          Quota used so far in the current period.

          <Expandable title="quotaUsage properties">

            <ResponseField name="campaigns" type="integer">

              Number of campaigns in this period. In the `monthly_quota_allocation` context, represents the maximum allowed; `-1` means unlimited. In the `quota_usage` context, represents the number sent so far.

            </ResponseField>

            <ResponseField name="emails" type="integer">

              Number of emails in this period. In the `monthly_quota_allocation` context, represents the maximum allowed. In the `quota_usage` context, represents the number sent so far.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="maxCampaignAudienceSize" type="integer">

      Maximum number of recipients allowed per campaign. Campaigns that exceed this limit may be rejected.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "accountDetails": {
          "status": "ACTIVE",
          "package": {
            "id": "Ascend_Professional",
            "group": "Ascend",
            "monthlyQuotaAllocation": {
              "campaigns": 20,
              "emails": 50000
            }
          },
          "quotaPeriod": {
            "dateFrom": "2020-05-14T14:27:26Z",
            "dateTo": "2020-06-14T14:27:26Z",
            "quotaUsage": {
              "campaigns": 1,
              "emails": 12450
            }
          }
        }
      }
      ```

    </CodeGroup>
