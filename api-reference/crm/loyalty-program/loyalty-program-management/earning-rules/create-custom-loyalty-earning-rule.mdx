    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/loyalty-earning-rules/v1/earning-rules/custom
    ```

    ## Body Params

    <ParamField body="type" type="string" required>

      Type of the custom earning rule.

      **Supported values:**

      - `SOCIAL_MEDIA` — Earning rule for social media.
      - `BIRTHDAY` — Earning rule for birthdays.

    </ParamField>

    <ParamField body="earningRule" type="CustomLoyaltyEarningRule">

      Custom earning rule to create.

      <Expandable title="earningRule properties">

        <ParamField body="title" type="string">

          Name of the earning rule.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="type" type="type">

          type

          <Expandable title="type properties">

            <ParamField body="fixedAmount" type="FixedAmount">

              Fixed amount of points awarded for each qualifying activity.

              _Nested structure omitted for brevity — see the `FixedAmount` object._

            </ParamField>

            <ParamField body="conversionRate" type="ConversionRate">

              Points awarded based on a conversion rate formula: `(amount spent) / (money_amount * points)`.

              _Nested structure omitted for brevity — see the `ConversionRate` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
