    Retrieves the specified data movement job.

    <Note>

    You can only retrieve jobs submitted for the current site.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE_MOVEMENT_JOBS">Data Mover Manage Jobs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data-mover/v1/jobs/{jobId}
    ```

    ## Path Params

    <ParamField path="jobId" type="string" required>

      Job ID.

    </ParamField>

    ## Response Object

    <ResponseField name="job" type="DataMovementJob">

      Details of the retrieved job.

      See the [Job Object](/api-reference/business-solutions/cms/operations/data-movement-jobs/job-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
