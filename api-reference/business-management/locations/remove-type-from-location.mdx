<Tabs>

  <Tab title="REST">

    Removes a location type from the specified location.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILOCATION.MANAGE-LOCATIONS">Manage Locations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/locations/v1/locations/{id}/remove-type
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the location where the type will be removed.

    </ParamField>

    ## Body Params

    <ParamField body="locationType" type="string" required>

      Location type to remove.

      **Supported values:**

      - `BRANCH`
      - `OFFICES`
      - `RECEPTION`
      - `HEADQUARTERS`
      - `INVENTORY`

    </ParamField>

    ## Response Object

    <ResponseField name="location" type="Location">

      Updated location.

      See the [Location Object](/api-reference/business-management/locations/location-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_LOCATION_TYPES_FOR_LOCATION` | Can't update location types for this location. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Location Updated | `wix.locations.v1.location_updated` |  |
