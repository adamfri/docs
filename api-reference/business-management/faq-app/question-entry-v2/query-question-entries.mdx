    Retrieves question entries, given the provided paging, filtering, and sorting.

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `question` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `sortOrder` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `categoryId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.READ-FAQ">Read FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/faq/v2/question-entries/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery">

      WQL query expression for filtering and sorting question entries.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object.

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object.

          Learn more about [sorting](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#sorting).

          Constraints: `maxItems 5`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

            <ParamField body="origin" type="AddressLocation">

              Origin point for geo-distance sorting on a GEO field

              _Nested structure omitted for brevity — see the `AddressLocation` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

          <Expandable title="pagingMethod properties">

            <ParamField body="cursorPaging" type="CursorPaging">

              Cursor paging options.

              Learn more about [cursor paging](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#cursor-paging).

              _Nested structure omitted for brevity — see the `CursorPaging` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="contentFormat" type="string">

      Format for answer content in the response.

      **Supported values:**

      - `DRAFTJS`
      - `PLAIN_TEXT`
      - `RICH_CONTENT`

    </ParamField>

    <ParamField body="fieldSet" type="string[]">

      Fields to include in the response.

      Constraints: `maxItems 100`.

      **Supported values:**

      - `SHARE_LINKS` — Include `share_link` fields inside question entries.

    </ParamField>

    </ResponseField>
