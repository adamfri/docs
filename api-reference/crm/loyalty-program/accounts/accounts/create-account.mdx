    Creates a loyalty account for a site contact.

    To create a new loyalty account, a customer must first be a site contact with a contact ID, see the Contacts API.
    The site must also have an [active loyalty program](https://dev.wix.com/docs/rest/crm/loyalty-program/program/activate-loyalty-program)
    before loyalty accounts can be created.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-accounts/v1/accounts
    ```

    ## Body Params

    <ParamField body="contactId" type="string" required>

      Contact ID for a site's contact. See the Contacts API for more information.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="LoyaltyAccount">

      Created loyalty account.

      See the [Account Object](/api-reference/crm/loyalty-program/accounts/accounts/account-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Loyalty Account Created | `wix.loyalty.v1.account_created` | Triggered when a loyalty account is created. |
