The Draft Posts API allows you to create and manage draft posts. A draft post is an article written by a site collaborator who is given the appropriate [roles and permissions](fallback::#blog-roles).

With the Draft Posts API, you can:

- [Create](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/create-draft-post) and [update](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/update-draft-post) draft posts.
- [Publish draft posts](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/publish-draft-post).
- [Query](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/query-draft-posts) and [list](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/list-draft-posts) draft posts.
- [Create](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/bulk-create-draft-posts), [update](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/bulk-update-draft-posts), and [delete](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/bulk-delete-draft-posts) multiple draft posts.
- [Delete](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/delete-draft-post) draft posts.
- [Restore deleted draft posts](fallback::https://dev.wix.com/docs/rest/business-solutions/blog/draft-posts/restore-from-trash-bin) from the trash bin.

Learn more about [Wix Blog](fallback::https://support.wix.com/en/article/wix-blog-about-the-wix-blog).

## Before you begin

It’s important to note the following before starting to code:

+ The size limit of a single draft post is 400KB.

+ With [Wix Pricing Plans](fallback::https://dev.wix.com/docs/rest/business-solutions/pricing-plans/pricing-plans/introduction), exclusive blog content can only be accessed by readers with a subscription. Learn more about [creating blog post subscriptions](fallback::https://support.wix.com/en/article/wix-blog-creating-blog-post-subscriptions).

+ With [Wix Multilingual](fallback::https://support.wix.com/en/article/wix-multilingual-an-overview), a blog can be translated into multiple languages. Learn more about [translating a blog](fallback::https://support.wix.com/en/article/wix-multilingual-translating-your-blog).
  <Note>

  `translationId` is only returned in a draft post object if the [Multilingual](fallback::https://support.wix.com/en/article/wix-multilingual-an-overview) app is installed.

  </Note>

## Blog roles
Collaborators can create and manage blogs based on certain roles: 
- **Blog editors** can fully manage the blog, but not other areas of a site.
- **Blog writers** can create and publish their own posts on a blog.
- **Guest writers** can create posts, but can't publish them. 

## Terminology

- **Post**: A published article on a blog. It is also referred to as a publication. A blog can have up to 100,000 posts.
- **Draft Post**: An article written by a Wix user, blog editor, blog writer, or a guest writer that is not yet published.
- **Category**: A group of similar and related posts. A post can be assigned to a maximum of 10 categories.
- **Tag**: A way to further sort and organize blog posts. Tags provide the ability to filter blog posts.
