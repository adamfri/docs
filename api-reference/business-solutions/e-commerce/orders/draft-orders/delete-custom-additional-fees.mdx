    Removes custom additional fees from a draft order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}/delete-custom-additional-fees
    ```

    ## Path Params

    <ParamField path="draftOrderId" type="string" required>

      Draft order ID.

    </ParamField>

    ## Body Params

    <ParamField body="customAdditionalFees" type="string[]" required>

      IDs of the additional fees to remove from the draft order.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DRAFT_ORDER_DOES_NOT_EXIST` | Couldn't find the draft order. |
    | `428` | `FAILED_PRECONDITION` | `ADDITIONAL_FEE_NOT_FOUND` | Couldn't find the additional fee. |
    | `428` | `FAILED_PRECONDITION` | `ADDITIONAL_FEE_REMOVE_NOT_SUPPORTED` | Can't remove additional fee because it wasn't added as part of the draft order. |
    | `409` | `ALREADY_EXISTS` | `DRAFT_ORDER_ALREADY_COMMITTED` | Draft order was already committed. |
