    Verifies a sender email by passing the verification code that was received in the sender email's inbox.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.ACCESS-VERTICALS-BY-AUTOMATIONS">Access Verticals by Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/sender-emails/v1/sender-emails/{senderEmailId}/verify
    ```

    ## Path Params

    <ParamField path="senderEmailId" type="string" required>

      ID of the sender email to verify.

    </ParamField>

    ## Body Params

    <ParamField body="verificationCode" type="string" required>

      Verification code that was received in the sender email's inbox.

      Constraints: `minLength 3`, `maxLength 10`.

    </ParamField>

    ## Response Object

    Returns `VerifySenderEmailResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INCORRECT_CODE` | Verification code is incorrect. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
