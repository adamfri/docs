    Retrieves the connected accounts for a social channel.

    Specify the `channelName` to retrieve the accounts the site owner has connected for that channel.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-publisher/v1/accounts
    ```

    ## Query Params

    <ParamField query="channelName" type="string">

      Social channel to retrieve connected accounts for.

      **Supported values:**

      - `INSTAGRAM`
      - `FACEBOOK`
      - `YOUTUBE`
      - `LINKEDIN`
      - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
      - `PINTEREST`
      - `GBP` — Google Business Profile.
      - `TIKTOK`

    </ParamField>

    ## Response Object

    <ResponseField name="accounts" type="Account[]">

      Connected accounts for the channel.

      See the [Account Object](/api-reference/business-management/marketing/social-media/account-v1/account-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NO_PAGES_FOR_USER` | The connected Facebook user has no pages, so no accounts can be retrieved. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
