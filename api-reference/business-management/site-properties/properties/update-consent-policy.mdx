    Updates a site's default consent policy.

    Read more about [Consent Apps](https://dev.wix.com/docs/build-apps/launch-your-app/legal-and-security/about-consent-apps#about-consent-apps).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-SITEPROP.MANAGE-PROPERTIES">Manage Consent Policy</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-properties/v4/properties/policy
    ```

    ## Body Params

    <ParamField body="consentPolicy" type="ConsentPolicy">

      Default consent policy defined by the Wix user. Can be further limited by site visitors.

      <Expandable title="consentPolicy properties">

        <ParamField body="essential" type="boolean">

          Whether the site uses cookies that are essential to site operation. Always `true`.

        </ParamField>

        <ParamField body="functional" type="boolean">

          Whether the site uses cookies that affect site performance and other functional measurements.

        </ParamField>

        <ParamField body="analytics" type="boolean">

          Whether the site uses cookies that collect analytics about how the site is used (in order to improve it).

        </ParamField>

        <ParamField body="advertising" type="boolean">

          Whether the site uses cookies that collect information allowing better customization of the experience for a current visitor.

        </ParamField>

        <ParamField body="dataToThirdParty" type="boolean">

          CCPA compliance flag.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `UpdateConsentPolicyResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `PERMISSION_DENIED` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method doesn't have the required permissions. |
    | `401` | `UNAUTHENTICATED` | `META_SITE_NOT_FOUND` | Couldn't find the site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    export const myUpdateConsentPolicyFunction = webMethod(Permissions.Anyone, async (consentPolicy) => {

          essential: $w('#essential').checked,

      });
