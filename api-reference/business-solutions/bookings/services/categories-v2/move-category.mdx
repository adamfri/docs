    <div className="wix-ref">

    Moves a category to the start, end, or immediately after a specified category by updating its `sortOrder` field.

    Wix Bookings assigns `sortOrder` values with large gaps between categories, allowing efficient reordering without updating the entire list. When gaps become too small, the system automatically reassigns new values to restore larger gaps.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/categories/set-position/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      ID of the category to move.

    </ParamField>

    ## Body Params

    <ParamField body="position" type="string">

      New position of the category.

      **Supported values:**

      - `LAST` — Place the category at the end of the list.
      - `FIRST` — Place the category at the beginning of the list.
      - `AFTER_CATEGORY` — Place the category immediately after a specific category.

    </ParamField>

    <ParamField body="afterCategoryId" type="string">

      ID of the reference category.
      Specify only for `{"position": "AFTER_CATEGORY"}`.

    </ParamField>

    ## Response Object

    <ResponseField name="category" type="Category">

      Updated category.

      See the [Category Object](/api-reference/business-solutions/bookings/services/categories-v2/category-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
