    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates moderation status of multiple reviews. All reviews are updated to the same moderation status.

    To update moderation status of a single review, call Update Moderation Status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v1/bulk/reviews/moderate
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Reviews to moderate.

    </ParamField>

    <ParamField body="status" type="string">

      Moderation status.

      **Supported values:**

      - `APPROVED` — The review has been approved and published, and site visitors can see it.
      - `REJECTED` — The review is rejected and site visitors can't see it.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Review Updated | `wix.reviews.v1.review_updated` | Triggered when a review is updated. |
    | Review Moderation Status Changed | `wix.reviews.v1.review_moderation_status_changed` | Triggered when a review's moderation status is changed or a review is created. |
    | Review Published | `wix.reviews.v1.review_review_published` | Triggered when a review's moderation status is set to `"APPROVED"`. |

    </div>
