Triggered when a folder is updated or deleted.

When a folder is deleted, any collection references that were in the deleted folder are moved to the root folder, triggering this event.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.cloud.autocms.v1.folder_updated` |
| Package | `@wix/autocms-folders-service` |
| Permissions | `Manage Data Collections` |

## Examples

<CodeGroup>
