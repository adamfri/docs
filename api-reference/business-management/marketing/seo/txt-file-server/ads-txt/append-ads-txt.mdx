<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Appends the submitted `content` object to Ads.txt.
    In order to reset Ads.txt to Wix's default, send `default: true` without a `content` object.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.MANAGE-ADS-TXT">Manage Ads.txt</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/promote-seo-robots-server/v2/ads
    ```

    ## Body Params

    <ParamField body="adsTxt" type="AdsTxt">

      Submitted `content` object will be appended to the existing Ads.txt file.
      To reset Ads.txt to Wix's default, submit `default:true` without a `content` object.

      See the [Ads Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/ads-txt/ads-txt-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="adsTxt" type="AdsTxt">

      Appended Ads.txt file.

      See the [Ads Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/ads-txt/ads-txt-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | — | Site ID is missing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Ads Txt Updated | `wix.promote.marketing.ads_txt_updated` |  |

    </div>

      ```json Response
          }
      }
      ```
