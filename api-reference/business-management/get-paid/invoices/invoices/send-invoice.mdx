    Sends an invoice to one or more contacts.

    Specify `contactIds` in the request to choose recipients. If `contactIds` isn't provided, the invoice is sent to the customer contact on the invoice.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/invoices/{invoiceId}/send
    ```

    ## Path Params

    <ParamField path="invoiceId" type="string" required>

      Invoice ID.

    </ParamField>

    ## Body Params

    <ParamField body="contactIds" type="string[]">

      List of contact IDs to send the invoice to. If not provided, the invoice is sent to the customer contact.

      Constraints: `format GUID`, `maxItems 5`.

    </ParamField>

    <ParamField body="messageContent" type="string">

      Optional message included with the sent invoice.

    </ParamField>

    ## Response Object

    <ResponseField name="invoice" type="Invoice">

      Sent invoice.

      See the [Invoice Object](/api-reference/business-management/get-paid/invoices/invoices/invoice-object) for this object's fields.

    </ResponseField>

    <ResponseField name="sendResults" type="SendResult[]">

      Results for each contact send attempt.

      <Expandable title="sendResults properties">

        <ResponseField name="contactId" type="string">

          Contact ID the send was attempted for.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="success" type="boolean">

          Whether the send was successful.

        </ResponseField>

        <ResponseField name="errorType" type="string">

          Error type if the send failed.

          **Supported values:**

          - `CUSTOMER_CONTACT_NOT_FOUND` — Couldn't find the contact.
          - `CONTACT_EMAIL_MISSING` — Contact doesn't have an email address.
          - `INTERNAL_ERROR` — Unexpected error.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `SITE_PROPERTIES_FAILED` | Couldn't retrieve business details from the site properties service. |
    | `428` | `FAILED_PRECONDITION` | `ILLEGAL_ACTION` | Invoice isn't in a state that allows sending. |
    | `428` | `FAILED_PRECONDITION` | `CUSTOMER_CONTACT_MISSING` | Invoice doesn't have a customer contact ID. |
    | `428` | `FAILED_PRECONDITION` | `SEND_LIMIT_REACHED` | Invoice has already been sent to the maximum of 5 distinct contacts. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
