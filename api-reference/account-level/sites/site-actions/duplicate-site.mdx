<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Duplicates a site with a new site name.

    <Note>

    When you duplicate a site, some business-related content such as store orders, contacts, invoices, and 3rd-party app settings are not be included.
    The duplicated site won’t have a domain or any Premium capabilities.

    </Note>

    Any installed apps that can be used only on sites with a Premium Plan, will be copied to the duplicated site and
    will appear unactivated. Once the site is upgraded, the app will be available for use.

    <Note>

    This call requires an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="my-account.duplicate-site">my-account.duplicate-site</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-actions/v1/sites/duplicate
    ```

    ## Body Params

    <ParamField body="sourceSiteId" type="string" required>

      ID of the site to duplicated.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="siteDisplayName" type="string" required>

      Display name for the new site.

      Constraints: `minLength 1`, `maxLength 40`.

    </ParamField>

    ## Response Object

    <ResponseField name="newSiteId" type="string">

      ID of the new site.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
