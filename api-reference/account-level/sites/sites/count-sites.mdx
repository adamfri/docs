  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the number of sites, given the provided filtering.
    See [Query Sites](https://dev.wix.com/docs/rest/account-level-apis/sites/sites/query-sites) for a list of supported filters.

    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ACC-DC-OS.READ-SITE">Read Site Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-list/v2/sites/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object. See [Query Sites](https://dev.wix.com/docs/rest/account-level-apis/sites/sites/query-sites) for a list of supported filters.
      Note: the `premium` and `appIds` filters are not supported in this endpoint.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of sites retrieved basd on the filter.
      Free Wix accounts are limited to max 1,000 sites.
      Premium accounts can have an unlimited number of sites.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `unauthenticated_user` | Authentication is required. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/site-list/v2/sites/count' \
        -H 'Content-Type: application/json' \
        -H 'Accept: application/json, text/plain, */*' \
        -H 'Authorization: <AUTH>' \
        -H 'wix-account-id: <ACCOUNT ID>' \
        --data-raw '{
          "filter":{"editorType":"EDITOR"}}'
      ```

      ```json Response
      {"count":210}
      ```

    </CodeGroup>
