    Retrieves a contact's activities, ordered from most recent to oldest.

    `contactId` is required for the first call. When paginating with `cursorPaging` on subsequent calls, pass only `cursorPaging.cursor`. Don't pass `contactId`, `categoryId`, `fromDate`, or `toDate` together with a cursor, as the cursor already carries those values. To learn about cursor paging, see [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.READ-CONTACTS">Read Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/crm/contacts-activity-log/v1/activities
    ```

    ## Query Params

    <ParamField query="cursorPaging" type="CursorPaging">

      Cursor token for retrieving subsequent pages. Pass `metadata.cursors.next` from the previous response. When providing a cursor, don't pass `contactId`, `categoryId`, `fromDate`, or `toDate`.

      <Expandable title="cursorPaging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="contactId" type="string">

      ID of the contact whose activities to retrieve. Required if `cursorPaging` isn't provided.

    </ParamField>

    <ParamField query="categoryId" type="string">

      ID of a category to filter activities by. Can't be used together with `cursorPaging`. To retrieve available category IDs, call [List Categories](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/activity-log/template-v1/list-categories).

    </ParamField>

    <ParamField query="fromDate" type="datetime">

      Earliest activity date to include in results, inclusive. Can't be used together with `cursorPaging`.

    </ParamField>

    <ParamField query="toDate" type="datetime">

      Latest activity date to include in results, inclusive. Can't be used together with `cursorPaging`.

    </ParamField>

    <ParamField query="language" type="string">

      2-letter language code in ISO 639-1 alpha-2 format. Determines the language of the `message` field for activities created by Wix from a template. Custom activity messages are always returned as provided, regardless of this parameter.

      Default: Language from the request context, or `en`.

    </ParamField>
