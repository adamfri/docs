    <div className="wix-ref">

    Updates an order's properties.

    <Note>

    <strong>Currently, only the following fields can be updated:</strong>
    + `buyerInfo.email`
    + `buyerLanguage`
    + `weightUnit`
    + `billingInfo.address`
    + `billingInfo.contactDetails`
    + `archived`
    + `attributionSource`
    + `seenByAHuman`
    + `recipientInfo.address`
    + `recipientInfo.contactDetails`
    + `shippingInfo.logistics.shippingDestination.address`
    + `shippingInfo.logistics.shippingDestination.contactDetails`
    + `extendedFields`

    </Note>

    To update a field's value, include the new value in the `order` object in the body params.
    To remove a field's value, pass `null`.

    <Note>

    + Removing `buyerInfo` or `contactDetails` results in an error.
    + `archived` can be set to `true` or `false`, but its value can't be removed. For example, to unarchive an order, pass `archived: false`.
    + To change the address an order is shipped to, update `shippingInfo.logistics.shippingDestination`. This also updates `recipientInfo` to match, unless `recipientInfo` was previously set independently. Updating only `recipientInfo` changes the final recipient's details without changing the shipping destination. For pickup orders, `shippingDestination` holds the pickup location, while `recipientInfo` identifies the final recipient.
    + To modify pricing or line items, use the [Draft Orders API](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/draft-orders/introduction).

    </Note>

    To update an order's payment status, use [Update Payment Status](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/update-payment-status).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v1/orders/{order.id}
    ```

    ## Path Params

    <ParamField path="order.id" type="string" required>

      Order ID.

    </ParamField>

    ## Body Params

    <ParamField body="order" type="Order" required>

      Order to be updated.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Newly created order.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ORDER_IS_PENDING` | Order can't be updated because its status is `PENDING`. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_IS_REJECTED` | Order can't be updated because its status is `REJECTED`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Updated | `wix.ecom.v1.order_updated` | Triggered when an order is updated. |

    To remove a field's value, pass `null`.

    <Note>

    + Removing `buyerInfo` or `contactDetails` results in an error.
    + `archived` can be set to `true` or `false`, but its value can't be removed. For example, to unarchive an order, pass `archived: false`.
    + To change the address an order is shipped to, update `shippingInfo.logistics.shippingDestination`. This also updates `recipientInfo` to match, unless `recipientInfo` was previously set independently. Updating only `recipientInfo` changes the final recipient's details without changing the shipping destination. For pickup orders, `shippingDestination` holds the pickup location, while `recipientInfo` identifies the final recipient.
    + To modify pricing or line items, use the [Draft Orders API](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/draft-orders/introduction).

    </Note>
