This article presents possible use cases and corresponding sample flows that you can support. This can be a helpful jumping off point as you plan your implementation. 

## Turn off guest commenting for a category to avoid spam

If you notice spam from site visitors, you can turn off guest commenting to allow only site members to comment. 

To restrict commenting to members only, call [Update Category](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/update-category) to modify `permissionsSettings.createComment.role` and `permissionsSettings.createReply.role` to `"MEMBER"`.

## Restrict permissions for replies to comments on product pages 

Allow any site visitor to leave a comment on any product page, but restrict replies to these comments to only site administrators.

To restrict these replies, call [Update Category](fallback::https://dev.wix.com/docs/api-reference/crm/community/comments/categories/update-category) and modify `permissionsSettings.createReply.role` to `"ADMIN"`.
