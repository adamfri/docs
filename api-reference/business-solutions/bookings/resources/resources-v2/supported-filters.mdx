<Note>This article applies to the JavaScript SDK only.</Note>

This article covers field support for filtering in
*Query Resources*
([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/resources/query-resources) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/query-resources)),
*Search Resources*
([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/resources/search-resources) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/search-resources)),
and *Count Resources*
([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/resources/count-resources) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/count-resources)).

## Filtering

Specify the `filter` object in the following format:

```json
{
  "filter": {
    "fieldName": {
      "$eq": "value"
    }
  }
}
```

The following table shows field support for filters and sorting for the
`resource` object:

| Field                                                                  | Supported Filters                                                 | Sortable |
|------------------------------------------------------------------------|-------------------------------------------------------------------|----------|
| `id`                                                                   | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`             | Sortable |
| `name`                                                                 | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$isEmpty`                |          |
| `typeId`                                                               | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`, `$isEmpty` | Sortable |
| `locationOptions.availableInAllLocations`                              | `$eq`, `$ne`, `$exists`, `$in`, `$nin`                            | Sortable |
| `locationOptions.specificLocationOptions.availableInBusinessLocations` | `$eq`, `$ne`, `$exists`, `$in`, `$nin`                            | Sortable |
| `locationOptions.specificLocationOptions.businessLocations.locationId` | `$eq`, `$ne`, `$isEmpty`, `$hasAll`, `$hasSome`                   | Sortable |
| `eventsSchedule.scheduleId`                                            | `$eq`, `$ne`, `$exists`, `$in`, `$nin`, `$startsWith`             | Sortable |

## Sorting

Results in *Query Resources*
([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/resources/query-resources) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/query-resources))
and *Search Resources*
([SDK](https://dev.wix.com/docs/sdk/backend-modules/bookings/resources/search-resources) | [REST](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resources-v2/search-resources))
are sorted by the `id` field in ascending order by default.

To sort by a different field, use the `sort` object in the following format:

```json
{
  "sort": [
    {
      "fieldName": "typeId",
      "order": "DESC"
    }
  ]
}
```
