The Programs API allows you to manage your app or site's [programs](##program*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#program). Use this API together with other [Wix Benefit Programs APIs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/introduction).

With the Programs API, you can:
- Provision programs.
- Update the status of programs.
- Retrieve programs.

## Programs in benefit programs
A program is a list of pools with the same beneficiary that are managed together. 

Create a program by [provisioning a program](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/programs/provision-program). This creates a list of pools and enrolls a beneficiary in them.

When you [renew](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/programs/renew-program), [pause](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/programs/pause-program), [resume](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/programs/resume-program), or [end](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/programs/end-program) a program, the action is applied to all the program's pools.

A visitor can be enrolled in multiple programs.

Learn more about benefit programs [components](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-program-components) and [lifecycle](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle).
