    Retrieves a list of up to 100 services, given the provided filtering, paging,
    and sorting.

    ### Defaults

    Search Services has the following default settings, which you can override:
    + Sorted by `createdDate` in ascending order.
    + `paging.limit` set to `100`.
    + `paging.offset` set to `0`.

    ### Filters

    When using filters for dates, you must use
    [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time).

    ## Body Params

    <ParamField body="search" type="CursorSearch" required>

      Search criteria including filter, sort, aggregations, and paging options.

      <Expandable title="search properties">

        <ParamField body="filter" type="object">

          Filter object for narrowing search results. For example, to return only services with specific payment options: `"filter": {"payment.options.online": true, "payment.options.in_person": false}`.

          Learn more about the filter format in the [supported filters article](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/filtering-and-sorting).

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Array of sort objects specifying result order. For example, to sort by creation date in descending order: `"sort": [{"fieldName": "createdDate", "order": "DESC"}]`.

          Learn more about the sort format in the [supported filters article](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/filtering-and-sorting).

          Constraints: `maxItems 10`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="aggregations" type="Aggregation[]">

          Aggregations for grouping data into categories (facets) and providing summaries for each category.
          For example, use aggregations to categorize search results by service type, payment options, or locations.

          Constraints: `maxItems 10`.

          <Expandable title="aggregations properties">

            <ParamField body="name" type="string">

              User-defined name of aggregation. Must be unique and will appear in aggregation results.

            </ParamField>

            <ParamField body="type" type="string">

              Type of aggregation. Client must specify matching aggregation field below.

              **Supported values:**

              - `VALUE` — Calculates the distribution of a specific field's values within a dataset, providing insights into the overall distribution and key statistics of those values.
              - `RANGE` — Calculates the count of the values from the specified field in the dataset that fall within the range of each bucket you define.
              - `SCALAR` — Calculates a single numerical value from a dataset, summarizing the dataset into 1 key metric: `COUNT_DISTINCT`, `SUM`, `AVG`, `MIN`, or `MAX`.
              - `DATE_HISTOGRAM` — Calculates the count of time values from the specified field in the dataset that fall within each time interval you define (hour, day, week, etc.).
              - `NESTED` — Flattened list of aggregations, where each aggregation is nested within previous 1.

            </ParamField>

            <ParamField body="fieldPath" type="string">

              Path to the field to aggregate by in dot notation. For example `name` or `paymentOptions.online`.

              Constraints: `maxLength 200`.

            </ParamField>

            <ParamField body="groupBy" type="GroupByAggregation" deprecated>

              Deprecated, use `nested` instead.

              **Deprecated.** Deprecated, use `nested` instead. Use `nested` instead. Removal: 2025-01-01.

              _Nested structure omitted for brevity — see the `GroupByAggregation` object._

          </Expandable>

        </ParamField>

              Search mode. Defines the search logic for combining multiple terms in the `expression`.

              **Supported values:**

              - `OR` — At least 1 of the search terms must be present.
              - `AND` — All search terms must be present.

            </ParamField>

            <ParamField body="expression" type="string">

              Search term or expression.

            </ParamField>

            <ParamField body="fields" type="string[]">

              Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

              Constraints: `maxLength 200`, `maxItems 10`.

            </ParamField>

            <ParamField body="fuzzy" type="boolean">

For example, `America/New_York`, `UTC`, or `+02:00`.

    ## Response Object

    <ResponseField name="services" type="Service[]">

      Retrieved services that match the search criteria specified in the request.

      Each service includes all standard service information including name, description,
      pricing details, location options, schedule information, and payment configuration.

      See the [Service Object](/api-reference/business-solutions/bookings/services/services-v2/service-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Cursor-based paging metadata for navigating search results.

      Contains the current page's cursor information, whether there are more results available,
      and count details. Use the `next` cursor to retrieve subsequent pages of results.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the current response page.

          This count reflects the actual number of items in the current result set,
          which may be less than the requested limit if fewer items are available.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Navigation cursors for moving between result pages.

          Contains `next` and `prev` cursor tokens for pagination. Use the `next` cursor
          to retrieve subsequent pages and `prev` cursor to go back to previous pages.
          Learn more about cursor paging in the [API Query Language guide](https://dev.wix.com/api/rest/getting-started/api-query-language#getting-started_api-query-language_cursor-paging).

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor token for retrieving the next page of results.

              Use this token in subsequent requests to continue pagination forward.
              Value is `null` when on the last page of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor token for retrieving the previous page of results.

              Use this token to navigate backwards through result pages.
              Value is `null` when on the first page of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates whether additional results are available beyond the current page.

          - `true`: More results exist and can be retrieved using the `next` cursor.
          - `false`: This is the final page of results.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="aggregationData" type="AggregationData">

      Aggregation results based on the aggregations specified in the search request.

      Provides categorized data summaries such as service counts by type, location distribution,
      payment method statistics, or custom aggregations. Available only when aggregations
      are requested in the search criteria.

      <Expandable title="aggregationData properties">

        <ResponseField name="results" type="AggregationResults[]">

          Array of aggregation results, each containing the aggregation metadata and its calculated values for the specified search criteria.

          Constraints: `maxItems 10000`.

          <Expandable title="results properties">

            <ResponseField name="name" type="string">

              User-defined name of aggregation as derived from search request.

              Constraints: `maxLength 100`.

            </ResponseField>

            <ResponseField name="type" type="string">

              Type of aggregation that must match specified kind as derived from search request.

              **Supported values:**

              - `VALUE` — Calculates the distribution of a specific field's values within a dataset, providing insights into the overall distribution and key statistics of those values.
              - `RANGE` — Calculates the count of the values from the specified field in the dataset that fall within the range of each bucket you define.
              - `SCALAR` — Calculates a single numerical value from a dataset, summarizing the dataset into 1 key metric: `COUNT_DISTINCT`, `SUM`, `AVG`, `MIN`, or `MAX`.
              - `DATE_HISTOGRAM` — Calculates the count of time values from the specified field in the dataset that fall within each time interval you define (hour, day, week, etc.).
              - `NESTED` — Flattened list of aggregations, where each aggregation is nested within previous 1.

            </ResponseField>

            <ResponseField name="fieldPath" type="string">

              Path to the field to aggregate by in dot notation. For example `name` or `paymentOptions.online`.

              Constraints: `maxLength 200`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
