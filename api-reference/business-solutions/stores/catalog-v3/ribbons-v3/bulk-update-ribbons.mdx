    Updates multiple ribbons.

    Each time a ribbon is updated, `revision` increments by 1.
    The current `revision` must be passed when updating a ribbon.
    This ensures you're working with the latest ribbon and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.RIBBON_WRITE">Ribbon write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/ribbons/update
    ```

    ## Body Params

    <ParamField body="ribbons" type="MaskedRibbon[]" required>

      Constraints: `minItems 1`, `maxItems 100`.

        </ParamField>

      Whether to return the full updated ribbon entities in the response.

      Default: `false`

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      - `ASSIGNED_PRODUCT_COUNT`

    import { ribbonsV3 } from "@wix/stores";

    const ribbons = [
