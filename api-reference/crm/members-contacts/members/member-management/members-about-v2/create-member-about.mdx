    Creates the "About" section content for a member.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-ABOUT">SCOPE.DC-MEMBERS.MANAGE-ABOUT</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v2/abouts
    ```

    ## Body Params

    <ParamField body="memberAbout" type="MemberAbout" required>

      The "About" section content to create.

      See the [Member About Object](/api-reference/crm/members-contacts/members/member-management/members-about-v2/member-about-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="memberAbout" type="MemberAbout">

      The created "About" section content.

      See the [Member About Object](/api-reference/crm/members-contacts/members/member-management/members-about-v2/member-about-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Member About Created | `wix.members.about.v2.member_about_created` | Triggered when a member's "About" section content is created. |
