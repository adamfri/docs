    <div className="wix-ref">

    Creates a schedule.

    If you want the schedule's events to appear in the
    [Bookings calendar](https://support.wix.com/en/article/wix-bookings-about-the-wix-booking-calendar),
    you must set `appId` to the ID of the Wix Bookings app by providing
    `{"appId": "13d21c63-b5ec-5912-8397-c3a5ddb27a97"}`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.MANAGE">Manage Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/calendar/v3/schedules
    ```

    ## Body Params

    <ParamField body="schedule" type="Schedule" required>

      Schedule to create.

      See the [Schedule Object](/api-reference/business-management/calendar/schedules-v3/schedule-object) for this object's fields.

    </ParamField>

    <ParamField body="idempotencyKey" type="string">

      Idempotency key guaranteeing that you don't create the same schedule more
      than once.

    </ParamField>

    ## Response Object

    <ResponseField name="schedule" type="Schedule">

      Created schedule.

      See the [Schedule Object](/api-reference/business-management/calendar/schedules-v3/schedule-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Schedule Created | `wix.calendar.v3.schedule_created` | Triggered when a schedule is created. |
