Use this JSON schema to define collection schemas and optional initial data for the [data collections app extension](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/data-collections/about-data-collections-extensions).

<ResponseField name="collections" type="Collection[]">

  Data collections automatically added to a site when the app is installed.

  Constraints: `maxItems 100`.

  <Expandable title="collections properties">

    <ResponseField name="idSuffix" type="string">

      Required. Collection ID suffix. The app namespace is automatically prepended in the CMS.
      For example, the full ID for `my-products-1` becomes `@company/app-name/my-products-1`.

      Constraints: `maxLength 256`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Collection's display name as shown in the CMS. For example, `My First Collection`.

    </ResponseField>

    <ResponseField name="displayField" type="string">

      Field whose value the CMS displays to represent the collection item when referenced in a different collection.

    </ResponseField>

    <ResponseField name="fields" type="Field[]">

      Required. Collection's field structure.

      Constraints: `minItems 1`, `maxItems 1000`.

      <Expandable title="fields properties">

        <ResponseField name="key" type="string">

          Required. Unique identifier for the field. For example, `firstName`.

          Constraints: `minLength 1`, `maxLength 1000`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Field's display name when displayed in the CMS. For example, `First Name`.

        </ResponseField>

        <ResponseField name="type" type="string">

          Required. Field's data type.

          Learn more about [data types in Wix Data](https://dev.wix.com/docs/rest/business-solutions/cms/data-types-in-wix-data).

          **Supported values:**

          - `TEXT` — Plain-text string.
          - `NUMBER` — Number.
          - `DATE` — Date string in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format: `YYYY-MM-DD`.
          - `DATETIME` — [JavaScript Date object](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date) (SDK) or an object in the following format: `"someFieldKey": { "$date": "YYYY-MM-DDTHH:mm:ss.sssZ"}`.
          - `IMAGE` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `BOOLEAN` — Boolean `true` or `false` value.
          - `DOCUMENT` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `URL` — URL in one of the following formats: `http://`, `https://`, `ftp://`, `mailto:`, `sms:`, `tel:`.
          - `RICH_TEXT` — [Rich-text](https://dev.wix.com/docs/rest/articles/getting-started/rich-text) string that may contain a subset of HTML tags.
          - `VIDEO` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `ANY` — Any field type.
          - `ARRAY_STRING` — Array of strings.
          - `ARRAY_DOCUMENT` — Array of documents: web or [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URLs.
          - `AUDIO` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `TIME` — Time string in `hh:mm:ss.SSS` format.
          - `LANGUAGE` — Language codes in [ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) format. These may include country codes in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#officially_assigned_code_elements) format.
          - `RICH_CONTENT` — [Rich content](https://dev.wix.com/docs/ricos/getting-started/introduction).
          - `MEDIA_GALLERY` — Array of web or [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URLs.
          - `ADDRESS` — Physical [address object](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-types-in-wix-data#address-object).
          - `REFERENCE` — Reference to another item in another collection. See [Query Referenced Data Items](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-items/query-referenced-data-items) to learn about item references.

          If you select this type, then you must pass the `referencedCollectionId` field as well.
          - `MULTI_REFERENCE` — References to multiple items in another collection. See [Query Referenced Data Items](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-items/query-referenced-data-items) to learn about item references.
          - `OBJECT` — JSON object.
          - `ARRAY` — Array.

        </ResponseField>

        <ResponseField name="encrypted" type="boolean">

          Whether the field is encrypted.

        </ResponseField>

        <ResponseField name="description" type="string">

          Field description.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="dataPermissions" type="DataPermissions">

      Required. Levels of permission for accessing and modifying data, defined by the lowest role needed to perform each action.

      <Expandable title="dataPermissions properties">

        <ResponseField name="itemRead" type="string">

          Required. Access level required to read data items.

          **Supported values:**

          - `ANYONE` — Anyone, including site visitors.
          - `SITE_MEMBER` — Any signed-in user, including site members and collaborators.
          - `SITE_MEMBER_AUTHOR` — Any signed-in user, but site members only have access to their own items.
          - `CMS_EDITOR` — Site collaborator that has a role with CMS access permission.
          - `PRIVILEGED` — CMS administrators and users or roles granted special access.

        </ResponseField>

        <ResponseField name="itemInsert" type="string">

          Required. Access level required to insert data items.

          **Supported values:**

          - `ANYONE` — Anyone, including site visitors.
          - `SITE_MEMBER` — Any signed-in user, including site members and collaborators.
          - `SITE_MEMBER_AUTHOR` — Any signed-in user, but site members only have access to their own items.
          - `CMS_EDITOR` — Site collaborator that has a role with CMS access permission.
          - `PRIVILEGED` — CMS administrators and users or roles granted special access.

        </ResponseField>

        <ResponseField name="itemUpdate" type="string">

          Required. Access level required to update data items.

          **Supported values:**

          - `ANYONE` — Anyone, including site visitors.
          - `SITE_MEMBER` — Any signed-in user, including site members and collaborators.
          - `SITE_MEMBER_AUTHOR` — Any signed-in user, but site members only have access to their own items.
          - `CMS_EDITOR` — Site collaborator that has a role with CMS access permission.
          - `PRIVILEGED` — CMS administrators and users or roles granted special access.

        </ResponseField>

        <ResponseField name="itemRemove" type="string">

          Required. Access level required to remove data items.

          **Supported values:**

          - `ANYONE` — Anyone, including site visitors.
          - `SITE_MEMBER` — Any signed-in user, including site members and collaborators.
          - `SITE_MEMBER_AUTHOR` — Any signed-in user, but site members only have access to their own items.
          - `CMS_EDITOR` — Site collaborator that has a role with CMS access permission.
          - `PRIVILEGED` — CMS administrators and users or roles granted special access.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="indexes" type="Index[]">

      Indexes defined for the collection. An index is a map of a collection's data, organized according to specific fields to increase query speed.

      Constraints: `maxItems 3`.

      <Expandable title="indexes properties">

        <ResponseField name="fields" type="Field[]">

          Fields for which the index is defined.

          Max: 3 fields (for a unique index: 1 field)

          Constraints: `minItems 1`, `maxItems 3`.

          <Expandable title="fields properties">

            <ResponseField name="path" type="string">

              Path of the field to index. For example: `title` or `options.price`.

              Constraints: `minLength 1`, `maxLength 128`.

            </ResponseField>

            <ResponseField name="order" type="string">

              Sort order for the index. Base on how the data is regularly queried.

              Default: `ASC`

              **Supported values:**

              - `ASC`
              - `DESC`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="unique" type="boolean">

          Whether the index enforces uniqueness of values in the field for which it is defined.
          If `true`, the index can have only one field.

          Default: `false`

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="initialData" type="object[]">

      Optional initial data to populate the collection with.

      Constraints: `maxItems 1000`.

    </ResponseField>

  </Expandable>

</ResponseField>
