    Retrieves a list of up to 500 item variants.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/menus/v1/variants
    ```

    ## Query Params

    <ParamField query="variantIds" type="string[]">

      Item variant IDs.

      Constraints: `format GUID`, `maxItems 500`.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      The metadata of the paginated results.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="variants" type="Variant[]">

      The retrieved item variants.

      See the [Item Variant Object](/api-reference/business-solutions/restaurants/menus/items/item-variants/item-variant-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="CursorPagingMetadata">

      The metadata of the paginated results.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Offset that was requested.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>
