    Deletes multiple intake forms in a single request.

    Deleting an intake form also permanently deletes the questionnaire behind it.
    This is irreversible.

    To delete a single intake form, call [Delete Intake Form](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/delete-intake-form).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.CONTENT-COLLECTOR">SCOPE.PARTNERS.CONTENT-COLLECTOR</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/content-collector/v1/bulk/intake-forms/delete
    ```

    ## Body Params

    <ParamField body="intakeFormIds" type="string[]" required>

      IntakeForm ids to be deleted

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>
