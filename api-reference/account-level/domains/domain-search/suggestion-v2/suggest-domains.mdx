    <div className="wix-api-columns">

    <div className="wix-ref">

    Suggests domains that are available for purchase, based on the provided
    `query` input.

    You may use this endpoint to get inspired and then call
    [Check Domain Availability](https://dev.wix.com/api/rest/account-level-apis/domain-search/check-domain-availability)
    to check whether a specific variation of the suggestions is also available
    for purchsase.

    The `tlds` must not include the dot. For example, `com` and not `.com`.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.PUBLIC_API_PERMISSION">DOMAINS.PUBLIC_API_PERMISSION</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/premium/domains/v2/suggest-domains
    ```

    ## Query Params

    <ParamField query="query" type="string" required>

      Input to base your domain suggestions on. May include
      letters, numbers, spaces, dots, and hyphens. Must not include the TLD.

      Min: 1 characters
      Max: 100 characters

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField query="tlds" type="string[]">

      [Top-level domains](https://en.wikipedia.org/wiki/Top-level_domain). Must
      not include the dot. For example, `com`, not `.com`. Not all TLDs can be
      connected to Wix sites. Supported TLDS include `com`, `net`, and `org`.
      Contact the [Wix B2B sales team](mailto:bizdev@wix.com) for more
      information.

      Max: 10 TLDs

      Constraints: `maxLength 63`, `minItems 0`, `maxItems 10`.

    </ParamField>

    <ParamField query="limit" type="integer">

      Number of domain suggestions to return. __Deprecated__: This field will be
      removed on March 1, 2025. Use `paging.limit` instead.

      Min: `1`
      Max: `20`
      Default: `10`

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Cursor paging options.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of domains to return in the results.

          Min: `0`
          Max: `20`

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="maxLength" type="integer">

      Maximum number of characters for the domain name, excluding the TLD.

      Min: `3`
      Max: `63`
      Default: `63`

    </ParamField>

    ## Response Object

    <ResponseField name="suggestions" type="DomainSuggestion[]">

      List of suggested available domains.

      See the [Suggestion Object](/api-reference/account-level/domains/domain-search/suggestion-v2/suggestion-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Metadata about the returned list of suggested domains.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of domains returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
