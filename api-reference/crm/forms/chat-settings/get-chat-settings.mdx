  <Tab title="REST">

    Retrieves a chat settings entity.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORMS.MANAGE-SUBMISSIONS">Manage Submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/forms/ai/v1/chat-settings/{chatSettingsId}
    ```

    ## Path Params

    <ParamField path="chatSettingsId" type="string" required>

      Chat settings ID.

    </ParamField>

    ## Response Object

    <ResponseField name="chatSettings" type="ChatSettings">

      Retrieved chat settings.

      See the [Chat Settings Object](/api-reference/crm/forms/chat-settings/chat-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

  </Tab>
