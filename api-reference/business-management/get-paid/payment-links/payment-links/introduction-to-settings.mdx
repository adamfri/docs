<Note>This article applies to the REST API only.</Note>

The Payment Link Settings API enables you to manage checkout settings for the payment link checkout flow.

The following checkout settings are supported:
- Enable or disable a [site policy agreement checkbox](fallback::https://support.wix.com/en/article/customizing-the-checkout-page#adding-site-policies).
- Enable or disable a "Continue Shopping" button, also known as a ["Continue Browsing" link](fallback::https://support.wix.com/en/article/customizing-links-on-your-cart-page#customizing-the-continue-browsing-links).
