---
title: "Referred Friend Object"
description: "The Referred Friend object in the Wix Referred Friend API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      ID of the referred friend.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Contact ID of the referred friend.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="referringCustomerId" type="string">

      ID of the customer who referred this friend.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the referred friend.

      **Supported values:**

      - `SIGN_UP_COMPLETED` — Initial status when the referred friend joins the site as a member.
      - `ACTIONS_COMPLETED` — Status after the referred friend completes a specific action, such as making a purchase.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the referred friend is updated.
      To prevent conflicting changes, the current revision must be passed when updating the referred friend.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the referred friend was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the referred friend was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "referredFriend": {
          "id": "3857d039-b129-4393-b983-947078b6a007",
          "contactId": "661f5bb3-0723-4aa4-87d7-a21ebd1d0fa3",
          "referringCustomerId": "07a3306c-b311-466e-92dd-c635c4145d1c",
          "status": "ACTIONS_COMPLETED",
          "revision": "2",
          "createdDate": "2024-08-12T08:12:17.813Z",
          "updatedDate": "2024-08-12T08:13:27.708Z"
        }
      }
      ```

    </CodeGroup>
