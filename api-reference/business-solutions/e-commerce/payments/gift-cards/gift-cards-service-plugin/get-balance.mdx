    This method retrieves gift card data from your app.
    Wix calls this method when a customer applies a gift card as a payment method at checkout.

    ## Endpoint

    ```http
    POST /v1/balance
    ```

    ## Body Params

    <ParamField body="code" type="string">

      Gift card code.

      Constraints: `minLength 8`, `maxLength 20`.

    </ParamField>

    <ParamField body="appInstanceId" type="string" deprecated>

      App ID of the Gift Card provider. Deprecated.

      **Deprecated.** App ID of the Gift Card provider. Deprecated. Removal: 2025-07-01. Constraints: `format GUID`.

    </ParamField>

    <ParamField body="locationId" type="string">

      The physical location ID. Can be based on the Locations API or an external provider.

    </ParamField>

    <ParamField body="pin" type="string">

      Gift card PIN.

    </ParamField>

    <ParamField body="extendedFields" type="ExtendedFields">

      [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

      **Developer Preview.**

    ## Response Object

    <ResponseField name="balance" type="number">

      Current balance.

      Constraints: `min 0`, `max 999999999.99`.

    </ResponseField>

    <ResponseField name="currencyCode" type="string">

      Currency code.

      Constraints: `format CURRENCY`.

    </ResponseField>

    <ResponseField name="externalId" type="string">

      External ID in the gift card provider's system.
      Used for integration and tracking across different platforms.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `GIFT_CARD_NOT_FOUND` | Couldn't find the gift card. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_DISABLED` | Gift card is disabled. |
    | `428` | `FAILED_PRECONDITION` | `GIFT_CARD_EXPIRED` | Gift card has expired. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_CURRENCY` | Gift card currency is missing. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
