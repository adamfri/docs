    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/bulk/items/create
    ```

    ## Body Params

    <ParamField body="items" type="Item[]" required>

      Items to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Item Object](/api-reference/business-solutions/benefit-programs/items/item-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full item entities.

      Default: `false`

    </ParamField>
