---
title: "Function Object"
description: "A function is the main entity in the Wix Functions ecosystem."
icon: "cube"
---

A function is the main entity in the Wix Functions ecosystem. All other entities are used to create functions or to define their behavior. Learn more about [Functions](https://support.wix.com/en/wix-functions).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Function ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the function is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the function.

      Ignored when creating a function.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the function was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the function was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="functionExtensionId" type="string">

      ID of the function type that defines when and how the function runs. This is the function type that the function is based on.

    </ResponseField>

    <ResponseField name="functionName" type="string">

      Display name for the function in the dashboard's function builder.

    </ResponseField>

    <ResponseField name="activationStatus" type="string">

      Activation status.

      **Read-only.**

      **Supported values:**

      - `ACTIVE` — Function is active and runs when triggered.
      - `INACTIVE` — Function is inactive and doesn't run when triggered.
      - `DRAFT` — Function is saved but has never been activated.

    </ResponseField>

    <ResponseField name="appId" type="string">

      ID of the Wix app that defines the function type that the function is based on.

    </ResponseField>

    <ResponseField name="functionExtensionName" type="string">

      Display name of the function type.

    </ResponseField>

    <ResponseField name="functionTemplateExtensionId" type="string">

      ID of the function template used to create this function.

    </ResponseField>

    <ResponseField name="formTemplateExtensionId" type="string">

      ID of the form template used to create this function. Included if the function was created using the [Builderless Productions](https://dev.wix.com/docs/api-reference/business-management/functions/builderless-productions/introduction) API.

    </ResponseField>

    <ResponseField name="hasUnpublishedChanges" type="boolean">

      Whether the function has changes that were made since it was last activated.

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags assigned to the function for organization and filtering.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, typically restricted from site members and visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="publicTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="publicTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "3099fa19-a7cc-4905-990f-480181918459",
        "revision": "1",
        "createdDate": "2024-01-01T01:01:01.1Z",
        "updatedDate": "2024-01-01T01:01:01.1Z",
        "functionExtensionId": "d1a528f3-ee9b-4a58-82af-7c61ca127e3a",
        "functionName": "Frequent buyer perk",
        "activationStatus": "DRAFT",
        "appId": "553c79f3-5625-4f38-b14b-ef7c0d1e87df",
        "functionExtensionName": "Loyalty rewards",
        "externalIds": []
      }
      ```

    </CodeGroup>
