@package_metadata:@wix/portfolio

To use the PortfolioSettings API, install the `@wix/portfolio` package.

#### Install the package

Follow the installation instructions for your development environment.

| Development environment | Installation method |
|--|--|
| Wix sites (editor or IDE) | Use the [package manager](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-in-the-editor). |
| Wix sites (local IDE) | Run `wix install @wix/portfolio` using the [Wix CLI](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-with-the-wix-cli).|
| Blocks apps | Use the same installation method as Wix sites. |
| CLI and self-hosted apps | Run `npm install @wix/portfolio` or `yarn add @wix/portfolio`. |
| Headless sites and apps | Run `npm install @wix/portfolio` or `yarn add @wix/portfolio`. |

#### Import the package

To import the package in your code:

```js
import { portfolioSettings } from '@wix/portfolio'
```
