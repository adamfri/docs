---
title: "Program Object"
description: "A loyalty program allows sites to maintain customer reward accounts."
icon: "cube"
---

A loyalty program allows sites to maintain customer reward accounts. Wix users can create a
loyalty program to increase customer retention. Read more about the [loyalty program](https://support.wix.com/en/article/wix-loyalty-program-an-overview).

<Tabs>

  <Tab title="REST">

    <ResponseField name="name" type="string">

      Program name.

    </ResponseField>

    <ResponseField name="pointDefinition" type="PointDefinition">

      Details about the program's collectible unit.

      <Expandable title="pointDefinition properties">

        <ResponseField name="customName" type="string">

          Display name for the program's collectible unit.

          It's recommended to use a plural, for example `"Stars"`.

          In contrast to a custom name, the default `"Points"` name is translated and adjusted to singular based on circumstances.

          Default: `"Points"`.

        </ResponseField>

        <ResponseField name="icon" type="Image">

          Details about the points icon.

          <Expandable title="icon properties">

            <ResponseField name="id" type="string">

              WixMedia image ID.

            </ResponseField>

            <ResponseField name="url" type="string">

              Image URL.

            </ResponseField>

            <ResponseField name="height" type="integer">

              Original image height.

              **Read-only.**

            </ResponseField>

            <ResponseField name="width" type="integer">

              Original image width.

              **Read-only.**

            </ResponseField>

            <ResponseField name="altText" type="string">

              Image alt text.

            </ResponseField>

            <ResponseField name="filename" type="string">

              Image filename.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Program status.
      Customers can only earn or redeem points while the program is `"ACTIVE"`.

      Default: `"DRAFT"`

      **Read-only.**

      **Supported values:**

      - `DRAFT` — Program is in draft mode. Customers can't earn or redeem points.
      - `ACTIVE` — Program is active. Customers can earn and redeem points.
      - `PAUSED` — Program is paused. Customers can't earn or redeem points while the program is paused.

      Set the program to `"ACTIVE"` to resume earning and redeeming points.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the program was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the program was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="pointsExpiration" type="PointsExpiration">

      Configuration for the points expiration feature.

      <Expandable title="pointsExpiration properties">

        <ResponseField name="status" type="string">

          Status of the points expiration feature.

          **Read-only.**

          **Supported values:**

          - `DISABLED` — Points expiration feature is disabled.
          - `ENABLED` — Points expiration feature is enabled.

        </ResponseField>

        <ResponseField name="monthsOfInactivity" type="integer">

          How many months a member should be inactive to lose the collected points.

          Constraints: `min 1`, `max 12`.

        </ResponseField>

        <ResponseField name="expiringPointsPercentage" type="integer">

          Percentage of points that a member loses after being inactive.

          Constraints: `min 1`, `max 100`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="premiumFeatures" type="PremiumFeatures">

      Information about the available program premium features.

      **Read-only.**

      <Expandable title="premiumFeatures properties">

        <ResponseField name="loyaltyProgram" type="boolean">

          Whether there are any loyalty program premium features.

          **Read-only.**

        </ResponseField>

        <ResponseField name="tiers" type="boolean">

          Whether this loyalty program includes tiers.

          **Read-only.**

        </ResponseField>

        <ResponseField name="pointsExpiration" type="boolean">

          Whether this loyalty program includes point expiration.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="assignPointsForOldOrders" type="boolean">

      Whether to assign points for orders that were created more than 30 days before they were
      updated or paid.

      By default (`false`), points are not assigned to such orders. This guards against
      retroactively awarding points for orders that predate an earning rule. Enable this
      (`true`) for sites where customers legitimately order far in advance and pay later
      (for example, bookings paid on the day of the session or manual payments).

      Default: `false`

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "loyaltyProgram": {
            "name": "Star Loyalty Program",
            "pointDefinition": {
                "customName": "Stars",
                "icon": {
                    "id": "",
                    "url": "shapes/58819f398c36404f8017aa8faa2240b4.svg",
                    "height": 0,
                    "width": 0
                }
            },
            "status": "ACTIVE",
            "pointsExpiration": {
                "status": "DISABLED",
                "monthsOfInactivity": 3,
                "expiringPointsPercentage": 100
            },
            "premiumFeatures": {
                "loyaltyProgram": true,
                "tiers": true,
                "pointsExpiration": true
            },
            "createdDate": "2022-05-22T08:18:32.186Z",
            "updatedDate": "2022-06-07T08:40:47.426Z"
        }
      }
      ```

    </CodeGroup>
