    <div className="wix-ref">

    Generates a URL for streaming a specific video file in the Media Manager. <br />

    To stream different assets of the file, specify the `assetKeys` parameter which generates a video streaming URL for each asset. If no assetKey is specified, it defaults to `src`, which generates one video streaming URL in the original file's format and quality.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEDIA.READ-MEDIAMANAGER">Read Media Manager</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-media/v1/files/generate-video-stream-url
    ```

    ## Body Params

    <ParamField body="fileId" type="string" required>

      File ID.

      You can also specify the file's Wix media URL. For example, `wix:image://v1/0abec0_b291a9349a0b4da59067f76287e386fb~mv2.jpg/leon.jpg#originWidth=3024&originHeight=4032`.
      Learn more [about the file ID parameter](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/file-id).

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField body="format" type="string">

      Video stream format.

      **Supported values:**

      - `HLS`
      - `DASH`

    </ParamField>

    <ParamField body="expirationInMinutes" type="integer">

      Number of minutes until the streaming URL expires. &lt;br />

      Applies only to private (secure) videos. Public videos are streamed from non-expiring URLs, so this value is ignored for them. &lt;br />
      The streaming token is re-validated on every chunk that is played, so set this longer than the video's play duration. &lt;br />
      Default: `1440` (24 hours).

    </ParamField>

    ## Response Object

    <ResponseField name="downloadUrl" type="DownloadUrl">

      URL for streaming a specific file in the Media Manager.

      <Expandable title="downloadUrl properties">

        <ResponseField name="url" type="string">

          The file download URL.

          Constraints: `format WEB_URL`.

        </ResponseField>

        <ResponseField name="assetKey" type="string">

          Key for downloading a different asset (format and quality) of a file.
          Default: `src`, key representing the original file's format and quality.

          Constraints: `maxLength 100`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
