    Creates a tag.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.MANAGE-TAGS">Manage Tags</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/tags/v1/tags
    ```

    ## Body Params

    <ParamField body="tag" type="Tag" required>

      The tag to be created.

      See the [Tag Object](/api-reference/business-management/tags/tag-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="tag" type="Tag">

      The created tag.

      See the [Tag Object](/api-reference/business-management/tags/tag-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `FQDN_NOT_FOUND` | Couldn't find the FQDN. |
    | `409` | `ALREADY_EXISTS` | `TAG_NAME_ALREADY_EXISTS` | There is already a tag with this name. |
    | `429` | `RESOURCE_EXHAUSTED` | `TAGS_REACHED_LIMIT` | Number of tags exceeds the server's limit. |
    | `500` | `INTERNAL` | `CREATE_ID_EXHAUSTED_RETRY_ATTEMPTS` | Failed to generate a unique tag ID after multiple attempts. |
    | `400` | `INVALID_ARGUMENT` | `EXPOSURE_NOT_SUPPORTED` | The specified `exposure` value isn't supported for this FQDN. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
