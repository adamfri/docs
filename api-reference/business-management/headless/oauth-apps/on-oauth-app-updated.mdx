Triggered when an OAuth app is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.headless.v1.o_auth_app_updated` |
| Package | `@wix/auth-management` |
| Permissions | `Headless Manage`, `Manage OAuth Apps`, `Read OAuth Apps` |

## Examples

<CodeGroup>

  ```javascript onOAuthAppUpdated
  import { oAuthApps } from '@wix/auth-management';

  oAuthApps.onOAuthAppUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onOAuthAppUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { oAuthApps } from '@wix/auth-management';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        oAuthApps,
      },
  });

  wixClient.oAuthApps.onOAuthAppUpdated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
