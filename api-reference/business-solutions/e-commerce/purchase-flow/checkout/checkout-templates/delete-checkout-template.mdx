    <div className="wix-ref">

    Deletes a checkout template.

    If a checkout template is deleted and a customer attempts to create a checkout with that `checkoutTemplateId` then
    the customer will be redirected to the domain site.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/ecom/v1/checkout-templates/{checkoutTemplateId}
    ```

    ## Path Params

    <ParamField path="checkoutTemplateId" type="string" required>

      ID of the checkout template to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteCheckoutTemplateResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Template Deleted | `wix.ecom.v1.checkout_template_deleted` | Triggered when a checkout template is deleted. |

    </div>
