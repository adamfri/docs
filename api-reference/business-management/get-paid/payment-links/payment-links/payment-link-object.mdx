---
title: "Payment Link Object"
description: "Payment links are unique URLs that Wix users can send to customers, allowing them to make convenient online payments for goods and services."

---

Payment links are unique URLs that Wix users can send to customers, allowing them to make convenient online payments for goods and services.
Learn more about [payment links](https://support.wix.com/en/article/wix-pay-links-creating-and-managing-pay-links).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Payment link ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the payment link is updated. To prevent conflicting changes, the existing revision must be specified when updating a payment link.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the payment link was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the payment link was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="title" type="string">

      Title of the payment link. Non-visible characters will be trimmed upon creation.

      Constraints: `minLength 1`, `maxLength 200`.

    </ResponseField>

    <ResponseField name="description" type="string">

      Description of the payment link.

    </ResponseField>

    <ResponseField name="currency" type="string">

      Currency code in [ISO-4217 alphabetic](https://www.iso.org/iso-4217-currency-codes.html) format.

      Constraints: `format CURRENCY`.

    </ResponseField>

    <ResponseField name="recipients" type="Recipient[]">

      Recipients of the payment link.

      Constraints: `maxItems 50`.

      <Expandable title="recipients properties">

        <ResponseField name="contactId" type="string">

          Recipient contact ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="lastSendDate" type="datetime">

          Date of last attempt to send payment link to the recipient.

          **Read-only.**

        </ResponseField>

        <ResponseField name="sendSuccessful" type="boolean">

          Status of the last attempt to send payment link to the recipient.

          **Read-only.**

        </ResponseField>

        <ResponseField name="sendMethods" type="string[]">

          Methods that should be used to send the payment link to the recipient.

          Constraints: `maxItems 1`.

          **Supported values:**

          - `EMAIL_METHOD` — Email method.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="totalReceived" type="TotalReceived">

      Total payments received.

      **Read-only.**

      <Expandable title="totalReceived properties">

        <ResponseField name="amount" type="string">

          Amount collected from all payments processed through this payment link.

          **Read-only.** Constraints: `format DECIMAL_VALUE`, `>= 0`, `<= 1000000000000000`.

        </ResponseField>

        <ResponseField name="paymentCount" type="integer">

          Number of payments received.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Payment link status.

      **Read-only.**

      **Supported values:**

      - `ACTIVE` — Payment link is active and can receive new payments.
      - `INACTIVE` — Payment link is disabled and can't receive new payments.
      - `PAID` — Payment link has reached it's payment limit and can't accept more payments.
      - `EXPIRED` — Payment link is expired and no longer valid for payments.

    </ResponseField>

    <ResponseField name="links" type="Links">

      Links generated for payment link, to enable sharing.

      **Read-only.**

      <Expandable title="links properties">

        <ResponseField name="url" type="PageUrlV2">

          Payment link URL.

          <Expandable title="url properties">

            <ResponseField name="relativePath" type="string">

              Relative path of the URL. E.g. `/mylink/123`

            </ResponseField>

            <ResponseField name="url" type="string">

              URL.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="expirationDate" type="datetime">

      Payment link expiration date.

    </ResponseField>

    <ResponseField name="paymentsLimit" type="integer">

      Limit on the total number of payments that can be processed using this payment link.

    </ResponseField>

    <ResponseField name="availableActions" type="string[]">

      Available actions for this payment link.

      **Read-only.**

      **Supported values:**

      - `DELETE` — Payment link has no associated payments, and can be deleted.
      - `DEACTIVATE` — Payment link is currently active, and can be deactivated.
      - `ACTIVATE` — Payment link is currently inactive, and can be reactivated.
      - `INITIATE_PAYMENT` — Payment limit has not been reached, and payment can be initiated.
      - `SEND` — Payment link can be sent to potential buyers.

    </ResponseField>

    <ResponseField name="source" type="Source">

      Payment link source.

      <Expandable title="source properties">

        <ResponseField name="appId" type="string">

          App ID.

        </ResponseField>

        <ResponseField name="entityId" type="string">

          ID of the original source entity. For example, a booking ID if payment link is created for a booking.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="displayData" type="DisplayData">

      Display data for payment link checkout.

      <Expandable title="displayData properties">

        <ResponseField name="primaryColor" type="string">

          Primary color to be used when displaying payment link.

        </ResponseField>

        <ResponseField name="secondaryColor" type="string">

          Secondary color to be used when displaying payment link.

        </ResponseField>

        <ResponseField name="ctaText" type="string">

          Text to be used as CTA for payment link. For example, "Pay", "Donate".
          CTA text will be trimmed upon payment link creation. Minimum length validation applies to trimmed CTA text.

        </ResponseField>

        <ResponseField name="image" type="Image">

          Image to be used when displaying payment link.

          <Expandable title="image properties">

            <ResponseField name="id" type="string">

              WixMedia image ID.

            </ResponseField>

            <ResponseField name="url" type="string">

              Image URL.

              Constraints: `format WEB_URL`.

            </ResponseField>

            <ResponseField name="height" type="integer">

              Original image height.

              **Read-only.**

            </ResponseField>

            <ResponseField name="width" type="integer">

              Original image width.

              **Read-only.**

            </ResponseField>

            <ResponseField name="altText" type="string">

              Image alt text.

            </ResponseField>

            <ResponseField name="filename" type="string">

              Image filename.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="lastPaymentDate" type="datetime">

      Last payment date.

      **Read-only.**

    </ResponseField>

    <ResponseField name="note" type="Note">

      Free text note attached to the payment link.

      <Expandable title="note properties">

        <ResponseField name="updatedDate" type="datetime">

          Date and time the note was updated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="text" type="string">

          Note text.

          Constraints: `minLength 0`, `maxLength 300`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="type" type="string">

      Payment link type. Must be passed in accordance with either ecomPaymentLink or ecomOrderPaymentLink.
      If ecomPaymentLink is selected, then payment link type must be 'ECOM', if ecomOrderPaymentLink is selected, then payment link type must be 'ECOM_ORDER'.

      **Supported values:**

      - `UNKNOWN_PAYMENT_LINK_TYPE` — Unknown payment link type.
      - `ECOM` — Payment link for payment for custom or catalog line items.
      - `ECOM_ORDER` — Payment link for payment of an existing Wix eCommerce order.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the payment link.

      [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 25`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 25`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
