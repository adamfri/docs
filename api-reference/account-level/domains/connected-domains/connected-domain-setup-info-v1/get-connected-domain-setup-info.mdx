<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves information for the initial setup of a connected domain.

    You must pass the relevant Wix account ID in the header of the call.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.READ_CONNECTED_DOMAINS">DOMAINS.READ_CONNECTED_DOMAINS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/domains/v1/connected-domain-setup-info/{connectedDomainId}
    ```

    ## Path Params

    <ParamField path="connectedDomainId" type="string" required>

      ID of the connected domain to retrieve setup information for.
      Identical to the domain name including TLD.

    </ParamField>

    ## Response Object

    <ResponseField name="connectedDomainSetupInfo" type="ConnectedDomainSetupInfo">

      Retrieved setup information.

      See the [Connected Domain Setup Info Object](/api-reference/account-level/domains/connected-domains/connected-domain-setup-info-v1/connected-domain-setup-info-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
