    <div className="wix-ref">

    Redeems a specified benefit.

    Calling this method records redemption of the benefit and adjusts the pool's associated balance. You still need to handle providing the beneficiary with the item.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/benefits/redeem
    ```

    ## Body Params

    <ParamField body="poolId" type="string" required>

      ID of the pool that contains the benefit to redeem.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="itemReference" type="ItemReference" required>

      Information about the item to redeem.

      <Expandable title="itemReference properties">

        <ParamField body="externalId" type="string" required>

          External ID of the item.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="category" type="string">

          Item category.

          Constraints: `maxLength 20`.

        </ParamField>

        <ParamField body="providerAppId" type="string" required>

          ID of the app providing the item.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="benefitKey" type="string" required>

      Key of the benefit to redeem.

      Constraints: `maxLength 64`.

    </ParamField>

    <ParamField body="count" type="integer">

      Amount of items to redeem.

      Constraints: `min 1`.

    </ParamField>

    <ParamField body="targetDate" type="datetime">

      Date that the item will be provided to the beneficiary.

      The pool's associated balance will update immediately. This parameter should be used to manage the logistics of providing the item.

    </ParamField>

    <ParamField body="idempotencyKey" type="string" required>

      Unique identifier, generated by the client.
      Used to recognize repeated attempts to make the same request.

      Constraints: `maxLength 200`.

    </ParamField>

    <ParamField body="additionalData" type="object">

      Additional information.

    </ParamField>

    <ParamField body="beneficiary" type="IdentificationData">

      Beneficiary of the pool containing the benefit to redeem.

      <Expandable title="One of the following">

        <ParamField body="id" type="id">

          id

          <Expandable title="id properties">

            <ParamField body="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="namespace" type="string" required>

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      Constraints: `minLength 1`, `maxLength 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="transactionId" type="string">

      ID of the transaction recording the associated change in balance.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `NOT_ENOUGH_BALANCE` | Pool's balance has insufficient credits to redeem the benefit. |
    | `428` | `FAILED_PRECONDITION` | `POLICY_EXPRESSION_EVALUATED_TO_FALSE` | Policy expression is false. |
    | `428` | `FAILED_PRECONDITION` | `POOL_NOT_ACTIVE` | Benefit's pool isn't active. |
    | `404` | `NOT_FOUND` | `POOL_NOT_FOUND` | Couldn't find the pool. |
    | `409` | `ALREADY_EXISTS` | `BENEFIT_ALREADY_REDEEMED` | Benefit was already redeemed with the specified idempotency key. This is likely a duplicate call. |
    | `404` | `NOT_FOUND` | `BENEFIT_NOT_FOUND` | There is no benefit with the specified data. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
