The Ricos Documents API provides methods for working with Ricos documents, Wix's standardized format for rich content. Learn more about [Rich Content](fallback::https://dev.wix.com/docs/rest/articles/get-started/about-rich-content) and [Ricos documents](fallback::https://dev.wix.com/docs/ricos/getting-started/introduction).

With the Ricos Documents API, you can:
- Validate Ricos documents.
- Convert content from HTML, Markdown, or plain text to Ricos document format.
- Convert Ricos documents to HTML, Markdown, or plain text.

## Use cases

- [Convert site visitor input between Ricos document and Markdown formats](fallback::https://dev.wix.com/docs/rest/assets/rich-content/ricos-documents/sample-flows#convert-site-visitor-input-between-ricos-document-and-markdown-formats)

## Terminology

- **Ricos document:** An object that defines rich content.
- **Plugin:** Allows rich content viewers to display specific content types. Learn more about [plugins](fallback::https://dev.wix.com/docs/ricos/getting-started/introduction#plugins).
