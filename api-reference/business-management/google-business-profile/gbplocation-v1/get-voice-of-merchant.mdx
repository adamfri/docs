    Retrieves whether Google considers a location's profile trusted and live.

    Google calls this Voice of Merchant. A location can be verified and still
    not have it, so check this before telling a site owner their profile is
    live.

    `state` says what's needed next, such as waiting, verifying, complying with
    Google's guidelines, or resolving who owns the listing.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/locations/{locationId}/voice-of-merchant
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID. This is Google's location identifier.

    </ParamField>

    ## Response Object

    <ResponseField name="voiceOfMerchant" type="VoiceOfMerchantState">

      The Voice-of-Merchant state as reported by Google.

      <Expandable title="voiceOfMerchant properties">

        <ResponseField name="hasVoiceOfMerchant" type="boolean">

          Whether the location is ready to be acted on by the merchant.

        </ResponseField>

        <ResponseField name="hasBusinessAuthority" type="boolean">

          Whether the merchant has business-authority (claim) for the location.

        </ResponseField>

        <ResponseField name="state" type="string">

          The action (if any) Google recommends the merchant take to obtain or
          restore voice-of-merchant. `STATE_NONE` means no action is required at
          this time.

          **Supported values:**

          - `WAIT_FOR_VOICE_OF_MERCHANT` — Google is still assessing the location. Nothing to do but wait.
          - `RESOLVE_OWNERSHIP_CONFLICT` — Someone else claims this location. The site owner has to resolve it with
          Google directly.
          - `COMPLY_WITH_GUIDELINES` — The location needs to comply with Google's guidelines. Check
          `recommendationReason` for what Google flagged.
          - `VERIFY` — The location needs to be verified. Check `hasPendingVerification` to see
          whether one is already under way before starting another.

        </ResponseField>

        <ResponseField name="recommendationReason" type="string">

          Set when `state == COMPLY_WITH_GUIDELINES`: why Google is asking the
          merchant to review the guidelines.

          **Supported values:**

          - `BUSINESS_LOCATION_SUSPENDED` — Listing has been suspended for guideline violations.
          - `BUSINESS_LOCATION_DISABLED` — Listing has been disabled.

        </ResponseField>

        <ResponseField name="hasPendingVerification" type="boolean">

          Set when `state == VERIFY`: true when a Verification resource is already
          in flight for the location (StartVerification was already called and the
          PIN is in transit).

        </ResponseField>

      </Expandable>

    </ResponseField>
