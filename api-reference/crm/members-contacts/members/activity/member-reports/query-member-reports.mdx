    Retrieves a list of member reports, given the provided paging, filtering, and sorting.

    Query Member Reports runs with these defaults, which you can override:
    - `createdDate` is sorted in `ASC` order
    - `paging.limit` is `100`
    - `paging.offset` is `0`

    To learn about working with _Query_ endpoints, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language), [Sorting and Paging](https://dev.wix.com/docs/rest/articles/getting-started/sorting-and-paging), and [Field Projection](https://dev.wix.com/docs/rest/articles/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `reportedMemberId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `reportingMemberId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `reason` | `$exists` | None |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | None |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
