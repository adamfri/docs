    <div className="wix-ref">

    Retrieves multiple info sections by ID or `uniqueName`, or creates multiple info sections if those with the passed `uniqueName` don't exist.

    <Note>

    If an info section with the passed `uniqueName` doesn't exist, the `uniqueName` and `title` fields are required to create a new info section.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INFO_SECTION_WRITE">Info section write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/info-sections/get-or-create
    ```

    ## Body Params

    <ParamField body="infoSections" type="InfoSectionForGetOrCreate[]">

      Info sections to retrieve or create.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="infoSections properties">

        <ParamField body="id" type="string">

          Info section ID.
          Pass an ID to retrieve an existing info section.

        </ParamField>

        <ParamField body="uniqueName" type="string">

          Info section unique name.

          > **Note:**
          > + Pass the `uniqueName` of an existing info section to return it.
          > + If no such info section exists - pass `uniqueName` and `title` to create an info section.

        </ParamField>

        <ParamField body="title" type="string">

          Info section title.

          Required when passing `uniqueName` to create a new info section.

        </ParamField>

        <ParamField body="description" type="RichContent">

          Info section description using rich content.

          Learn more about [Working with Rich Content](https://dev.wix.com/docs/go-headless/tutorials-templates/other-tutorials/working-with-rich-content).

          <Expandable title="description properties">

            <ParamField body="nodes" type="Node[]">

              Node objects representing a rich content document.

              _Nested structure omitted for brevity — see the `Node[]` object._

            </ParamField>

            <ParamField body="metadata" type="Metadata">

              Object metadata.

              _Nested structure omitted for brevity — see the `Metadata` object._

            </ParamField>

            <ParamField body="documentStyle" type="DocumentStyle">

              Global styling for header, paragraph, block quote, and code block nodes in the object.

              _Nested structure omitted for brevity — see the `DocumentStyle` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="plainDescription" type="string">

          Info section description in HTML.

          When provided on create/update, this string must be a valid HTML. It will then be converted to rich content.
          `plainDescription` is ignored when value is also passed to the `description` field.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT`

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INFO_SECTIONS_LIMIT_EXCEEDED` | Number of info sections exceeded the limit of 200. |
    | `400` | `INVALID_ARGUMENT` | `ONLY_SPACES_STRING_ERROR` | `uniqueName` contains only spaces. Provide a valid `uniqueName`. |
