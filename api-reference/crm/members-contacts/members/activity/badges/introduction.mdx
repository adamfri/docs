<Warning>

__Deprecation Notice:__

The Badges API has been replaced with the [Badges V4 API](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/activity/badges-v4/introduction) and will be removed on April 18, 2026.

</Warning>

The Badges API enables Wix users to manage badges and assign them to site members. Assign badges to site members to help them stand out from other members. Badges can also grant access to restricted pages reserved for specific members.

With the Badges API, you can:
+ Create, update, and delete badges.
+ Retrieve a site's badges or retrieve all the badges assigned to a specific member.
+ Assign and unassign badges to site members.

For an overview of badges, see [Creating and Managing Member Badges](fallback::https://support.wix.com/en/article/site-members-creating-and-managing-member-badges).

## Before you begin
Badge permissions can't be set with the Badges API. Wix users can [set badge permissions](fallback::https://support.wix.com/en/article/site-members-creating-and-managing-member-badges?tabs=Dashboard-0#managing-member-badges) in the Site Members area of the dashboard.

## Use cases
+ [Assign badges for the most active members](##assign-badges-for-the-most-active-members*fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/badges/use-cases#assign-badges-for-the-most-active-members)

## Terminology

 - **Badge:** A visible label that is displayed on a site member's profile. A badge has a required name, along with an optional icon and background color.
