    Creates a partner profile.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/profile/v1/partner-profiles
    ```

    ## Body Params

    <ParamField body="partnerProfile" type="PartnerProfile" required>

      Partner profile to create.

      See the [Partner Profile Object](/api-reference/account-level/studio-workspace/partner-profile-v1/partner-profile-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="partnerProfile" type="PartnerProfile">

      Created partner profile.

      See the [Partner Profile Object](/api-reference/account-level/studio-workspace/partner-profile-v1/partner-profile-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
