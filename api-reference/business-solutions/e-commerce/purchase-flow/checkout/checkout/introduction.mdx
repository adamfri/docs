<Warning>

__Deprecation Notice:__

**The eCommerce Checkout API** has been replaced with [Cart V2](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/introduction) and will be removed on February 1, 2027. Cart V2 unifies cart and checkout into a single Cart entity, so there's no separate checkout step.

For migration guidance, see the [Cart V2 Migration Guide](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/purchase-flow/cart-v2/migration-guide).

</Warning>

The checkout is the second stage of the eCommerce purchase flow: cart; checkout; order.

A checkout holds information about items to be purchased, price and tax summaries, shipping and billing info, any applied discounts, and more.

The eCommerce Checkout API currently provides functionality for [retrieving](fallback::https://github.com/wix-private/ecom/blob/a48b9078773f2d26bd1a1a8de1a00768d2eca111/server/wix-ecommerce-server/wix-ecommerce-platform-checkout/proto/appendices/docs/checkout/get-checkout*original::/checkout/get-checkout) checkouts and listening to events when a checkout is [created](fallback::https://github.com/wix-private/ecom/blob/a48b9078773f2d26bd1a1a8de1a00768d2eca111/server/wix-ecommerce-server/wix-ecommerce-platform-checkout/proto/appendices/docs/checkout/checkout-created*original::/checkout/checkout-created), [updated](fallback::https://github.com/wix-private/ecom/blob/a48b9078773f2d26bd1a1a8de1a00768d2eca111/server/wix-ecommerce-server/wix-ecommerce-platform-checkout/proto/appendices/docs/checkout/checkout-updated*original::/checkout/checkout-updated), and [marked as completed](fallback::https://github.com/wix-private/ecom/blob/a48b9078773f2d26bd1a1a8de1a00768d2eca111/server/wix-ecommerce-server/wix-ecommerce-platform-checkout/proto/appendices/docs/checkout/checkout-marked-as-completed*original::/checkout/checkout-marked-as-completed).
