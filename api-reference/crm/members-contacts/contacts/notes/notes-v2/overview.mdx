A note contains textual information associated with a contact.

## SDK package

```bash
npm install @wix/crm
```

Import the `notes` namespace from `@wix/crm`.

## Methods

  <Card title="Get Note" href="/api-reference/crm/members-contacts/contacts/notes/notes-v2/get-note">
