    Retrieves a list of rules, given the provided paging, filtering, and sorting.

    Query Rules runs with these defaults, which you can override:
    - `cursorPaging.limit` is `50`

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/pagination),
    and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `locationId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `appId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.
