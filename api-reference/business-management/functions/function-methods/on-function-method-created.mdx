Triggered when a function method is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.functions.v1.function_method_created` |
| Package | `@wix/functions` |
| Permissions | `Manage Stores`, `Manage Functions`, `Manage Restaurants - all permissions`, `Set Up Automations` |
