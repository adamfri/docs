    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates the business locations within all a contributor's role assignments for the specified site, overriding any existing locations.

    Replaces all existing location assignments for the contributor's roles with the locations specified in `newLocations`. Get location IDs from the [Locations API](https://dev.wix.com/docs/api-reference/business-management/locations/introduction).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/roles-management/contributor/change/locations
    ```

    ## Body Params

    <ParamField body="accountId" type="string" required>

      Contributor's account ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="newLocations" type="string[]" required>

      Location IDs to assign to the contributor's role assignments on the site. Replaces all existing location assignments. Get location IDs from the [Locations API](https://dev.wix.com/docs/api-reference/business-management/locations/introduction).

      Constraints: `format GUID`, `maxItems 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="newAssignedLocations" type="SiteLocationAssignment[]">

      Locations assigned to the contributor's role assignments on the site.

      Constraints: `maxItems 20`.

      <Expandable title="newAssignedLocations properties">

        <ResponseField name="locationIds" type="string[]">

          Location IDs assigned to the contributor's role assignments.

          Constraints: `format GUID`, `maxItems 100`.

        </ResponseField>

        <ResponseField name="assignmentIds" type="string[]">

          Assignment IDs mapping the locations to the contributor's role assignments on the site.

          **Read-only.** Constraints: `maxLength 20`, `maxItems 999`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
