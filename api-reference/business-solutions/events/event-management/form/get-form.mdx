    Retrieves an event registration form.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-EVENTS">Read Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/events/{eventId}/form
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID to which the form belongs.

    </ParamField>

    ## Response Object

    <ResponseField name="form" type="Form">

      Event form.
      Form is visible to site visitors.

      See the [Form Object](/api-reference/business-solutions/events/event-management/form/form-object) for this object's fields.

    </ResponseField>

    <ResponseField name="draftForm" type="Form">

      Deprecated, currently returns the same value as the form field.

      See the [Form Object](/api-reference/business-solutions/events/event-management/form/form-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
