Triggered when a contact is deleted.

If a contact is deleted as part of a merge, the `originatedFrom` property is sent as `merge`.
Otherwise, `originatedFrom` isn't returned.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.contacts.v4.contact_deleted` |
| Package | `@wix/crm` |
| Permissions | `Manage Stores`, `Manage Events`, `Manage Challenges`, `Read Contacts`, `Read Members and Contacts - all read permissions`, `Manage Restaurants - all permissions`, `Manage Contacts`, `Set Up Automations`, `Manage Members and Contacts - all permissions` |
