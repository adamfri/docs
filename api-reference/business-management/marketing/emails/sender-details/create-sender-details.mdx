    Creates a sender.

    <Note>

    You can only create a sender for a *verified* email address.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.ACCESS-VERTICALS-BY-AUTOMATIONS">Access Verticals by Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/sender-details/v1/sender-details
    ```

    ## Body Params

    <ParamField body="senderDetails" type="SenderDetails" required>

      Sender details to create.

      See the [Sender Details Object](/api-reference/business-management/marketing/emails/sender-details/sender-details-object) for this object's fields.
