    Retrieves aggregated conversion metrics for a campaign from Wix Analytics.
    Both campaignId and dateRange are required. Due to analytics query complexity, this method has a 120-second SLA.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/conversion-metrics
    ```

    ## Body Params

    <ParamField body="campaignId" type="string" required>

      Wix internal campaign ID (GUID) of the campaign to query.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="dateRange" type="DateRange" required>

      Date range to query. Required.

      <Expandable title="One of the following">

        <ParamField body="Range" type="Range">

          Range

          <Expandable title="Range properties">

            <ParamField body="custom" type="CustomDateRange">

              Custom date range.

              _Nested structure omitted for brevity — see the `CustomDateRange` object._

            </ParamField>

            <ParamField body="predefined" type="string">

              Predefined date range.

              **Supported values:**

              - `UNSPECIFIED` — Not specified.
              - `TODAY` — Today only.
              - `YESTERDAY` — Yesterday only.
              - `LAST_7_DAYS` — The last 7 days not including today.
              - `LAST_BUSINESS_WEEK` — The 5 day business week, Monday through Friday, of the previous business week.
              - `THIS_MONTH` — All days in the current month.
              - `LAST_MONTH` — All days in the previous month.
              - `LAST_14_DAYS` — The last 14 days not including today.
              - `LAST_30_DAYS` — The last 30 days not including today.
              - `THIS_WEEK_SUN_TODAY` — The period between the previous Sunday and the current day.
              - `THIS_WEEK_MON_TODAY` — The period between the previous Monday and the current day.
              - `LAST_WEEK_SUN_SAT` — The 7-day period starting with the previous Sunday.
              - `LAST_WEEK_MON_SUN` — The 7-day period starting with the previous Monday.
              - `LIFETIME` — Since the beginning of the campaign.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="summaryRow" type="ConversionMetrics">

      Aggregated conversion totals for the campaign over the requested date range.

      <Expandable title="summaryRow properties">

        <ResponseField name="orders" type="integer">

          Number of orders.

          **Read-only.**

        </ResponseField>

        <ResponseField name="revenue" type="number">

          Revenue generated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="date" type="string">

          Date the metrics apply to.

          **Read-only.**

        </ResponseField>

        <ResponseField name="leads" type="integer">

          Number of leads.

          **Read-only.**

        </ResponseField>

        <ResponseField name="cpl" type="number">

          Cost per lead, calculated as total campaign spend for the period divided by `leads`.

          Not returned when `leads` or spend is `0`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="leadsConversionRate" type="number">

          Conversion rate, calculated as `leads` divided by clicks.

          Not returned when `leads` or clicks is `0`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="cpp" type="number">

          Cost per purchase, calculated as total campaign spend for the period divided by `orders`.

          Not returned when `orders` or spend is `0`.

          **Read-only.**

        </ResponseField>

        <ResponseField name="roas" type="number">

          Return on ad spend, calculated as `revenue` divided by total campaign spend for the period.

          Not returned when `revenue` or spend is `0`.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ## Examples

    Retrieves conversion metrics (orders, revenue, leads, ROAS) for a Google Ads campaign over a custom date range.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/_serverless/pa-google/v1/conversion-metrics' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "campaignId": "b3f8e241-7c4a-4d19-a562-9f1e30d87c05",
        "dateRange": {
          "custom": {
            "from": "2026-03-01",
            "to": "2026-03-31"
          }
        }
      }'
      ```

      ```json Response
      {
        "summaryRow": {
          "date": "",
          "orders": 214,
          "revenue": 18750.40,
          "leads": 87,
          "cpl": 16.19,
          "leadsConversionRate": 0.0262,
          "cpp": 6.58,
          "roas": 13.31
        }
      }
      ```
