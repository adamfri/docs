    Retrieves a list of up to 200 folders with the specified filtering, sorting, and cursor paging.

    If no parameters are specified, the method returns all folders in the `MEDIA_ROOT` folder.

    ## Defaults

    Search Folders has the following default setting, which you can override:
    + Sorted by `updatedDate` in descending order.

    ## Filters

    When using filters for dates, you must use
    [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time).

    ## See also

    To learn about working with *Search* methods, see
    [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language) and
    [Sorting and Paging](https://dev.wix.com/docs/rest/articles/get-started/sorting-and-paging).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEDIA.READ-MEDIAMANAGER">Read Media Manager</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-media/v1/folders/search
    ```

    ## Body Params

    <ParamField body="rootFolder" type="string">

      The root folder in the Media Manager to search in.
      For more information, see Root Folders in [Terminology](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction#terminology).

      Default: `MEDIA_ROOT`.

      **Supported values:**

      - `MEDIA_ROOT` — Contains all files and folders in the Media Manager's **Site Files** tab in the UI.
      - `TRASH_ROOT` — Contains all files and folders in the Media Manager's **Trash** tab in the UI.
      - `VISITOR_UPLOADS_ROOT` — Contains all files and folders created by site visitors or members.

    </ParamField>

    <ParamField body="sort" type="Sorting">

      Field name and order to sort by. One of:

      `displayName`
      `updatedDate`

      Default: `updatedDate` in `desc` order.

      <Expandable title="sort properties">

        <ParamField body="fieldName" type="string">

          Name of the field to sort by.

          Constraints: `maxLength 512`.

        </ParamField>

        <ParamField body="order" type="string">

          Sort order.

          **Supported values:**

          - `ASC`
          - `DESC`

        </ParamField>

        <ParamField body="origin" type="AddressLocation">

          Origin point for geo-distance sorting on a GEO field
          results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

          <Expandable title="origin properties">

            <ParamField body="latitude" type="number">

              Address latitude.

            </ParamField>

            <ParamField body="longitude" type="number">

              Address longitude.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="paging" type="CursorPaging">

      Cursor and paging information.

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField body="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="search" type="string">

      Free text to match in searchable fields.

      For example, search for specific values in a folder's `displayName`.

    </ParamField>

    ## Response Object

    <ResponseField name="folders" type="Folder[]">

      Retrieved folders that match the search criteria specified in the request.

      Each folder includes all standard folder information.

      Constraints: `maxItems 200`.

      See the [Folder Object](/api-reference/assets/media/media-manager/folders/folder-object) for this object's fields.

    </ResponseField>

    <ResponseField name="nextCursor" type="PagingMetadataV2">

      The next cursor if it exists.

      <Expandable title="nextCursor properties">

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    import { Permissions, webMethod } from '@wix/web-methods';
    import { folders } from '@wix/media';
    import { auth } from '@wix/essentials';

    export const deleteFolders = webMethod(Permissions.Anyone, async (folderIds) => {
      try {
        const elevatedBulkDeleteFolders = auth.elevate(folders.bulkDeleteFolders);
        const deletedFolders = await elevatedBulkDeleteFolders(folderIds);

        console.log('Successfully moved folders to trash.');
        return deletedFolders;
      } catch (error) {
        console.error(error);
      }
    });

    export const listFolders = webMethod(Permissions.Anyone, async () => {
      try {
        const elevatedListFolders = auth.elevate(folders.listFolders)
        const foldersList = await elevatedListFolders();

        return foldersList;
      } catch (error) {
        console.error(error);
      }
    });

    export const searchFolders = webMethod(Permissions.Anyone, async (options) => {
      try {
        const elevatedSearchFolders = auth.elevate(folders.searchFolders)
        const foldersFound = await elevatedSearchFolders(options);

        return foldersFound;
      } catch (error) {
        console.error(error);
      }
    });
