Triggered when an event is updated, including when it's canceled.

Not triggered when `INSTANCE` events are updated. You can use the
[Events View API](https://dev.wix.com/docs/rest/business-management/calendar/event-views-v3/introduction)
to get notified about `INSTANCE` events.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.calendar.v3.event_updated` |
| Package | `@wix/calendar` |
| Permissions | `Read Calendar - Including PI`, `Manage Calendars`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions`, `Read bookings calendar - including participants` |

## Examples

<CodeGroup>

  ```javascript onEventUpdated
  import { events } from '@wix/calendar';

  events.onEventUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onEventUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { events } from '@wix/calendar';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        events,
      },
  });

  wixClient.events.onEventUpdated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
