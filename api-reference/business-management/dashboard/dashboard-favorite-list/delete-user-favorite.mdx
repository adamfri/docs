  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes the specified favorite page from the current Wix user's list of favorite dashboard pages. If no favorites remain in the list, it is deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.MANAGE_DASHBOARD">Manage Dashboard</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/dashboard/v1/user-favorite-list/delete-favorite/{favoriteId}
    ```

    ## Path Params

    <ParamField path="favoriteId" type="string" required>

      ID of the favorite page to delete from the list.

    </ParamField>

    ## Response Object

    <ResponseField name="favoriteList" type="DashboardFavoriteList">

      Updated dashboard favorite list.

      See the [Favorite List Object](/api-reference/business-management/dashboard/dashboard-favorite-list/favorite-list-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Favorite List Deleted | `wix.dashboard.v1.favorite_list_deleted` | Triggered when the dashboard favorite list is deleted. |
    | Favorite List Updated | `wix.dashboard.v1.favorite_list_updated` | Triggered when the dashboard favorite list is updated. |

    </div>
