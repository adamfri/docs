Triggered when an abandoned checkout is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.ecom.v1.abandoned_checkout_updated` |
| Package | `@wix/ecom` |
| Permissions | `Manage Stores - all permissions`, `Read eCommerce - all read permissions`, `Read Orders`, `Read Stores - all read permissions`, `Manage Restaurants - all permissions`, `Manage eCommerce - all permissions`, `Manage Orders` |
