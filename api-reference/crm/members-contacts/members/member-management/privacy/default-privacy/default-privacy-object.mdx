Default privacy defines the initial privacy status assigned to new members when they join a site.
This setting determines whether new members start with public or private profiles by default.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Privacy ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="defaultPrivacy" type="string">

      Default privacy status for a new member.

      **Supported values:**

      - `PRIVATE` — Default privacy status is private. All members have private profiles with no option to make them public.
      - `PUBLIC` — Default privacy status is public. All members can make their profile public.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the default privacy is updated. To prevent conflicting changes, the existing revision must be used when updating default privacy.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "24353b4f-0ffb-4155-ba54-c05751f10eae",
        "defaultPrivacy": "PRIVATE",
        "revision": "1"
      }
      ```

    </CodeGroup>
