    Searches Google's Business Profile catalog for existing listings.

    Specify either a free-text query or a title and address. Each result is a real
    catalog entry, and carries a `matchStatus` saying whether it can be claimed.

    This doesn't need a connected Google account, so you can call it before the
    site owner connects one, for example to check whether a business already has a
    listing.

    Read `matchStatus` carefully, because it's about the catalog rather than about
    the site owner:

    - `CLAIMABLE`: no Google account has claimed this listing.
    - `OWNED_ELSEWHERE`: some Google account has claimed it. That account may well
    be the site owner's own, so don't present this as someone else's listing.
    Confirm ownership by connecting their account and calling List Unimported
    Locations.

    For lighter-weight suggestions while someone types, call Suggest
    Establishments, which returns autocomplete hints rather than catalog entries.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

              Constraints: `maxLength 200`.

              Business name shown on the listing (Google's "title").

              Constraints: `minLength 1`, `maxLength 300`.

            </ResponseField>

              BCP-47 language tag, e.g. "en-US". Required by Google, immutable.

            <ResponseField name="primaryCategory" type="Category">

              Primary business category. Required by Google.

              _Nested structure omitted for brevity — see the `Category` object._

            </ResponseField>

            <ResponseField name="additionalCategories" type="Category[]">

              Additional categories. Google caps at 9.

              Constraints: `maxItems 9`.

              _Nested structure omitted for brevity — see the `Category[]` object._

            </ResponseField>

            <ResponseField name="profile" type="Profile">

              Optional. Google asks for a description for every category except lodging
              but doesn't enforce it, so neither does this API. Both an absent profile and
              one with an empty description are accepted.

              _Nested structure omitted for brevity — see the `Profile` object._

            </ResponseField>

            <ResponseField name="storefrontAddress" type="PostalAddress">

              Storefront postal address. Required for a business that serves customers at
              its premises, and allowed alongside `serviceArea` when that field's
              `businessType` is `CUSTOMER_AND_BUSINESS_LOCATION`.

              _Nested structure omitted for brevity — see the `PostalAddress` object._

            </ResponseField>

            <ResponseField name="serviceArea" type="ServiceArea">

              Service-area definition (for businesses that serve customers at the
              customer's location, exclusively or in addition to their storefront).

              _Nested structure omitted for brevity — see the `ServiceArea` object._

            </ResponseField>

            <ResponseField name="primaryPhone" type="string">

              Primary business phone.

              Constraints: `maxLength 50`.

            </ResponseField>

            <ResponseField name="additionalPhones" type="string[]">

              Additional phones. Google caps at 2.

              Constraints: `maxLength 50`, `maxItems 2`.

            </ResponseField>

            <ResponseField name="websiteUri" type="string">

              Business website.

              `null`. Sending an empty string is rejected.

              Merchant-defined store code (free-form identifier shown only to the merchant).

              Constraints: `maxLength 64`.

              Regular weekly business hours.

              Constraints: `maxItems 14`.

              _Nested structure omitted for brevity — see the `BusinessHours[]` object._

            </ResponseField>

            <ResponseField name="latLng" type="LatLng">

              Geographic coordinates of the storefront.

              _Nested structure omitted for brevity — see the `LatLng` object._

            </ResponseField>

            <ResponseField name="openInfo" type="OpenInfo">

              Open/closed state of the listing.

              _Nested structure omitted for brevity — see the `OpenInfo` object._

            </ResponseField>

            <ResponseField name="metadata" type="Metadata">

              Read-only signals Google reports about the listing.

              Only populated on the read paths (Query Google Locations, Get Google
              Location) and on the Update Google Location response. Search Google
              Locations reads Google's catalog rather than the merchant's own listing,
              so it leaves this unset — don't read a default there as a "no".

              **Read-only.**

              _Nested structure omitted for brevity — see the `Metadata` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="status" type="string">

          Whether this listing can be claimed. Read it carefully: it describes the
          catalog rather than the site owner. See Search Google Locations.

          **Supported values:**

          - `CLAIMABLE` — The catalog entry is unclaimed and can be created/associated.
          - `OWNED_ELSEWHERE` — The catalog entry is already claimed by some Google account.

        </ResponseField>
