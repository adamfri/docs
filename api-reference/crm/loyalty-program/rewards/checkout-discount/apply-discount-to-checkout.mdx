    Applies a discount to a checkout.

    You can apply one of the following discounts, which are exchanged for loyalty points: `reward`, `loyaltyCoupon`, or `referralReward`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-checkout-exchange/v1/loyalty-checkout-discount
    ```

    ## Body Params

    <ParamField body="checkoutId" type="string" required>

      ID of the checkout to apply the discount to.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="discount" type="LoyaltyCheckoutDiscount">

      The applied loyalty checkout discount.

      See the [Loyalty Checkout Discount Object](/api-reference/crm/loyalty-program/rewards/checkout-discount/loyalty-checkout-discount-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
