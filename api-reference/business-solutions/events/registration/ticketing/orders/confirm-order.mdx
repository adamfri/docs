    Confirms an order.

    Changes an order's `status` from `"INITIATED"`, `"PENDING"`, or `"OFFLINE_PENDING"` to `"PAID"`.

    Previously confirmed orders, with a `status` of `"PAID"` or `"FREE"` aren't changed with this method.

    Confirming orders with the `status` of `"INITIATED"` or `"PENDING"`, triggers an email containing the tickets to the buyer (and to additional guests, if specified).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/events/{eventId}/orders/confirm
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID to which the order belongs.

    </ParamField>

    ## Body Params

    <ParamField body="orderNumber" type="string[]">

      Order numbers.

      Constraints: `minLength 1`, `maxLength 36`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="orders" type="Order[]">

      Confirmed orders.

      See the [Order Object](/api-reference/business-solutions/events/registration/ticketing/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ORDER_ACTION_NOT_AVAILABLE` | Order can't be confirmed due to its current status or state. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Updated | `wix.events.ticketing.events.OrderUpdated` |  |
