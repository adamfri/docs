<span className="wix-method wix-method-get">GET</span>

Retrieves a list of transactions with specified filters.

Specify filters using the query params.

This method supports pagination.

## Endpoint

```http
GET https://www.wixapis.com/payments/v2/transactions
```

## Query Params

<ParamField query="from" type="datetime">

  Only include transactions where the `createdAt` property is after this date.

</ParamField>

<ParamField query="to" type="datetime">

  Only include transactions where the `createdAt` property is before this date.

</ParamField>

<ParamField query="limit" type="integer">

  Maximum number of transactions to retrieve.
  If no value is specified, the default is 10.

  Constraints: `min 0`, `max 1000`.

</ParamField>

<ParamField query="offset" type="integer">

  Offset.

</ParamField>

<ParamField query="order" type="string">

  Specify the order in which transactions are returned.
  Available options (only by `createdAt` date):
  - `date:asc` - order by date in ascending order (oldest first)
  - `date:desc` - order by date in descending order (most recent first)
  If no value is specified, the default is `date:desc`.

</ParamField>

<ParamField query="status" type="string[]">

  Filter by transaction status.

  **Supported values:**

  - `UNDEFINED`
  - `INITIALIZED`
  - `IN_PROCESS`
  - `APPROVED`
  - `PENDING`
  - `PENDING_MERCHANT`
  - `PENDING_BUYER`
  - `BUYER_CANCELED`
  - `TIMEOUT`
  - `REFUND`
  - `PARTIAL_REFUND`
  - `VOID`
  - `CHARGE_BACK`
  - `EXPIRED`
  - `DECLINED`
  - `FAILED`
  - `COMPLETED_FUNDS_HELD`
  - `TPA_CANCELED`
  - `OFFLINE`
  - `DISPUTE`
  - `AUTHORIZED`

</ParamField>

<ParamField query="paymentMethod" type="string">

  Filter by transaction payment method.

</ParamField>

<ParamField query="paymentProvider" type="string">

  Filter by transaction payment provider.

</ParamField>

<ParamField query="currency" type="string" deprecated>

  Filter by transaction currency.

  **Deprecated.** Filter by transaction currency. Removal: 2026-06-30.

</ParamField>

<ParamField query="fromUpdated" type="datetime">

  Only include transactions where the transaction was updated after this date.

</ParamField>

<ParamField query="toUpdated" type="datetime">

  Only include transactions where the transaction was updated before this date.

</ParamField>

<ParamField query="appId" type="string" deprecated>

  Filter by app ID.

  **Deprecated.** Filter by app ID. Removal: 2026-06-30.

</ParamField>

<ParamField query="includeRefunds" type="boolean">

  Whether to include refunds in the retrieved transaction objects.

  Default: `false`

</ParamField>

<ParamField query="ignoreTotals" type="boolean">

  Whether to include `pagination.total` in the response.

  Default: `false`

</ParamField>
