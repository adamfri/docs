Triggered when an event has started.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.events.guests.v1.guest_guest_event_starts` |
| Package | `@wix/events` |
| Permissions | `Read Events - all read permissions`, `Manage Events - all permissions`, `Manage Events`, `Manage Guest List`, `Read Event Tickets and Guest List` |

## Examples

<CodeGroup>

  ```javascript onGuestEventStarts
  import { guests } from '@wix/events';

  guests.onGuestEventStarts((event) => {
      // handle your event here
  });
  ```

  ```javascript onGuestEventStarts (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { guests } from '@wix/events';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        guests,
      },
  });

  wixClient.guests.onGuestEventStarts((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
