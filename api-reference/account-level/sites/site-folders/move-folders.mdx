    <div className="wix-ref">

    Move folders to a specific folder or to root level.
    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="FOLDERS.MOVE, FOLDERS.VIEW">FOLDERS.MOVE, FOLDERS.VIEW</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/site-folders/v2/folders/bulk/move
    ```

    ## Body Params

    <ParamField body="folderIds" type="string[]" required>

      List of folders IDs. Limited to 1000 folders.

      Constraints: `maxLength 36`, `minItems 1`, `maxItems 1000`.

    </ParamField>

    <ParamField body="targetFolderId" type="string">

      New parent ID.
      Empty if folder is moved to root level.

      Constraints: `maxLength 36`.

    </ParamField>

    ## Response Object

    <ResponseField name="folders" type="Folder[]">

      List of all the account's folders that were successfully moved.

      See the [Folder Object](/api-reference/account-level/sites/site-folders/folder-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `folder_not_found` | Couldn't find the specified folder. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
