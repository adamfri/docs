    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.READ_LIMITED">SCOPE.BENEFIT_PROGRAMS.READ (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/benefit-programs/v1/pool-definitions/{poolDefinitionId}
    ```

    ## Path Params

    <ParamField path="poolDefinitionId" type="string" required>

      ID of the pool definition to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="poolDefinition" type="PoolDefinition">

      Retrieved pool definition.

      See the [Pool Definition Object](/api-reference/business-solutions/benefit-programs/pool-definitions/pool-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
