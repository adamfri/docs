    Deletes a component's draft version.

    Previously published component versions aren't deleted. Deletion is blocked for component types defined as non-deletable.

    REST callers currently specify the component ID in the `id` path parameter; `componentId` is the replacement field for SDK and RPC callers.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/apps/v1/components/v1/components/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required />
