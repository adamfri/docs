    Retrieves geographic location suggestions matching a partial query string.
    Use the returned geo targets to populate the `locations` field when creating a campaign.
    Results may include restricted countries; restricted locations are rejected when the campaign is created.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/geo-options
    ```

    ## Query Params

    <ParamField query="queryLocation" type="string">

      Partial location name to search for.

    </ParamField>

    <ParamField query="languageCode" type="string">

      BCP-47 language code for localizing result display names.

    </ParamField>

    <ParamField query="countryCode" type="string">

      ISO 3166-1 alpha-2 country code to bias results toward a specific country.

    </ParamField>

    <ParamField query="queryLocations" type="string">

      Multiple location names to search for, separated by semicolons.

    </ParamField>

    ## Response Object

    <ResponseField name="googleSuggestion" type="GoogleSuggestion">

      Geo target suggestions matching the query. May include restricted countries; restricted locations are rejected when the campaign is created.

      See the [Google Suggestion Object](/api-reference/business-management/marketing/ads/google-ads/google-suggestion-v1/google-suggestion-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
