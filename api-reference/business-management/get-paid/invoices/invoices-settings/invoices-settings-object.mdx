---
title: "Invoices Settings Object"
description: "Invoice settings control how invoice numbers are generated for a site."
icon: "cube"
---

Invoice settings control how invoice numbers are generated for a site.

<Tabs>

  <Tab title="REST">

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the invoice settings are updated. To prevent conflicting changes, the current revision must be passed when updating the invoice settings.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the invoice settings were created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the invoice settings were last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="numbering" type="Numbering">

      Invoice numbering configuration. The invoice number is formatted as `{prefix}{nextNumber}{suffix}`. For example, `INV-1001-2024`. See the Invoices API's `numbering` field for the assigned result on individual invoices.

      <Expandable title="numbering properties">

        <ResponseField name="prefix" type="string">

          Prefix displayed before the invoice number. For example, `INV-`.

        </ResponseField>

        <ResponseField name="nextNumber" type="integer">

          Number from which subsequent invoices are numbered. Each prefix maintains its own number sequence, so changing the prefix resets the available range.

        </ResponseField>

        <ResponseField name="suffix" type="string">

          Suffix displayed after the invoice number. For example, `-2024`.

        </ResponseField>

        <ResponseField name="numberPadding" type="integer">

          Next number padding length of `0`. E.g. `nextNumber=123`, `length=5` formatted number `00123`; `nextNumber=123`, `length=3` formatted number `123`.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
