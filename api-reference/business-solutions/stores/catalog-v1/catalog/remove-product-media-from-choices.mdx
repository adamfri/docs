    Removes media items from all or some of a product's choices.
    (Media items can only be set for choices within one option at a time - e.g., if you set media items for some or all of the choices within the Colors option (blue, green, and red), you won't be able to also assign media items to choices within the Size option (S, M, and L).)

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v1/products/{id}/choices/media/delete
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Product ID from whose choices to remove media items.

    </ParamField>

    ## Body Params

    <ParamField body="media" type="MediaAssignmentToChoice[]">

      Media to remove from choices.

      Constraints: `minItems 1`, `maxItems 10`.

      <Expandable title="media properties">

        <ParamField body="option" type="string">

          Option name.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="choice" type="string">

          Choice name.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="mediaIds" type="string[]">

          Media IDs (available via the Query Product endpoint).

          Constraints: `maxItems 50`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `RemoveProductMediaFromChoicesResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
