    Permanently deletes multiple suppliers in a single synchronous request. This action cannot be undone.

    Supports up to 100 suppliers per request. To delete more than 100 suppliers, split the supplier IDs into multiple batches and make separate requests.

    Each supplier deletion is processed independently. The response includes metadata indicating success or failure for each supplier.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/bulk/suppliers/delete
    ```
