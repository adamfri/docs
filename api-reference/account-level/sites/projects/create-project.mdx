    Creates a project.

    You can optionally specify a template to base the project on and apps to install during creation.
    The response includes a `metaSiteId` that you can use to redirect users to their project dashboard at `https://manage.wix.com/dashboard/{metaSiteId}`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="META_SITE_PROVISION.PROVISION">META_SITE_PROVISION.PROVISION</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/funnel/projects/v1/create
    ```

    ## Body Params

    <ParamField body="type" type="string" required>

      Type of project to create.

      **Supported values:**

      - `WIX` — Standard [Wix site](https://manage.wix.com/studio/sites?viewId=all-items-view) with a frontend built using Wix Editor or Wix Studio.
      - `HEADLESS` — [Headless project](https://dev.wix.com/docs/go-headless) that creates a site using Wix's backend services with a custom frontend implementation.
      - `BRANDED_APP` — Native mobile app created with [Wix's app builder](https://www.wix.com/app-builder).

    </ParamField>

    <ParamField body="name" type="string">

      Project name displayed in the project dashboard.

    </ParamField>

    <ParamField body="templateId" type="string">

      ID of a template to base the new project on.
      See [Site Template IDs](https://dev.wix.com/docs/api-reference/account-level/sites/project-v1/site-template-ids) for examples.

      Default: blank template

    </ParamField>

    <ParamField body="folderId" type="string">

      Dashboard folder ID where the project is placed in the **Sites** section of the Wix Studio Workspace.

    </ParamField>

    <ParamField body="apps" type="App[]">

      Apps to install in the new project.

      Constraints: `maxItems 100`.

      <Expandable title="apps properties">

        <ParamField body="appDefId" type="string">

          ID of the app to install. See [About Apps Created by Wix](https://dev.wix.com/docs/api-reference/articles/get-started/apps-created-by-wix) for a list of available App Definition IDs.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="project" type="Project">

      Created project.

      See the [Project Object](/api-reference/account-level/sites/projects/project-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
