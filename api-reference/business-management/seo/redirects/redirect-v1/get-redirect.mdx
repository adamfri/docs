    Retrieves a redirect by ID.

    Call this method before [Delete Redirect](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/delete-redirect) and [Create Redirect](https://dev.wix.com/docs/api-reference/business-management/seo/redirects/redirect-v1/create-redirect) when changing an existing redirect,
    and keep the response: the create fills any field you omit with its default rather than with the
    redirect's previous value.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/seo-redirects-service/v1/redirects/{redirectId}
    ```

    ## Path Params

    <ParamField path="redirectId" type="string" required>

      ID of the redirect to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="redirect" type="Redirect">

      Retrieved redirect.

      See the [Redirect Object](/api-reference/business-management/seo/redirects/redirect-v1/redirect-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | — | The `redirectId` is missing or empty. Details are in `fieldViolations`. |
    | `404` | `NOT_FOUND` | `REDIRECT_NOT_FOUND` | Couldn't find the redirect. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Returns `REDIRECT_NOT_FOUND` when no redirect on the site has that ID.

    <CodeGroup>

      ```bash Request

      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json'
      ```

        "redirect": {
