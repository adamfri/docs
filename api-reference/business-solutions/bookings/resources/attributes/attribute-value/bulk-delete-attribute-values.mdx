    Deletes the values of the given attribute definitions for an entity.

    Each entry in `attribute_definition_ids` removes that attribute's value from the entity. IDs with no value for
    this entity are reported as a no-op success.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ATTRIBUTES.MANAGE">Manage_Wix_Attributes_Forms_submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/attributes/v1/attribute-values/{entityId}/bulk-delete
    ```

    ## Path Params

    <ParamField path="entityId" type="string" required>

      ID of the entity whose attribute values to delete.

    </ParamField>

    ## Body Params

    <ParamField body="attributeDefinitionIds" type="string[]" required>

      IDs of the attribute definitions whose values should be removed from this entity.

      Constraints: `format GUID`, `minItems 1`, `maxItems 50`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkDeleteAttributeValueResult[]">

      Delete results, one per requested attribute definition, in request order.

      Constraints: `minItems 1`, `maxItems 50`.

      <Expandable title="results properties">

          <Expandable title="itemMetadata properties">

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

              Constraints: `min 0`.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action for this item was successful. When `false`, the `error` field is returned.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Bulk action metadata (success and failure counts).

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.
