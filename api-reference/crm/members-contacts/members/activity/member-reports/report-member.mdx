    <div className="wix-ref">

    Creates a report for the reported member.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/member-reports
    ```

    ## Body Params

    <ParamField body="memberReport" type="MemberReport" required>

      Details of a member to report.

      See the [Member Report Object](/api-reference/crm/members-contacts/members/activity/member-reports/member-report-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="memberReport" type="MemberReport">

      Member report.

      See the [Member Report Object](/api-reference/crm/members-contacts/members/activity/member-reports/member-report-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `SELF_REPORTING_FORBIDDEN` | Member can't report themselves. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_REPORT_BLOCKED_MEMBER` | Blocked member can't be reported. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Member Report Created | `wix.members.v1.member_report_created` | Triggered when a member is reported. |

    </div>
