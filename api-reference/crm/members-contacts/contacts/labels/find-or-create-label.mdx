    Retrieves a label with a specified name, or creates one if it doesn't exist.

    Successful calls to this method always return a label,
    which can be specified in subsequent calls.

    For example, in the Contacts API, Label Contact and Unlabel Contact
    calls will fail if you include a non-existent label.
    To ensure successful calls, you can call this method first,
    and then use the response in the Label Contact and Unlabel Contact calls.

    To find an existing label without potentially creating a new one, call
    Get Label or Query Labels.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-LABELS">Manage Contact Labels</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/labels
    ```

    ## Body Params

    <ParamField body="displayName" type="string" required>

      Display name to retrieve or create.

      If an existing label is an exact match
      for the specified display name,
      the existing label is returned.
      If not, a new label is created and returned.

      Constraints: `minLength 1`, `maxLength 180`.

    </ParamField>

    <ParamField body="language" type="string">

      Language for localization.
      2-letter language code in [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) format.

    </ParamField>

    ## Response Object

    <ResponseField name="label" type="ContactLabel">

      Label that was found or created.

      See the [Label Object](/api-reference/crm/members-contacts/contacts/labels/label-object) for this object's fields.

    </ResponseField>

    <ResponseField name="newLabel" type="boolean">

      Indicates whether the label was just created or already existed.

      Returns `true` if the label was just created.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `LABELS_QUOTA_REACHED` | Maximum number of labels reached. Labels must be deleted before any more can be created. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Contact Label Created | `wix.contacts.v4.label_created` | Triggered when a label is created. |

    </div>

    ```javascript Create a new label and add it to a contact
    import { contacts, labels } from '@wix/crm';

    /* Sample contactId value: '2712ae1d-3f64-46c2-ac3a-94a6c2e29847'
     * 
     * Sample displayName value: 'Supplier'
     */

    export async function addNewLabelToContact(displayName, contactId) {

      try {
        const newLabel = await labels.findOrCreateLabel(displayName);
        const labelKeys = [newLabel.label.key];
        // Retrieve the new label's key
        if (newLabel.newLabel) {
          // Label contact
          const contact = await contacts.labelContact(contactId, labelKeys);
          const contactLabels = contact.contact.info.labelKeys.items;

          return contactLabels;
        }
        else {
          return "Label was not added to contact.";
        }
      } catch (error) {
        console.log(error);
        // Handle the error
      }
    }

    /* Promise resolves to: 
     * [
     *   "custom.contact",
     *   "custom.supplier"
    ```
