Triggered when a loyalty account is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.v1.account_created` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty` |
