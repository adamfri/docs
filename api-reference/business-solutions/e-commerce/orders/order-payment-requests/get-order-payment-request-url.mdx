    Retrieves the payment page URL for an order payment request.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-payment-requests/url
    ```

    ## Body Params

    <ParamField body="orderPaymentRequestId" type="string" required>

      ID of the order payment request.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="orderPaymentRequestUrl" type="string">

      Payment page URL for the order payment request.

      Constraints: `minLength 1`, `maxLength 100`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_PAYMENT_REQUEST_NOT_FOUND` | Couldn't find the order payment request. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_PAYMENT_REQUEST_PAGE_NOT_FOUND` | The Payment Request Page isn't published on the site. Add and publish a Payment Request Page in the Wix Editor. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
