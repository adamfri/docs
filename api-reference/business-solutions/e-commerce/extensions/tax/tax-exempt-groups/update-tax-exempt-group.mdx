    Updates a tax exempt group.

    Each time the tax exempt group is updated, `revision` increments by 1. The current `revision` must be passed when updating the tax exempt group. This ensures you're working with the latest tax exempt group and prevents unintended overwrites.

    Only the fields provided in the request are updated. To update multiple tax exempt groups in a single API call, call [Bulk Update Tax Exempt Groups](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/tax-exempt-groups/bulk-update-tax-exempt-groups).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

