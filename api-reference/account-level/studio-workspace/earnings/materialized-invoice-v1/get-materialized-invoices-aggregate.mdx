    Retrieves the total amount (in USD) and count of the partner's materialized invoices matching the provided filter.

    The totals cover exactly the invoices the filter matches, across every `status`. Pass an empty filter to total the partner's full invoice history. The Wix Studio dashboard's total is narrower: it sums only `PAID` and `UNPAID` invoices that match the filters selected in the UI, so it excludes `BELOW_THRESHOLD` invoices.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/revshare/v1/materialized-invoices/aggregate
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter selecting which materialized invoices to aggregate.

    </ParamField>

    ## Response Object

    <ResponseField name="materializedInvoicesTotalAmount" type="number">

      Total amount across the matching materialized invoices, in USD.

    </ResponseField>

    <ResponseField name="materializedInvoicesCount" type="number">

      Number of materialized invoices matching the filter.

    </ResponseField>
