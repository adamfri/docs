Guidelines ensuring that members post responsibly and respectfully. Site owners can set up Group Rules in the dashboard.
<Note>

Only admins can update the group rules.

</Note>

## SDK package

```bash
npm install @wix/groups
```

Import the `rules` namespace from `@wix/groups`.

## Methods

  <Card title="Create Or Replace All Rules" href="/api-reference/crm/community/groups/rules/create-or-replace-all-rules">

  </Card>
  <Card title="List Rules" href="/api-reference/crm/community/groups/rules/list-rules">
