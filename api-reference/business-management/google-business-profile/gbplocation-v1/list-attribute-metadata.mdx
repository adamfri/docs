    Retrieves the attributes a Business Profile can have, with each one's value
    type, display name and options.

    Use it to work out what you can send to Update Location Attributes, or to build
    an editor for a site owner.

    Specify exactly one of:

    - `locationId`, for the attributes available to an existing location, based on
    its category and country.
    - `categoryRegion`, for the attributes available to a Google category and
    country. Use this before a location exists, for example while a site owner is
    still choosing a category. It doesn't need a connected Google account.

    Errors:
    - `INVALID_ARGUMENT`: neither or both of the two lookup fields were specified.
    - `NOT_FOUND`: the location isn't recorded for this site. Google isn't called.
    - `GOOGLE_API_CALL_FAILED`: the call to Google failed. Google's status and
    response are in the error payload.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ```http
    GET https://www.wixapis.com/gbp/v1/attribute-metadata
    ```

      Cursor-based paging. `limit` maps to Google's page size (unset uses a
      server default of 200, min 1); `cursor` is the `next` token returned by a

      <Expandable title="paging properties">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

        </ParamField>

    ## Response Object

    <ResponseField name="attributeMetadata" type="AttributeMetadata[]">

      Attribute definitions available for this page.

      <Expandable title="attributeMetadata properties">

        <ResponseField name="attributeId" type="string">

          Attribute key, such as `has_wifi`, without the `attributes/` prefix. Pass it
          as `attributeId` when writing values with Update Location Attributes.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="valueType" type="string">

          The value type callers should provide for this attribute.

          **Supported values:**

          - `BOOL` — A true/false attribute.
          - `ENUM` — An attribute with a fixed set of single-select values.
          - `URL` — A URL-valued attribute.
          - `REPEATED_ENUM` — An attribute with a fixed set of multi-select values. Matches Google's
          AttributeValueType token spelling ("REPEATED_ENUM") so the value-type
          mapping is a direct name lookup.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Localized display name for the attribute, or English if unavailable.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="groupDisplayName" type="string">

          Localized display name of the group this attribute belongs to. Related
          attributes share a group and should be displayed together.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="repeatable" type="boolean">

          If true, the attribute supports multiple values.

        </ResponseField>

        <ResponseField name="valueMetadata" type="AttributeValueMetadata[]">

          For enum-typed attributes, the supported values and their display names.

          Constraints: `maxItems 200`.

          <Expandable title="valueMetadata properties">

            <ResponseField name="displayName" type="string">

              Localized display name for this value, or English if unavailable (e.g.
              "Paid" for a Wi-Fi attribute).

              Constraints: `maxLength 255`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="deprecated" type="boolean">

          If true, the attribute is deprecated and should no longer be used.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata. `cursors.next` is the token to specify for the next page, and
      `hasNext` says whether there is one.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>
