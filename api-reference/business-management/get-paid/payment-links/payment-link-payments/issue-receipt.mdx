    <div className="wix-ref">

    Issues a receipt for the specified payment link payment.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYLINKS.MANAGE">Manage Paylinks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payment-links/v1/payment-link-payments/{paymentLinkPaymentId}/issue-receipt
    ```

    ## Path Params

    <ParamField path="paymentLinkPaymentId" type="string" required>

      Payment link payment ID.

    </ParamField>

    ## Response Object

    <ResponseField name="receiptId" type="string">

      Issued receipt ID.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `RECEIPT_NOT_FOUND` | Couldn't find the receipt. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_PAYMENT_TYPE` | Payment type isn't valid for issuing a receipt. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_PAYMENT_DETAILS` | Either `regularPaymentLinkPayment` or `giftCardPaymentLinkPayment` must be provided. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_REGULAR_PAYMENT_LINK_PAYMENT_ORDER` | Either `ecomOrder` or `cashierOrder` must be provided in `regularPaymentLinkPayment.order`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
