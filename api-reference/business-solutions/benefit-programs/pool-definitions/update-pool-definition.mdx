    Updates a pool definition.

    Each time the pool definition is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the pool definition.
    This ensures you're working with the latest pool definition
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/benefit-programs/v1/pool-definitions/{poolDefinition.id}
    ```

    ## Path Params

    <ParamField path="poolDefinition.id" type="string" required>

      Pool definition ID.

    </ParamField>

    ## Body Params

    <ParamField body="poolDefinition" type="PoolDefinition" required>

      Pool definition to update.

      See the [Pool Definition Object](/api-reference/business-solutions/benefit-programs/pool-definitions/pool-definition-object) for this object's fields.

    </ParamField>

    <ParamField body="cascade" type="string">

      *Required.** Determines when the changes to this pool definition and program definitions containing it will be applied to associated programs and pools.

      **Supported values:**

      - `UNKNOWN_CASCADE` — Unknown cascade.
      - `NEXT_RENEWAL` — Changes are applied to existing programs and pools when they are next renewed.
      - `IMMEDIATELY` — Changes are applied to associated programs and pools immediately.
      - `FUTURE_PROVISIONS` — Changes are not applied to existing associated programs and pools. They are only applied to future programs and pools.

    </ParamField>

    ## Response Object

    <ResponseField name="poolDefinition" type="PoolDefinition">

      Updated pool definition.

      See the [Pool Definition Object](/api-reference/business-solutions/benefit-programs/pool-definitions/pool-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `cascade_is_required` | Cascade value wasn't specified. Provide a cascade value. |
    | `400` | `INVALID_ARGUMENT` | `cascade_value_not_supported` | Cascade value isn't supported. Provide a supported cascade value. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
