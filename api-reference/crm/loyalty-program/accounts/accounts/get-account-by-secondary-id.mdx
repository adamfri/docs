    Retrieves the account belonging to the specified contact or member.

    This method retrieves loyalty accounts using either a customer's contact ID or member ID. You can also retrieve an account
    using the loyalty account ID with Get Account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-accounts/v1/accounts/fetch-by
    ```

    ## Response Object

    <ResponseField name="account" type="LoyaltyAccount">

      Loyalty account.

      See the [Account Object](/api-reference/crm/loyalty-program/accounts/accounts/account-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
