The Portfolio Settings API allows you to manage a site's portfolio settings, including configurations for its media and project items. Learn more about the [Wix Portfolio](fallback::https://support.wix.com/en/article/wix-portfolio-an-overview) feature.

With the Portfolio Settings API, you can:

+ [Update](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/portfolio-settings/update-portfolio-settings) a site's portfolio settings. 
+ [Retrieve](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/portfolio-settings/get-portfolio-settings) a site's existing portfolio settings. 
+ Listen for events when a site's portfolio settings are [created](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/portfolio-settings/portfolio-settings-created).

## Before you begin

It's important to note the following points before starting to code:

+ You can only use this API on sites where a Wix user has installed the [Wix Portfolio app](fallback::https://www.wix.com/app-market/web-solution/wix-portfolio?appIndex=0&collimp_id=b54d3569-fdaa-49f6-83f8-2ac6e400bd11&referralSectionName=wix%20portfolio).
+ Since each site only has 1 portfolio, the settings are automatically created when the app is installed. Call [Update Portfolio Settings](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/portfolio-settings/update-portfolio-settings) to make any changes.
