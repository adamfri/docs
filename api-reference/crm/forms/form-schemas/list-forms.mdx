    <div className="wix-ref">

    Retrieves a list of form schemas that meet the specified criteria.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/form-schema-service/v4/forms
    ```

    ## Query Params

    <ParamField query="namespace" type="string" required>

      Namespace of the form schemas to list.

      Constraints: `minLength 10`, `maxLength 50`.

    </ParamField>

    <ParamField query="disabled" type="boolean">

      Whether to list disabled form schemas.

    </ParamField>

    <ParamField query="order" type="string">

      Order to list forms in the response.

      Ordering options.

      - `UPDATED_DATE_DESC`: Order by `updatedDate` in descending order.
      - `UPDATED_DATE_ASC`: Order by `updatedDate` in ascending order.
      - `CREATED_DATE_ASC`: Order by `createdDate` in ascending order.
      - `CREATED_DATE_DESC`: Order by `createdDate` in descending order.
      - `NAME_ASC`: Order by `properties.name` in ascending order.
      - `NAME_DESC`: Order by `properties.name` in descending order.

      Default: `UPDATED_DATE_DESC`

      **Supported values:**

      - `UPDATED_DATE_DESC` — Sort by updated date in descending order. Default.
      - `UPDATED_DATE_ASC` — Sort by updated date in ascending order.
      - `CREATED_DATE_ASC` — Sort by created date in ascending order.
      - `CREATED_DATE_DESC` — Sort by created date in descending order.
      - `NAME_ASC` — Sort by name in ascending order.
      - `NAME_DESC` — Sort by name in descending order.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Cursor token pointing to a page of results. Not used in the first request. Following requests use the cursor token and not filter or `order`.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      List of additional form fields to include in the response. For example, use the `NESTED_FORMS` fieldset to retrieve the nested forms field in
      the response in addition to the form’s base fields. Base fields don’t include any of the supported fieldset values. By default
      only the form’s base fields are returned.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `NESTED_FORMS` — Include nested form fields in the response.
      - `METADATA` — Returns only top-level administrative properties (such as ID, name, and dates).
      Excludes heavy content structures like fields, steps, and rules.

    </ParamField>

    <ParamField query="formIds" type="string[]">

      IDs of specific form schemas to retrieve.

      When specified, only form schemas with these IDs are returned.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="paymentForm" type="boolean">

      Whether to filter for payment form schemas.

      When `true`, returns only form schemas that contain payment fields.
      When `false`, returns all form schemas regardless of payment fields.

    </ParamField>

    <ParamField query="additionalMetadata" type="object">

      Optional metadata passed to SPI implementer, allowing clients to include additional business-specific data.

    </ParamField>

    <ParamField query="nameFilter" type="NameFilter">

      Filter by name

      <Expandable title="nameFilter properties">

        <ParamField query="filterType" type="string">

          Type of name matching to perform.

          **Supported values:**

          - `EXACT_MATCH` — Return form schemas with names that exactly match the specified name.
          - `STARTS_WITH` — Return form schemas with names that start with the specified name.

        </ParamField>

        <ParamField query="name" type="string">

          Name or name prefix to search for.

          Constraints: `maxLength 200`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="enabled" type="boolean">

      Whether to filter for enabled form schemas.

      Filters by whether the form schema is enabled.

      When `true`, returns only enabled form schemas.
      When `false`, returns only disabled form schemas.

      There is no value that returns both. To retrieve every form schema in the namespace, call this method twice, once with each value.

      Default: `true`

    </ParamField>

    ## Response Object

    <ResponseField name="forms" type="Form[]">

      The retrieved forms.

      Constraints: `maxItems 100`.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Details on the paged set of results returned.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Offset that was requested.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates if there are more results after the current page.
          If `true`, another page of results can be retrieved.
          If `false`, this is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
