---
title: "Folder Object"
description: "Folders contain collection references as well as other folders."
icon: "cube"
---

Folders contain collection references as well as other folders. A root folder with an empty `id` always exists.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Folder ID. Automatically generated by Wix.

      The ID field is empty for the root folder.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Folder's name as displayed in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-collection-folders).

      `name` is empty for the root folder.

      Constraints: `maxLength 1024`.

    </ResponseField>

    <ResponseField name="description" type="string">

      Folder description.

    </ResponseField>

    <ResponseField name="folders" type="Folder[]">

      Folders nested in the current folder.

      Only the root folder may contain other folders.

      Constraints: `maxItems 1000`.

      _Recursive reference to `Folder[]`._

    </ResponseField>

    <ResponseField name="collectionReferences" type="CollectionReference[]">

      Collection references in the current folder.

      Constraints: `maxItems 1000`.

      <Expandable title="collectionReferences properties">

        <ResponseField name="collectionName" type="string">

          Collection's name as displayed in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-creating-a-collection).

          Constraints: `maxLength 255`, `immutable`.

        </ResponseField>

        <ResponseField name="folderId" type="string">

          ID of the folder that contains the collection reference.

          Omitted if the collection reference is in the root folder.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "8b61c188-fa1c-4abe-8f6d-de0d9cd88bff",
        "name": "Favorites",
        "description": "My favorite collections",
        "collectionReferences": [
          {
            "collectionName": "Menu"
          }
        ],
        "folders": [
          {
            "id": "5008a61d-b33b-4c82-a20c-b924ad07112a",
            "name": "Shopping list page",
            "description": "Collections bound to shopping list page",
            "collectionReferences": [
              {
                "collectionName": "ShoppingList"
              },
              {
                "collectionName": "ShoppingItems"
              }
            ],
            "folders": []
          }
        ]
      }
      ```

    </CodeGroup>
