    Lists facets from the site’s contact list.
    Facets include labels and subscription statuses.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.READ-CONTACTS">Read Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/contacts/facets
    ```

    <ResponseField name="facets" type="ContactsFacet[]">

      List of facets.

        <ResponseField name="facetType" type="string">

          Type of facet.

          - `NOT_LABELED`
          - `LABEL`
          - `SUBSCRIPTION_STATUS`
          - `MEMBERSHIP_STATUS`

        </ResponseField>

        <ResponseField name="namespace" type="string">

          Scope for facet keys.

        </ResponseField>

        <ResponseField name="namespaceDisplayName" type="string">

        </ResponseField>

        <ResponseField name="count" type="integer">

        </ResponseField>

        <ResponseField name="queryFilter" type="object">

          Filter used to query contacts of this facet.
