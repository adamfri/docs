    Creates a supplier profile.

    The supplier's `appId` is automatically set to the ID of the calling application. Use this endpoint when onboarding new suppliers to your marketplace provider's network.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/suppliers
    ```

    ## Body Params

    <ParamField body="supplier" type="Supplier" required>

      Supplier to be created.

      See the [Supplier Object](/api-reference/business-solutions/suppliers-hub/suppliers/supplier-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="supplier" type="Supplier">

      The created Supplier.

      See the [Supplier Object](/api-reference/business-solutions/suppliers-hub/suppliers/supplier-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>
