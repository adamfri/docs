<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Resends a copy of the campaign to recipients who didn't open the original. Optionally, a different subject line can be used to improve open rates.

    The original campaign must have been sent at least 24 hours before resending and must have recipients who didn't open the email. Can only be called once per campaign.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/resend
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      ID of the campaign to resend.

    </ParamField>

    ## Body Params

    <ParamField body="emailSubject" type="string">

      Alternative subject line for the resent email. Use a different subject to improve open rates.

    </ParamField>

    ## Response Object

    <ResponseField name="campaignId" type="string">

      ID of the newly created and resent campaign.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Campaign Rejected Event | `wix.email_marketing.v1.campaign_campaign_rejected_event` | Triggered when a campaign is identified as abusive and rejected without sending emails to recipients. |
    | Campaign Published Event | `wix.email_marketing.v1.campaign_campaign_published_event` | Triggered when a draft campaign is published. |
    | Campaign Terminated Event | `wix.email_marketing.v1.campaign_campaign_terminated_event` | Triggered when a campaign is terminated after failing the sampling test due to poor mailing list quality. |
    | Campaign Distributed Event | `wix.email_marketing.v1.campaign_campaign_distributed_event` | Triggered when a campaign is successfully distributed to all recipients. |

    </div>
