    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/components/v1/components/get-max/{appId}
    ```

    ## Path Params

    <ParamField path="appId" type="string" required>

      App ID.

    </ParamField>

    ## Query Params

    <ParamField query="consistent" type="boolean">

      Whether to return consistent results for read-after-write operations.

    </ParamField>
