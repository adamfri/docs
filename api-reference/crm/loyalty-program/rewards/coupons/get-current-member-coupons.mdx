    <div className="wix-ref">

    Retrieves the loyalty coupons for the currently logged-in member.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-coupons/v1/coupons/my-coupons
    ```

    ## Response Object

    <ResponseField name="loyaltyCoupons" type="LoyaltyCoupon[]">

      Retrieved loyalty coupons.

      See the [Coupon Object](/api-reference/crm/loyalty-program/rewards/coupons/coupon-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
