    Sets a site's multilingual mode.

    Multilingual mode allows a site to support multiple locales. This means that when multilingual mode is enabled, you can create and manage secondary locales.

    To disable multilingual mode, all secondary locales must first be removed. This action removes all translated content from your site. Disabling multilingual mode will also reset the locale settings to their default values.

    <Note>

    You can only call this method on sites where a Wix user has installed the [Wix Multilingual app](https://www.wix.com/app-market/wix-multilingual?searchLocation=home).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/locale-settings/v2/settings/mode
    ```

    ## Body Params

    <ParamField body="multilingualModeEnabled" type="boolean" required>

      Whether to enable multilingual mode for the site.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="localeSettings" type="LocaleSettings">

      Updated locale settings.

      See the [Locale Settings Object](/api-reference/business-management/multilingual/locale-management/locale-settings/locale-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `SITE_CONTAIN_SECONDARY_LOCALES` | Can't disable multilingual mode while secondary locales exist on the site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Locale Settings Multilingual Mode Updated | `wix.multilingual.settings.v2.locale_settings_multilingual_mode_updated` | Triggered when the site's multilingual mode is updated. |

    </div>
