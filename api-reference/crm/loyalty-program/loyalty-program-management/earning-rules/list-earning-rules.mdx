    <div className="wix-ref">

    Retrieves a list of earning rules.

    Returns both automated and non-automated earning rules.

    You can filter the results by `triggerAppId` or `triggerActivityType`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_api/loyalty-earning-rules/v1/earning-rules/rules
    ```

    ## Query Params

    <ParamField query="triggerAppId" type="string">

      App ID that triggers the point assignment. For example, `9a5d83fd-8570-482e-81ab-cfa88942ee60`.

    </ParamField>

    <ParamField query="triggerActivityType" type="string">

      Type of activity that triggers the point assignment. For example, `restaurants-order-is-pending`.

    </ParamField>

    ## Response Object

    <ResponseField name="earningRules" type="LoyaltyEarningRule[]">

      Retrieved earning rules.

      See the [Loyalty Earning Rule Object](/api-reference/crm/loyalty-program/loyalty-program-management/earning-rules/loyalty-earning-rule-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
