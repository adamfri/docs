    <div className="wix-ref">

    Retrieves a product with the provided ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-PRODUCTS">Read Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v1/products/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Requested product ID.

    </ParamField>

    ## Query Params

    <ParamField query="includeMerchantSpecificData" type="boolean">

      Whether merchant specific data, such as cost and profit data, should be included in the response. Requires permissions to manage products.

    </ParamField>

    ## Response Object

    <ResponseField name="product" type="Product">

      Requested product data.

      See the [Product Object](/api-reference/business-solutions/stores/catalog-v1/catalog/product-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
