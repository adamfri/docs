Triggered at the start of a new payment cycle for an existing order.

Not triggered at the initial start of an offline order.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pricing_plans.v2.order_cycle_started` |
| Package | `@wix/pricing-plans` |
| Permissions | `Manage Orders`, `Read Orders`, `Manage Events` |
