    Removes the pattern a site has for a page type, so the Wix default applies again.

    The response reports the page type after the reset, with an empty `pattern` and
    `source` of `PATTERN_SOURCE_DEFAULT`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/seo/v1/seo-patterns/{pageType}/reset-to-default
    ```

    ## Path Params

    <ParamField path="pageType" type="string" required>

      Page type whose pattern to reset. For example, `STATIC_PAGE`, `BLOG_POST`, or
      `STORES_PRODUCT`.

    </ParamField>

    ## Body Params

    <ParamField body="pageId" type="string">

      ID of a single page built from a Wix Data collection, to reset the pattern of that
      page alone.

      Supported only for the `WIX_DATA_PAGE_ITEM` page type.

    </ParamField>

    ## Response Object

    <ResponseField name="seoPattern" type="SeoPattern">

      The page type after the reset: an empty `pattern`, and `source` of
      `PATTERN_SOURCE_DEFAULT`.

      See the [Seo Pattern Object](/api-reference/business-management/seo/seo-pattern-v1/seo-pattern-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_PAGE_TYPE` | Wix doesn't recognize the specified `pageType`. The error message lists the page types that are supported. |
    | `404` | `NOT_FOUND` | `PATTERN_NOT_FOUND` | Couldn't find the pattern. The site has no pattern of its own for this page type, so there's nothing to reset. |
    | `400` | `INVALID_ARGUMENT` | `PAGE_ID_NOT_SUPPORTED` | A `pageId` was specified for a page type that has a single pattern for the whole type. Only `WIX_DATA_PAGE_ITEM` supports a per-page pattern. |
    | `400` | `INVALID_ARGUMENT` | `COLLECTION_NAME_NOT_SUPPORTED` | A `collectionName` was specified. Resolving a dynamic page by collection isn't supported yet, so specify the page's ID in `pageId` instead. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
