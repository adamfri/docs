This article shares a possible use case for your implementation, as well as an example flow that supports it.
You're certainly not limited to this use case, but it can be a helpful jumping off point as you plan your implementation.

## Set Up a New Main Business Location

You can help Wix users create a new business location, set it as default, and update the opening hours for a location.

1. Call [Create Location](https://dev.wix.com/docs/sdk/backend-modules/business-tools/locations/create-location).

2. Set the new location as **default** by calling [Set Default Location](https://dev.wix.com/docs/sdk/backend-modules/business-tools/locations/set-default-location).

3. List all existing locations by calling [List Locations](https://dev.wix.com/docs/sdk/backend-modules/business-tools/locations/list-locations).

   <Note>

   Make sure to extract the relevant locations’ IDs from the response and save it for future calls.

   </Note>

4. Update a location's opening hours by calling [Update Location](https://dev.wix.com/docs/sdk/backend-modules/business-tools/locations/update-location).

   <Note>

   Currently, it isn't possible to partially update a location. Therefore, you'll need to specify the full location object when making the call.

   </Note>
