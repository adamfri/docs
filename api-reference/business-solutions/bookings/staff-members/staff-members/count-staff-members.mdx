    Counts how many staff members match the given filter.

    Counts only staff members who are service providers. To count the business's entire staff,
    including staff members who don't provide services, pass a `serviceProvider` filter or call
    [Count Staff Members V2](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/count-staff-members-v2).

    ### See also

    For the fields you can filter by, see [Filtering and Sorting](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/filtering-and-sorting).

    To learn about working with filters in general, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#filters).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/staff-members/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter to base the count upon.
      See [Query Staff Members](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/staff-members/query-staff-members)
      for a complete list of supported filters.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total number of staff members matching the given filter.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
