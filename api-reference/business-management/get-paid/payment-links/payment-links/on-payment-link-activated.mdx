Triggered when a payment link is activated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.paymentlinks.v1.payment_link_payment_link_activated` |
| Package | `@wix/get-paid` |
| Permissions | `Manage Stores`, `Manage Paylinks` |
