    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the current user's permissions for the specified data collection.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wix-data/v1/permissions/current
    ```

    ## Query Params

    <ParamField query="dataCollectionId" type="string" required>

      ID of the collection for which to check the current user's permissions.

      Constraints: `maxLength 256`.

    </ParamField>

    ## Response Object

    <ResponseField name="itemRead" type="boolean">

      Whether the current user can read items from the collection.

    </ResponseField>

    <ResponseField name="itemInsert" type="boolean">

      Whether the current user can create new items in the collection.

    </ResponseField>

    <ResponseField name="itemUpdate" type="boolean">

      Whether the current user can update existing items in the collection.

    </ResponseField>

    <ResponseField name="itemRemove" type="boolean">

      Whether the current user can remove items from the collection.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0025` | Returned when the specified data collection isn't found. Learn more about [Wix Data error codes](https://dev.wix.com/docs/rest/business-solutions/cms/wix-data-error-codes). |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request

        -H 'Content-Type: application/json' \

      ```

