The Projects API allows you to manage projects in a site's portfolio. Learn more about [projects in Wix Portfolio](fallback::https://support.wix.com/en/article/wix-portfolio-managing-your-wix-portfolio#managing-your-projects).

With the Projects API, you can:

+ [Create](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/create-project), [update](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/update-project), and [delete](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/delete-project) projects. 
+ [Retrieve](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/get-project), [list](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/list-projects), and [query](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/query-projects) projects.
+ Listen for events when a project is [created](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/project-created), [updated](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/project-updated), and [deleted](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/project-deleted). 

## Before you begin

It's important to note the following points before starting to code:

+ To add or update a cover image or video for projects, first upload the media file to the [Wix Media Manager](fallback::https://support.wix.com/en/article/wix-media-about-the-media-manager) by calling the [Import File](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/import-file) method.
+ You can only use this API on sites where a Wix user has installed the [Wix Portfolio app](fallback::https://www.wix.com/app-market/web-solution/wix-portfolio?appIndex=0&collimp_id=b54d3569-fdaa-49f6-83f8-2ac6e400bd11&referralSectionName=wix%20portfolio).
