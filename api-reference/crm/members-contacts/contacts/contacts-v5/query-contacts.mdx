    Retrieves a list of up to 100 contacts, given the provided filtering, sorting, and cursor paging.

    Query Contacts runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order
    - `paging.limit` is `50`

    To learn about working with Query methods, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language), [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging), and [Field Projection](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$in` | None |
    | `createdDate` | `$eq`, `$gt`, `$lt`, `$gte`, `$lte` | Sort: `ASC` |
    | `updatedDate` | `$eq`, `$gt`, `$lt`, `$gte`, `$lte` | Sort: `ASC` |
    | `email.email` | `$eq`, `$in`, `$exists` | None |
    | `phone.phone` | `$eq`, `$in`, `$exists` | None |
    | `externalId` | `$eq`, `$in`, `$exists` | None |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
