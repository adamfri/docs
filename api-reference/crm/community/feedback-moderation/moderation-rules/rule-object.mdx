<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Rule ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the rule is updated. To prevent conflicting changes, the existing `revision` must be used when updating a rule.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when the rule was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time when the rule was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="namespace" type="string">

      The app name and entity which the rule belongs to.
      Currently, moderation rules support [Comments](https://dev.wix.com/docs/rest/crm/community/comments/comments/introduction)
      and [Reviews](https://dev.wix.com/docs/rest/crm/community/reviews/reviews/introduction):

      + When the `namespace` is `comments` the format is `comments/{APP_ID}`. For example, for moderating content on Wix Blog the `namespace` is `"comments/14bcded7-0066-7c35-14d7-466cb3f09103"`.
      + When the `namespace` is `reviews` the format is `reviews/{APP_NAME}`. For example, for moderating content on Wix Reviews the `namespace` is `"reviews/stores"`.

      To retrieve the ID for a Wix app, see
      [Apps Created By Wix](https://dev.wix.com/docs/rest/articles/get-started/apps-created-by-wix).

      Constraints: `minLength 1`, `maxLength 120`.

    </ResponseField>

    <ResponseField name="name" type="string">

      Rule name.

      Constraints: `maxLength 120`.

    </ResponseField>

    <ResponseField name="audience" type="Audience">

      Audience to which the rule applies.

      <Expandable title="audience properties">

        <ResponseField name="type" type="string">

          Audience type.

          **Supported values:**

          - `VISITORS`
          - `MEMBERS`
          - `MEMBERS_AND_VISITORS`
          - `NEW_MEMBERS`

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="options" type="options">

          options

          <Expandable title="options properties">

            <ResponseField name="newMembersOptions" type="NewMembersOptions">

              Options for new members.

              **Note:** This object is relevant only when `type` is `NEW_MEMBERS`.

              <Expandable title="newMembersOptions properties">

                <ResponseField name="durationInHours" type="integer">

                  For how many hours the member is new.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="trigger" type="Trigger">

      A condition that triggers the rule.

      **Note:** If you need to have several triggers for the same `namespace`, create separate rules.

      <Expandable title="trigger properties">

        <ResponseField name="type" type="string">

          Trigger type.

          **Supported values:**

          - `PATTERNS` — The trigger is a specific word or phrase. You can specify additional options in the `patternsOptions` object.
          - `CONTENT_FEATURES` — The rule is triggered when non-textual features, such as videos, images, links, and attachments, exist in the content. You can specify additional options in the `contentFeaturesOptions` object.
          - `ATTRIBUTE` — A custom trigger based on an attribute and its value. For example, if you'd like to check all reviews with a low rating, then `name` would be `rating`, and `values` would be `[1, 2]`. You can specify additional options in the `patternsOptions` object.
          - `ALWAYS` — There is no specific trigger. The rule is triggered whenever new content is created or existing content is updated, with no other conditions required.

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="options" type="options">

          options

          <Expandable title="options properties">

            <ResponseField name="patternsOptions" type="Patterns">

              Options for the patterns trigger.

              <Expandable title="patternsOptions properties">

                <ResponseField name="words" type="string[]">

                  List of words that can trigger a rule. The `*` wildcard can be used to match a partial word. For example:
                  - `spam`: Matches only "spam".
                  - `spam*`: Matches "spam", "spammer", "spammy".
                  - `*spam`: Matches "antispam", "multispam".
                  - `sp*m`: Matches "spim", "spam", "spum".

                  Constraints: `maxLength 50`, `maxItems 1000`.

                </ResponseField>

                <ResponseField name="expressions" type="string[]">

                  [Regular expressions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions).

                  Constraints: `maxLength 300`, `maxItems 10`.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="contentFeaturesOptions" type="ContentFeatures">

              Options for the content features trigger.

              <Expandable title="contentFeaturesOptions properties">

                <ResponseField name="videos" type="boolean">

                  Whether the content contains videos.

                </ResponseField>

                <ResponseField name="images" type="boolean">

                  Whether the content contains images.

                </ResponseField>

                <ResponseField name="links" type="boolean">

                  Whether the content contains links.

                </ResponseField>

                <ResponseField name="attachments" type="boolean">

                  Whether the content contains attachments or files.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="attributeOptions" type="Attribute">

              Options for the attributes trigger. You can only have 1 attribute per rule.

              <Expandable title="attributeOptions properties">

                <ResponseField name="name" type="string">

                  Attribute name.

                  Constraints: `maxLength 20`.

                </ResponseField>

                <ResponseField name="values" type="string[]">

                  Attribute values.

                  Constraints: `maxLength 20`, `maxItems 20`.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="exemptions" type="Exemptions">

      List of site members or groups to whom the rule doesn't apply.

      <Expandable title="exemptions properties">

        <ResponseField name="memberGroups" type="string[]">

          List of member groups.

          Constraints: `format GUID`, `maxItems 50`.

        </ResponseField>

        <ResponseField name="memberIds" type="string[]">

          List of member IDs.

          Constraints: `format GUID`, `maxItems 50`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="action" type="Action">

      What action should be taken after the rule is triggered.

      <Expandable title="action properties">

        <ResponseField name="type" type="string">

          Action type.

          **Supported values:**

          - `UNKNOWN_TYPE`
          - `REJECT` — Reject the content without any further review.
          - `NEEDS_MANUAL_APPROVAL` — Send the content for manual review.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="enabled" type="boolean">

      Whether the rule is enabled.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the rule object.

      **Note:** You must configure extended fields using schema plugin extensions in your app's dashboard before you can access the extended fields with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "rule": {
          "id": "e3acb53a-cfed-41bc-9de5-e4060426c13a",
          "revision": "1",
          "createdDate": "2023-10-06T13:57:20.564Z",
          "updatedDate": "2023-10-06T13:57:20.564Z",
          "namespace": "comments/14bcded7-0066-7c35-14d7-466cb3f09103",
          "name": "Forbid to comment with link",
          "audience": {
            "type": "MEMBERS"
          },
          "trigger": {
            "contentFeatures": {
              "videos": false,
              "images": false,
              "links": true
            }
          },
          "exemptions": {
            "memberGroups": ["1149dbee-acc1-49ac-bedf-43176155e84a"],
            "memberIds": ["05565bc9-3d16-4fc8-ab8e-20b13a0730d8"]
          },
          "action": {
            "type": "REJECT"
          },
          "enabled": true
        }
      }
      ```

    </CodeGroup>
