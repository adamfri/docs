    Resolves effective promotions for a category. Only enabled promotions are returned, sorted by position in ascending order.

    A promotion is effective for the category when it's assigned to the category directly, or when it's assigned to any of the
    category's ancestors with `appliedToSubcategories` set to `true`. A promotion that's effective at several positions is
    returned once per position.

    Conflicts are resolved separately for each position: when multiple promotions are effective at the same position,
    the promotion with the latest activation date takes precedence, with the promotion ID as a tie-breaker.
    The activation date is the later of the promotion's creation date and the date it was last enabled.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_READ">Read v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/promotions/resolve
    ```

    ## Query Params

    <ParamField query="categoryId" type="string" required>

      Category ID to resolve effective promotions for.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="promotions" type="PositionedPromotion[]">

      Enabled promotions that are effective for the category, sorted by position in ascending order.

      <Expandable title="promotions properties">

        <ResponseField name="promotion" type="Promotion">

          Promotion.

          See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

        </ResponseField>

        <ResponseField name="position" type="integer">

          Position of the promotion within the category, starting from 1.

          Constraints: `min 1`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CATEGORY_NOT_FOUND` | Couldn't find the category. |
