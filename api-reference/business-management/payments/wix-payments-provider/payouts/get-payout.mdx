    Retrieves a single payout by ID.

    Calls are limited to 100 requests per 10 seconds per caller. Requests
    over the limit fail with a `RESOURCE_EXHAUSTED` error and the message
    `The request was throttled`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYMENTS.PAYOUTS-VIEW-FOR-SITE">View settlement reports and payouts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wixpay-payouts/v4/payouts/{payoutId}
    ```

    ## Path Params

    <ParamField path="payoutId" type="string" required>

      ID of the payout to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="accountId" type="string" required>

      ID of the Wix Payments account that owns the payout. The payout must
      belong to this account. Retrieve account IDs from the Accounts API.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="payout" type="Payout">

      Retrieved payout.

      See the [Payout Object](/api-reference/business-management/payments/wix-payments-provider/payouts/payout-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
