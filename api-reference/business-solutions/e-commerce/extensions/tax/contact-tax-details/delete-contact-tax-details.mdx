    Deletes a contact's tax details.

    Deleting a contact's tax details removes the contact's association with any tax exempt group, so the contact is no longer exempt at checkout.

    To delete tax details for multiple contacts in a single API call, call [Bulk Delete Contact Tax Details](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/bulk-delete-contact-tax-details).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/billing/v1/contact-tax-details/{contactTaxDetailsId}
    ```

    ## Path Params

    <ParamField path="contactTaxDetailsId" type="string" required>

      ID of the contact whose tax details to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteContactTaxDetailsResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
