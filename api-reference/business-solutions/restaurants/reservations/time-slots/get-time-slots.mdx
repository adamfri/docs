    Returns a list of time slots at a specified reservation location on a specified `date`, and their availability for a specified `partySize`.

    Without passing optional parameters, the list will contain a single time slot at the specified `date`.
    Use `slotsBefore` and `slotsAfter` to get additional time slots before and after the specified `date`.

    If you do not provide a `duration`, the duration will be calculated automatically based on the reservation location's configuration.
    The reservation location's settings used to determine the duration are its `defaultTurnoverTime` and `turnoverTimeRules`. These specify how much time should be allotted for a reservation of a party of a specified size.

    The interval between `startDate`s of time slots in the response is determined by the reservation location's `timeSlotInterval`. This interval is not affected by the `duration` provided.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-BASIC">Manage Reservations (Basic)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/reservations/v1/time-slots
    ```

    ## Body Params

    <ParamField body="reservationLocationId" type="string" required>

      ID of the reservation location for which to retrieve time slots.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="date" type="datetime" required>

      Date and time for which to retrieve a time slot in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601#coordinated_Universal_Time_(UTC)) format.

    </ParamField>

    <ParamField body="duration" type="integer">

      Duration in minutes of the time slot.

      Min: `5`

    </ParamField>

    <ParamField body="partySize" type="integer" required>

      Size of the party that needs to be seated during this time slot.

      Min: `1`

    </ParamField>

    <ParamField body="slotsBefore" type="integer">

      The number of time slots to retrieve before the specified `date`.

    </ParamField>

    <ParamField body="slotsAfter" type="integer">

      The number of time slots to retrieve after the specified `date`.

    </ParamField>

    ## Response Object

    <ResponseField name="timeSlots" type="TimeSlot[]">

      A list of time slots and their availability according to the specified party size.

      See the [Time Slot Object](/api-reference/business-solutions/restaurants/reservations/time-slots/time-slot-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
