<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Translation schema ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="key" type="SchemaKey">

      Translation schema unique key identifier.

      <Expandable title="key properties">

        <ResponseField name="appId" type="string">

          ID of the app that created the schema.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="entityType" type="string">

          A unique name defined by the app developer to differentiate translation schemas for various entities within their app. For example, if an app developer is creating a translation schema for blog posts, the `entityType` can be `'blog-posts'`.

          Constraints: `minLength 1`, `maxLength 100`, `immutable`.

        </ResponseField>

        <ResponseField name="scope" type="string">

          Scope of the translation schema.

          Constraints: `immutable`.

          **Supported values:**

          - `GLOBAL` — Global schema for all sites.
          - `SITE` — Custom schema for a specific site.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="fields" type="object">

      List of fields for the translation schema. This property uses a string to map to a `SchemaField` (`Map<string, SchemaField>`). The string serves as a key, which you'll need to access each field in the schema and when adding translation content.

      Constraints: `format map`, `minItems 1`, `maxItems 1000`.

      <Expandable title="fields properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="SchemaField">

          <Expandable title="value properties">

            <ResponseField name="id" type="string">

              Field ID. Validated according to Regex `^[A-Za-z0-9-_)(]+$`. Field IDs may contain parentheses to reference repeated items, such as images. These parentheses can't be nested and each opening parenthesis must be followed by a closing one. For example, `title()()` is valid, while `title)(` and `title(())` aren't valid. The value inside the parenthesis is validated according to Regex `^[^)(\\]\\[\\.]+$`.

              **Read-only.** Constraints: `minLength 1`, `maxLength 1000`.

            </ResponseField>

            <ResponseField name="type" type="string">

              **Required.** Field type.

              **Supported values:**

              - `SHORT_TEXT` — Short plain text displayed as a single line in the UI.
              - `LONG_TEXT` — Long plain text displayed as multiple lines in the UI.
              - `HTML` — Long text including styles, images, and links.
              - `RICH_CONTENT` — Rich-Content using the Wix Ricos format.
              - `IMAGE` — Wix Media Manager image.
              - `IMAGE_LINK` — Image URL without metadata.
              - `VIDEO` — Wix Media Manager video.
              - `DOCUMENT` — Wix Media Manager document.

            </ResponseField>

            <ResponseField name="displayName" type="string">

              Field name displayed in the [Translation Manager](https://support.wix.com/en/article/wix-multilingual-using-the-translation-manager).

            </ResponseField>

            <ResponseField name="groupName" type="string">

              Field group name.

            </ResponseField>

            <ResponseField name="minLength" type="integer">

              Field minimum text length.

            </ResponseField>

            <ResponseField name="maxLength" type="integer">

              Field maximum text length.

            </ResponseField>

            <ResponseField name="format" type="string">

              Field format. Content is validated based on the format set here in the field schema. For example, if the format is `EMAIL`, then the content for this field must be a valid email address.

            </ResponseField>

            <ResponseField name="hidden" type="boolean">

              Whether the field is hidden from the site. Hidden fields are still validated.

            </ResponseField>

            <ResponseField name="displayOnly" type="boolean">

              Whether the field is read-only, and not intended to be translated. For example, an image. Use this field when you want an image to remain in the [Translation Manager](https://support.wix.com/en/article/wix-multilingual-using-the-translation-manager) for context, but without being translated.

            </ResponseField>

            <ResponseField name="index" type="number">

              Field index. Use for cases where the order of the fields are relevant.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="previewFields" type="PreviewFields">

      Fields displayed in content previews. For example, a product name for a product translation schema.

      <Expandable title="previewFields properties">

        <ResponseField name="titleFieldId" type="string">

          ID of the field representing the schema's title.

        </ResponseField>

        <ResponseField name="imageFieldId" type="string">

          ID of the field representing the schema's image.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="hidden" type="boolean">

      Whether the translation schema is hidden from the site.

      Default: `false`

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Translation schema name displayed in the [Translation Manager](https://support.wix.com/en/article/wix-multilingual-using-the-translation-manager).

    </ResponseField>

    <ResponseField name="parentId" type="string">

      A reference to the parent schema. For example, if the schema is for a menu item,
      this property would contain the schema ID of the menu it belongs to.

      Required when `require_parent_entity` is set to `true`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the schema is updated. To prevent conflicting changes, the existing `revision` must be used when updating a schema.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the translation schema was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the translation schema was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="duplicateContent" type="boolean">

      Whether to duplicate the translated content when a site containing the translation schema and content is duplicated.

      Default: `false`

    </ResponseField>

    <ResponseField name="schemaGroupId" type="string">

      Indicate if this schema should be grouped under a custom group in the Translation Manager
      For more info about this field check dev-center extension `Multilingual Schema Group`

    </ResponseField>

    <ResponseField name="requireParentEntity" type="boolean">

      Whether content created or updated with this schema must include a `parent_entity_id`.
      When set to `true`, any Create Content or Update Content call targeting this schema
      will fail if `parent_entity_id` is missing or empty.

      The schema itself must also have a `parent_id` defined, otherwise the schema
      Create or Update call will fail with `SchemaRequireParentEntityWithoutParentIdException`.

      Default: `false`

      Example: A "menu-item" schema that always belongs to a "menu" parent schema would set
      `require_parent_entity = true` and `parent_id` to the "menu" schema ID. Every translation
      content item created for "menu-item" must then specify which menu it belongs to via
      `parent_entity_id`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "schema": {
          "id": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
          "revision": 1,
          "createdDate": "2019-10-30T17:22:10.299Z",
          "updatedDate": "2019-10-30T17:22:10.299Z",
          "key": {
            "appId": "4ad2dfe1-a943-45a8-94ac-f1dd8b78821b",
            "entityType": "Product",
            "scope": "GLOBAL"
          },
          "fields": {
            "title": {
              "id": "title",
              "type": "SHORT_TEXT",
              "display_name": "Title",
              "minLength": 1,
              "maxLength": 54,
              "hidden": false,
              "displayOnly": false
            },
            "description": {
              "id": "description",
              "type": "RICH_CONTENT",
              "display_name": "Description",
              "minLength": 1,
              "maxLength": 256,
              "hidden": false,
              "displayOnly": false
            },
            "image()": {
              "id": "image()",
              "type": "IMAGE",
              "displayName": "Product's Image",
              "minLength": null,
              "maxLength": null,
              "hidden": false,
              "displayOnly": false
            }
          }
        }
      }
      ```

    </CodeGroup>
