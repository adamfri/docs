    Moves a step within a section or to a different section.

    Each time the step is updated, `revision` increments by 1. Pass the current `revision` when possible to protect against conflicting updates.

    If `afterStepId` isn't specified, the step is moved to the beginning of the target section.
    The step's ordering is recalculated automatically.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/online-programs/v3/steps/{stepId}/move
    ```

    ## Path Params

    <ParamField path="stepId" type="string" required>

      Step ID.

    </ParamField>

    ## Body Params

    <ParamField body="sectionId" type="string" required>

      Target section ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="afterStepId" type="string">

      Step ID after which to place the moved step. Leave empty to move the step to the beginning of the target section.

    </ParamField>

    <ParamField body="revision" type="string">

      Current revision of the step. Pass it when available to protect against conflicting updates.

    </ParamField>

      Moved step.

    </ResponseField>
