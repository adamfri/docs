The Sections API allows you to manage menu sections. Sections gather together various dishes (or [items](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item/introduction)) into groups, such as "Appetizers", "Mains", "Desserts", "Drinks" and so on.    

With the Section API, you can:

- Create, delete, and update sections.
- Retrieve the information about a section.

<Warning>

While it's technically possible, adding the same section to multiple menus can break some functionality on Wix sites. We strongly recommend that you avoid adding any section to more than 1 menu.

</Warning>

## Before you begin

It's important to note the following point before starting to code:

- The Sections API only works with the Wix Restaurants Menus app. Make sure you have installed this app from the [Wix App Market](fallback::https://www.wix.com/app-market/wix-restaurants-menus-new).
