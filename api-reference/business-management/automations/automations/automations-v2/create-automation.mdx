    <div className="wix-ref">

    Creates an automation.

    <Note>

    Create and Update don't validate the automation configuration. Call [Validate Automation](https://dev.wix.com/docs/api-reference/business-management/automations/automations/automations-v2/validate-automation) before activating the automation to find configuration errors.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/automations-service/v2/automations
    ```

    ## Body Params

    <ParamField body="automation" type="Automation" required>

      Automation to create.

      See the [Automation Object](/api-reference/business-management/automations/automations/automations-v2/automation-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="automation" type="Automation">

      Details of the created automation.

      See the [Automation Object](/api-reference/business-management/automations/automations/automations-v2/automation-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Automation Created | `wix.automations.v2.automation_created` |  |
