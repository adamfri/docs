Triggered when a folder is updated, including when a folder is moved to a different parent folder.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.media.site_media.v1.folder_updated` |
| Package | `@wix/media` |
| Permissions | `Manage Bookings Services and Settings`, `Manage Events`, `Manage Challenges`, `Read Media Manager`, `Manage Media Manager`, `Manage Portfolio`, `Access Verticals by Automations`, `Manage Restaurants - all permissions`, `Set Up Automations`, `Picasso private app mega scope` |

## Examples

  ```javascript onFolderUpdated
  import { folders } from '@wix/media';

  folders.onFolderUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onFolderUpdated (self-hosted)

     }),
     modules: {
        folders,
      },
  });

  wixClient.folders.onFolderUpdated((event) => {
      // handle your event here
  });
  ```
