    <div className="wix-ref">

    Retrieves a list of custom field applications.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/custom-fields-applications/applications
    ```

    ## Body Params

    <ParamField body="customFieldIds" type="string[]" required>

      List of IDs of the custom fields with applications to retrieve.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="applications" type="CustomFieldApplication[]">

      Retrieved list of custom field applications.

      See the [Custom Field Application Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-field-applications/custom-field-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
