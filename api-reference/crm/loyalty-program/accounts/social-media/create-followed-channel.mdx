  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates an entity for the specified account ID when the account follows a social media channel.

    Members can only follow enabled channels. A Wix user has to enable channels in the dashboard.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-social-media/v1/followed-channels
    ```

    ## Body Params

    <ParamField body="followedChannel" type="FollowedChannel" required>

      Followed social media channel details.

      See the [Followed Channel Object](/api-reference/crm/loyalty-program/accounts/social-media/followed-channel-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="followedChannel" type="FollowedChannel">

      Followed social media channel details.

      See the [Followed Channel Object](/api-reference/crm/loyalty-program/accounts/social-media/followed-channel-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Followed Channel Created | `wix.loyalty.socialmedia.v1.followed_channel_created` | Triggered when an account follows a new channel. |

    </div>
