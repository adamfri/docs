---
title: "Loyalty Earning Rule Object"
description: "A loyalty earning rule defines how customers earn points in a loyalty program."
icon: "cube"
---

A loyalty earning rule defines how customers earn points in a loyalty program.
You can create rules for different activities, such as making purchases.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Loyalty earning rule ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="sourceAppId" type="string">

      ID of the app managing the earning rule. Can be a loyalty app ID or a Wix automations app ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="triggerAppId" type="string">

      ID of the app that triggers point assignment. Examples: Wix Stores, Wix Bookings, Wix Events.

      Constraints: `minLength 1`, `maxLength 80`.

    </ResponseField>

    <ResponseField name="triggerActivityType" type="string">

      Type of activity that triggers point assignment. For example, `wix-restaurants/orderSubmitted` or `birthday`.

      Constraints: `minLength 1`, `maxLength 80`.

    </ResponseField>

    <ResponseField name="title" type="string">

      Name of the earning rule.

      Constraints: `minLength 1`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the earning rule.

      **Supported values:**

      - `ACTIVE` — Earning rule is active and can assign points.
      - `PAUSED` — Earning rule is paused and can't assign points.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, incremented by 1 each time the earning rule is updated.
      Pass the latest `revision` when updating to prevent conflicting changes.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the earning rule was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the earning rule was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="metadata" type="Metadata">

      Additional metadata about the earning rule.

      **Read-only.**

      <Expandable title="metadata properties">

        <ResponseField name="canBeDeleted" type="boolean">

          Whether the earning rule can be deleted.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="triggerFilters" type="AutomationTriggerFilter[]">

      Trigger filters parsed from automation configuration. Only present for automation-based rules with filters.

      **Read-only.** Constraints: `maxItems 100`.

      <Expandable title="triggerFilters properties">

        <ResponseField name="fieldKey" type="string">

          Key identifying the field in the trigger payload (e.g., "service_id", "eventId", "programId").

          Constraints: `maxLength 110`.

        </ResponseField>

        <ResponseField name="values" type="string[]">

          Parsed entity IDs that the filter matches against.

          Constraints: `maxLength 256`, `maxItems 100`.

        </ResponseField>

      </Expandable>

    </ResponseField>
