    <Note>

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/delivery-profiles/remove-delivery-carrier
    ```

    ## Body Params

    <ParamField body="deliveryRegionId" type="string" required>

      Delivery region ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="appId" type="string" required>

      App ID of the delivery carrier to remove.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="deliveryProfile" type="DeliveryProfile">

      Updated delivery profile.

      See the [Delivery Profile Object](/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/delivery-profile-object) for this object's fields.

    </ResponseField>
