    Retrieves a group.

    For groups with `group.privacyStatus` set to `SECRET`, only group admins and group members can see the group and its content.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-groups-proxy/groups/v2/groups/{groupId}
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      ID of the group to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="contentType" type="string">

      Content type.

      **Supported values:**

      - `PLAIN_TEXT`
      - `DRAFTJS`
      - `RICH_CONTENT`

    </ParamField>

    ## Response Object

    <ResponseField name="group" type="Group">

      Retrieved group.

      See the [Group Object](/api-reference/crm/community/groups/groups/group-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
