    Creates a draft program.

    The service sets the program ID, revision, creation dates, owner, and initial
    `DRAFT` status. Publish the program when it's ready to be visible
    according to its access restrictions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/v3/programs
    ```

    ## Body Params

    <ParamField body="program" type="Program" required>

      Program to create. Server-generated fields such as `id`, `revision`, status, dates, owner, and content summary are ignored on create.

      See the [Program Object](/api-reference/business-management/online-programs/programs/program-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="program" type="Program">

      Created draft program.

      See the [Program Object](/api-reference/business-management/online-programs/programs/program-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
