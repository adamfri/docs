---
title: "Credit Transaction Object"
description: "A CreditTransaction represents a credit charge deducted from a user's balance for performing an AI action or other credit-consuming operation."
icon: "cube"
---

A CreditTransaction represents a credit charge deducted from a user's balance for performing an AI action or other credit-consuming operation.

Each transaction records the monetary cost of the operation, the equivalent number of credits charged and metadata about the operation that triggered the charge.
CreditTransactions are immutable records created through the Charge method and serve as an audit trail for credit usage and billing purposes.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      CreditTransaction ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the CreditTransaction is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the CreditTransaction.

      Ignored when creating a CreditTransaction.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the CreditTransaction was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the CreditTransaction was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="amount" type="Amount">

      Transaction value in credits and actual price.

      <Expandable title="amount properties">

        <ResponseField name="credits" type="integer">

          Amount of credits charged

          **Read-only.**

        </ResponseField>

        <ResponseField name="cost" type="Money">

          Monetary value of the transaction.

          <Expandable title="cost properties">

            <ResponseField name="amount" type="string">

              Monetary amount in main currency units, formatted as a decimal string with a period as a decimal separator. For example, `3456.99` or `-789`.

            </ResponseField>

            <ResponseField name="currencyCode" type="string">

              Currency code in [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) format. For example, `USD`.

              Constraints: `format CURRENCY`.

            </ResponseField>

            <ResponseField name="formattedValue" type="string">

              Localized monetary amount including the currency symbol. For example `1.000,30 €` or `-$12,345.67`.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="creditsExact" type="string">

          Exact credit value of this action, before sub-credit accumulation (e.g. "0.7"). Negative for reversals.

          `credits` is the whole number of credits actually deducted from the balance by this transaction, which
          can be 0 when the cost was below a whole credit, or larger than this action's own value when it also
          settled fractions carried over from earlier actions. This field is the action's own price, so it is
          what a refund reverses and what usage reporting should sum.

          Unset on transactions created before sub-credit accumulation, where `credits` was the rounded-up cost.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="description" type="string">

      Description of the transaction

      Constraints: `maxLength 100`.

    </ResponseField>

    <ResponseField name="callerAppId" type="string">

      App ID of app that initiated the action

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="externalRefId" type="string">

      External reference ID that links this credit transaction to the specific operation or action that triggered it.
      This ID is provided by the calling application when creating the transaction and can be used to correlate
      credit charges with specific AI actions, API calls, or other operations for tracking and reconciliation purposes.

    </ResponseField>

    <ResponseField name="metadata" type="object">

      Additional context about the operation that triggered this credit transaction.
      May include details such as the AI feature type, operation parameters, usage metrics,
      or other relevant information that helps track and understand credit consumption patterns.

    </ResponseField>

    <ResponseField name="idempotencyKey" type="string" />

  </Tab>
