    Assigns or unassigns instructors to the program

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/instructors-service/v2/assignments
    ```

    ## Body Params

    <ParamField body="programId" type="string" required>

      ID of the program

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="assignInstructorIds" type="string[]">

      IDs of instructors to assign

      Constraints: `format GUID`, `maxItems 10`.

    </ParamField>

    <ParamField body="unassignInstructorIds" type="string[]">

      IDs of instructors to unassign

      Constraints: `format GUID`, `maxItems 10`.

    </ParamField>

    <ParamField body="actionId" type="string">

      trace id used by BI.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    Returns `ChangeProgramInstructorsResponse`.
