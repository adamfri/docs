    Retrieves a list of up to 100 resources, given the provided filtering,
    sorting, and paging.

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `typeId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `locationOptions.availableInAllLocations` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `locationOptions.specificLocationOptions.availableInBusinessLocations` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `locationOptions.specificLocationOptions.businessLocations.locationId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `eventsSchedule.scheduleId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `name` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `singleResource.locationOptions.availableInAllLocations` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `singleResource.locationOptions.specificLocationOptions.availableInBusinessLocations` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `singleResource.locationOptions.specificLocationOptions.businessLocations.locationId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/resources/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery">

      Query object.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object in the following format:
          `"filter" : {`
          "fieldName1": "value1",
          "fieldName2":&#123;"$operator":"value2"&#125;
          &#125;``
          Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"sortField1","order":"ASC"},{"fieldName":"sortField2","order":"DESC"}]`

          Constraints: `maxItems 5`.

          <Expandable title="sort properties">

    ## Response Object

    <ResponseField name="resources" type="Resource[]">

      Retrieved resources.

      See the [Resource Object](/api-reference/business-solutions/bookings/resources/resources-v2/resource-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the current response page.

          This count reflects the actual number of items in the current result set,
          which may be less than the requested limit if fewer items are available.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Navigation cursors for moving between result pages.

          Contains `next` and `prev` cursor tokens for pagination. Use the `next` cursor
          to retrieve subsequent pages and `prev` cursor to go back to previous pages.
          Learn more about cursor paging in the [API Query Language guide](https://dev.wix.com/api/rest/getting-started/api-query-language#getting-started_api-query-language_cursor-paging).

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor token for retrieving the next page of results.

              Use this token in subsequent requests to continue pagination forward.
              Value is `null` when on the last page of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor token for retrieving the previous page of results.

              Use this token to navigate backwards through result pages.
              Value is `null` when on the first page of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Indicates whether additional results are available beyond the current page.

          - `true`: More results exist and can be retrieved using the `next` cursor.
          - `false`: This is the final page of results.

        </ResponseField>

      </Expandable>

    </ResponseField>
