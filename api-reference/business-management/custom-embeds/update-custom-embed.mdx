    Updates a custom embed.
    To prevent conflicting changes, you must pass the current revision number.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS">SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/embeds/v1/custom-embeds/{customEmbed.id}
    ```

    ## Path Params

    <ParamField path="customEmbed.id" type="string" required>

      Custom embed ID.

    </ParamField>

    ## Body Params

    <ParamField body="customEmbed" type="CustomEmbed" required>

      Custom embed to update.

      See the [Custom Embed Object](/api-reference/business-management/custom-embeds/custom-embed-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="customEmbed" type="CustomEmbed">

      Updated custom embed.

      See the [Custom Embed Object](/api-reference/business-management/custom-embeds/custom-embed-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CUSTOM_EMBED_NOT_FOUND` | Couldn't find the custom embed. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Custom embed ID.

      **Read-only.**

    </ParamField>

    <ParamField body="customEmbed" type="UpdateCustomEmbed" required>

      Custom embed to update.

      <Expandable title="customEmbed properties">

        <ParamField body="_id" type="string">

          Custom embed ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the custom embed is updated.
          To prevent conflicting changes, the current revision must be passed when updating a custom embed.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Custom embed name, as displayed to Wix users.

        </ParamField>

        <ParamField body="enabled" type="boolean">

          Whether the custom embed is enabled on the site.
          Default: `true`.

        </ParamField>

        <ParamField body="loadOnce" type="boolean">

          Whether to load the custom embed once during initial site rendering, rather than on each page navigation.
          This setting affects performance and should be chosen based on the embed's functionality.
          Default: `true`.

        </ParamField>

        <ParamField body="domain" type="string">

          Site domain that's connected to the site, if relevant.

        </ParamField>

        <ParamField body="position" type="string">

          Position where the custom embed code is placed on the page.

          **Supported values:**

          - `UNKNOWN_POSITION` — Illegal value, exception will be thrown if used
          - `HEAD` — HEAD position
          - `BODY_START` — BODY_START position
          - `BODY_END` — BODY_END position

        </ParamField>

        <ParamField body="embedData" type="CustomEmbed">

          Custom embed data.

          <Expandable title="embedData properties">

            <ParamField body="category" type="string">

              CustomEmbed's category

              **Supported values:**

              - `UNKNOWN_CATEGORY` — Illegal type, exception will be thrown if used
              - `ESSENTIAL` — Essential category
              - `FUNCTIONAL` — Functional category
              - `ANALYTICS` — Analytics category
              - `ADVERTISING` — Advertising category
              - `DATA_TO_THIRD_PARTY` — Data to third party category

            </ParamField>

            <ParamField body="html" type="string">

              CustomEmbed's html

              Constraints: `maxLength 15000`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="pageFilter" type="PageFilter">

          Page IDs where the custom embed should be loaded. By default, custom embeds are applied to all site pages.

          **Read-only.**

          <Expandable title="pageFilter properties">

            <ParamField body="pageIds" type="string[]">

              Pages where the site embed will be loaded.

              Constraints: `minLength 0`, `maxLength 50`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
