    Sets `labels` for a question entry.

    This method replaces all existing labels for the question entry.
    To clear all labels, specify an empty labels array.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/faq/v2/question-entries/{questionEntryId}/labels
    ```

    ## Path Params

    <ParamField path="questionEntryId" type="string" required>

      ID of the question entry to update labels for.

    </ParamField>

    ## Body Params

    <ParamField body="labels" type="Label[]">

      Labels to assign to the question entry.

      Constraints: `maxItems 100`.

      <Expandable title="labels properties">

        <ParamField body="title" type="string">

          Label name.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="sortOrder" type="number">

          Order of the question entry within the label.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="questionEntry" type="QuestionEntry">

      Question entry with updated labels.

      See the [Question Entry Object](/api-reference/business-management/faq-app/question-entry-v2/question-entry-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
