    <div className="wix-ref">

    Updates multiple inventory items, given the provided filter.

    Each time an inventory item is updated, `revision` increments by 1.
    The current `revision` must be passed when updating an inventory item.
    This ensures you're working with the latest inventory item and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INVENTORY_ITEM_WRITE">Inventory write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/inventory-items/update-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter object.

    </ParamField>

    <ParamField body="inventoryItem" type="InventoryItem" required>

      See the [Inventory Item Object](/api-reference/business-solutions/stores/catalog-v3/inventory-items-v3/inventory-item-object) for this object's fields.

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          - `OR` — At least one of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

      Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/introduction) to retrieve job details and metadata.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `REQUESTED_QUANTITY_MUST_BE_NON_NEGATIVE_DECREASING` | New `quantity` would result in invalid inventory state. For negative inventory, quantity can only increase. If preorders exist, quantity can't drop below the preorder counter. |
    | `428` | `FAILED_PRECONDITION` | `PRE_ORDER_VALIDATION` | Preorder enabled for a digital product or subscription product. Preorder isn't supported for these product types. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | Inventory Item Updated | `wix.stores.catalog.v3.inventory_item_updated` | Triggered when an inventory item is updated. |

    ## Examples

    Bulk update by filter inventory items associated with product, variant, and location. The response returns a `jobId` for the bulk update job.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/stores/v3/bulk/inventory-items/update-by-filter' \
        -H 'Content-type: application/json' \
        -H 'Authorization:  <AUTH>' \
        -d '{
              "inventoryItem": {
                "quantity": 5
              },
              "filter": {
                "id": "9c346207-6467-434f-aa9e-8999c32d119d"
              }
            }'
      ```

      ```json Response
      {
        "jobId": "9abd9f7c-df4f-489f-9522-525fa3849658"
      }
      ```
