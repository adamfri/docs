    Cancels a reservation.

    Sets the reservation status to `CANCELED`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-BASIC">Manage Reservations (Basic)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/reservations/v1/reservations/{reservationId}/cancel
    ```

    ## Path Params

    <ParamField path="reservationId" type="string" required>

      Reservation ID.

    </ParamField>

    ## Body Params

    <ParamField body="revision" type="integer" required>

      Revision number.

      Specify the existing `revision` to prevent conflicting updates to reservations.

    </ParamField>

    <ParamField body="phone" type="string">

      The phone number that was provided when the reservation was created.

      This requirement provides additional security by ensuring that the canceling party knows both the reservation's `reservationId` and the reservee's `phone`.

    </ParamField>

    ## Response Object

    <ResponseField name="reservation" type="Reservation">

      Reservation.

      See the [Reservation Object](/api-reference/business-solutions/restaurants/reservations/reservations/reservation-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PHONE_NUMBER_REQUIRED` | Phone number is required to cancel the reservation. |
    | `428` | `FAILED_PRECONDITION` | `PHONE_NUMBER_INCORRECT` | The phone number doesn't match the one used when creating the reservation. |
    | `428` | `FAILED_PRECONDITION` | `CAN_NOT_BE_UPDATED` | The reservation can't be updated in its current state. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Reservation Updated | `wix.table_reservations.v1.reservation_updated` | Triggered when a reservation is canceled. |

    </div>
