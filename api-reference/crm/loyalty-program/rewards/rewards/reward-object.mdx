title: "Reward Object"
description: "A loyalty reward is an object a customer can redeem with loyalty points."
icon: "cube"
---

A loyalty reward is an object a customer can redeem with loyalty points.
Redeeming a reward then creates a loyalty coupon that the customer can use.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Reward ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Reward name.

      Constraints: `minLength 1`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="active" type="boolean">

      Whether the reward is active. Default: `FALSE`

    </ResponseField>

    <ResponseField name="type" type="string">

      Reward type.

      **Supported values:**

      - `UNDEFINED` — Undefined reward type.
      - `DISCOUNT_AMOUNT` — Discount reward. Special flexible reward type used in checkout.
      - `COUPON_REWARD` — Coupon reward. [Learn more about coupons](https://support.wix.com/en/article/using-coupons-as-loyalty-rewards).

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the loyalty reward is updated.

      To prevent conflicting changes, the current `revision` must be passed when updating the loyalty reward.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the reward was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the reward was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "reward": {
          "id": "00000000-0000-0000-0001-000000000000",
          "name": "Flexible reward",
          "requiredPoints": 10,
          "active": true,
          "type": "DISCOUNT_AMOUNT",
          "discountAmount": {
            "amount": "1",
            "configsByTier": [
              {
                "amount": "1",
                "costInPoints": 10
              }
            ]
          },
          "revision": "3",
          "createdDate": "2024-02-09T09:07:32.797Z",
          "updatedDate": "2024-03-07T15:47:19.402Z"
        }
      }
      ```

    </CodeGroup>
