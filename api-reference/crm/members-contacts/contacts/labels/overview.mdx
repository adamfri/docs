Label that was found or created.

## SDK package

```bash
npm install @wix/crm
```

Import the `labels` namespace from `@wix/crm`.

## Methods

<CardGroup cols={2}>

  <Card title="List Labels" href="/api-reference/crm/members-contacts/contacts/labels/list-labels">
    GET Lists all contact labels for a site.
  </Card>
  <Card title="Find Or Create Label" href="/api-reference/crm/members-contacts/contacts/labels/find-or-create-label">
    POST Retrieves a label with a specified name, or creates one if it doesn't exist.
  </Card>
  <Card title="Get Label" href="/api-reference/crm/members-contacts/contacts/labels/get-label">
    GET Retrieves a label by the specified label key.
  </Card>
  <Card title="Delete Label" href="/api-reference/crm/members-contacts/contacts/labels/delete-label">
    DELETE Deletes the specified label from a site and removes it from the contacts it applies to.
  </Card>
  <Card title="Update Label" href="/api-reference/crm/members-contacts/contacts/labels/update-label">
    PATCH Renames a label.
  </Card>
  <Card title="Query Labels" href="/api-reference/crm/members-contacts/contacts/labels/query-labels">
    POST Retrieves a list of contact labels.
  </Card>
