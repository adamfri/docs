---
title: "Builderless Production Object"
description: "A function builderless production defines a function and its related entities."
icon: "cube"
---

A function builderless production defines a function and its related entities.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Function builderless production ID. This is the same as the associated function's ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="appId" type="string">

      App ID of the business solution that created the function type the function builderless production is based on.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="formValues" type="object">

      Form values used to create the function. Retrieve the required form values by calling the Form Schema API's [List Forms](https://dev.wix.com/docs/api-reference/crm/forms/form-schemas/list-forms) method, specifying the following parameters:
      - `namespace`: `wix.function_template.form`
      - `formIds`: An array that contains the function template's `formTemplateExtensionId`
      - `kind`: `EXTENSION`

      Constraints: `format map`.

      <Expandable title="formValues properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="any" />

      </Expandable>

    </ResponseField>

    <ResponseField name="function" type="Function">

      Function created from the function builderless production.

      <Expandable title="function properties">

        <ResponseField name="id" type="string">

          Function ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the function was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="functionExtensionId" type="string">

          The function's app extension ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="functionName" type="string">

          Function name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="activationStatus" type="string">

          Activation status

          **Read-only.**

          **Supported values:**

          - `ACTIVE` — Function is activated.
          - `INACTIVE` — Function is deactivated.
          - `DRAFT` — Function is saved but has never been activated.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of the app that defines the function.

          **Read-only.**

        </ResponseField>

        <ResponseField name="functionExtensionName" type="string">

          The function's app extension name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="functionTemplateExtensionId" type="string">

          Function template extension id

        </ResponseField>

        <ResponseField name="formTemplateExtensionId" type="string">

          Form template extension id

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the function was last updated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="revision" type="integer">

          Revision number that increases with every update.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="functionSpiConfiguration" type="FunctionSpiConfiguration">

      Service plugin configuration for the function.

      <Expandable title="functionSpiConfiguration properties">

        <ResponseField name="id" type="string">

          SpiConfiguration ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="revision" type="integer">

          SpiConfiguration revision.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the SpiConfiguration was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the SpiConfiguration was last updated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="functionId" type="string">

          Function ID

          **Read-only.**

        </ResponseField>

        <ResponseField name="configuration" type="object">

          Function SPI configuration dev center component payload.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="automationIds" type="string[]">

      Automations created from the function builderless production.

      **Read-only.** Constraints: `format GUID`, `maxItems 100`.

    </ResponseField>
