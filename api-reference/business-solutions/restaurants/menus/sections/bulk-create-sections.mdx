    Creates multiple sections at once.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/bulk/sections/create
    ```

    ## Body Params

    <ParamField body="sections" type="Section[]" required>

      Sections details.

      Constraints: `maxItems 100`.

      See the [Section Object](/api-reference/business-solutions/restaurants/menus/sections/section-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to receive the created sections in the response.

    </ParamField>
