    Retrieves the locations in a Google Business Profile account that the site
    hasn't imported yet.

    Call this before Create Location or Bulk Create Locations to find what's
    available to import. Locations are returned in the order Google returns them.

    A Google account must be connected first. See the
    [Connection API](https://dev.wix.com/docs/api-reference/business-management/google-business-profile/connection-v1).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/accounts/{accountId}/locations/unimported
    ```

    ## Path Params

    <ParamField path="accountId" type="string" required>

      GBP Account ID to list locations for.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Cursor-based paging. Unset `limit` uses a server default of 100; `cursor`
      is the `next` token returned by a previous response (opaque Google token).

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata. `cursors.next` is the token to specify for the next page, and
      `hasNext` says whether there is one.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="locations" type="UnimportedLocation[]">

      Locations from THIS page that are not yet imported into this Wix site under
      the given account. Order preserved from Google.

      Constraints: `maxItems 100`.

      <Expandable title="locations properties">

        <ResponseField name="googleLocationId" type="string">

          Google location ID (no `locations/` prefix).

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="title" type="string">

          Business name shown on the Google listing (Google's `title`).

          Constraints: `maxLength 300`.

        </ResponseField>

        <ResponseField name="storefrontAddress" type="PostalAddress">

          Storefront postal address; absent for service-area-only businesses.

          <Expandable title="storefrontAddress properties">

            <ResponseField name="countryCode" type="string">

              ISO 3166-1 alpha-2 country code (e.g. "US", "GB").

              Constraints: `format COUNTRY`.

            </ResponseField>

            <ResponseField name="postalCode" type="string">

              Postal/ZIP code.

              Constraints: `maxLength 20`.

            </ResponseField>

            <ResponseField name="administrativeArea" type="string">

              Administrative area (state, province, region).

              Constraints: `maxLength 100`.

            </ResponseField>

            <ResponseField name="locality" type="string">

              City or locality.

              Constraints: `maxLength 100`.

            </ResponseField>

            <ResponseField name="addressLines" type="string[]">

              Street address lines. Up to 5 lines.

              Constraints: `maxLength 255`, `maxItems 5`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="serviceArea" type="ServiceArea">

          Places served by a service-area business. Absent for a business that only
          has premises.

          When `businessType` is `CUSTOMER_AND_BUSINESS_LOCATION`, both this and
          `storefrontAddress` are set.

          <Expandable title="serviceArea properties">

            <ResponseField name="businessType" type="string">

              Type of service-area business.

              **Supported values:**

              - `CUSTOMER_LOCATION_ONLY`
              - `CUSTOMER_AND_BUSINESS_LOCATION`

            </ResponseField>

            <ResponseField name="places" type="PlaceInfo[]">

              Places served. Google caps at 20.

              Constraints: `maxItems 20`.

              _Nested structure omitted for brevity — see the `PlaceInfo[]` object._

            </ResponseField>

            <ResponseField name="regionCode" type="string">

              ISO 3166-1 alpha-2 country code. Required by Google for
              CUSTOMER_LOCATION_ONLY businesses; ignored otherwise.

              Constraints: `format COUNTRY`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
