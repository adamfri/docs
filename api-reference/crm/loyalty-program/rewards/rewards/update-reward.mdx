    Updates a loyalty reward.

    Call this method to update details of a reward, such as the name, whether a reward is active,
    or the amount of points it costs to redeem. Also call this method to add new tiers that are eligible to redeem a reward.

    You may not change the `type` of a reward. That's set upon creation and can't be updated.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/loyalty-rewards/v1/rewards/{reward.id}
    ```

    ## Path Params

    <ParamField path="reward.id" type="string" required>

      Reward ID.

    </ParamField>

    ## Body Params

    <ParamField body="reward" type="Reward" required>

      Reward information to update.

      See the [Reward Object](/api-reference/crm/loyalty-program/rewards/rewards/reward-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="reward" type="Reward">

      Updated reward.

      See the [Reward Object](/api-reference/crm/loyalty-program/rewards/rewards/reward-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
