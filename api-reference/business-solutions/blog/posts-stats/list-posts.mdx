    <div className="wix-ref">

    Retrieves a list of up to 100 published posts per request.

    List Posts runs with these defaults, which you can override:
    - `firstPublishedDate` is sorted in descending order, with pinned posts first.
    - `paging.limit` is `50`.
    - `paging.offset` is `0`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v3/posts
    ```

    ## Query Params

    <ParamField query="featured" type="boolean">

      Whether to return only featured posts.

      Default: `false`

    </ParamField>

    <ParamField query="hashtags" type="string[]">

      Hashtag filter.

      Pass an array of hashtags to return only posts containing any of the provided hashtags.
      If omitted, all posts with or without hashtags are returned.

      Constraints: `maxLength 100`, `maxItems 100`.

    </ParamField>

    <ParamField query="categoryIds" type="string[]">

      Category filter.

      Pass an array of category IDs to return only posts with any of the provided categories.
      If omitted, all posts with or without associated categories are returned.

      Constraints: `maxLength 38`, `maxItems 50`.

    </ParamField>

    <ParamField query="tagIds" type="string[]">

      Tag filter.

      Pass an array of tag IDs to return only posts with any of the provided tags.
      If omitted, all posts with or without tags are returned.

      Constraints: `maxLength 38`, `maxItems 50`.

    </ParamField>

    <ParamField query="sort" type="string">

      Sorting options.

      Default: `FEED`

      **Supported values:**

      - `FEED` — Ordered by `firstPublishedDate` in descending order with pinned posts first.
      - `PUBLISHED_DATE_ASC` — Ordered by `firstPublishedDate` in ascending order.
      - `PUBLISHED_DATE_DESC` — Ordered by `firstPublishedDate` in descending order.
      - `VIEW_COUNT` — Ordered by total number of views in descending order.
      - `LIKE_COUNT` — Ordered by total number of likes in descending order.
      - `TITLE_ASC` — Ordered by `title` in ascending order.
      - `TITLE_DESC` — Ordered by `title` in descending order.

    </ParamField>

    <ParamField query="paging" type="BlogPaging">

      Pagination options.

      <Expandable title="paging properties">

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

          Default: `0`

          Constraints: `min 0`.

        </ParamField>

        <ParamField query="limit" type="integer">

          Number of items to return.

          Default:`50`

          Constraints: `min 1`, `max 100`.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="language" type="string">

      Language filter.

      2-or-4-letter language code in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.
      Pass a language to only receive posts that are in that language.
      If omitted, posts in all languages are returned.

    </ParamField>

    <ParamField query="memberId" type="string">

      Post owner's member ID.

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      List of additional post fields to include in the response. For example, use the `URL` fieldset to retrieve the url field in
      the response in addition to the post’s base fields. Base fields don’t include any of the supported fieldset values. By default
      only the post’s base fields are returned.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `URL` — Includes post URL when present.
      - `CONTENT_TEXT` — Includes post content text string when present.
      - `METRICS` — Includes post metrics when present.
      - `SEO` — Includes SEO data.
      - `CONTACT_ID` — Includes post owner's contact ID.
      - `RICH_CONTENT` — Includes post rich content.
      - `REFERENCE_ID` — Includes post reference ID field.

    </ParamField>

    ## Response Object

    <ResponseField name="posts" type="Post[]">

      List of retrieved posts.

      See the [Post Object](/api-reference/business-solutions/blog/posts-stats/post-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metaData" type="MetaData">

      Details on the paged set of results returned.

      <Expandable title="metaData properties">

        <ResponseField name="count" type="integer">

          Number of items returned in this response.

          Requested offset.

        <ResponseField name="cursor" type="string">

        </ResponseField>

      </Expandable>

    </ResponseField>
