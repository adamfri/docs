    Retrieves a payment method type, with some fields localized according to the caller's language and country.

    The callers language and country are taken from the `languageCode` or `countryCode` parameters in the request.
    If these parameters are not specified, the values are taken from context of the call if possible. For example, if this method is called from a Wix site, the selected language on that site will be used.
    If language or country can't be determined, the method doesn't perform any filtering or localization.

    Language and country are used to determine localized values for the `displayName`, `description` fields.
    Country is used to determine localized values for the `priority` and `promoted` fields in `merchantFlow` and `buyerFlow`.
    `currencyCode` is used to determine the eligibility of payment method types for the provided currency.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.READ-SITE_PAYMENT_METHOD_TYPES">Read Site Payment Method Types</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/payments/site-payment-method-types/v1/site-payment-method-types/{sitePaymentMethodTypeId}
    ```

    ## Path Params

    <ParamField path="sitePaymentMethodTypeId" type="string" required>

      Site payment method type ID.

    </ParamField>

    ## Query Params

    <ParamField query="languageCode" type="string">

      Language used to determine localized values for fields in the response.

      Must be a 2-letter language code in [ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes) format.

    </ParamField>

    <ParamField query="countryCode" type="string">

      Country used to determine localized values for fields in the response.

      Must be a 2-letter country code in [ISO-3166 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#officially_assigned_code_elements) format.

    </ParamField>

    <ParamField query="currencyCode" type="string">

      Currency used to determine localized values for fields in the response.

      Must be a 3-letter currency code in [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) format.

    </ParamField>

    <ParamField query="requestedFields" type="string[]">

      Requested additional fields

      Constraints: `maxItems 2`.

      **Supported values:**

      - `ALLOWED_CURRENCIES` — Return `allowedCurrencyCodes`.

    </ParamField>

    ## Response Object

    <ResponseField name="sitePaymentMethodType" type="SitePaymentMethodType">

      Requested site payment method type.

      See the [Site Payment Method Type Object](/api-reference/business-management/payments/site-payment-method-types/site-payment-method-type-object) for this object's fields.

    </ResponseField>
