    <div className="wix-ref">

    Creates a confirmed marketing consent with a `state` of `CONFIRMED`.
    Required fields:
    - `details.type`.
    - `details.email` OR `details.phone`.
    - `lastConfirmationActivity`.

    To create a marketing consent with a different state, use Upsert Marketing Consent, or Bulk Upsert Marketing Consent.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MARKETING.CONSENT-MANAGE">Manage Marketing Consents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/marketing-consent/v1/marketing-consent
    ```

    ## Body Params

    <ParamField body="marketingConsent" type="MarketingConsent">

      Marketing consent to create.

      See the [Marketing Consent Object](/api-reference/business-management/marketing/marketing-consent/marketing-consent-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="marketingConsent" type="MarketingConsent">

      Newly created marketing consent.

      See the [Marketing Consent Object](/api-reference/business-management/marketing/marketing-consent/marketing-consent-object) for this object's fields.

    </ResponseField>

    <ResponseField name="link" type="Link">

      Marketing consent confirmation link.

      <Expandable title="link properties">

        <ResponseField name="type" type="string">

          Link type.

          **Supported values:**

          - `UNKNOWN_LINK_TYPE`
          - `CONFIRMATION`
          - `REVOKE_CONFIRMATION`

        </ResponseField>

        <ResponseField name="url" type="string">

          The link's URL.

          Constraints: `format WEB_URL`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Marketing Consent Created | `wix.marketing.marketing_consent.v1.marketing_consent_created` | Triggered when a marketing consent is created. |
