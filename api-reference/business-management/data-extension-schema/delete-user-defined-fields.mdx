    Deletes a user defined field from the specified data extension schema.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATAEXTENSIONS.MANAGE-SCHEMAS">Manage Data Extensions Schemas</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/schema-service/v1/schemas/delete-user-defined-fields
    ```

    ## Body Params

    <ParamField body="dataExtensionSchemaId" type="string" required>

      Schema ID.

    </ParamField>

    <ParamField body="fieldsToDelete" type="string[]" required>

      List of fields paths to delete. For example, ["size", "personalization.specialInstructions"].

      Constraints: `maxLength 1000`, `minItems 1`, `maxItems 10`.

    </ParamField>

    ## Response Object

    <ResponseField name="dataExtensionSchema" type="DataExtensionSchema">

      Updated schema.

      See the [Data Extension Schema Object](/api-reference/business-management/data-extension-schema/data-extension-schema-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Extension Schema Updated | `wix.data_extensions.v1.data_extension_schema_updated` | Triggered when a data extension schema is updated. |

    </div>
