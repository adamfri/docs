    Adjusts a specified numerical property for up to 100 products at a time.
    The property can be increased or decreased either by percentage or amount.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v1/bulk/products/adjust-properties
    ```

    ## Body Params

    <ParamField body="ids" type="string[]" required>

      Product IDs.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="adjust" type="AdjustValue">

      Numerical property to adjust.

      <Expandable title="One of the following">

        <ParamField body="value" type="value">

          value

          <Expandable title="value properties">

            <ParamField body="price" type="PropertyAdjustmentData">

              Adjust product price.
              If [variant management](https://support.wix.com/en/article/wix-stores-adding-and-customizing-product-options#setting-different-prices-for-variants) is enabled,
              variants prices will be calculated according to the adjusted price.
              If variant price is negative after the adjustment, the update will fail.

              _Nested structure omitted for brevity — see the `PropertyAdjustmentData` object._

            </ParamField>

            <ParamField body="cost" type="PropertyAdjustmentData">

              Adjust product cost of goods.
              If [variant management](https://support.wix.com/en/article/wix-stores-adding-and-customizing-product-options#setting-different-prices-for-variants) is enabled,
              cost of goods will be adjusted per variant.

              _Nested structure omitted for brevity — see the `PropertyAdjustmentData` object._

            </ParamField>

            <ParamField body="weight" type="PropertyAdjustmentData">

              Adjust product weight.
              If [variant management](https://support.wix.com/en/article/wix-stores-adding-and-customizing-product-options#setting-different-prices-for-variants) is enabled,
              weight will be adjusted per variant.
