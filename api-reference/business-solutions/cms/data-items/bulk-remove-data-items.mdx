    Removes multiple items from a collection.

    For retention or cleanup flows, first call [Query Data Items](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/query-data-items) to collect the IDs you want to remove, then pass those IDs to this method in batches.

    If any items in other collections reference the removed items in reference or multi-reference fields, those fields are cleared.

    <Note>

    Once an item has been removed from a collection, it can't be restored.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/bulk/items/remove
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection from which to remove the item.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="dataItemIds" type="string[]" required>

      IDs of data items to remove.

      Constraints: `maxLength 128`, `maxItems 1000`.

    </ParamField>

    <ParamField body="appOptions" type="object">

      Additional parameters specific to the [Wix app collection](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-wix-app-collections) you are querying.

      When querying the Wix Stores [Products collection](https://dev.wix.com/docs/develop-websites/articles/wix-apps/wix-e-commerce-stores/wix-stores-products-collection-fields), pass the following optional parameters:
      - `includeHiddenProducts`: Whether to include hidden products in the response. Default: `false`.
      - `includeVariants`: Whether to include product variants in the query. Default: `false`.

    </ParamField>

    <ParamField body="publishPluginOptions" type="PublishPluginOptions">

      Options for the Publish plugin.
      This plugin allows items in a [data collection](https://dev.wix.com/docs/rest/business-solutions/cms/data-collections/data-collection-object) to be marked as draft or published. Published items are visible to site visitors, while draft items are not.

      <Expandable title="publishPluginOptions properties">

        <ParamField body="includeDraftItems" type="boolean">

          Whether to include draft items.

          When `true`, both published and draft items are affected. Default: `false`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="condition" type="Condition">

      Condition for removing the items.

      When a condition is provided, the items are only removed if the condition is met.

      <Expandable title="condition properties">

        <ParamField body="filter" type="object">

          Filter, changes to item(s) will only apply if they satisfy this filter.
          Learn more about filters in [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language#filters).

        </ParamField>

      </Expandable>

    </ParamField>

          - `UNKNOWN_ACTION_TYPE`

        <ResponseField name="itemMetadata" type="ItemMetadata">

            <ResponseField name="originalIndex" type="integer">

            </ResponseField>

              Whether the requested action was successful. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              In case of failure, the error details.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="dataItem" type="DataItem">

          Updated data item.

          Returned if `returnEntity` is set to `true` and the action is successful.

          See the [Data Item Object](/api-reference/business-solutions/cms/data-items/data-item-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Bulk action metadata.

      <Expandable title="bulkActionMetadata properties">

          Number of items successfully processed.

          Number of items that couldn't be processed.

        </ResponseField>

      </Expandable>

    </ResponseField>
