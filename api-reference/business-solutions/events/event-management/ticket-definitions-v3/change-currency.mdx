    <div className="wix-ref">

    Changes ticket price currency per event.

    Updates the currency for all ticket definitions under the event.
    This doesn't convert price values. It only updates the currency code
    (for example, 10 USD becomes 10 EUR).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-TICKET-DEF">Manage Ticket Definitions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/ticket-definitions/currency
    ```

    ## Body Params

    <ParamField body="eventId" type="string" required>

      Event ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="currency" type="string" required>

      Ticket price currency in 3-letter [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) format.

      Constraints: `minLength 3`, `maxLength 3`.

    </ParamField>

    ## Response Object

    Returns `ChangeCurrencyResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CURRENCY_LOCKED` | Currency can't be changed because tickets have already been sold for this event. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Ticket Definition Updated | `wix.events.v3.ticket_definition_updated` | Triggered when a ticket definition is updated. |

    </div>
