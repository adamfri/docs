A data collection determines the structure of data to be stored in a database.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      [Collection ID](https://dev.wix.com/docs/develop-websites-sdk/code-your-site/work-with-data/introduction/about-collections#collection-ids). For example, `my-first-collection`.
      For [app collections](https://dev.wix.com/docs/api-reference/business-solutions/cms/collection-management/wix-app-collections/introduction), use `AppName/CollectionName`.

      Constraints: `maxLength 256`, `immutable`.

    </ResponseField>

    <ResponseField name="collectionType" type="string">

      Collection type. Indicates how the collection was created and how it is stored.

      **Read-only.**

      **Supported values:**

      - `NATIVE` — User-created collection.
      - `WIX_APP` — [Collection](https://support.wix.com/en/article/velo-working-with-wix-app-collections-and-code#what-are-wix-app-collections) created by a Wix app when it is installed. This type of collection can be modified dynamically by that app (for example, Wix Forms).
      - `BLOCKS_APP` — Collection created by a Wix Blocks app.
      - `EXTERNAL` — Collection located in externally connected storage.

    </ResponseField>

    <ResponseField name="ownerAppId" type="string">

      ID of the app that defined this collection. For collections defined by Wix users, this value is null.

      **Read-only.**

    </ResponseField>

    <ResponseField name="maxPageSize" type="integer">

      Maximum number of items returned in a single query, based on the underlying storage.
      Native collections have a maximum page size of 1000 for offset-based queries or 100 for cursor-based queries.
      External collections' maximum page size defaults to 50, but an external provider can set any maximum value up to 1000.

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Collection's display name as shown in the CMS. For example, `My First Collection`.

    </ResponseField>

    <ResponseField name="defaultDisplayOrder" type="Sort">

      Default item sorting order when a query doesn't specify one.

      **Read-only.**

      <Expandable title="defaultDisplayOrder properties">

        <ResponseField name="fieldKey" type="string">

          Field to sort by.

          Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="direction" type="string">

          Sort order. Use `ASC` for ascending order or `DESC` for descending order.

          Default: `ASC`

          **Supported values:**

          - `ASC`
          - `DESC`

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="displayNamespace" type="string">

      UI-friendly namespace of the Wix app with which the data collection is associated, such as Stores or Bookings.
      Empty for all data collections not owned by Wix apps.

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayField" type="string">

      Field whose value the CMS displays to represent the collection item when referenced in a different collection.

    </ResponseField>

    <ResponseField name="capabilities" type="CollectionCapabilities">

      Capabilities the collection supports.
      Capabilities are set by default. Values depend on the collection type.

      **Read-only.**

      <Expandable title="capabilities properties">

        <ResponseField name="dataOperations" type="string[]">

          Data operations the collection supports. The listed operations can be performed on data the collection contains.

          > **Note**: The `PATCH` and `BULK_PATCH` operations aren't currently supported.

          Constraints: `maxItems 100`.

          **Supported values:**

          - `AGGREGATE`
          - `BULK_INSERT`
          - `BULK_REMOVE`
          - `BULK_SAVE`
          - `BULK_UPDATE`
          - `COUNT`
          - `DISTINCT`
          - `FIND`
          - `GET`
          - `INSERT`
          - `INSERT_REFERENCE`
          - `IS_REFERENCED`
          - `QUERY_REFERENCED`
          - `REMOVE`
          - `REMOVE_REFERENCE`
          - `REPLACE_REFERENCES`
          - `SAVE`
          - `TRUNCATE`
          - `UPDATE`
          - `PATCH`
          - `BULK_PATCH`

        </ResponseField>

        <ResponseField name="collectionOperations" type="string[]">

          Collection operations supported. The listed operations can be performed on the collection itself.

          Constraints: `maxItems 100`.

          **Supported values:**

          - `UPDATE` — Allows updating the collection's structure, for example adding, updating, or deleting fields. If not included, the collection's structure can't be changed.
          - `REMOVE` — Allows deleting the entire collection. If not included, the collection can't be deleted.

        </ResponseField>

        <ResponseField name="indexLimits" type="IndexLimits">

          Maximum number of indexes for the collection.

          <Expandable title="indexLimits properties">

            <ResponseField name="regular" type="integer">

              Maximum number of regular (non-unique) indexes allowed for this collection.

            </ResponseField>

            <ResponseField name="unique" type="integer">

              Maximum number of unique indexes allowed for this collection.

            </ResponseField>

            <ResponseField name="total" type="integer">

              Maximum number of regular and unique indexes allowed for this collection.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="fields" type="Field[]">

      Collection's field structure.

      Constraints: `maxItems 1000`.

      <Expandable title="fields properties">

        <ResponseField name="key" type="string">

          Unique identifier for the field. For example, `firstName`.

          Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Field's display name when displayed in the CMS. For example, `First Name`.

        </ResponseField>

        <ResponseField name="type" type="string">

          Field's data type.

          Learn more about [data types in Wix Data](https://dev.wix.com/docs/rest/business-solutions/cms/data-types-in-wix-data).

          **Supported values:**

          - `TEXT` — Plain-text string.
          - `NUMBER` — Number.
          - `DATE` — Date string in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format: `YYYY-MM-DD`.
          - `DATETIME` — [JavaScript Date object](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date) ([SDK](https://dev.wix.com/docs/sdk/backend-modules/data/data-types-in-wix-data)) or an object in the following format: `"someFieldKey": { "$date": "YYYY-MM-DDTHH:mm:ss.sssZ"}` ([REST](https://dev.wix.com/docs/rest/business-solutions/cms/data-types-in-wix-data)).
          - `IMAGE` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `BOOLEAN` — Boolean `true` or `false` value.
          - `DOCUMENT` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `URL` — URL in one of the following formats: `http://`, `https://`, `ftp://`, `mailto:`, `sms:`, `tel:`.
          - `RICH_TEXT` — [Rich-text](https://dev.wix.com/docs/rest/articles/getting-started/rich-text) string that may contain a subset of HTML tags.
          - `VIDEO` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `ANY` — Any field type.
          - `ARRAY_STRING` — Array of strings.
          - `ARRAY_DOCUMENT` — Array of documents: web or [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URLs.
          - `AUDIO` — Web URL or a [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URL.
          - `TIME` — Time string in `hh:mm:ss.SSS` format.
          - `LANGUAGE` — Language codes in [ISO 639-1](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) format. These may include country codes in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#officially_assigned_code_elements) format.
          - `RICH_CONTENT` — [Rich content](https://dev.wix.com/docs/ricos/getting-started/introduction).
          - `MEDIA_GALLERY` — Array of web or [Media Manager](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction) URLs.
          - `ADDRESS` — Physical address object ([SDK](https://dev.wix.com/docs/sdk/backend-modules/data/data-types-in-wix-data#address-object) | [REST](https://dev.wix.com/docs/rest/business-solutions/cms/data-types-in-wix-data#address-object)).
          - `PAGE_LINK` — [Dynamic page link](https://support.wix.com/en/article/cms-linking-to-dynamic-pages).
          - `REFERENCE` — Reference to another item in another collection. See Query Referenced Data Items ([SDK](https://dev.wix.com/docs/sdk/backend-modules/data/items/query-referenced) | [REST](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/query-referenced-data-items)) to learn about item references.

          If you select this type, then you must pass the `referencedCollectionId` field as well.
          - `MULTI_REFERENCE` — References to multiple items in another collection. See Query Referenced Data Items ([SDK](https://dev.wix.com/docs/sdk/backend-modules/data/items/query-referenced) | [REST](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/query-referenced-data-items)) to learn about item references.
          - `OBJECT` — JSON object.
          - `ARRAY` — Array.
          - `LEGACY_TIME` — Deprecated type that might appear in legacy collections.
          - `LEGACY_BOOK` — Deprecated type that might appear in legacy collections.
          - `LEGACY_EXTERNAL_URL` — Deprecated type that might appear in legacy collections.
          - `LEGACY_BROKEN_REFERENCE` — Deprecated type that might appear in legacy collections.
          - `LEGACY_IMAGE` — Deprecated type that might appear in legacy collections.
          - `LEGACY_COLOR` — Deprecated type that might appear in legacy collections.
          - `LEGACY_EXTERNAL_VIDEO` — Deprecated type that might appear in legacy collections.
          - `SLUG` — SLUG type used for dynamic page URLs.
          - `EMAIL` — Email.
          - `MEDIA_IMAGE` — Media image object.
          - `MEDIA_VECTOR_ART` — Media vector art object.

        </ResponseField>

        </ResponseField>

    <ResponseField name="revision" type="integer">

      Collection's current revision number, which increments each time the collection is updated. For an update operation to succeed, you must specify the latest revision number.

      **Read-only.**

    </ResponseField>

    <ResponseField name="plugins" type="Plugin[]">

      Plugins the collection uses. Plugins apply additional capabilities to the collection or extend its functionality.

      Constraints: `maxItems 100`.

      <Expandable title="plugins properties">

        <ResponseField name="type" type="string">

          Plugin type.

          **Supported values:**

          - `PUBLISH` — Allows items to be marked as either draft or published. For each item you can set a publishing time when the item will become visible to site visitors.
          - `SINGLE_ITEM` — Ensures the collection can have one item at most. Can only be applied to a new collection.
          - `URLIZED` — Generates item URLs for collections used by dynamic pages.
          - `GRIDAPPLESS` — Deprecated. Will be removed in the future.
          - `MULTILINGUAL` — Indicates that the collection is translatable. This allows you to manage translation for selected fields using [Wix Multilingual](https://www.wix.com/app-market/wix-multilingual).
          - `SHARED` — Indicates that collection is shared with current site.
          - `EDITABLE_PAGE_LINK` — Indicates that page link fields are persisted and can be updated.
          - `CMS` — CMS-specific collection properties.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingModes" type="string[]">

      Paging modes the collection supports. In native collections, offset-based paging is supported by default.

      **Read-only.** Constraints: `maxItems 2`.

      **Supported values:**

      - `OFFSET` — Offset-based paging.
      - `CURSOR` — Cursor-based paging.

    </ResponseField>

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date the collection was last updated.

      **Read-only.**

    </ResponseField>
