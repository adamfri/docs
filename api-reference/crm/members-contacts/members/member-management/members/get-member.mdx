    Retrieves a member by ID.

    Members are typically associated with a contact, each having a distinct member ID and contact ID. When specifying the ID as a parameter, don't presume the IDs are identical since they represent separate entities.

    A member's default privacy status is `"PRIVATE"`. Private members aren't returned in the response if a [site visitor](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities#site-visitor) or [site member](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities#site-member) identity calls this method. Learn more about [managing your member privacy settings](https://support.wix.com/en/article/site-members-managing-your-member-privacy-settings).

    To retrieve the current member, call [Get My Member](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/get-my-member).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/members/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Member ID.

    </ParamField>

    ## Query Params

    <ParamField query="fieldsets" type="string[]">

      Predefined set of fields to return.

      Defaults to `"PUBLIC"`.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `PUBLIC` — Includes `id`, `contactId`, `createdDate`, `updatedDate` and the `profile` object.
      `status`, `privacyStatus`, and `activityStatus` are returned as `UNKNOWN`.
      - `EXTENDED` — Includes `id`, `loginEmail`, `status`, `contactId`, `createdDate`, `updatedDate`, `privacyStatus`, `activityStatus` and the `profile` object.
      - `FULL` — Includes all fields.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      The requested member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `MEMBER_TO_MEMBER_BLOCKED` | Can't get a member that's blocked by the calling Wix user. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
