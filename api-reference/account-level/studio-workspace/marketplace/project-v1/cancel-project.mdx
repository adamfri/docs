    Cancels a project on the provider's side, setting its `status` to `CANCELED_BY_PROVIDER`.

    Each time the project is updated, `revision` increments by 1. The current `revision` must be passed when updating the project. This ensures you're working with the latest project and prevents unintended overwrites.

    Specify `cancellationInfo` to record why the engagement ended.

    A project whose `status` is `COMPLETED`, `EXPIRED`, `CANCELED_BY_CLIENT`, or
    `CANCELED_BY_PROVIDER` can't be canceled, because those statuses are final. Cancellation is also
    final, so a canceled project can't be restarted.

    To mark the engagement as delivered instead, call Complete Project.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/marketplace/v1/projects/{projectId}/cancel
    ```

    ## Path Params

    <ParamField path="projectId" type="string" required>

      ID of the project to cancel.

    </ParamField>

    ## Body Params

    <ParamField body="revision" type="integer" required>

      Revision number, which increments by 1 each time the project is updated. To prevent conflicting
      changes, the current revision must be passed.

    </ParamField>

    <ParamField body="cancellationInfo" type="CancellationInfo" required>

      Reason the project was canceled, with any additional details.

      <Expandable title="cancellationInfo properties">

        <ParamField body="additionalInfo" type="string">

          Additional details about why the project was canceled.

        </ParamField>

        <ParamField body="reason" type="string">

          Reason the project was canceled.

          **Supported values:**

          - `OTHER` — A reason not covered by the other values.
          - `CLIENT_NOT_RESPONDING` — The client stopped responding.
          - `BUDGET_IS_TOO_LOW` — The client's budget was too low for the work.
          - `DUPLICATE_REQUEST` — The request duplicates another project.
          - `REPORT_AS_SPAM` — The request was reported as spam.
          - `DOESNT_MATCH_MY_SKILLS` — The work doesn't match the provider's skills.

        </ParamField>

      </Expandable>

    </ParamField>
