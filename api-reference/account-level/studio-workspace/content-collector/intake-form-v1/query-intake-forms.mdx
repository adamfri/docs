    Retrieves a list of up to 100 intake forms, given the provided paging, filtering, and sorting.

    No site ID is required. Results are scoped to the caller's account. Intake
    forms belonging to other accounts are never returned.

    Use Query Intake Forms for precise structured filtering and sorting, for
    example to export forms by `clientFormInteraction.submissionDate`. To match intake forms
    by a free-text expression on client name or project name, or to get
    aggregations, call [Search Intake Forms](https://dev.wix.com/docs/api-reference/account-level/partners/content-collector/intake-form-v1/search-intake-forms) instead.

    To learn about working with Query methods, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language), [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging), and [Field Projection](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `accountId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `userId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `publishDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | None |
    | `clientFormInteraction.submissionDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | None |
    | `project.name` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `project.industry` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `teamMemberIds` | `$hasSome`, `$hasAll`, `$exists`, `$isEmpty` | None |
