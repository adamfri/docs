    Removes an applied coupon from a join application's payment order.

    The join application must have a prepared payment order with a coupon applied, and `paymentStatus` must be `PAYMENT_IN_PROGRESS`, `PAYMENT_FAILED`, or `PAYMENT_CANCELED`. The last two let a member clear a coupon when retrying after a failed or canceled payment.

    Returns the order total after the coupon is removed.

    To apply a coupon, call [Apply Coupon](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/apply-coupon).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}/remove-coupon
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to remove the coupon from.

    </ParamField>

    ## Body Params

    <ParamField body="couponId" type="string" required>

      ID of the coupon to remove. Must match the coupon applied to the order.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="total" type="string">

      Order total after the coupon is removed, formatted using the precision of the site currency configured in Site Properties. The value doesn't include the currency.

      Constraints: `maxLength 50`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_PAYMENT_ORDER` | No payment order exists for the join application. Call Prepare Payment first. |
    | `428` | `FAILED_PRECONDITION` | `COUPON_DOES_NOT_EXIST` | The specified coupon isn't applied to the payment order. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_PAYMENT_STATUS` | The join application's `paymentStatus` doesn't permit removing a coupon. Allowed from `PAYMENT_IN_PROGRESS`, `PAYMENT_FAILED`, and `PAYMENT_CANCELED`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
