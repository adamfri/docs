<Note>This article applies to the REST API only.</Note>

The following table shows field support for filters and sorting for the Custom Fields Suggestion object:

| Fields                   | Supported Filters    | Sortable     |
|--------------------------|----------------------|--------------|
| `memberId`               | `$eq`,               | Not sortable |
| `groupId`                | `$eq`, `$in`         | Not sortable |
