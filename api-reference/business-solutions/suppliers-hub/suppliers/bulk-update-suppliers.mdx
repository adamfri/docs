    Updates multiple suppliers in a single synchronous request.

    Supports up to 100 suppliers per request. Each supplier must include its current revision number to prevent conflicting changes. Set `returnEntity` to `true` to receive the updated suppliers in the response.

    To update more than 100 suppliers, split them into multiple batches and make separate requests. When updating rating information, update both `rating` and `reviewCount` together to maintain consistency.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/bulk/suppliers/update
    ```

    ## Body Params

    <ParamField body="suppliers" type="MaskedSupplier[]" required>

      List of suppliers to update. Each must include current revision number.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="suppliers properties">

        <ParamField body="supplier" type="Supplier">

          Supplier to update.

          See the [Supplier Object](/api-reference/business-solutions/suppliers-hub/suppliers/supplier-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return updated supplier entities in the response. Set to `true` to receive the updated suppliers with their new revision numbers.

      Default: `false`

    </ParamField>
