    Verifies ownership of the site with Google.

    Wix places the verification token for the requested method and asks Google
    to confirm it. For Wix sites the `META` method is the common choice: Wix
    adds the `google-site-verification` meta tag to every page automatically.

    Verification requires a connected Google account and runs synchronously
    against Google, so allow up to a minute for the call to return.

    Requires the site to be published, have a connected domain, and allow
    search-engine indexing; otherwise fails with `FAILED_PRECONDITION`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gsc/v1/verify-site
    ```

    ## Body Params

    <ParamField body="method" type="string">

      Verification method to use. `META` is the only supported method and the
      default, so this field can be omitted.

      **Supported values:**

      - `UNKNOWN_VERIFICATION_METHOD` — Unknown verification method.
      - `META` — Verification via a `google-site-verification` meta tag, which Wix places
      on every page of the site. Wix hosts the site's pages, so this is the
      method that needs nothing from the Wix user.

    </ParamField>

    ## Response Object

    Returns `VerifySiteResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_TOKEN` | No Google account is connected for this site. Connect first with the GSC Connection API. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_PUBLISHED` | The site is not published. |
    | `428` | `FAILED_PRECONDITION` | `DOMAIN_NOT_CONNECTED` | The site has no connected domain. |
    | `428` | `FAILED_PRECONDITION` | `SITE_NOT_INDEXABLE` | The site does not allow search-engine indexing. |
    | `429` | `RESOURCE_EXHAUSTED` | `GOOGLE_QUOTA_EXCEEDED` | Google's API quota for the property is used up. Retry after the quota window resets. |
    | `503` | `UNAVAILABLE` | `GOOGLE_UNAVAILABLE` | Google answered with a temporary server error. Retry with backoff. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
