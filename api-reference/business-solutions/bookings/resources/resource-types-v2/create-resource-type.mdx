    Creates a new resource type.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/resources/resource-types
    ```

    ## Body Params

    <ParamField body="resourceType" type="ResourceType" required>

      Resource type to create.

      See the [Resource Type Object](/api-reference/business-solutions/bookings/resources/resource-types-v2/resource-type-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="resourceType" type="ResourceType">

      Created resource type.

      See the [Resource Type Object](/api-reference/business-solutions/bookings/resources/resource-types-v2/resource-type-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `RESOURCE_TYPE_ALREADY_EXISTS_FOR_NAME` | There is already a resource type with this name. Choose a different name. |
    | `429` | `RESOURCE_EXHAUSTED` | `MAX_NUMBER_OF_RESOURCE_TYPES_REACHED` | The site has reached the maximum number of resource types. Delete an existing resource type before creating a new 1. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Resource Type Created | `wix.bookings.resources.v2.resource_type_created` | Triggered when a resource type is created. |

    </div>
