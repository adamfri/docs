    Creates a trigger for the specified app. Once created, users can [create automations](https://support.wix.com/en/wix-automations-7067897) that run when this trigger occurs.

    Learn more about [triggers](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/about-triggers).

    <Note>

    You can only create triggers for [apps you own or collaborate on](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard-setup/manage-collaborators).
    You cannot try out this endpoint because
    it can be called only by the app that created the specified `triggerKey`.
    So please ignore the **Try It Out** button.

    </Note>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/triggers
    ```

    ## Body Params

    <ParamField body="trigger" type="Trigger">

      Trigger to add to the app.

      See the [Trigger Object](/api-reference/business-management/automations/triggers/trigger-catalog/trigger-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="trigger" type="Trigger">

      Created trigger.

      See the [Trigger Object](/api-reference/business-management/automations/triggers/trigger-catalog/trigger-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Create trigger
    import { triggerCatalog } from "@wix/automations";

    const payloadDataSchema = {
      $schema: "http://json-schema.org/draft-07/schema",
      type: "object",
      properties: {
        orderId: {
          type: "string",
          title: "Order ID",
          description: "Order ID.",
        },
        orderTotal: {
          type: "number",
          title: "Order Total",
          description: "Order total.",
        },
        customerEmail: {
          type: "string",
          title: "Customer Email",
          description: "Email of the customer who placed the order.",
        },
      },
      required: ["orderId", "orderTotal"],
    };

    async function createTrigger() {
      const response = await triggerCatalog.createTrigger({
        trigger: {
          appId: "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
          triggerKey: "my_app-new_order_received",
          displayName: "New Order Received",
          payloadDataSchema,
          baseUri: "https://my-app.example.com/order-received",
        },
      });
      return response;
    }
    ```
