<div className="wix-ref">

Creates a media item in a specified gallery.

<Note>

When creating or updating image items in a pro gallery, the images must be uploaded or imported to the [Wix Media Manager](https://dev.wix.com/api/rest/media/media-manager) first, as the `imageInfo` parameter currently only supports the Wix Media URL.

</Note>

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PROGALLERY.MANAGE-GALLERIES">Manage Galleries</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/pro-gallery/v2/galleries/{galleryId}/items
```

## Path Params

<ParamField path="galleryId" type="string" required>

  Gallery ID.

</ParamField>

## Body Params

<ParamField body="item" type="Item" required>

  <Expandable title="item properties">
