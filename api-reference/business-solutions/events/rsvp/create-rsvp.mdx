    Creates an RSVP, associated with a contact of the site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/rsvp
    ```

    ## Body Params

    <ParamField body="eventId" type="string">

      Event ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="form" type="FormResponse">

      RSVP form response.

      <Expandable title="form properties">

        <ParamField body="inputValues" type="InputValue[]">

          Form field inputs.

          Constraints: `maxItems 200`.

          <Expandable title="inputValues properties">

            <ParamField body="inputName" type="string">

              Form field input name.

              Constraints: `maxLength 100`.

            </ParamField>

            <ParamField body="value" type="string">

              Form field value.

              Constraints: `maxLength 5000`.

            </ParamField>

            <ParamField body="values" type="string[]">

              Form field values.

              Constraints: `maxLength 5000`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="status" type="string">

      RSVP status.

      **Supported values:**

      - `YES`
      - `NO`
      - `WAITING`

    </ParamField>

    <ParamField body="memberId" type="string">

      Member ID of the RSVP.

    </ParamField>

    <ParamField body="options" type="ModificationOptions">

      Create RSVP options.
      WIX_EVENTS.MANAGE_RSVP permission is required.

      <Expandable title="options properties">

        <ParamField body="silent" type="boolean">

          Whether to ignore notification settings (when hen true, no notifications to contact or user are sent).

        </ParamField>

        <ParamField body="ignoreLimits" type="boolean">

          Whether to create/update regardless of event guest limit.

        </ParamField>

        <ParamField body="ignoreFormValidation" type="boolean">

          Whether to ignore the form validation.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="marketingConsent" type="boolean">

      Whether marketing consent was given

    </ParamField>
