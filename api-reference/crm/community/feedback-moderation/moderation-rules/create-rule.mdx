    Creates a rule.

    You can create up to 20 rules per namespace.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MODERATION.MANAGE-MODERATION-RULES">Manage Moderation Rules</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/moderation/v1/rules
    ```

    ## Body Params

    <ParamField body="rule" type="Rule" required>

      Rule info.

      See the [Rule Object](/api-reference/crm/community/feedback-moderation/moderation-rules/rule-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="rule" type="Rule">

      Created rule.

      See the [Rule Object](/api-reference/crm/community/feedback-moderation/moderation-rules/rule-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_RULES` | Exceeded the limit of rules for this `namespace`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Rule Created | `wix.moderation.v1.rule_created` | Triggered when a rule is created. |
