    <Note>

    The Form Submission API only works with the Wix Forms app. Call [GetAppInstance](https://dev.wix.com/docs/rest/api-reference/app-management/apps/app-instance/get-app-instance) to confirm that the app named `wix_forms` is installed on the site.

    </Note>
    <br />
    Deletes a submission by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORMS.MANAGE-SUBMISSIONS">Manage Submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/forms/v4/submissions/{submissionId}
    ```

    ## Path Params

    <ParamField path="submissionId" type="string" required>

      ID of the submission to delete.

    </ParamField>

    ## Query Params

    <ParamField query="permanent" type="boolean">

      Whether to permanently delete a submission bypassing the trash bin.

      Default: `false`

    </ParamField>

    <ParamField query="preserveFiles" type="boolean">

      Whether to preserve files, associated with the submission. If the value is `false`, then the files are deleted after 210 days.

    </ParamField>

    ## Response Object

    Returns `DeleteSubmissionResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |

    | Submission Deleted | `wix.forms.v4.submission_deleted` | > **Note:** The Form Submission API only works with the Wix Forms app. Call [GetAppInstance](https://dev.wix.com/docs/rest/api-reference/app-management/apps/app-instance/get-app-instance) to confirm that the app named `wix_forms` is installed on the site. &lt;br> Triggered when a submission is deleted. |

    </div>
