    <ResponseField name="checkoutFields" type="CheckoutFields">

      Settings that apply to checkout fields and the checkout process.

      <Expandable title="checkoutFields properties">

        <ResponseField name="subscriptionCheckbox" type="SubscriptionCheckboxField">

          Subscription checkbox. &lt;br>&lt;br>

          Controls the marketing consent checkbox shown to the buyer at checkout. By default, a single
          checkbox lets the buyer opt in to both email and SMS marketing at once. When
          `subscriptionCheckbox.splitByChannel` is `true`, checkout instead shows two separate
          checkboxes - one for email, one for SMS - so the buyer can opt into each channel independently.

          <Expandable title="subscriptionCheckbox properties">

            <ResponseField name="visible" type="boolean">

              Whether the checkbox is visible to the customer.

              Default: `false`

            </ResponseField>

            <ResponseField name="checkedByDefault" type="boolean">

              Whether the checkbox is checked by default.

              Default: `false`

            </ResponseField>

            <ResponseField name="splitByChannel" type="boolean">

              Whether checkout shows two separate opt-in checkboxes for email and SMS
              instead of a single combined checkbox. Only takes effect when `visible` is `true`.
              Both checkboxes are always shown together - a buyer can't be shown just one channel.
              `checkedByDefault` applies to both checkboxes equally: when `true`, both start pre-checked.

              Default: `false`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="policyAgreementCheckbox" type="CheckboxField">

          Policy agreement checkbox. &lt;br>&lt;br>

          Defaults:
          + `visible`: `false`
          + `checkedByDefault`: `false`

          <Expandable title="policyAgreementCheckbox properties">

            <ResponseField name="visible" type="boolean">

              Whether the checkbox is visible to the customer.

            </ResponseField>

            <ResponseField name="checkedByDefault" type="boolean">

              Whether the checkbox is checked by default.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="giftCardRedeemEnabled" type="boolean">

          Whether the ability to redeem a gift card is enabled. &lt;br>&lt;br>

          Default: `false`

        </ResponseField>

        <ResponseField name="mitEnabled" type="boolean">

          Whether to allow for MIT transactions. &lt;br>&lt;br>

          Default: `false`

        </ResponseField>

        <ResponseField name="delayCaptureEnabled" type="boolean">

          Whether to allow for Auth & Capture transactions. &lt;br>&lt;br>

          Default: `false`

        </ResponseField>

        <ResponseField name="captureBeforeExpiryEnabled" type="boolean">

          Whether to automatically capture the transaction before the authorization expires.

          Default: `true`
          >**Note:** this setting is only relevant when `delay_capture_enabled: true`.

        </ResponseField>

      </Expandable>

    </ResponseField>

            </ResponseField>

            <ResponseField name="displayCheckoutLabel" type="boolean">

              Whether to display the 'Checkout' label within the header.
              Depending on the locale, the label may be translated.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "checkoutSettings": {
          "checkoutPolicies": {
            "termsAndConditions": {
              "visible": true,
              "content": "All product listings, prices, and specifications are subject to change without notice. ACCS reserves the right to modify or discontinue products at any time."
            },
            "privacyPolicy": {
              "visible": true,
              "content": "Your privacy is important to us. Please review our Privacy Policy to understand how we collect, use, and disclose information."
            },
            "returnPolicy": {
              "visible": true,
              "content": "Please refer to our Return Policy page for information on returns and refunds. ACCS reserves the right to refuse returns that do not meet our policy criteria."
            },
            "digitalItemPolicy": {
              "visible": false,
              "content": ""
            },
            "contactUs": {
              "visible": true,
              "content": "email: accs@mail.com"
            },
            "customPolicy": {
              "visible": true,
              "content": "Placing an order on our website constitutes an offer to purchase the products. We reserve the right to refuse or cancel any order for any reason. Payment must be received before order processing.",
              "title": "Orders and Payments"
            }
          },
          "checkoutFields": {
            "subscriptionCheckbox": {
              "visible": true,
              "checkedByDefault": true
            },
            "policyAgreementCheckbox": {
              "visible": true,
              "checkedByDefault": false
            },
            "giftCardRedeemEnabled": true,
            "mitEnabled": false
          }
        }
      }
      ```

    </CodeGroup>
