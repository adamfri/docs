    Updates multiple promotions. Works synchronously.

    To update a single promotion, call [Update Promotion](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/promotions-v3/update-promotion).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_WRITE">Manage v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/promotions/update
    ```

    ## Body Params

    <ParamField body="promotions" type="MaskedPromotion[]" required>

      List of promotions to update.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="promotions properties">

        <ParamField body="promotion" type="Promotion">

          Promotion to update, may be partial.

          See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the updated promotions in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkPromotionResult[]">

      Results of the bulk update operation.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Metadata for this specific update operation.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Provided only whenever possible. For example, `itemId` can't be provided when item creation has failed.

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

              Constraints: `min 0`.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action for this item was successful. When `false`, the `error` field is returned.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Promotion">

          Updated promotion. Returned only when `returnEntity` is `true` in the request.

          See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata for the bulk update operation.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

          Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

          Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

          Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MEDIA_NOT_FOUND` | Couldn't find the media in Media Manager. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_CATEGORY_ASSIGNMENT` | A category is assigned to the same promotion more than once. |
    | `400` | `INVALID_ARGUMENT` | `MEDIA_REMOVAL_NOT_ALLOWED` | Media can't be removed from a promotion. It can only be replaced. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
