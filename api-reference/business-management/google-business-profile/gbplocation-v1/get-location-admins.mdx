    Retrieves the accounts that manage a location's Business Profile, including
    invitations that haven't been accepted yet.

    Use it to check who already has access before inviting someone, because
    Google rejects an invitation for an account that already manages the
    location.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/locations/{locationId}/admins
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID (Google's opaque location id) to list admins for.

    </ParamField>

    ## Response Object

    <ResponseField name="locationAdmins" type="LocationAdmin[]">

      The accounts that manage this location, including any that have been
      invited but haven't accepted yet.

      <Expandable title="locationAdmins properties">

        <ResponseField name="id" type="string">

          Identifier of this admin record.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="googleLocationId" type="string">

          The Google location this admin record applies to.

          **Read-only.** Constraints: `maxLength 1024`.

        </ResponseField>

        <ResponseField name="name" type="string">

          Email address or account name of the manager, or of the invited account.

          **Read-only.**

        </ResponseField>

        <ResponseField name="accountResourceName" type="string">

          Resource name of the Google Account this Admin refers to (e.g.
          "accounts/12345").

          **Read-only.** Constraints: `maxLength 1024`.

        </ResponseField>

        <ResponseField name="role" type="string">

          Role granted to this admin.

          **Supported values:**

          - `MANAGER` — Can manage the profile but not transfer or delete it.
          - `OWNER` — Owner-level access to the profile.
          - `PRIMARY_OWNER` — The primary owner. A location has exactly one.
          - `SITE_MANAGER` — Legacy Google+ pages manager. Google no longer grants this.

        </ResponseField>

        <ResponseField name="pendingInvitation" type="boolean">

          True if the admin has been invited but has not accepted yet.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
