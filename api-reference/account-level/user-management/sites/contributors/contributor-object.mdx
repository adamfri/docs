---
title: "Contributor Object"
description: "A contributor represents a Wix user with edit or manage access to a site owned by a separate Wix account."
icon: "cube"
---

A contributor represents a Wix user with edit or manage access to a site owned by a separate Wix account. Contributors can be assigned roles that determine their level of access to the site and its assets.

<Tabs>

  <Tab title="REST">

    <ResponseField name="metaData" type="PersonMetaData">

      Contributor's metadata, including account ID, name, email, and role assignments.

      <Expandable title="metaData properties">

        <ResponseField name="id" type="string">

          Contributor's account ID.

        </ResponseField>

        <ResponseField name="fullName" type="string">

          Contributor's full name.

        </ResponseField>

        <ResponseField name="imageUrl" type="string">

          URL for contributor's profile image.

        </ResponseField>

        <ResponseField name="email" type="string">

          Contributor's email address.

        </ResponseField>

        <ResponseField name="assignments" type="Assignment[]">

          Contributor's role assignments, mapping their access to site assets and their assigned roles.

          <Expandable title="assignments properties">

            <ResponseField name="policy" type="AssignedPolicy">

              Role assigned to the user.

              <Expandable title="policy properties">

                <ResponseField name="policyId" type="string">

                  Role ID.

                </ResponseField>

                <ResponseField name="title" type="string">

                  Role title.

                </ResponseField>

                <ResponseField name="description" type="string">

                  Role description.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="assignmentId" type="string">

              Unique ID for this specific assignment.

            </ResponseField>

            <ResponseField name="subject" type="Subject">

              Identity assigned to the asset in an assignment, referred to as subject. Supported subjects include user IDs, account IDs, and app IDs.

              <Expandable title="subject properties">

                <ResponseField name="id" type="string">

                  ID of identity assigned to the asset.

                </ResponseField>

                <ResponseField name="subjectType" type="string">

                  Type of identity assigned to the asset. Supported subject types include user IDs, account IDs, and app IDs.

                  **Supported values:**

                  - `ACCOUNT`
                  - `USER`
                  - `USER_GROUP`
                  - `MEMBER_GROUP`
                  - `VISITOR_GROUP`
                  - `EXTERNAL_APP`
                  - `ACCOUNT_GROUP`
                  - `WIX_APP`

                </ResponseField>

                <ResponseField name="context" type="SubjectContext">

                  Context of identity assigned to the asset. For example, a `subjectType` = `USER` will have `context` = `ACCOUNT`.

                  _Nested structure omitted for brevity — see the `SubjectContext` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="isTeam" type="boolean">

      Whether the contributor account is a team account.

    </ResponseField>

    <ResponseField name="joinedAt" type="datetime">

      Date that the contributor joined the site.

    </ResponseField>

    <ResponseField name="invitedEmail" type="string">

      Email address that received the invite.

    </ResponseField>

    <ResponseField name="isClient" type="boolean">

      Whether the contributor account is a client account.

    </ResponseField>

    <ResponseField name="id" type="string">

      Contributor's user ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="callerCapabilities" type="string[]">

      A set of capability keys representing the actions that the caller is allowed
      to perform on this specific contributor. This field is calculated based on the
      identity of the request sender and may differ between callers.

      Constraints: `maxLength 20`, `maxItems 20`.

    </ResponseField>

    <ResponseField name="accountGroup" type="string">

      Account group of the contributor's owning account (enterprise, channels, unknown).
      Only meaningful for team accounts (is_team = true); resolved from population membership.
      Non-team contributors remain UNKNOWN_ACCOUNT_GROUP (proto default 0).

      **Supported values:**

      - `ENTERPRISE`
      - `CHANNELS`

    </ResponseField>

  </Tab>
