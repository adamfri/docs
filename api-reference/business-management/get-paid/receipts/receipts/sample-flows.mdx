This article shares some possible use cases you could support,
as well as a sample flow that could support each use case.
This can be a helpful jumping off point as you plan your implementation.

## Set up automatic receipt generation 
You can generate a receipt for an existing Wix eCommerce order or Wix Payments transaction automatically using [Wix Automations](fallback::https://dev.wix.com/docs/rest/business-management/automations/introduction).

1. Define an automations trigger. More about Automations can be found:
   - For app development: [Add a trigger to your app](fallback::https://dev.wix.com/docs/rest/business-management/automations/triggers/add-a-trigger-to-your-app).
   - For site development: [About custom triggers](fallback::https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/automations/about-custom-triggers).  
   
   The trigger payload output schema **must** contain a property of `wixCustomType` with a `RECEIPT` field.
1. Define an automation with the trigger from the previous step and set `Issue a receipt` as it's action. This triggers a call to [Create Receipt](fallback::https://dev.wix.com/docs/rest/business-management/get-paid/receipts/receipts/create-receipt) under the hood.
   <Note>

   Wix apps can create a [pre-installed automation](fallback::https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/automations/pre-installed-automations/about-pre-installed-automations) with the defined automation from the previous step, that will be installed automatically with the app.

   </Note>
1. When a Wix user, or your app, triggers the automation trigger defined above, a new receipt is generated.

## Manually trigger receipt creation 
You can provide the ability to manually generate a receipt for an existing Wix eCommerce or Wix Payments transaction.

1. Retrieve the relevant Wix eCommerce or Wix Payments transactions and display them to the Wix user with a call to action to create a receipt.
1. When a Wix user chooses to create a receipt for a specific transaction, call [Create Receipt](fallback::https://dev.wix.com/docs/rest/business-management/get-paid/receipts/receipts/create-receipt) with the specified receipt data collected from the transaction, along with any user data.

## Resend receipts 
You can enable Wix users to resend receipts to customers as necessary within a dashboard page.

1. In your dashboard page, display customer data, including their purchases, with a call to action to resend a receipt.
1. When the Wix user selects a specific customer, call [Query Receipts](https://dev.wix.com/docs/rest/business-management/get-paid/get-paid/receipts/receipt-v1/query-receipts) and filter by customer `contactId`. Display the returned data to the Wix user with a call to action to resend a receipt.
1. When the Wix user selects a receipt, call [Send Receipt Email](https://dev.wix.com/docs/rest/business-management/get-paid/get-paid/receipts/receipt-v1/send-receipt-email) to send the receipt to the customer.
