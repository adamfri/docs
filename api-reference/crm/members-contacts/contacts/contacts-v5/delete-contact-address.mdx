    <div className="wix-ref">

    Deletes an address from a contact by address ID.

    Each time the contact is updated, `revision` increments by 1. The current `revision` must be passed. This ensures you're working with the latest contact and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/contacts/v5/contacts/{contactId}/addresses/{addressId}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to delete the address from.

    </ParamField>

    <ParamField path="addressId" type="string" required>

      ID of the address to delete.

    </ParamField>

    ## Query Params

    <ParamField query="revision" type="integer" required>

      Contact revision number.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ADDRESS_NOT_FOUND` | Couldn't find an address with this `addressId` on the contact. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS_ID` | A contact has multiple addresses with the same ID. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
