    Updates a ticket.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/tickets/{ticketNumber}
    ```

    ## Path Params

    <ParamField path="ticketNumber" type="string" required>

      Unique ticket number.

    </ParamField>

    ## Body Params

    <ParamField body="eventId" type="string">

      Event ID to which the ticket belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="fields" type="FieldMask">

      Set of field paths, specifying which parts of this resource to update.
      When `fields` is empty, the request is interpreted as a full update.
      Behavior follows [google.protobuf.FieldMask](https://developers.google.com/protocol-buffers/docs/reference/google.protobuf#google.protobuf.FieldMask) semantics.

      <Expandable title="fields properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>

    <ParamField body="archived" type="boolean">

      Whether to archive the ticket.

    </ParamField>

    <ParamField body="guestDetails" type="GuestDetailsUpdate">

      Assigned guest details.

      <Expandable title="guestDetails properties">

        <ParamField body="form" type="FormResponse">

          Form of a guest assigned to a ticket.

          To update the form of a guest not assigned to a ticket, call Update Order.

          Doesn't support partial updates, the entire form object will be replaced when `guestDetails.form` is masked.

          <Expandable title="form properties">

            <ParamField body="inputValues" type="InputValue[]">

              Form field inputs.

              Constraints: `maxItems 200`.

              _Nested structure omitted for brevity — see the `InputValue[]` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="ticket" type="Ticket">

      Updated ticket.

      See the [Ticket Object](/api-reference/business-solutions/events/registration/ticketing/tickets/ticket-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
