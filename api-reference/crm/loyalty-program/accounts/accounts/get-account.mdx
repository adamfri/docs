    Retrieves a loyalty account by ID.

    You can also retrieve an account using a secondary ID, such as a contact ID or a member ID by calling
    Get Account by Secondary ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-accounts/v1/accounts/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the account to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="LoyaltyAccount">

      Retrieved loyalty account.

      See the [Account Object](/api-reference/crm/loyalty-program/accounts/accounts/account-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
