    Retrieves a list of up to 100 sites per request, given the provided paging, sorting and filtering.

    <Note>

    You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `name` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `published` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `premium` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `editorType` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `folderId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `namespace` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `domainConnected` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `displayName` |  | Sort: `ASC`, `DESC` |
    | `createdDate` |  | Sort: `ASC`, `DESC` |
    | `updatedDate` |  | Sort: `ASC`, `DESC` |
    | `trashedDate` |  | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ACC-DC-OS.READ-SITE">Read Site Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-list/v2/sites/query
    ```

    ## Body Params

    <ParamField body="query" type="QueryV2">

      Filter and sorting with the following format:
      `"filter" : { "displayName": "my-site" }`

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object with the following format:
          `"filter" : {`
          "displayName": "my-site",
          "namespace":&#123;"$in":["value1", "value2"]&#125;,
          "folderId": &#123;"$exists": false&#125;
          &#125;``
          Example of operators: `$in`, `$hasSome`, `$hasAll`, `$exists`

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object with the following format:
          `[{"fieldName":"displayName","order":"ASC"},{"fieldName":"createdDate","order":"DESC"}]`

          Constraints: `minItems 0`, `maxItems 4`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

            <ParamField body="origin" type="AddressLocation">

              Origin point for geo-distance sorting on a GEO field

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

            <ParamField body="cursorPaging" type="CursorPaging">

              Paging options to limit and offset the number of items.
              wix.common.Paging paging = 3;

      </Expandable>

    </ParamField>
