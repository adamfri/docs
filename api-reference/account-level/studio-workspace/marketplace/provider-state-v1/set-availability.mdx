    Sets whether the current provider receives new leads.
    Set `enabled` to `false` to pause all new leads (for example, while on vacation) and `true` to resume.
    The provider must be published; otherwise the call fails with `NOT_PUBLISHED`. Calling with availability
    already set to the requested value fails with `ALREADY_SET`. Resuming availability also clears any active
    prolonged-unavailability warning on the provider's status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/marketplace/v1/provider-states/set-availability
    ```

    ## Body Params

    <ParamField body="enabled" type="boolean">

      Whether the provider accepts new leads. Set to `true` to resume receiving new leads or `false` to pause them.

    </ParamField>

    ## Response Object

    <ResponseField name="providerState" type="ProviderState">

      Updated provider state.

      See the [Providerstate Object](/api-reference/account-level/studio-workspace/marketplace/provider-state-v1/providerstate-object) for this object's fields.

    </ResponseField>

    </Note>
