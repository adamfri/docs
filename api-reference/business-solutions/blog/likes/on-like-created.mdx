Triggers when a like is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.blog.v1.like_created` |
| Package | `@wix/blog` |
| Permissions | `Read Blog`, `Manage Blog`, `Read Draft Blog Posts` |

  import { likes } from '@wix/blog';
