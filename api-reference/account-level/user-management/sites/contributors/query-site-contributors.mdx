    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a list of contributors for the specified site, given the provided filters.

    Returns contributor account IDs and account owner IDs that match the specified filters.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-IDENTITY.MANAGE-CONTRIBUTORS">Manage Contributors</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/roles-management/v2/contributors/query
    ```

    ## Query Params

    <ParamField query="filter" type="QuerySiteContributorsFilter">

      Filter object for narrowing search results.

      <Expandable title="filter properties">

        <ParamField query="policyIds" type="string[]">

          Role IDs (referred to here as policy IDs) to filter by. Returns only contributors with at least one of the specified roles. See [Roles and Permissions](https://support.wix.com/en/article/roles-permissions-overview) for available roles.

          Constraints: `maxItems 20`.

        </ParamField>

        <ParamField query="locationIds" type="string[]">

          Location IDs to filter by. Returns only contributors with assignments to at least one of the specified locations.

          Constraints: `format GUID`, `maxItems 20`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="contributors" type="ContributorV2[]">

      List of site contributors matching the filter criteria.

      <Expandable title="contributors properties">

        <ResponseField name="accountId" type="string">

          Contributor's account ID.

        </ResponseField>

        <ResponseField name="accountOwnerId" type="string">

          User ID of the owner of the account that the contributor belongs to.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
