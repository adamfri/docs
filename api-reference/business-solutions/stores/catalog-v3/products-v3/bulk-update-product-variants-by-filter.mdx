    Updates multiple product variants, given the provided filter and search expression.

    Only the following variant fields can be updated:
    + `visible`
    + `price`
    + `revenueDetails.cost`
    + `physicalProperties`

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_WRITE">Product write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/products/update-variants-by-filter
    ```

    This example contains all fields that allowed in this method. All variants of all products that satisfy a filter will be updated.

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/stores/v3/bulk/products/update-variants-by-filter' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>' \
      -d '{
            "filter": {
              "id": "d17bb5c4-e10f-4b83-ae97-f27f2edc18f1"
            },
            "variant": {
              "visible": false,
              "price": {
                "compareAtPrice": {
                  "amount": "7"
                },
                "actualPrice": {
                  "amount": "6"
                }
              },
              "revenueDetails": {
                "cost": {
                  "amount": "5"

                "weight": 0.1,
                "pricePerUnit": {

                }
              }
            }
          }'
      ```
