Triggered when a schedule's time frame is updated, indicating a new first or
last event or a change in the recurrence period, such as an extension or
reduction.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.calendar.v3.schedule_time_frame_updated` |
| Package | `@wix/calendar` |
| Permissions | `Read Bookings - Public Data`, `Read Calendar - Including PI`, `Manage Calendars`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Read Bookings Calendar Availability`, `Read Calendar`, `Manage Bookings - all permissions`, `Read bookings calendar - including participants`, `Read Bookings Calendar` |

## Examples

<CodeGroup>

  import { scheduleTimeFrames } from '@wix/calendar';
