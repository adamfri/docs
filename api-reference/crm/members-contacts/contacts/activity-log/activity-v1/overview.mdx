A dated record of something that happened with a contact — such as a message sent, a subscription change, or any other noteworthy event.

## SDK package

```bash
npm install @wix/contacts-activity-log-activities
```

Import the `contactsActivityLogActivities` namespace from `@wix/contacts-activity-log-activities`.
