    Deletes a field from the structure of a data collection.

    When a field is deleted, all values associated with that field are also deleted
    from all items in the collection.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/collections/delete-field
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the data collection to update.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="fieldKey" type="string" required>

      ID of the field to delete.

      Constraints: `maxLength 1000`.

    </ParamField>

    ## Response Object

    <ResponseField name="dataCollection" type="DataCollection">

      Updated data collection.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
