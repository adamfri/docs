Triggered when a task is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.tasks.v2.task_created` |
| Package | `@wix/crm` |
| Permissions | `Read Tasks`, `Manage Tasks` |

## Examples

<CodeGroup>

  ```javascript onTaskCreated
  import { tasks } from '@wix/crm';

  tasks.onTaskCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onTaskCreated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';

    auth: AppStrategy({

      publicKey: 'YOUR_APP_PUBLIC_KEY',

      },
  });

      // handle your event here
  ```
