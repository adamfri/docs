    <div className="wix-ref">

    Updates a benefit item.

    Each time the benefit item is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the benefit item.
    This ensures you're working with the latest benefit item
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/benefit-programs/v1/items/{item.id}
    ```

    ## Path Params

    <ParamField path="item.id" type="string" required>

      Benefit item ID.

    </ParamField>

    ## Body Params

    <ParamField body="item" type="Item" required>

      Item to update.

      See the [Item Object](/api-reference/business-solutions/benefit-programs/items/item-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="item" type="Item">

      Updated item.

      See the [Item Object](/api-reference/business-solutions/benefit-programs/items/item-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Benefit item ID.

      **Read-only.**

    </ParamField>

    <ParamField body="item" type="UpdateItem" required>

      Item to update.

      <Expandable title="item properties">

        <ParamField body="_id" type="string">

          Benefit item ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the benefit item is updated.
          To prevent conflicting changes, the current revision must be passed when updating the benefit item.

          Ignored when creating a benefit item.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the item was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the item was updated.

          **Read-only.**

        </ParamField>

        <ParamField body="externalId" type="string">

          ID of the item in the app providing it.

          For example, if the item is a product provided by Wix Stores, the `externalId` would be the Wix Stores `product Id`.

          **Read-only.**

        </ParamField>

        <ParamField body="category" type="string">

          Benefit item category.

          **Read-only.**

        </ParamField>

        <ParamField body="itemSetId" type="string">

          Item set ID of the benefit that this benefit item is a part of.

          **Read-only.**

        </ParamField>

        <ParamField body="displayName" type="string">

          Benefit item display name.

        </ParamField>

        <ParamField body="providerAppId" type="string">

          ID of the [app](https://dev.wix.com/docs/rest/articles/getting-started/apps-created-by-wix) that defines and provides the item. For example, if the item is a Wix Stores product, this field's value is `215238eb-22a5-4c36-9e7b-e7c08025e04e`.

          **Read-only.**

        </ParamField>

        <ParamField body="extendedFields" type="ExtendedFields">

          Custom field data for the benefit item object.

              Constraints: `format map`.

              _Nested structure omitted for brevity — see the `object` object._
