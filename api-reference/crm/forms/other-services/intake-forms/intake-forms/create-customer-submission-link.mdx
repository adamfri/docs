    <div className="wix-ref">

    Creates a shareable link for customers to submit an intake form.

    The link is valid for 72 hours.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.READ">Read Intake Form</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_api/intake-forms/v1/intake-forms/{intakeFormId}/link
    ```

    ## Path Params

    <ParamField path="intakeFormId" type="string" required>

      Intake form ID.

    </ParamField>

    ## Response Object

    <ResponseField name="intakeFormUrl" type="string">

      Generated link URL for the intake form submission.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_SITE_URL` | Site doesn't have a configured URL. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
