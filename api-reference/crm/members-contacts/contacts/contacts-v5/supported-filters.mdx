## Fields supported by Query Contacts

The following table shows field support for filters and sorting for the [Query Contacts](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/query-contacts) method:

| Field           | Supported filters                   | Sortable |
|-----------------|-------------------------------------|----------|
| `id`            | `$eq`, `$in`                        |          |
| `createdDate`   | `$eq`, `$gt`, `$lt`, `$gte`, `$lte`  | Sortable |
| `updatedDate`   | `$eq`, `$gt`, `$lt`, `$gte`, `$lte`  | Sortable |
| `email.email`   | `$eq`, `$in`, `$exists`              |          |
| `phone.phone`   | `$eq`, `$in`, `$exists`              |          |
| `externalId`    | `$eq`, `$in`, `$exists`              |          |
