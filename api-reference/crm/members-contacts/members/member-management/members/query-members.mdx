    Retrieves a list of up to 100 members, given the specified filters, fieldsets, sorting, and paging.

    To learn about working with _Query_ methods, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/docs/rest/articles/getting-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/docs/rest/articles/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `profile.nickname` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `profile.slug` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `contactId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `contact.firstName` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `contact.lastName` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `privacyStatus` | `$eq`, `$ne`, `$in`, `$exists` | None |
    | `loginEmail` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | None |
    | `status` | `$eq`, `$ne`, `$in`, `$exists` | None |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/members/query
    ```

    <ParamField body="query" type="Query">

      Query options.

      <Expandable title="query properties">

        <ParamField body="filter" type="any">

        <ParamField body="paging" type="Paging">

          Limit number of results

          <Expandable title="paging properties">

            <ParamField body="limit" type="integer">

              Number of items to load.

            </ParamField>

            <ParamField body="offset" type="integer">

              Number of items to skip in the current sort order.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="sorting" type="Sorting[]">

          Sort the results

          <Expandable title="sorting properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

            <ParamField body="origin" type="AddressLocation">

              Origin point for geo-distance sorting on a GEO field
              results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

              _Nested structure omitted for brevity — see the `AddressLocation` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fieldsets" type="string[]">

      Predefined sets of fields to return.

      Default: `"PUBLIC"`.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `PUBLIC` — Includes `id`, `contactId`, `createdDate`, `updatedDate` and the `profile` object.
      `status`, `privacyStatus`, and `activityStatus` are returned as `UNKNOWN`.
      - `EXTENDED` — Includes `id`, `loginEmail`, `status`, `contactId`, `createdDate`, `updatedDate`, `privacyStatus`, `activityStatus` and the `profile` object.
      - `FULL` — Includes all fields.

    </ParamField>

    <ParamField body="search" type="Search">

      Plain text search.

      <Expandable title="search properties">

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Currently supported fields for search:

          - `loginEmail`
          - `contact.firstName`
          - `contact.lastName`
          - `profile.title`
          - `profile.nickname`
          - `profile.slug`

          Default: `profile.nickname`.

          Constraints: `maxItems 4`.

        </ParamField>

      </Expandable>

    </ParamField>
