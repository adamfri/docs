    Creates a contact.

    At least one of `name.first`, `name.last`, `email.email`, or `phone.phone` must be provided.

    Duplicate handling: By default, creation fails if a contact with the same identifiers (`externalId`, `email.email`, or `phone.phone`) already exists. Set `allowDuplicates` to `true` to bypass this check. Learn more about [contact matching and duplicates](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/matching-contacts).

    Image upload: When you provide an image URL, the image is uploaded asynchronously and an `imageUploadId` is returned for tracking upload progress. Call [Get Contact Image Upload Status](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/get-contact-image-upload-status) to monitor the upload.

    To create multiple contacts in a single request, call [Bulk Create Contacts](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/bulk-create-contacts).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts
    ```

    ## Body Params

    <ParamField body="contact" type="Contact" required>

      Contact to create.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ParamField>

    <ParamField body="allowDuplicates" type="boolean">

      Whether to create the contact even if it duplicates an existing contact.
      More about duplicate contacts can be found [here](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/matching-contacts).

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Created contact.

    <ResponseField name="imageUploadId" type="string">

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INSUFFICIENT_CONTACT_DATA` | A contact must have a name, phone number or email address. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_EMAIL` | The contact has duplicate emails. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_PHONE` | A contact has duplicate phones. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS` | A contact has duplicate addresses. |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_DEFAULT_ADDRESSES` | The contact has more than one address marked as default. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_ADDRESS_ID` | A contact has multiple addresses with the same ID. |
    | `400` | `INVALID_ARGUMENT` | `EMAIL_REQUIRED` | A contact has additional emails but no email. |
    | `400` | `INVALID_ARGUMENT` | `PHONE_REQUIRED` | A contact has additional phones but no phone. |
    | `409` | `ALREADY_EXISTS` | `DUPLICATE_CONTACT_EXISTS` | A contact with the same identifier already exists. More about identifiers can be found [here](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/matching-contacts). |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TIME_ZONE` | The contact time zone is not in valid IANA format. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_BIRTHDATE` | The contact birthdate is not in valid YYYY-MM-DD format. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_IMAGE_URL` | The contact image URL is invalid. |
