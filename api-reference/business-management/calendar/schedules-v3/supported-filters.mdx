<Note>This article applies to the REST API only.</Note>

Query endpoints allow you to filter and sort results based on service properties.
This article covers field support for filtering and sorting.

The following table shows field support for filters
for the `schedules` object in
[Query Schedules](fallback::https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/query-schedules):

| Field           | Supported Filters                             |
| --------------- | --------------------------------------------- |
| `id` | `$eq`, `$in` |
| `externalId` | `$eq`, `$in` |
| `appId` | `$eq`, `$in` |
| `status` | `$eq`, `$in` |

To learn about working with _Query_ endpoints in general, see
[API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).
