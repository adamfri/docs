    Creates an import object based on an uploaded file.

    Call this method after uploading your file to the URL obtained from Create Loyalty Import File Url.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/loyalty-imports/v1/loyalty-imports
    ```

    ## Body Params

    <ParamField body="fileUrl" type="string" required>

      URL of the file to import.

    </ParamField>

    <ParamField body="fileName" type="string">

      Name of the file to import.

    </ParamField>

    <ParamField body="fileSize" type="integer">

      Size of the file to import, in bytes.

    </ParamField>

    ## Response Object

    <ResponseField name="loyaltyImport" type="LoyaltyImport">

      Created loyalty import.

      See the [Loyalty Import Object](/api-reference/crm/loyalty-program/accounts/imports/loyalty-import-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Loyalty Import Created | `wix.loyalty.imports.v1.loyalty_import_created` | Triggered when a loyalty import is created. |
