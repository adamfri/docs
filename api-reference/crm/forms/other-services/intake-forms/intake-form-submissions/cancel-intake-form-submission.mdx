    <div className="wix-api-columns">

    <div className="wix-ref">

    Changes an intake form submission's status to `CANCELED`.

    The submission remains in the system for record-keeping, but is no longer valid. You can't reactivate it, the contact must create a new submission to have a valid submission again.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.MANAGE_LIMITED">Manage Intake Form (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/intake-forms/v1/submissions/{intakeFormSubmissionId}/cancel
    ```

    ## Path Params

    <ParamField path="intakeFormSubmissionId" type="string" required>

      Intake form submission ID.

    </ParamField>

    ## Response Object

    <ResponseField name="intakeFormSubmission" type="IntakeFormSubmission">

      Canceled intake form submission.

      See the [Intake Form Submission Object](/api-reference/crm/forms/other-services/intake-forms/intake-form-submissions/intake-form-submission-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
