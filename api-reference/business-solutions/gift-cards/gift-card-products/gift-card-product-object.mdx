A gift card product is a template that defines what a purchasable gift card looks like, including
its name, description, image, available denominations, and expiration policy.
When a customer buys a gift card, an individual gift card instance is created
based on the product's configuration.

      Gift card product ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the gift card product is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the gift card product.

      Ignored when creating a gift card product.

      **Read-only.**

    </ResponseField>

      **Read-only.**

      **Read-only.**

      Constraints: `maxLength 55`.

    <ResponseField name="image" type="Image">

      Gift card product image. Only images from the Wix Media Manager are supported. To use an external image, first upload it to the Wix Media Manager.

      When setting the image, you must provide at least `id`, `width`, and `height`.
      The `id` is the file name from the image URL. For example, for `https://static.wixstatic.com/media/5cc69183e7954e2c9760fa2383870992.jpg`, the `id` is `5cc69183e7954e2c9760fa2383870992.jpg`.

      <Expandable title="image properties">

        <ResponseField name="id" type="string">

          WixMedia image ID.

          Constraints: `maxLength 200`.

        </ResponseField>

        <ResponseField name="url" type="string">

          WixMedia image ID.

          Constraints: `format WEB_URL`.

        </ResponseField>

        <ResponseField name="height" type="integer">

          Original image height.

          **Read-only.**

        </ResponseField>

        <ResponseField name="width" type="integer">

          Original image width.

          **Read-only.**

        </ResponseField>

        <ResponseField name="altText" type="string">

          Image alt text.

        <ResponseField name="filename" type="string">

          Image filename.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="expirationType" type="string">

      Expiration type for gift cards created from this product.

      **Supported values:**

      - `NONE` — Gift cards created from this product don't expire.
      - `FIXED` — Gift cards expire on a specific date.
      - `RELATIVE` — Gift cards expire after a set period from the date of purchase.

    </ResponseField>

    <ResponseField name="presetVariants" type="PresetVariant[]">

      List of preset variants with predefined denominations that buyers can choose from. A product can have both preset variants and a custom variant.

      When updating, the entire list is replaced. There's no way to update an individual preset variant.

      Constraints: `minItems 0`, `maxItems 200`.

        <ResponseField name="id" type="string">
