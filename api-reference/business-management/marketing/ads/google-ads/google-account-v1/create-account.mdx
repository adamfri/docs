    Creates a Google Ads account linked to the current Wix site.
    This is a multi-step operation: validates that no account exists for the site, selects a
    Google Ads manager account based on the requested currency, creates the Google Ads customer
    account, sets up billing (skipped for test accounts), and saves the mapping to the database.
    If a `selectedIncentiveId` is provided, records the incentive choice for later application.
    The Wix Google Ads app must be installed on the site before calling this method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-GOOGLE-ADS">Manage google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/accounts
    ```

    ## Body Params

    <ParamField body="currency" type="string" required>

      Three-letter currency code in ISO-4217 alphabetic format. Used to select the appropriate Google Ads manager account.

      Constraints: `format CURRENCY`.

    </ParamField>

    <ParamField body="selectedIncentiveId" type="string">

      Incentive ID returned by `SuggestionsService.GetIncentives`, selected by the user before checkout.
      When provided, the incentive is recorded and applied automatically after the account's budget is assigned.

      Constraints: `maxLength 1000`.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="Account">

      The newly created Google Ads account.

      See the [Google Account Object](/api-reference/business-management/marketing/ads/google-ads/google-account-v1/google-account-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `CREATION_BLOCKED` | Account creation is currently disabled. |
    | `409` | `ALREADY_EXISTS` | `ACCOUNT_ALREADY_EXISTS` | A Google Ads account is already linked to this site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
