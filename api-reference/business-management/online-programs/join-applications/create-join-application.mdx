    Creates a join application for a program.

    Members creating their own applications can't specify `memberId`. It's automatically set to the calling member. Wix users must specify `memberId` when creating an application on a member's behalf.

    For member-initiated applications, `status` is set automatically: `APPROVED` for a public program, and `APPROVAL_PENDING` for a program that requires approval. A member can't specify `status`.

    A Wix user creating an application on a member's behalf can set the initial `status`, typically to `INVITED` or `APPROVED`. When a Wix user omits `status`, it defaults to `APPROVED`.

    The program must be published.

    To create multiple join applications in a single API call, call [Bulk Create Join Applications](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/bulk-create-join-applications).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications
    ```

    ## Body Params

    <ParamField body="joinApplication" type="JoinApplication" required>

      Join application to create.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Created join application.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `PROGRAM_NOT_FOUND` | The specified `programId` doesn't exist. |
    | `428` | `FAILED_PRECONDITION` | `PROGRAM_NOT_PUBLISHED` | The program exists but isn't published. |
    | `409` | `ALREADY_EXISTS` | `ALREADY_EXISTS` | A join application already exists for the specified `programId` and `memberId`. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_MEMBER_ID` | `memberId` is required when a Wix user creates an application on a member's behalf. |
    | `428` | `FAILED_PRECONDITION` | `PREMIUM_PLAN_REQUIRED` | The site needs a Premium plan to add more participants. |
    | `428` | `FAILED_PRECONDITION` | `PARTICIPANTS_LIMIT_EXCEEDED` | The program's participant limit has been reached. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
