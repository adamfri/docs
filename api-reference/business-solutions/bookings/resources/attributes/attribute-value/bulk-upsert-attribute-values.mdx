    Upserts attribute values for an entity.

    Each entry in `values` is upserted by its `attributeDefinitionId`: a matching value is updated, otherwise a new one is created. Existing attribute values for this entity that aren't in the list are left unchanged. The order of returned values isn't guaranteed; sort client-side if you need a stable order.

    To retrieve the resulting values paired with their definitions, call List Entity Attributes.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ATTRIBUTES.MANAGE">Manage_Wix_Attributes_Forms_submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/attributes/v1/attribute-values/{entityId}/bulk-upsert
    ```

    ## Path Params

    <ParamField path="entityId" type="string" required>

      ID of the entity whose attribute values to update.

    </ParamField>

    ## Body Params

    <ParamField body="values" type="BulkUpsertAttributeValue[]">

      Attribute values to upsert for this entity. Each entry is matched by `attribute_definition_id`.
      Values not listed aren't modified.

      Constraints: `minItems 1`, `maxItems 50`.

      <Expandable title="values properties">

        <ParamField body="attributeDefinitionId" type="string" required>

          ID of the attribute definition this value applies to.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the upserted attribute values in the response.

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `VALUE_REQUIRED` | An entry has no value set. |
    | `400` | `INVALID_ARGUMENT` | `VALUE_TYPE_MISMATCH` | An entry's value variant does not match the referenced attribute definition's `valueType`. |
    | `400` | `INVALID_ARGUMENT` | `VALUE_NOT_IN_ALLOWED_VALUES` | A string value is not one of the definition's configured `allowedValues`. |
    | `400` | `INVALID_ARGUMENT` | `VALUE_OUT_OF_RANGE` | A number value is outside the definition's configured `min`/`max` range. |
    | `404` | `NOT_FOUND` | `ATTRIBUTE_DEFINITION_NOT_FOUND` | Couldn't find the attribute definition referenced by an entry. |
