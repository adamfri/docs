    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SITE-PLUGIN.READ-PLACEMENT-STATUS">Read Site Plugin Status</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/app-plugins/v1/site-plugins/placement-status
    ```

    ## Response Object

    <ResponseField name="placementStatuses" type="PlacementStatus[]">

      Data about placement statuses of your app's site plugins on the user's site.
