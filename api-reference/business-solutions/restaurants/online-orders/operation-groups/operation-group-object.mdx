title: "Operation Group Object"
description: "An operation group is a aggregation of operations that each one of them point to a different location."

---

An operation group is a aggregation of operations that each one of them point to a different location.
Each operation group has different ordering page.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      OperationsGroup ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the OperationsGroup is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the OperationsGroup.

      Ignored when creating a OperationsGroup.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the OperationsGroup was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the OperationsGroup was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      The name of the operations group

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Data Extensions

            <ResponseField name="key" type="string" />

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags ([SDK](https://dev.wix.com/docs/sdk/backend-modules/tags/tags/introduction) | [REST](https://dev.wix.com/docs/rest/business-management/tags/introduction)) used to classify and sort different types of operation groups.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">
