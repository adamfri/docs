    Creates an action for the specified app. Once created, users can [create automations](https://support.wix.com/en/wix-automations-7067897) that include this action.

    Learn more about [actions](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions).

    <Note>

    You can only create actions for [apps you own or collaborate on](https://dev.wix.com/docs/build-apps/develop-your-app/app-dashboard-setup/manage-collaborators).

    </Note>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions
    ```

    ## Body Params

    <ParamField body="action" type="Action">

      Action to add to the app.

      See the [Action Object](/api-reference/business-management/automations/actions/action-catalog/action-object) for this object's fields.

    </ParamField>

    <ParamField body="baseUri" type="string">

      Base URI of the action provider service plugin that handles the action's invocation.

      Constraints: `maxLength 256`.

    </ParamField>

    ## Response Object

    <ResponseField name="action" type="Action">

      Created action.

      See the [Action Object](/api-reference/business-management/automations/actions/action-catalog/action-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `ACTION_ALREADY_EXISTS` | An action already exists for the requested app and action key. |
    | `403` | `PERMISSION_DENIED` | `UNAUTHORIZED_APP` | The caller is not authorized to manage actions for the requested app. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Create action
    import { actionCatalog } from "@wix/automations";

    const inputSchema = {
      $schema: "http://json-schema.org/draft-07/schema",
      type: "object",
      required: ["contactId", "amount"],
      properties: {
        contactId: {
          type: "string",
          format: "uuid",
          title: "Contact ID",
          identityType: "contact",
        },
        amount: {
          type: "number",
          title: "Gift card amount",
        },
        message: {
          type: "string",
          title: "Personal message",
        },
      },
    };

    async function createAction() {
      const response = await actionCatalog.createAction({
        action: {
          appId: "e4c3e640-0b63-4bd9-8574-53f8c14e0236",
          actionKey: "send-gift-card",
          displayName: "Send a gift card",
          description: "Send a gift card to a contact via email.",
          inputSchema,
          interfaceConfiguration: { type: "GENERIC" },
        },
      });
      return response;
    }
    ```
