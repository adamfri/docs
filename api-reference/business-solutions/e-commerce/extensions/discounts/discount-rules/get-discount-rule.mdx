    Retrieves a discount rule.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.READ-ECOM">Read eCommerce - all read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/discount-rules/{discountRuleId}
    ```

    ## Path Params

    <ParamField path="discountRuleId" type="string" required>

      ID of the discount rule to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="discountRule" type="DiscountRule">

      The requested discount rule.

      See the [Discount Rule Object](/api-reference/business-solutions/e-commerce/extensions/discounts/discount-rules/discount-rule-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
