    Retrieves the version of an action that's currently active on the site.

    - To retrieve a specific action version by ID, call [Get Action](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-action).
    - To retrieve the latest version of the action regardless of the site on which it's installed, call [Get Latest Action](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-latest-action).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/actions/apps/{appId}/keys/{actionKey=**}
    ```

    ## Path Params

    <ParamField path="appId" type="string" required>

      ID of the app that defines the action.

    </ParamField>

    ## Query Params

    <ParamField query="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

    </ParamField>

    ## Response Object

    <ResponseField name="action" type="Action">

      Retrieved action.
