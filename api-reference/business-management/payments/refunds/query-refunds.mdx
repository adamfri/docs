    Retrieves a list of refunds given the provided paging, filtering, and sorting. Up to 100 Refunds can be returned per request.

    To learn how to query refunds, see [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `chargeId` | `$eq`, `$in` | None |
    | `createdDate` |  | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.READ-REFUNDS">Read Refunds</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/refunds/v1/refunds/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery">

      Query options.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          "fieldName1": "value1",
          "fieldName2":&#123;"$operator":"value2"&#125;
          &#125;``

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"sortField1","order":"ASC"},{"fieldName":"sortField2","order":"DESC"}]`

          Constraints: `maxItems 4`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 64`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              - `ASC`

      </Expandable>

    ## Examples

    Get last 10 refunds for a charge that are not failed or reversed

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/payments/refunds/v1/refunds/query' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json'
        --data-binary '{
          "query": {
            "filter": {
              "chargeId": "602b516f-e8a2-4e1a-9a17-0708099a74db",
              "$not": {
                "status": {"$in": ["FAILED", "REVERSED"]}
              }
            },
            "sort": [{"fieldName": "createdDate", "order": "DESC"}],
            "cursorPaging": {
              "limit": 10
            }
          }
      ```
