    Updates a tax region.

    Each time the tax region is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the tax region.
    This ensures you're working with the latest tax region and prevents
    unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/billing/v1/tax-regions/{taxRegion.id}
    ```

    ## Path Params

    <ParamField path="taxRegion.id" type="string" required>

      Tax region ID.

    </ParamField>

    ## Body Params

    <ParamField body="taxRegion" type="TaxRegion" required>

      Tax region info to update.

      See the [Tax Region Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-regions/tax-region-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="taxRegion" type="TaxRegion">

      Updated tax region.

      See the [Tax Region Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-regions/tax-region-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CALCULATOR_ID_NOT_FOUND` | Couldn't find the calculator. |
    | `428` | `FAILED_PRECONDITION` | `CALCULATOR_IS_NOT_SUPPORTED_FOR_THIS_TAX_REGION` | The calculator doesn't support this tax region. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SUBDIVISION_FORMAT` | The `subdivision` format is invalid. It must be in ISO 3166-2 format. |
    | `400` | `INVALID_ARGUMENT` | `SUBDIVISIONS_NOT_SUPPORTED_FOR_COUNTRY` | Subdivisions aren't supported for the specified `country`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Tax region ID.

      **Read-only.**

    </ParamField>

    <ParamField body="taxRegion" type="UpdateTaxRegion" required>

      Tax region info.

      <Expandable title="taxRegion properties">

        <ParamField body="_id" type="string">

          Tax region ID.

          **Read-only.**

        </ParamField>

        <ParamField body="country" type="string">

          2-letter country code in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements) format, for example `US` or `GB`.

          Stored as a code only. No country display name is kept, so you're responsible for translating the code to a human-readable name.

          Constraints: `format COUNTRY`, `minLength 2`.

        </ParamField>

        <ParamField body="subdivision" type="string">

          Subdivision (such as a state, prefecture, or province) in [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) format, without the country prefix. For example, `NY` for New York, `ON` for Ontario, or `BY` for Bavaria.

          Use the ISO 3166-2 code, not a display name. A region stored with a full name such as `Georgia` instead of `GA` won't match at calculation time and silently results in no tax being charged. Stored as a code only, so no subdivision display name is kept.

          Leave empty or set to `*` to create a region that covers the entire country.

          Subdivisions are supported only for the following countries: `AU`, `BR`, `CA`, `FR`, `DE`, `IN`, `IT`, `MX`, `NL`, `PT`, `ES`, `AE`, `GB`, and `US`. For any other country, create the region at the country level.

          Constraints: `maxLength 50`.

        </ParamField>

        <ParamField body="appId" type="string">

          The app ID of the tax calculator to use for this region.

          Always resolve this value by calling [List Tax Calculators](https://dev.wix.com/docs/rest/business-solutions/e-commerce/tax/tax-calculation/list-tax-calculators); never hardcode it. Calculator app IDs are installation-scoped and can differ between sites. To use Avalara, pass the app ID whose calculator display name contains `Avalara`.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="taxIncludedInPrice" type="boolean">

          Whether tax is included in the price.

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the tax region is updated.
          To prevent conflicting changes, the current revision must be passed when updating the tax region.

          Ignored when creating a tax region.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the tax region was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the tax region was last updated.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>
