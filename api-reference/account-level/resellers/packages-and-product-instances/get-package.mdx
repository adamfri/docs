    Retrieves a package.

    You must pass the ID of the Wix account that the package belongs to in the
    header of the call. The call fails, if the package and Wix account don't
    match.

    <Note>

    This call requires an account level API key and cannot be
    authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="premium.reseller-package.read">premium.reseller-package.read</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/resellers/v1/packages/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Package ID.

    </ParamField>

    ## Response Object

    <ResponseField name="package" type="Package">

      Retrieved package.

      See the [Packages Object](/api-reference/account-level/resellers/packages-and-product-instances/packages-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
