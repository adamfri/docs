    Updates a note.

    This method supports partial updates.
    To prevent conflicting changes, the current revision must be passed when updating the note.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-NOTES">Manage Notes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/crm/notes/v2/notes/{note.id}
    ```

    ## Path Params

    <ParamField path="note.id" type="string" required>

      Note ID.

    </ParamField>

    ## Body Params

    <ParamField body="note" type="Note" required>

      Note to update.

      See the [Note Object](/api-reference/crm/members-contacts/contacts/notes/notes-v2/note-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="note" type="Note">

      Updated note.

      See the [Note Object](/api-reference/crm/members-contacts/contacts/notes/notes-v2/note-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Note ID.

      **Read-only.**

    </ParamField>

    <ParamField body="note" type="UpdateNote" required>

      Note to update.

      <Expandable title="note properties">

        <ParamField body="_id" type="string">

          Note ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the note is updated.
          To prevent conflicting changes, the current revision must be passed when updating the note.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the note was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the note was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="contactId" type="string">

          Contact ID associated with the note.

        </ParamField>

        <ParamField body="text" type="string">

          Note text.

        </ParamField>

        <ParamField body="type" type="string">

          Note type for organizing notes by their purpose.

          Default: `NOT_SET`

          **Supported values:**

          - `UNKNOWN_TYPE` — Unknown note type.
          - `NOT_SET` — Note doesn't have a specific classification.
          - `MEETING_SUMMARY` — Note is a summary of a meeting related to the contact.
          - `CALL_SUMMARY` — Note is a summary of a call related to the contact.

        </ParamField>

        <ParamField body="source" type="NoteSource">

          Information about who created the note.

          **Read-only.**

          <Expandable title="source properties">

            <ParamField body="sourceType" type="string">

              Note creator.

              **Read-only.**

              **Supported values:**

              - `UNKNOWN_SOURCE_TYPE`
              - `APP`
              - `USER`

            </ParamField>

            <ParamField body="appId" type="string">

              App ID, if the note was created by an app.

              **Read-only.**

            </ParamField>

            <ParamField body="userId" type="string">

              User ID, if the note was created by a Wix user.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
