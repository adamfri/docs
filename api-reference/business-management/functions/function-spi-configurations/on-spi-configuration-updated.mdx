Triggered when a service plugin configuration is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.functions.v1.spi_configuration_updated` |
| Package | `@wix/functions` |
| Permissions | `Manage Stores`, `Manage Functions`, `Manage Restaurants - all permissions`, `Set Up Automations` |
