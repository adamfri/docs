    Unassigns a role from group members.

    You can only unassign `ADMIN` roles. Calling this method with group members
    with `role.value` set to `MEMBER` returns an error.

    <Note>

    + Only group admins can assign roles.
    + You cannot remove members with this method.

    </Note>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-groups-proxy/roles/v2/groups/{groupId}/roles/unassign
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Body Params

    <ParamField body="memberIds" type="string[]">

      Member IDs. Limited to 100 member IDs. See the Members API for details.

      Constraints: `format GUID`, `minItems 0`, `maxItems 100`.

    </ParamField>

    <ParamField body="role" type="GroupRole">

      Role to unassign.

      See the [Group Role Object](/api-reference/crm/community/groups/member-management/roles/group-role-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="groupId" type="string">

      Group ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="siteMemberIds" type="string[]" deprecated>

      Member IDs. Limited to 100 member IDs. See the Members API for details.

      **Deprecated.** Constraints: `format GUID`, `maxItems 100`.

    </ResponseField>

    <ResponseField name="memberIds" type="string[]">

      Member IDs. Limited to 100 member IDs. See the Members API for details.

      Constraints: `format GUID`, `maxItems 100`.

    </ResponseField>

    <ResponseField name="role" type="GroupRole">

      Unassigned role.

      See the [Group Role Object](/api-reference/crm/community/groups/member-management/roles/group-role-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Role Unassigned From Group Member | `wix.social_groups.v2.group_role_unassigned` | Triggered when a role is unassigned from a group member. |
