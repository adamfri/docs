    Bulk installs apps on a tenant, specifying the details of the app instances to create.

    The IDs of these app instances are automatically generated and included in the `appInstance` objects in the response.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEV_CENTER.INSTALL-APPS">The app will be able to manage application installations on this site.</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps-installer-service/v1/bulk/app-instance/install
    ```

    ## Body Params

    <ParamField body="tenant" type="Tenant" required>

      Tenant details.

      <Expandable title="tenant properties">

        <ParamField body="id" type="string" required>

          Tenant ID. For a site, this is the [site ID](https://dev.wix.com/docs/rest/account-level/sites/sites/introduction). For an account this is the [account ID](https://dev.wix.com/docs/rest/account-level/user-management/accounts/accounts/about-accounts).

        </ParamField>

        <ParamField body="tenantType" type="string">

          Tenant type. This can be a Wix site or account.

          **Supported values:**

          - `SITE`
          - `ACCOUNT`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="appInstances" type="AppInstance[]">

      Details of the app instances to create when the apps are installed.

      Constraints: `maxItems 20`.

      See the [App Instance Object](/api-reference/business-management/app-installation/app-installation/app-instance-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkInstallAppResult[]">

      Information and metadata about the app installations.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Metadata about the app installation.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="appInstance" type="AppInstance">

          Details of the created app instance.

          See the [App Instance Object](/api-reference/business-management/app-installation/app-installation/app-instance-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata about the bulk installation.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>
