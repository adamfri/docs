    Asynchronously update tags on multiple consent configs by the provided filter.
    An empty filter will update all consent configs.
    A tag that appears both in the list of `assignTags` and `unassignTags` will be assigned.

    Call Get Async Job ([SDK](https://dev.wix.com/docs/sdk/backend-modules/async-jobs/get-async-job) | [REST](https://dev.wix.com/docs/rest/business-management/async-job/get-async-job)) and specify the returned job ID to retrieve the job's status and counters.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CONSENT_CONFIG.MANAGE">Consent config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bu/legal/v1/bulk/consent-configs/update-tags-by-filter
    ```

    ## Examples

    Asynchronously update tags on multiple consent configs by the provided filter

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/consent/consent-config/v1/bulk/consent-configs/update-tags-by-filter' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        --data-binary '{
          "filter": {
            "consentCategory": "analytics"
          },
          "assignTags": {
            "tags": ["my-app-tag", "my-other-app-tab"]
          },
          "unassignTags": {
            "tags": ["old-tag"]
          }
        }'
      ```
