Triggered when a form is updated or published.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.events.events.EventUpdated` |
| Package | `@wix/events` |
| Permissions | `Manage Stores`, `Read Events - all read permissions`, `Manage Bookings Services and Settings`, `Manage Events - all permissions`, `Manage Events`, `Read Events`, `Manage Challenges`, `Manage Portfolio`, `Manage Blog`, `Access Verticals by Automations`, `Manage Restaurants - all permissions`, `Set Up Automations`, `Manage Guest List` |
