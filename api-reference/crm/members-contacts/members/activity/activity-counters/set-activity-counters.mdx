<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Sets activity counters for a requested site member.

    If the counter does not already exist, it will be created.

    Counters are identified with a custom key, which must be unique.

    <Note>

    Make sure to pass a `memberId` and not a `contactId` to identify the member. Any relationship between a member's `memberId` and `contactId` is coincidental.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-ACTIVITY-COUNTERS">Manage Activity Counters</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/members/v1/activity-counters/{memberId}
    ```

    ## Path Params

    <ParamField path="memberId" type="string" required>

      Member ID whose counter will be set.

    </ParamField>

    ## Body Params

    <ParamField body="counter" type="Counter" required>

      Counter data for this site member.

      <Expandable title="counter properties">

        <ParamField body="key" type="string">

          Counter key, unique within the given app.

        </ParamField>

        <ParamField body="public" type="boolean">

          Whether this counter data is available to all. If `false`, the counter is only available to the data owner and counter owner.

        </ParamField>

        <ParamField body="count" type="integer">

          Activity count.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="activityCounter" type="ActivityCounter">

      Updated activity counter.

      See the [Activity Counter Object](/api-reference/crm/members-contacts/members/activity/activity-counters/activity-counter-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Activity Counter Updated | `wix.members.v1.activity_counter_updated` | Triggered when a member's activity counter is updated. |

    </div>
