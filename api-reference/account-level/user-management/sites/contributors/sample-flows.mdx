## Manage contributor access to specific locations

For multi-location businesses, you can use [Change Contributor Location](fallback::https://dev.wix.com/docs/api-reference/account-level/user-management/contributors/change-contributor-location) to restrict a contributor's access to specific physical locations, rather than granting access to the entire business. 
Learn more about managing business locations with the [Locations API](fallback::https://dev.wix.com/docs/api-reference/business-management/locations/introduction).

1. Call [Query Site Contributors](fallback::https://dev.wix.com/docs/api-reference/account-level/user-management/contributors/query-site-contributors) to retrieve a list of contributors and their current location assignments.
2. Call [Change Contributor Location](fallback::https://dev.wix.com/docs/api-reference/account-level/user-management/contributors/change-contributor-location) with the contributor's account ID and the new list of location IDs to assign.
3. Call [Remove Contributor](fallback::https://dev.wix.com/docs/api-reference/account-level/user-management/contributors/remove-contributor) to remove a contibutor from a site.
