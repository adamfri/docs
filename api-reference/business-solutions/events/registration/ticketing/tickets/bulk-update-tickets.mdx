    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates the `archived` state of multiple tickets.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/tickets
    ```

    ## Body Params

    <ParamField body="eventId" type="string">

      Event ID to which the tickets belong.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="ticketNumber" type="string[]">

      Unique ticket numbers.

      Constraints: `minLength 1`, `maxLength 36`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="archived" type="boolean">

      Whether tickets are archived.

    </ParamField>

    ## Response Object

    <ResponseField name="tickets" type="Ticket[]">

      Updated tickets.

      See the [Ticket Object](/api-reference/business-solutions/events/registration/ticketing/tickets/ticket-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Updated | `wix.events.ticketing.events.OrderUpdated` |  |

    </div>
