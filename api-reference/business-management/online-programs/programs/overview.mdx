A program is an Online Programs course, challenge, or structured journey.
Programs contain lifecycle state, public description, timeline, access rules,
pricing, SEO, rewards, and summary information for their content.

## SDK package

```bash
npm install @wix/online-programs
```

Import the `programs` namespace from `@wix/online-programs`.
