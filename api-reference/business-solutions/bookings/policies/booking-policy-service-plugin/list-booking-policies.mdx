    Retrieves booking policies for the specified services.

    Wix calls this method when a customer views available booking times or books a service. For example:
    - When a customer loads the Bookings calendar to select a time slot, [List Availability Time Slots](https://dev.wix.com/docs/api-reference/business-solutions/bookings/time-slots/time-slots-v2/list-availability-time-slots) calls this method.
    - When a customer books a service, [Get Availability Time Slot](https://dev.wix.com/docs/api-reference/business-solutions/bookings/time-slots/time-slots-v2/get-availability-time-slot) calls this method.

    Wix uses the returned policies to calculate the `bookingPolicyViolations` property, considering:
    - Limits on how early or late a customer can book.
    - Whether online bookings are allowed.

    Your implementation must return a policy for each service in the request, in the same order.
    All fields in the response must be returned unless explicitly marked as optional.

    ## Endpoint

    ```http
    POST /v2/list-booking-policies
    ```

    ## Body Params

    <ParamField body="serviceIds" type="string[]" required>

      IDs of services to retrieve booking policies for.

      Constraints: `format GUID`, `minItems 1`, `maxItems 8`.

    </ParamField>

    ## Response Object

    <ResponseField name="bookingPolicies" type="BookingPolicy[]">

      Booking policies for the requested services.

      <Expandable title="bookingPolicies properties">

        <ResponseField name="serviceId" type="string">

          Service ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="limitEarlyBooking" type="LimitEarlyBooking">

          Policy for limiting early bookings.

          <Expandable title="limitEarlyBooking properties">

            <ResponseField name="enabled" type="boolean">

              Whether there's a limit on how early a customer can book. If `false`, customers can book as far in advance as they want.

              Default: `false`

            </ResponseField>

            <ResponseField name="earliestBookingInMinutes" type="integer">

              Maximum number of minutes before the slot start time that a booking can be made. Must be greater than `latestBookingInMinutes`.

              Default: `10080` (7 days)

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="limitLateBooking" type="LimitLateBooking">

          Policy for limiting late bookings.

          <Expandable title="limitLateBooking properties">

            <ResponseField name="enabled" type="boolean">

              Whether there's a limit on how late a customer can book. If `false`, customers can book up to the last minute.

              Default: `false`

            </ResponseField>

            <ResponseField name="latestBookingInMinutes" type="integer">

              Minimum number of minutes before the slot start time that a booking can be made. Must be less than `earliestBookingInMinutes`.

              Default: `1440` (1 day)

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="onlineBooking" type="OnlineBooking">

          Policy for allowing online bookings.

          <Expandable title="onlineBooking properties">

            <ResponseField name="enabled" type="boolean">

              Whether the service can be booked online.

              Default: `true`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="intakeFormPolicy" type="IntakeFormPolicy">

          Rules for Intake Form integration

          <Expandable title="intakeFormPolicy properties">

            <ResponseField name="formId" type="string">

              ID of the form used as an intake form for the service.

            </ResponseField>

            <ResponseField name="requireBeforeBook" type="boolean">

              Whether the intake form must be completed before booking. If `false`, the form is handled after booking.

              Default: `false`

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
