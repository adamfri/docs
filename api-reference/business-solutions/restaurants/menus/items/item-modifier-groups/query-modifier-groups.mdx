    Retrieves a list of modifier groups given the provided paging, filtering, and sorting. Up to 500 modifier groups can be returned per request.

    To learn how to query modifier groups, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$nin` | None |
    | `createdDate` | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte` | None |
    | `updatedDate` | `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte` | None |
    | `modifiers.id` | `$in`, `$nin`, `$hasSome` | None |
    | `modifiers.preSelected` | `$eq`, `$ne` | None |
    | `rule.minSelections` | `$eq`, `$ne` | None |
    | `rule.maxSelections` | `$eq`, `$ne` | None |
    | `modifiers` | `$exists` | None |
    | `rule.required` | `$eq`, `$ne`, `$in`, `$nin` | None |
    | `rule` | `$exists` | None |
    | `name` | `$startsWith`, `$eq`, `$ne`, `$in`, `$nin` | None |
