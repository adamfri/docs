<Note>This article applies to the REST API only.</Note>

The event's guest attendance status updates based on the values of:

- For RSVP events: The status of a guest as defined in the [RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp-v2/rsvp-object) object.
- For ticketed events: The status of a buyer or ticket holder as defined in the [Order](fallback::https://dev.wix.com/docs/rest/business-solutions/events/orders/order-object) object.

This table below maps out how the `attendanceStatus` field is set based on the `status` field by guest type:

Guest type  |  Status | Attendance Status |
| ---------- | ------- | -------------------|
| RSVP  | YES  | ATTENDING  |
| RSVP | WAITING  | IN_WAITLIST  |
| RSVP  | NO  | NOT_ATTENDING |
| BUYER  | PAID  | ATTENDING |
| BUYER | OFFLINE_PENDING  | ATTENDING |
| BUYER | FREE| ATTENDING |
| BUYER | PENDING | NOT_ATTENDING |
| TICKET_HOLDER | PAID | ATTENDING |
| TICKET_HOLDER | OFFLINE_PENDING | ATTENDING |
| TICKET_HOLDER | FREE| ATTENDING |
| TICKET_HOLDER | PENDING | NOT_ATTENDING |
