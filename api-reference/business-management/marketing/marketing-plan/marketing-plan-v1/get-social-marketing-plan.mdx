    Retrieves the marketing plan's current status and its activities for the requested timeframe.

    Use this method to poll for completion after calling any of the generate or regenerate methods.
    When no `timeframe` is provided, the default start is today and there is no upper bound:
    all of the plan's activities from today onward are returned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan
    ```

    ## Response Object

    <ResponseField name="status" type="string">

      Current status of the marketing plan.

      **Supported values:**

      - `NEVER_CREATED` — No plan has been generated for this site yet.
      - `GENERATING` — The plan is currently being generated. Poll `GetSocialMarketingPlan` until status changes.
      - `ACTIVE` — The plan is ready to use and activities are available.
      - `INACTIVE` — The plan was automatically deactivated after a long period without engagement. An `INACTIVE` plan returns no activities. Calling `GetSocialMarketingPlan` after a long idle period can itself trigger this transition. Generating or regenerating reactivates the plan.
      - `FAILED` — Generation failed. Call a generate or regenerate method to try again.

    </ResponseField>

    <ResponseField name="marketingActivities" type="SocialPlanMarketingActivity[]">

      Marketing activities within the requested timeframe.

      Constraints: `minItems 0`, `maxItems 100`.

      <Expandable title="marketingActivities properties">

        <ResponseField name="marketingActivityId" type="string">

          Marketing activity ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="date" type="datetime">

          Scheduled date of the marketing activity.

        </ResponseField>

        <ResponseField name="items" type="Item[]">

          Posts associated with this activity. Items can be of any status (`DRAFT`, `SCHEDULED`, or published).
          Only items whose `status` is `DRAFT` can be scheduled with `ScheduleDrafts`.

          Constraints: `minItems 0`, `maxItems 10`.

          <Expandable title="items properties">

            <ResponseField name="id" type="string">

              Item ID.

              **Read-only.**

            </ResponseField>

            <ResponseField name="channel" type="Channel">

              Social channel the item is published to, and the account within that channel.

              _Nested structure omitted for brevity — see the `Channel` object._

            </ResponseField>

            <ResponseField name="type" type="string">

              Item format. The `type` and the content set in `data` must match a combination supported by the item's `channel.name`:

              - Instagram: `POST` with `instagramPost`, or `STORY` with `instagramStory`.
              - Facebook: `POST` with `facebookPost`, `REEL` with `facebookReel`, or `STORY` with `facebookStory`.
              - YouTube: `VIDEO` with `youtubeVideo`, or `SHORT` with `youtubeShort`.
              - LinkedIn: `POST` with `linkedinPost`.
              - X (Twitter): `POST` with `twitterPost`. Deprecated: No longer functional as of July 31, 2026.
              - Pinterest: `POST` with `pinterestPost`.
              - Google Business Profile: `POST` with `gbpPost`.
              - TikTok: `POST` with `tiktokPhoto`, or `VIDEO` with `tiktokVideo`.

              **Supported values:**

              - `POST` — A standard post.
              - `REEL` — A short-form vertical video reel.
              - `VIDEO` — A video.
              - `SHORT` — A short-form vertical video.
              - `STORY` — A story that's available for a limited time.

            </ResponseField>

            <ResponseField name="status" type="string">

              Current status of the item in its lifecycle.

              **Read-only.**

              **Supported values:**

              - `PUBLISHED` — Published to the social channel.
              - `SCHEDULED` — Scheduled to be published at a future date.
              - `CANCELED` — Scheduling was canceled before the item was published.
              - `FAILED` — Publishing failed.
              - `DELETED` — Deleted.
              - `PROCESSING` — Publishing is in progress.
              - `DRAFT` — Saved as a draft, not yet published.
              - `IN_QUEUE` — Queued for publishing as part of a bulk operation.

            </ResponseField>

            <ResponseField name="publishedDate" type="datetime">

              Date and time the item was published. Returned only after the item is published.

              **Read-only.**

            </ResponseField>

            <ResponseField name="schedulingInfo" type="SchedulingInfo">

              Scheduling info. Set to schedule the item for a future date instead of publishing it immediately.

              _Nested structure omitted for brevity — see the `SchedulingInfo` object._

            </ResponseField>

            <ResponseField name="referenceId" type="string">

              Caller-defined reference that uniquely identifies the item. Can be used to prevent duplicate publishing: an attempt to publish a second item with the same `referenceId` fails. Can also be used as a UTM campaign ID.

            </ResponseField>

              Aggregated analytics for the site, attributed to traffic from this post.

              _Nested structure omitted for brevity — see the `SiteAnalytics` object._

            </ResponseField>

            <ResponseField name="insightsSummary" type="InsightsSummary">

              Summary of the post's performance on the social channel, such as impressions and interactions.

              _Nested structure omitted for brevity — see the `InsightsSummary` object._

            </ResponseField>

            <ResponseField name="draftInfo" type="DraftInfo">

              Creation and update dates, returned for draft items.

              _Nested structure omitted for brevity — see the `DraftInfo` object._

            </ResponseField>

            <ResponseField name="suggested" type="boolean">

              Whether the item was generated as an AI suggestion.

            </ResponseField>

            <ResponseField name="external" type="boolean">

              Whether the item is a post created natively on the social channel rather than published through Wix.

            </ResponseField>

            <ResponseField name="publicationError" type="PublicationErrorDetails">

              Details of why the item failed to publish. Returned only when `status` is `FAILED`.

              **Read-only.**

              _Nested structure omitted for brevity — see the `PublicationErrorDetails` object._

            </ResponseField>

            <ResponseField name="siteAssetRef" type="AssetReference">

              Reference to the site content asset this post promotes (product, blog post, etc.).
              Mirrors marketing-plan-service's MarketingActivity.asset (named `asset` there;
              `site_asset_ref` here for clarity next to consumer_info). Written per-channel.

              _Nested structure omitted for brevity — see the `AssetReference` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="title" type="string">

          Title of the marketing activity.

        </ResponseField>

          Description of the marketing activity.

        <ResponseField name="videoCandidates" type="VideoCandidate[]">

          Asynchronously generated video options for this activity. Poll `GetMarketingActivityPosts` to check their status.

          Constraints: `minItems 0`, `maxItems 10`.

          <Expandable title="videoCandidates properties">

              Unique identifier of the video generation process.

              **Read-only.**

            </ResponseField>

            <ResponseField name="status" type="string">

              Current generation status of the video candidate.

              **Supported values:**

              - `IN_PROGRESS` — Video is currently being generated.
              - `FAILED` — Generation failed. Add a new candidate to retry.
              - `READY` — Video is ready. `video_url` is populated.

            </ResponseField>

            <ResponseField name="videoUrl" type="string">

              URL of the generated video. Returned only when `status` is `READY`.

            </ResponseField>

            <ResponseField name="prompt" type="string">

              Prompt used to generate the video.

            </ResponseField>

            <ResponseField name="sourceMediaUrl" type="string">

              URL of the source media used as input for video generation.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="asset" type="AssetReference">

          Site asset this activity is grounded in.

          <Expandable title="asset properties">

            <ResponseField name="type" type="string">

              Type of the site asset (for example, product or blog post). See `SiteAsset.Type` for the closed set of values.

              **Supported values:**

              - `BLOG_POST` — A Wix Blog post.
              - `EVENT` — A Wix Events event.
              - `STORES_PRODUCT` — A Wix Stores product.
              - `BOOKINGS_SERVICE` — A Wix Bookings service.
              - `STORES_COUPON` — A Wix Stores coupon.
              - `STORES_CATEGORY` — A Wix Stores category.

            </ResponseField>

            <ResponseField name="id" type="string">

              ID of the asset within its provider's data store.

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name of the asset (for example, the product title or blog post title), cached at activity-generation time.

              Constraints: `maxLength 3000`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
