    Retrieves the verified, published profile of a partner by their URL slug.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/profile/v1/partner-profiles/slug/{slug}/public
    ```

    ## Path Params

    <ParamField path="slug" type="string" required>

      URL slug of the partner profile.

    </ParamField>

    ## Response Object

            </ResponseField>

            <ResponseField name="link" type="string">

              URL for booking a meeting with the partner.

            </ResponseField>

          </Expandable>

        </ResponseField>
