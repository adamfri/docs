The Menus API allows you to create and manage restaurant menus, and configure which menus are visible on Wix sites.

Menus are divided by [sections](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/menus/sections/introduction), such as "Appetizers", "Mains", "Desserts", "Drinks", and so on. Sections contains [items](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item/introduction) with their [labels](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-label/introduction) and [price variants](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-variant/introduction). Additionally, you can upgrade your menu by adding [item modifier groups](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-modifiers/introduction), such as "Extra Toppings" or "Sides". Each of these sub-entities is created and managed separately, using their own API.

This API is specifically used for creating and managing Menu entities.

For more information about the broader Menus API, including the different entities, their relationships, and overall menu management, see [About the Menus API](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/menus/introduction).

With the Menus API, you can:

- Create, delete, and update menus.
- Retrieve information about menus.
- Configure which menus are visible on Wix sites.

## Before you begin

It's important to note the following point before starting to code:

- The Menus API only works with the Wix Restaurants Menus app. Make sure you have installed this app from the [Wix App Market](fallback::https://www.wix.com/app-market/wix-restaurants-menus-new).
