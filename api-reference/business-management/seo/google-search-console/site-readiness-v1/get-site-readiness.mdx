    Retrieves the site's readiness in Google Search Console.

    Returns whether the site's Google connection and ownership verification
    are in place, and if not, the first blocking step. Use this to decide what
    to resolve next — for example, a `SITE_OWNER_NOT_VERIFIED` blocking reason
    means the site's ownership isn't proven to Google yet, so call Verify
    Site.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gsc/v1/site-readiness
    ```

    ## Response Object

    <ResponseField name="siteReadiness" type="SiteReadiness">

      The site's current Google Search Console readiness.

      See the [Site Readiness Object](/api-reference/business-management/seo/google-search-console/site-readiness-v1/site-readiness-object) for this object's fields.

    </ResponseField>
