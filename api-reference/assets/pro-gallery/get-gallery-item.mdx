Gets a gallery item by ID.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PROGALLERY.READ-GALLERIES">Read Galleries</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`, `MEMBER`, `VISITOR`.

## Endpoint

```http
GET https://www.wixapis.com/pro-gallery/v2/galleries/{galleryId}/items/{itemId}
```

## Path Params

<ParamField path="galleryId" type="string" required>

  Gallery ID.

</ParamField>

<ParamField path="itemId" type="string" required>

  Item ID.

</ParamField>

## Response Object

<ResponseField name="item" type="Item">

  Returned media item.

  <Expandable title="item properties">

    <ResponseField name="id" type="string">

      Item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="sortOrder" type="number">

      Index that determines which position a media item is displayed in the gallery. &lt;br />

      Default: [Epoch](https://www.epoch101.com/) timestamp. &lt;br />

      >**Note:** If you assign the same sort order index to more than one media item in a gallery, the function fails.

    </ResponseField>

    <ResponseField name="title" type="string">

      Item title.

    </ResponseField>

    <ResponseField name="description" type="string">

      Item description.

    </ResponseField>

    <ResponseField name="link" type="Link">

      Link from the item. You can link to Wix sites or external URLs.

      <Expandable title="link properties">

        <ResponseField name="text" type="string">

          Display text of the link.

        </ResponseField>

        <ResponseField name="url" type="string">

          Target URL of the link.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="type" type="string">

      Type of item.

      **Read-only.**

      **Supported values:**

      - `UNDEFINED`
      - `IMAGE`
      - `VIDEO`
      - `TEXT`

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the item was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Item tags.

      <Expandable title="tags properties">

        <ResponseField name="values" type="string[]">

          List of tags assigned to the media item.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Expandable>

  <Expandable title="One of the following">

    <ResponseField name="metadata" type="metadata">

      metadata

      <Expandable title="metadata properties">

        <ResponseField name="image" type="Image">

          Details about the image.

          _Nested structure omitted for brevity — see the `Image` object._

        </ResponseField>

        <ResponseField name="video" type="Video">

          Details about the video.

          _Nested structure omitted for brevity — see the `Video` object._

        </ResponseField>

        <ResponseField name="text" type="Text">

          Details about the text file.

          _Nested structure omitted for brevity — see the `Text` object._

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Expandable>

</ResponseField>
