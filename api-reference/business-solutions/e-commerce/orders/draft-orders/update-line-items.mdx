    Updates a draft order's line items.

    You can update a line item's quantity, price, and description.
    <Note>

    + Specifying a quantity of `0` will remove the line item.
    + Price cannot be updated for line items with `paymentOption: MEMBERSHIP`.
    + Quantity cannot be decreased for fulfilled line items. To retrieve fulfillment information, specify the order ID when calling [List Fulfillments For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-fulfillments/list-fulfillments-for-single-order).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}/line-items
    ```

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DRAFT_ORDER_DOES_NOT_EXIST` | Couldn't find the draft order. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEM_DOES_NOT_EXIST` | Couldn't find the line item. |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_CHANGES_FOR_SAME_LINE_ITEM` | Request contains multiple changes for the same line item. |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_CHANGE_REQUEST` | Request doesn't contain any changes. |
    | `428` | `FAILED_PRECONDITION` | `UPDATING_PRICE_OF_REMOVED_ITEM_IS_FORBIDDEN` | Can't update the price of a line item that was already removed. |
    | `400` | `INVALID_ARGUMENT` | `UPDATING_LINE_ITEM_WITH_LOCATIONS` | Can't update line items with multiple locations. Only price changes and removals (set quantity to 0) are supported for multi-location line items. |
    | `428` | `FAILED_PRECONDITION` | `DRAFT_ORDER_ALREADY_COMMITTED` | Draft order was already committed. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_UPDATE_CATALOG_REFERENCE_OPTIONS_OF_NON_CATALOG_ITEM` | Can't update catalog reference options for a non-catalog line item. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_CATALOG_REFERENCE_OPTIONS_OF_FULFILLED_ITEM` | Can't update catalog reference options for a fulfilled or partially fulfilled line item. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_ITEM_WITH_EXTERNAL_FULFILLER` | Can't update an item that is being fulfilled by an external fulfillment service. These items can be identified when the `draftOrder.lineItems.lineItem.fulfillerId` field has value. |
    | `400` | `INVALID_ARGUMENT` | `MODIFIERS_SUM_CANNOT_EXCEED_ITEM_PRICE` | Sum of new modifiers exceeds new item price. |
    | `428` | `FAILED_PRECONDITION` | `LINE_ITEM_HAS_PLATFORM_FEES` | Can't update the price or quantity of a line item with platform fee. |
    | `428` | `FAILED_PRECONDITION` | `SUBSCRIPTION_SINGLE_ITEM_ALLOWED` | Converting a draft to a subscription order is supported only with exactly one line item. |
    | `428` | `FAILED_PRECONDITION` | `UPDATING_TAXABLE_ADDRESS_ON_EXISTING_ITEM_IS_FORBIDDEN` | Can't update the taxable address of a line item that already exists on the order. When editing an existing order, the taxable address can only be set for newly added line items. |
