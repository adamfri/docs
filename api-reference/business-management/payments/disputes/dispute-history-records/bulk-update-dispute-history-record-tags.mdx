    <div className="wix-ref">

    Updates tags on multiple dispute history records simultaneously using a list of dispute history record IDs.
    If a tag appears in both assign and unassign lists, it will be assigned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/dispute-history-records/v1/bulk/dispute-history-records/update-tags
    ```
