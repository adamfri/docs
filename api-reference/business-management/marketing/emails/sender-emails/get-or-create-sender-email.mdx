    Retrieve the sender email info by the email address, or creates a new one.

    If you try to create an email with a name that already exists, this method won't return an error. Instead, the info of the existing sender email will be returned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.ACCESS-VERTICALS-BY-AUTOMATIONS">Access Verticals by Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/sender-emails/v1/sender-emails/get-or-create
    ```

    ## Body Params

    <ParamField body="emailAddress" type="string" required>

      Requested sender email.

      Constraints: `format EMAIL`, `minLength 6`, `maxLength 254`.

    </ParamField>

    ## Response Object

    <ResponseField name="senderEmail" type="SenderEmail">

      The requested sender email.

      See the [Sender Email Object](/api-reference/business-management/marketing/emails/sender-emails/sender-email-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Sender Email Created | `wix.promote.v1.sender_email_created` | Triggered when a sender email is created. |

    </div>
