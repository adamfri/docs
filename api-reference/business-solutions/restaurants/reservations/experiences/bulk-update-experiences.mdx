    <div className="wix-ref">

    Updates up to 100 experiences in a single request.

    Each experience is updated independently. If an update fails for one experience, the failure is reported in that experience's `itemMetadata.error` and the remaining experiences are still processed. The call returns successfully even when some updates fail.

    Set `returnEntity` to `true` to receive the updated experiences in the response.

    Archived experiences can't be updated.

    To update a single experience, call [Update Experience](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/reservations/experiences/update-experience).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/experiences/v1/bulk/experiences/update
    ```

    ## Body Params

    <ParamField body="experiences" type="MaskedExperience[]" required>

      List of experiences to update, with the fields to update for each experience.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="experiences properties">

        <ParamField body="experience" type="Experience">

          Experience to update. May be partial.

          See the [Experience Object](/api-reference/business-solutions/restaurants/reservations/experiences/experience-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to include the updated experiences in the response. When `true`, each successfully updated experience is returned in the corresponding result's `item` field.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkUpdateExperiencesResult[]">

      List of results, one per experience in the request. Each result contains the update status for the corresponding experience, in the same order as the request.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Update status for an individual experience, including success or failure information and error details when the update failed.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Provided only whenever possible. For example, `itemId` can't be provided when item creation has failed.

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

              Constraints: `min 0`.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action for this item was successful. When `false`, the `error` field is returned.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Experience">

          Updated experience.

          Returned only when `returnEntity` is `true` in the request and the update succeeded.

          See the [Experience Object](/api-reference/business-solutions/restaurants/reservations/experiences/experience-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata for the bulk update, including the total number of successful and failed updates.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

          Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

          Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

          Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>
