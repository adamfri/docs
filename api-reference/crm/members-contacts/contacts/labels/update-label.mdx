    <div className="wix-ref">

    Renames a label.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-LABELS">Manage Contact Labels</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/contacts/v4/labels/{label.key}
    ```

    ## Path Params

    <ParamField path="label.key" type="string" required>

      Label key.

      `key` is generated when the label is created.
      It can't be modified, even if `displayName` is updated.

    </ParamField>

    ## Body Params

    <ParamField body="label" type="ContactLabel">

      Label to rename.

      See the [Label Object](/api-reference/crm/members-contacts/contacts/labels/label-object) for this object's fields.

    </ParamField>

    <ParamField body="language" type="string">

      Language for localization.
      2-letter language code in [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) format.

    </ParamField>

    ## Response Object

    <ResponseField name="label" type="ContactLabel">

      Renamed label.

      See the [Label Object](/api-reference/crm/members-contacts/contacts/labels/label-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Contact Label Updated | `wix.contacts.v4.label_updated` | Triggered when a label is updated. |

    </div>

    ## Method Parameters

    <ParamField body="key" type="string" required>

      Label key.

      `key` is generated when the label is created.
      It can't be modified, even if `displayName` is updated.

      **Read-only.** Constraints: `minLength 1`, `maxLength 80`.

    </ParamField>

    <ParamField body="label" type="RenameLabel" required>

      Label to rename. 

      <Expandable title="label properties">

        <ParamField body="namespace" type="string">

          Label namespace.

          Labels created by calling the Find Or Create Label method
          are automatically assigned to the `custom` namespace.

          **Read-only.**

        </ParamField>

        <ParamField body="namespaceDisplayName" type="string">

          Display name for the namespace,
          used to organize the list of labels in the site dashboard.

          **Read-only.**

        </ParamField>

        <ParamField body="key" type="string">

          Label key.

          `key` is generated when the label is created.
          It can't be modified, even if `displayName` is updated.

          **Read-only.** Constraints: `minLength 1`, `maxLength 80`.

        </ParamField>

        <ParamField body="displayName" type="string" required>

          Label display name shown in the dashboard.

          Constraints: `minLength 1`, `maxLength 180`.

        </ParamField>

        <ParamField body="labelType" type="string">

          Label type indicating how the label was created.

          **Read-only.**

          **Supported values:**

          - `SYSTEM` — Default system label for the contact list.
          - `USER_DEFINED` — Label created by calling the Find Or Create Label method.
          - `WIX_APP_DEFINED` — Label created by an app built by Wix.

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the label was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the label was last updated.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="options" type="UpdateLabelOptions">

      Language options.

      <Expandable title="options properties">

        <ParamField body="language" type="string">

          Language for localization.
          2-letter language code in [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) format.

        </ParamField>

      </Expandable>

    </ParamField>
