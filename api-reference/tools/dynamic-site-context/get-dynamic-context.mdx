Retrieves aggregated context for the caller's sites and account.

Returns enriched site information including installed apps, editor type,
Velo status, and account details. Results are paginated using cursor-based paging.

You can optionally filter by a single site ID or site display name.
When no filter is provided, all of the caller's sites are returned.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

## Endpoint

```http
POST https://www.wixapis.com/_api/dynamic-context/v1/dynamic-context
```

<ResponseField name="account" type="Account">

    <ResponseField name="id" type="string">

      Unique account identifier.

      Date and time the account was created.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the account was last modified.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      The account holder's display name. This field contains PII.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the account.

      - `DELETED` — The account has been deleted.

    </ResponseField>

  </Expandable>

</ResponseField>

    </ResponseField>

  </Expandable>
