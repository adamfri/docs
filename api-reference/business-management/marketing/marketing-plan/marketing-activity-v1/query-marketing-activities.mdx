    Retrieves marketing activities matching the given filter.

    Supported filter keys: `startDate`, `endDate`, `ids`, and `marketingActivityType`.
    Filtering by `ids` can't be combined with `startDate`, `endDate`, or `marketingActivityType` filters.
    Sorting, paging, and cursor paging in the request are ignored. Results are always sorted by `targetDate`
    ascending and there's no server-side paging.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-activities/query
    ```

    ## Examples

    Query marketing activities by target date range and type. Only the filter keys startDate, endDate, ids, and marketingActivityType are honored; sorting and paging are ignored.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-activities/query' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "query": {
          "filter": {
            "startDate": "2026-07-01T00:00:00.000Z",
            "endDate": "2026-07-31T23:59:59.000Z",
            "marketingActivityType": "SOCIAL_MARKETING"
          }
        }
      }'
      ```
