The Loyalty Accounts API allows you to create and manage loyalty accounts for a site's customers. The loyalty accounts
maintain a customer's balance of loyalty points. 

With the loyalty accounts API, you can:
+ [Create](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/create-account) a new loyalty account.
+ Adjust the balance of a [single loyalty account](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/adjust-points) or [multiple accounts](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/bulk-adjust-points).
+ [Earn points](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/earn-points) to a loyalty account.
+ [Retrieve](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/query-loyalty-accounts) loyalty accounts.
+ Listen for events that trigger when an account is [updated](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/points-updated) or [adjusted](https://dev.wix.com/docs/rest/crm/loyalty-program/accounts/loyalty-account-updated).

## Before you begin
It's important to note the following before starting to code:

+ A site must have an active loyalty program before loyalty accounts can be created. See the Loyalty Program API for more information.
+ To create a new loyalty account, a customer must be a site contact with a contact ID. See the Contacts API for more information.
