    Deletes an add-on group.

    Deleting the group doesn't delete individual add-ons.
    Any add-on not associated with another group isn't available for customers to book.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/add-on-groups/delete
    ```

    ## Body Params

    <ParamField body="addOnGroupId" type="string" required>

      ID of the add-on group to delete.

    </ParamField>

    <ParamField body="serviceId" type="string" required>

      ID of the service from which to delete the add-on group.

    </ParamField>

    ## Response Object

    Returns `DeleteAddOnGroupResponse`.
