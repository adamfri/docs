    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v1/bulk/products/update
    ```

    ## Body Params

    <ParamField body="ids" type="string[]" required>

      Product IDs.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="set" type="SetValue">

      Field to update.

      <Expandable title="One of the following">

        <ParamField body="value" type="value">

          value

          <Expandable title="value properties">

            <ParamField body="price" type="number">

              Set product price.
              If [variant management](https://support.wix.com/en/article/wix-stores-adding-and-customizing-product-options#setting-different-prices-for-variants) is enabled,
              variant prices will be calculated according to the set product price.
              If variant price is negative after setting new price, the update will fail.

              Constraints: `min 0`, `max 999999999.99`.

            </ParamField>

            <ParamField body="cost" type="number">

              Set product cost of goods.
              If [variant management](https://support.wix.com/en/article/wix-stores-adding-and-customizing-product-options#setting-different-prices-for-variants) is enabled,
              cost of goods will be set per variant.

              Constraints: `min 0`, `max 999999999.99`.

            </ParamField>

            <ParamField body="weight" type="number">

              Set product weight.
              If [variant management](https://support.wix.com/en/article/wix-stores-adding-and-customizing-product-options#setting-different-prices-for-variants) is enabled,
              weight will be set per variant.

              Constraints: `min 0`, `max 999999999.99`.

            </ParamField>

            <ParamField body="ribbon" type="string">

              Set product ribbon. Pass empty string to remove existing ribbon.

              Constraints: `maxLength 30`.

            </ParamField>

            <ParamField body="brand" type="string">

              Set product brand. Pass empty string to remove existing brand.

              Constraints: `maxLength 50`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
