    Adds or removes tags on multiple products.

    Specify which tags to assign and which tags to unassign. A tag that appears in both the list to assign and the list to unassign will be assigned. Tags that don't exist are ignored.

    Each product supports up to 100 public tags and 100 private tags, including the tags it already has. If an update exceeds either limit for a product, the update fails for that product, and the remaining products in the request are still updated.

    To update tags on all products matching a filter, call [Bulk Update Product Tags By Filter](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/bulk-update-product-tags-by-filter).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_WRITE">Product write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/products/update-tags
    ```
