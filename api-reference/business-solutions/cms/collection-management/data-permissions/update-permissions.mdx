    Updates permissions for the specified data collection.

    <Note>

    To update special permissions, call [Update Special Permissions](https://dev.wix.com/docs/rest/business-solutions/cms/data-permissions/update-special-permissions).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v1/permissions
    ```

    ## Body Params

    <ParamField body="dataPermissions" type="DataPermissions" required>

      Permissions to update.

      See the [Data Permissions Object](/api-reference/business-solutions/cms/collection-management/data-permissions/data-permissions-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="dataPermissions" type="DataPermissions">

      Updated permissions of the specified collection.

      See the [Data Permissions Object](/api-reference/business-solutions/cms/collection-management/data-permissions/data-permissions-object) for this object's fields.

    </ResponseField>

    | Status | Code | Application code | Description |

    <Note>
