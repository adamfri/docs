    Retrieves a ticket definition.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-TICKET-DEF">Manage Ticket Definitions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v3/ticket-definitions/{ticketDefinitionId}
    ```

    ## Path Params

    <ParamField path="ticketDefinitionId" type="string" required>

      Ticket definition ID.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `SALES_DETAILS` — Returns `salesDetails` in the response.
      - `EVENT_DETAILS` — Returns `eventDetails` in the response.
      - `SEATING_DETAILS` — Returns `seatingDetails` with available seats in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="ticketDefinition" type="TicketDefinition">

      The requested ticket definition.

      See the [Ticket Definition Object](/api-reference/business-solutions/events/event-management/ticket-definitions-v3/ticket-definition-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
