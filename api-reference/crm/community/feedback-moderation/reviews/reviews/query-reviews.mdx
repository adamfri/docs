    Retrieves a list of reviews, given the provided paging, filtering, and sorting.
    100 reviews can be returned per request.

    Query Reviews runs with these defaults, which you can override:

    - `createdDate` is sorted in `ASC` order
    - `paging.limit` is `100`

    To learn about working with _Query_ endpoints, see [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in` | None |
    | `namespace` | `$eq`, `$ne`, `$in` | None |
    | `moderation.moderationStatus` | `$eq`, `$ne`, `$in` | None |
    | `entityId` | `$eq`, `$ne`, `$in` | None |
    | `author.contactId` | `$eq`, `$ne`, `$in` | None |
    | `relevanceScore` | `$eq`, `$ne`, `$in`, `$lt`, `$lte`, `$gt`, `$gte` | Sort: `ASC`, `DESC` |
    | `content.rating` | `$eq`, `$ne`, `$in`, `$lt`, `$lte`, `$gt`, `$gte` | Sort: `ASC`, `DESC` |
    | `helpfulness` | `$eq`, `$ne`, `$in`, `$lt`, `$lte`, `$gt`, `$gte` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$lt`, `$lte`, `$gt`, `$gte` | Sort: `ASC`, `DESC` |
    | `verified` | `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `origin.type` | `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `content.media` | `$isEmpty` | None |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.READ-REVIEWS">Read reviews</span>
    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v1/reviews/query
    ```

    ## Body Params

    <ParamField body="query" type="QueryV2">

      Review query.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object. See [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language) for more information.

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sorting options.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              Default: `ASC`.

              **Supported values:**

              - `ASC` — Sort by ascending order.
              - `DESC` — Sort by descending order.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="cursorPaging" type="CursorPaging">

          Cursor paging options.

          <Expandable title="cursorPaging properties">

            <ParamField body="limit" type="integer">

              The number of items to load.
              Cursor token returned in the query response. To be used on the next query request, but not the first query request.

              Max: `100` &lt;br />
              Default: `50`

            </ParamField>

            <ParamField body="cursor" type="string">

              Cursor returned in last query response. Shouldn't be provided on first page request.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnPrivateReviews" type="boolean">

      Whether to return private (unpublished) reviews.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="metadata" type="PagingMetadataV2">

      Paging metadata.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag isn't set.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next result page.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous result page.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="reviews" type="Review[]">

      List of returned reviews.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ResponseField>
