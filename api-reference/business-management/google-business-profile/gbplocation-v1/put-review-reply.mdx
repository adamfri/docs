    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Creates or replaces the site owner's public reply to a review.

    A review has at most one reply, so calling this again replaces the existing
    text rather than adding a second one. The reply shows publicly on Google
    next to the review, attributed to the business.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/gbp/v1/locations/{locationId}/reviews/{reviewId}/reply
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID. This is Google's location identifier.

    </ParamField>

    <ParamField path="reviewId" type="string" required>

      Google's opaque review ID.

    </ParamField>

    ## Body Params

    <ParamField body="text" type="string" required>

      Reply text to post or replace.

      Constraints: `minLength 1`, `maxLength 4096`.

    </ParamField>

    ## Response Object

    <ResponseField name="reply" type="ReviewReply">

      The created or updated review reply.

      <Expandable title="reply properties">

        <ResponseField name="text" type="string">

          The reply text.

          Constraints: `maxLength 4096`.

        </ResponseField>

        <ResponseField name="updateTime" type="string">

          ISO 8601 timestamp of when the reply was last updated.

          Constraints: `maxLength 64`.

        </ResponseField>

      </Expandable>

    </ResponseField>
