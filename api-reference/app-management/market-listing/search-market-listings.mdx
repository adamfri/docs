    Searches published market listings by keyword or app name.

    Intended for AI agents and automation tools that need to find published app listings before taking action, such as installing an app. Defaults to listings in English (`en`).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/devcenter/app-market-listing/v1/market-listings/search
    ```

    ## Body Params

    <ParamField body="searchTerm" type="string">

      Text to search by app name or keyword.

    </ParamField>

    <ParamField body="paging" type="Paging">

      Paging options. Returns up to 50 results per page.

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField body="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="languageCode" type="string">

      2-letter language code in ISO 639-1 alpha-2 format. Returns listings in this language.

      Default: `en`

    </ParamField>

    ## Response Object

    <ResponseField name="marketListings" type="MarketListing[]">

      Published market listings matching the search.

      Constraints: `maxItems 50`.

      See the [Market Listing Object](/api-reference/app-management/market-listing/market-listing-object) for this object's fields.

    </ResponseField>

    <ResponseField name="paging" type="PagingMetadataV2">

      Paging metadata for the search result set.

      <Expandable title="paging properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
