<Tabs>

  <Tab title="REST">

    <ResponseField name="name" type="string">

      Referral program name.

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the referral program.

      **Read-only.**

      **Supported values:**

      - `DRAFT` — Referral program is in a draft state and is being modified. It is not yet active.
      - `ACTIVE` — Referral program is active.
      - `PAUSED` — Referral program is paused.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the program is updated.
      To prevent conflicting changes, the current `revision` must be passed when updating the program.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the program was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the program was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="referredFriendReward" type="Reward">

      Reward configuration for the referred friend.
      Specifies the reward given to a new customer who was referred to the business.

      <Expandable title="referredFriendReward properties">

        <ResponseField name="type" type="string">

          Type of the reward.

          **Supported values:**

          - `COUPON` — Coupon reward type.
          - `LOYALTY_POINTS` — Loyalty points reward type.
          - `NOTHING` — No reward type.

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="options" type="options">

          options

          <Expandable title="options properties">

            <ResponseField name="couponOptions" type="Coupon">

              Options for coupon reward type.

              <Expandable title="couponOptions properties">

                <ResponseField name="name" type="string">

                  Coupon name.

                  Constraints: `minLength 1`, `maxLength 50`.

                </ResponseField>

                <ResponseField name="discountType" type="string">

                  Coupon discount type.

                  **Supported values:**

                  - `FIXED_AMOUNT` — Discount as a fixed amount.
                  - `PERCENTAGE` — Discount as a percentage.
                  - `FREE_SHIPPING` — Free shipping. If `true`, the coupon applies to all items in all `namespaces`.

                </ResponseField>

                <ResponseField name="limitedToOneItem" type="boolean">

                  Whether the coupon is limited to one item.
                  If `true` and a customer pays for multiple items, the discount applies to only the lowest priced item.
                  Coupons with a bookings `scope.namespace` are always limited to one item.

                </ResponseField>

                <ResponseField name="appliesToSubscriptions" type="boolean">

                  Whether the coupon applies to subscription products.

                </ResponseField>

                <ResponseField name="discountedCycleCount" type="integer">

                  Specifies the amount of discounted cycles for a subscription item.

                  - Can only be set when `scope.namespace = pricingPlans`.
                  - If `discountedCycleCount` is empty, the coupon applies to all available cycles.
                  - `discountedCycleCount` is ignored if `appliesToSubscriptions = true`.

                  Max: `999`

                </ResponseField>

              </Expandable>

              <Expandable title="One of the following">

                <ResponseField name="discountTypeOptions" type="discountTypeOptions">

                  discountTypeOptions

                  _Nested structure omitted for brevity — see the `discountTypeOptions` object._

                </ResponseField>

                <ResponseField name="scopeOrMinSubtotal" type="scopeOrMinSubtotal">

                  scopeOrMinSubtotal

                  _Nested structure omitted for brevity — see the `scopeOrMinSubtotal` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="loyaltyPointsOptions" type="LoyaltyPoints">

              Options for the Loyalty points reward type.

              <Expandable title="loyaltyPointsOptions properties">

                <ResponseField name="amount" type="integer">

                  Number of loyalty points to give.

                  Constraints: `min 1`, `max 9999999`.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="successfulReferralActions" type="string[]">

      List of actions that complete a referral. For an action to be considered successful, the referred friend must place and pay for an item.

      Constraints: `maxItems 100`.

      **Supported values:**

      - `STORE_ORDER_PLACED` — Referred friend ordered and paid for an order in a store.
      - `PLAN_ORDERED` — Referred friend ordered and paid for a plan.
      - `TICKET_ORDERED` — Referred friend ordered and paid for a ticket.
      - `SESSION_BOOKED` — Referred friend booked and paid for a session.
      - `RESTAURANT_ORDER_PLACED` — Referred friend placed and paid for a restaurant order.
      - `ONLINE_PROGRAM_JOINED` — Referred friend joined an online program.

    </ResponseField>

    <ResponseField name="emails" type="Emails">

      Configures email notifications for the referral program.

      <Expandable title="emails properties">

        <ResponseField name="encourageToReferFriends" type="string[]">

          Configures email invitations to encourage customers to refer their friends. Select the apps for which this feature is enabled.

          **Supported values:**

          - `STORES` — Send an email to customers who've placed an order with stores.
          - `PRICING_PLANS` — Send an email to customers who've placed an order with pricing plans.
          - `EVENTS` — Send an email to customers who've placed an order with events.
          - `BOOKINGS` — Send an email to customers who've placed an order with bookings.
          - `RESTAURANTS` — Send an email to customers who've placed an order with restaurants.
          - `ONLINE_PROGRAMS` — Send an email to customers who've joined an online program.

        </ResponseField>

        <ResponseField name="notifyCustomersAboutReward" type="boolean">

          Whether to send email notifications to referring customers when they receive a referral reward.
          If true, referring customers will be notified by email when their referred friend completes a qualifying action (for example, placing an order).

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="premiumFeatures" type="PremiumFeatures">

      Indicates which premium features are available for the current account.

      **Read-only.**

      <Expandable title="premiumFeatures properties">

        <ResponseField name="referralProgram" type="boolean">

          Whether the site owner has access to the referral program feature.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "referralProgram": {
            "name": "Share the love!",
            "status": "ACTIVE",
            "revision": "3",
            "createdDate": "2024-01-01T10:49:25.803Z",
            "updatedDate": "2024-02-08T05:02:38.276Z",
            "referredFriendReward": {
                "type": "LOYALTY_POINTS",
                "loyaltyPointsOptions": {
                    "amount": 1
                }
            },
            "referringCustomerReward": {
                "type": "LOYALTY_POINTS",
                "loyaltyPointsOptions": {
                    "amount": 1
                }
            },
            "successfulReferralActions": [
                "STORE_ORDER_PLACED"
            ],
            "emails": {
                "encourageToReferFriends": [
                    "STORES"
                ],
                "notifyCustomersAboutReward": true
            },
            "premiumFeatures": {
                "referralProgram": true
            }
        }
      }
      ```

    </CodeGroup>
