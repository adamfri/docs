    Creates a translation content item.

    The content is validated based on the constraints defined in the corresponding schema.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.WRITE_TRANSLATION_CONTENT">Wix Multilingual - Write Translation Content</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/translation-content/v1/contents
    ```

    ## Body Params

    <ParamField body="content" type="Content" required>

      Translation content to create.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="content" type="Content">

      Newly created translation content.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Content Created | `wix.multilingual.translation.v1.content_created` | Triggered when translation content is created. |

    </div>
