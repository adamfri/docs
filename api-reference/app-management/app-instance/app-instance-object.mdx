---
title: "App Instance Object"
description: "An app instance is a specific occurrence of an app on a Wix site."
icon: "cube"
---

An app instance is a specific occurrence of an app on a Wix site.
When a Wix user installs an app, a unique instance is generated for that
specific site. Use the `instanceId` to keep track of the individual data
associated with each app instance.

<Tabs>

  <Tab title="REST">

    <ResponseField name="instanceId" type="string">

      App instance ID. Useful to keep track of the
      data that's associated with the specific instance of your app
      installed on a Wix site.

    </ResponseField>

    <ResponseField name="appName" type="string">

      App name, as you entered it in the App Dashboard.

    </ResponseField>

    <ResponseField name="appVersion" type="string">

      Version of your app that's installed on the Wix site.

    </ResponseField>

    <ResponseField name="isFree" type="boolean">

      Whether the Wix user has installed a free or paid version of your app
      on their site.

    </ResponseField>

    <ResponseField name="billing" type="BillingInfo">

      Billing information for the app instance. Available only in case
      `{"isFree": false}`.

      <Expandable title="billing properties">

        <ResponseField name="packageName" type="string">

          Name of the package that the site owner has paid for.

        </ResponseField>

        <ResponseField name="billingCycle" type="string">

          Interval of the billing cycle. `ONE_TIME` indicates that the Wix user has
          made a single upfront payment without any automatic subscription renewal.
          This is primarily for usage credits (for example, 5 SMS) but may occasionally apply
          to a one-time setup for the app.

          **Supported values:**

          - `NO_CYCLE`
          - `MONTHLY`
          - `YEARLY`
          - `ONE_TIME`
          - `TWO_YEARS`
          - `THREE_YEARS`
          - `FOUR_YEARS`
          - `FIVE_YEARS`

        </ResponseField>

        <ResponseField name="timeStamp" type="string">

          Date and time the Wix user purchased the app's paid plan or began their free trial. In
          `YYYY-MM-DDThh:mm:ss.sssZ` format.

        </ResponseField>

        <ResponseField name="expirationDate" type="string">

          Date and time the app's current billing cycle ends in
          `YYYY-MM-DDThh:mm:ss.sssZ` format. Available only for yearly and
          multi-yearly plans.

        </ResponseField>

        <ResponseField name="autoRenewing" type="boolean">

          Whether the app's subscription automatically renews at the end of the
          current billing cycle.

        </ResponseField>

        <ResponseField name="invoiceId" type="integer">

          ID of the invoice for the current billing cycle.

        </ResponseField>

        <ResponseField name="source" type="string">

          Information about any discounts applied to the app instance's current billing cycle.
          If the site owners applied a developer coupon or Wix Voucher
          when installing the paid version of your app, this field holds the coupon's
          name or `“Wix discount coupon”`. Site owners may receive a Wix Voucher when
          upgrading their Wix subscription. If there is no discount for the
          current billing cycle, the field is an empty string.

        </ResponseField>

        <ResponseField name="freeTrialInfo" type="FreeTrialInfo">

          Information about the free trial applied, if relevant.

          <Expandable title="freeTrialInfo properties">

            <ResponseField name="status" type="string">

              Current free trial status.

              **Read-only.**

              **Supported values:**

              - `IN_PROGRESS` — The free trial is currently in progress.
              - `ENDED` — The free trial has ended.
              - `NOT_AVAILABLE` — No free trial was applied, as none was available.

            </ResponseField>

            <ResponseField name="endDate" type="datetime">

              When the free trial has ended. Populated only once the free trial is over.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="permissions" type="string[]">

      List of [permissions](https://dev.wix.com/docs/build-apps/developer-tools/developers-center/example-app-walkthrough/build-an-app#4-add-permissions)
      that the Wix user has granted your app. You set the list of permissions that
      your app requires from the Wix user in your app's Permissions page.

    </ResponseField>

    <ResponseField name="availablePlans" type="AvailablePlan[]">

      Plans available to this app instance.

      <Expandable title="availablePlans properties">

        <ResponseField name="packageName" type="string">

          Package name of the available plan.

        </ResponseField>

        <ResponseField name="source" type="string">

          Source of the available plan. Can be a bundle or 3rd-party app.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="originInstanceId" type="string">

      ID of the Wix site from which the instance of your app has been cloned.

      All visual settings of the Wix site and app data are duplicated during the
      cloning process. Wix also notifies you in case there is any additional
      external functionality for the original site.

    </ResponseField>

    <ResponseField name="isOriginSiteTemplate" type="boolean" deprecated>

      __Deprecated__. This parameter will be removed on March 30, 2023. Use
      `copiedFromTemplate` instead.

      **Deprecated.**

    </ResponseField>

    <ResponseField name="copiedFromTemplate" type="boolean">

      Whether this app instance was created when another Wix site was cloned.

    </ResponseField>

    <ResponseField name="freeTrialAvailable" type="boolean">

      Whether this app instance includes a free trial that hasn't started yet.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "instance": {
          "appName": "MY_SHINY_APP",
          "appVersion": "0.0.53",
          "billing": {
            "billingCycle": "MONTHLY",
            "packageName": "e8f429d4-0a6a-468f-8044-87f519a53202"
          },
          "instanceId": "07864c16-3a6f-4dd2-9973-028705762b2c",
          "isFree": false,
          "permissions": [
            "WIX_DEVELOPERS.CREATE_CHECKOUT",
            "WIX_DEVELOPERS.MANAGE_APP_INSTANCE",
            "WIX_DEVELOPERS.MANAGE_CHARGE"
          ]
        },
        "site": {
          "locale": "he",
          "multilingual": {
            "isMultiLingual": false,
            "supportedLanguages": []
          },
          "paymentCurrency": "ILS",
          "siteDisplayName": "Mysite 34",
          "url": "https://doereg11.wixsite.com/mysite-34",
          "description": "My awesome site is all about selling stuff",
          "siteId": "64fc2d7e-1585-45ef-b1c3-6081185108c1"
        }
      }
      ```

    </CodeGroup>

  </Tab>
