    Updates a custom field application.

    Partial updates are not supported. Pass the whole `application` object in the request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/members/v1/custom-fields-applications/{application.customFieldId}
    ```

    ## Path Params

    <ParamField path="application.customFieldId" type="string" required>

      Custom field ID.

    </ParamField>

    ## Body Params

    <ParamField body="application" type="CustomFieldApplication" required>

      Custom field application to update.

      See the [Custom Field Application Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-field-applications/custom-field-application-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="application" type="CustomFieldApplication">

      Updated custom field application.

      See the [Custom Field Application Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-field-applications/custom-field-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
