    <div className="wix-ref">

    Creates a manual tax mapping for a specific tax group and region combination.

    You must specify the tax group ID and tax region ID. The tax group and tax region
    must already exist before creating the mapping.
    To create multiple manual tax mappings in a single request, use [Bulk Create Manual Tax Mappings](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/bulk-create-manual-tax-mappings).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/manual-tax-mappings
    ```

    ## Body Params

    <ParamField body="manualTaxMapping" type="ManualTaxMapping" required>

      Manual tax mapping to create.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="manualTaxMapping" type="ManualTaxMapping">

      Created manual tax mapping.

      See the [Manual Tax Mapping Object](/api-reference/business-solutions/e-commerce/extensions/tax/manual-tax-mappings/manual-tax-mapping-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `TAX_REGION_ID_NOT_FOUND` | The specified tax region ID doesn't exist. |
    | `404` | `NOT_FOUND` | `TAX_GROUP_ID_NOT_FOUND` | The specified tax group ID doesn't exist. |
    | `409` | `ALREADY_EXISTS` | `MANUAL_TAX_MAPPING_ALREADY_EXISTS` | A manual tax mapping already exists for the given tax group and tax region combination. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Manual Tax Mapping Created | `wix.billing.v1.manual_tax_mapping_created` | Triggered when a manual tax mapping is created. |
