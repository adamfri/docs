    <div className="wix-ref">

    Creates custom additional fees on a draft order.

    Newly created additional fees are not applied by default.
    To apply them, use Set Additional Fees.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}/create-additional-fees
    ```

    ## Path Params

    <ParamField path="draftOrderId" type="string" required>

      Draft order ID.

    </ParamField>

    ## Body Params

    <ParamField body="customAdditionalFees" type="AdditionalFeeOption[]">

      Custom additional fees to create.

      Created additional fees are not applied by default.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="customAdditionalFees properties">

        <ParamField body="name" type="string" required>

          Name of the additional fee.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="price" type="Price" required>

          Price of the additional fee.

          <Expandable title="price properties">

            <ParamField body="amount" type="string" required>

              Amount.

              Constraints: `>= 0`, `<= 1000000000000000`.

            </ParamField>

            <ParamField body="formattedAmount" type="string">

              Amount formatted with currency symbol.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="taxDetails" type="TaxDetails">

          Tax calculation details.

          <Expandable title="taxDetails properties">

            <ParamField body="taxable" type="boolean">

              Whether the additional fee is taxable.

            </ParamField>

            <ParamField body="taxGroupId" type="string">

              Optional tax group ID to use when calculating tax for this additional fee.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="applyToDraftOrder" type="boolean">

          Whether to apply the additional fee to the draft order.

          Default: `false`

        </ParamField>

        <ParamField body="code" type="string">

          Additional fee unique code (or ID) for future processing.

        </ParamField>

        <ParamField body="lineItemIds" type="string[]">

          IDs of the line items associated with this additional fee.

          If no `lineItemIds` are provided, the fee will be associated with the whole order.

          Constraints: `format GUID`, `maxItems 300`.

        </ParamField>

      </Expandable>

    </ParamField>
