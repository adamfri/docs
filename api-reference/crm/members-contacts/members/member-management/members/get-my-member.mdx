    Retrieves the current member.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    To retrieve a member by `ID`, call [Get Member](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/get-member).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-MEMBERS">Read Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/members/my
    ```

    ## Query Params

    <ParamField query="fieldsets" type="string[]">

      Predefined set of fields to return.

      Default: `"PUBLIC"`.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `PUBLIC` — Includes `id`, `contactId`, `createdDate`, `updatedDate` and the `profile` object.
      `status`, `privacyStatus`, and `activityStatus` are returned as `UNKNOWN`.
      - `EXTENDED` — Includes `id`, `loginEmail`, `status`, `contactId`, `createdDate`, `updatedDate`, `privacyStatus`, `activityStatus` and the `profile` object.
      - `FULL` — Includes all fields.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      The retrieved member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `NOT_FOUND` | The current site member could not be found (e.g. member was deleted). |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
