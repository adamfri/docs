    <div className="wix-ref">

    Retrieves a list of default tax groups.

    The default tax groups for a site are inherited by the apps installed on the site.
    For example, the Wix Stores app includes a `"Products"` tax group by default.

    Add additional default tax groups with the Tax Groups Integration service plugin (REST only).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/billing/v1/tax-groups/default-tax-groups
    ```

    ## Response Object

    <ResponseField name="taxGroups" type="TaxGroup[]">

      Retrieved default tax groups.

      See the [Tax Group Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-groups/tax-group-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">
