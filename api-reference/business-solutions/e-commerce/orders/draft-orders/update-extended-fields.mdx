    Updates extended fields on a draft order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>
    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{id}/update-extended-fields
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the entity to update.

    </ParamField>

    ## Body Params

    <ParamField body="namespace" type="string" required>

      Identifier for the app whose extended fields are being updated.

    </ParamField>

    <ParamField body="namespaceData" type="object" required>

      Data to update. Structured according to the [schema](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields#json-schema-for-extended-fields) defined when the extended fields were configured.

    </ParamField>

    ## Response Object

    <ResponseField name="draftOrder" type="DraftOrder">

      Updated draft order.

      See the [Draft Order Object](/api-reference/business-solutions/e-commerce/orders/draft-orders/draft-order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DRAFT_ORDER_DOES_NOT_EXIST` | Couldn't find the draft order. |
    | `409` | `ALREADY_EXISTS` | `DRAFT_ORDER_ALREADY_COMMITTED` | Draft order was already committed. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Draft Order Updated | `wix.ecom.v1.draft_order_updated` | Triggered when a draft order is updated. |

    </div>
