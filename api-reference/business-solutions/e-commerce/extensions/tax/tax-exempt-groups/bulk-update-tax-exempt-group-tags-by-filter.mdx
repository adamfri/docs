    Asynchronously updates tags on multiple tax exempt groups that match the provided filter criteria.

    An empty filter matches all tax exempt groups.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="BILLING.TAX_EXEMPT_GROUP_UPDATE_TAGS">BILLING.TAX_EXEMPT_GROUP_UPDATE_TAGS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/bulk/tax-exempt-groups/update-tags-by-filter
    ```

    ## Examples

    Asynchronously assigns and unassigns tags on all tax exempt groups matching the filter. Returns a job ID. An empty filter matches all tax exempt groups.

    <CodeGroup>

      ```bash Request
      curl -X POST \
          'https://www.wixapis.com/billing/v1/bulk/tax-exempt-groups/update-tags-by-filter' \
          -H 'Authorization: <AUTH>' \
          -H 'Content-Type: application/json' \
          -d '{
          "filter": {
            "name": { "$startsWith": "Full" }
          },
          "assignTags": {
            "publicTags": { "tagIds": ["b2b"] }
          }
        }'
      ```

