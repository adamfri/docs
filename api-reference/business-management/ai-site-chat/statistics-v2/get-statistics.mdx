    Retrieves aggregated AI Site-Chat statistics for the authenticated site.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INNOVATION_LAB.USER">Innovation Lab User</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/innovation/assistant/v2/statistics
    ```

    ## Query Params

    <ParamField query="dailyFields" type="string[]">

      Daily KPI fields to return in `statistics.dailyKpis`.

      Supported values: `kpi_date`, `mode`, `conversations_count`, `visitors_distinct_count`, `exposed_items_count`, `total_orders_count`, `replied_conversations_count`, `response_time_seconds_p50`, `first_response_time_seconds_p50`.

      Default: All supported daily KPI fields.

    </ParamField>

    <ParamField query="byPeriodFields" type="string[]">

      Period KPI fields to return in `statistics.periodKpis`.

      Supported values: `period`, `mode`, `conversations_count`, `visitors_distinct_count`, `exposed_items_count`, `total_orders_count`, `replied_conversations_count`, `response_time_seconds_p50`, `first_response_time_seconds_p50`.

      Default: All supported period KPI fields.

    </ParamField>

    ## Response Object

    <ResponseField name="statistics" type="Statistics">

      Aggregated AI Site-Chat statistics for the authenticated site.

      See the [Statistics Object](/api-reference/business-management/ai-site-chat/statistics-v2/statistics-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
