    <div className="wix-ref">

    Adds a plugin to a data collection.

    If a plugin of the same type already exists in the collection, this operation fails.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/collections/add-plugin
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the data collection to update.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="plugin" type="Plugin" required>

      Plugin to add to the collection. Must include the plugin type and any type-specific configuration.
      If a plugin of the same type already exists in the collection, this operation fails.

      <Expandable title="plugin properties">

        <ParamField body="type" type="string" required>

          Plugin type.

          **Supported values:**

          - `PUBLISH` — Allows items to be marked as either draft or published. For each item you can set a publishing time when the item will become visible to site visitors.
          - `SINGLE_ITEM` — Ensures the collection can have one item at most. Can only be applied to a new collection.
          - `URLIZED` — Generates item URLs for collections used by dynamic pages.
          - `GRIDAPPLESS` — Deprecated. Will be removed in the future.
          - `MULTILINGUAL` — Indicates that the collection is translatable. This allows you to manage translation for selected fields using [Wix Multilingual](https://www.wix.com/app-market/wix-multilingual).
          - `SHARED` — Indicates that collection is shared with current site.
          - `EDITABLE_PAGE_LINK` — Indicates that page link fields are persisted and can be updated.
          - `CMS` — CMS-specific collection properties.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="options" type="options">

          options

          <Expandable title="options properties">

            <ParamField body="publishOptions" type="PublishPluginOptions">

              Options for the Publish plugin.
              This plugin allows items in a [data collection](https://dev.wix.com/docs/rest/business-solutions/cms/data-collections/data-collection-object) to be marked as draft or published. Published items are visible to site visitors, while draft items are not.

              _Nested structure omitted for brevity — see the `PublishPluginOptions` object._

            </ParamField>

            <ParamField body="singleItemOptions" type="SingleItemPluginOptions">

              Options for the Single Item plugin.

              _Nested structure omitted for brevity — see the `SingleItemPluginOptions` object._

            </ParamField>

            <ParamField body="urlizedOptions" type="UrlizedPluginOptions">

              Options for the Urlized plugin.

              _Nested structure omitted for brevity — see the `UrlizedPluginOptions` object._

            </ParamField>

            <ParamField body="multilingualOptions" type="MultilingualOptions">

              Options for the Multilingual plugin.

              _Nested structure omitted for brevity — see the `MultilingualOptions` object._

            </ParamField>

            <ParamField body="editablePageLinkOptions" type="PageLinkPluginOptions">

              Options for the PageLink plugin.

              _Nested structure omitted for brevity — see the `PageLinkPluginOptions` object._

            </ParamField>

            <ParamField body="cmsOptions" type="CmsOptions">

              Options for the CMS plugin.

              _Nested structure omitted for brevity — see the `CmsOptions` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="dataCollection" type="DataCollection">

      Updated data collection.

    </ResponseField>
