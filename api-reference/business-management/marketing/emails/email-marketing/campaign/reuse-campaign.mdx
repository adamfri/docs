    Creates a copy of an existing campaign.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/reuse
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      Campaign ID.

    </ParamField>

    ## Response Object

    <ResponseField name="campaign" type="Campaign">

      Campaign information.

      See the [Campaign Object](/api-reference/business-management/marketing/emails/email-marketing/campaign/campaign-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Campaign Created | `wix.email_marketing.v1.campaign_created` | Triggered when a campaign is created. |

    </div>
