Triggered when a reward is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.loyalty.v1.reward_updated` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty` |

## Examples

<CodeGroup>

  ```javascript onRewardUpdated
  import { rewards } from '@wix/loyalty';

  rewards.onRewardUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onRewardUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { rewards } from '@wix/loyalty';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        rewards,
      },
  });

  wixClient.rewards.onRewardUpdated((event) => {
      // handle your event here
  });
  ```
