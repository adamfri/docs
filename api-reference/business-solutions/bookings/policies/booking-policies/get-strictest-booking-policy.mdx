    Retrieves the strictest version of each policy rule from a list of booking
    policies.

    Returns a hypothetical `bookingPolicy` object that combines the strictest
    version of each rule. The `id` of the returned policy is `null` and no
    corresponding `bookingPolicy` object is created. To create a new policy, you
    can call [Create Booking Policy](https://dev.wix.com/docs/rest/business-solutions/bookings/policies/booking-policies/create-booking-policy).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/booking-policies/strictest
    ```

    ## Body Params

    <ParamField body="bookingPolicyIds" type="string[]" required>

      IDs of the booking policies for which to retrieve the strictest rules for.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="bookingPolicy" type="BookingPolicy">

      Hypothetical `bookingPolicy` object that combines the strictest version of
      each rule. `bookingPolicy.id` is `null` and the returned object isn't actually
      created. To create a new policy, you can call [Create Booking Policy](https://dev.wix.com/docs/api-reference/business-solutions/bookings/policies/booking-policies/create-booking-policy).

      See the [Booking Policy Object](/api-reference/business-solutions/bookings/policies/booking-policies/booking-policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
