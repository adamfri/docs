    <div className="wix-ref">

    Retrieves a list of all data restorations from backups.

    Results are sorted by requested date, with the newest first.

    You can use this method to check whether a restoration initiated with Restore Backup has been completed successfully.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE-BACKUPS">Manage Data Backups</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wix-data/v2/backups/restorations
    ```

    ## Query Params

    <ParamField query="status" type="string[]">

      Statuses to filter by. If provided, only restorations with the specified statuses are listed.
      For example, to list only completed restorations, use `?status=COMPLETED`.
      To list completed and pending restorations, use `?status=COMPLETED&status=PENDING`.

      Default: No filtering

      Constraints: `maxItems 10`.

      **Supported values:**

      - `PENDING` — Restoration from a backup is in progress.
      - `COMPLETED` — Restoration from a backup has been successful.
      - `FAILED` — Restoration from a backup has failed.

    </ParamField>

    <ParamField query="paging" type="Paging">

      Offset and limit of items to retrieve.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

              Backup status.

              **Read-only.**

              **Supported values:**

              - `PENDING` — Backup creation is in progress.
              - `READY` — Backup has been created successfully and can be used for data restoration.
              - `FAILED` — Backup creation has failed.
              - `DELETED` — Backup has been deleted.
              - `CANCELED` — Backup has been canceled.

            </ResponseField>

            <ResponseField name="type" type="string">

              Type of backup, based on how it was triggered.

              **Read-only.**

              **Supported values:**

              - `ON_DEMAND` — Backup taken on demand.
              - `AUTO` — Backup taken automatically by the system on a regular schedule.

            </ResponseField>
