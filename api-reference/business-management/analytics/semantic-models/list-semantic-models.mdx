    Retrieves a list of all available semantic models.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ANALYTICS-AND-REPORTS.READ-SITE-ANALYTICS">Site Analytics - read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/analytics/semantic-model/v3/semantic-models
    ```

    ## Response Object

    <ResponseField name="semanticModels" type="SemanticModel[]">

      Available semantic models.

      Constraints: `maxItems 100`.

      See the [Semantic Model Object](/api-reference/business-management/analytics/semantic-models/semantic-model-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `NO_ACCOUNT_IDENTITY` | The caller isn't authenticated. Provide valid credentials and try again. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
