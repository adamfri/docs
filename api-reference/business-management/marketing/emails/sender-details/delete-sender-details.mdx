      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    </div>

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/sender-details/v1/sender-details/{senderDetailsId}
    ```

    ## Path Params

    <ParamField path="senderDetailsId" type="string" required>

      ID of the sender to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteSenderDetailsResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_DELETE_DEFAULT_SENDER_DETAILS` | Can't delete the default sender details. Mark another sender as default first. |
