    Retrieves how to render an address form for a country.

    Tells you which address fields to show and in what order, which are
    required, the administrative areas to offer such as states or provinces, and
    what to label each field in that country.

    This is public reference data, so it needs no connected Google account and
    no existing location. Call it before collecting an address, for example
    while creating a location.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/address-schema/{countryCode}
    ```

    ## Path Params

    <ParamField path="countryCode" type="string" required>

      ISO 3166-1 alpha-2 country code (e.g. "US", "UA", "KR").

    </ParamField>

    ## Query Params

    <ParamField query="locale" type="string">

      Optional BCP-47 locale (e.g. "fr", "en"). Selects the language variant for
      administrative-area names and triggers Google's secondary-language dataset
      for countries that publish one. Defaults to "en" when empty.

      Constraints: `maxLength 35`.

    </ParamField>

    ## Response Object

    <ResponseField name="schema" type="AddressSchema">

      The decoded address form schema for the requested country.

      <Expandable title="schema properties">

        <ResponseField name="countryCode" type="string">

          Echo of the requested ISO 3166-1 alpha-2 country code.

          Constraints: `maxLength 16`.

        </ResponseField>

        <ResponseField name="fields" type="string[]">

          Address fields to render, in display order (decoded from the format string).

          Constraints: `maxItems 16`.

          **Supported values:**

          - `NAME` — Code `N`. Recipient or contact name.
          - `ORGANIZATION` — Code `O`. Organization or company.
          - `STREET_ADDRESS` — Code `A`. Street address lines.
          - `DEPENDENT_LOCALITY` — Code `D`. Dependent locality, such as a neighborhood or suburb.
          - `LOCALITY` — Code `C`. Locality, such as a city or town.
          - `ADMIN_AREA` — Code `S`. Administrative area, such as a state, province, or region.
          - `POSTAL_CODE` — Code `Z`. Postal or ZIP code.
          - `SORTING_CODE` — Code `X`. Sorting code, such as CEDEX in France.

        </ResponseField>

        <ResponseField name="requiredFields" type="string[]">

          Subset of `fields` that are mandatory (decoded from the require string).

          Constraints: `maxItems 16`.

          **Supported values:**

          - `NAME` — Code `N`. Recipient or contact name.
          - `ORGANIZATION` — Code `O`. Organization or company.
          - `STREET_ADDRESS` — Code `A`. Street address lines.
          - `DEPENDENT_LOCALITY` — Code `D`. Dependent locality, such as a neighborhood or suburb.
          - `LOCALITY` — Code `C`. Locality, such as a city or town.
          - `ADMIN_AREA` — Code `S`. Administrative area, such as a state, province, or region.
          - `POSTAL_CODE` — Code `Z`. Postal or ZIP code.
          - `SORTING_CODE` — Code `X`. Sorting code, such as CEDEX in France.

        </ResponseField>

        <ResponseField name="administrativeAreas" type="string[]">

          Administrative areas (states / provinces / regions) for the country, in the
          language selected by `locale` (Latin names preferred for Latin locales).
          Empty for countries without a sub-region list.

          Constraints: `maxLength 200`, `maxItems 200`.

        </ResponseField>

        <ResponseField name="postalFormat" type="string">

          The raw libaddressinput format template (e.g. "%N%n%O%n%A%n%C, %S %Z").

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="languages" type="string[]">

          Languages the country's address data is available in (BCP-47 tags).

          Constraints: `maxLength 35`, `maxItems 20`.

        </ResponseField>

        <ResponseField name="administrativeAreaType" type="string">

          UI label type for the administrative area (e.g. "province", "state", "do").

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="localityType" type="string">

          UI label type for the locality (e.g. "city", "district").

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="subLocalityType" type="string">

          UI label type for the sub-locality / dependent locality.

          Constraints: `maxLength 64`.

        </ResponseField>

        <ResponseField name="postalCodeType" type="string">

          UI label type for the postal code (e.g. "postal", "zip", "pin").

          Constraints: `maxLength 64`.

        </ResponseField>

      </Expandable>

    </ResponseField>
