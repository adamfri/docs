    Redirects an abandoned checkout to its checkout page.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/abandoned-checkout/{abandonedCheckoutId}/redirect-to-checkout
    ```

    ## Path Params

    <ParamField path="abandonedCheckoutId" type="string" required>

      ID of the abandoned checkout.

    </ParamField>

    ## Query Params

    <ParamField query="metasiteId" type="string" required>

      Metasite ID of the site associated with the abandoned checkout.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object
