---
title: "Pool Definition Object"
description: "A pool definition acts as a template for future pools."
icon: "cube"
---

A pool definition acts as a template for future pools.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Pool definition ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the pool definition is updated.
      To prevent conflicting changes, the current revision must be specified when updating the pool definition.

      Ignored when creating a pool definition.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the pool definition was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the pool definition was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Pool definition name.

      Constraints: `maxLength 128`.

    </ResponseField>

    <ResponseField name="programDefinitionIds" type="string[]">

      List of program definition IDs that are associated with this pool definition.

      Constraints: `format GUID`, `maxItems 20`.

    </ResponseField>

    <ResponseField name="details" type="Details">

      Pool definition benefits and settings.

      <Expandable title="details properties">

        <ResponseField name="benefits" type="Benefit[]">

          List of benefits.

          Constraints: `maxItems 10`.

          <Expandable title="benefits properties">

            <ResponseField name="benefitKey" type="string">

              Unique identifier for this benefit.

              This key is consistent across the pool definition and all associated pools that contain this benefit.

              Constraints: `maxLength 64`.

            </ResponseField>

            <ResponseField name="itemSetId" type="string">

              ID that is used to associated items with this benefit.

              **Read-only.**

            </ResponseField>

            <ResponseField name="price" type="string">

              Price of the benefit in credits. The price is the same for all of this benefit's items.

            </ResponseField>

            <ResponseField name="additionalData" type="object">

              Additional information for this benefit.

            </ResponseField>

            <ResponseField name="providerAppId" type="string">

              ID of the app providing the benefit items.

            </ResponseField>

            <ResponseField name="displayName" type="string">

              Benefit name.

            </ResponseField>

            <ResponseField name="description" type="string">

              Benefit description.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="creditConfiguration" type="CreditConfiguration">

          Credit settings.

          If this object is empty, you can't set a price for the benefit.

          <Expandable title="creditConfiguration properties">

            <ResponseField name="amount" type="string">

              Initial available amount for associated balances.

              Constraints: `>= 0`.

            </ResponseField>

            <ResponseField name="rolloverConfiguration" type="RolloverConfiguration">

              Rollover settings.

              <Expandable title="rolloverConfiguration properties">

                <ResponseField name="enabled" type="boolean">

                  Whether unused credits roll over to a new cycle when a program renews.

                </ResponseField>

                <ResponseField name="balanceCap" type="string">

                  Maximum number of credits that can roll over to the next cycle when a program renews.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="unitDisplayName" type="string">

              Credit unit display name.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="additionalData" type="object">

          Additional information relating to this object.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="namespace" type="string">

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the pool definition object.

      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="programDefinitions" type="ProgramDefinitionInfo[]">

      Program definitions that this pool definition is associated with.

      **Read-only.** Constraints: `maxItems 20`.

      <Expandable title="programDefinitions properties">

        <ResponseField name="id" type="string">

          Program definition ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="externalId" type="string">

          Program definition external ID.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>
