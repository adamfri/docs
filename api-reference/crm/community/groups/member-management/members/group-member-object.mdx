title: "Group Member Object"
description: "A group member represents an existing site member that has joined a group."
icon: "cube"
---

A group member represents an existing site member that has joined a group.
You can add, remove, and query group members.
Learn more about [group members](https://support.wix.com/en/article/wix-groups-adding-new-members-to-your-group).

<Tabs>

  <Tab title="REST">

    <ResponseField name="memberId" type="string">

      Member ID. See the Members API for more details.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="role" type="GroupRole">

      Group member role.

      <Expandable title="role properties">

        <ResponseField name="value" type="string">

          Member's role.

          **Supported values:**

          - `MEMBER` — Regular group member.
          - `ADMIN` — Group administrator.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="joinedDate" type="datetime">

      Date and time the group Member joined the group.

      **Read-only.**

    </ResponseField>
