    Retrieves the schema of the identity types that triggers can reference.

    When a trigger's payload schema annotates a field with an identity type, such as `contact` or `member`, Wix can enrich the payload with that identity's fields. This method returns an object whose top-level keys are the supported identity types, each containing that identity's field schema. Use it to map identity fields when you display or configure an automation.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/triggers/identities_schema
    ```

    ## Response Object

    <ResponseField name="identitiesSchema" type="object">

      Schema of the supported identity types.

      The top-level keys are identity-type names, such as `contact` and `member`, and each value is the field schema for that identity type. All payload fields enriched with the same identity type share that type's schema. For example:

      &#123;
      "type": "object",
      "properties": &#123;
      "contact": &#123; "type": "object", "properties": &#123; ... &#125; &#125;,
      "member": &#123; "type": "object", "properties": &#123; ... &#125; &#125;
      &#125;
      &#125;

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
