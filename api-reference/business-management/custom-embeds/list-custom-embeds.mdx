    Retrieves a list of up to 100 custom embeds, sorted by position  (`HEAD`, `BODY_START` or `BODY_END`).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS">SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/embeds/v1/custom-embeds
    ```

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Pagination options.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="customEmbeds" type="CustomEmbed[]">

      List of custom embeds.

      See the [Custom Embed Object](/api-reference/business-management/custom-embeds/custom-embed-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Pagination metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
