    Clears a member's street addresses.

    Members are typically associated with a contact, each having a distinct member ID and contact ID. When specifying the ID as a parameter, don't presume the IDs are identical since they represent separate entities.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/members/v1/members/{id}/addresses
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the member whose street addresses will be deleted.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      Updated member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
