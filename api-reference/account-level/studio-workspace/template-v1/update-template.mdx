    Updates a template.

    Each time the template is updated, `revision` increments by 1. The current `revision` must be passed when updating the template. This ensures you're working with the latest template and prevents unintended overwrites.

    Currently, only the template's `name` can be updated.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES">SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/wixstudio/templates/v1/templates/{template.id}
    ```

    ## Path Params

    <ParamField path="template.id" type="string" required>

      Template ID.

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Template ID.

      **Read-only.**

    </ParamField>

    <ParamField body="template" type="UpdateTemplate" required>

      Template to update.

      <Expandable title="template properties">

        <ParamField body="_id" type="string">

          Template ID.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Template name.

        </ParamField>

        <ParamField body="sites" type="Sites">

          Sites created from this template within the current account.

          **Read-only.**

          <Expandable title="sites properties">

            <ParamField body="metaSiteIds" type="string[]">

              IDs of the sites created from this template within the current account.

              Constraints: `format GUID`, `maxItems 1000`.

            </ParamField>

            <ParamField body="count" type="integer">

              Number of sites created from this template within the current account.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="createdBy" type="string">

          ID of the user who created the template.

          **Read-only.**

        </ParamField>

        <ParamField body="lastEditedBy" type="string">

          ID of the user who last edited the template's site.

          **Read-only.**

        </ParamField>

        <ParamField body="lastEditedDate" type="datetime">

          Date and time the template's site was last edited.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the template is updated. To prevent conflicting changes, the current revision must be passed when updating the template. Ignored when creating a template.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the template was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the template was updated.

          **Read-only.**

        </ParamField>

        <ParamField body="templateType" type="string">

          Type of the template. A template is always created as `STUDIO`, and becomes `PUBLIC` when it's published.

          **Read-only.**

          **Supported values:**

          - `STUDIO` — Standard template created from a site.
          - `PUBLIC` — Published template that other Wix accounts can clone.

        </ParamField>

        <ParamField body="hidden" type="boolean">

          Whether the template is hidden from template galleries and pickers. A hidden template still exists and can be used to create sites, but doesn't appear in template lists. Default: `false`.

        </ParamField>

        <ParamField body="platform" type="string">

          Platform the template's site was built on. Derived automatically from the site.

          **Read-only.**

          **Supported values:**

          - `STUDIO` — Site built with Wix Studio.
          - `WIX` — Site built with the Wix Editor.

        </ParamField>

      </Expandable>

    </ParamField>
