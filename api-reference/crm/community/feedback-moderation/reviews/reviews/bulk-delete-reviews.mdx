    <div className="wix-ref">

    Deletes multiple reviews.

    All reviews that meet the specified `filter` criteria are deleted.

    To delete a single review, call Delete Review.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v1/bulk/reviews/delete
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Query options. See [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language) for more details.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Bulk job ID.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Review Deleted | `wix.reviews.v1.review_deleted` | Triggered when a review is deleted. |

    </div>

      ```bash Request
      curl POST \
        'https://www.wixapis.com/reviews/v1/bulk/reviews/delete'  \
        -H 'Content-Type: application/json;charset=UTF-8' \
        -H 'Authorization: <AUTH>' \
        -d '{
          "filter": 
            {
              "id": { 
                "$in": ["605c64b4-d40c-4d53-a777-015209763905", "605c64b4-d40c-4d53-a777-01520976111"] 
              }
            }
      ```
