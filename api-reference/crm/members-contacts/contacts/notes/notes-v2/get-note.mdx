    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/crm/notes/v2/notes/{noteId}
    ```

    ## Path Params

    <ParamField path="noteId" type="string" required>

      Note ID.

    </ParamField>
