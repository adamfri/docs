The Groups API provides functionality for managing groups, including creating, deleting, updating, and querying groups.

The Groups API allows you to:
* [Create](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/create-group) a new group.
* [Delete](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/delete-group) or [update](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/update-group) an existing group.
* Get group information [by ID](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/get-group) or [by slug](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/get-group-by-slug).
* [List](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/list-groups) or [query](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/query-groups) groups.
* Handle events that trigger when a group is [created](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/group-created), [updated](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/group-updated), or [deleted](fallback::https://dev.wix.com/docs/rest/crm/community/groups/groups/group-deleted).

## Who can create a group
Wix users determine who can create a group. 
This setting can be found in [a site's Dashboard](fallback::https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fwix-groups/settings?) under **Groups > General Settings > Group Creation**.
If set to **members with approval**, site members can create a group with the Create Group method, and the group becomes a 
[`createRequest`](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/introduction) with a status of `PENDING`. 
A Wix user either [approves](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/approve-group-requests) 
or [rejects](fallback::https://dev.wix.com/docs/rest/crm/community/groups/create-requests/reject-group-requests) the request to create a group.
If set to **all site members**, site members can create a group with the Create Group method and no approval is required.
If set to **only admins**, only Wix users can create a group with the Create Group method.  

The default is set to **members with approval**.
