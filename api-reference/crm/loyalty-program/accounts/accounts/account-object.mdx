---
title: "Account Object"
description: "A loyalty account stores a customer's loyalty points balance."
icon: "cube"
---

A loyalty account stores a customer's loyalty points balance. A site's customers can earn points to their account
and redeem those points for rewards.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Account ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Account owner's contact ID. See the Contacts API to learn more about a site's contacts.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="memberId" type="string">

      Member ID of the account owner. See the Members API to learn more about a site's members.

      **Read-only.**

    </ResponseField>

    <ResponseField name="points" type="Points">

      Details of the account's point totals.

      **Read-only.**

      <Expandable title="points properties">

        <ResponseField name="balance" type="integer">

          Current points balance.

          Equal to the sum of `earned` and `adjusted` points, minus `redeemed` points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="earned" type="integer">

          Total earned points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="adjusted" type="integer">

          Total adjusted points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="redeemed" type="integer">

          Total redeemed points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

        <ResponseField name="expired" type="integer">

          Total expired points.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="rewardAvailable" type="boolean">

      Whether the account has enough points in `points.balance` to redeem for a reward.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the account was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the account was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="lastActivityDate" type="datetime">

      Date and time of the account's last activity.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="number">

      Revision number, which increments by 1 each time the loyalty account is updated.

      To prevent conflicting changes, the current `revision` must be passed when updating the loyalty account.

      Ignored when creating an account.

    </ResponseField>

    <ResponseField name="tier" type="Tier">

      Tier information.

      See the Tiers API for more information.

      **Read-only.**

      <Expandable title="tier properties">

        <ResponseField name="id" type="string">

          Tier ID.

          This field will not be returned if the account belongs to the base tier.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the tier information was last recalculated.

          **Read-only.**

        </ResponseField>

        <ResponseField name="points" type="integer">

          Points earned and adjusted over the tier's current rolling window.

          **Read-only.** Constraints: `min 0`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="contact" type="Contact">

      Contact information.

      **Read-only.**

      <Expandable title="contact properties">

        <ResponseField name="id" type="string">

          Contact ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="name" type="string">

          Contact's first and last name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="picture" type="Image">

          Contact's profile picture.

          **Read-only.**

          <Expandable title="picture properties">

            <ResponseField name="id" type="string">

              WixMedia image ID.

            </ResponseField>

            <ResponseField name="url" type="string">

              Image URL.

            </ResponseField>

            <ResponseField name="height" type="integer">

              Original image height.

              **Read-only.**

            </ResponseField>

            <ResponseField name="width" type="integer">

              Original image width.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="email" type="string">

          Contact's email address.

          **Read-only.**

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Contact's first and last name. If no name is provided, uses contact's email.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pointsExpiration" type="PointsExpiration">

      Points expiration information.

      **Read-only.**

      <Expandable title="pointsExpiration properties">

        <ResponseField name="expirationDate" type="datetime">

          Date and time at which points are expiring.

          **Read-only.**

        </ResponseField>

        <ResponseField name="expiringPointsAmount" type="integer">

          Amount of points that are going to expire at that date.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>
