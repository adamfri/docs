<Tabs>

  <Tab title="REST">

    Updates the SEO configuration for the current site.

    Each time the SEO configuration is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the SEO configuration.
    This ensures you're working with the latest SEO configuration and prevents unintended overwrites.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="seo_user_config:v1:seo_user_config:update_seo_user_config">seo_user_config:v1:seo_user_config:update_seo_user_config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/seo/user-config/v1/seo-user-config
    ```

    ## Body Params

    <ParamField body="seoUserConfig" type="SeoUserConfig" required>

      SEO configuration fields to update.

      See the [Seo User Config Object](/api-reference/business-management/marketing/seo/seo-user-config/seo-user-config-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="seoUserConfig" type="SeoUserConfig">

      Updated SEO configuration.

      See the [Seo User Config Object](/api-reference/business-management/marketing/seo/seo-user-config/seo-user-config-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
