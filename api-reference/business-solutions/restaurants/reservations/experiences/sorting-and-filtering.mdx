The following table shows field support for filters and sorting for the Experience object:

| Field                                                                                     | Supported Filters                                                         | Sortable |
|-------------------------------------------------------------------------------------------|---------------------------------------------------------------------------|----------|
| `id`                                                                                      | `$eq`, `$ne`, `$in`, `$nin`, `$exists`                                    | Yes      |
| `tags`                                                                                    | `$eq`, `$ne`, `$in`, `$nin`, `$hasAll`, `$hasSome`, `$exists`, `$isEmpty` | Yes      |
| `reservation_location_id`                                                                 | `$eq`, `$ne`, `$in`, `$nin`, `$exists`                                    | Yes      |
| `configuration.visible`                                                                   | `$eq`, `$ne`, `$exists`                                                   | Yes      |
| `configuration.online_reservations.business_schedule.entries.weekly_options.start_date`   | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`      | Yes      |
| `configuration.online_reservations.business_schedule.entries.weekly_options.end_date`     | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`      | Yes      |
| `configuration.online_reservations.business_schedule.entries.one_time_options.start_date` | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`      | Yes      |
| `created_date`                                                                            | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`      | Yes      |
| `updated_date`                                                                            | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`      | Yes      |

**Sorting:** All listed fields support both ascending (`ASC`) and descending (`DESC`) sort orders.
