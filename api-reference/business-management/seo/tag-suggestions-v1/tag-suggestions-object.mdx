SEO tag texts generated for a page.

Suggestions are generated for each call and aren't stored, so there's no ID
to retrieve them by later. Calling the same method twice may return
different suggestions.

<Tabs>

  <Tab title="REST">

    <ResponseField name="suggestions" type="string[]">

      Suggested tag texts, best match first.

      **Read-only.** Constraints: `maxLength 1000`, `maxItems 10`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "tagSuggestions": {
          "suggestions": [
            "Handmade Ceramic Mugs - Unique Artisan Coffee Cups & Tea Mugs Online",
            "Handmade Ceramic Mugs | Unique Artisan Coffee Cups & Tea Mugs Online",
            "Handmade Ceramic Mugs - Unique Artisan Designs for Your Coffee Moments"
          ]
        }
      }
      ```

    </CodeGroup>
