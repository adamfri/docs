    <div className="wix-api-columns">

    <div className="wix-ref">

    Checks whether a custom slug is validate for the service.

    The checks include:
    - The slug adheres to the supported format.
    - No other service is currently using the slug.
    - No other service has used the slug in the past.

    The call fails if at least one of the checks fails.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/slugs/validate
    ```

    ## Body Params

    <ParamField body="serviceId" type="string" required>

      IO of the service to check custom slug validity for.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="slug" type="string">

      Custom slug to validate.

      Constraints: `maxLength 500`.

    </ParamField>

    ## Response Object

    <ResponseField name="valid" type="boolean">

      Whether the slug is valid.

    </ResponseField>

    <ResponseField name="slug" type="string">

      Valid slug. Available only if `{"valid": true}`.

    </ResponseField>

    <ResponseField name="errors" type="string[]">

      Reasons why the slug is invalid. Available only if `{"valid": false}`.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `SLUG_CONTAINS_ILLEGAL_CHARACTERS` — Slug contains illegal characters.
      - `SLUG_ALREADY_EXISTS` — Slug is already associated with another service.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
