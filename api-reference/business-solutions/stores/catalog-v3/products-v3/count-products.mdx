    Counts the number of products that match the provided filtering.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_READ">Read products in v3 catalog</span>
    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_READ_ADMIN">Product v3 read admin</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/products/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Defines how separate search terms in `expression` are combined

          **Supported values:**

          - `OR` — Any of the search terms must be present
          - `AND` — All search terms must be present

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnNonVisibleProducts" type="boolean">

      Whether to return non-visible products (`visible:false`). Your app must have the 'Product v3 read admin' (`SCOPE.STORES.PRODUCT_READ_ADMIN`) permission scope.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total number of products.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `NO_PERMISSION_TO_READ_MERCHANT_DATA` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method doesn't have the required permissions. |
    | `403` | `PERMISSION_DENIED` | `NO_PERMISSION_TO_INCLUDE_NOT_VISIBLE_PRODUCTS` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method doesn't have the required permissions. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/stores/v3/products/count' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>' \
      -d '{
            "filter": {
              "$and": [
                {
                  "allCategoriesInfo.categories": {
                    "$matchItems": [
                      {
                        "id": {
                          "$eq": "643721c3-446e-47f3-87ee-0a58d6842d48"
                        }
                      }
                    ]
                  }
                },
                {
                  "productType": {
                    "$eq": "PHYSICAL"
                  }
                },
                {
                  "visible": {
                    "$eq": false
                  }
                },
                {
                  "brand.id": {
                    "$eq": "4a16d28d-1736-41f0-87d8-995f6d9a5bdd"
                  }
                },
                {
                  "infoSections.id": {
                    "$hasSome": [
                      "59954f23-fbcd-42e5-ba61-7c8cf9d8b409"
                    ]
                  }
                },
                {
                  "actualPriceRange.minValue.amount": {
                    "$gt": 3
                  }
                },
                {
                  "actualPriceRange.minValue.amount": {
                    "$lt": 120
                  }
                },
                {
                  "inventory.availabilityStatus": {
                    "$in": [
                      "OUT_OF_STOCK",
                      "PARTIALLY_OUT_OF_STOCK"
                    ]
                  }
                },
                {
                  "options.choicesSettings.choices.choiceId": {
                    "$hasSome": [
                      "4498b805-2aed-43fb-b478-989c906c19cd"
                    ]
                  }
                }
              ]
            }
          }'
      ```

      ```json Response
      {
        "count": 1
      }
      ```
