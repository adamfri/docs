---
title: "Item Object"
description: "An item is a social media post managed through the Publisher API."
icon: "cube"
---

An item is a social media post managed through the Publisher API. An item can be a published post, a scheduled post, or a draft, as indicated by its `status`, and it targets a single connected social channel such as Instagram, Facebook, or TikTok.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Item ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="channel" type="Channel">

      Social channel the item is published to, and the account within that channel.

      <Expandable title="channel properties">

        <ResponseField name="name" type="string">

          Social channel the item is published to.

          **Supported values:**

          - `INSTAGRAM`
          - `FACEBOOK`
          - `YOUTUBE`
          - `LINKEDIN`
          - `TWITTER` — Deprecated: No longer functional as of July 31, 2026.
          - `PINTEREST`
          - `GBP` — Google Business Profile.
          - `TIKTOK`

        </ResponseField>

        <ResponseField name="accountId" type="string">

          ID of the connected account the item is published to.

        </ResponseField>

        <ResponseField name="accountName" type="string">

          Display name of the connected account the item is published to.

          **Read-only.**

        </ResponseField>

        <ResponseField name="externalItemId" type="string">

          ID of the post on the social channel. Returned after the item is published.

          **Read-only.**

        </ResponseField>

        <ResponseField name="externalItemUrl" type="string">

          URL of the post on the social channel. Returned after the item is published.

          **Read-only.**

        </ResponseField>

        <ResponseField name="publishingTarget" type="PublishingTarget">

          Specific destination within the account, such as a Facebook page or a Pinterest board.

          <Expandable title="publishingTarget properties">

            <ResponseField name="id" type="string">

              ID of the publishing target.

            </ResponseField>

            <ResponseField name="displayName" type="string">

              Display name of the publishing target.

            </ResponseField>

            <ResponseField name="pictureUrl" type="string">

              URL of the publishing target's picture.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="type" type="string">

      Item format. The `type` and the content set in `data` must match a combination supported by the item's `channel.name`:

      - Instagram: `POST` with `instagramPost`, or `STORY` with `instagramStory`.
      - Facebook: `POST` with `facebookPost`, `REEL` with `facebookReel`, or `STORY` with `facebookStory`.
      - YouTube: `VIDEO` with `youtubeVideo`, or `SHORT` with `youtubeShort`.
      - LinkedIn: `POST` with `linkedinPost`.
      - X (Twitter): `POST` with `twitterPost`. Deprecated: No longer functional as of July 31, 2026.
      - Pinterest: `POST` with `pinterestPost`.
      - Google Business Profile: `POST` with `gbpPost`.
      - TikTok: `POST` with `tiktokPhoto`, or `VIDEO` with `tiktokVideo`.

      **Supported values:**

      - `POST` — A standard post.
      - `REEL` — A short-form vertical video reel.
      - `VIDEO` — A video.
      - `SHORT` — A short-form vertical video.
      - `STORY` — A story that's available for a limited time.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the item in its lifecycle.

      **Read-only.**

      **Supported values:**

      - `PUBLISHED` — Published to the social channel.
      - `SCHEDULED` — Scheduled to be published at a future date.
      - `CANCELED` — Scheduling was canceled before the item was published.
      - `FAILED` — Publishing failed.
      - `DELETED` — Deleted.
      - `PROCESSING` — Publishing is in progress.
      - `DRAFT` — Saved as a draft, not yet published.
      - `IN_QUEUE` — Queued for publishing as part of a bulk operation.

    </ResponseField>

    <ResponseField name="publishedDate" type="datetime">

      Date and time the item was published. Returned only after the item is published.

      **Read-only.**

    </ResponseField>

    <ResponseField name="schedulingInfo" type="SchedulingInfo">

      Scheduling info. Set to schedule the item for a future date instead of publishing it immediately.

      <Expandable title="schedulingInfo properties">

        <ResponseField name="scheduledDate" type="datetime">

          Date and time the item is scheduled to be published.

        </ResponseField>

        <ResponseField name="schedulingTimestamp" type="datetime">

          Date and time the item was scheduled.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="referenceId" type="string">

      Caller-defined reference that uniquely identifies the item. Can be used to prevent duplicate publishing: an attempt to publish a second item with the same `referenceId` fails. Can also be used as a UTM campaign ID.

    </ResponseField>

    <ResponseField name="siteAnalytics" type="SiteAnalytics">

      Aggregated analytics for the site, attributed to traffic from this post.

      <Expandable title="siteAnalytics properties">

        <ResponseField name="traffic" type="integer">

          Number of site sessions attributed to this post.

        </ResponseField>

        <ResponseField name="pageView" type="integer">

          Number of page views attributed to this post.

        </ResponseField>

        <ResponseField name="siteBounceRate" type="float">

          Site bounce rate attributed to this post.

        </ResponseField>

        <ResponseField name="revenue" type="float">

          Revenue attributed to this post.

        </ResponseField>

        <ResponseField name="conversionFunnel" type="ConversionFunnel">

          Conversion funnel data attributed to this post.

          <Expandable title="conversionFunnel properties">

            <ResponseField name="cartViewsSessions" type="integer">

              Number of sessions that viewed the cart.

            </ResponseField>

            <ResponseField name="checkOutSessions" type="integer">

              Number of sessions that reached checkout.

            </ResponseField>

            <ResponseField name="storeOrdersSessions" type="integer">

              Number of sessions that placed a store order.

            </ResponseField>

            <ResponseField name="bookingsConfirmed" type="integer">

              Number of confirmed bookings.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the insights were last updated.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="insightsSummary" type="InsightsSummary">

      Summary of the post's performance on the social channel, such as impressions and interactions.

      <Expandable title="insightsSummary properties">

        <ResponseField name="impressions" type="integer">

          Number of unique impressions (reach).

        </ResponseField>

        <ResponseField name="interactions" type="integer">

          Number of interactions, such as likes and comments.

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the insights were last updated.

        </ResponseField>

        <ResponseField name="impressionsTotal" type="integer">

          Total number of impressions.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="draftInfo" type="DraftInfo">

      Creation and update dates, returned for draft items.

      <Expandable title="draftInfo properties">

        <ResponseField name="createdDate" type="datetime">

          Date and time the draft was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the draft was updated.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="suggested" type="boolean">

      Whether the item was generated as an AI suggestion.

    </ResponseField>

    <ResponseField name="external" type="boolean">

      Whether the item is a post created natively on the social channel rather than published through Wix.

    </ResponseField>

    <ResponseField name="publicationError" type="PublicationErrorDetails">

      Details of why the item failed to publish. Returned only when `status` is `FAILED`.

      **Read-only.**

      <Expandable title="publicationError properties">

        <ResponseField name="message" type="string">

          Error message shown when publishing fails.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="siteAssetRef" type="AssetReference">

      Reference to the site content asset this post promotes (product, blog post, etc.).
      Mirrors marketing-plan-service's MarketingActivity.asset (named `asset` there;
      `site_asset_ref` here for clarity next to consumer_info). Written per-channel.

      <Expandable title="siteAssetRef properties">

        <ResponseField name="siteAssetRefType" type="string">

          Type of the site asset (for example, product or blog post). See `SiteAsset.Type` for the closed set of values.

          **Supported values:**

          - `BLOG_POST` — A Wix Blog post.
          - `EVENT` — A Wix Events event.
          - `STORES_PRODUCT` — A Wix Stores product.
          - `BOOKINGS_SERVICE` — A Wix Bookings service.
          - `STORES_COUPON` — A Wix Stores coupon.
          - `STORES_CATEGORY` — A Wix Stores category.

        </ResponseField>

        <ResponseField name="id" type="string">

          ID of the asset within its provider's data store.

        </ResponseField>

        <ResponseField name="name" type="string">

          Display name of the asset (for example, the product title or blog post title), cached at post-creation time.

          Constraints: `maxLength 3000`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "item": {
          "id": "834dc801-3e5c-416a-bd14-b130a95d100e",
          "channel": {
            "name": "INSTAGRAM",
            "accountId": "17841405822304914"
          },
          "type": "POST",
          "status": "DRAFT",
          "instagramPost": {
            "mediaWrapper": {
              "media": [
                {
                  "type": "IMAGE",
                  "url": "https://static.wixstatic.com/media/cf2434_4b3a2d8eb7f54bc89c0d4524430a2af3~mv2.jpg"
                }
              ]
            },
            "caption": "Summer collection just dropped! Shop the look now. #summerstyle #newarrivals"
          },
          "draftInfo": {
            "createdDate": "2026-06-11T07:20:56.561Z",
            "updatedDate": "2026-06-11T07:20:56.561Z"
          },
          "suggested": false,
          "external": false
        }
      }
      ```

    </CodeGroup>
