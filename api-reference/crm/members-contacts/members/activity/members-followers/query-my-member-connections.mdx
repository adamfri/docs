    <div className="wix-ref">

    Retrieves a list of members and their connections to the current member.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v3/followers/my/connections
    ```

    ## Body Params

    <ParamField body="connectedMemberIds" type="string[]" required>

      List of member IDs whose connections to the current member will be retrieved.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="connectedMembers" type="ConnectedMembers[]">

      Retrieved list of members whose connections to the current member were retrieved.

      <Expandable title="connectedMembers properties">

        <ResponseField name="connectedMemberId" type="string">

          Site member ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="followedByMember" type="boolean">

          Whether the listed member is followed by the given member.

        </ResponseField>

        <ResponseField name="followingMember" type="boolean">

          Whether the listed member follows the given member.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
