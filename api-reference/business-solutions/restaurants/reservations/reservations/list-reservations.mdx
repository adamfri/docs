    Retrieves a list of up to 100 reservations.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-MEDIUM">Manage Reservations (Medium)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/table-reservations/reservations/v1/reservations
    ```

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Cursor token pointing to a page of results. Not used in the first request. Following requests use the cursor token and not `filter` or `sort`.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          You can get the relevant cursor token
          from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="sort" type="Sorting">

      Defines how reservations in the response are sorted.

      <Expandable title="sort properties">

        <ParamField query="fieldName" type="string">

          Name of the field to sort by.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.
          Default: `ASC`.

          **Supported values:**

          - `ASC` — Sort by ascending order.
          - `DESC` — Sort by descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="startDateFrom" type="datetime">

      Only reservations starting after this date are returned.

    </ParamField>

    <ParamField query="startDateTo" type="datetime">

      Only reservations starting before this date are returned.

    </ParamField>

    <ParamField query="status" type="string">

      Only reservations with this status are returned.

      **Supported values:**

      - `HELD` — A customer has begun the reservation flow, a temporary reservation is created and will expire in 10 minutes unless the customer moves forward with the reservation flow. This phase temporarily reserves the required number of seats and tables for a given party size at a chosen time while a customer enters details and/or confirms their reservation request.
      - `RESERVED` — The reservation is confirmed.
      - `CANCELED` — The reservation is canceled.
      - `FINISHED` — The reservation completed successfully.
      - `NO_SHOW` — The customer didn't show up for their reservation.
      - `SEATED` — The customer is currently occupying the table.
      - `REQUESTED` — A customer finished requesting this reservation, meaning they have added all necessary details and confirmed the request. Restaurant staff can now either approve or decline the reservation request.
      - `DECLINED` — The restaurant’s owner or staff declined the customer’s request to make the reservation.
      - `PAYMENT_INFORMATION_PENDING` — The reservation is awaiting payment. It will expire in 10 minutes from the created time unless the customer provides payment information. This phase temporarily reserves the required number of seats and tables for the given party size at the chosen time.

    </ParamField>

    </ResponseField>
