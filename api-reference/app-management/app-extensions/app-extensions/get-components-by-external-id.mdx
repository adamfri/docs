    Retrieves an app's components that have the specified external ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/components/v1/components/app/{appId}/external-id/{externalId}
    ```

    ## Path Params

    <ParamField path="appId" type="string" required>

      App ID.

    </ParamField>

    <ParamField path="externalId" type="string" required>

      Developer-provided external ID. External IDs aren't required to be unique; this request returns all matching components for the app.

    </ParamField>

    ## Query Params

    <ParamField query="consistent" type="boolean">

      Whether to return consistent results for read-after-write operations.

    </ParamField>

    ## Response Object

    <ResponseField name="components" type="Component[]">

      Components with the specified external ID.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
