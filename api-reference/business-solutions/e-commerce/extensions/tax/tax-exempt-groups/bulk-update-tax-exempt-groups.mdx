    Updates multiple tax exempt groups in a single request.

    Each time a tax exempt group is updated, `revision` increments by 1. The current `revision` must be passed for each tax exempt group. This ensures you're working with the latest tax exempt groups and prevents unintended overwrites.

    To update a single tax exempt group, call [Update Tax Exempt Group](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/tax-exempt-groups/update-tax-exempt-group).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/bulk/tax-exempt-groups/update
    ```
