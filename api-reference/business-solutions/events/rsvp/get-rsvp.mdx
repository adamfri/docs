    Retrieves an RSVP.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-GUEST-LIST">Read Event Tickets and Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v1/rsvp/{rsvpId}
    ```

    ## Path Params

    <ParamField path="rsvpId" type="string" required>

      RSVP ID.

    </ParamField>

    ## Query Params

    <ParamField query="eventId" type="string">

      Event ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="fieldset" type="string[]">

      Controls which data is returned. See [Fieldset](https://dev.wix.com/api/rest/wix-events/wix-events/fieldset#wix-events_wix-events_fieldset_rsvp-fieldset).

      Constraints: `maxItems 20`.

      **Supported values:**

      - `DETAILS` — Include RSVP details including: `created`, `modified`, `firstName`, `lastName`, `status`, `totalGuests`, `guests`, and `annonymized`.
      - `FORM` — Include RSVP form.
      - `CONTACT_DETAILS` — Include RSVP email.

    </ParamField>

    ## Response Object

    <ResponseField name="rsvp" type="Rsvp">

      RSVP.

      See the [Rsvp Object](/api-reference/business-solutions/events/rsvp/rsvp-object) for this object's fields.

    </ResponseField>
