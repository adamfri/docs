    <div className="wix-ref">

    Generates an upload URL to allow external clients to upload a contact image.
    To learn how external clients can use the generated upload URL in the response to upload a file,
    see the [Upload API](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/upload-api) article.

    You can call [Get Contact Image Upload Status](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/get-contact-image-upload-status) to query the status of the image upload.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/{contactId}/image/upload-url
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to generate an image upload URL for.

    </ParamField>

    ## Body Params

    <ParamField body="mimeType" type="string">

      MIME type. Must be one of: `image/png`, `image/jpeg`.

      Default: `image/png`

    </ParamField>

    ## Response Object

    <ResponseField name="uploadUrl" type="string">

      URL to upload the image to.

      Constraints: `format WEB_URL`.

    </ResponseField>

    <ResponseField name="imageUploadId" type="string">

      Upload ID. Pass this ID to [Get Contact Image Upload Status](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/get-contact-image-upload-status) to check the status of the upload.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_MIME_TYPE` | Invalid image MIME type. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
