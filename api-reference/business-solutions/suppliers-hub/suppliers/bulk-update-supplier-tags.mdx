    Updates tags on multiple suppliers specified by supplier IDs in a single synchronous request.

    Supports up to 100 suppliers per request. You can assign new tags, unassign existing tags, or both in a single operation. If a tag appears in both `assignTags` and `unassignTags` lists, it will be assigned. Assignment takes precedence.

    Use this endpoint to organize suppliers with public tags for categorization visible to site members, or private tags for internal management requiring additional permissions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/bulk/suppliers/update-tags
    ```
