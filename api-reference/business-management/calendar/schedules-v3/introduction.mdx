The Schedules API allows you to manage collections of
[events](fallback::https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction).
Schedules allow you to easily manage events that are linked to the same entity, such as a
[Bookings service](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/service-object)
or [Bookings resource](https://dev.wix.com/docs/rest/business-solutions/bookings/staff-members-and-resources/resource-v2/resource-object).
You can also create schedules for custom entities beyond the Wix ecosystem.
Schedules set [default values](fallback::https://dev.wix.com/docs/rest/business-management/calendar/default-values)
for their events, ensuring consistency across all related events.

With the Schedules API, you can:

+ Create and update schedules.
+ Retrieve schedules.
+ Cancel schedules permanently.
+ Track in real-time when a schedule is created or modified.

For more in-depth scheduling management, see:

+ [Events API](fallback::https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
+ [Schedule Time Frames API](fallback::https://dev.wix.com/docs/rest/business-management/calendar/schedule-time-frames-v3/introduction)
+ [Bookings APIs](https://dev.wix.com/docs/rest/business-solutions/bookings/about-wix-bookings)

## Before You Begin

It’s important to note the following points before starting to code:

+ The schedule object itself doesn’t store event details. Each event is independently managed.
+ An event must belong to exactly one schedule.
+ Once a schedule is marked as `CANCELLED`, you can't reactivate, update, or associate it with new events.
+ Recurring events aren't defined by the schedule itself. Instead, create a `MASTER` event to establish the recurrence pattern.

## Terminology

+ __Schedule__: Collection of [events](fallback::https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction) associated with a specific entity, such as a [Bookings service](fallback::https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/service-object), or [Bookings resource](https://dev.wix.com/docs/rest/business-solutions/bookings/staff-members-and-resources/resource-v2/resource-object). Schedules also serve as templates for the events they manage, setting default values like a default location.
+ __Status__: Indicates whether a schedule can be updated or if it’s permanently `CANCELLED`.
+ __Role__: You can assign roles to [Wix users](fallback::https://dev.wix.com/docs/build-apps/develop-your-app/access/about-identities#wix-users)
giving them specific access to the schedule.
  + __Writer__: Can read and modify the schedule.
  + __Commenter__: Can only read the schedule.
+ __Schedule time frame__: Defines the first and last event dates within a schedule and indicates whether any events recur indefinitely.
+ __Event__: A calendar entry that specifies details such as timing, location, and participants. Each event is associated with a schedule and may inherit its [default values](fallback::https://dev.wix.com/docs/rest/business-management/calendar/default-values). Events can be standalone or part of a recurring series and can block time or allow concurrent scheduling on the calendar.
