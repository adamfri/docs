    Reserved for Wix first-party client UI use. This endpoint is not intended for third-party integration.
    Submits a contact request from a site visitor to a partner. Triggers a PartnerContacted domain event
    and eventually sends a notification email to the partner.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="PARTNERS.AGENCY_PROFILE_CONTACT">PARTNERS.AGENCY_PROFILE_CONTACT</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/profile/v1/partner-profiles/{partnerId}/contact
    ```

    ## Path Params

    <ParamField path="partnerId" type="string" required>

      ID of the partner to contact.

    </ParamField>

    ## Body Params

    <ParamField body="email" type="string" required>

      Contact email address of the person submitting the request.

      Constraints: `format EMAIL`.

    </ParamField>

    <ParamField body="subject" type="string" required>

      Subject of the contact request.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    <ParamField body="message" type="string" required>

      Body of the contact message.

      Constraints: `minLength 1`, `maxLength 2000`.

    </ParamField>

    <ParamField body="fullName" type="string" required>

      Full name of the person submitting the request.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    Returns `ContactPartnerResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
