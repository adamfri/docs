    <div className="wix-ref">

    Creates an order.

    Use this method to create manual orders for phone or email sales or to add orders from external systems (such as POS, marketplaces, or legacy platforms). For standard online purchases, orders are created automatically through the checkout flow.

    To record payment information for the order, pass the order ID to [Add Payments](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/add-payments).

    For apps that aren't yet published in the Wix App Market, Create Order is limited to 5 calls per hour per site.

    <Note>

    + Inventory is automatically reduced when the order is placed (default) or when the order is paid. This can be configured per order creation in the `settings.orderApprovalStrategy` field in the body params. To configure this behavior for all orders, use the [Orders Settings API](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders-settings/introduction).
    + A confirmation email is sent when the order is approved.
    + If an item is digital - `lineItems[i].itemType.preset: DIGITAL` - then `lineItems[i].digitalFile` must be provided.
    + If `lineItems[i].id` is passed, it must be either a valid GUID, or empty.
    + Each line item must include either `taxDetails` or `taxInfo`.
    + If `currency`, `weightUnit`, or `buyerLanguage` aren't passed, they default to the site's settings.
    + `status` and `paymentStatus` may be adjusted during creation. For example, an order with a total of `0` is automatically created with `status: "APPROVED"` and `paymentStatus: "PAID"`.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/orders
    ```

    ## Body Params

    <ParamField body="order" type="Order" required>

      Order info.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ParamField>

    <ParamField body="settings" type="OrderCreationSettings">

      Determine order lifecycle

      **Developer Preview.**

      <Expandable title="settings properties">

        <ParamField body="orderApprovalStrategy" type="string">

          Condition for the order to be approved.
          Default: `DEFAULT`

          **Developer Preview.**

          **Supported values:**

          - `DEFAULT` — Order is automatically approved when `order.priceSummary.total = 0`, **or** after receiving payment.
          - `PAYMENT_RECEIVED` — Order is automatically approved **only** after receiving payment.
          - `PAYMENT_METHOD_SAVED` — Order is automatically approved when payment method is saved for it.

        </ParamField>

        <ParamField body="notifications" type="OrderCreateNotifications">

          Notification settings to be applied on order creation

          **Developer Preview.**

          <Expandable title="notifications properties">

            <ParamField body="sendNotificationToBuyer" type="boolean">

              Whether to send notification to the buyer.

              Default: `true`

            </ParamField>

            <ParamField body="sendNotificationsToBusiness" type="boolean">

              Whether to send notifications to the business.

              Default: `true`

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Newly created order.

      See the [Order Object](/api-reference/business-solutions/e-commerce/orders/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `PURCHASED_DATE_CANNOT_BE_IN_FUTURE` | The `purchasedDate` can't be in the future. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | --- | --- | --- |
    | Order Created | `wix.ecom.v1.order_created` | Triggered when an order is created. |
