    <div className="wix-ref">

    Retrieves a list of all team members of the requesting account with the specified filtering, sorting, and paging.

    <Note>

    This call requires an account level API key and can't be authenticated with the standard authorization header. API keys are currently available to selected beta users only.

    </Note>

    ## Filters

    When using filters for dates, you must use
    [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time).

    ## See also

    To learn about working with *Search* methods, see
    [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language) and
    [Sorting and Paging](https://dev.wix.com/docs/rest/articles/get-started/sorting-and-paging).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/roles-management/v3/team/search
    ```

    ## Body Params

    <ParamField body="query" type="string">

      Free text to match in searchable fields.

      For example, search for specific values in
      `name` or `email`.

    </ParamField>

    <ParamField body="orderBy" type="Ordering[]">

      Field name and order to sort by.

      <Expandable title="orderBy properties">

        <ParamField body="fieldName" type="string">

          Field to sort by.

          **Supported values:**

          - `Name` — Team member name.
          - `JoinedAt` — Date team member joined the account.

        </ParamField>

        <ParamField body="direction" type="string">

          Sort order.

          **Supported values:**

          - `ASC` — Ascending.
          - `DESC` — Descending.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="filter" type="object">

      Filter object for narrowing search results.

      For example, to return only users with a specific role: `{"filter": {"roleId": "6600344420111308827"}}`

      See [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language)
      for more information.

      Supported values: `inviteType` and `roleId`.

    </ParamField>

    <ParamField body="facets" type="string[]">

      Group data into categories (facets) and return the total count for each category.

      For example, use `facets` to aggregate search results by team member, invite status, or role.

      **Supported values:**

      - `Roles` — Total team members with each role.
      - `InviteStatus` — Total team members by [invite](https://dev.wix.com/docs/rest/account-level/user-management/accounts/account-invites/account-invite-object).
      `status`.
      - `Users` — Total team members.

    </ParamField>

    <ParamField body="paging" type="Paging">

      Paging options.

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField body="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="facets" type="Facet[]">

      Retrieved facets as specified in the request.

      <Expandable title="facets properties">

        <ResponseField name="facetType" type="string">

          Type of facet.

          **Supported values:**

          - `Roles` — Total team members with each role.
          - `InviteStatus` — Total team members by [invite](https://dev.wix.com/docs/rest/account-level/user-management/accounts/account-invites/account-invite-object).
          `status`.
          - `Users` — Total team members.

        </ResponseField>

        <ResponseField name="values" type="FacetValue[]">

          Values and the amount of each. Values with a count of `0` aren't returned.

          <Expandable title="values properties">

            <ResponseField name="value" type="string">

              Supported values: `Roles`, `InviteStatus`, `Users`.

            </ResponseField>

            <ResponseField name="count" type="integer">

              Number of existing items for the `value`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="teamMembers" type="TeamMemberV3[]">

      Retrieved team members and sent invites that match the search criteria specified in the request.

      Each file includes all standard `user` and `invite` information.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
