Triggered when an order is created.
Learn more about [webhook payload structure](https://dev.wix.com/docs/rest/api-reference/wix-e-commerce/orders/order-object-conversion#webhook-conversion-table).

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.ecom.v1.order_created` |
| Package | `@wix/ecom` |
| Permissions | `Manage Stores - all permissions`, `Read eCommerce - all read permissions`, `Read Orders`, `Read Stores - all read permissions`, `Manage Restaurants - all permissions`, `Manage eCommerce - all permissions`, `Manage Orders` |
