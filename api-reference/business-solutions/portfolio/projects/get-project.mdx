    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PORTFOLIO.MANAGE-PORTFOLIO">Manage Portfolio</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/portfolio/v1/projects/{projectId}
    ```

    ## Path Params

    <ParamField path="projectId" type="string" required>

      ID of the project to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="includePageUrl" type="boolean">

      Whether to include the project's relative path and full URL in the response. Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="project" type="Project">

      The requested project.

      See the [Project Object](/api-reference/business-solutions/portfolio/projects/project-object) for this object's fields.

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
