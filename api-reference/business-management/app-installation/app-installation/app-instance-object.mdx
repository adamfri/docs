---
title: "App Instance Object"
description: "The App Instance object in the Wix App Instance API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      App instance ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="appDefId" type="string">

      ID of the app to install.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="version" type="string">

      Version of the app to install.

      If you don't specify a version, the latest version of the app will be installed. Don't specify a version unless you want to install an older version of the app.

    </ResponseField>

    <ResponseField name="enabled" type="boolean">

      Whether the app instance is enabled.

    </ResponseField>

    <ResponseField name="appToken" type="string">

      A signed access token of the Wix user and the app instance.

      **Read-only.**

    </ResponseField>

    <ResponseField name="installedDate" type="datetime">

      Date and time the app instance was installed.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the app instance was last updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "appInstance": {
          "id": "07d49a20-531f-487a-8928-29426768dac7",
          "appDefId": "96186799-d99a-4b96-adf9-7cb2c1cf1e79",
          "version": "1",
          "enabled": true
        }
      }
      ```

    </CodeGroup>
