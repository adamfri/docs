    Retrieves a resource type.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>
    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.SESSIONS-RESOURCES">Read Bookings Calendar</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v2/resources/resource-types/{resourceTypeId}
    ```

    ## Path Params

    <ParamField path="resourceTypeId" type="string" required>

      ID of the resource type to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="resourceType" type="ResourceType">

      Retrieved resource type.

      See the [Resource Type Object](/api-reference/business-solutions/bookings/resources/resource-types-v2/resource-type-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
