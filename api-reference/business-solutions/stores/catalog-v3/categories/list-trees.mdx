    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a list of all trees installed on the site, sorted by `appNamespace` in ascending order.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_READ">Read categories</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/categories/v1/categories/list-trees
    ```

    ## Response Object

    <ResponseField name="trees" type="TreeReference[]">

      List of trees.

      Constraints: `maxItems 20`.

      <Expandable title="trees properties">

        <ResponseField name="appNamespace" type="string">

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ResponseField>

        <ResponseField name="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Returns the list of all category trees existing on the site.

    <CodeGroup>

      ```bash Request
      curl -X GET \
       'https://www.wixapis.com/categories/v1/categories/list-trees' \
       -H 'Content-Type: application/json' \
       -H 'Authorization: <AUTH>'
      ```

      ```json Response
      {
        "trees": [
          {
            "appNamespace": "@bookings/bookingslist",
            "treeKey": "en"
          },
          {
            "appNamespace": "@wix/stores",
            "treeKey": null
          }
        ]
      }
      ```

    </CodeGroup>

    </div>
