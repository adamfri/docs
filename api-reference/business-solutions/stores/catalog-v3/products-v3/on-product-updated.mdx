Triggered when a product is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.stores.catalog.v3.product_updated` |
| Package | `stores_products-v-3` |
| Permissions | `Manage Stores - all permissions`, `Manage Stores`, `Read products in v3 catalog`, `Read v3 catalog`, `Manage Products`, `Read Stores - all read permissions`, `Read Products`, `Product v3 read admin`, `Manage Restaurants - all permissions`, `Manage v3 catalog`, `Manage Orders` |
