<Note>This article applies to the REST API only.</Note>

The following table shows field support for filters and sorting for the Staff Member object:

| Field         | Query Filter Operators                                                | Sortable |
|---------------|-----------------------------------------------------------------------|----------|
| `id`          | `$eq`, `$ne`,`$in`, `$nin`                                            | Sortable |
| `createdDate` | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`  | Sortable |
| `updatedDate` | `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$nin`, `$exists`  | Sortable |
