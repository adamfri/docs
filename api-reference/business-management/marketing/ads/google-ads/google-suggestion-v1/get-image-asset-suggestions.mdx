    </Info>

    Retrieves AI-generated image assets for a Performance Max campaign using Runway AI.
    Generated images are automatically uploaded to the site's Wix Media Manager.
    Responses may take up to 60 seconds. `suggestionInfo.landingPageUrl` is required.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/image-asset-suggestions
    ```

    ## Body Params

    <ParamField body="suggestionInfo" type="AssetSuggestionInfo" required>

      Landing page URL and optional targeting context for image asset generation.

      <Expandable title="suggestionInfo properties">

        <ParamField body="landingPageUrl" type="string" required>

          Public URL of the campaign landing page, used to analyze content for asset generation.

        </ParamField>

        <ParamField body="assetTypes" type="string[]">

          Specific asset types to generate. Must correspond to the requested kind of asset (text or image).
          When omitted or empty, all supported types for the request are returned.
          Supported text types: HEADLINE, LONG_HEADLINE, DESCRIPTION.
          Supported image types: MARKETING_IMAGE, SQUARE_MARKETING_IMAGE, LOGO.

          Constraints: `maxItems 5`.

          **Supported values:**

          - `HEADLINE` — Short headline shown in ads. At least 3 required; up to 15 allowed. Maximum 30 characters.
          - `LONG_HEADLINE` — Longer headline used in certain ad formats. Exactly 1 required. Maximum 90 characters.
          - `DESCRIPTION` — Description shown below the headline. At least 2 required; up to 4 allowed. Maximum 90 characters.
          - `BUSINESS_NAME` — Business name shown in the ad. Exactly 1 required. Maximum 25 characters.
          - `MARKETING_IMAGE` — Landscape marketing image with a 1.91:1 aspect ratio (e.g. 1200x628). Multiple images allowed.
          - `SQUARE_MARKETING_IMAGE` — Square marketing image with a 1:1 aspect ratio (e.g. 1200x1200). Multiple images allowed.
          - `LOGO` — Square logo with a 1:1 aspect ratio (e.g. 1200x1200). A transparent background is recommended.
          - `PORTRAIT_MARKETING_IMAGE` — Portrait marketing image with a 4:5 aspect ratio (e.g. 960x1200). Multiple images allowed.
          - `LANDSCAPE_LOGO` — Landscape logo with a 4:1 aspect ratio (e.g. 1200x300).
          - `CALL_TO_ACTION_SELECTION` — Call-to-action button label. Select a value from CallToActionType. Optional.
          - `YOUTUBE_VIDEO` — YouTube video asset identified by an 11-character video ID. 1 to 5 videos recommended.
          - `MEDIA_BUNDLE` — HTML5 media bundle (ZIP file). Mutate-only in Google Ads.

        </ParamField>

        <ParamField body="searchThemes" type="string[]">

          Search themes used in the campaign's targeting, provided as context for more relevant suggestions.

          Constraints: `maxLength 1000`, `maxItems 25`.

        </ParamField>

        <ParamField body="userPrompt" type="string">

          Optional free-form instructions for refining the generated asset content.

        </ParamField>

        <ParamField body="provider" type="string">

          Provider to use for asset generation. Defaults to GOOGLE with WIX as fallback.

          **Supported values:**

          - `GOOGLE` — Google Ads Asset Generation API.
          - `WIX` — Wix in-house asset generation (Runway AI for images).

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="imageSuggestionInfo" type="ImageSuggestionInfo">

      Ad content (headlines, descriptions) used as context for image generation.

      <Expandable title="imageSuggestionInfo properties">

        <ParamField body="adContent" type="PerformanceMaxAdContent">

          Existing text ad content for the Performance Max campaign, used as context for image generation.

          <Expandable title="adContent properties">

            <ParamField body="headlines" type="HeadlineTextAsset[]">

              Short headline text assets for the campaign.

              Constraints: `maxItems 100`.

              _Nested structure omitted for brevity — see the `HeadlineTextAsset[]` object._

            </ParamField>

            <ParamField body="longHeadlines" type="LongHeadlineTextAsset[]">

              Long headline text assets for the campaign.

              Constraints: `maxItems 100`.

              _Nested structure omitted for brevity — see the `LongHeadlineTextAsset[]` object._

            </ParamField>

            <ParamField body="descriptions" type="DescriptionTextAsset[]">

              Description text assets for the campaign.

              Constraints: `maxItems 100`.

              _Nested structure omitted for brevity — see the `DescriptionTextAsset[]` object._

            </ParamField>

            <ParamField body="businessName" type="BusinessNameTextAsset">

              Business name asset for the campaign.

              _Nested structure omitted for brevity — see the `BusinessNameTextAsset` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
