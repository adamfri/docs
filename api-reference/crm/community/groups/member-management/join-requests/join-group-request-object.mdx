To join a private group, a site member must submit a Join Request, which can be approved or rejected by an admin.
When the request is approved, the site member becomes a group member.

<Tabs>

  <Tab title="REST">

    <ResponseField name="siteMemberId" type="string">

      Member ID. See the Members API for more details.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Contact ID. See the Contacts API for more details.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Join group request status.

      **Supported values:**

      - `PENDING` — Pending group request.
      - `APPROVED` — Approved group request.
      - `REJECTED` — Rejected group request.
      - `CANCELED` — Canceled group request.

    </ResponseField>

    <ResponseField name="requestDetails" type="RequestDetails">

      Join group request details.

      <Expandable title="requestDetails properties">

        <ResponseField name="rejectionReason" type="string">

          Reason the request has been rejected.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
