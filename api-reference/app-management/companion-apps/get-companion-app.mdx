    Retrieves the companion app for the current site.

    Fails if the current site doesn't have a companion app.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DEV_CENTER.READ_COMPANION_APPS">DEV_CENTER.READ_COMPANION_APPS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/companion-apps
    ```

    ## Response Object

    <ResponseField name="companionApp" type="CompanionApp">

      Retrieved companion app.

      See the [Companion App Object](/api-reference/app-management/companion-apps/companion-app-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
