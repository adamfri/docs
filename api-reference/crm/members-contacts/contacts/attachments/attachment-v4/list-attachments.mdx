    Retrieves a list of attachments associated with a specified contact.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACT-ATTACHMENTS">Manage Contact Attachments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/attachments/{contactId}
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      Contact ID for the attachments to be listed.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="Paging">

      Allow paginating, default: limit = 100 and offset = 0

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to return.

          Default: `100`
          Max: `100`

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="attachments" type="ContactAttachment[]">

      List of attachments for the specified contact.

      See the [Attachment Object](/api-reference/crm/members-contacts/contacts/attachments/attachment-v4/attachment-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Metadata for the paginated results.

          Offset that was requested.

        </ResponseField>

        </ResponseField>

      </Expandable>

    </ResponseField>
