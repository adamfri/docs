    Updates a brand.

    Each time the brand is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the brand.
    This ensures you're working with the latest brand and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.BRAND_WRITE">Brand write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v3/brands/{brand.id}
    ```

    ## Path Params

    <ParamField path="brand.id" type="string" required>

      Brand ID.

    </ParamField>

    ## Body Params

    <ParamField body="brand" type="Brand" required>

      Brand to update.

      See the [Brand Object](/api-reference/business-solutions/stores/catalog-v3/brands-v3/brand-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT`

    </ParamField>

    ## Response Object

    <ResponseField name="brand" type="Brand">

      Updated brand.

      See the [Brand Object](/api-reference/business-solutions/stores/catalog-v3/brands-v3/brand-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers
