    Reserves tickets for 20 minutes.

    Reserved tickets are deducted from ticket stock and can't be bought by another site visitor.
    When the reservation expires, the tickets are added back to the stock.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.EVENTS-CHECKOUT">Events Checkout</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/checkout/reservations
    ```
