  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates the `robots.txt` file entity.

    The content can be set to an empty string to create a blank file.

    To restore Wix's default content, set the `default` field to `true` and omit the `content` field.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/promote-seo-robots-server/v2/robots
    ```

    ## Body Params

    <ParamField body="robotsTxt" type="RobotsTxt">

      `robots.txt` file to update.

      See the [Robots Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/robots-txt/robots-txt-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="robotsTxt" type="RobotsTxt">

      Updated `robots.txt` file.

      See the [Robots Txt Object](/api-reference/business-management/marketing/seo/txt-file-server/robots-txt/robots-txt-object) for this object's fields.

    </ResponseField>

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X PUT https://www.wixapis.com/promote-seo-txt-file-server/v2/robots \
          -H 'Content-Type: application/json;charset=UTF-8' \
          -H 'Authorization: <AUTH>' \
          -d '{
              "robotsTxt": {
                  "content": "User-agent: *\nDisallow: /internals/\nAllow: /",
                  "default": false,
                  "subdomain": "www"
              }
          }'
      ```

      ```json Response
      {
          "robotsTxt": {
              "content": "User-agent: *\nDisallow: /internals/\nAllow: /",
      ```
