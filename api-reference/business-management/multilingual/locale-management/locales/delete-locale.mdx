<span className="wix-method wix-method-delete">DELETE</span>

<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a locale by ID.

    This method removes only secondary locales from a site. You can't call this method to delete the primary locale or a locale that's set as the visitor primary locale.

    <Warning>

    Deleting a locale permanently removes it and all its associated data from the site.

    </Warning>

    <Tip>

    - To change the primary locale, call Create New Primary Locale. This method automatically deletes the original primary locale and transfers its data to the new primary locale.
    - To delete a locale that's set as the visitor primary locale, first call Set Visitor Primary Locale to change the visitor primary locale, then call this method.

    </Tip>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/locales/v2/locale/{localeId}
    ```

    ## Path Params

    <ParamField path="localeId" type="string" required>

      ID of the locale to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteLocaleResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Locale Deleted | `wix.multilingual.locales.v2.locale_deleted` | Triggered when a locale is deleted. |

    </div>
