    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.EXTERNAL-DATABASE-CONNECTIONS-MANAGE">Manage External Database Connections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v1/external-database-connections/{name=**}
    ```

    ## Query Params

    <ParamField query="name" type="string" required>

      Name of the external database connection to retrieve.

      Constraints: `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="externalDatabaseConnection" type="ExternalDatabaseConnection">

      Details of the retrieved external database connection.

      See the [External Database Connection Object](/api-reference/business-solutions/cms/external-databases/external-database-connection/external-database-connection-object) for this object's fields.

    </ResponseField>

    ## Errors
