    <div className="wix-ref">

    Updates an existing schedule item.

    The changes are performed on a draft schedule item, even if the schedule item has already been published.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS-MEGA.MANAGE-EVENTS">Manage Events - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/schedule/draft/{itemId}
    ```

    ## Path Params

    <ParamField path="itemId" type="string" required>

      Schedule item ID to update.

    </ParamField>

    ## Body Params

    <ParamField body="eventId" type="string" required>

      Event ID to which the schedule item belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="item" type="ScheduleItemData">

      Schedule item info.

      <Expandable title="item properties">

        <ParamField body="hidden" type="boolean">

          Whether the schedule item is hidden from guests.

        </ParamField>

        <ParamField body="name" type="string">

          Schedule item name.

          Constraints: `maxLength 120`.

        </ParamField>

        <ParamField body="timeSlot" type="TimeInterval">

          Time slot of a schedule item.

          <Expandable title="timeSlot properties">

            <ParamField body="start" type="datetime">

              Start of the time slot interval, inclusive.

            </ParamField>

            <ParamField body="end" type="datetime">

              End of the time slot interval, exclusive.

            </ParamField>

            <ParamField body="timeZoneId" type="string">

              Time zone ID in TZ database format, e.g., `"EST"`, `"America/Los_Angeles"`.
              Defaults to `"Etc/UTC"` when not set.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="description" type="string">

          Rich text schedule item description.

          Constraints: `maxLength 10000`.

        </ParamField>

        <ParamField body="stageName" type="string">

          Stage or room name in which a session takes place.

          Constraints: `maxLength 30`.

        </ParamField>

        <ParamField body="tags" type="string[]">

          Schedule item tags. Used to organize the items by a theme.

          Constraints: `minLength 1`, `maxLength 30`, `maxItems 5`.

        </ParamField>

        <ParamField body="status" type="string">

          Schedule item status.

          **Supported values:**

          - `SCHEDULED` — Item is scheduled for a future date.
          - `CANCELED` — Item is canceled.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fields" type="FieldMask">

      Set of field paths to update.
      When fields are empty, request is interpreted as full update.
      Behavior follows [google.protobuf.FieldMask](https://developers.google.com/protocol-buffers/docs/reference/google.protobuf#google.protobuf.FieldMask) semantics.

      <Expandable title="fields properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>
