    Updates a promotion.

    Each time the promotion is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the promotion.
    This ensures you're working with the latest promotion and prevents unintended overwrites.

    To update multiple promotions in a single API call, call [Bulk Update Promotions](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/promotions-v3/bulk-update-promotions).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_WRITE">Manage v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v3/promotions/{promotion.id}
    ```

    ## Path Params

    <ParamField path="promotion.id" type="string" required>

      Promotion ID.

    </ParamField>

    ## Body Params

    <ParamField body="promotion" type="Promotion" required>

      Promotion to update, may be partial.

      See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="promotion" type="Promotion">

      Updated promotion.

      See the [Promotion Object](/api-reference/business-solutions/stores/catalog-v3/promotions-v3/promotion-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MEDIA_NOT_FOUND` | Couldn't find the media in Media Manager. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_CATEGORY_ASSIGNMENT` | A category is assigned to the same promotion more than once. |
    | `400` | `INVALID_ARGUMENT` | `MEDIA_REMOVAL_NOT_ALLOWED` | Media can't be removed from a promotion. It can only be replaced. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
