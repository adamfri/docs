    Updates multiple question entries.

    Each time a question entry is updated, its `revision` increments by 1.
    The current `revision` must be specified when updating the question entry.
    This ensures you're working with the latest version of a question entry and prevents unintended overwrites.

    To update a single question entry, call the Update Question Entry method.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/faq/question-entry/v2/bulk/question-entries/update
    ```

    ## Body Params

    <ParamField body="questionEntries" type="MaskedQuestionEntry[]">

      Question entries to update with their respective field masks.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="questionEntries properties">

        <ParamField body="questionEntry" type="QuestionEntry" required>

          Question entry to update.

          See the [Question Entry Object](/api-reference/business-management/faq-app/question-entry-v2/question-entry-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnFullEntity" type="boolean">

      Whether to include the full updated question entries in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkUpdateQuestionEntryResult[]">

      Results for each question entry update operation.

      Constraints: `maxItems 100`.

        <ResponseField name="questionEntry" type="QuestionEntry">

        </ResponseField>
