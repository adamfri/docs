<Tabs>

  <Tab title="REST">

    Updates a chat settings entity.

    Changes take effect immediately for new interactive form sessions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/forms/ai/v1/chat-settings/{chatSettings.id}
    ```

    ## Path Params

    <ParamField path="chatSettings.id" type="string" required>

      The ID of the chat settings. The chat settings specified in this object apply to the form with a matching ID.

    </ParamField>

    ## Body Params

    <ParamField body="chatSettings" type="ChatSettings" required>

      Chat settings to be updated.

      See the [Chat Settings Object](/api-reference/crm/forms/chat-settings/chat-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="chatSettings" type="ChatSettings">

      Updated chat settings.

      See the [Chat Settings Object](/api-reference/crm/forms/chat-settings/chat-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      The ID of the chat settings. The chat settings specified in this object apply to the form with a matching ID.

      **Read-only.** Constraints: `format GUID`.

    </ParamField>

    <ParamField body="chatSettings" type="UpdateChatSettings" required>

      Chat settings to be updated.

      <Expandable title="chatSettings properties">

        <ParamField body="_id" type="string">

          The ID of the chat settings. The chat settings specified in this object apply to the form with a matching ID.

          **Read-only.** Constraints: `format GUID`.

        </ParamField>

        <ParamField body="greetingMessage" type="string">

          Custom greeting message displayed when a visitor opens the AI chat.

        </ParamField>

        <ParamField body="chatEnabled" type="boolean">

          Whether AI chat is enabled for this form.

          Default: `true`

        </ParamField>

        <ParamField body="revision" type="integer">

          Revision number, which increments by 1 each time the chat settings are updated.
          To prevent conflicting changes, the current revision must be passed when updating the chat settings.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the chat settings were created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the chat settings were last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="summaryMessage" type="string">

          Message that summarizes the contents of the form. Appears after the greeting message.

        </ParamField>

        <ParamField body="extendedFields" type="ExtendedFields">

          Extended fields.

          <Expandable title="extendedFields properties">

            <ParamField body="namespaces" type="object">

              Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
              The value of each key is structured according to the schema defined when the extended fields were configured.

              You can only access fields for which you have the appropriate permissions.

              Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

              Constraints: `format map`.

              _Nested structure omitted for brevity — see the `object` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="manualSummary" type="boolean">

          Whether the summary message is manually set or AI-generated.
          When `false` the summary message is automatically generated by AI when the chat settings are saved.
          When `true`, the summary message can be manually set and won't be overwritten by AI.

          Default: `false`

        </ParamField>

        <ParamField body="personality" type="string">

          Personality of the AI when interacting with visitors.
          Defines the communication style of the AI chat responses.

          **Supported values:**

          - `PROFESSIONAL`
          - `FRIENDLY`
          - `PLAYFUL`
          - `DIRECT`

        </ParamField>

      </Expandable>

    </ParamField>
