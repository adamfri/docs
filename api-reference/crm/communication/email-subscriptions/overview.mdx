## SDK package

```bash
npm install @wix/email-subscriptions
```

Import the `emailSubscriptions` namespace from `@wix/email-subscriptions`.

  <Card title="Upsert Email Subscription" href="/api-reference/crm/communication/email-subscriptions/upsert-email-subscription">
