Triggered when a media item in a specified gallery is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pro_gallery.gallery_v2_gallery_item_created` |
| Package | `@wix/pro-gallery` |
| Permissions | `Manage Galleries`, `Read Galleries` |

## Examples

      // handle your event here
