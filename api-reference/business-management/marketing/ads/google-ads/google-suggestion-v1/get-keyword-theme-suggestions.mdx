    </Info>

    Retrieves keyword theme suggestions for a site based on its URL, language, and optional business info.
    Calls the Google Ads API directly. Use the returned themes to populate keyword targeting when creating a Smart campaign.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/keyword-theme-suggestions
    ```

    ## Body Params

    <ParamField body="suggestionInfo" type="SuggestionInfo">

      Site and campaign context used to generate keyword theme suggestions.

      <Expandable title="suggestionInfo properties">

        <ParamField body="liveSiteUrl" type="string">

          Public URL of the site. Google uses this to analyze business content and generate relevant suggestions.

          Constraints: `format WEB_URL`.

        </ParamField>

        <ParamField body="languageCode" type="string">

          BCP-47 language code specifying the language for the campaign and its suggestions.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="keywordThemes" type="KeywordThemes">

          Optional seed keyword themes used to guide the suggestion results.

          <Expandable title="keywordThemes properties">

            <ParamField body="keywordThemes" type="KeywordTheme[]">

            </ParamField>

        </ParamField>

          Optional override for the business name detected from the site URL.

        </ParamField>

        <ParamField body="adSchedule" type="WeeklyAdSchedule">

          Weekly schedule controlling which days and times ads are eligible to show.

          <Expandable title="adSchedule properties">
