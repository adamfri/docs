Triggered when a category is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.bookings.categories.v2.category_created` |
| Package | `@wix/bookings` |
| Permissions | `Read Bookings - Public Data`, `Manage Bookings Services and Settings`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions` |
