&nbsp;

The Currencies API is used to convert from one currency to another and get exchange rates.

 Currency rates are provided by [XE](fallback::https://www.xe.com/company/) and update on a daily basis. Rates are provided together with the timestamp when they were set. By using the Currencies API you agree to XE's [Terms of Use](fallback::https://www.xe.com/en/legal/dfs.php).

 With the Currencies API you can: 

- [Retrieve a list](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/currency-converter/list-currencies) of all the convertible currencies.
- [Convert amounts](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/currency-converter/convert-currency) between 2 currencies.
- [Retrieve the current conversion rate](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/currency-converter/get-conversion-rate) for a pair of currencies.  

## Before you begin

+ To use the Currencies API a site must be upgraded to a [Premium Plan](fallback::https://support.wix.com/en/article/upgrading-your-site-to-premium-3066683). 

+ The currency converter changes the displayed prices on a site for different currencies but doesn't change the payment currency. The payment is always made in the [currency set in a site's Dashboard](fallback::https://support.wix.com/en/article/setting-your-currency-for-accepting-payments).

+ The currency codes used must exist in the array of supported currencies returned by [List Currencies](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/currency-converter/list-currencies).

## Terminology

+ **XE**. A [currency converter provider](fallback::https://www.xe.com/company/) that the Currencies API uses. 
+ **Currency code**: A 3-letter [ISO-4217](fallback::https://en.wikipedia.org/wiki/ISO_4217) code representing each currency.
