A way to pay online or offline for goods or services offered by a specific site.

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Payment method type ID.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="legacyId" type="string">

      Value used buy some legacy APIs to refer to this payment method type. Can be empty.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Payment method type display name, based on locale.

      Used by Wix when displaying the payment method type, such as in the payment settings page for merchants, or the checkout page for buyers.

      Define your locale by specifying a `countryCode` and `languageCode` when calling `Get Payment Method Type` or `List Payment Method Types`.
      For more detailed information, see the descriptions for the `countryCode` and `languageCode` parameters for those methods.

    </ResponseField>

    <ResponseField name="description" type="string">

    <ResponseField name="merchantFlow" type="MerchantFlow">

      Settings that determine if and how to display this payment method type in the merchant flow. The merchant flow is the process a merchant goes through to configure which payment method types they accept on their site.

      <Expandable title="merchantFlow properties">

        <ResponseField name="icons" type="Icon[]">

          Details about the icons to display for this payment method type on the merchant's Accept Payments page in the site dashboard. Icons are localized according to the locale of the call.

          Define a locale by specifying a `countryCode` and `languageCode` when calling `Get Payment Method Type` or `List Payment Method Types`.
          For more detailed information, see the method descriptions.

          Constraints: `maxItems 200`.

          <Expandable title="icons properties">

            <ResponseField name="image" type="Image">

              Icon image.

              <Expandable title="image properties">

                <ResponseField name="id" type="string">

                  WixMedia image ID.

                  Constraints: `format GUID`.

                </ResponseField>

                <ResponseField name="url" type="string">

                  Image URL.

                  Constraints: `format WEB_URL`.

                </ResponseField>

                <ResponseField name="height" type="integer">

                  Original image height.

                  **Read-only.**

                </ResponseField>

                <ResponseField name="width" type="integer">

                  Original image width.

                  **Read-only.**

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="tag" type="string">

              Icon tag. Payment method types can have multiple icons, and tags are used to differentiate between them.
              For example, the UI design for multiple payment method types is upgraded, and now they each have an old icon tagged "v1" and a new icon tagged "v2". Developers can then easily choose to display all the original "v1" style of icons, or all the new "v2" style.

            </ResponseField>

            <ResponseField name="format" type="string">

              Icon image format.

              **Supported values:**

              - `SVG`
              - `PNG`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="priority" type="integer">

          Priority given to this payment method type in the list shown to the merchant.
          A lower value relative to other payment method types means a higher position on the list.

          Constraints: `min 1`, `max 10000`.

        </ResponseField>

        <ResponseField name="promoted" type="boolean">

          Whether the payment method type is promoted. Promoted payment method types are displayed more prominently on the Accept Payments page.

        </ResponseField>

        <ResponseField name="hidden" type="boolean">

          Whether the merchant cannot choose to accept payments from this payment method type.

        </ResponseField>

        <ResponseField name="countryRestricted" type="boolean">

          Indicates that payment method type is restricted in provided country.

        </ResponseField>

      </Expandable>

    </ResponseField>

        <ResponseField name="priority" type="integer">

          The priority given to this payment method type in the list of payment method types shown to the buyer.
          A lower value relative to other payment method types means a higher position on the list.

          Constraints: `min 1`, `max 10000`.

        </ResponseField>

        <ResponseField name="hidden" type="boolean">

          Whether the merchant cannot choose to accept payments from this payment method type.

        </ResponseField>

        <ResponseField name="countryRestricted" type="boolean">

          Indicates that payment method type is restricted in provided country.

        </ResponseField>

        <ResponseField name="minPaymentAmount" type="string">

          Minimum payment amount that can be made with this payment method type.
          If the request omits `currencyCode`, the field is not set because its value depends on the currency.

        </ResponseField>

        <ResponseField name="maxPaymentAmount" type="string">

          Maximum payment amount that can be made with this payment method type.
          If the request omits `currencyCode`, the field is not set because its value depends on the currency.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="brandOnly" type="boolean">

      Whether this payment method type is only used to represent a supported payment brand for another payment method type.

      For example, a Visa payment method is used to indicate that Visa can be used for credit card transactions. But the Visa payment method type is not used to accept payments. Instead, the credit card payment method type is used.

      Brand-only payment method types cannot be used to accept payments, and are not listed as a payment method type in a site's dashboard.

    </ResponseField>

    <ResponseField name="inPerson" type="boolean">

      Whether the payment method type can only be used for in-person payments, such as cash, point-of-sale payments, and card readers.

    </ResponseField>

    <ResponseField name="transactionExpirationDelayInSeconds" type="integer">

      Time (in seconds after which a transaction is marked as expired if it is not completed.

      Max: `15552000` (180 days)

    </ResponseField>

    <ResponseField name="currencyRestricted" type="boolean">

      Indicates that payment method type is restricted for the provided `currencyCode`.

    </ResponseField>

    <ResponseField name="currencyRestrictionEnabled" type="boolean">

      Indicates the payment method type has currency restriction and it is enabled.

    </ResponseField>

    <ResponseField name="allowedCurrencyCodes" type="string[]">

      Allowed currencies

      Constraints: `format CURRENCY`, `minItems 0`, `maxItems 100`.

    </ResponseField>

    <ResponseField name="paymentBrands" type="PaymentBrand[]">

      List of supported payment brands.
      These brands are represented by other site payment method types.
      The purpose of this list is to support the display of the brands' icons next to the payment method type.

      Constraints: `minItems 0`, `maxItems 100`.

      <Expandable title="paymentBrands properties">

        <ResponseField name="paymentBrandId" type="string">

          ID of a payment method type representing a payment brand.

          Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

    </ResponseField>
