Triggered when a media item in a specified gallery is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pro_gallery.gallery_v2_gallery_item_updated` |
| Package | `@wix/pro-gallery` |
| Permissions | `Manage Galleries`, `Read Galleries` |
