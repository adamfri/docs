    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-IDENTITY.MANAGE-CONTRIBUTORS">Manage Contributors</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invites/site-invite/{inviteId}/resend
    ```

    ## Path Params

    <ParamField path="inviteId" type="string" required>

      Invite ID.

    </ParamField>

    ## Body Params

    <ParamField body="defaultEmailLanguage" type="string">

      Language of emails to send. Relevant only for recipients that don't currently have a Wix user ID. Default: Site owner's language.

    </ParamField>
