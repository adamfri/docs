    <div className="wix-ref">

    Reports multiple events at once, activating site automations configured with the specified trigger key.

    Each event in `eventsInfo` is processed independently and asynchronously, so some events can succeed while others fail. Check `bulkActionMetadata` for the success and failure totals.

    To report a single event, call [Report Event](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/triggered-events/report-event).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/automations/v1/events/bulk-report
    ```

    ## Body Params

    <ParamField body="triggerKey" type="string" required>

      Trigger key as defined in your app's trigger configuration
      in the app dashboard.
      For example, `form_submitted` or `invoice_due`.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="eventsInfo" type="EventInfo[]" required>

      Repeated list of event details for bulk reporting.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="eventsInfo properties">

        <ParamField body="payload" type="object">

          Event payload, formatted as key:value pairs.
          Must comply with the payload schema
          if you provided one when configuring your trigger.

        </ParamField>

        <ParamField body="externalEntityId" type="string">

          ID of the related resource in GUID format.

        </ParamField>

        <ParamField body="idempotency" type="Idempotency">

          Idempotency information for the event.

          <Expandable title="idempotency properties">

            <ParamField body="key" type="string">

              A unique identifier for the event.
              If you send the same idempotency key in multiple report event requests, for the same trigger key and app id,
              consecutive requests will be ignored after the first one. Note that the idempotency key is kept for a week before it expires.

              Constraints: `minLength 1`, `maxLength 80`.

            </ParamField>

            <ParamField body="ttlInMilliseconds" type="integer">

              Optional. The time to live (TTL) in milliseconds before the key will expire. Default is a week.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="triggerKey" type="string">

      Trigger key associated with the event.

      Constraints: `minLength 1`, `maxLength 100`.

    </ResponseField>

    <ResponseField name="results" type="BulkReportEventResult[]">

      <Expandable title="results properties">

            </ResponseField>

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="eventInfo" type="EventInfo">

          Event details for the item in the request.

          <Expandable title="eventInfo properties">

            <ResponseField name="payload" type="object">

              Event payload, formatted as key:value pairs.
              Must comply with the payload schema

            </ResponseField>

            <ResponseField name="externalEntityId" type="string">

              ID of the related resource in GUID format.

            </ResponseField>

            <ResponseField name="idempotency" type="Idempotency">

              Idempotency information for the event.

              _Nested structure omitted for brevity — see the `Idempotency` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="activationIds" type="string[]" deprecated>

          The activation IDs of triggered ReportEvents.
          Deprecated: This field is being removed. Activation IDs are no longer returned in bulk operations.
          Will be removed on 2026-06-30.

          **Deprecated.** Removal: 2026-06-30. Constraints: `format GUID`, `maxItems 100`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata for the overall bulk action, including success and failure counts.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>
