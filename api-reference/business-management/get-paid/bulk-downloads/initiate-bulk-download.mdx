    Initiates a bulk download process.

    The process creates a .zip file containing the requested files. The .zip file is available for download using the `downloadUrl` in the `bulkDownload` response.
    The `downloadUrl` is available for 24 hours after the process begins.
    Downloads creation is limited per user up to 10 at once.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/get-paid/v1/bulk-downloads
    ```

    ## Body Params

    <ParamField body="bulkDownload" type="BulkDownload" required>

      Bulk download to initiate.

      See the [Bulk Download Object](/api-reference/business-management/get-paid/bulk-downloads/bulk-download-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="bulkDownload" type="BulkDownload">

      The initiated bulk download.

      See the [Bulk Download Object](/api-reference/business-management/get-paid/bulk-downloads/bulk-download-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `PERMISSION_DENIED` | Caller doesn't have permissions. |
    | `404` | `NOT_FOUND` | `USER_ID_NOT_FOUND` | User identification ID is missing. |
    | `400` | `INVALID_ARGUMENT` | `NAMESPACE_NOT_SUPPORTED` | Calling this method with this namespace isn't supported. |
    | `428` | `FAILED_PRECONDITION` | `BULK_DOWNLOAD_LIMIT_REACHED` | User has reached the limit of maximum bulk downloads. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
