    Retrieves a GPV payout by ID.

    Reads are scoped to the caller's partner account.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/revshare/v1/gpv-payouts/{gpvPayoutId}
    ```

    ## Path Params

    <ParamField path="gpvPayoutId" type="string" required>

      ID of the GpvPayout to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="gpvPayout" type="GpvPayout">

      The requested GpvPayout.

      See the [Gpv Payout Object](/api-reference/account-level/studio-workspace/earnings/gpv-payout-v1/gpv-payout-object) for this object's fields.

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
