    Retrieves the [service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/introduction) associated with a booking using an anonymous token.

    This method doesn't require standard authentication. Pass a token generated by [Get Anonymous Action Token](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/get-anonymous-action-token) instead.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/anonymous-bookings/{token}/service
    ```

    ## Path Params

    <ParamField path="token" type="string" required>

      Anonymous token for the booking.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Additional fields to return.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `STAFF_MEMBER_DETAILS` — When passed, `service.staffMemberDetails` is returned.
      - `RESOURCE_TYPE_DETAILS` — When passed, `service.serviceResources.resourceType.name` is returned.
      - `DISCOUNT_INFO_DETAILS` — When passed, `service.payment.discountInfo` is returned.

    </ParamField>
