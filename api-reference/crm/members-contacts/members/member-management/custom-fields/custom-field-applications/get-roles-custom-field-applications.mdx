    Retrieves a list of fields that are applied to specified roles.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/custom-fields-applications/roles
    ```

    ## Body Params

    <ParamField body="roleIds" type="string[]" required>

      IDs of roles with custom field applications to retrieve.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="RoleCustomFieldApplication[]">

      Retrieved list of custom field applications.

      <Expandable title="results properties">

        <ResponseField name="roleId" type="string">

          Role ID.

        </ResponseField>

        <ResponseField name="applications" type="FieldApplication[]">

          Custom field applications for the role.

          <Expandable title="applications properties">

            <ResponseField name="customFieldKey" type="string">

              Custom field key.

              **Read-only.**

            </ResponseField>

            <ResponseField name="applies" type="boolean">

              Whether the custom field applies to the member.

            </ResponseField>

            <ResponseField name="customField" type="CustomField">

              Custom field details.

              _Nested structure omitted for brevity — see the `CustomField` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
