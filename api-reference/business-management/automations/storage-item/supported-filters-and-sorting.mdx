The following table shows field support for filters and sorting
for the StorageItem object:

| Field           | Supported Filters                             | Sortable |
| --------------- | --------------------------------------------- | -------- |
| `id`            | `$eq`, `$ne`, `$in`                           | Sortable |
| `key`           | `$eq`, `$ne`, `$in`                           | Sortable |
| `displayName`   | `$eq`, `$ne`, `$in`                           | Sortable |
| `description`   | `$eq`, `$ne`, `$in`                           | Sortable |
| `type`          | `$eq`, `$ne`, `$in`                           | Sortable |
| `createdDate`   | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte`    | Sortable |
| `updatedDate`   | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte`    | Sortable |
