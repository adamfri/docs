    Accepts an invitation to join a program.

    Changes `status` from `INVITED` to `APPROVED`. Returns an error if the join application has any other status, or if it doesn't exist.

    For a free program, a participant is created automatically and `participantId` is populated. If the program requires payment, call [Prepare Payment](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/prepare-payment) to start the payment flow.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}/accept-invite
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to accept.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Accepted join application.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVALID_JOIN_APPLICATION_STATUS` | The join application isn't in `INVITED` status, which accepting an invitation requires. |
    | `428` | `FAILED_PRECONDITION` | `PREMIUM_PLAN_REQUIRED` | The site needs a Premium plan to add more participants. |
    | `428` | `FAILED_PRECONDITION` | `PARTICIPANTS_LIMIT_EXCEEDED` | The program's participant limit has been reached. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Join Application Updated | `wix.online_programs.participants.v3.join_application_updated` | Triggered when a join application is updated. |
    | Join Application Status Changed | `wix.online_programs.participants.v3.join_application_status_changed` | Triggered when a join application's `status` changes. |
