    Creates a question entry with the provided details including question text, answer content, and category assignment.
    The question entry must be assigned to an existing category and can optionally include labels for additional organization.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/faq/v2/question-entries
    ```

    ## Body Params

    <ParamField body="questionEntry" type="QuestionEntry" required>

      Question entry to create.

      See the [Question Entry Object](/api-reference/business-management/faq-app/question-entry-v2/question-entry-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="questionEntry" type="QuestionEntry">

      Created question entry.

      See the [Question Entry Object](/api-reference/business-management/faq-app/question-entry-v2/question-entry-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
