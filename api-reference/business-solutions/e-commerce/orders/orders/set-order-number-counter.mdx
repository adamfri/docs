    Sets the starting number for orders created after a migration.

    After importing historical orders, call Set Order Number Counter to define the number Wix assigns to the next order created through the regular order flow. This lets a merchant continue their existing numbering sequence after moving to Wix, without gaps or overlaps with the imported orders.

    The counter applies only to orders created after this call. Imported orders keep the `number` provided when they're imported.

    By default, the new counter must be higher than the current one. To set a lower value, for example after deleting imported orders and re-importing from scratch, set `allowLowerCounter` to `true`. Setting a lower counter can result in duplicate order numbers.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.IMPORT-ORDERS">SCOPE.ECOM.IMPORT-ORDERS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/orders/import/set-order-number-counter
    ```

    ## Body Params

    <ParamField body="counter" type="string" required>

      Starting number for orders created after this call. The next order gets this number, and each subsequent order increments by 1.

      Constraints: `min 0`, `max 999999999`.

    </ParamField>

    <ParamField body="allowLowerCounter" type="boolean">

      Whether to allow setting a counter lower than the current value. A lower counter can result in duplicate order numbers.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="oldCounter" type="string">

      Order number counter before the update.

    </ResponseField>

    <ResponseField name="newCounter" type="string">

      Order number counter after the update.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_SET_LOWER_ORDER_NUMBER_COUNTER` | The provided `counter` is lower than the current order number counter and `allow_lower_counter` is false. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
