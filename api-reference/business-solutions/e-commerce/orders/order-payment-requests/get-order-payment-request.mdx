    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/order-payment-requests/{orderPaymentRequestId}
    ```

    ## Path Params

    <ParamField path="orderPaymentRequestId" type="string" required>

      ID of the order payment request to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="orderPaymentRequest" type="OrderPaymentRequest">

      Retrieved order payment request.

      See the [Order Payment Request Object](/api-reference/business-solutions/e-commerce/orders/order-payment-requests/order-payment-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_PAYMENT_REQUEST_NOT_FOUND` | Couldn't find the order payment request. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
