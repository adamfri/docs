    Creates multiple contacts in a single request. Works synchronously.

    When you provide an image URL for a contact, the image is uploaded in the background and the returned contact temporarily has no image. Once the upload succeeds, the contact's image is updated.

    To create a single contact, call [Create Contact](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/create-contact).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/bulk/contacts/create
    ```

    ## Body Params

    <ParamField body="contacts" type="Contact[]" required>

      Contacts to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to include the created contacts in the response.

    </ParamField>

    <ParamField body="allowDuplicates" type="boolean">

      Whether to create the contact even if it duplicates an existing contact.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkContactResult[]">

        </ResponseField>
