Form submission that was created or retrieved.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Submission ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="formId" type="string">

      ID of the form which the submission belongs to.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="namespace" type="string">

      The app which the form submissions belong to. For example, the namespace for the Wix Forms app is `wix.form_app.form`. Call `Get Submission` to retrieve the namespace.

      **Read-only.** Constraints: `minLength 10`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the submission.

      The status a submission is created with depends on the form's namespace and on whether the form collects payment, so read it from the response rather than assuming.

      A submission for a form that collects payment starts as `PAYMENT_WAITING`. Otherwise, most namespaces record the submission immediately as `CONFIRMED`. Namespaces that need to complete another step first, such as taking payment for a pricing plan, create the submission as `PENDING` and confirm it later with Confirm Submission.

      A `PENDING` submission isn't recorded yet, and is deleted automatically if it isn't confirmed in time.

      **Supported values:**

      - `PENDING` — A submission is created, but has not yet been recorded in the Wix Forms collection.
      - `CONFIRMED` — A submission is recorded in the Wix Forms collection.
      - `PAYMENT_WAITING` — A form submission requiring payment is created.
      - `PAYMENT_CANCELED` — An order of a form submission is canceled.

    </ResponseField>

    <ResponseField name="submissions" type="object">

      Values the visitor submitted.

      Each key is the `target` of a field in the form schema, which is the field's stable storage key rather than its ID or label. Only keys matching a field target are accepted.

      Each value's shape follows that field's `inputType`: `STRING` fields submit a string, `NUMBER` a number, `BOOLEAN` a boolean, and `ARRAY` an array of the selected option values. Date and time fields are strings.

      3 input types submit structured values: `ADDRESS` submits an address object, `PAYMENT` an array holding 1 product object per item bought, and `SCHEDULING` an appointment object.

      For the full mapping, see [About Submission Values](https://dev.wix.com/docs/api-reference/crm/forms/form-submissions/about-submission-values).

      Constraints: `format map`.

      <Expandable title="submissions properties">

        <ResponseField name="key" type="string" />

        <ResponseField name="value" type="any" />

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the form submission was created.

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the form submission was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the form submission is updated. To prevent conflicting changes, the existing revision must be used when updating a form submission.

      **Read-only.**

    </ResponseField>

    <ResponseField name="submitter" type="Submitter">

      ID of the visitor that submitted the form.

      **Read-only.**

      <Expandable title="One of the following">

        <ResponseField name="submitter" type="submitter">

          submitter

          <Expandable title="submitter properties">

            <ResponseField name="memberId" type="string">

              Member ID.

            </ResponseField>

            <ResponseField name="visitorId" type="string">

              Visitor ID.

            </ResponseField>

            <ResponseField name="applicationId" type="string">

              Application ID.

            </ResponseField>

            <ResponseField name="userId" type="string">

              User ID.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="seen" type="boolean">

      Whether a site owner marked a submission as "seen".

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Data extension object that holds users' and apps' fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="orderDetails" type="OrderDetails">

      Order details. &lt;br>
      &lt;b>Note&lt;/b>: This object is only applicable when submitting a form in the Wix Payments app.

      <Expandable title="orderDetails properties">

        <ResponseField name="orderId" type="string">

          ID of the order related to submission (only applicable if a form has payments).

          **Read-only.**

        </ResponseField>

        <ResponseField name="number" type="integer">

          Order number.

          **Read-only.**

        </ResponseField>

        <ResponseField name="currency" type="string">

          Currency.

          **Read-only.**

        </ResponseField>

        <ResponseField name="itemSubtotal" type="string">

          Item subtotal.

          **Read-only.** Constraints: `>= 0.00`.

        </ResponseField>

        <ResponseField name="checkoutId" type="string">

          ID of the checkout related to submission (only applicable if a form has payments).

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="contactId" type="string">

      Contact ID of a site visitor who created the submission.

    </ResponseField>

    <ResponseField name="accessRestriction" type="string">

      Authorized viewer ID.

    </ResponseField>

    <ResponseField name="tags" type="PublicTags">

      Tag IDs collections associated with the current entity.

      <Expandable title="tags properties">

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="appointmentDetails" type="AppointmentDetails">

      Appointment details.

        </ResponseField>

        <ResponseField name="staffMemberName" type="string">

        </ResponseField>

      </Expandable>

    </ResponseField>
