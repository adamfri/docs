    Updates a product. Supports partial updates.

    Provider info fields (`providerInfo.productId` and `providerInfo.productCreatedDate`) are immutable and cannot be
    changed after creation.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/suppliers-hub/v1/products/{product.id}
    ```

    ## Path Params

    <ParamField path="product.id" type="string" required>

      Product ID.

    </ParamField>

    ## Body Params

    <ParamField body="product" type="Product" required>

      Product to update. May be partial - only fields to be updated need to be provided.

      See the [Product Object](/api-reference/business-solutions/suppliers-hub/products/product-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="product" type="Product">

      Updated product.

      See the [Product Object](/api-reference/business-solutions/suppliers-hub/products/product-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | Event | Type | Description |
    | --- | --- | --- |
    | Product Updated | `wix.suppliershub.marketplace_product.v1.product_updated` | Triggered when a product is updated. |
