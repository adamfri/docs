    <div className="wix-ref">

    Creates a new discount rule.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/discount-rules
    ```

    ## Body Params

    <ParamField body="discountRule" type="DiscountRule" required>

      Discount rule info.

      See the [Discount Rule Object](/api-reference/business-solutions/e-commerce/extensions/discounts/discount-rules/discount-rule-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="discountRule" type="DiscountRule">

      Discount rule.

      See the [Discount Rule Object](/api-reference/business-solutions/e-commerce/extensions/discounts/discount-rules/discount-rule-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MAX_DISCOUNT_RULES_REACHED` | Number of discount rules exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `MAX_QUANTITY_BASED_DISCOUNTS_REACHED` | Number of quantity-based discounts exceeds the server's limit. |
    | `428` | `FAILED_PRECONDITION` | `MAX_CUSTOM_TRIGGER_APPS_EXCEEDED` | Number of distinct custom trigger apps across all discount rules exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_ACTIVE_TIME_RANGE` | `activeTimeInfo.start` must be before `activeTimeInfo.end`. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_EMPTY_DISCOUNT` | Each discount value must be defined. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_DISCOUNT_TYPE` | `discountType` must be defined. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_SUBTOTAL_RANGE` | At least one of the following fields must be defined: `SubtotalRange.from`, `SubtotalRange.to`. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_ITEM_QUANTITY_RANGE` | At least one of the following fields must be defined: `ItemQuantityRange.from`, `ItemQuantityRange.to`. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SUBTOTAL_RANGE` | `SubtotalRange.to` must be greater than `SubtotalRange.from`. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_ITEM_QUANTITY_RANGE` | `ItemQuantityRange.to` must be greater than `ItemQuantityRange.from`. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TARGET_TYPE_FIELD` | `targetType` can't be set to `UNDEFINED_TARGET`. |
    | `400` | `INVALID_ARGUMENT` | `OPERATOR_TOO_DEEPLY_NESTED` | Trigger nesting exceeded the allowed depth. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SCOPE_TYPE` | `scopeType` doesn't match the actual scope. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TRIGGER_TYPE` | `triggerType` doesn't match the actual trigger. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SETTINGS_SUBJECT_TYPE` | `settings.applies_to` must be defined. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CUSTOMER_BUY_CONDITION` | `buyXGetYInfo.customerBuy.condition` must be defined. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SCOPE` | Quantity-based discount must target specific items. `specificItemsInfo.scopes.catalogItemFilter.catalogItemIds` can't be empty. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
