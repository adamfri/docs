Retrieves a list of up to 100 collections, given the provided paging, sorting and filtering.
See [Stores Pagination](https://dev.wix.com/api/rest/wix-stores/pagination) for more information.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-STORES.READ-PRODUCTS">Read Products</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`, `MEMBER`, `VISITOR`.

## Endpoint

```http
POST https://www.wixapis.com/stores/v1/collections/query
```

## Body Params

<ParamField body="query" type="Query">

  Query options.

  <Expandable title="query properties">

    <ParamField body="paging" type="Paging">

      paging

      <Expandable title="paging properties">

        <ParamField body="limit" type="integer">

          Amount of items to load per page

        </ParamField>

        <ParamField body="offset" type="integer">

          Number of items to skip in the display (relevant for all pages after the first)

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="filter" type="string">

      Filter string

    </ParamField>

    <ParamField body="sort" type="string">

      Sort string

    </ParamField>

  </Expandable>

</ParamField>

<ParamField body="includeNumberOfProducts" type="boolean">

  Whether number of products should be included in the response.

</ParamField>

<ParamField body="includeDescription" type="boolean">

  Wether to include collection description in the response. When `false` is passed, `collection.description` will return null.

</ParamField>

## Response Object

<ResponseField name="collections" type="Collection[]">

  List of collections.

  <Expandable title="collections properties">

    <ResponseField name="id" type="string">

      Collection ID (generated automatically by the catalog).

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Collection name.

    </ResponseField>

    <ResponseField name="media" type="Media">

      Media items (images, videos etc) associated with this collection. Read only.

      **Read-only.**

      <Expandable title="media properties">

        <ResponseField name="mainMedia" type="MediaItem">

          Primary media (image, video etc) associated with this product.

          _Nested structure omitted for brevity — see the `MediaItem` object._

        </ResponseField>

        <ResponseField name="items" type="MediaItem[]">

          Media (images, videos etc) associated with this product.

          _Nested structure omitted for brevity — see the `MediaItem[]` object._

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="numberOfProducts" type="integer">

      Number of products in the collection. Read only.

      **Read-only.**

    </ResponseField>

    <ResponseField name="description" type="string">

      Collection description.

    </ResponseField>

    <ResponseField name="slug" type="string">

      Collection slug.

    </ResponseField>

    <ResponseField name="visible" type="boolean">

      Collection visibility. Only impacts dynamic pages, no impact on static pages. Default: `true`.

    </ResponseField>

  </Expandable>

</ResponseField>

<ResponseField name="metadata" type="PagingMetadata">

  Details on the paged set of results returned.

  <Expandable title="metadata properties">

    <ResponseField name="items" type="integer">

      Amount of items to load per page

    </ResponseField>

    <ResponseField name="offset" type="integer">

      Number of items to skip in the display (relevant for all pages after the first)

    </ResponseField>

  </Expandable>

</ResponseField>

<ResponseField name="totalResults" type="integer">

  Total number of results returned.

</ResponseField>
