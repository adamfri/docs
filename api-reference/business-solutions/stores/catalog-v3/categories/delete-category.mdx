    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a category.

    Deleting a category also deletes all of its subcategories. Items that were assigned to the deleted categories remain in the catalog but are no longer associated with those categories.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_WRITE">Category write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/categories/v1/categories/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      Category ID.

    </ParamField>

    ## Query Params

    <ParamField query="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField query="appNamespace" type="string">

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField query="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `DeleteCategoryResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `MANAGED_CATEGORY_OPERATION_NOT_ALLOWED` | Category is managed by a specific app. Only that app can delete this category or modify its items. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Category Deleted | `wix.categories.v1.category_deleted` | Triggered when a category is deleted. |

    </div>
