    Updates the cookie banner settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.COOKIE-CONSENT-BANNER.MANAGE">Manage Cookie Consent Banner</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wixpress/cookie-banner-settings/v1/cookie-banner-settings/update
    ```

    ## Body Params

    <ParamField body="settings" type="CookieBannerSettings">

      Cookie banner settings to update.

      See the [Cookie Banner Settings Object](/api-reference/business-management/cookie-consent-policy/cookie-banner-settings/cookie-banner-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="settings" type="CookieBannerSettings">

      Updated cookie banner settings.

      See the [Cookie Banner Settings Object](/api-reference/business-management/cookie-consent-policy/cookie-banner-settings/cookie-banner-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
