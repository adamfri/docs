    Creates a draft post.

    For 3rd-party apps, `memberId` is a required field.

    In `categoryIds`, only categories that already exist will be added to the draft post. Including
    `categoryIds` that do not exist will not return an error, but they will not be added to the `categoryIds` array.
    If some of the categories exist, those will be added while those that do not exist will not be added to `categoryIds`.
    You can check which categories are available with
    [List Categories](https://dev.wix.com/docs/rest/business-solutions/blog/category/list-categories).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/blog/v3/draft-posts
    ```

    ## Body Params

    <ParamField body="draftPost" type="DraftPost" required>

      Draft post to create.

      See the [Draft Object](/api-reference/business-solutions/blog/draft-posts/draft-object) for this object's fields.

    </ParamField>

    <ParamField body="publish" type="boolean">

      Whether the draft post should be published on creation.

      Default: `false`

    </ParamField>

    <ParamField body="fieldsets" type="string[]">

      List of additional draft post fields to include in the response. For example, use the `URL` fieldset to retrieve the url field in
      the response in addition to the draft post's base fields. Base fields don’t include any of the supported fieldset values. By default
      only the draft post's base fields are returned.

      Constraints: `maxItems 10`.

      **Supported values:**

      - `URL` — Includes draft post preview URL.
      - `CONTENT` — Includes content field.
      - `RICH_CONTENT` — Includes rich content field.
      - `GENERATED_EXCERPT` — If the user has not set excerpt, returns the one autogenerated from content.

    </ParamField>

    ## Response Object

    <ResponseField name="draftPost" type="DraftPost">

      Created draft post info.

      See the [Draft Object](/api-reference/business-solutions/blog/draft-posts/draft-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | --- | --- | --- |
    | Draft Post Created | `wix.blog.v3.draft_created` | Triggered when a draft post is created. |
