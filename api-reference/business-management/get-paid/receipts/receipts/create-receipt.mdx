    Creates a receipt.

    Receipt number is assigned later and will be provided in the Get Receipt response.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/receipts/v1/receipts
    ```

    ## Body Params

    <ParamField body="receipt" type="Receipt" required>

      Receipt to create.

      See the [Receipt Object](/api-reference/business-management/get-paid/receipts/receipts/receipt-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="receipt" type="Receipt">

      Created receipt.

      See the [Receipt Object](/api-reference/business-management/get-paid/receipts/receipts/receipt-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `APP_INSTALLATION_FAILED` | Receipt app failed to install. |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Site not found. |
    | `500` | `INTERNAL` | `RECEIPT_PRESET_NOT_FOUND` | Specified receipt preset not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Receipt Created | `wix.receipts.v1.receipt_created` | Triggered when a receipt is created. |

    </div>
