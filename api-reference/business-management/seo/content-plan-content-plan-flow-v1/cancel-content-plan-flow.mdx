    Cancels a content plan flow.

    Cancellation is permanent. A canceled flow can't be resumed or restarted,
    and the keyword research linked to it is canceled with it. To generate a
    content plan afterwards, call Trigger Content Plan Generation Flow to
    start a flow.

    Calling this method on a flow that's already canceled succeeds and
    changes nothing.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/seo/v1/content-plan-flows/{contentPlanFlowId}/cancel
    ```

    ## Path Params

    <ParamField path="contentPlanFlowId" type="string" required>

      ID of the content plan flow to cancel.

    </ParamField>

    ## Response Object

    Returns `CancelContentPlanFlowResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
