    This method requires one of the following permission scopes:

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/storage-service/v1/storage-items/{key}/update-value
    ```

    ## Path Params

    <ParamField path="key" type="string" required>

      Key of the storage item to update.

    </ParamField>

    ## Response Object

    <ResponseField name="storageItem" type="StorageItem">

      Updated storage item.

      See the [Storage Item Object](/api-reference/business-management/automations/storage-item/storage-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_STORAGE_ITEM_TYPE_EXCEPTION` | Invalid value type. The specified value does not match the type of the value it updates. |
    | `400` | `INVALID_ARGUMENT` | `VALUE_TYPE_MISMATCH_EXCEPTION` | Invalid value type. The specified value does not match the type of the value it updates. |
    | `400` | `INVALID_ARGUMENT` | `STORAGE_ITEM_VALUE_VALIDATION_EXCEPTION` | Invalid format. The specified value has an incorrect format. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
