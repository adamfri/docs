    Adds labels to a contact.

    Use the Labels API to create or retrieve labels.

    Members are typically linked to contacts, and while they share a relationship, the member ID and contact ID are distinct identifiers.
    Make sure to specify the contact ID when calling Label Contact.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/contacts/{contactId}/labels
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to add labels to.

    </ParamField>

    ## Body Params

    <ParamField body="labelKeys" type="string[]" required>

      List of label keys to add to the contact.

      Label keys must exist to be added to the contact.
      Use the Labels API to create or retrieve labels.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts/contact-v4/contact-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CONTACT_NOT_FOUND` | Contact not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |

    import { contacts, labels } from '@wix/crm';

    /* Sample contactId value: '2712ae1d-3f64-46c2-ac3a-94a6c2e29847'
     * 
     * Sample displayName value: 'Supplier'
     */

    export async function addNewLabelToContact(displayName, contactId) {

      try {
        const newLabel = await labels.findOrCreateLabel(displayName);
        const labelKeys = [newLabel.label.key];
        // Retrieve the new label's key
        if (newLabel.newLabel) {
          // Label contact
          const contact = await contacts.labelContact(contactId, labelKeys);
          const contactLabels = contact.contact.info.labelKeys.items;

          return contactLabels;
        }
        else {
          return "Label was not added to contact.";

      } catch (error) {
