## Sync pizza menus across all sites

If you have several pizzeria sites, you might need to sync menus across those sites. For example, if you have a new item called "Margherita", this change also needs to be reflected on other sites.    

To sync the pizza menu across all sites:

1. Call [Get Item](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item/get-item) on the site where you created a new item.
1. Extract the whole `item` object.
1. Call [Create Item](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/menu/create-menu) for your other sites and pass the new item to each.
1. Call [Update Section](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/menu/update-menu) and add the new item ID to the `section.itemIds` array.
