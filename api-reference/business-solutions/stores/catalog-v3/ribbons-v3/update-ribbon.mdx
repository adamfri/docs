    Updates a ribbon.

    Each time the ribbon is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the ribbon.
    This ensures you're working with the latest ribbon and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.RIBBON_WRITE">Ribbon write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v3/ribbons/{ribbon.id}
    ```

    ## Path Params

    <ParamField path="ribbon.id" type="string" required>

      Ribbon ID.

    </ParamField>

    ## Body Params

    <ParamField body="ribbon" type="Ribbon" required>

      Ribbon to update.

      See the [Ribbon Object](/api-reference/business-solutions/stores/catalog-v3/ribbons-v3/ribbon-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCT_COUNT`

    </ParamField>
