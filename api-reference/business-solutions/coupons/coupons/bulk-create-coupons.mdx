    Creates multiple coupons.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-COUPONS.MANAGE-COUPONS">Manage Coupons</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v2/bulk/coupons/create
    ```

    ## Body Params

    <ParamField body="specifications" type="Specification[]">

      List of coupon specifications to be created.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="specifications properties">

        <ParamField body="name" type="string">

          Name of coupon.

        </ParamField>

        <ParamField body="code" type="string">

          Coupon code. Must be unique for all coupons on your site.

          Max: 20 characters

        </ParamField>

        <ParamField body="startTime" type="integer">

          Coupon valid from this date and time, in milliseconds.
          For example, `"1554066000000"`.

        </ParamField>

        <ParamField body="expirationTime" type="integer">

          Coupon expires at this date and time, in milliseconds.
          For example, `"1554325199999"`.

        </ParamField>

        <ParamField body="usageLimit" type="integer">

          Maximum number of times the coupon can be used.

          >**Note:** Multiple purchases by the same customer or purchases by different customers are both counted toward `usageLimit`.

        </ParamField>

        <ParamField body="limitPerCustomer" type="integer">

          Maximum number of times the coupon can be used per customer.

        </ParamField>

        <ParamField body="limitedToOneItem" type="boolean">

          Whether the coupon is limited to one item.

          If `true` and a customer pays for multiple items, the discount applies to only the lowest priced item.
          Coupons with a `bookings` `scope.namespace` are always limited to one item.

        </ParamField>

        <ParamField body="appliesToSubscriptions" type="boolean">

          Whether the coupon applies to subscription products.

        </ParamField>

        <ParamField body="discountedCycleCount" type="integer">

          Specifies the amount of discounted cycles for a subscription item.

          + Can only be set when `scope.namespace = pricingPlans`.
          + If `discountedCycleCount` is empty, the coupon applies to all available cycles.
          + `discountedCycleCount` is ignored if `appliesToSubscriptions = true`.

          Max: `999`

        </ParamField>

        <ParamField body="active" type="boolean">

          Whether the coupon is currently [active](https://support.wix.com/en/article/wix-stores-activating-and-deactivating-coupons).

          Default: `true`

        </ParamField>

        <ParamField body="type" type="string">

          Coupon type. Read-only.

        </ParamField>

        <ParamField body="tags" type="string[]">

          Tags for categorizing the coupon.

          Constraints: `maxLength 255`, `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnFullEntity" type="boolean">

      Whether to return full coupon entity in the response.

      Default: `false`

    </ParamField>
