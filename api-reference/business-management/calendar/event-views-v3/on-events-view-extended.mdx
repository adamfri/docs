Triggered when the current event view is extended.

Doesn’t include details about existing events added to the view due to the
extension. To receive updates about those events, subscribe to
[Events View Projection Updated](https://dev.wix.com/docs/rest/business-management/calendar/event-views-v3/events-view-projection-updated).

The event view is periodically extended by Wix Calendars, you can't manually
extend it.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.calendar.v3.events_view_extended` |
| Package | `@wix/calendar` |

## Examples

<CodeGroup>

  ```javascript onEventsViewExtended
  import { eventViews } from '@wix/calendar';

  eventViews.onEventsViewExtended((event) => {
      // handle your event here
  });
  ```

  ```javascript onEventsViewExtended (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { eventViews } from '@wix/calendar';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        eventViews,
      },
  });

  wixClient.eventViews.onEventsViewExtended((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
