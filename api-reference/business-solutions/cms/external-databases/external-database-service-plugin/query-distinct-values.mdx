    Retrieves a list of distinct values for a given field for all items that match the query, without duplicates.

    As with the [Query Data Items](https://dev.wix.com/docs/rest/assets/data/external-database-spi/query-data-items) endpoint, this endpoint retrieves items based on the filtering, sorting, and paging preferences provided.
    However, the Query Distinct Values endpoint doesn't return the full items that match the query. Rather, for items that match the query, it returns all unique values in the field specified in `fieldName`. If more than one item has the same value in that field, that value appears only once.

    See [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language) for more information about handling data queries.

    ## Endpoint

    ```http
    POST /v3/items/query-distinct-values
    ```

    ## Body Params

    <ParamField body="collectionId" type="string" required>

      ID of the collection to query.

    </ParamField>

    <ParamField body="filter" type="object">

      Filter to apply to the collection's data before aggregation. See [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#the-filter-section) for more information about handling data queries.

    </ParamField>

    <ParamField body="fieldName" type="string" required>

      Item field name for which to return all distinct values.

    </ParamField>

    <ParamField body="order" type="string">

      Order to by which to sort the results. Valid values are `ASC` and `DESC`.

      **Supported values:**

      - `ASC`
      - `DESC`

    </ParamField>

    <ParamField body="consistentRead" type="boolean" required>

      Whether to retrieve data from the primary database instance. This decreases performance but ensures data retrieved is up-to-date even immediately after an update. Applicable if the external database is eventually consistent.

    </ParamField>

    <ParamField body="returnTotalCount" type="boolean" required>

      When `true`, the query response must include the total number of items that match the query.

    </ParamField>

    ## Response Object

    <ResponseField name="distinctValues" type="any[]">

      List of distinct values contained in the field specified in `fieldName`. Values can be of any JSON type.
      If the field is an array, values must be unwound, independent values. For example, if the field name contains `["a", "b", "c"]`, the result must contain `"a"`, `"b"` and `"c"` as separate values.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="PagingMetadataV2">

      Paging information.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
