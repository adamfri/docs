The Collections API allows you to manage collections in a portfolio. A collection is a way to group similar projects together in your portfolio. Learn more about [collections in Wix Portfolio](fallback::https://support.wix.com/en/article/wix-portfolio-adding-and-setting-up-wix-portfolio#step-3-create-collections).

With the Collections API, you can:

+ [Create](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/create-collection), [update](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/update-collection), and [delete](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/delete-collection) collections. 
+ [Retrieve](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/get-collection), [list](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/list-collections), and [query](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/query-collections) collections.
+ Listen for events when a collection is [created](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/collection-created), [updated](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/collection-updated), and [deleted](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/collections/collection-deleted). 

## Before you begin

It's important to note the following points before starting to code:

+ After creating a collection, you can assign a new or existing project to the collection by specifying the collection's ID in the `collectionIds` parameter of the [Create Project](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/create-project) or [Update Project](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/update-project) methods. 
+ You can only use this API on sites where a Wix user has installed the [Wix Portfolio app](fallback::https://www.wix.com/app-market/web-solution/wix-portfolio?appIndex=0&collimp_id=b54d3569-fdaa-49f6-83f8-2ac6e400bd11&referralSectionName=wix%20portfolio).
