    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    </div>

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/loyalty-programs/v1/program/premium-features
    ```

    ## Response Object

    <ResponseField name="loyaltyProgram" type="boolean">

      Whether there are any loyalty program premium features.

      **Read-only.**

    </ResponseField>

    <ResponseField name="tiers" type="boolean">

      Whether this loyalty program includes tiers.

      **Read-only.**

    </ResponseField>

    <ResponseField name="pointsExpiration" type="boolean">

      Whether this loyalty program includes point expiration.

      **Read-only.**

    </ResponseField>
