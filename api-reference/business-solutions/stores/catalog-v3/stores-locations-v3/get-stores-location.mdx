    Retrieves a Stores location.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.LOCATION_READ">Read Stores Locations in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/locations/{storesLocationId}
    ```

    ## Path Params

    <ParamField path="storesLocationId" type="string" required>

      Stores location ID.

    </ParamField>

    ## Response Object

    <ResponseField name="storesLocation" type="StoresLocation">

      Stores location.

      See the [Stores Location Object](/api-reference/business-solutions/stores/catalog-v3/stores-locations-v3/stores-location-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
