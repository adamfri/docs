Site-wide data resource limits and current usage, including storage, data item counts, and data collection counts.

<Tabs>

  <Tab title="REST">

    <ResponseField name="storageLimitInBytes" type="integer">

      Maximum storage allowed for all native collections combined, in bytes.

      Storage usage is shared between the live and sandbox environments. For example, with a limit of
      1 GB, the live environment could use 700 MB and the sandbox 300 MB before the limit is reached.

      When this limit is reached, writes to collections fail.

    </ResponseField>

    <ResponseField name="itemCountLimit" type="integer">

      Maximum number of data items allowed per environment.

      This limit applies separately to the live and sandbox environments. For example, with a limit
      of 1,000, both the live and sandbox environments can each contain 1,000 items independently.

      When this limit is reached in an environment, writes to collections in that environment fail.

    </ResponseField>

    <ResponseField name="collectionCountLimit" type="integer">

      Maximum number of native data collections allowed.

    </ResponseField>

    <ResponseField name="collectionCount" type="integer">

      Total number of native data collections.

    </ResponseField>

    <ResponseField name="totalUsedLive" type="Usage">

      Storage and item usage across all native collections in the live environment.

      <Expandable title="totalUsedLive properties">

        <ResponseField name="bytes" type="string">

          Storage used, in bytes.

        </ResponseField>

        <ResponseField name="items" type="string">

          Number of data items.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="totalUsedSandbox" type="Usage">

      Storage and item usage across all native collections in the sandbox environment.

      <Expandable title="totalUsedSandbox properties">

        <ResponseField name="bytes" type="string">

          Storage used, in bytes.

        </ResponseField>

        <ResponseField name="items" type="string">

          Number of data items.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="dataCollectionUsages" type="DataCollectionUsage[]">

      Storage and item usage per native data collection.

      Constraints: `maxItems 1000`.

      <Expandable title="dataCollectionUsages properties">

        <ResponseField name="dataCollectionId" type="string">

          Data collection ID.

          Constraints: `maxLength 256`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Data collection display name.

        </ResponseField>

        <ResponseField name="dataCollectionType" type="string">

          Data collection type. Currently, only native collections are returned.

          **Supported values:**

          - `NATIVE` — User-created collection.
          - `WIX_APP` — [Collection](https://support.wix.com/en/article/velo-working-with-wix-app-collections-and-code#what-are-wix-app-collections) created by a Wix app when it is installed. This type of collection can be modified dynamically by that app (for example, Wix Forms).
          - `BLOCKS_APP` — Collection created by a Wix Blocks app.
          - `EXTERNAL` — Collection located in externally connected storage.

        </ResponseField>

        <ResponseField name="totalUsedLive" type="Usage">

          Storage and item usage in the live environment.

          <Expandable title="totalUsedLive properties">

            <ResponseField name="bytes" type="string">

              Storage used, in bytes.

            </ResponseField>

            <ResponseField name="items" type="string">

              Number of data items.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="totalUsedSandbox" type="Usage">

          Storage and item usage in the sandbox environment.

          <Expandable title="totalUsedSandbox properties">

            <ResponseField name="bytes" type="string">

              Storage used, in bytes.

            </ResponseField>

            <ResponseField name="items" type="string">

              Number of data items.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "storageLimitInBytes": "10000000000",
        "itemCountLimit": "1000000",
        "collectionCountLimit": 1000,
        "collectionCount": 2,
        "totalUsedLive": {
          "bytes": "1000",
          "items": "4"
        },
        "totalUsedSandbox": {
          "bytes": "2000",
          "items": "1"
        },
        "dataCollectionUsages": [
          {
            "dataCollectionId": "my_collection1",
            "displayName": "My Collection 1",
            "dataCollectionType": "NATIVE",
            "totalUsedLive": {
              "bytes": "800",
              "items": "3"
            },
            "totalUsedSandbox": {
              "bytes": "2000",
              "items": "1"
            }
          },
          {
            "dataCollectionId": "my_collection2",
            "displayName": "My Collection 2",
            "dataCollectionType": "NATIVE",
            "totalUsedLive": {
              "bytes": "200",
              "items": "1"
            },
            "totalUsedSandbox": {
              "bytes": "0",
              "items": "0"
            }
          }
        ]
      }
      ```

    </CodeGroup>
