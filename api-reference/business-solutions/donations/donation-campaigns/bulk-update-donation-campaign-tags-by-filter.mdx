    Updates tags on multiple donation campaigns using filter criteria.

    An empty filter updates all campaigns. The operation is asynchronous and returns a job ID for monitoring progress.

    Learn more about working with [async jobs](https://dev.wix.com/docs/rest/business-management/async-job/introduction).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DONATIONS.MANAGE-CAMPAIGNS">Manage Donation Campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/donation-campaigns/v2/bulk/donation-campaigns/update-tags-by-filter
    ```
