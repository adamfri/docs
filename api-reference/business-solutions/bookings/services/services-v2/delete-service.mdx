<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a service.

    Specify `{"preserveFutureSessionsWithParticipants": true}` to retain all
    future sessions for the service. By default, all future sessions are canceled.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/bookings/v2/services/{serviceId}
    ```

    ## Path Params

    <ParamField path="serviceId" type="string" required>

      ID of the service to delete.

    </ParamField>

    ## Query Params

    <ParamField query="preserveFutureSessionsWithParticipants" type="boolean">

      Whether to preserve future sessions with participants.

      Default: `false`

    </ParamField>

    <ParamField query="participantNotification" type="ParticipantNotification">

      Whether to notify participants about the change and an optional
      custom message.

      <Expandable title="participantNotification properties">

        <ParamField query="notifyParticipants" type="boolean">

          Whether to send a message about the changes to the customer.

          Default: `false`

        </ParamField>

        <ParamField query="message" type="string">

          Custom message to send to the participants about the changes to the booking.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `DeleteServiceResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Service Deleted | `wix.bookings.services.v2.service_deleted` | Triggered when a service is deleted. |

    </div>
