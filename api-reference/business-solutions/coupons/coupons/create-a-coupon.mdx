    Creates a new coupon.

    When creating a coupon, the `specification` object must contain values for `name`, `code`, `startTime`,
    and either `scope` or `minimumSubtotal`. The exception is for a `freeShipping` coupon type, for which you cannot apply
    a `scope` and `minimumSubtotal` is optional.

    The coupon `scope` defines the items a coupon applies to. A coupon can apply to all items in a specific Wix application,
    a group within the application, or a single item within a group.
    See [valid scope values](https://dev.wix.com/api/rest/coupons/coupons/valid-scope-values).

    The `specification` object must also contain a value for exactly 1 of the following coupon properties.
    This defines the coupon type.

    + `"moneyOffAmount"`
    + `"percentOffRate"`
    + `"freeShipping"`
    + `"fixedPriceAmount"`
    + `"buyXGetY"`

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-COUPONS.MANAGE-COUPONS">Manage Coupons</span>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v2/coupons
    ```

        <ParamField body="limitPerCustomer" type="integer">

          Whether the coupon is limited to one item.

          Coupons with a `bookings` `scope.namespace` are always limited to one item.

        </ParamField>

          Whether the coupon applies to subscription products.

        </ParamField>
