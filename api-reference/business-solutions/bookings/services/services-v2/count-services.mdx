    <div className="wix-ref">

    Counts how many services match the given filter.

    See [Query Services](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/query-services) for a list of supported filters.

    To learn about working with filters in general, see
    [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#filters)

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Query filter to base the count on. See [Query Services](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/query-services) for a list of supported filters.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of services matching the specified filter.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/bookings/v2/services/count' \
      -H 'Authorization: <AUTH>' \
      -d '{
        "filter": {
          "hidden": {
            "$eq": "false"
          }
        }
      }'
      ```

      ```json Response
      {
        "count": 2
      }
      ```

    </CodeGroup>
