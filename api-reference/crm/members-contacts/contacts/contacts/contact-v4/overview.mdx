## SDK package

```bash
npm install @wix/crm
```

Import the `contacts` namespace from `@wix/crm`.

## Methods

<CardGroup cols={2}>

  <Card title="List Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/list-contacts">
    GET Retrieves a list of up to 1,000 contacts per request.
  </Card>
  <Card title="Create Contact" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/create-contact">
    POST Creates a new contact.
  </Card>
  <Card title="Delete Contact" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/delete-contact">
    DELETE Deletes a contact.
  </Card>
  <Card title="Update Contact" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/update-contact">
    PATCH Updates a contact.
  </Card>
  <Card title="Merge Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/merge-contacts">
    POST Merges source contacts into a target contact.
  </Card>
  <Card title="Preview Merge Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/preview-merge-contacts">
    POST Previews merging source contacts into a target contact.
  </Card>
  <Card title="Label Contact" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/label-contact">
    POST Adds labels to a contact.
  </Card>
  <Card title="Unlabel Contact" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/unlabel-contact">
    DELETE Removes labels from a contact.
  </Card>
  <Card title="Query Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/query-contacts">
    POST Retrieves a list of contacts, given the provided paging, filtering, and sorting.
  </Card>
  <Card title="List Facets" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/list-facets">
    GET Lists facets from the site’s contact list.
  </Card>
  <Card title="Query Facets" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/query-facets">
    POST Retrieves facets from the site’s contact list by filter.
  </Card>
  <Card title="Bulk Delete Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/bulk-delete-contacts">
    POST Deletes multiple contacts.
  </Card>
  <Card title="Bulk Update Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/bulk-update-contacts">
    POST Updates the specified properties for multiple contacts.
  </Card>
  <Card title="Bulk Label And Unlabel Contacts" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/bulk-label-and-unlabel-contacts">
    POST Adds and removes labels from multiple contacts.
  </Card>
  <Card title="Get Contact" href="/api-reference/crm/members-contacts/contacts/contacts/contact-v4/get-contact">
    GET Retrieves a contact.
  </Card>
