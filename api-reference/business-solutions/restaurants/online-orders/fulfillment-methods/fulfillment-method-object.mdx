---
title: "Fulfillment Method Object"
description: "A Fulfillment Method represents a way in which a restaurant can provide orders to its customers."
icon: "cube"
---

A Fulfillment Method represents a way in which a restaurant can provide orders to its customers.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Fulfillment method ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      The current state of an item. Each time the item is modified, its `revision` changes by the server. for an update operation to succeed, you MUST pass the latest revision.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the fulfillment method was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the fulfillment method was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="type" type="string">

      Type of fulfillment method.

      **Supported values:**

      - `UNKNOWN_FULFILLMENT_TYPE` — Unknown fulfillment type.
      - `PICKUP` — The customer must pick up the order from the restaurant.
      - `DELIVERY` — The restaurant, or someone on behalf of the restaurant, must deliver the order to the customer.

    </ResponseField>

    <ResponseField name="name" type="string">

      Fulfillment method name.

    </ResponseField>

    <ResponseField name="enabled" type="boolean">

      Whether the fulfillment method is enabled.

    </ResponseField>

    <ResponseField name="fee" type="string">

      Fee for using this fulfillment method.

    </ResponseField>

    <ResponseField name="availability" type="Availability">

      Availability of this fulfillment method.

      <Expandable title="availability properties">

        <ResponseField name="availableTimes" type="DayOfWeekAvailability[]">

          A list of availability times for the days of the week.

          <Expandable title="availableTimes properties">

            <ResponseField name="dayOfWeek" type="string">

              The day of week this availability relates to.

              **Supported values:**

              - `MON` — Monday.
              - `TUE` — Tuesday.
              - `WED` — Wednesday.
              - `THU` — Thursday.
              - `FRI` — Friday.
              - `SAT` — Saturday.
              - `SUN` — Sunday.

            </ResponseField>

            <ResponseField name="timeRanges" type="TimeOfDayRange[]">

              A list of time ranges during which the fulfillment should be available.

              <Expandable title="timeRanges properties">

                <ResponseField name="startTime" type="TimeOfDay">

                  The start time in time of day representation.

                  _Nested structure omitted for brevity — see the `TimeOfDay` object._

                </ResponseField>

                <ResponseField name="endTime" type="TimeOfDay">

                  The end time in time of day representation.

                  _Nested structure omitted for brevity — see the `TimeOfDay` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="timeZone" type="string">

          The timezone in which the availability times are given.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="minOrderPrice" type="string">

      Minimum order price to qualify for using this fulfillment method.

    </ResponseField>

    <ResponseField name="businessLocationId" type="string">

      Business location ID ([SDK](https://dev.wix.com/docs/sdk/backend-modules/restaurants/wix-restaurants-new/about-business-locations) | [REST](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/about-business-locations)) of the operation this fulfillment method belongs to.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags used to classify and sort different types of fulfillment methods.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
