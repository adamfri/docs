    <div className="wix-ref">

    Retrieves a marketing consent by its details.
    Required fields:
    - `details.type`.
    - `details.email` OR `details.phone`.

    <Note>

    Due to the ongoing development of our new documentation portal, the query parameter is not displaying as expected. Use the `details` object located in the marketing consent object in the request. You can also see the code example for reference.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MARKETING.CONSENT-READ">Read Marketing Consents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/marketing-consent/v1/marketing-consent/get-by
    ```

    ## Query Params

    <ParamField query="type" type="string" required>

      The communication channel of the marketing consent.

      **Supported values:**

      - `UNKNOWN_TYPE`
      - `EMAIL`
      - `PHONE`

    </ParamField>

    <ParamField query="linkLanguage" type="string">

      Language of the page

    </ParamField>

    ## Response Object

    <ResponseField name="marketingConsent" type="MarketingConsent">

      The requested marketing consent.

      See the [Marketing Consent Object](/api-reference/business-management/marketing/marketing-consent/marketing-consent-object) for this object's fields.

    </ResponseField>

    <ResponseField name="communicationEligibility" type="CommunicationEligibility">

      Details about whether the subject of the marketing consent is eligible to receive marketing messages.

      <Expandable title="communicationEligibility properties">

        <ResponseField name="granted" type="boolean">

          Whether the recipient of the marketing consent is eligible to receive marketing messages. For example, if a visitor cancels their marketing consent, `CommunicationEligibility.granted` is `false`. Note that this only serves as a signal for your app to decide whether or not it should send marketing messages to the recipient's email address or phone number.

        </ResponseField>

        <ResponseField name="revokeConfirmationLink" type="string">

          Cancellation link.

        </ResponseField>

        <ResponseField name="reason" type="string">

          The reason the recipient of the marketing consent isn't eligible to receive marketing messages, for example, if the visitor unsubscribed from a newsletter.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
