    <div className="wix-ref">

    Adds and removes labels from multiple contacts.

    Labels are added to and removed from all contacts that meet the specified
    `filter` and `search` criteria.
    The request should specify a `filter` value, a `search` value, or both.
    To perform a dry run, call Query Contacts with the intended filter options.

    When this method is used, a bulk job is started and the job ID is returned.
    The job might not complete right away, depending on its size.
    The job's status can be retrieved with Get Bulk Job.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/bulk/contacts/add-remove-labels
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter options.
      Labels will be removed from contacts that meet the `filter` and `search` criteria.

      See
      [Field Support for Filtering, Sorting, and Searching](https://dev.wix.com/docs/rest/crm/members-contacts/contacts/contacts/contact-v4/sort-filter-and-search)
      for a list of supported filters and fields.

    </ParamField>

    <ParamField body="search" type="string">

      Plain text search for an exact match, up to 100 characters.
      Labels will be removed from contacts that meet the `filter` and `search` criteria.

      See
      [Field Support for Filtering, Sorting, and Searching](https://dev.wix.com/docs/rest/crm/members-contacts/contacts/contacts/contact-v4/sort-filter-and-search)
      for a list of searchable fields.

    </ParamField>

    <ParamField body="labelKeysToAdd" type="string[]">

      List of label keys to add to the contacts.

      Label keys must exist to be added to the contact.
      Contact labels can be created or retrieved with
      [Find or Create Label](https://dev.wix.com/api/rest/contacts/labels/find-or-create-label)
      or
      [List Labels](https://dev.wix.com/api/rest/contacts/labels/list-labels)

      Constraints: `maxItems 100`.

    </ParamField>

    <ParamField body="labelKeysToRemove" type="string[]">

      List of label keys to remove from the contacts.

      Constraints: `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Bulk job ID.
      The job's status can be retrieved with Get Bulk Job.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NEITHER_FILTER_NOR_SEARCH` | The request should contain a `filter` value, a `search` value, or both. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Contact Updated | `wix.contacts.v4.contact_updated` | Triggered when a contact is updated. If a contact is updated as part of a merge, the `originatedFrom` property is sent as `merge`. Otherwise, `originatedFrom` isn't returned. |

    </div>

    ## Examples

    Adds and removes labels to/from contacts with first name "John".

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/contacts/v4/bulk/contacts/add-remove-labels' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        --data-binary '{
          "filter": {
            "info.name.first": "John"
          },
          "labelKeysToAdd": ["custom.name-john", "custom.name-starts-with-J"],
          "labelKeysToRemove": ["custom.last-name-smith"]
        }'
      ```

      ```json Response
      {
        "jobId": "8046df3c-1234-4098-a5ab-c91ad8f33c47"
      }
      ```

    </CodeGroup>
