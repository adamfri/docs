    Retrieves a list of group memberships of a site member.

    Only Wix users can retrieve a site member's group memberships.
    Site members can only retrieve a list of their own group memberships.

    Default sorts by `groupId` in descending order.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-groups-proxy/members/v2/members/{memberId}/memberships
    ```

    ## Path Params

    <ParamField path="memberId" type="string" required>

      Member ID. See the Members API for details.

    </ParamField>

    ## Query Params

    <ParamField query="limit" type="integer">

      Number of items to load. Maximum `100`.

    </ParamField>

    <ParamField query="offset" type="integer">

      Number of items to skip in the current sort order.

    </ParamField>

    ## Response Object

    <ResponseField name="memberships" type="Membership[]">

      Site member's memberships.

      <Expandable title="memberships properties">

        <ResponseField name="groupId" type="string">

          Group ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="status" type="string">

          Membership status with group.

          **Supported values:**

          - `UNKNOWN_STATUS` — Undefined membership status.
          - `JOINED` — Site member is a group member.
          - `PENDING` — Site member has submitted a request to join this group. The request is still `PENDING`.

        </ResponseField>

        <ResponseField name="role" type="GroupRole">

          Group member role. When membership status is not `JOINED`, this is empty.

          <Expandable title="role properties">

            <ResponseField name="value" type="string">

              Member's role.

              **Supported values:**

              - `MEMBER` — Regular group member.
              - `ADMIN` — Group administrator.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Paging information.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
