    Retrieves a list of reservation locations given the provided paging, filtering, and sorting. Up to 100 reservation locations can be returned per request.

    For a detailed list of supported operations, see the Supported Filters and Sorting article.
    To learn how to query reservation locations, see [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in` | None |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.READ-LOCATIONS-BASIC">Read Reservation Locations (Basic)</span>
    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.READ-LOCATIONS-FULL">Read Reservation Locations (Full)</span>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ```http
    POST https://www.wixapis.com/table-reservations/reservation-locations/v1/reservation-locations/query
    ```
