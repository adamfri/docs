    Installs an app on a tenant, specifying the details of the app instance to create.

    The ID of this app instance is automatically generated and included in the `appInstance` object in the response.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEV_CENTER.INSTALL-APPS">The app will be able to manage application installations on this site.</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps-installer-service/v1/app-instance/install
    ```

    ## Body Params

    <ParamField body="tenant" type="Tenant" required>

      Tenant details.

      <Expandable title="tenant properties">

        <ParamField body="id" type="string" required>

          Tenant ID. For a site, this is the [site ID](https://dev.wix.com/docs/rest/account-level/sites/sites/introduction). For an account this is the [account ID](https://dev.wix.com/docs/rest/account-level/user-management/accounts/accounts/about-accounts).

        </ParamField>

        <ParamField body="tenantType" type="string">

          Tenant type. This can be a Wix site or account.

          **Supported values:**

          - `SITE`
          - `ACCOUNT`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="appInstance" type="AppInstance" required>

      Details of the app instance to create when the app is installed.

      See the [App Instance Object](/api-reference/business-management/app-installation/app-installation/app-instance-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="appInstance" type="AppInstance">

      The app instance created when the app was installed.

      See the [App Instance Object](/api-reference/business-management/app-installation/app-installation/app-instance-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `DOMAIN_ENTITY_MISSING` | Required domain entity is missing from the request. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_TENANT_TYPE` | Tenant type isn't supported for this operation. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_DEV_VERSION` | Development version of the app isn't valid for installation. |
    | `400` | `INVALID_ARGUMENT` | `ACCOUNT_INVALID_DEV_VERSION` | Development version of the app isn't valid for installation on this account. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
