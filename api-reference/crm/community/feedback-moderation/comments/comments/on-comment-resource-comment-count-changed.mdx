Triggered when the total number of comments has changed in a resource.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.comments.v2.comment_resource_comment_count_changed` |
| Package | `@wix/comments` |
| Permissions | `Read Comments`, `Manage Comments` |
