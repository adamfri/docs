    Retrieves an add-on.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/addons/v1/add-ons/{addOnId}
    ```

    ## Path Params

    <ParamField path="addOnId" type="string" required>

      ID of the add-on to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="addOn" type="AddOn">

      Retrieved add-on.

      See the [Add On Object](/api-reference/business-solutions/bookings/services/add-ons/add-on-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
