Triggered when a rule is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.moderation.v1.rule_updated` |
| Package | `@wix/moderation-rules` |
| Permissions | `Manage Moderation Rules` |

## Examples

<CodeGroup>

  ```javascript onRuleUpdated
  import { moderationRules } from '@wix/moderation-rules';

  moderationRules.onRuleUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onRuleUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  ```
