<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Links media items that are already associated with a specific product to a choice within the same product.

    Media items can only be set for choices within one option at a time - e.g., if you set media items for some or all of the choices within the Colors option (blue, green, and red), you won't be able to also assign media items to choices within the Size option (S, M, and L).

    To remove all existing media items, call the [Remove Product Media From Choices](https://dev.wix.com/api/rest/wix-stores/catalog/products/remove-product-media-from-choices) endpoint.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v1/products/{id}/choices/media
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Product ID.

    </ParamField>

    ## Body Params

    <ParamField body="media" type="MediaAssignmentToChoice[]">

      Product media items and the choices to add the media to.

      Constraints: `minItems 1`, `maxItems 10`.

      <Expandable title="media properties">

        <ParamField body="option" type="string" required>

          Option name.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="choice" type="string" required>

          Choice name.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="mediaIds" type="string[]">

          Media IDs (available via the Query Product endpoint).

          Constraints: `maxItems 50`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `AddProductMediaToChoicesResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
