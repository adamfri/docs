    Retrieves a booking policy.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v1/booking-policies/{bookingPolicyId}
    ```

    ## Path Params

    <ParamField path="bookingPolicyId" type="string" required>

      ID of the booking policy to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="bookingPolicy" type="BookingPolicy">

      Retrieved booking policy.

      See the [Booking Policy Object](/api-reference/business-solutions/bookings/policies/booking-policies/booking-policy-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
