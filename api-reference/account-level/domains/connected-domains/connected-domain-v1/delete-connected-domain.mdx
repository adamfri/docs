<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a `connectedDomain` object and removes related DNS records from
    [Google's Cloud DNS](https://cloud.google.com/dns).

    You must pass the relevant Wix account ID in the header of the call.

    If you delete a `"PRIMARY"` domain, the site automatically uses the standard
    URL for free Wix sites. Read more about
    [URLs of free Wix sites](https://support.wix.com/en/article/changing-your-free-wix-url-8591528).

    When you delete a subdomain, its CNAME record is deleted from Google's Cloud DNS.

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.MANAGE_CONNECTED_DOMAINS">DOMAINS.MANAGE_CONNECTED_DOMAINS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/domains/v1/connected-domains/{connectedDomainId}
    ```

    ## Path Params

    <ParamField path="connectedDomainId" type="string" required>

      ID of the connected domain to delete. Identical to the domain name including TLD.

    </ParamField>

    ## Response Object

    Returns `DeleteConnectedDomainResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
