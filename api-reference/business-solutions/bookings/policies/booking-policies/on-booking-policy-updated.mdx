Triggered when a booking policy is updated, including when a policy's
`default` attribute changes.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.bookings.v1.booking_policy_updated` |
| Package | `@wix/bookings` |
| Permissions | `Read Bookings - Public Data`, `Manage Bookings Services and Settings`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions`, `Picasso private app mega scope` |

## Examples

<CodeGroup>

  ```javascript onBookingPolicyUpdated
  import { bookingPolicies } from '@wix/bookings';

  bookingPolicies.onBookingPolicyUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onBookingPolicyUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';

    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        bookingPolicies,
      },
  });

  wixClient.bookingPolicies.onBookingPolicyUpdated((event) => {
      // handle your event here
  });
  ```
