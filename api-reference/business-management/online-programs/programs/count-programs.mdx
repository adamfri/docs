    <div className="wix-ref">

    Counts programs that match a filter.

    Results use the same visibility rules as `QueryPrograms`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/v3/programs/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      WQL filter for the programs to count.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of programs matching the filter and caller visibility.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Counts programs matching a filter.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/online-programs/v3/programs/count' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "filter": {
          "status": {
            "$eq": "PUBLISHED"
          }
        }
      }'
      ```

      ```json Response
      {
        "count": 4
      }
      ```

    </CodeGroup>

    </div>
