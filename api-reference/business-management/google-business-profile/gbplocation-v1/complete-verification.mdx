    Completes a verification by submitting the PIN Google sent.

    Specify the `pendingVerificationId` from Start Verification and the `pin`
    the site owner received by the method they chose.

    Verification succeeding doesn't on its own mean the profile is live on
    Google. Call Get Voice Of Merchant to check that.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/locations/{locationId}:completeVerification
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      Location ID. This is Google's location identifier.

    </ParamField>

    ## Body Params

    <ParamField body="pin" type="string" required>

      The PIN the site owner received by the method they chose.

      Constraints: `minLength 4`, `maxLength 8`.

    </ParamField>

    <ParamField body="pendingVerificationId" type="string" required>

      The `pendingVerificationId` that Start Verification returned for this
      verification. Store it between starting and completing, which can span
      sessions.

      Constraints: `minLength 1`, `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="verificationState" type="string">

      Verification state after completing the process.

      **Supported values:**

      - `UNVERIFIED`
      - `PENDING_VERIFICATION`
      - `VERIFIED`

    </ResponseField>
