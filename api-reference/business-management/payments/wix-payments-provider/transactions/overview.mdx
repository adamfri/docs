## SDK package

```bash
npm install @wix/dev
```

Import the `wixPaymentsTransactionsV3Transaction` namespace from `@wix/dev`.

## Methods

<CardGroup cols={2}>

  <Card title="Create Transaction" href="/api-reference/business-management/payments/wix-payments-provider/transactions/create-transaction">
    POST Creates initial request for a transaction to authorize and optionally capture funds.
  </Card>
  <Card title="Get Transaction" href="/api-reference/business-management/payments/wix-payments-provider/transactions/get-transaction">
    GET Retrieves transaction info by ID.
  </Card>
  <Card title="Capture Transaction" href="/api-reference/business-management/payments/wix-payments-provider/transactions/capture-transaction">
    POST Manually captures an authorized transaction by ID.
  </Card>
  <Card title="Void Or Refund Transaction" href="/api-reference/business-management/payments/wix-payments-provider/transactions/void-or-refund-transaction">
    POST Voids or refunds the transaction by ID.
  </Card>
  <Card title="Accept Dispute" href="/api-reference/business-management/payments/wix-payments-provider/transactions/accept-dispute">
    POST Accepts a dispute.
  </Card>
  <Card title="Generate Evidence Upload Url" href="/api-reference/business-management/payments/wix-payments-provider/transactions/generate-evidence-upload-url">
    POST Generates URL to upload evidence for a dispute.
  </Card>
  <Card title="Add Evidence" href="/api-reference/business-management/payments/wix-payments-provider/transactions/add-evidence">
    POST Adds evidence to a dispute.
  </Card>
  <Card title="Submit Evidence" href="/api-reference/business-management/payments/wix-payments-provider/transactions/submit-evidence">
    POST Submits evidence and triggers the review process.
  </Card>

</CardGroup>
