    <div className="wix-api-columns">

    <div className="wix-ref">

    Disconnects a staff member from a Wix user, clearing the `associatedWixIdentity` field.

    Consequently, the user can no longer manage the staff member's working hour schedule in the dashboard.

    You must call Disconnect Staff Member From User before connecting a different Wix user to the staff member.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/staff-members/{staffMemberId}/disconnect-staff-member-from-user
    ```

    ## Path Params

    <ParamField path="staffMemberId" type="string" required>

      ID of the staff member to disconnect from its Wix user.

    </ParamField>

    ## Body Params

    <ParamField body="fields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `RESOURCE_DETAILS` — Includes `resource` in the response.
      - `ASSOCIATED_IDENTITY_STATUS` — Includes `associatedIdentityStatus` in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="staffMember" type="StaffMember">

      Updated staff member.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:
