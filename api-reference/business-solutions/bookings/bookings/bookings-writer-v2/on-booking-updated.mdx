Triggered when a booked schedule is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.bookings.v2.booking_updated` |
| Package | `@wix/bookings` |
| Permissions | `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions`, `Read bookings calendar - including participants` |
