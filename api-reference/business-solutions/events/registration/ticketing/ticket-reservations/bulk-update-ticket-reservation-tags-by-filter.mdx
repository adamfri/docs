    Updates tags on multiple ticket reservations asynchronously using filters.

    Allows bulk tag updates on reservations matching specified criteria.
    The operation runs asynchronously and returns a job ID for tracking progress.
    An empty filter will update all reservations.

    If a tag appears in both assign and unassign lists, it will be assigned.
    Use this for large-scale tag operations based on reservation properties.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/bulk/ticket-reservations/update-tags-by-filter
    ```
