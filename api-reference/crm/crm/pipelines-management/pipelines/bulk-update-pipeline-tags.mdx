    Updates tags on multiple pipelines by specified pipeline IDs.

    If you specify a tag in both `assignTags` and `unassignTags`, the tag is assigned to the pipelines.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/pipelines/v1/bulk/pipelines/update-tags
    ```

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.
