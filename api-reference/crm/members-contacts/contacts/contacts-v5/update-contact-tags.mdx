    Adds or removes tags on a contact.

    Specify which tags to assign and which to unassign. A tag that appears in both the list to assign and the list to unassign is assigned. At least one tag must be specified to assign or unassign.

    To update tags on multiple contacts, call [Bulk Update Contact Tags](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts-v5/bulk-update-contact-tags).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/{contactId}/update-tags
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact whose tags to update.

    </ParamField>

    ## Body Params

    <ParamField body="assignTags" type="PrivateTags">

      Tags to assign.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission to access, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              A list of tag IDs.
              To create a tag, use the [Tags API](https://dev.wix.com/docs/api-reference/business-management/tags/introduction) with the contacts FQDN: `wix.contacts.*.contact`.

              Constraints: `maxLength 5`, `maxItems 1000`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="PrivateTags">

      Tags to unassign.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission to access, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              A list of tag IDs.
              To create a tag, use the [Tags API](https://dev.wix.com/docs/api-reference/business-management/tags/introduction) with the contacts FQDN: `wix.contacts.*.contact`.

              Constraints: `maxLength 5`, `maxItems 1000`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts-v5/contact-object) for this object's fields.

    </ResponseField>
