    Creates a component.

    Specify the `appId` of the app the component belongs to. If you don't specify an `id`, one is generated. Creating a component produces its first immutable version.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/components/v1/components
    ```

    ## Body Params

    <ParamField body="component" type="Component" required>

      Component to create.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="component" type="Component">

      Created component.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    Creates a dashboard component for an app. The component type is inferred from the data variant.
