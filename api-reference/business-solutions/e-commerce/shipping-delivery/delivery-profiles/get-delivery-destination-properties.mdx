    Retrieves delivery destination properties.

    Returns properties for Rest of World, as well as aggregated country and subdivision data. Properties include whether postal codes are required and whether pickup is the only delivery option for each destination.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.READ-ECOM">Read eCommerce - all read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/delivery-profiles/delivery-destination-properties
    ```

    ## Response Object

    <ResponseField name="restOfWorld" type="DeliveryDestinationProperties">

      Delivery destination properties for Rest of World.

      <Expandable title="restOfWorld properties">

        <ResponseField name="postalCodeRequired" type="boolean">

          Whether a postal code is required for delivery to this destination.

        </ResponseField>

        <ResponseField name="pickupOnly" type="boolean">

          Whether only pickup is available at this destination.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="countries" type="CountryDeliveryProperties[]">

      List of countries and their delivery destination properties.

      Constraints: `maxItems 195`.

      <Expandable title="countries properties">

        <ResponseField name="country" type="string">

          2-letter country code in [ISO-3166 alpha-2](https://www.iso.org/obp/ui/#search/code/) format.

          Constraints: `format COUNTRY`.

        </ResponseField>

        <ResponseField name="deliveryDestinationProperties" type="DeliveryDestinationProperties">

          Delivery destination properties for the country.

          <Expandable title="deliveryDestinationProperties properties">

            <ResponseField name="postalCodeRequired" type="boolean">

              Whether a postal code is required for delivery to this destination.

            </ResponseField>

            <ResponseField name="pickupOnly" type="boolean">

              Whether only pickup is available at this destination.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="subdivisions" type="SubdivisionDeliveryProperties[]">

          List of subdivisions and their delivery destination properties.

          Constraints: `maxItems 100`.

          <Expandable title="subdivisions properties">

            <ResponseField name="subdivision" type="string">

              Code for a subdivision (such as state, prefecture, or province) in [ISO 3166-2](https://www.iso.org/standard/72483.html) format.

              Constraints: `minLength 1`, `maxLength 5`.

            </ResponseField>

            <ResponseField name="deliveryDestinationProperties" type="DeliveryDestinationProperties">

              Delivery destination properties for the subdivision.

              _Nested structure omitted for brevity — see the `DeliveryDestinationProperties` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
