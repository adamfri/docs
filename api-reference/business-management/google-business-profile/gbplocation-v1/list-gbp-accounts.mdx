    Retrieves the Google Business Profile accounts the connected Google account
    can access.

    A Google account can have access to more than one Business Profile account,
    each holding its own locations. Use this to find the account ID to specify when
    importing locations.

    A Google account must be connected first. See the
    [Connection API](https://dev.wix.com/docs/api-reference/business-management/google-business-profile/connection-v1).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/accounts
    ```

    ## Response Object

    <ResponseField name="accounts" type="GbpAccount[]">

      GBP accounts accessible to the connected Gmail for this Wix site.

      <Expandable title="accounts properties">

        <ResponseField name="accountId" type="string">

          Google GBP Account ID.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Display name of the GBP Account.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="accountType" type="string">

          Type of the GBP Account (e.g. PERSONAL, LOCATION_GROUP, ORGANIZATION).

          Constraints: `maxLength 64`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata. `cursors.next` is the token to specify for the next page, and
      `hasNext` says whether there is one.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>
