    <div className="wix-ref">

    Creates a collection reference to put a data collection into a folder.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v1/folders/collection-references/create
    ```

    ## Body Params

    <ParamField body="collectionReference" type="CollectionReference" required>

      Collection reference to create.

      <Expandable title="collectionReference properties">

        <ParamField body="collectionName" type="string" required>

          Collection's name as displayed in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-creating-a-collection).

          Constraints: `maxLength 255`, `immutable`.

        </ParamField>

        <ParamField body="folderId" type="string">

          ID of the folder that contains the collection reference.

          Omitted if the collection reference is in the root folder.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="collectionReference" type="CollectionReference">

      Details of the created collection reference.

      <Expandable title="collectionReference properties">

        <ResponseField name="collectionName" type="string">

          Collection's name as displayed in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-creating-a-collection).

          Constraints: `maxLength 255`, `immutable`.

        </ResponseField>

        <ResponseField name="folderId" type="string">

          ID of the folder that contains the collection reference.

          Omitted if the collection reference is in the root folder.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `FOLDER_NOT_FOUND` | Couldn't find the folder. |
    | `409` | `ALREADY_EXISTS` | `COLLECTION_REFERENCE_EXISTS` | The collection reference already exists. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
