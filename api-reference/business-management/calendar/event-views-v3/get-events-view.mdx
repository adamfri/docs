  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the current event view.

    Doesn’t return details about events within the view. You can use
    [Query Events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/query-events),
    providing `eventsView.endDate` as `toLocalDate` to retrieve the
    events.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PI">Read Calendar - Including PI</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/calendar/v3/events/view
    ```

    ## Response Object

    <ResponseField name="eventsView" type="EventsView">

      Retrieved event view.

      See the [Events View Object](/api-reference/business-management/calendar/event-views-v3/events-view-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Retrieves the view’s end date for the calendar view.

    <CodeGroup>

      ```bash Request
      curl -X GET \
      'https://www.wixapis.com/calendar/v3/events/view' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>'
      ```

      ```json Response
      {
        "eventsView": {
          "endDate": "2025-10-04T00:00:00Z",
          "futureDurationInDays": 380
        }
      }
      ```

    </CodeGroup>

    </div>
