The Transactions API allows you to retrieve your app or site's [transactions](##transaction*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#transaction). Use this API together with other [Wix Benefit Programs APIs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/introduction).

A transaction is a record of a change to a pool's associated [balance](##balance*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#balance)

## Before you begin
It's important to note the following points before starting to code:
- Sites using this API must install the Pricing Plans app.
