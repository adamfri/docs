  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    <Note>

    Only logged-in [Wix users](https://dev.wix.com/docs/rest/articles/get-started/about-identities#wix-user) or [API key admins](https://dev.wix.com/docs/rest/articles/get-started/about-identities#api-key-admin) can use this API.

    </Note>

    Uninstalls an app from a tenant.

    This removes the instance of a specified app from the tenant.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="APPS_INSTALLER.UNINSTALL_SITE_LEVEL">APPS_INSTALLER.UNINSTALL_SITE_LEVEL</span>
    <span className="wix-scope" title="APPS_INSTALLER.UNINSTALL_ACCOUNT_LEVEL">APPS_INSTALLER.UNINSTALL_ACCOUNT_LEVEL</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps-installer-service/v1/app-instance/uninstall
    ```

    ## Body Params

    <ParamField body="tenant" type="Tenant">

      Tenant details.

      <Expandable title="tenant properties">

        <ParamField body="id" type="string">

          Tenant ID. For a site, this is the [site ID](https://dev.wix.com/docs/rest/account-level/sites/sites/introduction). For an account this is the [account ID](https://dev.wix.com/docs/rest/account-level/user-management/accounts/accounts/about-accounts).

        </ParamField>

        <ParamField body="tenantType" type="string">

          Tenant type. This can be a Wix site or account.

          **Supported values:**

          - `SITE`
          - `ACCOUNT`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="appDefId" type="string" required>

      The ID of the app to install.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    Returns `UninstallAppResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
