    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates a list of favorite dashboard pages for the current Wix user. A Wix user can only have one such list.

    <Note>

    When first calling this method on behalf of a Wix user, you can create a list that contains one or more favorite dashboard pages. However, if a list already exists for that Wix user, calling this method generates an error.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.MANAGE_DASHBOARD">Manage Dashboard</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/dashboard/v1/user-favorite-list
    ```

    ## Body Params

    <ParamField body="favoriteList" type="DashboardFavoriteList" required>

      Dashboard favorite list to create.

      See the [Favorite List Object](/api-reference/business-management/dashboard/dashboard-favorite-list/favorite-list-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="favoriteList" type="DashboardFavoriteList">

      Created dashboard favorite list.

      See the [Favorite List Object](/api-reference/business-management/dashboard/dashboard-favorite-list/favorite-list-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Favorite List Created | `wix.dashboard.v1.favorite_list_created` | Triggered when the dashboard favorite list is created. |
