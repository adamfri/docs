    Returns whether it's possible to install an app on a tenant, either by providing app instance details or using a share URL.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEV_CENTER.INSTALL-APPS">The app will be able to manage application installations on this site.</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps-installer-service/v1/app-instance/is-permitted-to-install
    ```

    ## Body Params

    <ParamField body="installType" type="string" required>

      Installation type.

      **Supported values:**

      - `APPS_INSTALL` — Installation based on app instance data provided in the request.
      - `SHARE_URL_INSTALL` — Installation based on a shareable app URL.

    </ParamField>

    ## Response Object

    <ResponseField name="permitted" type="boolean">

      Whether the installation is permitted.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_TENANT_TYPE` | Tenant type isn't supported for this operation. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
