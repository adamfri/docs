    Deletes the partner profile of the currently authenticated partner. No profile ID is required, as the profile is identified by the caller's authenticated identity.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/partners/profile/v1/partner-profiles
    ```

    ## Response Object

    Returns `DeletePartnerProfileResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
