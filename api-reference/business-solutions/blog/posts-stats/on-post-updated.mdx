Triggered when a post is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.blog.v3.post_updated` |
| Package | `@wix/blog` |
| Permissions | `Read Blog`, `Manage Blog`, `Read Draft Blog Posts` |

## Examples

<CodeGroup>

  ```javascript onPostUpdated
  import { posts } from '@wix/blog';

  posts.onPostUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onPostUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { posts } from '@wix/blog';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        posts,
      },
  });

  wixClient.posts.onPostUpdated((event) => {
      // handle your event here
  });
  ```
