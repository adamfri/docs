    Generates alt text suggestions for a single image of a Wix-managed item.

    The image must be Wix-hosted media and belong to a Wix-managed item, such
    as a site page or a store product, identified by `image.parentItemId` and
    `itemType`. That item's stored SEO data gives the AI context about what
    the image is for. This method can't generate alt text for an arbitrary
    image URL with no owning item.

    Returns up to 5 ready-to-use alt texts in the site's language.

    To generate alt text for up to 20 images in a single call, call
    [Bulk Generate Alt Text Suggestions](https://dev.wix.com/docs/api-reference/business-management/seo/tag-suggestions-v1/bulk-generate-alt-text-suggestions).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/seo/suggestions/v1/tag-suggestions/alt-text
    ```

    ## Body Params

    <ParamField body="image" type="ImageReference" required>

      The image to generate alt text for.

      <Expandable title="image properties">

        <ParamField body="id" type="string">

          Your reference ID for the image. Echoed back in the result so you can
          match suggestions to images. It isn't interpreted.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="url" type="string">

          URL of the image file. Must be Wix-hosted media, meaning a URL on a Wix media
          domain such as `static.wixstatic.com`. Other hosts are rejected.

          Constraints: `format WEB_URL`, `maxLength 1000`.

        </ParamField>

        <ParamField body="parentItemId" type="string">

          ID of the Wix item the image belongs to, for example, a page ID or a
          store product ID, matching the request's `itemType`.

          Constraints: `maxLength 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="itemType" type="string" required>

      Type of the Wix item the image belongs to, as an SEO item type
      identifier. For example, `STATIC_PAGE_V2` for a regular site page,
      `STORES_PRODUCT` for a store product, or `BLOG_POST` for a blog post.
      Other values are rejected.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="altTextSuggestions" type="AltTextSuggestions">

      The generated alt text suggestions.

      <Expandable title="altTextSuggestions properties">

        <ResponseField name="imageId" type="string">

          Your reference ID for the image, echoed from the request.

          **Read-only.** Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="url" type="string">

          URL of the image, echoed from the request.

          **Read-only.** Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="suggestions" type="string[]">

          Suggested alt texts, best match first.

          **Read-only.** Constraints: `maxLength 1000`, `maxItems 5`.

        </ResponseField>

      </Expandable>

    </ResponseField>
