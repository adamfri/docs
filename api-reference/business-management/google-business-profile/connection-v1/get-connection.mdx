    Retrieves the site's Google Business Profile connection status.

    Returns `NEVER_CONNECTED` when no Google account has been connected. Poll
    this after sending the site owner to the URL from Get Connect URL.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/connection
    ```

    ## Response Object

    <ResponseField name="connection" type="Connection">

      The site's connection. Absent when `status` is `NEVER_CONNECTED`.

      See the [Connection Object](/api-reference/business-management/google-business-profile/connection-v1/connection-object) for this object's fields.

    </ResponseField>

    <ResponseField name="status" type="string">

      Current status of the site's Google connection.

      **Supported values:**

      - `UNKNOWN_CONNECTION_STATUS`
      - `NEVER_CONNECTED` — No Google account has been connected for this site.
      - `VALID` — The connection is usable.
      - `NEEDS_RECONNECT` — The connection exists but its stored Google credentials are gone, for
      example because the Google account owner exercised a data-deletion request.
      The site owner must connect again.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MULTIPLE_CONNECTIONS_NOT_REPRESENTABLE` | See GetConnectUrl: reported rather than answering for an arbitrary connection, which would be a silent lie a caller cannot detect. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
