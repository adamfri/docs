    <div className="wix-ref">

    Retrieves a campaign's editor data, including the content and subject line.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/composer
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      Campaign ID.

    </ParamField>

    ## Response Object

    <ResponseField name="composer" type="Composer">

      Campaign editor data.

      <Expandable title="composer properties">

        <ResponseField name="composerDataJson" type="string">

          Editor content for the campaign. The format depends on `campaignEditorType`:

          - `WEB`: Wix proprietary JSON format used by the drag-and-drop email editor.
          - `MOBILE`: A subset of the `WEB` format, used by the mobile email editor.
          - `MJML`: MJML markup wrapped in a JSON object under key "mjml".

          Passing the wrong format for the given `campaignEditorType` causes a silent failure when sending or previewing the campaign.

          Constraints: `maxLength 10000000`.

        </ResponseField>

        <ResponseField name="defaultValues" type="DefaultValues">

          Fallback values for dynamic placeholders in the campaign content.

          <Expandable title="defaultValues properties">

            <ResponseField name="map" type="object">

              Map of placeholder keys to their default values.

              Constraints: `format map`, `maxItems 500`.

              _Nested structure omitted for brevity — see the `object` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="emailSubject" type="string">

      Campaign subject line.

      Constraints: `maxLength 1000`.

    </ResponseField>

    <ResponseField name="emailPreheader" type="string">

      Short preview text shown after the subject line in some email clients.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
