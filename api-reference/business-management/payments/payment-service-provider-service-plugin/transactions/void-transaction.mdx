This endpoint is used to send requests to void transactions to a Payment Service Provider (PSP).

Wix calls this endpoint to void a transaction.
Learn more about [implementing this endpoint](https://dev.wix.com/docs/rest/business-management/payments/service-plugins/payment-service-provider-service-plugin/capturing-and-voiding-payments).

## Endpoint

```http
POST /void
```

## Body Params

<ParamField body="wixTransactionId" type="string" required>

  Wix transaction ID.

  Constraints: `format GUID`.

</ParamField>

<ParamField body="pluginTransactionId" type="string" required>

  PSP transaction ID.

  Constraints: `minLength 1`, `maxLength 200`.

</ParamField>

<ParamField body="voidAmount" type="string" required>

  Total amount to void in a currency’s minor units. This must be the same as the authorized amount.
  Learn more about [currencies](https://dev.wix.com/docs/rest/business-management/payments/service-plugins/payment-service-provider-service-plugin/currencies).

</ParamField>

<ParamField body="merchantCredentials" type="object" required>

  Credentials that the PSP provided when the merchant connected their account.

  Constraints: `format map`.

  <Expandable title="merchantCredentials properties">

    <ParamField body="key" type="string" />

    <ParamField body="value" type="string" />

  </Expandable>

</ParamField>

<ParamField body="siteId" type="string">

  Wix site ID.

</ParamField>

## Response Object

<ResponseField name="reasonCode" type="integer">

  Wix [reason code](https://dev.wix.com/docs/rest/business-management/payments/service-plugins/payment-service-provider-service-plugin/reason-codes#void-declined) indicating a failed request.

</ResponseField>

<ResponseField name="errorCode" type="string">

  PSP-specific error code.

</ResponseField>

<ResponseField name="errorMessage" type="string">

  PSP-specific error message.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
