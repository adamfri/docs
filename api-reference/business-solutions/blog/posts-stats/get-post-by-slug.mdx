    Retrieves a post with the provided slug.

    The slug is the end of a post's URL that refers to a specific post.
    For example, if a post's URL is `https:/example.com/blog/post/my-post-slug`,
    the slug is `my-post-slug`. The slug is case-sensitive, and is generally derived from the post title,
    unless specified otherwise.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v3/posts/slugs/{slug=**}
    ```

    ## Query Params

    <ParamField query="slug" type="string" required>

      Slug of the post to retrieve.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      List of additional post fields to include in the response. For example, use the `URL` fieldset to retrieve the url field in
      the response in addition to the post’s base fields. Base fields don’t include any of the supported fieldset values. By default
      only the post’s base fields are returned.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `URL` — Includes post URL when present.
      - `CONTENT_TEXT` — Includes post content text string when present.
      - `METRICS` — Includes post metrics when present.
      - `SEO` — Includes SEO data.
      - `CONTACT_ID` — Includes post owner's contact ID.
      - `RICH_CONTENT` — Includes post rich content.
      - `REFERENCE_ID` — Includes post reference ID field.

    </ParamField>

    <ParamField query="language" type="string">

      Language of the post.

    </ParamField>

    ## Response Object

    <ResponseField name="post" type="Post">

      Retrieved post info.

      See the [Post Object](/api-reference/business-solutions/blog/posts-stats/post-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
