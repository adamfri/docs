    Retrieves totals across the GPV payouts matching a filter: the total earned
    amount (USD), the total gross payment volume (GPV) (USD), the payout count,
    and the minimum and maximum revenue-share rate applied. Use it to summarize a
    partner's GPV earnings for a period without paging through every payout.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/partners/revshare/v1/gpv-payouts/aggregate
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter selecting which GpvPayouts to aggregate, using the same query syntax as `QueryGpvPayouts` (for example, a `transactionDate` range). An empty filter aggregates all of the caller's GpvPayouts.

    </ParamField>

    ## Response Object

    <ResponseField name="payoutsTotalAmount" type="number">

      Total amount earned across the matching GpvPayouts, in USD.

    </ResponseField>

    <ResponseField name="payoutsCount" type="number">

      Number of matching GpvPayouts.

    </ResponseField>

    <ResponseField name="payoutsTotalGpv" type="number">

      Total gross payment volume (GPV) across the matching GpvPayouts, in USD.

    </ResponseField>

    <ResponseField name="payoutsMinimumRevenueSharePercent" type="number">

      Lowest revenue-share rate applied across the matching GpvPayouts, as a fractional percent (for example, `0.05` means 0.05%).

    </ResponseField>

    <ResponseField name="payoutsMaximumRevenueSharePercent" type="number">

      Highest revenue-share rate applied across the matching GpvPayouts, as a fractional percent (for example, `0.1` means 0.1%).

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    Returns the total amount, total GPV, count, and revenue-share rate range for a filter

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/partners/revshare/v1/gpv-payouts/aggregate' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        -d '{
          "filter": {
            "transactionDate": {
              "$gte": "2025-01-01T00:00:00.000Z",
              "$lt": "2025-02-01T00:00:00.000Z"
            }
          }
        }'
      ```

      ```json Response
      {
        "payoutsTotalAmount": 24.18,
        "payoutsCount": 3,
        "payoutsTotalGpv": 26430.5,
        "payoutsMinimumRevenueSharePercent": 0.05,
        "payoutsMaximumRevenueSharePercent": 0.1
      }
      ```
