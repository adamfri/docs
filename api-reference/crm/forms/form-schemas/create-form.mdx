    <div className="wix-ref">

    Creates a form schema.

    Each form schema defines the structure, fields, validation rules, and layout for forms.
    The form schema serves as a blueprint that can be used by an app to generate actual forms. The app that can use the schema is determined by the specified `namespace`.

    For how to compose each kind of form field, including which `identifier`, `inputType`, and `componentType` values to combine, see [About Form Fields](https://dev.wix.com/docs/api-reference/crm/forms/form-schemas/about-form-fields).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/forms
    ```

    ## Body Params

    <ParamField body="form" type="Form" required>

      Form schema to create.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="form" type="Form">

      Created form schema.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_FIELD_TARGETS` | Multiple fields have the same target name. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_FIELD_IDS` | Multiple fields have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_STEP_IDS` | Multiple steps have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_RULE_IDS` | Multiple rules have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_FIELD_TARGETS` | Fields are missing required target names. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_FIELD_TARGETS_NAME` | Field target names aren't supported for this field type. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_NESTED_FORM_IDS` | Nested form fields are missing required form IDs. |
    | `400` | `INVALID_ARGUMENT` | `NON_EXISTING_NESTED_FORMS` | Referenced nested forms don't exist. |
    | `400` | `INVALID_ARGUMENT` | `NESTED_FORM_FIELDS_MISSING` | Nested form is missing required fields. |
    | `400` | `INVALID_ARGUMENT` | `FIELD_SCHEMA_NOT_SUPPORTED` | Field schema isn't supported by the platform. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_FORM_NAMESPACE` | Form namespace isn't supported. |
    | `400` | `INVALID_ARGUMENT` | `FORM_FIELDS_COUNT_EXCEEDED` | Number of form fields exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `NAMESPACE_FORMS_COUNT_EXCEEDED` | Number of forms in the namespace exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `NAMESPACE_DELETED_FORMS_COUNT_EXCEEDED` | Number of deleted forms in the namespace exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `FORM_SIZE_EXCEEDED` | Form size exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_PRODUCT_IDS` | Multiple products have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_PRODUCT_NAME` | Product is missing a required name. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
