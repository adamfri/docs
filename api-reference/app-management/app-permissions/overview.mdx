## SDK package

```bash
npm install @wix/app-management
```

Import the `appPermissions` namespace from `@wix/app-management`.

## Methods

<CardGroup cols={2}>

    GET Lists all permissions for the specified app.
  </Card>
  <Card title="Create App Permission" href="/api-reference/app-management/app-permissions/create-app-permission">
    POST Adds a permission to the specified app.
  </Card>
  <Card title="Delete App Permission" href="/api-reference/app-management/app-permissions/delete-app-permission">
    DELETE Deletes a permission from the specified app.
