---
title: "Balance Object"
description: "A balance is the number of available credits in a pool."
icon: "cube"
---

A balance is the number of available credits in a pool.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Balance ID. This is the same as the associated pool's ID.

      **Read-only.** Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the balance is updated.
      To prevent conflicting changes, the current revision must be passed when updating the balance.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the balance was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the balance was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="beneficiary" type="IdentificationData">

      Beneficiary of the associated pool.

      **Read-only.** Constraints: `immutable`.

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="amount" type="BalanceAmount">

      Available credits.

      **Read-only.**

      <Expandable title="amount properties">

        <ResponseField name="available" type="string">

          number of available credits.

          **Read-only.**

        </ResponseField>

        <ResponseField name="reserved" type="string">

          number of reserved credits.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="poolInfo" type="PoolInfo">

      Associated pool information.

      **Read-only.**

      <Expandable title="poolInfo properties">

        <ResponseField name="id" type="string">

          Pool ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="poolDefinitionId" type="string">

          ID of the pool definition the pool was created from.

          **Read-only.**

        </ResponseField>

        <ResponseField name="programDefinitionId" type="string">

          ID of the program definition the pool was created from.

          **Read-only.**

        </ResponseField>

        <ResponseField name="programId" type="string">

          ID of the program that contains the pool.

          **Read-only.**

        </ResponseField>

        <ResponseField name="creditAmount" type="string">

          Available credits.

          **Read-only.**

        </ResponseField>

        <ResponseField name="namespace" type="string">

          Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="externalProgramDefinitionId" type="string">

          External ID of the program definition the pool was created from.

          **Read-only.**

        </ResponseField>

        <ResponseField name="externalProgramId" type="string">

          External ID of the program that contains the pool.

          **Read-only.**

        </ResponseField>

        <ResponseField name="creditRolloverConfiguration" type="RolloverConfigurationInfo">

          Credit rollover configuration information for the pool.

          **Read-only.**

          <Expandable title="creditRolloverConfiguration properties">

            <ResponseField name="enabled" type="boolean">

              Whether unused credits roll over to a new cycle when a program renews.

              **Read-only.**

            </ResponseField>

            <ResponseField name="balanceCap" type="string">

              Maximum number of credits that can roll over to the next cycle when a program renews.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="status" type="string">

          Pool status

          **Read-only.**

          **Supported values:**

          - `ACTIVE` — Pool is active.
          - `PAUSED` — Pool is paused. It can be resumed.
          - `ENDED` — Pool is ended. It can't be resumed.
          - `PROVISIONING` — Pool provisioning is in progress. This status exists for a short time during processing.
          - `RENEWING` — Pool renewing is in progress. This status exists for a short time during processing.
          - `PENDING` — Pool is pending

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the balance object.
      [Extended fields](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/schema-plugins/about-schema-plugin-extensions) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="lastTransactionId" type="string">

      ID of the transaction associated with the most recent change to the balance.

      **Read-only.**

    </ResponseField>
