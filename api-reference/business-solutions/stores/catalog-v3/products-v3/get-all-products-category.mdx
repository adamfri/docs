    <div className="wix-ref">

    Retrieves the ID of the "All Products" category, which is automatically assigned to all products.

    Learn more about the [Categories API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/categories/introduction).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_READ_LIMITED">Read v3 catalog (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/all-products-category
    ```

    ## Response Object

    <ResponseField name="categoryId" type="string">

      ID of the "All Products" category automatically assigned to all products.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="treeReference" type="TreeReference">

      Category tree reference. For Wix Stores, `appNamespace` is `"@wix/stores"` and `treeKey` is `null`.

      <Expandable title="treeReference properties">

        <ResponseField name="appNamespace" type="string">

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ResponseField>

        <ResponseField name="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
