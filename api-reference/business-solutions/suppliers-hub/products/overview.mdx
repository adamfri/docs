A product provided by a business partner and displayed in the Wix Marketplace.

Products can be of type DROPSHIPPING, WHOLESALE, or both.
Wix users can discover and add these products to their stores.

## SDK package

```bash
npm install @wix/suppliers-hub
```

Import the `products` namespace from `@wix/suppliers-hub`.
