    <div className="wix-ref">

    Retrieves multiple brands by name, or creates multiple brands if those with the passed `brandNames` don't exist.

    <Note>

    `results.item` always contains the full brand entity for each retrieved or created brand. Bulk Get Or Create Brands doesn't accept a `returnEntity` parameter.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.BRAND_WRITE">Brand write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/brands/get-or-create
    ```

    ## Body Params

    <ParamField body="brandNames" type="string[]" required>

      Brand names to retrieve or create.

      Constraints: `minLength 1`, `maxLength 50`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkBrandsResult[]">

    Retrieve an existing brand "Adidas" and create a new brand "Reef". The response also includes the number of products using each brand.

        -d '{
          "brandNames": [
