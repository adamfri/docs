    Creates a new external database connection.

    Before you can establish a connection between a site and an external database, you must prepare an external database adaptor.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.EXTERNAL-DATABASE-CONNECTIONS-MANAGE">Manage External Database Connections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v1/external-database-connections
    ```

    ## Body Params

    <ParamField body="externalDatabaseConnection" type="ExternalDatabaseConnection" required>

      External database connection details.

      See the [External Database Connection Object](/api-reference/business-solutions/cms/external-databases/external-database-connection/external-database-connection-object) for this object's fields.

    </ParamField>

    <ParamField body="connectionType" type="string" required>

      Connection type. The connection type specifies the type of adaptor by which the external collection is integrated with the site.

      **Supported values:**

      - `STANDALONE` — External database connection based on the legacy [external database collection service plugin](https://dev.wix.com/docs/velo/api-reference/wix-data-v2/service-plugins-spis/external-database-collection-legacy/introduction).
      - `WIX_SERVICE_PLUGIN` — External database connection based on the [external database service plugin](https://dev.wix.com/docs/rest/business-solutions/cms/service-plugins/external-database-service-plugin/introduction).

    </ParamField>

    ## Response Object

    <ResponseField name="externalDatabaseConnection" type="ExternalDatabaseConnection">

      Details of the created external database connection.

      See the [External Database Connection Object](/api-reference/business-solutions/cms/external-databases/external-database-connection/external-database-connection-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
