    Updates a package's external ID field.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="PREMIUM.PACKAGE_UPDATE_EXTERNAL_ID">PREMIUM.PACKAGE_UPDATE_EXTERNAL_ID</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/resellers/v1/packages/update/{packageId}/{externalId}
    ```

    ## Path Params

    <ParamField path="packageId" type="string" required>

      ID of the package to update.

    </ParamField>

    <ParamField path="externalId" type="string" required>

      External ID that will be assigned to the package.

    </ParamField>

    ## Response Object

    <ResponseField name="updatedPackage" type="Package">

      Updated package.

      See the [Packages Object](/api-reference/account-level/resellers/packages-and-product-instances/packages-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
