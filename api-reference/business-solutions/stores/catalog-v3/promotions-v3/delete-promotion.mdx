    Deletes a promotion.

    Once a promotion is deleted, it can't be retrieved using the API and no longer appears on the site.

    To delete multiple promotions in a single API call, call [Bulk Delete Promotions](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/promotions-v3/bulk-delete-promotions).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_WRITE">Manage v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/stores/v3/promotions/{promotionId}
    ```

    ## Path Params

    <ParamField path="promotionId" type="string" required>

      ID of the promotion to delete.

    </ParamField>

    ## Response Object

    Returns `DeletePromotionResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
