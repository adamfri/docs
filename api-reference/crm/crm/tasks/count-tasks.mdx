    <div className="wix-ref">

    Counts the number of tasks.

    This method returns the count of all tasks regardless of their `status`.

    Optionally, you can specify a filter to count only tasks that meet certain criteria.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.READ-TASKS">Read Tasks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/tasks/v2/tasks/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter which tasks to count. See [supported filters](https://dev.wix.com/docs/rest/api-reference/crm/tasks/task-v2/filter-and-sort).

      Filter tasks in the following format:

      `"filter" : {`
      "fieldName1": "value1",
      "fieldName2":&#123;"$operator":"value2"&#125;
      &#125;``

      Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      The number of tasks that match the specified filter.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_TO_COUNT` | Number of tasks exceeds the system's limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
