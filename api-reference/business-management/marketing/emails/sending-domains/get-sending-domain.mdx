      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SENDING-DOMAINS.READ">Read Sending Domains</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/sending-domains/v1/sending-domains/{sendingDomainId}
    ```

    ## Path Params

    <ParamField path="sendingDomainId" type="string" required>

      Sending domain ID.

    </ParamField>

    ## Response Object

    <ResponseField name="sendingDomain" type="SendingDomain">

    </ResponseField>
