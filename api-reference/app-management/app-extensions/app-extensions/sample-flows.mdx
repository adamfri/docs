This article presents a possible use case and corresponding sample flow that you can support. It provides a useful starting point as you plan your implementation.

## Add components to an app

When building an app, you add components such as pages or widgets, then review them before promoting an app version.

To add components to an app:

1. Call [Validate Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/validate-components) with the component operations you want to check. Use this step for local feedback before saving component configuration.
1. Call [Create Component](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/create-component) with the component's `appId`, `type`, and `data`. The `type` enum value determines the matching lower-case `ComponentData` oneof variant to send in `data`. Repeat for each component, or call [Upsert Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/upsert-components) to create or update several components for the app in a single request.
1. Call [Get Draft App Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/get-draft-app-components) with the `appId` to review the app's current draft components.
1. Call [Update Component](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/update-component) with the component's `appId`, `id`, latest `revision`, and the fields to change.
1. Optionally, call [Delete Component](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/delete-component) to delete a draft component. If you need to undo the deletion, call [Restore Deleted Component](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/restore-deleted-component), then call [Get Draft App Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/get-draft-app-components) to retrieve the restored draft component state.
1. Call [Get Max Version Of App Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/get-max-version-of-app-components) with the `appId` to confirm the latest version of each component before promoting an app version.
