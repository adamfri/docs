    Retrieves a semantic model by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ANALYTICS-AND-REPORTS.READ-SITE-ANALYTICS">Site Analytics - read permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/analytics/semantic-model/v3/semantic-models/{semanticModelId}
    ```

    ## Path Params

    <ParamField path="semanticModelId" type="string" required>

      ID of the semantic model to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="semanticModel" type="SemanticModel">

      Retrieved semantic model.

      See the [Semantic Model Object](/api-reference/business-management/analytics/semantic-models/semantic-model-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `NO_ACCOUNT_IDENTITY` | The caller isn't authenticated. Provide valid credentials and try again. |
    | `404` | `NOT_FOUND` | `SEMANTIC_MODEL_NOT_FOUND` | Couldn't find the semantic model. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
