SPI for implementing custom staff assignment algorithms in Wix Bookings, enabling sophisticated resource allocation based on business logic beyond built-in random and ranking options.

## SDK package

```bash
npm install @wix/bookings
```

Import the `staffSorting` namespace from `@wix/bookings`.
