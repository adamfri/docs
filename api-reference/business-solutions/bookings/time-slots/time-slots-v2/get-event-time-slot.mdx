    <div className="wix-ref">

    Retrieves detailed information about a specific class session time slot.

    Call this method after selecting a suitable slot with List Event Time Slots to obtain its full capacity and booking-policy status.

    ### Service type limitations

    To retrieve appointment availability, call [Get Availability Time Slot](https://dev.wix.com/docs/api-reference/business-solutions/bookings/time-slots/time-slots-v2/get-availability-time-slot).

    To retrieve course availability, follow the [End-to-End Booking Flow for courses](https://dev.wix.com/docs/api-reference/business-solutions/bookings/end-to-end-booking-flows#book-a-course).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-CALENDAR">Read Bookings Calendar Availability</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/service-availability/v2/time-slots/event/{eventId}
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID.

    </ParamField>

    ## Query Params

    <ParamField query="timeZone" type="string">

      Time zone in [IANA tz database format](https://en.wikipedia.org/wiki/Tz_database) for adjusting `fromLocalDate` and `toLocalDate` values.
      For example, `America/New_York` or `UTC`.

      Default: `timeZone` specified in the business [site properties](https://dev.wix.com/docs/api-reference/business-management/site-properties/properties/get-site-properties).

    </ParamField>

    ## Response Object

    <ResponseField name="timeSlot" type="TimeSlot">

      The time slot.

      See the [Time Slot Object](/api-reference/business-solutions/bookings/time-slots/time-slots-v2/time-slot-object) for this object's fields.

    </ResponseField>

    <ResponseField name="timeZone" type="string">

      Time zone in [IANA tz database format](https://en.wikipedia.org/wiki/Tz_database) for adjusting `fromLocalDate` and `toLocalDate` values.
      For example, `America/New_York` or `UTC`.

      Default: `timeZone` specified in the business [site properties](https://dev.wix.com/docs/api-reference/business-management/site-properties/properties/get-site-properties).

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
