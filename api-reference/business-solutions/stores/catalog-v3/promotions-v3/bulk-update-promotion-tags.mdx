      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Adds or removes tags on multiple promotions.

    Specify which tags to assign and which tags to unassign. A tag that appears in both the list to assign and the list to unassign will be assigned. Tags that don't exist are ignored.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_WRITE">Manage v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/promotions/update-tags
    ```

    ## Body Params

    <ParamField body="promotionIds" type="string[]" required>

      IDs of the promotions to update.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="assignTags" type="Tags">

      Tags to assign to the promotions.

      If the same tag ID appears in both `assignTags` and `unassignTags`, it's assigned.

    <ParamField body="unassignTags" type="Tags">
