    Updates multiple invoices.

    To update a single invoice, call [Update Invoice](https://dev.wix.com/docs/api-reference/business-management/get-paid/invoices/invoices/update-invoice).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/bulk/invoices/update
    ```

    ## Body Params

            <ParamField body="paths" type="string[]" />

          </Expandable>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the updated entities in the response.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `SITE_PROPERTIES_FAILED` | Couldn't retrieve business details from the site properties service. |
    | `428` | `FAILED_PRECONDITION` | `SUBSCRIPTION_SETTINGS_IMMUTABLE` | Subscription settings are immutable once the invoice's eCommerce order has been created (after payment is initiated). |
    | `400` | `INVALID_ARGUMENT` | `ORDER_TOTAL_EXCEEDS_LIMIT` | Invoice total must be less than 10^13. |
    | `400` | `INVALID_ARGUMENT` | `DUE_DATE_BEFORE_ISSUE_DATE` | Invoice `dueDate` is before `issueDate`. |
    | `400` | `INVALID_ARGUMENT` | `INVOICE_DATE_OUT_OF_RANGE` | Invoice `issueDate` is more than 100 years before the current time, or `dueDate` is more than 100 years after the current time. |
    | `400` | `INVALID_ARGUMENT` | `TIME_ZONE_INVALID` | Invoice `regionalProperties.timeZone` must be a valid time zone. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEMS_MUST_EXIST` | Invoice must have at least one line item. |
    | `400` | `INVALID_ARGUMENT` | `LINE_ITEMS_IDS_MUST_BE_UNIQUE` | Line item IDs must be unique. |
    | `400` | `INVALID_ARGUMENT` | `RICH_CONTENT_TOO_LARGE` | Rich content object exceeds the maximum allowed size. |
    | `400` | `INVALID_ARGUMENT` | `RICH_CONTENT_INVALID` | Rich content object couldn't be parsed. |
    | `400` | `INVALID_ARGUMENT` | `INVOICE_IDS_MUST_BE_UNIQUE` | Invoices contain duplicate invoice IDs. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Examples

    Updates multiple invoices in a single request.

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/invoices/v4/bulk/invoices/update' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        -d '{
          "invoices": [
            {
              "invoice": {
                "id": "51be0e68-75c3-4b7a-97e7-3a6643ecf3e2",
                "revision": "1",
                "dueDate": "2024-03-15T10:00:00.000Z",
                "customerInfo": {
                  "contactDetails": {
                    "email": "john.updated@techcorp.com"
                  }
                }
              },
              "fieldMask": {
                "paths": ["dueDate", "customerInfo.contactDetails.email"]
              }
            },
            {
              "invoice": {
                "id": "8f2a1b3c-4d5e-6f7a-8b9c-0d1e2f3a4b5c",
                "revision": "2",
                "customerInfo": {
                  "contactDetails": {
                    "phone": "+1-555-999-8888"
                  }
                }
              },
              "fieldMask": {
                "paths": ["customerInfo.contactDetails.phone"]
              }
            }
          ],
          "returnEntity": false
        }'
      ```

          },
          {
            "itemMetadata": {
              "id": "8f2a1b3c-4d5e-6f7a-8b9c-0d1e2f3a4b5c",

          "totalSuccesses": 2,

        }
