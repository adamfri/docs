    Submits generated mockup images for one or more products.

    Marketplace providers call this method to report completion of asynchronous mockup generation
    initiated via [Bulk Generate Mockups](https://dev.wix.com/docs/api-reference/business-solutions/suppliers-hub/marketplace-provider-service-plugin/bulk-generate-mockups).
    Include the generated mockup URL when `status` is `COMPLETED`, or set `status` to `FAILED`
    for products where generation couldn't be completed.

    Each mockup is keyed by the combination of provider, `providerProductId`, and `imageType`,
    so a product can have a separate mockup submitted for each supported image type (for example,
    `SITE_LOGO` and `CUSTOM`).

    Providers can batch results across multiple calls in any grouping&mdash;there's no requirement
    to submit all products from a given [Bulk Generate Mockups](https://dev.wix.com/docs/api-reference/business-solutions/suppliers-hub/marketplace-provider-service-plugin/bulk-generate-mockups) request in a single submission.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliershub/v2/submit-generated-mockups
    ```

    ## Body Params

    <ParamField body="mockups" type="GeneratedMockup[]">

      Mockup generation results. Include the generated mockup URL for successful generations,
      or set `status` to `FAILED` for unsuccessful ones.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="mockups properties">

        <ParamField body="providerProductId" type="string" required>

          Product ID on the provider's platform.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="mockupUrl" type="string">

          URL of the generated mockup image.

          Required when `status` is `COMPLETED`.

        </ParamField>

        <ParamField body="imageType" type="string" required>

          Type of image that was applied to generate the mockup.

          Must match the `imageType` from the original [Bulk Generate Mockups](https://dev.wix.com/docs/api-reference/business-solutions/suppliers-hub/marketplace-provider-service-plugin/bulk-generate-mockups) request
          for this product. Mockups are stored per product and image type, so a product can hold a separate
          mockup for each supported type, such as `SITE_LOGO` and `CUSTOM`.

          **Supported values:**

          - `SITE_LOGO` — Site logo automatically fetched from the Wix site's configured logo.
          - `CUSTOM` — Custom image provided by the site owner.
          - `FALLBACK` — Placeholder image used when the site has no logo and no custom image is provided. Displays "Your image here" text.

        </ParamField>

        <ParamField body="status" type="string" required>

          Mockup generation status.

          Providers typically submit `COMPLETED` or `FAILED` to report the final outcome. `PENDING`
          may be submitted to indicate that generation is still in progress, but doesn't currently
          drive any state change on the Wix side.

          **Supported values:**

          - `PENDING` — Mockup generation is in progress.
          - `COMPLETED` — Mockup generation completed successfully.
          - `FAILED` — Mockup generation failed.

        </ParamField>

      </Expandable>

    </ParamField>
