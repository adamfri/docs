    Retrieves an info section.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INFO_SECTION_READ">Read info sections in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/info-sections/{infoSectionId}
    ```

    ## Path Params

    <ParamField path="infoSectionId" type="string" required>

      Info section ID.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT`

    </ParamField>

    ## Response Object

    <ResponseField name="infoSection" type="InfoSection">

      Info section.

      See the [Info Section Object](/api-reference/business-solutions/stores/catalog-v3/info-sections-v3/info-section-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
