    <div className="wix-ref">

    Retrieves the total amount of published posts of the blog.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.READ-BLOGS">Read Blog </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v2/stats/posts/total
    ```

    ## Query Params

    <ParamField query="language" type="string">

      Language filter.

      2-or-4-letter language code in [IETF BCP 47 language tag](https://en.wikipedia.org/wiki/IETF_language_tag) format.
      Pass a language to receive the total amount of posts in that specified language.

    </ParamField>

    ## Response Object

    <ResponseField name="total" type="integer">

      Total amount of published posts.

      Constraints: `min 0`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
