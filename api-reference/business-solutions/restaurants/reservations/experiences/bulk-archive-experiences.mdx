    Archives multiple experiences.

    Archiving an experience sets `configuration.visible` to `false`, preventing it from appearing on the live site and from accepting new reservations.

    To unarchive experiences, call [Bulk Unarchive Experiences](https://dev.wix.com/docs/api-reference/business-solutions/restaurants/reservations/experiences/bulk-unarchive-experiences).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-LOCATIONS">Manage Reservation Locations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/experiences/v1/bulk/experiences/archive
    ```

    ## Body Params

    <ParamField body="experienceIds" type="string[]" required>

      IDs of the experiences to archive.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>
