    <div className="wix-ref">

    Creates a new donation campaign.

    The campaign is created in an active state and can immediately accept donations.

    <Note>

    Other than the fields marked as required, **one or both** of the following fields must be passed on create:
    + `customAmountEnabled`
    + `predefinedDonationAmounts`

    </Note>

    To create multiple donation campaigns in a single call, use [Bulk Create Donation Campaigns](https://dev.wix.com/docs/rest/business-solutions/donations/donation-campaigns/bulk-create-donation-campaigns).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DONATIONS.MANAGE-CAMPAIGNS">Manage Donation Campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/donation-campaigns/v2/donation-campaigns
    ```

    ## Body Params

    <ParamField body="donationCampaign" type="DonationCampaign" required>

      Donation campaign to create.

      See the [Donation Campaign Object](/api-reference/business-solutions/donations/donation-campaigns/donation-campaign-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="donationCampaign" type="DonationCampaign">

      Created donation campaign.

      See the [Donation Campaign Object](/api-reference/business-solutions/donations/donation-campaigns/donation-campaign-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `SITE_CURRENCY_UNAVAILABLE` | Site currency settings are temporarily unavailable. Try again later. |
    | `400` | `INVALID_ARGUMENT` | `NO_PAYMENT_DEFINITION` | Either `customAmountEnabled` must be set to `true` or at least one amount must be provided in `predefinedDonationAmounts`. |
    | `400` | `INVALID_ARGUMENT` | `NON_POSITIVE_CAMPAIGN_GOAL_AMOUNT` | The `campaignGoal.targetAmount` must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CUSTOM_AMOUNT_RANGE` | The `customAmountOptions.maximum` must be greater than `customAmountOptions.minimum`. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_PREDEFINED_AMOUNTS` | The `predefinedDonationAmounts` array contains duplicate amounts. |
    | `400` | `INVALID_ARGUMENT` | `NON_POSITIVE_PREDEFINED_AMOUNT` | All amounts in `predefinedDonationAmounts` must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_CAMPAIGN_NAME` | Campaign `name` can't be empty. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Donation Campaign Created | `wix.donations.v2.donation_campaign_created` | Triggered when a donation campaign is created. |

    </div>
