      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_REPORTS.READ-REPORTS">Read Reports</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reports/v2/reports/reason-types/count
    ```

    ## Body Params

    <ParamField body="entityName" type="string" required>

      Reported entity name. For example, `comment`.

      Constraints: `minLength 1`, `maxLength 300`.

    </ParamField>

    <ParamField body="entityId" type="string" required>

      ID of the reported entity.

      Constraints: `minLength 1`, `maxLength 300`.

    </ParamField>

    ## Response Object

    <ResponseField name="reasonTypeCount" type="ReasonTypeCount[]">

      List of reports grouped by the reason type.

      Constraints: `maxItems 100`.

      <Expandable title="reasonTypeCount properties">

        <ResponseField name="reasonType" type="string">

          Reason for report.

          **Supported values:**

          - `UNKNOWN_TYPE` — Unknown type. This value is not used.
          - `OTHER` — Entity is reported for other reasons. Specify in `details`.
          - `SPAM` — Entity is reported for spam.
          - `NUDITY_OR_SEXUAL_HARASSMENT` — Entity is reported for nudity or sexual harassment.
          - `HATE_SPEECH_OR_SYMBOLS` — Entity is reported for hate speech.
          - `FALSE_INFORMATION` — Entity is reported for false information.
          - `COMMUNITY_GUIDELINES_VIOLATION` — Entity is reported for a community guideline violation.
          - `VIOLENCE` — Entity is reported for violence.
          - `SUICIDE_OR_SELF_INJURY` — Entity is reported for mentioning suicide.
          - `UNAUTHORIZED_SALES` — Entity is reported for unuathorized sales.
          - `EATING_DISORDER` — Entity is reported for mentioning an eating disorder.
          - `INVOLVES_A_CHILD` — Entity is reported for involving a minor.
          - `TERRORISM` — Entity is reported for mentioning terrorism.
          - `DRUGS` — Entity is reported for mentioning drugs.
          - `UNLAWFUL` — Entity is reported for unlawful actions.
          - `EXPOSING_IDENTIFYING_INFO` — Entity is reported for exposing identifying details.

        </ResponseField>

        <ResponseField name="count" type="integer">

          Number of reports by reason type.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
