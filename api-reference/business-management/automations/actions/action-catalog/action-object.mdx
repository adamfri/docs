---
title: "Action Object"
description: "An action is a building block that Wix users can add to their automations."
icon: "cube"
---

An action is a building block that Wix users can add to their automations. Each action represents a unit of functionality that an app installed on the site exposes for use in automations, such as sending an SMS, creating a coupon, or assigning loyalty points.

A site's action catalog only contains actions provided by apps that are installed on the site.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Action ID. (per component version)

      **Read-only.**

    </ResponseField>

    <ResponseField name="appId" type="string">

      ID of the [app that created the action](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="actionKey" type="string">

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      **Read-only.** Constraints: `minLength 5`, `maxLength 50`.

    </ResponseField>

    <ResponseField name="inputSchema" type="object">

      Action [input schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#the-input-schema).

      **Read-only.**

    </ResponseField>

    <ResponseField name="outputSchema" type="object">

      Action [output schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#the-output-schema).

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Action display name. Users see this name when they [choose an action for an automation](https://support.wix.com/en/article/wix-automations-creating-an-automation-with-the-new-builder#step-4-choose-an-action). For example, "Send SMS" or "Create Coupon".

      **Read-only.**

    </ResponseField>

    <ResponseField name="description" type="string">

      Action description displayed in the site dashboard to Wix users.

      **Read-only.**

    </ResponseField>

    <ResponseField name="implementedMethods" type="ImplementedMethods">

      Additional [service plugin methods](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/introduction#implement-the-service-plugin-methods) implemented for this action.

      <Expandable title="implementedMethods properties">

        <ResponseField name="validateConfiguration" type="boolean">

          Whether [Validate Configuration](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/validate-configuration) is implemented.

          Default: `false`.

        </ResponseField>

        <ResponseField name="getQuotaInfo" type="boolean">

          Whether [Get Quota Info](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/get-quota-info) is implemented.

          Default: `false`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="executionType" type="string" deprecated>

      Whether the action is executed immediately or with a delay.

      > **Note:** Set up [actions with a timeout](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/introduction#action-timeouts) instead.

      **Deprecated.** Whether the action is executed immediately or with a delay.

      > **Note:** Set up [actions with a timeout](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/introduction#action-timeouts) instead. Removal: 2025-03-10.

      **Supported values:**

      - `UNKNOWN_EXECUTION_TYPE` — Unknown type.
      - `SYNC` — Action completes immediately.
      - `ASYNC` — Action completes asynchronously.

    </ResponseField>

    <ResponseField name="interfaceConfiguration" type="InterfaceConfiguration">

      Selected user interface for the action. The UI is displayed to the Wix user in the site dashboard when they configure the action.

      <Expandable title="interfaceConfiguration properties">

        <ResponseField name="type" type="string">

          Type of action configuration UI.

          **Supported values:**

          - `UNKNOWN_TYPE` — Unknown action configuration UI.
          - `GENERIC` — The generic action configuration UI. This requires you to provide a
          [UI schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#the-ui-schema).

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="options" type="options">

          options

          <Expandable title="options properties">

            <ResponseField name="genericOptions" type="GenericOptions">

              Details for the generic UI.

              <Expandable title="genericOptions properties">

                <ResponseField name="uiSchema" type="object">

                  UI schema.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="icon" type="Image">

      Action icon displayed in the [site dashboard](https://support.wix.com/en/article/about-your-wix-dashboard) to Wix users.

      <Expandable title="icon properties">

        <ResponseField name="id" type="string">

          WixMedia image ID.

        </ResponseField>

        <ResponseField name="url" type="string">

          Image URL.

        </ResponseField>

        <ResponseField name="height" type="integer">

          Original image height.

          **Read-only.**

        </ResponseField>

        <ResponseField name="width" type="integer">

          Original image width.

          **Read-only.**

        </ResponseField>

        <ResponseField name="altText" type="string">

          Image alt text.

        </ResponseField>

        <ResponseField name="filename" type="string">

          Image filename.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the action was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the action was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="baseUri" type="string">

      Action base URI. Wix calls your action at this base address.

      Learn more about the [Action Provider service plugin](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/introduction).

    </ResponseField>

  </Tab>
