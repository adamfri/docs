    Updates the specified trigger for the specified app.

    After the trigger is updated, it only contains the values specified in the request. Earlier values are replaced.

    > You cannot try out this endpoint because
    > it can be called only by the app that created the specified `triggerKey`.
    > So please ignore the **Try It Out** button.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/automations/triggercatalog/v1/trigger/{trigger.id}
    ```

    ## Path Params

    <ParamField path="trigger.id" type="string" required>

      Trigger ID. (per component version)

    </ParamField>

    ## Body Params

    <ParamField body="trigger" type="Trigger">

      Trigger to update.

      See the [Trigger Object](/api-reference/business-management/automations/triggers/trigger-catalog/trigger-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="updatedTrigger" type="Trigger">

      Updated trigger.

      See the [Trigger Object](/api-reference/business-management/automations/triggers/trigger-catalog/trigger-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
