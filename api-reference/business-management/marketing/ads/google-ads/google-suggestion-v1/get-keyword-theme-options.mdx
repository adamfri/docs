    Retrieves keyword theme suggestions matching a partial text query (autocomplete-style).
    Calls the Google Ads API directly. Use these results to help users select keyword themes interactively.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/keyword-theme-options
    ```

    ## Query Params

    <ParamField query="queryText" type="string">

      Partial keyword text to match against (autocomplete input).

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField query="languageCode" type="string">

      BCP-47 language code used to filter results to a specific language.

      Constraints: `maxLength 1000`.

    </ParamField>

    <ParamField query="countryCode" type="string">

      ISO 3166-1 alpha-2 country code used to filter results to a specific country.

      Constraints: `format COUNTRY`.

    </ParamField>

    ## Response Object

    <ResponseField name="googleSuggestion" type="GoogleSuggestion">

      Keyword theme options matching the query.

      See the [Google Suggestion Object](/api-reference/business-management/marketing/ads/google-ads/google-suggestion-v1/google-suggestion-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
