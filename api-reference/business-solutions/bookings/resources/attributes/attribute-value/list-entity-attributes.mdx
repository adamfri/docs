      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves the entity's attribute values, each paired with its attribute definition (for the name, type, and config).

    `visibility` is defined on the attribute definition and is not enforced here: results include values for non-visible attributes. When rendering public-facing output, filter out attributes whose `visibility` is `false`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ATTRIBUTES.MANAGE">Manage_Wix_Attributes_Forms_submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_api/attributes/v1/attribute-values/{entityId}
    ```

    ## Path Params

    <ParamField path="entityId" type="string" required>

      ID of the entity whose attributes to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="paging" type="CursorPaging">

      Cursor-based paging.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="entityAttributes" type="EntityAttribute[]">

      The entity's attribute values, each paired with its attribute definition. Order isn't guaranteed.

      Constraints: `maxItems 50`.

      <Expandable title="entityAttributes properties">

        <ResponseField name="attributeDefinition" type="AttributeDefinition">

          The attribute definition.

          <Expandable title="attributeDefinition properties">

            <ResponseField name="id" type="string">

              Attribute definition ID.

              **Read-only.** Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="revision" type="integer">

              Revision number, which increments by 1 each time the attribute definition is updated.
              To prevent conflicting changes, the current revision must be passed when updating.
              Ignored when creating an attribute definition.

              **Read-only.**

            </ResponseField>

            <ResponseField name="createdDate" type="datetime">

              Date and time the attribute definition was created.

              **Read-only.**

            </ResponseField>

            <ResponseField name="updatedDate" type="datetime">

              Date and time the attribute definition was last updated.

              **Read-only.**

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name for the attribute, shown to end users (for example, `Capacity`).

              Must be unique within the site. Required when creating an attribute definition.

            </ResponseField>

            <ResponseField name="valueType" type="string">

              Value type of this attribute.
              Immutable after creation. `UpdateAttributeDefinition` rejects requests that change `value_type`.
              Required when creating an attribute definition.

              **Supported values:**

              - `STRING` — String attribute: single-select from a predefined list of allowed string values.
              - `NUMBER` — Integer number attribute with a required min/max range.
              - `BOOL` — Boolean attribute (true/false).

            </ResponseField>

            <ResponseField name="visibility" type="boolean">

              Whether this attribute is shown to end users on the public site.

              - `true`: shown in the UI and available for filtering.
              - `false`: hidden from end users. Back-office admins can still see and edit the attribute.

              Default: `true`.

            </ResponseField>

            <ResponseField name="defaultValue" type="AttributeDefaultValue">

              Default value for the attribute. When a configuration change leaves a stored
              attribute value out of range or outside the allowed values, that value is reset to this
              default (see Update Attribute Definition).

              The variant must match `valueType`. Required when creating an attribute definition.

              _Nested structure omitted for brevity — see the `AttributeDefaultValue` object._

            </ResponseField>

            <ResponseField name="extendedFields" type="ExtendedFields">

              Custom field data for the attribute definition.
              [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields) must be configured in the app dashboard before they can be accessed with API calls.

              _Nested structure omitted for brevity — see the `ExtendedFields` object._

            </ResponseField>

            <ResponseField name="tags" type="Tags">

              Custom tags for organizing and filtering attribute definitions.
              Manage tags using `BulkUpdateAttributeDefinitionTags` or `BulkUpdateAttributeDefinitionTagsByFilter`.

              _Nested structure omitted for brevity — see the `Tags` object._

            </ResponseField>

          </Expandable>

          <Expandable title="One of the following">

            <ResponseField name="config" type="config">

              config

              _Nested structure omitted for brevity — see the `config` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="attributeValue" type="AttributeValue">

          The entity's value for this attribute.

          See the [Attribute Value Object](/api-reference/business-solutions/bookings/resources/attributes/attribute-value/attribute-value-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Paging metadata.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        <ResponseField name="cursors" type="Cursors">

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to the previous page in the list of results.
