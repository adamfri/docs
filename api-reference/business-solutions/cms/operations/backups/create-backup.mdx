    <div className="wix-ref">

    Creates an on-demand backup of live content in a site's collections.

    By default, all of the site's collections are included in the backup. For a partial backup, specify which collections to include in the `backup.collections` parameter.

    The process of creating a backup takes time.
    You can check whether a backup has completed successfully with List Backups.

    You can store up to 3 on-demand backups for each site.
    If 3 on-demand backups already exist, the oldest existing on-demand backup for the site is deleted when a new one is created. Automated backups are not affected.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE-BACKUPS">Manage Data Backups</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v2/backups
    ```

    ## Response Object

    <ResponseField name="backup" type="Backup">

      Details of the requested backup.

      <Expandable title="backup properties">

        <ResponseField name="id" type="string">

          Backup ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="status" type="string">

          Backup status.

          **Read-only.**

          **Supported values:**

          - `PENDING` — Backup creation is in progress.
          - `READY` — Backup has been created successfully and can be used for data restoration.
          - `FAILED` — Backup creation has failed.
          - `DELETED` — Backup has been deleted.
          - `CANCELED` — Backup has been canceled.

        </ResponseField>

        <ResponseField name="type" type="string">

          Type of backup, based on how it was triggered.

          **Read-only.**

          **Supported values:**

          - `ON_DEMAND` — Backup taken on demand.
          - `AUTO` — Backup taken automatically by the system on a regular schedule.

        </ResponseField>

        <ResponseField name="requestedDate" type="datetime">

          Date and time the backup was requested.

          **Read-only.**

        </ResponseField>

        <ResponseField name="startedDate" type="datetime">

          Date and time the backup commenced. Value is `null` until the backup process begins in the background.

          **Read-only.**

        </ResponseField>

        <ResponseField name="finishedDate" type="datetime">

          Date and time the backup process finished. Value is `null` until the backup process is completed in the background.

          **Read-only.**

        </ResponseField>

        <ResponseField name="deletedDate" type="datetime">

          Date and time the backup was deleted. Value is `null` if that backup hasn't been deleted.

          **Read-only.**

        </ResponseField>

        <ResponseField name="sizeInBytes" type="integer">

          Backup size in bytes. Value is `null` until the backup process is completed.

          **Read-only.**

        </ResponseField>

        <ResponseField name="collections" type="Collection[]">

          IDs and display names of collections the backup contains.

          **Read-only.** Constraints: `maxItems 1000`.

          <Expandable title="collections properties">

            <ResponseField name="id" type="string">

              Collection ID.

              **Read-only.** Constraints: `maxLength 255`.

            </ResponseField>

            <ResponseField name="displayName" type="string">

              Collection display name.

              **Read-only.**

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
