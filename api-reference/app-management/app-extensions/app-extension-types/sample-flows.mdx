## Discover component types before creating components

When building an app, you may need to show developers which component types are available before they create or validate component configuration.

To discover component types before creating components:

1. Call [Get Component Types Display Data](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extension-types/get-component-types-display-data) to retrieve available component type display metadata.
1. Use the returned `type`, `displayName`, `description`, `labels`, and `attributes` to show available component types in your app-building experience.
1. If `exampleComponentData` is returned, use it as a reference when preparing component `data`. The selected component `type` maps to the matching lower-case `ComponentData` oneof variant.
1. Call [Validate Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/validate-components) with the selected component type and data before saving the component configuration.
1. Call [Create Component](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/create-component) or [Upsert Components](fallback::https://dev.wix.com/docs/api-reference/app-management/app-extensions/app-extensions/upsert-components) to save the component.
