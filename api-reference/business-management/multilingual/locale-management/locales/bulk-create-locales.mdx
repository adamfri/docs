    Creates multiple secondary locales.

    <Note>

    - This method can only be called on sites where multilingual mode is enabled.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/locales/v2/bulk/locale/create
    ```

    ## Body Params

    <ParamField body="locales" type="Locale[]" required>

      Locales to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to receive the created locales in the response.

    </ParamField>
