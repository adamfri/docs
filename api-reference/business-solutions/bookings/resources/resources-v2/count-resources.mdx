    Counts resources according to given criteria.

    See [Query Resources](https://dev.wix.com/docs/api-reference/business-solutions/bookings/resources/resources-v2/query-resources) for a list of supported filters.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/resources/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter to base the count on. See [Query Resources](https://dev.wix.com/docs/api-reference/business-solutions/bookings/resources/resources-v2/query-resources) for a list of supported filters.

    </ParamField>

    <ParamField body="search" type="SearchDetails" deprecated>

      Free text to match in searchable fields. Field is deprecated due to decision to use query instead of search for performing the count.

      **Deprecated.** Free text to match in searchable fields. Field is deprecated due to decision to use query instead of search for performing the count. Removal: 2024-05-01.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Search mode. Defines the search logic for combining multiple terms in the `expression`.

          **Supported values:**

          - `OR` — At least 1 of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `locationOptions.availableInAllLocations`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total number of resources matching the filter.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
