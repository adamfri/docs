With the Locations API, Wix users can define multiple physical locations for their business. This allows them to set individual opening hours for each location.

The Locations API allows you to:

* [List](fallback::https://dev.wix.com/docs/rest/business-management/locations/list-locations) existing locations.
* [Create](fallback::https://dev.wix.com/docs/rest/business-management/locations/create-location), [update](fallback::https://dev.wix.com/docs/rest/business-management/locations/update-location), and [archive](fallback::https://dev.wix.com/docs/rest/business-management/locations/archive-location) locations.
* [Set a default location](fallback::https://dev.wix.com/docs/rest/business-management/locations/set-default-location) that is reflected in the site properties.

Read more about how Wix users can manage their [location specific bookings](fallback::https://support.wix.com/en/article/wix-bookings-offering-services-at-multiple-locations). You can also read more about how to retrieve the [site properties](fallback::https://dev.wix.com/docs/rest/business-management/site-properties/properties/get-site-properties).

## Before you begin
It’s important to note the following before starting to code:

+ Locations can't be deleted. Instead, you can archive a location using [Archive Location](fallback::https://dev.wix.com/docs/rest/business-management/locations/archive-location). Archiving is permanent; archived locations can't be unarchived.
+ The default location can't be archived.
+ The [Update Location](fallback::https://dev.wix.com/docs/rest/business-management/locations/update-location) method completely overrides an existing location. Currently, you can't partially update a location.
+ Currently, the location type is just informational and doesn't affect a location's functionality.
+ The `INACTIVE` location status isn't currently supported.
+ The [Wix Bookings API](https://dev.wix.com/docs/rest/business-solutions/bookings/about-wix-bookings) doesn't support the `businessSchedule` object.

## Terminology

+ **Default location:** Location reflected in the [site properties](fallback::https://dev.wix.com/docs/rest/business-management/site-properties/properties). This location is used on invoices.
+ **Type:** Describes whether a location is an office, reception, branch or the headquarters.
+ **Status:** Indicates whether a location is `"ACTIVE"` or `"INACTIVE"`.
+ **Business Schedule:** Describes the location's regular and exceptional opening hours.
    - **Period:** Regular, weekly opening hours of the location.
    - **Special Hour Period:** Exception to the location's regular hours. The location can be either open or closed during the **Special Hour Period**.
