    Removes an item's own SEO tags, so that it inherits its tags again.

    Only the tags set for the item are removed. The item itself isn't affected. After this
    call `hasOverride` is `false`, and `resolvedTags` reports the tags the item now
    inherits. Any `noindex` directive that was set on the item is removed with its tags, so
    the item can be indexed again.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/seo/v1/item-seo-tags/{itemType}/{itemId}/reset-to-default
    ```

    ## Path Params

    <ParamField path="itemType" type="string" required>

      Type of item to remove tags from. For example, `STATIC_PAGE` or `STORES_PRODUCT`.

    </ParamField>

    <ParamField path="itemId" type="string" required>

      ID of the item to remove tags from.

    </ParamField>

    ## Response Object

    <ResponseField name="itemSeoTags" type="ItemSeoTags">

      Item SEO tags after the item's own tags were removed.

      See the [Item Seo Tags Object](/api-reference/business-management/seo/item-seo-tags-v1/item-seo-tags-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_ITEM_TYPE` | Wix doesn't support the specified `itemType`. The error message lists the item types that are supported. |
    | `404` | `NOT_FOUND` | `ITEM_NOT_FOUND` | Couldn't find the item. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
