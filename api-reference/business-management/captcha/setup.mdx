@package_metadata:@wix/captcha

To use the Captcha API, install the `@wix/captcha` package.

#### Install the package

Follow the installation instructions for your development environment.

| Development environment | Installation method |
|--|--|
| Wix sites (editor or IDE) | Use the [package manager](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-in-the-editor). |
| Wix sites (local IDE) | Run `wix install @wix/captcha` using the [Wix CLI](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-with-the-wix-cli).|
| Blocks apps | Use the same installation method as Wix sites. |
| CLI and self-hosted apps | Run `npm install @wix/captcha` or `yarn add @wix/captcha`. |
| Headless sites and apps | Run `npm install @wix/captcha` or `yarn add @wix/captcha`. |

#### Import the package

To import the package in your code:

```js
import { captcha } from '@wix/captcha'
```
