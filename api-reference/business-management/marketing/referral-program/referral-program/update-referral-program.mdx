    <div className="wix-ref">

    Updates a referral program. Supports partial updates.

    Revision number, which increments by 1 each time the referral program is updated.
    To prevent conflicting changes, the current revision must be passed when updating the referral program.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/_api/referral-programs/v1/program
    ```

    ## Body Params

    <ParamField body="referralProgram" type="ReferralProgram" required>

      Referral program to update. Include the latest `revision` for a successful update.

      See the [Program Object](/api-reference/business-management/marketing/referral-program/referral-program/program-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="referralProgram" type="ReferralProgram">

      Updated referral program.

      See the [Program Object](/api-reference/business-management/marketing/referral-program/referral-program/program-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
