    <div className="wix-api-columns">

    <div className="wix-ref">

    Updates an OAuth app.

    Only fields provided in `mask.paths` are updated.

    You can update the following fields:
    + `name`
    + `description`
    + `allowedDomain`
    + `loginUrl`
    + `logoutUrl`
    + `technology`

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.OAUTH_APP.MANAGE">Manage OAuth Apps</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/oauth-app/v1/oauth-apps/{oAuthApp.id}
    ```

    ## Path Params

    <ParamField path="oAuthApp.id" type="string" required>

      ID of the OAuth app.

    </ParamField>

    ## Body Params

    <ParamField body="oAuthApp" type="OAuthApp" required>

      Updated OAuth app details. May include some or all fields.

      See the [O Auth App Object](/api-reference/business-management/headless/oauth-apps/o-auth-app-object) for this object's fields.

    </ParamField>

    <ParamField body="mask" type="FieldMask">

      Explicit list of fields to update. Only fields listed are updated.

      <Expandable title="mask properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="oAuthApp" type="OAuthApp">

      Updated OAuth app info.

      See the [O Auth App Object](/api-reference/business-management/headless/oauth-apps/o-auth-app-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | OAuth App Updated | `wix.headless.v1.o_auth_app_updated` | Triggered when an OAuth app is updated. |

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      ID of the OAuth app.

      **Read-only.**

    </ParamField>

    <ParamField body="oAuthApp" type="UpdateOAuthApp" required>

      Updated OAuth app details. May include some or all fields.

      <Expandable title="oAuthApp properties">

        <ParamField body="_id" type="string">

          ID of the OAuth app.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the OAuth app was created, in ISO 8601 format.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Display name of the OAuth app, as it appears in the dashboard.

        </ParamField>

        <ParamField body="description" type="string">

          Description of the OAuth app, as it appears in the dashboard.

        </ParamField>

        <ParamField body="secret" type="string">

          For internal use only.

          **Read-only.**

        </ParamField>

        <ParamField body="loginUrl" type="string">

          External login URL to which users are redirected automatically to authenticate. If no login URL is specified, the user is redirected to Wix to authenticate.

        </ParamField>

        <ParamField body="allowedRedirectUris" type="string[]">

          List of URIs to which redirection from Wix is allowed after authentication.

          When a client redirects a user to Wix for authentication, the client provides a URI to redirect the user back to after the user has been authenticated.
          Wix only redirects the user if the exact URI is contained in this array.

          Constraints: `format URI`, `maxItems 20`.

        </ParamField>

        <ParamField body="allowedRedirectDomains" type="string[]">

          List of domains to which redirection from Wix is allowed after processes other than authentication.

          When a client redirects a user to a Wix page (for example, for checkout), the client provides a URL to redirect the user back to.
          Wix only redirects the user if the URL is in one of the specified domains.

          Constraints: `maxItems 20`.

        </ParamField>

        <ParamField body="allowSecretGeneration" type="boolean">

          For internal use only.

        </ParamField>

        <ParamField body="logoutUrl" type="string">

          External logout URL to which we invoke when user logout at wix. If no logout URL is specified, the user is logged out only at Wix.

        </ParamField>

        <ParamField body="applicationType" type="string">

          OAuth application type.

          **Supported values:**

          - `WEB_APP` — OAuth app type is a web application.
          - `MOBILE` — OAuth app type is a mobile application.
          - `OTHER` — OAuth app type is some other type of application.

        </ParamField>

        <ParamField body="technology" type="string">

          OAuth technology used by the oauth application.

          **Supported values:**

          - `JAVASCRIPT` — OAuth technology using JavaScript.
          - `ANGULAR` — OAuth technology using Angular.
          - `VUE` — OAuth technology using Vue.js.
          - `REACT` — OAuth technology using React.
          - `REACT_NATIVE` — OAuth technology using React Native.
          - `IOS` — OAuth technology using iOS.
          - `ANDROID` — OAuth technology using Android.
          - `OTHER_TECHNOLOGY` — OAuth technology using some other kind of technology.

        </ParamField>

        <ParamField body="wixPagesDomainsMappings" type="WixPagesDomainMapping[]">

          List of domain mappings from external domains to Wix domains.
          When a user accesses a non-Wix domain, they can be automatically forwarded to the corresponding
          Wix domain based on these mappings. This enables domain-level redirection from
          external domains to Wix-hosted pages.

          Constraints: `maxItems 200`.

          <Expandable title="wixPagesDomainsMappings properties">

            <ParamField body="origin" type="string">

              Constraints: `maxLength 2048`.

            </ParamField>

            <ParamField body="destination" type="string">

              Constraints: `maxLength 2048`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="redirectUrlWixPages" type="string">

          Redirect url for Wix-hosted pages.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="mask" type="FieldMask" required>

      Explicit list of fields to update. Only fields listed are updated.

      <Expandable title="mask properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>
