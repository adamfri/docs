    Retrieves a list of triggers, given the provided paging, filtering, and sorting.

    Query Triggers searches the entire trigger catalog, regardless of which apps are installed on a site. To retrieve only the triggers available on a specific site, call Resolve Triggers instead. To query all triggers provided by a particular app, specify the app's ID in the query's `filter`. Query Triggers returns the latest version of each matching trigger.

    Query Triggers runs with these defaults, which you can override:

    - `createdDate` is sorted in `DESC` order.
    - `paging.limit` is `50`.
    - `paging.offset` is `0`.

    To learn about working with Query methods, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language), [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging), and [Field Projection](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `appId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `triggerKey` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `displayName` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `source.type` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `metadata.hidden` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `implementedMethods.validateConfiguration` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `implementedMethods.getDynamicSchema` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `implementedMethods.refreshPayload` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
