    <div className="wix-ref">

    Retrieves a gift card.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.READ-GIFT-CARDS">Read Gift Cards</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/gift-cards/{code}
    ```

    ## Path Params

    <ParamField path="code" type="string" required>

      Gift card code.

    </ParamField>

    ## Body Params

    <ParamField body="context" type="Context">

      Contextual information for the request, including the physical location ID if applicable.

      <Expandable title="context properties">

        <ParamField body="locationId" type="string">

          Physical location ID. Can be based on the Locations API or an external provider.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="appId" type="string">

      App ID of the gift card provider.

    </ParamField>

    <ParamField body="pin" type="string">

      Gift card PIN.
      Required for some providers, like 'Moneris'.

    </ParamField>

    ## Response Object

    <ResponseField name="giftCard" type="GiftCard">

      Retrieved gift card.

      See the [Gift Card Object](/api-reference/business-solutions/e-commerce/payments/gift-cards/gift-cards/gift-card-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `GIFT_CARD_NOT_FOUND` | Gift card not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
