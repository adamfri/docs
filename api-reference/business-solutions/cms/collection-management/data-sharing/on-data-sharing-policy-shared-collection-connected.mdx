Triggered when a new connection is created, which means a collection is shared with another site.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.data.v1.data_sharing_policy_shared_collection_connected` |
| Package | `@wix/data` |
| Permissions | `Manage Data Collection Sharing` |

## Examples

<CodeGroup>

  ```javascript onDataSharingPolicySharedCollectionConnected
  import { sharing } from '@wix/data';

  sharing.onDataSharingPolicySharedCollectionConnected((event) => {
      // handle your event here
  });
  ```

  ```javascript onDataSharingPolicySharedCollectionConnected (self-managed)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { sharing } from '@wix/data';

    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
    }),
    modules: {
        sharing,
      },
  });

  wixClient.sharing.onDataSharingPolicySharedCollectionConnected((event) => {
      // handle your event here
  });
  ```
