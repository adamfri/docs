    Updates a `serviceOptionsAndVariants` object.

    Currently, only a single option is supported per `serviceOptionsAndVariants` object.

    If you want to update `variants`, you must pass the entire list of supported
    variants, not only newly added variants.

    If you want to update `options`, you must pass the entire list of supported
    options, not only newly added options.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bookings/v1/serviceOptionsAndVariants/{serviceOptionsAndVariants.id}
    ```

    ## Path Params

    <ParamField path="serviceOptionsAndVariants.id" type="string" required>

      ID of the `serviceOptionsAndVariants` object.

    </ParamField>

    ## Body Params

    <ParamField body="serviceOptionsAndVariants" type="ServiceOptionsAndVariants" required>

      `ServiceOptionsAndVariants` object to update.

      See the [Service Options And Variants Object](/api-reference/business-solutions/bookings/services/service-options-and-variants/service-options-and-variants-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="serviceOptionsAndVariants" type="ServiceOptionsAndVariants">

      Updated `serviceOptionsAndVariants` object.

      See the [Service Options And Variants Object](/api-reference/business-solutions/bookings/services/service-options-and-variants/service-options-and-variants-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNKNOWN_OPTION_IDS` | Unknown option IDs in the `variants` array. |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_CURRENCIES` | Multiple currencies in the `variants` array. All variants must use the same currency. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_OPTION_TYPE` | The passed option type isn't supported for the passed service. Staff member based variants require that the service's schedule has staff members defined as `scheduleOwnerId` in the active schedule's `availability.linkedSchedules` array. |
    | `400` | `INVALID_ARGUMENT` | `UNKNOWN_STAFF_IDS` | All resource IDs passed in `variants.values.choices.staffMemberId` must be connected to the service's schedule, defined as `scheduleOwnerId` in the active schedule's `availability.linkedSchedules` array. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_STAFF_VARIANTS` | All staff members providing the service must have their associated resource IDs specified in the `variants` array. Either add missing resource IDs to `variants.values.choices.staffMemberId`, or remove them from the service schedule's `scheduleOwnerId`s in the active schedule's `availability.linkedSchedules` array. |
    | `400` | `INVALID_ARGUMENT` | `IDENTICAL_CHOICES` | Remove identical choices from the request. Note that choices aren't case sensitive. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_CUSTOM_CHOICES` | All custom choices must be provided in the `variants` array. Either add missing variants or remove unnecessary choices. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_OPTION_DATA` | Passing `customData` isn't supported for the passed `options.values.type`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
