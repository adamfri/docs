Triggered when a branch is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.editor.branches.v1.branch_updated` |
| Package | `@wix/editor-branches` |
| Permissions | `Manage SEO Settings`, `Manage Site Branches` |
