    <div className="wix-ref">

    This method requests information about remaining quota in the plan.
    A Wix user can purchase a paid plan from your site or utilize a free plan
    if you offer one.
    You provide information about the current plan including how many searches remain
    out of the total in the plan, the dates of the plan, and whether the user currently has a paid plan.

    Wix calls this method when a Wix user opens the SEO page of the Dashboard.

    ## Endpoint

    ```http
    POST /v1/get-quota
    ```

    ## Response Object

    <ResponseField name="quota" type="Quota">

      *Required if `quotaEnabled` is `true` in the configuration**. Information about remaining credit in the plan.

      <Expandable title="quota properties">

        <ResponseField name="remaining" type="integer">

          *Required**. Number of searches left until the end of the current quota cycle.

        </ResponseField>

        <ResponseField name="limit" type="integer">

          *Required**. Total number of searches available in the current quota cycle.

        </ResponseField>

        <ResponseField name="startDate" type="datetime">

          *Required**. Start date and time of the current quota cycle as UTC datetime in `YYYY-MM-DDThh:mm[:ss][.sss]Z` format.

        </ResponseField>

        <ResponseField name="endDate" type="datetime">

          *Required**. End date and time of the current quota cycle as UTC datetime in `YYYY-MM-DDThh:mm[:ss][.sss]Z` format.
          After this time, the quota is reset

        </ResponseField>

        <ResponseField name="paidPlan" type="boolean">

          *Required**. Whether the user currently has a paid plan.
          If `false`, the user is offered an upgrade using the `upgradeUrl` from the configuration.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `429` | `RESOURCE_EXHAUSTED` | `QUOTA_LIMIT_REACHED` |  |
    | `401` | `UNAUTHENTICATED` | `MISSING_TOKEN` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
