    <div className="wix-api-columns">

    <div className="wix-ref">

    Checks whether a draft can be created for an order.

    If `orderDraftable` returns as `true`, the order can be used to create a draft order.

    If `orderDraftable` returns as `false`, refer to the `nonDraftableReasons` array in the response to understand why the order is not draftable.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/draft-orders/{orderId}/draftability
    ```

    ## Path Params

    <ParamField path="orderId" type="string" required>

      Order ID.

    </ParamField>

    ## Response Object

    <ResponseField name="orderId" type="string">

      Order ID.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="orderDraftable" type="boolean">

      Whether a draft can be created based on the order.

    </ResponseField>

    <ResponseField name="nonDraftableReasons" type="string[]">

      Reasons why a draft order cannot be created from the order.

      Constraints: `minItems 0`, `maxItems 5`.

      **Supported values:**

      - `PARTIALLY_OR_FULLY_REFUNDED` — Modifications of refunded orders are not supported.
      - `UNSUPPORTED_CHANNEL_TYPE` — Original order must be created via one of the following channel types:
      + WEB
      + POS
      + BACKOFFICE_MERCHANT
      + WIX_APP_STORE
      - `ORDER_STATUS_IS_NOT_SUPPORTED` — Order status is not APPROVED.
      - `ORDER_AND_SITE_CURRENCIES_ARE_INCONSISTENT` — Site and order currencies are different.
      - `ORDER_AND_SITE_WEIGHT_UNITS_ARE_INCONSISTENT` — Site and order weight units are different.
      - `ORDER_NOT_FOUND` — Order not found.
      - `SUBSCRIPTION_LINE_ITEM_EXISTS` — Modifications of orders with subscription items are not supported.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | — | Couldn't find the order. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
