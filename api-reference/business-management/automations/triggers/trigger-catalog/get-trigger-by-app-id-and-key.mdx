    Retrieves a trigger by app ID and trigger key.

    Use this to retrieve the full details of a single trigger provided by an app, including its payload schema and filter fields.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/v1/triggers/apps/{appId}/keys/{triggerKey=**}
    ```

    ## Path Params

    <ParamField path="appId" type="string" required>

      ID of the [app that created the trigger](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/add-a-trigger-to-your-app).

    </ParamField>

    ## Query Params

    <ParamField query="triggerKey" type="string" required>

      Trigger key.

      Learn more about [adding a trigger to your app](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/add-a-trigger-to-your-app).

    </ParamField>

    <ParamField query="enrichWithIdentitySchema" type="boolean">

      When the trigger payload schema includes the [`identityType` annotation](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/the-trigger-payload-schema#identitytype), whether to include the full schema of that identity type. For example, when `true` and the `identityType` is `contact`, the full [contact schema](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/contacts/contact-v4/contact-object) is returned.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="trigger" type="Trigger">

      The requested trigger.

      See the [Trigger Object](/api-reference/business-management/automations/triggers/trigger-catalog/trigger-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
