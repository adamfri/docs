    <div className="wix-ref">

    Adds a page to the current Wix user's list of favorite dashboard pages. If the Wix user doesn't have a list, the method creates a new list and adds the favorite page to it.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-OS.MANAGE_DASHBOARD">Manage Dashboard</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/dashboard/v1/user-favorite-list/add-favorite
    ```

    ## Body Params

    <ParamField body="favorite" type="Favorite" required>

      Favorite page to add to the list.

      <Expandable title="favorite properties">

        <ParamField body="id" type="string">

          Favorite ID. Automatically generated by Wix.

        </ParamField>

        <ParamField body="pageId" type="string">

          ID of the page added to the list.

          Constraints: `minLength 1`, `maxLength 200`.

        </ParamField>

        <ParamField body="relativeUrl" type="string">

          Relative URL appended to the page's URL for customizing the navigation. It can include path segments, a query string, or a fragment identifier.

        </ParamField>

        <ParamField body="title" type="string">

          Custom title displayed in the list of favorite pages.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="favoriteList" type="DashboardFavoriteList">

      Updated dashboard favorite list.

      See the [Favorite List Object](/api-reference/business-management/dashboard/dashboard-favorite-list/favorite-list-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Favorite List Created | `wix.dashboard.v1.favorite_list_created` | Triggered when the dashboard favorite list is created. |
    | Favorite List Updated | `wix.dashboard.v1.favorite_list_updated` | Triggered when the dashboard favorite list is updated. |

    </div>
