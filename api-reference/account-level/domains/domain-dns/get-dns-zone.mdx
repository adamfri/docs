  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the DNS zone belonging to the domain from
    [Google's Cloud DNS](https://cloud.google.com/dns).

    <Note>

    This call requires an account level API key and cannot be authenticated with the standard authorization header.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="DOMAINS.READ_DNS_ZONES">DOMAINS.READ_DNS_ZONES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    GET https://www.wixapis.com/domains/v1/dns-zones/{domainName}
    ```

    ## Path Params

    <ParamField path="domainName" type="string" required>

      Domain to retrieve the DNS zone for.

    </ParamField>

    ## Response Object

    <ResponseField name="dnsZone" type="DnsZone">

      Retrieved DNS zone.

      See the [Dns Zone Object](/api-reference/account-level/domains/domain-dns/dns-zone-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
