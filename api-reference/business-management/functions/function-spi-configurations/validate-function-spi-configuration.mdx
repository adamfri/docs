    <div className="wix-ref">

    Validates a service plugin configuration against the service plugin schema without creating it.

    Learn more about [service plugin schema and configurations](https://dev.wix.com/docs/api-reference/business-management/functions/about-service-plugins-and-wix-functions#service-plugin-schema-and-configurations).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/functions/v1/function-spi-configurations/validate
    ```

    ## Body Params

    <ParamField body="functionSpiConfiguration" type="FunctionSpiConfiguration" required>

      Service plugin configuration to validate.

      See the [Spi Configuration Object](/api-reference/business-management/functions/function-spi-configurations/spi-configuration-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="valid" type="boolean">

      Whether the service plugin configuration is valid.

    </ResponseField>

    <ResponseField name="validationErrors" type="FunctionSpiConfigurationError[]">

      List of validation errors for the service plugin configuration.

      Constraints: `maxItems 100`.

      <Expandable title="validationErrors properties">

        <ResponseField name="errorType" type="string">

          Type of validation error.

          **Supported values:**

          - `MISSING_REQUIRED_FIELD` — Required field is missing from the configuration.
          - `TYPE_MISMATCH` — Field value has incorrect data type.
          - `SCHEMA_MISMATCH` — Configuration structure doesn't match the expected schema.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
