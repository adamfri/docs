    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the version of Stores Catalog installed on a site.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CATALOG_READ_LIMITED">Read v3 catalog (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v3/provision/version
    ```

    ## Response Object

    <ResponseField name="catalogVersion" type="string">

      The version of Stores Catalog installed on a site.

      **Supported values:**

      - `V1_CATALOG` — Version 1 of the catalog.
      - `V3_CATALOG` — Version 3 of the catalog.
      - `STORES_NOT_INSTALLED` — Stores app is not installed.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      ~~~cURL
      curl -X GET \
          'https://www.wixapis.com/stores/v3/provision/version' \
          -H 'Content-type: application/json' \
          -H 'Authorization: <AUTH>'
      ~~~
      ```

      ```json Response
      ~~~json
      {
          "catalogVersion": "V3_CATALOG"
      }
      ~~~
      ```
