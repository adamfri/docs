    <div className="wix-ref">

    Creates the SEO configuration for the current site.

    If a configuration already exists for the site, this method returns an `ALREADY_EXISTS` error.
    Use [Update Seo User Config](https://dev.wix.com/docs/api-reference/business-management/marketing/seo/seo-user-config/update-seo-user-config)
    to modify an existing configuration.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="seo_user_config:v1:seo_user_config:create_seo_user_config">seo_user_config:v1:seo_user_config:create_seo_user_config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/seo/user-config/v1/seo-user-configs
    ```

    ## Body Params

    <ParamField body="seoUserConfig" type="SeoUserConfig" required>

      SEO configuration to create.

      See the [Seo User Config Object](/api-reference/business-management/marketing/seo/seo-user-config/seo-user-config-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="seoUserConfig" type="SeoUserConfig">

      Created SEO configuration.

      See the [Seo User Config Object](/api-reference/business-management/marketing/seo/seo-user-config/seo-user-config-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">
