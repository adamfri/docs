<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Removes all items from a collection.

    If any items in other collections reference the removed items in reference or multi-reference fields, those fields are cleared.

    <Note>

    Once items have been removed from a collection, they can't be restored.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.WRITE">Write Data Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v2/items/truncate
    ```

    ## Body Params

    <ParamField body="dataCollectionId" type="string" required>

      ID of the collection to truncate.

      Constraints: `maxLength 256`.

    </ParamField>

    ## Response Object

    Returns `TruncateDataItemsResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Item Deleted | `wix.data.v2.data_item_deleted` | Triggered when a data item is deleted or truncated. |

    </div>
