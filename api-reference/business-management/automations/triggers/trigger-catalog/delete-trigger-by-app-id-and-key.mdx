    Deletes a trigger from the specified app.

    <Note>

    [Automations that have the deleted trigger](https://support.wix.com/en/article/wix-automations-creating-an-automation-with-the-new-builder#step-2-choose-a-trigger) no longer run.
    You cannot try out this endpoint because
    it can be called only by the app that created the specified `triggerKey`.
    So please ignore the **Try It Out** button.

    </Note>

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/automations/triggercatalog/v1/trigger
    ```

    ## Query Params

    <ParamField query="triggerAppId" type="string" required>

      ID of the [app that created the trigger](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/add-a-trigger-to-your-app).

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="triggerKey" type="string" required>

      Trigger key.

      Learn more about how trigger providers [add triggers to their app](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/add-a-trigger-to-your-app).

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    Returns `DeleteTriggerByAppIdAndKeyResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
