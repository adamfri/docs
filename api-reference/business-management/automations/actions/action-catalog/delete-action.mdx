<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    <Info>

      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Deletes an action from the specified app.

    <Note>

    [Automations that include the deleted action](https://support.wix.com/en/article/wix-automations-creating-an-automation-with-the-new-builder#step-4-choose-an-action) can no longer execute it.

    </Note>

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/automations/actioncatalog/v1/action
    ```

    ## Query Params

    <ParamField query="actionAppId" type="string" required>

      ID of the app that defines the action.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField query="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    Returns `DeleteActionResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTION_NOT_FOUND` | No action exists for the requested app and action key. |
    | `403` | `PERMISSION_DENIED` | `UNAUTHORIZED_APP` | The caller is not authorized to manage actions for the requested app. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
