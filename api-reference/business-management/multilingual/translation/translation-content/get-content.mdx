    Retrieves a translation content item.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.READ_TRANSLATION_CONTENT">Wix Multilingual - Translation Content + Published Content Read</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/translation-content/v1/contents/{contentId}
    ```

    ## Path Params

    <ParamField path="contentId" type="string" required>

      ID of the translation content to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="content" type="Content">

      The requested translation content.

      See the [Content Object](/api-reference/business-management/multilingual/translation/translation-content/content-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
