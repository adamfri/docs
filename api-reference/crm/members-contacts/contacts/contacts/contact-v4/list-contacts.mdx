    Retrieves a list of up to 1,000 contacts per request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.READ-CONTACTS">Read Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/contacts
    ```

    ## Query Params

    <ParamField query="sort" type="Sorting">

      [Sort order](https://dev.wix.com/api/rest/contacts/contacts/sort-and-filter).

      <Expandable title="sort properties">

        <ParamField query="fieldName" type="string">

          Field to sort by.

          Supported properties:
          `createdDate`, `lastActivity.activityDate`, `primaryInfo.email`, `info.name.first`, `info.name.last`, `info.company`,
          `info.jobTitle`, `info.birthdate`

          Constraints: `maxLength 100`.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.
          Use `ASC` for ascending order or `DESC` for descending order.

          Defaults to `ASC`.

          **Supported values:**

          - `ASC`
          - `DESC`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="paging" type="Paging">

      [Pagination](https://dev.wix.com/api/rest/getting-started/pagination), defaults to offset = 0 and limit = 50 (max limit 1,000).

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to return. Learn more about pagination in [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#paging).

          Default: `50`. &lt;br>
          Maximum: `1000`.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="fields" type="string[]">

      List of projected fields to return.
      If both `fields` and `fieldsets` are sent in the request,
      the union of both lists is returned.
      `id` and `revision` are always returned.

      Supported properties:
      `source`, `createdDate`, `updatedDate`, `lastActivity`, `primaryInfo`,
      `info.name`, `info.emails`, `info.phones`, `info.addresses`, `info.company`,
      `info.jobTitle`, `info.picture`, `info.birthdate`, `info.locale`,
      `info.labelKeys`, `info.locations`, `info.extendedFields`

      Constraints: `maxLength 100`, `maxItems 100`.

    </ParamField>

    <ParamField query="fieldsets" type="string[]">

      Constraints: `maxItems 10`.

      **Supported values:**

      - `BASIC` — name, primaryEmail, primaryPhone
      - `COMMUNICATION_DETAILS` — name, phones, emails, addresses
      - `EXTENDED` — name, primaryInfo(email, phone), extendedFields
      - `FULL` — Full contact object

    </ParamField>
