    Retrieves a list of tasks, given the specified paging, filtering, and sorting.

    Query Tasks runs with the following defaults, which you can override:
    - `createdDate` in `DESC` order

    For field support for filters and sorting, see [Tasks: Supported Filters and Sorting](https://dev.wix.com/docs/rest/api-reference/crm/tasks/task-v2/filter-and-sort).

    To learn about working with _Query_ methods, see [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language), [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging), and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte` | Sort: `ASC`, `DESC` |
    | `dueDate` | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte` | Sort: `ASC`, `DESC` |
    | `status` | `$eq`, `$ne`, `$in`, `$nin` | None |
    | `contact.id` | `$eq`, `$ne`, `$in`, `$exists` | None |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
