Triggered when a connection is disconnected, which means a collection is removed from the site it was previously shared with.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.data.v1.data_sharing_policy_shared_collection_disconnected` |
| Package | `@wix/data` |
| Permissions | `Manage Data Collection Sharing` |

      // handle your event here
  });

  ```javascript onDataSharingPolicySharedCollectionDisconnected (self-managed)

      publicKey: 'YOUR_APP_PUBLIC_KEY',
    }),
    modules: {
        sharing,
      },
  });

      // handle your event here
  });
  ```
