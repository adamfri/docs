      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves a list of search terms that triggered a campaign's ads, given the provided filtering and sorting.
    Supports both Smart campaigns and Performance Max Leads campaigns. Uses the Wix internal campaignId instead of the Google Ads resource name.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v2/search-term-metrics
    ```

    ## Body Params

    <ParamField body="campaignId" type="string" required>

      Wix internal campaign ID (GUID) of the campaign to query.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="searchTermText" type="string">

      Filters results to search terms whose text contains this string. When omitted, all search terms are returned.

    </ParamField>

    <ParamField body="searchTermTextsFilter" type="SearchTermTextsFilter">

      Filters results to an explicit list of search term texts. When combined with searchTermText, only terms matching both conditions are returned.

      <Expandable title="searchTermTextsFilter properties">

        <ParamField body="type" type="string">

          Whether to include or exclude search terms that match the provided list.

          **Supported values:**

          - `UNSPECIFIED` — Unknown filter type. Do not use.
          - `MATCH` — Return only search terms that appear in the provided list.
          - `NOT_MATCH` — Return only search terms that do not appear in the provided list.

        </ParamField>

        <ParamField body="searchTermTexts" type="string[]">

          Exact search term texts to filter by.

          Constraints: `maxLength 1000`, `maxItems 1000`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="dateRange" type="DateRange">

      Date range to query. When omitted, defaults to the campaign lifetime.

      <Expandable title="One of the following">

        <ParamField body="Range" type="Range">

          Range

          <Expandable title="Range properties">

            <ParamField body="custom" type="CustomDateRange">

              Custom date range.

              _Nested structure omitted for brevity — see the `CustomDateRange` object._

            </ParamField>

            <ParamField body="predefined" type="string">

              Predefined date range.

              **Supported values:**

              - `UNSPECIFIED` — Not specified.
              - `TODAY` — Today only.
              - `YESTERDAY` — Yesterday only.
              - `LAST_7_DAYS` — The last 7 days not including today.
              - `LAST_BUSINESS_WEEK` — The 5 day business week, Monday through Friday, of the previous business week.
              - `THIS_MONTH` — All days in the current month.
              - `LAST_MONTH` — All days in the previous month.
              - `LAST_14_DAYS` — The last 14 days not including today.
              - `LAST_30_DAYS` — The last 30 days not including today.
              - `THIS_WEEK_SUN_TODAY` — The period between the previous Sunday and the current day.
              - `THIS_WEEK_MON_TODAY` — The period between the previous Monday and the current day.
              - `LAST_WEEK_SUN_SAT` — The 7-day period starting with the previous Sunday.
              - `LAST_WEEK_MON_SUN` — The 7-day period starting with the previous Monday.
              - `LIFETIME` — Since the beginning of the campaign.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="sort" type="SearchTermSorting">

      Sorting to apply. Defaults to descending by cost when omitted.

      <Expandable title="sort properties">

        <ParamField body="field" type="string">

          Metric field to sort by.

          **Supported values:**

          - `UNSPECIFIED` — Unknown field. Do not use.
          - `IMPRESSIONS` — Number of times the ad was shown for this search term.
          - `CLICKS` — Number of clicks on the ad for this search term.
          - `COST` — Total amount spent on ads triggered by this search term, in the account's currency.
          - `SEARCH_TERM` — The search term text entered by the user.

        </ParamField>

        <ParamField body="order" type="string">

          Sort direction.

          **Supported values:**

          - `ASC` — Ascending order.
          - `DESC` — Descending order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="paging" type="Paging">

      Paging to apply.

      <Expandable title="paging properties">

        <ParamField body="nextPageToken" type="string">

          Token for retrieving the next page of results.

        </ParamField>

        <ParamField body="pageSize" type="integer">

          Number of results to return.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="SearchTermMetrics[]">

      Per-search-term metric results for the requested page.

        <ResponseField name="impressions" type="integer">

          The search term text entered by the user that triggered the ad.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="summaryRow" type="SearchTermMetrics">

      Aggregated totals across all search terms, not just the current page.

      <Expandable title="summaryRow properties">

        <ResponseField name="impressions" type="integer">

          Number of times the ad was shown for this search term.

          **Read-only.**

        </ResponseField>

        <ResponseField name="clicks" type="integer">

          Number of clicks on the ad for this search term.

          **Read-only.**

        </ResponseField>

          Total amount spent on ads triggered by this search term, in the account's currency.

          **Read-only.**

        <ResponseField name="searchTerm" type="string">

          The search term text entered by the user that triggered the ad.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="nextPageToken" type="string">

      Token to pass in the next request to retrieve the following page of results.

    ## Examples

    Retrieves search term metrics using a Wix campaign ID, with optional text filtering and paging.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/_serverless/pa-google/v2/search-term-metrics' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "campaignId": "b3f8e241-7c4a-4d19-a562-9f1e30d87c05",
        "searchTermText": "leather bag",
        "searchTermTextsFilter": {
          "type": "NOT_MATCH",
          "searchTermTexts": ["free leather bag", "cheap leather bag"]
        },
        "dateRange": {
          "custom": {
            "from": "2026-03-01",
            "to": "2026-03-31"
          }
        },
        "sort": {
          "field": "CLICKS",
          "order": "DESC"
        },
        "paging": {
          "pageSize": 10
        }
      }'
      ```

      ```json Response
      {
        "results": [
          {
            "searchTerm": "leather bag women",
            "impressions": 5632,
            "clicks": 421,
            "cost": 176.82
          },

            "searchTerm": "leather handbag",
            "impressions": 3890,
            "clicks": 298,
            "cost": 125.16
          }
        ],
        "summaryRow": {
          "searchTerm": "",
          "impressions": 9522,
          "clicks": 719,
          "cost": 301.98
        },
      ```
