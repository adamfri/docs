    Runs Google URL inspection on the given site pages.

    Inspection starts synchronously and the response contains the results of
    the first chunk of pages. When the first chunk covered every requested
    page, the status is already `COMPLETE` and no polling is needed. When
    pages remain, the status is `ONGOING` and Wix keeps inspecting them
    server-side. Poll Get Inspection until the status is `COMPLETE` or
    `ERROR`.

    Each page inspection consumes Google URL-inspection quota for the
    connected account. Inspection stops early when that quota runs out, so
    check `remaining_page_count` to see whether any pages were left
    uninspected.

    Google allows up to 2,000 page inspections a day per property. Sites with
    more pages than that can't be inspected through this method and fail with
    `FAILED_PRECONDITION` (`SITE_EXCEEDS_INSPECTION_LIMIT`). Inspect single
    pages manually in Google Search Console instead.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gsc/v1/inspect-urls
    ```

    ## Body Params

    <ParamField body="pageIds" type="string[]" required>

      IDs of the site pages to inspect. Each inspection result identifies its
      page in the `page` object, with the same `pageId`.

      Constraints: `maxLength 200`, `maxItems 2000`.

    </ParamField>

    <ParamField body="updateResults" type="boolean">

      Whether to merge the new results into the previous inspection instead of
      replacing it.

      Default: `false`. A new inspection replaces the stored results.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="InspectedPage[]">

      Results of the pages inspected so far.

      <Expandable title="results properties">

        <ResponseField name="page" type="SitePage">

          The inspected page.

          **Read-only.**

          <Expandable title="page properties">

            <ResponseField name="pageId" type="string">

              ID of the page.

              **Read-only.** Constraints: `maxLength 200`.

            </ResponseField>

            <ResponseField name="name" type="string">

              Display name of the page.

              **Read-only.** Constraints: `maxLength 1000`.

            </ResponseField>

            <ResponseField name="path" type="string">

              URL path of the page.

              **Read-only.** Constraints: `maxLength 2000`.

            </ResponseField>

            <ResponseField name="itemType" type="string">

              Item type of the page. For example, `static-page` or a vertical item
              type.

              **Read-only.** Constraints: `maxLength 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="status" type="string">

          Whether the page's inspection succeeded. `OK` or `ERROR`.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

        <ResponseField name="data" type="object">

          Google's raw URL-inspection result for the page, as returned by the
          Google Search Console
          [URL Inspection API](https://developers.google.com/webmaster-tools/v1/urlInspection.index/inspect).

          Any human-readable text in this payload (issue descriptions and the like)
          is in English. Verdicts and states are stable identifiers, so localize
          from those rather than from the text.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time this result was produced.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of the inspection. `ONGOING` means Wix is still inspecting the
      remaining pages in the background. Poll Get Inspection for the rest.

      **Supported values:**

      - `UNKNOWN_INSPECTION_STATUS` — Unknown inspection status.
      - `ONGOING` — The inspection is still running in the background.
      - `COMPLETE` — The inspection finished, and nothing is running in the background anymore.
      Pages can still be left uninspected if the connected account's Google
      quota ran out, so check the remaining page count.
      - `ERROR` — The inspection stopped with an error.

    </ResponseField>

    <ResponseField name="remainingPageCount" type="integer">

      Number of pages not inspected yet.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MISSING_TOKEN` | No Google account is connected for this site. Connect first with the GSC Connection API. |
    | `428` | `FAILED_PRECONDITION` | `SITE_EXCEEDS_INSPECTION_LIMIT` | The site has more pages than Google allows to inspect in a day (2,000 per property). Inspect single pages manually in Google Search Console. |
    | `429` | `RESOURCE_EXHAUSTED` | `GOOGLE_QUOTA_EXCEEDED` | Google's API quota for the property is used up. Retry after the quota window resets. |
    | `503` | `UNAVAILABLE` | `GOOGLE_UNAVAILABLE` | Google answered with a temporary server error. Retry with backoff. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
