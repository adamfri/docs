Triggered when the `robots.txt` file entity is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.promote.seo.robots_txt_updated` |
| Package | `@wix/seo` |
| Permissions | `Manage Stores`, `View SEO Settings`, `Manage SEO Settings` |

## Examples

<CodeGroup>

  ```javascript onRobotsTxtUpdated
  import { robotsTxt } from '@wix/seo';

  robotsTxt.onRobotsTxtUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onRobotsTxtUpdated (self-managed)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { robotsTxt } from '@wix/seo';

      publicKey: 'YOUR_APP_PUBLIC_KEY',
    }),
    modules: {

      },
  });

  wixClient.robotsTxt.onRobotsTxtUpdated((event) => {
      // handle your event here
  });
  ```
