    <div className="wix-ref">

    Restores specific collections from a backup.

    The process of restoring data from a backup takes time.
    You can check whether your restoration has completed successfully with List Restorations.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.MANAGE-BACKUPS">Manage Data Backups</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v2/backups/{backupId}/partial-restore
    ```

    ## Path Params

    <ParamField path="backupId" type="string" required>

      ID of backup to be restored.

    </ParamField>

    ## Body Params

    <ParamField body="restorationCollections" type="RestorationCollection[]">

      **Required.** Collections to be restored.

      Note: If collections have a multi-reference relationship,
      the preexisting references will be restored if at least one of those collections are restored.

      Constraints: `maxItems 1000`.

      <Expandable title="restorationCollections properties">

        <ParamField body="dataCollectionId" type="string">

          Collections to be restored.

          Note: If collections have a multi-reference relationship,
          the preexisting references will be restored if at least one of those collections are restored.

          Constraints: `minLength 1`, `maxLength 1000`.

        </ParamField>

        <ParamField body="restoreDestination" type="RestoreDestination">

          Destination where to restore the collection.
          When not specified destination is taken from backup.

          <Expandable title="restoreDestination properties">

            <ParamField body="dataCollectionId" type="string">

              Collection ID.

              Constraints: `minLength 1`, `maxLength 255`.

            </ParamField>

            <ParamField body="displayName" type="string">

              Collection's display name as shown in the CMS. If empty, `displayName` is taken from `backup.collections`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="restoration" type="Restoration">

      Details of data restoration from backup.

      <Expandable title="restoration properties">

        <ResponseField name="id" type="string">

          Restoration ID.

          **Read-only.** Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="backup" type="Backup">

          Details of the backup used for the restoration.

          **Read-only.**

          <Expandable title="backup properties">

            <ResponseField name="id" type="string">

              Backup ID.

              **Read-only.** Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="status" type="string">

              Backup status.

              **Read-only.**

              **Supported values:**

              - `PENDING` — Backup creation is in progress.
              - `READY` — Backup has been created successfully and can be used for data restoration.
              - `FAILED` — Backup creation has failed.
              - `DELETED` — Backup has been deleted.
              - `CANCELED` — Backup has been canceled.

            </ResponseField>

            <ResponseField name="type" type="string">

              Type of backup, based on how it was triggered.

              **Read-only.**

              **Supported values:**

              - `ON_DEMAND` — Backup taken on demand.
              - `AUTO` — Backup taken automatically by the system on a regular schedule.

            </ResponseField>

            <ResponseField name="requestedDate" type="datetime">

              Date and time the backup was requested.

              **Read-only.**

            </ResponseField>

            <ResponseField name="startedDate" type="datetime">

              Date and time the backup commenced. Value is `null` until the backup process begins in the background.

              **Read-only.**

            </ResponseField>

            <ResponseField name="finishedDate" type="datetime">

              Date and time the backup process finished. Value is `null` until the backup process is completed in the background.

              **Read-only.**

            </ResponseField>

            <ResponseField name="deletedDate" type="datetime">

              Date and time the backup was deleted. Value is `null` if that backup hasn't been deleted.

              **Read-only.**

            </ResponseField>

            <ResponseField name="sizeInBytes" type="integer">

              Backup size in bytes. Value is `null` until the backup process is completed.

              **Read-only.**

            </ResponseField>

            <ResponseField name="collections" type="Collection[]">

              IDs and display names of collections the backup contains.

              **Read-only.** Constraints: `maxItems 1000`.

              _Nested structure omitted for brevity — see the `Collection[]` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="status" type="string">

          Status of restoration.

          **Read-only.**

          **Supported values:**

          - `PENDING` — Restoration from a backup is in progress.
          - `COMPLETED` — Restoration from a backup has been successful.
          - `FAILED` — Restoration from a backup has failed.

        </ResponseField>

        <ResponseField name="requestedDate" type="datetime">

          Date and time the restoration was requested.

          **Read-only.**

        </ResponseField>

        <ResponseField name="startedDate" type="datetime">

          Date and time the restoration commenced. Value is `null` until the restoration process begins in the background.

          **Read-only.**

        </ResponseField>

        <ResponseField name="finishedDate" type="datetime">

          Date and time the restoration finished. Value is `null` until the restoration process is completed in the background.

          **Read-only.**

        </ResponseField>

        <ResponseField name="restorationCollections" type="RestorationCollection[]">

          Restored collections.

          **Read-only.** Constraints: `maxItems 1000`.

          <Expandable title="restorationCollections properties">

            <ResponseField name="dataCollectionId" type="string">

              Collections to be restored.

              Note: If collections have a multi-reference relationship,
              the preexisting references will be restored if at least one of those collections are restored.

              Constraints: `minLength 1`, `maxLength 1000`.

            </ResponseField>

            <ResponseField name="restoreDestination" type="RestoreDestination">

              Destination where to restore the collection.
              When not specified destination is taken from backup.

              _Nested structure omitted for brevity — see the `RestoreDestination` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
