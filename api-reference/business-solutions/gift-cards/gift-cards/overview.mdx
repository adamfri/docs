A gift card represents a prepaid payment method that customers can use to make purchases.
Gift cards store monetary value that can be redeemed during checkout and support email
delivery to recipients with personalized messaging. All balance changes are automatically
tracked for audit and reporting purposes.

## SDK package

```bash
npm install @wix/gift-vouchers
```

Import the `giftVouchers` namespace from `@wix/gift-vouchers`.
