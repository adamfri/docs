    Creates multiple brands.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.BRAND_WRITE">Brand write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/brands/create
    ```

    ## Body Params

    <ParamField body="brands" type="Brand[]" required>

      Brands to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Brand Object](/api-reference/business-solutions/stores/catalog-v3/brands-v3/brand-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the full created brand entities in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkBrandsResult[]">

      Brands created by bulk action.

      Constraints: `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Bulk action metadata for brand.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

            </ResponseField>

        <ResponseField name="item" type="Brand">

          Full brand entity.

          Returned only if `returnEntity: true` is passed in the request.

          See the [Brand Object](/api-reference/business-solutions/stores/catalog-v3/brands-v3/brand-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `BRAND_LIMIT_EXCEEDED` | Number of brands exceeded the store limit. |
    | `400` | `INVALID_ARGUMENT` | `ONLY_SPACES_STRING_ERROR` | `name` contains only spaces. Provide valid text content. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
