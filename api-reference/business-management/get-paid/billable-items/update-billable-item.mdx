    Updates a billable item.

    Each time the BillableItem is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the billable item.
    This ensures you're working with the latest billable item
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BILLABLE_ITEMS.MANAGE-BILLABLE-ITEMS">Manage Billable Items</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/billable-items/v1/billable-items/{billableItem.id}
    ```

    ## Path Params

    <ParamField path="billableItem.id" type="string" required>

      Billable item ID.

    </ParamField>

    ## Body Params

    <ParamField body="billableItem" type="BillableItem" required>

      Billable item to update. May be partial.

      See the [Billable Item Object](/api-reference/business-management/get-paid/billable-items/billable-item-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="billableItem" type="BillableItem">

      Updated billable item.

      See the [Billable Item Object](/api-reference/business-management/get-paid/billable-items/billable-item-object) for this object's fields.

    </ResponseField>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Billable item ID.

      **Read-only.**

    </ParamField>

    <ParamField body="billableItem" type="UpdateBillableItem" required>

      Billable item to update. May be partial.

      <Expandable title="billableItem properties">

        <ParamField body="_id" type="string">

          Billable item ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the billable item is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the billable item.

          Ignored when creating a billable item.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the billable item was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the billable item was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string" required>

          Billable item name, for display on invoices.

          Constraints: `minLength 1`, `maxLength 200`.

        </ParamField>

        <ParamField body="description" type="string">

          Detailed description of the billable item. Provides additional information about the product or service.

        </ParamField>

        <ParamField body="price" type="string" required>

          Price of the billable item in decimal format with up to 4 decimal places.
          Represents the base cost before taxes are applied. This is a required field when creating a new billable item.

          Constraints: `format DECIMAL_VALUE`, `>= -1000000000000000`, `<= 1000000000000000`.

        </ParamField>

        <ParamField body="taxGroupId" type="string">

          Reference to a tax group that defines the tax rules applicable to this billable item.
          Use the Tax Groups API ([SDK](https://dev.wix.com/docs/sdk/backend-modules/billing/tax-groups/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/tax/tax-groups/introduction)) to retrieve available tax groups for the business.
          The tax group determines how taxes are calculated when this item is added to an invoice.
          If not specified, the default tax rules for the business will apply.

        </ParamField>

        <ParamField body="image" type="string">

          Billable item image, stored in the Wix Media Manager.
          Upload an image with the Media Manager API ([SDK](https://dev.wix.com/docs/sdk/backend-modules/media/introduction) | [REST](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction)) or the site dashboard before associating it to a billable item.
