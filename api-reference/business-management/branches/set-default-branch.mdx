    <div className="wix-ref">

    Sets the specified branch as the default.

    The default branch is used for API operations when no branch ID is specified.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DOCUMENT-MANAGEMENT.MANAGE-BRANCHES">Manage Site Branches</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/branches/v1/branches/{branchId}/set-default
    ```

    ## Path Params

    <ParamField path="branchId" type="string" required>

      Branch ID.

    </ParamField>

    ## Response Object

    <ResponseField name="branch" type="Branch">

      Updated branch.

      See the [Branch Object](/api-reference/business-management/branches/branch-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">
