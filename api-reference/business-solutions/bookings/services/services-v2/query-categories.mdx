    <div className="wix-ref">

    Retrieves a list of [service categories](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/categories-v2/introduction), given the provided filtering.

    ### Defaults

    Query Categories has the following default setting, which you can't override:
    Sorted by `id` in ascending order.

    ### Filters

    When using date filters, you must use
    [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time).

    ### See also

    To learn about working with Query methods, see
    [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language)
    and [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/categories/query
    ```

    ## Body Params

    <ParamField body="filter" type="QueryCategoriesFilter">

      Filter.

      <Expandable title="filter properties">

        <ParamField body="services" type="object">

          Service filter. See [Query Services](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/query-services) for a list of supported filters.

        </ParamField>

        <ParamField body="categoryIds" type="string[]">

          List of category IDs to filter by.

          Constraints: `format GUID`, `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="categories" type="Category[]">

      Retrieved categories.

      <Expandable title="categories properties">

        <ResponseField name="id" type="string">

          Category ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="name" type="string">

          Category name.

          **Read-only.**

        </ResponseField>

        <ResponseField name="sortOrder" type="integer">

          Order of a category within a category list.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/bookings/v2/services/categories/query' \
      -H 'Authorization: <AUTH>' \
      ```
