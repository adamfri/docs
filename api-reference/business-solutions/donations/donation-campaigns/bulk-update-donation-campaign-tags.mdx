    Updates tags on multiple donation campaigns by ID.

    Use this method to assign or remove tags from specific campaigns.
    A tag that appears in both assign and unassign lists will be assigned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DONATIONS.MANAGE-CAMPAIGNS">Manage Donation Campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/donation-campaigns/v2/bulk/donation-campaigns/update-tags
    ```
