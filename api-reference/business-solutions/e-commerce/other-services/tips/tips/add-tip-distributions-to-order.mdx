    <div className="wix-ref">

    Adds tip distributions to an
    eCommerce order ([SDK](https://dev.wix.com/docs/sdk/backend-modules/ecom/orders/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/orders/order-object)).

    If no tip exists on the order, an `additionalFee` is added and the total tip
    amount is equal to the sum of all distribution amounts. If a tip is already
    present, the existing `additionalFee` is replaced and the total tip amount is
    increased by the sum of the new tip distributions.

    The call fails if:
    + The order's `paymentStatus` is either `FULLY_REFUNDED` or `PARTIALLY_REFUNDED`.
    + Any of the tip distribution amounts is zero or negative.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/tips/v1/tips/tip-distributions/add
    ```

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ORDER_NOT_FOUND` | Couldn't find the order. |
    | `404` | `NOT_FOUND` | `DRAFT_ORDER_NOT_FOUND` | Couldn't find the draft order. |
    | `409` | `ALREADY_EXISTS` | `ORDER_IS_ALREADY_EDITED` | Order is already being edited. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_CANNOT_BE_EDITED` | Order can't be edited. |
    | `428` | `FAILED_PRECONDITION` | `PARTIALLY_OR_FULLY_REFUNDED_ORDER_CANNOT_BE_EDITED` | Can't edit an order with a `paymentStatus` of `FULLY_REFUNDED` or `PARTIALLY_REFUNDED`. |
    | `500` | `INTERNAL` | `FAILED_SETTING_TIP_ON_ORDER` | Failed to set the tip on the order. |
    | `500` | `INTERNAL` | `FAILED_DELETING_TIP_FROM_ORDER` | Failed to delete the tip from the order. |
    | `500` | `INTERNAL` | `FAILED_COMMITING_TIP_ON_ORDER` | Failed to commit the tip on the order. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TIP_DISTRIBUTION` | The tip distribution is invalid. All distribution amounts must be positive. |

    <div className="wix-ref">

    Adds tip distributions to an
    eCommerce order ([SDK](https://dev.wix.com/docs/sdk/backend-modules/ecom/orders/introduction) | [REST](https://dev.wix.com/docs/rest/business-solutions/e-commerce/orders/order-object)).

    If no tip exists on the order, an `additionalFee` is added and the total tip
    amount is equal to the sum of all distribution amounts. If a tip is already
    present, the existing `additionalFee` is replaced and the total tip amount is
    increased by the sum of the new tip distributions.

    The call fails if:
    + The order's `paymentStatus` is either `FULLY_REFUNDED` or `PARTIALLY_REFUNDED`.
    + Any of the tip distribution amounts is zero or negative.

    <Note>

      **Authentication**

      This method may require higher-level permissions than the caller has, based on their [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) and [roles and permissions](https://support.wix.com/en/article/roles-permissions-overview). In these cases, you can ensure the method is called with the required level of authorization by using one of the following:

      - In Wix sites and Wix apps, use [elevated permissions](https://dev.wix.com/docs/api-reference/articles/authentication/about-elevated-permissions).
      - In Wix Headless projects, use [API key authentication](https://dev.wix.com/docs/go-headless/develop-your-project/admin-operations/about-admin-operations).

    </Note>
