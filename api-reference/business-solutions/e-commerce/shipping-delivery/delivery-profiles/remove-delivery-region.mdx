    </Info>

    Removes a delivery region from a delivery profile.

    You can remove all delivery regions from a profile, leaving the profile empty. An empty profile won't provide shipping options until a new delivery region is added.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/ecom/v1/delivery-profiles/{deliveryProfileId}/delivery-region/{deliveryRegionId}
    ```

    ## Path Params

    <ParamField path="deliveryProfileId" type="string" required>

      Delivery profile ID.

    </ParamField>

    <ParamField path="deliveryRegionId" type="string" required>

      Delivery region ID.

    </ParamField>

    ## Query Params

    <ParamField query="revision" type="integer">

      Delivery profile revision.

      **Read-only.**

    </ParamField>

    ## Response Object

    <ResponseField name="deliveryProfile" type="DeliveryProfile">

      Updated delivery profile with the delivery region removed.

      See the [Delivery Profile Object](/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/delivery-profile-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DELIVERY_PROFILE_NOT_FOUND` | Couldn't find the delivery profile. |
    | `404` | `NOT_FOUND` | `DELIVERY_REGION_NOT_FOUND` | Couldn't find the delivery region. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:

    | Delivery Profile Updated | `wix.ecom.v1.delivery_profile_updated` | Triggered when a delivery profile is updated. |
    | Delivery Profile Region Removed | `wix.ecom.v1.delivery_profile_region_removed` | Triggered when a delivery region is removed from a delivery profile. |
