    <ResponseField name="offlineBehavior" type="string">

      Defines how the AI assistant functions during the non-active hours.

      **Supported values:**

      - `CHAT_ONLY` — Allows the site visitor to write messages, but doesn't send a contact form.
      - `HIDE` — Hides the AI assistant from the site.
      - `CONTACT_FORM_WITHOUT_CHAT` — Doesn't allow the site visitor to write messages, but does send a contact form.
      - `CONTACT_FORM_WITH_CHAT` — Allows the site visitor to write messages and sends a contact form.

    </ResponseField>

    <ResponseField name="navigationSummary" type="boolean">

      Whether the AI assistant should send a summary of the site visitor's navigation on the site.

    </ResponseField>

      Wix Media image ID used for the AI assistant.

    </ResponseField>

    <ResponseField name="generatedQuestions" type="boolean">

      Whether to display example questions from the AI assistant.

    </ResponseField>
