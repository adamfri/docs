    <div className="wix-ref">

    Retrieves a brand by name, or creates a brand if one with the passed `brandName` doesn't exist.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.BRAND_WRITE">Brand write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/brands/get-or-create
    ```

    ## Body Params

    <ParamField body="brandName" type="string" required>

      Brand name to retrieve or create.

      Constraints: `minLength 1`, `maxLength 50`.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT`

    </ParamField>

    ## Response Object

    <ResponseField name="brand" type="Brand">

      Brand.

      See the [Brand Object](/api-reference/business-solutions/stores/catalog-v3/brands-v3/brand-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `BRAND_LIMIT_EXCEEDED` | Number of brands exceeded the store limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Brand Created | `wix.stores.catalog.v3.brand_created` | Triggered when a brand is created. |

    </div>

    <div className="wix-examples">

    ## Examples

    Get an existing brand using GetOrCreate method. Response should also include the amount of products using this brand.

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/stores/v3/brands/get-or-create' \
        -H 'Content-type: application/json' \
        -H 'Authorization:  <AUTH>' \
        -d '{
          "brandName": "Adidas",
          "fields": [
              "ASSIGNED_PRODUCTS_COUNT"
            ]
        }'
      ```

      ```json Response
      {
        "brand": {
          "id": "35cfd6ff-2c0d-4e68-b881-2fc78942a3c4",
          "revision": "1",
          "createdDate": "2024-06-27T11:46:29.372Z",
          "updatedDate": "2024-06-27T11:57:23.510Z",
          "name": "Adidas",
          "assignedProductsCount": 2
        }
      }
      ```

    </CodeGroup>
