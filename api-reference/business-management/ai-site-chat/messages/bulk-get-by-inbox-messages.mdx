    Retrieves messages by inbox conversation ID.

    Up to 100 Messages can be returned per request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INNOVATION_LAB.ADMIN">Innovation Lab Administrator</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/innovation/widget/v1/messages/get-by-inbox
    ```

    ## Query Params

    <ParamField query="inboxConversationId" type="string" required>

      conversationId of the conversation in inbox.

      Can be found in [Message.conversationId](https://dev.wix.com/docs/api-reference/crm/communication/inbox/messages/message-object)

    </ParamField>

    <ParamField query="inboxMessageSequences" type="string[]">

      List of message sequences in the inbox conversation to retrieve messages for.

      Can be found in [Message.sequence](https://dev.wix.com/docs/api-reference/crm/communication/inbox/messages/message-object)

      Constraints: `maxLength 20`, `minItems 1`, `maxItems 100`.

    </ParamField>
