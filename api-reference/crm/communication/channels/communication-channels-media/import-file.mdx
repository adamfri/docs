    Imports a file from an external URL directly into the Media Manager.

    Call this method to import files from external URLs into the Media Manager, such as files hosted on another site or server.

    To import a file, you need to do one of the following:
    - Specify its [MIME type](https://developer.mozilla.org/en-US/docs/Web/HTTP/Basics_of_HTTP/MIME_types) in the `mimeType` field of the request. For example, `mimeType: 'image/jpeg'`.
    - Specify its extension in either the `displayName` or `url` field of the request. For example, `displayName: 'Example Image.jpeg` or `url: https://www.example.com/image.jpeg`.
    - Ensure the server hosting the file supports HEAD requests. In these cases, Wix servers can retrieve the MIME type from the hosting server.

    <Note>

    - If you want to validate the media type, specify the file's expected media type in the optional `mediaType` field of the request.  For example, `mediaType: 'IMAGE'`.
    - When you import a file, it's not immediately available, meaning you can't manage or use the file straight away. Learn more about [knowing when a file is ready](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/importing-files#knowing-when-a-file-is-ready) to use in the Media Manager.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-INBOX.MANAGE-MSGS">Manage Inbox Messages</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/communication-channels-media/v1/import-file
    ```

    ## Body Params

    <ParamField body="url" type="string" required>

      Publicly accessible URL for the file to import.

      Constraints: `format WEB_URL`.

    </ParamField>

    <ParamField body="displayName" type="string">

      Display name for the file in the Media Manager. If not specified, file name is extracted from the URL.

    </ParamField>

    <ParamField body="mimeType" type="string" required>

      File mime type.

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField body="urlParams" type="object">

      Optional URL parameters to send with the import request.

    </ParamField>

    <ParamField body="urlHeaders" type="object">

      Optional headers to send with the import request.

    </ParamField>

    ## Response Object

    <ResponseField name="fileId" type="string">

      File ID. Generated when a file is uploaded to the Media Manager.

      **Read-only.** Constraints: `maxLength 400`.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Display name of the file as it appears in the Media Manager.

      Constraints: `maxLength 200`.

    </ResponseField>

    <ResponseField name="url" type="string">

      Static URL for accessing the imported file.

      **Read-only.** Constraints: `format WEB_URL`.

    </ResponseField>

    <ResponseField name="sizeInBytes" type="string">

      Size of the imported file in bytes.

      **Read-only.**

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_FILE_FORMAT` | File format not supported. |
    | `500` | `INTERNAL` | `FILE_DESCRIPTOR_NOT_FOUND` | File descriptor not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
