    <div className="wix-ref">

    If an automation's action is delayed, implement this method to retrieve the latest data in the trigger payload before the action fires.

    For example, if an automation is triggered but its action is set to fire only 24 hours later, Wix calls Refresh Payload before starting
    the action. This fetches the latest data in the trigger payload. The returned data can be used to update the trigger payload that is passed
    to the action.

    ## Endpoint

    ```http
    POST /refresh-payload
    ```

    ## Body Params

    <ParamField body="triggerKey" type="string">

      Trigger key as defined in your app's trigger configuration in the app dashboard. For example, `form_submitted` or `invoice_due`.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="externalEntityId" type="string">

      ID of the related resource in GUID format.

    </ParamField>

    <ParamField body="payload" type="object" required>

      Payload to update.

    </ParamField>

    ## Response Object

    <ResponseField name="payload" type="object">

      Updated payload.

    </ResponseField>

    <ResponseField name="cancelActivation" type="boolean">

      Whether the automation activation should be canceled.

      Default: `false`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    A Refresh payload sample request for an event that had it's start date updated since the time the payload was sent

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.<your-deployment-uri>.com/refresh-payload' \
      -H 'user-agent: Wix' \
      -H 'accept-encoding: gzip, deflate' \
      -H 'content-type: text/plain; charset=utf-8' \
      -d '{
        "triggerKey": "event-starts",
        "payload": {
          "event_id": "13453-w33e",
          "title": "My Party",
          "start_date": "2026-01-07T07:45:00"
        }
      }'
      ```

      ```json Response
      {
        "payload": {
          "event_id": "13453-w33e",
          "title": "My Party",
          "start_date": "2026-02-10T10:00:00"
        }
      }
      ```

    </CodeGroup>
