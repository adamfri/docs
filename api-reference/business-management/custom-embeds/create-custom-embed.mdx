    <div className="wix-ref">

    Creates a custom embed within the specified position (`HEAD`, `BODY_START` or `BODY_END`).

    Required fields: `name`, `position`, `embedData` (including `category` and `html`).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS">SCOPE.EDITOR.MANAGE_CUSTOM_EMBEDS</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/embeds/v1/custom-embeds
    ```

    ## Body Params

    <ParamField body="customEmbed" type="CustomEmbed" required>

      Custom embed to create.

      See the [Custom Embed Object](/api-reference/business-management/custom-embeds/custom-embed-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="customEmbed" type="CustomEmbed">

      Created custom embed.

      See the [Custom Embed Object](/api-reference/business-management/custom-embeds/custom-embed-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `429` | `RESOURCE_EXHAUSTED` | `SITE_EMBEDS_LIMIT_EXCEEDED` | Number of custom embeds exceeds the server's limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Custom Embed Created | `wix.embeds.v1.custom_embed_created` | Triggered when a custom embed is created. |

    </div>

      ```bash Request

        -d '{
          "customEmbed": {
            "name": "Header Custom Embed",
      ```
