    Retrieves the connection status of a site's social channel account.

    Use this to check whether a channel is connected and able to publish before creating or publishing items.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-publisher/v1/{channelName}/long-lived-token-status
    ```

    ## Path Params

    <ParamField path="channelName" type="string" required>

      Social channel to check.

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      Connection status of the channel.

      **Supported values:**

      - `NEVER_CREATED` — The channel was never connected.
      - `VALID` — The channel is connected and able to publish.
      - `INVALID` — The channel's connection is no longer valid and must be reconnected.
      - `DISCONNECTED` — The channel was disconnected.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
