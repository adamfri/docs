    Generates product mockup images showing the site owner's logo or custom image on the provider's products.

    Wix calls this method when a site owner requests mockup previews for products from the marketplace provider.

    The generated mockup images are delivered asynchronously. Once generation is complete, the provider notifies Wix by calling [Submit Generated Mockups](https://dev.wix.com/docs/api-reference/business-solutions/suppliers-hub/marketplace-provider-submissions/submit-generated-mockups).

    ## Endpoint

    ```http
    POST /v2/bulk/mockups/generate
    ```

    ## Body Params

    <ParamField body="mockups" type="Mockup[]">

      Mockups to generate.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="mockups properties">

        <ParamField body="providerProductId" type="string">

          Unique product identifier on the provider's platform.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="image" type="Image">

          Image to overlay on the product mockup.

          <Expandable title="image properties">

            <ParamField body="url" type="string">

              Image URL.

              Constraints: `format WEB_URL`.

            </ParamField>

            <ParamField body="imageType" type="string">

              Type of image used for mockup generation.

              **Supported values:**

              - `UNKNOWN_IMAGE_TYPE` — Unknown image type.
              - `SITE_LOGO` — The site's logo.
              - `CUSTOM` — A custom image provided by the site owner.
              - `FALLBACK` — Default product mockup image used when a site logo or custom image mockup is not available.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
