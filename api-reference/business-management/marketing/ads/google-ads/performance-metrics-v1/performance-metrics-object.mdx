---
title: "Performance Metrics Object"
description: "Query performance metrics, conversion data, search terms, shopping performance, and asset-level data for running Google Ads campaigns."
icon: "cube"
---

Query performance metrics, conversion data, search terms, shopping performance, and asset-level data for running Google Ads campaigns.

<Tabs>

  <Tab title="REST">

    <ResponseField name="impressions" type="integer">

      Number of times the ad was shown.

      **Read-only.**

    </ResponseField>

    <ResponseField name="clicks" type="integer">

      Number of clicks on the ad.

      **Read-only.**

    </ResponseField>

    <ResponseField name="ctr" type="number">

      Click-through rate expressed as a decimal, for example 0.05 for 5%.

      **Read-only.**

    </ResponseField>

    <ResponseField name="date" type="string">

      Date of this metric row, in YYYY-MM-DD format.

      **Read-only.**

    </ResponseField>

    <ResponseField name="campaignResourceName" type="string">

      Google Ads resource name of the campaign, in the format `customers/{customerId}/campaigns/{campaignId}`.

      **Read-only.**

    </ResponseField>

    <ResponseField name="phoneCalls" type="integer">

      Number of phone calls initiated through the ad.

      **Read-only.**

    </ResponseField>

    <ResponseField name="leads" type="integer">

      Number of leads generated by the campaign.

    </ResponseField>

    <ResponseField name="cost" type="number">

      Total amount spent in the account's currency. Already converted from micros.

    </ResponseField>

    <ResponseField name="clicksByAdNetworkType" type="AdNetworkTypeSegmentation">

      Click count broken down by the ad network that served the ad.

      <Expandable title="clicksByAdNetworkType properties">

        <ResponseField name="search" type="integer">

          Count of the metric attributed to Google Search.

        </ResponseField>

        <ResponseField name="other" type="integer">

          Count of the metric attributed to ad networks not individually listed here.
          For Smart campaigns this includes all non-search networks such as display, video, and partner networks.
          For Performance Max campaigns this captures any networks beyond the ones explicitly broken out below.

        </ResponseField>

        <ResponseField name="gmail" type="integer">

          Count of the metric attributed to Gmail placements.

        </ResponseField>

        <ResponseField name="youtube" type="integer">

          Count of the metric attributed to YouTube placements.

        </ResponseField>

        <ResponseField name="discover" type="integer">

          Count of the metric attributed to Google Discover placements.

        </ResponseField>

        <ResponseField name="display" type="integer">

          Count of the metric attributed to the Google Display Network.

        </ResponseField>

        <ResponseField name="searchPartners" type="integer">

          Count of the metric attributed to Google Search partner sites.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="impressionsByAdNetworkType" type="AdNetworkTypeSegmentation">

      Impression count broken down by the ad network that served the ad.

      <Expandable title="impressionsByAdNetworkType properties">

        <ResponseField name="search" type="integer">

          Count of the metric attributed to Google Search.

        </ResponseField>

        <ResponseField name="other" type="integer">

          Count of the metric attributed to ad networks not individually listed here.
          For Smart campaigns this includes all non-search networks such as display, video, and partner networks.
          For Performance Max campaigns this captures any networks beyond the ones explicitly broken out below.

        </ResponseField>

        <ResponseField name="gmail" type="integer">

          Count of the metric attributed to Gmail placements.

        </ResponseField>

        <ResponseField name="youtube" type="integer">

          Count of the metric attributed to YouTube placements.

        </ResponseField>

        <ResponseField name="discover" type="integer">

          Count of the metric attributed to Google Discover placements.

        </ResponseField>

        <ResponseField name="display" type="integer">

          Count of the metric attributed to the Google Display Network.

        </ResponseField>

        <ResponseField name="searchPartners" type="integer">

          Count of the metric attributed to Google Search partner sites.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "performanceMetrics": {
          "impressions": 47381,
          "clicks": 3316,
          "ctr": 0.0699,
          "date": "2026-03-31",
          "campaignResourceName": "customers/3827461950/campaigns/7412836509",
          "phoneCalls": 12,
          "leads": 87,
          "cost": 1408.65,
          "clicksByAdNetworkType": {
            "search": 2841,
            "other": 198,
            "gmail": 47,
            "youtube": 89,
            "discover": 63,
            "display": 55,
            "searchPartners": 23
          },
          "impressionsByAdNetworkType": {
            "search": 38210,
            "other": 3940,
            "gmail": 1620,
            "youtube": 1870,
            "discover": 892,
            "display": 621,
            "searchPartners": 228
          }
        }
      }
      ```

    </CodeGroup>
