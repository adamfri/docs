    Checks whether a Ricos document is valid given the specified plugins.

    Use the `fixDocument` parameter to include a valid version of your Ricos document in the response.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RICOS.MANAGE-DOCUMENTS">Manage Ricos Document</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ricos/v1/ricos-document/validate
    ```

    ## Body Params

    <ParamField body="document" type="object" required>

      Ricos document to validate.

    </ParamField>

    <ParamField body="plugins" type="string[]">

      List of [plugins](https://dev.wix.com/docs/ricos/getting-started/introduction#plugins) to enable in the document.

      Constraints: `minItems 0`, `maxItems 100`.

      **Supported values:**

      - `UNKNOWN_PLUGIN`
      - `ACTION_BUTTON`
      - `AUDIO`
      - `CODE_BLOCK`
      - `COLLAPSIBLE_LIST`
      - `DIVIDER`
      - `EMOJI`
      - `FILE`
      - `GALLERY`
      - `GIPHY`
      - `HASHTAG`
      - `HEADING`
      - `HTML`
      - `IMAGE`
      - `INDENT`
      - `LAYOUT`
      - `LINE_SPACING`
      - `LINK`
      - `LINK_BUTTON`
      - `LINK_PREVIEW`
      - `MENTIONS`
      - `POLL`
      - `SPOILER`
      - `TABLE`
      - `TEXT_COLOR`
      - `TEXT_HIGHLIGHT`
      - `VERTICAL_EMBED`
      - `VIDEO`
      - `FONT_FAMILY`
      - `CARD`
      - `SMART_BLOCK`
      - `TOC`
      - `SHAPE`

    </ParamField>

    <ParamField body="fixDocument" type="boolean">

      Whether to return a valid version of the document in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="valid" type="boolean">
