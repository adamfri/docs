---
title: "Chat Settings Object"
description: "The Chat Settings object in the Wix Chat Settings API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      The ID of the chat settings. The chat settings specified in this object apply to the form with a matching ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="greetingMessage" type="string">

      Custom greeting message displayed when a visitor opens the AI chat.

    </ResponseField>

    <ResponseField name="chatEnabled" type="boolean">

      Whether AI chat is enabled for this form.

      Default: `true`

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the chat settings are updated.
      To prevent conflicting changes, the current revision must be passed when updating the chat settings.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the chat settings were created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the chat settings were last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="summaryMessage" type="string">

      Message that summarizes the contents of the form. Appears after the greeting message.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="manualSummary" type="boolean">

      Whether the summary message is manually set or AI-generated.
      When `false` the summary message is automatically generated by AI when the chat settings are saved.
      When `true`, the summary message can be manually set and won't be overwritten by AI.

      Default: `false`

    </ResponseField>

    <ResponseField name="personality" type="string">

      Personality of the AI when interacting with visitors.
      Defines the communication style of the AI chat responses.

      **Supported values:**

      - `PROFESSIONAL`
      - `FRIENDLY`
      - `PLAYFUL`
      - `DIRECT`

    </ResponseField>

  </Tab>
