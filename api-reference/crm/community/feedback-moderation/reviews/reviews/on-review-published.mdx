Triggered when a review's moderation status is set to `APPROVED`.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.reviews.v1.review_review_published` |
| Package | `@wix/reviews` |
| Permissions | `Manage Stores`, `Manage Reviews` |

## Examples

<CodeGroup>

  ```javascript onReviewPublished
  import { reviews } from '@wix/reviews';

  reviews.onReviewPublished((event) => {
      // handle your event here
  });
  ```

  ```javascript onReviewPublished (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { reviews } from '@wix/reviews';

  const wixClient = createClient({
    auth: AppStrategy({

      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        reviews,
      },
  });

  wixClient.reviews.onReviewPublished((event) => {
      // handle your event here
  });
  ```
