    Retrieves the settings for a site’s payment links.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYLINKS.MANAGE">Manage Paylinks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/paymentlinks/v1/payment-links-settings
    ```

    ## Response Object

    <ResponseField name="paymentLinksSettings" type="PaymentLinksSettings">

      Payment link settings.

      See the [Payment Links Settings Object](/api-reference/business-management/get-paid/payment-links/payment-link-settings/payment-links-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
