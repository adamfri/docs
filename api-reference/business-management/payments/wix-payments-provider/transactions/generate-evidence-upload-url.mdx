Generates URL to upload evidence for a dispute.

Deprecated in favor of `wix.payments.dispute_evidence_documents.v1.DisputeEvidenceDocumentService.CreateDisputeEvidenceDocument`,
which returns the evidence file upload URL in its response.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/payments/v3/transactions/{transactionId}/disputes/{disputeId}/generate-evidence-upload-url
```

## Path Params

<ParamField path="transactionId" type="string" required>

  Transaction ID.

</ParamField>

<ParamField path="disputeId" type="string" required>

  Dispute ID.

</ParamField>

## Body Params

<ParamField body="accountId" type="string" required>

  Wix Payments account ID.

  Constraints: `format GUID`.

</ParamField>

## Response Object

<ResponseField name="uploadUrl" type="string">

  Evidence upload URL.

  Constraints: `format WEB_URL`.

</ResponseField>

<ResponseField name="uploadToken" type="string">

  Evidence upload token.

  Constraints: `minLength 1`, `maxLength 1000`.

</ResponseField>

## Errors

| Status | Code | Application code | Description |
| --- | --- | --- | --- |
| `428` | `FAILED_PRECONDITION` | `DISPUTE_EVIDENCE_ARE_NOT_EXPECTED` | Dispute evidence isn't expected at this time. |

<Note>

  This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
