    Duplicates a section.

    You can duplicate a section to the same business location, or to 1 or more different business locations.
    You can specify whether to also duplicate the section's sub-entities, such as its items.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/sections/{id}/duplicate
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the section to be duplicated.

    </ParamField>

    ## Body Params

    <ParamField body="businessLocationIds" type="string[]">

      Business location IDs to assign to the duplicated section or sections.

      If you specify one or more IDs, a duplicate is created for each ID, with that ID in its `businessLocationId` field.
      If you don't specify an ID, one duplicate is created with the same `businessLocationId` as the original section.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField body="duplicateSubEntities" type="boolean">

      Whether to duplicate the section's sub-entities, such as its items.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="sectionId" type="string[]">

      IDs of the newly created sections.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
