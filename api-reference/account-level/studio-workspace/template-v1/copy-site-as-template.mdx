    Creates a template by duplicating an existing site.

    Duplicates the site specified in `siteMetaSiteIdToCopy`, then turns the duplicate into a template. The original site is left unchanged and doesn't have to belong to your account - you can copy any site you're allowed to duplicate.

    As with Create Template, the template is always created with a `templateType` of `STUDIO` and becomes `PUBLIC` only when you publish it.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES">SCOPE.STUDIO.MANAGE-CUSTOM-TEMPLATES</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wixstudio/templates/v1/templates/copy-site
    ```

    ## Body Params

    <ParamField body="templateName" type="string" required>

      Name of the template to create.

      Constraints: `minLength 4`, `maxLength 20`.

    </ParamField>

    <ParamField body="siteMetaSiteIdToCopy" type="string" required>

      ID of the site to duplicate and create the template from.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="templateType" type="string">

      Type of the template to create.

      **Supported values:**

      - `STUDIO` — Standard template created from a site.
      - `PUBLIC` — Published template that other Wix accounts can clone.

    </ParamField>

    ## Response Object

    <ResponseField name="template" type="Template">

      Created template.

      See the [Template Object](/api-reference/account-level/studio-workspace/template-v1/template-object) for this object's fields.

    </ResponseField>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
