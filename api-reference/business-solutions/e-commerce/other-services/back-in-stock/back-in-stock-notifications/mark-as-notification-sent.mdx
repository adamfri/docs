    <div className="wix-ref">

    Sets `status` of a back in stock request to `NOTIFICATION_SENT`.

    Use this endpoint if the notification is sent manually offline. If the notification is sent
    automatically or with the Report Items Back In Stock method, then `status` updates on its own.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES-MEGA.MANAGE-STORES">Manage Stores - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/back-in-stock-service/v1/back-in-stock-notification-requests/{id}/mark-as-notification-sent
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of the notification request to mark.

    </ParamField>

    ## Response Object

    <ResponseField name="request" type="BackInStockNotificationRequest">

      Marked back in stock notification request.

      See the [Back In Stock Notification Request Object](/api-reference/business-solutions/e-commerce/other-services/back-in-stock/back-in-stock-notifications/back-in-stock-notification-request-object) for this object's fields.

    </ResponseField>
