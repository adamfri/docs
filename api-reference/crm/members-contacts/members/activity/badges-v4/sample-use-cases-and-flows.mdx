This article presents possible use cases and corresponding sample flows that you can support. This can be a helpful jumping off point as you plan your implementation.

## Set up a member tier system

You can create multiple badges that represent different membership tiers and arrange them in a hierarchy. This flow demonstrates creating multiple badges and managing their display order.

1. Call [Create Badge](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badges-v4/create-badge) for each tier level starting with the highest tier. For example, "Gold Member". Then create additional tier badges following the same pattern for "Silver" and "Bronze" members.
1. Call [Query Badges](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badges-v4/query-badges) to retrieve all created badges and collect their IDs.
1. Call [Update Badges Display Order](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badges-v4/update-badges-display-order) to arrange the badge IDs in the desired display order.
1. Call [Bulk Create Badge Assignments](fallback::https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments-v4/bulk-create-badge-assignments) to assign appropriate badges based on member activity or subscription level.
