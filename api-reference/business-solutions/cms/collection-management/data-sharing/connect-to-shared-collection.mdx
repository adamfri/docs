    <div className="wix-ref">

    Connects the current site to a shared data collection.

    When you call this method, the shared collection appears in the current site's CMS under the specified namespace. You can also access the shared collection by using the [Data Items APIs](https://dev.wix.com/docs/api-reference/business-solutions/cms/data-items/introduction).

    <Note>

    The `namespace` is an identifier that serves as part of the collection ID when querying collection data. Therefore, it must be unique in a site.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/data/v1/data-collection-sharing/connect-to-shared-collection
    ```

    ## Body Params

    <ParamField body="namespace" type="string" required>

      Namespace to connect collection with on the target site.
      Must be unique in the site.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="displayNamespace" type="string">

      Optional display name for the namespace that appears on the target site.

    </ParamField>

    <ParamField body="dataSharingPolicyId" type="string">

      Data sharing policy ID to connect with.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="connection" type="SharingConnection">

      Created connection to shared data collection.

      <Expandable title="connection properties">

        <ResponseField name="sourceDataCollectionId" type="string">

          ID of the data collection owned and shared by the source site.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="sourceSiteId" type="string">

          ID of the source site that owns the collection and created the policy.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="targetDataCollectionId" type="string">

          ID of the shared collection on the target site.
          The ID includes the namespace. For example, `"namespace/collectionName"`.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="targetSiteId" type="string">

          ID of the target site that the collection is shared with.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="targetDisplayNamespace" type="string">

          Optional display name for the namespace that appears on the target site.

        </ResponseField>

        <ResponseField name="dataSharingPolicyId" type="string">

          ID of the data sharing policy that controls this connection.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Date and time the connection was created.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the connection was last updated.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0154` | Data sharing policy not found. Verify the policy ID is correct. |
    | `403` | `PERMISSION_DENIED` | `WDE0144` | Permissions denied. Must have `MANAGE DATA COLLECTION SHARING` permission. |
    | `409` | `ALREADY_EXISTS` | `WDE0104` | Can't connect to your own collection. Source and target sites must be different. |
    | `409` | `ALREADY_EXISTS` | `WDE0102` | Namespace already exists. Choose a namespace unique to the current site. |
    | `409` | `ALREADY_EXISTS` | `WDE0155` | Collection already connected. This collection is already shared with the current site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Sharing Policy Shared Collection Connected | `wix.data.v1.data_sharing_policy_shared_collection_connected` | Triggered when a new connection is created, which means a collection is shared with another site. |
