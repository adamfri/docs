    Generates alt text suggestions for up to 20 images in one call.

    Every image must be Wix-hosted media and belong to a Wix-managed item of
    the same type. Images are processed independently: the response reports
    per-image success, and the call succeeds as long as at least 1 image
    succeeded. A call where every image failed returns a `GENERATION_FAILED`
    error. An image URL that isn't Wix-hosted rejects the whole request.

    To generate alt text for a single image, call
    [Generate Alt Text Suggestions](https://dev.wix.com/docs/api-reference/business-management/seo/tag-suggestions-v1/generate-alt-text-suggestions).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/seo/suggestions/v1/tag-suggestions/alt-text-bulk
    ```

    ## Body Params

    <ParamField body="images" type="ImageReference[]" required>

      The images to generate alt text for.

      Constraints: `maxItems 20`.

      <Expandable title="images properties">

        <ParamField body="id" type="string">

          Your reference ID for the image. Echoed back in the result so you can
          match suggestions to images. It isn't interpreted.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="url" type="string">

          URL of the image file. Must be Wix-hosted media, meaning a URL on a Wix media
          domain such as `static.wixstatic.com`. Other hosts are rejected.

          Constraints: `format WEB_URL`, `maxLength 1000`.

        </ParamField>

        <ParamField body="parentItemId" type="string">

          ID of the Wix item the image belongs to, for example, a page ID or a
          store product ID, matching the request's `itemType`.

          Constraints: `maxLength 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="itemType" type="string" required>

      Type of the Wix item the images belong to, as an SEO item type
      identifier. All images in one call must belong to items of the same type.
      For example, `STATIC_PAGE_V2` for a regular site page, `STORES_PRODUCT`
      for a store product, or `BLOG_POST` for a blog post. Other values are
      rejected.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkAltTextResult[]">

      A result per requested image, in request order.

      **Read-only.** Constraints: `maxItems 20`.

      <Expandable title="results properties">

        <ResponseField name="imageId" type="string">

          Your reference ID for the image, echoed from the request.

          **Read-only.** Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="success" type="boolean">

          Whether alt text was generated for this image.

          **Read-only.**

        </ResponseField>

        <ResponseField name="suggestions" type="string[]">

          Suggested alt texts, best match first. Empty when `success` is `false`.

          **Read-only.** Constraints: `maxLength 1000`, `maxItems 5`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="successCount" type="integer">

      Number of images that got suggestions.

      **Read-only.**

    </ResponseField>

    <ResponseField name="failureCount" type="integer">

      Number of images that failed. Failed images can be retried
      individually with
      [Generate Alt Text Suggestions](https://dev.wix.com/docs/api-reference/business-management/seo/tag-suggestions-v1/generate-alt-text-suggestions).

      **Read-only.**

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `GENERATION_FAILED` | The AI generation pipeline failed for every requested image. |
    | `429` | `RESOURCE_EXHAUSTED` | `QUOTA_LIMIT_REACHED` | The caller's generation quota is exhausted. Reserved for future metering and not currently returned. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Examples

    All images in one call belong to items of the same type. Each result echoes the `id` you sent, so you can match suggestions to images.

    <CodeGroup>

      ```bash Request

      -d '{
        "itemType": "STORES_PRODUCT",

          {
            "id": "front",

            "parentItemId": "37915fe9-4975-4fcd-9703-e2790a5a31a5"
          }
        ]
      }'
      ```

      ```json Response
            ]
          }
        ],
        "successCount": 2,
        "failureCount": 0
      }
      ```
