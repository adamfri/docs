    Moderates the draft content of multiple comments that match the specified filter.

    The same action, `APPROVE` or `REJECT`, applies to all comments that match the filter.
    - `APPROVE`: Moves `draftContent` to `content` and updates the comment `status` to `PUBLISHED`.

    - `REJECT`: Handles the draft content based on the current comment status:
    - If the comment `status` is `PUBLISHED`, clears `draftContent`.
    - If the comment `status` is `PENDING`, keeps `draftContent` unchanged and changes `status` to `HIDDEN`.

    To moderate a single comment, call Moderate Draft Content.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.MANAGE.COMMENTS">Manage Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/comments/v1/bulk/comments/moderate-by-filter
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the app where to moderate the comments.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="filter" type="object" required>

      Filter to identify the comment content that needs to be moderated. Each key corresponds to an option name, and its values correspond to the choices for this option. For example, &#123;`"resourceId"`: `"64ad407e0bf87891bba7de3a"`, `"parentComment.id"`: `"726cb137-a9c3-408b-9cc2-2b64c6be8a95"`&#125;.

    </ParamField>

    <ParamField body="draftContentAction" type="string" required>

      Action to do regarding draft content

      **Supported values:**

      - `APPROVE` — Approve draft content.
      - `REJECT` — Reject draft content.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

      Pass this ID to Get Async Job, in the Async Jobs API, to retrieve job details and metadata.

      Constraints: `format GUID`.

    </ResponseField>
