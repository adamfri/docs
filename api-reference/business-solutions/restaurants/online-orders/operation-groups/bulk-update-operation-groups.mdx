    Update multiple OperationGroups in a single request. Works synchronously.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/v1/bulk/operation-groups/update
    ```

    ## Body Params

    <ParamField body="operationGroups" type="MaskedOperationGroup[]" required>

      List of OperationGroups to be updated.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="operationGroups properties">

        <ParamField body="operationGroup" type="OperationGroup">

          OperationGroup to be updated, may be partial

          See the [Operation Group Object](/api-reference/business-solutions/restaurants/online-orders/operation-groups/operation-group-object) for this object's fields.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      set to `true` if you wish to receive back the updated OperationGroups in the response

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkOperationGroupResult[]">

      Results

      Constraints: `minItems 1`, `maxItems 100`.

        <ResponseField name="itemMetadata" type="ItemMetadata">
