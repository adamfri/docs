<Note>This article applies to the JavaScript SDK only.</Note>

@package_metadata:@wix/table-reservations

To use the Reservations API, install the `@wix/table-reservations` package.

#### Install the package

Follow the installation instructions for your development environment.

| Development environment | Installation method |
|--|--|
| Wix sites (editor or IDE) | Use the [package manager](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-in-the-editor). |
| Wix sites (local IDE) | Run `wix install @wix/table-reservations` using the [Wix CLI](https://dev.wix.com/docs/develop-websites/articles/coding-with-velo/packages/work-with-npm-packages-with-the-wix-cli).|
| Blocks apps | Use the same installation method as Wix sites. |
| CLI and self-hosted apps | Run `npm install @wix/table-reservations` or `yarn add @wix/table-reservations`. |
| Headless sites and apps | Run `npm install @wix/table-reservations` or `yarn add @wix/table-reservations`. |

#### Import the package

To import the package in your code:

```js
import { reservations } from '@wix/table-reservations'
```
