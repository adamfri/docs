    <div className="wix-ref">

    Retrieves a list of up to 100 group members, given the provided paging.

    For groups with `group.privacyStatus` set to `SECRET`, only group admins and group members can see the group and its content.

    Default sorts by `joinedDate` in descending order.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-groups-proxy/members/v2/groups/{groupId}/members
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Query Params

    <ParamField query="limit" type="integer">

      Number of items to load. Maximum `100`.

    </ParamField>

    <ParamField query="offset" type="integer">

      Number of items to skip in the current sort order.

    </ParamField>

    ## Response Object

    <ResponseField name="members" type="GroupMember[]">

      Retrieved members.

      See the [Group Member Object](/api-reference/crm/community/groups/member-management/members/group-member-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Paging information.

      <Expandable title="metadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
