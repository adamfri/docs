    Deletes a category.

    <Warning>

    If you delete a category, the comments in that category become orphaned and cause loading errors. Therefore, before deleting a category, you must handle any comments it contains.
    See [Sample Flows](https://dev.wix.com/docs/api-reference/crm/community/comments/sample-flow) for more information on how to handle comments before deleting a category.

    </Warning>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="WIX_COMMENTS.CATEGORY_DELETE">WIX_COMMENTS.CATEGORY_DELETE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/comments/v1/categories/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      ID of the category to delete.

    </ParamField>

    ## Query Params

    <ParamField query="revision" type="string">

      Current revision of the category.

    </ParamField>

    ## Response Object

    Returns `DeleteCategoryResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    | Category Deleted | `wix.comments.v1.category_deleted` | Triggered when a category is deleted. |
