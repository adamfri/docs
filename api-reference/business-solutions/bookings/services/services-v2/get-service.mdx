    Retrieves a service.

    ### Conditional fields

    Use the `conditionalFields` request parameter to receive additional data in the response.
    These fields are excluded from the response by default because retrieving them requires
    additional calls to other services.

    Supported values:
    + `STAFF_MEMBER_DETAILS`: Returns `service.staffMemberDetails`.
    + `STAFF_WORKING_HOURS_LOCATIONS`: Requires `STAFF_MEMBER_DETAILS`. Returns `service.staffMemberDetails.staffMembers[].workingHoursLocationCoverage` for filtering staff by business location.
    + `RESOURCE_TYPE_DETAILS`: Returns the name of each service resource's resource type. See `service.serviceResources.resourceType.name`.
    + `DISCOUNT_INFO_DETAILS`: Returns `service.payment.discountInfo`.
    + `RESOURCE_DETAILS`: Returns the name of each individual resource assigned to a service resource. See `service.serviceResources.resourceDetails`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v2/services/{serviceId}
    ```

    ## Path Params

    <ParamField path="serviceId" type="string" required>

      ID of the service to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="conditionalFields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 5`.

      **Supported values:**

      - `STAFF_MEMBER_DETAILS` — When passed, `service.staffMemberDetails` is returned.
      - `RESOURCE_TYPE_DETAILS` — Returns the name of each service resource's resource type (for example, `'Meeting rooms'` or `'Equipment'`). See `serviceResources.resourceType.name`.
      - `DISCOUNT_INFO_DETAILS` — When passed, `service.payment.discountInfo` is returned.
      - `RESOURCE_DETAILS` — Returns details about each individual resource assigned to a service resource, including the resource name. See `serviceResources.resourceDetails`.

    </ParamField>

    ## Response Object

    <ResponseField name="service" type="Service">

      Retrieved service.

      See the [Service Object](/api-reference/business-solutions/bookings/services/services-v2/service-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
