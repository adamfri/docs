    Creates a ribbon.

    To assign the ribbon to a product, include the `ribbon.id` or `ribbon.name` when [creating](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/create-product) or [updating](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/update-product) a product.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.RIBBON_WRITE">Ribbon write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/ribbons
    ```

    ## Body Params

    <ParamField body="ribbon" type="Ribbon" required>

      Ribbon to create.

      See the [Ribbon Object](/api-reference/business-solutions/stores/catalog-v3/ribbons-v3/ribbon-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="ribbon" type="Ribbon">

      Created ribbon.

      See the [Ribbon Object](/api-reference/business-solutions/stores/catalog-v3/ribbons-v3/ribbon-object) for this object's fields.

    </ResponseField>

    ## Errors
