    <div className="wix-ref">

    Retrieves the actions in the site's action catalog, based on the provided filtering, sorting, and paging.

    The site's action catalog contains actions provided by all the apps installed on the site. Wix users can add these actions as building blocks in their automations. To reference a retrieved action when creating or updating an automation, use the `appId` and `actionKey` pair.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions/resolve
    ```
