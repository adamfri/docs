---
title: "Rule Object"
description: "A rule defines the fee that is applied when specific conditions (also defined by the rule) are met."
icon: "cube"
---

A rule defines the fee that is applied when specific conditions (also defined by the rule) are met. You can use a rule to apply a service fee to a restaurant order.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Rule ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="locationId" type="string">

      Business location ID ([SDK](https://dev.wix.com/docs/sdk/backend-modules/restaurants/wix-restaurants-new/about-business-locations) | [REST](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/about-business-locations)) of the rule.

    </ResponseField>

    <ResponseField name="name" type="string">

      Rule name.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the rule was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the rule was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="taxRate" type="string">

      Percentage value to apply as a custom tax rate. For example, `5` represents a 5% fee applied to the order's total. &lt;br />
      Min: '0'. &lt;br />
      Max: `100`.

    </ResponseField>

    <ResponseField name="conditionsType" type="string" deprecated>

      Specifies the type of condition.

      **Deprecated.** Specifies the type of condition. Use `condition_type` instead. Removal: 2024-02-15.

      **Supported values:**

      - `NO_CONDITIONS` — Indicates that the Rule has no conditions specified.
      - `CONDITION` — Indicates that the Rule has a single Condition.
      - `CONDITION_TREE` — Indicates that the Rule has a complex condition specified as a ConditionTree.

    </ResponseField>

    <ResponseField name="conditionType" type="string">

      Specifies the type of condition.

      **Supported values:**

      - `UNDEFINED_CONDITION_TYPE` — Indicates that the Rule has no conditions specified.
      - `CONDITION` — Indicates that the Rule has a single Condition.
      - `CONDITION_TREE` — Indicates that the Rule has a complex condition specified as a ConditionTree.

    </ResponseField>

    <ResponseField name="enabled" type="boolean">

      Whether the rule is enabled. If `true`, the rule is evaluated when service fees are calculated. If `false`, the rule will not be evaluated when service fees are calculated.

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number. Increments by 1 each time the rule is updated.
      To prevent conflicting changes, the existing `revision` must be used when updating a rule.

      **Read-only.**

    </ResponseField>

    <ResponseField name="label" type="string">

      DEPRECATED. Defines the app that the rule is connected to.

    </ResponseField>

    <ResponseField name="appId" type="string">

      Defines the app that the rule is connected to.

    </ResponseField>

    <ResponseField name="roundingStrategy" type="string">

      Rounding strategy to apply to fee and tax calculation.

      **Supported values:**

      - `HALF_UP` — Rounds up any number exactly halfway between two integers. For example, `2.5` rounds to `3`, and `3.5` and rounds to `4`.
      - `HALF_EVEN` — Rounds such numbers to the nearest even integer. For example, `2.5` rounds to `2`, but `3.5` rounds to `4`.

    </ResponseField>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags ([SDK](https://dev.wix.com/docs/sdk/backend-modules/tags/tags/introduction) | [REST](https://dev.wix.com/docs/rest/business-management/tags/introduction)) used to classify and sort different types of rules.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

    ## Example

    <CodeGroup>

      ```json Object
      {
        "rule": {
          "id": "4aea505e-ac49-4f72-b4f1-b07c064a20cd",
          "revision": "1",
          "createdDate": "2023-12-10T07:06:39.306Z",
          "updatedDate": "2023-12-10T07:06:39.306Z",
          "name": "rule_name",
          "taxRate": "12.9",
          "conditionType": "CONDITION",
          "enabled": false,
          "roundingStrategy": "HALF_EVEN",
          "customTaxRate": "11",
          "conditionOptions": {
            "orderFieldPath": "priceSummary.subtotal",
            "expectedFieldType": "NUMBER",
            "number": {
              "value": "10",
              "operation": "EQ"
            }
          },
          "percentageFee": "11.9"
        }
      }
      ```
