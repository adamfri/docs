---
title: "Function Template Object"
description: "A function template is a function draft based on a function type."
icon: "cube"
---

A function template is a function draft based on a function type. It contains logic that you can keep or modify.

<Tabs>

  <Tab title="REST">

    <ResponseField name="functionId" type="string">

      ID of the function built to create this template. This is the function that was built by the business solution to create the template.

      **Read-only.**

    </ResponseField>

    <ResponseField name="originFunctionId" type="string">

      ID of the original function that was copied to create this template.

      **Read-only.**

    </ResponseField>

    <ResponseField name="originMetaSiteId" type="string">

      ID of the Wix site where the original function was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Display name. This is the name used in the function builder in the [dashboard](https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Ffunctions/manage).

    </ResponseField>

    <ResponseField name="displayDescription" type="string">

      Description of what the function template's logic does.

    </ResponseField>

    <ResponseField name="appDefId" type="string">

      App ID of the business solution that created this template. This is the same as the app ID of the business solution that created the template's function type.

      **Read-only.**

    </ResponseField>

    <ResponseField name="id" type="string">

      Function template ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="version" type="integer">

      Function template version. This changes when the business solution updates the template.

      **Read-only.**

    </ResponseField>

    <ResponseField name="functionExtensionId" type="string">

      ID of the function type that this template was created from.

      **Read-only.**

    </ResponseField>

    <ResponseField name="formTemplateExtensionId" type="string">

      ID of the form template to use for [builderless creation](https://dev.wix.com/docs/api-reference/business-management/functions/builderless-productions/create-function-builderless-production). Specify this ID when calling [List Forms](https://dev.wix.com/docs/api-reference/crm/forms/form-schemas/list-forms) to retrieve the form values to use for builderless creation.

    </ResponseField>

      ```json Object
        "formTemplateExtensionId": "85cb270e-6097-4a7c-b253-8cd6923b61c8",
        "version": "1"
      }
      ```

    </CodeGroup>
