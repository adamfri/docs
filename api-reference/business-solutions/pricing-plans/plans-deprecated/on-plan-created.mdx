Triggered when a pricing plan is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pricing_plans.plan_created` |
| Package | `@wix/pricing-plans` |
| Permissions | `Read Pricing Plans`, `Manage Events`, `Manage Challenges`, `Manage Pricing Plans` |
