    Validates an automation. A valid automation has no validation errors.

    This method:

    - Validates that the [trigger is properly configured](https://dev.wix.com/docs/api-reference/business-management/automations/automations/automations-v2/configure-your-automation#configuring-the-trigger).
    - Validates that all [actions are properly configured](https://dev.wix.com/docs/api-reference/business-management/automations/automations/automations-v2/configure-your-automation#configuring-actions) with correct [input](https://dev.wix.com/docs/api-reference/business-management/automations/actions/about-actions#understanding-input-mapping) and other mappings.
    - Validates custom logic added by [trigger providers](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/trigger-provider-service-plugin/validate-configuration) and [action providers](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/validate-configuration).

    <Note>

    [Create Automation](https://dev.wix.com/docs/api-reference/business-management/automations/automations/automations-v2/create-automation) and [Update Automation](https://dev.wix.com/docs/api-reference/business-management/automations/automations/automations-v2/update-automation) don't validate the automation configuration. You can call this method before activating the automation to locate any configuration errors.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/automations-service/v2/automations/validate
    ```

    ## Body Params

    <ParamField body="automation" type="Automation" required>

      Automation to validate.

      See the [Automation Object](/api-reference/business-management/automations/automations/automations-v2/automation-object) for this object's fields.

    </ParamField>

    <ParamField body="validationSettings" type="ValidationSettings">

      Validation settings.

      When not specified, the method validates the full automation. This includes the trigger, actions, and provider validation logic.

      > **Note**: Trigger and action providers can add custom validation logic by implementing the Validate Configuration method in the [trigger service plugin](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/trigger-provider-service-plugin/validate-configuration) and [action service plugin](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/validate-configuration).

      <Expandable title="validationSettings properties">

        <ParamField body="actionIds" type="string[]">

          IDs of actions to validate.

          When specified, only these actions are validated.

          When not specified, the full automation is validated. This includes the trigger, actions, and custom logic added by the [trigger provider](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/trigger-provider-service-plugin/validate-configuration) and [action provider](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/validate-configuration).

          Constraints: `format GUID`, `maxItems 30`.

        </ParamField>

        <ParamField body="skipProviderValidations" type="boolean">

          Whether to skip [trigger provider](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/trigger-provider-service-plugin/introduction) and [action provider](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-provider-service-plugin/introduction) validations.

          Default: `false`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      Validation status.

      **Supported values:**

      - `VALID` — Automation is valid. No errors found.

      You can save and run valid automations on user sites.
      - `VALID_WITH_WARNINGS` — Automation is valid but contains at least one error with a `WARNING` severity.

      Errors with a `WARNING` allow you to save and run the automation on user sites, but this can result in unexpected behavior.
      - `INVALID` — Automation is not valid. It contains at least one error with a `CRITICAL` severity.

      Errors with a `CRITICAL` severity do not allow you to save and run the automation on user sites.

    </ResponseField>

    <ResponseField name="triggerValidationErrors" type="TriggerValidationError[]">

      Errors found in the automation's [trigger](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/about-triggers).

          - `PROVIDER_ERROR` — Error found in how the [trigger provider](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/trigger-provider-service-plugin/introduction) configured their trigger.
