    <div className="wix-ref">

    Updates order and tickets.

    This method only supports orders with status set to `"INITIATED"`, `"PENDING"`, or `"OFFLINE_PENDING"`.

    Guest details updated here must match the registration form input fields.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.EVENTS.EVENTS-CHECKOUT">Events Checkout</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/checkout/{orderNumber}
    ```

    ## Path Params

    <ParamField path="orderNumber" type="string" required>

      Unique order number.

    </ParamField>

    ## Body Params

    <ParamField body="eventId" type="string" required>

      Event ID to which the checkout belongs.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="buyer" type="Buyer">

      Buyer details.

      <Expandable title="buyer properties">

        <ParamField body="firstName" type="string">

          Buyer first name.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="lastName" type="string">

          Buyer last name.

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="email" type="string">

          Buyer email.

          Constraints: `format EMAIL`, `minLength 5`, `maxLength 255`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="guests" type="Guest[]">

      Guest details.

      Constraints: `minItems 1`, `maxItems 20`.

      <Expandable title="guests properties">

        <ParamField body="form" type="FormResponse">

          Specific guest info.

          <Expandable title="form properties">

            <ParamField body="inputValues" type="InputValue[]">

              Form field inputs.

              Constraints: `maxItems 200`.

              _Nested structure omitted for brevity — see the `InputValue[]` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="memberId" type="string">

      Member ID.

      If empty, no site member is associated with this order.

    </ParamField>

    <ParamField body="discount" type="DiscountRequest">

      Discount to apply on the invoice.

      <Expandable title="discount properties">

        <ParamField body="couponCode" type="string">

          Discount coupon code.

          Constraints: `maxLength 20`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="paidPlanBenefit" type="PaidPlanBenefit">

      Benefit granted by the pricing plan.

      <Expandable title="paidPlanBenefit properties">

        <ParamField body="planOrderId" type="string">

          Pricing plan ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="benefitId" type="string">

          Pricing plan benefit ID.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Updated order.

      See the [Order Object](/api-reference/business-solutions/events/registration/ticketing/orders/order-object) for this object's fields.

    </ResponseField>

    <ResponseField name="orderPageUrl" type="string">

      Order page URL.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
