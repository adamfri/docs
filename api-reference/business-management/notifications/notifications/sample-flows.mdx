This article shares a possible use case your app could support, as well as a sample flow that could support this use case. This can be a helpful jumping-off point as you plan your app's implementation.

## Notify a Wix site owner when a customer makes a new room reservation using your app

When a customer makes a new reservation, notify the Wix site owner with the customer name, room type, and the day of the week.

To notify a Wix site owner:

1. In your app's dashboard, [create a notification template](fallback::https://dev.wix.com/docs/rest/business-management/notifications/notifications/creating-a-notification-template) with the Wix site owner as the recipient. For example:

   > **Title:** New &#123;&#123;roomType&#125;&#125; reservation.
   >
   > **Message:** &#123;&#123;customerName&#125;&#125; just made a new &#123;&#123;roomType&#125;&#125; reservation for &#123;&#123;dayOfWeek&#125;&#125;.

   Note the given notification template ID and the dynamic values.

2. A customer makes a new room reservation. For example, Sally Jones reserves the studio for Friday.

3. Pass the given notification template ID and the dynamic values to the [Notify](fallback::https://dev.wix.com/docs/rest/business-management/notifications/notifications/notify) endpoint to trigger the notification based on the notification template:

   ```json
   {
     "notificationTemplateId": "<NOTIFICATION_TEMPLATE_ID>",
     "dynamicValues": {
       "roomType": {
         "text": "studio"
       },
       "customerName": {
         "text": "Sally Jones"
       },
       "dayOfWeek": {
         "text": "Friday"
       }
     }
   }
   ```

4. The Wix site owner receives the notification:

   > **Title:** New studio reservation.
   >
   > **Message:** Sally Jones just made a new studio reservation for Friday.
