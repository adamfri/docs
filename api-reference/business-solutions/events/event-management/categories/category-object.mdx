A Category is a classification object that groups related events on a site so you can organize and display them by themes, venues, or other facets.

You can manage Categories, assign events to them, and use them to control the selection and order of events across different pages and widgets.

Read more about [Categories](https://support.wix.com/en/article/creating-and-displaying-event-categories).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Category ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="name" type="string">

      Category name.

      Constraints: `minLength 1`, `maxLength 30`.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when category was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="counts" type="CategoryCounts">

      The total number of draft and published events assigned to the category.

      **Read-only.**

      <Expandable title="counts properties">

        <ResponseField name="assignedEventsCount" type="integer">

          Total number of draft events assigned to the category.

        </ResponseField>

        <ResponseField name="assignedDraftEventsCount" type="integer">

          Total number of published events assigned to the category. Deleted events are excluded.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="states" type="string[]">

      Category state.

      Default: `MANUAL`.

      **Note:** The WIX_EVENTS.MANAGE_AUTO_CATEGORIES permission scope is required to use states other than `MANUAL`.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `MANUAL` — Categoty is created manually by the user.
      - `AUTO` — Category is created automatically.
      - `RECURRING_EVENT` — Category is created automatically when publishing recurring events.
      - `HIDDEN` — Category is hidden.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "category": {
          "id": "e9779de3-a085-4255-b3a6-9559990d4436",
          "name": "leather",
          "states": ["MANUAL"],
          "counts": {
            "assignedEventsCount": 2,
            "assignedDraftEventsCount": 8
          },
          "createdDate": "2021-04-01T09:49:37.068Z"
        }
      }
      ```

    </CodeGroup>
