Triggered when a service is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.bookings.services.v2.service_updated` |
| Package | `@wix/bookings` |
| Permissions | `Manage Stores`, `Read Bookings - Public Data`, `Manage Bookings Services and Settings`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions` |

## Examples

<CodeGroup>

  ```javascript onServiceUpdated
  import { services } from '@wix/bookings';

  services.onServiceUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onServiceUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';

      publicKey: 'YOUR_APP_PUBLIC_KEY',

     modules: {

      },
  });

      // handle your event here
  });
  ```
