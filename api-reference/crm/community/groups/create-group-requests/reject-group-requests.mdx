    Rejects group requests.

    Only Wix users can reject group requests.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/social-groups-proxy/group-requests/v2/group-requests/reject
    ```

    ## Body Params

    <ParamField body="rejections" type="Rejection[]">

      Rejection data.

      Constraints: `maxItems 100`.

      <Expandable title="rejections properties">

        <ParamField body="groupRequestId" type="string">

          ID of the group request to reject.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="reason" type="string">

          Rejection reason. Free text displayed to the creator of the rejected group request. Limited to 1,000 characters.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="groupRequest" type="GroupRequest[]">

      Rejected group requests.

      See the [Group Request Object](/api-reference/crm/community/groups/create-group-requests/group-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Group Request Rejected | `wix.social_groups.v2.group_request_rejected` | Triggered when a group request is rejected. |
