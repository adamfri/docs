    <div className="wix-ref">

    Creates a new referring customer or returns an existing one for the provided contact ID.

    You can use `"me"` instead of a specific contact ID to generate a referring customer for the current identity's contact.

    See [About Identities](https://dev.wix.com/docs/build-apps/develop-your-app/access/about-identities) to learn more about identities.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/referral-customers/v1/referring-customers
    ```

    ## Body Params

    <ParamField body="contactId" type="string" required>

      Contact ID or `"me"` to generate the current identity's referring customer.

      Constraints: `minLength 2`.

    </ParamField>

    ## Response Object

    <ResponseField name="referringCustomer" type="ReferringCustomer">

      Created referring customer.

      See the [Referring Customer Object](/api-reference/business-management/marketing/referral-program/referring-customers/referring-customer-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Referring Customer Created | `wix.loyalty.referral.v1.referring_customer_created` | Triggered when a referring customer is created. |
