    <div className="wix-ref">

    Creates a new email marketing campaign from editor data.

    The campaign is created as a draft. Call [Publish](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/email-marketing/campaign/publish) to send it to recipients.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns
    ```

    ## Body Params

    <ParamField body="composer" type="Composer" required>

      Campaign composer.

      <Expandable title="composer properties">

        <ParamField body="composerDataJson" type="string" required>

          Editor content for the campaign. The format depends on `campaignEditorType`:

          - `WEB`: Wix proprietary JSON format used by the drag-and-drop email editor.
          - `MOBILE`: A subset of the `WEB` format, used by the mobile email editor.
          - `MJML`: MJML markup wrapped in a JSON object under key "mjml".

          Passing the wrong format for the given `campaignEditorType` causes a silent failure when sending or previewing the campaign.

          Constraints: `maxLength 10000000`.

        </ParamField>

        <ParamField body="defaultValues" type="DefaultValues">

          Fallback values for dynamic placeholders in the campaign content.

          <Expandable title="defaultValues properties">

            <ParamField body="map" type="object">

              Map of placeholder keys to their default values.

              Constraints: `format map`, `maxItems 500`.

              _Nested structure omitted for brevity — see the `object` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="campaignEditorType" type="CampaignEditorType">

      Editor type that determines the format of `composer.composerDataJson`.

      Default: `WEB`

      <Expandable title="campaignEditorType properties">

        <ParamField body="value" type="string">

          **Supported values:**

          - `WEB` — Wix classic drag-and-drop email editor. The `composerDataJson` is stored in Wix proprietary JSON format.
          - `MOBILE` — Wix classic mobile-optimized email editor. The `composerDataJson` is stored in a subset of the `WEB` format.
          - `MJML` — AI-powered email editor. The `composerDataJson` is stored in MJML format wrapped in JSON.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="emailSubject" type="string">

      Subject line displayed in recipients' inboxes (optional).

    </ParamField>

    <ParamField body="emailPreheader" type="string">

      Short preview text shown after the subject line in some email clients (optional).

    </ParamField>

    ## Response Object

    <ResponseField name="campaign" type="Campaign">

      Campaign information.

      See the [Campaign Object](/api-reference/business-management/marketing/emails/email-marketing/campaign/campaign-object) for this object's fields.

    </ResponseField>

      curl -X POST \
