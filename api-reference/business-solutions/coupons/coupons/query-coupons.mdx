    <div className="wix-ref">

    Retrieves a list of coupons with pagination and filters.
    A maximum of 100 coupons will be returned per request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-COUPONS.MANAGE-COUPONS">Manage Coupons</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v2/coupons/query
    ```

    ## Body Params

    <ParamField body="query" type="Query">

      query

      <Expandable title="query properties">

        <ParamField body="paging" type="Paging">

          Optional pagination parameters

          <Expandable title="paging properties">

            <ParamField body="limit" type="integer">

              Number of items to load.

            </ParamField>

            <ParamField body="offset" type="integer">

              Offset since the beginning of the collection.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="filter" type="string">

          Filter string (e.g., when &#123;"expired":"true"&#125;, expired coupons will be returned).

        </ParamField>

        <ParamField body="sort" type="string">

          Sort string.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="coupons" type="Coupon[]">

      Returned coupons.

      See the [Coupon Object](/api-reference/business-solutions/coupons/coupons/coupon-object) for this object's fields.

    </ResponseField>

    <ResponseField name="totalResults" type="integer">

      Total results.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
