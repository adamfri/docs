    Retrieves a list of item variants given the provided paging, filtering, and sorting. Up to 500 item variants can be returned per request.

    To learn how to query item variants, see [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$in`, `$nin`, `$eq`, `$ne` | None |
    | `name` | `$in`, `$nin`, `$eq`, `$ne` | None |
    | `createdDate` | `$gt`, `$gte`, `$lt`, `$lte`, `$eq`, `$ne` | None |
    | `updatedDate` | `$gt`, `$gte`, `$lt`, `$lte`, `$eq`, `$ne` | None |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/variants/query
    ```
