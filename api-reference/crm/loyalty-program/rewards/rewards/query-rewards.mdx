    Retrieves a list of rewards with the specified paging, filtering, and sorting.

    Query Rewards runs with these defaults, which you can override: `cursorPaging.limit` is `50`.

    To learn about working with _Query_ endpoints, see [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language),[Sorting and Paging](https://dev.wix.com/docs/rest/articles/get-started/sorting-and-paging),and [Field Projection](https://dev.wix.com/docs/rest/articles/get-started/field-projection).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.READ-LOYALTY">Read Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-rewards/v1/rewards/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery" required>

      Query parameters.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object.

          Learn more about [filtering](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#filters).

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object.

          Learn more about [sorting](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#sorting).

          Constraints: `maxItems 5`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

            <ParamField body="origin" type="AddressLocation">

              Origin point for geo-distance sorting on a GEO field
              results are ordered by distance from this point (ASC = nearest first, DESC = farthest first).

              _Nested structure omitted for brevity — see the `AddressLocation` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

          <Expandable title="pagingMethod properties">

            <ParamField body="cursorPaging" type="CursorPaging">

              Cursor paging options.

              Learn more about [cursor paging](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language#cursor-paging).

              _Nested structure omitted for brevity — see the `CursorPaging` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="rewards" type="Reward[]">

      Retrieved loyalty rewards.

      See the [Reward Object](/api-reference/crm/loyalty-program/rewards/rewards/reward-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Details on the paged set of results returned.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in current page.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
