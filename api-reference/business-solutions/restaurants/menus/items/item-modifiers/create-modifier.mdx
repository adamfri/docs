    Creates an item modifier.

    To create multiple item modifiers at once, use [Bulk Create Modifiers](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-modifiers/bulk-create-modifiers).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/item-modifiers/v1/modifiers
    ```

    ## Body Params

    <ParamField body="modifier" type="Modifier" required>

      Item modifier to create.

      See the [Item Modifier Object](/api-reference/business-solutions/restaurants/menus/items/item-modifiers/item-modifier-object) for this object's fields.

    ## Response Object

    <ResponseField name="modifier" type="Modifier">

      See the [Item Modifier Object](/api-reference/business-solutions/restaurants/menus/items/item-modifiers/item-modifier-object) for this object's fields.
