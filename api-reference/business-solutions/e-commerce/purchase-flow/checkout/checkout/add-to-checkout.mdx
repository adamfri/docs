    Adds catalog line items and/or custom line items to a checkout.

    When adding [catalog](https://dev.wix.com/docs/rest/business-solutions/stores/catalog/e-commerce-integration) items
    to a checkout, the `lineItems.catalogReference.appId` and `lineItems.catalogReference.catalogItemId` fields are required.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>
    <span className="wix-scope" title="SCOPE.ECOM.MANAGE-ADMIN">Manage eCommerce - Admin Permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkouts/{id}/add-to-checkout
    ```

              - `FULL_PAYMENT_ONLINE` — The entire payment for this item happens as part of the checkout.
              - `FULL_PAYMENT_OFFLINE` — The entire payment for this item happens after checkout. For example, when using cash, check, or other offline payment methods.
