---
title: "Category Object"
description: "A comments category allows you to define settings for a specific group of comments."
icon: "cube"
---

A comments category allows you to define settings for a specific group of comments. For example, which site visitors can comment, react, and reply to a blog post or product page.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Category ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Category name.

    </ResponseField>

    <ResponseField name="guestCommenting" type="boolean">

      Whether guest commenting is allowed.

    </ResponseField>

    <ResponseField name="guestReactions" type="boolean">

      Whether guests can add reactions to comments.

    </ResponseField>

    <ResponseField name="reactionType" type="string">

      Type of reactions available for comments.

      **Supported values:**

      - `VOTE`
      - `REACTIONS`
      - `MULTIPLE_REACTIONS`

    </ResponseField>

    <ResponseField name="repliesReactionType" type="string">

      Type of reactions available for replies.

      **Supported values:**

      - `REACTIONS`
      - `MULTIPLE_REACTIONS`

    </ResponseField>

    <ResponseField name="markedCommentLabelType" type="string">

      Default comment label for marked comments.

      When a [comment's](https://dev.wix.com/docs/api-reference/crm/community/comments/comments/introduction#terminology) `marked` field is set to `true`,
      it indicates that the comment has been flagged or marked for special attention. No additional automated behavior or action is taken with the comment.
      See the [Comments Sample Flows](https://dev.wix.com/docs/api-reference/crm/community/comments/comments/sample-flows) for an example of handling marked comments.

      **Supported values:**

      - `FEATURED`
      - `BEST_ANSWER`
      - `SOLVED`
      - `PINNED`
      - `CUSTOM`

    </ResponseField>

    <ResponseField name="customMarkedCommentLabel" type="string">

      Custom label value for marked comments. See the description for `markedCommentLabelType` for more information about marked comments.

    </ResponseField>

    <ResponseField name="mainReaction" type="ReactionIcon">

      Type of icon to use as the main comment reaction.

      <Expandable title="One of the following">

        <ResponseField name="icons" type="icons">

          icons

          <Expandable title="icons properties">

            <ResponseField name="iconType" type="string">

              Type of icon to use.

              **Supported values:**

              - `LOVE`
              - `THUMBS_UP`

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="ratingsSettings" type="RatingsSettings">

      Ratings settings.

      <Expandable title="ratingsSettings properties">

        <ResponseField name="ratingsEnabled" type="boolean">

          Whether ratings are enabled.

        </ResponseField>

        <ResponseField name="ratingRequired" type="boolean">

          Whether leaving a rating is required.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the category is updated. To prevent conflicting changes, the current revision must be passed when updating the category.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the category was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the category was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="permissionsSettings" type="PermissionsSettings">

      Permissions settings for specific actions in the category.

      <Expandable title="permissionsSettings properties">

        <ResponseField name="createComment" type="Permissions">

          Whether comments are enabled and for which roles.

          <Expandable title="createComment properties">

            <ResponseField name="role" type="string">

              Which users have permission for this action.

              **Supported values:**

              - `ALL`
              - `MEMBER`
              - `ADMIN`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="createReply" type="Permissions">

          Whether replies are enabled and for which roles.

          <Expandable title="createReply properties">

            <ResponseField name="role" type="string">

              Which users have permission for this action.

              **Supported values:**

              - `ALL`
              - `MEMBER`
              - `ADMIN`

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="createReact" type="Permissions">

          Whether reactions are enabled and for which roles.

          <Expandable title="createReact properties">

            <ResponseField name="role" type="string">

              Which users have permission for this action.

              **Supported values:**

              - `ALL`
              - `MEMBER`
              - `ADMIN`

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="active" type="boolean">

      Whether the category is active and being used in a live site.

    </ResponseField>

    <ResponseField name="appId" type="string">

      ID of the app the category applies to.

    </ResponseField>

  </Tab>
