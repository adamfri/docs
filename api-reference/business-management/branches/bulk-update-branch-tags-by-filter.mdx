  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Asynchronously updates tags on multiple branches that match the provided filter criteria.

    Specify which tags to assign and which tags to unassign. A tag that appears both the list to assign and the list to unassign tags, will be assigned.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    To update a single branch's tags, call [Update Branch](https://dev.wix.com/docs/api-reference/business-management/branches/update-branch).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DOCUMENT-MANAGEMENT.MANAGE-BRANCHES">Manage Site Branches</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/branches/v1/bulk/branches/update-tags-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter to select which branches to update. See [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language) for more information.

    </ParamField>

    <ParamField body="assignTags" type="PublicTags">

      Tags to assign to the branches.

      <Expandable title="assignTags properties">

        <ParamField body="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="PublicTags">

      Tags to unassign from the branches.

      <Expandable title="unassignTags properties">

        <ParamField body="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID. Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job) to retrieve the status of the asynchronous operation.
