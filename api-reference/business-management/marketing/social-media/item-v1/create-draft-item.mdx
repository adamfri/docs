    Creates a draft item.

    A draft is an item that's saved but not yet published, with a `status` of `DRAFT`. Drafts appear on the site's Social Media Marketing page in the dashboard, where they can be reviewed and published. To publish a draft, call Publish Item By ID.

    The item's `type` and content must match a combination supported by the target channel. See `item.type` for the supported combinations.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-publisher/v1/items
    ```

    ## Body Params

    <ParamField body="item" type="Item">

      Item to create as a draft.

      See the [Item Object](/api-reference/business-management/marketing/social-media/item-v1/item-object) for this object's fields.

    </ParamField>

    <ParamField body="itemExtras" type="ItemExtras">

      itemExtras

      <Expandable title="itemExtras properties">

        <ParamField body="userOrigin" type="string">

          Where the user began the flow to open the publisher. For example, `stores.product-list`.

        </ParamField>

      </Expandable>

    </ParamField>
