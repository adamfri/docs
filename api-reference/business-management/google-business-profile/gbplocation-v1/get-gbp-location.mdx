      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Retrieves a GBP location as it's stored for the site.

    This doesn't call Google, so it's the cheapest way to check whether a
    location is recorded and to read its `accountId` or
    `serviceAreaPostalAddress`. To get the live Google profile as well, call
    Get Google Location.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gbp/v1/locations/{locationId}
    ```

    ## Path Params

    <ParamField path="locationId" type="string" required>

      ID of the location to retrieve. This is Google's location identifier.

    </ParamField>

    ## Response Object

    <ResponseField name="gbplocation" type="GBPLocation">

      The retrieved location.

      See the [Gbplocation Object](/api-reference/business-management/google-business-profile/gbplocation-v1/gbplocation-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
