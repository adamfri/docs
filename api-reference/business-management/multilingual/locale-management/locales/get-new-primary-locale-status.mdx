    Retrieves the status of the Create New Primary Locale method.

    Call this method to see if your primary locale was successfully changed. Specify the token returned by Create New Primary Locale. If the token specified is invalid, a 404 error is returned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/locales/v2/locale/change-primary
    ```

    ## Query Params

    <ParamField query="token" type="string" required>

      Token to retrieve the process status. Returned in the response of Create New Primary Locale.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      The current status of the Create New Primary Locale method.

      **Supported values:**

      - `IN_PROGRESS` — Indicates the process of creating a new primary locale is in progress.
      - `FINISH_SUCCESSFUL` — Indicates the process of creating a new primary locale was successful and all content under the previous primary locale is now tagged under the new locale. New primary locale data is available in the `finishSuccessfulData` object.
      - `FINISH_WITH_ERROR` — Indicates the process of creating a new primary locale failed. Additional error details are available in the `finishWithErrorData` object.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
