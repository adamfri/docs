    <div className="wix-ref">

    Deletes multiple form schemas at once.

    The schemas are moved to the trash bin where they're stored for 90 days before permanent deletion.
    When permanently deleted, all associated form submissions are also deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/v4/bulk/forms/delete
    ```

    ## Body Params

    <ParamField body="formIds" type="string[]" required>

      IDs of the form schemas to delete.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="permanent" type="boolean">

      Whether to permanently delete the form schemas, bypassing the trash bin.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkFormResult[]">

      Results of the bulk delete operation

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          <Expandable title="itemMetadata properties">

        </ResponseField>

        <ResponseField name="item" type="Form">

          Deleted form schema.

          See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">
