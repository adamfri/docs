    Adds media items to a specified product, either via URL or existing media ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-PRODUCTS">Manage Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v1/products/{id}/media
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Product ID.

    </ParamField>

    ## Body Params

    <ParamField body="media" type="MediaDataForWrite[]">

      Sources of media items already uploaded to the Wix site.

      Constraints: `minItems 1`, `maxItems 50`.

      <Expandable title="media properties">

        <ParamField body="choice" type="OptionAndChoice">

          Assign this media item to a specific product choice.
          Note that you may set media items for choices under only one option (e.g., if Colors blue, green, and red have media items, Sizes S, M, and L can't have media items assigned to them).
          You may clear existing media from choices with the [Remove Product Media From Choices](/catalog/products/remove-product-media-from-choices).

          <Expandable title="choice properties">

            <ParamField body="option" type="string">

              Option to add the media to.

              Constraints: `minLength 1`, `maxLength 50`.

            </ParamField>

            <ParamField body="choice" type="string">

              Choice to add the media to.

              Constraints: `minLength 1`, `maxLength 50`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `AddProductMediaResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Add media items to a product
    /**************************************
     * Backend code - products.web.js/ts *
     **************************************/

    import { Permissions, webMethod } from '@wix/web-methods';
    import { products } from '@wix/stores';

    export const addProductMedia = webMethod(Permissions.Anyone, (_id, media) => {
      return products.addProductMedia(_id, media);
    });

    /*************
     * Page code *
     *************/
    import { addProductMedia } from 'backend/products.web';

    // ...

    const _id = ...; // get product ID
    const url = "wix:image://v1/1a11a1_..._1a~mv2.jpg/1a11a1_..._1a~mv2.jpg";
    const choice = "Color";
    const option = "Blue";

    let media;
    if (choice !== "" && option !== "") {
      media = [{ // add media item to a choice
        url,
        choice: {
          choice,
          option
        }
      }];
    } else {
      media = [{ // add media item to the product
        url
      }];
    }

    addProductMedia(_id, media);
    ```
