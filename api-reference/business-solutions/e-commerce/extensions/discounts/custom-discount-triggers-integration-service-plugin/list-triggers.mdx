    Lists all custom triggers provided by your service plugin integration.

    This method is automatically called by Wix eCommerce to populate the custom [minimum requirements section of an automatic discount](https://support.wix.com/en/article/wix-stores-creating-automatic-discounts#:~:text=Create%20minimum%20requirements).

    ## Endpoint

    ```http
    POST /v1/list-triggers
    ```

    ## Response Object

    <ResponseField name="customTriggers" type="CustomTrigger[]">

      Custom triggers.

      <Expandable title="customTriggers properties">

        <ResponseField name="id" type="string">

          Custom trigger ID.

          Constraints: `minLength 1`, `maxLength 100`.

        </ResponseField>

        <ResponseField name="name" type="string">

          Custom trigger name to display in the dashboard.

          Constraints: `minLength 1`, `maxLength 200`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
