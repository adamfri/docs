    <div className="wix-ref">

    Sets or updates attendance information for multiple booking sessions.

    Refer to Set Attendance for detailed behavior of individual attendance
    entries.

    The call fails entirely if any entry in `attendanceDetails` is missing a
    required field.

    If attendance details are provided for a non-existent session, the call
    succeeds for valid sessions while marking the unavailable session as a
    failure in the response.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bulk/attendance/set
    ```
