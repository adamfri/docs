Triggered when a media item in a specified gallery is deleted.

<Note>

The event is triggered when a gallery item is deleted individually and when a gallery item is deleted because its gallery is deleted.
The property `originatedFrom` has the value `Gallery Deleted` if the entire gallery is deleted. If the gallery item is deleted individually, this field is empty.

</Note>

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.pro_gallery.gallery_v2_gallery_item_deleted` |
| Package | `@wix/pro-gallery` |
| Permissions | `Manage Galleries`, `Read Galleries` |
