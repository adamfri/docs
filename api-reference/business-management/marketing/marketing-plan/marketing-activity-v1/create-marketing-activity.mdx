    Creates a marketing activity.

    Required fields: `title`, `description`, `targetDate`, and `marketingActivityType` (must be set and not `UNKNOWN`;
    one of `SOCIAL_MARKETING`, `EMAIL_MARKETING`, or `BLOG`). Missing any of these returns a `FAILED_PRECONDITION` error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-activity
    ```

    ## Body Params

    <ParamField body="marketingActivity" type="MarketingActivity" required>

      Marketing activity to create.

    <ResponseField name="marketingActivity" type="MarketingActivity">

      See the [Marketing Activity Object](/api-reference/business-management/marketing/marketing-plan/marketing-activity-v1/marketing-activity-object) for this object's fields.
