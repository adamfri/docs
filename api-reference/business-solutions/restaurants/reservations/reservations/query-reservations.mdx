    Retrieves a list of reservations given the provided paging, filtering, and sorting. Up to 100 reservations can be returned per request.

    For a detailed list of supported operations, see the [Sorting, Filtering, and Search](https://dev.wix.com/docs/rest/api-reference/wix-restaurants/reservations/reservations/sorting-filtering-and-search) article.
    To learn how to query reservations, see [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in` | None |
    | `status` | `$eq`, `$ne`, `$in` | None |
    | `details.startDate` | `$eq`, `$ne`, `$in`, `$lt`, `$gt`, `$lte`, `$gte` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
