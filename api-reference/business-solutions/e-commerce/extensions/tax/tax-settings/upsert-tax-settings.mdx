    Creates or updates the site's tax settings.

    If the site's tax settings don't exist yet, this method creates them. Otherwise, it updates the existing settings.

    Since these settings are shared across all Wix products on the site, changes take effect immediately for all integrated products.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="billing:tax:v1:tax_settings:upsert_tax_settings">billing:tax:v1:tax_settings:upsert_tax_settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/tax-settings
    ```

    ## Body Params

    <ParamField body="taxSettings" type="TaxSettings" required>

      Tax settings to upsert.

      See the [Tax Settings Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-settings/tax-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="taxSettings" type="TaxSettings">

      Created or updated tax settings.

      See the [Tax Settings Object](/api-reference/business-solutions/e-commerce/extensions/tax/tax-settings/tax-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    Updates the site's tax settings. The first update for a site creates the tax settings; subsequent updates modify them in place.

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/billing/v1/tax-settings' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>' \
        -d '{
          "taxSettings": {
            "taxIncludedInItemPrices": true
          }
        }'
      ```

      ```json Response
      {
        "taxSettings": {
          "taxIncludedInItemPrices": true,
          "createdDate": "2026-05-14T10:23:47.812Z",
          "updatedDate": "2026-06-22T15:08:34.207Z"
        }
      }
      ```

    </CodeGroup>
