    <div className="wix-ref">

    Creates a new referred friend or returns an existing entity if it already exists.

    This method must be called with a [member identity](https://dev.wix.com/docs/build-apps/develop-your-app/access/about-identities#site-members).

    A referral code must be provided either in the request or via scope.

    The member must be eligible to become a referred friend.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/referral_friends/v1/referred-friends
    ```

    ## Body Params

    <ParamField body="referralCode" type="string">

      Referral code for the referred friend.

    </ParamField>

    ## Response Object

    <ResponseField name="referredFriend" type="ReferredFriend">

      Created referred friend.

      See the [Referred Friend Object](/api-reference/business-management/marketing/referral-program/referred-friends/referred-friend-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `MEMBER_NOT_ELIGIBLE` | The member isn't eligible to become a referred friend. This can happen if another customer has already referred the member or if the member is already a referring customer. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">
