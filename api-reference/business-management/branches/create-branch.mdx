    <div className="wix-ref">

    Creates a branch.

    If a source branch isn't provided, the branch will include a blank website.

    <Note>

    Align the `sourceType` field with its corresponding source properties:
    - When `sourceType` is `SOURCE_BRANCH`, provide `sourceBranchProperties`.
    - When `sourceType` is `SOURCE_TEMPLATE`, provide `sourceTemplateProperties`.

    Using `UNKNOWN_SOURCE_TYPE` or mismatched properties results in an `ILLEGAL_SOURCE_TYPE` error.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DOCUMENT-MANAGEMENT.MANAGE-BRANCHES">Manage Site Branches</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/branches/v1/branches
    ```

    ## Body Params

    <ParamField body="branch" type="Branch" required>

      Branch to create.

      See the [Branch Object](/api-reference/business-management/branches/branch-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="branch" type="Branch">

      Created branch.

      See the [Branch Object](/api-reference/business-management/branches/branch-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `SOURCE_BRANCH_NOT_FOUND` | Couldn't find the source branch. |
    | `428` | `FAILED_PRECONDITION` | `TEMPLATE_ID_NOT_SUPPORTED` | The specified template isn't supported for branch creation. |
    | `409` | `ALREADY_EXISTS` | `ORIGINAL_BRANCH_ALREADY_EXISTS` | Original branch already exists. |
    | `409` | `ALREADY_EXISTS` | `TARGET_BRANCH_SITE_HEADER_ALREADY_EXISTS` | A site header representing the full immutable state of the site already exists for the specified branch. Each branch can only have 1 site header. |
    | `428` | `FAILED_PRECONDITION` | `ILLEGAL_SOURCE_TYPE` | The `sourceType` field doesn't match its corresponding source properties. Use `sourceBranchProperties` for `SOURCE_BRANCH` or `sourceTemplateProperties` for `SOURCE_TEMPLATE`. |
    | `404` | `NOT_FOUND` | `SOURCE_USER_BRANCH_DOES_NOT_EXIST` | Couldn't find the source user branch. |
    | `400` | `INVALID_ARGUMENT` | `EDITOR_TYPE_VALIDATION` | The provided `editorType` isn't supported. Only `STUDIO_TWO` may be provided explicitly. |
    | `428` | `FAILED_PRECONDITION` | `CONTEXT_MISSING_USER_ID` | The request context doesn't carry a user identity, which is required for creating a branch from a template. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Branch Created | `wix.editor.branches.v1.branch_created` | Triggered when a branch is created. |

    </div>
