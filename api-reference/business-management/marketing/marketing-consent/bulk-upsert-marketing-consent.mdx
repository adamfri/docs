    <div className="wix-ref">

    Creates or updates multiple marketing consents.
    Required fields:
    - `details.type`.
    - `details.email` OR `details.phone`.
    - `state`.

    When a marketing consent's `state` is `PENDING` or `CONFIRMED`, the `info.lastConfirmationActivity` field is required.
    When a marketing consent's `state` is `REVOKED`, the `info.lastRevokeActivity` field is required.

    <Note>

    For existing marketing consents with `{"type": "EMAIL"}`, you can't update the `state` to `UNKNOWN_STATE`. Trying to do so maintains the current state. However, you can create a new marketing consent and set the `state` to `UNKNOWN_STATE`. Note that you can't create more than a single consent per email or phone number.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MARKETING.CONSENT-MANAGE">Manage Marketing Consents</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/marketing-consent/v1/bulk/marketing-consent/upsert
    ```

    ## Body Params

    <ParamField body="info" type="MarketingConsent[]">

      List of marketing consent information to update or create.

      Constraints: `minItems 1`, `maxItems 500`.

      See the [Marketing Consent Object](/api-reference/business-management/marketing/marketing-consent/marketing-consent-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkUpsertMarketingConsentResult[]">

      List of created or updated marketing consents.

      <Expandable title="results properties">

        <ResponseField name="originalIndex" type="integer">

          Position of the newly created or updated marketing consent in the array.

        </ResponseField>

        <ResponseField name="marketingConsent" type="MarketingConsent">

          Newly created or updated marketing consent.

          See the [Marketing Consent Object](/api-reference/business-management/marketing/marketing-consent/marketing-consent-object) for this object's fields.

        </ResponseField>

        <ResponseField name="error" type="string">

          Information about the error. Only returns if the action fails.

        </ResponseField>

        <ResponseField name="link" type="Link">

          Marketing consent confirmation or cancelation link.

          <Expandable title="link properties">

            <ResponseField name="type" type="string">

              Link type.

              **Supported values:**

              - `UNKNOWN_LINK_TYPE`
              - `CONFIRMATION`
              - `REVOKE_CONFIRMATION`

            </ResponseField>

            <ResponseField name="url" type="string">

              The link's URL.

              Constraints: `format WEB_URL`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="metadata" type="Metadata">

      Numbers of successful and failed actions.

      <Expandable title="metadata properties">

        <ResponseField name="totalSuccess" type="integer">

          Number of successful actions.

        </ResponseField>

        <ResponseField name="totalFailure" type="integer">

          Number of failed actions.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
