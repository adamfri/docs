    <div className="wix-ref">

    Deletes a `serviceOptionsAndVariants` object.

    Because each service can be connected to only a single `serviceOptionsAndVariants`
    object, the service doesn't support [varied pricing](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/about-service-payments)
    after deleting a `serviceOptionsAndVariants` object. Instead, Wix Bookings
    uses its standard price calculation.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/bookings/v1/serviceOptionsAndVariants/{serviceOptionsAndVariantsId}
    ```

    ## Path Params

    <ParamField path="serviceOptionsAndVariantsId" type="string" required>
