    <div className="wix-ref">

    Renames an extended field.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-EX-FIELDS">Manage Contact Extended Fields</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/contacts/v4/extended-fields/{field.key}
    ```

    ## Path Params

    <ParamField path="field.key" type="string" required>

      Extended field key.

      When accessing contact data,
      extended field data is available at `extendedFields[key]`.
      For example, if the key is "custom.notes",
      the value can be accessed at `extendedFields["custom.notes"]`.

      `key` is generated when the extended field is created
      and can't be modified, even if `displayName` changes.

    </ParamField>

    ## Body Params

    <ParamField body="field" type="ExtendedField">

      Extended field to rename.

      See the [Extended Field Object](/api-reference/crm/members-contacts/contacts/extended-fields/extended-field-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="field" type="ExtendedField">

      Renamed extended field.

      See the [Extended Field Object](/api-reference/crm/members-contacts/contacts/extended-fields/extended-field-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Extended Field Updated | `wix.contacts.v4.extended-field_updated` | Triggered when an extended field is updated. |

    </div>
