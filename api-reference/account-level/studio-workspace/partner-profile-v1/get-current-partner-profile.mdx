    Retrieves the partner profile of the currently authenticated partner.

    The partner's public profile URL is `https://www.wix.com/studio/community/partners/{slug}`, where `slug` is returned in this response.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ARENA.MANAGE-LEADS">Manage CRM and Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/profile/v1/partner-profiles/current
    ```

    ## Response Object

    <ResponseField name="partnerProfile" type="PartnerProfile">

      Retrieved partner profile.

      See the [Partner Profile Object](/api-reference/account-level/studio-workspace/partner-profile-v1/partner-profile-object) for this object's fields.

    </ResponseField>

    <Note>
