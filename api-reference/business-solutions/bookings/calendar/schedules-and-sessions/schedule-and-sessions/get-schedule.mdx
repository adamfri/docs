Gets a schedule from the calendar.

> **Permissions**
> This endpoint requires the Read Bookings Calendar or the Manage Bookings permissions scope.
> With the Read Bookings Calendar permission scope, the schedule participants are not returned.

## Endpoint

```http
GET https://www.wixapis.com/bookings/v1/calendar/schedules/{id}
```

## Path Params

<ParamField path="id" type="string" required>

  Schedule ID.

</ParamField>

## Response Object

<ResponseField name="schedule" type="Schedule">

  Schedule.

  See the [Schedule Object](/api-reference/business-solutions/bookings/calendar/schedules-and-sessions/schedule-and-sessions/schedule-object) for this object's fields.

</ResponseField>

## Errors

<Note>

</Note>
