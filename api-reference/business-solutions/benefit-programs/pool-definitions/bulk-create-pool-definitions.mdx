    Creates pool definitions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/bulk/pool-definitions/create
    ```

    ## Body Params

    <ParamField body="poolDefinitions" type="PoolDefinition[]" required>

      Pool definitions to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Pool Definition Object](/api-reference/business-solutions/benefit-programs/pool-definitions/pool-definition-object) for this object's fields.

    </ParamField>

    <ParamField body="cascade" type="string">

      Determines when the changes to the program definitions containing these pool definitions will be applied to associated programs.

      Required if the `poolDefinition.programDefinitionIds` parameter is defined.

      **Supported values:**

      - `UNKNOWN_CASCADE` — Unknown cascade.
      - `NEXT_RENEWAL` — Changes are applied to existing programs and pools when they are next renewed.
      - `IMMEDIATELY` — Changes are applied to associated programs and pools immediately.
      - `FUTURE_PROVISIONS` — Changes are not applied to existing associated programs and pools. They are only applied to future programs and pools.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created pool definitions.

      Default: `false`

    </ParamField>
