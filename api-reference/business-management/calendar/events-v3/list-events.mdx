    <div className="wix-ref">

    Retrieves a list of events by their IDs.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PUBLIC">Read Calendar</span>
    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PI">Read Calendar - Including PI</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/calendar/v3/events
    ```

    ## Query Params

    <ParamField query="eventIds" type="string[]" required>

      IDs of the events to retrieve.

      Min: 1 event ID
      Max: 100 event IDs

      Constraints: `minLength 36`, `maxLength 250`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField query="timeZone" type="string">

      Time zone in [IANA tz database format](https://en.wikipedia.org/wiki/Tz_database)
      for calculating `adjustedStart` and `adjustedEnd`. For example,
      `America/New_York` or `UTC`.

      Default: `timeZone` specified in the business [site properties](https://dev.wix.com/docs/rest/business-management/site-properties/properties/get-site-properties).

    </ParamField>

    <ParamField query="fields" type="string[]">

      Information about which fields containing personal data to return. Refer to the
      [permissions article](https://dev.wix.com/docs/rest/business-management/calendar/permissions)
      for more information.

      Supported values:
      + `PI_FIELDS`: Returns all fields with personal data. Your app must have `Read Calendars - Including PI` or `Manage Calendars` permission scope.
      + `OWN_PI_FIELDS`: Returns only fields containing your own personal data.

      Max: 1 field
      Default: No personal data is returned.

      Constraints: `maxItems 1`.

      **Supported values:**

      - `PI_FIELDS` — Returns all fields with personal data. Your app must have `Read Calendars - Including PI` or `Manage Calendars` permission scope.
      - `OWN_PI_FIELDS` — Returns only fields containing your own personal data.

    </ParamField>

    ## Response Object

    <ResponseField name="events" type="Event[]">

      Retrieved events matching the provided IDs.

      See the [Event Object](/api-reference/business-management/calendar/events-v3/event-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
