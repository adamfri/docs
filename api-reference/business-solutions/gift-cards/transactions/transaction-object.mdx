---
title: "Transaction Object"
description: "A transaction represents a change to a gift card's balance, including redemptions, refunds, and initial value assignments."
icon: "cube"
---

A transaction represents a change to a gift card's balance, including redemptions,
refunds, and initial value assignments. Transactions provide an audit trail
of all gift card activity and cannot be modified once created.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Transaction ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the transaction was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="type" type="string">

      Type of transaction indicating the reason for the balance change.

      **Read-only.**

      **Supported values:**

      - `REDEEM` — Gift card was used to pay for a purchase.
      - `VOID` — Previous redemption was cancelled, restoring the gift card balance.
      - `INITIAL` — Initial value was assigned when the gift card was created.
      - `PAYMENT_METHOD_REFUND` — Refund was processed, adding value back to the gift card.
      - `MANUAL` — Manual adjustment.

    </ResponseField>

    <ResponseField name="giftCardId" type="string">

      Gift card ID associated with this transaction.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="amount" type="Amount">

      Monetary amount of the transaction.
      Positive values represent credits, negative values represent debits.

      **Read-only.**

      <Expandable title="amount properties">

        <ResponseField name="amount" type="string">

          Monetary amount in the specified currency as a decimal string.
          For example, `"10.50"` for $10.50, or `"100"` for $100.00.

          Constraints: `format DECIMAL_VALUE`, `>= 0`.

        </ResponseField>

        <ResponseField name="formattedAmount" type="string">

          Amount formatted with currency symbol for display purposes.
          For example: `"$10.50"` or `"€25.00"`.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="updatedBalance" type="Amount">

      Gift card balance after this transaction was applied.

      **Read-only.**

      <Expandable title="updatedBalance properties">

        <ResponseField name="amount" type="string">

          Monetary amount in the specified currency as a decimal string.
          For example, `"10.50"` for $10.50, or `"100"` for $100.00.

          Constraints: `format DECIMAL_VALUE`, `>= 0`.

        </ResponseField>

        <ResponseField name="formattedAmount" type="string">

          Amount formatted with currency symbol for display purposes.
          For example: `"$10.50"` or `"€25.00"`.

          **Read-only.** Constraints: `maxLength 20`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="operationType" type="string">

      Whether the transaction adds to or subtracts from the gift card balance.

      **Read-only.**

      **Supported values:**

      - `ADD` — Transaction adds value to the gift card balance.
      - `SUBTRACT` — Transaction subtracts value from the gift card balance.

    </ResponseField>

    <ResponseField name="orderInfo" type="OrderInfo">

      Order details when the transaction is related to an eCommerce purchase or refund.

      <Expandable title="orderInfo properties">

        <ResponseField name="orderId" type="string">

          Order ID associated with the gift card purchase.

          Constraints: `format GUID`, `immutable`.

        </ResponseField>

        <ResponseField name="orderNumber" type="string">

          Human-readable order number displayed to customers.
          For example, `"1001"`.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
