> **Note for app developers:** Wix Data APIs require the site's [code editor](##code-editor*fallback::https://dev.wix.com/docs/develop-websites/articles/getting-started/development-environments#code-editor) to be enabled. If you are building a Wix app, add a [data collections extension](fallback::https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/data-collections/about-data-collections-extensions) to automatically enable the code editor and create data collections when your app is installed on a site.

The Data Movement Jobs API allows you to create and manage jobs to move data to and from a Wix site. Jobs can transfer [data items](fallback::https://dev.wix.com/docs/rest/business-solutions/cms/data-items/introduction) or [localized CMS content](fallback::https://support.wix.com/en/article/wix-multilingual-translating-cms-collection-content) between data collections, files, or sites.

<Note>

By default, jobs run on the current site. However, a job can run on any site in the same account. Learn more about [managing multiple sites under one account](fallback::https://support.wix.com/en/article/managing-multiple-sites-under-one-account).

</Note>

With the Data Movement Jobs API, you can:

- [Submit a job](https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/submit-job) to move data from a source to a destination.
- [Query](https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/query-jobs) and [list jobs](https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/list-jobs) for the current site.
- [Retrieve a job](https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/get-job) to view its status.
- [Terminate a job](https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/terminate-job) before it completes.
- [List a job's logs](https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/list-movement-logs) to view additional details about it.

## Before you begin

It's important to note the following points before starting to code:

- You can only move localized CMS content to or from a site that has [Wix Multilingual](fallback::https://support.wix.com/en/article/wix-multilingual-adding-and-setting-up-wix-multilingual) installed.

- [Export data from a collection to a file](##export-data-from-a-collection-to-a-file*fallback::https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/sample-flows#export-data-from-a-collection-to-a-file).
- [Import data from a file to a collection](##import-data-from-a-file-to-a-collection*fallback::https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/sample-flows#import-data-from-a-file-to-a-collection).
- [Export, edit, and import localized CMS content](##export-edit-and-import-translated-cms-content*fallback::https://dev.wix.com/docs/rest/business-solutions/cms/data-movement-jobs/sample-flows#export-edit-and-import-translated-cms-content).
- Move data from the current site to another site in the same account.

## Error information

When working with the Data Movement Jobs API, you might encounter the following errors:

| Error Code | Description                                                                                                                                                                              |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `WDH0000`  | Unknown error.                                                                                                                                                                           |
| `WDH0001`  | Validation error during initialization.                                                                                                                                                  |
| `WDH0002`  | Internal service error when calling other Wix APIs. The error message contains additional information.                                                                                   |
| `WDH0003`  | Invalid data error when the data you're trying to move has an invalid format or unexpected values. For example, when uploading a file with corrupt contents or in an unsupported format. |

Errors can also be generated by other Wix services, such as the [Data Items API](fallback::https://dev.wix.com/docs/rest/business-solutions/cms/data-items/introduction) or the [Multilingual API](fallback::https://dev.wix.com/docs/rest/business-management/multilingual/translation/introduction).

Learn more about [Wix Data error codes](fallback::https://dev.wix.com/docs/sdk/backend-modules/data/wix-data-error-codes).

## Terminology

- **Data movement job**: A process that moves data from a source to a destination.
- **Source**: Where data is moved from. This can be a data collection, a file, or localized CMS content.
- **Destination**: Where data is moved to. This can be a data collection, a file, or localized CMS content.
- **Localization**: Translated CMS content. Learn more about [translating CMS collection content with Wix Multilingual](fallback::https://support.wix.com/en/article/wix-multilingual-adding-and-setting-up-wix-multilingual).
