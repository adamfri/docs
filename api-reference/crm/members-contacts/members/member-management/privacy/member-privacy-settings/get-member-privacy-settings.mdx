<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the member privacy settings for a site.

    If no settings were set, the default settings are retrieved.

    <Note>

    This method requires [visitor or member authentication](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Endpoint

    ```http
    GET https://www.wixapis.com/members/v1/privacy-settings
    ```

    ## Response Object

    <ResponseField name="memberPrivacySettings" type="MemberPrivacySettings">

      Retrieved member privacy settings.

      See the [Member Privacy Settings Object](/api-reference/crm/members-contacts/members/member-management/privacy/member-privacy-settings/member-privacy-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">
