    Updates one or more items in a collection. Items must be completely replaced.

    The response array must include the same items that were updated, and each returned item must be added the `_createdDate` and `_updatedDate` fields.

    ## Endpoint

    ```http
    POST /v3/items/update
    ```

    ## Body Params

    <ParamField body="collectionId" type="string" required>

      ID of the collection in which to update the items.

    </ParamField>

    <ParamField body="items" type="object[]" required>

      Items to update.

      Constraints: `minItems 1`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="DataItemModificationResult[]">

      Response must include either the updated item or an error.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
