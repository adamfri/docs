Submits evidence and triggers the review process.

Deprecated in favor of `wix.payments.disputes.v1.DisputeService.DefendDispute`.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/payments/v3/transactions/{transactionId}/disputes/{disputeId}/submit-evidence
```

## Path Params

<ParamField path="transactionId" type="string" required>

  Transaction ID.

</ParamField>

<ParamField path="disputeId" type="string" required>

  Dispute ID.

</ParamField>

## Body Params

<ParamField body="accountId" type="string" required>

  Wix Payments account ID.

  Constraints: `format GUID`.

</ParamField>

## Response Object

<ResponseField name="transaction" type="Transaction">

  Transaction information.

  See the [Transaction Object](/api-reference/business-management/payments/wix-payments-provider/transactions/transaction-object) for this object's fields.

</ResponseField>

## Errors

| Status | Code | Application code | Description |
| --- | --- | --- | --- |
| `428` | `FAILED_PRECONDITION` | `DISPUTE_EVIDENCE_LENGTH_EXCEEDED` | Total evidence size exceeds the maximum allowed. |

<Note>

  This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
