Triggered when translation schema is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.translation.v1.schema_updated` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation Schema Read` |
