    Retrieves a list of up to 1,000 categories with the specified filtering, sorting, and cursor paging.
    Specify supported values in `fields` to include those fields in the response.

    ## Defaults

    Search Categories has the following default settings, which you can override:
    + Sorted by `createdDate` in descending order.
    + `cursorPaging.limit` set to `100`.

    To learn about working with *Search* methods, see
    [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language)
    and [Sorting and Paging](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-sorting-and-paging).

    Learn more about the differences between [_Query_ and _Search_](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-search-query-and-list-methods) methods.

    This method requires one of the following permission scopes:

    ## Endpoint

    ```http
    POST https://www.wixapis.com/categories/v1/categories/search
    ```

    ## Body Params

    <ParamField body="search" type="CursorSearch">

      Search criteria including filter, sort, aggregations, and paging options.

      <Expandable title="search properties">

        <ParamField body="filter" type="object">

          Filter object for narrowing search results.

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Array of sort objects specifying result order.

          Constraints: `maxItems 10`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC` — Ascending order.
              - `DESC` — Descending order.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="aggregations" type="Aggregation[]">

          Aggregations for grouping data into categories (facets) and providing summaries for each category.
          For example, use aggregations to categorize search results by service type, payment options, or locations.

          Constraints: `maxItems 10`.

          <Expandable title="aggregations properties">

            <ParamField body="name" type="string">

              User-defined name of aggregation. Must be unique and will appear in aggregation results.

            </ParamField>

            <ParamField body="type" type="string">

              Type of aggregation. Client must specify matching aggregation field below.

              **Supported values:**

              - `VALUE` — Calculates the distribution of a specific field's values within a dataset, providing insights into the overall distribution and key statistics of those values.
              - `RANGE` — Calculates the count of the values from the specified field in the dataset that fall within the range of each bucket you define.
              - `SCALAR` — Calculates a single numerical value from a dataset, summarizing the dataset into 1 key metric: `COUNT_DISTINCT`, `SUM`, `AVG`, `MIN`, or `MAX`.
              - `DATE_HISTOGRAM` — Calculates the count of time values from the specified field in the dataset that fall within each time interval you define (hour, day, week, etc.).
              - `NESTED` — Flattened list of aggregations, where each aggregation is nested within previous 1.

            </ParamField>

            <ParamField body="fieldPath" type="string">

              Path to the field to aggregate by in dot notation. For example `name` or `paymentOptions.online`.

              Constraints: `maxLength 200`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="search" type="SearchDetails">

          Free text to match in searchable fields.

          <Expandable title="search properties">

            <ParamField body="mode" type="string">

              Search mode. Defines the search logic for combining multiple terms in the `expression`.

              **Supported values:**

              - `OR` — At least 1 of the search terms must be present.
              - `AND` — All search terms must be present.

            </ParamField>

            <ParamField body="expression" type="string">

              Search term or expression.

            </ParamField>

            <ParamField body="fields" type="string[]">

              Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `parentCategory.index`.

              Constraints: `maxLength 200`, `maxItems 20`.

            </ParamField>

            <ParamField body="fuzzy" type="boolean">

              Whether to enable the search method to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="timeZone" type="string">

          Time zone in [IANA tz database format](https://en.wikipedia.org/wiki/Tz_database) or [ISO 8601 UTC offset format](https://en.wikipedia.org/wiki/ISO_8601#Time_offsets_from_UTC) for adjusting time fields in the specified filters and returned aggregation data. For example, `America/New_York`, `UTC`, or `+02:00`.

          Default: Time zone specified in the business [site properties](https://dev.wix.com/docs/api-reference/business-management/site-properties/properties/get-site-properties).

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

          <Expandable title="pagingMethod properties">

            <ParamField body="cursorPaging" type="CursorPaging">

              Cursor-based paging for result navigation. When requesting `cursor_paging.cursor`,
              `filter`, `sort`, or `search` can't be specified.

              _Nested structure omitted for brevity — see the `CursorPaging` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="treeReference" type="TreeReference" required>

      Category tree reference details.
      > **Note:** Pass `treeReference` only in the first request. Pass the cursor token in subsequent requests.

      <Expandable title="treeReference properties">

        <ParamField body="appNamespace" type="string" required>

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField body="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="returnNonVisibleCategories" type="boolean">

      Whether to return the categories with `visible` set to `false`.

      Default: `false`. Only visible categories are returned in the response

    </ParamField>

    <ParamField body="fields" type="string[]">

      Array of projected fields. A list of specific field names to return.

      Constraints: `maxItems 100`.

      **Supported values:**

      - `BREADCRUMBS_INFO`
      - `DESCRIPTION`
      - `RICH_CONTENT_DESCRIPTION`

    </ParamField>

    ## Response Object

    <ResponseField name="categories" type="Category[]">

      Retrieved categories that match the search criteria specified in the request.

      Each category includes all standard category information.

      Constraints: `minItems 0`, `maxItems 1000`.

      See the [Category Object](/api-reference/business-solutions/stores/catalog-v3/categories/category-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="CursorPagingMetadata">

      Cursor-based paging metadata for navigating search results.

      Contains the current page's cursor information, whether there are more results available,
      and count details. Use the `next` cursor to retrieve subsequent pages of results.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursor strings that point to the next page, previous page, or both.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="hasNext" type="boolean">

          Whether there are more pages to retrieve following the current page.

          + `true`: Another page of results can be retrieved.
          + `false`: This is the last page.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="aggregationData" type="AggregationData">

      Aggregation results based on the aggregations specified in the search request.

      Provides categorized data summaries. Only available when aggregations
      are requested in the search criteria.

      <Expandable title="aggregationData properties">

        <ResponseField name="results" type="AggregationResults[]">

          Array of aggregation results, each containing the aggregation metadata and its calculated values for the specified search criteria.

          Constraints: `maxItems 10000`.

          <Expandable title="results properties">

            <ResponseField name="name" type="string">

              User-defined name of aggregation as derived from search request.

              Constraints: `maxLength 100`.

            </ResponseField>

            <ResponseField name="type" type="string">

              Type of aggregation that must match specified kind as derived from search request.

              **Supported values:**

              - `VALUE` — Calculates the distribution of a specific field's values within a dataset, providing insights into the overall distribution and key statistics of those values.
              - `RANGE` — Calculates the count of the values from the specified field in the dataset that fall within the range of each bucket you define.
              - `SCALAR` — Calculates a single numerical value from a dataset, summarizing the dataset into 1 key metric: `COUNT_DISTINCT`, `SUM`, `AVG`, `MIN`, or `MAX`.
              - `DATE_HISTOGRAM` — Calculates the count of time values from the specified field in the dataset that fall within each time interval you define (hour, day, week, etc.).
              - `NESTED` — Flattened list of aggregations, where each aggregation is nested within previous 1.

            </ResponseField>

            <ResponseField name="fieldPath" type="string">

              Path to the field to aggregate by in dot notation. For example `appNamespace`.

              Constraints: `maxLength 200`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
