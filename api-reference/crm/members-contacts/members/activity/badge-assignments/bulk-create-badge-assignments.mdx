    Assigns multiple badges to multiple members in a single request.

    To assign a single badge for a member, call [Create Badge Assignment](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/badge-assignments/create-badge-assignment).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/badges/v4/bulk/assignments/create
    ```

    ## Body Params

    <ParamField body="badgeAssignments" type="BadgeAssignment[]" required>

      List of badge assignments to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Badge Assignment Object](/api-reference/crm/members-contacts/members/activity/badge-assignments/badge-assignment-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created badge assignments in the response. Set to `true` to receive full badge assignment objects.

    </ParamField>
