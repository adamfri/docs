      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Deletes an email transmission by ID.

    Deletion is only allowed for transmissions with `PROCESSED` or `REJECTED` status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/emails/transmissions/v1/email-transmissions/{emailTransmissionId}
    ```

    ## Path Params

    <ParamField path="emailTransmissionId" type="string" required>

      Email transmission ID.

    </ParamField>

    ## Response Object

    Returns `DeleteEmailTransmissionResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `EMAIL_TRANSMISSION_IS_IN_PROGRESS` | The email transmission can't be deleted while it's in progress. Wait until the status is `PROCESSED` or `REJECTED`, then try again. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Email Transmission Deleted | `wix.emails.transmissions.v1.email_transmission_deleted` | Triggered when an email transmission is deleted. |

    </div>
