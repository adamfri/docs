    <div className="wix-ref">

    Asynchronously updates tags on multiple products that match the provided filter criteria.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    Specify which tags to assign and which tags to unassign. Tags that don't exist are ignored.

    Each product supports up to 100 public tags and 100 private tags, including the tags it already has. If an update exceeds either limit for a product, the update fails for that product, and the remaining matching products are still updated.

    To update tags on a specific list of products, call [Bulk Update Product Tags](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/bulk-update-product-tags).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_WRITE">Product write in v3 catalog</span>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter object. See [API Query Language](https://dev.wix.com/docs/api-reference/articles/work-with-wix-apis/data-retrieval/about-the-wix-api-query-language) for more information.

    </ParamField>

      Tags to assign to the matching products.

        <ParamField body="privateTags" type="TagList">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="publicTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="Tags">

      Tags to unassign from the matching products.

      See `assignTags` if the same tag ID may appear in both lists.

        <ParamField body="privateTags" type="TagList">

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

        </ParamField>

          <Expandable title="publicTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

        </ParamField>

      </Expandable>

    ## Examples

    Asynchronously assigns a public tag to every visible product and unassigns a private tag from them. Poll the returned jobId with Get Async Job to track progress.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/stores/v3/bulk/products/update-tags-by-filter' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "filter": {
          "visible": true
        },
        "assignTags": {
          "publicTags": {
            "tagIds": [
              "RjcTI"
            ]
          }
        },
        "unassignTags": {
          "privateTags": {
            "tagIds": [
              "i3xh6"
            ]
          }
        }
      }'
      ```

      ```json Response
      {
        "jobId": "09fd1a13-1091-449c-9b7f-1f98206c02ae"
      }
      ```
