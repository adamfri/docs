    Runs fresh SEO keyword research and refreshes the content-plan inputs used for blog activities.

    If no plan generation is in progress, the refreshed inputs are followed by marketing-plan
    regeneration. If a plan generation is already in progress, this method still refreshes the
    keyword research and content-plan inputs without replacing the current plan status or starting
    a parallel marketing-plan generation when the refresh completes.

    Processing is asynchronous and multi-stage (slower than `RegenerateMarketingPlan`). The
    response immediately returns a `status` of `GENERATING`. During the refresh-only path, this
    status describes the existing plan generation; no separate refresh-completion status is exposed.
    Use this variant after changing the content pillars (the `topics` in the marketing settings)
    so future blog activities use the refreshed keyword research.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan/regenerate-marketing-plan-with-keyword-research
    ```

    ## Response Object

    <ResponseField name="status" type="string">

      Current plan status. Returns `GENERATING` immediately; poll `GetSocialMarketingPlan` until `ACTIVE` or `FAILED`.

      **Supported values:**

      - `NEVER_CREATED` — No plan has been generated for this site yet.
      - `GENERATING` — The plan is currently being generated. Poll `GetSocialMarketingPlan` until status changes.
      - `ACTIVE` — The plan is ready to use and activities are available.
      - `INACTIVE` — The plan was automatically deactivated after a long period without engagement. An `INACTIVE` plan returns no activities. Calling `GetSocialMarketingPlan` after a long idle period can itself trigger this transition. Generating or regenerating reactivates the plan.
      - `FAILED` — Generation failed. Call a generate or regenerate method to try again.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
