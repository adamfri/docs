    <div className="wix-ref">

    Updates a site's receipt settings, or creates them if none exist.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/receipts/v1/receipts-settings
    ```

    ## Body Params

    <ParamField body="receiptsSettings" type="ReceiptsSettings" required>

      Receipt settings to update. Partial update is supported, but if no receipt settings entity exists, the full entity must be specified.

      See the [Receipts Settings Object](/api-reference/business-management/get-paid/receipts/receipts-settings/receipts-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="receiptsSettings" type="ReceiptsSettings">

      Updated receipt settings.

      See the [Receipts Settings Object](/api-reference/business-management/get-paid/receipts/receipts-settings/receipts-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Site not found. |
    | `400` | `INVALID_ARGUMENT` | `NEXT_NUMBER_MISSING` | The `nextNumber` field must be specified. |
    | `400` | `INVALID_ARGUMENT` | `PREFIX_CONTAINS_ILLEGAL_CHARACTERS` | Specified prefix contains illegal characters. |
    | `400` | `INVALID_ARGUMENT` | `SUFFIX_CONTAINS_ILLEGAL_CHARACTERS` | Specified suffix contains illegal characters. |
    | `400` | `INVALID_ARGUMENT` | `NEXT_NUMBER_DESCENDING` | Specified number is lower than the already used number for the prefix. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Receipts Settings Updated | `wix.receipts.v1.receipts_settings_updated` | Triggered when a site's receipt settings are updated. [TEST] |

    </div>
