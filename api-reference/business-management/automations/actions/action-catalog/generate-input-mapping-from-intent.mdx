    Generates an action's input mapping from a natural language description of the desired configuration.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions/generate-input-mapping-from-intent
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the app that defines the action.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `minLength 5`, `maxLength 100`.

    </ParamField>

    <ParamField body="intent" type="string" required>

      Natural language description of the desired action configuration.

      Constraints: `minLength 1`, `maxLength 10000`.

    </ParamField>

    <ParamField body="conversationId" type="string" required>

      Conversation ID, used to maintain context across multiple requests in the same conversation with the calling agent.

      Constraints: `minLength 1`, `maxLength 256`.

    </ParamField>

    <ParamField body="actionSchema" type="object" required>

      Accumulated schema for the action, used to inform the generation.

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      Status of the generation.

      **Supported values:**

      - `INPUT_MAPPING_GENERATED` — Input mapping was generated successfully.
      - `ADDITIONAL_INFORMATION_REQUIRED` — Intent doesn't contain enough information to generate the input mapping.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `ACTION_SPI_NOT_FOUND` | The requested action does not have a matching service plugin implementer. |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_INTENT` | The intent is empty or contains only whitespace. |
    | `428` | `FAILED_PRECONDITION` | `GENERATE_INPUT_MAPPING_FROM_INTENT_NOT_IMPLEMENTED` | The action provider does not implement intent-based input mapping generation. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
