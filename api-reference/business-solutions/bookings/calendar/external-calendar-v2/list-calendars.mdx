    <div className="wix-ref">

    Retrieves details about the external calendar accounts associated with the specified connection.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-EXTERNAL-CALENDARS">Manage External Calendars</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/bookings/v2/external-calendars/connections/{connectionId}/calendars
    ```

    ## Path Params

    <ParamField path="connectionId" type="string" required>

      ID of the external calendar connection to list calendars for.

    </ParamField>

    ## Response Object

    <ResponseField name="calendars" type="Calendar[]">

      List of calendars belonging to the external calendar account.

      <Expandable title="calendars properties">

        <ResponseField name="id" type="string">

          ID of the external calendar account.

          **Read-only.**

        </ResponseField>

        <ResponseField name="name" type="string">

          Display name of the external calendar account.
          For example, `Primary` or `Birthdays`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CONNECTION_NOT_CONNECTED` | The connection isn't in a connected state. Ensure the connection is established before listing calendars. |
    | `428` | `FAILED_PRECONDITION` | `NOT_SUPPORTED_BY_PROVIDER` | The external calendar provider doesn't support this operation. Use a different connection method or provider. |
    | `403` | `PERMISSION_DENIED` | `PREMIUM_FEATURE_NOT_ENABLED` | This feature requires a premium plan. Upgrade to access external calendar integration. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
