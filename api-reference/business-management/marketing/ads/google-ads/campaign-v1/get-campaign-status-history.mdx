    Retrieves the full status change history for a campaign in chronological order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/campaigns/{campaignId}/status-history
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      ID of the campaign whose status history to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="statusChangeHistory" type="CampaignStatusChange[]">

      Chronological list of status changes for the campaign. Maximum 1,000 items.

      Constraints: `maxItems 1000`.

      <Expandable title="statusChangeHistory properties">

        <ResponseField name="status" type="string">

          The campaign status value after the change.

          **Supported values:**

          - `LIVE` — Campaign is currently serving ads, depending on budget information.
          - `PAUSED` — Campaign has been paused by the user.
          - `ENDED` — Campaign has been ended.
          - `IN_REVIEW` — The campaign was created but its budget hasn't been charged yet.
          - `ERROR` — Error state.
          - `DISAPPROVED` — Campaign is not approved.
          - `NOT_SERVING` — Campaign is currently not serving due to budget limitations.
          - `DRAFT` — Campaign is a draft.
          - `LEARNING` — Campaign is in the learning phase. Currently supported only for Google Ads Performance Max leads campaigns.

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time the status change occurred.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
