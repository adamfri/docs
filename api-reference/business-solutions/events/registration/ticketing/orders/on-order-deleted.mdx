## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.events.ticketing.events.OrderDeleted` |
| Package | `@wix/events` |
| Permissions | `Read Events - all read permissions`, `Manage Events - all permissions`, `Manage Events`, `Read Basic Events Order Info`, `Manage Orders` |
