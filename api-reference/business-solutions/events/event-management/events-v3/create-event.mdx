    <div className="wix-ref">

    Creates an event. <br /> <br />
    The event includes a default registration form in the selected language, which consists of input fields for first name, last name, and email. See the [Registration Form API](https://dev.wix.com/docs/rest/business-solutions/events/form/about-the-registration-form-api) for more information. <br /> <br />
    You can create the event as a draft by setting `draft` to `true`. Otherwise, the event is published right away. <br /> <br />
    To create a recurring event, set `individualEventDates` in the `dateAndTimeSettings.recurringEvents` object. <br /> <br />
    The event is automatically set up to send daily summary reports of new guests to your business email.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/events
    ```

    ## Body Params

    <ParamField body="event" type="Event" required>

      Event data.

      See the [Event Object](/api-reference/business-solutions/events/event-management/events-v3/event-object) for this object's fields.

    </ParamField>

    <ParamField body="draft" type="boolean">

      Whether to create the event as a draft.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 20`.

      **Supported values:**

      - `DETAILS` — Returns `shortDescription`, `mainImage` and `calendarUrls`.
      - `TEXTS` — Returns `description`.
      - `REGISTRATION` — Returns `registration`.
      - `URLS` — Returns `eventPageUrl`.
      - `FORM` — Returns `form`.
      - `DASHBOARD` — Returns `summaries`.
      - `FEED` — Returns `feed`.
      - `ONLINE_CONFERENCING_SESSION` — Returns `onlineConferencing.session`.
      - `SEO_SETTINGS` — Returns `seoSettings`.
      - `AGENDA` — Returns `agendaSettings`.
      - `CATEGORIES` — Returns `categories`.

    </ParamField>

    ## Response Object

    <ResponseField name="event" type="Event">

      Created event.

      See the [Event Object](/api-reference/business-solutions/events/event-management/events-v3/event-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_SLUG_FORMAT` | The `slug` format is invalid. Use only lowercase letters, numbers, and hyphens. |
    | `428` | `FAILED_PRECONDITION` | `EVENT_LIMIT_REACHED` | Number of events exceeds the limit of events per Wix user. |
    | `428` | `FAILED_PRECONDITION` | `SLUG_ALREADY_IN_USE` | There is already an event with this `slug`. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_EVENT_CONFIGURATION` |  |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Event Created | `wix.events.v3.event_created` | Triggered when an event is created. |
    | Event Published | `wix.events.v3.event_published` | Triggered when an event is published. |
