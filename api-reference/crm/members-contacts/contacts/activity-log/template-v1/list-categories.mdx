    Retrieves all activity categories.

    Use a category ID to filter a contact's activities by type in [List Activities](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/activity-log/activity-v1/list-activities), or to filter templates by category in [List Templates](https://dev.wix.com/docs/api-reference/crm/members-contacts/contacts/activity-log/template-v1/list-templates).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.READ-CONTACTS">Read Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/crm/contacts-activity-log/v1/categories
    ```

    ## Query Params

    <ParamField query="language" type="string">

      2-letter language code in ISO 639-1 alpha-2 format. Determines the language of translated fields (`name`).

      Default: Language from the request context, or `en`.

    </ParamField>

    <ResponseField name="categories" type="Category[]">
