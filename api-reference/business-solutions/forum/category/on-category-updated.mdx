Triggered when a category is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.forum.category_updated` |
| Package | `@wix/forum` |
| Permissions | `Read Forums`, `Manage Forums` |

## Examples

<CodeGroup>

  ```javascript onCategoryUpdated
  import { categories } from '@wix/forum';

  categories.onCategoryUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onCategoryUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { categories } from '@wix/forum';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        categories,
      },
  });

  wixClient.categories.onCategoryUpdated((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
