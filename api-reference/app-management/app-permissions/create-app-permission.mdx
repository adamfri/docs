    <div className="wix-ref">

    Adds a permission to the specified app.

    When users install your app on a site, it requests this permission.

    <Note>

    Disregard the **Authentication** note below. You can only call this method by authenticating with an account-level [API key](https://dev.wix.com/docs/rest/articles/get-started/api-keys).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEV_CENTER.WRITE_PERMISSIONS">Write Dev Center App Permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/app-permissions/v1/app-permissions
    ```

    ## Body Params

    <ParamField body="appPermission" type="AppPermission" required>

      Permission to add to the specified app.

      See the [App Permission Object](/api-reference/app-management/app-permissions/app-permission-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="appPermission" type="AppPermission">

      Details of permission that was added to the app.

      See the [App Permission Object](/api-reference/app-management/app-permissions/app-permission-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
