    Removes labels from a contact.

    If a label is no longer needed
    and you want to remove it from all contacts,
    you can delete by calling Delete Label from the Labels API.

    Members are typically linked to contacts, and while they share a relationship, the member ID and contact ID are distinct identifiers.
    Make sure to specify the contact ID when calling Unlabel Contact.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/contacts/v4/contacts/{contactId}/labels
    ```

    ## Path Params

    <ParamField path="contactId" type="string" required>

      ID of the contact to remove labels from.

    </ParamField>

    ## Query Params

    <ParamField query="labelKeys" type="string[]" required>

      List of label keys to remove from the contact.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="contact" type="Contact">

      Updated contact.

      See the [Contact Object](/api-reference/crm/members-contacts/contacts/contacts/contact-v4/contact-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `CONTACT_NOT_FOUND` | Contact not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Contact Updated | `wix.contacts.v4.contact_updated` |  |
