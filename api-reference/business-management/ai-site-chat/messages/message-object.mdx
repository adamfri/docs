---
title: "Message Object"
description: "The Message object in the Wix Message API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Message ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the message was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="sender" type="string">

      Message sender type.

      **Supported values:**

      - `ASSISTANT` — AI assistant.
      - `USER` — Wix user. For example, a site admin.
      - `SYSTEM` — Message was sent automatically due to widget settings. For example, a contact form.
      - `SITE_VISITOR` — Site visitor.

    </ResponseField>

    <ResponseField name="conversationId" type="string">

      Conversation ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="answerTo" type="string">

      ID of the message that this message is answering.

    </ResponseField>

    <ResponseField name="messageType" type="string">

      Message type.

      **Supported values:**

      - `QUESTION` — Question.
      - `ANSWER` — Answer.
      - `INTRO` — Intro message, as defined in the widget settings.
      - `LEGAL` — Legal disclaimer, as defined in the widget settings.
      - `CONTACT_FORM` — Contact form.
      - `CONTACT_FORM_SUBMITTED` — Message confirms that a contact form was successfully submitted.
      - `SITE_OWNER_NOTIFICATION` — Notification for the site owner.
      - `OFFLINE` — Message informing the site visitor that the AI assistant is offline, as defined in the widget settings.
      - `OUT_OF_QUOTA` — Message that informs the Wix user that they have reached the maximum number of messages on their current plan.
      - `USER_ANSWER` — User answer.
      - `SITE_NAVIGATION` — Site visitor site Navigation information.
      - `NAVIGATION_ANSWER` — Site visitor site Navigation information answer.
      - `IGNORED_ANSWER` — AI Site Chat ignored the question.
      - `VISITOR_OPTION_SELECTED` — Site visitor selected an option from  Message.visitor_options.
      - `ADD_TO_CART` — Site visitor added a product to the cart.
      - `BOOK_SERVICE` — Site visitor booked a service.
      - `GENERATED_QUESTION` — AI assistant generated a question for the user to try.
      - `SUGGESTED_QUESTION` — Suggested question, as defined in the widget settings.
      - `USER_QUESTION` — Wix user question for testing and training.
      - `USER_QUESTION_ANSWER` — Wix assistant answer for testing and training.
      - `WIX_USER_MEDIA` — Media uploaded by Wix user for visitor.
      - `MEDIA` — Media uploaded by visitor for Wix user.
      - `WIX_USER_CARD` — Card template sent by the Wix User.
      - `WIX_USER_MINIMAL_BODY` — Simple template sent by the Wix User.
      - `WIX_USER_FORM` — Form sent by the Wix User.
      - `WIX_SYSTEM` — System message from comm channels.
      - `FAQ_QUESTION` — FAQ question from site visitor in Manual chat mode.
      - `FAQ_ANSWER` — FAQ answer sent by Wix user in Manual chat mode.

    </ResponseField>

    <ResponseField name="body" type="Body">

      Message body.

      <Expandable title="body properties">

        <ResponseField name="mainText" type="string">

          Main text of the message.

        </ResponseField>

        <ResponseField name="footerText" type="string">

          Footer text of the message.

        </ResponseField>

        <ResponseField name="additionalData" type="object[]">

          Additional data for the message.

          Constraints: `maxItems 30`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="inboxId" type="string">

      Message Id in the Inbox

      **Read-only.**

    </ResponseField>

    <ResponseField name="visitorOptions" type="string[]">

      Options site visitor can choose from.

      Constraints: `maxLength 500`, `maxItems 10`.

    </ResponseField>

    <ResponseField name="assistantActions" type="string[]">

      List of actions that ai assistant executed on the site visitor's behalf.

      Constraints: `maxLength 500`, `maxItems 10`.

    </ResponseField>

    <ResponseField name="visitorOptionsFields" type="object[]">

      List of detailed options the visitor can choose from.

      **Read-only.** Constraints: `maxItems 50`.

    </ResponseField>

    <ResponseField name="engineStatus" type="string">

      Exact status message returned by ai site chat engine,

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "message": {
          "id": "a1d9c4e7-2f36-4c81-b5a0-7e3d9f2c6b18",
          "createdDate": "2026-07-08T10:30:02.000Z",
          "sender": "ASSISTANT",
          "conversationId": "0f2c6e91-4a7d-4b3e-9f18-5c2a7e6b1d33",
          "answerTo": "b3f1a7d2-9c14-4e58-8a2b-6d0f5c8e1a44",
          "messageType": "ANSWER",
          "body": {
            "mainText": "Our business hours are 9 AM to 5 PM, Monday through Friday.",
            "footerText": "Powered by Wix AI Site-Chat",
            "additionalData": []
          },
          "inboxId": "d4e8b21f-6c9a-4d17-8f3b-1a5c7e9d2b60",
          "visitorOptions": [
            "Contact support",
            "See pricing"
          ],
          "assistantActions": [],
          "visitorOptionsFields": [],
          "engineStatus": "COMPLETED"
        }
      }
      ```

    </CodeGroup>
