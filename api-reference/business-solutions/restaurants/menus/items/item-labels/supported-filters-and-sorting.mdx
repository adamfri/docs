<Note>This article applies to the REST API only.</Note>

The following table shows field support for filters and sorting for the item variants object:

| Field                                            | Supported Filters                          | Sortable |
| -------------------------------------------------| ------------------------------------------ | -------- |
| `id`                                             | `$eq`, `$ne`, `$in`, `$nin`                | Sortable |
| `createdDate`                                    | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte` | Sortable |
| `updatedDate`                                    | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte` | Sortable |
| `name`                                           | `$eq`, `$ne`, `$in`, `$nin`, `$startsWith` | Sortable |
| `icon`                                           | `$exists`                                  | Sortable |
