Triggered when a report is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.reports.v2.report_updated` |
| Package | `@wix/reports` |
| Permissions | `Manage Reports`, `Read Reports` |

## Examples

<CodeGroup>

  ```javascript onReportUpdated
  import { reports } from '@wix/reports';

  reports.onReportUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onReportUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { reports } from '@wix/reports';

    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        reports,
      },
  });

  wixClient.reports.onReportUpdated((event) => {
      // handle your event here
  });
  ```
