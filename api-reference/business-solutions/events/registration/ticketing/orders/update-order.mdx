    Updates an order's `checkoutForm` and/or `archived` status.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v1/events/{eventId}/orders/{orderNumber}
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID to which the order belongs.

    </ParamField>

    <ParamField path="orderNumber" type="string" required>

      Unique order number.

    </ParamField>

    ## Body Params

    <ParamField body="fields" type="FieldMask">

      Set of field paths to update.

      <Expandable title="fields properties">

        <ParamField body="paths" type="string[]" />

      </Expandable>

    </ParamField>

    <ParamField body="checkoutForm" type="FormResponse">

      Checkout form.

      <Expandable title="checkoutForm properties">

        <ParamField body="inputValues" type="InputValue[]">

          Form field inputs.

          Constraints: `maxItems 200`.

          <Expandable title="inputValues properties">

            <ParamField body="inputName" type="string">

              Form field input name.

              Constraints: `maxLength 100`.

            </ParamField>

            <ParamField body="value" type="string">

              Form field value.

              Constraints: `maxLength 5000`.

            </ParamField>

            <ParamField body="values" type="string[]">

              Form field values.

              Constraints: `maxLength 5000`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="archived" type="boolean">

      Whether to archive the order.

    </ParamField>

    ## Response Object

    <ResponseField name="order" type="Order">

      Updated order.

      See the [Order Object](/api-reference/business-solutions/events/registration/ticketing/orders/order-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ORDER_ACTION_NOT_AVAILABLE` | Order can't be updated due to its current status or state. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Order Updated | `wix.events.ticketing.events.OrderUpdated` |  |
