    Retrieves all available dates of each fulfillment type within the specified time range.

    A date is considered available if it has at least one available time slot.

    The response includes time slots with delivery fulfillment types only if you specify a delivery address.
    Only fulfillment methods capable of delivering to the specified address are considered when calculating time slot availability.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/restaurants/operations/v1/operations/{operationId}/available-dates
    ```
