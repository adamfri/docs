    <div className="wix-ref">

    Retrieves a conversation by conversation ID.

    If you don't have the conversation ID, use Get Or Create Conversation in the Conversations API
    to retrieve the conversation with the visitor, contact, or member ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-INBOX.READ-MSGS">Read Inbox Messages</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/inbox/v2/conversations/{conversationId}
    ```

    ## Path Params

    <ParamField path="conversationId" type="string" required>

      Conversation ID.

    </ParamField>

    ## Response Object

    <ResponseField name="conversation" type="Conversation">

      Retrieved conversation.

      See the [Conversation Object](/api-reference/crm/communication/inbox/conversations/conversation-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `NOT_OWNED_BY_BUSINESS` | Conversation isn't owned by the business. |
    | `404` | `NOT_FOUND` | `CONVERSATION_NOT_FOUND` | Conversation not found. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
