    Updates a member's slug.

    To update the current member's slug, call [Update My Slug](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/update-my-slug).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/members/{id}/slug
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Member ID.

    </ParamField>

    ## Body Params

    <ParamField body="slug" type="string" required>

      New slug.

      Constraints: `maxLength 255`.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      Updated member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `SLUG_ALREADY_EXISTS` | There is already a member with this slug. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Member Updated | `wix.members.v1.member_updated` | Triggered when a member is updated. |

    </div>
