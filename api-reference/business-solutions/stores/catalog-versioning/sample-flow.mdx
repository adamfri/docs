## Create a product while supporting both V1 and V3 catalogs

When building an integration that creates products, you need to call the correct API based on the site's catalog version.

To create a product while supporting both catalog versions:

1. Call [Get Catalog Version](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-versioning/get-catalog-version) to retrieve the catalog version.
2. If the `catalogVersion` is `V1_CATALOG`, call [Create Product](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v1/catalog/create-product) on the V1 catalog.
3. If the `catalogVersion` is `V3_CATALOG`, call [Create Product](fallback::https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/create-product) on the V3 catalog.
