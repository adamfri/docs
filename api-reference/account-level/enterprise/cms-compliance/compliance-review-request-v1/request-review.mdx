    Submits a CMS compliance action on a data item for review.

    Call this method when a user requests to publish or unpublish a CMS data item. The service
    fetches the relevant data item version(s) from CMS and emits a `ReviewRequested` domain event
    carrying the action, fetched content, and submitting identity. For `UNPUBLISH_CHANGED`, the
    caller can also specify which version to preserve as a draft. Nothing is emitted if a fetch fails.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ENTERPRISE.CMS-COMPLIANCE-MANAGE">Enterprise CMS compliance flow </span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/cms-compliance/v1/request-review
    ```

    ## Body Params

    <ParamField body="action" type="string" required>

      Compliance action performed on the data item.

      **Supported values:**

      - `PUBLISH_DRAFT` — Publish an item that currently exists only as a draft.
      - `PUBLISH_CHANGED` — Publish a draft containing changes to an existing published item.
      - `UNPUBLISH_PUBLISHED` — Unpublish an item that has no pending draft changes.
      - `PUBLISH_PUBLISHED` — Submit an already-published item for review without content changes.
      - `UNPUBLISH_CHANGED` — Unpublish an item that also has pending draft changes.

    </ParamField>

    <ParamField body="dataItemId" type="string" required>

      ID of the CMS data item the action was performed on. Matches the item's `_id` in CMS.

      Constraints: `maxLength 128`.

    </ParamField>

    <ParamField body="collectionId" type="string" required>

      ID of the CMS collection the data item belongs to.

      Constraints: `maxLength 256`.

    </ParamField>

    <ParamField body="versionOnUnpublish" type="string">

      Version to preserve as a draft after `UNPUBLISH_CHANGED`.
      Ignored for all other actions. If omitted, the review request is still submitted.

      **Supported values:**

      - `KEEP_LATEST_DRAFT_VERSION` — Preserve the item's latest draft edits.
      - `KEEP_LIVE_PUBLISHED_VERSION` — Preserve the item's current live version.

    </ParamField>

    ## Response Object

    <ResponseField name="complianceReviewRequest" type="ComplianceReviewRequest">

      Submitted compliance review request, also emitted as a `ReviewRequested` event.

      See the [Compliance Review Request Object](/api-reference/account-level/enterprise/cms-compliance/compliance-review-request-v1/compliance-review-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `401` | `UNAUTHENTICATED` | `MISSING_IDENTITY` | The request identity doesn't include the required account ID. |
    | `428` | `FAILED_PRECONDITION` | `CMS_METASITE_NOT_RESOLVED` | Couldn't resolve the account's CMS metasite. Exactly one `ACCOUNT_MASTER_CMS` metasite must exist for the account. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_ACTION` | The `action` is missing or isn't a recognized review action. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
