    Updates a delivery region.

    This method doesn't support updating delivery carriers in the region. To manage carriers, use [Add Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/add-delivery-carrier), [Update Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/update-delivery-carrier), or [Remove Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/remove-delivery-carrier).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v1/delivery-profiles/{deliveryProfileId}/delivery-region/{deliveryRegion.id}
    ```

    ## Path Params

    <ParamField path="deliveryProfileId" type="string" required>

      Delivery profile ID.

    </ParamField>

    <ParamField path="deliveryRegion.id" type="string" required>

      Delivery region ID.

    </ParamField>

    ## Body Params

    <ParamField body="deliveryRegion" type="DeliveryRegion" required>

      Delivery region to update.

      <Expandable title="deliveryRegion properties">

        <ParamField body="id" type="string" required>

          Delivery region ID.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Delivery region name. For example, `"Domestic"` or `"International"`.

        </ParamField>

        <ParamField body="active" type="boolean">

          Whether this delivery region is active and available during checkout.

          Default: `true`

        </ParamField>

        <ParamField body="deliveryCarriers" type="DeliveryCarrier[]">

          Delivery carriers assigned to this region. Carriers are managed using the [Add Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/add-delivery-carrier), [Update Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/update-delivery-carrier), and [Remove Delivery Carrier](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/remove-delivery-carrier) methods.

          **Read-only.** Constraints: `minItems 0`, `maxItems 25`.

          <Expandable title="deliveryCarriers properties">

            <ParamField body="appId" type="string">

              Carrier app ID.

              Get app IDs from the [app dashboard](https://dev.wix.com/dc3/my-apps/), or by calling [List Installed Delivery Carriers](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/list-installed-delivery-carriers).

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="backupRate" type="BackupRate">

              Backup rate to use when the carrier doesn't return a rate for a specific shipping option.

              When `active` is `false` and the carrier doesn't return a rate, the carrier's shipping options aren't shown to customers.

              _Nested structure omitted for brevity — see the `BackupRate` object._

            </ParamField>

            <ParamField body="additionalCharges" type="AdditionalCharge[]">

              Additional charges to add to the delivery rate. These charges are combined with the carrier's rate into a single shipping cost and itemized in order details.

              Constraints: `maxItems 10`.

              _Nested structure omitted for brevity — see the `AdditionalCharge[]` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="destinations" type="Destination[]">

          Geographic destinations covered by this region. If empty, the region applies globally (Rest of World). A site can have up to 250 destinations across all delivery profiles.

          Constraints: `minItems 0`, `maxItems 250`.

          <Expandable title="destinations properties">

            <ParamField body="countryCode" type="string">

              2-letter country code in [ISO-3166 alpha-2](https://www.iso.org/obp/ui/#search/code/) format.

              Constraints: `format COUNTRY`.

            </ParamField>

            <ParamField body="subdivisions" type="string[]">

              Subdivision codes in [ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2) format. For example, `"US-CA"` for California. If empty, the delivery region applies to the entire country.

              The following countries don't support subdivision-level delivery and require an empty `subdivisions` list. Sending subdivisions for these countries fails with `SUBDIVISIONS_UNSUPPORTED_FOR_COUNTRY`:
              `AT`, `BE`, `BS`, `CH`, `CI`, `CZ`, `DO`, `GR`, `NO`, `PL`, `RS`, `SD`, `SI`, `SK`, `SN`.

              Constraints: `minLength 1`, `maxLength 256`, `minItems 0`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="createdDate" type="datetime">

          Date and time the delivery region was created.

          **Read-only.**

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="revision" type="integer">

      Delivery profile revision.

      **Read-only.**

    </ParamField>

    ## Response Object

    <ResponseField name="deliveryProfile" type="DeliveryProfile">

      Updated delivery profile with the updated delivery region.

      See the [Delivery Profile Object](/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/delivery-profile-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DELIVERY_PROFILE_NOT_FOUND` | Couldn't find the delivery profile. |
    | `404` | `NOT_FOUND` | `DELIVERY_REGION_NOT_FOUND` | Couldn't find the delivery region. |
    | `428` | `FAILED_PRECONDITION` | `DESTINATIONS_COLLISION` | One or more destinations already exist in another delivery region in this profile. |
    | `400` | `INVALID_ARGUMENT` | `DELIVERY_CARRIER_CANNOT_BE_UPDATED` | This method doesn't support updating delivery carrier data. Use Add Delivery Carrier, Update Delivery Carrier, and Remove Delivery Carrier instead. |
    | `428` | `FAILED_PRECONDITION` | `SUBDIVISIONS_UNSUPPORTED_FOR_COUNTRY` | Returned when a `destinations` entry sets `subdivisions` for a country that doesn't support subdivision-level delivery. Remove `subdivisions` from the destination, or use a supported country. |
    | `400` | `INVALID_ARGUMENT` | `DELIVERY_REGION_NAME_ALREADY_EXISTS` | A delivery region with this name already exists. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
