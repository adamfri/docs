    Retrieves a list of automations, given the provided paging, filtering, and sorting.

    Returns both site-specific automations and [preinstalled automations](https://dev.wix.com/docs/build-apps/develop-your-app/extensions/backend-extensions/automations/pre-installed-automations/about-pre-installed-automations). When a preinstalled automation has been overridden on the site, the method returns the overridden automation, not the original one.

    <Note>

    Only returns automations created by apps installed on the site.

    </Note>

    Learn more about [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `name` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `configuration.trigger.appId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `configuration.trigger.triggerKey` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `configuration.trigger.filters` |  | Sort: `ASC`, `DESC` |
    | `configuration.trigger.filterValueSelection.selectedFilterValues` | `$hasSome`, `$hasAll`, `$exists`, `$isEmpty` | Sort: `ASC`, `DESC` |
    | `configuration.status` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `origin` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
