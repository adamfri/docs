    Updates an order payment request.

    Only `UNPAID` order payment requests can be updated. The `amount` can't be changed after the order payment request is created.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/ecom/v1/order-payment-requests/{orderPaymentRequest.id}
    ```

    ## Path Params

    <ParamField path="orderPaymentRequest.id" type="string" required>

      Order payment request ID.

    </ParamField>

    ## Body Params

    <ParamField body="orderPaymentRequest" type="OrderPaymentRequest" required>

      Order payment request to update.

      See the [Order Payment Request Object](/api-reference/business-solutions/e-commerce/orders/order-payment-requests/order-payment-request-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="orderPaymentRequest" type="OrderPaymentRequest">

      Updated order payment request.

      See the [Order Payment Request Object](/api-reference/business-solutions/e-commerce/orders/order-payment-requests/order-payment-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_PAID_ORDER_PAYMENT_REQUEST` | Order payment requests with a `status` of `PAID` can't be updated. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_EXPIRED_ORDER_PAYMENT_REQUEST` | Order payment requests with a `status` of `EXPIRED` can't be updated. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_VOIDED_ORDER_PAYMENT_REQUEST` | Order payment requests with a `status` of `VOIDED` can't be updated. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_UPDATE_ORDER_PAYMENT_REQUEST_AMOUNT` | The amount of an order payment request can't be changed after it's created. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    <ParamField body="orderPaymentRequest" type="UpdateOrderPaymentRequest" required>

      Order payment request to update.

      <Expandable title="orderPaymentRequest properties">

        <ParamField body="_id" type="string">

          Order payment request ID.

        <ParamField body="source" type="Source">

          Details about the source that created the order payment request.

            <ParamField body="externalId" type="string">

              Reference to a record in the source system. For example, if the payment request was created from a paylink or invoice, use this field to store the paylink ID or invoice ID.

              Constraints: `minLength 1`, `maxLength 100`, `immutable`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="status" type="string">

          Payment request status. Set by the system. A new order payment request starts as `UNPAID`, unless `expirationDate` is already in the past at creation time, in which case it is created as `EXPIRED`. The system sets the status to `PAID` once payment is collected, `EXPIRED` when the expiration date passes, or `VOIDED` when the request is voided.

          **Read-only.**

          **Supported values:**

          - `UNPAID` — Payment is owed but hasn't been collected yet.
          - `PAID` — Payment has been collected.
          - `EXPIRED` — The order payment request has passed its `expirationDate` without being paid.

        </ParamField>

        <ParamField body="orderId" type="string">

          Order ID.

          Constraints: `format GUID`, `immutable`.

        </ParamField>

        <ParamField body="orderNumber" type="string">

          Order number.

          **Read-only.**

        </ParamField>

        <ParamField body="amount" type="Price">

          Amount to collect. Set when the order payment request is created and can't be changed afterward.

          Constraints: `immutable`.

          <Expandable title="amount properties">

            <ParamField body="amount" type="string">

              Amount.

              Constraints: `>= 0`, `<= 1000000000000000`.

            </ParamField>

            <ParamField body="formattedAmount" type="string">

              Amount formatted with currency symbol.

              **Read-only.**

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="currency" type="string">

          Three-letter currency code in [ISO-4217 alphabetic format](http://en.wikipedia.org/wiki/ISO_4217). Always matches the order's currency.

          **Read-only.** Constraints: `format CURRENCY`.

        </ParamField>

        <ParamField body="paymentGatewayOrderId" type="string">

          Payment gateway order ID associated with this payment request.

          **Read-only.**

        </ParamField>

        <ParamField body="title" type="string">

          Title displayed to the customer on the payment page.

          Constraints: `minLength 1`, `maxLength 200`.

        </ParamField>

        <ParamField body="description" type="string">

          Description displayed to the customer on the payment page.

        </ParamField>

        <ParamField body="expirationDate" type="datetime">

          Date and time the order payment request expires. If not provided, the order payment request doesn't expire.
