    <div className="wix-ref">

    Retrieves a list of question entries, given the specified filters and paging.

    See [Query Question Entries](https://dev.wix.com/docs/rest/business-management/faq-app/faq/question-entry-v2/query-question-entries) for a list of supported filters.

    Use the `fieldSet` parameter to control whether sharing links are included in the response.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.READ-FAQ">Read FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/faq/v2/question-entries
    ```

    ## Query Params

    <ParamField query="categoryId" type="string">

      ID of the category to filter question entries by.

    </ParamField>

    <ParamField query="questionEntryIds" type="string[]">

      IDs of specific question entries to retrieve.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    <ParamField query="questionEntryLabel" type="string">

      Label name to filter question entries by.

    </ParamField>

    <ParamField query="paging" type="CursorPaging">

      Pagination settings. Not required if specific question entry IDs are provided.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Maximum number of items to return in the results.

        </ParamField>

        <ParamField query="cursor" type="string">

          Pointer to the next or previous page in the list of results.

          Pass the relevant cursor token from the `pagingMetadata` object in the previous call's response.
          Not relevant for the first request.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="contentFormat" type="string">

      Format for answer content in the response.

      **Supported values:**

      - `DRAFTJS`
      - `PLAIN_TEXT`
      - `RICH_CONTENT`

    </ParamField>

    <ParamField query="fieldSet" type="string[]">

      Fields to include in the response.

      Constraints: `maxItems 100`.

      **Supported values:**

      - `SHARE_LINKS` — Include `share_link` fields inside question entries.

    </ParamField>

    ## Response Object

    <ResponseField name="questionEntries" type="QuestionEntry[]">

      List of up to 100 retrieved question entries.

      See the [Question Entry Object](/api-reference/business-management/faq-app/question-entry-v2/question-entry-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="PagingMetadataV2">

      Pagination information for navigating through results.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor string pointing to the next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to the previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
