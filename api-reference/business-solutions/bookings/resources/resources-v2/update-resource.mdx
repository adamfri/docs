    <div className="wix-ref">

    Updates a resource.

    Each time the resource is updated, `revision` increments by 1. You must include the current revision of the resource when updating it.
    This ensures you're working with the latest service information and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bookings/v2/resources/{resource.id}
    ```

    ## Path Params

    <ParamField path="resource.id" type="string" required>

      Resource ID.

    </ParamField>

    ## Body Params

    <ParamField body="resource" type="Resource" required>

      Resource to update.

      See the [Resource Object](/api-reference/business-solutions/bookings/resources/resources-v2/resource-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="resource" type="Resource">

      Updated resource.

      See the [Resource Object](/api-reference/business-solutions/bookings/resources/resources-v2/resource-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_NAME_IS_REQUIRED` | Resource `name` can't be empty. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_LOCATION_ID_IS_REQUIRED` | Business location ID is required. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_SPECIFIC_LOCATION_OPTIONS_NOT_ALLOWED` | `specificLocationOptions` can't be set when `availableInAllLocations` is set to `true`. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_SPECIFIC_LOCATION_OPTIONS_MUST_BE_SET` | `specificLocationOptions` must be set when `availableInAllLocations` is set to `false` or empty. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_AVAILABLE_IN_BUSINESS_LOCATION_MUST_BE_TRUE` | `availableInBusinessLocations` must be set to `true`. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_WORKING_HOURS_SCHEDULE_ID_IS_REQUIRED` | `workingHoursSchedules.scheduleId` is required. |
    | `400` | `INVALID_ARGUMENT` | `RESOURCE_WORKING_HOURS_SHARED_IS_REQUIRED` | `workingHoursSchedules.shared` is required. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Resource Updated | `wix.bookings.resources.v2.resource_updated` | Triggered when a resource is updated. |

    </div>

    ## Examples

    To update a resource the fields `id` and `revision` are required. Partial updates are supported.

    <CodeGroup>

      ```bash Request
      curl -X PATCH \
      'https://www.wixapis.com/bookings/v2/resources/77c7a7d1-0045-47eb-bef7-f1bcac5f68e1' \
      -H 'Authorization: <AUTH>' \
      -d '{
        "resource": {
          "id": "77c7a7d1-0045-47eb-bef7-f1bcac5f68e1",
          "revision": "1",
          "name": "Updated name"
        }
      }'
      ```

      ```json Response
      {
        "resource": {
          "id": "77c7a7d1-0045-47eb-bef7-f1bcac5f68e1",
          "revision": "2",
          "createdDate": "2024-11-22T13:28:29.869Z",
          "updatedDate": "2024-11-22T15:08:44.446Z",
          "name": "Updated name",
          "locationOptions": {
            "availableInAllLocations": true
          },
          "eventsSchedule": {
            "scheduleId": "c0091359-7007-4288-be59-dccade075472"
          }
        }
      }
      ```

    </CodeGroup>

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Resource ID.

      **Read-only.**

    </ParamField>

    <ParamField body="resource" type="UpdateResource" required>

      Resource to update.

      <Expandable title="resource properties">

        <ParamField body="_id" type="string">

          Resource ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the resource is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the resource.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Time in `YYYY-MM-DDThh:mm:ss.sssZ` format the resource was last updated.

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Name of the resource.

        </ParamField>

        <ParamField body="typeId" type="string">

          ID of the [resource type](https://dev.wix.com/docs/rest/business-solutions/bookings/resources/resource-types-v2/introduction).

          Once a type has been set it can't be modified. You can create a resource
          without specifying a type. However, customers can't book such resources.

        </ParamField>

        <ParamField body="workingHoursSchedules" type="WorkingHoursSchedules">

          Information about the [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction)
          specifying the working hours and locations of the resource.

          Resources without a working hour schedule are available 24/7 at the locations
          specified in the field `locationOptions`.
          When both `workingHoursSchedules` and `locationOptions` are set,
          `workingHoursSchedules` takes precedence.

          <Expandable title="workingHoursSchedules properties">

            <ParamField body="values" type="WorkingHoursSchedule[]">

              Schedules specifying the working hours of the resource. Currently, only a single schedule is supported.

              Constraints: `maxItems 1`.

              _Nested structure omitted for brevity — see the `WorkingHoursSchedule[]` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="locationOptions" type="LocationOptions">

          Information about the location where the resource is available.

          <Expandable title="locationOptions properties">

            <ParamField body="availableInAllLocations" type="boolean">

              Whether the resource is available in all [business locations](https://dev.wix.com/docs/rest/business-solutions/bookings/services/services-v2/about-service-locations#location-types).

              - `true`: The resource is available in all business locations.
              - `false`: The resource is available only in specific locations.

              Default: `false`

            </ParamField>

            <ParamField body="specificLocationOptions" type="SpecificLocation">

              Details of resource availability in specific locations.

              _Nested structure omitted for brevity — see the `SpecificLocation` object._

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="eventsSchedule" type="EventsSchedule">

          Schedule containing the [events](https://dev.wix.com/docs/rest/business-management/calendar/events-v3/introduction)
          for which the resource has been booked.

          **Read-only.**

          <Expandable title="eventsSchedule properties">

            <ParamField body="scheduleId" type="string">

              ID of the event [schedule](https://dev.wix.com/docs/rest/business-management/calendar/schedules-v3/introduction).

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="extendedFields" type="ExtendedFields">

          Extensions enabling users to save custom data related to the resource.

          <Expandable title="extendedFields properties">

            <ParamField body="namespaces" type="object">

              Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
              The value of each key is structured according to the schema defined when the extended fields were configured.

              You can only access fields for which you have the appropriate permissions.

              Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

              Constraints: `format map`.

              _Nested structure omitted for brevity — see the `object` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>
