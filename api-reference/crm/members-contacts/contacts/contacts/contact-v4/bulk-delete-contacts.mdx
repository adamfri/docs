    Deletes multiple contacts.

    All contacts that meet the specified `filter` and `search` criteria are deleted.
    The request should contain a `filter` value or a `search` value, or both.
    To perform a dry run, call Query Contacts with the intended filter options.

    When this method is called, a bulk job is started and the job ID is returned.
    The job might not complete right away, depending on its size.
    The job's status can be retrieved with Get Bulk Job.

    The following errors might occur during the bulk processing and will appear in the bulk job:
    - `CANNOT_DELETE_SITE_MEMBERS` - Contact is a site member and can't be deleted. Member must be deleted first.
    - `CANNOT_DELETE_CONTACT_WITH_BILLING_SUBSCRIPTION` - Contact has a valid billing subscription and can't be deleted.
    - `CANNOT_DELETE_MEMBER_OWNER_OR_CONTRIBUTOR` - Member is a Wix user and can't be deleted. This can happen only if the request indicated to delete the member.
    - `FAILED_DELETE_CONTACT_AFTER_MEMBER_DELETION` - Member was deleted, but contact was not. This can happen only if the request indicated to delete the member.
    - `FAILED_DELETE_CONTACT` - Contact could not be deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>
    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v4/bulk/contacts/delete
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

      Possible filters:
      `$eq`, `$exists`, `$gt`, `$gte`, `$hasAll`, `$hasSome`, `$in`, `$lt`, `$lte`, `$ne`, `$startsWith`.

      See [Sort, Filter, and Search](https://dev.wix.com/docs/rest/crm/members-contacts/contacts/contacts/contact-v4/sort-filter-and-search)
      for a detailed list of supported filters for contact properties, extended fields, and custom fields.

      Example:
      `{ "filter": { "info.name.last": "Smith" } }`

    </ParamField>

    <ParamField body="search" type="string">

      Plain text search for an exact match, up to 100 characters.

      Searchable fields:

      - `info.name.first`
      - `info.name.last`
      - `info.emails.email`
      - `info.phones.phone`

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Bulk job ID.
      The job's status can be retrieved with Get Bulk Job.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NEITHER_FILTER_NOR_SEARCH` | The request should include a `filter` value, a `search` value, or both. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Contact Deleted | `wix.contacts.v4.contact_deleted` | Triggered when a contact is deleted. |
