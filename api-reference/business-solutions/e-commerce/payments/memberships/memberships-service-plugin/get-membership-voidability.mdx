    This method retrieves from your app whether a membership can be voided.

    ## Endpoint

    ```http
    POST /v1/get-voidability
    ```

    ## Body Params

    <ParamField body="transactionId" type="string" required>

      Transaction ID to check if it can be voided.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="voidable" type="boolean">

      Whether the membership charge can be voided.

    </ResponseField>

    <ResponseField name="reason" type="string">

      Reason why the membership charge cannot be voided.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `TRANSACTION_NOT_FOUND` | Transaction not found |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
