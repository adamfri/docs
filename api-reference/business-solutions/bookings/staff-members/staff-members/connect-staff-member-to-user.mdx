    Connects a Wix user to a staff member, enabling them to manage their own working hour schedule in the dashboard.

    By default, Wix Bookings uses the staff member's `email`.
    However, you can specify an alternative email address. If no existing Wix user is associated with that email, Wix sends them an invitation to become a Wix user.
    If an existing user is found but not linked to the site, Wix Bookings sends an invitation to join the site.

    To check the connection status, call [Get Staff Member](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/get-staff-member), and specify `ASSOCIATED_IDENTITY_STATUS` in the `fields` parameter.

    You must call [Disconnect Staff Member From User](https://dev.wix.com/docs/api-reference/business-solutions/bookings/staff-members/disconnect-staff-member-from-user) before connecting a different Wix user to the staff member.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/staff-members/{staffMemberId}/connect-staff-member-to-user
    ```

    ## Path Params

    <ParamField path="staffMemberId" type="string" required>

      ID of the staff member to connect to the Wix user.

    </ParamField>

    ## Body Params

    <ParamField body="email" type="string">

      Email of the Wix user to connect to the staff member.

      Default: Email of the staff member.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Conditional fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `RESOURCE_DETAILS` — Includes `resource` in the response.
      - `ASSOCIATED_IDENTITY_STATUS` — Includes `associatedIdentityStatus` in the response.

    </ParamField>

    ## Response Object

    <ResponseField name="staffMember" type="StaffMember">

      Updated staff member.

      See the [Staff Member Object](/api-reference/business-solutions/bookings/staff-members/staff-members/staff-member-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Staff Member Updated | `wix.bookings.staff.v1.staff_member_updated` | Triggered when a staff member is updated. |
    | Staff Member Connected To User | `wix.bookings.staff.v1.staff_member_connected_to_user` | Triggered when a Wix user is connected to a staff member. The event is triggered when the connection status changes to `CONNECTED`. It isn't triggered when Wix Bookings sends an invitation to become a Wix user or join a site. |
