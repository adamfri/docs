    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.READ.COMMENTS">Read Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/comments/v1/comments/{commentId}
    ```

    ## Path Params

    <ParamField path="commentId" type="string" required>

      ID of the comment to retrieve.

    </ParamField>

    <ResponseField name="comment" type="Comment">

      Retrieved comment.

      See the [Comment Object](/api-reference/crm/community/feedback-moderation/comments/comments/comment-object) for this object's fields.

    </ResponseField>

    <Note>
