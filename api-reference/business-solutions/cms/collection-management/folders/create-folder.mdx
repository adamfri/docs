    Creates a folder.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/wix-data/v1/folders
    ```

    ## Body Params

    <ParamField body="folderDetails" type="FolderDetails">

      Folder details.

      <Expandable title="folderDetails properties">

        <ParamField body="name" type="string">

          Folder name as it appears in the [CMS](https://support.wix.com/en/article/cms-formerly-content-manager-working-with-collection-folders).

        </ParamField>

        <ParamField body="description" type="string">

          Folder description.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="folder" type="Folder">

      Created folder.

      See the [Folder Object](/api-reference/business-solutions/cms/collection-management/folders/folder-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `FOLDER_NOT_FOUND` | Couldn't find the folder. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
