Triggered when a Wix user is connected to a staff member.

The event is triggered when the connection status changes to `CONNECTED`. It
isn't triggered when Wix Bookings sends an invitation to become a Wix user or
join a site.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.bookings.staff.v1.staff_member_connected_to_user` |
| Package | `@wix/bookings` |
| Permissions | `Read Bookings - Public Data`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions` |
