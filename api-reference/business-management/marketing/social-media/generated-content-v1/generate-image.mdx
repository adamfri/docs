    Generates an image from a text prompt and a source image.

    Image generation runs asynchronously. This method starts the process and returns an `executionId`. Poll Get Generated Image with that `executionId` until the status is `READY` (the `imageUrl` and `fileId` are then populated) or `FAILED`. The generated image is also added to the "Social Marketing AI Media" folder in the site's Media Manager.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/social-publisher/v1/generate-image
    ```

    ## Body Params

    <ParamField body="userInput" type="string" required>

      Text prompt describing the image to generate.

    </ParamField>

    <ParamField body="imageUrl" type="string" required>

      URL of the source image to generate from.

    </ParamField>

    ## Response Object

    <ResponseField name="status" type="string">

      Status of the generation request.

      **Supported values:**

      - `UNKNOWN_STATUS`
      - `OK` — The generation request was accepted.

    </ResponseField>

    <ResponseField name="executionId" type="string">

      Identifies the asynchronous image-generation process.

    </ResponseField>
