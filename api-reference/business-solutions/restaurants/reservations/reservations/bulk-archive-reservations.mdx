<Tabs>

  <Tab title="REST">

    Archives multiple reservations at once.

    Archived reservations aren't shown in the dashboard along with other reservations. However, they can still be viewed in a separate section.
    Archived reservations can't be updated with Update Reservation.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-RESERVATIONS.MANAGE-RESERVATIONS-MEDIUM">Manage Reservations (Medium)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/table-reservations/reservations/v1/bulk/reservations/archive
    ```

    ## Body Params

    <ParamField body="reservationIds" type="string[]" required>

      IDs of reservations to archive.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.
