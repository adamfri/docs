    Removes the social post drafts from a marketing activity, leaving its story drafts unchanged.

    Only drafts are removed. Posts that were already published or scheduled stay on the activity.
    To remove the activity's stories, use `ClearMarketingActivityStories`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-plan/clear-marketing-activity-posts
    ```

    ## Body Params

    <ParamField body="marketingActivityId" type="string">

      ID of the marketing activity whose post drafts will be removed.

      **Read-only.**

    </ParamField>

    ## Response Object

    Returns `ClearMarketingActivityPostsResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
