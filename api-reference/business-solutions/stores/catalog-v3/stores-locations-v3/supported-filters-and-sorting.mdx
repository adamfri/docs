<Note>This article applies to the REST API only.</Note>

The following table shows field support for filters and sorting for the Stores location object:

| Field             | Supported Filters                                                      | Sortable |
|-------------------|------------------------------------------------------------------------|----------|
| `id`              | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith`              |          |
| `createdDate`     | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$lt`, `$le`, `$gt`, `$ge` | Sortable |
| `updatedDate`     | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$lt`, `$le`, `$gt`, `$ge` | Sortable |
| `wixLocationId`   | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith`              |          |
| `name`            | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`, `$startsWith`              | Sortable |
| `locationType`    | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`                             | Sortable |
| `defaultLocation` | `$eq`, `$ne`, `$exists`, `$in`, `$hasSome`                             | Sortable |
