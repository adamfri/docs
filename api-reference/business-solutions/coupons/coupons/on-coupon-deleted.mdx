Triggered when a coupon is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.ecommerce.coupons.v2.coupon_deleted` |
| Package | `@wix/marketing` |
| Permissions | `Manage Stores - all permissions`, `Manage Coupons` |
