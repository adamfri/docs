    Retrieves an event by the slug URL.

    The slug is the end of an event URL that refers to a specific event. For example, if an event's URL is `https://example.com/events/event/{my-event-slug}`, the slug is `my-event-slug`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-EVENTS">Read Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v3/events/slug/{slug}
    ```

    ## Path Params

    <ParamField path="slug" type="string" required>

      URL slug.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Constraints: `maxItems 20`.

      **Supported values:**

      - `DETAILS` — Returns `shortDescription`, `mainImage` and `calendarUrls`.
      - `TEXTS` — Returns `description`.
      - `REGISTRATION` — Returns `registration`.
      - `URLS` — Returns `eventPageUrl`.
      - `FORM` — Returns `form`.
      - `DASHBOARD` — Returns `summaries`.
      - `FEED` — Returns `feed`.
      - `ONLINE_CONFERENCING_SESSION` — Returns `onlineConferencing.session`.
      - `SEO_SETTINGS` — Returns `seoSettings`.
      - `AGENDA` — Returns `agendaSettings`.
      - `CATEGORIES` — Returns `categories`.

    </ParamField>

    ## Response Object

    <ResponseField name="event" type="Event">

      Event.

      See the [Event Object](/api-reference/business-solutions/events/event-management/events-v3/event-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
