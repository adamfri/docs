    <div className="wix-api-columns">

    <div className="wix-ref">

    Moves a draft post to the trash bin.
    A published post can also be deleted by the `post.id`. See the [Posts API](https://dev.wix.com/docs/rest/business-solutions/blog/posts-stats/post-object) for more information about posts.

    To permanently delete a post bypassing the trash bin, set the `permanent` field value to `true`. The post can't be restored after this.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BLOG.MANAGE-BLOG">Manage Blog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/blog/v3/draft-posts/{draftPostId}
    ```

    ## Path Params

    <ParamField path="draftPostId" type="string" required>

      Draft post ID.

    </ParamField>

    ## Query Params

    <ParamField query="permanent" type="boolean">

      Whether to bypass the trash bin and delete the post permanently.

      Default: `false`

    </ParamField>

    ## Response Object

    Returns `DeleteDraftPostResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Draft Deleted | `wix.blog.v3.draft_deleted` | Triggered when a draft post is deleted. |

    </div>
