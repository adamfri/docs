    Updates a site's loyalty program.

    This method updates the name of the loyalty program and the details of the collectible points unit.
    To activate the loyalty program, call Activate Loyalty Program.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/loyalty-programs/v1/program
    ```

    ## Body Params

    <ParamField body="loyaltyProgram" type="LoyaltyProgram" required>

      Loyalty program fields to update.

      See the [Program Object](/api-reference/crm/loyalty-program/loyalty-program-management/program/program-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="loyaltyProgram" type="LoyaltyProgram">

      Updated loyalty program.

      See the [Program Object](/api-reference/crm/loyalty-program/loyalty-program-management/program/program-object) for this object's fields.

    </ResponseField>
