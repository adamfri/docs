    Adds points to a loyalty account.

    Only a positive amount can be added using this method. To adjust an account's balance
    for a negative amount, use Adjust Points.

    This method allows customers to manually earn points to their loyalty accounts. To use this method you must include an `appId` and an `idempotencyKey`.
    Any string can be set as the `appId` or `idempotencyKey`. In contrast to when an account earns points through an action taken on your site, then,
    the `appId` automatically sets to the source app that generates the points. In both cases, the transaction `type` is `"EARN"`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-accounts/v1/accounts/{accountId}/earn-points
    ```

    ## Path Params

    <ParamField path="accountId" type="string" required>

      Loyalty account ID.

    </ParamField>

    ## Body Params

    <ParamField body="amount" type="integer">

      Amount of points to earn. Must be a positive, whole number.

      Min: `1`

      Max: `9999999`

      Constraints: `min 1`, `max 9999999`.

    </ParamField>

    <ParamField body="description" type="string">

      Description of how the points were earned.

      Max: 100 characters

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="appId" type="string" required>

      ID of the app that initiated the transaction.

      If points were earned manually, then the `appId` is the Loyalty app's
      `wixAppId` of `553c79f3-5625-4f38-b14b-ef7c0d1e87df`. If points were earned in an automatic event,
      then the `appId` is from that automation's `sourceAppId`.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="idempotencyKey" type="string" required>

      Unique string identifier generated by the app. Wix uses this identifier to recognize subsequent retries of the same request.

      Please use `GUID` format.

      Constraints: `minLength 1`, `maxLength 256`.

    </ParamField>

    <ParamField body="activityType" type="string">

      Activity type.

      If points were earned through automation it should be set to the trigger key.

    </ParamField>

    <ParamField body="orderId" type="string">

      Order ID which was source of this transaction.

    </ParamField>

    <ParamField body="limitApplied" type="boolean">

      Whether the points amount was adjusted by an earn points limit provider.

      **Read-only.**

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="LoyaltyAccount">

      Updated loyalty account.

      See the [Account Object](/api-reference/crm/loyalty-program/accounts/accounts/account-object) for this object's fields.

    </ResponseField>

    <ResponseField name="transactionId" type="string">

      Transaction ID associated with the points earned.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Loyalty Account Updated | `wix.loyalty.v1.account_updated` | Triggered when a loyalty account is updated, including when points are adjusted, earned, or redeemed. |
    | Points Updated | `wix.loyalty.v1.account_points_updated` | Triggered when the points of a loyalty account are adjusted, earned, or redeemed. |
