A tax document is a tax-related form that Wix Payments issues to a merchant, such as a US IRS Form 1099-K.
Each tax document belongs to a Wix Payments account and covers a specific period.
When a document's file is available, you can generate a temporary URL to download it as a PDF.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Tax document ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the tax document was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the tax document was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="string">

      Revision number, which increments by 1 each time the tax document is updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="accountId" type="string">

      ID of the Wix Payments account the tax document belongs to.

      Constraints: `format GUID`, `immutable`.

    </ResponseField>

    <ResponseField name="type" type="string">

      Type of tax document.

      Constraints: `immutable`.

      **Supported values:**

      - `FORM_1099_K` — US IRS Form 1099-K.

    </ResponseField>

    <ResponseField name="period" type="TaxPeriod">

      Period the tax document covers.

      Constraints: `immutable`.

      <Expandable title="One of the following">

        <ResponseField name="options" type="options">

          options

          <Expandable title="options properties">

            <ResponseField name="yearPeriod" type="YearPeriod">

              The tax document covers a full calendar year.

              <Expandable title="yearPeriod properties">

                <ResponseField name="year" type="integer">

                  Calendar year the tax document covers. For example, `2024`.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="downloadable" type="boolean">

      Whether a file is available to download for the tax document. When `false`, calling Generate File Download Info returns an error.

      At least one of `downloadable` and `problematic` is always `true`.

    </ResponseField>

    <ResponseField name="problematic" type="boolean">

      Whether a problem was found with the tax document's file, for example incorrect data that's being corrected.

      At least one of `downloadable` and `problematic` is always `true`, and both can be `true` at the same time.

    </ResponseField>

    <ResponseField name="sourceType" type="string">

      How the tax document's amounts are aggregated.

      **Read-only.**

      **Supported values:**

      - `PAYMENT` — Amounts are aggregated by payment date.
      - `PAYOUT` — Amounts are aggregated by payout date.

    </ResponseField>

    <ResponseField name="displayName" type="string">

      Human-readable name for the tax document's file.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "taxDocument": {
          "id": "3f2b9c7a-1e6d-4b8a-9c2f-7a1e6d4b8a9c",
          "createdDate": "2024-01-31T09:15:00.000Z",
          "updatedDate": "2024-02-05T14:22:00.000Z",
          "revision": "2",
          "accountId": "c1d2e3f4-5a6b-7c8d-9e0f-1a2b3c4d5e6f",
          "type": "FORM_1099_K",
          "period": {
            "yearPeriod": {
              "year": 2023
            }
          },
          "downloadable": true,
          "problematic": false,
          "sourceType": "PAYMENT",
          "displayName": "1099-K 2023"
        }
      }
      ```

    </CodeGroup>
