    Retrieves a list of referral events, given the provided paging, filtering, and sorting.

    To learn about working with Query endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/pagination),
    and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `referredFriendSignupEvent` | `$exists` | Sort: `ASC`, `DESC` |
    | `successfulReferralEvent` | `$exists` | Sort: `ASC`, `DESC` |
    | `actionEvent` | `$exists` | Sort: `ASC`, `DESC` |
    | `rewardEvent` | `$exists` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REFERRALS.MANAGE-REFERRALS">Manage Referrals</span>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/referral-tracker/v1/referral-events/query
    ```
