The following table shows field support for filters and sorting
for the function object:

| Field                         | Supported Filters                             | Sortable |
| ----------------------------- | --------------------------------------------- | -------- |
| `id`                          | `$eq`, `$ne`, `$in`, `$exists`                | Sortable |
| `createdDate`                 | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte`    | Sortable |
| `updatedDate`                 | `$eq`, `$ne`, `$gt`, `$lt`, `$gte`, `$lte`    | Sortable |
| `appId`                       | `$eq`, `$ne`, `$in`, `$exists`                | Sortable |
| `functionExtensionId`         | `$eq`, `$ne`, `$in`, `$exists`                | Sortable |
| `functionName`                | `$eq`, `$ne`, `$in`, `$exists`, `$startsWith` | Sortable |
| `activationStatus`            | `$eq`, `$ne`, `$in`                           | Sortable |
| `functionExtensionName`       | `$eq`, `$ne`, `$in`, `$exists`, `$startsWith` | Sortable |
