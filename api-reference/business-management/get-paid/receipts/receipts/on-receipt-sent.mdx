Triggered when a receipt is sent.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.receipts.v1.receipt_sent` |
| Package | `@wix/get-paid` |
| Permissions | `Manage Receipts`, `Manage Stores` |
