    Retrieves a locale by ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MULTILINGUAL.MANAGE_TRANSLATIONS">Wix Multilingual</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/locales/v2/locale/{localeId}
    ```

    ## Path Params

    <ParamField path="localeId" type="string" required>

      ID of the locale to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="locale" type="Locale">

      The requested locale.

      See the [Locale Object](/api-reference/business-management/multilingual/locale-management/locales/locale-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
