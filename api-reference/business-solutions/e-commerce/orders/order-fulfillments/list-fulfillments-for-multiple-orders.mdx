    Retrieves fulfillments associated with multiple specified orders.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/fulfillments/list-by-ids
    ```

    ## Body Params

    <ParamField body="orderIds" type="string[]" required>

      List of order IDs for which to retrieve fulfillments.

      Constraints: `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="ordersWithFulfillments" type="OrderWithFulfillments[]">

      List of order IDs and their associated fulfillments.

      See the [Fulfillments Object](/api-reference/business-solutions/e-commerce/orders/order-fulfillments/fulfillments-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
