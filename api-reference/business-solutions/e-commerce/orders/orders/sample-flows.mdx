This article presents possible use cases and corresponding sample flows that you can support. It provides a useful starting point as you plan your implementation.

## Use an order ID across different eCommerce APIs

Some eCommerce functionality is accessible by using an order's ID and passing it to other eCommerce APIs.

1. To retrieve transaction details, including payment IDs, pass the order ID to [List Transactions For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/list-transactions-for-single-order).
2. To add a payment record, pass the order ID and payment details to [Add Payments](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/add-payments).
3. To modify the payment status, pass the order ID along with the payment ID to [Update Payment Status](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/update-payment-status).
4. To retrieve fulfillment details, pass the order ID to [List Fulfillments For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-fulfillments/list-fulfillments-for-single-order).

## Search for orders by customer

You can retrieve all orders placed by a specific customer using their email address.

1. Call [Search Orders](fallback::https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/orders/search-orders) with a filter on `buyerInfo.email`. For example:

    ```json
    {
      "search": {
        "filter": {
          "buyerInfo.email": "customer@example.com"
        }
      }
    }
    ```

2. The response contains an array of orders matching the filter. Use the `pagingMetadata.cursors` object to paginate through results if needed.
3. To get transaction details for a specific order, pass the order `id` to [List Transactions For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-transactions/list-transactions-for-single-order).

## Track fulfillment status

You can retrieve fulfillment details for an order and update tracking information.

1. Call [List Fulfillments For Single Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-fulfillments/list-fulfillments-for-single-order) with the order ID to get existing fulfillments.
2. To add a new fulfillment with tracking information, call [Create Fulfillment](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-fulfillments/create-fulfillment). For example:

    ```json
    {
      "fulfillment": {
        "lineItems": [
          {
            "id": "line-item-id",
            "quantity": 1
          }
        ],
        "trackingInfo": {
          "trackingNumber": "1Z999AA10123456784",
          "shippingProvider": "ups",
          "trackingLink": "https://www.ups.com/track?tracknum=1Z999AA10123456784"
        }
      }
    }
    ```

3. To update tracking information on an existing fulfillment, call [Update Fulfillment](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/order-fulfillments/update-fulfillment) with the order ID, fulfillment ID, and updated tracking details.
