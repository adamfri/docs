    Updates a customization.

    Each time the customization is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the customization.
    This ensures you're working with the latest customization and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.CUSTOMIZATION_WRITE">Customization write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v3/customizations/{customization.id}
    ```

    ## Path Params

    <ParamField path="customization.id" type="string" required>

      Customization ID.

    </ParamField>

    ## Body Params

    <ParamField body="customization" type="Customization" required>

      Customization to update.

      See the [Customization Object](/api-reference/business-solutions/stores/catalog-v3/customizations-v3/customization-object) for this object's fields.

    </ParamField>

    <ParamField body="fields" type="string[]">

      Fields to include in the response.

      Supported values: `ASSIGNED_PRODUCTS_COUNT`

      Constraints: `maxItems 100`.

      **Supported values:**

      - `ASSIGNED_PRODUCTS_COUNT` — Assigned products count.
      - `CHOICE_DISPLAY_IMAGE` — Returns display images for choices.

    </ParamField>

    ## Response Object

    <ResponseField name="customization" type="Customization">

      Updated customization.

      See the [Customization Object](/api-reference/business-solutions/stores/catalog-v3/customizations-v3/customization-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    ## Method Parameters

    <ParamField body="_id" type="string" required>

      Customization ID.

      **Read-only.**

    </ParamField>

    <ParamField body="customization" type="UpdateCustomization" required>

      Customization to update.

      <Expandable title="customization properties">

        <ParamField body="_id" type="string">

          Customization ID.

          **Read-only.**

        </ParamField>

        <ParamField body="revision" type="integer" required>

          Revision number, which increments by 1 each time the customization is updated.
          To prevent conflicting changes,
          the current revision must be passed when updating the customization.

          Ignored when creating a customization.

          **Read-only.**

        </ParamField>

        <ParamField body="_createdDate" type="datetime">

          Date and time the customization was created.

          **Read-only.**

        </ParamField>

        <ParamField body="_updatedDate" type="datetime">

          Date and time the customization was updated.

          **Read-only.**

        </ParamField>

        <ParamField body="key" type="string">

          A read-only identifier generated from the customization name.

          Use `key` in the `catalogReference.options` object when [integrating Catalog V3 with eCommerce APIs](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/e-commerce-integration).

          **Read-only.**

        </ParamField>

        <ParamField body="name" type="string">

          Customization name for options (for example, `"color"`, `"size"`) and modifiers (for example, `"greeting card"`).

          Constraints: `minLength 1`, `maxLength 50`.

        </ParamField>

        <ParamField body="customizationType" type="string">

          Customization type.

          Constraints: `immutable`.

          **Supported values:**

          - `PRODUCT_OPTION`
          - `MODIFIER`

        </ParamField>

        <ParamField body="customizationRenderType" type="string">

          Customization render type.

          Defines how the customization will be displayed in the storefront.

          Constraints: `immutable`.

          **Supported values:**

          - `FREE_TEXT` — Customization by free text input.
          - `TEXT_CHOICES` — Customization by selection of text choices.
          - `SWATCH_CHOICES` — Customization by selection of colors.

        </ParamField>

        <ParamField body="assignedProductsCount" type="integer">

          Number of products this customization is assigned to.
          > **Note:** Returned only when you pass `"ASSIGNED_PRODUCTS_COUNT"` to the `fields` array in Customizations API requests.

          **Read-only.**

        </ParamField>
