    Creates a storage item.

    Each storage item has a unique key and a value of a specific data type. Once created, you can't change the value type.

    <Note>

    You can currently create up to 100 storage items.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/storage-service/v1/storage-items
    ```

    ## Body Params

    <ParamField body="storageItem" type="StorageItem" required>

      Storage item to create.

      See the [Storage Item Object](/api-reference/business-management/automations/storage-item/storage-item-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="storageItem" type="StorageItem">

      Created storage item.

      See the [Storage Item Object](/api-reference/business-management/automations/storage-item/storage-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_STORAGE_ITEM_KEY_EXCEPTION` | Invalid storage item key. The storage item key can only contain letters, numbers, and underscores. |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_STORAGE_ITEMS` | The site has too many storage items. |
    | `400` | `INVALID_ARGUMENT` | `STORAGE_ITEM_VALUE_VALIDATION_EXCEPTION` | Invalid storage item value. The value has an invalid format. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
