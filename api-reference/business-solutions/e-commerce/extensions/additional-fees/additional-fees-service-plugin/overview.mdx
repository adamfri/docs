Describes the additional fees integration to be called by Wix and received by the relevant additional fees provider. This integration is used to calculate the additional fees according to your own custom logic.

## SDK package

```bash
npm install @wix/ecom
```

Import the `additionalFees` namespace from `@wix/ecom`.
