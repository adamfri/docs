    <div className="wix-ref">

    This endpoint enables you to delete multiple sites.

    This is not a permanent delete. Sites are moved to the trash bin and can be restored through site collaborators.

    Learn more about [deleting multiple sites](https://support.wix.com/en/article/moving-a-site-to-trash).

    <Note>

    This call requires an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="my-account.delete-site">my-account.delete-site</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/site-actions/v1/bulk/sites/delete
    ```

    ## Body Params

    <ParamField body="ids" type="string[]" required>

      Site IDs.

      Min: 1 site ID &lt;br>
      Max: 20 site IDs

      Constraints: `format GUID`, `minItems 1`, `maxItems 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkSiteResult[]">

      List of deletion results.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Result of deletion request per site describing the success or failure of each deletion.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Site ID.

            </ResponseField>

            <ResponseField name="originalIndex" type="number">

              Index of the site in the request array. Allows for correlation between request and response.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for the site. When `false`, the action failed and an `error` object is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Summary of deletion data.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="number">

          Number of sites that were deleted successfully.

        </ResponseField>

        <ResponseField name="totalFailures" type="number">

          Number of sites that were not deleted successfully.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
