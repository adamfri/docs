    Retrieves a list of checkout templates, given the provided paging, filtering, and sorting.

    Query Checkout Templates runs with these defaults, which you can override:
    - `id` sorted in `ASC` order

    The following table shows field support for filters and sorting for the checkout template object:

    | Field              | Supported Filters                                         | Sortable |
    | ------------------ | --------------------------------------------------------- | -------- |
    | `id`               | `$eq`, `$ne`, `$in`, `$startsWith`, `$exists`, `$hasSome` | Sortable |
    | `status`           | `$eq`, `$ne`, `$in`, `$exists`, `$hasSome`                | Sortable |

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `status` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>
