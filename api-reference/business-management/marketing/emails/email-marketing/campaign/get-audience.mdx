    <div className="wix-ref">

    Retrieves the audience configured for a campaign.

    Primarily used to retrieve the audience of a paused campaign so it can be passed back when republishing.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/audience
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      Campaign ID.

    </ParamField>

    ## Response Object

    <ResponseField name="audience" type="CampaignAudience">

      Campaign audience.

      <Expandable title="audience properties">

        <ResponseField name="contactIds" type="string[]">

          IDs of contacts to whom to send the campaign.

          Constraints: `format GUID`, `maxItems 100`.

        </ResponseField>

        <ResponseField name="labelIds" type="string[]">

          IDs of contact labels used to define the campaign audience.

          Constraints: `maxLength 100`, `maxItems 20`.

        </ResponseField>

        <ResponseField name="segmentIds" type="string[]">

          IDs of segments used to define the campaign audience.

          Constraints: `format GUID`, `maxItems 20`.

        </ResponseField>

        <ResponseField name="contactsFilter" type="object">

          Filter for contacts in JSON format.

        </ResponseField>

        <ResponseField name="contactsSearchTerm" type="string">

          Contacts plain text search expression (searches in name, phone and email fields).

        </ResponseField>

        <ResponseField name="activeContactsOnly" type="boolean">

          Whether to exclude inactive contacts from the campaign audience.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
