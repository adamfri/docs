    Retrieves a translation schema by ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MULTILINGUAL.READ_TRANSLATION_SCHEMA">Wix Multilingual - Translation Schema Read</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/translation-schema/v1/schemas/{schemaId}
    ```

    ## Path Params

    <ParamField path="schemaId" type="string" required>

      ID of the translation schema to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="schema" type="Schema">

      The requested translation schema.

      See the [Schema Object](/api-reference/business-management/multilingual/translation/translation-schema/schema-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
