    Triggered in case Wix creates an invoice that includes charges for an instance
    of your app.

    ## Endpoint

    ```http
    POST /v1/invoice-created
    ```

    ## Body Params

    <ParamField body="subscriptionId" type="string">

      ID of the subscription for which Wix has created an invoice that includes
      your custom charges. To track usage and billing for apps, we recommend to use
      `instanceId` instead of the `subscriptionId`.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="currency" type="string">

      Supported values: `AUD`, `BRL`, `CAD`, `EUR`, `GBP`, `ILS`, `INR`, `JPY`, `MXN`, `PLN`, `RUB`, `TRY`, `USD`.

      3-letter currency code in
      [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)
      format of the charges. Wix may add supported currencies in the future.

      Constraints: `format CURRENCY`.

    </ParamField>

    <ParamField body="invoiceId" type="string">

      ID of the created invoice.

    </ParamField>

    <ParamField body="lineItems" type="InvoiceLineItem[]">

      Line items included in the invoice.

      Constraints: `maxItems 20`.

      <Expandable title="lineItems properties">

        <ParamField body="chargeId" type="string">

          ID of the charge as returned in List Charges.

          Max: 64 characters

        </ParamField>

        <ParamField body="amount" type="string">

          Charge amount.

          Constraints: `format DECIMAL_VALUE`.

        </ParamField>

        <ParamField body="id" type="string">

          ID of the line item in the invoice that Wix sends to the customer.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `InvoiceCreatedResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
