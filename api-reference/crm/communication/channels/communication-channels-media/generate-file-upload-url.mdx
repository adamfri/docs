    <div className="wix-api-columns">

    <div className="wix-ref">

    Generates a secure upload URL for storing a file in the Media Manager.

    To upload the file to the Media Manager after calling this method, call the Media Manager's [Upload API](https://dev.wix.com/docs/api-reference/assets/media/media-manager/files/upload-api) with the `uploadUrl` response.

    Call this method to upload files to the Media Manager from a local device, such as a computer or phone.

    <Note>

    Due to limits on the size and duration of files that you can upload, we recommend importing files to the Media Manager by calling the [Import File](https://dev.wix.com/docs/api-reference/crm/communication/channels/communication-channels-media/import-file) method. See [Wix Media: Supported Media File Types and File Sizes](https://support.wix.com/en/article/wix-media-supported-media-file-types-and-file-sizes) for more details.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-INBOX.MANAGE-MSGS">Manage Inbox Messages</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/communication-channels-media/v1/upload-url
    ```

    ## Body Params

    <ParamField body="fileName" type="string">

      File name used to identify the file type. For example, `myFile.jpeg` identifies as an `image/jpeg` file type.

      Constraints: `maxLength 200`.

    </ParamField>

    <ParamField body="mimeType" type="string" required>

      File mime type.

      Constraints: `maxLength 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="uploadUrl" type="string">

      Temporary URL for uploading a file to the Media Manager. The URL is valid for 10 hours.

      Constraints: `format WEB_URL`.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MIME_TYPE_MISMATCH` | MIME type doesn't match the file extension. |
    | `400` | `INVALID_ARGUMENT` | `ZERO_FILE_SIZE` | File can't be empty. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_FILE_FORMAT` | File format not supported. |
    | `400` | `INVALID_ARGUMENT` | `FILE_SIZE_OVER_LIMIT` | File size exceeds the allowed limit for this media type. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
