    Adds [info sections](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/info-sections-v3/introduction) to multiple products, given the provided filter and search expression.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.PRODUCT_WRITE">Product write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/stores/v3/bulk/products/add-info-sections-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter object.

    </ParamField>

    <ParamField body="infoSectionIds" type="string[]" required>

      IDs of the info sections to add.

      Constraints: `format GUID`, `minItems 1`, `maxItems 20`.

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          Defines how separate search terms in `expression` are combined

          **Supported values:**

          - `OR` — Any of the search terms must be present
          - `AND` — All search terms must be present

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If the array is empty, all searchable fields are searched. Use dot notation to specify a JSON path. For example, `order.address.streetName`.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to enable the search function to use an algorithm to automatically find results that are close to the search expression, such as typos and declensions.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID.

      Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/introduction) to retrieve job details and metadata..

      Constraints: `format GUID`.

    </ResponseField>

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
