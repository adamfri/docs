    Restores a deleted component.

    Use this method to make a deleted draft component available again in the app's draft components. Provide the `appId` and `componentId` of the deleted component to restore.

    The request fails if the component doesn't exist, isn't deleted, or can't be restored. The response is empty; to retrieve the restored component, call GetComponent or GetDraftAppComponents after restoring.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/apps/v1/components/v1/components/restore
    ```

    ## Body Params

    <ParamField body="appId" type="string">

      App ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="componentId" type="string">

      Component ID.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    Returns `RestoreDeletedComponentResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
