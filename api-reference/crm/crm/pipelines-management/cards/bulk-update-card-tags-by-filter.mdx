    <div className="wix-ref">

    Asynchronously updates tags on multiple cards using a filter to specify which cards to update.

    An empty filter updates all cards in the pipeline.

    If you specify a tag in both `assignTags` and `unassignTags`, the tag is assigned to the cards.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CRM.MANAGE-PIPELINES">Manage Pipelines</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/crm/pipelines/v1/bulk/cards/update-tags-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter object.

    </ParamField>

    <ParamField body="assignTags" type="PrivateTags">

      List of tags to assign.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="PrivateTags">

      List of tags to unassign.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ResponseField name="jobId" type="string">

      Job ID.

      Constraints: `format GUID`.

    </ResponseField>

    | Status | Code | Application code | Description |

    | `400` | `INVALID_ARGUMENT` | `EMPTY_ASSIGN_AND_UNASSIGN_LISTS` | Both assign and unassign tag lists are empty. |

    ## Examples

    Updates tags on multiple cards matching a filter.

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/crm/pipelines/v1/bulk/cards/update-tags-by-filter' \
        -H 'Authorization:<AUTH>' \
        -H 'Content-Type: application/json' \
        --data-binary '{
          "filter": {
            "pipelineId": {
              "$eq": "f9e8d7c6-b5a4-3210-fedc-ba9876543210"
            },
            "stageId": {
              "$in": ["01234567-89ab-cdef-0123-456789abcdef"]
            },
            "priority": {
              "$eq": "P1_URGENT"
            },
            "createdDate": {
              "$gte": "2024-01-01T00:00:00.000Z",
              "$lte": "2024-01-31T23:59:59.999Z"
            }
          },
          "assignTags": {
            "privateTags": {
              "tagIds": [
                "urgent-review",
                "january-batch",
                "needs-followup"
              ]
            }
          },
          "unassignTags": {
            "privateTags": {
              "tagIds": [
                "pending-approval",
                "draft"
              ]
            }
          }
        }'
      ```

      ```json Response
      {
        "jobId": "job-12345678-90ab-cdef-1234-567890abcdef"
      }
      ```
