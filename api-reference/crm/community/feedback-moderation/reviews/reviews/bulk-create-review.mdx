    <div className="wix-ref">

    Creates multiple reviews.

    If the `authorName` field is empty, and the review author:
    - is a site member, their member name is used.
    - isn't a site member, the field is set to `null`.

    To create a single review, call Create Review.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v1/bulk/reviews/create
    ```

    ## Body Params

    <ParamField body="reviews" type="Review[]" required>

      Reviews to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created entities.

    </ParamField>

    ## Response Object
