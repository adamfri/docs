    Updates the display order of badges.

    Provide an ordered array of badge IDs to set their display sequence.

    This affects how badges appear to site members and in the site dashboard.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/badges/v4/badges/order
    ```

    ## Body Params

    <ParamField body="ids" type="string[]" required>

      Ordered list of badge IDs.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="badges" type="Badge[]">

      Badges in their new display order.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges-v4/badge-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
