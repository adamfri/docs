---
title: "Template Object"
description: "A template is a reusable starting point for creating new sites, based on an existing site."
icon: "cube"
---

A template is a reusable starting point for creating new sites, based on an existing site.

Wix Studio partners create a template from one of their sites, then use that template to create new sites within their account. Each new site is a duplicate of the template's site. A partner can also publish a template, turning it into a public template that other Wix accounts can clone.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Template ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Template name.

    </ResponseField>

    <ResponseField name="sites" type="Sites">

      Sites created from this template within the current account.

      **Read-only.**

      <Expandable title="sites properties">

        <ResponseField name="metaSiteIds" type="string[]">

          IDs of the sites created from this template within the current account.

          Constraints: `format GUID`, `maxItems 1000`.

        </ResponseField>

        <ResponseField name="count" type="integer">

          Number of sites created from this template within the current account.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdBy" type="string">

      ID of the user who created the template.

      **Read-only.**

    </ResponseField>

    <ResponseField name="lastEditedBy" type="string">

      ID of the user who last edited the template's site.

      **Read-only.**

    </ResponseField>

    <ResponseField name="lastEditedDate" type="datetime">

      Date and time the template's site was last edited.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the template is updated. To prevent conflicting changes, the current revision must be passed when updating the template. Ignored when creating a template.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the template was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the template was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="templateType" type="string">

      Type of the template. A template is always created as `STUDIO`, and becomes `PUBLIC` when it's published.

      **Read-only.**

      **Supported values:**

      - `STUDIO` — Standard template created from a site.
      - `PUBLIC` — Published template that other Wix accounts can clone.

    </ResponseField>

    <ResponseField name="hidden" type="boolean">

      Whether the template is hidden from template galleries and pickers. A hidden template still exists and can be used to create sites, but doesn't appear in template lists. Default: `false`.

    </ResponseField>

    <ResponseField name="platform" type="string">

      Platform the template's site was built on. Derived automatically from the site.

      **Read-only.**

      **Supported values:**

      - `STUDIO` — Site built with Wix Studio.
      - `WIX` — Site built with the Wix Editor.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "template": {
          "id": "8046df3c-7575-4098-a5ab-c91ad8f33c47",
          "name": "Bloom Bakery",
          "sites": {
            "metaSiteIds": ["9c8f0e2a-3b7d-4c1e-8a6f-2d4b1e7c9a05"],
            "count": 1
          },
          "createdBy": "f1a2b3c4-d5e6-4789-9abc-1234567890ab",
          "lastEditedBy": "f1a2b3c4-d5e6-4789-9abc-1234567890ab",
          "lastEditedDate": "2024-03-20T11:05:44.000Z",
          "revision": "3",
          "createdDate": "2024-03-18T17:22:10.299Z",
          "updatedDate": "2024-03-20T11:05:44.000Z",
          "templateType": "STUDIO",
          "hidden": false,
          "platform": "STUDIO"
        }
      }
      ```

    </CodeGroup>
