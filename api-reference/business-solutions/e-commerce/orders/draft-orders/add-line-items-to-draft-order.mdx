    Adds catalog or custom line items to a draft order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}/add-line-items
    ```

    ## Path Params

    <ParamField path="draftOrderId" type="string" required>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `DRAFT_ORDER_DOES_NOT_EXIST` | Couldn't find the draft order. |
    | `428` | `FAILED_PRECONDITION` | `MAX_ITEMS_REACHED` | Number of items exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `MULTIPLE_ADDS_FOR_SAME_LINE_ITEM` | Line item was added more than once in the same request. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_NOT_AVAILABLE` | Catalog item isn't available. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_NOT_FOUND` | Couldn't find the catalog item. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_PAYMENT_OPTION_UNSUPPORTED` | Catalog item's payment option isn't supported. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_ALREADY_EXIST` | There is already a catalog item with this ID on the draft order. |
    | `400` | `INVALID_ARGUMENT` | `GIFT_CARD_ITEM_UNSUPPORTED` | Gift card items aren't supported. |
    | `400` | `INVALID_ARGUMENT` | `SUBSCRIPTION_ITEM_UNSUPPORTED` | Subscription items aren't supported. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_EXTERNAL_LINE_ITEM_ID` | External line item ID isn't unique. Each line item must have a unique external ID. |
    | `428` | `FAILED_PRECONDITION` | `DRAFT_ORDER_ALREADY_COMMITTED` | Draft order was already committed. |
    | `428` | `FAILED_PRECONDITION` | `SUBSCRIPTION_SINGLE_ITEM_ALLOWED` | Converting a draft to a subscription order is supported only with exactly one line item. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_LINE_ITEM_IDS` | Line items have duplicated IDs. |
    | `428` | `FAILED_PRECONDITION` | `DRAFT_ORDER_HAS_GLOBAL_DEPOSIT` | Draft order has global deposit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
