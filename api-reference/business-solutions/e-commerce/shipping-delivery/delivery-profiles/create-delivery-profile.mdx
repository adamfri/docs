    Creates a delivery profile.

    A site can have up to 99 delivery profiles.
    Attempting to exceed this limit returns a `DELIVERY_PROFILES_LIMIT_EXCEEDED` error.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/delivery-profiles
    ```

    ## Body Params

    <ParamField body="deliveryProfile" type="DeliveryProfile" required>

      Delivery profile to create.

      See the [Delivery Profile Object](/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/delivery-profile-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="deliveryProfile" type="DeliveryProfile">

      Created delivery profile.

      See the [Delivery Profile Object](/api-reference/business-solutions/e-commerce/shipping-delivery/delivery-profiles/delivery-profile-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `DELIVERY_PROFILES_LIMIT_EXCEEDED` | Maximum number of delivery profiles exceeded. A site can have up to 99 profiles. |
    | `428` | `FAILED_PRECONDITION` | `DESTINATIONS_COLLISION` | One or more destinations already exist in another delivery region within this profile. |
    | `428` | `FAILED_PRECONDITION` | `SINGLE_DEFAULT_DELIVERY_PROFILE` | A default delivery profile already exists for this site. |
    | `428` | `FAILED_PRECONDITION` | `UNKNOWN_DELIVERY_CARRIER` | The specified `appId` of one or more delivery carriers in `deliveryRegions.deliveryCarriers` doesn't exist. |
    | `428` | `FAILED_PRECONDITION` | `DELIVERY_CARRIER_MISSING_BACKUP_RATE` | A delivery carrier in `deliveryRegions.deliveryCarriers` requires a `backupRate` to be set. |
    | `428` | `FAILED_PRECONDITION` | `SUBDIVISIONS_UNSUPPORTED_FOR_COUNTRY` | Returned when a `destinations` entry sets `subdivisions` for a country that doesn't support subdivision-level delivery. Remove `subdivisions` from the destination, or use a supported country. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Delivery Profile Created | `wix.ecom.v1.delivery_profile_created` | Triggered when a delivery profile is created. |
    | Delivery Profile Region Added | `wix.ecom.v1.delivery_profile_region_added` | Triggered when a delivery region is added to a delivery profile. |
