    <div className="wix-ref">

    Redeems a current customer's loyalty points for a loyalty reward and creates a loyalty coupon.

    Creating a loyalty coupon also creates a corresponding "reference" coupon with the [Coupons API](https://dev.wix.com/docs/rest/business-management/marketing/coupons/coupons/coupon-object).
    The customer receives the reference coupon, which they can apply to their order. The loyalty coupon and its corresponding reference coupon
    are linked and the loyalty coupon's `status` reflects the current state of the reference coupon.

    Check which loyalty rewards a site has available with List Rewards in the Loyalty Rewards API.

    <Note>

    This endpoint requires [visitor or member authentication](https://dev.wix.com/docs/build-apps/develop-your-app/access/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/loyalty-coupons/v1/coupons/redeem-my-coupon
    ```

    ## Body Params

    <ParamField body="rewardId" type="string" required>

      ID of the loyalty reward to redeem. See the Loyalty Rewards API for more information.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="coupon" type="LoyaltyCoupon">

      Created loyalty coupon.

      See the [Coupon Object](/api-reference/crm/loyalty-program/rewards/coupons/coupon-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
