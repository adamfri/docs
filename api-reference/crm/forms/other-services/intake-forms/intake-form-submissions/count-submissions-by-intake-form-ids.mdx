    <div className="wix-ref">

    Counts intake form submissions by form IDs.

    Returns the total number of submissions per intake form.

    If you include a deleted intake form ID in the request, that form is omitted from the response.

    Use this method for analytics, reporting, or checking if a form has submissions before deleting it.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.READ">Read Intake Form</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/intake-forms/v1/submissions/count
    ```

    ## Body Params

    <ParamField body="intakeFormIds" type="string[]" required>

      List of intake form IDs to count submissions for.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="intakeFormSubmissionCounts" type="IntakeFormSubmissionCount[]">

      Submission counts per intake form.

      <Expandable title="intakeFormSubmissionCounts properties">

        <ResponseField name="intakeFormId" type="string">

          Intake form ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="submissionCount" type="integer">

          Total number of submissions for the intake form.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
