    Updates a Google Ads account linked to the current Wix site.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-GOOGLE-ADS">Manage google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/_serverless/pa-google/v1/accounts/{account.id}
    ```

    ## Path Params

    <ParamField path="account.id" type="string" required>

      Account ID.

    </ParamField>

    ## Body Params

    <ParamField body="account" type="Account" required>

      The account data to update. The `id` field is required.

      See the [Google Account Object](/api-reference/business-management/marketing/ads/google-ads/google-account-v1/google-account-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="account" type="Account">

      The updated Google Ads account.

      See the [Google Account Object](/api-reference/business-management/marketing/ads/google-ads/google-account-v1/google-account-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
