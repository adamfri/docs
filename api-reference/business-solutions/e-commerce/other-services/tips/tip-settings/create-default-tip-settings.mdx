    Creates a default `tipSettings` object.

    The call fails if there is already an existing default `tipSettings` object.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/tip-settings/v1/tip-settings/create-default
    ```

    ## Body Params

    <ParamField body="tipSettings" type="TipSettings" required>

      Default tip settings to create.

      See the [Tip Settings Object](/api-reference/business-solutions/e-commerce/other-services/tips/tip-settings/tip-settings-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="tipSettings" type="TipSettings">

      Created default tip settings.

      See the [Tip Settings Object](/api-reference/business-solutions/e-commerce/other-services/tips/tip-settings/tip-settings-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `DEFAULT_SETTINGS_ALREADY_EXISTS` | Default `tipSettings` object already exists. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_HAVE_MORE_THAN_ONE_DEFAULT_PRESET` | Only 1 preset can be set as default. |
    | `428` | `FAILED_PRECONDITION` | `PRESET_PERCENTAGE_TOO_HIGH` | Preset percentage exceeds the maximum allowed value. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
