    <div className="wix-ref">

    Returns the total number of deleted form schemas in the specified namespace that match the specified filter criteria.
    This counts form schemas in the trash bin, not permanently deleted form schemas.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/deleted-forms/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object for counting deleted form schemas.

    </ParamField>

    <ParamField body="namespace" type="string" required>

      Namespace for filtering the form schemas.

      Constraints: `minLength 10`, `maxLength 50`, `immutable`.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Deleted forms count.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Counts the number of deleted forms

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'http://www.wixapis.com/form-schema-service/v4/deleted-forms/count' \
        -H 'Content-Type: application/json' \
        -H 'Authorization: <AUTH>' \
        -d '{
          "filter": {
            "createdDate": {
              "$gt": "2025-01-31T07:16:52.779Z"
            }
          },
          "namespace": "wix.form_app.form"
        }'
      ```

      ```json Response
      {
          "count": 2
        }
      ```

    </CodeGroup>
