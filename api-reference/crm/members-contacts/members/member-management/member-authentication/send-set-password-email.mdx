      **Developer Preview.** This method is in Developer Preview and may change without notice.

    </Info>

    Sends a site member an email with a link to set or reset their password.

    The set password link is valid for 3 hours,
    and it can be used only once.
    If the link expires, the original password remains.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/identity/members/v1/auth/members/send-set-password-email
    ```

    ## Body Params

    <ParamField body="email" type="string" required>

      Login email of the member whose password will be set.

    </ParamField>

    <ParamField body="requestedByMember" type="boolean" deprecated>

      > **Deprecated:**
      > This field has been replaced with `hideIgnoreMessage`.

      Whether the email is being sent by member request.

      If `true`, the email tells the member
      they can safely ignore
      if they did not request the password change.

      Defaults to `false`.

      **Deprecated.**

    </ParamField>

    <ParamField body="hideIgnoreMessage" type="boolean">

      Whether to hide the ignore this email message .

      If `true`, the email tells the member
      they can safely ignore
      if they did not request the password change.

      Default: `false`.

    </ParamField>

    ## Response Object

    <ResponseField name="accepted" type="boolean">

      Indicates if the request was successfully received.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
