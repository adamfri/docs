    Counts the total number of gift cards matching the specified filter criteria.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gift-cards/v1/gift-cards/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter options to count specific gift cards.
      Use the same filter format as Query Gift Cards.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Total number of gift cards matching the filter criteria.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    ## Examples

    Count existing gift cards filtered by `expirationDate`

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/gift-cards/v1/gift-cards/count' \
        -H 'Authorization: <AUTH>' \
        -H 'Content-Type: application/json' \
        -d '{
              "filter": {
                "expirationDate": {
                  "$gte": "2024-10-01T14:52:02.588Z"
                }
              }
            }'
      ```

      ```json Response
      {
        "count": 2
      }
      ```
