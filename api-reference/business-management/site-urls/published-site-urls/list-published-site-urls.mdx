<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a list of a site's published URLs.
    If a site hasn't been published, the call returns an empty array.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-SITES.READ-URLS">Read Site URLs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/urls-server/v2/published-site-urls
    ```

    ## Query Params

    <ParamField query="filters" type="Filters">

      Optional filters for the list. If this field is omitted, defaults to primary URLs of all URL types.

      <Expandable title="filters properties">

        <ParamField query="urlType" type="string">

          URL type filter.
          Default: `ALL`

          **Supported values:**

          - `ALL` — All URLs.
          - `PREMIUM` — Only URLs directing to the Premium version of the site.
          - `FREE` — Only URLs provided by Wix for free. These URLs include `wixsite.com`.

        </ParamField>

        <ParamField query="primary" type="boolean">

          Whether to return only the site's primary URL.

        </ParamField>

        <ParamField query="multilingual" type="boolean">

          Whether to return language subdomains hosted by [Wix Multilingual](https://support.wix.com/article/wix-multilingual-adding-and-setting-up-wix-multilingual).

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="urls" type="Url[]">

      List of published site URLs. This array will be empty if the site isn't published.

      Constraints: `maxItems 1000`.

      <Expandable title="urls properties">

        <ResponseField name="urlType" type="string">

          URL type.

          **Supported values:**

          - `PREMIUM` — Only URLs directing to the Premium version of the site.
          - `FREE` — Only URLs provided by Wix for free. These URLs include `wixsite.com`.

        </ResponseField>

        <ResponseField name="primary" type="boolean">

          Whether this is the site's primary URL.

        </ResponseField>

        <ResponseField name="url" type="string">

          Published site URL.

          Constraints: `maxLength 3000`.

        </ResponseField>

        <ResponseField name="multilingualInfo" type="MultilingualInfo">

          Language subdomain info hosted by [Wix multilingual](https://support.wix.com/article/wix-multilingual-adding-and-setting-up-wix-multilingual).

          <Expandable title="multilingualInfo properties">

            <ResponseField name="languageCode" type="string">

              Language tag in [IETF BCP 47](https://en.wikipedia.org/wiki/IETF_language_tag) format. For example, `en-US`.

              Constraints: `format LANGUAGE_TAG`.

            </ResponseField>

            <ResponseField name="defaultLanguage" type="boolean">

              Whether this is the site's default language.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `UNABLE_TO_EXTRACT_MS_ID` | Can't extract site ID from request. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_IDENTITY` | Can't extract identity from request. |
    | `400` | `INVALID_ARGUMENT` | `NO_PRIMARY_URL` | No primary URL exists for this site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
