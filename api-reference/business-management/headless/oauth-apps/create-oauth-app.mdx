    Creates a new OAuth app for a Wix Headless client.

    Use this API to enable headless functionality for a Wix site. An OAuth app allows external sites or apps to securely access your site's data and services using Wix APIs.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.OAUTH_APP.MANAGE">Manage OAuth Apps</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/oauth-app/v1/oauth-apps
    ```

    ## Body Params

    <ParamField body="oAuthApp" type="OAuthApp" required>

      OAuth app to create.

      See the [O Auth App Object](/api-reference/business-management/headless/oauth-apps/o-auth-app-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="oAuthApp" type="OAuthApp">

      Created OAuth app info.

      See the [O Auth App Object](/api-reference/business-management/headless/oauth-apps/o-auth-app-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | OAuth App Created | `wix.headless.v1.o_auth_app_created` | Triggered when an OAuth app is created. |

    </div>
