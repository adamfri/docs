    <div className="wix-ref">

    Captures (charges) previously authorized payments, converting the authorization hold into an actual charge.

    Use this method to complete payment when you're ready to fulfill an order, typically after confirming
    inventory availability and preparing for shipment.

    *Note**: Only payments with `AUTHORIZED` status can be captured. The capture amount cannot exceed the authorized amount.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-billing/capture-authorized-payments
    ```

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `PAYMENT_NOT_FOUND` | Couldn't find the payment. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_AMOUNT` | Capture amount doesn't match the authorized amount. |
    | `428` | `FAILED_PRECONDITION` | `PAYMENT_ALREADY_VOIDED` | Payment was already voided. |
    | `409` | `ALREADY_EXISTS` | `PAYMENT_ALREADY_CAPTURED` | Payment was already captured. |
    | `428` | `FAILED_PRECONDITION` | `PAYMENT_NOT_AUTHORIZED` | Payment doesn't have `AUTHORIZED` status. |
    | `409` | `ALREADY_EXISTS` | `PAYMENT_HAS_PENDING_CAPTURE` | Payment already has a capture in progress. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_HAS_CHARGEBACKS` | Order has chargebacks and can't be captured. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
