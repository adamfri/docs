    Suggests corrected heading levels for a page's headings.

    Pass the page's headings in document order, each with its raw HTML and
    your own reference IDs. The AI checks the heading hierarchy (one H1,
    no skipped levels, headings that match their content) and returns a
    suggested tag per heading that should change, echoing your reference IDs
    back so you can locate each element.

    The heading nodes are the request's content, so this method works for any
    page, including headless projects.

    This method must be called with a [Wix user identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities), for example an app acting on
    behalf of a signed-in site owner. Calls made with an API key fail,
    because the page's title is read through the site's accessibility
    analysis, which runs as the user.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/seo/suggestions/v1/tag-suggestions/heading-structure
    ```

    ## Body Params

    <ParamField body="headings" type="HeadingNode[]" required>

      The page's heading elements, in the order they appear on the page.

      Constraints: `maxItems 200`.

      <Expandable title="headings properties">

        <ParamField body="id" type="string">

          Your reference ID for the heading element. Required, and must be unique
          within the request together with `uiElementId` and `attributeId` if you
          send them.

          Constraints: `minLength 1`, `maxLength 1000`.

        </ParamField>

        <ParamField body="attributeId" type="string">

          Additional reference ID for the heading's text attribute, if you use
          one. Echoed back unchanged.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="htmlString" type="string">

          Raw HTML of the heading element, including its tag, for example,
          `<h2>Our services</h2>`. Elements that aren't headings are ignored for
          the structure check. Send page content only. Don't include personal
          data.

          Constraints: `minLength 1`, `maxLength 100000`.

        </ParamField>

        <ParamField body="uiElementId" type="string">

          Additional reference ID for the heading element, if you use one. Echoed
          back unchanged.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField body="sectionId" type="string">

          Your reference ID for the page section the heading belongs to. Helps
          the AI keep one heading hierarchy per section.

          Constraints: `maxLength 1000`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="pageId" type="string" required>

      Your reference ID for the page the headings belong to. For Wix pages,
      the page ID, which lets the page's title be read to give the AI context.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    <ParamField body="itemType" type="string" required>

      Type of the page's item, as an SEO item type identifier. For example,
      `STATIC_PAGE_V2` for a regular site page or `BLOG_POST` for a blog post.
      Other values are rejected.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    ## Response Object

    <ResponseField name="suggestions" type="HeadingSuggestion[]">

      A suggestion per heading whose level should change. Headings that are
      already correct aren't returned.

      **Read-only.** Constraints: `maxItems 200`.

      <Expandable title="suggestions properties">

        <ResponseField name="headingId" type="string">

          Your reference ID for the heading element, echoed from the request.

          **Read-only.** Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="uiElementId" type="string">

          Your `uiElementId` reference, echoed from the request.

          **Read-only.** Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="attributeId" type="string">

          Your `attributeId` reference, echoed from the request.

          **Read-only.** Constraints: `maxLength 1000`.

        </ResponseField>

        <ResponseField name="currentTag" type="string">

          The heading's current tag. For example, `H2`.

          **Read-only.** Constraints: `maxLength 10`.

        </ResponseField>

        <ResponseField name="proposedTag" type="string">

          The suggested tag. For example, `H3`, or `P` for text that shouldn't be
          a heading.

          **Read-only.** Constraints: `maxLength 10`.

        </ResponseField>

      </Expandable>

    </ResponseField>
