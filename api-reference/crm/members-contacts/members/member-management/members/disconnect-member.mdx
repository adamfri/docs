    Disconnects a member.

    A disconnected member can't log in to members-only pages, isn't visible in the dashboard,
    and their `status` changes to `OFFLINE`.

    Use this when you want to permanently remove access without deleting member data.

    <Note>

    This action is irreversible. To connect the same member again, you have to create a member with a new slug.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/members/{id}/disconnect
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of a member to disconnect.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      Disconnected member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
