    <div className="wix-api-columns">

    <div className="wix-ref">

    Checks whether you can [reschedule](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/reschedule-booking) or [cancel](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/cancel-booking) a list of bookings without using [force resolution](https://dev.wix.com/docs/api-reference/business-solutions/bookings/bookings/bookings-writer-v2/sample-flows#force-resolution).

    Call this method to determine which standard actions are available before attempting to modify bookings. If standard actions aren't available, you may need to use force resolution to override business rules and availability validation.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/bulk/bookings/calculate_allowed_actions
    ```

    ## Body Params

    <ParamField body="bookingIds" type="string[]" required>

      List of booking IDs to calculate allowed actions for.

      Constraints: `minItems 1`.

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkCalculateAllowedActionsResult[]">

            </ResponseField>

        </ResponseField>

        <ResponseField name="item" type="AllowedActions">

          Booking entity.

          <Expandable title="item properties">

            <ResponseField name="cancel" type="boolean">

              Whether canceling the booking is allowed.

            </ResponseField>

            <ResponseField name="reschedule" type="boolean">

              Whether rescheduling the booking is allowed.

            </ResponseField>

          </Expandable>

        </ResponseField>
