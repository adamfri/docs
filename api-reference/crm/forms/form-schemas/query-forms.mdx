    Retrieves a list of form schemas given the provided paging, filtering, and sorting.

    You must specify a namespace equality filter. For example, `"namespace:{"$eq":"<your_namespace>"}`.

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$in`, `$ne`, `$nin` | Sort: `ASC`, `DESC` |
    | `namespace` | `$eq` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$gt`, `$gte`, `$in`, `$lt`, `$lte`, `$ne`, `$nin` | Sort: `ASC`, `DESC` |
    | `updatedDate` | `$eq`, `$gt`, `$gte`, `$in`, `$lt`, `$lte`, `$ne`, `$nin` | Sort: `ASC`, `DESC` |
    | `properties.name` | `$eq`, `$ne`, `$nin`, `$in`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `name` | `$eq`, `$ne`, `$nin`, `$in`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `properties.disabled` | `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `enabled` | `$eq`, `$ne` | Sort: `ASC`, `DESC` |
    | `fields.validation.predefined.format` | `$hasSome` | None |
    | `tags.privateTags.tagIds` | `$hasAll`, `$hasSome` | Sort: `ASC`, `DESC` |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/forms/query
    ```

    ## Body Params

    <ParamField body="query" type="CursorQuery">

      WQL expression. You must specify a namespace equality filter. For example, `"namespace:{"$eq":"<your_namespace>"}`.

      <Expandable title="query properties">

        <ParamField body="filter" type="object">

          Filter object in the following format:
          `"filter" : {`
          "fieldName1": "value1",
          "fieldName2":&#123;"$operator":"value2"&#125;
          &#125;``
          Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"sortField1","order":"ASC"},{"fieldName":"sortField2","order":"DESC"}]`

          Constraints: `maxItems 3`.

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

              Constraints: `maxLength 512`.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

            <ParamField body="cursorPaging" type="CursorPaging">

              Cursor token pointing to a page of results. Not used in the first request. Following requests use the cursor token and not `filter` or `sort`.

      Constraints: `maxLength 50`.

    </ParamField>
