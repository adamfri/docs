Gives the information about all guests who bought tickets to an event or who RSVP'ed. Read more about Event Guests in this [overview](https://dev.wix.com/docs/rest/business-solutions/events/event-guests/introduction).

## SDK package

```bash
npm install @wix/events
```

Import the `guests` namespace from `@wix/events`.
