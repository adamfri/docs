    <div className="wix-ref">

    Creates a new comment and publishes it.

    The `appId`, `contextId`, and `resourceId` are all required and associate the created comment with the specific
    resource it responds to. See **Integrations** in the Comments introduction for a list of integrated scopes for these fields.

    If the created comment is a direct response to another comment, the `commentId` of the parent comment should be passed
    as `parentComment.id` in this comment's request. See **Terminology** in the Comments introduction for additional information on parent comments and replies.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.MANAGE.COMMENTS">Manage Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/comments/v1/comments
    ```

    ## Body Params

    <ParamField body="comment" type="Comment">

      Comment to create.

      See the [Comment Object](/api-reference/crm/community/feedback-moderation/comments/comments/comment-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="comment" type="Comment">

      Created comment.

      See the [Comment Object](/api-reference/crm/community/feedback-moderation/comments/comments/comment-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INVALID_CAPTCHA` | Captcha validation failed. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Comment Created | `wix.comments.v2.comment_created` | Triggered when a comment is created. |
    | Resource Comment Count Changed | `wix.comments.v2.comment_resource_comment_count_changed` | Triggered when the total number of comments has changed in a resource. |
