title: "Like Object"
description: "A like represents a positive reaction to blog content."

---

A like represents a positive reaction to blog content.

Likes are associated with specific blog content using their FQDN and entity ID,
allowing likes to be created for various types of blog content such as posts or comments.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Like ID.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the like was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="entityId" type="string">

      ID of the specific blog content being liked, such as a blog post or comment.

    </ResponseField>

    <ResponseField name="fqdn" type="string">

      Fully qualified domain name that identifies the type of blog content being liked. For example, `wix.blog.v3.post` for blog posts.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
          "like": {
            "id": "87654321-4321-4321-4321-210987654321",
            "createdDate": "2024-01-15T10:30:00.000Z",
            "entityId": "12345678-1234-1234-1234-123456789012",
            "fqdn": "wix.blog.v3.post"
          }
        }
      ```

    </CodeGroup>
