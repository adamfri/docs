    Queries service plugin configurations with filtering and sorting support.

    Query Functions SPI Configurations runs with these defaults, which you can override:
    - `createdDate` is sorted in `DESC` order
    - `paging.limit` is `50`
    - `paging.offset` is `0`

    For field support for filters and sorting, see [Supported Filters and Sorting](https://dev.wix.com/docs/api-reference/business-management/functions/function-spi-configurations/supported-filters-and-sorting).

    To learn how to query service plugin configurations, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/get-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `functionId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions
