    Creates a gift card with an initial value and optional recipient notification settings.

    Gift card codes can be custom-provided or automatically generated by the system.
    When notification info is included, the gift card can be sent via email to recipients with personalized messaging.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gift-cards/v1/gift-cards
    ```

    ## Body Params

    <ParamField body="giftCard" type="GiftCard" required>

      Gift card to create.

      See the [Gift Card Object](/api-reference/business-solutions/gift-cards/gift-cards/gift-card-object) for this object's fields.

    </ParamField>

    <ParamField body="idempotencyKey" type="string">

      Unique identifier to prevent duplicate gift card creation.
      Use this to safely retry gift card creation requests.

    </ParamField>

    ## Response Object

    <ResponseField name="giftCard" type="GiftCard">

      Created gift card with the full code visible and unobfuscated.

      The full code isn't retrievable with the other methods.

      See the [Gift Card Object](/api-reference/business-solutions/gift-cards/gift-cards/gift-card-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
