    Creates a new checkout based on the checkout template.

    Before using this method, you must have a checkout template available. Create a checkout template with Create Checkout Template.

    The customer can be directed to the new checkout using the checkout's `checkoutUrl`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkout-templates/{checkoutTemplateId}/create-checkout-from-template
    ```

    ## Path Params

    <ParamField path="checkoutTemplateId" type="string" required>

      ID of the checkout template to use to create a checkout from.

    </ParamField>

    ## Body Params

    <ParamField body="siteId" type="string" required>

      ID of the site associated with the checkout template.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutId" type="string">

      ID of the created checkout.

      Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="checkoutUrl" type="string">

      URL of the created checkout page.

    </ResponseField>

    <ResponseField name="purchaseFlowId" type="string">

      Persistent ID that correlates between the various eCommerce elements: cart, checkout, and order.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_CREATE_CHECKOUT_FROM_INACTIVE_TEMPLATE` | Checkout template is inactive. |
    | `428` | `FAILED_PRECONDITION` | `ITEM_NOT_FOUND_IN_CATALOG` | One or more items in the checkout template could not be found in the catalog. |
    | `428` | `FAILED_PRECONDITION` | `INSUFFICIENT_INVENTORY` | One or more items in the checkout template have insufficient inventory. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Checkout Template Used | `wix.ecom.v1.checkout_template_used` | Triggered when a checkout is created from a checkout template. |

    </div>
