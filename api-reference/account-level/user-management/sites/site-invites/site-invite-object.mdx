title: "Site Invite Object"
description: "This service manages all invites related actions (site and account level)"

---

This service manages all invites related actions (site and account level)

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Invite ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="siteId" type="string">

      Site ID the user is invited to as a collaborator.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="email" type="string">

      Email address where the invite was sent.

      Constraints: `format EMAIL`.

    </ResponseField>

    <ResponseField name="policyIds" type="string[]">

      Role IDs included in the invite.

    </ResponseField>

    <ResponseField name="inviterId" type="string" deprecated>

      Deprecated. Use `inviterAccountId`.

      **Read-only.** **Deprecated.**

    </ResponseField>

    <ResponseField name="status" type="string">

      Invite Status.

      Supported values:
      - **Pending:** The invite has been sent and is valid, waiting for the user's response.
      - **Used:** The invite has been accepted.
      - **Deleted:** The invite has been deleted or revoked.
      - **Declined:** The user declined the invite.
      - **Expired:** The invite has expired without being accepted.

      **Supported values:**

      - `Pending`
      - `Used`
      - `Deleted`
      - `Declined`
      - `Expired`

    </ResponseField>

    <ResponseField name="acceptLink" type="string">

      Link to accept the invite.

    </ResponseField>

    <ResponseField name="inviterAccountId" type="string">

      Inviting account ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="acceptedByAccountId" type="string">

      Account ID that accepted the invite. Populated only once the invite is accepted.

      **Read-only.**

    </ResponseField>

    <ResponseField name="dateCreated" type="datetime">

      Date the invite was created.

    </ResponseField>

    <ResponseField name="staffId" type="string">

      User's Wix Bookings staff ID, if relevant.

    </ResponseField>

    <ResponseField name="expirationDate" type="datetime">

      Invite expiration date

    </ResponseField>

    <ResponseField name="locationIds" type="string[]">

      Location ids included in the invite

      **Read-only.** Constraints: `format GUID`, `maxItems 20`.

    </ResponseField>

    <ResponseField name="callerCapabilities" type="string[]">

      A set of capability keys representing the actions that the caller is allowed
      to perform on this specific contributor. This field is calculated based on the
      identity of the request sender and may differ between callers.

      Constraints: `maxLength 20`, `maxItems 20`.

    </ResponseField>

  </Tab>
