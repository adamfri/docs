Triggered when a schedule is cloned.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.calendar.v3.schedule_cloned` |
| Package | `@wix/calendar` |
| Permissions | `Read Calendar - Including PI`, `Manage Calendars`, `Manage Bookings`, `Read Bookings - Including Participants`, `Manage Bookings - all permissions`, `Read bookings calendar - including participants` |

## Examples

  import { schedules } from '@wix/calendar';

  schedules.onScheduleCloned((event) => {
      // handle your event here
  });

      },

      // handle your event here
  });
