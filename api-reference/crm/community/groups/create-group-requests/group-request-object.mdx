---
title: "Group Request Object"
description: "A group request is a site member's request for a site admin to create a group."
icon: "cube"
---

A group request is a site member's request for a site admin to create a group.
You can approve, reject, or view group requests.
Learn more about [Wix Groups](https://support.wix.com/en/article/wix-groups-about-groups).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Group request ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="group" type="Group">

      Group requested for creation.

      <Expandable title="group properties">

        <ResponseField name="id" type="string">

          Group ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="slug" type="string">

          A unique part of a group's URL, for example `https:/example.com/groups/slug`.

        </ResponseField>

        <ResponseField name="privacyStatus" type="string">

          Group privacy status.

          **Supported values:**

          - `PUBLIC` — Anyone can see the group and its content. Anyone can join the group.
          - `PRIVATE` — Anyone can see the group, but only members can see its content. New members must submit a `Join Group Request`.
          - `SECRET` — Only admins and members can see the group. New members can only be added by other members.

        </ResponseField>

        <ResponseField name="name" type="string">

          Group name.

        </ResponseField>

        <ResponseField name="description" type="string">

          Group description in [DraftJS](https://draftjs.org) format.

        </ResponseField>

        <ResponseField name="teaser" type="string">

          Group teaser.

        </ResponseField>

        <ResponseField name="memberTitle" type="string">

          What group members are called, for example `Coworkers`, `Friends`, or `Students`.

        </ResponseField>

        <ResponseField name="coverImage" type="CoverImage">

          Cover image. You cannot upload your own cover image.

          <Expandable title="coverImage properties">

            <ResponseField name="image" type="Image">

              Cover image.

              <Expandable title="image properties">

                <ResponseField name="mediaId" type="string">

                  Image ID (for internal use).

                </ResponseField>

                <ResponseField name="width" type="integer">

                  Image width.

                </ResponseField>

                <ResponseField name="height" type="integer">

                  Image height.

                </ResponseField>

                <ResponseField name="preset" type="boolean">

                  Indicates pre-configured/auto-generated images (from templates, client generated).

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="position" type="Position">

              Position of the corner of the cover image (or logo).

              <Expandable title="position properties">

                <ResponseField name="x" type="float">

                  horizontal coordinate

                </ResponseField>

                <ResponseField name="y" type="float">

                  vertical coordinate

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="mobilePosition" type="Position">

              Position of the corner of the cover image (or logo) for mobile browser.

              <Expandable title="mobilePosition properties">

                <ResponseField name="x" type="float">

                  horizontal coordinate

                </ResponseField>

                <ResponseField name="y" type="float">

                  vertical coordinate

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="altText" type="string">

              Alternative text is typically a relatively short phrase that describes what the image depicts.

              The alternative text is used:
              + If the browser cannot display the image.
              + If the user is utilizing a screen reader.
              + By search engines to understand what images are on your site.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="settings" type="GroupSettings">

          Group specific settings.

          These settings can also be found in [a site's Dashboard](https://www.wix.com/my-account/site-selector/?buttonText=Select%20Site&title=Select%20a%20Site&autoSelectOnSingleSite=true&actionUrl=https:%2F%2Fwww.wix.com%2Fdashboard%2F%7B%7BmetaSiteId%7D%7D%2Fwix-groups/settings?).

          <Expandable title="settings properties">

            <ResponseField name="membersCanInvite" type="boolean">

              __Deprecated.__ Use `allowedToInviteMembers` instead.
              Whether regular members are permitted to invite new members.
              If `false`, only admins can invite members. Defaults to `true`.

            </ResponseField>

            <ResponseField name="membersCanApprove" type="boolean">

              __Deprecated.__ Use `allowedToApproveJoinRequests` instead.
              Whether all group members are permitted to approve join group requests.
              If `false`, member approval is limited to the admins.

            </ResponseField>

            <ResponseField name="welcomeMemberPostEnabled" type="boolean">

              Whether a daily post about new members is enabled.

            </ResponseField>

            <ResponseField name="groupDetailsChangedPostEnabled" type="boolean">

              Whether an automatic post about changing the group details is enabled.

            </ResponseField>

            <ResponseField name="showMemberList" type="boolean">

              Whether all members can see the full member list.

            </ResponseField>

            <ResponseField name="allowedToInviteMembers" type="string">

              Determines who can invite members to the group

              **Supported values:**

              - `OWNER_AND_ADMINS`
              - `OWNER`
              - `ALL_MEMBERS`

            </ResponseField>

            <ResponseField name="allowedToApproveJoinRequests" type="string">

              Determines who can approve member join requests to the group

              **Supported values:**

              - `OWNER_AND_ADMINS`
              - `OWNER`
              - `ALL_MEMBERS`

            </ResponseField>

            <ResponseField name="aiSpamProtectionEnabled" type="boolean">

              Whether AI spam protection is enabled for post creation in the group.
              If not explicitly set, the default behavior is 'true' (enabled).

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="membersCount" type="integer">

          Total count of current group members.

          **Read-only.**

        </ResponseField>

        <ResponseField name="ownerId" type="string">

          Group owner.

          **Read-only.**

        </ResponseField>

        <ResponseField name="createdDate" type="datetime">

          Group creation date and time.

          **Read-only.**

        </ResponseField>

        <ResponseField name="updatedDate" type="datetime">

          Date and time of the latest group update.

          **Read-only.**

        </ResponseField>

        <ResponseField name="lastActivityDate" type="datetime">

          Date and time of the most recent group activity, for example a post or comment.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="status" type="string">

      Status of group request.

      **Supported values:**

      - `PENDING` — Pending group request.
      - `APPROVED` — Approved group request.
      - `REJECTED` — Rejected group request.
      - `CANCELED` — Canceled group request.

    </ResponseField>

    <ResponseField name="requestDetails" type="RequestDetails">

      Group request details.

      <Expandable title="requestDetails properties">

        <ResponseField name="rejectionReason" type="string">

          Reason the request has been rejected.

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
