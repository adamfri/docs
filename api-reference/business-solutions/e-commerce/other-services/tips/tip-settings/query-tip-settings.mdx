    Retrieves a list of up to 100 tip settings, given the provided paging, filtering, and sorting.

    Query Tip Settings runs with these defaults, which you can override:
    - `cursorPaging.limit` is `50`.
    - Sorted by `id` in ascending order.

    Use [UTC time](https://en.wikipedia.org/wiki/Coordinated_Universal_Time)
    when setting a filter for dates.

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/api/rest/getting-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/api/rest/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `locationId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `paymentTerminalId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `default` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `allowCustomerTip` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `allowBusinessTipAtPayment` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `allowEditDistribution` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `allowCustomAmount` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
    | `tipType` | `$eq`, `$ne`, `$in`, `$exists` | Sort: `ASC`, `DESC` |
