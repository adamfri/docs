Triggered when a new data sharing policy is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.data.v1.data_sharing_policy_created` |
| Package | `@wix/data` |
| Permissions | `Manage Data Collection Sharing` |
