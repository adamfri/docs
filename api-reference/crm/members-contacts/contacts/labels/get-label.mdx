    <div className="wix-ref">

    Retrieves a label by the specified label key.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-LABELS">Manage Contact Labels</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/contacts/v4/labels/{key}
    ```

    ## Path Params

    <ParamField path="key" type="string" required>

      Label key.

      `key` is generated when the label is created.
      It can't be modified, even if `displayName` is updated.

    </ParamField>

    ## Query Params

    <ParamField query="language" type="string">

      Language for localization.
      2-letter language code in [ISO 639-1 alpha-2](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) format.

    </ParamField>

    ## Response Object

    <ResponseField name="label" type="ContactLabel">

      The specified label.

      See the [Label Object](/api-reference/crm/members-contacts/contacts/labels/label-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
