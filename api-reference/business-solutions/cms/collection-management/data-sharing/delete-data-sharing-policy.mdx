<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a data sharing policy and disconnects all associated connections.

    <Warning>

    When you delete a sharing policy, all target sites connected to the shared collection using this policy immediately lose access to the collection and its data. This can cause code in the target sites to break.

    </Warning>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DATA.MANAGE_COLLECTION_SHARING">Manage Data Collection Sharing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/data/v1/data-collection-sharing/policies/{dataSharingPolicyId}
    ```

    ## Path Params

    <ParamField path="dataSharingPolicyId" type="string" required>

      Data sharing policy ID.

    </ParamField>

    ## Response Object

    Returns `DeleteDataSharingPolicyResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `WDE0154` | Data sharing policy not found. Verify the policy ID is correct and is owned by the current site. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Data Sharing Policy Deleted | `wix.data.v1.data_sharing_policy_deleted` | Triggered when a data sharing policy is deleted. |

    </div>
