    Creates a new review request.

    A review request is a request sent to a customer to solicit a review for a specific order or specific items.
    This method requires either the `order.id` or `items.catalogItemId`.

    You must pass either an order ID or at least 1 item ID:
    + **Order ID only:** The review request automatically includes the 5 most expensive items from the order.
    + **Item IDs only:** The review request includes only the specified items.
    + **Order ID and item IDs:** The review request includes the specified items from the given order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_REVIEWS.MANAGE-REVIEW_REQUESTS">Manage Review Requests</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v2/review-requests
    ```

    ## Body Params

    <ParamField body="reviewRequest" type="ReviewRequest" required>

      Review request to create.

      See the [Review Request Object](/api-reference/crm/community/feedback-moderation/reviews/review-requests/review-request-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="reviewRequest" type="ReviewRequest">

      Created review request.

      See the [Review Request Object](/api-reference/crm/community/feedback-moderation/reviews/review-requests/review-request-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `INITIATOR_IDENTITY_NOT_SUPPORTED` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method isn't supported for creating review requests. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_IS_EMPTY` | Order has no items. |
    | `428` | `FAILED_PRECONDITION` | `ORDER_NOT_FOUND` | Couldn't find the order. |
    | `400` | `INVALID_ARGUMENT` | `EITHER_ORDER_OR_ITEMS_REQUIRED` | Must specify either the `order.id` or at least 1 `items.catalogItemId`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
