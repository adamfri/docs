---
title: "Schedule Item Object"
description: "Schedule item describes the schedule within an event."
icon: "cube"
---

Schedule item describes the schedule within an event. Each event may contain multiple schedule items.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Schedule item ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="hidden" type="boolean">

      Whether a schedule item is hidden from guests.

    </ResponseField>

    <ResponseField name="name" type="string">

      Schedule item name.

      Constraints: `maxLength 120`.

    </ResponseField>

    <ResponseField name="timeSlot" type="TimeInterval">

      Time slot of a schedule item.

      <Expandable title="timeSlot properties">

        <ResponseField name="start" type="datetime">

          Start of the time slot interval, inclusive.

        </ResponseField>

        <ResponseField name="end" type="datetime">

          End of the time slot interval, exclusive.

        </ResponseField>

        <ResponseField name="timeZoneId" type="string">

          Time zone ID in TZ database format, e.g., `"EST"`, `"America/Los_Angeles"`.
          Defaults to `"Etc/UTC"` when not set.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="description" type="string">

      Rich text schedule item description.

      Constraints: `maxLength 10000`.

    </ResponseField>

    <ResponseField name="stageName" type="string">

      Stage or room name in which a session takes place.

      Constraints: `maxLength 30`.

    </ResponseField>

    <ResponseField name="tags" type="string[]">

      Schedule item tags. Used to organize the items by a theme.

      Constraints: `minLength 1`, `maxLength 30`, `maxItems 5`.

    </ResponseField>

    <ResponseField name="status" type="string">

      Schedule item status.

      **Supported values:**

      - `SCHEDULED` — Item is scheduled for a future date.
      - `CANCELED` — Item is canceled.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the schedule item was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the schedule item was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="eventId" type="string">

      Event ID to which the schedule item belongs.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="draft" type="boolean">

      Whether the schedule item is a draft.

      **Read-only.**

    </ResponseField>

  </Tab>
