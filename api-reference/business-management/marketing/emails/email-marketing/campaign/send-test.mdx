    <div className="wix-ref">

    Sends a test email to a specified address, allowing you to preview what the campaign will look like for recipients.

    There is a rate limit per campaign to prevent excessive test sends.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/test
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      Campaign ID.

    </ParamField>

    ## Body Params

    <ParamField body="emailSubject" type="string">

      Email subject line for the test email. Defaults to the campaign's subject line if not provided.

    </ParamField>

    <ParamField body="toEmailAddress" type="string" required>

      Recipient email address.

      Constraints: `format EMAIL`.

    </ParamField>

    ## Response Object

    Returns `SendTestResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
