    <div className="wix-ref">

    Adds a country code to the main phone of multiple contacts that match the provided filter. Works asynchronously.

    A contact's main phone is changed only if adding the country code produces a valid phone number. Otherwise, the contact is left unchanged.

    To check the status of the bulk update, pass the returned `jobId` to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-CONTACTS">Manage Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/bulk/contacts/update-phone-country-code-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      A filter for the contacts that the country code will be applied to.

      Example:
      `{ "filter": { "name.last": "Smith" } }`

    </ParamField>

    <ParamField body="search" type="SearchDetails">

      Free text to match in searchable fields for the contacts that the country code will be applied to.

      <Expandable title="search properties">

        <ParamField body="mode" type="string">

          How separate search terms in `expression` are combined.

          **Supported values:**

          - `OR` — Any of the search terms must be present.
          - `AND` — All search terms must be present.

        </ParamField>

        <ParamField body="expression" type="string">

          Search term or expression.

        </ParamField>

        <ParamField body="fields" type="string[]">

          Fields to search in. If empty, searches all searchable fields. Use dot notation to specify the JSON path.

          Constraints: `maxLength 200`, `maxItems 20`.

        </ParamField>

        <ParamField body="fuzzy" type="boolean">

          Whether to use fuzzy search, which allows typos using a managed proximity algorithm.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="countryCode" type="string" required>

      [ISO-3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) country code to apply.

      Applied only to contacts whose phone number isn't already in [ITU E.164 international](https://www.itu.int/rec/T-REC-E.164/) format. If the phone number still can't be converted to E.164 format after applying the country code, that contact fails with `PHONE_CANNOT_BE_FIXED_WITH_COUNTRY_CODE`.

      Constraints: `format COUNTRY`.

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID. Pass this ID to [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job) to retrieve the status of the asynchronous operation.

      Constraints: `format GUID`.

    </ResponseField>
