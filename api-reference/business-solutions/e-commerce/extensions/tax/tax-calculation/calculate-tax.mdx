    Calculates tax for the provided line items.

    Tax is calculated for each line item based on the tax region
    that corresponds to the address provided in `lineItems.addressIndex` and the tax group in `taxGroupId`. If no tax region is found for
    the line item's address then no tax will be calculated for this line item.

    The tax is calculated by a tax calculator app installed on the site.
    Call List Tax Calculators to see which tax calculators are available.
    To provide your own tax calculations, use the Tax Calculation service plugin.

    The breakdown of calculated tax returned, includes:
    + `taxSummary`: The overall total tax calculated.
    + `taxSummary.aggregatedTaxBreakdown`: The total tax calculated for each jurisdiction.
    + `lineItemTaxDetails.taxSummary`: The total tax calculated for each line item.
    + `lineItemTaxDetails.taxBreakdown`: The tax calculated for each line item in each jurisdiction.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/calculate-tax
    ```

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_LINE_ITEM_ADDRESS_INDEX` | The `addressIndex` value in one or more line items doesn't reference a valid address in the `addresses` array. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_TAXABLE_ADDRESS` | No taxable address was provided for tax calculation. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_COUNTRY_IN_ADDRESS` | The `country` field is missing in one or more addresses. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_SUBDIVISION_IN_ADDRESS` | The `subdivision` field is missing in one or more addresses. |
