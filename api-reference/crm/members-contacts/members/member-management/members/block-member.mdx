    Blocks a member.

    A blocked member can't log in to members-only pages.

    To block multiple members, call [Bulk Block Members](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/bulk-block-members).

    To unblock a member, call [Approve Member](https://dev.wix.com/docs/api-reference/crm/members-contacts/members/member-management/members/approve-member).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/members/{id}/block
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      ID of a member to block.

    </ParamField>

    ## Response Object

    <ResponseField name="member" type="Member">

      Blocked member.

      See the [Member Object](/api-reference/crm/members-contacts/members/member-management/members/member-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `MEMBER_SELF_BLOCK_FORBIDDEN` | Member can't block themselves. |
    | `400` | `INVALID_ARGUMENT` | `OWNER_MEMBER_BLOCK_FORBIDDEN` | Site owner can't be blocked. |
    | `428` | `FAILED_PRECONDITION` | `ACTIVE_SUBSCRIPTION_MEMBER_BLOCK_FORBIDDEN` | Member with active subscriptions can't be blocked. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
