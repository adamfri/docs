    Retrieves AI-generated search theme suggestions for a Performance Max campaign.
    Responses may take up to 60 seconds. `textSuggestionInfo.languageCode` is required.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_serverless/pa-google/v1/search-theme-suggestions
    ```

    ## Body Params

    <ParamField body="landingPageUrl" type="string">

      Public URL of the campaign landing page, used to analyze content and suggest relevant themes.

    </ParamField>

    <ParamField body="textSuggestionInfo" type="TextSuggestionInfo" required>

      Language and exclusion settings for search theme generation.

      <Expandable title="textSuggestionInfo properties">

        <ParamField body="languageCode" type="string" required>

          ISO 639-1 two-letter language code specifying the language in which text assets should be generated.

        </ParamField>

        <ParamField body="excludeTexts" type="string[]">

          Text strings to exclude from the generated suggestions, such as existing headlines or descriptions already in use.

          Constraints: `maxLength 1000`, `maxItems 100`.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="searchThemes" type="string[]">

      AI-generated search theme strings for use in a Performance Max campaign.

      Constraints: `maxLength 1000`, `maxItems 25`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
