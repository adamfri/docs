## Query Gift Cards

The following table shows field support for filters and sorting for the [Query Gift Cards](fallback::https://dev.wix.com/docs/rest/business-solutions/gift-cards/gift-cards/query-gift-cards) method:

| Field            | Supported Filters                                                         | Sortable |
|------------------|---------------------------------------------------------------------------|----------|
| `_id`            | `$eq`, `$ne`, `$exists`, `$in`, `$startsWith`, `$gt`, `$lt`, `$le`, `$ge` | Sortable |
| `_createdDate`   | `$eq`, `$ne`, `$exists`, `$in`, `$lt`, `$le`, `$gt`, `$ge`                | Sortable |
| `_updatedDate`   | `$eq`, `$ne`, `$exists`, `$in`, `$lt`, `$le`, `$gt`, `$ge`                | Sortable |
| `code`           | `$eq`, `$ne`, `$exists`, `$in`, `$startsWith`, `$gt`, `$lt`, `$le`, `$ge` | Sortable |
| `codeSuffix`     | `$eq`, `$ne`, `$exists`, `$in`, `$startsWith`, `$gt`, `$lt`, `$le`, `$ge` | Sortable |
| `balance`        | `$eq`, `$ne`, `$exists`, `$in`                                            | Sortable |
| `expirationDate` | `$eq`, `$ne`, `$exists`, `$in`, `$lt`, `$le`, `$gt`, `$ge`                | Sortable |
| `initialValue`   | `$eq`, `$ne`, `$exists`, `$in`                                            | Sortable |

## Search Gift Cards

The following table shows field support for search, aggregation, sorting, and filtering for the [Search Gift Cards](fallback::https://dev.wix.com/docs/rest/business-solutions/gift-cards/gift-cards/search-gift-cards) method:

| Field            | Capabilities                | Filters                                                                         | Sortable |
|------------------|-----------------------------|---------------------------------------------------------------------------------|----------|
| `_id`            | Search: ✗<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`, `$begins`, `$gt`, `$lt`, `$lte`, `$gte` | Sortable |
| `_createdDate`   | Search: ✗<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`, `$lt`, `$lte`, `$gt`, `$gte`            | Sortable |
| `_updatedDate`   | Search: ✗<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`, `$lt`, `$lte`, `$gt`, `$gte`            | Sortable |
| `code`           | Search: ✓<br /> Aggregate: ✗ | `$eq`, `$ne`, `$exists`, `$in`, `$any`, `$begins`, `$gt`, `$lt`, `$lte`, `$gte` | Sortable |
| `codeSuffix`     | Search: ✓<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`, `$begins`, `$gt`, `$lt`, `$lte`, `$gte` | Sortable |
| `balance`        | Search: ✗<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`                                          | Sortable |
| `expirationDate` | Search: ✗<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`, `$lt`, `$lte`, `$gt`, `$gte`            | Sortable |
| `initialValue`   | Search: ✗<br /> Aggregate: ✓ | `$eq`, `$ne`, `$exists`, `$in`, `$any`                                          | Sortable |
