    Retrieves a list of items based on the provided filtering, sorting, and paging preferences.

    See [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language) for more information about handling data queries.

    ## Endpoint

    ```http
    POST /v3/items/query
    ```

    ## Body Params

    <ParamField body="collectionId" type="string" required>

      ID of the collection to query.

    </ParamField>

    <ParamField body="query" type="QueryV2" required>

      Query preferences. See [API Query Language](https://dev.wix.com/api/rest/getting-started/api-query-language) for information about handling data queries.

      <Expandable title="query properties">

        <ParamField body="filter" type="object" required>

          Filter object in the following format:
          `"filter" : {`
          "fieldName1": "value1",
          "fieldName2":&#123;"$operator":"value2"&#125;
          &#125;``
          Example of operators: `$eq`, `$ne`, `$lt`, `$lte`, `$gt`, `$gte`, `$in`, `$hasSome`, `$hasAll`, `$startsWith`, `$contains`

          **Note:** Your endpoint must properly handle requests with filtering preferences that adhere to Wix Data data types. For example, a query request that includes filtering by a field whose type is Date and Time would contain an object in the following format: `"someDateAndTimeFieldKey": { "$date": "YYYY-MM-DDTHH:mm:ss.sssZ"}`. Learn more about [data types in Wix Data](https://dev.wix.com/docs/rest/business-solutions/cms/data-items/data-types-in-wix-data).

        </ParamField>

        <ParamField body="sort" type="Sorting[]">

          Sort object in the following format:
          `[{"fieldName":"sortField1","order":"ASC"},{"fieldName":"sortField2","order":"DESC"}]`

          <Expandable title="sort properties">

            <ParamField body="fieldName" type="string">

              Name of the field to sort by.

            </ParamField>

            <ParamField body="order" type="string">

              Sort order.

              **Supported values:**

              - `ASC`
              - `DESC`

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="fields" type="string[]">

          Array of projected fields. A list of specific field names to return.

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="pagingMethod" type="pagingMethod">

          pagingMethod

          <Expandable title="pagingMethod properties">

            <ParamField body="paging" type="Paging">

              Paging options to limit and skip the number of items. Paging mode is defined when the collection is created.

              _Nested structure omitted for brevity — see the `Paging` object._

            </ParamField>

            <ParamField body="cursorPaging" type="CursorPaging">

              Cursor token pointing to a page of results. Not used in the first request. Following requests use the cursor token and not `filter` or `sort`. Paging mode is defined when the collection is created.

              _Nested structure omitted for brevity — see the `CursorPaging` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="includeReferencedItems" type="ReferencedItemToInclude[]">

      Fields for which to include the full referenced items in the query's results, rather than just their IDs.
      Returned items are sorted in ascending order by the creation date of the reference.
      If the field being querried is a multi-reference field and the array is empty, the response does not return any items.

      <Expandable title="includeReferencedItems properties">

        <ParamField body="fieldKey" type="string">

          Field name in the referencing collection.

        </ParamField>

        <ParamField body="limit" type="integer">

          Maximum number of referenced items to return.

        </ParamField>

        <ParamField body="filter" type="object">

          Filter criteria to specify which items to include in the response.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="consistentRead" type="boolean" required>

      Whether to retrieve data from the primary database instance. This decreases performance but ensures data retrieved is up-to-date even immediately after an update. Applicable if the external database is eventually consistent.

    </ParamField>

    <ParamField body="returnTotalCount" type="boolean" required>

      When `true`, the query response must include the total number of items that match the query.

    </ParamField>

    ## Response Object

    <ResponseField name="items" type="object[]">

      Retrieved items.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="PagingMetadataV2">

      Pagination information.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="cursors" type="Cursors">

          Cursors to navigate through the result pages using `next` and `prev`. Returned if cursor paging is used.

          <Expandable title="cursors properties">

            <ResponseField name="next" type="string">

              Cursor pointing to next page in the list of results.

            </ResponseField>

            <ResponseField name="prev" type="string">

              Cursor pointing to previous page in the list of results.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `ITEM_ALREADY_EXISTS` | There is already an item with this ID. |
    | `404` | `NOT_FOUND` | `ITEM_NOT_FOUND` | Couldn't find the item. |
    | `409` | `ALREADY_EXISTS` | `COLLECTION_ALREADY_EXISTS` | There is already a collection with this ID. |
    | `404` | `NOT_FOUND` | `COLLECTION_NOT_FOUND` | Couldn't find the collection. |
    | `409` | `ALREADY_EXISTS` | `REFERENCE_ALREADY_EXISTS` | There is already a reference between these items. |
    | `404` | `NOT_FOUND` | `REFERENCE_NOT_FOUND` | Couldn't find the reference. |
    | `400` | `INVALID_ARGUMENT` | `VALIDATION_ERROR` | 1 or more field values are invalid. |
    | `400` | `INVALID_ARGUMENT` | `COLLECTION_CHANGE_NOT_SUPPORTED` | The collection field can't be changed. |
    | `400` | `INVALID_ARGUMENT` | `BAD_REQUEST` | The request is invalid. |
