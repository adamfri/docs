    Asynchronously updates tags on multiple plans that match the provided filter criteria.

    Specify which tags to assign and which tags to unassign. A tag that appears in both the list to
    assign and the list to unassign is assigned. Tags that don't exist are ignored. An empty filter
    updates all plans.

    To check the status of the bulk update, pass the returned `jobId` to
    [Get Async Job](https://dev.wix.com/docs/api-reference/business-management/async-job/get-async-job).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.MANAGE-PLANS">Manage Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/pricing-plans/v3/bulk/plans/update-tags-by-filter
    ```

    <ParamField body="filter" type="object" required>

      WQL filter that selects plans whose tags to update. An empty filter selects all plans.

    </ParamField>

    <ParamField body="assignTags" type="Tags">

      Tags to assign to the plans.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

            <ParamField body="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="Tags">

      Tags to unassign from the plans.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

    ## Examples

    Assigns a public tag to every public plan. Returns the ID of the asynchronous job that updates the tags.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/pricing-plans/v3/bulk/plans/update-tags-by-filter' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "filter": {
          "visibility": "PUBLIC"
        },
        "assignTags": {
          "publicTags": {
            "tagIds": [
              "vN3xQ"
            ]
          }
        }
      }'
      ```

      ```json Response
      {
        "jobId": "a1b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d"
      ```
