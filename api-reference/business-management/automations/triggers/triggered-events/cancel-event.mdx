    Cancels any remaining actions for a trigger and external entity.

    Events are not cancelable by default.
    To make an event cancelable,
    you must first pass an `externalEntityId`
    and the applicable `triggerKey` to [Report Event](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/triggered-events/report-event).
    When you call Cancel Event with the same `externalEntityId` and `triggerKey`,
    the event is canceled,
    as are all other events that share the `externalEntityId` and `triggerKey`.
    See
    [Reporting and Canceling Events](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/triggered-events/reporting-and-canceling-events)
    for more information.

    To cancel events for multiple external entities in a single call, call [Bulk Cancel Event](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/triggered-events/bulk-cancel-event).

    > You cannot try out this endpoint because
    > it can be called only by the app that created the specified `triggerKey`.
    > So please ignore the **Try It Out** button.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/automations/v1/events/cancel
    ```

    ## Body Params

    <ParamField body="externalEntityId" type="string" required>

      ID of the related resource in GUID format.
      For example, `fc81a355-3429-50fc-a4c7-def486e828f3`.

      Typically, this ID is defined in your system,
      but you can also use any Wix resource GUID,
      such as contact ID, member ID, or invoice ID.
      See
      [Choose the right `externalEntityId`](https://dev.wix.com/docs/rest/business-management/automations/triggered-events/reporting-and-canceling-events#choose-the-right-externalentityid)
      for more information.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="triggerKey" type="string" required>

      Trigger key whose event you want to cancel.
      For example, `form_submitted` or `invoice_due`.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    ## Response Object

    Returns `CancelEventResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
