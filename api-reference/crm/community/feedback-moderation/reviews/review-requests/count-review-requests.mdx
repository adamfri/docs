  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves the number of review requests that match a specified filter.

    If a filter isn't passed in the request, the method returns the count of all review requests.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_REVIEWS.READ-REVIEW_REQUESTS">Read Review Requests</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v2/review-requests/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object in the following format:
      `"filter" : {`
      "fieldName1": "value1",
      "fieldName2":&#123;"$operator":"value2"&#125;
      &#125;``

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of review requests.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_TO_COUNT` | Number of review requests exceeds the server's limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    <CodeGroup>

      ```bash Request
      curl -X POST \
        'https://www.wixapis.com/reviews/v2/review-requests/count'  \
        -H 'Content-Type: application/json;charset=UTF-8' \
        -H 'Authorization: <AUTH>' \
        -d '{
              "filter":
                {
                  "namespace": "stores"
                }
            }'
      ```

      ```json Response
      {
        "count": 1
      }
      ```

    </CodeGroup>

    </div>
