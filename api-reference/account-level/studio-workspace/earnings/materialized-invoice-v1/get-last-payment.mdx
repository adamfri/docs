    Retrieves the partner's most recent payment.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix user or by using an account level API key.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PARTNERS.REVSHARE">SCOPE.PARTNERS.REVSHARE</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    <Note>This is an account-level method.</Note>

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/partners/revshare/v1/materialized-invoices/last-payment
    ```

    ## Response Object

    <ResponseField name="lastPayment" type="LastPayment">

      The partner's most recent payment.

      <Expandable title="lastPayment properties">

        <ResponseField name="id" type="string">

          Last payment ID.

          **Read-only.**

        </ResponseField>

        <ResponseField name="refCode" type="string">

          Reference code for the payment.

          A reference code is the identifier assigned by the payment handler (Tipalti).

        </ResponseField>

        <ResponseField name="payeeId" type="string">

          ID of the payee receiving the payment.

          Constraints: `minLength 1`, `maxLength 64`.

        </ResponseField>

        <ResponseField name="date" type="datetime">

          Estimated date and time the payee will receive the funds.

        </ResponseField>

        <ResponseField name="amountInUsd" type="number">

          Amount submitted for payment, in USD.

        </ResponseField>

        <ResponseField name="paid" type="boolean">

          Whether the payment succeeded.

        </ResponseField>

        <ResponseField name="rejectionReason" type="string">

          Reason the payment failed, when applicable. Deprecated. Use `rejection` instead.

        </ResponseField>

        <ResponseField name="rejection" type="Rejection">

          Details of why the payment was rejected, when applicable.

          <Expandable title="rejection properties">

            <ResponseField name="issueType" type="string">

              Category of the rejection issue.

              **Supported values:**

              - `UNKNOWN_ISSUE_TYPE` — Issue type not specified.
              - `GENERAL` — A general issue not covered by a more specific category.
              - `PAYOUT_METHOD` — An issue with the partner's configured payout method.
              - `PAYEE_BANK` — An issue with the payee's bank details.

            </ResponseField>

            <ResponseField name="reason" type="string">

              Human-readable explanation of why the payment was rejected.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
