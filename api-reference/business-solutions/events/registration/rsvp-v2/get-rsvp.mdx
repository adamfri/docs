    Retrieves an RSVP by ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.READ-GUEST-LIST">Read Event Tickets and Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/events/v2/rsvps/{rsvpId}
    ```

    ## Path Params

    <ParamField path="rsvpId" type="string" required>

      ID of the RSVP to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `DETAILS` — Returns `createdDate`, `updatedDate`, `firstName`, `lastName`, `totalGuests`, `guests`.
      - `FORM` — Returns `form`.
      - `CONTACT_DETAILS` — Returns `email`.

    </ParamField>

    ## Response Object

    <ResponseField name="rsvp" type="Rsvp">

      Retrieved RSVP.

      See the [Rsvp Object](/api-reference/business-solutions/events/registration/rsvp-v2/rsvp-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
