    Updates a report.

    Each time the report is updated, `revision` increments by 1. The current `revision` must be passed when updating the report. This ensures you're working with the latest report and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_REPORTS.MANAGE-REPORTS">Manage Reports</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/reports/v2/reports/{report.id}
    ```

    ## Path Params

    <ParamField path="report.id" type="string" required>

      Report ID.

    </ParamField>

    ## Body Params

    <ParamField body="report" type="Report" required>

      Report to update.

      See the [Report Object](/api-reference/crm/community/feedback-moderation/reports-v2/report-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="report" type="Report">

      Updated report.

      See the [Report Object](/api-reference/crm/community/feedback-moderation/reports-v2/report-object) for this object's fields.

    </ResponseField>

    ## Errors

              - `DRUGS` — Entity is reported for mentioning drugs.
