This article presents a possible use case and a corresponding sample flow that you can support. This can be a helpful jumping off point as you plan your implementation.

## Import site members

You can create site members without a member signing up directly on a site. This allows Wix users to create members in bulk or to import members from another site.

To import site members:

1. Create a list of members or retrieve the list from an external site. Structure the list as an array of `member` objects, ensuring that each `member` has a login email address. For example:

    ```json
    {
      "member": {
        "loginEmail": "member_needs_an@email.com",
        "contact": { ... },
        "profile": { ... }
      }
    }
    ```

1. Iterate through the array, calling [Create Member](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/members/create-member) for each member. To comply with rate limits, ensure that requests are sent at least 1 second apart.

1. Call [Send Set Password Email](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/member-authentication/send-set-password-email). You can trigger the email immediately after creating the member or allow the Wix user to send it later. If the email is sent later, you should iterate through an array of member email addresses, calling [Send Set Password Email](fallback::https://dev.wix.com/docs/rest/crm/members-contacts/members/member-authentication/send-set-password-email) for each email address.
