    <div className="wix-ref">

    Continues the registration process when a member is required to verify an email address
    using a verification code received by email.

    Email verification is required when the registering member is already listed as a contact.

    Typically, after a successful verification, you generate and use member tokens for the
    registered member so that subsequent API calls are called as part of a member session.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/iam/verification/v1/auth/verify
    ```

    ## Body Params

    <ParamField body="code" type="string" required>

      The code to verify.

      Constraints: `minLength 6`, `maxLength 6`.

    </ParamField>

    <ParamField body="stateToken" type="string" required>

      A state token representing the `REQUIRE_EMAIL_VERIFICATION` state.

    </ParamField>

    ## Response Object

    <ResponseField name="state" type="string">

      Current state of the login or registration process.

      **Supported values:**

      - `UNKNOWN_STATE` — Initial unknown state.
      - `SUCCESS` — Login completed successfully.
      - `REQUIRE_OWNER_APPROVAL` — Member needs the owner to approve their registration.
      - `REQUIRE_EMAIL_VERIFICATION` — Member needs to verify their email.
      - `STATUS_CHECK` — The `status` is not one that prevents the member logging in, meaning it's not `OFFLINE`, `BLOCKED`, or `DELETED`.
      - `REQUIRE_MISSING_FIELDS` — Member is missing fields that are marked as required on the site's signup form, and needs to complete them to finish registration.

    </ResponseField>

    <ResponseField name="sessionToken" type="string">

      Session token. If `state` is not `SUCCESS`, this field is undefined.

    </ResponseField>
