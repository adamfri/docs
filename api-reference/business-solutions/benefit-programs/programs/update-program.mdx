    Updates a program.

    Each time the program definition is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the program definition.
    This ensures you're working with the latest program definition
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/benefit-programs/v1/programs/{program.id}
    ```

    ## Path Params

    <ParamField path="program.id" type="string" required>

      Program ID.

    </ParamField>

          **Read-only.**

        </ParamField>

        <ParamField body="status" type="string">

          Program status.

          **Read-only.**

          **Supported values:**

          - `ACTIVE` — Program is active.
          - `PAUSED` — Program is paused. It can be resumed.
          - `ENDED` — Program has ended. It can't be resumed.
          - `PROVISIONING` — Program is being activated for the first time. This status exists for a short time during processing.
          - `PAUSING` — Program is being paused. This status exists for a short time during processing.
          - `RESUMING` — Program is being re-activated after being paused. This status exists for a short time during processing.
          - `ENDING` — Program is being ended. This status exists for a short time during processing.

        </ParamField>
