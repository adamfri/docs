    Generates a receipt document for a specific payment on an invoice. Requires the `paymentId` of a confirmed payment on the invoice.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INVOICES.MANAGE">Manage Invoices</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/invoices/v4/invoices/{invoiceId}/generate-receipt
    ```

    ## Path Params

    <ParamField path="invoiceId" type="string" required>

      Invoice ID.

    </ParamField>

    ## Body Params

    <ParamField body="paymentId" type="string" required>

      Payment ID.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    <ResponseField name="receiptId" type="string">

      Generated receipt ID.

      Constraints: `format GUID`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
