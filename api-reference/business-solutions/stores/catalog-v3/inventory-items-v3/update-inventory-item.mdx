    Updates an inventory item.

    Each time the inventory item is updated, `revision` increments by 1.
    The current `revision` must be passed when updating the inventory item.
    This ensures you're working with the latest inventory item and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.INVENTORY_ITEM_WRITE">Inventory write in v3 catalog</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/stores/v3/inventory-items/{inventoryItem.id}
    ```

    ## Path Params

    <ParamField path="inventoryItem.id" type="string" required>

      Inventory item ID.

    </ParamField>

    ## Body Params

    <ParamField body="inventoryItem" type="InventoryItem" required>

      Inventory item to update.

      See the [Inventory Item Object](/api-reference/business-solutions/stores/catalog-v3/inventory-items-v3/inventory-item-object) for this object's fields.

    </ParamField>

    <ParamField body="reason" type="string">

      Reason for update.

      **Supported values:**

      - `ORDER`
      - `MANUAL`
      - `REVERT_INVENTORY_CHANGE`

    </ParamField>

    ## Response Object

    <ResponseField name="inventoryItem" type="InventoryItem">

      Updated inventory item.

      See the [Inventory Item Object](/api-reference/business-solutions/stores/catalog-v3/inventory-items-v3/inventory-item-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `REQUESTED_QUANTITY_MUST_BE_NON_NEGATIVE_DECREASING` | New `quantity` would result in invalid inventory state. For negative inventory, quantity can only increase. If preorders exist, quantity can't drop below the preorder counter. |
    | `428` | `FAILED_PRECONDITION` | `PRE_ORDER_VALIDATION` | Preorder enabled for a digital product or subscription product. Preorder isn't supported for these product types. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

              When set to `true`, the item is marked as available for sale without tracking exact quantities.
              When set to `false`, the item is marked as out of stock.
