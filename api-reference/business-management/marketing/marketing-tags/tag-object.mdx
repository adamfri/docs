Add marketing tags to your site

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Marketing tag ID.

      **Read-only.** Constraints: `format GUID`.

    </ResponseField>

    <ResponseField name="type" type="string">

      Marketing tag type.

      **Read-only.**

      **Supported values:**

      - `GOOGLE_ADS`
      - `GOOGLE_ANALYTICS`
      - `YANDEX_METRICA`
      - `FACEBOOK_PIXEL`
      - `GOOGLE_TAG_MANAGER`
      - `TIKTOK_PIXEL`
      - `GOOGLE_TAG_MANAGER_CONSENT_MODE`
      - `GOOGLE_ANALYTICS_CONSENT_MODE`

    </ResponseField>

    <ResponseField name="enabled" type="boolean">

      Whether this tag is enabled.
      Defaults to `true`.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "cab0a9e1-b2aa-41b6-991a-9bd40ab15e62",
        "type": "FACEBOOK_PIXEL",
        "enabled": true,
        "facebookPixel": {
          "domain": "some-domain.com",
          "trackingId": "111111111111111"
        }
      }
      ```

    </CodeGroup>
