    Retrieves the draft version of each of an app's components.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DEVCENTER.MANAGE_COMPONENTS">Manage Dev Center App Extensions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/components/v1/components/app/{appId}
    ```

    ## Path Params

    <ParamField path="appId" type="string" required>

      App ID.

    </ParamField>

    ## Query Params

    <ParamField query="consistent" type="boolean">

      Whether to return consistent results for read-after-write operations.

    </ParamField>

    ## Response Object

    <ResponseField name="components" type="Component[]">

      Draft components.

      See the [Component Object](/api-reference/app-management/app-extensions/app-extensions/component-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
