    Creates a product in the Marketplace.

    Products must include all required fields for the specified types.
    The first image in `media.items` becomes the main image.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/products
    ```

    ## Body Params

    <ParamField body="product" type="Product" required>

      Product to create. Must include all required fields for the specified product types.

      See the [Product Object](/api-reference/business-solutions/suppliers-hub/products/product-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="product" type="Product">

      Created product with assigned ID and read-only fields populated.

      See the [Product Object](/api-reference/business-solutions/suppliers-hub/products/product-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Product Created | `wix.suppliershub.marketplace_product.v1.product_created` | Triggered when a product is created. |
