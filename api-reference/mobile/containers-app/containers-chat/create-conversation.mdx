    Creates a conversation for a project.

    The conversation is created with `ACTIVE` status and the title `new chat`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="containers:chat:v1:conversation:create_conversation">containers:chat:v1:conversation:create_conversation</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/containers/chat/v1/conversations
    ```

    ## Body Params

    <ParamField body="conversation" type="Conversation" required>

      Conversation to create.

      See the [Conversation Object](/api-reference/mobile/containers-app/containers-chat/conversation-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="conversation" type="Conversation">

      Created conversation.

      See the [Conversation Object](/api-reference/mobile/containers-app/containers-chat/conversation-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
