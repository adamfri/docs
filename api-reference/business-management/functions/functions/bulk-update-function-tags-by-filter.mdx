    <div className="wix-ref">

    Asynchronously update tags on multiple functions.
    An empty filter updates all functions.
    A tag that appears both the list to assign and the list to unassign tags, will be assigned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/functions/v1/bulk/functions/update-tags-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter.

    </ParamField>

    <ParamField body="assignTags" type="Tags" required>

      List of tags to assign.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, typically restricted from site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="publicTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="Tags">

      List of tags to unassign.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, typically restricted from site members and visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

          Tags that are exposed to anyone with access to the entity, including site members and visitors.

          <Expandable title="publicTags properties">

            <ParamField body="tagIds" type="string[]">

    </ParamField>
