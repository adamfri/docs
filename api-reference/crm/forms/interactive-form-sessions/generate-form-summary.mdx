    Generates an AI summary of a form's structure and purpose in natural language, based on the form's fields and configuration, of max 255 characters.

    The summary describes what the form collects and its intended use case,
    useful for accessibility, previews, and AI-powered form discovery.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/ai/v1/interactive-form-sessions/generate-form-summary
    ```

              Identification for the field, describing its purpose. For example, `TEXT_INPUT` or `CONTACTS_EMAIL`.

              Set this to the known value for the kind of field you're creating.
              An unrecognized value, such as a custom string or a GUID, is dropped rather than rejected: the request still succeeds, but the field doesn't appear in the response's `formFields`, and neither the field nor its submitted values appear in the Wix dashboard.

              Several fields share a general-purpose `componentType`, so `identifier` is often the only value that distinguishes them.
              For example, both a short answer field and a long answer field use the `TEXT_INPUT` component, and are told apart by their `TEXT_INPUT` and `TEXT_AREA` identifiers.

              For the full list of known values, see [About Form Fields](https://dev.wix.com/docs/api-reference/crm/forms/form-schemas/about-form-fields).

              - `UNKNOWN_FIELD_TYPE` — Unknown field type.
              - `INPUT` — Input field that collects data from users.
