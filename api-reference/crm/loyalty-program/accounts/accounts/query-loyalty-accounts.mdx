    Retrieves a list of loyalty accounts, given the provided paging, filtering, and sorting.
    Query Loyalty Accounts runs with these defaults, which you can override:
    - `createdDate` is sorted in `ASC` order
    - `paging.limit` is `100`
    - `paging.offset` is `0`
    To learn about working with _Query_ methods, see [API Query Language](https://dev.wix.com/docs/rest/articles/get-started/api-query-language).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `contactId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `memberId` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
    | `points.balance` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `points.earned` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `points.adjusted` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `points.redeemed` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `points.expired` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `createdDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `lastActivityDate` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` | Sort: `ASC`, `DESC` |
    | `tier.id` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` | Sort: `ASC`, `DESC` |
