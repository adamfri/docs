    <div className="wix-ref">

    Removes a single item from multiple categories.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CATEGORIES.CATEGORY_ITEM_WRITE">Category item write</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/categories/v1/bulk/categories/remove-item
    ```

    ## Body Params

    <ParamField body="item" type="ItemReference" required>

      Item to remove.

      <Expandable title="item properties">

        <ParamField body="catalogItemId" type="string" required>

          ID of the item within the catalog.

          For Wix Stores, this is the product ID from the [Catalog V3 Products API](https://dev.wix.com/docs/api-reference/business-solutions/stores/catalog-v3/products-v3/introduction).

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

        <ParamField body="appId" type="string" required>

          ID of the Wix app providing the catalog.

          Currently, only Wix Stores is supported. Use `"215238eb-22a5-4c36-9e7b-e7c08025e04e"` for all Wix Stores products.

          Constraints: `minLength 1`, `maxLength 36`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="categoryIds" type="string[]" required>

      IDs of categories from which to remove the item.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="treeReference" type="TreeReference" required>

      Category tree reference details.

      <Expandable title="treeReference properties">

        <ParamField body="appNamespace" type="string" required>

          Namespace of the app whose catalog this category tree belongs to.

          Currently, only `"@wix/stores"` is supported.

          Constraints: `minLength 4`, `maxLength 150`.

        </ParamField>

        <ParamField body="treeKey" type="string">

          Key to differentiate between multiple trees managed by the same app.

          For Wix Stores, pass `null` or omit this field, as each store has only one category tree.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkItemToCategoriesResult[]">

      Items removed by bulk action.

      Constraints: `minItems 1`, `maxItems 100`.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Bulk action metadata for category.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Bulk action metadata.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `403` | `PERMISSION_DENIED` | `MANAGED_CATEGORY_OPERATION_NOT_ALLOWED` | One or more categories are managed by a specific app. Only that app can modify items in those categories. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:

    | --- | --- | --- |
