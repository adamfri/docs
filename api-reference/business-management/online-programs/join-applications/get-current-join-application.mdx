    Retrieves the calling member's join application for a program.

    The member is taken from the caller's identity, so you don't specify a member. Returns a `NOT_FOUND` error if the member has no application for the program.

    To retrieve any member's join application by ID, call [Get Join Application](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/get-join-application).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/online-programs/participants/v3/join-applications/current/{programId}
    ```

    ## Path Params

    <ParamField path="programId" type="string" required>

      ID of the program to retrieve the calling member's join application for.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Retrieved join application. A member has at most one join application per program.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `NOT_FOUND` |  |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
