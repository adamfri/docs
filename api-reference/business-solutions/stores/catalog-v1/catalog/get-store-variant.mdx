    Retrieves a store variant with the provided ID.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-PRODUCTS">Read Products</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/stores/v1/variants/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Store variant ID. Comprised of the `productId` and the `variantId`, separated by a hyphen. For example, `{productId}-{variantId}`.

    </ParamField>

    ## Response Object

    <ResponseField name="variant" type="StoreVariant">

      The requested store variant.

      <Expandable title="variant properties">

        <ResponseField name="id" type="string">

        <ResponseField name="variantId" type="string">

          Variant ID.

          Constraints: `format GUID`.

        <ResponseField name="productId" type="string">

          Product ID.

        </ResponseField>

        <ResponseField name="variantName" type="string">

          Variant name.

          Constraints: `minLength 1`, `maxLength 80`.

        </ResponseField>

        <ResponseField name="productName" type="string">

          Product name.

          Constraints: `minLength 1`, `maxLength 80`.

        </ResponseField>

          Whether the variant is managed or represents a product.

        </ResponseField>

        <ResponseField name="sku" type="string">

          Variant SKU (stock keeping unit).

          Constraints: `maxLength 40`.

        </ResponseField>

        <ResponseField name="stock" type="VariantStock">

          Variant inventory status.

          <Expandable title="stock properties">

            <ResponseField name="trackQuantity" type="boolean">

              Whether inventory is being tracked.

            <ResponseField name="quantity" type="integer">

            <ResponseField name="key" type="string" />

        </ResponseField>

          Collections that include this variant.

        </ResponseField>

        <ResponseField name="media" type="PlatformMedia">

          </Expandable>

        </ResponseField>
