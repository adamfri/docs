    Updates multiple donation campaigns in a single request.

    Each update increments the campaign's `revision` by 1. To prevent conflicts, you must provide the current `revision` for each campaign in the request.

    You can update campaign settings like payment options, goals, and frequencies while maintaining existing donation history.

    To update a single donation campaign, use [Update Donation Campaign](https://dev.wix.com/docs/rest/business-solutions/donations/donation-campaigns/update-donation-campaign).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DONATIONS.MANAGE-CAMPAIGNS">Manage Donation Campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/donation-campaigns/v2/bulk/donation-campaigns/update
    ```

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `500` | `INTERNAL` | `SITE_CURRENCY_UNAVAILABLE` | Site currency settings are temporarily unavailable. Try again later. |
    | `400` | `INVALID_ARGUMENT` | `NO_PAYMENT_DEFINITION` | Either `customAmountEnabled` must be set to `true` or at least one amount must be provided in `predefinedDonationAmounts`. |
    | `400` | `INVALID_ARGUMENT` | `NON_POSITIVE_CAMPAIGN_GOAL_AMOUNT` | The `campaignGoal.targetAmount` must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_CUSTOM_AMOUNT_RANGE` | The `customAmountOptions.maximum` must be greater than `customAmountOptions.minimum`. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATE_PREDEFINED_AMOUNTS` | The `predefinedDonationAmounts` array contains duplicate amounts. |
    | `400` | `INVALID_ARGUMENT` | `NON_POSITIVE_PREDEFINED_AMOUNT` | All amounts in `predefinedDonationAmounts` must be greater than 0. |
    | `400` | `INVALID_ARGUMENT` | `EMPTY_CAMPAIGN_NAME` | Campaign `name` can't be empty. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
