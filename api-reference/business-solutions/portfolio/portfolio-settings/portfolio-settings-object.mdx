---
title: "Portfolio Settings Object"
description: "The Portfolio Settings object in the Wix Portfolio Settings API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="revision" type="integer">

      Revision number. Increments by 1 each time the portfolio settings object is updated. To prevent conflicting changes, the existing revision must be passed when updating the portfolio settings object.

      **Read-only.**

    </ResponseField>

    <ResponseField name="projectItemSettings" type="ProjectItemSettings">

      Portfolio's project item settings.

      <Expandable title="projectItemSettings properties">

        <ResponseField name="addItemDirection" type="string">

          The direction in which to add new project items to a gallery. Default: `GALLERY_START`

          **Supported values:**

          - `GALLERY_START` — Add new project items to the beginning of the gallery.
          - `GALLERY_END` — Add new project items to the end of the gallery.

        </ResponseField>

        <ResponseField name="defaultItemName" type="string">

          Default title assigned to a project item if no title is provided. Default: `FILE_NAME`

          **Supported values:**

          - `FILE_NAME` — File name assigned as the title.
          - `EMPTY` — No title assigned.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="mediaSettings" type="MediaSettings">

      Portfolio's media settings.

      <Expandable title="mediaSettings properties">

        <ResponseField name="folderId" type="string">

          ID of the folder containing the media.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the portfolio settings were created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the portfolio settings were updated.

      **Read-only.**

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "portfolioSettings": {
          "revision": 5,
          "projectItemSettings": {
            "addItemDirection": "GALLERY_END",
            "defaultItemName": "FILE_NAME"
          },
          "mediaSettings": {
            "folderId": "5f6197ab-a4b4-426d-b1fb-02603e24c0be"
          },
          "createdDate": "2024-07-31T12:00:00Z",
          "updatedDate": "2024-10-27T09:30:00Z"
        }
      }
      ```

    </CodeGroup>
