When a guest responds to a RSVP **Registration Form** then a new RSVP 
is created *and a confirmation email is sent*.

RSVP registration settings can be configured in Business Manager.
RSVP options can be Yes only or Yes and No. 

Limiting the number of guests is optional. Once the guest list is
full the registration is closed, unless Waitlist is enabled.

*If user RSVP to Waitlist, he will get a email once 
additional space in event is available*

## RSVP management

* [Create RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/create-rsvp): Creates RSVP and associates a contact of the site.
The *Form response* has to be sent according to *Registration Form* input fields when creating RSVP or at checkout.
If site member is creating a RSVP the site member id is associated.  
To change existing RSVP - use dashboard.
* [List RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/list-rsvp): Lists RSVPs with a basic filter support.
* [Query RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/query-rsvp): Lists RSVPs with a support of queries.
* [Get RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/get-rsvp): Gets a single RSVP.
* [Update RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/update-rsvp): Updates RSVP.
* [Delete RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/delete-rsvp): Deletes RSVP.
* [Check in RSVP](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/check-in-rsvp): Checks in RSVP.
* [Delete RSVP Check In](fallback::https://dev.wix.com/docs/rest/business-solutions/events/rsvp/delete-rsvp-check-in): Deletes RSVP check-in.
