The Disputes API is a tool for managing payment disputes that arise when customers contest charges with their payment service provider (PSP) or bank. You can use it to track dispute statuses, submit evidence against disputes, and accept disputes.

Disputes may occur for reasons including fraud, service issues, or billing errors, so it's essential for you to address them promptly to maintain an optimal financial experience.

With the Disputes API you can:
- Retrieve dispute details and monitor their lifecycle status.
- Defend disputes by submitting evidence.
- Accept liability for disputes when appropriate.
- Monitor dispute events through event subscriptions.

## Related APIs
To manage disputes effectively, you'll also need to use the [Dispute Evidence Documents API](fallback::https://dev.wix.com/docs/api-reference/business-management/payments/disputes/dispute-evidence-documents/introduction) and the [Dispute History Records API](fallback::https://dev.wix.com/docs/api-reference/business-management/payments/disputes/dispute-history-records/introduction). Learn more about [dispute management](fallback::https://dev.wix.com/docs/api-reference/business-management/payments/disputes/about-dispute-management).
