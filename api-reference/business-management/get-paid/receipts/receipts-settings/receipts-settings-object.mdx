Receipts Settings for all Receipts.

<Tabs>

  <Tab title="REST">

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the receipt settings are updated. To prevent conflicting changes, the current revision must be passed when updating the receipt settings.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the receipt settings were created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the receipt settings were last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="numbering" type="Numbering">

      Receipt numbering settings.

      <Expandable title="numbering properties">

        <ResponseField name="prefix" type="string">

          Receipt prefix that will be displayed before the receipt number.

        </ResponseField>

        <ResponseField name="nextNumber" type="integer">

          Next receipt number. Used during receipt creation to ensure unique and consecutive numbering.

        </ResponseField>

        <ResponseField name="suffix" type="string">

          Receipt suffix that will be displayed after the receipt number.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the receipt settings.

      Extended fields must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
