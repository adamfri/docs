    Retrieves the number of item variants that match a specified filter.

    If a filter isn't passed in the request, the endpoint returns the count of all item variants.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/restaurants/menus/v1/variants/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter for counting variants.

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Counted variants.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `TOO_MANY_TO_COUNT` | Number of variants exceeds the server's limit. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Gets the total count of variants matching specified filters

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/restaurants/menus/item-variants/v1/variants/count' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
          "filter": {
              "name": "Small"
          }
      }'
      ```

      ```json Response
      {
        "count": 2
      }
      ```

    </CodeGroup>

    </div>

    </div>
