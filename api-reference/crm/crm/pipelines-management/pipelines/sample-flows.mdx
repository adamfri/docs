This article presents possible use cases and corresponding sample flows that you can support using both the Pipelines and Cards APIs. These flows provide useful starting points as you plan your implementation.

## Track deals for small sales teams

You can create a simple deal tracking system that helps small businesses organize their sales opportunities in one place.

To track deals for a small sales team:

1. Call [Create Pipeline](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/pipelines/create-pipeline) to create a sales pipeline. 

2. Call [Create Card](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/create-card) to add deals with customer information:

3. Call [Move Card](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/move-card) to move deals through stages as they progress.

4. Call [Query Cards](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/query-cards) to view active deals.

5. Call [Search Cards](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/search-cards) with aggregations to generate basic sales reports.

## Create event pipeline for event planning

You can create an event planning system that helps event planners track their events from initial planning through completion. 

To create and manage an event pipeline:

1. Call [Create Pipeline](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/pipelines/create-pipeline) to create an event planning pipeline. For example, you can create stages like "Event Planning", "Vendors Booked", "Final Details", and "Event Complete" as the final stage. 

2. Call [Create Card](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/create-card) to create event cards with client and vendor contacts. 

3. Call [Bulk Update Card Tags](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/bulk-update-card-tags) to organize multiple events by type.

4. Call [Query Cards](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/query-cards) to monitor upcoming events and deadlines.

## Integrate pipeline data with external CRM systems

You can synchronize pipeline and card data with external CRM systems by using events and API queries.

To integrate pipeline data with external CRM systems:

1. Listen for events, for example:
  - [Card Created](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/create-card)
  - [Card Moved](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/card-moved)
  - [Card Updated](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/card-updated)
  - [Pipeline Updated](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/pipelines/pipeline-updated)

2. When an event occurs, sync the data to your external CRM:

3. Call [Query Pipelines](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/pipelines/query-pipelines) and [Search Cards](fallback::https://dev.wix.com/docs/api-reference/crm/crm/pipelines-management/cards/search-cards) to perform regular synchronization checks.
