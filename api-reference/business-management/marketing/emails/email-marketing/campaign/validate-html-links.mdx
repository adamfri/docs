  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Validates links that are inside the provided HTML. This method automatically takes out links from the HTML block and validates them. Call this method when you want to check whether the link complies with the abuse rules and can be used in a campaign.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaign-validation/validate-html-links
    ```

    ## Body Params

    <ParamField body="html" type="string" required>

      HTML string with links.

      Constraints: `maxLength 2000000`.

    </ParamField>

    ## Response Object

    <ResponseField name="blacklistedLinks" type="string[]">

      Non-valid links.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Check all links in an HTML string against the email marketing blocklist.

    <CodeGroup>

      ```bash Request
      curl -X POST 'https://www.wixapis.com/email-marketing/v1/campaign-validation/validate-html-links' \
      -H 'Content-Type: application/json' \
      -H 'Authorization: <AUTH>' \
      -d '{
            "html": "<a href=\"https://www.wix.com\">Learn more</a><a href=\"https://support.wix.com\">Get help</a>"
          }'
      ```

      ```json Response
      {
        "blacklistedLinks": []
      }
      ```

    </CodeGroup>

    </div>
