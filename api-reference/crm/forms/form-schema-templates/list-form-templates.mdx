    Retrieves the form templates in a namespace, optionally filtered by template IDs.

    Templates are returned only for apps installed on the site, together with templates from apps made
    by Wix. If the app that owns the namespace isn't installed on the site, the response is empty.

    Returned template content, such as field labels, is served in the language resolved from the request.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.VIEW-FORM">View Forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/form-templates/v2/templates
    ```

    ## Query Params

    <ParamField query="namespace" type="string" required>

      Namespace whose templates to retrieve. A namespace groups the templates and forms that belong to
      the same app or use case, such as a bookings or pricing plans checkout. The value is defined by
      the app that owns the templates in the app dashboard.

      Constraints: `minLength 10`, `maxLength 50`.

    </ParamField>

    <ParamField query="templateIds" type="string[]">

      IDs of the specific templates to retrieve within the namespace. When omitted, all templates in
      the namespace are returned.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="templates" type="FormTemplate[]">

      Retrieved form templates. All matching templates are returned in a single response.

      See the [Form Template Object](/api-reference/crm/forms/form-schema-templates/form-template-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
