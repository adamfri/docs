    Retrieves dynamic output schemas for multiple actions in a single request.

    To retrieve the dynamic output schema for a single action, call [Get Action Dynamic Output Schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/action-catalog/get-action-dynamic-output-schema).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions/bulk/dynamic-output-schema
    ```

    ## Body Params

    <ParamField body="actionsInputMappings" type="ActionInputMappings[]" required>

      List of actions to retrieve dynamic output schemas for.

      Constraints: `minItems 1`, `maxItems 20`.

      <Expandable title="actionsInputMappings properties">

        <ParamField body="appId" type="string">

          ID of the app that defines the action.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="actionKey" type="string">

          Action key.

          Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

          Constraints: `minLength 5`, `maxLength 50`.

        </ParamField>

        <ParamField body="actionId" type="string">

          Identifier for the action in the automation. Used to match each output schema to its corresponding action in the response.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="inputMapping" type="object">

          Action input mapping as defined in the [action's input schema](https://dev.wix.com/docs/api-reference/business-management/automations/actions/the-action-input-schema).

          The input mapping must include all parameters specified in the action's input schema's `required` array, and can include any other parameters from the schema.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkActionOutputSchemaResult[]">

      Retrieved dynamic output schemas, one per requested action.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Item metadata.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="outputSchema" type="object">

          A [JSON schema](https://json-schema.org/) containing the action's output schema.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Bulk action metadata.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>
