    Retrieves a list of `serviceOptionsAndVariants` objects, given the provided
    paging, filtering, and sorting.

    Query Service Options And Variants* runs with these defaults, which you can override:

    - `id` sorted in `ASC` order.
    - `cursorPaging.limit` set to `100`.

    To learn about working with _Query_ endpoints, see
    [API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language),
    [Sorting and Paging](https://dev.wix.com/docs/rest/articles/getting-started/sorting-and-paging),
    and [Field Projection](https://dev.wix.com/docs/rest/articles/getting-started/field-projection).

    | Property | Filters | Sort |
    | --- | --- | --- |
    | `id` | `$eq`, `$in`, `$ne` | Sort: `ASC`, `DESC` |
    | `serviceId` | `$eq`, `$in`, `$ne` | Sort: `ASC`, `DESC` |
    | `options.values` | `$exists` | None |
    | `variants.values` | `$exists` | None |
    | `options.values.id` | `$hasAll`, `$hasSome` | None |
    | `options.values.type` | `$hasAll`, `$hasSome` | None |
    | `variants.values.price.value` | `$hasAll`, `$hasSome` | None |
    | `variants.values.price.currency` | `$hasAll`, `$hasSome` | None |
    | `variants.values.choices.custom` | `$hasAll`, `$hasSome` | None |
    | `variants.values.choices.optionId` | `$hasAll`, `$hasSome` | None |

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v1/serviceOptionsAndVariants/query
    ```
