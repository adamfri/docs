    <div className="wix-ref">

    Calculates the cart from its current state (line items, discounts, delivery method, and more) and returns a detailed summary, including subtotal, delivery costs, taxes, fees, and total price.

    Line item discounts are already applied to the cart.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.ECOM.WRITE-CARTS-V2_LIMITED">Write Carts V2 (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v2/carts/{cartId}/calculate
    ```

    ## Path Params

    <ParamField path="cartId" type="string" required>

      Cart ID.

    </ParamField>

    ## Body Params

    <ParamField body="refreshCart" type="boolean">

      Whether to retrieve the latest item prices, discounts, and inventory data from the catalogs before calculating the cart.

      Default: `false`.

    </ParamField>

    Calculates the cart from its current state (line items, discounts, delivery method, and more) and returns a detailed summary, including subtotal, delivery costs, taxes, fees, and total price.

    Line item discounts are already applied to the cart.
