    Deletes multiple products permanently in a single request. Supports partial success.

    Each result includes an `itemMetadata` object indicating success or failure with error details.
    When handling failures, distinguish between validation errors which shouldn't be retried,
    and transient errors which can be retried. Only retry failed items, not the entire batch.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.SUPPLIERS_HUB.WRITE_MARKETPLACE">Write Marketplace</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/suppliers-hub/v1/bulk/products/delete
    ```

    ## Body Params

    <ParamField body="productIds" type="string[]" required>

      Product IDs to delete.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>
