Returns a list of up to 100 products, given the provided paging, sorting and filtering.
See [Stores Pagination](https://dev.wix.com/api/rest/wix-stores/pagination) for more information.

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-STORES.READ-PRODUCTS">Read Products</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`, `MEMBER`, `VISITOR`.

## Endpoint

```http
POST https://www.wixapis.com/stores/v1/products/query
```
