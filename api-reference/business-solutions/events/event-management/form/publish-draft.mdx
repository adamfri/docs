    Publishes the draft form.

    > Note: After deprecation this method will return the existing form. All changes made to the form, such as Add Control, Update Control, Delete Control will automatically trigger form publishing.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-EVENTS">Manage Events</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v1/events/{eventId}/form/publish
    ```

    ## Path Params

    <ParamField path="eventId" type="string" required>

      Event ID to which the form belongs.

    </ParamField>

    ## Response Object

    <ResponseField name="form" type="Form">

      Event form.

      See the [Form Object](/api-reference/business-solutions/events/event-management/form/form-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Form Event Updated | `wix.events.events.EventUpdated` | Triggered when a form is updated or published. |

    </div>
