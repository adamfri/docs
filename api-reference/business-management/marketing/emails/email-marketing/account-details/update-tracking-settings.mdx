    <div className="wix-ref">

    Updates a site's email tracking settings.

    Tracking settings apply to the whole site, so they affect every email sent from it, including email marketing campaigns, automation emails, and triggered emails. This method is the only way to change tracking settings, and the updated values are returned in `accountDetails.trackingSettings` when you call [Get Account Details](https://dev.wix.com/docs/api-reference/business-management/marketing/emails/email-marketing/account-details/get-account-details).

    Disabling opens tracking doesn't affect click tracking, and it doesn't delete opens already recorded. Campaign statistics continue to report opens collected before the update.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/account-details/tracking-settings/update
    ```

    ## Body Params

    <ParamField body="trackingSettings" type="TrackingSettings" required>

      Tracking settings to update.

      <Expandable title="trackingSettings properties">

        <ParamField body="opensTrackingEnabled" type="boolean" required>

          Whether email opens are tracked. When opens tracking is disabled, the tracking pixel isn't added to outgoing emails and new opens aren't recorded. Click tracking isn't affected.

          Opens tracking is enabled for a site until it's explicitly disabled.

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `UpdateTrackingSettingsResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
