The Project Items API allows you to manage a project's items. Learn more about [project items in Wix Portfolio](fallback::https://support.wix.com/en/article/wix-portfolio-adding-media-to-projects).

With the Project Items API, you can:

+ [Create](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/create-project-item), [update](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/update-project-item), and [delete](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/delete-project-item) project items. 
+ [Retrieve](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/get-project-item) or [list](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/list-project-items) project items. 
+ [Duplicate](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/duplicate-project-items) project items from one project to another project.
+ Listen for events when a project item is [created](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/project-item-created), [updated](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/project-item-updated), or [deleted](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/project-item-deleted). 

## Before you begin

It's important to note the following points before starting to code:

+ You need an existing project to create project items. If you don't already have one, call [Create Project](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/projects/create-project) to create a project, and then call [Create Project Item](fallback::https://dev.wix.com/docs/rest/business-solutions/portfolio/project-items/create-project-item) to create a project item. 
+ Project items consist of images or videos. Before you create or update a project item with a new media file, upload the media file to the [Wix Media Manager](fallback::https://support.wix.com/en/article/wix-media-about-the-media-manager) by calling the [Import File](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/import-file) method.
+ You can only use this API on sites where a Wix user has installed the [Wix Portfolio app](fallback::https://www.wix.com/app-market/web-solution/wix-portfolio?appIndex=0&collimp_id=b54d3569-fdaa-49f6-83f8-2ac6e400bd11&referralSectionName=wix%20portfolio).
