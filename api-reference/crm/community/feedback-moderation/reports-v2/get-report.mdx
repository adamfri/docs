    Retrieves a report.

    Site members and visitors can only access their own reports.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_REPORTS.READ-REPORTS">Read Reports</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/reports/v2/reports/{reportId}
    ```

    ## Path Params

    <ParamField path="reportId" type="string" required>

      ID of the report to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="report" type="Report">

      Retrieved report.

      See the [Report Object](/api-reference/crm/community/feedback-moderation/reports-v2/report-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
