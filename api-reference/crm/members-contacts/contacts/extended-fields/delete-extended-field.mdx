    Deletes an extended field.

    When an extended field is deleted,
    any contact data stored in the field is also permanently deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.MANAGE-EX-FIELDS">Manage Contact Extended Fields</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/contacts/v4/extended-fields/{key}
    ```

    ## Path Params

    <ParamField path="key" type="string" required>

      Extended field key.

    </ParamField>

    ## Response Object

    Returns `DeleteExtendedFieldResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    | Event | Type | Description |
    | --- | --- | --- |
    | Extended Field Deleted | `wix.contacts.v4.extended-field_deleted` | Triggered when an extended field is deleted. |

    </div>
