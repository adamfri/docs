    Retrieves a channel's OAuth authorization URL that a site owner opens to connect the channel.

    Use this to connect a channel without a browser popup: retrieve the URL, surface it to the site owner, and have them authorize the channel in their browser. The channel's OAuth redirect then completes the connection server-side, after which the channel becomes connected. Poll Get Long Lived Token Status until the status is `VALID` to confirm the channel is connected.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SOCIAL-POSTS">Manage Social Posts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/social-publisher/v1/{channelName}/connect-url
    ```

    ## Path Params

    <ParamField path="channelName" type="string" required>

      The social channel to connect.

    </ParamField>

    ## Response Object

    <ResponseField name="connectUrl" type="string">

      The channel's OAuth authorization URL. The site owner opens it to authorize the channel; on success the connection completes server-side and the channel becomes connected.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
