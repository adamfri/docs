    Updates tags for the specified storage items.

    Learn more about [tags](https://dev.wix.com/docs/api-reference/business-management/tags/introduction).

    <Note>

    A tag that appears in both `assignTags` and `unassignTags` is assigned.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

