## Filtering

The following table shows field support for filters for the
[participation object](fallback::https://dev.wix.com/docs/rest/business-management/calendar/participations-v3/participation-object)
in [Query Participations](fallback::https://dev.wix.com/docs/rest/business-management/calendar/participations-v3/query-participations).

| Field        | Supported Filters |
|--------------|-------------------|
| `id`         | `in`              |
| `eventId`    | `eq`, `in`        |
| `scheduleId` | `eq`, `in`        |
| `externalId` | `eq`, `in`        |

To learn about working with _Query_ endpoints in general, see
[API Query Language](https://dev.wix.com/docs/rest/articles/getting-started/api-query-language).

## Sorting

The response in [Query Participations](fallback::https://dev.wix.com/docs/rest/business-management/calendar/participations-v3/query-participations)
is always sorted by `createdDate`. The default sort order is descending.

| Field         | Order         |
|---------------|---------------|
| `createdDate` | `ASC`, `DESC` |
