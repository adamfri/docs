When sending an [email campaign](fallback::https://dev.wix.com/docs/rest/business-management/marketing/email-marketing/campaign/campaign-object), the email address to send it from must be verified in order ensure that the email reaches its destination. With the Sender Emails API, you can create and verify "from" and "reply-to" email addresses for an email campaign. Once verified, these emails are used to create and manage different senders using the [Sender Details API](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-details/introduction).

With the Sender Emails API you can:

- [Create](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/create-sender-email) and [delete](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/delete-sender-email) sender emails.
- [Get](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/get-sender-email) information about a sender email.
- [Verify](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/verify-sender-email) sender emails.

## Sender email verification flow

The following steps describe the process for verifying an email address using the Sender Emails API:

1. Call [Create Sender Email](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/create-sender-email) and specify the email address you'd like to use.
1. Call [Send Verification Code](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/send-verification-code) and check the sender email's inbox for the verification code.
1. Use the received verification code to call [Verify Sender Email](fallback::https://dev.wix.com/docs/rest/business-management/marketing/sender-emails/verify-sender-email) and verify the email address.

## Before you begin

It's important to note the following:

- The verification code is sent to the email address you specify, so ensure you have access to that inbox.
- If the verification code wasn't received, check the spam folder. If it's not there, try to send the verification email again.
- Usually, the verified email address will be used as both the "from" and "reply-to" address. However, there are cases where campaigns are sent from an authenticated address owned by Wix:
  - When a verified email uses a publicly available mailbox provider domain, such as @gmail, @yahoo, or @outlook. For example, if the email sender is `pianosinfo@gmail.com` it will appear as the "reply-to" address, while the "from" address will be something like `pianos@pb01.wixemails.com` or `pianos@wixsiteautomations.com`. This ensures that the email reaches the recipients' inbox rather than their junk folder or being rejected entirely. 
  - When the domain of the verified email address is not properly authenticated and has a strict [DMARC](fallback::https://dmarc.org/) policy configured.

## Terminology

- **Campaign:** A single, organized effort to send marketing emails to a list of recipients.
- **Sender Email:** The "sent from" email address used in email campaigns.
- **Reply-to Email:** The email address where recipients can send their replies to a marketing campaign.
