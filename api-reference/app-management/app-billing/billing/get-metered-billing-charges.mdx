<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Retrieves a preview of charges for a site's [usage-based billing](https://dev.wix.com/docs/build-apps/launch-your-app/pricing-and-billing/set-up-a-usage-based-business-model#set-up-a-usage-based-business-model).

    When you call this method, Wix triggers your app's [List Custom Charges service plugin](https://dev.wix.com/docs/api-reference/app-management/app-billing/custom-charges-service-plugin/list-charges) and returns the charges you provide. Use this method to verify that your service plugin is working correctly and returning the expected charges.

    <Note>

    This method only retrieves charge information for testing purposes. It doesn't create an invoice or charge the customer. Wix creates actual invoices by calling your List Custom Charges service plugin directly.

    </Note>

    <Note>

    This feature isn't yet available to all users. Your app can have only 1 usage-based plan and no other plans. To add a usage-based plan to your app, [submit a request to add a usage-based plan](https://www.wix.com/support-chatbot?nodeId=25a57397-ccf7-4376-8b74-48d51edf7159&referral=devRels).

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/apps/v1/metered-billing-charges
    ```

    ## Query Params

    <ParamField query="currency" type="string">

      3-letter currency code in
      [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217#Active_codes) format.

    </ParamField>

    <ParamField query="startDate" type="datetime">

      Start of the period you want to retrieve the custom charges for in
      `YYYY-MM-DDThh:mm:ss.sssZ` format.

    </ParamField>

    <ParamField query="endDate" type="datetime">

      End of the period you want to retrieve the custom charges for in
      `YYYY-MM-DDThh:mm:ss.sssZ` format.

    </ParamField>

    ## Response Object

    <ResponseField name="charges" type="Charge[]">

      List of retrieved custom charges.

      <Expandable title="charges properties">

        <ResponseField name="id" type="string">

          ID of the custom charge. The ID consists of 64 characters.

        </ResponseField>

        <ResponseField name="description" type="string">

          Description of the custom charge.

        </ResponseField>

        <ResponseField name="amount" type="string">

          Charge amount.

          Min: `0.50`

          Constraints: `format DECIMAL_VALUE`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
