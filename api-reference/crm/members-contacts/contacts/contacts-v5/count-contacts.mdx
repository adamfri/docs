    <div className="wix-ref">

    Retrieves the number of contacts that match the provided filter and search criteria.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CONTACTS.READ-CONTACTS">Read Contacts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/contacts/v5/contacts/count
    ```

    ## Body Params

    <ParamField body="filter" type="object">

      Filter object.

      Example:
      `{ "filter": { "name.last": "Smith" } }`

    </ParamField>

    <ParamField body="search" type="string">

      Plain text search for an exact match.

      Supported search properties are:

      - `name.full`
      - `email.email`
      - `phone.phone`
      - `member_info.email`
      - `member_info.profile_info.nickname`
      - `company.name`
      - `company.job_title`

      Max: 100 characters

    </ParamField>

    ## Response Object

    <ResponseField name="count" type="integer">

      Number of contacts that match the provided filter and search criteria.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>

    <div className="wix-examples">

    ## Examples

    Returns the total number of contacts matching a filter.

    <CodeGroup>

      ```bash Request
      curl -X POST \
      'https://www.wixapis.com/contacts/v5/contacts/count' \
      -H 'Authorization: <AUTH>' \
      -H 'Content-Type: application/json' \
      -d '{
        "filter": {
          "email.email": "john.doe@example.com"
        }
      }'
      ```

      ```json Response
      {
        "count": 1
      }
      ```

    </CodeGroup>
