    Retrieves a list of function types, given the provided paging, filtering, and sorting.

    Query Functions Types runs with these defaults, which you can override:
    - `paging.limit` is `50`
    - `paging.offset` is `0`

    <Note>

    Query Function Types doesn't support filters and sorting.

    </Note>

    To learn how to query functions, see [API Query Language](https://dev.wix.com/docs/api-reference/articles/get-started/api-query-language).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FUNCTIONS.MANAGE-FUNCTIONS">Manage Functions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/functions/v1/types/query
    ```
