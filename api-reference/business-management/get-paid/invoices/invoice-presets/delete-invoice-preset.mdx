    Deletes an invoice preset.

    The default invoice preset can't be deleted. To delete a preset that's currently the default, first call [Set Default Invoice Preset](#set-default-invoice-preset) to assign a different preset as the default.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">
