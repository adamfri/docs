    Updates a pool.

    Each time the pool is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the pool.
    This ensures you're working with the latest pool
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/benefit-programs/v1/pools/{pool.id}
    ```

    ## Path Params

    <ParamField path="pool.id" type="string" required>

      Pool ID.

    </ParamField>

    ## Body Params

    <ParamField body="pool" type="Pool" required>

      Pool to update.

      See the [Pool Object](/api-reference/business-solutions/benefit-programs/pools/pool-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="pool" type="Pool">

      Updated pool.

      See the [Pool Object](/api-reference/business-solutions/benefit-programs/pools/pool-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
