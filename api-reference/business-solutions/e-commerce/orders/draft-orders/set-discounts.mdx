    Applies or unapplies discounts on a draft order.

    Unapplied discounts are still part of the draft order, but do not affect balance.
    Existing discounts that are not passed in the request will keep their current state.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders/{draftOrderId}/set-discounts
    ```

    ## Path Params

    <ParamField path="draftOrderId" type="string" required>

      Draft order ID.

    </ParamField>

    ## Body Params

    <ParamField body="discounts" type="IdAndApplied[]" required>

      Discounts to set on the draft order.

      Any existing discounts that are not passed will not change.

      Constraints: `minItems 1`, `maxItems 320`.

      <Expandable title="discounts properties">

        <ParamField body="id" type="string" required>

          Entity ID.

          Depending on the context, the value is either a discount ID or an additional fee ID.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="applied" type="boolean" required>

          Whether the discount or additional fee should be applied to the draft order.

        </ParamField>

      </Expandable>

    </ParamField>

    | `428` | `FAILED_PRECONDITION` | `DISCOUNTS_AMOUNT_EXCEED_SHIPPING_TOTAL` | Shipping discount exceeds the shipping's total price. |
    | `409` | `ALREADY_EXISTS` | `DRAFT_ORDER_ALREADY_COMMITTED` | Draft order was already committed. |
