Triggered when an extended field is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.contacts.v4.extended-field_created` |
| Package | `@wix/crm` |
| Permissions | `Manage Stores`, `Manage Bookings Services and Settings`, `Manage Events`, `Manage Challenges`, `Manage Portfolio`, `Manage Contact Extended Fields`, `Access Verticals by Automations`, `Manage Restaurants - all permissions`, `Set Up Automations`, `Manage Members and Contacts - all permissions` |
