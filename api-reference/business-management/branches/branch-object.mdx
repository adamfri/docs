---
title: "Branch Object"
description: "A branch is a version of draft site content that can be edited independently."
icon: "cube"
---

A branch is a version of draft site content that can be edited independently. Also known as a test site.

Branches let site owners and developers create isolated versions of a site for testing changes without affecting the live site. Each branch maintains its own content, design, and settings while sharing the same site infrastructure.

Learn more about [branches](https://support.wix.com/en/article/about-test-sites).

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Branch ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the branch is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating the branch.

      **Read-only.**

    </ResponseField>

    <ResponseField name="type" type="string">

      Branch type.

      **Supported values:**

      - `USER` — A branch created by a site owner that can be accessed for editing and publishing in the editor.
      - `TECHNICAL` — A branch created for technical purposes, unrelated to site owners. For internal use, can't be accessed in the editor.
      - `ORIGINAL_BRANCH` — The original branch of the site, created when the site is created. Can be accessed for editing and publishing in the editor.

    </ResponseField>

    <ResponseField name="name" type="string">

      Branch name.

    </ResponseField>

    <ResponseField name="sourceType" type="string">

      Source type for this branch's content. Must be aligned with the corresponding source properties below.

      **Supported values:**

      - `SOURCE_BRANCH` — This branch's source was another branch. Must be used with `sourceBranchProperties`.

    </ResponseField>

    <ResponseField name="lastPublishDate" type="integer">

      Date and time the branch was last published.

      **Read-only.**

    </ResponseField>

    <ResponseField name="editorType" type="EditorType">

      Wix editor type.
      Provide this field only when the new branch uses a different editor than the branch it was created from, and the branch is not created from a template. Only `STUDIO_TWO` may be provided explicitly; otherwise the editor type is calculated automatically.

      Constraints: `immutable`.

      <Expandable title="editorType properties">

        <ResponseField name="editorTypeOptions" type="string">

          Wix editor types.

          **Supported values:**

          - `STUDIO` — Wix Studio Editor.
          - `CLASSIC` — Wix's Classic Editor.
          - `HARMONY` — Wix Type Harmony Editor.
          - `STUDIO_TWO` — Wix StudioTwo Editor.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="default" type="boolean">

      Whether this branch is the default branch. The default branch is used for API operations when no branch ID is specified.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the branch was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the branch was last updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the branch.
      [Extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields) must be configured in the app dashboard before they can be accessed with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="PublicTags">

      Public tags assigned to the branch.

      <Expandable title="tags properties">

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "branch": {
          "id": "11111111-1111-1111-1111-111111111111",
          "revision": 1,
          "type": "USER",
          "name": "my_branch",
          "sourceType": "SOURCE_BRANCH",
          "lastPublishDate": "2025-01-15T11:54:44.789Z",
          "editorType": {
            "editorTypeOptions": "STUDIO"
          },
          "default": false,
          "sourceBranchProperties": {
            "branchId": "00000000-0000-0000-0000-000000000000",
            "branchRevision": 1
          },
          "createdDate": "2025-01-15T11:54:44.789Z",
          "updatedDate": "2025-01-15T11:54:44.789Z",
          "extendedFields": null
        }
      }
      ```

    </CodeGroup>
