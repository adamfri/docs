    Retrieves the list of point-of-view options a site can choose from when configuring marketing settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-MARKETING-PLAN">Manage Marketing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/promote/marketing-plan-service/v1/marketing-settings/point-of-view-options
    ```

    ## Response Object

    <ResponseField name="options" type="PointOfViewOption[]">

      Selectable point-of-view options, ordered for display.

      Constraints: `minItems 0`, `maxItems 10`.

      <Expandable title="options properties">

        <ResponseField name="pointOfViewKey" type="string">

          The enum value identifying this point of view.

          **Supported values:**

          - `FIRST_PERSON` — Uses "I", "we", "my", "our".
          - `SECOND_PERSON` — Uses "you", "your".
          - `THIRD_PERSON` — Uses "they", "their", or the business name.

        </ResponseField>

        <ResponseField name="displayName" type="string">

          Localized display name for this point of view in the account's language.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
