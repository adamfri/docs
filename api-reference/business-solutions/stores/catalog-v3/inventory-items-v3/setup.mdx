<Note>This article applies to the JavaScript SDK only.</Note>

To use the InventoryItemsV3 API, install the `@wix/stores` package using npm or Yarn:
  ```bash
npm install @wix/stores
```

or

```bash
yarn add @wix/stores
```

Then import `{ inventoryItemsV3 }` from `@wix/stores`:

```js
import { inventoryItemsV3 } from '@wix/stores'
```
