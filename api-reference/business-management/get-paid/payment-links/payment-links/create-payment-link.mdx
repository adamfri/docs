    <div className="wix-ref">

    Creates a new payment link.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PAYLINKS.MANAGE">Manage Paylinks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/paymentlinks/v1/payment-links
    ```

    ## Body Params

    <ParamField body="paymentLink" type="PaymentLink" required>

      Payment link to create.

      See the [Payment Link Object](/api-reference/business-management/get-paid/payment-links/payment-links/payment-link-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="paymentLink" type="PaymentLink">

      Created payment link.

      See the [Payment Link Object](/api-reference/business-management/get-paid/payment-links/payment-links/payment-link-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NO_META_SITE` | Site not found. |
    | `400` | `INVALID_ARGUMENT` | `CHECKOUT_TEMPLATE_MISSING_ITEMS` | For the `ECOM` payment link type, `ecomPaymentLink.lineItems` must be passed. |
    | `428` | `FAILED_PRECONDITION` | `NOT_ENABLED_FOR_PARTNERS` | Payment links app isn't available for partners. |
    | `428` | `FAILED_PRECONDITION` | `UNPUBLISHED_SITE` | Site isn't published. |
    | `428` | `FAILED_PRECONDITION` | `SITELESS_NOT_SUPPORTED` | Instance without site isn't supported. |
    | `428` | `FAILED_PRECONDITION` | `FAILED_TO_INSTALL_ECOM` | Wix eCommerce isn't installed. |
    | `428` | `FAILED_PRECONDITION` | `MISSING_ACCEPT_PAYMENTS` | Site isn't set up to accept payments. |
    | `428` | `FAILED_PRECONDITION` | `NO_EMAIL_FOR_RECIPIENT` | No email address found in recipient's contact details for the `EMAIL` send method. |
    | `428` | `FAILED_PRECONDITION` | `ECOM_ORDER_ALREADY_PAID` | Wix eCommerce order is already paid when trying to create payment link of 'type': ECOM_ORDER. |
    | `428` | `FAILED_PRECONDITION` | `ECOM_ORDER_INVALID_STATE` | Wix eCommerce order state is invalid. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_RECIPIENT_SEND_METHOD` | Recipient's send method is missing. |
    | `400` | `INVALID_ARGUMENT` | `RECIPIENT_NOT_FOUND` | Recipient's contact details not found. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_RECIPIENT_SEND_METHOD` | Recipient's send method is invalid. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_TITLE_MIN_LENGTH` | Title is missing. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_EXPIRATION_DATE` | Expiration date is invalid. |
    | `400` | `INVALID_ARGUMENT` | `DIFFERENT_CURRENCIES_IN_PAYMENT_LINK_AND_ECOM_ORDER` | Mismatch between payment link and Wix eCommerce order currencies. |
    | `400` | `INVALID_ARGUMENT` | `ECOM_ORDER_PASSED_PAYMENT_STATE` | This Wix eCommerce order has already been paid. |
    | `400` | `INVALID_ARGUMENT` | `ECOM_ORDER_BALANCE_IS_SMALLER_THAN_PAYMENT_LINK_AMOUNT` | Wix eCommerce order balance is smaller than payment link amount. |
    | `400` | `INVALID_ARGUMENT` | `ORDER_NOT_FOUND` | Wix eCommerce order not found. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_PAYMENTS_LIMIT_FOR_ECOM_ORDER_PAYMENT_LINK` | Payment links of `type`: `ECOM_ORDER` must have a `paymentsLimit` set to 1. |
    | `400` | `INVALID_ARGUMENT` | `INVARIANT_VIOLATION` | Field value violation. Applicable fields: `title`, `price`, `expirationDate`, `paymentsLimit`, `ecomPaymentLink.lineItems`, `ecomOrderPaymentLink.amount`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Payment Link Created | `wix.paymentlinks.v1.payment_link_created` | Triggered when a payment link is created. |
