      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CONSENT_CONFIG.MANAGE">Consent config</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/bu/legal/v1/consent-configs/{consentConfig.id}
    ```

    ## Path Params

    <ParamField path="consentConfig.id" type="string" required>

      Consent config ID.

    </ParamField>

    ## Body Params

    <ParamField body="consentConfig" type="ConsentConfig" required>

      Consent config to update, may be partial.

      See the [Consent Config Object](/api-reference/business-management/cookie-consent-policy/consent-configs/consent-config-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="consentConfig" type="ConsentConfig">

      Updated consent config.

      See the [Consent Config Object](/api-reference/business-management/cookie-consent-policy/consent-configs/consent-config-object) for this object's fields.

    </ResponseField>

        <ParamField body="configType" type="string">

          Type of consent config. Currently only the `TAG_OVERRIDE` type is supported.

          **Supported values:**

          - `UNKNOWN_CONFIG` — Unknown config type.
          - `TAG_OVERRIDE` — Overrides the app embed's category.

        </ParamField>

        <ParamField body="consentCategory" type="string">

          The consent config's categories for compliance with privacy regulations.

          **Supported values:**

          - `UNKNOWN_CATEGORY`
          - `essential` — Includes core functionality such as security, verification of identity and network management. These cookies can’t be disabled.
          - `functional` — Includes collecting data to remember choices users make to improve and give a more personalised experience.
          - `analytics` — Includes tracking visitor interactions with a site, to discover errors and provide better overall analytics.
          - `advertising` — Includes tracking advertising effectiveness to provide a more relevant service and deliver better ads to suit visitors' interests.
          - `data_to_third_party` — Includes collecting data to pass on to a third party.
