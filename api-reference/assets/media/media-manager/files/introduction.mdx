The Files API allows you to manage files and generate file URLs from a site's Media Manager. 

With the Files API, you can:
- [Get](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/get-file-descriptor), [list](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/list-files), [search](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/search-files), and [query](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/query-file-descriptors) files.
- [Import](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/import-file), [update](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/update-file-descriptor), and [delete](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/bulk-delete-files) files.
- [Restore](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/bulk-restore-files-from-trash-bin) files from the trash bin.
- Generate URLs for:
  - [Downloading files](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/generate-file-download-url).
  - [Downloading a compressed file](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/generate-files-download-url).
  - [Uploading files](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/generate-file-upload-url).
  - [Uploading files larger than 10MB](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/generate-file-resumable-upload-url).
  - [Streaming video files](fallback::https://dev.wix.com/docs/rest/assets/media/media-manager/files/generate-video-streaming-url).
