    <div className="wix-ref">

    Retrieves add-on groups for a service with enriched add-on details.

    Add-on details are returned based on their display order.

    If you specify `groupIds`, only those groups are returned.
    By default, all groups associated with the service are returned.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.READ-BOOKINGS-PUBLIC">Read Bookings - Public Data</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/add-on-groups/list-add-on-groups-by-service-id
    ```

    ## Body Params

    <ParamField body="serviceId" type="string" required>

      ID of the service to retrieve add-on groups for.

    </ParamField>

    <ParamField body="groupIds" type="string[]">

      List of group IDs to return. By default, all groups are returned.

      Constraints: `format GUID`, `maxItems 3`.

    </ParamField>

    ## Response Object

    <ResponseField name="addOnGroupsDetails" type="AddOnGroupDetail[]">

      List of group details with their linked add-ons.

      Constraints: `maxItems 3`.

      <Expandable title="addOnGroupsDetails properties">

        <ResponseField name="groupId" type="string">

          Group ID.

        </ResponseField>

        <ResponseField name="maxNumberOfAddOns" type="integer">

          Maximum number of add-ons customers can select from this group.

        </ResponseField>

        <ResponseField name="groupName" type="string">

          Group name displayed to customers.

        </ResponseField>

        <ResponseField name="addOns" type="AddOn[]">

          Add-ons linked to this group in display order.

          Constraints: `maxItems 7`.

          <Expandable title="addOns properties">

            <ResponseField name="addOnId" type="string">

              Add-on ID.

            </ResponseField>

            <ResponseField name="name" type="string">

              Add-on name displayed to customers.

            </ResponseField>

            <ResponseField name="price" type="Money">

              Add-on price.

              _Nested structure omitted for brevity — see the `Money` object._

            </ResponseField>

            <ResponseField name="nameTranslated" type="string">

              Translated add-on name.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="prompt" type="string">

          Instructional prompt displayed to customers. For example, `Choose up to 2 relaxing spa treatments to enhance your experience`. You can also use this field as a group description. For example, `Beginner-friendly rental equipment`.

        </ResponseField>

        <ResponseField name="groupNameTranslated" type="string">

          Translated group name.

        </ResponseField>

        <ResponseField name="promptTranslated" type="string">

          Instructional translated prompt displayed to customers. For example, `Choose up to 2 relaxing spa treatments to enhance your experience`. You can also use this field as a group description. For example, `Beginner-friendly rental equipment`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
