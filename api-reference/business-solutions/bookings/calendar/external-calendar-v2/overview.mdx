You can use the [External Calendar API](https://dev.wix.com/docs/api-reference/business-solutions/bookings/calendar/external-calendar-v2/introduction)
to connect external calendars to a Wix site. Supported external calendars
include Google, Microsoft, and Apple calendars. The `externalCalendar` object
doesn't have any fields.

## SDK package

```bash
npm install @wix/bookings
```

Import the `externalCalendars` namespace from `@wix/bookings`.
