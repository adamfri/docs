---
title: "Custom Field Object"
description: "A custom field extends the default member profile with additional information fields."
icon: "cube"
---

A custom field extends the default member profile with additional information fields.
Custom fields allow Wix users to collect and display specific information from members, beyond the standard profile fields.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Custom field ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Custom field title.

    </ResponseField>

    <ResponseField name="key" type="string">

      Custom field key.

      **Read-only.**

    </ResponseField>

    <ResponseField name="defaultPrivacy" type="string">

      Privacy level of the custom field.

      **Supported values:**

      - `PUBLIC` — The information appears on the members' public profile pages.
      - `PRIVATE` — Only the member can see this information.

    </ResponseField>

    <ResponseField name="fieldType" type="string">

      Type of information to provide for members.

      **Supported values:**

      - `TEXT` — A text box to write text.
      - `NUMBER` — Only a number can be entered into the field.
      - `DATE` — Only a date can be entered into the field.
      - `URL` — Only a URL can be entered into the field.
      - `SOCIAL` — Only a link from the selected social media platform can be entered into the field.

    </ResponseField>

    <ResponseField name="socialType" type="string">

      Social network type.

      **Supported values:**

      - `FACEBOOK` — Facebook social media platform.
      - `INSTAGRAM` — Instagram social media platform.
      - `LINKEDIN` — LinkedIn social media platform.
      - `TWITTER` — X (formerly Twitter) social media platform.
      - `YOUTUBE` — Youtube social media platform.
      - `PINTEREST` — Pinterest social media platform.
      - `TIKTOK` — TikTok social media platform.
      - `DEVIANTART` — DeviantArt social media platform.
      - `SOUNDCLOUD` — SoundCloud social media platform.
      - `TUMBLR` — Tumblr social media platform.
      - `VIMEO` — Vimeo social media platform.
      - `VKONTAKTE` — VKontakte social media platform.
      - `ODNOKLASSNIKI` — Odnoklassniki social media platform.
      - `OTHER` — Other social media platform.

    </ResponseField>

    <ResponseField name="fieldOrigin" type="string">

      Field origin.

      **Read-only.**

      **Supported values:**

      - `CUSTOM` — Custom field created by a Wix user.
      - `CONTACT` — Contact type of field. These are default fields that are already provided by Members Area, such as: "birth date", "position", "company".
      - `SYSTEM` — System fields, such as: "first name", "last name", "email", "phone", "address", and  "title". Some system fields are only available from the dashboard.

    </ResponseField>

    <ResponseField name="appliesTo" type="string">

      Which members will have the custom field in their profile.

      **Read-only.**

      **Supported values:**

      - `ALL_MEMBERS` — Everyone will have this field.
      - `SELECTED_MEMBERS` — Only selected members will have this field. See the [Custom Field Application API](https://dev.wix.com/docs/rest/crm/members-contacts/members/custom-fields/custom-field-applications/introduction) for more information.

    </ResponseField>

    <ResponseField name="section" type="string">

      A section which the field belongs to.

      **Read-only.**

      **Supported values:**

      - `GENERAL` — General section. All custom fields and the following default fields are assigned to this section: "first name", "last name", "email", "phone", "birth date", "position", "company".
      - `SOCIAL` — Social media section. The "social media" field is assigned to this section.
      - `DISPLAY_INFO` — Display info section. The default "title" field is assigned to this section.
      - `ADDRESS` — Address section. The default "address" field is assigned to this section.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when the field was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time when the field was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the custom field is updated. To prevent conflicting changes, the existing revision must be used when updating a custom field.

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "2b8a8b49-356c-45c2-93cd-0f1fa4ec4d3e",
        "name": "Favorite Animal",
        "key": "custom.favorite-animal",
        "defaultPrivacy": "PRIVATE",
        "fieldType": "TEXT",
        "socialType": "UNKNOWN",
        "fieldOrigin": "CUSTOM",
        "appliesTo": "ALL_MEMBERS",
        "section": "GENERAL",
        "createdDate": "2024-01-01T01:01:01.1Z",
        "updatedDate": "2024-01-01T01:01:01.1Z",
        "revision": "1"
      }
      ```

    </CodeGroup>
