Add-ons are optional extras that extend business offerings (such as booking services) with additional features, time, or products for an extra cost.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Add-on ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the add-on is updated.
      To prevent conflicting changes, the current revision must be passed when updating the add-on.

      Ignored when creating an add-on.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the add-on was created in `YYYY-MM-DDThh:mm:ss.sssZ` format.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the add-on was last updated in `YYYY-MM-DDThh:mm:ss.sssZ` format.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Display name of the add-on shown to customers.

    </ResponseField>

    <ResponseField name="price" type="Money">

      Pricing information for the add-on.

      <Expandable title="price properties">

        <ResponseField name="value" type="string">

          Add-on price amount as a decimal string with period as decimal separator. For example, `3.99` for a $3.99 add-on or `15.00` for a $15.00 add-on.

          Constraints: `format DECIMAL_VALUE`, `>= 0`, `<= 1000000000000000`.

        </ResponseField>

        <ResponseField name="currency" type="string">

          Currency code for the add-on price. Must be a valid [ISO 4217](https://en.wikipedia.org/wiki/ISO_4217) currency code. For example, `USD` for US dollars or `EUR` for euros.

          Constraints: `format CURRENCY`.

        </ResponseField>

        <ResponseField name="formattedValue" type="string">

          Add-on price amount as a decimal string in local format for display purposes. For example, `$3.99` for US format or `3,99 €` for European format.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="taxGroup" type="string">

      ID of the [tax group](https://dev.wix.com/docs/rest/business-solutions/e-commerce/extensions/tax/tax-groups/introduction) to categorize the add-on for tax calculation in [Wix eCommerce](https://dev.wix.com/docs/rest/business-solutions/e-commerce/introduction).
      Learn more about [how Wix eCommerce implements tax calculation](https://dev.wix.com/docs/rest/business-solutions/e-commerce/extensions/tax/introduction).

      This field doesn't apply to custom checkout/billing implementations.

    </ResponseField>

    <ResponseField name="mainMedia" type="MediaItem">

      Main image for the add-on.

      <Expandable title="One of the following">

        <ResponseField name="media" type="media">

          media

          <Expandable title="media properties">

            <ResponseField name="image" type="Image">

              Add-on's main image.

              <Expandable title="image properties">

                <ResponseField name="id" type="string">

                  WixMedia image ID. To manage media assets, use the [Media Manager API](https://dev.wix.com/docs/rest/assets/media/media-manager/introduction)

                  Constraints: `maxLength 2048`.

                </ResponseField>

                <ResponseField name="url" type="string">

                  Image URL.

                  Constraints: `maxLength 2048`.

                </ResponseField>

                <ResponseField name="height" type="integer">

                  Original image height.

                  **Read-only.**

                </ResponseField>

                <ResponseField name="width" type="integer">

                  Original image width.

                  **Read-only.**

                </ResponseField>

                <ResponseField name="altText" type="string">

                  Image alt text.

                </ResponseField>

                <ResponseField name="filename" type="string">

                  Image filename.

                  **Read-only.**

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Data extensions enabling users to save custom data related to the add-on.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      [Tags](https://dev.wix.com/docs/rest/business-management/tags/introduction) assigned to add-ons for categorization and filtering purposes.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

  </Tab>
