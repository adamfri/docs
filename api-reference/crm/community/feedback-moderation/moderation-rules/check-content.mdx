    <div className="wix-ref">

    Checks the submitted content for any conditions that might trigger a rule, and then returns actions to take if the rule is triggered.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.MODERATION.MANAGE-MODERATION-RULES">Manage Moderation Rules</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/moderation/v1/rules/check
    ```

    ## Body Params

    <ParamField body="namespace" type="string">

      Namespace value.

      Constraints: `maxLength 120`.

    </ParamField>

    <ParamField body="content" type="ModerationContent">

      Content to check.

      <Expandable title="content properties">

        <ParamField body="attributes" type="Attribute[]">

          Content attributes. For example, if you'd like to check all reviews with a low rating, then `name` would be `rating`, and `values` would be `[1, 2]`.

          **Note:** Only applicable when `trigger` is the `ATTRIBUTE` type.

          Constraints: `maxItems 420`.

          <Expandable title="attributes properties">

            <ParamField body="name" type="string">

              Attribute name.

              Constraints: `maxLength 20`.

            </ParamField>

            <ParamField body="value" type="string">

              Attribute value.

              Constraints: `maxLength 20`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

      <Expandable title="One of the following">

        <ParamField body="content" type="content">

          content

          <Expandable title="content properties">

            <ParamField body="richContent" type="RichContent">

              Content is in the rich content format.

              **Note:** Only applicable when `trigger` is the `CONTENT_FEATURES` and `PATTERNS` type.

              _Nested structure omitted for brevity — see the `RichContent` object._

            </ParamField>

            <ParamField body="plainText" type="string">

              Content is plain text.

              **Note:** Only applicable when `trigger` is the `PATTERNS` type.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="violations" type="Violation[]">

      Rule violation details.

      <Expandable title="violations properties">

        <ResponseField name="ruleId" type="string">

          Rule ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="action" type="Action">

          Action to take.

          <Expandable title="action properties">

            <ResponseField name="type" type="string">

              Action type.

              **Supported values:**

              - `UNKNOWN_TYPE`
              - `REJECT` — Reject the content without any further review.
              - `NEEDS_MANUAL_APPROVAL` — Send the content for manual review.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
