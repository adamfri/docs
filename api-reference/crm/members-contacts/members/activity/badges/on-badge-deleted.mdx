Triggered when a badge is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.badges.v3.badge_deleted` |
| Package | `@wix/members` |
| Permissions | `Manage Stores`, `Manage Challenges`, `Manage Badges`, `Read Badges` |
