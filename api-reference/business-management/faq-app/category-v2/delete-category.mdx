  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a category.

    Deleting a category permanently removes it from the site's FAQ page.
    Questions that belong to the deleted category are also deleted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LABS.MANAGE-FAQ">Manage FAQ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/faq/v2/categories/{categoryId}
    ```

    ## Path Params

    <ParamField path="categoryId" type="string" required>

      ID of the category to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteCategoryResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Category Deleted | `wix.faq.category.v2.category_deleted` | Triggered when a category is deleted. |

    </div>
