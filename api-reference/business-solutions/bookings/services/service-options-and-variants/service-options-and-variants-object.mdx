---
title: "Service Options And Variants Object"
description: "The serviceOptionsAndVariants object links a service to its variants."
icon: "cube"
---

The `serviceOptionsAndVariants` object links a [service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/introduction)
to its variants.
You can use it to offer customers different prices for a service,
depending on which choices they book.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      ID of the `serviceOptionsAndVariants` object.

      **Read-only.**

    </ResponseField>

    <ResponseField name="serviceId" type="string">

      ID of the service related to these options and variants.

    </ResponseField>

    <ResponseField name="options" type="ServiceOptions">

      Service options. Note that currently only a single option is supported per service.

      <Expandable title="options properties">

        <ResponseField name="values" type="ServiceOption[]">

          Values of the service options.

          Max: 1 service option

          Constraints: `minItems 1`, `maxItems 1`.

          <Expandable title="values properties">

            <ResponseField name="id" type="string">

              ID of the service option.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="type" type="string">

              Type of the service option.

              **Supported values:**

              - `CUSTOM` — The service option is based on a custom parameter. For example, age group,
              booked equipment, or appointment timing.
              - `STAFF_MEMBER` — It's a [staff member](https://dev.wix.com/docs/rest/business-solutions/bookings/staff-members/introduction)
              based option.
              - `DURATION` — It's a duration-based option.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="variants" type="ServiceVariants">

      Information about the service's variants.

      <Expandable title="variants properties">

        <ResponseField name="values" type="ServiceVariant[]">

          Values of the service variants.

          Constraints: `minItems 1`, `maxItems 100`.

          <Expandable title="values properties">

            <ResponseField name="choices" type="ServiceChoice[]">

              Choices for the service option. Currently, only a single choice is supported
              because a service can have only a single option.

              Max: 1 choice

              Constraints: `minItems 1`, `maxItems 1`.

              <Expandable title="choices properties">

                <ResponseField name="optionId" type="string">

                  ID of the service option.

                  Constraints: `format GUID`.

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="price" type="Money">

              Information about the service variant's price.

              <Expandable title="price properties">

                <ResponseField name="value" type="string">

                  Monetary amount. Decimal string with a period as a decimal separator (e.g., 3.99). Optionally, a single (-), to indicate that the amount is negative.

                  Constraints: `format DECIMAL_VALUE`, `>= 0`.

                </ResponseField>

                <ResponseField name="currency" type="string">

                  Currency code. Must be valid ISO 4217 currency code (e.g., USD).

                  Constraints: `format CURRENCY`.

                </ResponseField>

                <ResponseField name="formattedValue" type="string">

                  Monetary amount. Decimal string in local format (e.g., 1 000,30). Optionally, a single (-), to indicate that the amount is negative.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="minPrice" type="Money">

      Price of the cheapest service variant.

      **Read-only.**

      <Expandable title="minPrice properties">

        <ResponseField name="value" type="string">

          Monetary amount. Decimal string with a period as a decimal separator (e.g., 3.99). Optionally, a single (-), to indicate that the amount is negative.

          Constraints: `format DECIMAL_VALUE`, `>= 0`.

        </ResponseField>

        <ResponseField name="currency" type="string">

        <ResponseField name="formattedValue" type="string">

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="maxPrice" type="Money">

      Price of the most expensive service variant.

      **Read-only.**

      <Expandable title="maxPrice properties">

        <ResponseField name="value" type="string">

          Monetary amount. Decimal string with a period as a decimal separator (e.g., 3.99). Optionally, a single (-), to indicate that the amount is negative.

          Constraints: `format DECIMAL_VALUE`, `>= 0`.

        </ResponseField>

        <ResponseField name="currency" type="string">

          Currency code. Must be valid ISO 4217 currency code (e.g., USD).

          Constraints: `format CURRENCY`.

        </ResponseField>

        <ResponseField name="formattedValue" type="string">

          Monetary amount. Decimal string in local format (e.g., 1 000,30). Optionally, a single (-), to indicate that the amount is negative.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the `serviceOptionsAndVariants` object is updated.
      To prevent conflicting changes,
      the current revision must be passed when updating and deleting the `serviceOptionsAndVariants` object.

      Ignored when creating a `serviceOptionsAndVariants` object.

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extensions enabling users to save custom data related to service options and variants.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
