    Updates a receipt preset.

    Each time the receipt preset is updated,
    `revision` increments by 1.
    The current `revision` must be passed when updating the receipt preset.
    This ensures you're working with the latest receipt preset
    and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RECEIPTS.MANAGE">Manage Receipts</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/receipts/v1/receipt-presets/{receiptPreset.id}
    ```

    ## Path Params

    <ParamField path="receiptPreset.id" type="string" required>

      Receipt preset ID.

    </ParamField>

    ## Body Params

    <ParamField body="receiptPreset" type="ReceiptPreset" required>

      Receipt preset to update. May be partial.

      See the [Receipt Preset Object](/api-reference/business-management/get-paid/receipts/receipt-presets/receipt-preset-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="receiptPreset" type="ReceiptPreset">

      Updated receipt preset.
