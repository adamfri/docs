    Returns up to 100 public activity counters for the provided filter and paging.

    Only counters that are marked as public are returned.

    Supported fields for filtering:
    - `memberId`

    Supported operations:

    Comparison:
    - $eq
    - $ne
    - $in

    Logical:
    - $and
    - $not
    - $or

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.READ-ACTIVITY-COUNTERS">Read Activity Counters</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/activity-counters/query
    ```

    ## Body Params

    <ParamField body="query" type="Query">

      Query options.

      <Expandable title="query properties">

        <ParamField body="filter" type="any">

          Filter object.

        </ParamField>

        <ParamField body="paging" type="Paging">

          Paging options.

          <Expandable title="paging properties">

            <ParamField body="limit" type="integer">

              Number of items to load.

            </ParamField>

            <ParamField body="offset" type="integer">

              Number of items to skip in the current sort order.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="activityCounters" type="ActivityCounter[]">

      Retrieved activity counters.

      See the [Activity Counter Object](/api-reference/crm/members-contacts/members/activity/activity-counters/activity-counter-object) for this object's fields.

    </ResponseField>

    <ResponseField name="metadata" type="PagingMetadata">

      Paging metadata.

      <Expandable title="metadata properties">

      </Expandable>

    </ResponseField>
