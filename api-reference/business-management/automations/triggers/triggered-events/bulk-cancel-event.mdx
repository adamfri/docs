    <div className="wix-ref">

    Cancels any remaining actions for multiple events at once, given a trigger key and the events' external entity IDs.

    Each external entity ID is processed independently, so some cancellations can succeed while others fail. Check `bulkActionMetadata` for the success and failure totals.

    To cancel a single event, call [Cancel Event](https://dev.wix.com/docs/api-reference/business-management/automations/triggers/triggered-events/cancel-event).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC.MANAGE-YOUR-APP">Manage Your App</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/automations/v1/events/bulk-cancel
    ```

    ## Body Params

    <ParamField body="triggerKey" type="string" required>

      Trigger key whose events you want to cancel.
      For example, `form_submitted` or `invoice_due`.

      Constraints: `minLength 1`, `maxLength 100`.

    </ParamField>

    <ParamField body="externalEntityIds" type="string[]" required>

      Repeated list of external_entity_id, representing the related resources' IDs.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="triggerKey" type="string">

      Trigger key related to the canceled event.

      Constraints: `minLength 1`, `maxLength 100`.

    </ResponseField>

    <ResponseField name="results" type="BulkCancelEventResult[]">

      List of results for each item in the bulk cancel event request.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Metadata of the item, including its ID and success or failure status.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="externalEntityId" type="string">

          ID of the related resource in GUID format.

          Constraints: `format GUID`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata for the overall bulk action, including success and failure counts.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

          Number of items that couldn't be processed.

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>
