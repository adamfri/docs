    <div className="wix-api-columns">

    <div className="wix-ref">

    Sets the list of currencies that can be displayed on the site.

    When you set currencies for a site, visitors can view prices in any of these currencies.
    Prices are automatically converted using up-to-date exchange rates.
    The supplied list completely replaces the previous currency list.

    To disable currency conversion entirely, pass an empty array.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.STORES.MANAGE-STORES">Manage Stores</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/settings/v1/currencies/site
    ```

    ## Body Params

    <ParamField body="currencies" type="SiteCurrency[]">

      List of currencies to enable for the site.
      This list replaces any previously configured currencies.
      Pass an empty array to disable currency conversion.

      Constraints: `maxItems 156`.

      See the [Site Currency Object](/api-reference/business-solutions/stores/site-currency/site-currency-object) for this object's fields.

    </ParamField>

    ## Response Object

    Returns `SetCurrenciesResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
