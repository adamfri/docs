    Updates RSVP.

    Each time the RSVP is updated, `revision` increments by 1. The existing `revision` must be specified when updating the RSVP. This ensures you're working with the latest RSVP and prevents unintended overwrites.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-GUEST-LIST">Manage Guest List</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/events/v2/rsvps/{rsvp.id}
    ```

    ## Path Params

    <ParamField path="rsvp.id" type="string" required>

      ID of the RSVP.

    </ParamField>

    ## Body Params

    <ParamField body="rsvp" type="Rsvp" required>

      RSVP to update.

      See the [Rsvp Object](/api-reference/business-solutions/events/registration/rsvp-v2/rsvp-object) for this object's fields.

    </ParamField>

    <ParamField body="options" type="ModificationOptions">

      RSVP options. &lt;br> The **WIX_EVENTS.MANAGE_RSVP** permission is required to pass these fields.

      <Expandable title="options properties">

        <ParamField body="ignoreLimits" type="boolean">

          Whether to create or update an RSVP regardless of the event's guest limit.

        </ParamField>

        <ParamField body="ignoreFormValidation" type="boolean">

          Whether to ignore the form validation.

        </ParamField>

        <ParamField body="ignoreResponseStatus" type="boolean">

          Whether to accept the RSVP `status` even when the event's registration doesn't allow it, for example when registration is closed or hasn't started, the waitlist is unavailable, or the event only accepts `YES` responses.

        </ParamField>

        <ParamField body="ignoreAdditionalGuestNames" type="boolean">

          Whether to ignore the additional guest names validation.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="fields" type="string[]">

      Predefined sets of fields to return.

      Constraints: `maxItems 3`.

      **Supported values:**

      - `DETAILS` — Returns `createdDate`, `updatedDate`, `firstName`, `lastName`, `totalGuests`, `guests`.
      - `FORM` — Returns `form`.
      - `CONTACT_DETAILS` — Returns `email`.

    </ParamField>

    ## Response Object

    <ResponseField name="rsvp" type="Rsvp">

      Updated RSVP.

      See the [Rsvp Object](/api-reference/business-solutions/events/registration/rsvp-v2/rsvp-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_RSVP_STATUS` | RSVP status value is invalid. |
    | `400` | `INVALID_ARGUMENT` | `UNEXPECTED_RSVP_STATUS` | RSVP status isn't valid for this operation. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_FORM_RESPONSE` | Form response is invalid or doesn't match the event's form requirements. |
    | `428` | `FAILED_PRECONDITION` | `GUEST_LIMIT_EXCEEDED` | Number of guests exceeds the event's guest limit. |
    | `428` | `FAILED_PRECONDITION` | `RSVPS_CLOSED` | RSVPs for this event are closed. |
    | `428` | `FAILED_PRECONDITION` | `RSVPS_NOT_STARTED` | RSVPs for this event haven't started yet. |
    | `428` | `FAILED_PRECONDITION` | `WAITING_LIST_UNAVAILABLE` | Waitlist isn't available for this event. |
    | `400` | `INVALID_ARGUMENT` | `ADDITIONAL_GUESTS_MUST_HAVE_NAMES` | Additional guests must have names when `guestCount` is greater than 0. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
