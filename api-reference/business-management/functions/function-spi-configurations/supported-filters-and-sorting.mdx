The following table shows field support for filters and sorting
for the function SPI configuration object:

| Field                    | Supported Filters                             | Sortable |
| ------------------------ | --------------------------------------------- | -------- |
| `id`                     | `$eq`, `$ne`, `$in`, `$exists`                | Sortable |
| `functionId`             | `$eq`, `$ne`, `$in`, `$exists`                | Sortable |
