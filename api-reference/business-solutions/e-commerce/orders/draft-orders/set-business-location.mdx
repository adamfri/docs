    Sets business location on a draft order.

    When committed, the order will become associated to a specific business location. This affects who can see and manage this order, and how it is calculated in reports.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/ecom/v1/draft-orders/set-business-location
    ```

    ## Body Params

    <ParamField body="draftOrderId" type="string" required>

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="businessLocation" type="Location">

        <ParamField body="name" type="string">

          Location name.

          **Read-only.** Constraints: `minLength 1`, `maxLength 500`.

        </ParamField>

      </Expandable>

    </ParamField>
