    <div className="wix-ref">

    Adds a list of [pricing plan IDs](https://dev.wix.com/docs/api-reference/business-solutions/pricing-plans/plans/plans-v3/introduction) to a service's `payment.pricingPlanIds` array.

    The call doesn't validate whether the service's `payment.options.pricingPlan`
    is set to `true`. If it's set to `false`, customers aren't able to pay
    for their bookings using pricing plans. You can call [Update Service](https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/services-v2/update-service) to change a service's supported payment methods.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-BOOKINGS.MANAGE-BOOKINGS">Manage Bookings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/bookings/v2/services/{serviceId}/pricing-plans/add
    ```

    ## Path Params

    <ParamField path="serviceId" type="string" required>

      ID of the service to update.

    </ParamField>

    ## Body Params

    <ParamField body="pricingPlanIds" type="string[]" required>

      IDs of the [pricing plans](https://dev.wix.com/docs/api-reference/business-solutions/pricing-plans/pricing-plans/plans/introduction)
      to add to the service's `payment.pricingPlanIds` array.
      Maintained for backward compatibility. Use `pricing_plan_selections` for explicit benefit selection.

      Constraints: `format GUID`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="service" type="Service">

      Updated service.

      See the [Service Object](/api-reference/business-solutions/bookings/services/services-v2/service-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_PRICING_PLAN` | The specified pricing plan doesn't exist or isn't valid for this service. |
    | `400` | `INVALID_ARGUMENT` | `SERVICE_DOES_NOT_SUPPORT_PRICING_PLANS` | The service's `payment.options.pricingPlan` is set to `false`. Update the service to accept pricing plan payments before adding pricing plans. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Service Updated | `wix.bookings.services.v2.service_updated` | Triggered when a service is updated. |
