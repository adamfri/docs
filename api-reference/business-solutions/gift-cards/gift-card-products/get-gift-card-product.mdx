    Retrieves a gift card product.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gift-cards/v1/gift-card-products/{giftCardProductId}
    ```

    ## Path Params

    <ParamField path="giftCardProductId" type="string" required>

      ID of the gift card product to retrieve.

    </ParamField>

    ## Response Object

    <ResponseField name="giftCardProduct" type="GiftCardProduct">

      Retrieved gift card product.

      See the [Gift Card Product Object](/api-reference/business-solutions/gift-cards/gift-card-products/gift-card-product-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
