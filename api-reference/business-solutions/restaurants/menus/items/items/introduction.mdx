<Note>This article applies to the REST API only.</Note>

The Items API allows you to manage menu items. Items are various dishes, that are grouped into [sections](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/menus/sections/introduction). Each item has its own label and price, and can be customized with [item modifiers](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-modifiers/introduction) and [price variants](https://dev.wix.com/docs/rest/business-solutions/restaurants/menus/item-variant/introduction)

With the Items API, you can:

- Create, delete, and update items.
- Retrieve the information about an item.
- Count items that meet a specified filter.

## Before you begin

It's important to note the following point before starting to code:

- The Items API only works with the Wix Restaurants Menus app. Make sure you have installed this app from the [Wix App Market](fallback::https://www.wix.com/app-market/wix-restaurants-menus-new).

## Terminology

**Menu**: A list of food and beverage items available for purchase at a restaurant, café, or other dining establishment.
