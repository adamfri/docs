A form template is a reusable definition of a form's fields, steps, and settings. It's used as the
source when creating a form. App owners define templates for their namespace in the app dashboard,
and this API retrieves them.

## SDK package

```bash
npm install @wix/form-templates
```

Import the `formTemplates` namespace from `@wix/form-templates`.
