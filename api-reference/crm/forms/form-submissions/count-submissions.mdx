    <Note>

    The Form Submission API only works with the Wix Forms app. Call [GetAppInstance](https://dev.wix.com/docs/rest/api-reference/app-management/apps/app-instance/get-app-instance) to confirm that the app named `wix_forms` is installed on the site.

    <br />
    Counts the number of submissions belonging to the specified forms.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-FORMS.READ-SUBMISSIONS">Read Submissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/v4/submissions/count
    ```

    ## Body Params

    <ParamField body="formIds" type="string[]" required>

      Form IDs.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    <ParamField body="namespace" type="string" required>

      Identifies the app which the form submissions belong to. For example, the namespace for the Wix Forms App is `"wix.form_app.form"`. The namespace of a submission can be retrieved using the Get Submission endpoint.

      Constraints: `minLength 10`, `maxLength 50`.

    </ParamField>

    <ParamField body="statuses" type="string[]">

      List of statuses of submissions which should be taken into count
      Default: CONFIRMED, PAYMENT_WAITING, PAYMENT_CANCELED

      Constraints: `maxItems 4`.

      **Supported values:**

      - `PENDING` — A submission is created, but has not yet been recorded in the Wix Forms collection.
      - `CONFIRMED` — A submission is recorded in the Wix Forms collection.
      - `PAYMENT_WAITING` — A form submission requiring payment is created.
      - `PAYMENT_CANCELED` — An order of a form submission is canceled.

    </ParamField>

    ## Response Object

    <ResponseField name="formsSubmissionsCount" type="FormSubmissionsCount[]">

      Forms submission count.

      <Expandable title="formsSubmissionsCount properties">

        <ResponseField name="formId" type="string">

          Form ID.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="totalCount" type="integer">

          Total number of submissions.

        </ResponseField>

        <ResponseField name="unseenCount" type="integer">

          Number of submissions that haven't yet been seen by site Extensions with manage submission permissions.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
