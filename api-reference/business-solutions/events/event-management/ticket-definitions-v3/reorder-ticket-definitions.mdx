    <div className="wix-api-columns">

    <div className="wix-ref">

    Adjusts the order in which ticket definitions display in an event dashboard, as well as the order of available tickets displayed in the ticket picker.
    <Note>

    You may use both `beforeTicketDefinitionId` and `afterTicketDefinitionId` but only the last one provided takes effect.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-EVENTS.MANAGE-TICKET-DEF">Manage Ticket Definitions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/events/v3/ticket-definitions/reorder
    ```

    ## Body Params

    <ParamField body="eventId" type="string" required>

      Event ID.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="ticketDefinitionId" type="string" required>

      Ticket definition ID.

      Constraints: `format GUID`.

    </ParamField>

    ## Response Object

    Returns `ReorderTicketDefinitionsResponse`.

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INVALID_REORDER_INSTRUCTION` | Neither `beforeDefinitionId` or nor `afterDefinitionId` are specified. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Ticket Definition Updated | `wix.events.v3.ticket_definition_updated` | Triggered when a ticket definition is updated. |

    </div>
