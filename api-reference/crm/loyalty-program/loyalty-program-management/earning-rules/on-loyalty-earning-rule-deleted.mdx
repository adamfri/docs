| Property | Value |

| Event type | `wix.loyalty.v1.loyalty_earning_rule_deleted` |
| Package | `@wix/loyalty` |
| Permissions | `Read Loyalty`, `Manage Loyalty`, `Manage Restaurants - all permissions` |
