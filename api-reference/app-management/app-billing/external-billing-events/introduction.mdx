<Note>

This API is only for [Partner Billed Apps](fallback::https://dev.wix.com/docs/build-apps/launch-your-app/pricing-and-billing/partner-billed-apps-reporting), which charge users using their own payment provider.

</Note>

The External Billing Events API allows you to report charges and refunds to Wix for revenue tracking when you handle payment processing yourself, such as through Stripe or PayPal.

To get your Partner Billed App approved, you need to:

1. Get approval from Wix.
2. Implement this API.
3. [Submit Partner Billed App reports](fallback::https://dev.wix.com/docs/build-apps/launch-your-app/pricing-and-billing/partner-billed-apps-reporting#submit-a-partner-billed-app-report).

<Note>

Hosting your own [external pricing page](fallback::https://dev.wix.com/docs/build-apps/launch-your-app/pricing-and-billing/set-up-an-external-pricing-page) doesn't automatically make you a Partner Billed App. External pricing pages that process payments through Wix should use the [Billing API](fallback::https://dev.wix.com/docs/rest/app-management/app-billing/billing/introduction), whereas external pricing pages that process payments independently should use this External Billing Events API.

</Note>

The API has 1 method, [Report External Billing Event](fallback::https://dev.wix.com/docs/rest/app-management/app-billing/external-billing-events/report-external-billing-event), that lets you send the details of a billing event. In each method call, you report 1 external billing event associated with a single instance of your app.

## Before you begin

It’s important to note the following point before starting to code:

Since you report a billing event for a specific app instance, you need at least 1 of the following:

- An [access token](fallback::https://dev.wix.com/docs/rest/app-management/oauth-2/introduction) set up for the app instance. This is the recommended option.
- The [app instance ID](fallback::https://dev.wix.com/docs/rest/app-management/app-instance/introduction).
- An [API key](https://dev.wix.com/docs/rest/articles/get-started/api-keys) with the account-level `Manage Custom Apps` permission, from the account that owns your app.

## Terminology

- **Partner Billed App**: An app that processes payments yourself using your own payment provider such as Stripe or PayPal instead of using Wix checkout. Requires Wix approval and regular reporting of billing events using this API.
- **External billing event**: A charge or refund that occurs outside the Wix Billing system.
- **External pricing page**: A custom pricing page that you host on your own servers.
- **App instance**: Specific occurrence of your app on a particular Wix site.
