The Pool Definitions API allows you to manage your app or site's [pool definitions](##pool-defintion*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#pool-defintion). Use this API together with other [Wix Benefit Programs APIs](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/introduction).

With the Pool Definitions API, you can:
- Retrieve, create, update, and delete pool definitions.
- Add and remove pool definitions from program definitions.

## Pool definitions in benefit programs
Pool definitions are where you define the key parts of benefit programs: [benefits](##benefit*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#benefit) and [credit](##credit*fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/terminology#credit) settings.

Consider a pool definition to be the theory of a pool. A pool definition is how a pool looks before a visitor enrolls in it.

Learn more about benefit programs [components](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-program-components) and [lifecycle](fallback::https://dev.wix.com/docs/rest/business-solutions/benefit-programs/benefit-programs-lifecycle).
