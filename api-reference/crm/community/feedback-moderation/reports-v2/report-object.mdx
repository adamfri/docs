---
title: "Report Object"
description: "The Report object in the Wix Report API."
icon: "cube"
---

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Report ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="entityName" type="string">

      Reported entity name, such as `comment`.

      Constraints: `minLength 1`, `maxLength 50`, `immutable`.

    </ResponseField>

    <ResponseField name="entityId" type="string">

      Reported entity ID.

      Constraints: `minLength 1`, `maxLength 50`, `immutable`.

    </ResponseField>

    <ResponseField name="identity" type="IdentificationData">

      Identity of who created a report.

      **Read-only.**

      <Expandable title="identity properties">

        <ResponseField name="identityType" type="string">

          Identity type

          **Read-only.**

          **Supported values:**

          - `ANONYMOUS_VISITOR` — A site visitor who has not logged in.
          - `MEMBER` — A logged-in site member.

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="id" type="id">

          id

          <Expandable title="id properties">

            <ResponseField name="anonymousVisitorId" type="string">

              ID of a site visitor that has not logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

            <ResponseField name="memberId" type="string">

              ID of a site visitor that has logged in to the site.

              Constraints: `format GUID`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="reason" type="Reason">

      Reason for the report.

      <Expandable title="reason properties">

        <ResponseField name="reasonType" type="string">

          Report reason type.

          **Supported values:**

          - `UNKNOWN_TYPE` — Unknown type. This value is not used.
          - `OTHER` — Entity is reported for other reasons. Specify in `details`.
          - `SPAM` — Entity is reported for spam.
          - `NUDITY_OR_SEXUAL_HARASSMENT` — Entity is reported for nudity or sexual harassment.
          - `HATE_SPEECH_OR_SYMBOLS` — Entity is reported for hate speech.
          - `FALSE_INFORMATION` — Entity is reported for false information.
          - `COMMUNITY_GUIDELINES_VIOLATION` — Entity is reported for a community guideline violation.
          - `VIOLENCE` — Entity is reported for violence.
          - `SUICIDE_OR_SELF_INJURY` — Entity is reported for mentioning suicide.
          - `UNAUTHORIZED_SALES` — Entity is reported for unuathorized sales.
          - `EATING_DISORDER` — Entity is reported for mentioning an eating disorder.
          - `INVOLVES_A_CHILD` — Entity is reported for involving a minor.
          - `TERRORISM` — Entity is reported for mentioning terrorism.
          - `DRUGS` — Entity is reported for mentioning drugs.
          - `UNLAWFUL` — Entity is reported for unlawful actions.
          - `EXPOSING_IDENTIFYING_INFO` — Entity is reported for exposing identifying details.

        </ResponseField>

        <ResponseField name="details" type="string">

          Why the entity is reported.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the rule is updated. To prevent conflicting changes, the existing revision must be used when updating a rule.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time when the report created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time when the report updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Custom field data for the report object.

      **Note:** You must configure extended fields using schema plugin extensions in your app's dashboard before you can access the extended fields with API calls.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "report": {
          "id": "dd7cfd02-1837-4fb8-bc6f-86316f0984a9",
          "entityName": "comment",
          "entityId": "50353fbc-b265-4f03-888f-a53aa272758d",
          "identity": {
            "identityType": "MEMBER",
            "memberId": "141a3e01-da55-4b3a-a44a-2f194bfc8897"
          },
          "reason": {
            "reasonType": "DRUGS",
            "description": "This person promotes drug usage."
          },
          "revision": "1",
          "createdDate": "2021-10-26T17:22:10.299Z",
          "updatedDate": "2021-10-26T17:22:10.299Z"
        }
      }
      ```

    </CodeGroup>
