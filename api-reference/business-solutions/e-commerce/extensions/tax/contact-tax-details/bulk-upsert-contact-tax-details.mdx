    Creates or updates the tax details of multiple contacts in a single request.

    For each contact, if tax details already exist they're updated. Otherwise, new tax details are created.

    To create or update tax details for a single contact, call [Upsert Contact Tax Details](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/upsert-contact-tax-details).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/bulk/contact-tax-details/upsert
    ```

    ## Body Params

    <ParamField body="contactTaxDetails" type="ContactTaxDetails[]" required>

      Contact tax details to create or update.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Contact Tax Details Object](/api-reference/business-solutions/e-commerce/extensions/tax/contact-tax-details/contact-tax-details-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created or updated contact tax details in the response.

      Default: `false`

    </ParamField>

    <ParamField body="fields" type="string[]">

      Additional fields to return in the response.

      Supported values: `CONTACT_DETAILS`

      Constraints: `maxItems 10`.

      **Supported values:**

      - `CONTACT_DETAILS` — Returns the contact's details, including first name, last name, company, email, and VAT ID.

    </ParamField>
