Triggered when a task is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.tasks.v2.task_updated` |
| Package | `@wix/crm` |
| Permissions | `Read Tasks`, `Manage Tasks` |

## Examples

<CodeGroup>

  ```javascript onTaskUpdated
  import { tasks } from '@wix/crm';

  tasks.onTaskUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onTaskUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';

      publicKey: 'YOUR_APP_PUBLIC_KEY',

      // handle your event here
  ```
