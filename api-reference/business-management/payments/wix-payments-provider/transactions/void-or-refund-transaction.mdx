<Warning>

  **Deprecated.** This method is deprecated.

</Warning>

Voids or refunds the transaction by ID. Voids if the transaction was only authorized. Refunds if the transaction was already captured.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-REFUNDS">Manage Refunds</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
POST https://www.wixapis.com/payments/v3/transactions/{transactionId}/refund
```

## Path Params

<ParamField path="transactionId" type="string" required>

  Transaction ID.

</ParamField>

## Body Params

<ParamField body="accountId" type="string" required>

  Wix Payments account ID.

  Constraints: `format GUID`.

</ParamField>

<ParamField body="amount" type="integer">

  Amount to capture in minor units (for example, cents). Leave empty to capture the whole transaction amount.

</ParamField>

<ParamField body="capturableAmount" type="integer">

  Amount that can be captured or voided in minor units to place a hold on a card to reserve funds.
  Specify the amount to prevent double partial refunds.

</ParamField>

<ParamField body="refundableAmount" type="integer">

  Amount in minor units that can be refunded.
  Specify the amount to prevent double partial refunds.

</ParamField>

<ParamField body="idempotencyKey" type="string">

  Key to ensure idempotency.

</ParamField>

<ParamField body="externalVoidOrRefundId" type="string">

  Corresponding void or refund ID within the external entity that made the request.

</ParamField>

<ParamField body="reason" type="string">

  Reason for void or refund.

  **Supported values:**

  - `OTHER`
  - `FRAUD`
  - `COMPLIANCE`
  - `DUPLICATE_PAYMENT`
  - `ABANDONED_PAYMENT`
  - `MERCHANT_REQUEST`
  - `BUYER_REQUEST`

</ParamField>

<ParamField body="metadata" type="object">

  Metadata to store within the created void or refund.

  Constraints: `format map`, `maxItems 16`.

  <Expandable title="metadata properties">

    <ParamField body="key" type="string" />

    <ParamField body="value" type="string" />

  </Expandable>

</ParamField>

## Response Object

<ResponseField name="transaction" type="Transaction">

  Voided or refunded transaction information.

  See the [Transaction Object](/api-reference/business-management/payments/wix-payments-provider/transactions/transaction-object) for this object's fields.

</ResponseField>

## Errors

| Status | Code | Application code | Description |
| --- | --- | --- | --- |
| `409` | `ALREADY_EXISTS` | `TRANSACTION_ALREADY_VOIDED` | Transaction was already voided. |
| `409` | `ALREADY_EXISTS` | `TRANSACTION_ALREADY_REFUNDED` | Transaction was already refunded. |

<Note>

  This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
