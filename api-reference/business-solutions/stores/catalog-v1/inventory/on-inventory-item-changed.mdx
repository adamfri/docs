Triggered when an inventory item is changed.

## Event details

| Property | Value |
| --- | --- |
| Event type | `com.wix.ecommerce.inventory.api.v1.InventoryItemChanged` |
| Package | `@wix/stores` |
| Permissions | `Manage Stores - all permissions`, `Manage Stores`, `Manage Products`, `Read Stores - all read permissions`, `Read Products` |
