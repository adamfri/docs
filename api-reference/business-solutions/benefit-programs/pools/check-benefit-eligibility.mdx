    <div className="wix-ref">

    Checks if a benefit can currently be redeemed.

    To be redeemed, a benefit's pool must be active and the associated balance must be greater than the cost of the benefit.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/pools/check-eligibility
    ```

    ## Body Params

    <ParamField body="poolId" type="string" required>

      ID of the pool that the benefit to check belongs to.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="benefitKey" type="string">

      Key of the benefit to check.

    </ParamField>

    <ParamField body="itemReference" type="ItemReference" required>

      Information about the item to check.

      <Expandable title="itemReference properties">

        <ParamField body="externalId" type="string" required>

          External ID of the item.

          Constraints: `format GUID`.

        </ParamField>

        <ParamField body="category" type="string">

          Item category.

          Constraints: `maxLength 20`.

        </ParamField>

        <ParamField body="providerAppId" type="string" required>

          ID of the app providing the item.

          Constraints: `format GUID`.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="count" type="integer">

      Amount of items to check.

      Ensures the balance is high enough to redeem this many items.

      Constraints: `min 1`.

    </ParamField>

    <ParamField body="targetDate" type="datetime">

      Date that the item will be provided to the beneficiary.

      This parameter should be used to manage the potential logistics of providing the item.

    </ParamField>

    <ParamField body="additionalData" type="object">

      Additional information.

    </ParamField>

    <ParamField body="beneficiary" type="IdentificationData">

      Beneficiary of the pool containing the benefit to check.

      <Expandable title="One of the following">

        <ParamField body="id" type="id">

          id

          <Expandable title="id properties">

            <ParamField body="anonymousVisitorId" type="string">

              ID of a site visitor that hasn't logged in to the site.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="memberId" type="string">

              ID of a site member.

              Constraints: `format GUID`.

            </ParamField>

            <ParamField body="wixUserId" type="string">

              ID of a Wix user.

              Constraints: `format GUID`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="namespace" type="string" required>

      Namespace for your app or site's benefit programs. Namespaces allow you to distinguish between entities that you created and entities that other apps created.

      Constraints: `minLength 1`, `maxLength 20`.

    </ParamField>

    ## Response Object

    <ResponseField name="result" type="EligibilityCheckResult">

      Result of the eligibility check.

      <Expandable title="result properties">

        <ResponseField name="benefitResults" type="BenefitResult[]">

          Eligibility status.

          Constraints: `maxItems 10`.

          <Expandable title="benefitResults properties">

            <ResponseField name="type" type="string">

              Eligibility status.

              **Supported values:**

              - `ELIGIBLE_BENEFIT` — Item is eligible to be redeemed.
              - `NOT_ENOUGH_BALANCE` — Balance is lower than the cost of redeeming the items.
              - `POOL_NOT_ACTIVE` — Pool isn't active.
              - `BENEFIT_NOT_FOUND` — Invalid benefit details provided.
              - `POOL_NOT_FOUND` — Invalid pool details provided.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
