    Updates the task list on the in-flight assistant turn.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="containers:chat:v1:conversation:relay_tasks">containers:chat:v1:conversation:relay_tasks</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    ## Endpoint

    ```http
    POST https://www.wixapis.com/containers/chat/v1/conversations/{conversationId}/relay-tasks
    ```

    ## Path Params

    <ParamField path="conversationId" type="string" required>

      Conversation ID.

    </ParamField>

    ## Body Params

    <ParamField body="correlationId" type="string" required>

      ID of the user message the assistant turn is responding to.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="tasks" type="Task[]">

      Current task list.

      Constraints: `maxItems 200`.

      <Expandable title="tasks properties">

        <ParamField body="id" type="string">

          Client-supplied task ID, unique within the turn.

          Constraints: `maxLength 100`.

        </ParamField>

        <ParamField body="title" type="string">

          Human-readable task description.

          Constraints: `maxLength 500`.

        </ParamField>

        <ParamField body="status" type="string">

          Current status of the task.

          **Supported values:**

          - `PENDING`
          - `IN_PROGRESS`
          - `DONE_TASK`
          - `FAILED`

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    Returns `RelayTasksResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
