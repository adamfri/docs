    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-GOOGLE-ADS">View google ads campaigns</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/_serverless/pa-google/v1/campaign/daily-budget-boundaries
    ```

    ## Response Object

    <ResponseField name="campaignDailyBudgetBoundaries" type="CampaignDailyBudgetBoundaries">

      The minimum and maximum allowed daily budget for the account's currency and subscription level.

      <Expandable title="campaignDailyBudgetBoundaries properties">

        <ResponseField name="minimumDailyBudget" type="number">

          The minimum daily budget for the campaign.

        </ResponseField>

        <ResponseField name="maximumDailyBudget" type="number">

          The maximum daily budget for the campaign.

        </ResponseField>

        <ResponseField name="minimumDailyBudgetInUsd" type="number">

          The minimum daily budget for the campaign, converted to USD.

          Returned only when the account currency isn't one of the currencies natively supported by Google Ads (USD, EUR, GBP, or JPY).

        </ResponseField>

        <ResponseField name="maximumDailyBudgetInUsd" type="number">

          The maximum daily budget for the campaign, converted to USD.

          Returned only when the account currency isn't one of the currencies natively supported by Google Ads (USD, EUR, GBP, or JPY).

        </ResponseField>

      </Expandable>

    </ResponseField>
