Triggered when a visitor, contact, or member
sends a message to the business.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.crm.inbox.v2.message_message_sent_to_business` |
| Package | `@wix/inbox` |
| Permissions | `Manage Stores`, `Manage Inbox Messages`, `Read Inbox Messages` |

## Examples

<CodeGroup>

  ```javascript onMessageSentToBusiness
  import { messages } from '@wix/inbox';

  messages.onMessageSentToBusiness((event) => {
      // handle your event here
  });
  ```

  ```javascript onMessageSentToBusiness (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { messages } from '@wix/inbox';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        messages,
      },
  });

  wixClient.messages.onMessageSentToBusiness((event) => {
      // handle your event here
  });
  ```

</CodeGroup>
