    Prepares payment for a join application, or resolves an existing Pricing Plans entitlement.

    Before creating or refreshing checkout details, the method checks whether the member already has an eligible Pricing Plans entitlement for the program. If so, it returns the join application with `paymentStatus` set to `PAYMENT_SUCCESSFUL` and the eligible plan IDs in `paymentInfo.paidPlanIds`. No checkout is needed, even when the application was previously in `PAYMENT_PENDING`.

    If no eligible entitlement exists, `paymentStatus` must be `PAYMENT_PENDING`, `PAYMENT_FAILED`, or `PAYMENT_CANCELED`. Calling the method for `PAYMENT_FAILED` or `PAYMENT_CANCELED` retries payment by replacing stale payment details with newly prepared ones.

    Specify `paymentType` to choose the flow:

    - `SINGLE_PAYMENT`: Creates a Wix Payments order and sets `paymentStatus` to `PAYMENT_IN_PROGRESS`.
    - `PAID_PLANS`: Validates that pricing plans are connected to the program and sets `paymentStatus` to `PAYMENT_IN_PROGRESS`.

    Check the returned `paymentStatus` before starting checkout, and direct the member to checkout only when it's `PAYMENT_IN_PROGRESS`. To apply a discount before the member completes a Wix Payments checkout, call [Apply Coupon](https://dev.wix.com/docs/api-reference/business-management/online-programs/join-applications/apply-coupon).

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/participants/v3/join-applications/{joinApplicationId}/prepare-payment
    ```

    ## Path Params

    <ParamField path="joinApplicationId" type="string" required>

      ID of the join application to prepare payment for.

    </ParamField>

    ## Body Params

    <ParamField body="paymentType" type="string" required>

      Type of payment to prepare.

      **Supported values:**

      - `SINGLE_PAYMENT` — One-time payment through Wix Payments.
      - `PAID_PLANS` — Payment through Wix Pricing Plans.

    </ParamField>

    ## Response Object

    <ResponseField name="joinApplication" type="JoinApplication">

      Join application with refreshed payment info. Check `paymentStatus` before directing the member to checkout.

      See the [Join Application Object](/api-reference/business-management/online-programs/join-applications/join-application-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `OP_APP_NOT_INSTALLED` | Online Programs isn't installed on the site. |
    | `428` | `FAILED_PRECONDITION` | `PP_APP_NOT_INSTALLED` | Pricing Plans isn't installed on the site. |
    | `404` | `NOT_FOUND` | `NO_PAID_PLAN_CONNECTED` | No paid plan is connected to the program. |
    | `428` | `FAILED_PRECONDITION` | `INVALID_PAYMENT_STATUS` | The join application's `paymentStatus` doesn't permit preparing payment. Allowed from `PAYMENT_PENDING`, `PAYMENT_FAILED`, and `PAYMENT_CANCELED`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
