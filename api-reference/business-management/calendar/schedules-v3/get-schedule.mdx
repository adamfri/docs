    Retrieves a schedule.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PUBLIC">Read Calendar</span>
    <span className="wix-scope" title="SCOPE.DC-CALENDAR.READ-PI">Read Calendar - Including PI</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/calendar/v3/schedules/{scheduleId}
    ```

    ## Path Params

    <ParamField path="scheduleId" type="string" required>

      ID of the schedule to retrieve.

    </ParamField>

    ## Query Params

    <ParamField query="fields" type="string[]">

      Information about which fields containing personal data to return. Refer to the
      [permissions article](https://dev.wix.com/docs/rest/business-management/calendar/permissions)
      for more information.

      Supported values:
      + `PI_FIELDS`: Returns all fields with personal data. Your app must have `Read Calendars - Including PI` or `Manage Calendars` permission scope.
      + `OWN_PI_FIELDS`: Returns only fields containing your own personal data.

      Max: 1 field
      Default: No personal data is returned.

      Constraints: `maxItems 1`.

      **Supported values:**

      - `PI_FIELDS` — Returns all fields with personal data. Your app must have `Read Calendars - Including PI` or `Manage Calendars` permission scope.
      - `OWN_PI_FIELDS` — Returns only fields containing your own personal data.

    </ParamField>

    ## Response Object

    <ResponseField name="schedule" type="Schedule">

      Retrieved schedule.

      See the [Schedule Object](/api-reference/business-management/calendar/schedules-v3/schedule-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
