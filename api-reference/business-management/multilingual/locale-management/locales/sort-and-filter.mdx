This article covers field support for filtering and sorting in the Locale API.

## Query Contents

The following table shows field support for filters and sorting for the locale object when using [Query Locales](fallback::https://dev.wix.com/docs/rest/business-management/multilingual/locales/locale/query-locales):

| Field               | Supported Filters                                                              | Sortable   |
| --------------------| ------------------------------------------------------------------------------ | ---------- |
| `id`                | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `languageCode`      | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `regionCode`        | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `visibility`        | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `primaryLocale`     | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `flag`              | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `regionalFormat`    | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
| `effectiveUrlStructure` | `eq`, `ne`, `exists`, `in`, `hasSome`, `startsWith`, `ascending`, `descending` |  Sortable  |
