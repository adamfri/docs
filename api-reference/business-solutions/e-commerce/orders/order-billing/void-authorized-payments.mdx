    Voids (cancels) previously authorized payments, releasing the authorization hold without charging the customer.

    Use this method when you no longer need to capture an authorized payment, such as when an order is cancelled
    or when inventory becomes unavailable after authorization.

    *Note**: Only payments with `AUTHORIZED` status can be voided. Already captured payments cannot be voided.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/order-billing/void-authorized-payments
    ```

    ## Body Params

    <ParamField body="orderId" type="string" required>

      ID of the order containing the payments to void.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="paymentIds" type="string[]" required>

      IDs of authorized payments to void (cancel).

      Only payments with `AUTHORIZED` status can be voided.

      Constraints: `format GUID`, `minItems 1`, `maxItems 100`.

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `404` | `NOT_FOUND` | `PAYMENT_NOT_FOUND` | Couldn't find the payment. |
    | `404` | `NOT_FOUND` | `GATEWAY_TRANSACTION_NOT_FOUND` | Couldn't find the gateway transaction. |
    | `409` | `ALREADY_EXISTS` | `PAYMENT_ALREADY_VOIDED` | Payment was already voided. |
    | `428` | `FAILED_PRECONDITION` | `PAYMENT_ALREADY_CAPTURED` | Payment was already captured. |
