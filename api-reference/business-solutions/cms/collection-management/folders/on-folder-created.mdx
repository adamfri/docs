Triggered when a folder is created.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.cloud.autocms.v1.folder_created` |
| Package | `@wix/autocms-folders-service` |
| Permissions | `Manage Data Collections` |

## Examples

<CodeGroup>

  ```javascript onFolderCreated
  import { folders } from '@wix/autocms-folders-service';

  folders.onFolderCreated((event) => {
      // handle your event here
  });
  ```

  ```javascript onFolderCreated (self-managed)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { folders } from '@wix/autocms-folders-service';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
    }),
    modules: {
        folders,
      },
  });

  wixClient.folders.onFolderCreated((event) => {
      // handle your event here
  });
  ```
