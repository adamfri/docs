    Creates a program for the specified beneficiary. Creating a program is also referred to as provisioning a program.

    You can provision a program from a program definition or a pool definition:
    - **Program definition**: The provisioned program has pools that are created from the pool definitions in the program definition.
    - **Pool definition**: The provisioned program has 1 pool that is created from the pool definition.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.BENEFIT_PROGRAMS.MANAGE">Manage benefit programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/benefit-programs/v1/programs/provision
    ```
