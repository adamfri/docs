title: "Operation Object"
description: "An operation is a service a restaurant offers that includes various aspects of its online ordering."

An operation is a service a restaurant offers that includes various aspects of its online ordering.
You can define default fulfillments, service fees, and scheduling requirements for each operation.

<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Operation ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number. Increments by 1 each time the operation is updated.
      To prevent conflicting changes,
      the existing `revision` must be specified when updating an operation.

      **Read-only.**

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the operation was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the operation was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="name" type="string">

      Operation name.

    </ResponseField>

    <ResponseField name="default" type="boolean">

      Whether the operation is the default operation. &lt;br />
      Default: `false`.

    </ResponseField>

    <ResponseField name="fulfillmentIds" type="string[]">

      IDs of the fulfillment methods ([SDK](https://dev.wix.com/docs/sdk/backend-modules/restaurants/wix-restaurants-new/fulfillment-methods/introduction) | [REST](https://dev.wix.com/docs/rest/api-reference/wix-restaurants/fulfillment-methods/introduction)) associated with the operation.

      Constraints: `format GUID`, `maxItems 500`.

    </ResponseField>

    <ResponseField name="onlineOrderingStatus" type="string">

      Online ordering status of the operation. &lt;br />

      **Supported values:**

      - `UNDEFINED_ONLINE_ORDERING_STATUS` — Online ordering status is not defined.
      - `ENABLED` — Operation currently accepts online orders.
      - `DISABLED` — Operation currently does not accept online orders.
      - `PAUSED_UNTIL` — Operation currently does not accept online orders, but will accept online orders from a specified time and date. When applied, `pausedUntilOptions` is a required field.

    </ResponseField>

    <ResponseField name="defaultFulfillmentType" type="string">

      Default fulfillment type of the operation.

      **Supported values:**

      - `PICKUP` — Pickup fulfillment. The customer picks up the order from the restaurant.
      - `DELIVERY` — Delivery fulfillment. The restaurant, or a representative, delivers the order to the customer.

    </ResponseField>

    <ResponseField name="orderScheduling" type="OrderScheduling">

      Information about when an order can be placed for.

      <Expandable title="orderScheduling properties">

        <ResponseField name="type" type="string">

          Scheduling type. &lt;br />
          - When `ASAP`, `asapOptions` is a required field.
          - When `PREORDER`, `preorderOptions` is a required field.

          **Supported values:**

          - `ASAP` — Orders can be scheduled for the future and to be handled immediately.
          - `PREORDER` — Orders can be scheduled only for the future.

        </ResponseField>

      </Expandable>

      <Expandable title="One of the following">

        <ResponseField name="orderSchedulingOptions" type="orderSchedulingOptions">

          orderSchedulingOptions

          <Expandable title="orderSchedulingOptions properties">

            <ResponseField name="asapOptions" type="AsapOrderScheduling">

              Options for scheduling. Required if `type` is `ASAP`.

              <Expandable title="asapOptions properties">

                <ResponseField name="preparationTime" type="PreparationTime">

                  Amount of time needed to prepare the order. &lt;br />
                  - When `MAX_TIME`, `maxTimeOptions` is a required field.
                  - When `MAX_RANGE`, `timeRangeOptions` is a required field.

                  _Nested structure omitted for brevity — see the `PreparationTime` object._

                </ResponseField>

                <ResponseField name="asapFutureHandlingType" type="string">

                  Defines if and how non-immediate orders should be handled. &lt;br />
                  When this value is `BUSINESS_DAYS_AHEAD_HANDLING`, `businessDaysAheadHandlingOptions` is a required field.

                  **Supported values:**

                  - `NO_FUTURE_HANDLING` — No future handling.
                  - `BUSINESS_DAYS_AHEAD_HANDLING` — Allows future orders for up to a specified number of business days ahead.

                </ResponseField>

              </Expandable>

              <Expandable title="One of the following">

                <ResponseField name="asapFutureHandlingOptions" type="asapFutureHandlingOptions">

                  asapFutureHandlingOptions

                  _Nested structure omitted for brevity — see the `asapFutureHandlingOptions` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

            <ResponseField name="preorderOptions" type="PreorderScheduling">

              Options for scheduling. Required if `type` is `PREORDER`.

              <Expandable title="preorderOptions properties">

                <ResponseField name="method" type="PreorderMethod">

                  Method for `PREORDER` scheduling type.

                  _Nested structure omitted for brevity — see the `PreorderMethod` object._

                </ResponseField>

                <ResponseField name="fulfillmentTimesDisplay" type="FulfillmentTimesDisplayConfig">

                  Configuration of the fulfillment times. &lt;br />
                  Currently, only `TIME_WINDOWS` is supported.

                  _Nested structure omitted for brevity — see the `FulfillmentTimesDisplayConfig` object._

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="operationGroupId" type="string">

      ID of the operation group this operation belongs to.

    </ResponseField>

    <ResponseField name="businessLocationId" type="string">

      ID of the business location ([SDK](https://dev.wix.com/docs/sdk/backend-modules/restaurants/wix-restaurants-new/about-business-locations) | [REST](https://dev.wix.com/docs/rest/business-solutions/restaurants/wix-restaurants-new/about-business-locations)) of this operation.

      **Read-only.**

    </ResponseField>

    <ResponseField name="extendedFields" type="ExtendedFields">

      Extended fields.

      <Expandable title="extendedFields properties">

        <ResponseField name="namespaces" type="object">

          Extended field data. Each key corresponds to the namespace of the app that created the extended fields.
          The value of each key is structured according to the schema defined when the extended fields were configured.

          You can only access fields for which you have the appropriate permissions.

          Learn more about [extended fields](https://dev.wix.com/docs/rest/articles/getting-started/extended-fields).

          Constraints: `format map`.

          <Expandable title="namespaces properties">

            <ResponseField name="key" type="string" />

            <ResponseField name="value" type="object" />

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="tags" type="Tags">

      Tags ([SDK](https://dev.wix.com/docs/sdk/backend-modules/tags/tags/introduction) | [REST](https://dev.wix.com/docs/rest/business-management/tags/introduction)) used to classify and sort different types of operations.

      <Expandable title="tags properties">

        <ResponseField name="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="tags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="tags properties">

            <ResponseField name="tagIds" type="string[]">

              List of tag IDs

              Constraints: `maxLength 5`, `maxItems 100`.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>
