    Creates a new review using a contact ID.

    This method requires a contact ID, see the [Contacts API](https://dev.wix.com/docs/rest/crm/members-contacts/contacts/contacts/introduction).

    After a review is created, it may require moderation, see the introduction for the Reviews API for more information about moderation.

    If the `authorName` field is empty, and the review author:
    - is a site member, their member name is used.
    - isn't a site member, the field is set to `null`.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-REVIEWS.MANAGE-REVIEWS">Manage Reviews</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/reviews/v1/reviews
    ```

    ## Body Params

    <ParamField body="review" type="Review" required>

      Review data.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="review" type="Review">

      Created review.

      See the [Review Object](/api-reference/crm/community/feedback-moderation/reviews/reviews/review-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Review Created | `wix.reviews.v1.review_created` | Triggered when a review is created. |
    | Review Published | `wix.reviews.v1.review_review_published` | Triggered when a review's moderation status is set to `"APPROVED"`. |

    </div>
