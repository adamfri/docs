  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Deletes a comment.

    This method deletes the `content` of the comment and sets its `status` to `DELETED`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC_COMMENTS.MANAGE.COMMENTS">Manage Comments</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    DELETE https://www.wixapis.com/comments/v1/comments/{commentId}
    ```

    ## Path Params

    <ParamField path="commentId" type="string" required>

      ID of the comment to delete.

    </ParamField>

    ## Response Object

    Returns `DeleteCommentResponse`.

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Comment Updated | `wix.comments.v2.comment_updated` | Triggered when a comment is updated. |
    | Comment Deleted | `wix.comments.v2.comment_comment_deleted` | Triggered when a comment is deleted, internal use. This event should be deprecated in favor of the DELETED event with full entity. |
    | Resource Comment Count Changed | `wix.comments.v2.comment_resource_comment_count_changed` | Triggered when the total number of comments has changed in a resource. |
    | Comment Deleted | `wix.comments.v2.comment_deleted` | Triggered when a comment is deleted. |

    </div>
