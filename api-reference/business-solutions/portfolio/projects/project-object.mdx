<Tabs>

  <Tab title="REST">

    <ResponseField name="id" type="string">

      Project ID.

      **Read-only.**

    </ResponseField>

    <ResponseField name="revision" type="integer">

      Revision number, which increments by 1 each time the project is updated. To prevent conflicting changes, the existing revision must be passed when updating the project object.

      **Read-only.**

    </ResponseField>

    <ResponseField name="title" type="string">

      Project title.

    </ResponseField>

    <ResponseField name="description" type="string">

      Project description.

    </ResponseField>

    <ResponseField name="hidden" type="boolean">

      Whether the project is hidden from the portfolio. Default: `false`

    </ResponseField>

    <ResponseField name="collectionIds" type="string[]">

      IDs of the collections that include the project.

      Constraints: `format GUID`, `maxItems 1000`.

    </ResponseField>

    <ResponseField name="details" type="ProjectDetail[]">

      Project details.

      <Expandable title="details properties">

        <ResponseField name="label" type="string">

          Project label.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="slug" type="string">

      Project slug.

    </ResponseField>

    <ResponseField name="createdDate" type="datetime">

      Date and time the project was created.

      **Read-only.**

    </ResponseField>

    <ResponseField name="updatedDate" type="datetime">

      Date and time the project was updated.

      **Read-only.**

    </ResponseField>

    <ResponseField name="url" type="PageUrlV2">

      Project page URL and relative path. Returned when `includePageUrl` is `true` in the request.

      **Read-only.**

      <Expandable title="url properties">

        <ResponseField name="relativePath" type="string">

          The relative path for the page within the site. For example, `/product-page/a-product`.

        </ResponseField>

        <ResponseField name="url" type="string">

          The page's full URL. For example, `https://mysite.com/product-page/a-product`.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="seoData" type="SeoSchema">

      Project SEO data.

      <Expandable title="seoData properties">

        <ResponseField name="tags" type="Tag[]">

          SEO tag information.

          <Expandable title="tags properties">

            <ResponseField name="type" type="string">

              SEO tag type.

              Supported values: `title`, `meta`, `script`, `link`.

            </ResponseField>

            <ResponseField name="props" type="object">

              A `{"key": "value"}` pair object where each SEO tag property (`"name"`, `"content"`, `"rel"`, `"href"`) contains a value.
              For example: `{"name": "description", "content": "the description itself"}`.

            </ResponseField>

            <ResponseField name="meta" type="object">

              SEO tag metadata. For example, `{"height": 300, "width": 240}`.

            </ResponseField>

            <ResponseField name="children" type="string">

              SEO tag inner content. For example, `<title> inner content </title>`.

            </ResponseField>

            <ResponseField name="custom" type="boolean">

              Whether the tag is a [custom tag](https://support.wix.com/en/article/adding-additional-meta-tags-to-your-sites-pages) —
              i.e. an entry from the site's Advanced/Custom Tags list.

              This flag is scoped to that feature only. It is NOT an indicator of whether a standard tag
              (`title`, `description`, Open Graph, etc.) reflects a manually configured value versus a computed
              default/pattern — standard tags always resolve with `custom: false`, even when their content comes
              from a page's manually saved SEO title/description override. Don't use this field to verify whether
              a live page reflects a manual per-page SEO edit.

              Limitation: when `ResolveStaticPageSeoTags` is called without `seoData`, the per-page SEO data is read
              only from the Vibe/Wix-managed-headless override store. That store holds nothing for classic Wix Editor
              or Wix Studio pages, so even genuine Advanced/Custom Tags saved on those pages are missing from the
              response entirely — there, `false` means this API could not tell, not that no custom tag exists.
              Pass `seoData` explicitly to resolve against a known set of tags.

            </ResponseField>

            <ResponseField name="disabled" type="boolean">

              Whether the tag is disabled. If the tag is disabled, people can't find your page when searching for this phrase in search engines.

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="settings" type="Settings">

          SEO general settings.

          <Expandable title="settings properties">

            <ResponseField name="preventAutoRedirect" type="boolean">

              Whether the [automatical redirect visits](https://support.wix.com/en/article/customizing-your-pages-seo-settings-in-the-seo-panel) from the old URL to the new one is enabled.

              Default: `false` (automatical redirect is enabled).

            </ResponseField>

            <ResponseField name="keywords" type="Keyword[]">

              User-selected keyword terms for a specific page.

              Constraints: `maxItems 5`.

              <Expandable title="keywords properties">

                <ResponseField name="term" type="string">

                  Keyword value.

                </ResponseField>

                <ResponseField name="isMain" type="boolean">

                  Whether the keyword is the main focus keyword.

                </ResponseField>

                <ResponseField name="origin" type="string">

                  The source that added the keyword terms to the SEO settings.

                </ResponseField>

              </Expandable>

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="watermark" type="Watermark">

      Optional watermark that can be applied to all project's images.

      <Expandable title="watermark properties">

        <ResponseField name="position" type="string">

          Position of the watermark on the image.

          **Supported values:**

          - `NORTH_WEST`
          - `NORTH`
          - `NORTH_EAST`
          - `WEST`
          - `CENTER`
          - `EAST`
          - `SOUTH_WEST`
          - `SOUTH`
          - `SOUTH_EAST`

        </ResponseField>

        <ResponseField name="size" type="integer">

          Size of the watermark, from 0 to 100.

          Constraints: `min 0`, `max 100`.

        </ResponseField>

        <ResponseField name="opacity" type="integer">

          Opacity of the watermark.

          Constraints: `min 1`, `max 100`.

        </ResponseField>

        <ResponseField name="imageUrl" type="string">

          Image ID of the Watermark as saved in Media Platform.

          Constraints: `maxLength 300`.

        </ResponseField>

        <ResponseField name="enabled" type="boolean">

          Whether the watermark is to be displayed on Items & Cover Photos.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Example

    <CodeGroup>

      ```json Object
      {
        "id": "123e4567-e89b-12d3-a456-426614174000",
        "revision": 5,
        "title": "Sample Project",
        "description": "This is a sample description for the project.",
        "hidden": false,
        "coverImage": {
          "imageInfo": {
            "id": "64c4566-e87b-77d3-a456-4266141779902",
            "url": "https://example.com/cover.jpg",
            "altText": "Project cover image"
          }
        },
        "collectionIds": [
          "123e4567-e89b-12d3-a456-426614174001",
          "123e4567-e89b-12d3-a456-426614174002"
        ],
        "details": [
        {
          "label": "GitHub",
          "link": {
            "text": "View on GitHub",
            "url": "https://github.com/example/project",
            "target": "_blank"
          }
        },
        {
          "label": "Description",
          "text": "A detailed description of the project."
        }
        ],
        "slug": "sample-project",
        "createdDate": "2024-07-31T12:00:00Z",
        "updatedDate": "2024-07-31T12:00:00Z",
        "url": {
          "relativePath": "/project/sample-project",
          "url": "https://portfolio.com/project/sample-project"
        }
      }
      ```
