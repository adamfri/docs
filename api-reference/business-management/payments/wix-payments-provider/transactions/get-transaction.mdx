Retrieves transaction info by ID.

<Note>

  **Authentication**

  You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

</Note>

## Permissions

This method requires one of the following permission scopes:

<div className="wix-scopes">

<span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-TRANSACTIONS">Manage Transactions</span>

</div>

Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

Callable by: `APP`.

## Endpoint

```http
GET https://www.wixapis.com/payments/v3/transactions/{transactionId}
```

## Path Params

<ParamField path="transactionId" type="string" required>

  Transaction ID.

</ParamField>

## Query Params

<ParamField query="accountId" type="string" required>

  Wix Payments account ID.

  Constraints: `format GUID`.

</ParamField>

## Response Object

<ResponseField name="transaction" type="Transaction">

  Transaction information.

  See the [Transaction Object](/api-reference/business-management/payments/wix-payments-provider/transactions/transaction-object) for this object's fields.

</ResponseField>

## Errors

<Note>

  This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

</Note>
