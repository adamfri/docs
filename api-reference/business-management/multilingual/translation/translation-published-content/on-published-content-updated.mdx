Triggered when published content is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.multilingual.localization_public.v3.published_content_updated` |
| Package | `@wix/multilingual` |
| Permissions | `Wix Multilingual - Translation API`, `Wix Multilingual - Translation Content + Published Content Read` |
