    Creates a copy of an existing form schema with a new ID.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/form-schema-service/v4/forms/{formId}/clone
    ```

    ## Path Params

    <ParamField path="formId" type="string" required>

      ID of the form schema to clone.

    </ParamField>

    ## Response Object

    <ResponseField name="form" type="Form">

      Cloned form schema.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ## Event Triggers

    This method triggers the following events:

    | Event | Type | Description |
    | --- | --- | --- |
    | Form Created | `wix.forms.v4.form_created` | Triggers when a form schema is created. |

    </div>
