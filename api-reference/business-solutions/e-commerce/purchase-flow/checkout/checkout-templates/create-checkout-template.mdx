    Creates a checkout template.

    A checkout template is used to create a new checkout that will include predefined information. For example, a single link with
    a `checkoutTemplateId` can be shared with customers and each time the link is clicked, a new checkout page will be created
    for that customer with certain checkout information already populated.

    The customizable features include the option to allow or to lock coupon codes or gift cards. For example, if a store owner is
    using the checkout template to offer a flash sale to their social media followers, they may want to lock the option to apply an
    additional coupon on top of the sale being offered. If so, they can set `customization.lockedCoupon` to `true`.

    A checkout can be created with a checkout template by calling Create Checkout From Template.
    The site may add further customizations to the new checkout and then redirect the customer using the new checkout's `checkoutUrl`.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/checkout-templates
    ```

    ## Body Params

    <ParamField body="checkoutTemplate" type="CheckoutTemplate" required>

      Checkout template to create.

      See the [Checkout Template Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout-templates/checkout-template-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="checkoutTemplate" type="CheckoutTemplate">

      Created checkout template.

      See the [Checkout Template Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout-templates/checkout-template-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_CREATE_CHECKOUT_TEMPLATE_WITHOUT_ITEMS` | Checkout template must have at least 1 item. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
