    Creates a tax exempt group.

    Creating a tax exempt group only defines the group. To make its members exempt, assign the group reduced or zero override rates on the relevant manual tax mappings, then associate customers with the group through their contact tax details.

    To create multiple tax exempt groups in a single API call, call [Bulk Create Tax Exempt Groups](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/extensions/tax/tax-exempt-groups/bulk-create-tax-exempt-groups).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.MANAGE-ORDERS">Manage Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/billing/v1/tax-exempt-groups
    ```
