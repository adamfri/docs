    Updates a single plan.

    To update multiple plans at once, call Bulk Update Plans.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAIDPLANS.MANAGE-PLANS">Manage Pricing Plans</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/pricing-plans/v3/plans/{plan.id}
    ```

    ## Path Params

    <ParamField path="plan.id" type="string" required>

      Plan ID.

    </ParamField>

    ## Body Params

    <ParamField body="plan" type="Plan" required>

      plan to update.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-v3/plan-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="plan" type="Plan">

      Updated plan.

      See the [Plan Object](/api-reference/business-solutions/pricing-plans/plans-v3/plan-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `NAME_NOT_BLANK` | Plan or fee `name` can't be blank. |
    | `400` | `INVALID_ARGUMENT` | `VALID_BILLING_CYCLE` | Billing cycle must be at least 7 days and can't exceed 10 years. |
    | `400` | `INVALID_ARGUMENT` | `VALID_PLAN_DURATION` | Plan duration can't exceed 10 years. |
    | `400` | `INVALID_ARGUMENT` | `FREE_PRICING_VARIANT_IS_NOT_RECURRING` | Recurring plans can't be free. |
    | `400` | `INVALID_ARGUMENT` | `FREE_TRIAL_IS_APPLICABLE` | Only recurring paid plans can have a free trial. |
    | `400` | `INVALID_ARGUMENT` | `CYCLES_COMPLETED_END_OPTION_IS_APPLICABLE` | Plans with `endType` set to `CYCLES_COMPLETED` must specify the number of billing cycles. |
    | `400` | `INVALID_ARGUMENT` | `PRICING_VARIANT_IDS_UNIQUE` | All pricing variant IDs in the plan must be unique. |
    | `400` | `INVALID_ARGUMENT` | `FEE_IDS_UNIQUE` | All fee IDs in the plan must be unique. |
    | `400` | `INVALID_ARGUMENT` | `PRICE_OVERRIDE_IDS_UNIQUE` | All price override IDs within a pricing variant must be unique. |
    | `400` | `INVALID_ARGUMENT` | `FEE_OVERRIDE_IDS_UNIQUE` | All fee override IDs within a pricing variant must be unique. |
    | `400` | `INVALID_ARGUMENT` | `FEE_OVERRIDE_FEE_EXISTS` | Fee overrides must reference a fee on the same pricing variant. |
    | `400` | `INVALID_ARGUMENT` | `VALID_DATE_RANGE` | Configured date ranges must have valid boundaries. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_AMOUNT` | Monetary amounts can't have more decimal places than the plan currency supports. |
    | `400` | `INVALID_ARGUMENT` | `PERK_IDS_UNIQUE` | All perk IDs in the plan must be unique. |
    | `400` | `INVALID_ARGUMENT` | `AT_LEAST_ONE_ACTIVE_VARIANT` | At least one pricing variant must be active. |
    | `400` | `INVALID_ARGUMENT` | `REQUIRED_FIELD` | The `slug` field can't be empty. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).
