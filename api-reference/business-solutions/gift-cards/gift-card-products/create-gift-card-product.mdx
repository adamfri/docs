    Creates a gift card product.

    A site currently supports a maximum of 1 gift card product. This is a temporary limitation that will be removed in a future release. To replace the existing product, call [Delete Gift Card Product](https://dev.wix.com/docs/api-reference/business-solutions/gift-cards/gift-card-products/delete-gift-card-product) first, or use [Update Gift Card Product](https://dev.wix.com/docs/api-reference/business-solutions/gift-cards/gift-card-products/update-gift-card-product) to modify it in place.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gift-cards/v1/gift-card-products
    ```

    ## Body Params

    <ParamField body="giftCardProduct" type="GiftCardProduct" required>

      Gift card product to create.

      See the [Gift Card Product Object](/api-reference/business-solutions/gift-cards/gift-card-products/gift-card-product-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="giftCardProduct" type="GiftCardProduct">

      Created gift card product.

      See the [Gift Card Product Object](/api-reference/business-solutions/gift-cards/gift-card-products/gift-card-product-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `409` | `ALREADY_EXISTS` | `GIFT_CARD_PRODUCT_ALREADY_EXISTS` | A gift card product already exists on this site. A site currently supports a maximum of 1 gift card product. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_CREATE_GIFT_CARD_PRODUCT_WITHOUT_VARIANTS` | The gift card product must have at least one preset variant or a custom variant. |
    | `428` | `FAILED_PRECONDITION` | `CANNOT_CREATE_GIFT_CARD_PRODUCT_WITH_PAST_EXPIRATION_DATE` | The `fixedExpirationDate` can't be in the past. |
    | `400` | `INVALID_ARGUMENT` | `CANNOT_CREATE_GIFT_CARD_PRODUCT_WITH_INVALID_CUSTOM_AMOUNTS_RANGE` | The custom variant's `minValue` must be less than `maxValue`. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
