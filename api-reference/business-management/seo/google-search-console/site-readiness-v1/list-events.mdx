    Retrieves the history of Google Search Console setup events for the site:
    when it was connected, verified, added, and when sitemaps and indexing
    were last submitted.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.VIEW-SEO">View SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/gsc/v1/events
    ```

    ## Response Object

    <ResponseField name="events" type="Event[]">

      The site's Google Search Console setup events, with the date each event
      last occurred.

      Constraints: `maxItems 20`.

      <Expandable title="events properties">

        <ResponseField name="eventType" type="string">

          What happened.

          **Read-only.**

          **Supported values:**

          - `UNKNOWN_EVENT_TYPE` — Unknown event type.
          - `ACCOUNT_CONNECTED` — A Google account was connected to the site.
          - `SITE_VERIFIED` — Site ownership was verified with Google.
          - `SITE_ADDED` — The site was added to Google Search Console.
          - `SITEMAP_SUBMITTED` — The site's sitemap was submitted to Google.
          - `SITE_INDEXING_REQUESTED` — Site indexing was requested.
          - `PAGE_INDEXING_REQUESTED` — Page indexing was requested.

        </ResponseField>

        <ResponseField name="occurredDate" type="datetime">

          Date and time the event last occurred.

          **Read-only.**

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
