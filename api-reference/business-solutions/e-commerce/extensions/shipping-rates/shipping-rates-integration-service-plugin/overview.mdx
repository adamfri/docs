Describes the Shipping Rates integration to be called by Wix and received by the relevant shipping rates providers. This integration is used to get shipping rates based on, for example, the shipped item or the address for delivery.

## SDK package

```bash
npm install @wix/ecom
```

Import the `shippingRates` namespace from `@wix/ecom`.
