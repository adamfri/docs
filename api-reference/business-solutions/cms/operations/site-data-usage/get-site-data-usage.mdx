    <div className="wix-ref">

    Retrieves the current data usage and resource limits for a site.

    By default, returns cached values. Set `consistentRead` to `true` to retrieve real-time values.
    <Note>

    that using `consistentRead` results in a slower response and should only be used when near real-time accuracy is needed. For example, just before enforcing a resource limit.

    </Note>

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.SITE_DATA_USAGE_READ">SCOPE.DC-DATA.SITE_DATA_USAGE_READ</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/wix-data/v1/site-data-usage/v1/site-data-usage
    ```

    ## Query Params

    <ParamField query="fields" type="string[]">

      Fields to return in the response. If not provided, all fields are returned.

      Supported properties:
      `storageLimitInBytes`, `itemCountLimit`, `collectionCountLimit`, `collectionCount`,
      `totalUsedLive`, `totalUsedSandbox`, `dataCollectionUsages`

      Constraints: `maxLength 1000`, `maxItems 1000`.

    </ParamField>

    <ParamField query="consistentRead" type="boolean">

      Whether to return real-time values instead of cached values.

      Setting this to `true` results in a slower response. Use only when near real-time accuracy
      is critical, such as just before enforcing a resource limit.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="siteDataUsage" type="SiteDataUsage">

      Retrieved site data usage.

      See the [Site Data Usage Object](/api-reference/business-solutions/cms/operations/site-data-usage/site-data-usage-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
