    Creates a new badge.

    New badges do not have any badge permissions by default.
    Wix users can set badge permissions from the [Badges page in the dashboard](https://support.wix.com/en/article/site-members-creating-and-managing-member-badges?tabs=Dashboard-0#managing-member-badges).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v3/badges
    ```

    ## Body Params

    <ParamField body="badge" type="Badge" required>

      Badge to create.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges/badge-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="badge" type="Badge">

      Created badge.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges/badge-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    ```javascript Create an expert contributor badge
    import { badges } from '@wix/members';
    import { items } from '@wix/data';

    /* Sample badge value:
     * {
     *     backgroundColor: "#42A5F5",
     *     description: "Expert Contributor Badge",
     *     icon: "http://example.com/expert-badge-icon.svg",
     *     permissionsEnabled: true,
     *     textColor: "#FFFFFF",
     *     title: "Expert Contributor Badge"
     *   }
     * }
     */

    export async function createExpertContributorBadge(memberId) {
      const EXPERT_THRESHOLD = 5; // Minimum number of blog posts to be considered an expert contributor
      const SUBJECT_KEYWORD = 'velo'; // Subject keyword for blog posts

      // Count the number of blog posts created by the member with the given ID on the subject of 'velo'
      const blogPostsCount = await items.query('BlogPosts')
        .eq('author', memberId)
        .contains('tags', SUBJECT_KEYWORD)
        .count();

      // Count if the member meets the criteria to be an expert contributor
      if (blogPostsCount >= EXPERT_THRESHOLD) {
        const expertBadge = {
          backgroundColor: "#42A5F5",
          description: "Expert Contributor Badge",
          icon: "http://example.com/expert-badge-icon.svg",
          permissionsEnabled: true,
          textColor: "#FFFFFF",
          title: "Expert Contributor Badge"
        };

        try {
          const newExpertBadge = await badges.createBadge(expertBadge);

          console.log('Expert badge created for member ', memberId, ': ', newExpertBadge);
          return newExpertBadge;
        } catch (error) {
            console.error('Error creating expert badge:', error);
            // Handle the error
        }
      } else {
          console.log('Member with ID ', memberId, ' does not meet the criteria for the expert badge.');
      }
    }
    ```
