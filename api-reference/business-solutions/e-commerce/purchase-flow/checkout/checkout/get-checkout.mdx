    Retrieves a checkout.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-STORES.READ-ORDERS">Read Orders</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`, `MEMBER`, `VISITOR`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/ecom/v1/checkouts/{id}
    ```

    ## Path Params

    <ParamField path="id" type="string" required>

      Checkout ID.

    </ParamField>

    ## Response Object

    <ResponseField name="checkout" type="Checkout">

      Retrieved checkout.

      See the [Checkout Object](/api-reference/business-solutions/e-commerce/purchase-flow/checkout/checkout/checkout-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
