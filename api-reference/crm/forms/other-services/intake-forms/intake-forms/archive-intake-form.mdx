    <div className="wix-ref">

    Archives an intake form, disabling it from accepting new submissions.

    Existing submissions remain accessible. You can [unarchive](https://dev.wix.com/docs/api-reference/crm/forms/other-services/intake-forms/intake-forms/unarchive-intake-form) the form later to resume accepting submissions.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.INTAKE-FORM.MANAGE_LIMITED">Manage Intake Form (PII)</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/_api/intake-forms/v1/intake-forms/{intakeFormId}/archive
    ```

    ## Path Params

    <ParamField path="intakeFormId" type="string" required>

      Intake form ID.

    </ParamField>

    ## Body Params

    <ParamField body="formRevision" type="integer" required>

      Revision number, which increments by 1 each time the intake form is updated.
      To prevent conflicting changes, you must specify the current revision when updating the intake form.

    </ParamField>

    ## Response Object

    <ResponseField name="intakeForm" type="IntakeForm">

      Archived intake form.

      See the [Intake Form Object](/api-reference/crm/forms/other-services/intake-forms/intake-forms/intake-form-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
