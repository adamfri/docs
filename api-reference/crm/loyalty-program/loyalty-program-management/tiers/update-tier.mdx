    Updates a loyalty tier.

    Call this method to update tier-specific settings, such as the name and the required points
    threshold of an individual loyalty tier. To update global settings that apply to all of a site's loyalty tiers,
    call Update Tiers Program Settings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-LOYALTY.MANAGE-LOYALTY">Manage Loyalty</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/loyalty-tiers/v1/tiers/{tier.id}
    ```

    ## Path Params

    <ParamField path="tier.id" type="string" required>

      Tier ID.

    </ParamField>

    ## Body Params

    <ParamField body="tier" type="Tier" required>

      Tier details to update.

      See the [Tier Object](/api-reference/crm/loyalty-program/loyalty-program-management/tiers/tier-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="tier" type="Tier">

      Updated loyalty tier.

      See the [Tier Object](/api-reference/crm/loyalty-program/loyalty-program-management/tiers/tier-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    This method triggers the following events:

    | --- | --- | --- |
    | Tier Updated | `wix.loyalty.v1.tier_updated` | Triggered when a tier is updated. |
