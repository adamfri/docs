    Creates a draft order.

    Pass one of the following in `source`:
    + `sourceOrderId`: Creates a draft for editing an existing order. If the order already has an active draft that you created, the existing draft is returned with `preexistingDraftOrder: true`. To apply the draft's changes to the original order, call [Commit Draft Order](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/draft-orders/commit-draft-order).
    + `draftOrder`: Creates a draft order from scratch with the provided initial values. To convert it to an order, call [Create Order From Draft](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/draft-orders/create-order-from-draft).

    <Note>

    + An order can have a single active draft at a time. If the active draft was created by a different identity, the call fails with `ORDER_IS_ALREADY_EDITED`.
    + A draft created for an existing order expires 24 hours after its last update. Modifying the draft resets the timer, and an expired draft is replaced with a new one on the next call to Create Draft Order. Drafts created from scratch don't expire.

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-ECOM-MEGA.MANAGE-ECOM">Manage eCommerce - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/ecom/v1/draft-orders
    ```

    ## Body Params

    <ParamField body="orderId" type="string">

      ID of the order to create a draft for.

    </ParamField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `428` | `FAILED_PRECONDITION` | `ORDER_CANNOT_BE_EDITED` | Order can't be edited. |
    | `409` | `ALREADY_EXISTS` | `ORDER_IS_ALREADY_EDITED` | Order is already being edited by another owner. |
    | `500` | `INTERNAL` | `FAILED_TO_FETCH_SETTINGS` | Couldn't fetch settings. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_LINE_ITEM_IDS` | Line items have duplicated IDs. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_NOT_AVAILABLE` | Catalog item isn't available. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_NOT_FOUND` | Couldn't find the catalog item. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_PAYMENT_OPTION_UNSUPPORTED` | Catalog item's payment option isn't supported. |
    | `400` | `INVALID_ARGUMENT` | `CATALOG_ITEM_ALREADY_EXIST` | There is already a catalog item with this ID on the draft order. |
    | `400` | `INVALID_ARGUMENT` | `GIFT_CARD_ITEM_UNSUPPORTED` | Gift card items aren't supported. |
    | `400` | `INVALID_ARGUMENT` | `SUBSCRIPTION_ITEM_UNSUPPORTED` | Subscription items aren't supported. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_EXTERNAL_LINE_ITEM_ID` | External line item ID isn't unique. Each line item must have a unique external ID. |
    | `404` | `NOT_FOUND` | `NOT_AUTHORIZED_TO_READ_DRAFT_ORDERS` | The [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities) used to call the method doesn't have the required permissions. |

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    + `draftOrder`: Creates a draft order from scratch with the provided initial values. To convert it to an order, call [Create Order From Draft](https://dev.wix.com/docs/api-reference/business-solutions/e-commerce/orders/draft-orders/create-order-from-draft).

    <Note>

    + An order can have a single active draft at a time. If the active draft was created by a different identity, the call fails with `ORDER_IS_ALREADY_EDITED`.
    + A draft created for an existing order expires 24 hours after its last update. Modifying the draft resets the timer, and an expired draft is replaced with a new one on the next call to Create Draft Order. Drafts created from scratch don't expire.

    </Note>
