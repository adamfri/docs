    Retrieves a list of abandoned checkouts, given the provided paging, filtering, search details and sorting. Up to 100 abandoned checkouts can be returned per request.

    | Property | Capabilities | Filters |
    | --- | --- | --- |
    | `activities.type` | Search: ✗<br />  Sort: ✗ | `$hasAll`, `$hasSome` |
    | `appliedDiscounts.coupon.code` | Search: ✗<br />  Sort: ✗ | `$hasAll`, `$hasSome` |
    | `contactDetails.firstName` | Search: <span style={{ color: "#2e7d32" }}>✓</span><br />  Sort: ✗ | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` |
    | `contactDetails.lastName` | Search: <span style={{ color: "#2e7d32" }}>✓</span><br />  Sort: ✗ | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte`, `$startsWith` |
    | `createdDate` | Search: ✗<br />  Sort: `ASC`, `DESC` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` |
    | `updatedDate` | Search: ✗<br />  Sort: `ASC`, `DESC` | `$eq`, `$ne`, `$in`, `$exists`, `$gt`, `$gte`, `$lt`, `$lte` |
    | `id` | Search: ✗<br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
    | `buyerInfo.contactId` | Search: ✗<br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
    | `buyerInfo.email` | Search: <span style={{ color: "#2e7d32" }}>✓</span><br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
    | `buyerInfo.memberId` | Search: ✗<br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
    | `buyerInfo.userId` | Search: ✗<br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
    | `buyerInfo.visitorId` | Search: ✗<br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
    | `status` | Search: ✗<br />  Sort: ✗ | `$eq`, `$in`, `$ne`, `$nin` |
