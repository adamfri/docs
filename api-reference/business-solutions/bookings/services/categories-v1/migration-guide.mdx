This guide helps you migrate from Categories V1 to the current recommended [Categories V2 API](fallback::https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/categories-v2/introduction).
Categories V1 will be removed on **January 1, 2026**.

## Key changes

The main differences between Categories V1 and V2 are:

- **List method replaced with Query**: The V1 List method is replaced by Query Categories for more flexible filtering and pagination.
- **New Move method**: V2 introduces a dedicated Move Category method for reordering, replacing the need to update categories just to change their position. Consequentially, the `sortOrder` field is now read-only and automatically managed by Wix Bookings.
- **Same core functionality**: Creating, updating, and deleting categories work similarly with updated method names.

See the [Categories V2 API documentation](fallback::https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/categories-v2/introduction) and [sample flows](fallback::https://dev.wix.com/docs/api-reference/business-solutions/bookings/services/categories-v2/sample-flows) for complete details.
