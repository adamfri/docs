    Updates a badge.

    Note that the badge `slug` is based on the badge `title`. If you update the `title`, the `slug` updates accordingly.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-BADGES">Manage Badges</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    PATCH https://www.wixapis.com/members/v3/badges/{badge.id}
    ```

    ## Path Params

    <ParamField path="badge.id" type="string" required>

      Badge ID.

    </ParamField>

    ## Body Params

    <ParamField body="badge" type="Badge" required>

      Badge to update.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges/badge-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="badge" type="Badge">

      Updated badge.

      See the [Badge Object](/api-reference/crm/members-contacts/members/activity/badges/badge-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
