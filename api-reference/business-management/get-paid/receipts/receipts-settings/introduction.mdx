Receipt settings are customizations for receipt numbering.

The Receipts Settings API enables you to managing a site's receipt numbering settings. 

## Before you begin
It's important to note the following points before starting to code:

- Only one receipts settings entity exists per site.
- A site's receipts settings can't be deleted.

## Terminology
- **Receipt**: Static document that functions as a proof of payment for a successful transaction.
- **Receipt Settings**: Site level settings related to receipts numbering schema.
