Triggered when an resource is updated.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.bookings.resources.v2.resource_updated` |
| Package | `@wix/bookings` |
| Permissions | `Read Bookings - Public Data`, `Manage Bookings`, `Read Bookings - Including Participants`, `Read Bookings - all read permissions`, `Manage Bookings - all permissions` |

## Examples

<CodeGroup>

  ```javascript onResourceUpdated
  import { resources } from '@wix/bookings';

  resources.onResourceUpdated((event) => {
      // handle your event here
  });
  ```

  ```javascript onResourceUpdated (self-hosted)
  import { createClient, AppStrategy } from '@wix/sdk';
  import { resources } from '@wix/bookings';

  const wixClient = createClient({
    auth: AppStrategy({
      appId: 'MY-APP-ID',
      publicKey: 'YOUR_APP_PUBLIC_KEY',
     }),
     modules: {
        resources,
      },
  });

  wixClient.resources.onResourceUpdated((event) => {
      // handle your event here
  });
  ```
