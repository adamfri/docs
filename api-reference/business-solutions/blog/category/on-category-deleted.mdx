Triggered when a category is deleted.

## Event details

| Property | Value |
| --- | --- |
| Event type | `wix.blog.v3.category_deleted` |
| Package | `@wix/blog` |
| Permissions | `Read Blog`, `Manage Blog`, `Read Draft Blog Posts` |
