    <div className="wix-ref">

    Retrieves a list of all data collections associated with the site or project.

    By default, the list is ordered by ID in ascending order.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-DATA.DATA-COLLECTIONS-MANAGE">Manage Data Collections</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/data/v2/collections
    ```

    ## Query Params

    <ParamField query="sort" type="Sorting">

      Defines how collections in the response are sorted.

      Default: Ordered by ID in ascending order.

      <Expandable title="sort properties">

        <ParamField query="fieldName" type="string">

          Name of the field to sort by.

          Constraints: `maxLength 1000`.

        </ParamField>

        <ParamField query="order" type="string">

          Sort order.

          **Supported values:**

          - `ASC`
          - `DESC`

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="paging" type="Paging">

      Pagination information.

      <Expandable title="paging properties">

        <ParamField query="limit" type="integer">

          Number of items to load.

        </ParamField>

        <ParamField query="offset" type="integer">

          Number of items to skip in the current sort order.

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField query="consistentRead" type="boolean">

      Whether to retrieve data from the primary database instance.
      This decreases performance but ensures data retrieved is up to date even immediately after an update.
      Learn more about [Wix Data and eventual consistency](https://dev.wix.com/api/rest/wix-data/wix-data/eventual-consistency).

      Default: `false`

    </ParamField>

    <ParamField query="fields" type="string[]">

      List of specific field names to return, if empty all fields are returned.
      Affects all returned collections

      Constraints: `maxLength 128`, `maxItems 100`.

    </ParamField>

    ## Response Object

    <ResponseField name="collections" type="DataCollection[]">

      List of collections.

      See the [Data Collection Object](/api-reference/business-solutions/cms/collection-management/data-collections/data-collection-object) for this object's fields.

    </ResponseField>

    <ResponseField name="pagingMetadata" type="PagingMetadataV2">

      Paging information.

      <Expandable title="pagingMetadata properties">

        <ResponseField name="count" type="integer">

          Number of items returned in the response.

        </ResponseField>

        <ResponseField name="offset" type="integer">

          Offset that was requested.

        </ResponseField>

        <ResponseField name="total" type="integer">

          Total number of items that match the query. Returned if offset paging is used and the `tooManyToCount` flag is not set.

        </ResponseField>

        <ResponseField name="tooManyToCount" type="boolean">

          Flag that indicates the server failed to calculate the `total` field.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
