    Retrieves a copy of an action's input mapping, with any per-action unique values regenerated.

    Used by the automations editor when a Wix user duplicates an action that contains values, such as IDs, that must remain unique across multiple actions. If the action's service plugin implements `DuplicateInputMapping`, the input mapping is passed through it; otherwise, the original input mapping is returned unchanged.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CRM.SETUP-AUTOMATIONS">Set Up Automations</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/v1/actions/copy
    ```

    ## Body Params

    <ParamField body="appId" type="string" required>

      ID of the app that defines the action.

      Constraints: `format GUID`.

    </ParamField>

    <ParamField body="actionKey" type="string" required>

      Action key.

      Learn about [adding an action to your app](https://dev.wix.com/docs/api-reference/business-management/automations/actions/add-an-action-to-your-app).

      Constraints: `maxLength 100`.

    </ParamField>

    <ParamField body="inputMapping" type="object" required>

      Input mapping to copy.

    </ParamField>

    ## Response Object

    <ResponseField name="inputMapping" type="object">

      Copied input mapping, with any per-action unique values regenerated.

    </ResponseField>
