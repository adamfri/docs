    <div className="wix-ref">

    Retrieves a list of configurations set by apps that provide the ability to create form schemas. For example, Wix Forms or Wix Bookings.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    GET https://www.wixapis.com/form-schema-service/v4/forms/providers-config
    ```

    ## Response Object

    <ResponseField name="configs" type="FormsSchemaProvidersConfig[]">

      List of configurations set by form schema providers.

      Constraints: `maxItems 50`.

      <Expandable title="configs properties">

        <ResponseField name="namespace" type="string">

          Namespace of the app which provides this configuration

          Constraints: `maxLength 50`.

        </ResponseField>

        <ResponseField name="appId" type="string">

          ID of app which provides this config.

          Constraints: `maxLength 36`.

        </ResponseField>

        <ResponseField name="restrictions" type="FormProviderRestrictions">

          Restrictions on form schemas set by this app.

          <Expandable title="restrictions properties">

            <ResponseField name="maxFormsAmount" type="integer" deprecated>

              Maximum number of forms allowed per namespace.
              Use `maxForms` instead.

              **Deprecated.** Maximum number of forms allowed per namespace.
              Use `maxForms` instead. Use `max_forms` instead. Removal: 2026-08-05. Constraints: `min 0`, `max 15000`.

            </ResponseField>

            <ResponseField name="maxFieldsAmount" type="integer" deprecated>

              Maximum number of fields allowed per form.
              Use `maxFields` instead.

              **Deprecated.** Maximum number of fields allowed per form.
              Use `maxFields` instead. Use `max_fields` instead. Removal: 2026-08-05. Constraints: `min 0`, `max 200`.

            </ResponseField>

            <ResponseField name="maxDeletedFormsAmount" type="integer">

              Maximum number of deleted forms allowed per namespace.
              Use `maxDeletedForms` instead.

            </ResponseField>

            <ResponseField name="maxForms" type="integer">

              Maximum number of forms allowed per namespace.
              Doesn't include deleted forms.

              Constraints: `min 0`, `max 15000`.

            </ResponseField>

            <ResponseField name="maxFields" type="integer">

              Maximum number of fields allowed per form.
              This includes all field types and display elements within a single form.

              Constraints: `min 0`, `max 200`.

            </ResponseField>

            <ResponseField name="maxDeletedForms" type="integer">

              Maximum number of deleted forms allowed per namespace.
              Forms in the trash bin count toward this limit.

            </ResponseField>

          </Expandable>

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
