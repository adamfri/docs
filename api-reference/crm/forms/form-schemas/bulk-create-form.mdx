    <div className="wix-ref">

    Creates multiple form schemas in a single request.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.FORMS.EDIT-FORM">Manage forms</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/forms/v4/bulk/forms/create
    ```

    ## Body Params

    <ParamField body="forms" type="Form[]">

      Form schemas to create.

      Constraints: `minItems 1`, `maxItems 30`.

      See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return the created form schemas in the response.

      Default: `false`

    </ParamField>

    ## Response Object

    <ResponseField name="results" type="BulkFormResult[]">

      Results of the bulk create operation, including created form schemas and metadata.

      <Expandable title="results properties">

        <ResponseField name="itemMetadata" type="ItemMetadata">

          Metadata about the bulk operation result for this form schema.

          <Expandable title="itemMetadata properties">

            <ResponseField name="id" type="string">

              Item ID. Should always be available, unless it's impossible (for example, when failing to create an item).

            </ResponseField>

            <ResponseField name="originalIndex" type="integer">

              Index of the item within the request array. Allows for correlation between request and response items.

            </ResponseField>

            <ResponseField name="success" type="boolean">

              Whether the requested action was successful for this item. When `false`, the `error` field is populated.

            </ResponseField>

            <ResponseField name="error" type="ApplicationError">

              Details about the error in case of failure.

              _Nested structure omitted for brevity — see the `ApplicationError` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="item" type="Form">

          Deleted form schema.

          See the [Form Object](/api-reference/crm/forms/form-schemas/form-object) for this object's fields.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="bulkActionMetadata" type="BulkActionMetadata">

      Metadata about the bulk operation.

      <Expandable title="bulkActionMetadata properties">

        <ResponseField name="totalSuccesses" type="integer">

          Number of items that were successfully processed.

        </ResponseField>

        <ResponseField name="totalFailures" type="integer">

        </ResponseField>

        <ResponseField name="undetailedFailures" type="integer">

          Number of failures without details because detailed failure threshold was exceeded.

        </ResponseField>

      </Expandable>

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_FIELD_TARGETS` | Multiple fields have the same target name. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_FIELD_IDS` | Multiple fields have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_STEP_IDS` | Multiple steps have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `DUPLICATED_RULE_IDS` | Multiple rules have the same ID. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_FIELD_TARGETS` | Fields are missing required target names. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_FIELD_TARGETS_NAME` | Field target names aren't supported for this field type. |
    | `400` | `INVALID_ARGUMENT` | `MISSING_NESTED_FORM_IDS` | Nested form fields are missing required form IDs. |
    | `400` | `INVALID_ARGUMENT` | `NON_EXISTING_NESTED_FORMS` | Referenced nested forms don't exist. |
    | `400` | `INVALID_ARGUMENT` | `NESTED_FORM_FIELDS_MISSING` | Nested form is missing required fields. |
    | `400` | `INVALID_ARGUMENT` | `FIELD_SCHEMA_NOT_SUPPORTED` | Field schema isn't supported by the platform. |
    | `400` | `INVALID_ARGUMENT` | `UNSUPPORTED_FORM_NAMESPACE` | Form namespace isn't supported. |
    | `400` | `INVALID_ARGUMENT` | `FORM_FIELDS_COUNT_EXCEEDED` | Number of form fields exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `NAMESPACE_FORMS_COUNT_EXCEEDED` | Number of forms in the namespace exceeds the server's limit. |
    | `400` | `INVALID_ARGUMENT` | `NAMESPACE_DELETED_FORMS_COUNT_EXCEEDED` | Number of deleted forms in the namespace exceeds the server's limit. |

    | `400` | `INVALID_ARGUMENT` | `MULTI_NAMESPACE_BULK_OPERATION` | Bulk operation can't be performed across multiple namespaces. |
