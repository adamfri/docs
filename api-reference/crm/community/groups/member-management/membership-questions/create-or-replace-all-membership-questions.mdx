<Tabs>

  <Tab title="REST">

    <div className="wix-api-columns">

    <div className="wix-ref">

    Creates membership questions if none have been set up. Otherwise, replaces all existing questions.

    Providing an empty array means that members won't have to answer any question when joining the group.
    Only admins can create or replace membership questions.

    <Note>

    This endpoint requires [visitor or member authentication](https://dev.wix.com/docs/rest/articles/getting-started/access-types-and-permissions).

    </Note>

    ## Endpoint

    ```http
    PUT https://www.wixapis.com/social-groups-proxy/questions/v2/membership-questions/{groupId}
    ```

    ## Path Params

    <ParamField path="groupId" type="string" required>

      Group ID.

    </ParamField>

    ## Body Params

    <ParamField body="questions" type="MembershipQuestion[]">

      New membership questions.

      Constraints: `maxItems 50`.

      See the [Membership Question Object](/api-reference/crm/community/groups/member-management/membership-questions/membership-question-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="questions" type="MembershipQuestion[]">

      Membership questions.

      See the [Membership Question Object](/api-reference/crm/community/groups/member-management/membership-questions/membership-question-object) for this object's fields.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
