    Retrieves region suggestions for partial text, for autocompleting a city,
    state or region as someone types.

    Only places of that kind come back. Street addresses and businesses never
    do, so use Suggest Establishments to autocomplete a business name.

    Needs no connected Google account and no existing location. Text shorter
    than 3 characters returns an empty list rather than an error, so you can
    call it on every keystroke.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.PROMOTE.MANAGE-SEO">Manage SEO Settings</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/gbp/v1/regions/suggest
    ```

    ## Body Params

    <ParamField body="query" type="string" required>

      Partial free-text the end-user is typing (e.g. "new y"). Sent per debounced
      keystroke; Google returns region/city predictions matching this prefix.
      Queries shorter than 3 chars return an empty list (handled server-side),
      not an error.

      Constraints: `minLength 1`, `maxLength 200`.

    </ParamField>

    <ParamField body="countryCode" type="string" required>

      ISO 3166-1 alpha-2 country to restrict results to (e.g. "US").

      Constraints: `format COUNTRY`.

    </ParamField>

    <ParamField body="languageCode" type="string">

      Optional BCP-47 language for the returned names (e.g. "fr"). Defaults to
      Google's behavior (typically the account/region language) when empty.

      Constraints: `maxLength 35`.

    </ParamField>

    ## Response Object

    <ResponseField name="suggestions" type="RegionSuggestion[]">

      Region/city predictions ranked by Google, best match first.

      Constraints: `maxItems 20`.

      <Expandable title="suggestions properties">

        <ResponseField name="placeId" type="string">

          Google's opaque place identifier for the predicted region.

          Constraints: `maxLength 255`.

        </ResponseField>

        <ResponseField name="description" type="string">

          Full human-readable prediction text (e.g. "New York, NY, USA").

          Constraints: `maxLength 512`.

        </ResponseField>

        <ResponseField name="mainText" type="string">

          Primary part of the prediction (e.g. "New York"), for bold styling.

          Constraints: `maxLength 512`.

        </ResponseField>

        <ResponseField name="secondaryText" type="string">

          Secondary part of the prediction (e.g. "NY, USA"), for muted styling.

          Constraints: `maxLength 512`.

        </ResponseField>

      </Expandable>

    </ResponseField>
