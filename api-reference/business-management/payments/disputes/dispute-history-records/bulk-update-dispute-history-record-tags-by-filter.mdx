    <div className="wix-ref">

    Asynchronously updates tags on multiple dispute history records based on filter criteria.
    Returns a job ID that can be used to track the operation status. If a tag appears in both assign and unassign lists, it will be assigned.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PAYMENTS.MANAGE-DISPUTES">Manage Disputes</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/payments/dispute-history-records/v1/bulk/dispute-history-records/update-tags-by-filter
    ```

    ## Body Params

    <ParamField body="filter" type="object" required>

      Filter that determines which disputes to update tags for.

      An empty filter updates all disputes.

    </ParamField>

    <ParamField body="assignTags" type="Tags">

      Tags to assign to the filtered dispute history records.

      <Expandable title="assignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="publicTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="unassignTags" type="Tags">

      Tags to remove from the filtered dispute history records.

      <Expandable title="unassignTags properties">

        <ParamField body="privateTags" type="TagList">

          Tags that require an additional permission in order to access them, normally not given to site members or visitors.

          <Expandable title="privateTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

        <ParamField body="publicTags" type="TagList">

          Tags that are exposed to anyone who has access to the labeled entity itself, including site members and visitors.

          <Expandable title="publicTags properties">

            <ParamField body="tagIds" type="string[]">

              List of tag IDs.

              Constraints: `maxLength 5`, `maxItems 100`.

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    ## Response Object

    <ResponseField name="jobId" type="string">

      Job ID for tracking the asynchronous bulk update operation.

      Constraints: `format GUID`.

    </ResponseField>

