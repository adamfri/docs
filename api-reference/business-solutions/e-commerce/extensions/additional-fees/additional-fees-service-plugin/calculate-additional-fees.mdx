    Requests calculation of additional fees from the service plugin implementer for a given cart or checkout.

    Wix calls this method when a site visitor views their cart, begins checkout, or when cart contents change during the checkout process.

    Wix uses the returned additional fees to display line items on the cart and checkout pages and to calculate the final order total.

    Your implementation must respond within 3 seconds. Longer response times result in timeout errors.

    **Restrictions:** Do not call the Estimate Cart Totals, Estimate Current Cart Totals, or Get Checkout methods from your implementation. Doing so results in a runtime error.

    **Error handling:** If your implementation returns an error or times out, Wix proceeds without additional fees. The site visitor won't see additional fees on their cart or checkout.

    ## Endpoint

    ```http
    POST /v1/calculate-additional-fees
    ```

    ## Response Object

    <ResponseField name="additionalFees" type="AdditionalFee[]">

      Additional fees calculated for the cart or checkout. Each fee represents a separate line item that will be added to the order total.

      Constraints: `maxItems 100`.

      <Expandable title="additionalFees properties">

        <ResponseField name="code" type="string">

          Unique code identifying the type of fee. For example, `fragile-packaging` or `gift-wrap`. Used for internal tracking and reporting.

        </ResponseField>

        <ResponseField name="name" type="string">

          Display name of the fee shown to the site visitor on the cart and checkout pages. For example, "Fragile Packaging Fee" or "Gift Wrapping".

          Constraints: `minLength 1`, `maxLength 50`.

        </ResponseField>

        <ResponseField name="price" type="string">

          Price of the fee, excluding any tax. This amount is added to the order total.

          If `taxDetails.taxable` is `true`, Wix calculates tax on top of this price — do not include tax in this value.

          Constraints: `>= 0`, `<= 1000000000000000`.

        </ResponseField>

        <ResponseField name="taxDetails" type="TaxDetails">

          Tax information for the fee. Determines whether the fee is taxable and which tax rules apply.

          <Expandable title="taxDetails properties">

            <ResponseField name="taxable" type="boolean">

              Whether the fee is subject to tax. When `true`, Wix applies the site's tax rules to calculate tax on the fee amount.

              Default: `false`

            </ResponseField>

            <ResponseField name="taxGroupId" type="string">

              ID of the tax group that defines tax rates and rules for this fee. If provided, Wix uses the specified tax group's configuration instead of the default tax settings.

              Available only when `taxable` is `true`.

            </ResponseField>

            <ResponseField name="taxableAddress" type="TaxableAddress">

              Address type to calculate tax against for this fee.

              Available only when `taxable` is `true`.

              **Developer Preview.**

              _Nested structure omitted for brevity — see the `TaxableAddress` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="lineItemIds" type="string[]">

          IDs of line items this fee applies to. Use this to associate the fee with specific items in the cart. For example, a fragile packaging fee might only apply to breakable items.

          If empty, the fee applies to the entire order.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="translatedName" type="string">

          Translated display name of the fee. When provided, this value is shown to the site visitor instead of `name`.

          Use this field to provide localized fee names based on the site visitor's language preferences.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="currency" type="string">

      Three-letter currency code in [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217) format. Must match the currency of the Wix site where the fees are being calculated — if it doesn't match, the fees in this response are silently filtered out and not applied to the order.

      Constraints: `maxLength 3`.

    </ResponseField>

    <ResponseField name="additionalFees" type="AdditionalFee[]">

      Additional fees calculated for the cart or checkout. Each fee represents a separate line item that will be added to the order total.

      Constraints: `maxItems 100`.

      <Expandable title="additionalFees properties">

        <ResponseField name="code" type="string">

          Unique code identifying the type of fee. For example, `fragile-packaging` or `gift-wrap`. Used for internal tracking and reporting.

        </ResponseField>

        <ResponseField name="name" type="string">

          Display name of the fee shown to the site visitor on the cart and checkout pages. For example, "Fragile Packaging Fee" or "Gift Wrapping".

          Constraints: `minLength 1`, `maxLength 50`.

        </ResponseField>

        <ResponseField name="price" type="string">

          Price of the fee, excluding any tax. This amount is added to the order total.

          If `taxDetails.taxable` is `true`, Wix calculates tax on top of this price — do not include tax in this value.

          Constraints: `>= 0`, `<= 1000000000000000`.

        </ResponseField>

        <ResponseField name="taxDetails" type="TaxDetails">

          Tax information for the fee. Determines whether the fee is taxable and which tax rules apply.

          <Expandable title="taxDetails properties">

            <ResponseField name="taxable" type="boolean">

              Whether the fee is subject to tax. When `true`, Wix applies the site's tax rules to calculate tax on the fee amount.

              Default: `false`

            </ResponseField>

            <ResponseField name="taxGroupId" type="string">

              ID of the tax group that defines tax rates and rules for this fee. If provided, Wix uses the specified tax group's configuration instead of the default tax settings.

              Available only when `taxable` is `true`.

            </ResponseField>

            <ResponseField name="taxableAddress" type="TaxableAddress">

              Address type to calculate tax against for this fee.

              Available only when `taxable` is `true`.

              **Developer Preview.**

              _Nested structure omitted for brevity — see the `TaxableAddress` object._

            </ResponseField>

          </Expandable>

        </ResponseField>

        <ResponseField name="lineItemIds" type="string[]">

          IDs of line items this fee applies to. Use this to associate the fee with specific items in the cart. For example, a fragile packaging fee might only apply to breakable items.

          If empty, the fee applies to the entire order.

          Constraints: `format GUID`.

        </ResponseField>

        <ResponseField name="translatedName" type="string">

          Translated display name of the fee. When provided, this value is shown to the site visitor instead of `name`.

          Use this field to provide localized fee names based on the site visitor's language preferences.

        </ResponseField>

      </Expandable>

    </ResponseField>

    <ResponseField name="currency" type="string">

      Three-letter currency code in [ISO-4217 alphabetic](https://en.wikipedia.org/wiki/ISO_4217) format. Must match the currency of the Wix site where the fees are being calculated — if it doesn't match, the fees in this response are silently filtered out and not applied to the order.

      Constraints: `maxLength 3`.

    </ResponseField>
