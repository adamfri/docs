    Calculates service fees for an order.

    The specified order information is evaluated against all rules created for the site. If the rule conditions are met, the service fee set in the rule is applied. Otherwise, no service fee is added.

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.RESTAURANTS.MEGA-SCOPES">Manage Restaurants - all permissions</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `MEMBER`, `APP`, `VISITOR`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/service-fees/v1/calculate
    ```

        <ParamField body="priceSummary" type="PriceSummary" required>

          <Expandable title="priceSummary properties">

              Subtotal of the order.

            </ParamField>

          </Expandable>

        <ParamField body="shippingInfo" type="ShippingInformation">

          <Expandable title="shippingInfo properties">
