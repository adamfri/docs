    Creates up to 100 steps in a single API call.

    Specify the parent section in each step's `sectionId`.
    The service derives the parent program automatically.
    To create quiz steps, create or clone the quizzes separately, then specify their IDs in each step's `quizOptions.id`.

    This is the preferred bulk-create method.
    To create a single step, call [CreateStep](https://dev.wix.com/docs/api-reference/business-management/online-programs/steps/create-step).

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.CHALLENGES.MANAGE">Manage Online Programs</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/online-programs/v3/bulk/steps/create
    ```

    ## Body Params

    <ParamField body="steps" type="Step[]" required>

      Steps to create.

      Constraints: `minItems 1`, `maxItems 100`.

      See the [Step Object](/api-reference/business-management/online-programs/steps/step-object) for this object's fields.

    </ParamField>

    <ParamField body="returnEntity" type="boolean">

      Whether to return created steps in the response.

    </ParamField>
