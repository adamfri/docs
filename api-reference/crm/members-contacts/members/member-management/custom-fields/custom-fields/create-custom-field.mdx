    Creates a custom field.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-MEMBERS.MANAGE-MEMBERS">Manage Members</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/members/v1/custom-fields
    ```

    ## Body Params

    <ParamField body="field" type="CustomField" required>

      Custom field to create.

      See the [Custom Field Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-fields/custom-field-object) for this object's fields.

    </ParamField>

    ## Response Object

    <ResponseField name="field" type="CustomField">

      Created custom field.

      See the [Custom Field Object](/api-reference/crm/members-contacts/members/member-management/custom-fields/custom-fields/custom-field-object) for this object's fields.

    </ResponseField>

    ## Errors

    | Status | Code | Application code | Description |
    | --- | --- | --- | --- |
    | `400` | `INVALID_ARGUMENT` | `INCORRECT_FIELD_TYPE` | Custom field `fieldType` is invalid. |
    | `400` | `INVALID_ARGUMENT` | `INCORRECT_FIELD_PRIVACY` | Custom field `defaultPrivacy` is invalid. |
    | `400` | `INVALID_ARGUMENT` | `INVALID_FIELD_SOCIAL_TYPE` | Custom field `socialType` is invalid. |

    <Note>

      This method may also return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>
