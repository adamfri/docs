    <div className="wix-ref">

    Builds an HTML preview of the campaign. Use this to display what the email will look like before publishing.

    <Note>

      **Authentication**

      You can only call this method when authenticated as a Wix app or Wix user [identity](https://dev.wix.com/docs/api-reference/articles/authentication/about-identities).

    </Note>

    ## Permissions

    This method requires one of the following permission scopes:

    <div className="wix-scopes">

    <span className="wix-scope" title="SCOPE.DC-PROMOTE.EMAIL-MARKETING">Manage Email Marketing</span>

    </div>

    Learn more about [app permissions](https://dev.wix.com/docs/build-apps/develop-your-app/access/authorization/about-permissions).

    Callable by: `APP`.

    ## Endpoint

    ```http
    POST https://www.wixapis.com/email-marketing/v1/campaigns/{campaignId}/preview
    ```

    ## Path Params

    <ParamField path="campaignId" type="string" required>

      ID of the campaign to preview.

    </ParamField>

    ## Body Params

    <ParamField body="placeholders" type="object">

      Values to replace campaign placeholders with (unique for each campaign).

      Constraints: `format map`.

      <Expandable title="placeholders properties">

        <ParamField body="key" type="string" />

        <ParamField body="value" type="PlaceholderContent">

          A typed value used to substitute a named placeholder in campaign content. Placeholders appear in campaign templates as named tokens, and this message provides the replacement value for a given key.

          <Expandable title="One of the following">

            <ParamField body="value" type="value">

              value

              _Nested structure omitted for brevity — see the `value` object._

            </ParamField>

          </Expandable>

        </ParamField>

      </Expandable>

    </ParamField>

    <ParamField body="removeMissingPlaceholders" type="boolean">

      When true, unresolved placeholders are removed from the preview.
      When false (default), unresolved placeholders remain visible.

    </ParamField>

    ## Response Object

    <ResponseField name="html" type="string">

      Preview HTML.

    </ResponseField>

    <ResponseField name="emailSubject" type="string">

      Email subject with resolved dynamic parameters.

      Constraints: `maxLength 1000`.

    </ResponseField>

    ## Errors

    <Note>

      This method doesn't return any custom errors, but may return standard errors. [Learn more about standard Wix errors](https://dev.wix.com/docs/rest/articles/getting-started/errors).

    </Note>

    </div>
